# Signed binomial supercongruences — OEIS A352373

Research note dated 18 September 2026. This package contains a conventional
proof of the assertion still labelled conjectural in OEIS A352373 at the time
of consultation, together with extensions and exact computational checks.

## Result

For integers r,s, a nonnegative integer t, and

    a(n) = [x^(t*n)] (1+x)^(r*n) (1-x)^(s*n),

we prove, for all positive integers m,h,

    a(m*p^h) == a(m*p^(h-1)) mod p^(3*h)      for primes p >= 5,
    a(m*3^h) == a(m*3^(h-1)) mod 3^(3*h-1).

Negative exponents mean formal power series. The parameter m need not be
coprime to p. The OEIS family conjecture is t=1. The note covers A352373,
A348410, A351856, and A351857 as explicit specializations. A234839 is a known
special case and is not presented as a new discovery.

The proof's only non-elementary imported theorem is the classical Jacobsthal
binomial congruence, including negative upper entries, cited precisely in the
paper. All weighted-cancellation and valuation deductions are included.

## Reproduce the computations

Requires Python 3.9 or newer. No third-party Python packages, network connection,
computer algebra system, or proof assistant are required.

From the extracted package directory:

```sh
python code/verify.py --output results
```

On systems whose Python executable is named `python3`, substitute that name.
The script checks exact integers and rational residues, never floating-point
approximations. The two independent coefficient algorithms are a binomial
convolution and the recurrence obtained from the first-order differential
equation for `(1+x)^R(1-x)^S`. Every recurrence division is checked to be exact.

The included run used Python 3.13.5 and passed:

| Collection | Checks |
|---|---:|
| Family congruences | 13,690 |
| Proof-component congruences | 15,154 |
| Möbius-transform denominator checks | 500 |

Of the family differences, 10,050 were nonzero and 3,640 were zero. The JSON
file specifies the actual parameter grid and selected prime/height/base cases;
the tests do not claim to cover all primes or all parameters below an unstated
bound. Randomized cases use seed 352373. An empty valuation in the CSV means
that the difference is zero, whose p-adic valuation is infinite.

The output files are intentionally regenerated by the command above. Counts
and case records are deterministic; elapsed time and Python version may differ.
Assertions use explicit checks and remain enabled under `python -O`.

For an individual value:

```python
import sys
sys.path.insert(0, "code")
from verify import sequence

print(sequence(-1, -3, 1, 5))   # A352373(5) = 3252
```

## Compile the paper

A normal TeX Live or MiKTeX installation with `newpx`, `amsmath`, `amsthm`,
`mathtools`, `microtype`, `geometry`, `tcolorbox`, `hyperref`, and `cleveref`
(and the standard packages listed in the source) is sufficient.
No separate font files or images are needed.

```sh
pdflatex -interaction=nonstopmode -halt-on-error signed_binomial_supercongruence.tex
pdflatex -interaction=nonstopmode -halt-on-error signed_binomial_supercongruence.tex
```

## Scope and status

This is an unrefereed AI-assisted research draft, not an independently reviewed
or proof-assistant-verified result. The finite tests are not the proof; the
paper supplies the all-parameter mathematical argument. The general assertion
was still labelled conjectural in OEIS, but the literature search was limited.
An equivalent theorem under another formulation has not been ruled out, and
publication priority is not claimed. No OEIS submission or other external
write was made.
