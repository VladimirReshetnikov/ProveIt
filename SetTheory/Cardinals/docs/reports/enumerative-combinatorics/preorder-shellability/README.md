# An explicit shelling for preorder lattice-point posets

**Research draft, 20 September 2026.** A complete proposed affirmative solution
to Question 4.6 of Athanasiadis and Chapoton, *Polytopes and posets associated
to preorders*, arXiv:2605.26916v1, p. 13.

## Result

For any finite preorder τ on [n], let Pτ consist of nonnegative integer
vectors a satisfying a(I) ≤ |I| for every order ideal I, ordered coordinatewise.
The article constructs an explicit pure shelling of the order complex of
Pτ with its minimum removed. Coning also shells the order complex of Pτ.
Both complexes are Cohen–Macaulay over the integers and over every field.

The proof extends to the integer independence poset of every integral
polymatroid. It includes two proofs of the needed insertion exchange property,
an exact description of every shelling restriction face, ordinary and flag
h-enumerators, shellability of rank selections, and a separate proof of
contractibility in the nonempty unweighted preorder case.

The essential construction orders bases decreasingly lexicographically, then
orders the chains ending at each base by a **base-dependent** alphabet.
Coordinates allowing a unit transfer to an earlier coordinate are placed last.
The article proves that this order makes every overlap exactly a union of
codimension-one faces.

This is not a duplicate of the manifest's preorder reciprocity or
root-polytope reports. Their enumerative conclusions are not proof inputs.
See `manifest_selection.md` for the precise comparison.

## Reproduce

Use Python **3.10 or later**, without `-O`. No third-party Python packages are
needed. The program rejects optimized execution because assertions are checks.
From this directory:

```sh
python3 code/verify.py --output results
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
```

On a system where Python is named `python`, substitute that command for
`python3`. Building the PDF needs an ordinary TeX Live or MiKTeX installation
with the packages named in the article preamble. No shell escape, bibliography
processor, external graphics, or proprietary fonts are required. The worked
LaTeX table is regenerated by the verifier; a generated copy is already included.

GNU Make users can run `make verify` and `make pdf`, or `make all`. Set
`PYTHON=python` or `LATEX=pdflatex` as needed. `make clean` removes only TeX
intermediates and Python caches, not the PDF, source, or recorded mathematical data.

## Recorded scope

All exact checks passed for:

| Family | Cases | Facets checked |
| --- | ---: | ---: |
| All labeled preorders on 1–4 elements | 389 | 33,640 |
| All exchange families in 3 coordinates, ranks 1–3 | 126 | 1,242 |
| Weighted 3-element preorders, capacities (2,1,1) and (0,2,2) | 58 | 2,020 |

The 126 exchange families were selected by testing all 1,093 nonempty
subfamilies of the relevant weak-composition sets. The empty preorder is also
checked separately.

The verifier constructs actual prefix-vector facets, enumerates their subfaces,
and checks pure shelling intersections and restriction faces directly. It also
compares inequality-defined bases with complete supply assignments, and compares
ordinary and flag h-enumerators with independent face-count transforms.

`--max-n 5` is available but **no exhaustive size-five run is included or claimed**.
The verifier intentionally enumerates all 2^r subfaces of each rank-r facet.

## Status and limitations

The all-size assertions are based on the proofs, not extrapolation from the
finite computations. This draft has not been independently refereed or checked
in a proof assistant. The source explicitly poses the selected question;
targeted searches did not locate a resolution. That search does not establish
priority for every general shelling lemma, particularly in the related
multicomplex literature. Ordinary shellability is carefully distinguished from
M-shellability. No EL-labeling, general real-rootedness result, or flag-polytope
realization is claimed. See `STATUS.md` and `sources.md`.
