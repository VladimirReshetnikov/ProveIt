# Data and provenance

The two JSON files serve different purposes and must not be conflated.

- `exact_coefficients.json` is locally generated by `code/make_fixtures.py`.
  It contains exact integer coefficients through index 64 for H, G, F, J2 and
  the defect B, plus rooted-tree coefficients r through index 66. It is a
  reproducible regression fixture, not an independent external observation.
  The independent bounded-degree and canonical colored-tree checks provide
  separate finite validations of the identities using these coefficients.
- `oeis_samples.json` contains 29 displayed terms from each linked primary
  OEIS entry, observed on 5 October 2026. The terms were transcribed from
  the displayed data rows, separately from the local recurrence outputs.
  A244407 starts at n=1 and is compared with f[n-1]. A244410 starts at n=0;
  its special n=0 term is 1, and its positive-index terms are compared with
  f[n]-1. These samples do not claim complete b-file coverage.

No coefficients in `exact_coefficients.json` are loaded to calculate a
sequence: the runner first recalculates the arrays and then compares them
with the fixture. It likewise loads the external sample only after the
calculation. The coefficient algorithms do not require network access.

To independently regenerate the exact fixture without changing this copy,
run from the package root, choosing a NEW output file (existing files and symlinks are rejected):

```sh
python -B code/make_fixtures.py --output /tmp/report227-coefficients.json
cmp data/exact_coefficients.json /tmp/report227-coefficients.json
```

Numerical diagnostics are produced on demand by `code/reproduce.py` and are
not exact data fixtures. Their constants and decimal values are explicitly
not interval-certified.
