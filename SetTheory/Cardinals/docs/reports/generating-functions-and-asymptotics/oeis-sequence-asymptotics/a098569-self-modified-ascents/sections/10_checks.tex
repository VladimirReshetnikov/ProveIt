\section{Reproducible checks and their precise scope}
\label{sec:checks}
The accompanying package contains the complete TeX source, four deterministic computational receipts, the checking programs, an immutable-source builder and an actual-archive replay verifier. The programs use Python 3.11 or later, mpmath 1.3.0 and SymPy 1.14.0. Their roles are finite validation and reproducibility; the preceding analytic arguments establish the theorems.

\subsection{Exact and symbolic checks}
The exact verifier independently computes the binomial sums and the coefficients obtained by multiplying individual cell generating polynomials. Its default range is $0\le N\le40$. It checks all 820 positive-size triangle entries in that range, 820 conditional binary products, 820 fixed-dimension binomial-transform identities, 1640 residual-cell tail identities, 1640 direct bad-cell expectation comparisons, and the 40 total transforms. The expectation check uses a separate cell-polynomial recurrence carrying summed indicators and includes the zero-residual cases. Source-linked finite fixtures check 26 ordinary and 25 binary terms with the current shifts in \eqref{eq:index}. The code also calculates exact sums at $N=100,200,500,1000,2000$.

The symbolic verifier independently enumerates weighted multi-indices, applies exact Gaussian moments, and compares the results with $C_1,C_2,Q_1,Q_2$. It generates $C_3$ as well. A second weighted-exponential route checks the numerator contractions through weight four. Further exact algebra checks the moment formulas, the constants $1/24$ and $1/1152$, the rational identity in Theorem~\ref{thm:rational}, $F_0'=u$, the inverse equation and the seed separation. No coefficient is fitted to numerical data.

Large exact integers are hashed using their unsigned big-endian byte encodings; they are not converted to unbounded decimal strings. Each Python process explicitly sets a 640-digit decimal conversion cap and disables bytecode writes. Every child invocation repeats these settings. Guards use explicit exceptions, so optimized Python cannot remove validation.

\subsection{Finite numerical diagnostics}
The default numerical cases use 90 decimal digits at unmarked sizes $100,200,500,1000,2000$, together with marks $t=\pm0.25$ at $N=500$. The exact gamma phase is retained. A bounded finite-precision bisection solves the saddle equation, checking endpoint signs and residuals. The script compares exact integer sums with the saddle carriers and moment corrections, records the full-support leading local-limit error and the tail mass outside $I_N$, and evaluates both binary carriers and inverse seeds.

\subsection{Build and replay discipline}
The public source inventory is complete: every file other than the manifest itself is hashed, and extra files, directories, symlinks or malformed names are rejected. The builder does not regenerate its own manifest. It requires a new output directory outside the source tree and compares source inventories before and after its work.

The PDF is compiled from a disposable copy with a private TeX format and cache, three passes, fixed date and metadata, and shell escape disabled. Overfull boxes, missing glyphs and unresolved references are rejected. The builder requires the regenerated PDF and all four computational receipts to match their frozen originals byte for byte. It writes a deterministic archive with fixed member order, timestamps and modes.

The archive replay first validates the actual input ZIP against the trusted source package. It extracts two separate copies and builds under ordinary Python and Python with optimization. It compares all seven top-level output files: the PDF, ZIP, four receipts and build-check record. It also compares archive member bytes and metadata, requires each regenerated ZIP to equal the original input archive, and checks that the trusted source tree, both extracted source trees and input archive remain unchanged. The 241 finite guard cases and operational bounds are enumerated in the computation note. These filesystem tests are not a general security proof against hostile concurrent changes.

The document was rendered and visually inspected page by page before packaging. Reproducibility is asserted for the recorded toolchain, not arbitrary TeX or library versions. All finite checks remain distinct from effective asymptotic bounds, external peer review and formal proof verification.
