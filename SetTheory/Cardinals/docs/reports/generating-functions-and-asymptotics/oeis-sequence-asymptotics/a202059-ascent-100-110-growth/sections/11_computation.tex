\section{Bounded computation and reproducibility}\label{sec:computation}
The accompanying source package contains this \LaTeX\ article, bounded Python programs, source-prefix fixtures with URLs, deterministic receipts, an integrity manifest, and a builder. It redistributes no third-party paper. The computational checks exercise the finite maps and inequalities; the proofs above establish the all-length asymptotics.

The checks recompute source recurrence prefixes for $100$ and $110$ and compare small cases with independent literal pattern enumeration. They inspect refined run ceilings, candidate pools, skeleton reconstruction, the Vandermonde bound, and the exact triangular-term identity. The lower checks use explicit stars-and-bars ranks and inverse decoding, test positivity and legality, and measure repair, block-composition, and padding fibers separately. They also test doubled seeds and all-length parameter choices. Exact empty-row distributions include cases with a nonzero rejected tail and $Q<r$, so the retained-half check is not limited to vacuous cutoffs. No fitted exponent or numerical trend is used as a proof of an asymptotic assertion.

Inputs and resources are bounded; validation uses explicit exceptions rather than removable assertion statements. Every spawned Python process runs with bytecode writing disabled and the integer-to-decimal conversion limit fixed at $640$ digits. Large integers are summarized by byte-based hashes when necessary. Both ordinary and optimized Python execution must reproduce the same receipts.

The builder verifies the complete source manifest, works in a fresh output directory outside the sources, and compiles a disposable copy with a private \TeX\ format, fixed timestamps, and shell escape disabled. The archived PDF and fresh PDF must agree byte for byte on the recorded toolchain. The separate replay command validates an actual archive, extracts two copies, builds under normal and optimized Python, and compares all archive members, metadata, PDFs, receipts, and build outputs. Its original-build directory option also checks those outputs against the first build. Source-tree inventories must remain unchanged. An integrity manifest is not a digital signature, and byte reproducibility is not a substitute for mathematical proof.

The companion files \texttt{README.md} and \texttt{COMPUTATION.md} give the exact bounded ranges, commands, and receipt interpretation. A different \TeX\ distribution or font version may change PDF bytes even when the mathematics and rendered appearance agree; the strict comparison intentionally reports such a difference rather than silently accepting it.
