# Three Exceptions Before Every Square

A research report on OEIS A097356, A206226, A206227, and A206240.
Prepared for Vladimir Reshetnikov, October 1, 2026.

## Main result

Let A(N) count partitions of N with parts at most floor(sqrt(N)). Let
u > 0 solve integral_0^1 x/(exp(u*x)-1) dx = 1, and set

    rho = 1-exp(-u)
    H = 2*u-log(rho)
    C = u/(2*pi*sqrt(2-3*exp(-u)))
    C_lower = C*rho

The report proves that the liminf of N*A(N)*exp(-H*sqrt(N)) is C_lower,
confirming the conjectured sharp lower asymptotic constant in A097356.
However, a literal eventual lower inequality with that constant fails.
For all sufficiently large m, it fails at exactly

    N = (m+1)^2-3, (m+1)^2-2, (m+1)^2-1

within m^2 <= N < (m+1)^2. An effective smallest such m is not established.

The report also proves a uniform all-orders coefficient expansion,
phase-polynomial corrections, a limiting distribution, a summatory law,
and phase-sensitive inverse formulas. Ignoring the inverse phase can
cause order-log(Y) index errors; the phase map reduces these to O(1).

## Attribution and limits

The leading restricted-partition asymptotic is classical Szekeres theory.
The pre-existing OEIS amplitudes are credited, not presented as new.
The particular endpoint and inverse refinements are developed and proved
in this report. This is not an exhaustive worldwide priority audit.

The proofs are conventional analytic proofs, accompanied by executable
checks. No Lean/Coq formalization is included or claimed. The rational
certificate verifies the finite coefficient signs using the analytic tail
bounds proved in Appendix A; it does not formalize the contour analysis.
The arbitrary-precision numerical tables are checks, not proofs of the
asymptotic theorem. A complete exponentially improved/resurgent
transseries and uniform all-orders inverse switching layers remain open
research directions in the report.

## Reproduce the exact rational certificate

The completed run used Python 3.13.5; Python 3.11 or newer is recommended. No third-party dependency is needed
for this command:

```sh
python certificate.py
```

Assertions must remain enabled: do not run Python with `-O`.
Every arithmetic interval endpoint in this script is an exact Fraction.
Printed decimal enclosures are rounded outward.

## Reproduce the tables

```sh
python -m pip install -r requirements.txt
python verify.py --max-m 256 --output results
```

The included run used mpmath 1.3.0 and 80 decimal digits. Partition counts
and threshold comparisons are exact integers. All A097356 counts through
N=66048 were generated; the first 54 A097356 terms and first 17 A206226
terms were checked against the inspected OEIS entries. Counts for all
indices are used during the run but not redundantly stored in the ZIP;
selected exact values are in the CSV files and the full range can be
regenerated by the driver.

For a faster smoke test that does not overwrite the supplied results:

```sh
python verify.py --max-m 32 --output smoke-results
```

The algorithm takes O(max_m^3) arbitrary-precision integer additions and
stores O(max_m^2) integers. Those are operation counts, not bit-complexity
or fixed-time guarantees.

## Regenerate the figures (optional)

The figures are already included. To recreate them:

```sh
python -m pip install -r requirements-figures.txt
python make_figures.py
```

The generator uses Matplotlib's default color cycle, no custom fonts,
and the saved exact-count comparison data. The title derives its block
index from the data, so a smaller verification run is labeled correctly.

## Build the PDF

A TeX installation with newtx, amsmath, amsthm, mathtools, microtype,
geometry, graphicx, booktabs, tabularx, enumitem, xurl, hyperref, cleveref,
fancyhdr, listings, and caption is sufficient.

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error article.tex
```

Alternatively run `pdflatex article.tex` three times to stabilize the
contents and cross-references. The PDF figures must remain at their
relative paths under `figures/`.

The source repository was read, not modified. This ZIP is a standalone
research package and does not depend on a local ProveIt checkout.
