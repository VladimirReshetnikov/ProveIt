Python 3.10 or later; standard library only.
A TeX Live installation with pdfLaTeX, pdftex, and kpsewhich.
LaTeX packages: fontenc, lmodern, microtype, amsmath, amssymb, amsthm,
mathtools, booktabs, array, geometry, hyperref, fancyhdr.
Poppler pdftoppm and pdfinfo are used for optional visual quality assurance,
not by the deterministic archive builder.
No network access is required by any reproduction command.
