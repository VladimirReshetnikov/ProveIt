Python 3.11+ with the standard library only for exact finite arithmetic.
TeX Live with pdfTeX/pdfLaTeX, lmodern, microtype, amsmath, amssymb, amsthm,
mathtools, booktabs, array, geometry, hyperref, fancyhdr and T1 fonts.
Poppler pdftoppm/pdfinfo for optional all-page visual inspection.
No network access is needed to reproduce this package.
Same-toolchain byte reproducibility was tested with Python 3.12.14,
pdfTeX 3.141592653-2.6-1.40.26 (TeX Live 2025/dev/Debian), and ZIP_STORED.
The exact integer and rational outputs are toolchain-independent mathematics;
PDF byte identity additionally depends on the installed TeX/font versions.
