# Proportional-depth research package

Main mathematical note: `proportional-depth.md`.
Literature comparison: `literature.md` (prepared separately; especially important for the substantial Prellberg 2002 overlap).
Independent review: `/workspace/shared/iterated-bell-proportional-audit/audit.md` and its frozen reviewed snapshot/checks. The research draft subsequently received attribution and contour-clarification wording updates; the audit hashes identify the precise reviewed text.

The note extends the audited fixed-contour method to all slopes λ>0, proves strict positivity of the amplitude through an exact quadratic Bell-composition inequality, gives all fixed orders and smooth-model inverses, and retains floor-depth phase oscillations. It does not claim novelty of the leading bivariate equivalent or the parabolic-coordinate method.

## Checks

- `orbit-coefficients.json`: exact orbit polynomials and original β=1 forward polynomials through order 3, generated by the frozen audited coefficient generator.
- `generate_proportional.py`: generates the β-dependent integrand polynomials through order 3 and checks degree bounds, the explicit first correction, and exact β=1 agreement.
- `proportional-coefficients.json`: its output. Run `python generate_proportional.py` with SymPy installed.
- `check_proportional.py`: exploratory long-double contour quadrature for I(β), I'(β), I''(β) and exact integer recurrence checks at λ=1/2,1,2 and n=39,40,79,80,159,160; odd indices at λ=1/2 explicitly test the floor shift δ=−1/2. Requires NumPy, SciPy, and mpmath. Run `python check_proportional.py`.
- `diagnostics.json`: output from that run. These contour numbers are NOT rigorous enclosures and do not establish positivity.

At n=160, the exact count divided by the predicted first-corrected expression was approximately 0.999845, 1.000009, and 1.000013 for λ=1/2,1,2, respectively. At n=159 and λ=1/2 with depth 79 (δ=−1/2), the analogous ratio was 0.999748. This checks conventions numerically; it is not a remainder certificate. General positivity instead follows rigorously from the analytic/combinatorial argument and the original audited I(1)>0 seed.

No frozen source/reporting/certificate file was changed. No external publication or communication was performed.
