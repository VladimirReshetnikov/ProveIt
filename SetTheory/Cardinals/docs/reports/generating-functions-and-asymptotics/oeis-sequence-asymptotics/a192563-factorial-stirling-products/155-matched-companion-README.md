# Report155 companion: matched-cycle Fock certificates

An exact-arithmetic, Python-standard-library companion for A192561,

\[
 b_n=\sum_{k=0}^{n}\left[{n+1\atop k+1}\right]^2 k!.
\]

It provides three independent deliverables:

1. Exact enumeration by the unsigned Stirling recurrence
2. A rigorously enclosed positive Fock-norm expansion, with **full rational lower and upper endpoints**
3. Formal asymptotic coefficients through \(A_{10}\), generated by rational polynomial arithmetic and the Bernoulli recurrence

No numerical fitting, floating-point root finding, special-function library, network access, or third-party Python package is used. Integer decisions use only integers and `fractions.Fraction`. This is a computational companion to the mathematical argument in Report155, not a formal proof-assistant verification of that argument.

## Requirements and reproducibility

Use Python 3.11 or later on POSIX with `O_NOFOLLOW`, `O_DIRECTORY`, directory-relative opens, and hard-link support. The supplied runs were checked on Python 3.12. Run commands from this `companion` directory. `-B` prevents Python from creating bytecode caches.

The bundled result files already exist. Choose **fresh filenames** when reproducing them:

```sh
python -B fock_exact.py certificate --input inputs/certificate_n10.json --output results/replay_n10.json
python -B fock_exact.py certificate --input inputs/certificate_n0.json --output results/replay_n0.json
python -B fock_exact.py coefficients --order 10 --output results/replay_A10.json
python -B fock_exact.py enumerate --n 10 --output results/replay_enumeration_n10.json
python -B -m unittest -v test_companion
python -O -B -m unittest -v test_companion
```

The generated JSON has deterministic content and no timestamps or elapsed-time fields. The certificate results and coefficient results can be compared byte-for-byte with their bundled counterparts. Existing outputs are never replaced. Remove only your own unneeded replay files yourself, or choose another fresh name.

The unique integer in the interval is

\]

Outward-rounded decimal bounds, with 30 places after the decimal point, are

These decimal displays are produced by integer floor/ceiling division; they are not binary floating-point approximations. ## What the interval proves

Let \(P_n(z)=\prod_{j=1}^{n}(1+z/j)\). The Gaussian monomial identity gives

\[
\frac{b_n}{(n!)^2}=\frac1\pi\int_{\mathbb C}e^{-|z|^2}|P_n(z)|^2\,dA(z).
\]

For rational \(b\ge0\), write

\[
d=\sum_{j=1}^n(j+b)^{-1}-b,\quad s=\sum_{j=1}^n(j+b)^{-2},\quad
 e^{-bt}\frac{P_n(b+t)}{P_n(b)}=\sum_{k\ge0}c_k t^k.
\]

The recurrence used by the program is

\[
c_0=1,\quad c_1=d,\qquad
kc_k=dc_{k-1}+\sum_{r=2}^k(-1)^{r-1}S_r(b)c_{k-r}.
\]

Set \(C_K=\sum_{k<K}k!c_k^2\). For \(s<q<1\), the proved global bound implies

\[
0\le C-C_K\le T e^E,\quad
T=\frac{(s/q)^K}{1-q},\quad E=\frac{qd^2}{s(1-q)},\qquad
b_n=(n!)^2P_n(b)^2e^{-b^2}C.
\]

The program encloses \(e^{-b^2}\) and \(e^{E-b^2}\), and combines their bounds with the nonnegative rational quantities \(C_K,T\). No subtraction of nearly equal floating-point quantities occurs.

The function \(g(x)=\sum_{j=1}^n(j+x)^{-1}-x\) is strictly decreasing. Exact sign bisection on \([0,n]\) returns an upper endpoint \(b\ge a\), where \(g(a)=0\). Consequently \(s(b)\le s(a)\le1/\varphi<2/3\), so \(q=K/(K+1)\) is admissible for every allowed \(K\ge2\). This choice minimizes the simpler exact-center bound when \(d=0\); **it is not claimed to minimize the rational-center bound when \(d\ne0\)**.

For \(x\ge0\), with \(m+2>x\), the exponential enclosure is

\[
\sum_{j=0}^{m}\frac{x^j}{j!}\le e^x\le
\sum_{j=0}^{m}\frac{x^j}{j!}
 +\frac{x^{m+1}}{(m+1)!}\frac1{1-x/(m+2)}.
\]

It follows from a geometric upper bound on successive omitted-term ratios. Negative arguments are enclosed by reciprocating the positive-argument interval.

An interval crossing an integer threshold does not, by convergence alone, prove equality. `compare_threshold` returns `undecided` on such a boundary unless an independently computed exact integer is supplied. No ceiling of an asymptotic estimate is used as an integer threshold rule.

## Asymptotic coefficient generation

The normalization is

\[
\frac{b_n}{(n!)^2}\sim\frac{e^{w^2+1}}{2\pi w}
\sum_{r\ge0}\frac{A_r}{w^r},\qquad w=W(en).
\]

The program uses \(B_1=-1/2\) and the classical Bernoulli-polynomial log-Gamma expansion. It constructs

\[
g_m(t)=\frac{(-1)^m(B_{m+1}(t)-B_{m+1})}{m(m+1)},\quad
p_r=\frac1r\sum_{m=1}^r m g_m p_{r-m},
\]

then takes the exact polynomial Fock inner products
\(H_r=\sum_{j=0}^r\sum_k k![t^k]p_j[t^k]p_{r-j}\).
Convolution with the formal Stirling factor gives \(A_r\). Polynomials in the output use ascending powers of \(t\), with reduced rational strings. The first terms are

\[
A_0=1,\quad A_1=-\frac16,\quad A_2=\frac{55}{72},\quad
A_3=\frac{1381}{6480},\quad A_4=\frac{76541}{155520}.
\]

`results/coefficients_A10.json` includes every \(g_m,p_r,H_r,E_r,A_r\) through order 10. Formal coefficient generation is exact. The rigorous all-orders asymptotic remainder argument belongs to Report155; these coefficients alone do not provide effective finite-\(n\) remainder constants.

## Input and safety contract

Certificate JSON must contain exactly the four fields shown in the fixed inputs. Booleans, floats, duplicate keys, unknown fields, nonfinite numbers, and out-of-range values are rejected. Limits are deliberately modest:

| Operation | Bounds |
|---|---|
| Certificate | \(0\le n\le20\), \(2\le K\le96\) |
| Rational bisection | 8–64 steps |
| Exponential Taylor sum | 16–192 terms |
| Coefficient generation | order 0–10 |
| Standalone enumeration | \(0\le n\le1000\) |
| Input/output size | 16 KiB / 4 MiB |
| JSON nesting | at most 16 levels |

All limits are checked explicitly, without `assert`, and remain active under `python -O`. Some permitted high-end certificate inputs cost more exact-integer arithmetic than the approximately four-second bundled example; limits are workload bounds, not a timing guarantee.

Safe I/O is descriptor-pinned. It refuses dot/parent traversal, symlink ancestors, final symlinks, FIFOs, and nonregular input files. Output parents must already exist. Outputs must end in `.json`. A completely written private temporary file is atomically published through an exclusive hard link. A pre-existing file, directory, FIFO, or dangling symlink is never replaced. Temporary files are cleaned on ordinary failures. If a filesystem error occurs after successful publication, a complete output may remain; inspect it before retrying. Hard kills or machine failure can leave an unpublished private temporary file.

These precautions prevent ordinary path traversal and symlink substitution; they are not a sandbox against a hostile kernel, network filesystem, or a process that can manipulate the output directory itself. Inputs and outputs may use absolute paths or ordinary relative paths. No subprocesses are launched by the companion itself. Importing the modules performs no computation, writes, network I/O, or interpreter-setting changes; the usual Python bytecode cache behavior is avoided with `-B`.

## Reading exact endpoints

Long numerators and denominators are stored as decimal **strings**. This avoids JSON-number ambiguity and Python's process-wide integer/string limit. No global limit is disabled. To reconstruct an endpoint:

```python
import json
from fock_exact import decode_rational
with open("results/certificate_n10.json", encoding="utf-8") as stream:
    result = json.load(stream)
lower = decode_rational(result["interval"]["lower"])
upper = decode_rational(result["interval"]["upper"])
```
