# Report219 Nonattacking bishop amplitude and diagonal corrections

This package contains a 13-page self-contained mathematical article on OEIS A002465 and A238260, its editable TeX, and exact reproducibility code. The theorem evaluates the amplitude b = exp(r)/(2*pi*sqrt(r*r-1)) and gives all fixed orders, with the first parity split at order n^-3. The inverse retains parity and uses two ceilings. Remainder constants and onsets are not numerically certified.

The leading equivalent is already stated as a theorem by Kotěšovec. Exact counting formulas and the exponential base are prior. The article makes a bounded source comparison, not a global priority claim. Source papers are linked, not redistributed.

## Contents

- Report219.pdf and Report219.tex: article and editable source
- code/: exact angular generator, independently reconstructed affine oracle, several exact count routes, inverse algebra, optional non-certified diagnostics, and reusable coefficient JSON
- reference_receipts/: deterministic default full-check receipts, including optional 80-digit diagnostics, explicit guard tests, and an angular-only order-4 check
- build_pdf.py: offline fresh-output PDF builder with fixed metadata and stabilized references
- build_archive.py: deterministic ZIP builder with an explicit public file set
- verify_package.py and MANIFEST.json: byte lengths and SHA-256 integrity check
- toolchain.json: versions used for the reference build

## Rebuild from the actual ZIP

Unzip into a fresh directory, enter Report219, and run:

    python verify_package.py
    python code/reproduce.py all --with-diagnostics --out /tmp/report219-normal
    python -O code/reproduce.py all --with-diagnostics --out /tmp/report219-optimized
    python code/test_contracts.py --out /tmp/report219-contracts-normal
    python -O code/test_contracts.py --out /tmp/report219-contracts-optimized
    diff -r /tmp/report219-normal /tmp/report219-optimized
    diff -r reference_receipts/reproduction /tmp/report219-normal
    diff -r /tmp/report219-contracts-normal /tmp/report219-contracts-optimized
    diff -r reference_receipts/contracts /tmp/report219-contracts-normal

The output directory must be new. Choose other fresh paths if those examples already exist. Read code/README.md for input contracts, exact ranges and lighter checks. The extra order-4 receipt is angular-only, with no independent order-4 affine comparison. It can be regenerated by `python code/reproduce.py coefficients --order 4 --skip-oracle --out /tmp/report219-order4` and compared against reference_receipts/order4.

The default symbolic run reaches order 3; the angular algorithm accepts any nonnegative fixed order, with rapidly growing time and memory cost.

To rebuild the PDF:

    python build_pdf.py --output /tmp/Report219-rebuilt.pdf --logs-dir /tmp/report219-build-logs
    cmp Report219.pdf /tmp/Report219-rebuilt.pdf

The builder requires an installed TeX Live distribution with pdfTeX, LaTeX, Latin Modern, AMS packages, microtype, hyperref, enumitem, fancyhdr, booktabs and geometry. It uses only local TeX files, disables shell escape, redirects caches to temporary storage, and builds a local format if the installation has no ready format. It never downloads software or replaces an existing output. PDF byte identity is tested with the toolchain in toolchain.json; other TeX/font versions may produce different bytes without changing the mathematics.

To recreate the ZIP from an extracted package:

    python build_archive.py --output /tmp/Report219-rebuilt.zip

The ZIP has a single Report219/ root, sorted entries, fixed timestamps, standard deflate compression, and no machine-local paths. The manifest covers the public files except itself. Archive byte identity assumes the recorded Python/zlib implementation. Generated receipt paths, clock time, process flags, and environment paths do not enter semantic receipts.

## What the checks establish

Exact agreement of different finite counting and symbolic routes validates implementation and normalization. The article's analytic proof establishes the asymptotic theorem. Decimal residuals, root-solver success and finite exact comparisons do not establish an effective remainder constant, onset, numerical interval certificate, or single-ceiling threshold formula.
