# Report163 bounded exact companion

Python 3.10 or later, standard library only. No network is used. The
production module disjoint_partitions.py has no input-file or file-writing
API; it prints deterministic JSON. No other report or unpublished working
file is needed. Use -B as shown to disable Python bytecode-cache writes.

## Commands

From the report directory:

    python -B companion/disjoint_partitions.py counts
    python -B companion/disjoint_partitions.py verify
    python -B companion/disjoint_partitions.py sources
    python -B companion/disjoint_partitions.py threshold --value 1000 --max-n 24
    python -B companion/disjoint_partitions.py bounds --value 100000000000000000000
    python -B -m unittest discover -s companion -p 'test_disjoint_partitions.py' -v
    python -B -O -m unittest discover -s companion -p 'test_disjoint_partitions.py' -v

All correctness checks use explicit exceptions, so optimization does not
remove them. Public integer APIs reject booleans, floats, strings, negative
values, and values outside their caps before enumeration. CLI integers
must be canonical nonnegative ASCII decimal tokens: no signs, leading
zeroes except 0, whitespace, decimal points, or Unicode digits.

- counts --max-n N: enumerate a(n) through 0<=n<=N, with N<=24, default 24
- verify --max-n N --queen-to K --rounding-to R: defaults (24,8,100000),
  caps 0<=N<=24, 1<=K<=8, 2<=R<=100000. Queens and greedy diagnostics are
  separate bounded tests, so they still run if N is smaller
- sources: all 46 displayed numeric OEIS terms and source provenance;
  only the first 25 terms, n=0 through 24, are independently enumerated
- threshold --value V --max-n N: exact first-passage scan, 1<=V<=10^100,
  0<=N<=24. If reached is false, first_n and count_at_first are null, and
  the only first-passage conclusion is N(V)>N. V=1 has first index zero
- bounds --value V: a proven finite bracket at integer 1<=V<=10^100.
  For V>1 the lower endpoint is the first n>=2 whose explicit upper
  bound 3^(n-1)*n^floor((n-2)/4) reaches V, so all smaller n are excluded.
  The upper endpoint is 7k+1 for the first k with 2^k*k!>=V. The lower
  scan is capped at n=256 and factorial scan at k=128; these cover the
  entire allowed input range. V=1 returns the exact bracket [0,0].
  Endpoints otherwise need not be exact first passages. This command
  uses integer arithmetic only, with no Lambert-W evaluation

Success returns status 0. Invalid arguments return status 2 and no JSON on
stdout. A failed internal mathematical check returns status 1 and no partial
JSON. Output is capped at 2 MiB. Exact counts and potentially large bounds
are decimal strings in JSON, avoiding precision loss in typical consumers.
Small bounded indices are JSON integers. There are no JSON floats.

## Independent finite constructions

Strict partitions are generated by subset-sum dynamic programming and
compared with a recursive increasing-parts generator. Matchings are visited
in increasing edge-index order; each is tested for maximality against all
edges, including unselected earlier ones. The forced singleton {n} is
removed for this traversal. Through n=24, all 179455 resulting matchings
are encoded by anchors and free-label assignments, decoded, and checked
for distinctness, mass bounds, and the exact free-label cap. A separate
maximal-clique recursion uses the full strict-partition graph through n=18.

All ordinary queens permutations through k=8 are generated by checking both
diagonal constraints. For all five values n=5k+r, 1<=r<=5, the report's
strict triples are greedily extended using every partition size. The
extension is tested for maximality; original permutations are recovered
from the unique edges through the small anchors; extension collisions are
excluded. Queens sizes 2 and 3 correctly have no configurations.

Twenty-four small greedy examples use k=1,...,4, m=2k,...,2k+2, and two
admissible n values. Their actual choices are enumerated and checked
against the full product and crude-power lower bounds; disjoint triple
ranges and distinct bases are checked. At m=2k the product is 2^k*k!.
The upper floor identity and all-residue range separation are checked
through n=100000. These finite checks do not replace the proofs.

The tests compare complete deterministic data files, cover conventions,
first passages and proven integer brackets, validate every cap, inject
failures, exclude production assert and file/network APIs by AST checks,
and compare normal/-O outputs byte for byte in an empty working directory.
Those AST checks are a regression guard, not a sandbox for malicious code.
All code should be run from a trusted local directory and Python install.

## Scope

Enumeration checks are diagnostics for definitions, indexing, normalization,
and the injections. They do not prove the asymptotic theorem, reprove the
external Luria-Simkin queens theorem, certify novelty, establish existence
of a limiting coefficient, give a multiplicative equivalent, or establish
any all-orders expansion or transseries. Finite integer brackets follow
proved elementary inequalities; the companion supplies no effective
onset for the stronger asymptotic inverse constant 5.
