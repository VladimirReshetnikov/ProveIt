# Exact reproducibility checks

These checks are standalone: no files outside this directory and no network access are needed. They validate explicit algebra and finite counting data accompanying report112. They do **not** prove its analytic theorem, any functional or local limit theorem, any asymptotic equivalent, or the applicability of a cited theorem.

## Run

Python 3.10 or newer and SymPy 1.14.0 are required. The recorded run used Python 3.12.14 and SymPy 1.14.0; check your version with `python3 --version`. Install the pinned dependency in your own virtual environment with `python3 -m pip install -r checks/requirements.txt` if needed. From the report directory:

```
python3 checks/validate.py
python3 -O checks/validate.py
python3 checks/run_validation.py
```

The last command repeats ordinary and optimized validation, runs every named mutation under `-O`, then copies only the six validation inputs to a fresh temporary directory and repeats both modes and every mutation there. It writes human-readable logs and machine-readable evidence in `checks/results/`. A complete run takes a few minutes. No Python `assert` statement is used: explicit exception checks remain active with optimization enabled. The single-checker exit status is 0 on success and 2 for an expected validation failure. Unexpected exceptions do not count as successful mutant rejection.

## What is certified

1. **Rational kernels and moments.** Both kernels are reconstructed rather than loaded as executable symbolic expressions. The corner kernel is a sum of geometric series. The Schnyder kernel is independently reconstructed as `J(I-F)^(-1)` in physical coordinates, then changed to quotient coordinates. Fixtures use coefficient/exponent lists; no fixture text is evaluated as code. Every rational-function identity is checked exactly. Positive geometric-series decompositions provide nonnegative coefficients. Row sums, primitive color matrices, stationary distribution, phase drifts and mean-zero Poisson correctors are exact. Effective covariance is obtained in two ways: the corrected-increment second moment and the Hessian of the logarithm of the explicit Perron root. Phase-conditioned covariance matrices are separately checked and are unequal; a common whitening cannot erase that difference. Physical covariance is four times quotient covariance.
2. **Exponential moments.** With `R = exp(t) = 6/5`, the corner quotient-displacement moment is exactly `(2/3)R + (4/27)R/(1-R/3)^2`. For Schnyder, a weighted face has row sum `f = R^4/[8(1-R^2/2)] < 1`, and the entire aggregate's sum of physical elementary lengths has moment `(3/4)R^2/(1-f)`. These are exact rational inequalities and equalities. The latter bounds aggregate displacement; the quotient-coordinate phase correction is bounded. A finite corrector and the uniform-stationary dual preserve finiteness. No finite truncation is used to infer an exponential tail.
3. **Fourier witnesses.** Every listed diagonal edge has a positive-probability realization. The three rows `(dx,dy,-1)` have determinant `+1` or `-1`. Therefore their character equations force both spatial frequencies and the eigenphase to vanish modulo `2 pi`. Together with color primitivity and equality in the triangle inequality, this is the full lattice/time witness, not a numerical spectral-radius sample.
4. **Seeds for every integer H >= 1.** Forward and dual paths are checked symbolically. In each repeated block, both coordinate extrema over all repetitions occur at the first or last repetition. Their polynomial coefficients after substituting `H = 1+T` are nonnegative. Every edge has a positive-probability support witness; every phase joins correctly; every intermediate point lies in the quadrant; final location is `(H,H)` with the specified phase. These are all-H algebraic certificates, not tests at a few H values.
5. **Finite original-walk counts.** Direct enumeration reproduces all 32 recorded A377922 terms and all 31 recorded A377920 terms. It does not use the transition matrices for those enumerations. Corner enumeration goes through time 32 and preserves `y <= 33-k`, allowing endpoints of height 0 **or 1**. Consequently the final recorded fixed-(1,1) count is genuine, rather than a spurious zero produced by axis-only pruning. The corner value at index 0 is the source convention `p_0=0`; the empty walk is excluded rather than counted as a polyhedron. The corner sandwich is checked for indices 1 through 31; its two support-preserving endpoint extensions are also checked symbolically. Schnyder time is the number of SE steps, with weighted face closure in decreasing x. The shift is exactly n+2 SE steps, or n+1 aggregates after the final mandatory SE step is removed. The exceptional A377920 values at indices 0 through 3 are source inputs, not derived from the positive shifted relation. The auxiliary walk enumeration has `r_0=1`, representing the two-SE walk. This is a formal auxiliary initialization, not a claim that a size-zero combinatorial subfamily contains one object; the source subfamily identification is used only in its stated size range.
6. **Independent endpoint normalization.** A second enumerator uses exact rational coefficients of the quotient kernels: the Schnyder geometric denominator uses a two-variable recurrence. It checks fixed-endpoint probabilities through time 12 against original integer walk counts. The corner endpoint tilt is 1, the Schnyder endpoint tilt is 4; endpoint and size-shift identities are also explicit fixtures. The all-size justification remains the pathwise telescoping tilt and the source bijection, not extrapolation from time 12.
7. **A377921, carefully limited.** The full formal generating-function identity, including low-degree polynomial corrections, reconstructs 31 coefficients and matches the 16 recorded coefficients independently supplied. The nonnegative positive convolution, `b_n <= a_n`, and `8 max(b_n,...,b_(n-3)) >= a_n` are checked for 4 <= n <= 30. The inverse sandwich is checked at every rational breakpoint and one rational point of every intervening open cell for which the available A377920 prefix guarantees `N_A(8y)` exists. These finite convolution checks do not by themselves prove an all-n exponent, monotonicity, or an asymptotic inverse law. Separately, the report proves a six-face sleeve injection giving `a_(n-6) <= b_n <= a_n` for n >= 8. The finite sleeve module checks all zero/positive local-degree cases (contiguous same-color blocks reduce identically for every positive degree), the six annular 4-cycles and their faces, bipartition, canonical outer labels, root recovery, inverse deletion and the Euler/size increment. The resulting six-shift comparison is checked for 8 <= n <= 30. The all-n comparison uses the written surgery and injectivity proof; combined with the analytic result for A377920 it gives the all-n logarithmic exponent for A377921. The finite suite is supporting evidence for those proofs, not a replacement.
8. **Exact angle/order bounds.** Squared rational inequalities prove `pi/4 < theta_P < pi/3` and `pi/6 < theta_S < pi/5`, hence `4 < alpha_P < 5` and `6 < alpha_S < 7`. Both rational `2 cos(theta)` values are nonintegers. The accompanying general proof is: a rational multiple of pi would make twice its cosine an algebraic integer; a rational algebraic integer is an integer. Thus theta/pi, and consequently alpha, are irrational. The code certifies the exact inputs and inequalities; the general algebraic-integer lemma and the analytic non-D-finiteness argument are mathematical proofs rather than finite computational tests.

## Mutation evidence and integrity

Every mutation changes a genuine mathematical claim or schema requirement. Categories include kernel coefficients, probability normalization, drifts, correctors, averaged and phase covariances, correlations, angle/order inputs, exponential convergence and bounds, supported Fourier edges and lattice index, all four seed paths, sleeve colors/outer labels/root recovery/annular edges/faces/Euler increment/size shift, endpoint tilts and time shifts, OEIS terms, convolution weights, window constants, missing/unknown/duplicate fields, noncanonical rationals, wrong integer types and forbidden analytic scope claims. Mutants remain syntactically valid JSON; zero denominators are rejected by schema validation before rational parsing.

`results/validation_manifest.json` lists every name, expected diagnostic, actual diagnostic, exit code, and both baseline and mutated fixture hashes. Each rejected mutant must exit 2 with its expected diagnostic and no traceback; syntax-only failures, crashes, timeouts and wrong diagnostics fail the runner. Baseline input SHA-256 hashes are read before and after the run and must match. The fresh replay's byte-identical inputs and full rerun are separately recorded in `results/fresh_replay_manifest.json`. These are integrity and reproducibility records, not signatures or a proof of correctness of Python, SymPy, the checker implementation, or the analytic report.

## Reading results

`ordinary.json` and `optimized.json` contain exact verified matrices, certificates, seeds, count ranges, reconstructed coefficients and explicit exclusions. `ordinary.log` and `optimized.log` are short reader summaries. `fresh_replay.log` summarizes replay status. A PASS means all declared finite/algebraic checks passed for these bytes. The cone theorem, FCLT, unrestricted/killed LLT, asymptotic transfer, G-function argument, full amplitudes and live-source completeness remain outside finite certification.
