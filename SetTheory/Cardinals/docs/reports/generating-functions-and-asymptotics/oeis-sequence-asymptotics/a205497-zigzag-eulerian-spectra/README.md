**Exact minimal recurrences, a crossover law, and growing-edge log-concavity for OEIS A205497**

Let z(n,k) count linear extensions with k descents of a naturally labelled n-element fence poset (OEIS A205497; the rectangular arrangement is M[i,k] = z(i+k+2,k)). The report determines the exact reduced denominator of every column generating function, the minimal recurrence order of every column, uniform Perron asymptotics while k grows with n, a crossover law at k ≍ n/log n, and strict log-concavity in a growing window at both edges of each row.

**Status: AI-assisted, unrefereed, not formalized.** The intake brute-forced the triangle for n ≤ 9, checked the order asymptotic at k = 1000, and reran the verification script on a copy; it did not re-derive every proof.

## What is claimed

- **Theorem 1.1 (algebra).** With H_m the 0/1 matrix (1 if i+j ≥ m+1) and D_m(x) = det(I − xH_m), the reduced denominator of column k is R_k = lcm_{1≤m≤k+1} D_m^(k+2−m), its degree r_k is the minimal (indeed the minimal eventual) constant-coefficient recurrence order, given by a totient formula (Theorem 5.4); the reduced numerator has degree r_k − k − 3 for k ≥ 1; and r_k = (40/(27π²))(k+1)³ + O(k² log k), so the minimal order is asymptotically 80/(9π²) ≈ 0.9006 of the familiar unreduced order. The collisions between the D_m are classified completely (Theorems 5.1, 5.3).
- **Theorem 1.2 (analysis).** (i) z(n,k) ~ α_{k+1}ρ_{k+1}ⁿ uniformly for k+1 ≤ cn/log n, any fixed 0 < c < 1, with an explicit uniform relative-error bound (Theorem 7.3); (ii) when n/(k+3/2) − log n → s, the relative correction tends to exp(−e^(−s)) (Theorem 8.1); (iii) for every fixed 0 < c < 1/2 and all large n, z(n,k)² > z(n,k−1)z(n,k+1) for 1 ≤ k ≤ cn/log n − 2 and at the reflected indices n−2−k (Theorem 9.2).
- **Two OEIS-entry corrections** (Section 6): the unreduced numerator degree is A005586(k−1), not A005586(k) as the zero-based wording of the entry's Conjecture 4(ii) reads; the last term of the column-three numerator is +x¹⁴, not the −x¹⁴ printed in A205497 (the + sign is already in Xin–Zhong, Example 5.11; the coefficient [x¹⁴]C₃ = z(19,3) = 546629054 agrees with A205493). No OEIS edit was submitted.

## What is not claimed

- Full-row log-concavity, real-rootedness, simple roots, and interlacing of the zig-zag Eulerian polynomials (Petersen–Zhuang, Conjecture 6.1) are **not** proved; Theorem 1.2(iii) covers only a growing window at each edge.
- The fixed-column rational formulas, their Perron growth rates, the familiar product denominator and its degree are Xin and Zhong's; the denominator cancellation was already observed in their Remark 5.7; the order-polynomial (P-partition) framework and the big-return interpretation are Petersen and Zhuang's. None is claimed as new.
- Global bibliographic novelty of the additional theorems has not been independently certified; the literature and repository searches were targeted.
- No claim that the old OEIS conjectures are all still open.
- The numerical tail bounds in `data/crossover_diagnostics.json` are ordinary multiprecision evaluations, not interval arithmetic, and exclude rounding error: a tiny bound is not a claim of that many certified digits. Finite checks (rows through n = 100, columns 0–12) are evidence, not proofs of the unbounded statements.
- Nothing is formalized; Section 11 only sketches a formalization route.

## Rerunning the scripts

`code/build.sh` and `code/build.ps1` are the delivered wrappers. They assume the delivered root layout (`verify.py`, `illustrate.py` and the manuscript beside `data/`) and **rewrite the recorded files in `data/`**; do not run them in the report. After the move, `code/verify.py` by default writes to `code/data/` (its `--out-dir` default is `Path(__file__).parent/'data'`), and `code/illustrate.py` writes to `code/data/` and reads `code/data/verification_report.json`. Run both on a copy:

```sh
R=SetTheory/Cardinals/docs/reports/generating-functions-and-asymptotics/oeis-sequence-asymptotics/a205497-zigzag-eulerian-spectra
W=$(mktemp -d)
cp "$R/code/verify.py" "$R/code/illustrate.py" "$W/"
cd "$W"
uv run --no-project --with sympy==1.14.0 --with mpmath==1.3.0 python verify.py --out-dir data      # about 80 s
uv run --no-project --with sympy==1.14.0 --with mpmath==1.3.0 --with matplotlib==3.10.8 python illustrate.py
```

`verify.py --out-dir data` writes `triangle.json`, `rational_certificates.json`, `minimal_orders.txt`, `orders_table.tex` and `verification_report.json`; `illustrate.py` then writes `order_ratio.pdf`, `order_ratio.png`, `asymptotic_table.tex`, `crossover_diagnostics.json` and `crossover_table.tex`. Compare them with the shipped `data/` files ignoring line endings: the scripts use `Path.write_text`, which writes CRLF on Windows, while the delivered files are LF. At intake every regenerated text file equalled the delivery up to line endings. Do not compare `order_ratio.pdf` byte for byte; see the next section. Alternatively, `verify.py` alone can be run in place with an explicit output directory: `python code/verify.py --out-dir "$W/data"`.
