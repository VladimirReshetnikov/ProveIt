## Why the tape and bootstrap alternatives need care

The report distinguishes public Core tapes, concrete list zippers and symbolic register-box tapes. Its bounded bitset replay checks entire finite tape support and 13 exact startup checkpoints. That is finite corroboration, not a Lean refinement theorem. A fixed bitset cannot replace arbitrary-natural register boxes or unbounded symbolic runs. A new representation would require read/write simulation, explicit bounds failure and a run induction, while the balanced lookup reuses an already established equality.

Similarly, replacing 62,699 self-loop steps by 6,874 scan entries leaves 39,889 abstract bootstrap entries. Existing scan lemmas may justify reachability, but do not automatically preserve the exact 95,714-step clock. Counted scan contracts would be needed for that stronger claim. Emitting tens of thousands of proof links could enlarge the current 13-chunk proof rather than simplify it. The packet correctly leaves these as measured design alternatives.

## Length padding, transport and negative results

The ordinary length theorem assumes a command codec with round-trip decoding and residual bounded by the input code. With the mandatory positive-continuation wrapper, a nonempty word’s code is at least its length minus one. A universally halting command-boundary word remains halting after any finite prefix when command execution is total: the prefix either halts or reaches another store covered by the universal hypothesis.

Completeness additionally requires the increment-by-one scheduler to reach every sufficiently large candidate. Mere unbounded growth or a skipping scheduler is insufficient. The argument does not authorize arbitrary binary tapes, source interiors, interference with parser registers or omission of protected-tail soundness. For the current four-command `EnumPerm`, the existing specialized lower bound and completeness proof are already short; this library abstraction is not a demonstrated local compression. Its common-NIP application concerns a different command interface, whose compiler and runtime obligations remain separate.

Positive-stuttering transport similarly requires an initial inductive invariant, whole-tape locality, positive blocks and preservation/reflection of halting. The packet’s CM215 exposition and finite synthesis corroborate already delivered relative proofs in Sources 168–169 and 174; they do not replace those compiled adapters. GC–ZC/common-NIP discussion is attributed research, not a newly reviewed complete calibration. The reported labeled-quotient obstruction from 1,426 to 1,423 classes concerns a finite program-graph family, not TM minimality.

The content census found 865 exact current-tree alias occurrences at the inspected origin snapshot; unmatched content is not automatically mathematically novel. Preserve the report, source prototypes, histories and statuses while reusing verified aliases. The preferred Lean sequence is to adapt the existing normalized checker, test balanced lookup with unchanged site statements, and consider import separation. Each requires fresh kernel and endpoint checks; none changes the chosen 215-state machine or its consistency theorem merely by appearing in this archive.
