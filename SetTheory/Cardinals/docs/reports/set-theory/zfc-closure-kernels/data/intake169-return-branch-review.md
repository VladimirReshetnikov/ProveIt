# Return242 and branch-borrowing: independent source comparison

Both main reductions are sound as ordinary relative proofs, but neither adds a new state saving to the current 241 candidate. Their inherited-label tables are byte-identical (`6b700aa713418cfe347a6ff2d0a92de7c31810d1cf69814b4684c7fb463876a0`), as are their canonical tables. They delete old15, change `11/0` from `0R15` to `0R27`, and change `27/1` from `1R39` to `1R22`. All 484 rows equal primary242A after the single retained-state rename **15→27**. Applying the existing 17/39 reduction gives all 482 rows of current241 under that same rename: it does not give 240.

This review reads the main manuscripts, proof appendices and relevant code as source. The accompanying reviewer script performs 4,425 literal/metadata comparisons. No delivered checker, simulator, compiler or generator was executed, and no checksum manifest was validated. The reviewer authored the separate, still-uncompiled primary-A Fold242 drafts; that comparison role is disclosed. Existing supplied PASS records below remain supplied evidence.

The main proof uses an old-side invariant: left bit zero at old18/47/65 and current bit zero at old27. Every incoming transition needed by that invariant is present and writes the claimed bit; starting at old95 imposes no tape restriction. Checkpoints exclude old15. The sole exceptional entry is old11/read0: the old path takes two steps and the new path takes two or four depending on the next bit. Each endpoint has the same state, head and entire tape; all intermediate states are active. All other checkpoint steps agree literally. Positive block lengths therefore transfer finite halting in both directions, for arbitrary function tapes and head positions. The exact clock equation is `t_new = t_old + 2k`, with `k ≤ t_old/2`, hence `t_new ≤ 2t_old`. This sharper bound and footprint preservation concern the same primary-A machine; they are not a further optimization. The inherited combined243 calibration is a separate dependency, and no all-internal PA closure is supplied.

Return242’s most useful distinct idea is the tag-independent MP test in `semantic-extensions.tex` and `research/semantic-targets/semantic_targets.tex`. In an irreflexive structure with at least two elements, if T and H hold under every assignment, testing `floor(H/4) = P(T,b)` suffices to infer b. The four tag cases are justified: implication gives MP; a universally valid membership atom is impossible; a universal formula yields its body under each assignment; a universally valid equality atom forces the two numeric labels to coincide. The singleton and pointwise counterexamples explain why the hypotheses matter. The original proof compiler’s deliberately failing discard operation remains failing because `P(T,1)>0`; intended exact implication successes remain successes. Recognizing membership atoms, or odd codes outside reflexive equalities, as refutations is another sound semantic relaxation. These are promising implementation freedoms, with no delivered smaller calibrated table and no new internal PA proof.

The scanner probe records 99 failures among 8,390 finite fixtures for a proposed sufficient three-zero contraction premise. Its first failure is a decrement of logical register 1 at `11101001001000000`, with context `01001`. This rules out that premise on those fixtures; it is not an unbounded impossibility proof.

Both packages also retain four R5 transfer-plus-increment rotations. The whole-register normal form is unchanged; the physical patch changes only `142/0` to `0R72` and `142/1` to `1R17`. Source leaves drop from 6,459 to 6,455 and guarded cases from 8,390 to 8,386, but no physical state is deleted. These rows do not invalidate either fold’s protected incoming conditions; the added old-side predecessor of17 writes one/right. Combining the rotations with both folds therefore remains a 241-state proposal, with a changed logical source requiring its own calibration/runtime argument. Existing full coverage is not automatically reusable. The local delete50/delete171 alternatives compete for the same old27 branch and cannot simply be stacked with the main reduction.

Branch borrowing additionally supplies a standalone Lean relative proof in `formal/`, covering arbitrary `Int → Bool` tapes. Its literal old/new arrays independently match all 486/484 rows; the general block argument and specialized invariant/paths have no identified mathematical blocker. The delivered log reports 18 probes, 13 callers, zero warnings and only `propext`/`Quot.sound` where axioms occur. It is not a fresh check here. `Tables242.lean` explicitly raises recursion depth to 4096 and heartbeats to 2,000,000; its driver uses separate module timeouts and a version query. It must not be described as our default-limit checked proof or a source/logic/PA calibration.

The branch package’s atomic orientation experiment is a separate useful design: a primitive-recursive involution reverses membership/equality argument orientation while preserving decoded semantics and substitution. Its matched complete-emitter totals are 268/270/269/267 for normal/reverse-membership/reverse-equality/reverse-both. These do not improve the current241 machine. A formula code also used as a binder label needs alpha transport, not a literal conjugation, and both binary runtime and source calibration are explicitly unproved for the 267-state emitted control.

Recommended combination: finish the existing primary-A plus 17/39 chain, retain the alternative function-tape proof and clock accounting, and treat the semantic MP/NIP changes, H rotations and atomic codec orientation as distinct future source transformations. Other reviewers confirmed that context-reuse and zero-branch use this same delete15 table, while contextual-reuse and detour use primaryA. The six headline counts therefore do not represent six independent deletions.

One reviewer-only assertion was corrected before this receipt: the initial static script mistakenly tested the pre-fold incoming17 invariant on the post-fold merged241 table. The corrected check applies it to the old242 side, as the proof requires.
