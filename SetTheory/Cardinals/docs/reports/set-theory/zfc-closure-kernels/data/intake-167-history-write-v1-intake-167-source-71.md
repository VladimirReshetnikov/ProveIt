## Useful exact proof interfaces retained

For the loop, let old entry registers be `(N,X)=(a,b)`. The positive three-instruction block returns to its entry with `(N+1,X−1)`; the zero two-instruction block exits with `(N+1,0)`. Induction on b proves the same complete register file and finite positive clock on both source programs. The surrounding deterministic CFG has no interior entry, so these finite blocks support both halting directions from the program root. It is not necessary to strengthen the theory or assume the source invariant to obtain this result.

The fixed-width AX bridge has outputs: old current, GEN of old cache, theorem-valued remaining outputs, cleared D/H, and final truth under the collision `c=a`. For N outputs, the report supplies exact reusable command lists:

* `Discard = MP 1; AX(1;0,0,0); NIP^N`.
* `Leaf_j = Discard; AX(parameters); NIP^j; DROP; NIP^(N+1-j)`, for `1≤j≤N−1`; a current-output leaf uses `Discard; AX; NIP^N`.
* `GEN_i = Build_H; DROP; NIP; AX(i;i,0,0); NIP^(N−1); DROP; NIP; NIP`.
* `MP` compilation: `Build_A; DROP; Build_(A→B); NIP; DROP; NIP; MP B; AX(B;0,0,0); NIP^N; DROP; NIP; NIP`.

The three-field source omits the final displayed `u=0` parameter. Old truth cells and the retained tail are accounted for explicitly; earlier NIP halts already witness successful refutation. This is an ordinary source completeness/soundness argument, not a newly checked all-internal arithmetic theorem. Relevant widths are 10 originally, 9/8 for fusion, 12 for new propositional bases and 13 for splitting the theory bundle.

The fresh-only caveat uses assignments `x∈Q^N`, labels `f_i(x)=x_i+2Σ_(k<i)x_k`, actual equality and coordinate quantifiers. The finite-dependence bound validates atomic vacuity when `c>a+b`. With `R(s,t) ⇔ s=0 ∧ t=1`, the assignment `x0=x1=0,x2=1` makes `R(f1,f2)` true; varying only x0 to1 makes `(f1,f2)=(2,3)`, so the omitted small-binder vacuity implication fails. Commuting quantifiers, distribution, the stated equality conditions and logical rows remain valid. The CP/GIC set-theoretic bundle is deliberately outside this model claim.

The NIP product-interval checker treats upper code9 as infinity, truncates lower bounds at8, and checks closure rather than claiming least reachable states. Its initial family has logical registers1,2,5 zero and the other six arbitrary naturals. The discarded restoration body is unreachable under that certificate. The source rewrite allows at most one consecutive old stutter; the specialized comparison has `X=0` and arbitrary H at entry, halts iff H=1, otherwise returns H=X=0 preserving the other seven registers. Direct old-state142 deletion changes four live source occurrences, only one with X=0; the separate six-leaf literal proposal disturbs shared phase routers.
