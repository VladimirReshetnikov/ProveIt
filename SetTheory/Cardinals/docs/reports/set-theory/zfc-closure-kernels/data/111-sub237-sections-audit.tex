\section{The actual starting point}
\label{sec:audit}

The objective is to construct a machine $M$ with at most 236 working
states and prove
\[
 \mathrm{ZFC}\vdash
 \bigl(\neg\Halt(M,0^{\mathbb Z})
           \longleftrightarrow\Con(\mathrm{ZFC})\bigr).
\]
Here a working state is a state with two transition rows.  The machine
has one two-way infinite binary tape, begins on zeros, and writes one
bit and moves one cell left or right on every transition.  Initialization
counts toward the state total.  The separate halt outcome has no rows.
An inherited numerical label larger than 236 is not evidence of an
extra working state.

The first useful finding is that the four inspected 238-state table
deliveries do not supply four different reductions to combine.  Their
inherited-label tables are byte-identical, with SHA-256
\hash{069942be27db9736875ea042320e51ac3b1}{eac7116cbe01cdce520fa6056f78c}
and their canonical table has SHA-256
\hash{909f29c493e0ccc5d6a481fd7a20a9a82}{eb934ab2aa7df17b5ec3789255a8c08}
Their common table already combines the source/decoder reduction
deleting inherited state 218 with the coordinated runtime-helper
reduction deleting state 169.  The incoming 237-state candidate then
deletes state 235.  Reapplying any of these three deletions cannot
save another state.  This conclusion is an exact table comparison,
not an inference from similar titles or descriptions~\cite{repo,parent237}.
