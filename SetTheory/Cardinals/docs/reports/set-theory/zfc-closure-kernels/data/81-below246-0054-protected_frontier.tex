\paragraph{Source theorem.}
For every register file $R$, this graph and the original program have
identical register instruction traces from their empty-PC roots, under
the order-preserving bijection between instruction occurrences.

\paragraph{Proof.}
The two ordered leaf lists contain exactly the same operations and
arguments, including all break and continue counts.  The initial leaves
correspond, and all 8,391 guarded successor indices agree.  Therefore
instruction-count induction preserves both the register file and the
current leaf index.  The unique halt corresponds in both programs.
This proves the trace statement and both directions of halting
equivalence.\hfill$\square$

\subsection{What the remaining compiler problem requires}

Preserving source subtrees and incoming decoder context does not cover
all runtime uses of a physical state.  Terminal instruction handlers
also borrow decoder transitions.  For example, the marker protocol
uses a chain containing the original row $32/1$ followed by $46/0$.
If a source rotation changes the role of state 46, merely keeping its
old read-zero row at some other decoder location does not preserve the
borrowed chain.  In contrast, an isolated borrowed terminal row can
sometimes move with its physical state to a newly formed source pair,
provided every incoming borrowed transition remains compatible.

The precise continuation is consequently a constrained compiler search:
associate physical state labels with grammar nodes, record the borrowed
rows as fixed finite transition constraints, and transport labels during
reassociation only when those constraints remain satisfied.  Ordinary
source occurrences may be retargeted; every borrowed occurrence must
retain its verified microcontract.  The terminal-dependency audit records
54 such source-decoder rows.  This constraint set permits useful
changes below a borrowed row without freezing its entire continuation
subtree.

The best protected graph above has a proved source theorem, while a
physical 245-state realization is not established for it.  Before such
a realization is claimed, its complete binary table must pass the
universal instruction-frame checks and a safe blank-tape initialization
proof.  The graph and finite certificates preserve a concrete research
frontier for that remaining work.
