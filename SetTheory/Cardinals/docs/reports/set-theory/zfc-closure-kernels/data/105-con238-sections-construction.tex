\section{Result, conventions, and exact identity}
\label{sec:result}

The requested strict threshold is achieved: the delivered machine has
\textbf{238 working states}, including all initialization, so its count
is smaller than 239. The tape is indexed by $\mathbb Z$ and uses symbols
$0,1$, with $0$ blank. The head begins at coordinate zero, and every cell
initially contains zero. Every transition writes a bit and moves one cell
left or right. There is no stationary move, external input, prewritten
program, or uncharged initializing machine.

The canonical controls are $0,1,\ldots,237$. Start is $0$, the recurrent
dispatcher is $84$, and $238$ is a separate halt outcome with no outgoing
transitions. Each working control has exactly two transition rows.
A row $q\ b\ w\ D\ r$ means that state $q$, reading $b$, writes $w$,
moves in direction $D$, and enters $r$. The full table appears in the
appendix and in \file{machines/zfc238.tm}.

\begin{theorem}[Exact 238-state consistency machine]
\label{thm:main}
Let $M_{238}$ be the canonical table identified below. For the ordinary
effective finite-proof predicate of first-order ZFC,
\begin{align*}
 \mathrm{ZFC}&\vdash
 \Halt(M_{238},0^{\mathbb Z})
 \leftrightarrow \exists p\,\Proof_{\mathrm{ZFC}}(p,\bot),\\
 \mathrm{ZFC}&\vdash
 \neg\Halt(M_{238},0^{\mathbb Z})\leftrightarrow\Con(\mathrm{ZFC}).
\end{align*}
The proof is the ordinary mathematical composition developed in this
report, using the explicitly identified inherited calibration.
\end{theorem}

The theorem does not assume that ZFC is consistent. The assertion that
this particular machine actually runs forever follows if ZFC is
consistent. No finite execution test is used to infer that assertion.

\subsection{Why the bit is kept temporarily}

The row $91/1$ originally erases the read $1$ immediately. Keeping it
briefly allows existing helpers $167$ and $151$ to distinguish two caller
contexts. The modified row of $80$ can then serve its original role and
the role formerly assigned to $169$. The surrounding tape contains the
information needed to recover the correct control path. Subsequent steps
perform the required erasure and restore the complete intended tape.

This is a change to a small control implementation, with a compensating
helper edit. It is not obtained by finding two states whose transition
rows were already identical. The savings count all surviving helpers,
and the proof checks both original callers of the reused control.

Disjoint changed rows alone would not prove compatibility. A changed
helper can affect another block even without sharing its entry state,
and a source transformation can invalidate a tape guard. The independent
audit therefore checks the complete block traces and incoming ports,
and the source-sensitive guard is rederived on $B(S)$. There are twelve
distinct local identities, replayed on both corresponding edges, giving
24 comparisons. An additional direct proof checks the final 238 runtime
without using the local-fold guard as a premise.
