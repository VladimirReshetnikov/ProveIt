\section{Independent review and additional searches}
\label{sec:additional-review}

The successful G construction became available in existing shared ProveIt
project work while an independent search was developing symmetry and
polarity variants.  This packet retains the G construction's core
\file{portable/} files unchanged and adds independent review, a fresh
runtime replay, and the separate search evidence.  The G discovery is not
attributed to the symmetry or polarity branch.  The exact input inventory
and its hashes are recorded in \file{PROVENANCE.json}.

The fresh replay of the G construction returned
\file{FULL_REPLAY_PASS}.  It reconstructed the source, checked the
emitter and logical derivations, proved the three folds, checked the
complete blank initialization, and freshly derived all 5,956 unbounded
runtime cases.  The inherited baseline's retained runtime certificates
were audited; this run did not redundantly rederive all earlier runtime
tables.  The optional \file{--full-baseline} mode remains available for
that purpose.  The full receipt and phase logs are under
\file{verification_runs/independent_full_replay/}.

Three additional reviews examine the logical bootstrap, source binding,
and literal transition folds separately.  In particular, the source
review reconstructs the exact changed formula words independently of
the G constructor and emitter.  The logic review checks that the
propositional interface precedes the new equality proof and that
$G(a,b,a)$ is available in an unconditional logical-row position even
though the corresponding set-theory bundle's gate is disabled.

\subsection{A new logical source simplification}

The independent polarity branch changes the enumerated K matrix from
$\psi$ to $\neg\psi$ while keeping the private label equal to the
code of $\psi$.  Contraposition, conjunction exchange, and placing the K
component last reduce the bundle from eight native negation macros to
four.  Each macro expands to 47 fine instructions, so the reduction is
188 occurrences.  The next section gives both consistency directions
and the exact code/private-label argument.  A 19-step contextual rewrite
certificate checks the displayed formula fusion.

This is a useful remaining opportunity: compile this shorter source while
retaining or improving the contextual sharing that made the G machine
small.  The present packet records the completed source theorem and the
measured compiler specimen; it does not infer a smaller state count from
the shorter formula.

\subsection{Scoped negative searches}

The separate source-layout search also considered rotations beyond the
usual closed-block rule.  For
$((A,B),C)\leftrightarrow(A,(B,C))$, it suffices that $A$ has no escaping
break and $C$ has no escaping continue; the middle block can be open.
Every accepted source was nevertheless checked by both complete guarded
control-flow resolvers before finite table and boot checks.
The measured SYM layout retained 224 states and reduced the tested
problematic address tails from 42 to 36.  The retained run did not
establish a further state saving.

Another bounded search tried replacing two context-separated decoder
pairs by two shared hosts and one common router, for a possible net
one-state reduction.  No candidate passed the tested local templates.
These negative records cover only the stated search spaces and have no
force as lower bounds on arbitrary Turing machines.

The independently regenerated nine equality-frontend proof modes from
the G construction also passed.  Their receipt is retained under
\file{verification_runs/independent_exploratory_replay/}.  The additional
symmetry, polarity, and logical-obstruction checks can be replayed with
\file{additional_research/reproduce_additional.py}; they are supplementary
to the core 223-state theorem.
