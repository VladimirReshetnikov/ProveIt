\subsection{A combined family of numerical axiom builders}

The current machine enumerates numerical derivations. An apparent
classical equivalence of formulas is therefore insufficient by itself:
the source transfer must apply to all numeric axiom parameters and to the
actual falsity code 1. This branch combines two already proved source
transformations, without changing arbitrary matrix codes inside the
closure scheme.

The first transformation is the anchored equality-orientation family.
It jointly orients the existential equality axiom and the anchor
premises of the Euclidean equality axiom; independently it can reverse
the membership-transport equality premises, the Euclidean conclusion,
and the equality-vacuity atom. The supplied converse-theory proof
recovers the same numerical theorem sets in both directions. Five
binary choices give 32 builders. The second transformation removes
chosen double negations in the fixed theory bundle using the common
numerical calculus. The original bundle has six selected sites; the
generator combines every orientation with DNE masks 0, 32 and 63,
giving 96 exact source targets.

For each target, the checker reads the pinned original specification as
a symbolic syntax tree, emits the original stack macros, and interprets
those macros independently. It checks the protected old formula,
generalization output, all eight logical rows, final bundle, and the
unique reads of the remaining input parameters. The source fragment is
1,270 fine tokens before DNE; mask 32 has 1,252 and mask 63 has 1,162.
These are exact source-word lengths. They do not count grammar states.

All 32 orientation variants at DNE mask 32 received an eight-second
bounded grammar screen. Each resulting grammar passed the independent
54-lock structural auditor. The control retained 128 rules; the best
nonidentity output retained 131. Other outputs retained 132--138.
This is evidence about those recorded heuristic runs, not about the
minimum grammar for any of the 32 target words.

\subsection{Independent parameters and output order}

The next family permutes the parameters $a,b,c$ independently inside
one complete logical schema, keeping the fourth Lukasiewicz parameter
$u$ fixed. Every such permutation is a bijection of that schema's
numerical instance family. The same generator also exchanges each pair
of adjacent logical outputs. After duplicate targets are removed, the
control, single-row permutations and adjacent exchanges give 48 source
targets. They preserve the DNE32 bundle and its gate.

The completeness transfer is explicit. If the eight logical rows are
pushed in order $\pi=(\pi_1,\ldots,\pi_8)$, put
\[
 k_\pi(j)=9-\operatorname{pos}_\pi(j).
\]
The axiom selector for row $j$ is
\[
 \mathtt{DISCARD;AX;}\mathtt{NIP}^{\,k_\pi(j)}
 \mathtt{;DROP;}\mathtt{NIP}^{\,11-k_\pi(j)}.
\]
Here the exponent applies to the NIP repetition, not to the preceding
commands. AX pushes the protected old formula, GEN and eight logical
rows; the first $k$ pops select the desired row. DROP installs that row
and pushes the current bundle. The remaining $11-k$ pops remove the
bundle and the other new stack entries. The block returns the selected
theorem with the old stack and zero cache. Every intermediate axiom or
GEN code has an outer constructor tag different from the halting code.
For independently renamed parameters, use the inverse permutation when
constructing the selected AX command. With incoming cache zero, all
three scalar parameters are independently realizable. Induction on the
finite derivation gives a primitive-recursive new candidate number
using the unchanged dual-Cantor encoding. The scheduler's dirty-root
reachability argument then supplies the same halting equivalence.

Ten of the 48 targets had seeded grammars of at most 132 rules and
received twelve-second screens. All ten outputs passed the structural
auditor. The control remained at 128; the others used 130--132 rules.
These new combinations failed to improve the machine count in the
recorded search.

\subsection{A valid generalization variation with an invalid short scanner}

One additional source observation is that GEN may use the independently
arbitrary parameter $c=\mathtt{axiomcode}-3$ as its binder instead of
$a$. Soundness still holds because unrestricted generalization is valid
for any numerical binder. For completeness, an intended
$\forall i\,\theta$ is obtained by choosing $c=i$ in the GEN selector
block. Other logical and bundle outputs retain their own complete
families. The cleanup still selects GEN in stack slot nine.

At the macro level this changes the initial read from 166 to 168:
\[
 (166,121,180,176)\quad\rightsquigarrow\quad
 (168,121,180,176).
\]
The symbolic stack check verifies the new GEN output before parameter
$b$ is read. Applying it to the 48 preceding targets gives 48 additional
targets, for 96 in this second family. Eight seeded grammars of at most
132 rules were screened for twelve seconds each. Every one failed the
required zero-run bound: the resulting AST had maximum zero run seven.
Their other structural constraints pass when that scanner assertion is
diagnostically disabled, but the disabled assertion is essential to the
117-role runtime. Those eight proposals are therefore rejected.

There is a further search limitation: the optimizer accepts moves only
when the resulting zero run is at most six, whereas these seeds already
have zero run seven. Their stored outputs need not represent effective
exploration of the legal short-scanner space. The failure is recorded as
an inadmissible seed/output, not as a negative theorem about the valid
GEN transformation. A future search can supply a different valid seed
or jointly change the scanner and grammar, charging both costs.

\subsection{Exact artifacts and reproduction scope}

\texttt{combined\_variants.json} and
\texttt{genc\_parameter\_variants.json} retain all generated symbolic
rows, macro words, fine words, source choices and hashes. The
\texttt{screen\_valid/} and \texttt{genc\_screen/} directories retain
the actual candidates, search logs and auditor results. The
\texttt{gen\_c\_diagnostic.json} file identifies the exact rejected
scanner assertion. The archived source-search package supplies the
unchanged audited emitter, original opcode map, baseline grammar,
source proof and independent auditor. The local scripts specify the
new combinations and bounded screens.

All searches are timed, so a repeated run with the same RNG seed need
not stop at the same iteration on another computer. The retained
candidates and their structural checks are deterministic. No output
from this branch has been promoted to a certified 244-state machine.
