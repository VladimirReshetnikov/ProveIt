ATTRIBUTED PRIOR INDEPENDENT VERIFIER

The files verify_rm_certificate.py and verify_schema_rm_certificate.py are
copied unchanged from the prior zfc_small_machines_20261016 incoming report
in ProveIt commit 96836f9eea3540e96322c3d28c7127a582aae223. The former is that
archive's vendor/one_schema_machine/verify_rm_certificate.py; the latter is
code/verify_schema_rm_certificate.py.

The first verifier was prepared in the earlier one-schema research report.
Its independent string/integer path engine checks the finite register-program
certificate without importing the grammar generator or binary TM compiler.
The second verifier adapts its input interface to explicit reference DAGs.
No new authorship of these two files is claimed.

The original attribution and license-boundary notice is retained verbatim in
ORIGINAL_NOTICE.txt. No blanket relicensing of upstream work is intended.
Andrew Wade's compiler sources are not redistributed in this directory.

The new recheck_included_certificate.py runner adds fixed local input pins,
expected result checks, and a rejected swapped-branch negative control. Its
successful execution is not presented as formal kernel verification.
