\section{Two obstructions to deleting one membership-congruence row}
\label{sec:one-row-obstructions}

The results in this section concern the exact numerical calculus behind
the source program. They preserve native equality, seven of the eight
logical rows, and every instance of the literal nonlogical bundle. They
do not establish a consistency-strength separation for a reduced theory.
In particular, a new interpretation of ZFC in either reduced calculus is
not excluded. The conclusions exclude two particular proposed proof
strategies, with explicit counterinterpretations.

\subsection{The precise calculus and its numerical aliases}

Write $\mathcal C$ for the calculus generated by truth code $0$, modus
ponens, generalization, the eight rows $\rho_1,\ldots,\rho_8$, and the
guarded bundle. The authoritative definitions are
\href{https://github.com/jeff87654/busy-beaver/blob/zf-254/ZF/m254/coq/logic/Codes254.v}{\texttt{Codes254.v}}
and
\href{https://github.com/jeff87654/busy-beaver/blob/zf-254/ZF/m254/coq/logic/Thm254.v}{\texttt{Thm254.v}}.
The retrieved blob hash of \texttt{Codes254.v} is
\texttt{fd6f94345cfb65be33f427c03ba09fe003b2fbbb}; a copy accompanies this
report. Put
\[
 P(x,y)=\frac{(x+y)(x+y+1)}2+y,
\]
\[
 \begin{aligned}
 \operatorname{Imp}(x,y)&=4P(x,y),&
 \operatorname{Rel}(i,j)&=4P(i,j)+1,\\
 \operatorname{All}(i,x)&=4P(i,x)+2,&
 \operatorname{Eq}(i,j)&=4P(i,j)+3.
 \end{aligned}
\]
Falsity is the actual numerical code
$F=1=\operatorname{Rel}(0,0)$. Negation, conjunction and existential
quantification are the source macros
\[
 \neg A=(A\to F),\qquad
 A\land B=\neg(A\to\neg B),\qquad
 \exists i\,A=\neg\forall i\neg A.
\]
Code $0$ is interpreted as truth. The only non-well-founded constructor
collision, $\operatorname{Imp}(0,0)=0$, is then truth-value preserving.
Every positive decoded code $c$ mentions only labels strictly below $c$;
the exceptional code $0$ is closed. In particular the variable labelled
by the matrix code $c$ is semantically fresh for that matrix. This also
holds for $c=1$, whose displayed label $0$ is smaller than $1$ and whose
interpretation below is constant false.

We use the original parameter order:
\[
 \begin{aligned}
 \rho_3(a,b,c)&:\quad
   a=b\ \to\bigl(\operatorname{Rel}(c,a)\to
                         \operatorname{Rel}(c,b)\bigr),\\
 \rho_5(a,b,c)&:\quad
   c=a\ \to\bigl(\operatorname{Rel}(c,b)\to
                         \operatorname{Rel}(a,b)\bigr).
 \end{aligned}
\]
These are right and left membership congruence, respectively.
Let $\mathcal C_{-3}$ omit every $\rho_3$ instance, and let
$\mathcal C_{-5}$ omit every $\rho_5$ instance. All other rules and
emissions remain literally unchanged.

For precision, the nonlogical formulas are written below with $R(i,j)$
standing for the native atom $\operatorname{Rel}(i,j)$, not for a newly
defined relation. The matrix $\phi_c$ has numerical code $c$:
\[
\begin{aligned}
C(a,b,c):={}&\exists b\,\Bigl[
 \forall a\Bigl(R(a,b)\to\Bigl(
  \exists c\bigl[
   \forall b\bigl(\forall c(R(c,b)\to R(c,a))\to R(b,c)\bigr)
       \land R(c,b)\bigr]\\[-2pt]
 &\hspace{48mm}\land\forall c(R(c,a)\to R(c,b))\Bigr)\Bigr)
       \land R(c,b)\Bigr],\\
G(a,b,c):={}&\exists c\,\Bigl[
 \forall a\bigl(R(a,b)\to
   \forall b(\phi_c\to\exists b(\phi_c\land R(b,c)))\bigr)\\[-2pt]
 &\hspace{37mm}\land\forall b(R(b,c)\to\exists a\phi_c)\Bigr].
\end{aligned}
\]
The bundle is $(C\land G)\land(V_R\land V_=)$, where
$V_R$ is $R(a,b)\to\forall c R(a,b)$ and $V_=$ is
$(a=b)\to\forall c(a=b)$. The gate is exactly $c\ne a$ and $c\ne b$;
the case $a=b$ is allowed. If the gate fails, the source emits truth $0$.
The displayed shadowed binders matter to the proofs below.
The upstream set-theory interpretation is documented in
\href{https://github.com/jeff87654/busy-beaver/blob/zf-254/ZF/m254/design/settheory.md}{\texttt{design/settheory.md}}.

\subsection{Label-dependent permutations preserve the entire bundle}

\paragraph{Theorem 1 (relative nonderivability).}
Assume $\operatorname{Con}(\mathrm{ZFC})$. Then
\[
 \mathcal C_{-3}\nvdash\rho_3(0,1,2),\qquad
 \mathcal C_{-5}\nvdash\rho_5(1,2,0).
\]
The two target codes are, respectively, $27982632$ and $74042232$.
Thus a deleted membership-congruence family cannot simply be recovered
from the other seven logical rows and the unchanged set-theory bundle.

\paragraph{Construction.}
Work in ZFC. For each label $i$ choose definable rank-preserving class
bijections $g_i,f_i:V\to V$. Only one finite transposition will be needed.
For a valuation $s$, set
\[
 R(i,j)[s]\quad\Longleftrightarrow\quad
             g_i(s(i))\in f_j(s(j)),\qquad
 (i=j)[s]\quad\Longleftrightarrow\quad s(i)=s(j).
\]
Interpret implication materially and $\forall i$ by varying coordinate
$i$ over all sets. This is a semantics for the numerical proof rules.
It deliberately depends on variable names and is not an ordinary
first-order structure with a single membership relation.

Rank preservation implies $g_i(x)\notin f_i(x)$ for every $i,x$.
Hence $F=R(0,0)$ is false under every valuation, including while coordinate
$0$ is being quantified. All source negation and existential macros
therefore have their classical meanings. The truth-code collision and
every occurrence of a captured falsity alias are sound. Freshness is
unchanged: changing coordinate $c$ does not change any atom whose labels
are below $c$, and does not change the fixed functions associated with
those labels.

The propositional row, quantified implication, quantifier commutation,
$\exists i\forall i A\to A$, equality existence, Euclidean equality,
and both guarded atomic vacuity formulas are valid. Modus ponens and
generalization preserve validity. If all $g_i$ are identities, $\rho_5$
is valid; if all $f_i$ are identities, $\rho_3$ is valid. This verifies
every retained logical rule in the two interpretations used below.

\paragraph{Validation of $C$.}
First suppose $a,b,c$ are pairwise distinct. Write $p=s(c)$ and choose
a limit ordinal $\alpha>\operatorname{rank}(p)$. For the outer $b$-witness
take $B=f_b^{-1}(V_\alpha)$. The seed is true since
$g_c(p)\in V_\alpha$. If the universally bound value $X$ at $a$ satisfies
$R(a,b)$, then $\operatorname{rank}(X)<\alpha$. Since rank is preserved,
$f_a(X)\subseteq V_\alpha$, proving the transitivity arm.

For the power-container arm define
\[
 K_X=\{g_b(Y):f_b(Y)\subseteq f_a(X)\},\qquad
 W_X=f_c^{-1}(K_X).
\]
The first object is a set: it is the image of the actual powerset of
$f_a(X)$ under $g_b\circ f_b^{-1}$. It satisfies
\[
 \operatorname{rank}(K_X)\leq\operatorname{rank}(X)+1<\alpha.
\]
Thus $g_c(W_X)\in V_\alpha$, which is the required $R(c,b)$ after
the inner $c$ is rebound to $W_X$. The shadowed universal $c$ in the
subset test ranges over $Z$ and asserts
\[
 \forall Z\,\bigl(g_c(Z)\in f_b(Y)\to
                         g_c(Z)\in f_a(X)\bigr).
\]
Surjectivity of $g_c$ makes this exactly $f_b(Y)\subseteq f_a(X)$.
The required conclusion is $g_b(Y)\in f_c(W_X)=K_X$, which follows
from its definition. This verifies the literal tree, including its
shadowed $b$ and $c$ binders.

If $a=b$, the universally quantified closure premise becomes
$g_a(X)\in f_a(X)$ and is false. Only the seed remains, supplied by
the same $B$. These are all gate-allowed collisions; the excluded
cases $c=a$ or $c=b$ emit truth.

\paragraph{Validation of $G$.}
Suppose $a\ne b$ and fix all other free coordinates. Let $\Psi(x,y)$
be the interpreted finite matrix, with input coordinate $a$ and output
coordinate $b$. Coordinate $c$ is fresh, by the numerical bound above.
For the original free domain value $B=s(b)$, the actual input set is
\[
 A=g_a^{-1}[f_b(B)].
\]
Collection and Separation in ZFC give a set $Y$ meeting every nonempty
$\Psi$-fiber over $A$, with every member of $Y$ a $\Psi$-output. One
can require its source to lie in $A$, which is stronger than the bundle's
global support condition. Set
\[
 C=f_c^{-1}(g_b[Y]).
\]
Injectivity of $g_b$ gives
$R(b,c)[b:=y,c:=C]\ \leftrightarrow\ y\in Y$.
This proves coverage and support in the displayed $G$. If $a=b$, the
input premise is a false diagonal and $C=f_c^{-1}(\varnothing)$ makes
output membership empty. This proof includes matrix codes $0$ and $1$:
they mean truth and falsity, respectively, and are fresh in the required
semantic sense. It does not use a truth predicate for arbitrary formulas.

\paragraph{The two refutations.}
Let $e=\varnothing$, $u=\{e\}$, $A=\{u\}$, and $B=\{e,u\}$.
The distinct sets $A,B$ have rank $2$. Let $\pi$ interchange them and
fix every other set.

For $\mathcal C_{-3}$ take every $g_i$ to be the identity, $f_1=\pi$,
and $f_i=\mathrm{id}$ for $i\ne1$. With
$s(0)=s(1)=B$ and $s(2)=e$, equality $0=1$ and $R(2,0)$ are true,
whereas $R(2,1)$ is false. This refutes $\rho_3(0,1,2)$.

For $\mathcal C_{-5}$ take every $f_i$ to be the identity, $g_1=\pi$,
and $g_i=\mathrm{id}$ for $i\ne1$. With
$s(0)=s(1)=B$ and $s(2)=\{B\}$, equality $0=1$ and $R(0,2)$ are true,
whereas $R(1,2)$ is false. This refutes $\rho_5(1,2,0)$ in the original
source parameter order.

For any finite numerical derivation, recursively translating its formulas
by this interpretation produces finite ZFC formulas. The preceding
arguments give finite ZFC proofs of each translated axiom, using just
the corresponding finite Separation/Collection instances. The translated
MP and GEN steps remain valid. A proof of either target would therefore
give a ZFC proof of its universally quantified interpretation. The fixed
hereditarily finite countervaluation gives a ZFC proof of its negation.
Under $\operatorname{Con}(\mathrm{ZFC})$ this is impossible, completing
the proof. This is an ordinary proof-translation argument; no serialized
PA proof object or Lean formalization is claimed.

\subsection{What a reserved-label relation really repairs}

Fix distinct reserved labels $r,s$ and use object-variable labels outside
$\{r,s\}$. Define, as an actual formula macro,
\[
 R^{r,s}(i,j):=\exists r\exists s\,
       \bigl((r=i)\land(s=j)\land R(r,s)\bigr).
\]
The relation atom inside this macro always has the same two labels.
This does repair the logical congruence problem for the new relation,
without deriving either missing native congruence row.

Here are finite syntactic derivation templates, so that this assertion
does not silently appeal to full first-order substitution. Propositional
reasoning is available from $\rho_8$ and the original $\rho_6$; the latter
gives explosion from the relative $F$ as in the upstream
\href{https://github.com/jeff87654/busy-beaver/blob/zf-254/ZF/m254/coq/logic/Comp_Prop254.v}{\texttt{Comp\_Prop254.v}}.
Equality reflexivity follows from $\rho_7(x,x,x+1)$, existential
monotonicity, $\rho_1(x+1,x)$, and equality vacuity. Equality symmetry
and transitivity then follow from $\rho_7$. These derivations use neither
membership-congruence row; their individual steps are exhibited in
ProveIt's \texttt{TarskiDerived.lean}, as documented by
\href{https://github.com/VladimirReshetnikov/ProveIt/blob/6446ff5668307a2ac6aee1896037f0b792090389/Computability/BusyBeaver/Research/ZFC/tarski_logic_layer.md}{the logic-layer report}.
The inspected source is the preserved
\href{https://github.com/VladimirReshetnikov/ProveIt/blob/6446ff5668307a2ac6aee1896037f0b792090389/SetTheory/Cardinals/docs/reports/set-theory/zfc-closure-kernels/code/35-dirty-formal-src-BusyBeaver-ZFC-TarskiDerived.lean}{\texttt{TarskiDerived.lean} source copy}.
Its \texttt{ex\_mono} uses only $\rho_2$, GEN and propositional
contraposition. Its \texttt{ex\_elim} on the fresh equality formula uses
equality vacuity, \texttt{ex\_mono}, and $\rho_6$. Thus the helper
dependencies of \texttt{eq\_refl}, not just its final displayed step,
avoid $\rho_3$ and $\rho_5$.

The needed conditional quantifier lifting is elementary. If
$\vdash H\to(A\to B)$ and $\vdash H\to\forall kH$, contraposition
gives $H\to(\neg B\to\neg A)$. Generalize it at $k$ and apply
$\rho_2$ twice to obtain
$H\to(\forall k\neg B\to\forall k\neg A)$.
Propositional contraposition yields
\[
 \vdash H\to(\exists k A\to\exists k B).
\]
Unconditional existential monotonicity is the same proof without $H$.

For right congruence let $H$ be $j=k$. Equality transitivity gives
\[
 H\to\bigl(((r=i)\land(s=j)\land R(r,s))\to
              ((r=i)\land(s=k)\land R(r,s))\bigr).
\]
Equality vacuity at $r$ and $s$ permits two applications of conditional
lifting. The result is
$j=k\to(R^{r,s}(i,j)\to R^{r,s}(i,k))$.
Left congruence is identical, changing the first equality guard.
No label in $R(r,s)$ has been substituted or renamed. Atomic vacuity
for the macro at an object label different from $i,j$ follows by the
existing vacuity induction through its fixed binders. The numerical gate
for native vacuity can use every label distinct from the atom's two
labels; it does not require a separate larger-label assumption.

For a single deletion one may also anchor irreflexivity at the actual
falsity label. In $\mathcal C_{-3}$ choose $(r,s)=(1,0)$. The two equality
guards of $R^{1,0}(i,i)$ imply $1=0$; retained left congruence yields
$R(1,0)\to R(0,0)=F$. Existential monotonicity and
$\exists kF\to F$ finish the derivation.
The last implication follows from $F\to\forall kF$ and $\rho_6$,
so it remains valid for $k=0$. In $\mathcal C_{-5}$ use $(r,s)=(0,1)$
and retained right congruence instead. Thus native equality, the surviving
logical rows and this macro provide the intended equality-congruence and
irreflexivity lemmas for the interpreted relation.

These are finite schematic derivations in the reduced numerical calculus.
They are not a claim that the literal CP/GIC bundle has been translated
to the new relation, nor a checked proof-assistant extension.

\subsection{An anchored rank interpretation obstructs GIC transfer}

\paragraph{Theorem 2 (the natural right-row repair fails).}
Assume $\operatorname{Con}(\mathrm{ZFC})$. In $\mathcal C_{-3}$,
replacing the displayed relation occurrences of GIC by $R^{1,0}$ does not give a
derivable full GIC schema. This remains true even though $R^{1,0}$ has
the logical congruence and irreflexivity properties just proved. The
connective macros keep their distinguished $F=\operatorname{Rel}(0,0)$;
the replacement concerns the displayed nonlogical $R$-occurrences, not
those hidden falsity occurrences.

\paragraph{Construction and logical validity.}
For a set $X$, put
\[
 h_j(X)=
 \begin{cases}
 V_{\operatorname{rank}(X)},&j=0,\\
 X,&j\ne0.
 \end{cases}
\]
Interpret the native atom by
\[
 R(i,j)[s]\quad\Longleftrightarrow\quad s(i)\in h_j(s(j)),
\]
and interpret equality and coordinate quantifiers as before.
Every $h_j$ preserves rank, and fixes every hierarchy stage $V_\beta$.
Thus all diagonal membership atoms are false. In particular the actual
$F$ is constant false while coordinate $0$ is quantified; $\rho_6$ with
binder $0$, every relative-negation macro, and the code-$0$ collision
are sound. All seven retained rows of $\mathcal C_{-3}$ and both guarded
vacuity formulas hold. Left congruence is immediate because the first
argument is interpreted uniformly across labels. Matrix freshness holds
for exactly the same numerical reason as in Theorem~1.

\paragraph{Literal CP, including collisions.}
Take pairwise distinct $a,b,c$, a free seed $p=s(c)$, and a limit ordinal
$\alpha>\operatorname{rank}(p)$. Choose the outer witness $B=V_\alpha$.
Since $h_b(V_\alpha)=V_\alpha$, the seed is true. A universally bound
$X$ in this container has rank below $\alpha$. The transitivity arm is
$h_a(X)\subseteq V_\alpha$, which follows from rank preservation.

For the inner power container choose
\[
 W=V_{\operatorname{rank}(X)+1}.
\]
It has rank $\operatorname{rank}(X)+1<\alpha$, so $R(c,b)$ is true
with $c:=W$. The shadowed universal $c$ in the subset test gives
exactly $h_b(Y)\subseteq h_a(X)$. Consequently
\[
 \operatorname{rank}(Y)=\operatorname{rank}(h_b(Y))
 \leq\operatorname{rank}(h_a(X))=\operatorname{rank}(X).
\]
Hence $Y\in W=h_c(W)$, the required $R(b,c)$. This proof works
unchanged when any one of $a,b,c$ is $0$. If $a=b$, the closure premise
$X\in h_a(X)$ is false, and the same $B$ supplies the seed. These
exhaust all permitted coincidences. Failed gates again emit truth.

\paragraph{Literal GIC, including matrix codes $0$ and $1$.}
If $a=b$, the coverage premise is a false diagonal; choose $C=\varnothing$.
Because $h_c(\varnothing)=\varnothing$, support is vacuous as well.
Now suppose $a\ne b$. If $c>0$, output membership is ordinary membership:
$R(b,c)[b:=y,c:=C]$ means $y\in C$. The actual input set is
$h_b(B)$, including when $b=0$. ZFC Collection and Separation applied
to the one interpreted finite matrix give exactly the required output
set and its global support. This covers $c=1$: its matrix is false,
and one may choose the empty set.

If $c=0$, its matrix is truth and the gate forces $a,b\ne0$.
Choose $C=V_1=\{\varnothing\}$. Output membership means
$\operatorname{rank}(y)<1$, so there is an output, namely
$\varnothing$. It witnesses coverage for every input, and support is
automatic because the matrix is truth. Thus every literal GIC instance
holds, not merely a restricted collection schema.

\paragraph{Failure of the regularized GIC.}
For object labels $i,j$ outside $\{0,1\}$, the new relation has the
ordinary semantic meaning
\[
 R^{1,0}(i,j)[s]\quad\Longleftrightarrow\quad
         \operatorname{rank}(s(i))<\operatorname{rank}(s(j)).
\]
Let $u=\{\varnothing\}$. Consider GIC for the constant-in-input matrix
$\phi(x,y;p):=(y=p)$, with free domain $B=u$ and parameter $p=u$.
The domain is nonempty for this relation, since
$\operatorname{rank}(\varnothing)<\operatorname{rank}(u)$.
Coverage forces $R^{1,0}(u,C)$ for a proposed collector $C$, so
$\operatorname{rank}(C)>1$. But then $R^{1,0}(\varnothing,C)$ also
holds. Support at $\varnothing$ would imply $\varnothing=u$, a
contradiction.

One completely specified target uses input label $2$, output/domain
label $3$, parameter label $5$, and collector label $167$. Indeed
$\operatorname{Eq}(3,5)=167$, so the original code-as-label convention
can be used. Take the displayed $G(2,3,167)$, whose matrix is
$\operatorname{Eq}(3,5)$, and replace its displayed native $R$-occurrences by $R^{1,0}$, retaining
the connective macros and their fixed falsity code. All object labels in
those displayed occurrences avoid the two reserved labels,
so the macro is capture-free. The valuation $s(3)=s(5)=u$ refutes this
specific translated formula. Its native unmodified GIC instance remains
valid in the interpretation.

The same finite proof-translation argument as in Theorem~1 now proves
the claimed relative nonderivability. This result obstructs this anchored
right-congruence regularization. It does not address every possible
definition of membership, does not settle the analogous left-row
interpretation, and does not prove that either reduced calculus has
smaller consistency strength than ZFC.

\subsection{Computational scope and attribution}

The accompanying \texttt{check\_label\_twist.py} checks the two numeric
target codes, explicit countervaluations, all retained atomic/equality/
vacuity instances on the $16$ objects of $V_4$, and finite transport
identities used in the infinite proof. Its JSON report records the
individual counts. These finite carriers are diagnostics, not finite
models of CP or GIC. The infinite axioms are justified by the proofs
above. The accompanying anchored-rank diagnostic similarly checks its
explicit GIC countervaluation without claiming a finite model of the
literal set theory.

The upstream theory, numerical codec and logical basis retain their
original attribution. ProveIt's earlier
\href{https://github.com/VladimirReshetnikov/ProveIt/blob/6446ff5668307a2ac6aee1896037f0b792090389/Computability/BusyBeaver/Research/ZFC/typed_countermodel.md}{finite-sort obstruction}
concerns a calculus after more of its equality mechanism has been
removed. Its earlier
\href{https://github.com/VladimirReshetnikov/ProveIt/blob/6446ff5668307a2ac6aee1896037f0b792090389/Computability/BusyBeaver/Research/ZFC/logical_engine_completeness.md}{logical-engine analysis}
also studies equality proxies and reserved labels. The new scope here is
one missing membership-congruence row with native equality and every
other original row and bundle instance retained, followed by the
specific anchored-rank obstruction. No general historical-priority claim
is made for label-dependent semantics or equality-guarded definitions.
