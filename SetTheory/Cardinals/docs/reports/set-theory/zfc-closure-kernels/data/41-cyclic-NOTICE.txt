This archive contains a new research report, new reference implementations,
and two unchanged public Turing-machine tables used as benchmark data.

The 254-state machine is Mira-Cult's construction. Jeff (jeff87654) supplies
its subsequent Coq verification. The 253-state reduction is mira-emmy's
public pull request 20, building on the same construction and verification.

254 source:
https://github.com/jeff87654/busy-beaver/blob/297ab8df7e5de329605c3875b4934643b371a5e3/ZF/m254/machine/zfc_254.tm

253 source:
https://github.com/mira-emmy/busy-beaver/blob/0d544f2a2e3c18f12278441a74b7879f31cbe856/ZF/m253/machine/zfc_253.tm

No upstream-wide license or m253/m254-specific license was found at these
pins. The inclusion of these unchanged reference tables does not assert a
license grant or relicense them. ProveIt's existing import likewise excludes
the upstream snapshot from its blanket MIT-0 grant:
https://github.com/VladimirReshetnikov/ProveIt/blob/8cf840b8a26d002041e7a26dc9688ce7ce5fd751/lib/jeff-busy-beaver-zfc254/README.proveit.md

Some new original implementation files carry MIT-0 notices in their headers.
Those notices apply only to the indicated new files, not to the benchmark
tables, the source mathematical publications, or upstream verification code.

The algebraic source is Hajnal Andreka and Istvan Nemeti,
Formalizing set theory in weak logics, arXiv:1111.0995v1 (2011).
The finite class-theory source is Harvey M. Friedman,
Simplified Axioms for Class Theory (15 September 2020).
The new finite-source generator records all normalization and proof-repair
decisions; it is not a verbatim copy of the publication's printed formulas.

The upstream machines and established source results are prior work. No
new sub-253-state binary consistency machine is claimed in this archive.
