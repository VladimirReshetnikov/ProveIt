ATTRIBUTION AND SOURCE STATUS
=============================

This report and the new code are research prepared for Vladimir Reshetnikov
and ProveIt. They retain the experimental status stated in report.tex.

Existing machine and calculus attribution:
  Mira-Cult: original 254-state machine and numeric calculus.
  Jeff and busy-beaver contributors: upstream verification and derivation work.
  Andrew Wade: compiler/framework and preceding machine engineering.
  mira-emmy: the public 253 reduction, upstream PR20 at the pinned head.
  ProveIt contributors: the physical-register permutation, clean bootstrap,
    current formal endpoint, arithmetic interfaces and earlier experiments.

reference/proveit/ is a minimal byte-preserving source snapshot. It is not a
new fork or a complete Lean build environment. Source origins, immutable URLs,
sizes, and hashes appear in data/source_provenance.json.
reference/proveit/LICENSE is the ProveIt MIT No Attribution license. The
reference/proveit/lib/jeff-busy-beaver-zfc254/ subtree and the upstream README
retain their original upstream provenance; this package does not relicense
third-party source or machine tables. The preserved filenames and file headers
identify borrowed code. No upstream reduction is attributed to this report.

The original search records were kept unchanged, including their recorded
paths and elapsed times. machine_experiments/transport_normalization.json
explains the one-extra-LF byte correspondence for degree-one input hashes.
The diagnostic always checked the canonical machine-table digest before
searching. The root source inventory lists the canonical reference bytes.

The new source files are in code/ and machine_experiments/. The Python package
provides reference algorithms and finite replays. It contains no new Lean or
Coq kernel proof, no internal ZFC/PA proof, and no certified 251-state machine.
