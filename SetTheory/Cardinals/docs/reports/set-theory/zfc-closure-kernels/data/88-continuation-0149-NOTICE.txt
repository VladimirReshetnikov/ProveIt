source_decoder.py is imported for its independent Decoder implementation.
Its original standalone CLI and prior-package default paths are preserved;
the portable state commands import the module and supply their own inputs.
It is not a standalone entry point for this archive.

permutation_rebracket.py contains small explicit module-loading and ordered
leaf-traversal routines equivalent to those used by prior compile_rebracket.py;
its unrelated candidate generator is not imported. The guarded affine
semantics it calls remain the unchanged vendor/context246 implementation.

The new C++ incoming-edge and scanner-compensation search files extend the
new continuation-quotient matcher developed in this research session. They
are finite discovery programs; their presence is not a universal machine
correctness certificate. All runs use existing old-label tables and count
working-state graph reachability explicitly.

blank_start_survey.cpp adapts the prior initialization search in
vendor/context246/search/seed_search.cpp. It removes the table mutations,
raises the minimum frame distance to 64, adds complete input validation,
and records every bounded endpoint. The cited prior source is retained
unchanged in the vendor directory.
