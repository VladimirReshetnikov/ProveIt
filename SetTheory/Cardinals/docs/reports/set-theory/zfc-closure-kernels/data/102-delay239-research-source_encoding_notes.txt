Independent local-proof review
------------------------------

Files:
  review_local239.py
  local239_independent_review.json

The independent checker replays the six finite certificate paths directly
against both literal tables.  Every unassigned tape position is treated as
an independent original bit.  Any attempt to read such a position fails;
all replayed reads are forced by explicit assumptions or earlier writes.
The entire symbolic tapes agree at each endpoint, including every exterior
cell.  The checker additionally verifies the complete transition domains,
all other rows under the state map 169->80, and every incoming transition
needed for the old-machine structural invariant.

Cases (old steps/new steps, common endpoint relative to entry head):
  old 80/read0:  1/5,  state 25,  head +1
  old 80/read1:  1/1,  state 91,  head +1
  old 169/read0: 1/3,  state 57,  head +1
  old 169/read1: 1/5,  state 56,  head +1
  old 91/read0:  1/1,  state 106, head +1
  old 91/read1:  3/11, state 2,   head −3

The structural invariant is: state 67 has a 0 immediately to its left;
state 80 has 01 to its left; state 91 has011 to its left; state 169 has a 0
immediately to its left.  These predicates are vacuous initially at state 95
and are preserved by all incoming rows.

One semantic premise remains external to this short local checker:
old 169 reading 1 implies a 1 immediately to its right.  The state-fold agent's
verify_selector_guard.py checks it during all 8,386 unbounded runtime cases
using the unchanged inherited proof engine.  Its wrapper adds no rewrite
rule.  An affine 1-run of constant term at least 2, with nonnegative variable
coefficients, proves the premise for every natural valuation in a case.

Coverage review: q169 has no self-loop, so a unary summary cannot skip an
unexamined q169 control visit.  The four single-block proofs cover the list
induction steps and contain no q169 state.  At q169 an opaque/list head lacking
a registered lemma would make the underlying checker fail; hence the
wrapper's run test does not omit a successful unbounded proof branch.  The
full proof checks exact tape joins between instruction frames.  The extra
finite blank guard audit covers the initialization prefix.

The simulation argument uses invariants only at mapped OLD configurations.
It does not require these same predicates at every intermediate state of
the new run.  Each block has positive old and new length, and the displayed
blocks contain no intermediate halt.  Infinite old runs yield infinite new
runs; finite old halting runs yield finite new halting runs.  Together with
determinism this proves halting equivalence.  The root's direct full8386-case
runtime verification gives a separate route to the same machine-level
simulation result.

This track has not audited the entire earlier logical consistency compiler.
The local result transfers the exact 240 machine/source theorem to 239.  The
parent report must keep the inherited logical proof chain explicit and
distinguish ordinary mathematical verification from a proof-assistant
endpoint.

Source and compiler experiments
-------------------------------

1. Register permutation family: a rigorous narrow negative result.

permutation_quotient_screen.py constructs an overapproximation of exact
step-bisimilarity over every physical-register permutation in the specified
12-selector-row family.  Mutable rows are the read-1 rows of states
18,21,25,47,49,53,65,70,93,169,173,201; allowed skip targets are
60,44,31,56,38,40,28,64,69.  Distinct logical registers must have distinct
physical images; choices are otherwise allowed independently at different
occurrences, a relaxation of one global bijection.  Starting with 29,941
ordered state pairs including diagonals, 13 refinements leave no distinct
pair.  Thus none of the 9! permutations yields an exact transition quotient
within this family.  This says nothing against context-dependent folds,
changed initialization, changed tape layouts or multiple-step simulation.
Receipt: permutation_quotient_screen.json.

2. Source reachability: independently closed interval invariant.

reachable_intervals.py uses a finite capped interval domain, with every
final source-edge preservation obligation rechecked after convergence.
The cap 8 run gives 145,225 updates, 8,381 admitted guarded cases, 8,380
nonterminal edges, and excludes precisely:
  site 6314 positive, site 6315 control,
  site 6429 positive, site 6430 increment, site 6431 control.
Sites 6315, 6430, 6431 are unreachable.  These agree with the root's independent
cap 3 analysis.  The receipt is reachable_intervals8.json.  The new 239 proof
does not need these source restrictions: the direct runtime verification
covers all 8,386 cases and all independent natural register values.

3. Sequence grammar search: one independently verified alternate 240 layout.

Five 55-second heuristic runs examined 6,647,187 proposals in total.  No run
found a 124-node sequence grammar.  The current complement has 115 states and
the grammar has 125; some copied upstream search metadata says 118 and must
not be used as a state count.  Search engines were adapted from the existing
Source 68/Source 71 research implementations; this is not a new algorithm.

cluster_variant1 is a different 240-state table with 6,455 source leaves,
maximum source depth 48 (old 51), and the same maximum zero-run 6.  A 1,932-pair
increment/decrement-segment bisimulation checks every control edge against
the original source.  The exact blank initialization is unchanged at 409691
steps.  The inherited unbounded runtime checker passes all 8,386 cases.

4. NIP source specialization: six leaves saved, binary repair unfinished.

The exact source interval proves R6=0 at entry 11101001010.  The NIP check can
then be specialized from 12 leaves to 6, giving 6,449 source leaves.  An exact
affine prefix certificate splits R5 into 0, 1, 2+n, with a natural-number
induction for the clearing loop.  There are 8,369 commuting outside control
edges.  The normal form halts exactly when entry R5=1; otherwise it returns
with R5=R6=0 and all other registers unchanged.

Files: nip_specialize.py; nip_specialized/source_certificate.json and
nip_specialized/sites_logical.json.  The direct NIP idea was already in
earlier Source 57/Source 71 reports; the present result instantiates and
checks it against the exact current source.  A nominal 240 binary rewrite
breaks the existing 72/90 compensated return.  No repaired binary table or
state saving from this source specialization is claimed.  Work was paused
when the actual 239 fold was found.

Other finite heuristic fragment/commutation searches found no certified
state-saving alternative.  Their negative finite search outcomes are not
impossibility theorems and need not be included in the main deliverable.
