Semantic contraction
--------------------
The proposed direct full-seed construction is mathematically well-founded.
KEind222.c222_complete (lines305-323 of the baseline) gives satisfaction of
the ORIGINAL named theory with literal equality, not just satisfaction of its
equality translation. Thus a derivable translated bundle can establish the
full named seed property on the original model. The construction requires
free-name preservation under the equality translation and a private label
equal to the code of a double-negated translated matrix. The code bound then
makes the private label fresh and distinct from the two role labels. Named
falsity is literal False, so the named-bundle normalization itself requires
no irreflexivity hypothesis; the numerical decoding theorem still does.

Only the preliminary indiscernibility quotient is bypassed. The tagged-domain
bisimulation quotient, well-founded-part model construction and ordinary
completeness theorem remain. Existing Rocq Complete222 already uses the
corresponding direct construction, so credit the earlier cross-lane proposal
and Rocq architecture. Any net source saving must count the new freshness and
named-semantics proofs and retained compatibility modules.

A subsequent experiment can state the direct named seed lemma for arbitrary
distinct input/output labels. Choosing input3/output1 then matches the odd
name map used by Code254GIC.toNamed: slot1 maps to3, slot0 to1. This would derive
FormSeed directly and avoid KLowerSeed's additional equality binder moving
the input from3 to0. The same double-negation code is positive and divisible
by4, hence exceeds3. This is an unimplemented next step; its interface split
and net maintenance cost must be measured before any deletion is claimed.

Rocq boundary refactor
---------------------
The generic enumerator-completeness theorem inspected in the sibling patch
has the right strength. At a boundary pl(seed)=0, the reach theorem finds
each candidate np(seed)+k or has already halted. Choose Y=np(seed) and
N=P3(PY(P1 tail)); pairing bounds give Y<=N, so k=N-Y is valid. The reset/start
prefix and universal run_first theorem handle arbitrary remaining registers.
The theorem is completeness-only: arbitrary initial registers need not obey
the invariant required for soundness. Existing zero and seed endpoints are
specializations, and their statements remain intact. Compilation and recursive
kernel checks are owned by the Rocq worker, not claimed by this review.
