# Independent adversarial review: uniform-witness equality bases

## Verdict as of this review

The uniform ordinary proof schemes for positive-tag Rel/Eq binders have no identified bootstrap or freshness gap. This is conditional on the exact retained schemas and emitted witness family described below. It does not certify a source program, transition table, state saving or a compiled proof-assistant endpoint. Finite strict replay receipts are separate files.

The reviewed candidates retain rho2/3/4/5/6/8, full membership vacuity, MP, closed GEN, truth seed0 and the exact K core/gate. Candidate A adds primitive symmetry and replaces old rho1 with `Ex_a All_kappa Eq(a,b)`. Candidate B instead supplies `Ex_a All_kappa (Eq(a,b) AND Eq(b,a))`, with neither primitive symmetry nor rho7. Both delete primitive equality vacuity. Here kappa is RelCode or EqCode, strictly above both endpoints, even on the diagonal.

## Attacks checked

1. **Circular reflexivity or hidden old rho1.** The seriality argument uses the new uniform witness alone: `All_i F` implies `All_i not B_i`, contradicting the given `Ex_i B_i`. It never invokes primitive Eq reflexivity, old equality existence, universal specialization or existential elimination. Defined E(a,a) is a generalized propositional identity. Consequently the original reflexivity bootstrap that required VE is not being reused covertly.
2. **Using quantifier elimination before it is established.** Membership-only fresh vacuity is structural. Its negation case derives `Ex_i A -> A` from `A -> All_i A`, existential monotonicity and rho6. Seriality then supplies fresh `All_i A -> A`. Only after that is universal Eq at kappa used to obtain an unquantified membership implication.
3. **Uniform-binder collision with an arbitrary matrix.** Merely kappa(x,y)>x,y is insufficient for arbitrary f. The two-leg detour is essential. Choose z larger than every label of f,x,y. Both kappa(x,z) and kappa(z,y) exceed z, so they are absent from their respective matrices. z itself is absent from the first universal premise. This works for x=y, label0, and an original matrix explicitly containing kappa(x,y).
4. **GEN under an open premise.** The construction generalizes closed implication theorems and then distributes quantification with rho2. Premise transport uses an explicit fresh-vacuity theorem. No generalized open Eq or E assumption is required.
5. **E's internal auxiliary and requested binder collide.** E-vacuity first transports to w above a,b,i and the old auxiliary. Membership congruence transports to w above the third requested label. E-Euclid uses a common fresh w above all endpoint labels and all old auxiliary codes. These choices also cover diagonal endpoints and coordinate0. The auxiliary need not commute with arbitrary substitution.
6. **Missing Eq→E bridge.** No such unquantified bridge is needed. Congruence plus GEN/rho2 supplies `All_kappa G(a,b) -> E_ab^kappa`; existential monotonicity applied to UW then gives `Ex_a E_ab^kappa`, and safe-auxiliary transport gives the old interpreted rho1. Candidate B obtains both congruence directions from its conjunction and does not need primitive SYM.
7. **Relative bottom / Rel(0,0) alias.** Quantifier-free renaming fixes designated bottom, rather than literally renaming its numerical Rel(0,0) representation. `F -> All_i F` uses explosion; `All_i F -> F` is the newly proved seriality. E's fresh intermediate membership matrices avoid accidental zero/zero atoms until possible final specialization. This is a proof interpretation and need not be an injective syntactic substitution. The final checker must preserve this convention consistently.
8. **Classical tautology leaves importing equality strength.** The required classical basis remains derived from rho8; rho6 supplies explosion. Those derivations do not use old rho1, Eq reflexivity or VE. Primitive SYM is allowed only in A and must be forbidden in B. Finite proof-local checking cannot by itself replace the uniform argument.
9. **K's actual matrix/private-code coupling.** The safe coupling still selects c after applying the new E interpretation to an ordinary matrix and padding by double negation. c exceeds every resulting variable label and is not1 or3. The equality-free K template then translates literally into the actual source's `kcore(1,3,c,c)`. Reusing the un-translated matrix code would be invalid.
10. **Upper consistency / new witness validity.** In ordinary nonempty equality semantics, choose the a-witness equal to b's value. kappa is distinct from both endpoint names, so universal kappa is vacuous in G; the symmetric conjunction is also true. These are valid replacements, not unproved new set axioms. The existing relative-bottom/IR interpretation handles the numerical codes0 and1.

## Gated-witness variant

It is also sufficient to put `Ex_a All_c G(a,b)` in the final gated bundle and remove the standalone rho1 row, provided the gate is still c distinct from a,b. Project its instance at c=RelCode(a,b) to recover the witness family used above. Soundness uses the gate's freshness. Exact source emission, altered logical-row counts, proof-enumerator block counts and runtime remain independent obligations; the old fixed-count compiler must be explicitly adapted.

## Checker audit

The initial worker checker omitted explicit nonnegative prior-index and natural-label syntax checks. That does not reveal a flaw in the generated proofs, but it is insufficient for strong adversarial-checker claims. `check_witness_strict.py` independently checks natural formula labels/binders, constructor arities, nonnegative earlier proof references, exact rule set, closed GEN, independent expected endpoints and Boolean tautologies. It imports no generator or worker checker. Large nested JSON parsing was interrupted to avoid memory pressure; compact DAG input is required for the final replay. No interrupted run is counted as a certificate pass.
