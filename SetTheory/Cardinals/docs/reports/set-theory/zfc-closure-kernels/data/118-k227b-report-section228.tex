\subsection{The source-loop identity}
At each of four exact source occurrences, the old block repeatedly decrements
register~6 and increments register~5, then performs one final increment of
register~5. The new block performs the increment first, then tests/decrements
register~6 and repeats when positive. For initial values $(r_6,r_5)=(n,y)$,
both terminate at
\[
 (r_6,r_5)=(0,y+n+1),
\]
leave every other register unchanged, and exit normally. This is a direct
induction on $n$. The zero case checks the final versus initial increment;
the successor case reduces to $(n,y+1)$. Each repeated cycle strictly decreases
the natural source register.

The checker identifies all four exact local control graphs and proves that no
outside edge enters any block interior. Collapsing the four old and new blocks
produces identical 5,113-node control-flow graphs. Thus the local arithmetic
identity applies in its actual source context, including divergent surrounding
executions. The source shrinks from 5,125 to 5,121 operations, with 6,656 guarded
cases. This is a semantic source rewrite, not merely reassociation of an
unchanged operation list.
