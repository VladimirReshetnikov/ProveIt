INDEPENDENT TECHNICAL REVIEW OF THE CONSTRUCTOR FUSIONS
18 October 2026

Reviewed text: selective_equality.tex, sections se:fusion and
se:witness-fusion, in the accompanying formalism contribution.

The upper-model constructions are sound, conditional on the explicitly
identified inherited native-model calibration. This is an ordinary
mathematical review; it is not a proof-assistant check or a binary-machine
compiler certificate.

1. The H = N fusion

Start with the native model M, whose equality is literal identity, and use
the raw carrier U = M x M. Equality, E, and object-valued assignment lookup
observe first coordinates. Inc(s,t) observes s_0 and t_1. Defining

  N_U(a,b) = (H_M(a_0,b_1), N_M(a_1,b_1))

therefore supplies the native hull in the object role and the native NAND
constructor in the class role without an incompatible demand on either
coordinate. Direct substitution in R and D has the displayed native
projection. In particular no incidence or constructor congruence is used.
The independent named selector q is essential to this particular model:
the first coordinate of the fused N_U(d_U,d_U) need not be q_M.

2. Sharing Y, Z, and W through C, A, and Q

The native pairing P_M has both exact projections, hence is injective.
A fixed nesting supplies an injective map J : M^6 -> M. The second
coordinate J(s_0,s_1,j_0,j_1,z_0,z_1) makes C_U injective on complete raw
triples, while its first coordinate retains the native update. Coding only
first coordinates would not justify the unique raw preimage required here.

For any c in the range of C_U, its unique preimage determines all arguments
for the desired native witnesses. A_U(c,d_U) and A_U(c,q_U) occupy disjoint
raw argument pairs because d_M != q_M. Thus their first coordinates can
supply Y_M and W_M respectively, and Q_U(c,d_U) can supply Z_M. Off these
specified inputs an arbitrary default gives total functions.

For every input, the second coordinates must retain

  (A_U(j,k))_1 = A_M(j_0,k_0),
  (Q_U(j,a))_1 = Q_M(j_0,a_1).

This leaves the native class clauses valid even on the inputs used for
witness decoding. The first coordinates of the substituted witnesses are
exactly the displayed native witnesses. Their occurrences enter E_U or
the replacement argument of C_U, so these occurrences consume only first
coordinates. This includes the witness inside the expanded term D_U.
Changing C_U's second coordinate does not alter V_U or E_U observations.

Consequently the six-function and five-function upper-model transports
have no raw-argument collision or coordinate-projection defect. The lower
directions are direct definitional expansions of the eliminated function
symbols, with no assumption that C is injective in arbitrary target models.

3. The further three-function, one-constant transport

The subsequently proposed construction retains V, C, A and one constant d.
Use U = M^3. Equality and E observe coordinate 0, while Inc(s,t) observes
s_0 and t_1. Let tag0 = P_M(d_M,d_M), and let K9 be a fixed injective
pairing of nine native coordinates. Then

  J9(x) = P_M(q_M,K9(x))

is injective and its range avoids tag0, by the first native projection.
Prescribe d_U = (d_M,d_M,tag0) and
q_U = (q_M,A_M(d_M,d_M),tag0) before defining the functions. Define C by

  (C_U(s,j,z))_0 = C_M(s_0,j_0,z_0),
  (C_U(s,j,z))_1 = N_M(j_1,z_1) when s = d_U,
                    Q_M(j_0,z_1) when s = q_U,
                    an arbitrary native value otherwise,
  (C_U(s,j,z))_2 = J9(s_0,s_1,s_2,j_0,j_1,j_2,z_0,z_1,z_2).

Now C_U is injective, and neither d_U nor q_U lies in its image. Set
r_U = C_U(d_U,d_U,d_U) and h_U = C_U(d_U,d_U,q_U). Injectivity implies
r_U != h_U; image separation makes d_U,q_U,r_U,h_U pairwise distinct.

Define A_U's second coordinate to be A_M(a_0,b_0) and its third to be
tag0. Its first coordinate defaults to q_M. When its first argument c
is in the C image, decode its unique raw preimage (s,j,z) and use these
first-coordinate cases according to its second argument:

  d_U: H_M(s_0,j_1),       q_U: Y_M(s_0,j_1,z_0),
  r_U: W_M(s_0,j_0,z_1),   h_U: Z_M(s_0,j_1,z_0).

These cases are disjoint. Since d_U is outside the C image,
A_U(d_U,d_U) equals the prescribed q_U in all three coordinates.
This proves the defining abbreviation q = A(d,d) and resolves its
apparent dependence on C. The definition order is: prescribe raw d/q,
define C, compute r/h, define A, then verify q = A(d,d).

The derived N(a,b) = C(d,a,b) and Q(j,a) = C(q,j,a) have the exact
native class second coordinates. The terms

  H(b,t) = A(C(b,t,d),d),    Y(b,t,u) = A(C(b,t,u),q),
  W(s,j,a) = A(C(s,j,a),r),  Z(b,t,u) = A(C(b,t,u),h)

have the exact required native object first coordinates. C's class and
coding coordinates never alter update-law observations, and A's object
coordinate never alters atomic-class observations. All occurrence roles
therefore retain the earlier clause projections. This audit found no
raw-argument collision or coordinate-projection gap in this construction.
It does not audit the separately emitted exact byte counts or establish
a Turing-machine state bound.

4. Scope

The optional elimination of G through the first coordinate of A belongs
to a separate variant. The witness-sharing construction explicitly retains
primitive G; this review does not assume that both uses of A can be combined.

The model transport proves a signature reduction, not a Turing-machine
state reduction. It does not supply the missing fewer-than-245-state
compiler or a new kernel-checked consistency endpoint.
