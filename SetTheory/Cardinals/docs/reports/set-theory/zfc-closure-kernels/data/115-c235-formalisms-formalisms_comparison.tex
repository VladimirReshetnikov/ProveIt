\subsection{A finite arithmetic presentation and its cost boundary}

Another precisely calibrated presentation, already discussed in that
dossier, is Robinson arithmetic $\mathsf Q$ together with one fixed
$\Pi^0_1$ sentence $\theta$.  ZFC proves
\[
 \operatorname{Con}(\mathsf Q+\theta)\quad\longleftrightarrow\quad\theta.
\]
For the forward implication by contraposition, $\neg\theta$ is
$\Sigma^0_1$; effective $\Sigma^0_1$ completeness supplies a finite
$\mathsf Q$ proof of $\neg\theta$ from a witness, contradicting the
extra axiom.  For the reverse implication, ZFC's natural-number
structure satisfies $\mathsf Q$ and the fixed true sentence $\theta$;
finite-proof soundness gives consistency.  These are formalizable
arguments for each fixed sentence, not an assertion that every model
of ZFC has externally standard natural numbers.

Taking $\theta=\operatorname{Con}(\mathrm{ZFC})$ therefore gives a
finite arithmetic theory with the desired consistency calibration.
This observation does not yield a small implemented checker: the added
sentence contains the arithmetized ZFC proof predicate.  A complete
machine must still charge its construction and interpretation.  It
illustrates why a short axiom \emph{list}, by itself, can relocate the
original computational task inside one formula without reducing the
complete binary program.  No new numerical state bound is supplied
for this route.

\subsection{What a fair state comparison must include}

A complete blank-tape construction must implement four connected tasks:
recognizing or generating the theory's axiom instances; checking and
exhaustively enumerating finite derivations; decoding the selected
representation while maintaining its work data; and initializing the
literal query, program data, counters, and runtime frame from the blank
tape.  The state count is the number of \emph{distinct} working states
after all those tasks have been combined and shared.  An estimate for
an isolated input writer or equation emitter does not establish that
complete count.

The inspected equational-generator experiment makes the distinction
concrete.  For its different seven-equation input basis, a complete
register-control source has a 299-state binary table and its isolated
emitter has 171 states, before the missing literal ZFC query/writer
and full new-source calibration are supplied.\footnote{
\url{https://github.com/VladimirReshetnikov/ProveIt/blob/13ec39ed43148b1807f51ed6e6528e1c84659562/Computability/BusyBeaver/Research/ZFC/equational_generator_cost.md}.}
Those measurements are not a compilation or a lower bound for E663.
They show why the short equational input still needs a substantially
better complete interpreter architecture before it can improve the
present binary-state result.

The E663 work gives a precise new target for that architectural search.
Its ground-rewrite formulation also has an elementary completeness
argument through the ground-term congruence algebra, so a future checker
can avoid the full machinery of first-order quantifier substitution.
It must still handle arbitrary ground substitutions on both sides of
an equation, contextual replacement, either rewrite direction, and fair
coverage of every finite certificate.  These requirements are the
remaining implementation problem; no smaller measured machine is
claimed for the alternatives in the table.
