Dependency wiring
-----------------
1. The builder starts from the exact pinned K230 table and reconstructs
   the literal edits, source-layout adapters, local folds, callback repair
   and canonical renumbering. The reproducer compares the rebuilt tables
   with the delivered bytes. The separate canonical audit checks every
   transition, the complete bijection, initial state and terminal state.

2. The independent source checker imports neither the source builder nor
   the runtime engine. It proves the four total transfer-plus-one macros
   have the required actual control boundaries, then compares every
   instruction and guarded edge of the final source. This yields the
   whole-program source equivalence for every register map at root entry.
   The actual final source is also reconstructed and compared byte for byte.

3. Sparse initialization reaches the same entire finite tape support for
   baseline and candidate. The independent dense checker executes a fixed
   number of literal transitions and compares the complete support against
   the explicit calibrated frame: head -5, marker -6, header 176, the actual
   nonzero logical seed, and 167 spare blocks of value one. Its representation
   also fixes both infinite exteriors to zero. Canonical renumbering joins
   the two independently checked machine representations.

4. Quick mode validates the input pins, case-array integrity, exhaustive
   zero/positive guard census and positive affine durations of the stored
   runtime receipts. It is explicitly described as integrity validation.
   Full mode additionally invokes the actual universal runtime checker
   without a prefix limit on both pinned K230 and rebuilt K226, validates
   the fresh complete receipts, and compares the fresh case arrays with
   the delivered arrays. Elapsed wall times are intentionally excluded
   from exact comparison. The driver cannot promote a partial receipt.

5. The unchanged runtime rules establish positive finite instruction
   blocks on arbitrary valid frames with independent natural registers
   and an arbitrary finite spare tail. Together with exact initialization,
   the source comparison and the baseline runtime replay, these connect
   the new table directly to the exact published K230 theorem. The guarded
   state140 discovery argument is not an additional assumption of this
   final proof chain.
