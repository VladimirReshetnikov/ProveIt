\subsection{A final contextual state-18 search}

The last bounded lane uses a richer interface than globally assigning both
orientations to an atom. Fine terminal $\mathtt C$ (physical state 18) retains
its unconditional right-entry interface. It may occur directly as a left
child only if the containing word is entered on bit one, giving the safe
suffix $10$. The companion runtime addendum gives the local physical
microtrace proof of this conditional interface.

For a production $w=ab$, the optimizer computes an incoming mask recursively.
A direct left child $a=\mathtt C$ restricts the mask of $w$ to bit one.
Every other left child must itself admit bit zero, and every right child must
admit bit one. Failure of either child condition gives the parent mask zero.
All mandatory roots and route roots must admit both bits. These gates are
checked after dependency closure and before acceptance. An independent
auditor reconstructs the mandatory physical roots and repeats the recursive
calculation; neither checker turns this structural condition into a theorem
about a newly compiled binary table.

The 180-second run uses the fourteen-entry proposal family, 50 retained
bootstrap locks, and RNG seed 181402. It makes 1,848,127 proposals, with
707,975 accepted moves, 3,817 uphill moves, 34 restarts, and seven closure
rejections. It retains 128 grammar rules, maximum zero run six, and depth 46.
The final output contains no conditional $\mathtt C$-left word. Its contextual
structural audit passes; no new literal runtime or bootstrap theorem is
claimed for that output.

There is an exact source-level explanation for the narrow opportunity. Among
the fourteen core required words, only $\mathtt{BDC}$ contains $\mathtt C$.
The retained locks force $\mathtt{BDC}=\mathtt B\cdot\mathtt{DC}$ and
$\mathtt{DC}=\mathtt D\cdot\mathtt C$. None of the twenty-two caller
projection targets contains $\mathtt C$. Under these locks a conditional
$\mathtt C$-left use can therefore help only through unconstrained selector
padding. This is a statement about this explicit family, not a lower bound
on other sources, bootstrap layouts, or machines.
