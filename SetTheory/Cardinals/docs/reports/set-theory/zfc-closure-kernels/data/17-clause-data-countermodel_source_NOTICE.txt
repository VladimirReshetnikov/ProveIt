AUTHORSHIP, SOURCE PROVENANCE, AND LICENSE BOUNDARIES

1. ORIGINAL MACHINE AND VERIFICATION

Mira-Cult designed the 254-state machine, compact proof-search program,
and nonextensional container/collection approach. Jeff (jeff87654) supplies
the public Coq verification in jeff87654/busy-beaver. The numeric 254-state
table and indispensable functional inputs Dag254.v and tools/logic/spec.py
are preserved here for precise scientific identification, criticism and
reproduction of the examined program. No upstream-wide license was found
in the pinned busy-beaver source. This report does not relicense that work.
Only those two small functional source files are included from the proof
package; the larger Coq libraries and proof sources are not redistributed.

Pinned upstream: 297ab8df7e5de329605c3875b4934643b371a5e3
https://github.com/jeff87654/busy-beaver

2. 253-STATE REDUCTION

The 253-state table is the separately published PR20 construction in
mira-emmy/busy-beaver, head 0d544f2a2e3c18f12278441a74b7879f31cbe856.
It changes four rows and reuses a startup state from the original machine.
The report's regenerate_253.py is an independent small implementation
using the published mathematical transition data and explicit bijection.
It is not the upstream proof or a new construction claim.

https://github.com/jeff87654/busy-beaver/pull/20
