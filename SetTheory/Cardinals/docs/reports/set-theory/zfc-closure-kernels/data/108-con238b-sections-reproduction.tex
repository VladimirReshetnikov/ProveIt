\subsection{Commands}

From the extracted package root, the normal full final-table
replay is:
\begin{verbatim}
python3 -B reproduce.py --output replay
\end{verbatim}
It checks construction, exact startup, inherited source
certificate, static Lean source/seed identity, independent
dyadic source/frame identities, local fold, and all final-table
unbounded instruction cases.

To replay the independent predecessor-guard route as well:
\begin{verbatim}
python3 -B reproduce.py --with-guard --output replay-both
\end{verbatim}
This complete two-route replay passed in the preparation
environment in approximately 467 seconds. The final-table
unbounded pass took approximately 183 seconds, and the
predecessor-guard pass approximately 266 seconds. These
are reproducibility observations about this environment,
not asymptotic complexity claims.

For finite construction/source/local/startup checks only:
\begin{verbatim}
python3 -B reproduce.py --quick --output replay-quick
\end{verbatim}
The output directory must be new or empty. The driver
writes fresh receipts there and preserves the delivered
evidence. It checks each subprocess exit code and the
specific JSON success status. A zero exit code alone is
not accepted as proof completion.

The expected final statuses are
\term{FULL\_238\_MATHEMATICAL\_REPLAY\_PASS}
or, for the explicitly abbreviated run,
\term{QUICK\_238\_REPLAY\_PASS}.
The quick status does not claim to have rerun either
unbounded proof.

Build the article from its editable source using:
\begin{verbatim}
mkdir -p build-pdf
pdflatex -halt-on-error -output-directory=build-pdf report.tex
pdflatex -halt-on-error -output-directory=build-pdf report.tex
\end{verbatim}
All section files and the generated table source are
included. The delivered PDF was compiled and visually
inspected.

The two full runtime routes share the attributed affine/list
execution engine. Their independence is therefore qualified:
the local finite-footprint verifier uses a separate symbolic
tape implementation, and the source interval checker uses a
different decoder and rotation representation; the unbounded
list reasoning itself is not duplicated in a second
proof-assistant kernel.

The trust boundary consists of the inspected finite
verification programs, the soundness arguments for their
rules, ordinary arithmetic/list reasoning, and the inherited
logical calibration. The checksums preserve identity rather
than establish mathematical truth by themselves.

\subsection{Suggested incorporation}

The archive can be retained as a new \file{docs/incoming/}
research package. Its full extracted contents can also form
a directory such as
\file{Computability/BusyBeaver/Research/ZFC/candidate-combined238/}.
Preserve its relative structure so that the replay commands
remain portable. The existing 240-state and incoming
239-state artifacts provide provenance and should retain
their original identities.

For a future formal endpoint, the most direct implementation
route is to instantiate the existing binary framework with
the new literal table, exact startup, source tree, and
coverage certificate. The alternative is to formalize
Theorem~\ref{thm:fold} and its next-one guard, then compose
with a checked Boundary239 endpoint. Neither route requires
redesigning the set-theoretic calibration.
