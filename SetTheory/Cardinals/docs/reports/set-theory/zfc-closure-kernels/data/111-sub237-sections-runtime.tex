\section{Why the complete runtime replay is unbounded}
\label{sec:runtime}

The fresh proof closes 8,386 guarded interfaces, not 8,386 small
numerical examples.  All nine register values are independent
natural variables.  A decrement case distinguishes zero from
one plus an arbitrary natural.  The gap, first spare value, and
entire finite spare tail also remain arbitrary.  The endpoint
comparison includes tape exterior, all register blocks and spares,
control, orientation, and physical head displacement.

The inspected engine uses three rules.  A literal transition consumes
one certainly present cell; an unknown natural run length cannot
supply it without a positive constant part.  A homogeneous-run
shortcut is allowed only for an exact table self-loop moving in
the scan direction.  Induction on run length, including zero,
proves its writes, motion, and clock.  An opaque finite spare-list
traversal is allowed only after rederiving the one-block schema on
the exact table.  Its arbitrary-value contract preserves control
and direction and costs $v+2$ steps; structural induction on the
finite list proves the traversal rule.

Tape normalization joins adjacent homogeneous runs, removes
zero-length runs and absorbs finite zero runs in an infinite zero
exterior.  It also uses the direct identity
$C(A)1=1B(A)$ and its reversal for lists of blocks, where
$B(v)=0\,1^{v+1}$ and $C(v)=1\,0\,1^v$.
The underlying one-block identity and its list induction do not
depend on bounded register values.  Every nonhalting instruction
must end at the exact symbolic frame with a clock whose coefficients
are nonnegative and whose constant is positive.  Every halting
instruction must reach literal halt state 254.  The per-case
4,000-rule cap bounds discovery of a proof expression, not machine
time or its input naturals.  This explains the mathematical content
behind the reproducible runtime receipt~\cite{parent237}.

The fresh complete proof uses 2,261,369 symbolic rules, exercises
all 474 rows and has minimum certified instruction duration 13.
Every deterministic proof field and all case-array bytes match
the parent evidence.  The separate finite startup audit reaches
inherited dispatcher 96 after 409,835 transitions, at head $-5$,
with marker $-6$, header 176, 351 one-cells, register seed
\[
                 (3,0,0,0,3,0,0,0,0),
\]
and 167 spare blocks all of value 1.  Every other cell is zero.
The new 237-state exceptional rows are not visited during this
startup, so its clock agrees with the 238-state intermediate.
Startup is an exact finite computation establishing the entry
frame; the instruction contracts then cover the unbounded run.

\file{CalibratedRotation240.halts_iff_zfc_refutation} theorem with

The claim of ZFC formalizability rests on that mathematical
content, not on a general inference that every external Lean
theorem is provable in ZFC.  The ancestor logical dependency
closure is cited rather than rebuilt here.  This report supplies
no new kernel-checked 237-state endpoint and no serialized
object-level ZFC or PA derivation.  With the inherited ordinary
calibration retained, the exact table still has the requested
ZFC biconditional at 237 states.

The biconditional itself has no consistency assumption.
Assuming $\Con(\mathrm{ZFC})$ gives nonhalting; the usual second
incompleteness hypotheses then prevent a ZFC proof of that
nonhalting.  Bare consistency does not additionally exclude a
ZFC proof of halting.  That stronger, two-sided independence
claim requires suitable arithmetic soundness.
