Runtime search code and provenance
=================================

The finite tape simulator structures in shared_row_superopt.cpp and
coupled_tail_superopt.cpp are adapted from the attributed ProveIt
check_literal_cases.cpp and earlier incoming merge_search.cpp implementation.
The candidate families, coupled synthesis, lazy synthesis, and local fixture
generator were written for this research turn. The original simulator license
and project attribution must accompany any redistributed research package.

The exact baseline old-label table is the previously supplied routing245 table:
SHA-256 f8dbeacdad5fd89c57e3f240781324b09110be8e0ccdb838a9c710fb28d2a267.
The full literal fixture SHA-256 is
71fd6d7d0460c3f920ba945c04f2e3a1b571ce070e445ae019417ff0d675abc1.

whole_frame_dynamic.py and audit_frame_dynamic.py are unchanged copies from
the incoming zfc-below245-source-search-20261018 package. Their exact source
paths and hashes are recorded in validation-driver-provenance.json. The new
validate_emitted.py file only orchestrates them and records commands/results.

No search result in this directory is a proof-assistant kernel endpoint, and
no bounded rejection in these experiments is a state-minimality claim.
