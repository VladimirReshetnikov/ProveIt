This is a research contribution prepared for Vladimir Reshetnikov and ProveIt.
It does not claim a verified Turing machine with fewer than 245 working states.

The file vendor/zfc245-proof-20261018.zip is redistributed byte-for-byte from
the pinned ProveIt incoming archive. Its NOTICE.txt, PROVENANCE.json, licenses,
original sources, and earlier contributions remain authoritative for those
materials. Extracting it is part of the offline reproduction procedure.

Attribution is retained for Mira-Cult's compact set theory and machine work,
Jeff Ketchersid's and the upstream contributors' Rocq development, Andrew James
Wade's compiler, and Vladimir Reshetnikov's and the ProveIt contributors'
formalization, reductions, and earlier research packages. The exact source
URLs, inspected revisions, archive hashes, and the scope of new work are in
PROVENANCE.json.

New search code derived from prior searchers and new verification code adapted
from prior checkers keep that provenance in their source headers and local
README files. research/theory/notices and research/framework/licenses retain
the upstream license texts for copied backend and source components. No new
license is asserted over a third party's work.

The pseudo-hereditarily-small model construction is attributed to the folklore
result presented by Greg Oman, On the axiom of union, Archive for Mathematical
Logic 49 (2010), 283-289, DOI 10.1007/s00153-009-0163-1. The new report gives a
self-contained direct application to the precise CP-minus-transitivity
theory with generalized image collection. The construction itself is not
claimed as new.

All raw compiler controls and rejected 244-state tables are explicitly marked
as experiments. Counts of source DAG nodes, grammar productions, raw emitted
states, and completely checked working states are different quantities.

No GitHub repository, branch, pull request, or external formal endpoint was
modified by preparing this archive.
