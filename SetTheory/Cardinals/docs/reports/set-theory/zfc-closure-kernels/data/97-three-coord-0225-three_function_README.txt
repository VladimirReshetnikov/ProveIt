THREE-FUNCTION SELECTIVE-EQUALITY PRESENTATION
============================================

Status
------
Ordinary mathematical upper-model construction and exact finite payload.
This package does not contain a new binary Turing machine or establish a
state count below 245.  The 999-bit number is a serialized clause payload.
The consistency calibration inherits exactly the native FC15/FC16 upper
models and selective-equality/EPSC lower results documented by the parent
report.  It is not a new proof of those inherited calibration theorems.

Main result
-----------
One constant d, three proper functions V:2, C:3, A:2, four ordinary binary
predicates E, Inc, G, Eq, at most four local variables per clause.

                                     clauses  literals  nodes  flat bits
SE19, two explicit constants             19        45     240      1155
SE19, one constant q := A(d,d)           19        45     268       999
SE20 extensional, two constants          20        49     284      1346
SE20 extensional, one constant           20        49     324      1182

The one-constant variants use eight term tokens: four variables, d, V, C,
A.  Each term node therefore costs exactly three flat bits.  The named
two-constant controls require four bits per term node.  All occurrences
of derived operations and composite markers are expanded in the payload.

Reproduction (Python standard library only)
------------------------------------------
Run from this directory, or supply the absolute path to the script:

  python3 three_function_sharing.py
  python3 three_function_sharing.py --output /tmp/three_function_check
  python3 three_function_sharing.py --stage 0
  python3 three_function_sharing.py --stage 1
  python3 three_function_sharing.py --stage 1 --extensional

The default command emits all four payloads and repeats all recorded codec,
substitution, and finite-stage controls.  It completes without network or
third-party packages.  Ground/refuter commands use the one-constant theory.

  python3 three_function_sharing.py --whole-search
  python3 three_function_sharing.py --whole-search --extensional

The last two commands intentionally run indefinitely unless they find a
finite refutation; their cost grows quickly.  They print each completed
stage and stop only at UNSAT.  Resource errors are errors, not refutations.

Ground codec and fairness
------------------------
Code(d)=0.  For positive codes use

  Code(f(children)) = 1 + tag(f) + 4*tuple_code(children),

where tags V,C,A,padding are 0,1,2,3.  The padding constructor is unary and
has no occurrences in the theory's clauses; adding it to the ground
enumeration language is a conservative extension.  tuple_code uses a
right-nested Cantor pairing, with a unary tuple encoded by its entry.
Decoding gives a bijection N -> padded ground terms, and every child code
is strictly below its parent.  Thus enumeration over 0..n eventually
covers every finite ground instance, including variable collisions.
Endpoints generated by substitution are retained even if their codes
exceed n.  Equality remains an ordinary propositional predicate.

By Herbrand's theorem and propositional compactness, the finite-stage
search halts if and only if the universal equality-free theory is
inconsistent.  This is a reference semidecision procedure, not a compact
binary-machine implementation.

Product construction
--------------------
Raw carrier M^3.  Eq/E use coordinate 0, Inc/G use the assignment/object
coordinate 0 and class coordinate 1.  C's first coordinate is native
update, its second implements NAND or quantification according to two
distinct raw argument markers, and its third injectively records all
nine coordinates of its three raw inputs.  The C image avoids d and q.
A's second coordinate always supplies the native atomic class; its first
coordinate decodes a unique raw C preimage and dispatches to hull,
support, existential-witness, or unboundedness-witness functions using
four pairwise distinct raw marker arguments.  Its default first coordinate
and fixed third coordinate ensure that A(d,d) is exactly the prescribed
raw q.  V retains native lookup in coordinate 0.  This satisfies all
nineteen clauses with exactly their stated selective equality transport.

No raw decoder, pairing operator, identity test, class sort, or additional
function is an extra symbol or axiom in the finite presentation.  These
are only ingredients of the upper model construction.
