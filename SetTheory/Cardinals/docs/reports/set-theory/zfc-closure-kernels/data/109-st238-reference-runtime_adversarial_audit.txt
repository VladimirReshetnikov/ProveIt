1. Affine runs, including zero lengths
=====================================
Every represented run length is a 13-component affine expression. The
normalizer requires all coefficients to be nonnegative. The nine primary
register parameters, additional gap, first spare value, and actual spare-tail
width therefore range over nonnegative integers without bounded testing.
For a positive decrement the selected value is 1+x; for a zero decrement it
is exactly zero. These two forms exhaust the possible inputs.

A possibly empty run can be traversed in one symbolic operation only when
the literal transition is a self-loop moving in the current scan direction.
For length zero this rule denotes zero literal steps and preserves control,
head, and tape. For length n>0 it is justified by n repeated applications of
that same transition. No guessed bit is read in the zero-length case.
Every other literal transition requires a positive constant term, so the
symbolic head is known to scan a real cell for every parameter assignment.
Subtracting one then preserves nonnegativity. This avoids the usual bug of
executing a transition on an atom that may denote an empty word.

The scan rule may write a different bit; moving a block of the written bit
to the other side of the zipper is the exact effect of the repeated row.
Clock and motion are increased by the run length with the correct sign.

2. Zipper orientation and the whole tape
======================================
The left and right sequences are stored nearest-boundary first. In direction
+1 the head is the first cell on the right; in direction -1 it is the first
cell on the left. A move continuing in the current direction transfers the
written cell to the opposite sequence. A reversal restores the written cell
to the same sequence and switches which side contains the head. This yields
exactly a one-cell move in either case. The representation does not silently
move the head twice or omit the just-written cell at a reversal.

Normalizing adjacent equal-bit runs, removing an identically empty run, and
absorbing finite zeroes into an adjacent infinite zero exterior all preserve
the represented tape. Opaque contexts in the one-block lemmas cannot be
read: attempting to reach one produces an error. The lemmas therefore do
not assume any value for exterior cells. Equality of final symbolic keys is
sufficient for equality of the entire represented relative tape, not merely
selected register values. The independently accumulated head-motion equation
then fixes the absolute translation of that relative tape.

3. Arbitrary finite spare lists and the empty-tail case
=====================================================
The four list rules are derived from literal one-block computations on the
current exact table. Each returns to the same control state and orientation,
uses no outside cell, preserves the block value, and takes exactly v+2 steps.
Induction on a finite list therefore gives the corresponding whole-list
scan. The empty list takes zero steps and is included. The first spare is
represented separately, so the entire spare suffix is nonempty while the
remaining abstract list may be empty.

Slot 12 must be interpreted as the actual encoded width
W(A)=sum_{v in A}(v+2) of the one fixed spare-tail list A. It is not a second
independent tape sequence. Both encodings B(v)=0 1^(v+1) and C(v)=1 0 1^v
have width v+2, so all list conversions preserve W(A). Treating the width as
an algebraic variable is sound: polynomial identities proved for all values
remain true after substituting this actual width. The implementation uses
one named abstract tail throughout; no two unrelated list widths are equated.

The normalizer's C(A)1=1B(A) rule follows from C(v)1=1B(v) by list induction.
The latter identity reduces to ordinary adjacent-run combination and does
not invoke the abstract-list identity. Its reversal is the exact reversed
word identity. The implementation's direction/reversal flag changes agree
with these two orientations. The empty-list identity is also valid.

4. Endpoints, halting, progress, and frame closure
================================================
For a nonhalting instruction, acceptance requires exact equality with the
intended full target frame and accumulated motion -overflow. The target's
padding is increased by delta+overflow, where delta is one precisely for a
positive decrement. Hence the new padding remains nonnegative. An increment
appends one auxiliary spare of value one; all previous spare values and their
order are preserved. No instruction empties the spare suffix. These facts
close the representation invariant for arbitrarily many source instructions.

A nonhalt case cannot accept reaching halt254: its target control is 96.
The next attempted row at254 would fail. A literal halt case deliberately
accepts on reaching254 without requiring a specific output tape or head;
that is sufficient for the claimed halting predicate. Neither unary
acceleration nor list acceleration can hide an unobserved intermediate halt:
unary control is unchanged, and each list block was literally derived and
returns to its working-state entry.

Individual empty scans may take zero steps, but every accepted instruction
segment has a nonnegative affine duration with strictly positive constant
term. The smallest current constant is13. Consequently infinitely many
source steps give infinitely many actual binary steps. The symbolic loop
caps50 and4000 bound proof search only; a failed closure is rejected. They
do not impose a bound on natural register values, tape lengths, or actual
runtime. Symbolic proof-operation counts must not be described as total
running times of the machine's proof search.

5. Source pointers and the actual initial seed
=============================================
The independent source checker pins both lists, checks complete ordered
prefix partitions, and compares all labels and guarded successor indices.
Its extra equality-to-left-endpoint check proves that every generated
successor pointer agrees with its decoded leaf after infinite zero padding.
This closes the binary runtime interface; matching instruction indices alone
would not suffice if discarded suffix bits could be nonzero. Fixed-width
overflow and the empty pointer are checked under the same convention.

RegisterPath consumes precisely the leaf depth before executing the
instruction, so the source projection to (leaf index, entire register
function) is exact. Both source decoders have ample fuel and finite complete
trees; an exhausted decoder is never confused with the literal halt leaf.
