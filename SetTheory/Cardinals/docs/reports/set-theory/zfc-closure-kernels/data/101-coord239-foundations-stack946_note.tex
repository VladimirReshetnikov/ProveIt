\begin{abstract}
The inspected ProveIt Source 79 finite environment-stack kernel has a
1,169-bit complete equational encoding. We identify its class NAND
constructor with its native stack-cons function. We then apply the earlier
false-class witness-slice technique as $\mathsf{Pick}(x)=W(x,d)$, and the
previously reviewed truth fusion $\mathsf{top}=d$. The resulting complete
packet has 946 bits: 14 equations, 215 term nodes, 13 operation symbols and
three local variables, permitting four-bit opcodes. We give the explicit
countable upper model needed to justify these specializations and the
reverse term interpretation. The ordinary consistency calibration depends
on the existing raw-EPSC/ZFC comparison. This is a concrete frontend and
payload improvement; no smaller binary Turing machine or proof-assistant
endpoint is supplied by this note.
\end{abstract}

\section{Sources, attribution and the exact claim}

The inspected ProveIt commit is
\texttt{13ec39ed43148b1807f51ed6e6528e1c84659562}.
Source 79 supplies the native stack, its same-carrier Boolean conversion,
the 1,169-bit packet and its longer alternative member-selector
term~\cite{stack79}. Source 40 already uses the general technique of
storing functions in an unconstrained existential-witness slice at a false
class~\cite{kernel40}. Truth-constant fusion is earlier work, recorded in
the Source 78 and Source 79 reviews~\cite{review79}.

The new concrete specialization in this note is $J=P$, followed by the
particular composition $\mathsf{Pick}(x)=W(x,d)$ and
$\mathsf{top}=d$ in that stack kernel. We claim the exhibited encoding
improvement relative to the inspected sources, not global historical
priority for a general operation-sharing principle. All inherited machine,
calculus, compiler and formalization attribution is unchanged.

Write $\mathcal E_{946}$ for the literal 14-equation packet accompanying
this note, and write $s=N(d,d)$ and $t=d$ for its ground endpoints. The
mathematical claim is the ordinary ZFC-formalizable equivalence
\[
 \mathcal E_{946}\not\vdash s=t\quad\longleftrightarrow\quad
 \Con(\mathrm{ZFC}),
\]
using the stated inherited raw-EPSC calibration. A fair ground rewrite
search for $s=t$ would therefore have the required halting calibration.
Its binary implementation, blank initialization and state cost are still
required before this supplies a Turing-machine bound.

\section{The inherited closure theory and native stack}

For an ordinary binary relation $E$ and an equality-free formula
$R(x,y)$ in the language containing only $E$, with any finite tuple of
parameters, define
\[
 \Empty(x)\equiv\forall u\,\neg E(u,x),\qquad
 y\subseteq_E z\equiv\forall u\,(E(u,y)\to E(u,z)),
\]
\[
 \LB(R)\equiv\forall x\,\exists z\,\forall y\,
               (R(x,y)\to y\subseteq_E z).
\]
The raw empty-seed positive subset closure schema (EPSC) says that
$\LB(R)$ implies the existence of $h$ such that
\begin{align}
 &\forall x,y\;(((\Empty(x)\lor E(x,h))\land R(x,y))\to E(y,h)),\label{epsc-close}\\
 &\forall y\;(E(y,h)\to\exists x\,R(x,y)).\label{epsc-support}
\end{align}
Schema matrices are equality-free pure-membership formulas, with arbitrary
finite parameters. Ordinary first-order reasoning is used; native equality
remains available in the stack equations below. Sources 14 and 08 supply
its ordinary consistency
comparison with ZFC; this note imports that result explicitly~\cite{epsc14}.

The stack kernel has one constant $d$, native binary functions $P,V,A$,
class constructors $J,Q$, predicates $E,\eps$, and the native equations
\begin{align}
 V(P(x,s),d)&=x,\label{head}\\
 V(P(x,s),A(j,d))&=V(s,j).\label{tail}
\end{align}
The selectors $\nu_0=d$, $\nu_{i+1}=A(\nu_i,d)$ are generated by finite
terms. Equations~\eqref{head}--\eqref{tail} recover every finite stream
coordinate by a finite sequence of ordinary equality substitutions.

Its class semantics is
\begin{align}
 \eps(s,J(a,b))&\leftrightarrow\neg(\eps(s,a)\land\eps(s,b)),\label{class-nand}\\
 \eps(s,A(i,j))&\leftrightarrow E(V(s,i),V(s,j)),\label{class-atom}\\
 \eps(s,Q(a))&\leftrightarrow\exists z\,\eps(P(z,s),a).\label{class-exists}
\end{align}
After Skolemization, the last line becomes an equality of predicate values
at the chosen witness $W(s,a)$ together with the arbitrary-candidate
implication. No class axiom is required for $d$.

For a descriptor $b$, the closure matrix is
\[
 R_b(x,y)=\eps(P(y,P(x,b)),V(b,d)).
\]
The code slot is 2, the output slot is 0, the input slot is 1, and parameters
occupy slots 3 and above. De Bruijn binding uses a prepended stream cell.
Hence every fixed pure-$E$ formula with finite parameters is represented
by a closed class term constructed before its descriptor. No circular code
equation or full truth predicate for the expanded language is assumed.

The six universal closure clauses use a Boolean branch flag $G(b)$,
$h=\mathsf{Target}(b)$, $n_z=\mathsf{Next}(b,z)$ and
$m_z=\mathsf{Mem}(b,z)$:
\begin{align*}
 &G(b)\lor R_b(h,n_z),\\
 &G(b)\lor E(m_z,n_z),\\
 &G(b)\lor\neg E(m_z,z),\\
 &\neg G(b)\lor E(\mathsf{Pick}(x),x)\lor\neg R_b(x,y)\lor E(y,h),\\
 &\neg G(b)\lor\neg E(x,h)\lor\neg R_b(x,y)\lor E(y,h),\\
 &\neg G(b)\lor\neg E(y,h)\lor R_b(\mathsf{Next}(b,y),y).
\end{align*}
If local boundedness holds, the first three clauses force the hull branch;
the last three then give~\eqref{epsc-close}--\eqref{epsc-support}. Empty
objects have no value satisfying the member literal. Conversely a member
choice $\mathsf{Pick}$ makes the empty-seed clause impose no extra condition
at nonempty inputs. The bad-input and supported-hull branches share their
witness functions only because their obligations are exclusive.

\section{The specializations}

The shortest new packet applies
\[
             J(a,b)=P(a,b),\qquad
             \mathsf{Pick}(x)=W(x,d),\qquad
             \mathsf{top}=d.                     \tag{S}
\]
These are substitutions in the complete equations, not uncharged macro
abbreviations. The resultant theory may have fewer models than the original
presentation. The upper construction below is therefore essential: a
syntactic identification of operation names alone does not prove
equiconsistency.

\begin{lemma}[Immediate lower interpretation]
Every nontrivial $\mathcal E_{946}$-model expands by the definitions (S)
to a nontrivial model of Source 79's original equational kernel.
\end{lemma}
\begin{proof}
Every original equation becomes exactly its supplied transformed equation.
The native equations~\eqref{head}--\eqref{tail} retain their entire
universal ranges. The new truth equation is
$d=N(d,N(d,d))$, so the Boolean basis makes $d$ the Boolean top. The
original ground endpoints become $N(d,d)$ and $d$ exactly. No quotient of
the native stack functions is taken.
\end{proof}

\section{A countable upper model for the shared constructor}

Assume $\Con(\mathrm{ZFC})$ in ordinary ZFC. First-order completeness
and downward L\"owenheim--Skolem give a countably infinite set-coded model
of ZFC. Relabel its carrier by the external natural numbers, retaining its
membership relation $E$. This model need not be transitive or
$\omega$-standard.

Let $\pi$ be a Cantor pairing bijection with
$\pi(i,j)\geq\max(i,j)$. Choose the structural operations
\[
 d=0,\qquad P(x,s)=3\pi(x,s)+1,\qquad
 A(i,j)=3\pi(i,j)+2,\qquad Q(a)=3a+3.
\]
Their positive ranges are disjoint, and each value strictly exceeds its
arguments. A $P$-code is a stream cell. Every non-$P$ stream has head and
tail 0. Define $\operatorname{idx}(i)$ as the number of successive outer
layers $A(j,0)$, ending with 0 when the selector has any other shape.
Set $V(s,i)$ to stream coordinate $\operatorname{idx}(i)$ of $s$.
Both native equations now hold for all carrier elements, including all
noncanonical selectors.

Define every carrier element as a class by structural recursion:
\begin{itemize}
 \item class $d=0$ is always false;
 \item a $P(a,b)$-code is the NAND of the classes $a,b$;
 \item an $A(i,j)$-code is membership between the indicated stream coordinates;
 \item a $Q(a)$-code existentially binds a prepended coordinate.
\end{itemize}
The strict decrease of constructor arguments proves termination. This is
where the new sharing occurs: a $P$-code denotes a stream when used by $V$
and a NAND class when used by $\eps$. These are different operations with
compatible specifications. There is no rule requiring a $P$-class to be
false, and no existing native equation constrains its class interpretation.

Induction on class code shows that every fixed class is a finite pure-$E$
formula in finitely many stream coordinates. For fixed $b$, its descriptor
relation is therefore a pure-$E$ relation in $x,y$ with finitely many
parameters determined by $b$. The chosen ZFC model satisfies the relevant
EPSC instance. Applying it separately to every descriptor supplies the
closure branch and the $\mathsf{Target},\mathsf{Next},\mathsf{Mem},G$
interpretations, just as in Source 79. This does not require the global
external class decoder to be internally definable in that ZFC model.

\section{Allocating the false-class witness slice}

The class incidence just defined is independent of $W$. For $a\ne d$,
choose $W(s,a)$ as the least external-index witness whenever
$\exists z\,\eps(P(z,s),a)$, and 0 otherwise. At $a=d$, both sides of
the chosen-witness equation are false regardless of $W(s,d)$:
\[
 \eps(s,Q(d))=\text{false}
       =\eps(P(W(s,d),s),d).
\]
The arbitrary-candidate implication also has false antecedent at $d$.
Thus the entire function slice $s\mapsto W(s,d)$ is unconstrained by
the existential specification.

Use that slice as a member selector:
\[
 W(x,d)=
 \begin{cases}
  \min\{u:E(u,x)\},&\text{if $x$ has a member},\\
  0,&\text{otherwise}.
 \end{cases}
\]
It is total on the countable carrier and meets exactly the condition used
to realize the empty-seed closure clause. No new requirement on $E$ or
on the hull is added. In particular, this is shorter than representing
the member-selection problem as a nontrivial class term. The specific
false interpretation of $d$ is needed only in this upper construction;
it is not claimed as a theorem of the new equational presentation.

Finally equip this same countably infinite carrier with a transported
countably infinite Boolean algebra whose top is the existing element $d$.
Interpret the Sheffer operation $N$ as Boolean NAND and predicate-valued
functions by that algebra's top or bottom. Keep $P,V,A,Q,W$ and all closure
functions on the same carrier unchanged. The equations hold, the native
stack equations remain true, and $N(d,d)\ne d$.

\begin{theorem}[Ordinary calibration of the 946-bit packet]
Subject to the inherited raw-EPSC/ZFC calibration,
ordinary ZFC proves that $\mathcal E_{946}$ has a model separating
$N(d,d)$ and $d$ if and only if $\Con(\mathrm{ZFC})$.
\end{theorem}
\begin{proof}
The construction proves the upper implication from $\Con(\mathrm{ZFC})$.
For the other direction, the lower interpretation gives the original
Source 79 kernel. More explicitly, Sh1~\cite{sh1} makes the nontrivial
carrier a Boolean algebra. An ultrafilter is applied to predicate values
only. Its map to two truth values preserves all propositional equations,
and the native functions remain on their original carrier. The resulting
ordinary structure satisfies the displayed universal clauses. Selector and
formula representation recover every raw-EPSC instance, and the inherited
calibration gives $\Con(\mathrm{ZFC})$.
\end{proof}

The theorem is a model-theoretic proof in the ZFC metatheory. The supplied
Python checks do not verify it in a proof assistant. Nor does this establish
an internal PA proof-code equivalence.

\section{A second allocation and one incompatible shortcut}

One can instead use the same unconstrained slice to represent the unary
quantifier constructor:
\[
                  Q(a)=W(a,d).
\]
In the upper model reserve $W(a,d)=3a+3$, the increasing quantifier code,
and retain an independent $\mathsf{Pick}$. The same structural recursion
and false-class argument work, and the reverse is again a literal term
interpretation. This packet has 950 bits.

These slice allocations are alternatives. The argument does not permit
one to impose both $\mathsf{Pick}(x)=W(x,d)$ and $Q(x)=W(x,d)$: it would
identify a prescribed structural quantifier code with a member of every
nonempty $x$, a compatibility condition not established here.

Likewise the Boolean operation $N$ must not be identified with $P$. Boolean
NAND is commutative; if $P$ were commutative, the head equation applied to
$P(x,s)=P(s,x)$ would force $x=s$ for all elements and collapse the carrier.
Sharing $J$ with $P$ does not assert commutativity of $P$: only the predicate
value $\eps(s,P(a,b))$ has the symmetric NAND interpretation.

\section{Exact encoding and executable evidence}

The existing codec has an 8-bit symbol count, three arity bits per symbol,
an 8-bit variable capacity, a one-bit marker per equation and a terminating
zero marker, and two ground endpoint terms. Local variables and operation
symbols share one fixed-width opcode space. Every term is an arity-delimited
prefix tree; no helper definitions are omitted.

\begin{center}
\begin{tabular}{lrrrr}
\toprule
Variant & Symbols & Nodes & Opcode bits & Complete bits\\
\midrule
Source 79, explicit Pick &16&214&5&1169\\
Earlier truth fusion only &15&214&5&1166\\
$J=P$, truth fusion &14&214&5&1163\\
Long derived Pick, $J=P$, truth fusion &13&221&4&970\\
$Q(a)=W(a,d)$, $J=P$, truth fusion &13&216&4&950\\
$\mathsf{Pick}(x)=W(x,d)$, $J=P$, truth fusion &13&215&4&\textbf{946}\\
\bottomrule
\end{tabular}
\end{center}

Every row has 14 equations and at most three local variables. For the
preferred packet the complete count is
\[
 \underbrace{8+3\cdot13+8}_{55\text{ header}}
 +\underbrace{14+1+4\cdot215}_{875\text{ equations}}
 +\underbrace{4\cdot4}_{16\text{ endpoints}}=946.
\]
The improvement over the original packet is 223 bits, about 19.08\%.
The exact bit-character hash excludes the terminating file newline and is
recorded in the JSON receipt and companion README.

This is an improvement within the complete equational packet family, not a
global minimum across all encodings. Earlier complete equational packets
include 2,324 bits (Source 70), 2,194 (Source 77), 1,768 (Source 78), and
1,750 (the joint 77/78 construction)~\cite{earlier}. Source 42 already has
a smaller numerical count of 901 bits for a complete \emph{native clause}
packet, with a different equality and inference interface. Completing
equality for that same variant gives 1,998 bits. A different Source 42
variant has 917 native bits and 1,703 equality-completed bits; the preferred
variant therefore depends on the inference interface~\cite{clause42}.
Source 44 reports
an 881-bit native clause \emph{template}, whose function signature and
arities are supplied externally to its codec~\cite{template44}. These
boundaries differ. The broader comparison table is in the companion review.

The executable builder regenerates all ten comparison variants. Each
passes 72 Boolean truth assignments, exact term/arity reconstruction by
two structurally different parsers, every strict-prefix truncation and
malformed/trailing-input controls. Source 79's original 2,080 selector and
16,384 formula regressions are rerun. A separate companion exercises the
modified shared-constructor formula interpretation and the spare-witness
slice. Those are transcription and bounded semantic regressions, not
finite models of EPSC and not tests of consistency.

\section{What this alternative interpreter still needs}

A complete binary implementation must enumerate finite ground substitutions,
respect repeated occurrences of each equation variable, locate arbitrary
one-hole term contexts, allow both rewrite orientations and search fairly.
All finite ground rewrite traces can be enumerated; their soundness is
equational substitution, and their completeness follows from the ground-term
congruence quotient. Those ordinary facts identify the correct specification.
They do not charge the parser, copying/comparison routines, storage, control
flow or blank-tape initializer.

The companion \texttt{ground\_rewrite.py} implements this abstract
specification by enumerating all finite binary certificates: for positive
$n$, remove the leading 1 from its binary expansion. Each certificate
specifies a finite trace, and each step gives an equation, its orientation,
a child-index path, and ground values for the union of the variables on
\emph{both} equation sides. Union is essential. For example, reversing
\eqref{head} rewrites $x$ to $V(P(x,s),d)$ and must introduce a freely
chosen ground value for $s$. Reversed Sh1 likewise introduces variables
absent from the matched side. Repeated occurrences share the same chosen
value. An invalid field, path or source match rejects that certificate.

Every finite trace has a finite certificate and every finite certificate
can be checked in finite abstract time. Term parsing, substitution,
comparison and context reconstruction use explicit stacks, without a fixed
input-depth bound. These facts prove fairness and termination of each
individual certificate check for the abstract algorithm. The accompanying
fixtures cover contextual forward and reverse rewrites, repeated and
one-sided variables, malformed/truncated certificates, and 2,500-deep ground
terms. The actual-packet search was only bounded to 65,536 certificate
strings and found no derivation; that finite exhaustion is inconclusive.

The measured saving cannot be subtracted from a Turing-machine state count.
Its practical value is a substantially shorter fully specified input for a
new interpreter, with a consistency argument that respects native equality
and avoids the known missing-substitution countermodels. The 239-state
binary result in the accompanying main report uses a separate transformation
of the inherited calibrated machine. Its state count does not follow from
this packet reduction.
