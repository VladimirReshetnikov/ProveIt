# Supplemental search records

These records document bounded unsuccessful alternatives and search controls.
They are not premises of the successful 223-state machine and do not prove
minimality. Some source-only variants never reached valid machine allocation.
Interrupted conditional-machine searches are distinguished from completed scopes.
The source reports retain development-relative artifact locators for provenance;
only the primary portable packet has a full aggregate replay entrypoint.

The helper_screens folder includes standalone C++17 screen implementations,
exact original K224 table, discovery domains, completed logs and controls. For
example, from helper_screens:

    g++ -O3 -std=c++17 two_helpers.cpp -o /tmp/two_helpers
    /tmp/two_helpers input224.legacy.tm 5 5 65 65 neutral_precise.txt precise_seed_r5.txt
    g++ -O3 -std=c++17 halting_folds.cpp -o /tmp/halting_folds
    /tmp/halting_folds input224.legacy.tm 6 257 precise_seed_r6.txt

The supplied domains are fixed discovery fixtures. Their source projection is
not offered as an independent correctness proof for an arbitrary edited table.
Any surviving candidate would still need full source/runtime/startup validation.
The completed screens found none. The actual 223 construction came from
conditional-K helper allocation, not these local screen families.
