# The joint 1,750-bit packet: proof and evidence boundaries

This is a subsequent combination of Source 77's selector dispatch and Source 78's detour encoding, developed during batch 169. The exact [ordinary proof proposal](data/intake169-joint-proof-proposal.md), [builder source proposal](data/intake169-joint-source-proposal.json) and [independent source review](data/intake169-joint-builder-source-review.json) are retained unchanged. Their statements that execution was pending describe their earlier freeze point. Root has since run the proposed builder on copied inputs; the [actual record](data/intake169-joint-verification.json) and [independent output review](data/intake169-joint-actual-review.json) are separate later evidence.

The proof first defines membership using two class updates and incidence. It then replaces V, A, U and F with H at four fixed actual selectors. Only object-coordinate congruence is required: equality-equivalent selectors must never be silently interchanged. The removed membership congruence follows from C congruence, reflexivity of the identical ground term `H(tag_A,d,o)`, and incidence congruence. C and H coordinate splitting is justified in both directions using the retained equality axioms. Boolean truth fusion applies to this equality-free universal clause presentation; the optional ground alias is a conservative definition charged in the packet.

The fresh result is 1,750 bits with alias/split congruences, versus 1,768 without alias. Both use four-bit opcodes. The shorter packet counts its 52-bit signature/capacity header, 1,682-bit equation payload and 16-bit ground endpoints. It has 21 equations and 415 both-side term nodes. The no-alias version counts 49 + 1,703 + 16 bits, with 18 equations and 421 nodes. These are complete packet sizes under this codec, not just a formula payload.

The builder binds exact transformed clauses to the 12 Horn certificates, checks 49 finite inferences and 94 Boolean assignments per variant, verifies arities and full codec roundtrips, rejects every strict truncation and three malformed/trailing inputs, and exercises both directions of every equation in contexts. Opening independently reconstructed the serialized output and reviewed root's terminal execution and unchanged inputs. The builder author and Horn-helper author are identified in the respective reviews; this is not an independently reimplemented full semantic solver.

The model transformations, inherited FC13B consistency calibration, Sheffer basis and ground-term completeness supply the ordinary semantic argument. Finite certificate and serialization checks do not prove those metatheorems. Neither packet supplies an implementation of a binary fair proof search, a reduced Turing-machine state count or an internal PA equivalence. The separate native-stack construction of Source 79 requires a same-carrier model argument and is not silently included in this joint proof.
