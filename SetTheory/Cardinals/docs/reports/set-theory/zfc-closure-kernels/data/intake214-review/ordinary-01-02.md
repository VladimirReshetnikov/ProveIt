## 02: Direct seeds and shared normalization

The direct-full-seed idea is explicitly credited to Source186; it is not a new independent discovery in this delivery. The new refinements are a seed-only named theory `SeedAx f := exists psi, f = B_psi` and a proposed combined freshness bound `Free i f -> i < enc (th f)`. Both can simplify the direct route without changing the numerical calculus. The current completeness theorem (`KEind222.lean:305`) accepts any named predicate, demands derivability of interpreted codes, and gives the continuation semantics of the original named formulas. Therefore the seed-only specialization is mathematically sound in principle, and does not assume semantic equivalence of a formula and its equality interpretation on an arbitrary model.

The counterexample separating literal equality from membership indiscernibility is valid: take two distinct elements and empty membership. Their equality translation is true but literal equality is false. This structure is not asserted to model the seed theory. The proposal correctly retains irreflexivity and an explicit valuation/nonempty-domain witness; the final witness changes from `KIndisc222.mk mem (e0)` to `e0` only after a direct full seed on the original domain is proved. Current endpoint calls (`KEndpoint.lean:39–40`) and `KIndisc222.fullSeed_of_derivable` (`:145`) still use the first quotient.

Freshness has an existing reusable ingredient: `Code254GIC.occurs_lt_enc` (`:109`), together with `NF.Free.occurs`, already bounds free names in any named formula. One can compare a single combined induction with a small free-support-preservation lemma for `th` followed by this existing bound. The equality case must account for the auxiliary binder `x+y+1`; the original argument names remain free. `Tarski.sat_ext` (`TarskiCalculus.lean:98`) supplies the semantic environment update step, so no new semantic-invariance induction should be needed.
