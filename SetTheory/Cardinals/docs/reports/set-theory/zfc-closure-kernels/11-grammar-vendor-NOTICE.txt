MINIMAL REPRODUCIBILITY SOURCES
Prepared 2026-10-16 for the accompanying small-Turing-machine research report.

This directory contains the exact source files and finite input data needed
by generate_schema_candidates.py and verify_schema_rm_certificate.py, plus
the incoming report's PSC reference checker and its regression artifacts.
All copied source files are unmodified. SHA256SUMS records their hashes.
This is a deliberately partial source snapshot, not a complete ProveIt or
busy-beaver checkout and not a copy of either project's formal proof library.

5. REPRODUCTION AND SCOPE

Use Python 3.10 or newer; all required imports are standard-library modules
or the files above. Use python -B (or PYTHONDONTWRITEBYTECODE=1) to avoid
creating Python bytecode caches beside these unmodified inputs. The
candidate generator copies the Wade modules into its selected output
directory before executing them. No network connection, Git checkout,
Lean installation, or Coq installation is needed for these finite checks.

For the candidate generator, pass --repo vendor/ProveIt and
--rebracket-dir vendor/one_schema_machine. For the new certificate checker,
pass --prior-machine-dir vendor/one_schema_machine. Choose a separate
output directory outside vendor/ProveIt. The preserved path depth matters:
recover_wade_dag.py derives its repository root from its own file location.

Successful generation and finite register-machine certificate verification
are executable evidence. They are not a theorem that the resulting binary
machine has halting equivalent to inconsistency of ZFC. The accompanying
report states the remaining logical and compiler calibration obligations.
