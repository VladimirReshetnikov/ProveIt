## Source 176: useful semantic cleanup and a conditional affine interface

The proposed drain theorem has a precise all-natural contract. At a test of register `r`, let the nonzero edge decrement `r`, add a fixed nonnegative vector `c` with `c[r]=0`, and return to the same test. Let the zero edge leave the loop and add `d` once. For any register file `R`, exactly `R[r]` nonzero iterations followed by the zero exit produce

`R'[r] = d[r]`, and `R'[j] = R[j] + R[r] * c[j] + d[j]` for `j ≠ r`.

This is a single arithmetic induction, not a bounded-register observation. Homogeneous matrices express the resulting affine updates. Composition must follow execution order, and a retained test's decrement stays outside a matrix with nonnegative coefficients. A strict rank on eliminated exits prevents an infinite chain of individually terminating macros from disappearing into one edge; positive retained transitions and explicit halt observations preserve the halting argument.

The submitted contraction removes 1,059 recognized drains from a 1,426-vertex canonical graph, leaving 367 vertices, 732 edges and 33 shared matrices; maximum eliminated-chain rank is six. These are auxiliary proof-graph counts, not machine states. Delivered checks include 5,295 local regressions, 1,098 complete core-edge regressions and nine mutation rejections. They support the finite data but do not replace the all-natural induction. Source-to-graph adequacy and the arithmetic contraction checker remain uncompiled proposals. The current two canonical graphs are already identical: ordinary normalized equality is simpler for this pair, while affine contraction may become valuable for comparing genuinely different loop implementations. The scoped labelled minimization and interval-analysis negatives are not general lower bounds. See the manuscript's “Contract 1059 drain loops” section.

The context215 proposal is a concrete application of inherited old-run positive stuttering. Six whole-tape block pairs and nine old-table histories cover its five-row patch; one incompatible history is eliminated by its last written bit. The other histories establish the local guards. At each synchronized boundary the old run supplies the next guard; the new machine need not independently satisfy that history invariant. Positive durations, identical complete endpoints and no interior halt support both halting directions for every initial tape at control zero. Its finite checks are not an already compiled context215 endpoint. CM215 may still be faster to integrate because its delivered Core/dense bridge already exists, while M124/FM215 have smaller local proofs but missing representation adapters.

The DR dependency census is also limited correctly: two changed physical rows affect 139 guarded executions out of 6,151. Disjoint direct evaluator footprints for the other 6,012 do not prove that symbolic box-oracle assumptions remain valid. Reuse requires a theorem covering every dynamic lookup and oracle footprint. Reducing source depth or changing four operands alone does not settle that obligation.

The selected logical change avoids proving syntax facts where only satisfaction is needed. A derivable **named** bundle is obtained first; the existing `Code254Models.sat_encode_decode` theorem then supplies its decoded semantic meaning under the already required irreflexivity hypothesis. The padded matrix bound follows directly from `F=1` and the right Cantor projection: `enc(¬¬ψ) = 4 P(enc(¬ψ),1) ≥ 4`. This removes three formula inductions and an obsolete intermediate bundle theorem without changing the numerical calculus.

The literal proposal passed an isolated Lean check in 20.049 seconds with nine inherited linters. Our small successor removes the unused irreflexivity argument from `matrix_iff`, updates its five local calls and deletes eight unused simp arguments. A parser-failed comment/`omit` ordering attempt is retained. The corrected successor passed in 19.946 seconds, zero warnings, with four standard-axiom reports and an explicitly typed copy of the original seed endpoint. All five definition bodies and both seed endpoint statement texts remain exact; the four removed helpers have no outside maintained consumers. The similarly named `Code254GIC.enc_pos` is a different theorem and remains. Independent review rechecked the candidate/client/log/object bindings and all 184 phase-5 provider object hashes. This is isolated compilation against the existing basis, not a fresh complete endpoint build.

The packet also proposes a narrower padded-seed model interface, generic axiom transport and a common propositional projection. The derivation-induction transport is valid when target derivability of every source axiom is actually supplied; bidirectional admissibility must be proved from a common unchanged basis. Equal axiom images do not imply equal AX outputs at each fixed tuple. These abstractions currently remove no identified maintained consumer and remain research rather than new axioms or calibration shortcuts.

## Shared zero-credit result and selection

Both concrete credit implementations use fields DROP `[0]`, NIP `[1]`, MP `[2,x]`, AX `[c+3,y,x]` with Cantor pairing. Nonempty continuations use a successor residual; `[DROP]` genuinely has raw code zero. The parser's strict residual descent gives an all-natural inverse, not a bounded test or an identification of the empty word with candidate zero.

Lowering a selected NIP to DROP strictly lowers the raw code and preserves the occurrence position. Raising that same position reconstructs the original word, giving an injection into DROP occurrences in earlier completed candidates. It proves enough credit at every finite scheduling prefix and immediately before each NIP, without AX credit. This is stronger than merely assuming an abstract lowering map. The mathematical injection is inherited; these deliveries supply concrete formal codec/schedule proofs.

The result allows zero protected theorem heads over an opaque tail only after actual source refill, command behavior and stack depth are connected to this schedule. Theorem-valued top/cache, compiler completeness, binary simulation, initialization and ZFC calibration remain. The current primary machine already has its own safe startup; replacing it is not justified by this isolated theorem.

The immediate selected work is therefore the seed semantic cleanup, alongside separately reviewed normalized correspondence and fast physical-table adaptations from earlier proposals. The decoder framing library is a promising next interface. Affine contraction, context/marker endpoint adapters and zero-credit machine integration remain explicit future obligations. No new Rocq implementation or broad search is selected for this Lean proof-shortening checkpoint.
