# Finite-only research specimens: not certified alternatives

These three literal 220-state specimens preserve useful starting points for
search below 220. **None has a complete candidate-specific unbounded binary
runtime proof.** They are not part of the three certified constructions in
`../machine/` and are excluded from `portable/reproduce.py`.

- `occurrence_row160`: baseline row160/read0 becomes `0 R 187`. The source is
  unchanged. Historical checks cover 6,167 finite primitive cases, 6,162
  admitted guards times three sample patterns, and the complete original blank
  frame at 410,123 steps. These finite samples do not establish the unbounded
  primitive interface or an arbitrary-tape equivalence.
- `six_leaf_zero_nop`: a 4,750-leaf source, versus the baseline's 4,744, inserts
  a six-leaf zero-register semantic NOP. Historical admitted finite checks
  cover 6,164 guards times three patterns and exact startup at 409,835 steps.
  Source closure facts and a historical guarded-stuttering receipt are retained.
  The primitive word is changed: do not infer identical CFG or word equality.
- `six_leaf_zero_nop_row160`: the preceding NOP table plus the same row160
  rewrite. It passes 6,175 basic finite primitive cases. No combined-table
  admitted-domain, exact-startup, or unbounded-runtime proof is supplied.

Each folder supplies a native `candidate.tm`, complete `sites.json`, selected
historical discovery receipts, and a `table_recipe.json`. The latter is a
literal patch list from the pinned baseline, not a semantic derivation. To
reconstruct and authenticate only these exact table bytes:

```sh
python3 -B exploratory/rebuild_tables.py --output-dir ../k220-exploratory-tables
```

The complete source files are supplied verbatim, not regenerated by that script.
A successful reconstruction is **not** a runtime or consistency certificate.
The historical NOP stuttering receipt records the source layout before the NOP
insertion (hash beginning 9e5759); the final supplied NOP source hash begins
2b9932. Its independently refreshed source-closure receipt binds the latter.
Historical workspace paths are provenance strings, not replay dependencies.
The full discovery search and finite testing environment are intentionally not
bundled, so those historical finite receipts are not freshly reproduced by the
core or byte-reconstruction scripts.
