## Source 60: consistency-preserving seeds and arithmetic controls

Let S be the original equality-bearing native CP/all-Form-GIC/IR theory, and
let Γ contain universal closures of the current formula, cache and every
head of the finite positive prefix of the original unshifted-Cantor stack.
The ordinary seed theorem is the sandwich

```text
Con(S + Γ) → Nonhalt(s) → Con(S).
```

The first direction uses one common nonempty model, preserving truth under
**every assignment** through MP, stack transfers, GEN and the actual gated
axiom roots. The second direction uses the existing arbitrary-start
completeness theorem; it needs no formula invariant. The theorem does not
claim completeness for S+Γ: initial seeds may be overwritten or inaccessible.
Universal closure is an external certificate condition and need not be
written on the tape.

A proof of `Con(ZFC) → Con(S+Γ)` therefore suffices for the calibrated
nonhalting equivalence. Universally ZFC-valid seeds are a sufficient special
case, using the same membership and actual equality in one ZFC model.
A mere abstract equiconsistency or separate satisfiability of open formulas
would not justify this admission test.

The two-atom tagged hierarchy validates the **full** native theory inside a
possibly nonstandard set-coded ZFC model. Its CP powerset bound includes both
atoms, since they have no predecessors and are raw subsets of every object.
Collection, Separation and bounds on internal ranks validate every translated
GIC matrix with parameters. Distinct atoms falsify Extensionality, proving
relative to Con(ZFC) that Extensionality is not a native theorem. Its universal
closure is nevertheless a ZFC theorem and hence an admissible seed.

This should be reconciled with source 52: that earlier report already supplied
common-ZFC-model semantic startup and an HF-based restricted decision
procedure. Source 60 adds the general S+Γ sandwich and the full strictness
witness. Its five extra formulas below 65,536 are measured against the legacy
six-constructor recognizer, not against source 52's stronger checker. The
current checked `SeedInvariant254` and `DirtyProgram254.Safe` still require
native derivability; semantic-only certificates need their own Lean invariant
bridge. Existing dirty-root absorption preserves the formula fields and can
be reused, but supplies no binary frame by itself.

The arithmetic rewrite uses the exact dual-Cantor identity
`P(t,1)=P(0,t)+2`. From clean scratch X=Y=0, prefilling Y by 2 before the
additive pair-and-scale tail produces `T=4P(t,1)`, clears X/Y and preserves
arbitrary stack W and all other registers. The drain invariant
`Y+P(X,T)` and decreasing natural counters prove the unbounded contract;
finite sample inputs only test its implementation. Adding 8 after scaling is
an alternative, with different control structure.

The prefill source has 5,590 leaves and 7,221 guarded cases, versus 6,460/8,391 in
the original; direct transfer has 5,650/7,311. All retain 203 shared decoder
nodes. The unmodified backend emits 281-state controls; contextual emission
and folds yield two explicit 255-state runtimes. Both freshly checked blank
runs reach the baseline's complete 82,552-step frame with 77 one-cells. These
are concrete controls, not a state saving or a new proof-assistant endpoint.
The unchanged 252 theorem does not certify them.

Four checked difference-bound invariants exclude the same six source cases
and still admit a halt case. They start from the all-zero root and cannot
be imported unchanged for nonzero semantic seeds. A composable box oracle
tracks register displacement and existentially preserves a finite valid

The completed compound-fold and synthesized-action ledgers describe precise

it did not rerun the full research searches. The fixed finite-true-axiom

## Source 61: remove a dead return and transport the selector

The final recipe starts with the exact shared-carry 250 table. Change old
row 60/read 0 from `(0,R,0)` to `(0,R,20)`, remove states 0, 1, 3, and retain all
other surviving rows and start 97. The resulting canonical machine has 247
working states, 494 rows, start 0, dispatch 89 and separate halt 247. Its SHA-256 is
`58bbbda620daf6d4d62f486db05f54d0dccb8373c080c1b5a0b26533e7a3a669`;
the old-label table is
`0d37614f3caf37139b0be127837630539224acd1c45d748cf5704abfc3230b42`.

The key runtime argument is that a plain unary block is `0 1^(v+1)`.
After its separator the selector always scans 1, including when v=0.
Old 0/read 1 and 20/read 1 both erase that one and return left to 2. The unchanged
return rows 2/4/6 complete marking before inspecting the exterior context.
The selector induction quantifies arbitrary register values and has exact
duration `2*width(prefix)+3`; nine selector cases are not nine numeric samples.

An intermediate 248 table first deletes 1/3 and edits old 0/read 0 so states 0
and 20 have identical behavior on both symbols. Its 496 row equations then
give an unconditional one-step 248→247 configuration quotient, preserving
arbitrary-tape finite executions and halting. That quotient does **not**
transport the original 250 blank start across the preceding row edit. The
new machine therefore has its own independently checked startup.

The prefix arithmetic rows survive unchanged. Increment appends a value-one
spare; positive decrement moves the register-file origin right by one and
adds its boundary one; zero decrement returns through 112 and requires a
following block. Nine primaries plus a nonempty spare suffix establish that
premise for every selected primary, without a finite reservoir restriction.
These facts permit reuse of the arithmetic arguments already under
formalization for 250, but not reuse of its old table or bootstrap theorem.

The suite freshly checked all 8,391 guarded cases of the unchanged 6,460-leaf
program, complete source-token/tree coverage and a separate full-width-PC
audit retaining overflow and trailing zeros. Positive literal progress is
recorded; the minimum is 13 transitions. The recurrent frame includes the
clean PC, total head-to-header distance at least 40, nonempty spares and both
blank exteriors. Reverse halting reflection uses induction on finite binary
halting time, rather than extrapolating an infinite run from finite samples.
The full-PC audit shares the literal symbolic engine; it is not an independent
second binary semantics.

Two separate sparse/dense literal executions reached the same whole-tape
startup after 741,241 transitions: old 96/canonical 89, head −5, marker −6,
header 245 and distance 250. The physical primaries are
`[0,0,0,3,0,0,3,0,0]`, followed by 235 value-one spares, with 487 one-cells and
blank exterior. The logical vector is `(N,T,W,A,D,H,X,Y,L)=(3,0,0,0,3,0,0,0,0)`.
