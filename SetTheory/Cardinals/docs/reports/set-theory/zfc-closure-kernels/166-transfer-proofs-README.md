These standalone proof texts preserve the detailed reasoning and independent
review of its components:

1. transfer_compiler.md proves the complete command compiler for the original
   transfer map, with the cache-equals-one halt guard.
2. independent_compiler_review.md audits every case and the code-zero alias.
3. composite_transfer_review.md transports that proof to the actual closed
   composition old DROP; old NIP; old NIP. The additional top-equals-one halt

4. protected_credit.md proves the unbounded three-command scheduler theorem
   used by the actual non-root blank initializer. Its finite corroboration is
   not the proof. The cutoff-one result needs two explicit theorem heads;
   the matched AX supplies ten and preserves a permanent margin of eight.
5. nip_drop_obstruction.md rejects the different, cheaper NIP;DROP command for
   the stated clean source seed. It makes no unverified binary-bootstrap claim.
6. credit_extension.md notes a sufficient AX-credit threshold of five for this
   scheduler proof. It does not construct a smaller source or physical table.

Historical component notes correctly distinguish their local proof scope from
later integrated validation. Statements that a component alone does not certify
a binary machine are not a remaining gap in the final integrated 215-state result.
