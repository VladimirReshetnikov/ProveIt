## Useful contributions and proof boundaries

The successful-MP dummy zero push can be omitted. The compiler must delete
its last cleanup NIP: after the subsequent gated-off AX, ten NIPs retrieve B,
DROP puts B in the current-formula register and pushes zero, and one NIP
restores cache zero and the original stack. If B=F, that NIP halts instead,
as the universal compiler contract permits. The discard's MP always fails
because I(T,1)>0, so the other compiler uses of MP do not acquire an unhandled
successful case. Leaves and GEN retain their contracts. This is a valid
ordinary source/enumerator calibration, not a literal ordinal bisimulation
or a new Lean theorem. It changes native row164/1 only, to1R114. It removes
