### Useful positive arguments

1. **Negative equality and odd-code halting.** Interpret raw tag3 as disequality J and replace the six emitted equality occurrences by E'=N J. 2. **Negative equality with dual B.** Replacing rho6 by A→Q_i Ex_i A is positively calibrated when F remains membership R(0,0), the FULL translated rho1 `N Q_i N N J` is retained, and unrestricted rho8 remains. Delivered source pricing is unfavorable:217 distinct source subtrees and exploratory232 working states, not a217-state candidate.
3. **Membership-blind inverse detachment.** A total decoder may be arbitrary on membership codes if it is exact on implication/quantifier/equality codes. Soundness uses theorem validity under every assignment, not truth at one assignment: no membership atom is globally valid, unequal-label equality is not globally valid, equal-label equality returns the first theorem, and a universal theorem has a globally valid body. With negative equality both odd tags can be unconstrained. The explicit approximate decoder and its all-natural quotient proof are useful even though the measured full command increased the source DAG. For general computable decoders the stated constructor equations and totality remain assumptions; the explicit displayed decoder has the elementary proof needed for the intended application.
4. **Shifted even codec.** I*=max(0,4P−2), Q*=4P lets the eleven-leaf approximate decoder be exact on both required even constructors. The shared code0 interpretations are both truth and are treated directly, not as a bijective codec translation. Positive-code field descent and the private-label bound are retained. Complete source/compiler/startup obligations remain separate; all measured sources had a ten-zero run and failed the inherited six-zero boundary.
5. **Cache-return MP.** Successful MP may return `(0,W,0,D)` and failure `(0,W,D,0)`, preserving the stack. `DROP,NIP` recovers the derived current theorem or yields a valid contradiction halt. This is genuinely different from Source151's no-push-copy convention. Physical source binding and runtime are not inferred from this argument.
