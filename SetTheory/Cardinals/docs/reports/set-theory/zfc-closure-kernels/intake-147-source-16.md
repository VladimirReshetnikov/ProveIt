## Theory reconstruction and additional mathematical statements

The exact source is nonempty-domain classical equality-free first-order logic with primitive falsity and **all** parameterized subset-seeded PSC instances. The reconstruction is sound:

- Constant matrices give exact extensions of subset-bounded predicates. The reflexive initial input forces every intended output into the hull; support excludes extras. This requires no Separation or choice of local bounds (`:60–75`).
- The full-profile equivalence E combines incoming D and outgoing profiles and is a pure-logical membership congruence. Constant E-singletons are bounded by their endpoint. The gated singleton/subset decoder is locally bounded without Union; its raw-edge descent uses outgoing E to put the selected singleton inside a nonsingleton input. It gives subset transitive covers without asserting the seed belongs to the hull. Raw Separation and Union then follow from pre-established bounds (`:78–136`). This is exactly the already checked RawPSCProfile route, not the incoming-only monochromatic alternative of source13.
- Exact D-saturation is subset-bounded by raw Union. H is a fixed first-order hereditary, D-invariant predicate, defined using an S-member transitive cover. The source08 purity cut proves `H(a) iff S(a) and all members H` without recursively defining H, choosing a cover per member, or assuming Foundation (`:138–184`).
- Interpreted equality is D, membership remains raw, quantifiers are restricted to H. Heredity gives full raw/interpreted inclusion absoluteness for a pure left argument; saturation gives first-coordinate congruence. Raw PSC on the H-guarded matrix followed by D-saturation transfers both closure arms and unrestricted support. These remain ordinary mathematical arguments; no source16 proof-code translator or literal-machine endpoint is supplied.
- The raw D congruence and raw IR nonclaims are preserved. A theorem `v0∈v0` is a usable **designated theoremhood** contradiction target in the complete PSC calculus: generalization plus an empty-object witness contradicts it. It cannot be uniformly substituted for primitive Bottom throughout connectives/binders (`:313–328`).

The additional finite-model proposition is correct and useful. For a finite raw domain with Empty and exact Power, iterate `A0=empty`, `A(n+1)={x:members(x)⊆A(n)}`. Empty gives strictness initially. The result is effective and ZFC-formalizable, needs no natural set-theoretic meaning, and can use a fixed finite signature by numerical state tags. ## Complete Hilbert checker: implementation and proof boundary

Implementation: `reference_checker/psc_hilbert.py`,518lines. This review inspected every line, not just tests.

**Parsing and binding.** Formulae are flat prefix tuples with primitive B, R plus two ASCII names, binary I, and A plus one bound name. `_parse` validates exact arities and full consumption, then computes subtree intervals with an explicit stack (`:56–103`). Reverse-header handling preserves left/right order. Free-variable sets remove bound names; all-variable sets include free and bound names (`:155–186`). Formula equality compares flat token tuples, not nested Python trees.

`substitute_many` validates a simultaneous free-variable map, removes identity/absent substitutions, tracks bound scopes by an explicit stack per original name, and reserves every existing name and replacement name before selecting fresh `_vN`. At a potentially capturing binder it renames only bound occurrences in that scope, preserving nested shadowing; replacement values are not substituted again (`:198–251`). The condition excluding currently bound substitution sources is correct. This handles fresh-variable and variable-identifying substitution; it is not restricted to permutations. No concrete capture bug found.

**PSC generation.** Eleven distinct wrapper names avoid every matrix name and both designated slot names; the two slots must be distinct as *names*, but need not denote distinct objects. Three simultaneous substitutions replace only free input/output occurrences. The bound, initial subset/member guard, recurrence and unrestricted support are exactly PSC. All remaining free parameters are universally closed in lexicographic order (`:268–305`). No logical equality, external relation, fixed-slot freshness shortcut or hidden IR axiom is introduced.

**Acceptance boundary.** Each certificate instruction has an exact operation/field set and constructs its conclusion. K/S/C are classical propositional schemas; UI builds `All x A -> subst A x y`; QD checks x not free in its antecedent; MP requires exact earlier-antecedent equality; GEN uses an earlier theorem; PSC calls the actual generator. There is no ASSERT/ASSUME/arbitrary-axiom/supplied-conclusion operation. References reject bool, negative, forward and noninteger values (`:318–403`). The sole refutation target is final primitive Bottom (`:340–350`). The identity example is accepted as a theorem demonstration and is explicitly not a refutation.

**Ordinary soundness.** K/S/C are tautologies with Bottom false. The simultaneous substitution lemma validates UI, including alpha-renaming. QD's side condition makes its antecedent invariant when x varies. PSC lines are closed actual instances. MP preserves theoremhood, and GEN is unrestricted because all nonlogical axioms are closed and there are no assumptions. Induction on finite certificate length gives PSC theoremhood of every accepted line (`reference_checker/README.md:133–148`; `03:205–223`). The implementation follows these rules.

**Ordinary completeness.** K/S/C are a complete classical implicational-with-Bottom Hilbert basis; UI/QD plus GEN/MP are the standard complete relational first-order extension. Since terms are only variables, arbitrary variable substitution gives every required free-for term instance. When substitution is ordinary free-for, the implementation returns the ordinary instance literally; additional capture-renamed versions are valid extensions. A conventionally complete proof can be represented by exact earlier indices. Fresh PSC wrapper names are harmless because alpha-renaming is provable in this calculus; free parameter instances follow from the universally closed schema by UI. Thus ordinary PSC inconsistency iff some accepted finite certificate ends in Bottom (`README:150–172`; `03:225–239`). This completeness does not apply to any of the old reduced table frontends.

**Fair search/totality.** Byte decoding rejects invalid UTF8/JSON, duplicate keys, floating/nonfinite values, malformed formula tokens/operations/references. The custom integer parser avoids Python's fixed decimal-digit limit (`psc_hilbert.py:406–448`). Malformed excessively nested JSON is rejected on RecursionError; every valid certificate has bounded JSON structural depth because formulae are flat token arrays. Formula nesting itself has no recursion cutoff: parsing, binding traversal and rendering are iterative; the2500-binder test succeeds. `length_lex_bytes` enumerates all finite byte strings exactly once by length then lexicographic order; every finite certificate has some accepted serialization. `search_refutation` accepts only final Bottom (`:451–465`). This is mathematically fair and total per finite candidate with ideal finite storage. Resource exhaustion is not a successful refutation, and no physical-runtime totality theorem is claimed.

No independent semantic finite check can prove completeness or consistency. Here the universal claims rest on the inspected ordinary proof; the tests are regression evidence for its implementation.
