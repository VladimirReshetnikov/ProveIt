## Mathematical claims and their limits

The new implicational row has exactly the same instance set as the old one:
`L'(a,b,c,u)=L(b,u,a,c)` and `L(a,b,c,u)=L'(c,a,u,b)` are literal constructor
identities with inverse parameter permutations. This needs no falsity,
quantifier or consistency assumption. The first stage changes the order of
register reads and sharing; it is not an arbitrary logical-axiom replacement.

The abstract enumerator proof is an ordinary argument at the stated command
boundary, including theorem-valued retained data for soundness and the
proof-building/reset blocks for completeness. It does not prove that the
literal binary table implements that boundary. Nor does it calibrate the
reduced equality-free numeric calculus to the full source theory.

The original and dual relative-falsity rows have different theorem sets.
The report's stronger arbitrary-added-theory counterexample blocks a general
refutation-conservativity shortcut. Neither countermodel decides refutation
equivalence over the actual CP/GIC bundle. The identity-quantifier logical
diagnostic likewise shows missing cross-variable instantiation, not a model
of the complete theory or unconditional nonhalting. Keeping the original row
avoids the dual-row change but leaves equality-free proof transport open.

The register-certificate theorem is correctly conditional on actual matching
operations and finite, register-preserving contracted control paths. At each
operation boundary equal vectors select the same decrement branch and receive
the same update; matching both exits restores the relation. Thus finite
halting agrees from any common register vector. No claim about an unexamined
infinite control-only path is smuggled into this theorem. Its independent
Python checker is finite evidence, not a Lean/Rocq certificate theorem or a
proof of the Wade binary framework.

The later project `RegisterBisimulation.lean` proves the generic exposed-operation
halting equivalence with actual increment/decrement/halt semantics. It has not
instantiated these relations or proved the control-path contraction and binary
simulation interfaces.
