## Historical metadata is not an inventory of this package

`reference/upstream-attribution.md`, `reference/prior/prefix250-audit-README.md`, and `reference/prior/prefix250-audit-provenance.json` describe their **original source imports or archives**. Their file counts, dependency-closure statements, hashes, build histories, and relative links belong to those original layouts. They do not assert that this package contains every file described there or reproduces those earlier builds. Similarly, retained historical filename references in adapted source comments describe the predecessor layout; the current proof is `report.tex` with its `sections/` inputs, and current provenance is `PROVENANCE.json`.

The present `README.md`, `PROVENANCE.json`, and actual package contents describe the scope of this deliverable. In particular, no complete Lean or Rocq dependency closure is bundled and no new proof-assistant endpoint for the exact 247-state machine is claimed.

## Meaning of independent checks

“Independent” in script names or review records means a separately implemented automated check or a separate automated mathematical review within this investigation. It does not mean external peer review, an independent publication, or a new Lean/Rocq kernel certificate. Adapted tests retain their predecessor attribution even where their execution is separate from the primary symbolic checker.
