# Attribution and verification scope

This work was prepared for Vladimir Reshetnikov's ProveIt project with
ChatGPT-assisted research, code generation and independent parallel review.
The original 219-state construction and its logical calibration are the pinned
upstream ProveIt contribution at commit
`26d5de6d21fa354d50e0b84fe851c289925b8d72`, not discoveries of this packet.
The unchanged upstream ZIP preserves its attribution, licenses, proof sources
and recursively included predecessors. New material uses the inherited MIT No
Attribution terms in `LICENSE`.

The new contribution is the exact 218-state construction, source bisimulation,
full upstream-to-final table lineage, complete initialization and unbounded
runtime certification, portable wrappers, independent audits and report. The
symbolic runtime and mathematical helper are unchanged hash-pinned upstream
files, extracted from the recursively bundled K221 packet. Physical certificate
wrappers adapt the independently reviewed K219 runtime checker. The complete
source proof is independently implemented standard-library code.

Historical baseline receipts and historical intermediate construction records
are labeled as such. They are not substituted for the final exact K218 source,
startup and unbounded runtime certificates. Development receipts inside the
unchanged upstream ZIP can refer to intermediate artifacts; operative manifests
and recursive construction/calibration replay bind the inherited final bytes.

The accepted theorem is an internal consistency equivalence in ZFC. The packet
does not prove Con(ZFC), assert unconditional nonhalting, or claim that 218 is
minimal. It does not supply a newly compiled exact-K218 proof-assistant endpoint.

The unchanged membership-fourth-parameter supplement concerns a separate,
restricted logical proposal. Its nonderivability result is not an assumption,
construction component or limitation of the 218-state machine theorem.
