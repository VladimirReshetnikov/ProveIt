1. The top element is not assumed before deletion is justified. Sh1
   determines a Boolean algebra whose NAND operation is N; the derived
   top is N(t,N(t,t)). The cofactor identity treats d as arbitrary.
   The constant true class k=P(d,P(d,d)) supplies r=1 using only native
   Head and the NAND-class equation. The closure instance then forces d=1.

2. This is a same-carrier Boolean algebra, not an uncharged additional
   truth-value sort. On a separating model, N(d,d) != d and the derived
   d=1 show that the Boolean algebra is nontrivial. Its homomorphism to
   two truth values is applied only to the outputs p_E and p_eps. All
   native functions and native equalities are retained on the original
   carrier. No native operation is claimed to commute with projection.

3. The binder proof uses the equation at z=W(s,a). Its family minimum
   is therefore attained by the named native value. There is no appeal
   to an infinitary meet or to ultrafilters preserving such a meet.

4. The lower formula interpretation is equality-free pure membership.
   The native Head/Tail equations recover every required coordinate.
   A formula's code is constructed before the descriptor which contains
   it, and parameters start after the code slot. There is no truth
   predicate for the expanded native language.

5. In the inherited E692 upper model, class truth, selector index, raw
   membership value, and the transported Boolean algebra are different
   semantic roles. Literal native equality remains equality of free trees.
   The raw-value choices are ordered Q(b) < P(b,z) < A(b,z); descriptor
   parameters are proper subtrees or the preassigned default d. Surjective
   leaves e_m justify quantifier transfer to the raw membership structure.

6. The native d may be the Boolean top while the class represented by
   native d is false: the class predicate p_eps(s,d) is the Boolean bottom.
   Consequently its binder equation does not restrict W(s,d), and that
   slice can supply member choice. This does not assign W two incompatible
   roles on the same input pair.

7. The new W=V barrier is independent of any particular free-model
   construction: with a=Q(A(Q(d),Q(Q(d)))), class incidence on
   P(z,P(x,s)) is not E(z,x), while Head/Tail makes the named witness
   independent of x. The witness belongs to every nonempty raw object.
   EPSC's previously derived full-profile singletons of an empty and
   a nonempty raw object are disjoint nonempty objects, a contradiction.

8. The p_E=p_eps barrier uses only two raw-EPSC instances after the
   constant-true class gives a universal raw set. False relation gives
