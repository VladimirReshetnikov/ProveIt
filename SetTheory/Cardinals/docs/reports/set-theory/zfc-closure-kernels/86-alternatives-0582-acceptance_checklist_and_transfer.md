## Acceptance checklist

1. **Exact machine and count.** Supply a complete table with a declared blank start, exactly two symbols, one bi-infinite tape, and only L/R moves. Count every working state, including initialization; halt is separate. Verify totality of all `2n` rows, target closure, start membership, final halt write/move, canonical renumbering and a content hash. Require `n ≤ 245`. Graph reachability is not blank-run reachability. An uncompiled program/decoder or a table with preloaded data is not a qualifying machine.
2. **Exact semantic target.** State a recursive first-order ZFC proof presentation, including Foundation, Power Set, both full formula schemas and Choice. Identify its bottom and proof-checking predicate, or give the ordinary finite-proof translation to the explicitly used presentation. The conclusion must be `ZFC ⊢ (¬Halt(M,blank) ↔ Con(ZFC))`; neither external equiconsistency alone nor a stronger-theory consistency statement substitutes for it.
3. **Own blank prefix.** Provide a finite run of the actual candidate from all zeros to a completely specified related configuration. Check state, head and the entire finite support, hence the blank exterior. A window, fingerprint, state96 visit or heuristic root detector is insufficient. The baseline's initializer cannot be transported through a quotient that excludes `(97,0)`.
4. **Seed safety.** For an unchanged source, identify all nine logical registers and the logical zero tail; spare physical blocks are not additional logical registers. The baseline physical vector is `[0,0,0,3,0,0,3,0,0]` with logical-to-physical positions `(6,2,0,4,3,7,8,5,1)`. The easy sufficient family has `T=H=W=0`, arbitrary other six natural-valued fields and empty PC. More generally use `C254(T) ∧ C254(H) ∧ Good(W)` or a separately proved dirty-reset family. Completeness from every root does not imply soundness from an arbitrary dirty formula/cache/stack.
5. **Whole recurrent frame.** Retain marker, complete PC, header, all primary and spare blocks, and zero exterior. For the inherited implementation, register `v` is `0 1^(v+1)`, header distance is `d=|P|+gap ≥ 40`, and the spare list is finite and nonempty. Use the clean-PC condition, including zero extension beyond stored P and trailing zeros after the consumed leaf. A new representation may replace these invariants, but must prove its own sufficient counterparts.
6. **Universal local contracts.** Check all register values and arbitrary permitted contexts/spares, not only sampled values. Baseline mark takes `2w(A)+3` steps. Positive decrement takes `2w(A)+4`, moves the file boundary right one, returns at old origin in state48. Zero decrement needs a following block, takes `2w(A)+7`, restores the file and exits at head−1 in state112. Increment takes `2w(file)+7`, returns at head−1 in state48 and appends `[1]`. Other operations preserve spares. Therefore the nonempty resource cannot run out. Distinguish blank exterior needed for file extension from genuinely arbitrary opaque context.
7. **Complete decode/source correspondence.** Bind certificates to the actual program, not only cached site counts. For the original tree this is all 6,459 nodes, 6,460 leaves and 8,391 guarded cases, including both branches of 1,931 decrements. Check register selection/guard identity and exact break/continue/path arithmetic. If the decoder is rearranged, verify every corresponding leaf action, every guarded successor and initial leaf, or prove another complete bisimulation. In-order operation agreement without successor control and register operands is insufficient.
8. **Sound symbolic execution.** Literal steps must use the candidate table. Scan rules must be proved by induction; peeling unknown runs requires the asserted positive bound. Opaque context cannot be read. Register oracles must have proved macro contracts on this table, correct guard register, a single pending effect and preserved spare assumptions. The target is the whole frame, not the first return to dispatch. For this implementation, `h′=h−ε`, `d′=d+δ+ε`, where δ records positive decrement and ε PC overflow.
9. **Halting in both directions.** Every logical successor must reach an active related frame in a finite **strictly positive** number of binary steps; an actual logical halt must lead to the binary halt; and a failed logical decode may not be mistaken for an actual halt. Exhaustive source coverage discharges the latter. Use the positive-segment theorem below. Neither long simulation nor a one-way compiler theorem establishes equivalence.
10. **Proof/evidence status.** Separate ordinary universal arguments, finite regression, local kernel theorems, complete exact-machine kernel theorem and a serialized object-theory derivation. Hash inputs and final outputs; replay on a fresh writable copy. Preserve source/theory assumptions and attribution. No accepted result may rely on an unproved reachability claim for excluded quotient rows, unchecked oracle effects, or the consistency of ZFC itself.

These are sufficient proof obligations, not a mandated implementation. A direct whole-machine conjugacy, a reachability-specific invariant, or another equivalent construction can discharge the same logical requirements without retaining all 8,391 original cases.

## Reusable transfer theorem (ordinary theorem in ZFC)

Let `B` be a deterministic machine transition on set-coded configurations with an absorbing halted predicate. Let `A` be a partial deterministic abstract transition `next`, a designated terminal predicate `Term`, and relation `R(a,c)`. Suppose ZFC proves:

- Every `R(a,c)` has active binary c.
- If `R(a,c)` and `next(a)=b`, there is an integer `k>0` with `R(b,B^k(c))`.
- If `R(a,c)` and `next(a)` is undefined, then `Term(a)`.
- If `R(a,c)` and `Term(a)`, then the binary run from c halts.
- For a fixed finite N, `R(a₀,B^N(blank))`.
- Abstract halting from a₀, defined as reaching a designated terminal after finitely many defined steps, is equivalent to existence of a finite ZFC refutation.

Then ZFC proves `¬Halt(B,blank) ↔ Con(ZFC)`.

**Proof.** Finite induction on an abstract prefix constructs a binary prefix to each related abstract endpoint; its accumulated clock is at least the abstract prefix length. Thus any abstract halt produces a binary halt. Conversely, strongly induct on a binary halting time t from a related configuration. If the abstract successor is undefined, the third hypothesis gives a terminal immediately. Otherwise the second gives k>0 and an active related endpoint. Since binary halts are absorbing, activity of that endpoint forces k<t. The remaining binary run halts after t−k<t, so induction yields an abstract halt from the successor and hence from the original state. Adding/removing a fixed finite binary prefix preserves eventual halting, again by absorption. Compose with the calibration and negate both sides. All choices are finite existential eliminations; there is no fairness or infinite-choice assumption. All definitions, recursions and inductions are available in ZFC. ∎

`TransferTheorem.lean` gives the small reusable final composition against the existing `RuntimePerm252.PositiveSimulation` interface. It is a **source draft only** here; no local Lean compilation is claimed. The existing generic positive-segment proof is already retained in the pinned source.

### Restricted state-fold corollary

Suppose f maps old active states to new active states and old halt to new halt, and each allowed old state/read pair commutes with f, with the exact same write and move. Induction transfers every finite old trace avoiding the excluded pairs, with identical head/tape and mapped state. To obtain an unbounded correctness result, prove avoidance on an invariant closed under the old executions, or replay sound universal local contracts directly on the new table. A finite census of avoided pairs does not prove this premise. If the old blank start is excluded, prove a separate new blank prefix. Preserved positive instruction segments and active endpoints then meet the transfer theorem; arbitrary global state equivalence is unnecessary.

Inside ordinary ZFC, finite syntax and proof trees form sets and Henkin completeness produces nonempty set-coded models, not transitive models. From a ZF model, internal rank/Collection validates native CP/GIC/IR. Conversely a native CP/GIC model has the set-sized bisimulation quotient; the internally well-founded subdomain, with its actual formula relativization and GIC closure lemmas, yields ZF including Foundation and Power. “Internally well-founded” quantifies over subsets represented in that model, not all external subsets. Taking external well-founded elements of an arbitrary model is not the proof. The internal constructible subdomain of a set model of ZF is externally a set and supplies a ZFC model. Soundness and completeness yield the finite-refutation comparisons. All schemas range over actual finite formulas and all satisfaction predicates concern set structures. Thus the ordinary argument is ZFC mathematics; it is not a blanket translation of universe-polymorphic Lean into ZFC.
