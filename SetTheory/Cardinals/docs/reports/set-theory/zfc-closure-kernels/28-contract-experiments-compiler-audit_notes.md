dual-quantifier schema. Source12's sorts have d0=2 and d(i+1)=di+2^di.

invariant proves the ideal reduced enumerator nonhalting without Con(ZFC).

mixed-radix truth tables. Neither gives a serialized PA derivation or a
literal-machine simulation.

Consequently the reduced248,249,250,251,252 tables are not merely promising
uncalibrated proposals. Their intended proof-engine route has been rejected.
Given a correct ZFC simulation, those tables' nonhalting would be provable
in ZFC and so (assuming consistency) could not satisfy the requested ZFC
equivalence with Con(ZFC). This does not refute the ordinary one-domain
theories PSC, EPSC or CP/GIC, and it does not refute the full-equality public
253/254 construction.

Source19 also shows why fresh UI plus injective renaming plus signed atomic
UI is inadequate for composite variable identification. In actual two-bit
coordinate quantification with R(i,j)=(i!=j and s(i)=s(j)), the matrix
((Rxy iff Rxz) iff Ryz) is universally true in x but becomes uniformly
false when x is identified with an already occurring y. That particular
diagnostic is not asserted to model PSC/C/G; the finite-sort model covers
the stronger theory claim.

## Completed bounded continuation

occurs once), all6 permutations of scalar parameters in every other logical
row, row order, C/G swaps, outer conjunction trees and grammar choices. Thus
the basic idea of combining those transformations is prior work. Its reported
60,000-iteration stochastic search is not an exhaustive parameter grid.

Our new `rho8_grid.py` performs a reproducible systematic slice:12 safe rho8
permutations ×2,048 seeds ×exponents2,4,8 ×legacy/overlap-safe grammar, while
retaining the best known source19 C/G layout. It checks each row's symbolic
output and the single stream read, prices decision count+55+actual dispatcher
depth, compiles improving candidates and re-extracts all decision edges.
The fixed predecessor regenerates the exact268 table and its4,533-pair
register certificate. The completed grid evaluated147,456 DAG recipes in
344.468 seconds; it found no improvement below268. Twenty recipes attained268,
and observed dispatcher depths ranged from6 to11. Only the baseline and final
winner were compiled (two compilations); every strictly improving candidate
would also have been compiled and re-extracted. This is not147,456 distinct
compiled tables. The fixed winner is exactly the prior source19 table, with
206 decision states and framework55+7. A separately invoked path verifier
accepted all4,533 relation pairs, including both decrement branches.

A bounded follow-up tried associative rotations only inside closed axiom
grammar subroutines, followed by structural sharing and reachability pruning.
