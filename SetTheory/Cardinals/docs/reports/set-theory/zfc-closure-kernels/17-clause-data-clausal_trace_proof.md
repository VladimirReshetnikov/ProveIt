# A complete ground-clause route for the PSC consistency machine

## Scope and result

The new executable reference in `clausal_trace.py` takes exactly the existing
equality-free, pure-subset PSC schema generated by the attributed
`qpsc_syntax.closure(..., seed='subset', mixed=False)`. It compiles a finite
list of schema instances into universally closed Skolem clauses, checks a
linear ground-tableau refutation, and fairly enumerates candidate finite
certificates. It has no optional theorem mode and accepts no caller-supplied
nonlogical axiom. The separate generic `Clauses`/`check_trace` interface is
used only for arbitrary-formula regressions and future compiler comparisons.

Let Q be this recursively enumerable PSC theory, with the language consisting
of logical bottom, membership, implication, and universal quantification over
ordinary nonempty first-order domains. At the mathematical algorithm level,

\[
  \exists n\;\operatorname{Accept}(n)
  \quad\Longleftrightarrow\quad
  Q\text{ is syntactically inconsistent}.
\]

The equivalence is provable in ZFC by ordinary completeness and Herbrand's
theorem. Combining it with the separately established consistency calibration
of Q gives the requested consistency-search specification. This note does not
re-prove the set-theoretic calibration and makes no claim that the Python
source or any binary compiler has been formally verified. In particular it
does not attach a binary-state count to the reference.

The contribution is an explicit alternative implementation and a sharply
bounded checker interface. Clausal tableaux, Skolemization, Herbrand
expansions, and their completeness are established methods, not new results.
Relevant primary research includes Anders Schlichtkrull's formalized
Herbrand/semantic-tree development and Christoph Wernhard's clausal-tableau
development, cited below.

## 1. Exact signed clausification

A source variable is a natural-number label. A source term after
Skolemization is either a universally quantified variable or a function
application. All source predicate symbols are the single binary relation E.
A ground term is a finite application tree with no variable leaves. The
compiler introduces a distinguished fresh constant 0 even if no existential
quantifier occurs, so that the Herbrand universe is nonempty.

The manually entered formula parser additionally recognizes `T` as logical
truth, for convenient generic regressions and formula construction. The
natural-number matrix codec deliberately uses only `B`, `E`, `I`, and `A`:
bottom, membership, implication, and universal quantification. It is not
claimed to enumerate the extended syntax containing the literal token `T`.
Truth is already expressible in its base grammar as `I(B,B)`. The codec
roundtrip and surjectivity statements below concern this base grammar.

The compiler walks an ordinary named formula using an explicit environment
from current bound-variable labels to terms. Re-entering a binder overwrites
its environment entry only in that recursive call; this handles shadowing
without textual replacement. Every newly universal occurrence gets a globally
fresh variable. Every newly existential occurrence gets a globally fresh
Skolem function, whose arguments are all universal variables currently in
scope, in their recorded order. These lists include unused universal
variables, which is harmless. The signature is never reset between source
sentences, preventing witness aliasing across axioms.

For polarity +, bottom becomes false and implication becomes disjunction of
the negative antecedent and positive consequent. For polarity -, bottom
becomes true and implication becomes conjunction of the positive antecedent
and negative consequent. A universal binder at positive polarity introduces
a fresh universal variable. A universal binder at negative polarity is an
existential binder after negation normalization and introduces its fresh
Skolem application.

CNF is represented as a list of clauses. The empty list is true; a list
containing the empty clause is false. Conjunction concatenates clause lists;
disjunction takes all concatenations of one left clause and one right clause.
These conventions correctly handle both logical constants and all empty
cases. A generated clause's variables are universally closed independently.

### Clausification lemma

For every finite list of closed equality-free sentences A, the generated
clause set C(A) is satisfiable exactly when A is satisfiable.

**Proof.** Negation normalization follows the classical truth tables and
quantifier duality. Standardize universal variables and existential symbols
apart by the compiler's globally fresh counters. In negation normal form all
quantifiers occur positively. Each existential occurrence can be replaced by
a function of the universal variables in its lexical scope. Given a model of
the sentences, choose witnesses for all relevant assignments; witness choices
for an occurrence outside a truth-relevant disjunct can be arbitrary. In ZFC
these choices exist. The converse substitutes the function values as
existential witnesses. Outer existential witnesses need not be additional
function arguments, since they are already determined by their preceding
universal arguments and the fixed witness functions. Thus the construction
preserves existence of a model. Distinct fresh symbols guarantee simultaneous
expansion of the finite list. Finally, move globally fresh universal variables
through conjunctions and disjunctions and distribute the Boolean connectives.
The usual equivalences hold because domains are nonempty and moved variables
are absent from the other operand. The resulting universal CNF is exactly
the recursively generated clause list. This proves both directions. QED.

No claim is made that Skolemization preserves equivalence in the original
language or that arbitrary witness functions work. It preserves existence of
an expansion. Also, replacing a Skolem function by a constant is generally
incorrect: `forall x exists y E(x,y)` requires a unary witness, whereas
`exists y forall x E(x,y)` has a constant witness. The regression explicitly
distinguishes these cases.

## 2. The two-instruction ground checker

An extension instruction has the form

```
["e", source_clause_index, ground_substitution_arguments]
```

The checker obtains the source clause from its own compiled package. It
checks the exact argument count, verifies every function symbol's declared
arity, and substitutes ground terms for the source variables in sorted label
order. No quantifier, bound-variable substitution, or freshness condition
survives in the resulting clause.

The instruction creates one tableau branch for every literal in that ground
clause. The implementation follows the first branch and stores the remaining
siblings together with the parent's trail length. Each branch consists of an
ordered trail of ground literals; atoms are compared by exact tree equality.
It does not identify distinct terms or assume a free-model interpretation of
the original theory.

A closure instruction has the form

```
["c", ancestor_index]
```

It is accepted only if the newest trail literal has exactly the same ground
atom as the indexed earlier literal, with the opposite sign. After closure,
the checker automatically removes the finished branch's trail suffix and
advances to the next stored sibling. When no sibling remains, the entire
refutation is complete. An empty source clause closes a branch immediately.
Any extra instruction after completion and any unfinished branch at the end
of the input are rejected. No certificate can simply abandon the expensive
side of a split.

### Ground soundness lemma

If the checker accepts a trace from a package C, a finite set of ground
instances of clauses of C is propositionally unsatisfiable.

**Proof.** Suppose a valuation satisfies every ground instance used by the
trace. At the root the empty trail is true. At an extension of a true trail,
some literal of the source ground clause is true; choose that child. Every
such child is present because branch count is the clause's actual length,
not a certificate assertion. Following true children must eventually reach a
closed leaf in the finite accepted tableau. A complementary pair cannot both
be true, and the empty clause cannot be true. This is a contradiction. The
linear backtracking implementation is exactly a preorder traversal of that
finite tree. QED.

### Ground completeness lemma

Every finite propositionally unsatisfiable list of ground clauses has an
accepted trace, even with closure restricted to the newest literal.

**Proof.** Order the finitely many clauses. Starting with the empty trail,
branch on every literal of the first clause, then every literal of the second,
and so forth. Close a branch at the first complementary pair. When a pair first
appears, it contains the newest literal, so the restricted closure suffices.
If a branch survived all clauses, it would be a consistent finite set of
literals containing at least one literal from every clause. Assign its atoms
their indicated truth values and arbitrary values to all other atoms. This
would satisfy the clause list, contrary to the hypothesis. Every branch
therefore closes. If an empty clause occurs, its branch closes immediately.
Serialize the finite tree in preorder to obtain the required trace. QED.

The proof does not require resolution, factoring, unification, a lifting
lemma, duplicate-literal elimination, or a global numbering of ground atoms.
Those omissions are useful concrete design decisions for a small verifier;
they do not establish that its final TM will be smaller than other designs.

## 3. Herbrand completeness and schema fairness

If Q is inconsistent, a finite proof uses finitely many PSC instances. Let A
be that finite list. By the clausification lemma, C(A) is unsatisfiable. By
Herbrand's theorem there is a finite propositionally unsatisfiable list of
ground instances of C(A). The ground completeness lemma provides an accepted
trace. Conversely, an accepted trace makes C(A) unsatisfiable by ground
soundness; the clausification lemma and ordinary first-order completeness
then make the finite list A, and hence Q, syntactically inconsistent.

Crucially, Q remains a schema: it is not replaced by one fixed finite list of
axioms. The actual search enumerates arbitrary finite lists of matrix codes
together with arbitrary finite instruction traces. Every finite witness is
eventually reached.

An equivalent staged presentation makes both dimensions explicit. At stage B,
compile the first B matrix instances with stable globally fresh symbols, add
the dummy constant, form ground terms of depth at most B using the current
finite signature, and include all instances of the current source clauses
over those terms. Each stage is finite. A contradiction uses some finite
prefix of matrices and some finite maximum ground-term depth, so a sufficiently
large B includes it. Appending later matrices does not alter earlier clause
or Skolem identifiers. If a different frontend does not preserve identifiers,
dovetail independently over the axiom-prefix bound and ground-term-depth
bound instead of assuming monotonicity.

The delivered implementation uses a single natural-number certificate codec
instead of materializing every staged Herbrand expansion. Cantor pairing
encodes a matrix list and a trace list. A trace instruction code is even for
closure and odd for extension. Terms encode a function symbol paired with a
finite list of child-term codes. All recursive child codes are strictly less
than the containing positive code; list tails strictly decrease. The same is
true of the bottom/membership/implication/universal matrix codec. Consequently
every natural is decoded in finite mathematical time, and every finite valid
certificate over the enumerated matrix grammar has a natural code. Checking a decoded finite candidate also
terminates. Enumerating 0,1,2,... and halting on the first accepted code is
therefore a genuine semidecision algorithm for inconsistency.

The Python host has ordinary finite memory and recursion limits. Resource
exceptions are deliberately not caught as successful refutations. The
diagnostic `--prefix` option is bounded testing; completing it is not the
mathematical machine's halt and proves no consistency statement.

## 4. Equality and the comparison with Hilbert repair

The frontend deliberately accepts the equality-free PSC language. This is
essential for a ground propositional kernel with raw syntactic atoms. If an
alternative finite theory contains equality, one must first translate equality
to a fresh binary predicate with reflexivity, symmetry, transitivity and
congruence axioms for every predicate and every function symbol, including
all subsequently introduced Skolem functions. A quotient of the resulting
model recovers ordinary equality. Ignoring these axioms produces the wrong
satisfiability problem. No equality translation is implemented here.

A conservative direct Hilbert reference is propositional logic, modus ponens
and generalization, full capture-avoiding specialization
`forall x A -> A[t/x]`, and the exportation scheme
`forall x(A -> B) -> (A -> forall x B)` when x is not free in A. In the
pre-Skolem function-free language, admissible terms t are variables. Merely
adding same-variable specialization supplies only t=x; the other admissible
renamings and exportation still require proof. The clausal route has a
different audit boundary: quantify correctly once during clausification,
then use a completely propositional backend.

## 5. Executed verification and reproduction

Run, from this directory:

```
python check_clausal_trace.py
python clausal_trace.py --prefix 1000
```

The executed results are in `clausal_trace_results.json`:

| Check | Executed result |
| --- | ---: |
| Closed generic first-order formulas | 159 |
| Finite original-structure / Skolem-expansion comparisons | 2,862 |
| Propositional CNFs compared with independent truth tables | 20,854 |
| Accepted finite ground refutations | 4,613 |
| Deliberately malformed or unsound traces rejected | 15 |
| Actual PSC matrices clausified | 200 |
| Clauses from those PSC matrices | 2,167 |
| Fresh Skolem symbols from those PSC matrices | 1,326 |
| Maximum observed Skolem arity | 5 |
| Roundtrips tested separately for matrix, term and certificate codecs | 5,000 each |
| Refutation-candidate diagnostic prefix | 1,000, with no acceptance |

The finite semantic test independently enumerates every Skolem interpretation
over domains of sizes one and two for its selected formulas. In particular,
it checks witness dependence, binder shadowing, distinct existential symbols,
polarity, truth, falsity and the CNF empty cases. The propositional test covers
every set of up to four nontautological clauses over three atoms, not just
hand-chosen successful examples. Its truth-table oracle is independent of
the trail verifier. These checks substantiate implementation behavior but
are not a substitute for the mathematical proofs or a proof-assistant check.

`synthetic_ground_refutation.json` concerns the inconsistent pair
`forall x E(x,x)` and `exists x not E(x,x)`. It demonstrates the generic
interface and is explicitly not a claimed PSC refutation.

The additional `specialization_certificates.json` directly checks the two
logical instances most relevant to the finite-sort obstruction. Negating
the universal closure of `(forall x R(x,b)) -> R(a,b)` yields the clauses
`R(x,b)` and `not R(a,b)`, with a and b fresh Skolem constants. The trace
instantiates x with a and closes the resulting literal pair. Negating
`forall b ((forall x R(x,b)) -> R(b,b))` similarly yields `R(x,b)` and
`not R(b,b)` and instantiates x with b. Each trace has two extension
instructions and one closure. The test independently compares the generated
clauses with exactly these expected clauses before checking the trace.
These artifacts are generic logical regression certificates, not optional
theorem input modes of the PSC inconsistency search.

The same file gives an explicit Skolem-dependence control on domain {0,1}
with R the diagonal relation. Here `forall x exists y R(x,y)` has the unary
witness f(x)=x, whereas `exists y forall x R(x,y)` is false and neither
constant interpretation can satisfy its compiled clauses. The executable
checks original formula truth, the indicated unary witness, and absence of
a constant expansion independently. This is an actual finite negative
control for treating every witness as a constant.

When the code is placed in the final package's `code/` directory, the results
can be regenerated in `data/` by running from the package root:

```
python code/check_clausal_trace.py --output-dir data
```

## 6. Full-word compiler control

`search_full_grammar.py` also ran a bounded grammar experiment on the complete
published equality-preserving AX macro word. No logical row, theory row,
falsity code, equality operation, gate, read, or macro order was changed.
The 186-macro word consists of 17 closed macro kinds. Across 1,000 seeds for
each of frequency exponents 1,2,4,8, the selected recipe (exponent 4, seed 287)
reduced the full decision DAG from 219 nodes to 208. The public Wade backend
then emitted 270 working states, including its 62 framework states, and 539
transition rows, with its existing missing `1.inc/read1` row unchanged.

The exact RM bisimulation has 4,533 related operation sites; both sides have
6,460 unfolded sites, and both decrement outcomes were checked. The named
table SHA-256 is

```
49013eb2d701779f12537b37aa2e553f14a063b8ec0a3eee690534aa13f6700e
```

This is a reproduction/comparison, not a new record: the earlier source-08
report already achieved 269 = 207 + 62 with the full unchanged word. It also
does not reconstruct Mira-Cult's smaller interpreter. The result must not be
reported as a 243-state machine by subtracting 27 framework states. The
actual generated table and finite RM correspondence are the available
evidence. The bounded search was stopped once that prior comparison was
identified.
