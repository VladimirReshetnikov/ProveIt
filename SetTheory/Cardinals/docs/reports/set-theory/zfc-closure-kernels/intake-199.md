## Source 164: projection basis and MP without a numeric input

The projection theorem is a new calibrated restriction. Let L,R unpair
floor(n/4), without checking the outer constructor tag. Restrict rho8's fourth
input to `0,A,L(A),R(A),LL(A),RR(A),LLR(A),RRR(A),LLRR(A)`. Every one of the
1,260 axiom leaves in the fixed3,728-node Source 149 certificate belongs to
one of these families. Evaluating the finite schematic derivation under
arbitrary natural assignments recovers every unrestricted instance, including
zero collapse, without adding object-level substitution. The converse is
immediate, so the full native theorem sets agree. The broader disjunction
`U=A or 4U≤A` is another calibrated restriction.

Nine is minimal only for covering this fixed certificate with displayed
subterm projections and constant zero. There are six optimal covers; the
chosen prefix-closed one uses seven projection edges if values are retained.
This is not a lower bound on alternative proofs, theories or TMs. The
four-value countermodel and its universal raw-code lifting limit a smaller
propositional family, but GEN already fails in that evaluator. They therefore
do not refute full-theory equiconsistency.

The second new interface removes MP's numeric field. AX reads absolute A=x,
keeps old d as rho8's fourth input, and leaves a comparison residual
`max(A−C−1,0)` or its opposite. A dummy AX setter assigns any MP consequent
while preserving the current theorem and protected stack. The strong
compiler permits arbitrary residual on return and handles reset, row
selection, GEN, MP and cofinal enumeration. Its gated bundle is the new
current theorem; cache is zero. The all-natural command algebra was reviewed;
the 4,619 finite tests use a safe-row interface and induction-hypothesis
oracles, so they do not prove a literal binary-source splice. Original work
