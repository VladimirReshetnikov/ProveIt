# Historical finite discovery diagnostics only

The unchanged `finite.json` records 30,810 finite admitted-dispatcher tests.
`frame_transport.json` records how their finite inputs were transported by
exact ordinal source correspondence. These were useful discovery diagnostics,
not universal proofs and not premises of the final machine theorem.

Their explicit finite-only scope is preserved. The final certificate instead
requires the independently checked all-natural source proof, exact complete
blank startup and fresh complete unbounded 6,167-case primitive refinement.
No discovery receipt is silently promoted to a completed unbounded proof.
