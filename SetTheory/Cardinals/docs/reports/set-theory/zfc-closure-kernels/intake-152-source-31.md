## Ordinary mathematical and code audit

### Default-last four-slot frontend

For a matrix starting at scopedepthd>0, variablei is normalized to min(i,d-1); the depth increases at every own binder. This is a structural retraction onto well-scoped syntax. The running checker implements the same semantics by selecting the last environment entry when a variable index runs beyond its list. Crucially, each fixed wrapper hole first projects exactly its four matrix slots; only then is the raw matrix exposed and total lookup applied. It does not clamp against the surrounding wrapper environment, and under nested binders the current scope grows. Equal environment values are permitted. Neither the mathematical normalizer nor the checker restricts logic to four variable names or distinct values.

The old/new checker bodies were compared and the full actual tree checker read: proof rule arities/references, opposite signed atom closure, implication branching, positive universal instantiation with existing or next fresh parameters, negative universal globally fresh witness allocation, and strict matrix-only public entry point remain intact. A certificate is transported by normalizing every matrix; its proof tree, signs, references and allocated names are unchanged. Every exposed entry has the same truth/atomic value under that transport. Therefore an accepted default-index certificate corresponds to an accepted original certificate with normalized matrices. Conversely, old legal matrices are fixed and every formerly accepted numeric certificate remains accepted at its original code. The least new accepting candidate can only decrease, but this proves no runtime or compiled-state bound.

The codec decodes arbitrary finite nonnegative integers to raw finite syntax with decreasing recursive payloads. It retains an explicit public validity checker for proof shape and references. The generic logical-identity certificate tests have contradictory logical premises, not EPSC axioms; no public EPSC2 refutation was found. Resource exceptions propagate, never accept. Defaulting an index supplies meaningful semantics; it does not justify deleting malformed proof checks or witness freshness.

### Dense quantified-NAND codec

At scopedepthd>=1, atoms use i+d*j (i,j<d), and compounds use d*d+Cantor(code(left atd+1),code(right atd+1)). Every natural number is either an atom belowd*d or a compound; because d*d>=1, both unpaired child payloads are strictly below the parent. Strong induction on the numeric code, uniformly in depth, proves total decoding and both roundtrip directions. Own binders raise depth for both children. Cache keys include depth and code. There is no hidden injectivity assumption on environment values and no zero-scope bijection claim. The independent semantics evaluator covers all16 binary relations on a2-object carrier and colliding assignments. This is a representation theorem, with ordinary mathematical proof and bounded executable checks, not an implemented smaller frontend machine.
