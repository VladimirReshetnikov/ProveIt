# Validation of this contribution

The delivered core verification completed successfully on 18 October 2026,
using Python 3.12.14. All 18 subprocess checks passed,
as did the separate independent replay of the rejected first 245-state table's
finite initializer. The complete machine-readable results are in
`_recheck/verification_summary.json` and the adjacent logs.

The new 246-state and 250-state constructions each pass all 8,391 universal
instruction-frame cases, all register inductions, independent source-equivalence

410,735 and 407,983 transitions, respectively. This supplies blank-start
halting equivalence with the pinned reference by the composition theorem in
the report. It does not supply a new machine below 246 states.

245-state reassociation has a reproduced local counterexample; the isolated
short-scanner table fails 36 cases; the colored short-scanner table fails
30 cases. The verifier explicitly requires those outcomes, rather than
treating them as accepted machines.

The 28-page PDF was compiled with LaTeX, rasterized, and visually reviewed.
The final build has no overfull boxes or undefined references. Its SHA-256 is
`7ef2010a77d9e928d55cd3bdae847cf5eff963c10cb8bbe0966c3e5ee7bd5bba`. The separate delivered PDF has exactly the same bytes.

These checks are conventional finite and symbolic mathematical certificates.
No new Lean/Rocq kernel endpoint or serialized ZFC/PA derivation was built.
The logical calibration is inherited through the interfaces stated in the
report. The bounded discovery searches do not establish a state lower bound.

To rerun the core checks from this directory:

```sh
python3 -B verify_bundle.py
```

To rebuild the report:

```sh
make pdf
```

certificate files regenerated by a rerun need not remain byte-identical.
