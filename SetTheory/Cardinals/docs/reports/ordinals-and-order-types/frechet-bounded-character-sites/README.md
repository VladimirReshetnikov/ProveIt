## What the article establishes

Let P_kappa be the site of free filters on omega generated modulo the cofinite filter by fewer than kappa sets. It is ordered by strengthening and equipped with the relative dense topology. The article represents its Booleanization C_kappa as a regular-open algebra on the set of free ultrafilters, with a topology generated by small intersections of original Stone clopens.

The original algebra P(omega)/Fin is order dense in C_kappa exactly for kappa <= p, where p is the pseudointersection number. Above p there is no complete Boolean homomorphism from the original completion to C_kappa that fixes every original Boolean event. This is a **marked** comparison result, not a claim of abstract nonisomorphism in every case.

The atoms of C_kappa are precisely ultrafilters of character below kappa. Thus it is atomless, and its localic Boolean sheaf topos has no geometric points, exactly for kappa <= u. Full atomicity is equivalent to every allowed filter extending an allowed ultrafilter, not merely to the existence of some small ultrafilter.

The reduced-power sheafification is computed by explicit Boolean mixtures of old sequences. It has finitary first-order transfer and an attained existential truth value. A p-fold conjunction of old predicates sharply distinguishes the stages above p. For a field K, the global-section ring is von Neumann regular with idempotent algebra C_kappa; in the atomless range it is not a full direct product of nonzero fields.

One application imports the precise model properties in Millán's 2009 proof of Theorem 3.14. In that model the hierarchy has an atomless countable-base stage, an intermediate atomic stage with c atoms, and the full atomic stage with 2^c atoms. **The forcing construction is a cited input, not a new proof in this package.**

## Rebuild

A TeX installation providing pdfLaTeX, the NewTX packages, and the ordinary packages named in the source is required. Font files are not included. No BibTeX invocation is needed.

```sh
bash build.sh
```

Or, to compile only the article:

```sh
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
```

To rerun only the exact finite checks, use Python 3.10 or newer:

```sh
python3 verify_finite.py --output verification_results.json
```

The JSON output is deterministic. Identical PDF bytes across different TeX installations are not promised.

## Verification scope

The supplied run checked 507,348 mixture-equality comparisons, 33,508 relative filter families, 65,812 candidate finite frame-point maps, and the other exact finite calculations listed in Section 12.2. All checks passed.

These are finite Boolean algebras, not proper cofinite-extending filters on finite index sets. They test algebraic formulas and semantic interfaces. They cannot prove assertions about p, u, uncountable characters, or forcing consistency. The infinite proofs are in the article.
