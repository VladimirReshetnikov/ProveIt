# Proof audit

Date: 24 September 2026. This is a self-audit, not independent referee review.

## Exact claims and assumptions

The ambient theory is ordinary ZFC. Posets, coordinate-label families, and
ordinals are sets. The state poset and label set in the central theorem are
finite. The abstract pure-coordinate theorem assumes lambda_q = omega^rho_q,
with rho_q >= 0, and convex lifetimes: A_s intersect A_u is included in A_t
whenever s <= t <= u. Empty active sets are allowed.

The compressed maximal-frontier formula requires a nonempty finite skeleton
and positive pure ordinal fibers, rho_q > 0. The all-support formula permits
singleton fibers. The CNF-refinement theorem handles arbitrary nonnegative
ordinal fibers, including zero, finite, and successor fibers.

Height means the well-founded rank height sup_x(r(x)+1), with r(x) =
sup_{y<x}(r(y)+1). It is not maximal order type. The finitary powerset is the
Hoare quotient, equivalently finitely generated downsets under inclusion.
It includes the empty downset. A finite-skeleton ideal means any downset,
not necessarily a directed ideal.

## Dependency map

1. Cantor normal form proves strict natural-sum monotonicity, closure below
   pure ordinals, and p # delta < p + omega^rho when delta < omega^rho.
2. Over a fixed state chain, R(i,x) = prefix_i # natural_sum(x_q) is a strict
   rank bound below the sum of retirement costs.
3. Varying one retiring coordinate per stage, with all other coordinates at
   their least values, constructs an actual chain of that same type.
4. Every decreasing sequence lies over one maximal finite state chain.
   The full decreasing-sequence tree is a finite union of prefix-closed
   well-founded trees, whose root rank is their maximum.
5. Maximal generators give an exact all-support-antichain representation of
   finitely generated downsets of ordinal lexicographic sums.
6. Maximal chains in the ideal lattice are linear extensions, yielding the
   finite recurrence and path certificates.
7. CNF block refinement is an exact order isomorphism, proving the result
   for arbitrary original ordinal lengths.
8. The principal lower interval below K is K(K), proving exact local ranks.

The maximal-frontier theorem follows separately from two order embeddings.
The classical product-height/Milner–Rado formula is a test oracle, not a premise
for the central theorem. The repository's survivor formula for maximal order
types and its uniform-height theorem are not used as unproved premises.

## Delicate points explicitly checked

**Natural sum is not path addition.** Natural sum appears only in rank bounds
and the separate product benchmark. Paths use ordinary ordinal addition.
Persistent omega^2 plus a retiring omega gives omega + omega^2 = omega^2.

**An empty exit still costs one point.** The default weight 1 is needed for
support states with no retirement and for finite endpoints. K(empty) has
height 1 and K of an N-point finite poset has height N+1.

**Convexity has two uses.** It makes the configuration relation transitive and
ensures that a coordinate used in an earlier witness block cannot reappear.
Without it the proposed relation need not even be a partial order.

**The tree union is finite and prefix-closed.** The argument covers entire
decreasing sequences, not merely points. A cover by arbitrary subposets does
not have the same maximum-height property. Infinite unions do not support
the argument as stated.

**Purity is essential to the unrefined cost formula.** Two states with the
same omega+1 coordinate form 2 x (omega+1), of height omega+2; the naive
unrefined cost gives omega+1. The finite phase-refinement corollary, not blind
substitution, handles this case.

**Completed fibers are used only where valid.** Positive pure limit fibers
cannot be internally generated by finitely many points. That fact justifies
the canonical maximal frontier. Successor fibers are handled through the
exact support representation and CNF blocks, not through a false extension
of the completed-fiber representation.

**The upper frontier embedding permits empty sections.** It uses the genuine
order isomorphism K(alpha) = 1+alpha isomorphic to alpha for positive pure
alpha. The reverse embedding uses all active sections nonempty. No claim is
made that every unrestricted tuple belongs to a canonical stratum.

**Finite maximum and ordinary addition.** The dynamic program uses only
monotonicity of addition in its left operand and attainment of a finite
maximum. It does not assume strict monotonicity or cancellativity there.

**Point-rank predecessor.** A principal lower interval has a greatest
finitely generated downset. Its height is a successor, and its expanded
maximal blocks have size 1. The code decrements the finite final coefficient;
it does not perform commutative ordinal subtraction.

**Complexity encodings.** The O(N * number_of_ideals) ordinal-operation count
uses the expanded pure-block input. Chain-partition bounds use this same
encoding. NP membership of the threshold problem assumes explicit ordered
exponent labels and pure blocks. No polynomial-time claim is made for binary
CNF coefficients before unary expansion.

**General non-chain coordinates.** The sufficient extension explicitly
requires a least element and an attaining chain for each pure height. It
only extends the abstract theorem; it does not assert a finitary-powerset
support representation for arbitrary non-chain fibers.

## Computational evidence

`verification.json` records 63,270 successful assertions under Python 3.13.5.
Independent finite routines compare path enumeration, the ideal recurrence,
frontier compression, direct finite ranks, and the Cartesian formula.
They share the ordinal representation; the arithmetic is separately tested.
There is no finite-to-infinite extrapolation. The test output is not a Lean
proof or independent validation of every transfinite argument.

## Status boundaries

The article is unrefereed. No formal proof assistant was run. A focused
literature check is insufficient to establish world-first novelty. The
results close the stated ordinal-fiber height gap in the pinned repository
and supply additional structural consequences. Width, general iteration,
and unrestricted infinite-state extensions are not claimed.
