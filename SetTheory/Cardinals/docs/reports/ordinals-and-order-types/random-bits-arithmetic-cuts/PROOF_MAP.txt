PROOF MAP AND HYPOTHESES
========================

Ambient setting
---------------
M is a fixed countable model of PA. Nonstandardness is explicitly required
for the nontrivial category, induction-failure, and standard-cut statements.
A cut is an external nonempty successor-closed initial segment; M itself
is allowed. No additive or multiplicative closure is imposed.
All probability sums are external countable real sums.
The formula and all codes are internal; code enumerations are external.

Main chain
----------
Elementary binary coding -> deterministic coding cut and finite-change
invariance -> arbitrary-bias probability classification -> prescribed-cut
realization -> diagonal countable marker construction -> Boolean spectra.
The bounded-induction equivalence uses the deterministic coding interface;
the three-regime theorem combines it with the probability classification.

1. Arbitrary biases (Theorem 3.1; pairwise extension Theorem 8.1).
   Cut(P) = Cut(b) intersect S(min(p,1-p)) almost surely.
   Summable deviations are finite by the first Borel-Cantelli argument.
   Divergent minority mass makes every fixed internal trace null; the
   countability of the model permits the union over codes and endpoints.
   For pairwise independent bits, a mismatch second-moment bound replaces
   factorization. Mere fair marginals do not suffice.

2. Every successor cut (Theorem 4.2).
   Increasing cofinal markers in the cut, plus positive summable residual
   noise, realize any desired cut by a full-support nonatomic product law.
   Any prescribed FINITE family of probabilities strictly between 0 and 1
   can be retained. This does not match arbitrary correlated joint data.

3. Countable conjunction universality (Theorem 5.2).
   Any inclusion-monotone family C_S, indexed by nonempty finite subsets
   of the standard natural numbers, is realizable. Necessity and the
   Boolean classification use probabilities bounded away from 1.
   Realization can use arbitrarily small positive biases, with every bit
   in the entire countable array jointly independent.
   The marker recursion puts a new point above relevant finitely many
   constraints INSIDE its own target cut, not above all previous points.

4. Every finite Boolean observable (Theorem 5.5).
   Its coding cut is the intersection of C_S over its minimal nonempty
   supports that change its all-zero output. The lower bound uses disjoint
   exact-support events; the upper bound is a union bound. The argument
   works for nonmonotone functions as well as monotone ones.
   The vanishing-bias refinement preserves all conjunction constraints.

5. Induction (Theorems 6.3 and 6.6).
   Cut(P)=M iff bounded induction holds with the exponential function named.
   Proper Cut(P) also violates a bare-language Sigma_1(P) induction instance
   via beta coding. An infinite externally locally finite predicate can
   satisfy bounded induction with named exponentiation while violating
   bare-language Sigma_1(P) induction. No assertion of bare Delta_0(P)
   failure follows merely by deleting the name for exponentiation.

6. Topology and stability (Section 7).
   Nonstandard-endpoint coding events are dense meager F_sigma sets.
   The exact standard-cut fiber is comeager. Every other cut fiber is
   dense meager and still supports a full-support probability law.
   The coding-cut map is exactly Baire class two. The Pi^0_3 fiber bound
   is an upper bound, not a completeness claim for all cuts.
   Locally summable mismatch errors preserve the cut under any coupling.

7. Finite theory (Sections 8 and 9).
   Catalog ranking and source-coding asymptotics are classical. Exact
   rational enumeration checks the stated small finite cases independently.
   The sharp pairwise atom bound is classical and explicitly attributed.
   The K-times-one-atom bound for catalogs is not claimed sharp for K>1.
   The summability theorem uses prefixes of ONE fixed infinite bias law;
   p_N=lambda/N is instead a triangular array with a new law at each N.
