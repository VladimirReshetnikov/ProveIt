# Six Sheets, Three Escapes

**Complete Fiber Geometry and Explicit Normalization of a Five-Dimensional Keller Map**

Research article prepared for Vladimir Reshetnikov's ProveIt program, 24 September 2026.

## Read the article

- `Six_Sheets_Three_Escapes.pdf` is the compiled article.
- `Six_Sheets_Three_Escapes.tex` is its complete, independently compilable LaTeX source.

The article develops the fiber theory of the existing map F_6 in Shuhong Gao,
*Counterexamples to the Jacobian conjecture in dimensions greater than two*,
arXiv:2608.00222v1, Section 4.5.1. That version leaves its full fiber
stratification to further work. The map itself, its nonzero constant Jacobian,
and its generic degree are NOT new results of this article.

## Results developed here

The main results are a uniform simple-root chart through the exceptional
hyperplane; an exact criterion for every geometric fiber and the spectrum
{0,1,2,3,4,6}; a closed omitted surface isomorphic to G_m x A^1; an explicit
smooth normalization free of rank six over target space; the two-component
nonproperness locus; geometric S_6 monodromy and an arithmetic S_6
specialization; a general quadratic-contraction normalization lemma; and
real fiber cardinalities {0,1,2,3,4}.

The finite normalization is described by just six basis elements and three
multiplication rules. The source is its open subset obtained by deleting
ramification and three unramified boundary components.

These are original derivations relative to the inspected sources, with
written proofs and exact supplemental checks. This is an AI-assisted research
draft prepared with ChatGPT, not a peer-reviewed publication or a Lean/Rocq
formalization. No claim of exhaustive literature priority is made. See
`SOURCE_AUDIT.md` for provenance and scope.

## Reproduce the checks

Tested with Python 3.13.5 and SymPy 1.14.0:

```sh
python -m pip install -r requirements.txt
python code/verify.py
```

The completed run passes 63 exact checks. It uses rational polynomial rings,
finite fields, modular powers/gcds, and exact Sturm sequences. There is no
floating-point arithmetic, random sampling, network call, or external data
in the verification run.

The written proofs establish the universal chart, normalization, and geometric
theorems. Finite round-trip tests are only supplementary sanity checks, not
substitutes for those proofs. This is a computer-algebra certificate and does
not claim a proof-assistant kernel trust boundary.

## Files

`code/build_map.py` constructs the actual polynomial map using sparse exact
arithmetic. It checks the two stages of denominator cancellation. Its
standalone invocation writes data to `data/`.

`code/verify.py` performs all checks and exposes `fiber_polynomial`,
`simple_part`, `reconstruct`, and `section`. The supplied reconstruction
function accepts exact rational roots; the article gives the identical
formulas for arbitrary algebraic roots. Unsupported or multiple roots raise
errors rather than being silently approximated.

`data/map_coefficients.json` encodes the five coordinate polynomials. A term
is `[exponent_vector, rational_coefficient_string]`; exponent order is
`(x,y,z1,z2,z3)`.

`data/normalized_discriminant.json` encodes the 179 terms of H in the
coordinate order `(c,A,B,D,K)`, where `K=E+B^2-A*D`.

`data/verification_report.txt` is the output of the completed run.

The coefficient files are regenerated by the verifier from the formulas;
they are not accepted as trusted input. `SHA256SUMS.txt` records the delivered
file checksums. The archive contains no third-party paper PDFs or font files.
