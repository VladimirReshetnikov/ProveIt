# Fixed alphabet accessible automata

Research article and reproducibility package, 2 October 2026.

## Scope

`accessible-automata.pdf` is the 16-page article; `accessible-automata.tex` is its editable source. The objects are rooted accessible complete deterministic transition structures with a fixed labeled alphabet of size k>=2, up to state isomorphism, with no accepting-state subset. The cases k=2 and k=3 are OEIS A006689 and A006690.

The theorem concerns every fixed inverse-power order at each fixed k. The leading equivalent is classical. Bibliography and attribution are in `SOURCES.md`; publication priority remains qualified because the full 1978 Korshunov survey was not obtained for direct inspection. Numerical coefficients are high-precision evaluations, not interval certificates. The inverse theorem's constants and starting thresholds are existential.

## Requirements

- Python 3.10 or later; tested with Python 3.12.14
- mpmath 1.3.0 and SymPy 1.14.0, listed in requirements.txt
- Bash for the convenience scripts
- For PDF rebuilding: pdfTeX/LaTeX, kpsewhich, and standard TeX Live packages providing article, fontenc, lmodern, geometry, amsmath, amssymb, amsthm, mathtools, booktabs, array, microtype, hyperref, enumitem, and fancyhdr
- Poppler is optional, only for rendering PDF pages for inspection

Install Python dependencies in your own environment with `python -m pip install -r requirements.txt`. The scripts do not install software or access the network.

## Verify and replay

From the extracted package directory:

    python code/verify_manifest.py
    bash replay.sh
    bash build.sh
    python code/verify_manifest.py

Set `PYTHON=/path/to/python` when needed. The full replay regenerates coefficients through order 5 for k=2,3,4, repeats k=2 at 90 digits, tests exact identities, computes exact counts through n=500, checks a separately derived c3, validates successive-order errors, and demonstrates model inversion. It also tests exact imaginary phases and preservation of exponentially small corrections at k=500. Runtime can be several minutes. Outputs stay within the extracted package: logs in `.replay/`, numerical data in `data/` and `checks/`.

To calculate another fixed order:

    python code/generate_coefficients.py --k 2 --order 8 --digits 100 --output data/custom.json

The CLI accepts order>=1; order zero is the closed form c0=c. Increase `--digits` and/or `--guard-digits` and compare runs at higher orders. Interpolation reconstructs a polynomial whose degree bound is proved in the article; it does not fit counting-sequence data. The code uses an exact four-cycle for powers of i and adds working precision proportional to k to retain exponentially small rho. These measures do not guarantee every requested digit for arbitrary k/order.

`build.sh` uses only this package and installed TeX resources. It creates a local `.build/` directory, sets local TeX cache/config/format paths, and generates a LaTeX format and font map if needed. No prebuilt workspace cache is included or required. SOURCE_DATE_EPOCH is fixed for reproducibility; PDF bytes can vary with TeX/font versions. The supplied PDF is readable without TeX.

## File guide

- `code/generate_coefficients.py`: finite saddle, Gaussian, uniform-moment, Fuss-Catalan and two-boundary coefficient algorithm
- `code/validate_generated_coefficients.py`: exact-count residual and precision-stability tests
- `code/verify_numerical_precision_regressions.py`: exact phase and large-fixed-k numerical regressions
- `code/verify_identities.py`: 355 exact identity checks
- `code/derive_coefficients.py`: symbolic c1/c2 derivation
- `code/check_expansion.py`: exact-count comparisons through n=200
- `code/compare_independent.py`: comparison of separate coefficient derivations
- `code/inversion_demo.py`: Lambert/Newton model inversion at exact count values
- `checks/verify_exact_counts.py`: exact recurrence, exhaustive restricted-growth, kernel and large-n checks
- `checks/check_third_order.py`: separate cumulant-based c3 calculation, using checks/verification.json generated by the preceding program
- `data/` and `checks/*.json`: numerical reference results regenerated by replay
- `code/verify_manifest.py`: standard-library checksum verifier
- `code/make_archive.py`: path-safe archive and manifest builder
- `VERIFICATION.md`: tested scope and results
- `SOURCES.md`: public bibliography, attribution and literature limitation
- `MANIFEST.sha256`: checksum of every shipped file except the manifest itself

Finite checks support the derivation but do not prove its asymptotic remainder. The proof is in the article. Neither convergence of the infinite correction series, growing-alphabet uniformity, an exhaustive novelty claim, nor an unqualified ceiling rule follows from the numerical data.
