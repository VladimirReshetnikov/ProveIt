# Attribution, provenance, and contribution boundary

Prepared for Vladimir Reshetnikov and incorporation into ProveIt, using the
source snapshot `f0ae4e0991ca44a7bb4e5671d42e33d775e48035`.

The literal K215 machine, its ZFC-refutation calibration, the original
native-window/Pell compiler, the blank-input interface, and the earlier
signed-domain and root-amalgamation arguments are inherited ProveIt work.
They are not claimed as new contributions of this package. Original notices
and MIT No Attribution licenses are retained in `upstream/`.

New work in this package comprises the four-coordinate reduction to twelve
positive supplied variables, the special rational auxiliary-Pell integrality
argument used in that reduction, the explicit norm circuits and size
certificates, the 26-integer domain conversion, the optional lower-degree
weight, and the restricted 5,280-tile coefficient adapter with its denser
anchor geometry. The package includes independent mathematical and finite
implementation audits of those constructions.

This is OpenAI-assisted mathematical research. New material is supplied
under the same MIT No Attribution terms as ProveIt. Existing source excerpts
retain their original attribution and are listed by path and hash in
`SOURCE_MANIFEST.json`.

No global minimum, new universal variable bound, new end-to-end Lean/Rocq
proof, actual K215 halting witness, or proof of Con(ZFC) is claimed.
