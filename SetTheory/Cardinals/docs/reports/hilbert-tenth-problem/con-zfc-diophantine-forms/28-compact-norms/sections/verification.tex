\section{Verification, reproduction, and integration}

\subsection{What was checked}
For the twelve-variable construction, the independent verifier does not
import either circuit emitter. It checks the complete generic norm identity
coefficient by coefficient against a product of conjugate quartic factors.
The comparison contains 295 monomials. It also verifies the 1649-monomial
expansion of the uniform leading form \eqref{eq:leading12}, keeping all
four fixed ports symbolic. Thus exact degree is certified for every valid
positive $\beta$, rather than inferred from a few numerical substitutions.
The final product and sum-of-squares tails are checked structurally.
Twenty-four signed integer assignments and twenty-four rational assignments
independently check the core formulas and shared-computation substitutions.
The ledger validates every operand, topological order, and liveness.

For nine variables, the verifier regenerates the shifted quartic, checks all
346 weighted coefficient records, and authenticates the immutable parent
JSON. A symbolic leading-term computation handles the actual cancellation
inside the final norm and verifies the nonzero coefficient
$441\cdot2^{192}$. Using the four materialized ports, it evaluates the exact
bounded recipes for the index constants modulo three primes. Direct finite
digit sums are compared with the generated DAG: twelve outputs and 312
named intermediates agree. The structured bounds and signed finalizer also
receive the finite edge-case checks recorded in Section~\ref{sec:nine-improved}.

The coefficient reproduction rebuilds all 943 tiles from the literal 430
K215 actions, checks the helical control data, verifies the compact support
geometry with 69,230 basis-convolution identities, and independently
reconstructs all four binaries byte for byte. The complete new mathematical
proofs are reviewed separately. These finite checks detect implementation
and transcription mistakes; they are not substitutes for quantified proofs.

\subsection{Reproduction commands}
From the extracted package directory, run
\begin{verbatim}
python3 reproduce.py
\end{verbatim}
The default run uses only the Python standard library and the bundled gzip
coefficients. It regenerates the two constructions in a temporary directory,
compares their exact JSON with the delivered circuits, runs the independent
verifiers, and writes the run receipt to \texttt{verification/REPRODUCED.json}.
It does not require a GitHub connection or a full ProveIt checkout.

To rebuild and independently audit the coefficient bytes as well, run
\begin{verbatim}
python3 reproduce.py --rebuild-coefficients
\end{verbatim}
This creates about 5.3 MB of raw coefficient data temporarily. No large
Jones index integer is materialized. To compile the article using a normal
TeX installation, run
\begin{verbatim}
pdflatex -interaction=nonstopmode -halt-on-error report.tex
pdflatex -interaction=nonstopmode -halt-on-error report.tex
\end{verbatim}
The included PDF was rendered and visually inspected after compilation.

\subsection{Suggested integration}
The archive is a self-contained package suitable for a new numbered
subdirectory of the existing report. It includes a root README, the LaTeX
article and compiled PDF, the three twelve-variable circuits, the
nine-variable DAG and exact coefficient recipes, builders, independent
verifiers, the complete compact coefficient binding and gzip payloads,
mathematical review notes, and source provenance.

Existing reports should retain their identities. The new twelve-variable
form supersedes the inspected twelve-variable products on degree and
operation count together, while the old unrestricted-integer reductions,
low-degree lifts, and 67-operation form remain relevant. The new nine-variable
form is a further degree/operation tradeoff, not an improvement in variable
count. Its immutable quartic source carries historical metadata, and the
current binding is given explicitly in \texttt{INSTANCE.json}.

\subsection{Formalization status}
The K215 endpoint and the repository's parametric Jones reduction belong to
existing formal developments. The new polynomial specialization, its new
root bounds and finalizer, the complete native compiler, and the composed
endpoint are not presented here as newly checked Lean or Rocq theorems.
The delivered theorem is an ordinary proof formalizable in ZFC, using the
identified inherited mathematical results. This distinction is preserved in
every verification receipt and in the recommended README language.

\section{Further research questions}

\paragraph{1. Remove the new degree bottleneck.}
The weight reduction exposes the degree-$134$ term $H^2e$ as the dominant
part of the twelve-variable norm. Can an auxiliary-root translation, a
different elimination order, or an ordinary rather than normalized strong
equation reduce this term while retaining sound rational-to-integer
recovery? Any proposed improvement must check zero denominators and all
algebraic conjugates before assuming the desired roots are integers.

\paragraph{2. Transfer the new norm to fewer unrestricted integers.}
The present proof uses $h>0$ to get $k>2R$. The existing 26-integer lifts
allow signed $h$ and recover its sign later. Is there a different initial
majorant or a staged reconstruction that permits the new low-degree norm
on that larger domain? Substituting the old positivity encoding into this
new proof without addressing that dependency would be unjustified.

\paragraph{3. Generalize the signed divisibility finalizer.}
Lemma~\ref{lem:signed-divisor-combiner} uses a polynomial majorant for
$|v/u|$ to avoid squared divisibility. Can comparable quotient bounds
replace squaring in other explicit relation-combining constructions, and
which degree or circuit savings remain after the cost of the majorant is
included? The lemma itself does not depend on the K215 compiler.

\paragraph{4. Improve the structured nine-variable majorants.}
The new $V_1$ has the same degree as $\sqrt{|a_1|}$, so a further major
degree improvement cannot come from a lower-degree uniform polynomial
majorant for unrestricted growth in the same variables. It may instead
come from altering the underlying ratio representation, the finalizer, or
the quartic parent. Can a lower-dimensional or lower-height quadratic
parent reduce the fixed exponent $5^{33}$ while preserving a fully explicit
coefficient recipe?

\paragraph{5. Mechanize the new lemmas and the interface boundary.}
The signed-divisor lemma has a short elementary proof, including its
zero-sum radical case, and is a natural first formalization target. The
generic norm identity and rational Pell saturation lemma are similarly
reusable. A clean formal interface should expose the signed-root and weak
outer-unit hypotheses explicitly, so that future algebraic reductions can
be verified without reopening the native compiler proof.

\paragraph{6. Optimize coefficient geometry independently of algebra.}
The compact Wang tuple already gives concrete, portable base coefficients.
Can the support and clause geometry be shortened further while preserving
all rotation, carry, population and rank-adjustment properties? This is an
independent finite optimization problem. A smaller verified whole tuple can
then be substituted into both new formulas without changing their degrees
or operation ledgers.

\paragraph{7. Maintain a reproducible comparison frontier.}
The present repository contains several genuinely different optimization
objectives. A machine-readable catalogue with domains, exact-degree
certificates, operation models, coefficient bindings and proof dependencies
would make future claims easier to compare. In particular, comparison
scripts should never silently count an abbreviation as a new unknown or
count a large fixed exponent as one arithmetic gate.
