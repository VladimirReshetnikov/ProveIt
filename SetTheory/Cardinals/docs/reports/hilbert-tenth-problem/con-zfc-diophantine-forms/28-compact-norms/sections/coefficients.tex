\section{One complete fixed coefficient tuple}
\label{sec:coefficients}

\subsection{The selected existing construction}
Both new formulas use the complete compact Wang943 tuple from package 19
\cite{p19}. This is the smallest materialized base tuple in the inspected
catalogue. Its base is
\[
 \rho=2^{625},\qquad d_0=5^{10}=9\,765\,625,\qquad
 B=2^{d_0}=\rho^{15625}.
\]
The four ports are exactly
\begin{equation}
 \beta=B-1,\qquad K_0=D_C+BD_R,\qquad M_C,
 \qquad M_F=M_F^{\rm native}+B-1.
 \label{eq:tuple}
\end{equation}
The last shift is indispensable. Substituting the unshifted native mask
into a formula whose port is named $M_F$ changes the polynomial and is not
just a change of notation.

The complete tuple is reused through package 19's proved adapter for the
inputless arithmetic interface. The common theorem requires the actual
native language, carry bounds, anchor synchronization, population equation,
and rank-adjustment property, not merely four integers with selected
congruences. Reproducing those finite data checks supports the adapter;
the ordinary soundness and completeness proof remains part of the cited
mathematics.

\subsection{A bounded recipe for all four integers}
Here is a compact exact description. The ordered tile list
\texttt{compiler/wang943\_tiles.json} contains 943 quadruples of west,
north, east and south edge colors. It is determined by the literal K215
table, with Start first, Forbidden second, and the remaining tiles in
lexicographic order. The tile classes have counts
\[
 430+2+2+488+4+4+3+9+1=943:
\]
working transitions, halt loops, headless copies, directed head arrivals,
finish tiles, initialization tiles, reset tiles, seam tiles, and the
forbidden tile. Their full finite rule and the marked-periodic-tiling proof
are preserved in \texttt{compiler/WANG943\_COEFFICIENTS.md}.

Put $A_c=1024$. For a tile $t_i=(x_{i0},\ldots,x_{i3})$, define
\[
 c_i=1+\sum_{s=0}^3\sum_{j=0}^9
       \operatorname{bit}_j(x_{is}+512)A_c^{1+10s+j}
           +\sum_{j=41}^{44}A_c^j.
\]
The extra bit encodes occupancy. The four ten-position copy groups have
starting positions $1023,1013,1003,983$, in west/north/east/south order;
at copy position $e_s(j)$ put $c_{e_s(j)}=A_c^{1+10s+j}$.
The dummy positions $1063,1064$ have coefficient zero. At the four anchors
$1095,1096,2195,3296$, put $A_c^{41},A_c^{42},A_c^{43},A_c^{44}$,
respectively. Let $\mathcal E$ be this set of 989 selector, copy, dummy
and anchor positions. Set
\[
 \mu=A_c-2+\sum_{j=1}^{44}(A_c-3)A_c^j
                      +2^{450}(2^{78}-1).
\]
The compact layout is
\begin{align*}
 D_C={}&\rho^{30}+\rho^{5517}+\rho^{1100}+\rho^{2200}
       +\sum_{e\in\mathcal E}c_e(\rho^{7631-e}+\rho^{8733-e}),\\
 D_R={}&\rho^{5497},\\
 M_C={}&B-1-\sum_{e\in\mathcal E\setminus\{1\}}\rho^e
                                     -2\rho^{1063},\\
 M_F^{\rm native}={}&4+\mu(\rho^{7631}+\rho^{8733})
       +\sum_{j=0}^{9}\rho^{1013+j}
       +\sum_{j=0}^{9}\rho^{6520+j}+\rho^{2195}+\rho^{3296}.
\end{align*}
All exponents are fixed nonnegative integers. These finite formulas and the
fixed tile list completely determine \eqref{eq:tuple}.

\subsection{Why the compact layout is compatible}
The inherited adapter proves that the two clause bands have disjoint sets
of possible rotation hits, so at least one is clean. The two anchors have
only the intended simultaneous alignment. The tested targets have exactly
their specified convolution contributions; unintended overlaps at untested
positions are harmless. The largest unshifted convolution position is
$12029<15625$, and the radix $\rho=2^{625}$ exceeds the complete carry
threshold. These facts are checked on the actual finite support, rather
than inferred from stronger spacing conditions belonging to older layouts.

The population and residue invariants are
\begin{align*}
 \operatorname{popcount}(M_F^{\rm native})&=989,&
 \operatorname{popcount}(M_C)&=d_0-989,\\
 M_C&\equiv2\pmod4,&M_F^{\rm native}&\equiv4\pmod8,\\
 2D_C-D_R&\equiv4\pmod5.
\end{align*}
The last residue is a unit; it supplies the dummy adjustment needed for
canonical rank congruences. Padding of the marked halting tableau supplies
the prescribed positive witnesses. Because the complete arithmetic
interface is preserved, the new root combination and the unchanged
quartic parent may both use the tuple. This does not authorize combining
one port from this tuple with a port from an older T4 tuple.

Each raw SHA-256 equals the published value in package 19. The full hashes

The nine-variable coefficient recipe applies further finite operations to
these same four integers. Its $z_\star,y_\star$ and 346 coefficient records
are exact fixed constants, but they have not been expanded into binary
integers. The 20,260-byte figure describes the four base ports only; it is
not the expanded height or file size of every coefficient in $F_9$.

The compiler and machine data are reused work. Their source revision,
original paths, license information, and copied proof notes are retained.
The new contributions of this report are the algebraic weights, signed
finalizer, resulting circuits and degree certificates, and their combination
with this existing complete tuple.
