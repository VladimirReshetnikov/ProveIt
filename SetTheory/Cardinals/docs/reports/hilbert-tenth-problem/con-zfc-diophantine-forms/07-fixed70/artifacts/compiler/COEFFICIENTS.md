# Exact finite specification of the fixed compiler coefficients

These formulas determine ordinary integers, once and for all. No Diophantine
unknown occurs in an exponent, summation bound, predicate, or choice in this
file. The enormous integers are given in compressed form, as is customary
for coefficients such as `2^(10^100)`. Here the compression also uses explicit
finite sums over a precisely specified finite list of windows.

The literal machine, tile ordering, window predicate, and window ordering
are in `k215_one_sided.py`, `finite_window_constants.py`, and
`NORMALIZATION.md`. In particular, there is no unspecified compiler index,
infinite search, or assumption about which computations halt in this recipe.

## 1. Fixed scalar layout

Let

```
a = 4366,
k = 113175624520853754856480928432,
ell = 97,
A = 2^ell,
p = 56587812260426877428240418274,
m = 113175624520853754856480967730,
U = 113175624520853754856480993923,
H = 5771956850563541497680530703172,
T1 = 11883440574689644259930504379381,
T2 = 17994924298815747022180478051224,
g = 21050666160878798403305464887146,
b = 5^44,
L = 5^45,
d = b*L = 5^89,
V = 2^b,
B = V^L = 2^d.
```

The variable name V in this file denotes a fixed inner radix, not the vertical
boundary tile and not an auxiliary Pell variable. H denotes a fixed layout
shift, not the horizontal boundary tile or a Pell modulus.

For reproduction, `ell = max(2,bit_length(k+1))`,
`m0 = 2ell+30a+8`, `p = max(0,ceil((k+9a+4-m0)/2))`,
`m=m0+2p`, and `U=m+6a-3`. Then

```
H = 51U+3a+1,
T1 = 105U+4a+2,
T2 = 159U+4a+3,
g = 186U+4a+4.
```

The coefficient source uses the least power of five L satisfying
`L >= 213U+4a+5`. For this instance, the modified compiler's radix target is
dominated by `2mu+4`; its exact bit length is

`ell*(9a+4+p)+2 = 5489017789261407110539324384486`.

The least power of five at least this number is b above. The dominance check
in `compact_layout` proves it using a strict upper bound on the other term,
without constructing mu or any giant power. These choices are exactly those
of the retained modified75 compiler, rather than new unproved numerals.

## 2. The finite window list

Write `w_0,...,w_(k-1)` for the exact list generated by `allowed_windows`:
Start, End, then every other allowed 3-by-3 tile-index tuple in lexicographic
order. Tile indices range from 0 through 4365. Coordinates of a window are
listed in row-major order, with rows and columns numbered 0,1,2.

For `r,c` in `{0,1,2}` and `0 <= s < a`, set

```
j(r,c,s) = 1 + 3ar + ac + s,
e(r,c,s) = k + 3a + (2-r)*3a + (2-c)*a + s.
```

There is exactly one dummy position,

`e_* = k+12a = 113175624520853754856480980824`.

Define the finite native position set

```
E = {0,...,k-1}
    union {e(r,c,s): r,c in {0,1,2}, 0 <= s < a}
    union {e_*}
    union {U,3U,9U,27U}.
```

Its members are pairwise distinct and its cardinality is `m+1`. The values
of all members and all summation bounds are fixed by the preceding integers.

Define positive coefficients c_e on all positions except the dummy:

```
c_i = 1
      + sum_{r=0}^2 sum_{c=0}^2 A^j(r,c,w_i[3r+c])
      + sum_{h=1}^4 A^(9a+h)                     (0 <= i < k),
c_e(r,c,s) = A^j(r,c,s),
c_U = A^(9a+1), c_3U = A^(9a+2),
c_9U = A^(9a+3), c_27U = A^(9a+4),
c_e_* = 0.
```

Finally put

`mu = A-2 + sum_{j=1}^{9a+4+p} A^j`.

This mu includes the fixed zero-expression padding clauses. Omitting these
clauses would change both the mask population and the compiler contract.

## 3. Fixed convolution coefficients and masks

Define

```
DC0 = V^(3a) + V^(H+a) + V^(8U) + V^(24U)
      + sum_{e in E} c_e*(V^(T1-e)+V^(T2-e)),
DR = V^H.
```

All displayed exponents are nonnegative fixed integers. Evaluate the fixed
integer `2DC0-DR` modulo 5, and set epsilon to 1 if its residue is zero and
to 0 otherwise. Then

```
DC = DC0 + epsilon*V^g,
K = DC + B*DR.
```

This one-bit choice is a finite arithmetic computation on already defined
fixed integers. It is neither a Diophantine unknown nor a halting query.
For example, it may be evaluated by modular exponentiation and the finite
sums above without expanding V. Since b is a power of five, `V=2 mod 5`;
the correction guarantees `2DC-DR != 0 mod 5` exactly as in the retained
compiler. The complete finite specification includes this choice even though
the numerical value of epsilon is not separately materialized in this packet.

The old field mask is

```
MF0 = mu*(V^T1 + V^T2)
      + sum_{r=0}^1 sum_{c=0}^2 sum_{s=0}^{a-1} V^e(r,c,s)
      + sum_{r=0}^2 sum_{c=0}^1 sum_{s=0}^{a-1} V^(H+e(r,c,s))
      + V^(9U) + V^(27U).
```

The modified half-binomial compiler uses

```
MC = B-1 - sum_{e in E, e != 1} V^e - 2V^e_*,
MF_native = MF0 + 4,
MF_shifted = MF_native + B-1.
```

In particular, MF_shifted is not a native one-cell mask. Confusing it with
MF_native is an incorrect coefficient substitution. Both MC and MF_native
are strictly between 0 and B-1; their binary populations add to d. The
modified masks have `MC=2 mod 4` and `MF_native=4 mod 8`.

## 4. Numerals supplied to the fixed-input polynomial

The required ports can be supplied by these exact integers:

```
beta = B-1,
K = DC+B*DR,
MC as above,
MF = MF_shifted,
W0 = V*B^2 = 2^(2*5^89 + 5^44).
```

If a retained version of the source uses the raw input-size constant, it is
`2d = 2*5^89`. Any additional aliases such as B, beta+1, or K+1 are ordinary
fixed numerals formed from this same list. The main source in the report
specifies precisely which aliases it uses and how arithmetic gates are counted.

The endpoint W0 inserts the unique End selector at cyclic cell 2. This is the
specialization of the former ordinary input x=1, whose doubled helical distance
is 2. It gives an I-run of length 3 and a unary initialization with four 1s.
The normalized machine then starts the literal blank K215 computation.

## 5. Why this is an ordinary Diophantine specification

The set of windows is finite and every membership test is a fixed lookup or
Boolean test on finite integers. The only powers and sums in this file occur
in the definitions of fixed coefficients. Substituting these fixed integers
into the finite arithmetic circuit of the report produces one integer
polynomial, or its stated finite polynomial system, with no remaining
variable exponent, finite-sequence quantifier, or bounded universal test.

The distinction is practical: the decimal coefficients and all k windows
cannot reasonably be materialized. Their finite recipes nevertheless fix
every coefficient uniquely and terminate in principle. The arithmetic gate
counts in the report follow the repository's convention that fixed numerals
are inputs; they do not measure the bit length or the construction cost of
these gigantic numerals.
