# A literal fixed 229-generator semigroup in SL4(Z)

Research construction, 2026-10-03. This is a separate matrix-semigroup theorem.
It neither instantiates a Higman embedding nor establishes a subgroup,
ordinary-affine Diophantine input interface, arithmetic-operation bound, or
optimal generator count. No inverse generators are adjoined.

## 1. Exact theorem and input convention

Let S be the nonempty-product semigroup generated by the 229 **literal integer
4 by 4 matrices** in `data/semigroup.json`, in the stated order. Let U be the
Neary--Woods 15-state two-symbol machine transcribed in `data/u15_table.json`.
The blank is 0; the states A,...,O are u1,...,u15; 1 is the paper's b and 0 is c.
The only undefined transition is J1=(u10,b), which is accepting halting.

For any two finite binary words ell,r, initialize U in state A, with its head
at coordinate zero scanning 0. Cell -i-1 contains ell[i], cell i+1 contains
r[i], and every unlisted cell is 0. Thus both halves are nearest-head-first.
There are two blank tails, never a nonblank infinite periodic background.

The released executable map `compiler.from_tape(ell,r)` returns an integer
matrix T(ell,r) in SL4(Z), and

    U halts on (ell,r)  iff  T(ell,r) belongs to S.                 (1)

Membership in this one fixed S is many-one r.e.-complete. The executable
deliverable materializes every stage of (1). The effective arbitrary-TM/input
to (ell,r) compilation is the published Neary--Woods mathematical dependency,
not software claimed to have been reimplemented here. Section 8 states this
dependency precisely. Bounded tests are supplementary evidence, not a proof
of universality or of nonhalting.

## 2. U15 to a directed semi-Thue system

Use the 20-letter alphabet

    Sigma = {0,1,A,B,C,D,E,F,G,H,I,J,K,L,M,N,O,[,],X}.

Here X is a fresh cleanup symbol and the terminal word is the one-letter
word X. A live finite configuration is

    [ l q a r ]

where l,r are binary words, q is an ordinary state, and a is the scanned bit.
The input word is w(ell,r) = [ reverse(ell) A 0 r ]. Unrepresented cells
beyond either boundary are zero.

For each defined transition (q,a)->(b,R,p), include the three rules

    qa0 -> bp0,    qa1 -> bp1,    qa] -> bp0].

For each defined transition (q,a)->(b,L,p), include the three rules

    0qa -> p0b,    1qa -> p1b,    [qa -> [p0b.

The boundary rules extend exactly one newly visited blank cell. In addition,
include

    J1 -> X,
    0X -> X,  X0 -> X,  1X -> X,  X1 -> X,
    [X] -> X.

All 93 rules have nonempty left and right sides. They are literally listed
in the packet, with transition-cell/context metadata. The count is

    29*3 + 1 + 4 + 1 = 93.

**Simulation invariant.** Starting at a live configuration, exactly one
machine/halting rule applies. Indeed there is exactly one state symbol,
whose scanned bit determines the transition; the bit immediately in the
movement direction or its adjacent boundary determines exactly one of the
three rules. No other state symbol or X is present, so no foreign transition
or cleanup can apply. A defined transition produces precisely the next live
configuration, with a zero cell inserted only on crossing an endpoint.

At J1 the only rule is J1->X. Its result is [l X r]. Thereafter only adjacent
tape erasures and the final [X]->X rule can apply. Every such rule decreases
word length. All tape letters can be erased, and [X]->X then reaches X.
Conversely X cannot occur at all before J1->X is used. This proves

    U halts on (ell,r)  iff  w(ell,r) ->* X.                       (2)

No reverse simulation, premature cleanup, rejecting halt, or unrestricted
boundary erasure is included. The symbol X itself has no outgoing rewrite.

## 3. Rewriting to a fixed constrained correspondence equation

Introduce a fresh separator #. Form these 114 inner tiles (h_i,g_i):

* (a,a) for every one of the 20 letters a of Sigma
* (v,u) for each of the 93 directed rules u->v
* (#,#), the last tile

Both sides of every tile are nonempty. Only the separator tile contains #.
For a word s of tile indices, concatenate its h and g sides in order. For
every w in Sigma*, including malformed words, the exact equivalence is

    w ->* X  iff  there exists s with w# h(s) = g(s) X#.           (3)

The tile word s may be empty. If w=X, choose s empty.

**Forward direction.** A single directed step alpha u beta -> alpha v beta
is represented by the copy tiles spelling alpha, the rewrite tile (v,u),
the copy tiles spelling beta, and the separator tile. Concatenate these
blocks for a derivation w=w0->w1->...->wd=X. Then

    h(s)=w1#...wd#,    g(s)=w0#...w(d-1)#,

and the equation follows. The authored witness compiler implements this
construction, checking every requested rule and position before use.

**Reverse direction.** Write s=s0 # s1 # ... # sr, where these displayed #
symbols mean occurrences of the separator tile and each sj contains none.
Comparing the final segments of the equation forces h(sr) empty. Since all
nonseparator tile sides are nonempty, sr is empty, hence g(sr) is empty.
If r=0, s is empty and w=X. Otherwise comparing successive #-segments gives

    w=g(s0), h(s0)=g(s1), ..., h(s(r-2))=g(s(r-1)), h(s(r-1))=X.

For each j, the tile word sj partitions g(sj) into successive nonempty
pieces. Each piece is either copied or replaced by the right side of a
directed rule. These disjoint replacements can be serialized left-to-right:
after each replacement, perform the next one after the already replaced
prefix. Thus g(sj)->*h(sj). Concatenation gives w->*X. This reasoning allows
zero-change copy-only batches and does not assume every intermediate word
is a simulated machine configuration. For well-formed input, Section 2
already proves every possible rewrite remains sound.

## 4. Explicit free-group matrices

Put

    P = [[1,2],[0,1]],  Q = [[1,0],[2,1]],
    E_j = Q^(-j) P Q^j = [[1+4j,2],[-8j^2,1-4j]].               (4)

All these matrices have determinant one. P and Q freely generate a rank-two
free group, by the standard ping-pong proof: on the real projective line use
the disjoint sets |x|<1 and |x|>1. For nonzero integer n,
P^n maps the first set into the second, and Q^n maps the second into the
first. The infinite cyclic subgroups have infinite order, so the ping-pong
lemma gives their free product. In particular this is a matrix-group
embedding, not just an embedding of positive words.

For completeness, any distinct conjugates E_j freely generate: a nonempty
reduced word can be collected into E_(j1)^(n1)...E_(jk)^(nk), where every
n_i is nonzero and adjacent indices differ. Its expansion is

    Q^(-j1) P^(n1) Q^(j1-j2) P^(n2) ... P^(nk) Q^(jk).

Every interior Q exponent is nonzero; the P exponents are nonzero. Omitting
possibly empty endpoint Q powers leaves a nonempty reduced P,Q word.
This argument includes j=0. It does not infer independence merely from the
fact that subgroups of free groups are free.

In the upper 2 by 2 block, map the listed Sigma letters successively to
E_1,...,E_20, and # to E_21. Call the induced injective word/group map Phi.
In the lower block, independently use t=E_0=P and x_i=E_i for 1<=i<=114.
Their numerical use in a separate block makes these independent codings.

## 5. The fixed numerical generator list and variable target

For every tile i, use

    A_i = diag(Phi(h_i), x_i),
    B_i = diag(Phi(g_i)^(-1), t^(-1) x_i^(-1) t),
    C   = diag(Phi(X#)^(-1), t).

For each query word w, use

    T(w) = diag(Phi(w#)^(-1), t).                                (5)

The inverse in B_i is the inverse of the **entire** word matrix Phi(g_i).
Its order is not changed to a forward concatenation of letter inverses.
All inverses are explicit integral determinant-one 2 by 2 inverses; all
4 by 4 matrices are block diagonal and belong to SL4(Z).

The semigroup has exactly 2*114+1=229 distinct generators. For example,
the lower words x_i, t^(-1)x_j^(-1)t, and t are mutually distinct in the
free group, proving distinctness even when an upper block repeats. The
compiler also checks numerical pairwise distinctness. The JSON file expands
every integer; no undefined word, presentation, universal compiler,
symbolic parameter, or existential generator is left in the fixed list.

## 6. Marker normal form: the unrestricted semigroup enforces the constraint

**Lemma.** A positive generator word has lower block t if and only if it is

    A_(i1) ... A_(id) C B_(id) ... B_(i1)                         (6)

for some d>=0 and some indices. No ordering constraint is imposed externally.

**Proof.** Work in the free group on t,x1,...,x114, which Section 4 embeds
faithfully into the lower matrices. The homomorphism taking the t exponent
sum sends every A and B to 0 and C to 1. A positive word with value t thus
contains exactly one C.

The kernel of the exponent-sum homomorphism has free basis

    y_(i,h)=t^h x_i t^(-h),  i=1,...,114, h in Z.

One direct justification groups a reduced y word into maximal runs with
equal h. Within each run the x word is nonempty and reduced. Between runs
there is a nonzero t power. Expanding the conjugates therefore leaves a
nonempty reduced t,x word. Conversely scanning any word of total t exponent
zero and recording the current height before each x letter expresses it in
these y letters.

Scan the positive generator word, writing its lower group value as K t.
Before the unique C the current height is 0; after C it is 1. Consequently:

* an A_i before C contributes y_(i,0)
* a B_i before C contributes y_(i,-1)^(-1)
* an A_i after C contributes y_(i,1)
* a B_i after C contributes y_(i,0)^(-1)

The equation Kt=t means K is the identity. A height -1 letter has only
negative occurrences, with no possible inverse occurrence; a height +1
letter has only positive occurrences. Free reduction cannot remove any
such letter. Therefore there are no B before C and no A after C. What
remains is a positive word in the y_(i,0), followed by a negative word.
It reduces to the identity exactly when their indices match in reversed
order, proving (6). The converse follows by immediate cancellation. This
proof uses no cyclic rotation, designated start occurrence, hidden inverse
generator, bounded product length, or uncharged constrained-word condition.

## 7. Upper-block equation and many-one reduction

For a product (6), put s=i1...id. Its upper block is exactly

    Phi(h(s)) Phi(X#)^(-1) Phi(g(s))^(-1).

Equality with T(w)'s upper block Phi(w#)^(-1) is equivalent, by multiplying
on the left by Phi(w#) and on the right by Phi(g(s)) Phi(X#), to

    Phi(w# h(s)) = Phi(g(s) X#).

Both sides are positive words; injectivity from Section 4 makes this the
literal word equation (3). Together with the marker lemma,

    T(w) in S  iff  w->*X.

Section 2 now proves (1). The empty inner word is realized by the nonempty
one-generator product C exactly for w=X. Hence the nonempty-semigroup
convention creates no missing zero-step case. The main U15 inputs start in
A and never equal X, so their accepting witnesses require real simulation.

## 8. Precise universality dependency and r.e.-completeness

Published source: Turlough Neary and Damien Woods, *Four Small Universal Turing
Machines*, Fundamenta Informaticae **91(1) (2009), 123--144**,
DOI **10.3233/FI-2009-0036**. The publisher's record is

https://journals.sagepub.com/doi/10.3233/FI-2009-0036

The author-hosted reading PDF used to inspect tables and proofs is

https://dna.hamilton.ie/assets/dw/NearyWoods-FI09.pdf

That PDF retains draft pagination 105--126 and draft DOI metadata. Its
printed-page locators, including Table 16 on printed page 121 and input
conventions on printed page 112, are **draft-specific**, not published
page numbers. The published bibliography above is independently confirmed
by the publisher and the author's publications page at
https://dna.hamilton.ie/woods/. The distributable archive links this
copyrighted reading source rather than including the PDF cache.

The effective halting-preserving chain is Lemmas 2.1 and 2.2 and Theorem 2.1
(ordinary deterministic TM -> clockwise TM -> bi-tag), then Definition 3.1,
equations (3)--(4), Tables 1--3, the correctness argument of Theorem 3.1
with the paragraph immediately following it, and Section 3.5/Table 16.
Theorem 3.1 is explicitly numbered for U9; the subsequent paragraph extends
its correctness argument to the remaining machines. It should not be cited
as a separately stated U15 r.e.-completeness theorem.

These are effective finite encodings. On the proper source configurations
from the clockwise construction, the bi-tag simulation preserves halting.
For U15 its finite tape is P b [c] D, where P is the encoded finite program,
D the encoded data, and the brackets here mark the initial scanned c.
Thus our halves are ell=reverse(binary(Pb)), r=binary(D). Both tails are c.
The sole undefined transition in Table 16 is (u10,b); the later prose
mentioning (u10,c) conflicts with the table and is not used to alter it.

It follows from the published effective simulation that the finite-tape
halting language H_U is many-one hard for the ordinary halting set K.
Direct simulation of the fixed table makes H_U r.e. Thus H_U is many-one
r.e.-complete, not merely undecidable. Equation (1) gives H_U <=m Mem(S).
Finally, enumerate nonempty words over the fixed 229 matrices and compute
their integer products. This semidecides equality with any target matrix,
so Mem(S) is r.e. Therefore Mem(S) is many-one r.e.-complete.

The delivered source compiles finite U15 inputs to targets. It does not
implement the arbitrary-TM-to-clockwise-to-bi-tag compiler. The prior Report
16 loader did not implement that compiler either. The published effective
construction is sufficient as a mathematical proof dependency; it is not
advertised as an executed software stage or a polynomial-time reduction.

The broader matrix mechanism is corroborated by Halava--Harju--Hirvensalo,
*Undecidability Bounds for Integer Matrices using Claus Instances*, IJFCS
18(5) (2007), 931--948, Section 2 and Section 7, Lemma 3/Theorems 15--16:
https://users.utu.fi/harju/articles/HHH_ClausInst.pdf

https://www.csc.liv.ac.uk/research/techreports/tr2008/ulcs-08-005.pdf

## 9. Exact resources and encoder complexity

The emitted ledger gives: 15 states, 2 tape symbols, 29 defined transitions,
20 semi-Thue letters, 93 rules, 114 inner tiles, 229 distinct 4 by 4 integer
generators. The largest absolute generator entry is 63,038,000, requiring
26 magnitude bits (27 bits suffice with a separate sign). Across all 3,664
matrix-entry slots there are 1,831 nonzero entries and 21,372 magnitude
bits using bit_length(abs(entry)), counting zero as zero magnitude bits.
This last figure is a declared census, not a compressed file-size claim.

Let n=|ell|+|r|. The input word has n+4 letters; w# has n+5. The encoder
uses n+5 exact 2 by 2 multiplications by fixed E_j matrices, followed by
one determinant-one inverse (two sign changes and one diagonal-entry swap)
and block assembly. The implemented inverse additionally checks determinant
one with two variable-integer multiplications and a subtraction; these do
not change the bit bound below. For 1<=j<=21 the maximum row-sum norm is
3611<2^12. Thus every
target entry has magnitude bit length at most 12(n+5)+1. It has O(n) output
bits. Iterative multiplication by fixed integers has O(n^2) bit-operation
cost with elementary linear-time fixed-integer arithmetic and O(n) working
bits, apart from the stored input/output. This is a bit bound in finite-tape
length, not in arbitrary source-program length and not in simulation time.

Far-end zero padding can give different target matrices for the same
physical infinite tape. The equivalence (1) holds for either spelling;
injectivity on semantic tapes is unnecessary for a many-one reduction.

## 10. Verification and limits

All new Python uses the standard library and was authored locally. The only
old machine-readable dependency is the small pinned transition JSON data;
no upstream Python was imported or executed. The checker independently
transcribes the compact transition table, uses a tape-list semantics oracle,
and uses an independent Leibniz 4 by 4 determinant and generic product.

Normal and Python -O checks cover:

* all 229 determinants and numerical pairwise distinctness
* 6,750 live local configurations, including both boundary directions
* all cleanup derivations from 225 binary contexts of length at most three
* 64,036 matched rewrite/TM steps across 225 bounded 300-step runs; 12
  inputs reach the halting cell in those prefixes
* every word of length at most eight over A1,A2,B1,B2,C: 488,281 words;
  exactly 15 have lower block t, all with the proved normal form
* an actual main-interface accepting input ell=011, r=empty, with a
  14-step rewrite derivation, 94 tiles and a literal 189-generator product
  equaling the encoded target in all sixteen entries
* 100 random finite-tape encodings, invalid-input rejection, and zero-step X
* an 8,192-bit standalone CLI input and exact decimal-output round trip,
  beyond Python's default decimal-conversion digit limit

The accepting witness is saved in `evidence/accepting-witness.json`.
These finite checks cannot decide nonhalting inputs or replace the proofs.
No computer-assisted formal proof checker has been used.
