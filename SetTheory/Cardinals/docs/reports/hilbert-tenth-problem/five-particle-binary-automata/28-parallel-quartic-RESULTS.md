# Bounded certificate milestone

The direct, paid emitter is implemented for every validated finite source, fixed
mass n, fixed whole-step horizon T, and either direction. The all-input proof and
independent audit find no correctness blocker. The result is an exact-endpoint
quartic relation with zero or one complete **natural** witness per external fiber.

## What is concretely implemented

- Direct source/mode/pair/marker/orientation slots, without an F-template array
- Literal type-specific exactness and finite guard tables in both orientations
- Fixed bitonic anchor sorting and nearest-neighbor all-type isolation
- Deterministic isolated-key compaction into floor(n/2) fully defined lanes
- Complete hypothetical rediscovery, including newly born candidate types
- Type+anchor prospective equality, deliberately ignoring orientation
- Simultaneous endpoint transport, fixed coordinate sorting, and 2T block gates
- Canonical external signed pairs, strict sortedness, and endpoint equations
- Explicit quadratic residual emission and ordinary sparse quartic expansion
- Exact register, residual, monomial-occurrence, coefficient-bit, and byte ledgers

checks that the delivered sparse quartic is exactly the literal square-sum

witness, and that all 1,494 upward witness-coordinate mutations are rejected.
It passed in both interpreter modes.

X={-118,-112,0,18,23} is fixed by the new whole rule. E has one isolated raw key;
its hypothetical swap creates key (1,0). P has one isolated raw key; its

## Boundaries of the result

This is not fixed arity over unknown/unbounded T, not real-witness uniqueness,
and not a claim about infinite supports. The current endpoint acceptance is
exact Y equality, not an implicitly supplied halting predicate. The proof is
source-level mathematics plus code audit, not a proof-assistant result.

Testing is exhaustive only over the four named finite coordinate domains.
The larger corpus is targeted. The supplemental certificate runs use all n<=3
horizon fixtures, plus mass-5 horizons T<=1. Mass-5 T=2 and T=3 fixtures are
available as independently generated CA answers but are not claimed as completed
certificate tests in this bounded milestone. An initial oversized supplemental
run was stopped; the deliberately bounded final suites were then rerun normally
and under -O. No failed computational result is being treated as a pass.

No universal-size polynomial was emitted. The concrete n=2 polynomial is fully
expanded and serialized. Larger measured instances were fully emitted in memory
as residual systems and checked there; their expansion is available through the
compiler but was not claimed to have been stored. Counts are current costs, not
minimality or a numeric improvement over differently scoped previous work.

A is a signed-register assignment count, not a bounded-fan-in elementary-addition
count. Residual monomial occurrences and coefficient bits charge wide affine
sums. Inherited source metadata uses `source.radius` for the legacy ordered bound
and `source.factors` for endpoint-template types; current ledgers separately name
`new_rule_radius`, `legacy_ordered_radius`, and `endpoint_type_count`. For the
minimal moving source the radii are 1,698 and 21,144 respectively.

One inherited fixture provenance path was replaced by a portable reference label.
`fixture-provenance-rebind.json` records the old/new fixture digests and identical
canonical non-provenance payload. Actual tested fixture digests are preserved in
receipts; the source/code/polynomial data did not change. Final provenance uses
stable reference identifiers only.

## Standalone-verifier metadata repair

The final verifier now rejects Boolean/floating-point arities, mismatched
external/total variable counts, and input/target metadata not bound to the
canonical natural prefix. Recognized artifact schemas/formats are checked.
37 negative regressions cover these bindings in both interpreter modes.
This is a verifier reporting/binding repair; the polynomial and compiler
formulas remain unchanged. The earlier sealed packet is preserved as v1.
