# Independent review: explicit complete-witness height bound

Reviewed 2026-10-03. The original compiler packet was read only. This review audits the actual operation families and supplies an explicit source/mass-computable bound. The tag/L1 recurrence is a valid supplementary check, but is not needed to define the primary constant below.

## 1. Explicit constants and conclusion

Let `R>=0` bound the magnitudes of the n coordinates entering one genuine block. Write

- `b=B3`, `ell=floor(n/2)`, and `F=metadata.factors` (the total endpoint-type count)
- `K_E,K_P` for the actual occurrence-slot counts stated in the original proof
- `P_B=2^ceil(log2 K_B)` when `K_B>0`, and `P_B=1` when `K_B=0`
- `H_star=2[b+max(Z+J,3b+1)]`
- `a=14+12ell`
- `d=(10+6ell)b+Z+J+2H_star+n(J+1)+F+P_E+P_P+10`

Here P_E and P_P are **padded occurrence widths**, not counts of endpoint types. F has the latter role. All constants are finite and computable from the validated source and n without a coordinate bound or horizon.

Every natural auxiliary coordinate generated by either complete block is at most

    a R + d.

The same bound covers both accepted external sortedness scans. Thus one may use

    H=a+d,
    C(s,n)=(4b+1)(a+d).

For an accepted horizon-T computation, every complete-witness coordinate is at most `C(s,n)(A+T+1)`. This bound is conservative; no optimality is claimed.

## 2. Semantic facts needed for the bounds

All actual selectors and mask factors are Boolean. Selected live fields stored as signed pairs remain bits: the positive component is the selected bit and the negative component is zero. Counts, ranks, arities, and indices can depend on the coordinates, but their height bounds are independent of R.

A signed assignment of value z creates natural components each at most |z|. A comparator with signed difference d creates a bit at most 1 and a slack at most |d|. Equality uses a second comparison shifted by one; every comparator estimate below includes this shift where applicable. Canonicality residuals and the final polynomial squares allocate no extra product registers.

Validated metadata gives all source gaps at most D, shifts of magnitude at most 1, `S+D<=b`, and `L<=b`. On a raw pass whose input coordinates have magnitude at most rho:

- old descriptor sites have magnitude at most rho
- new descriptor sites have magnitude at most rho+b
- anchors have magnitude at most rho+1
- arities are 2 or 3; padding sites are zero

The dispatch/commit heads `z +/- S` followed by a source gap are included because `S+D<=b`. Endpoint marker shifts and reverse anchors are included because their shifts have magnitude at most 1.

Travel masking confines t to its source interval even on rejected slots. Consequently every raw ID is in `[0,F-1]`: the behind/ahead segments partition their fixed E moving-mode ID segment; phase-near offsets partition their fixed P segment; interaction, direct, and home IDs are their literal source IDs. Missing lane IDs are zero. This uses only the actual arithmetic masks, not prospective acceptance.

## 3. Complete raw-pass bound

For any raw input list with magnitude bound rho, all raw-pass witnesses are bounded by

    M_raw(rho) = 2rho + 3b + Z + J + n(J+1) + F + 10.

The following bounds account for every raw assignment/comparator category:

| Category | Bound |
| --- | --- |
| Materialized gap or coordinate difference | `2rho` |
| Travel/gap/distance-condition comparison slack, including equality shift | `2rho+b+1` |
| Exactness interval comparison slack | `2rho+3b+2` |
| Detector interval comparison slack | `2rho+Z+J+1` |
| Hit count | `n` |
| Count/arity equality or singleton/count comparison slack | `n+4` |
| Individual detector offset term | `J` |
| Sum of detector offset terms | `nJ` |
| Selected detector class | `J+1` |
| Truth-table class equality slack | `J+2` |
| Masked travel value | `b` |
| Type ID | `F` |
| Boolean register or comparison bit | `1` |

A detector flag is true only when its corresponding signed offset is in `[0,J]`. This proves the term bound even for multiple hits. If the count is one the selected class is in `[0,J]`; otherwise the class is exactly `J+1`. All table cells and rejected classes are still evaluated. No bound in this section assumes that the raw slot is live or that the input list has distinct coordinates.

## 4. Sorting, isolation, and lane-routing bounds

For the initial raw pass use rho=R. Sorting only selects existing live bits, anchors, and slot indices. Its repeated selects do not enlarge their semantic magnitudes.

| Category | Bound |
| --- | --- |
| Sorted live signed components | `1` |
| Sorted anchor magnitude | `R+1` |
| Sorted slot-index magnitude | `P_B` |
| Live-field equality comparison slack | `2` |
| Anchor-order comparison slack | `2R+3` |
| Adjacent-anchor isolation comparison slack | `2R+2+H_star` |
| Prefix rank | `P_B` |
| Rank/presence/rank-routing comparison slack | `P_B+n+1` |
| Slot-routing equality comparison slack | `P_B+1` |
| Routed ID / arity magnitude | `F` / `3` |
| Routed old / new coordinate magnitude | `R` / `R+b` |
| Routed anchor magnitude | `R+1` |

Padding values `0,0,-1` and missing-lane descriptor zeros obey the same bounds. Rank bounds use the padded occurrence count and do not assume that all isolated keys can be routed. The actual block-specific isolation constant is at most H_star. Route comparisons and all selected branches are included.

## 5. Hypothetical passes, prospective comparisons, and final transport

For each original x and one lane, a hit is a Boolean conjunction. Its arity-comparison slack is at most 3 and its coordinate-equality slack is at most `2R+1`. Each displacement assignment has magnitude at most

    |hit*(new-old)| <= 2R+b.

There are exactly three padded displacement terms for one lane. Therefore every one-lane hypothetical coordinate has magnitude at most

    rho_h = 7R+3b.

This bound requires neither a live lane nor a successful prospective test, and does not use disjointness. Coordinate sorting preserves rho_h; its strict-order comparison slacks are at most `14R+6b+1`.

The complete after-raw pass is therefore bounded by

    M_raw(rho_h)
      = 14R+9b+Z+J+n(J+1)+F+10.

All after-pass slots, including rejected ones, are covered. For the comparisons between an after descriptor and its lane descriptor:

| Category | Bound |
| --- | --- |
| Near-neighborhood comparison slack | `8R+3b+2+H_star/2` |
| Anchor equality comparison slack | `8R+3b+3` |
| ID equality comparison slack | `F+1` |
| Own/other/relevant/selected Boolean value | `1` |

The near bound uses `q<=H_star/2`. Both equality comparisons are included.

Final transport uses ell lanes, hence at most `3ell` displacement terms per coordinate. Its assigned coordinate magnitude is at most

    R_f=(1+6ell)R+3ell b.

Final sorting preserves R_f and has comparison slack at most

    2R_f+1=(2+12ell)R+6ell b+1.

Final hit and displacement assignments have the same bounds as the hypothetical transport. The largest R coefficients in the whole audit are 14 and `2+12ell`, both at most a. Every displayed constant term is at most d. Signed components, Boolean values, and every comparator slack are therefore bounded by `aR+d`.

## 6. True-boundary reset and ordinary binary length

The existing endpoint theorem and geometric movement bound give `R_star=A+4bT` for every genuine block input and accepted final endpoint. Apply the one-block bound separately at each boundary. Do not iterate the coarse hypothetical-coordinate bound across blocks.

The initial and target sortedness scans use differences of magnitude at most `2R_star+1`, also at most `aR_star+d`. The accepted-target condition is essential; no assertion is made for arbitrarily large rejected targets.

Since `aR_star+d <= (a+d)(R_star+1)` and `R_star+1 <= (4b+1)(A+T+1)`, the stated C follows. With the exact emitted witness count

    W(T)=4max(n-1,0)+T(w_E+w_P),

the **sum of ordinary binary coordinate lengths**, using one bit for zero, is at most

    W(T) ceil(log2(C(s,n)(A+T+1)+2))
      = O_{s,n}((T+1)log(A+T+2)).

No claim about other tuple encodings is needed. For n<2 the tuple is empty for every T. At T=0 only external order witnesses remain. A zero slot count with n>=2 does not remove the pair-gap scratch created before the family loops.

## 7. Supplementary recurrence and independent execution

The Section 6 tag/L1 recurrence in the companion proof is also sound. Its tag-0 bit bounds rely on the separately proved Boolean invariant; degree two alone is insufficient. The fresh-block transfer is legitimate because every true boundary coordinate is a single canonical signed pair and later blocks read no discarded scratch.

Additional checks performed during this review:

- All six original source/fixture hashes match the normal audit receipt
- Complete fresh-block operation streams match 24 actual blocks in forward/reverse horizon-2 certificates: increment-right mass 3, direct mass 2, and empty-source mass 3
- Renaming only boundary pairs and newly allocated local variables preserves every operation kind and polynomial; allocation totals and full certificate operation totals match
- Normal and optimized receipts agree on hashes, all block entries, all endpoint entries, and the summary: 66 emitted blocks, 332 complete block assignments, 72 accepted endpoint assignments

The explicit majorant above is an all-family mathematical derivation. These finite checks corroborate implementation binding; they do not independently reprove the original automaton endpoint theorem or substitute for the structural induction.
