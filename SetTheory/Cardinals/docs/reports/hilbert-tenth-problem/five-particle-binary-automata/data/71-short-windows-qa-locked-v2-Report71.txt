                                                    Abstract

          The conservative binary five-particle compiler admits a further reduction in its sufficient radius.
      Keep pair exactness L = 3D + 4, but shorten triple exactness from 3b + 1 to b = 4D + 5 in both its
      edge and phase blocks. We define both new blocks on every bi-infinite binary input, prove that
      each is a number-conserving involution, and prove all-anchor recognition equivalence and exact
      forward and inverse agreement on the entire admissible doubled micrograph. The resulting rule has
      sufficient radius 76D + 105 + 3J, where D = 2m + 4p and J is the source’s finite counter-class cut.
      A changed-output-support argument improves this to 76D + 104 + 3J for the very same rule; the
      boundary-read predicates are unchanged.
          The inherited universal-source ledger gives 38 722 713, or 38 722 712 with the support refinement.
      Its source table remains absent and universality remains an inherited premise. Explicit malformed
      inputs distinguish each new block and the composition from both predecessors. Pair-padding
      counterexamples concern only the unchanged templates and selector with an enabled nonzero
      branch. There is no new-rule evaluator, arbitrary-input arithmetic certificate, minimum-radius or
      priority claim.

2     Source, geometry and complete endpoint families

2.1   Source interface and admissibility

The source is a finite deterministic partial injection on Q × Z2≥0 . A branch e : q → q ′ selects side
v ∈ {−1, +1} and its corresponding counter index j (left for v = −1, right for v = +1), updates
that counter by ∆ ∈ {−1, 0, +1}, and has domain predicate Ge . Enabled outputs are natural.
Branch domains at each control and actual branch images at each target control are disjoint on all
natural-counter IDs, including unreachable ones. The exact image predicate is

                               Ie (c′ ) = Ge (c′ − ∆ej ) ∧ (c′ − ∆ej ∈ Z2≥0 ).

Both Ge and Ie depend only on classes 0, 1, . . . , J, > J of the two counters. There is a designated halt
control with no outgoing branch. Other controls may be stuck; such blocking is not designated halting.

modes are homes Hq and outbound/inbound modes Oe , Ie for each nonzero branch. Give all signed

                          Enc(q, cℓ , cr )σ = {−(Z + cℓ ), 0, Z + cr , S, S + d(Hqσ )}.

Lemma 3.1. The map Es is a number-conserving involution on {0, 1}Z , with radius at most 3b + r =
13b + 10 + 3J.

Proof. Distinct selected centers are farther apart than H and have disjoint write intervals. If a radius-b
recognition window met writes at two selected centers u, w, then |u − w| ≤ 4b ≤ H, a contradiction.
Every post-update recognition word therefore equals its old word or the word after exactly one selected
Tu . That update passed (16); hence
                                             R(Es x) = R(x)
at every integer anchor on every bi-infinite input. This covers initially absent anchors, dense malformed
configurations, and potential cooperative births or deaths.
Now take any recognized isolated anchor u, whether selected or rejected. Every other selected w has
|w − u| > H = b + r, so its write misses Ir (u), which contains all control and prospective data. The
complete status analysis is:
 1. An isolated rejected anchor’s determining word is unchanged, so its failed prospective test remains
    failed.
 2. A selected anchor sees precisely its own Tu image. The equality Tu2 = id interchanges the two
    recognized sets in (16), preserving success.
 3. A nonisolated recognized anchor stays nonisolated by recognition-set invariance; it remains blocked
    even if its guarded types change.
 4. An absent anchor remains absent by the same invariance.
 5. A recognized isolated identity control passes prospectivity harmlessly. Its protected radius-r word
    prevents a new control from appearing there on the second application.
Thus the entire selected-anchor set is invariant. Each selected control sees only its own prior image on
reapplication and undoes its disjoint change. Therefore Es2 = id.
Equal-weight changes on disjoint blocks conserve finite particle number. A finite-support input permits
only finitely many nontrivial changes, since each uses an original occupied site in its disjoint block;
finite support is preserved. No total on infinite inputs is needed.
For locality, a changed output coordinate has a writing anchor within b. Isolation reads H + b about
that anchor and dominates radius-r control/prospectivity. Thus R(Es ) ≤ b + (H + b) = 3b + r. Finite
Boolean tests and translation covariance make this a binary CA. Closed intervals and exclusion at
distances ≤ H are used throughout.

Lemma 3.2. The map Ps is a number-conserving full-shift involution with radius at most 6b.

Proof. Selected writes are disjoint. A radius-b candidate window cannot meet two of them, because
then their centers would be at distance at most 4b. Each post-update candidate predicate consequently
sees no rewrite or exactly one individually prospectively stable rewrite. Thus the complete typed
candidate set is invariant, including initially absent keys and keys of other types.
For every isolated candidate, any other selected write misses its radius-3b prospective-decision window:
the center distance is greater than 4b, the write radius is b. An isolated rejected key therefore keeps
its failed prospective test. A selected key’s own involution interchanges the sets in (17), preserving
success. Nonisolated keys stay blocked and noncandidates stay absent. Hence the entire selected-key
set is invariant and a second application reverses the same disjoint involutions. Equal weights give
finite conservation and finite support as in Lemma 3.1.
Isolation reads HP + rP = 5b about a candidate anchor; prospectivity reads 3b. A possibly writing
anchor lies within b of an output site, so R(Ps ) ≤ 6b. No uniqueness theorem is assumed on malformed
phase inputs: multiple same-anchor types are competing keys and are rejected by typed isolation.
This differs deliberately from raw-anchor coalescing in the edge block.


4     All-anchor admissible agreement

Full-shift safety alone does not establish simulation preservation. We now show that shortening
exactness creates no admissible match at any integer anchor, then classify every intended edge and
phase case.


4.1   The close pair and the only possible singleton

Every admissible configuration has exactly one occupied pair at distance at most D, the head. Head-
marker distances are at least S − D = D + 2 > D, and marker-marker distances are at least Z. Every
literal endpoint likewise contains a unique close pair; every triple’s singleton has distance greater than
D from both head sites. This includes the reverse behind endpoint at distance L + 1 and the shifted
endpoint interaction.
Thus any new raw match, at any anchor, must use the actual head pair. Its distinct signed gap fixes
the signed mode and endpoint orientation; any displayed singleton must be an actual marker. Every
triple singleton lies within L + 1 of the actual head anchor: near-travel distances lie in S, . . . , L + 1,
and all interaction distances are S. Since

                                              Z > 2(L + 1),

at most one actual marker can support any triple using this head. This common head-to-marker
bound excludes cross-template competition; bounding only one template’s diameter would not suffice.
For a fixed endpoint and actual head pair, the offsets force the invariant anchor. Ordinary triples
anchor at the singleton marker. Only the reverse endpoint uses an anchor one site from its current
singleton, as detailed below. Other markers are therefore at least Z from an ordinary anchor, or Z − 1
from the old endpoint anchor. Since

                                           Z − 1 > 3b + 1 > b,

4.2   Homes and multiple raw branch types

At Hq+ only outgoing dispatch/direct forward endpoints contain its gap, all at the origin. At Hq− only
incoming commit/direct reverse endpoints contain its gap, again at the origin. No moving free or
travel template uses a home gap. Hence raw edge anchors are empty or a singleton, although several
raw types may occur there.
At plus homes the full guarded set is empty or a singleton by source-domain disjointness; at minus
homes it is empty or a singleton by exact actual-image disjointness. Class reads are faithful: counter
markers encode the classes while the head lies inside b < Z. The reverse image guard includes existence
of natural pre-counters and therefore enters only an enabled subdivision. Replacing it with the forward
guard would not justify this conclusion. If there is no enabled incident edge, every control Tu is identity
even when raw branch types occur at the origin. Direct zero-update edges retain Ge = Ie .

5.1   A support refinement for the very same rule

Every phase endpoint lies in IL+D = Ib−1 . For a positive near endpoint the extremum is t + d =
L+D = b−1, including the equality t = L, d = D. The two negative-side head sites lie in [−L, −S +D],
and their singleton is at zero, so the full negative near support lies in [−L, 0]. Home endpoints lie in
[0, S + D] and free endpoints in [0, D]. Thus every complete phase endpoint word has zeros at both
−b and b.
On any non-endpoint word the transposition is identity; on either endpoint word the two boundary
zeros remain zero. Therefore no phase transposition can change an output site at either boundary, on
any input. The triple predicate nevertheless still reads those two zeros; the transposition still reads
the complete Ib word. No predicate, transposition, isolation threshold HP = 4b or prospective test has
changed.
Eligibility still reads radius 5b about its anchor. Only the anchors that can actually change a specified
output site now lie within b − 1 rather than b. The output is determined by its old bit and those
possible changes, proving for the same map

                    R(Ps ) ≤ 6b − 1,     R(Fs ) ≤ 19b + 9 + 3J = 76D + 104 + 3J.                     (18)

This is an upper-bound refinement, not a smaller-window definition or a minimum-radius theorem.
The simple common-support observation does not apply to edge endpoints: a positive reverse-behind
endpoint at t = L, d− = D reaches L + 1 + D = b.
