# Report 18: portable cellular-clock domination reproducibility

This package extends the sealed Report 17 offline replay with the complete
cellular-clock proof, independent audit, and **six mandatory executable stages**.
The optimized literal source is unchanged: SHA-256
`fa61d06178d718511232a80a05e02192d940fde3c273f0c202f0623253b2ade3`.
There are 122,622 controls and 141,561 literal branches.

## Offline replay

Use Python 3.9+ on a Unix-like system (tested with Python 3.12). Only the Python
standard library is required. No network, sibling release, paper PDF, third-party
text extraction, or absolute research-data path is required. Allow about 0.5 GB
of temporary disk and 1 GB of free memory. From this extracted directory run:

```sh
python -B verify_manifest.py
python -B run_checks.py
```

All 20 stages run in **separate fresh normal and `-O` copies**, using isolated
Python startup and the inherited offline audit guard. Every mandatory scientific
input has a known SHA-256 pin. All seven baseline tables are regenerated from the
original pinned generator and compared byte-for-byte with mandatory historical
identities. The old 54 MB table pair is not duplicated in the delivery.

The aggregate compares all 28 generated receipts/traces byte-for-byte across
modes and against their canonical delivered counterparts. Mode information is
recorded by the aggregate; portable audit receipts deliberately use a
mode-independent schema. Absence and corruption of every mandatory scientific-input pin,
including proof/reference/source-manifest and baseline pins, network construction,
and external data reads must be rejected. No delivered file is modified and
no logs or Python caches are generated by the default aggregate command.
The final JSON printed to the terminal is the fresh result;
`replay-receipt.json` records the release-author replay.

The standard-library guard checks reproducibility restrictions. It is not a
security sandbox for malicious Python/native code. Interpreter runtime files
remain available; external research inputs do not.

Individual stages can also be run with `python -B script.py`, or `python -B -O
script.py`. They regenerate their named canonical outputs in this package. For
non-mutating verification use the aggregate. Release authors alone can run
`python -B run_checks.py --record`, then `python -B write_manifest.py` to update
canonical receipts and the exact inventory. Neither is needed by readers.

## Provenance and scope

All Report 17 mathematical material, scientific tables, builders, loader,
compiler references, and orientation notes are retained. `PORTABILITY.md`
explains inherited and new adaptations. `historical/report18-adaptations.json`
contains exact reversible line edits with original and portable hashes; replay
reconstructs each original and verifies it against a pinned producer manifest.
`historical/source-manifests/` contains the byte-identical original manifests.
Their excluded files are historical identity records, not required replay inputs.
`historical/source-manifest-inspection.json` records the separate packaging-time
inspection of those original inventories. No historical PASS replaces a live
check. The outer `manifest.json` covers every delivered regular file except
itself and rejects extra files and symlinks.

The source hashes, proof hashes, reference-only scope, and exact pin catalog are
in `PROVENANCE.json` and `verify_pins.py`. The proof and original audit describe
their producer workspace; the portable route below uses the single bundled
source plus a pinned regenerated baseline, never sibling directories. References
to original receipts/logs in the unchanged audit describe its historical run;
new receipts are freshly computed by the mandatory aggregate.

CA microedges, the old startup's 126,594,455,831,808,973,674,445,902 microedges,
and all whole-prime CA clocks are **theorem-derived**, not CA executions.
No gate array, truth table, billions-step CA trajectory, full old literal
startup, universal polynomial, or proof-assistant formalization is supplied.
Theorems establish unbounded claims; executable finite checks corroborate them.
The primary universality and four-mass lower-bound results retain their inherited
