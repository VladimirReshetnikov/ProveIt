# Portable cellular-clock checks

See the package-parent `README.md` for the complete offline command. Every
script here is mandatory in both isolated replay modes. Run `python -B
../run_checks.py` from this directory, or `python -B run_checks.py` from its
parent. Individual commands regenerate their canonical receipt files here.

The proof and independent audit notes are sealed original bytes. The programs
have exact, manifest-verifiable portability edits documented in the parent
`PORTABILITY.md` and `historical/report18-adaptations.json`. References in the
unchanged scientific notes to the frozen producer directories, original
receipts, optional comparisons, or logs describe the producer's original run.
The portable package requires every comparison, uses only bundled pinned data
and the mandatory regenerated baseline, and ships no development logs.

Whole-prime CA clocks are theorem-derived exact integers. Executed literal-row
checks and five-counter traversals are identified separately; no CA trajectory
or gate array is executed.
