## Reproduce without changing this packet

Python3 and the standard library suffice. From any working directory:

    python3 -B /absolute/path/replay.py --verify-only
    python3 -B /absolute/path/replay.py

The first command verifies exact manifest inventory and hashes. The second runs seven own-code arithmetic checks/generators in a temporary working directory, compares exact JSON receipts, checks six optimized-mode rejections and the recoder's optimized-mode support, and then verifies that every source byte is unchanged. It never executes the included ant recipe code, upstream Lean, a saved ant schedule, a dense periodic board, or the strict astronomical constant prefix. The MANIFEST.json hash should itself be authenticated from the enclosing reviewed report/archive.

Individual own-code entry points print JSON on stdout. `bridge_dag.py --emit`, `compose_initialization.py --pair-dag data/pair_inline-dag.json --emit`, and `polynomial_initialization.py --pair-dag data/pair_inline-dag.json --emit` stream the literal source, which has over2.3million lines; ordinary replay does not store that expansion. Composition/degree/polynomial `--output` options require a fresh file outside the resolved source tree and never overwrite. The recoder uses its own documented read-only `--verify-dir` or fresh `--output-dir` contract.
