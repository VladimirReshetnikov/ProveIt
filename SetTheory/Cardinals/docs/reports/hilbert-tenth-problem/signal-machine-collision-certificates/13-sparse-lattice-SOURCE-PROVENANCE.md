# Source provenance and scope

## Mathematical report and implementation

The report and reproduction programs were prepared with AI assistance for this research project. They are ordinary mathematical arguments and executable checks, not a machine-checked formal proof. The preferred compiler uses a single natural one-hot selector over the full list of local input rows. A separately implemented factorized compiler is retained only as a clearly labeled baseline.

The core compiler was independently compared coefficientwise before release. The audited source hash was `0e28de61b1ed7ef98a59b06440d09146f35d9a3b9b7923433fbf568706c5217f`. The release changes one documentation sentence to point readers to the accompanying report rather than a development filename; executable code is unchanged. The release coefficient audit records the actual packaged hash and was rerun on those bytes. The same Morita compiler is intentionally present as `replay/morita/audit.py` and `replay/core/morita_audit.py`, so both standalone entry points have relative imports.

The source-specific row implementation and finite tests are independent transcriptions of the cited mathematical construction. The table CSVs are generated by that implementation; they are not the authors' original software. The completed doubling table is nonuniversal. The other completed table is a deliberate unsafe-source counterexample. Completion pairs unused inputs and outputs separately within each conserved-mass fiber.

## Primary sources

1. K. Morita and K. Imai, Number-conserving reversible cellular automata and their computation-universality, RAIRO Theoretical Informatics and Applications 35 (2001), 239–258: https://www.numdam.org/item/ITA_2001__35_3_239_0/
   The source interface is Theorem 3.6 and its rules. Rule (8.2), printed page 249, has a conservation-violating plus sign. This release uses the minus sign forced by the stated target encoding. No author-issued erratum is asserted. Target increment counter selection is also made explicit.
2. K. Morita, Universality of a reversible two-counter machine, Theoretical Computer Science 168 (1996), 303–320: https://doi.org/10.1016/S0304-3975(96)00081-3
   The report's reachable-legality preservation argument is an explicit deduction through the history and prime-encoding constructions, not a claim that the paper states an independent totality theorem. Valid encodings are essential.
3. B. Durand, E. Formenti, A. Grange, Z. Róka, Number conserving cellular automata: new results on decidability and dynamics, DMTCS Proceedings AB (2003), 129–140: https://dmtcs.episciences.org/2301/pdf
4. E. Formenti and A. Grange, Number conserving cellular automata II: dynamics, Theoretical Computer Science 304 (2003), 269–290: https://doi.org/10.1016/S0304-3975(03)00134-8
   These provide classical bounded-diameter/generalized-shift context. No new classification theorem is claimed.
5. C. Haase, S. Kreutzer, J. Ouaknine, J. Worrell, Reachability in Succinct and Parametric One-Counter Automata, CONCUR 2009: https://people.mpi-sws.org/~joel/publications/onecounter09.pdf
   Related one-counter context, not attribution of the exact mass-two CA theorem.
6. A. Alhazov and K. Imai, Particle Complexity of Universal Finite Number-Conserving Cellular Automata, CANDAR 2016, 209–214: https://doi.org/10.1109/CANDAR.2016.0045 ; publisher abstract https://ieeexplore.ieee.org/document/7818615
   The report relies only on the verified abstract-level five-particle and radius statements. Full-paper optimality and reversibility claims were not verified. Numerical-state and weighted-alphabet models are distinguished.

No third-party papers or figures are included. Copyright and other rights in the cited works remain with their respective holders. Reproduction materials do not confer redistribution rights in those works. No source is cited as establishing novelty of this report's exact certificate or low-mass presentation.
