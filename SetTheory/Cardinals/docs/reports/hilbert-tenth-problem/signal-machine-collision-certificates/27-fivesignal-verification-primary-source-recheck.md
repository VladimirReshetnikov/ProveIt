# Primary source recheck

4 October 2026. Read-only checks by the report writer, additional to the original
independent audit's source review. These are bibliographic and scope checks, not
a literature-priority search or execution of source programs.

- Dai and Xia: the arXiv primary article identifies Liyun Dai and Bican Xia.
  Section 4, Theorem 4.1 and Proposition 3 give a three-variable nonsemialgebraic
  nontermination example with diagonal update diag(2,3,5) and a non-strict guard.
  https://arxiv.org/html/1206.0232v1
- Ouaknine and Worrell: Example 3.1 uses an irrational-angle rotation about a
  fixed axis and a non-strict guard. It is the relevant prior rotation-cone
  comparison, not an independent claim of new abstract nonsemialgebraicity.
  https://www.cs.ox.ac.uk/james.worrell/lrs5.pdf
- Becker, Chapelle, Durand-Lose, Levorato, Senot: author names and Definition 1
  verified. The definition permits repeated speeds across meta-signals but
  requires pairwise distinct speeds within each collision input/output set.
  https://arxiv.org/pdf/1307.6468
- Durand-Lose's author overview explicitly includes rational initial coordinates
  in rational-machine terminology and describes geometric multiplication,
  division, translation, scaling, and shrinking constructions.
  https://www.univ-orleans.fr/lifo/Members/Jerome.Durand-Lose/Recherche/AGC/intro_AGC.html
- The author's AGC5 manuscript contains prior shrinking and acceleration
  constructions, consistent with the report's cautious attribution.
  https://www.univ-orleans.fr/lifo/membres/Jerome.Durand-Lose/Recherche/Publications/2011_NC_UC.pdf
- Matiyasevich's 1971 expanded primary paper is the final linked MRDP citation:
  *Diophantine representation of enumerable predicates*, Mathematics of the
  USSR-Izvestiya 5(1), 1-28. The publisher record expressly states the consequence
  that every enumerable predicate is Diophantine, using the earlier results of
  Davis, Putnam, and Robinson.
  https://www.mathnet.ru/eng/im1910

The report's only bibliographic correction from its first build was H. Dai to
L. Dai. The MRDP reference was replaced with the verified linked expanded paper.
No change to the mathematical argument resulted.
