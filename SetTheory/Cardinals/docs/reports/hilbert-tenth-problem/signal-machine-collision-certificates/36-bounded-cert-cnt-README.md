# Encoded-gap counting continuation

A separate, unnumbered proof packet for all encoded positive integer gap triples, regardless of halting.

`PROOF.md` proves the exact floor and shell formulas, the slope 743/1125, a nonnegative error with normalized liminf 0 and limsup 1 at log-base-two-squared scale, exact residue-class errors at total 10*2^M, and the inverse theorem with triple multiplicity. Distinct represented totals instead have density 3/20.

`check_counting.py` is fresh exact arithmetic, with independently gcd-derived primitive scales. Read it before execution. `checks.json` records the finite checks; they are not a replacement for the proof. Earlier packets remain untouched.
