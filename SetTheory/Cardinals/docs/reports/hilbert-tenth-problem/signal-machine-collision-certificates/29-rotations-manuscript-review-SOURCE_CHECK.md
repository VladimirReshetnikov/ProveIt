# Fresh primary source checks for the manuscript review

Checked 4 October 2026. These are passage-level checks of attributions used in Report 59, not an exhaustive novelty or repository search. No program from these sources was executed.

1. **Fijalkow et al., STACS 2017.** The [publisher's primary PDF](https://drops.dagstuhl.de/storage/00lipics/lipics-vol066-stacs2017/LIPIcs.STACS.2017.29/LIPIcs.STACS.2017.29.pdf), introduction and Example 1 on printed page 29:3, confirms the matrix `(1/5)[[4,-3],[3,4]]` and failure of semialgebraic separation for an unreachable target on the orbit-closure circle. The introduction credits polynomial-time orbit decision to Kannan and Lipton, whose 1986 bibliographic entry matches reference [2]. The printed angle has a known arctangent inconsistency; Report 59 uses the correct displayed matrix and does not repeat the angle. The present input classifier is correctly distinguished from an inductive invariant.

2. **Durand-Lose, AGC6.** The [author manuscript](https://www.univ-orleans.fr/lifo/Members/Jerome.Durand-Lose/Recherche/Publications/2012_IJUC_UC_HC.pdf), introduction and Section 3, explicitly imposes equal incoming/outgoing populations and implements rational stack updates by translation and scaling. Its abstract and later construction establish conservative shrinking. Report 59 appropriately treats these techniques as established rather than claiming them as new.

3. **AGC5 and AGC8.** [AGC5](https://www.univ-orleans.fr/lifo/membres/Jerome.Durand-Lose/Recherche/Publications/2011_NC_UC.pdf), Section 3.1 and Figure 1, describes five reference signals in a larger decoding arrangement and contains population-changing rules; Section 4's inner structure uses five meta-signals plus a start type. [AGC8](https://arxiv.org/pdf/1307.6468), Section 2 and Definition 1, distinguishes types, instances and distinct speeds. The manuscript's caution against confusing these counts with exactly five live signals is supported.

4. **Earlier loop results.** [Dai and Xia](https://arxiv.org/html/1206.0232v1), Section 4, Theorem 4.1 and Proposition 3, gives the nonsemialgebraic three-variable example with diagonal update `2,3,5` and a non-strict guard. [Ouaknine and Worrell](https://www.cs.ox.ac.uk/james.worrell/lrs5.pdf), Example 3.1 on printed page 7, gives an irrational-angle rotation with the non-strict guard `z-y>=0`. Its displayed squared-cone shorthand omits the nonnegative axial restriction, but the intended closed upper cone follows directly from its guard. Report 59 makes only the correct closed-cone comparison and distinguishes strict-boundary deletions.

5. **Exact real computation.** [Gärtner and Ziegler](https://lmcs.episciences.org/1019/pdf), Section 1.4 and Definition 1.2, specifies exact field operations, finitely many real constants and the promised-domain convention. Corollary 2.6(a), printed page 10, gives the relative `F_sigma` necessary condition. Its locally-closed wording is stronger than needed; Report 59 correctly proves the `F_sigma` fact through finite basic sign sets instead. [Calvert, Kramer and Miller](https://arxiv.org/pdf/1006.0396), Section 1 and Lemma 1.1, corroborates finite real parameters and field-operation register contents. Neither source licenses a floor, oracle or completed-infinite computation primitive in the lower-bound model.

6. **Real projection.** [Basu's author-hosted survey](https://www.math.purdue.edu/~sbasu/raag_survey2011_final.pdf), Section 2.1, Theorem 2.1 on printed page 4, states the required real quantifier-elimination theorem. It supports arbitrary real coefficients and imposes no compactness condition on existential real witnesses.

7. **Pell specialization.** The local pinned `PellMatiyasevic.lean` source, SHA-256 `993760c797ad0ff66fa77064a616fce779550bc745cbf6c44e04f392fd0bed0a`, was inspected as mathematical text around lines 760–947. The named theorem statements and positive-branch constructions support the exact substitutions in Sections 10.3–10.4. This review does not claim Lean execution or an independent upstream-commit provenance audit.
