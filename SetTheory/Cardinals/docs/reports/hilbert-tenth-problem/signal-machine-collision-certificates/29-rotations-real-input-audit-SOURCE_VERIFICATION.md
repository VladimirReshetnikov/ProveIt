# Independent source verification

Checked 4 October 2026. This file records fresh passage-level verification, separate from the source author's assertions. It is a bounded check of the general ingredients actually used, not a novelty survey.

## BSS model and relative topological upper bound

Tobias Gärtner and Martin Ziegler, *Real Analytic Machines and Degrees: A Topological View on Algebraic Limiting Computation*, Logical Methods in Computer Science 7(3:11), 2011.

- Primary journal PDF: https://lmcs.episciences.org/1019/pdf
- DOI: 10.2168/LMCS-7(3:11)2011
- Inspected Section 1.4 on printed pages 3–4: exact field operations, exact comparison, finitely many listed real constants, and register access
- Inspected Definition 1.2 on printed page 4: relative semidecidability ignores behavior outside the promised domain
- Inspected Corollary 2.6(a) and its proof on printed page 10: semidecidable subsets of a domain have relative F_sigma upper bound by countable semialgebraic path decomposition

The source's proof includes wording suggesting every semialgebraic set is locally closed. The companion does not depend on that stronger wording: its finite-sign decomposition proves the needed F_sigma property directly. The cited corollary and its application are correct.

## Finite real parameters and field contents

Wesley Calvert, Ken Kramer, and Russell Miller, *The Cardinality of an Oracle in Blum-Shub-Smale Computation*, EPTCS 24 (2010), pp. 56–66.

- Primary author-submitted PDF: https://arxiv.org/pdf/1006.0396
- DOI: 10.4204/EPTCS.24.10
- Inspected Section 1 on printed page 56: finite programs may contain finitely many real parameters and use addition, subtraction, multiplication, division, copying, and exact comparisons
- Inspected Lemma 1.1 on printed page 57: register contents stay in the field generated by parameters and inputs
- Inspected Definition 1.2 on printed page 57: semidecidability as the domain of a partial BSS-computable function

These passages support the companion's model and arbitrary-fixed-real-constant qualification. The stronger fixed-path rational-function claim is established independently in the review; field containment alone is not substituted for path semialgebraicity.

## Real quantifier elimination

Saugata Basu, *Algorithms in Real Algebraic Geometry: A Survey*.

- Author-hosted PDF: https://www.math.purdue.edu/~sbasu/raag_survey2011_final.pdf
- Inspected Section 1.1 on printed page 1: the coefficient field R is a real closed field
- Inspected Section 2.1, Theorem 2.1 on printed page 4: a finite first-order polynomial-sign formula with real quantifier blocks has an equivalent quantifier-free formula

This verifies the form needed for each fixed integer witness tuple, including arbitrary real coefficients and no compactness requirement. It is an authoritative author-hosted statement of the classical result, not an assertion that the original Tarski or Seidenberg full texts were newly inspected here.
