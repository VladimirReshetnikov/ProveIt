# The non-Zeno variant is a separate finite machine

The delivered RULES.json describes the 138-event contracted machine. Its zero-based rule 113 outputs Q114, which starts the contraction phase. Repeating its first 114 events is therefore not a periodic run of that unchanged table.

For the separate non-Zeno variant, retain zero-based rules 0 through 113, replace Q114 by Q0 in rule 113's output, and discard unused later messenger/temporary-marker labels and rules. The final reflection then restores the initial section label Q0 at L, with speed +1. The resulting 114-rule variant has return 2M, the same normalized 36-row chamber, and a physical clock bounded below by 2D per macro. Its valid infinite runs are non-Zeno.
