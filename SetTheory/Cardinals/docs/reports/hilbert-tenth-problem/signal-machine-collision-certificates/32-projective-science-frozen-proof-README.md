# Fixed center projective returns with five live signals

This separate packet proves a concrete extension of the preceding rational planar compiler. Every rational homogeneous matrix

is realized by a finite complete binary word on the same five-live-signal stationary-marker section. Its exact chamber is a bounded center-strict rational polygon after normalization. The return is the projective map w -> Aw/(s+bw), with shape-dependent physical scale.

The elementary new operation has eight events and moves the outer marker to vD+(1−v)y. After twelve inner recentering events its only added guard is sy<D_outer, where s=(v+2)/3. Correcting its centered 2 by 2 action gives a pure projective scale shear. Conjugation supplies every rational scale row.

A particularly short consequence uses the 20-event raw operation and a 24-event global contraction. In this same 44-event word, infinite validity is exactly D≥3y/2; equality is Zeno and strict inequality is non-Zeno. The rule table, parameters and four exact guard rows are supplied separately. On native positive-integer gaps, the three validity/clock classes also have explicit quadratic unique-witness certificates: one witness for infinite validity, none for Zeno validity, and one for non-Zeno infinite validity.
