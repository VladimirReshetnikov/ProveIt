# Diagonal Hardinian arrays — research package

**Main result.** For every fixed nonnegative integer r,

    H_r(n,n) ~ C_r 4^(r n) n^(-r(r-1)/2),

with

    C_r = 2^(r(r-3)) / 3^(r^2)
          * ( product_{j=1}^r Gamma(1+j/2)
              / (r! Gamma(3/2)^r) )^2.

The formula confirms the constants tabulated by Dougherty-Bliss and Kauers in
2024, but their proposed restriction to powers of 2, 3, and pi fails at r=7:

    C_7 = 2^18 * 5^2 / (3^45 * pi^3).

The manuscript also gives an exact finite determinant for all parameters at a
fixed array size, an exact enumeration algorithm, and a limiting
negative-binomial law for total deficits in the positive minor representation.

## Read first

- `article.pdf`: the complete 20-page research manuscript.
- `article.tex`: editable LaTeX source, including proofs and bibliography.
- `notes/proof_audit.md`: assumptions, normalization checks, and scope.
- `notes/source_status.md`: sources actually consulted and priority caveats.

This is unrefereed research. The proof is intended to be complete, but neither
priority nor correctness has been independently certified. No OEIS edit,
submission, author contact, or formal proof-assistant verification has occurred.
The result is for fixed r; it is not uniform in growing r and is not a full
inverse-power asymptotic expansion.

## Reproduce the mathematics and computations

Python 3.10 or later is recommended. The core counter and the exact test suite
use only the Python standard library:

```sh
python code/verify.py
python code/hardinian.py 40 --max-r 7
python code/hardinian.py 12 --max-r 11 --method generic
```

`hardinian.py` outputs decimal strings for counts in JSON, preserving exact
integers when the output is read by applications whose numeric type is a float.
Its Python API is `counts(n, max_r=7, method="auto")`. Counts with r >= n are
zero. n must be a positive integer; r must be nonnegative.

`method="auto"` uses skew-Pascal identities through r=7, and a general Newton
coefficient method for higher orders. `method="generic"` is also available for
cross-checks. The direct array and minor methods in the module are exponential
reference implementations intended for small test cases, not large production
runs. Complexity estimates in the article count arithmetic operations; integer
bit complexity is explicitly distinguished.

For the numerical ratio tables, install mpmath if needed and run:

```sh
python -m pip install -r requirements.txt
python code/generate_data.py
```

The default generator covers n=1..40,80,120,200,400 and 0<=r<=7. Exact counts are
computed with Python integers; mpmath is used only for displayed ratios involving
pi. The default run includes the n=400 calculation, which took about 24 seconds
in the recorded environment. Timing on other machines can differ substantially.
`--max-n 200` is a faster exploratory option and omits the n=400 ratio-table row.

## Build the PDF

A normal TeX Live or MiKTeX installation with the packages listed in the source
is sufficient. No fonts are bundled. The source uses the standard newtx font
packages. From the package root, run:

```sh
sh build.sh
```

The equivalent commands are three passes of:

```sh
pdflatex -interaction=nonstopmode -halt-on-error article.tex
```

The included `data/ratio_table.tex` is an input to the article; keep it beside
the other data files. It is generated by `code/generate_data.py`.

## Data inventory

- `data/exact_counts.csv`: 352 exact counts, 44 sizes by 8 parameters.
- `data/asymptotic_ratios.csv`: 42 ratios, six sizes by seven positive parameters.
- `data/constants.json`: exact rational prefactors Q_r = C_r*pi^floor(r/2), r=0..20.
- `data/ratio_table.tex`: rounded table for the article.
- `data/oeis_reference_selected.json`: 71 selected independent OEIS reference
  values, transcribed from the web-retrieved b-files and attributed to their URLs.
- `data/verification_report.json`: the successful exact verification audit.
- `data/computation_run.json`: precision, environment, and per-size timings.

The OEIS reference file is not regenerated by the tested algorithm. Generated
counts and asymptotic ratios are in separate files to keep the comparison honest.
The tests include direct array enumeration, complementary minors, squared
Pascal minors, Pfaffians, independent coefficient extraction, likelihood ratios,
and rational Hankel determinants.
