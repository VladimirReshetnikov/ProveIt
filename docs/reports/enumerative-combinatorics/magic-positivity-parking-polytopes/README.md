# Coefficientwise magic positivity through dimension ten

An exact-arithmetic partial solution of Conjecture 8.1 of Hill, Luo, Trinh,
and Vindas-Meléndez, arXiv:2607.15503v1 (July 2026).

## Result

For every dimension 3 <= n <= 10 and **every** positive integer parameter
vector b, the generalized parking-function polytope X_n(b) is magic positive.
The proof certifies a stronger statement: all ordinary monomial coefficients
of n! mu_(n,j)(1+x_1,...,1+x_n) are nonnegative integers. For dimensions 4..10,
every monomial of total degree at most j has a positive coefficient. Dimension
three has just one missing monomial: the constant in mu_(3,3).

This is an all-parameter polynomial certificate, not a test over a finite
parameter box. The full conjecture in unrestricted dimension is **not** proved.

The article also gives an all-dimensional formula and sharp lower bound for
the first magic coefficient, an exact zero classification of the final magic
coefficient, and a cube-addition reduction to the parameter face b_1 = 1.
Dimension three has a complete printed algebraic proof. Dimensions 4..10 use
the supplied exact-arithmetic computation. No proof assistant was used.

## Read and reproduce

Open `article.pdf` or edit `article.tex`. The source uses ordinary pdfLaTeX
packages and the companion `tables/area_catalogue.tex` file.

From this directory, with Python 3.9 or later:

```sh
python code/verify_certificates.py
python code/evaluate_polytope.py 2 3 1
python code/evaluate_polytope.py 2 3 1 --dilation 5
python code/sparse_magic.py --max-dimension 10 --output data/rebuilt
```

The Python tools need **no third-party packages**. The full verifier regenerates
every polynomial, verifies 55 independent summation-kernel identities, checks
the first-coefficient formula, and cross-checks 731 direct geometric lattice
counts (486 at positive dilation and 245 at dilation zero). The delivered run
passed in about 33 seconds in the execution environment; timings vary.

To compile the article:

```sh
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
```

To replay the initial area draw:

```sh
python code/select_area.py --seed 89054884759964478034823739394527898187 --output selection-replayed.json
```

It selects entry 33 of 120: **Discrete geometry**. The original first-draw record
is `data/selection.json`; no redraw was made after observing the subject.

## Files and variable conventions

- `article.pdf`, `article.tex`: paper, proofs, algorithms, bibliography.
- `code/sparse_magic.py`: exact sparse-polynomial generator and certificate I/O.
- `code/verify_certificates.py`: regeneration, kernel identities, geometric checks.
- `code/evaluate_polytope.py`: exact Ehrhart/magic/h* coefficient evaluator.
- `code/select_area.py`: initial random selection and replay.
- `data/certificates/`: **not distributed** (24 MB, 76 files). The
  `lattice_nn.json` and `magic_nn_jj.json` certificates are regenerated by
  `python code/sparse_magic.py --max-dimension 10 --output data/certificates`,
  and `python code/verify_certificates.py` regenerates every polynomial it
  checks. The whole directory, `summary.json` included, is rebuilt by that
  command; `data/verification.json` and `data/sparse.log` record the delivered
  run and are still shipped.
- `data/verification.json`: exact cases, integer results, and verification summary.
- `data/example_2_3_1.json`: worked asymmetric example.
- `notes/`: source audit, exclusion audit, and precise claim boundaries.
- `SHA256SUMS`: hashes for all other delivered files.

Each polynomial is stored as a sorted list `[[exponent_vector], coefficient]`,
with integer coefficients, dimension, and scale. Divide coefficients by n!.
Missing monomials are exactly zero. **Lattice files use b variables; magic
files use x = b - 1 variables.** These are different conventions.

The auxiliary n=1 certificates use ambient degree one. When b_1=1, the polytope
is a point of intrinsic dimension zero: its intrinsic magic polynomial is 1,
not the ambient transform 1-y. The n=2 certificate correctly detects the
known exceptional vector (1,1). Neither is included in the n>=3 positivity claim.

## Trust boundary

The mathematical recursion is proved in the article and credited to its
published sources. Exact generation checks identities, not just example values.
The independent geometric enumerator is a separate error-detection route; it
is not used as a substitute for the symbolic proof. The draft has not been
independently refereed or formally verified, and novelty has not been
independently established. See `notes/STATUS.md` for what is and is not claimed.
