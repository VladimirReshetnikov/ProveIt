# Every ordinal as a point-separating game value

**Research manuscript — 20 September 2026**

## Main result and scope

For every ordinal lambda, order the binary functions lambda -> {0,1}
lexicographically. Give this set either:

1. the topology of all downward-closed sets; or
2. the topology generated by downward-closed sets with finitely many points deleted.

The manuscript proves that the point-separating game value is exactly lambda
for both topologies. The first space is compact T0. The second is compact T1.
For infinite lambda neither space is Hausdorff. Compact means the finite-subcover
property, without an implicit Hausdorff requirement.

In particular lambda = omega^2 + 1 supplies a compact T1 witness of cardinality
continuum for Problem 1.2 of Chiozini–Csernák–Soukup, arXiv:2510.05754v3.
This is a proposed complete solution in the question's stated topological
category. It is not an independently refereed or proof-assistant-verified result,
and it does not solve a Hausdorff-strengthened version of the problem.

## Rebuild

With Python 3.10+:

```sh
python3 code/finite_checks.py --output verification/results.json
```

With a TeX installation providing newtx, amsmath/amsthm, mathtools, geometry,
microtype, fancyhdr, tcolorbox, hyperref, cleveref, listings, and enumitem:

```sh
pdflatex -interaction=nonstopmode -halt-on-error ordinal_separation.tex
pdflatex -interaction=nonstopmode -halt-on-error ordinal_separation.tex
```

A third pass can be useful after changing pagination. The bibliography is
embedded, so BibTeX is not needed for this source. `make check` runs the tests;
`make` builds the PDF when its source is newer.

## Actual finite checks

All checks passed in the delivered run:

- 130,816 minimax transitions for finite chains through 512 points;
- 1,398,090 prefix/query cases for the untouched-child rule;
- 2,036 legal Seeker-cut trace checks;
- 1,000 seeded random query sequences, totaling 10,348 turns;
- 131,070 finite subset queries checking the majority bound;
- 30,071 finite-hole configurations checking the untouched-subcylinder argument.

These counts describe finite audits, not a computational proof of the infinite
or transfinite theorem. The actual transfinite proofs are in the article.
The checks use exact integers and sets; no floating-point approximation is used.

No third-party paper or font file is included. The article's bibliography links
to the primary source.
