The PDF, not the older v1 HTML rendering, is the main source for the problem
status used in the article. Its first page explicitly describes games on T0
spaces. Definition 1.1 is on PDF page 2. Problem 1.2 occurs on PDF pages 4 and
16 and asks whether omega^2 < ps(X) < omega_1 is possible. Page 4 states the
known realization of ordinals through omega^2 by zero-dimensional T2 spaces.

The article supplies its own definitions, constructions, and proofs and does
not reproduce the source paper. No source PDF is bundled.

## Status qualifications

The checked version explicitly leaves the selected problem open. Searches
made for this work did not locate a later solution, but this is not an exhaustive
bibliographic review or a guarantee of priority. The proposed theorem is not
independently refereed or proof-assistant verified.

The affirmative answer concerns the question as actually written, without a
Hausdorff requirement. A strengthened Hausdorff question is not resolved by
the construction, even though the primary source's earlier positive examples
had that stronger separation property.
