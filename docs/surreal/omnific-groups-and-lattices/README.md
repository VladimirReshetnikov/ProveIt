## A unipotent dichotomy and universal elementary quotients

## Main results

The article proves a real algebraic-group criterion for acquiring nonconstant
omnific points: these points exist exactly when the real group has a nonidentity
unipotent. The equivalent structural criterion for rigidity is that the identity
component is reductive and its derived group's real points are compact. Over the
complex coefficient field, rigidity instead holds exactly when the identity
component is a torus. Both statements include fixed integral or Gaussian-integral
models, with explicit finite-polynomial families in the nonrigid case.

For every finite n >= 3, let P_n be generated by elementary matrices with purely
infinite parameters. The article proves that P_n is nontrivial, normal, perfect,
and has no nontrivial class group homomorphism into any set-sized group. Thus
constant coefficient extraction is the universal set-sized abstract group
quotient of E_n(Oz), with target SL_n(Z), and of E_n(Oz[i]), with target SL_n(Z[i]).
These statements concern elementary groups E_n; no identification with the full
special linear group over an omnific ring is assumed or proved.

Supporting results include explicit real and Gaussian orthogonal families, exact
unitriangular filtrations, a separating proper-class congruence tower, and precise
contrasts with fixed set-sized Hahn fields and finite-support series.

## Build the PDF

Use a standard TeX Live installation with pdfLaTeX and the packages named in the
preamble. The source uses standard Latin Modern fonts and includes its own
bibliography; no external bibliography file, images, or nonstandard fonts are
needed. From this directory, run:

```sh
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
```

Three passes resolve the contents and cross-references. The supplied PDF was
built without unresolved references or layout warnings and was visually reviewed.
Python and SymPy are not required to compile the article.

## Reproduce the optional finite checks

The script uses Python 3.10 or later and SymPy. The included run used Python
3.13.5 and SymPy 1.14.0. To use the tested SymPy version:

```sh
python -m pip install sympy==1.14.0
python verification.py --output verification-results.txt
```

The program raises an error on any failed identity and exits successfully only
after all checks pass. It uses exact symbolic arithmetic and deterministic finite
integer examples, not floating-point evidence. It does not implement surreal
numbers or infinite Hahn summation.
