# Tail-Spans and Differential Transcendence in Surreal and Surcomplex Hahn Fields

Research article prepared for Vladimir Reshetnikov, September 22, 2026.

## Main results

Theorem 5.1 classifies the entire algebra generated by a finite tuple of
Hahn sums built from independent square roots. The cofinite span of the
coefficient vectors gives the polynomial dimension, and exactly the finite
exceptional coefficient indices give the algebraic constant field.
Theorem 5.2 identifies all components of the relation ideal after its
finite splitting extension.

Theorem 7.3 constructs a continuum-sized, explicitly binary-prefix-indexed
family of actual positive infinitesimal surreal numbers with all normalized
Berarducci–Mantova derivatives algebraically independent over Q((t^Q)),
where t = omega^(-1). It proves differential transcendence degree continuum
for A_R((t^Q)) / Q((t^Q)); A_R denotes the real-algebraic numbers.

Theorems 9.3 and 10.1 prove joint algebraic independence of mixed z and
Euler-scale derivatives of common-domain analytic Hahn functions whose
every nonzero coefficient is quadratic over C(z). The relation field is
C(z)((t^Q)), larger than C((t^Q))(z).

## Research status

Complete mathematical proofs are included relative to standard Hahn-field,
Galois, Conway-normal-form, and Berarducci–Mantova foundations. These are
proposed contributions, not certified priority claims. No named historical
open problem is claimed solved. The general proofs have not been independently
refereed or verified in a proof assistant. See AUDIT.md for scope restrictions.

## Rebuild the PDF

Install a TeX distribution providing pdfLaTeX and the packages listed at the
beginning of article.tex, including New PX text/math and needspace. Then run:

    python build.py

Or run the following command three times:

    pdflatex -interaction=nonstopmode -halt-on-error article.tex

No BibTeX, shell escape, external image, or network access is needed by the
build itself. The source uses installed TeX fonts; font files are not included.

## Reproduce the exact checks

Python 3.10 or later is expected; the recorded run used Python
3.13.5 and SymPy 1.14.0.

    python -m pip install -r requirements.txt
    python verify.py --output verification_results.json

The check seed is 20260922. Timing and interpreter-version
fields may vary. The checks use exact integers, rationals, polynomial
identities, and exact symbolic differentiation. They do not numerically
approximate infinite surreal sums.

The record contains 404 successful finite checks. It is not a proof
of any arbitrary-support theorem, hereditary statement about all infinite
subsets, or continuum-sized independence statement.
