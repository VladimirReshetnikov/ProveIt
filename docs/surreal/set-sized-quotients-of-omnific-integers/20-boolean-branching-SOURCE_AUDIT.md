## Novelty boundary

The proposed new contribution is the combined support-local, dominant-scale
splitting, rank-extension, atomlessness/proper-class, and representation
nonseparation package. No identical package was found in the inspected sources.
The search and repository comparison were targeted, not exhaustive. Absence
from those sources does not establish historical priority.

The standard determinant trick, coefficient projection as a module map,
multiquadratic square-class theory, finite Boolean powers, and ultrafilter
methods are not claimed to be inventions of this article. The contribution is
the proof that these methods give the stated exact results for omnific
normalization and its support-local reduced fibres.
