# Spectral Descent and Exact Ramification in Surcomplex Matrix Calculus

A research article prepared for Vladimir Reshetnikov, September 21, 2026.

## Main result

Work over K_Gamma = C((t^Gamma)), with Gamma an arbitrary set-sized ordered
abelian group, not assumed divisible. For a positive semidefinite Hermitian
matrix A of rank r and integer q >= 2, let Delta_k be the minimum valuation
of all k-by-k minors, and Delta_0 = 0. The article proves

    K_Gamma(A^(1/q)) = K_(Gamma + sum_k Z Delta_k/q)
                    = K_Gamma(trace(A^(1/q))).

The extension degree is the size of the subgroup generated by the Delta_k
modulo q Gamma. The degree is at most q^r, and the bound is attained.

The engine is exponent-preserving Hermitian and normal spectral resolution
and an SVD over nondivisible Hahn fields. Hermitian diagonalization is
constructed by a finite splitting tree with at most n-1 nontrivial nodes.
Strong Hahn summability, not sequential convergence, licenses the infinite
series. The article also proves a finite-witness simultaneous spectral
statement, an exact Gram-factorization criterion, and a joint primitive-trace
result for several positive roots, without requiring their matrices to commute.

## Status and prior work

This is an unrefereed AI-assisted research manuscript, not a formally verified
proof development. It does not claim to solve a named published open problem.
The exact arbitrary-rank determinantal/primitive-trace package is presented
as a candidate original contribution, with a qualified literature comparison.
Priority has not been certified.

The spectral construction has important predecessors: Adkins (1991),
Keller and Ochsenius (1995), and Parusinski and Rond (2020). The article also
compares the February 2026 preprint by Dai, Liang, Lu, and Zhi. The ordinary
spectral theorem, classical Hahn support facts, and basic finite Kummer theory
are not represented as new. Complete references and the inspected repository
revision are in the article.

No infinite-dimensional operator theorem, global multivariable analytic
eigenbasis, or general effective representation of all surreal numbers is
claimed. The field and extension statements are set-sized; their surreal
interpretation uses the exact support group of a finite input matrix.

## Build

A TeX Live or MiKTeX installation with the standard packages named in the
preamble is sufficient. The bibliography is embedded: no BibTeX, external
figures, shell escape, or downloaded fonts are required.

From this directory:

    pdflatex -interaction=nonstopmode -halt-on-error article.tex
    pdflatex -interaction=nonstopmode -halt-on-error article.tex
    pdflatex -interaction=nonstopmode -halt-on-error article.tex

Alternatively run `bash build.sh` or `./build.ps1` in PowerShell. The delivered
PDF was compiled with pdfLaTeX on Linux; the PowerShell wrapper is supplied
for convenience and was not executed in the build environment.

## Rerun the finite checks

Python 3.9 or later; the delivered run used Python 3.13.5 and SymPy 1.14.0.

    python -m pip install -r requirements.txt
    python code/verify.py --output-dir rerun-results

The supplied results report **807 exact scalar assertions, PASS**. The suite
checks a 3-by-3 Hermitian projector and polar construction through degree six,
48 finite ramification-group cases, six rational matrix profiles, and the
displayed finite identities. Counts include individual zero coefficients;
they are not counts of independent theorems. These finite checks do not
machine-prove the statements about arbitrary Hahn supports or value groups.

The valuation convention in the rational tests is v(t)=(0,1), v(u)=(1,0),
lexicographic order. The least, not the largest, polynomial monomial sets the
valuation. All computations are exact; no floating-point tests are used.
