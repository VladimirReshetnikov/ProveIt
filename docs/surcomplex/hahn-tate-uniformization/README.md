**Exact summability domains, surcomplex elliptic curves, and torsion ramification**

## Main result

Let K = C((t^Gamma)), for any set-sized ordered abelian exponent group Gamma, and let q have positive valuation alpha. Let H_alpha be the principal convex subgroup generated by alpha: the values bounded in absolute value by some ordinary integer multiple of alpha. Put U_q = {u in K^* : v(u) in H_alpha}.

The manuscript proves that U_q is exactly the strong-Hahn-summability domain of the classical bilateral theta and Tate coordinate families (excluding the coordinate poles q^Z). It then proves the surjective group isomorphism

    U_q / q^Z  ≅  E_q(K).

The domain may be proper, but all elliptic-curve points are reached. The proof first uses classical rank-one Tate uniformization in a residue workspace and then lifts every coarse infinitesimal using formal groups and a proved unrestricted formal-evaluation lemma. It does not claim that Hahn partial sums converge in the full surreal topology.

Additional results include exact scalar-extension behavior; the coarse reduction diagram; the valuation-circle quotient; recovery of q from j without enlarging its support subgroup; and the torsion field formula

    K(E_q[n]) = K(q^(1/n)) = K_(Gamma + Z alpha/n),
    degree = order of alpha in Gamma / n Gamma.

A single point Phi_q(q^(1/n)) generates that field. Set-sized normal-form workspaces transport the main theorem to No[i]. The negative-j regime v(j)<0 is covered; a general theorem for the good-reduction regime is not claimed.

## Research status

This is a candidate-original research manuscript, not a claimed solution of a named published open problem. The exact-domain/arbitrary-rank package was not identified in the targeted literature search. Priority is not certified. Tate's rank-one theorem, classical theta and modular identities, and the Kummer origin of Tate torsion are explicitly credited, not claimed as new.

The proofs have not been independently refereed or formalized in Lean. The included computations verify finite truncations and normalization choices only. They do not prove the strong-summability, surjectivity, or class-transport results.

## Reproduce the checks

Python 3.9 or later is intended; the recorded run used Python 3.13.5 and SymPy 1.14.0.

    python -m pip install -r requirements.txt
    python code/check_identities.py

The program uses exact rational symbolic arithmetic and no network access or numerical floating-point evaluation. It exits with an assertion failure if a checked identity is false. Its JSON records the actual runtime versions.

Checked: the Weierstrass equation, the differential identity u X' = X + 2Y, and inversion through q^5; discriminant versus product through q^9; j through q^5; inverse modular composition through J^6; the local-parameter sign; theta shift coefficients; and finite lattice witnesses.

## Build the PDF

Use a TeX Live or equivalent installation with newtx, amsmath/amsthm, tikz-cd, tcolorbox, hyperref, and cleveref.

    latexmk -pdf -interaction=nonstopmode -halt-on-error article.tex

Alternatively, run `pdflatex` three times to resolve the contents, references, and bookmarks. The source has an embedded bibliography.
