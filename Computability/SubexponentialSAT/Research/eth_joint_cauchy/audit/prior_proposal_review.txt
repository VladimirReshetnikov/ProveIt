3. Established frontier in these reports

All runtime statements below depend on the unchanged source theorem.
For fixed clause width the general bound remains
  poly(n,m) * 2^{O_k(n loglog(n)/sqrt(log n))},
and the fixed-density bound remains
  poly(n,m) * 2^{O_{k,D}(n/sqrt(log n))}.

The strongest established density envelope in the seven reports is
  poly_k(n,m) *
  2^{O_k((n/sqrt(log n))*min{log(2+m/n),loglog n})}.
It improves slowly growing densities, but not the unrestricted n-only
order or the fixed-density order. Both density reports prove variants
of this same construction: density-only expander-code checks, followed
by greedy elimination and an incidence encoding that retains actual
monomial sparsity.

The strongest explicitly declared geometric-mode contraction schedule
has coefficient 648.4410666487529 multiplying s/sqrt(log_2 s), with
normalized root M<=s, degree<=ceil(s^(9/10)), root precision/truncation
<=s, and fixed entry-oracle constants. Its parameters are
  r=256, rho=6/r=3/128,
  u_d=floor(lambda/(720*12^d)),
  a_d=2 sum_{j=0}^d u_j,
  H=ceil(s/lambda), lambda=ceil(log_2 s).

The same report already optimizes its schedule family. Its continuous
boundary coefficient is
  C_*(r)=2*pi*sqrt(480*log_2 r)
         /(ln(2)*(1-(6/r)^(2/3))^(3/2)),
with r approximately 251.005440999 and infimum approximately
638.527489792. Strict feasible schedules can approach this infimum.
It would be inaccurate to call 648.441 the absolute best coefficient
implicit in every existing proposal.

The factorial-Cauchy report changes weights from b+1 to
  1+b+2*v_2(b!) = 3b+1-2*s_2(b),
with no extra column tiles. It divides the leading logarithmic mode
enumeration bound by sqrt(3). Combining it with the declared schedule
above gives 374.3776243832656. Combining it with schedules approaching
the existing continuous boundary gives infimum approximately
368.65401811665055. These synthesized comparisons should be included
when assessing a new coefficient, even though no one prior ZIP packages
the entire combination.

4. The seven packets, with nonduplicative content

(a) cauchy_mode_improvement:
    Exact finite Cauchy separation; both factorial gains transferred to
    the target; prime-subring congruence at actual extension points;
    weight slope 3; unchanged source/target groups and recursive size.
    It explicitly leaves exploiting the narrower actual row family open.

(b) eth_contraction_improvements:
    Exact taper h~M/u instead of 3M/u; precision ~6MD/u instead of 24MD/u;
    optimized r=256 schedule; streamed finite differences with <=2^L
    evaluations and correct extra precision before factorial division.
    It also derives the continuous schedule-family optimum above.

(c) 3sat_precision_refinement:
    Exact cardinal-Hermite loss and integer condition count; solves the
    real full-loss minimax problem. Minimum maximum loss for required
    mass W is W/(u/3+2/9-(2/9)4^{-u}), so leading constant 6 is already
    optimal within that normalization-loss model. It gives an exact
    rank-based mode network, but its fast summation remains a hypothesis.

(d) sat_density_improvement:
    Uniform all-density envelope using density-only sparse checks and
    fixed-degree explicit expander powering. It handles m<=d by direct
    enumeration of occurring variables. Global row count<n/4 and 3n
    greedy rounds keep fewer than 4n equations.

(e) eth_density_refinement:
    Overlapping density theorem, a different small-m construction,
    exact precision and conservative schedule improvements, Max-k-SAT
    consequence, dimensional obstruction, and exact local Cauchy Smith
    spectrum. The Smith result is especially relevant to novelty.

(f) 3sat_refinement:
    Exact scalar parity indicator, no auxiliary V axis, coefficient
    divisibility, and sharp incidence cap k(p+a-1)=k(n+a). At the source's
    at-most 6n test bound this changes 8kn to 7kn. It does not remove the
    incidence entropy. Its second contraction needs the unproved LF
    compact-factorization theorem; a separate union-support compiler is
    also unproved.

(g) 3sat_asymptotic_analysis:
    No stronger bound; precise degree-preserving and linear-wire
    interfaces; limitations of taper/partition/degree/parity shortcuts;
    meaningful incidence-support examples arising from genuine 3CNF;
    original-variable quotient, exterior-power, and norm-hashing leads.

5. Conditional targets must not be called existing achieved algorithms

The precision packet proposes
  general: n loglog n/log n in the exponent;
  fixed density: n/log n.
It requires an algorithm summing actual structured modes with only
exp(O(M/u)) admissible recursive calls. This is not proved.

The scalar-refinement packet proposes
  general: n(loglog n)^(3/2)/log n;
  fixed density: n sqrt(loglog n)/log n.
It requires LF, which factors high-degree group tensors into bounded-
degree networks with a correspondingly reduced total edge count.
The compressed rank graph alone violates the contraction degree bound.

The asymptotic-analysis packet proposes
  general: n sqrt(loglog n/log n)
through a degree-preserving recursive compressed kernel, or
  general: n/sqrt(log n)
through linear-wire streaming compression. Neither interface is given.
The union-support variant in the scalar packet has the latter target
and the same missing local-factorization/entry-cost problem.

An improved constant such as 324.2205 does not prove or dominate these
unproved order-level targets. A correct conclusion is improvement of the
strongest established and readily synthesized coefficient certificates,
with the order-level targets still unresolved.

6. Novelty boundary for the proposed full-orientation construction

eth_density_refinement/report.tex, subsection 'A local Cauchy rank
obstruction', already proves that the odd-unit matrix
  K_ij=1/(a+2i-2j)
has Smith invariant valuations
  e_j=2j+2*v_2(j!)=4j-2*s_2(j).
Its proof uses Cauchy determinants and factorial divisibility of integer
Vandermonde determinants. This local slope 4 fact is prior work within
the reviewed repository and should be credited explicitly.

What none of the seven reports supplies is an explicit integral
factorization valid at every retained valuation i, on the complete
same-bit orientation blocks, preserving the source and target groups,
preserving the O(L) packet arity, and retaining at most 6M/D modes of
each quotient index. Establishing these properties and handling
unramified-extension evaluation points is the substantive new step.
Merely restating the local Smith spectrum would repeat existing work.

If that full construction has weight slope 4 with the same multiplicity,
then the existing explicit r=256 schedule gives coefficient
  648.4410666487529/2 = 324.22053332437645.
The ratio to the same-schedule factorial-Cauchy synthesis is
  sqrt(3)/2 =0.8660254037844386,
a 13.3974596 percent reduction in its leading exponent coefficient.
It also improves on the stronger existing schedule-family factorial
infimum approximately 368.6540181. The corresponding new continuous
family infimum would be approximately 319.2637449, but this is optional
parameter optimization, not necessary for the new kernel result.

These coefficients concern upper-bound certificates for the normalized
contraction interface. They are not absolute SAT exponents in n and do
not establish wall-clock speedups or lower bounds for older programs.
