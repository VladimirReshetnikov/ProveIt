\subsection{How to reproduce the supplied computations}

From the extracted archive root run:
\begin{verbatim}
python3 verify_all.py
python3 -O verify_all.py
\end{verbatim}
The second command is an optional repeat demonstrating that optimized
Python does not remove acceptance conditions. A shorter review is
available as \texttt{python3 verify\_all.py --quick}; it skips the separate
root replay and is not a replacement for the complete audit.
The wrapper isolates generated files from the shipped reference results.
The root certificate can also be checked directly with
\begin{verbatim}
python3 code/independent_affine_audit.py \
  code/anchored_backend_certificate.json
\end{verbatim}
The local README documents outputs and the other individual scripts.
The supplied PDF can be rebuilt, given a LaTeX installation, with
\texttt{python3 build\_report.py}. The archive includes all referenced
\texttt{.tex} sections; no remote inputs are needed for compilation.

\subsection{What is not certified by this archive}

There is no new Lean formalization of the plan or norm certificate.
The programs do not implement the asymptotically fast matrix algorithms,
the complete exact interpolation contractor, or an end-to-end 3-SAT
solver. Their finite scalar timings would not predict the practicality
of those asymptotic algorithms. No threshold for the eventual constant
is asserted: the packing margins are small, the fixed matrix algorithms
are theoretical, and the hidden constants remain large.

The mathematical theorem is relative to the explicitly named contraction,
mode-counting, reduction, and ring-implementation lemmas of the reviewed
corpus. The full cited formalization was inspected at the statement and
source level, with its exact-commit CI status, but not rebuilt locally.
These are material boundaries of the present verification.

\section{Next targets that could change the order}

The most useful next search should change an interface that produces the
logarithmic loss. More finite menus within the same envelope can improve
the coefficient, but Section~\ref{sec:envelope} already quantifies the
limited remaining room for the present root architecture.

\paragraph{Original-variable measurements with paid shared information.}
A promising target is an exact decomposition which retains original
variable directions while exposing shared measurements of lower total
description entropy than the current selected-incidence indices.
Its theorem would need to specify the reconstruction identity, coefficient
access algorithm, precision, child degree, child wire count, and the cost
of enumerating or contracting the shared measurements. The incidence
coherence lemma explains why a fully shared linear substitution without
such measurements is insufficient. This is a research interface to
construct, not an algorithm established here.

\paragraph{A different graded exact crossing representation.}
The Anthropic paper already identifies the growth of the graded crossing
space as a possible source of a different denominator power. Ordinary
partition growth gives the square-root scale. A replacement with smaller
graded growth would still have to satisfy the complete locality and
duality identities and efficient coefficient access. Truncating or
regrading the same oscillator representation does not supply these
properties; earlier packets audit those restricted attempts
\cite{anthropic-paper,alternate}. This is an existing open route, not a
new improvement claimed by this memorandum.

\paragraph{A new packet geometry in another characteristic.}
The finite-abelian-group version of Lemma~\ref{lem:prime} identifies
precisely where the prime-cycle obstruction can be escaped. A viable
construction would still have to preserve enough interpolation nodes,
pay the jet-recovery loss, obtain an integral separated kernel, and close
the recursion. A lower initial precision alone does not meet those
requirements.

The proved advance in this archive is the combination of a new plan
family, compatible support choices, a sharper rectangular envelope, and
the paid recursive certificate. The requested smaller logarithmic order
for unrestricted 3-SAT remains open in this work.
