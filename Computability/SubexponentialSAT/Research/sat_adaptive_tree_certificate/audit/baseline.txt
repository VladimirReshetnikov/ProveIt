3. GLOBAL ASYMPTOTIC ENVELOPE

For fixed width k and n active variables, the strongest established order
available from compatible bounds in this corpus is

  poly_k(n,m) * 2^{O_k( n/sqrt(log n) *
                   min{log(2+m/n), log log n} )},

with polynomial space. Its implied constants are uniform in m/n. This gives
n/sqrt(log n) at fixed density; n log log log n/sqrt(log n) at
m=Theta(n log log n); and n log log n/sqrt(log n) in the unrestricted worst case.

If n includes unused variables, remove them and multiply the count by the
appropriate power of two. Retain the direct clause-network branch
poly(n,m)*2^{O_k(m/sqrt(log(m+2)))} where useful. Small logarithms are absorbed
by a constant-size base case. The direct branch appears in the primary
manuscripts and can matter when m=o(n); no later packet worsens it.

Key exact source: Research/sat_density_improvement/density_aware_sat_improvement.tex
lines 101-120 (main theorem, uniform constants, imported results), 122-139
(intermediate density), and 164-181 (normalized contraction premise).
The separate eth_density_refinement report gives the same regime result.

No incoming ZIP proves a smaller global logarithmic order. Each explicitly
states the general and fixed-density order are unchanged. Any constant C
improvement in 2^{(C+o(1))s/sqrt(log2 s)} is still an asymptotic improvement
between explicit upper bounds, but it must not be described as a stronger
big-O exponent order or as a resolution of the missing n/log n interface.

4. STRONGEST CONDITIONAL TARGETS

Research/3sat_precision_refinement/report.tex lines 640-735 constructs an exact
rank-encoded mode graph and explains why reapplying the general contraction
theorem is invalid: the compressed graph has only r genuine high-degree
tensors, violating the new instance's degree premise. For r increasing,
u=O(log M/log r), u'=O(log r), and the two apparent square-root savings cancel.

Its lines 742-757 state the missing Structured-mode acceleration hypothesis:
exp(O(M/u)) admissible recursive contractions, each <=M/8 wires, preserving
degree, precision, polynomial descriptions and polynomial space. Lines 764+
derive normalized 2^{O(s/log s)}, and lines 808-866 derive fixed-density
2^{O(n/log n)} and general 2^{O(n log log n/log n)}. The algorithm meeting the
hypothesis is explicitly not supplied. This remains the fastest conditional
global target in the reviewed corpus.

The 3sat_refinement conditional target n(log log n)^(3/2)/log n is weaker.
The 3sat_asymptotic_analysis missing-interface targets are
n sqrt(log log n/log n) (degree-preserving recursion) and n/sqrt(log n)
(uniform linear-wire compression). None is established.

7. ADAPTIVE-TREE NOVELTY / OVERLAP CHECK

The adaptive packet's exact new selection is a partition of r=9 vertices into
three triples, minimizing total crossing entropy for each weight array.
It proves H_cross <=(3/4)H_total by averaging 280 partitions. The block builder
is still flat, with its cost bounded separately by an l2-support cardinality.
It does not combine the averaging with a fast multiplication backend.
Its polynomial-space streamed separator tree is fixed and balanced.

The contraction-tree packet uses a fixed balanced tree for each near-equal
block and a fixed triangle; each merge is bounded by weighted l2 support:
  (sqrt(v1+v2+v3-(21/25)min(v1,v2,v3))/r) K.
No adaptive tree-permutation minimax theorem or Euclidean support averaging
for the whole operation set was found. Its report/report.tex lines472-478
EXPLICITLY lists observed pair entropies and different split trees as future
research: a finite-group optimizer is feasible, but a uniformly smaller
coefficient needs an all-budget-distributions analysis. Therefore merely
proposing an adaptive optimizer repeats an existing idea; proving a uniform
adaptive-tree/support theorem could close a stated open direction.

The full-mode weighted entropy inequality itself is already prior work:
  sum_e z_e h_e <= (sqrt(sum_e z_e^2)/r+o(1)) K(M,u).
Sources: cached_tree.tex lines50-65; adaptive_sat_review.tex lines458-493;
earlier joint-Cauchy packet. Do not claim this inequality alone as new.

8. RESTRICTED ORDER BARRIERS

Precision report lines589-638 shows a taper lower bound Omega(M/u), plus
2^{Omega(M/sqrt(u))} abstract feasible binary tuples even with ordinary-degree
caps. Factorial valuations grow linearly, so retuning that basis changes
constants rather than partition-exponent order.

The rank-compression degree obstacle is in precision report lines709-735.
For increasing grouping arity, packing forces u=O(log M/log r). Dense complete
mode graphs retain a constant fraction of the entropy at balanced separator
and contraction bottlenecks; raising r alone is therefore not a source of a
vanishing logarithmic factor. These are barriers to analyzed proof strategies,
not lower bounds on SAT or all conceivable contraction algorithms.
