1. Exact adaptive selection and entropy
======================================
For a fixed exact-weight allocation, replace opposite directed list domains
by a pair domain d_{uv}=|I_{uv}| |I_{vu}|. Empty lists contribute zero and
must be skipped before taking logarithms. Domain one is permitted.

For each fixed plan j, P_j=max_v product_e d_e^(v_e) is an integer and
F_j=(1/5) log_2 P_j. All exponents are 0, 2, or 5. Minimizing these exact
integers is equivalent to minimizing the matrix work bound, without a
floating-point comparison or a count oracle. Counts come from the inherited
exact-weight dynamic program. Fixed r in {7,9,13}, polynomial mode/weight
budgets, and polynomial count bit length make this selection polynomial.

Pointwise min_j F_j <= average_j F_j = max_(v_1,...,v_4)
[(v_1+...+v_4) dot g]/20. Applying the inherited weighted entropy bound to
the fixed finite collection of possible sums is legitimate even though the
maximizing support tuple depends on the entropy vector. No min/max exchange
or assumption of arbitrary edge permutation is needed. Assign the same
weight to both orientations of each edge, giving the factor two in
b^2=2 Q/(25 q^2 r^2).

The complete operation menus include all recursive block constructions and
the final triangle. Counting only the final triangles would leave a gap;
the supplied full support certificates do not have that gap.

3. Ring arithmetic and storage
=============================
Do not apply a field matrix-multiplication algorithm directly to the source
ring, which has zero divisors. The existing integer-coordinate/CRT bridge
is essential. It is sufficient that the source extension/truncation ring is
free of polynomial rank over Z/(2^p), with explicitly computable integer
structure constants of polynomial bit length. Lift coordinates to
[0,2^p), compute coordinate matrix products over sufficiently many
nonexceptional odd prime fields, reconstruct their nonnegative integer
values, apply structure constants, and reduce modulo 2^p. Every exact
coordinate product has a bound of the form inner_dimension*(2^p-1)^2,
whose bit length is polynomial in s. The number of coordinate products and
CRT primes is polynomial. No source-ring nonunit is inverted.

A fixed rational bilinear square algorithm with exponent strictly below
12/5 can have its fixed denominators cleared, excluding only finitely many
prime characteristics. The primary reference Le Gall 2014 explicitly works
over an arbitrary field and proves omega<2.3728639, already sufficient:
  https://arxiv.org/html/1401.7714v1
  https://arxiv.org/abs/1401.7714
The latest numerical omega is unnecessary here; the inherited common
backend bound 12/5 supports a fair comparison. A specific square algorithm
strictly below that threshold can be fixed once, so its constants and bad
primes do not depend on s.

Square blocking yields logarithmic rectangular work cost
  H_1+H_2+H_3-(3/5) min(H_1,H_2,H_3).
Rounding and padding cost only polynomial factors. Sequential bilinear
recursion and sequential CRT use polynomial overhead times the input/output
table storage. The work cost is at least any H_i+H_j, so every operation's
input/output table lies below the selected plan's bound. Singleton caches
are inputs to an operation and are included. Finite local regrouping code
does not implement or benchmark this theoretical matrix backend.

4. Every recursive entry remains paid
====================================
Caching a singleton tensor requires an actual child contraction for every
incident index assignment. The entropy bound gives alpha_r=sqrt(2(r-1))/r,
so the local time recurrence is
  T_d <= poly(s) [2^((alpha_r+o(1)) K_d) T_(d+1)
                  +2^((b_r+o(1)) K_d)].
The improved b_r is an aggregation coefficient, not a replacement for the
alpha_r child-entry cost. The candidate retains this separation correctly.

Calls for different cache entries run sequentially. Ancestor cached tables
are retained while a child is evaluated, so space is a sum over active
depths, bounded by a polynomial factor times the largest local table.
The time prefix sum of cache exponents must not be charged to space; the
candidate does not do so. Conversely, deleting the time prefix would be an
error, and the candidate's C_1 and C_infinity include it.

The local recurrence uses poly(s), with the input description cost carried
as one common polynomial factor in s+L. If a proof were to multiply a fresh
poly(L) at every depth, it would need repair when L is unrestricted. The
source's scalar-entry cost can instead be factored once across the complete
operation count. poly(s) accumulated across O(log log s) levels is
2^(O(log s log log s)), which is absorbed in the stated lower-order exponent.
