Date: 2026-10-26 Pacific; source snapshot ProveIt ab2fbc9e03d5c3d0ad6dec8686960bfe498b0b06.

Scope. This audits the new local contraction/table construction and the concrete normalized time/space certificate. It imports the existing exact deformation, precision, child-network, entry-evaluation and SAT-reduction framework. It does not independently prove the whole ETH assertion. The implementation is finite algebra verification, not a subexponential SAT solver and not an implementation of the asymptotically fast matrix backend.

1. EXACT TABLE ALGEBRA
For a set A of group vertices, define f_A on the directed pair-index axes with exactly one endpoint in A by summing the product of all Z_g (g in A) over axes with both endpoints in A. Each pair index is already a fixed exact-weight list index from the joint-Cauchy packet; no extra counting oracle is introduced.
For disjoint A,B, |A|=a, |B|=b, k=a+b, the common axes of f_A,f_B are precisely the 2ab directed A-B pair indices. The axes exclusive to f_A are the 2a(r-k) directed A-outside indices; exclusive to f_B are 2b(r-k). All three classes are disjoint. Matricizing produces f_(A union B)=f_A*f_B, with matrix dimensions whose logarithms are the sums H1,H2,H3 on those three classes. This is an exact distributive-law identity over any commutative coefficient ring, including the required two-adic quotient with nilpotents.

2. WEIGHTED ENTROPY AND MERGE COST
The compatible slope-four/near-unit-padded mode decomposition has at most (2+o(1))M/(r^2 D) modes of each q on each directed pair. Imported precision is (6+o(1))MD/u. Thus weighted sums of pair-index bit lengths satisfy sum_j w_j H_j <= (sqrt(sum_j w_j^2 v_j)/r+o(1))*K, where K=pi sqrt2/ln2*M/sqrtu and v_j are the disjoint axis-class cardinalities. This uniform bound also covers zero or small exact-weight allocations.
A square backend with exponent nu in [2,3] gives rectangular bit work, up to polynomial factors, 2^(H1+H2+H3-(3-nu)min H_j). This expression is the maximum of the three weighted sums obtained by placing weight nu-2 on one class and weight1 on the others. Therefore a valid merge coefficient is sqrt(v_total-[1-(nu-2)^2]min v_j)/r.
All subtrees are built once after all single-group caches are available. Since r is fixed, finitely many tree nodes multiply time by only a constant. The dominant table time is the maximum merge coefficient, not their sum. This does not reduce the fully charged cost of obtaining each single-group cache from recursive tensor contractions; the existing star-cache recurrence remains.

3. EXACT RING BACKEND AND BIT COSTS
Fix a rational exact bilinear square-multiplication base of exponent strictly below12/5. The classical Coppersmith-Winograd bound over Q supplies such a base; its dimension, rank and rational coefficients are constants. A finite collection of denominator primes can be excluded once and for all.
Represent a ring element in the fixed polynomial basis of (Z/2^p)[U,V]/(f(U),V^ell), f monic of degree h and irreducible modulo2. There are h*ell polynomially many coordinates. Choose canonical integer coordinates in[0,2^p). Each coordinate-pair scalar matrix product has nonnegative entries at most d_inner*(2^p-1)^2. Its bit bound is <=log2(d_inner)+2p+O(1), polynomial in the root size. Compute each scalar product modulo sufficiently many small odd primes avoiding the fixed denominators, using the rational base reduced in each prime field; reconstruct each exact nonnegative integer entry by CRT; then combine basis products and reduce modulo f,V^ell,2^p. Thus no nonunit or forbidden rational denominator is inverted in the target ring. There are only polynomially many coordinate pairs and CRT primes; their bit costs alter only polynomial factors.
A fixed bilinear base admits depth-first evaluation with quadratic matrix storage: form each fixed linear-combination input, recurse on one rank product, accumulate output, and release temporary arrays. Rectangular products are square-blocked with block size the smallest dimension. Matrix sizes and index lengths have polynomially many bits. Reordering tables for block access is achievable by sorting records, with polynomial logarithmic overhead. The rectangular work bound dominates input/output table sizes for nu>=2, so copying/reformatting does not raise the leading exponent.
For the three top blocks, all binary subblocks have size <=ceil(r/3)<r/2 in the concrete cases. Boundary cardinality2k(r-k) is increasing in that range. Hence simultaneous tables, matrix blocks, and recursion frames use space controlled by the largest top-block boundary. Across recursion depths, spaces add; their exponents do not add.
