# Local mathematical and implementation reviews

These files record independent AI-assisted review tasks conducted during
this research. They are not external human peer review or proof-assistant
certificates.

- `SUPPORT_AUDIT.md`: protected-support isolation, carry bound, both source
  presentations, and exact finite combinatorial checks.
- `HALF_CARRIER_AUDIT.md`: refined root gap, undoubled midpoint carrier,
  noncircular Pell-index recovery, completeness, and leading form.
- `ORDINARY_FOURTEEN_AUDIT.md`: early-index bootstrap and ordinary
  strong-rank hypothesis for the degree-56 equation.
- `audit_midpoint_independent.py`: a separately implemented multiplication
  of all eight formal radical factors, with 72 diagnostic assignments.
- `midpoint_independent_audit.json`: its deterministic receipt.

The final editorial review found and resolved two notation issues: the
unscaled carriers have separate symbols rather than subscript zero, and
the internal ZFC-provability statement explicitly uses inherited proofs
formalizable in ZFC. No external-truth-to-internal-provability inference
is used. The relevant theorem and ordinary proof dependencies are stated
in the main article.
