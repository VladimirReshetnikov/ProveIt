# Three-parameter calculus and modular saturation

**Experimental alternative; not the preferred equation.** This prototype has
231 nonnegative integer variables, degree 4, 183 quadratic residuals, 6,369
expanded monomials, and coefficient height 83,899,166. It does not improve the
retained 229-variable natural parent. It is separate from the main package's
247-variable equation over unrestricted integers. The two coordinate domains
must not be conflated.

The mathematical contribution is a reusable modular saturation lemma. It
removes a bounded disequality witness from a source proof calculus by using an
unbounded modular inverse. Replacing the four-parameter Łukasiewicz axiom by
K, S, and Peirce leaves seven bounded local columns instead of eight. The
current compiler's additional gates and branches cost more than the removed
range certificate saves. We retain the measured failure because it identifies
a real architectural tradeoff rather than another untested size claim.

## Contents

- `research_note.tex`: construction, both directions of the modular lemma,
  the propositional-basis replacement, completeness lifts, and limitations.
- `equation.json`: all 183 literal quadratic residuals in 231 natural variables.
  The equation is their sum of squares equal to zero.
- `expanded_polynomial.json`: every collected coefficient of that quartic.
- `source_spec.json`, `local_majorant.json`, `SUMMARY.json`: source change,
  recorded majorant certificate, and exact prototype metrics.
- `basis_certificate.json`: a 521-step K/S/Peirce and modus-ponens derivation of
  `((c->d)->a)->((a->c)->(b->c))`; no assumptions or extra inference rules.
- `make_basis_certificate.py`: deterministic constructor for that certificate.
- `verify_research.py`, `VERIFIED.json`: a small independent checker and its
  receipt. The checker uses only the Python standard library.
- `build_saturated.py`, `PARENT_PIN.json`: compiler adapter and exact hashes of
  its inherited dependencies. The inherited source closure is not duplicated.
- `elimination_certificate.json`: the natural-variable contraction certificate;
  its raw source is regenerated by the compiler adapter.

## Standalone checks

From this directory run:

```sh
python verify_research.py
```

This checks every axiom instance and MP reference in the 521-step proof,
independently expands the sum of 183 squared residuals, compares every
coefficient with the supplied polynomial, recomputes its metrics, confirms
all 231 variables occur, and rejects two deliberate corruptions. It also
runs 4,061 small soundness controls, a heterogeneous CRT control, the
positive-quotient lift control, and countercontrols demonstrating why the
guard-unit hypothesis and separate bound on U matter.

These finite checks do **not** prove the unbounded CRT/Pell interpretation,
the inherited C222-to-ZFC calibration, or ZFC consistency. The source-change
and saturation arguments are ordinary mathematical proofs in the research
note. There is no new end-to-end Lean formalization.

## Rebuild against the retained parent

The exact dependency is `docs/incoming/ConZFC_Residual_Bases_Denominator_Engineering_2026-10-25.zip`
in ProveIt at commit `3ecd6a6cf53d47519228328567f45fb7ee9781d9`.
Its SHA-256 is
`f02c30fd6455f618db0f654691887975a933f2200dafa9be7696135dc229058b`.
Extract the archive and set `PROVEIT_NATURAL_PARENT` to the absolute path of
`ConZFC_Residual_Bases_Denominator_Engineering/natural`:

```sh
PROVEIT_NATURAL_PARENT=/absolute/path/to/ConZFC_Residual_Bases_Denominator_Engineering/natural \
  python build_saturated.py --output /absolute/path/to/empty-output-directory
```

The adapter checks hashes of all 30 pinned compiler/checker files before
loading them. It regenerates the raw arithmetic graph, the contracted
231-variable equation, the expanded polynomial, and contraction certificate.
The inherited independent contraction checker is called during generation.
For an additional raw affine-export check, invoke the parent's
`check_affine_export.py` on the regenerated `raw/semantic.json` and
`raw/equation.json`, with `--expanded raw/expanded_polynomial.json`.

The parent supplies the existing descending-factorial, binomial, Pell-frame,
and numerical-calculus proofs. This directory intentionally has enough data
for standalone coefficient/propositional checks but requires that external,
pinned closure for arithmetic regeneration. The main 247-variable construction
elsewhere in the package remains standalone.

## Interpretation and caveat

Relative to the retained ordinary arithmetic and C222 calibration, the new
source calculus has a refutation exactly when ZFC does, and the prototype
quartic has a natural zero exactly when that calculus has a refutation.
Consequently the corresponding no-natural-zero sentence is provably
equivalent in ZFC to Con(ZFC). The note proves the new source and saturation
steps; it does not relabel inherited proof obligations as fresh formal work.
There is no claim of global minimality, a new variable record, or literature
priority for modular saturation.
