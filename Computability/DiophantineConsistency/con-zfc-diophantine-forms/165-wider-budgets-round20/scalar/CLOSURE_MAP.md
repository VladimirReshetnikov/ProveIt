## Four optional nonsemantic files omitted

To reduce archive size without deleting mathematical source, the package omits
these historical rendered copies and aggregate repository indexes:

1. `inherited_rebased/inherited/roots_baseline/standalone.pdf`
2. `inherited_rebased/inherited/roots_baseline/thirteen/standalone.pdf`
3. `source/provenance/rootfusion/CON_ZFC_FORMS_README.md`
4. `inherited_rebased/inherited/scalar_source/provenance/rootfusion/CON_ZFC_FORMS_README.md`

Their exact former hashes and lengths are recorded in
`OMITTED_OPTIONAL_FILES.json`. Both PDF counterparts `standalone.tex` and
all underlying Markdown proofs are retained at their original paths.
Neither PDF is read by an active checker, proof-reconstruction recipe or
source theorem.

The two identical aggregate indexes described repository-wide delivered
packages for waves5–10, aggregate frontiers and file listings. They were not
source proof lemmas. Before omission, a complete search found no reference
to their filename in retained Python, Markdown or TeX files. All actual
proofs, source calibration interfaces, individual licenses and coefficient
recipes summarized by those indexes that belong to this closure are retained.
The active root source-pin list excludes these four optional files.

Upstream `SOURCE_PINS.json`, `MANIFEST_SHA256.json` and similar files nested
beneath `inherited_rebased/` are preserved byte-for-byte as HISTORICAL provenance
indexes. Their mentions of optional omitted files do not define this package's
active closure; do not use those historical package-manifest checks as the
release entry point. Run the root checker and root replay, whose complete
verified closure is the root manifest. No mathematical proof file or actual
coefficient payload has been omitted. No duplicate-path materializer or
hash-only storage is used; retained files remain directly readable.
