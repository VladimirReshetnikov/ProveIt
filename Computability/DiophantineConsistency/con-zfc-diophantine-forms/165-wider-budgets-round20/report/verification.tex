\section{Reproduction and evidence boundaries}
\label{sec:verification}
\subsection{Portable entry points and complete definitions}
From the extracted release root, run
\begin{quote}\ttfamily
python3 -B verify\_release.py
\end{quote}
The integrated verifier checks the release inventory and runs its explicit
verification plan in a disposable temporary copy. The option
\texttt{--output ../receipt.json} saves a fresh receipt outside the sealed
release; \texttt{--integrity-only} checks inventory rather than mathematical
reproduction. Optimized steps set \texttt{PYTHONOPTIMIZE=1}, so child
Python processes inherit the same mode. This keeps rebuilds and
fresh receipts from changing the sealed reference data. The plan and final
receipt identify the component commands actually executed. Mathematical
checks need Python 3.10 or later and its standard library, not network
access, a repository checkout, an external computer algebra system or a
proof assistant.

The selected direct equations are \file{signed/balanced238},
\file{signed/dimension237} and \file{signed/power239}.
Each contains its entire residual array and its fully collected quartic.
\file{signed/exposed241} and \file{signed/power_exposed242} are technical
source stages, explicitly labeled. The frozen transformation certificates
record every source edit, row operation, shear, projection and restoration.
A historical coordinate label by itself is not a proof that its semantic
value survived an integral translation; the restoration maps supply that
interpretation.

The height-one catalog supplies complete final coefficient arrays and
ordinary literal polynomial text, not an unevaluated universal-polynomial
parameter. Graph certificates specify all aliases, unit paths, internal
flows, equality choices, source-row occurrences and accepted deletions.
The scalar equations are the complete files
\file{scalar/integer11_degree298_ops147.json} and
\file{scalar/integer11_degree300_ops145.json}, together with their six
bound numerical leaves. Registers abbreviate polynomials; only the eleven
declared coordinates are independent unknowns.

Rebuild the report with
\begin{quote}\ttfamily
sh report/build\_report.sh
\end{quote}
This needs a standard pdfLaTeX installation. The builder runs three passes
in a temporary directory and rejects overfull boxes or unresolved references.
The principal residual appendix is generated directly by
\file{report/render_residuals.py}; its binding receipt records source and
TeX hashes. PDF metadata and font bytes may vary across TeX installations.
The literal coefficient arrays and numerical payloads are the normative
mathematical data, not one particular PDF binary.

\subsection{Independent finite checks}
The checks distinguish source semantics, exact finite algebra and byte
identity. Required tests use explicit exceptions and remain active with
Python assertions disabled.
\begin{itemize}
\item The signed checker imports no producer. It recognizes the exact
shared-error source mutation, replays the retained raw projection and
translation maps, checks the complete factorial-free power-base and
horizon edit, and verifies all source-frame atoms. It authenticates the
parent closure, checks unit-pivot restorations, inverse row and coordinate
maps, exact final residuals and every collected quartic coefficient.
Quadratic restorations require the eliminated coordinate to occur only
linearly in the other rows. Malformed coefficients, invalid restorations,
noninvertible maps and invalid nonlinear substitutions are rejected.
\item The height-one checker independently reconstructs the full energy
from divergence squares and equality/unit identities. It checks occurrence
coverage, row boundaries, internal trees, alias classes, unit anchoring and
all source pullbacks. The new anchored-product equality mode must select
an existing unit alias and an alias of its own class. The contraction
records must identify a genuine internal flow edge. Universal source-lift
identities, complete coefficient height, exact degree, constant and every
live coordinate are checked on the actual emitted arrays.
\item The scalar checker reconstructs all fixed numerical payloads and
checks every live gate in independent free polynomial rings. It proves the
exact integral center shears, collects all center-remainder coefficients,
and verifies attained actual degree coefficients. A separately implemented
top-form checker binds 23 complete highest homogeneous forms, including
all rebased terms involving $h$. Both alternative operation labels at each
of the 292 arithmetic gates are tested: 584 mutated graphs are rejected.
\item Deterministic component rebuilds replay frozen finite choices rather
than rerunning an optimizer. The normal and optimized-interpreter receipts
state the exact checks performed, and the integrated release replay
confirms that the portable source closure is sufficient.
\end{itemize}
The incoming-source inspection receipts are separate from the new endpoint
receipts. All seven incoming packages passed their source reconstruction or
verification entry points in isolated clean copies, in normal and inherited
optimized-Python modes, without altering the original inputs. A separate
implementation recollected every coefficient of 60 incoming quartic
sums of squares and one 153-variable octic; it also strictly validated
155 residual files containing 205674 literal terms. The scalar numerical
reconstruction independently followed 430 machine transitions through
943 tiles and the full convolution and mask recipe. Recollecting an incoming array authenticates its coefficients
and measured finite invariants; it does not independently prove all
unbounded arithmetic claims of that incoming package.

\subsection{The retained logical boundary}
The shared direct parent closure is under \file{signed/parent252}.
The complete incoming shared-error proof and the factorial-free proof are
retained under \file{signed/inherited_shared} and
\file{signed/inherited_free}; their historical metrics are not the new
endpoint metrics. The newer ordinary delta proofs and frozen transformations
identify the exact composition. The C222, ZF and ZFC interfaces remain
those named in Section~\ref{sec:foundation}.

The height-one outputs inherit precisely their cataloged arithmetic
sources. A matched old source is not silently identified with the new
238-variable principal. The scalar branch retains its separate source34
compiler and numerical tuple, the complete rebased incoming proof, and
the older source closure. The degree-298 handoff restores the specified
$B_0$-only source; no unproved early cancellation or deleted scale guard
is used.

Hashes certify file identity, not mathematical truth. Coefficient replay
proves finite identities, not an unbounded Pell or CRT theorem. The new
ordinary proofs compose with identified inherited calibrations; neither
a Python run nor inclusion of a theorem-name source file rebuilds their
full transitive proof-assistant development. No new end-to-end kernel check,
encoded object-language ZFC derivation, proof of consistency, or decision
of the calibrated equations' solvability is claimed.
