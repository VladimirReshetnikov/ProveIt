- `report/`: complete readable report, exact compact row check, TeX sources.
- `integer_system/`: joint-positivity 28/26-variable equations and builder.
- `integer_system_audit/`: independent row/degree/coefficient reconstruction,
  complete actual source34 coefficient tuple, inherited mathematical proofs.
- `norm/final10/`: completed ten-integer finalizer, literal source-specific
  circuits, actual fixed leaves, author checkers, inert inherited source.

  guard, actual leading-coefficient/degree checks.

  positive-gap 86-record/81-position source at height1873; read-only auditors.
- `alternative/`: 17-local-witness literal stack/Horn polynomials, intermediate
  tradeoffs retained only to reproduce the authored derivation.
- `direct/`: flow and affine-product proofs, 23-local-witness polynomial,
  uncompiled global constructor, authored checks.
- `direct_audit/`: independent exact local audit and inert pinned API sources.
- `disjointness/`, `disjointness_audit/`: standalone asymmetric parity theorem
  and independent arithmetic audit; no complete consistency integration.
- `review/`: eight-package comparison, exact pins, static intake receipts,
  pinned formal-status documents. Full incoming archives are not redistributed.
- `verify.py`: manifest verification, isolated authored replay, rebuild checks.
- `negative_controls.py`: changed-byte tamper control. Component auditors have
  separate mathematical mutations; these two test classes are not conflated.
