# Provenance and attribution

This package is a new research proposal prepared for incorporation into
Vladimir Reshetnikov's ProveIt Diophantine-consistency collection.
The comparison and primary retrieval snapshot is
beb0192cb8dc36f78c369c080f2adfbc1887a486.

The new material consists of the congruence-carrier compositions, the
divided auxiliary-norm construction and its balanced polynomial instance,
the two triangular integer reductions, their proofs, independently written
finite checkers, the paper, and the integration wrapper.

The native compiler, literal machine calibration, coefficient recipes,
normalized source kernel, earlier polynomial packets, and their source
proofs are inherited. Their contributors' original notices and licenses
are retained verbatim. In particular:

- licenses/ preserves the root and package 44 MIT No Attribution texts,
  the complete native license directory, Wade's notice/license, and
  normalized-source and machine attribution.
- integer/coefficients_source/licenses/ preserves the matching source
  package and machine notices for the unrestricted-integer branch.
- Git blob identities, exact source URLs, byte counts and SHA-256 hashes
  identify the preserved sources.

An upstream attribution notice can describe an older numerical tuple.
It is retained as historical attribution; active coefficient specifications
are the appropriate ACTIVE_BINDING.json, original complete binding,
and coefficient proof, not old numerical parameters in a notice.

The license for this package is MIT No Attribution, consistent with the
target repository. No additional attribution obligation is imposed.
