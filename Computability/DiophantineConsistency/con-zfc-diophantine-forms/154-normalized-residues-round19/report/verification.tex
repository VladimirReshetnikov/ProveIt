\section{Reproduction and evidence boundaries}
\label{sec:verification}
\subsection{Portable entry points}
From the extracted release root, run
\begin{quote}\ttfamily
python3 -B verify\_release.py
\end{quote}
The integrated verifier authenticates the release inventory, copies the
working tree to a disposable temporary directory, executes the explicit
\file{VERIFY_PLAN.json} and checks that the sealed reference tree remains
unchanged. The optional \texttt{--output} argument saves a fresh receipt
outside the sealed release, for example
\begin{quote}\ttfamily
python3 -B verify\_release.py --output ../new\_verification.json
\end{quote}
The \texttt{--integrity-only} option checks inventory rather than mathematical
reproduction. Python and its standard library suffice for the mathematical
checks; neither network access, a repository checkout, an external computer
algebra system nor a proof assistant is required.

The selected signed equations are \file{signed/balanced244},
\file{dimension243}, \file{sparse250}, \file{dimension246} and
\file{lowheight247}, with the latter four also below \file{signed/}.
The additional \file{exposed247} and \file{balanced247} entries are technical
source and construction checkpoints. Each directory supplies complete
residuals, the complete collected polynomial and exact metrics. The frozen
certificates record every row addition, shear and restoration.

The height-one catalog identifies \file{minimum528}, \file{compact534},
\file{balanced580}, \file{sparse620} and \file{sparser717}. Each has a
complete coefficient array, ordinary literal polynomial text, a full graph
certificate and its source binding. The scalar material retains the authentic
degree-300 control, its numerical payloads and the precise restricted
family theorem. It does not supply a new lower-degree calibrated endpoint.

The report has a separate build command:
\begin{quote}\ttfamily
sh report/build\_report.sh
\end{quote}
A standard TeX installation is needed only for that command. The builder
uses a temporary directory, runs three passes, retains compilation logs and
rejects overfull boxes or unresolved references. The principal residual
appendix is generated directly from the literal JSON by
\file{report/render_residuals.py}; its binding receipt records both source
and generated-TeX hashes. PDF bytes can vary with TeX versions and metadata;
the literal equation arrays are normative mathematical data.

\subsection{What was independently checked}
The final component receipts record the following checks in ordinary and
optimized Python. Required tests use explicit exceptions, so disabling
Python assertions does not disable the checks.
\begin{itemize}
\item The signed checker imports no producer. It authenticates the exact
centered source, recognizes the deleted guard and the eleven changed
common-sphere coefficients, and derives the new odd-square row from the
recorded translation. It replays every inverse row or coordinate operation,
every unit restoration and every index compaction. For quadratic restorations
it checks the only-linear-occurrence condition. It recollects every coefficient
of all seven emitted arrays and rejects malformed coefficients, restorations,
noninvertible changes and invalid nonlinear substitutions.
\item The height-one checker reconstructs every coefficient from divergence
squares and equality/unit identities. It checks all source pullbacks,
occurrence boundaries, tree edges, aliases, signs and the universal symbolic
lift at every vertex. All five selected profiles passed, including deliberate
polarization and other certificate corruptions. Four matched-source replays
first reproduce the original Round~18 graph hashes, then check the new
polarization results. Isolated release-only normal and optimized rebuilds
also passed.
\item The independent scalar highest-form audit checks the exact registers
at the authentic coefficients, including the complete negative-square highest
part of $P$. Those finite identities supply the inputs to the unbounded
polynomial degree argument. The separate scalar checker reconstructs all six numerical payloads,
binds every live gate of the attaining control, checks its exact
center-remainder certificate, and rejects both alternative operation labels
at each gate. The graph rebuild is byte identical.
\item A separate implementation recollected all coefficients of 44 incoming
direct arrays, including intermediate and comparison endpoints, in normal
and optimized modes. Their supplied expansions and measured domains,
dimensions, degrees, supports and heights agreed. This does not certify
all unbounded theorems of the corresponding incoming packages.
\end{itemize}
These are component execution results, not an inference from merely listing
commands. The integrated release receipt records which sealed-plan steps
actually ran. The mathematical audits separately checked the normalized
sphere and odd-radix witness arguments, the polarization bijection and the
restricted scalar degree theorem.

\subsection{The retained logical boundary}
The common-remainder arithmetic input and its portable ordinary source
closure are retained under \file{prior_direct_closure}. The earlier signed
sources used by the height-one comparisons are bound separately under
\file{round18_closure}. They preserve the Pell, CRT, factorial, orientation,
strict-range and finite-calculus arguments and their named C222/ZF/ZFC
interfaces. The scalar branch retains its separate source34 numerical
compiler, native calibration, signed-rank, carrier and interpolation route.
No coefficient tuple or domain is silently exchanged between branches.

Authentication establishes file identity, not mathematical truth. Exact
coefficient replay proves finite algebra, not an unbounded classification
theorem. The ordinary witness proofs compose with the explicitly identified
inherited calibration; a hash, an included Lean interface file or a successful
Python run does not rebuild a transitive proof-assistant development.
No new end-to-end kernel check or encoded object-language ZFC derivation is
claimed. Nothing in these checks decides whether ZFC is consistent or
whether any calibrated equation has a zero.
