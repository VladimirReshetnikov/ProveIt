the new local reduction. Their presence is not a claim that every recursively
cited source theorem has been re-formalized or rechecked in this session.

documents refer to their original contexts. They are not active script
dependencies. The new report and root `SOURCE_PINS.json` identify the paths
used in this delivery; all verification scripts run with bundled data.

arithmetic compiler, signed/normalized Pell interface, and the new prime
separation polynomial. The first three stages retain their source proofs;
the last stage is proved in full in the new article.
