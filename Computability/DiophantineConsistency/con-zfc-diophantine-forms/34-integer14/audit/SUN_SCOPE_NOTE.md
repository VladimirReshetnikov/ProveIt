# Scope of the ten-integer comparison

Primary source checked: Zhi-Wei Sun, *Ten unknowns for Hilbert's tenth
problem over the integers*, arXiv:2609.01594v2, revised 2 September 2026.
https://arxiv.org/html/2609.01594v2

Theorem 1.1 represents every recursively enumerable set with ten integer
witnesses. Thus sixteen integer variables is not a universal record.
Section 7's explicit final expression still requires the instance-specific
source polynomials and exponents supplied through the cited 2021 compiler.
Those data have not been instantiated for this report. The new 16-variable
construction instead supplies a concrete circuit tied to the existing
K215/quartic coefficient recipes. No claim that 16 is theoretically minimal
is justified.
