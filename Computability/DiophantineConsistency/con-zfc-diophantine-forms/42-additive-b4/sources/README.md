These are supplemental source copies from the pinned ProveIt revision,
not a second active build tree. SOURCE_LEDGER.json at the package root
records their repository paths, exact commit and delivered SHA-256 hashes.
The subpackages contain additional source proofs, exact coefficient data,
licenses and more detailed provenance.

KEndpoint215.lean records the existing formal machine endpoint. Its
imports require the original ProveIt Lean development; this archive
does not claim to rebuild it or to formalize the new Diophantine adapter.
The mathematical equivalence is composed from the identified ordinary
machine/compiler and arithmetic theorems, not from a claimed proof of
Lean's soundness inside ZFC.

shift and a later 60-operation representation. The active B4 parent is
the literal pre-shift JSON in ten_integer/data/parent_quartic31.json.
The report explicitly gives that parent's residuals. These source copies
must not be used to replace its variable order or shifted coordinate
without applying the documented transformation.

Relative paths and reproduction commands inside historical documents
refer to their original source packages. Use the top-level reproduce.py
for the delivered artifacts. Some text copies have a normalized terminal
newline, as disclosed in the provenance ledger.
