# Fourteen unrestricted integers with even strong traces

New literal endpoints: **14/85/110** and **14/87/108** (variables / exact degree /
charged binary operations), improving the matched 14/86/112 and 14/88/110 points.
The older 14/82/113 point remains a separate tradeoff.

The ordinary proof supplies the signed even-trace normalization, an unweighted
two-root merger, exact maps and fresh-witness restoration to the authenticated
odd-scale source. The full six coefficient integers and finite recipe are kept.
No global optimum, consistency assertion or new kernel certificate is claimed.

Run `python -B build.py --check`, `python -B check.py`, `python -B -O check.py`,
and `python -B reconstruct_coefficients.py`. All use only the standard library.
See PROOF.md, report_section.tex, CHECK.json and CLOSURE_MAP.md. A separate general
correlated-radical separation lemma is retained without a twelve-variable record.
