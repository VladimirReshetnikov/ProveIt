# Attribution and boundaries

The fixed compiler tuple, original package31 source, and Jones arithmetic interfaces are inherited from Vladimir Reshetnikov's ProveIt repository and the mathematical work attributed there, including James P. Jones's Diophantine representation constructions. Repository source receipts are in SOURCE_PINS.json. The upstream documents retain their original attribution and semantic boundaries.

Newly authored here are the combination of the frozen selective code with sparse +1 target padding and the parity-calibrated binary block, the explicit nine-variable circuits, their proofs of numerical applicability, and their exact degree/gate audits. The sharp near-square majorant and positive-divisor finalizer are inherited from the preceding wave6 construction, with proof reproduced in PROOF.md rather than claimed as new in this iteration.

Copied Python circuit utility code comes from that preceding local artifact. The selective verifier and code certificate are newly authored sibling work, copied here to make the deliverable self-contained. No upstream programs are fetched or executed by the builder. Upstream mathematical JSON data is parsed by standard-library code.

The present result is not a consistency proof or a new end-to-end formal proof-assistant rebuild. Imported compiler and arithmetic theorems remain separately identified. LICENSE preserves the repository license supplied with the preceding artifact.
