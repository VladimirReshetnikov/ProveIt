## 2. A fixed-weight square-combining lemma

**Lemma.** Let `m >= 2`, let `u0,...,u_(m-2)` be odd integers and let `u_(m-1)` be any integer.
If a rational number is a signed sum

```
sum_(j=0)^(m-1) epsilon_j 2^j sqrt(uj),
```

then every uj is an integer square. Conversely, if all the uj are integer
squares, every such signed sum is an integer. In the latter case the sum is odd.

**Proof.** Omit zero radicands. Write each nonzero uj uniquely as `dj bj^2`,
where dj is a signed squarefree integer and bj is positive. Radicals belonging
to distinct signed squareclasses are linearly independent over Q. One way to
see this is to work in the multiquadratic extension generated by the radicals
and apply its distinct sign characters; this also includes negative radicands.
In the coefficient of a fixed nontrivial squareclass, the terms coming from
the first m-1 indices have the form `epsilon_j 2^j bj`, with bj odd. Their
2-adic valuations are exactly their distinct indices j. If the last term has
the same odd squareclass, its coefficient has valuation at least m-1. If its
squareclass is even, it is the only term in that class, since the earlier
radicands are odd. Thus in every nonempty nontrivial class the coefficient has
a unique term of least 2-adic valuation. It cannot vanish. Linear independence
therefore rules out all nontrivial squareclasses. Every nonzero uj is a
rational square and, being an integer, is an integer square. The converse and
oddness follow directly. This argument does not assume that the original
radicands are nonnegative. QED.

This proof only uses the elementary fact that an odd integer plus an even
integer is nonzero, iterated after factoring powers of two. It does not need
any real-size bound on the radicands.

For P13 the relevant uj are

```
H^2 Afirst, Dmain/4, H^2 Bguard, H^2 Fhalf, H^2 Caux.
```

The first four are always odd integers. Indeed q is even, X and Y are
multiples of eight, a is a multiple of eight, Delta is 3 modulo 8, and c is
odd. Thus `Dmain=4 mod 8`. Also Afirst and Bguard are 1 modulo 4, and Fhalf is
odd by its division-free formula. H is odd. Consequently a zero of P13 forces
all five displayed radicands to be squares. The formal-norm product has a
zero factor over C, so the lemma applies to the corresponding signed sum.

The elementary rational-square fact used here is: if `(a/b)^2` is an integer
and gcd(a,b)=1, then b^2 divides a^2, hence b=1.

## 4. Rational integrality for the adjacent-coefficient Pell equation

**Lemma.** If Q>1 and V are integers, and y is rational with

```
Q V^2-(Q-1)y^2=1,                                  (AP)
```

then y is an integer. Q need not itself be a square.

**Proof.** Replace V,y by their absolute values, both positive; zero is
impossible in (AP). Write y=a/m in lowest terms, m>0. Equation (AP) implies
`m^2 | (Q-1)`. In particular `(Q-1)y` is integral. If V=1, then y=1.
For V>1 define

```
V'=(2Q-1)V-2(Q-1)y,
y'=(2Q-1)y-2Q V.
```

V' is an integer, and the identity
`(2Q-1)^2-4Q(Q-1)=1` shows that (AP) is preserved. Further,

```
(Q-1)(y^2-V^2)=V^2-1>0,
(QV)^2-[(Q-1)y]^2=QV^2+Q-1>0.
```

Hence `y>V` and `QV>(Q-1)y`, which give `-V<V'<V`. The new norm excludes
V'=0. The reduced denominator of y' remains m: its numerator is congruent
to a modulo m, since `Q=1 mod m`. Replacing V',y' by their absolute values
and applying strong induction on V reaches V=1 and forces m=1. QED.

This is an inherited elementary Pell lemma, already proved in
`positive/upstream/source69_PROOF.md`; it is reproduced here because it
closes the only rational-to-integral recovery in the new construction.

### 6.1 An explicit odd normalized strong coordinate

Put `Aparam=a+2` and choose the new strong index

```

zstrong=psi_Aparam(m),
f=chi_Aparam(m).
```

The composition identity gives

```

```

Since `D^2-1=Delta c^2`, the binomial formula

```
psi_D(c)=sum_(j>=0) binom(c,2j+1) D^(c-2j-1)(D^2-1)^j
```

shows that c divides psi_D(c): the j=0 term has a factor c, and every
j>=1 term has a factor c^2. Hence c^2 divides zstrong. R,c,m are odd;
the even-base Pell recurrence makes zstrong odd. Therefore

```

```

is an odd positive integer. Choose r=(i-1)/2 and I=Delta i c^2. The Pell
identity yields

```
f^2=1+Delta i^2 c^4=F2,
I^2=Delta(f^2-1).
```

As Delta=3 modulo 8 and i,c are odd, `f^2=4 mod 8`; thus f/2 is an odd
integer. This proves the needed normalized restriction directly, without
an unjustified assertion that a generic Pell period can be made odd.

### 6.2 An explicit auxiliary witness with the squared modulus

Write R=2n+1, where n is odd. Define Q_n by

```

```

The elementary identities are

```

Q_n(1-Aparam^2)=(-1)^n psi_Aparam(2n+1).
```

They follow, for example, from Q_0(z)=1, Q_1(z)=4z-3 and the recurrence
`Q_(n+2)=(4z-2)Q_(n+1)-Q_n`. Put

```

ystar=psi_I(R).
```

These are positive integers and

```

```

Since `I^2=Delta(f^2-1)`,

```
I^2 = -Delta = 1-Aparam^2 mod f^2.
```

Thus Vstar=-c modulo f^2. Since c divides I, Vstar=-R modulo c. Also
`f^2=1 mod c`, so gcd(c,f)=1. Consequently

```

is an integer (indeed positive), and

```

This is the exact form of V used by P13. Thus requiring the old T to be
a multiple of f does not lose the canonical existential witnesses. This
reconstruction is also present in `positive/upstream/package65_proof.md`,

## 9. What is new here, and what is inherited

The established literature already uses products of conjugate radical
sums to combine square conditions. It would be incorrect to claim this
norm method itself as a new discovery. The present local contribution is
the use of forced odd radicands and the fixed weights 1,2,4,8,16, together
with absorption of the main Pell congruence into the norm center and the
adjacent-Pell midpoint shear. These steps remove auxiliary witnesses and
large magnitude-dependent separating weights for this concrete source.

Relevant primary sources inspected during the audit include:

* Bayer, David, Hassler, Matiyasevich, Schleicher, *Diophantine equations over
  Z: universal bounds and parallel formalization*, arXiv:2506.20909v2,
  https://arxiv.org/html/2506.20909v2 . Section 5, Lemma 5.1 uses the
  classical square-combining norm with a magnitude-dependent weight

  arXiv:2609.01594v2, https://arxiv.org/html/2609.01594v2 . Section 2 recalls
  the classical square-combining polynomials and Pell/Lucas identities.
* Matiyasevich and Robinson, *Reduction of an arbitrary Diophantine equation
  to one in 13 unknowns*, Acta Arithmetica 27 (1975), 521--553, DOI
  10.4064/aa-27-1-521-553. The publisher metadata was inspected; the full
  publisher PDF was not accessible during this audit.

No comprehensive priority search or proof of global optimality has been

Completeness uses

```
t=[tau+gamma+4d+8fhalf+2delta y-(2Q-1)V]/2,
```

which is integral: tau and (2Q-1)V are odd, while gamma is even.

For `Z0=2Ht+b0`, conjugate pairing is now

```
(Z0-S)^2+2H(2Q-1)V(Z0-S)+H^2V^2+4H^2delta.
```

The same degree argument gives exact degree 1392, since the cross
coefficient still has degree 59 and the dominant first-four radical has
degree 28. This optional version uses smaller fixed scale coefficients;
no operation-count or artifact-verification claim is made for it here.
