## Text and identifier conventions

`PROVENANCE.json` distinguishes repository Git blob IDs from SHA256 hashes of
local artifact bytes. The compact component's four immediate inherited text
copies each have one additional terminal line-feed from materialization;
removing that byte reproduces the observed repository blob exactly. Their
mathematical content, JSON data, and polynomial source are unchanged. Both
identities are recorded rather than conflated.

New coefficient payloads have their own literal hashes and format declarations.
The three compact/positive coefficient tuples are separate specializations.
No source port from one tuple is silently substituted into another.

## Scope of review

Ordinary unbounded proofs and finite artifact checks are separate evidence.
The package includes AI-assisted independent internal reviews, not external
human endorsements. It proves equivalences under the named inherited
calibrations, does not decide consistency, and does not claim a new end-to-end
Lean/Rocq object or encoded object-ZFC derivation.
