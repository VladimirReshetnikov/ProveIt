# Incorporation notes

Use a new directory for this complete release. The existing numbered packages
and incoming parent archives are immutable comparison sources.

Suggested review order:

1. Read the report's results, integral-restoration theorem and exact Gram proof.
2. Run python3 -B verify.py --rebuild.
3. Inspect gram/balanced/equation.json and the principal residual appendix.
4. Review the source theorem boundary in the report and the retained parent
   archives before adopting the composed Con(ZFC) endpoint.

The principal equation is the 240-variable Gram form with 5,803 terms and
height 6,404. Preserve the 240-variable ordinary sum-of-squares companion
with 9,217 terms and height 4,512, and the lower-height Gram companion with
9,357 terms and height 4,160: these represent different support/height
tradeoffs. The factorial-free 241-variable companion is a separate
source-lineage application of the same projection theorem.

The narrow full-rank certificates rule out further affine consequences
from constant residual-row combinations for these projected systems.
They do not establish optimality for arbitrary arithmetic or logical changes.

The pairing-ring theory construction is a separate research artifact.
Its future compilation requires a concrete target-language translation and
exact axiom coefficients before any final Diophantine size claim.
