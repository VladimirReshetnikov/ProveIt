\section{Calibration and the meaning of the checks}
The source34 integer chain uses the pinned ordinary signed-kernel theorem,
its mixed-field coefficient adapter, initialized finite-strip extraction,
and the exact K215/refutation correspondence. The source44 positive chain
uses its own normalized positive kernel and compact compiler adapter.
The file \texttt{baseline/CALIBRATION\_CITATIONS.md} identifies each theorem,
source path, commit and available copied proof. These are different
coherent coefficient interfaces, not interchangeable symbols satisfying
only a few numerical bounds.

The new work proves arithmetic witness transformations on top of that
ordinary chain. For a reader who has not accepted the inherited calibration,
the independently stated new conclusions are predecessor zero-existence
equivalences, together with the identified calibration obligations. This
boundary is not repaired by running more test assignments, authenticating
a digest, or citing a theorem about a related machine without its adapter.

The repository's external Lean theorem about the exact machine and its
syntactic refutation predicate is also distinct from a newly exported
object-language ZFC proof of each polynomial biconditional. No such new
export is claimed here. This iteration does not resume the paused
formalization project.

\subsection{Reproduction}
Each component includes its literal circuit, an independently transcribed
specification or checker, ordinary proof and source bindings. Exact
polynomial identities and nonzero leading coefficients provide algebraic
and degree evidence. Finite Pell examples and deliberate corruptions test
transcription and exceptional cases; they are not substitutes for the
unbounded existence and recovery arguments.

The release-level reproduction script runs the listed checks in normal
and optimized Python, authenticates the payloads, and checks that literal
artifacts rebuild without byte changes. Its receipt distinguishes executed
checks from inherited mathematical assumptions. The source ZIP contains
this report's TeX and PDF, executable checks and the actual fixed integer
payloads. It requires no solution of the resulting consistency equation
and makes no search claim about whether such a solution exists.

\subsection{What remains open}
There is no single definition of ``simplest'' that makes all the rows
comparable. Nine-variable equations retain a variable-count advantage;
shorter operation-count formulas with more variables remain relevant;
and direct quartics optimize degree instead. Further compression must
preserve the unbounded reverse witness construction, rather than only
produce a smaller circuit on a few sample assignments.

The generic tiling compiler in the separate exponentiation section is not
silently instantiated with the raw 943-tile list. That list contains an
all-zero tile. A bare strict-boundary rectangle-existence test would accept
a trivial rectangle and would not express the required initialized
computation. A valid new endpoint needs an explicit initialized source
adapter, with its proof, before its variable count can be advertised as a
Con(ZFC) construction.
