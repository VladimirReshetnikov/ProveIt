## Transferable lemmas and exact limits

### First priority: squared-output factorial radius

Bootstrap `direct/proofs/NEW_RESULTS.md`, SHA-256
`4325a6efb837934469efd2718ebe04f871a145fef0c1a853d5e595e718a780cd`,
proves for all natural n,F:

```
F = ceil((F²+1)^n / binom(F²+n,n))  iff  F=n!.
```

The proof was checked directly. Put K=n! and R=F². A fixed point gives
`1<=F<=K` and, for n>=2,

```
0 <= K - K*product((R+1)/(R+j), j=1..n)
  < K*n*(n-1)/(2F²).
```

For n>=4, monotonicity in R and R>=1 give the lower quotient
`2^n/(n+1)`. Its ceiling is at least n: check n=4 separately, then use
`2^n>=n(n+1)` from n=5 onward. Therefore F>=n, the deficit is <K/2,
and F>K/2. Substituting that improved bound gives deficit
`<2*n*(n-1)/K<=1`. Thus the ceiling equals K. At n=0,1 it is identically1;
at n=2 it lies strictly between1 and2. At n=3 the ceilings for F=1..6
are `2,4,5,6,6,6`, with only F=6 fixed. F=0 cannot be fixed. Conversely,
at F=K the same deficit is strictly less than1/2. The separate n²F-radius
lemma and one common square radius for arguments <=H are also proved.

This is a complete all-input ordinary lemma, not a sampled fixed-point
search. The exact natural ceiling rows are
`N+C=CF+r+1`, `C=r+s+1`.

The present raw source uses the output-linear radius `d=f*K²`. Replacing
its two radius products by `f*f` is a plausible one-product source saving;
the archived source uses a different local-column/compiler organization,
so its 781/956-variable counts do not predict our new counts. A valid
transfer must re-establish the changed literal row definitions, radix and
binomial bounds before factorial interpretation, omitted-index collapsed
seed exclusion, all source signs and both completeness maps. In particular
the current encoded-index choose-two estimate must use the changed numerator
`N=(1+f²)^K`; the bound `P=1+(t1)f<=1+f²` is available only after proving
`f=K!>t1`. Recompile and fully review the resulting integer projections
before claiming any final variable/term/height improvement.

**A concrete obstruction prevents treating this as a one-gate patch to the
accepted74-predicate source.** Its K-index slack guard has already been
removed. The current collapsed-K exclusion uses the unconditional relation
`d=f*K²>=K` before factorial correctness is available. With `d=f²`, the
retained presemantic bounds `K>=3,f>=2` do not give `d>=K`. Invoking
`f=K!` to supply that bound would require the very K-index interpretation
that the collapsed-branch proof is supposed to establish. The all-input
factorial fixed-point theorem does not by itself resolve that circularity.
Restoring the K-index guard would cost three integer guard witnesses, while
the local radius rewrite only removes one product wire; that route could
worsen the final variable count. A fresh noncircular branch-exclusion proof
or a measured different compiler is needed before any endpoint improvement.

### Common modular Pell residues

Pell Residues `report.tex`, Sections4–5, separates the freely chosen Pell
base A from a certified lower bound L. For radix q>=2 and maximum lower
digit index H, impose the single congruence

```
2*A*(q+1) = (q+1)²+1 + q^(H+1)*h0.
```

Then the quadratic-algebra map `sqrt(A²-1) -> q+1-A` modulo `q^(H+1)`
gives, simultaneously for every n,

```
X_n(A)+(q+1-A)*Y_n(A) == (q+1)^n  (mod q^(H+1)).
```

The congruence has arbitrarily large positive A: the gcd of `2(q+1)` and
`q^(H+1)` is1 or2, and in the latter case `(q+1)²+1` is even. Choose A
above both L and q+1. The residue expression is positive since
`X_n>(A-1)Y_n`. Thus exact Euclidean low-digit and divisibility rows have
natural witnesses. In this supplied compiler eleven whole numerator powers
disappear, while indexed Pell pairs remain. Growth-frame decoupling is
essential: one cannot append the congruence to an arbitrarily fixed old A.
This is a promising larger redesign, not a sign-only reduction of the
current75/74-predicate body.

### Centered factorial without a separate radius

Valuations and Centered `direct_quartic/centered_factorial_proof.md`,
SHA-256 `cf9e7a4313e372a3f8d48984eef4a49a9914d10ad4a27300ec214467b7815adf`,
proves for all natural n,f:

```
f=n! iff f=floor((2f+n+1)^n / (2^n*binom(f+n,n))).
```

The pairing proof was checked directly. With a=n! and
`m=f+(n+1)/2`, the quotient is `a/product(1-d²/m²)` over positive
distances from the mean. It is >=a, so a fixed point first forces f>=a.
The distance-square sum is `n(n²-1)/24<=a/6`; hence the excess is at most
`a/(6a-1)<1`. The cases n=0,1 give exactly1. This proves both existence
and uniqueness without assuming the intended factorial value first.

For odd n=2h+1, the power of2 cancels and the graph is simply
`(f+h+1)^n = C*f+r`, `C=r+s+1`, `C=binom(f+n,n)`.
The archive explicitly pads the proof horizon and majorant odd, proves the
binomial digit bound for arbitrary candidate f, and uses the **sum** of both
factorial numerators in the shared radix. It does not assume the second
candidate numerator is already bounded by the first. Its 23->21 power-call
saving is real for that source, but does not establish a saving in the
current body without redoing these interfaces and sign theorems.
