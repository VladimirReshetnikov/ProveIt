## Reproduce

Only Python3's standard library and retained local files are required for
all mathematical-artifact replays. Normal and optimized receipts must match.
`replay.py` copies this entire package to a fresh temporary path and repeats
all required stages there,with no access to the original sibling rounds.

LaTeX compilation is separate and optional: `pdflatex report.tex` twice on a
normal TeX installation. `build_tex.py` regenerates section.tex from PROOF.md
using Pandoc,escaping formula characters rather than treating them as Markdown
emphasis. The numerical recipe appendices are complete fixed definitions,
not additional graph variables. TEX_BUILD.log/PDF_QA.json record actual QA.

not finite-test proofs of unbounded theorems,consistency decisions,actual
zeros,new compiled formal-kernel artifacts or encoded internal-ZFC replays.
