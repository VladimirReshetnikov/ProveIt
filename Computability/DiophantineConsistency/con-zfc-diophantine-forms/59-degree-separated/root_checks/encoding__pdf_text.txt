                       Degree-Separated Quadratic Extraction
                A source-coding improvement for explicit consistency equations

                                        Research appendix for ProveIt
                                                  23 October 2026

                                                          Abstract
          Separating constant, linear, and quadratic reversed kernels removes all cross-degree label constraints.
      A frozen certificate for the original 31-variable, 22-equation quadratic source has convolution height
      2161 instead of 5556. The source identities, coefficient bounds, unconditional positivity, and optional
      all-real positivity repair are proved below, with exact finite verification artifacts. This appendix is a
      local source theorem, not an end-to-end consistency proof or a claim of a globally simplest equation.


1     Degree-separated source extraction
The gain in this section comes from changing the multiplication architecture, not from finding a smaller
code for the previous homogenized square. Linear and quadratic monomials are placed in separate kernels,
so that their labels may coincide. For the explicit code below the linear monomial N and the quadratic
monomial J 2 both have label 2; this would be prohibited by every previous dummy-coordinate isolation
condition.

1.4      One-cell positivity repair for signed adapters
An adapter that must prove positivity for every integer g, rather than only g ≥ 0, may use

                                              G+ (B, U ) = G(B, U ) + B 2162 .

This changes no target coefficient since 2162 > Q, and increases the exact height only to 2162. Completing
the square, and using the bounds above,

Indeed the normalized subtractions 2C/B 443 and 2C 2 /B 37 are each less than 1/4 for B ≥ 4096C. Positivity
thus holds for every real U . The added off-target coefficient is 1, within the same coefficient bound; a
sparse bounded-input adapter can take N1 = B 2163 .

1.5      What is and is not certified
The exact standard-library replay and ten corruption controls are in verify_split.py and test_split.py;
ordinary and optimized Python produce byte-identical verification receipts. Neither search code nor
a third-party symbolic package is a replay dependency. Compared with the frozen wave7 source, the
convolution height falls from 5556 to 2161 (about 61.1%) and H + M + 2 falls from 5741 to 2279 (about
60.3%). These are source exponents, not final equation degrees. The finalizer must still be composed and
its actual arithmetic circuit independently audited. No global optimum or new end-to-end proof-assistant
certificate is claimed. The unbounded compiler/refutation and arithmetic finalizer theorems remain
identified inherited semantic dependencies.
