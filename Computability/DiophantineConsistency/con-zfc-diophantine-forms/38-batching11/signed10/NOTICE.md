# Provenance

The literal `data/parent_quartic31.json` and arithmetic-circuit/verifier
framework originate in ProveIt source31-sun10, commit
22e75dd6b87b1b199bb08c778d7cf075ae5aae08. The earlier source code's MIT-0
license, upstream native compiler licenses, and machine notices are preserved
elsewhere in the enclosing archive.

The data in the sibling `compiler/` directory are the new coherent
complemented-label compiler tuple, and all four ports are rebound together.
The source parent JSON is a generic symbolic polynomial; its historical
default-binding metadata does not select the active instance.

The source-coding stage in this directory is new to this synthesis. The
Lucas bridge follows Zhi-Wei Sun, arXiv:2609.01594v2, with source31's previously
proved coprime square and quintic divisor mergers. The new contribution is
an application of the shared quadratic batching theorem to that interface.
The development and checks are AI-assisted. No independent human review or
new proof-assistant verification is asserted.
