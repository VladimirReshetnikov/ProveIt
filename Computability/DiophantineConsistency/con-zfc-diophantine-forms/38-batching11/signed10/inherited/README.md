# Inherited source 31 proof and finalizer

These files are byte-exact archival copies from ProveIt at the commit in
`SOURCE_PINS.json`. They are included for offline inspection of the coprime
square merger, quintic divisibility merger, signed separating weights, and
three-root norm. The manifest records each source path, byte count, and hash.

`SIGNED10_PROOF.md`, Sections 4–7, and
`INDEPENDENT_MATHEMATICAL_REVIEW.md` contain the relevant inherited proofs.
`build_signed10.py` and `circuit.py` preserve the original evaluator code.
They are reference material, not part of the current build.

The old positional source, degree, coefficient values, default binding,
and references to files not included in this archival folder describe the
historical instance only. They do not select the active instance here.
The current construction and all active binding information are in
`../PROOF.md`, `../data/INSTANCE.json`, and the sibling compiler directory
`../../compiler/`. The build entry point is `../build.py`.
