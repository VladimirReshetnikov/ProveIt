# Alternative-route components from the present investigation

Two complete source-level improvements are provided. Neither is advertised
as a newly compiled small Con(ZFC) polynomial.

1. `selector/`: A natural-domain interpolation theorem and stutter deletion
   replace three Boolean selectors by one natural selector in the incoming
   height-controlled commutative certificate. The literal local polynomial
   has 21 witnesses, five exposed coordinates, exact degree14 and 50,461
   monomials, compared with 23 witnesses at the same degree. A two-ternary
   selector variant has 22 witnesses, degree12 and 40,990 monomials. Both
   entire sparse polynomials are supplied, with inherited branch source rows.
2. `gadgets/`: Exact smaller graphs for the actual direct annotated checker.
   A quadratic graph jointly represents zero-test and predecessor; natural
   linear masks shorten tree and list-head graphs. Complete ordinary
   polynomials, expansions, metrics, and elementary universal proofs are
   supplied. They preserve the existing numerical coding.

All scripts use only Python's standard library and raise explicit exceptions
on failed checks. Run each directory's `build_and_verify.py` normally or
under `python3 -O`. Generated JSON is deterministic.

The `selector` result builds on source68's local C222 Horn rows and the
incoming Round11 height certificate. `gadgets` builds on the incoming Joint
Guards pairing graph and the actual checker conventions recorded in
ProveIt's active research. These dependencies are retained explicitly;
there is no claim that inherited semantic calibration was reconstructed
from scratch or that the whole direct checker was compiled.
