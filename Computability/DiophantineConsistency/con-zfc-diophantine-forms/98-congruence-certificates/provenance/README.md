# Source ledger

`SOURCES.json` binds the comparison snapshot, immediate source archives, retained 16-variable comparison circuits, positive parent circuits, and compact44 recipe. Each component retains its own more detailed source pins and coefficient binding.

The `comparison16/` directory contains verbatim inherited source files for the degree-184/135-operation and degree-192/134-operation comparisons. They are reference snapshots, not additional equations proposed by this contribution; relative links in those snapshots belong to their original archive.

Historical notices and source ledgers are retained verbatim. Their original paths and examples describe the historical source package. The root ledger and current component binding files identify the actual delivered copies. The ordinary calibration theorems are explicitly inherited, and a complete new proof-assistant replay is not claimed.
