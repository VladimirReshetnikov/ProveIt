# Signed-power bootstrap and transport absorption

The new mechanism yields a sextic in 34 unrestricted integer unknowns,
versus the incoming 35-variable sextic. It first removes a quantified scale
by a cubic signed-power guard and a self-dividing transport carrier, then
uses monic projection. This is not another projection of the old equation.

Read PROOF.md, section.tex and review/MATHEMATICAL_REVIEW.md. The proof has
been independently reviewed as ordinary mathematics relative to the named
inherited results. It is not newly kernel checked. AUDIT.json reports the
separate finite algebra, source-integrity, coefficient and diagnostic checks.

The endpoint signed34_sextic.json is the sum of squares of 19 cubic-or-lower
residuals. Its degree is exactly six. The intermediate signed40_sextic.json
has 40 variables and 25 residuals. absorbed30_octic.json matches rather than
improves the incoming 30-integer octic. No quartic record is claimed.

From this directory run:

    python build.py
    python check.py
    python review/check_independent.py

All three also run with -O and are independent of the current working
directory. Python 3 and SymPy are required. The complete retained incoming
integer41 directory is copied byte-for-byte under upstream/q41, including
its proofs, provenance, licenses, literal parent systems, coefficients,
source geometry and dependency documents. UPSTREAM_COPY_RECEIPT.json seals
all copied members. Those are inherited sources, not newly authored proofs.
No upstream builder is imported or executed by our verification scripts.

All four coefficient payloads are present. The active polynomial JSON files
resolve their paths relative to their own containing directory, and check.py
checks the decompressed raw integer hashes and lengths against the inherited
manifest. The binding is the entire source34 mixed-parity-unrounded-1064921
tuple, not arbitrary parameters. Historical upstream metadata is preserved
verbatim as provenance and is not an alternative active binding.

SEXTIC_RESTORATION.json gives exact integer-polynomial restoration into the
intermediate system; tau_old=tau+E(c-eta). The JSON variable tau denotes the
shifted Pell-root coordinate. The mathematical proof uses inherited native
compiler, syntactic calibration, ordinary strong-rank and signed auxiliary
step-down results. No global minimality or end-to-end proof-assistant claim
is made.
