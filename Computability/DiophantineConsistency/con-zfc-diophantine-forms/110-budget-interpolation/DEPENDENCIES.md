# Dependency closure and source authentication

The runtime closure is self-contained apart from Python and SymPy. Every
advertised command runs offline from a fresh arbitrary directory, with
`PYTHONPATH` removed. It requires no earlier workspace, hidden prior release,
download, credential, proof assistant, or repository installation.

The eleven-variable component intentionally imports the sibling `guard/`
arithmetic modules and fixed six-port tuple. The positive-ten component is
self-contained and uses its distinct compact44 tuple. Those coefficient
tuples must not be mixed. The absorption component imports only
`finalizers/source/con-zfc-parity-norms-2026-10-23/`; the two other inspected
finalizer families are not dependencies and are omitted.

## Complete explicitly replayed source releases

Two original archives and their complete extracted source files are retained:

1. Rootfusion: `baseline/ConZFC_13_Integer_Norms_2026-10-24.zip` and
   `baseline/ConZFC_13_Integer_Norms_2026-10-24/`.
2. First parity family: `baseline/con-zfc-parity-norms-2026-10-23.zip` and
   `finalizers/source/con-zfc-parity-norms-2026-10-23/`.

`check_sources.py` checks archive length, SHA-256, Git blob identity and CRC,
then compares every extracted source file byte-for-byte to the authenticated
archive. The original upstream manifests and all licenses are unchanged.
The portable prior replay runner accepts the explicit retained parity path
to avoid including an unnecessary second extracted copy.

The archive pins and source URLs are recorded in `baseline/FETCH_LEDGER.json`,
against ProveIt commit `7e533c33819ee1f703b69f2778a767cdc069940d`.
That historical inspection ledger also records other downloaded files which
are not dependencies of the current advertised replay. They are intentionally
not all shipped. Their recorded authentication or inherited review claims
must not be confused with fresh replay of those unretained archives.

## Retained proof interfaces

The full current component pin sets, payloads, recipes, proof interfaces,
licenses and notices are retained unchanged. Guard and eleven source pins
authenticate the copied centered-budget, interpolation, rootfusion and
native-calibration material used in the new ordinary proofs. Positive-ten's
pins preserve its source URLs and complete compact44 binding and reconstruction
inputs. Original nested pin documents retain their historical path contexts;
they are source evidence, not a promise to reproduce every historical build
entry point. The master verifies the present component pin maps and explicit
prior replays.

Alternative's three exact predecessor files are retained under
`provenance/certificate_predecessor/` and authenticated by its unchanged
`PROVENANCE.json`. Relevant machine/compiler proof and notice files accompany
them. No unimplemented special-function graph is silently treated as a
materialized ordinary polynomial.

## Packaging exclusions

The bulk inspection baseline, unused finalizer source families, unrelated
positive-family source directories, large repository tree listings, unfinished
exploration snapshots, and redundant prior archive are excluded. Necessary
source and output paths are enumerated in `PACKAGING_INVENTORY.json`; the
root seal covers every file in this delivery. Ordinary source-relative prose
links outside the declared closure are historical citations, not hidden
operational dependencies.

Independent review uses SymPy 1.14.0. It is an external runtime dependency,
not bundled third-party code. The source archive identities, exact local
polynomial proofs, and inherited semantic calibration are distinct claims.
