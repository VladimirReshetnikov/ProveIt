# Attribution and verification scope

This contribution builds on Vladimir Reshetnikov's ProveIt repository and
its incoming research contributions. Original retained source notices and
licenses accompany each inherited component. No inherited file is presented
as newly authored work. The root report explains which mathematical steps
are new and which compiler/calculus, Pell, carry and representation theorems
are inherited.

Authored replay scripts in this release do not execute retained upstream
programs. Retained Lean sources are inert reference material, not an assertion
that a new end-to-end theorem has been kernel checked. The one-stack Lean
constructor is explicitly a proposal that has not been elaborated.
