# Provenance and reuse

This package was prepared for Vladimir Reshetnikov's ProveIt repository.
The new mathematical reductions, coefficient-budget certificate, explanatory
text and checking programs were developed in this research iteration.
The package carries the repository's MIT No Attribution license in `LICENSE`.

Reused source material keeps its existing licenses and notices. The component
directories identify that material precisely; preserve their `NOTICE.md`,
source pins, coefficient bindings, and `licenses/` directories. In particular,
the fixed machine, compiler data and coefficient payloads have inherited
attributions that are not replaced by this root notice.

The repository snapshot is commit
`2605669a532342f153b13eb6b4a0af4b54f5fa37`. No remote repository was changed.

The finished equations retain the repository's native compiler and syntactic
ZFC calibration. This package proves new reductions and supplies exact algebra
checks; it does not claim a new end-to-end proof-assistant certificate or an
absolute minimum for the size of a consistency equation. The independent
coefficient-budget architecture is a proved source theorem and local
polynomial, not a completed fixed-dimensional consistency equation.
