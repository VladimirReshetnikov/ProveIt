\section{Reproduction and verification boundary}
\subsection{One command from a clean extraction}
From any directory run Python on the extracted release's
\path{verify_release.py}. It requires Python 3.10 or later, SymPy, and NumPy.
The command first rejects optimized Python execution ($\texttt{-O}$ and
$\texttt{-OO}$), verifies the exact manifest file set and every SHA-256,
and checks all retained source Git blob identities. It then creates an
isolated temporary copy and executes only the newly authored checks there.
Any check failure causes a nonzero exit. It does not rewrite the sealed
release or import an upstream program. No network or proof-assistant install
is required for the finite replay.

The archive contains the editable \LaTeX{} source and rendered PDF;
all exact JSON arithmetic circuits and degree ledgers; raw and compressed
native coefficients; compressed signed derived coefficients with precise
encodings; all small isolation certificates; the newly authored builders and
verifiers; source proofs, exact pins, and inherited licenses/notices.
For a normal TeX Live or MiKTeX installation, run \texttt{pdflatex report.tex}
twice from \path{report/}, or use \texttt{latexmk -pdf report.tex}.
The supplied shell helper is a Linux fallback for the research environment;
it uses its existing TeX installation without shell escape.
The environment-specific font/format cache is not shipped.

The archive-level manifest is integrity metadata, not an external digital
signature. Its own file cannot contain its own hash. The outer ZIP hash
should be recorded by the recipient if a trusted transport digest is desired.

\subsection{Checks actually supported by the scripts}
\begin{enumerate}
\item Reconstruct the complete native tuple from the literal tile list and
verify its bounded decoder, synchronization, rank-controller conditions,
and every payload hash.
\item Expand all 22 shifted parent residuals in a symbolic integer polynomial
ring, deriving the 136 weighted records and their actual coefficient bounds.
\item Exhaustively check each source-record/monomial/target collision
condition, including padding translations and coefficient signs.
\item Prove the shared source circuit equals the explicit source in
$\Z[B,\beta,K_0,M_C,M_F]$, with 159 port-monomial terms.
This is exact symbolic identity checking, not random polynomial testing.
\item Replay the full nine-variable source and finalizer with the actual
tuple, its separately translated domains, the Pell-majorant identities and
norm obstruction/completeness fixtures. A separately authored audit checks
the same full circuits and leading coefficient.
\item Replay every retained ten-integer source and tail with signed test
inputs; check its polynomial identities and nonzero top coefficients over
three finite fields. Circuit degree propagation gives the matching upper
bound, so a nonzero diagonal coefficient proves exact total degree.
\item Multiply the positive construction's formal radicals independently,
replay full univariate polynomials over three finite fields using the actual
coefficient tuple, check the unit guard, and test its pre-index bounds.
A separate leading-form audit compares the analytic leader with the literal
circuit.
\item Independently traverse the important pinned 38/44 circuits for all
live binary gates and compare the cost--degree frontier against the correct
optional variants, not only headline forms.
\end{enumerate}
Numerical fixtures are finite diagnostics. Exact symbolic identities and
nonzero modular leading coefficients have the stated finite mathematical
force; neither proves an unbounded compiler theorem by itself. The newly
written proofs, composed with the stated inherited theorems, provide the
ordinary mathematical consistency equivalence formalizable in ZFC.

\subsection{Formalization status at the later pin}
The postscript separately records
\texttt{2d7766807b92f6d505649885d472e20cc0236b4f}, later than the
construction snapshot. Its exact status and compiler documents report
an executable supplied-data Jones compiler, sparse coefficient reader,
explicit index construction, the full primitive-recursive graph compiler,
and an externally checked nine-variable ZFC endpoint whose coefficients
remain existence-based. Extraction of the actual refutation program to
\texttt{ScalarPRCode.Realizes haltingTest} remains open. The ordinary P67
compiler proof and a checked object-level ZFC derivation remain separate
open integration boundaries.

We have not rerun those Lean builds here and do not claim that the new
literal equations in this archive have been kernel checked. The new sparse
quadratic interface is an attractive integration target for that executable
compiler; the later progress does not retroactively certify these circuits.
