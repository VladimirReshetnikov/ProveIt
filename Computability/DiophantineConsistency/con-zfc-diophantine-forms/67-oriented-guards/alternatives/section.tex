\section{Beyond K215 and Jones: an architectural fork}
The search need not preserve the blank-tape machine. A concrete next experiment is to use a standard fixed-input universal machine and place the ZFC-refuter program in a coefficient-supported initial boundary. Neary--Woods provide standard universal machines with pairs $(5,5),(6,4),(9,3),(15,2)$; the five-symbol machine uses 22 instructions (\url{https://doi.org/10.3233/FI-2009-0036}). This suggests reducing the native transition alphabet, not claiming a smaller polynomial from machine size alone.

The missing theorem is an economical finite-input boundary compiler. The input must not be expanded into a new tile per symbol, nor represented as a polynomial in a variable base whose degree is its length. A useful prototype first proves arbitrary finite input boundaries for a test machine, then materializes a universal machine's exact refuter input and counts all coefficients. No such endpoint is claimed here.

A genuinely independent published route is Carl--Moroz's direct Diophantine representation of first-order provability, specialized to finite G\"odel--Bernays axioms (\url{https://webdoc.sub.gwdg.de/ebook/serien/e/mpi_mathematik/2007/132.pdf}). It removes proof enumeration but, in its published explicitization, is much larger than the present frontier. For a proof-oriented alternative, Larchey-Wendling--Forster's constructive Coq DPRM route through FRACTRAN is available (\url{https://arxiv.org/abs/2003.04604}); its extracted size for this refutation task remains to be measured.

A tempting shortcut is invalid: deleting FRACTRAN priorities and allowing any applicable fraction leaves a vector-addition system under prime valuations. Its ordinary reachability is decidable, so it cannot serve as a uniform universal refutation engine. An actual zero-test or equivalent capability must remain. Finally, every consistency calibration must be internal to ZFC and use finite proof translations, not an assumption of ZFC's arithmetic soundness. The accompanying \texttt{alternatives/REVIEW.md} records the exact open obligations.
