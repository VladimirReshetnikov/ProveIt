\section{Verification, reproducibility, and proof status}
\subsection{What has been checked exactly}

The finite checks complement the unbounded proofs. They establish that the supplied literal equations implement the stated transformations; they do not search for a ZFC contradiction or prove an infinite arithmetic theorem by testing examples.

The independent source reviewer imports no builder or optimizer. It checks the frozen original rows, exactly one changed body row, all 66 predicates and their private coordinates, 575 original prefix-row deduction identities, and 118 complete polynomial combinations of original rows. It independently reconstructs 605 usable prefix signs and confirms all 34 unsigned frame atoms. It binds the nine selected power calls to their actual exponents, retained index slacks and common base. It also checks all 19 division/remainder identities used to recover the omitted signs, including the radix identity required to bound the CRT modulus.

A separately authored projection verifier uses its own sparse-polynomial addition, multiplication and substitution routines. It replays every monic elimination over \(\Z\), checks that no unconstrained coordinate was dropped, verifies the full retained-coordinate and retained-row partitions, and compares every surviving quadratic residual. It then expands the entire sum of squares and compares every coefficient of each of the four projected polynomials. Thus their variable counts, exact degrees, supports and coefficient heights are measured from complete literal equations.

For the height-two construction, a third independent checker verifies all 1,243 source-row pullback identities, 383 canonical old product definitions, 165 new products, 1,942 unit equations, all coefficient-collision conditions, and the entire 14,518-term polynomial. It verifies that all 3,564 coordinates occur, the constant term is one, and the degree is exactly four.

Focused corruption controls alter an inverse coefficient, a collected polynomial coefficient, the unit seed and recurrence, a product reconstruction, a source identity and a transformed row sign. They are rejected. The relevant source and coefficient checks also pass with Python optimization enabled, so their validation does not depend on disabled \code{assert} statements. Small numerical controls illustrate the signed-power inequalities and the essential base-one counterexample; the lemmas in the report supply the unbounded proofs.

\subsection{Rebuilding the package}

The supported numerical tools use Python 3 and its standard library. From the extracted package root, run
\begin{quote}\ttfamily\small
python3 verify\_all.py
\end{quote}
This authenticates the pinned source, checks both radius variants with the independent source reviewer, verifies all four projections and all their coefficients, and checks the preferred height-two equation. Verification receipts are written under a temporary directory unless an explicit output location is requested.

For a deterministic rebuild of the two projected families, the builders support \code{--check}, which regenerates and compares their complete artifacts. The height-two builder can generate an independent output directory from its supplied source; the resulting normative files are byte-identical. Exact invocation examples are in the package README. Rebuilding the PDF additionally requires a standard LaTeX installation with the listed common packages.

The final appendix prints every residual of the principal 577-variable equation. The JSON coefficient lists remain authoritative for byte-level reproduction and include all four projected alternatives and the height-two polynomial. Each term \code{[c,[i,j,...]]} means \(c\,x_ix_j\cdots\); an empty index list means the constant monomial. All indices are zero-based.
