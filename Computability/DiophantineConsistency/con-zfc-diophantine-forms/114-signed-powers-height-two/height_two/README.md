# Coefficient-height-two consistency quartic

The preferred equation is `anchored/expanded_polynomial.json`:

- 3,564 unrestricted integer variables;
- exact degree four;
- coefficient alphabet exactly `{-2,1,2}` and constant term one;
- 14,518 nonzero monomials;
- sum of 3,350 explicitly supplied quadratic squares.

`PROOF.md` proves exact zero-set equivalence with the included
1,457-variable signed-frame source by coordinate projection and a unique
polynomial extension. The source's calibration to syntactic ZFC
refutability is inherited from the main research report; this coefficient
compiler itself requires only fixed polynomial identities.

Run the independent checker:

```
python3 verify.py anchored --mutations
python3 -O verify.py anchored --mutations
```

Rebuild the literal artifacts with:

```
python3 build.py anchored/source.json rebuilt --anchor-linear
```

The delivered data contains the preferred anchored construction. A simpler
3,716-variable unanchored comparison can be generated by omitting
`--anchor-linear`; its generated files are not included. It has the same
coefficient alphabet and zero-set correspondence. All programs require
only the Python standard library. The package neither assumes consistency
nor claims that coefficient height two is a global optimum.

An exploratory compilation of the newer quotient-radius source gave
3,567 variables, 3,353 rows, and 14,668 monomials at the same degree and
height. Those larger comparison files are not included. The output-radius
`anchored/` point is supplied as the smaller coefficient-height tradeoff;
the quotient-radius source gives the better small-variable projected
quartic elsewhere in the main archive.
