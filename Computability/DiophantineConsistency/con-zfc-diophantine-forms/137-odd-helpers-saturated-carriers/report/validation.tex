\section{What is checked and how to reproduce it}
\subsection{Independent mathematical and literal reviews}
The direct review checks all eight retained charts, not only the headline
three. It independently reconstructs the raw signed-domain modifications,
all $18$ power lowerings, $15$ primary norms, the complete frame and cap pool,
$11$ successor residue ideals, private graph scopes, Horn identities,
monic eliminations, translations and every collected quartic coefficient.
Eight deliberately corrupted artifacts must be rejected. The separate
ordinary audit treats the negative comparison-base branches, reconstructs
private helper witnesses and gives the self-radix soundness and completeness
order. Finite helper examples are diagnostic controls, not the proof.

The independent compact audits certify all live gates by exact local
polynomial identities, recover full leading forms or specified nonzero
leading monomials, authenticate source and coefficient bytes and examine the
unbounded witness maps. Across the four eleven-integer circuits and the two
low-degree circuits they reject $720$ individual live-gate corruptions in
each Python mode. The positive review rejects a further $163$ individual
gate corruptions, as well as targeted scaling, shear and operand changes.
Thus $883$ single-gate corruptions are rejected per mode; this count excludes
the many other algebraic checks and supplemental controls.

In particular, the positive review reconstructs the complete indexed BFS943
coefficient tuple from its printed finite decoder and verifies the
$N_{\rm old}=q^6N$ normalization by exact symbolic identities.
The integer review independently reconstructs the source34 recipe and
verifies the interpolation chronology, rather than using numerical evidence
for an unbounded statement. The root ordinary review separately checks the
thirteen-integer square-class argument, literal old-zero maps, unit-product
conjunction and attained coefficient.

\subsection{Finite offline replay}
The exact receipt environment is Python $3.12.14$ with SymPy $1.14.0$.
The direct arithmetic and the compact producer builders use the standard
library; selected independent symbolic audits use SymPy. All equations have
literal integer coefficients and fixed exponent schedules. The finite
coefficient recipes construct fixed data and do not simulate the encoded
machine or search for a refutation.

From the extracted release root, run
\begin{verbatim}
python -B reproduce.py --receipt ../round17-replay/REPRODUCE_CHECK.json
\end{verbatim}
The runner first checks the release inventory and reviewed code hashes.
It then makes separate temporary copies, deletes the declared generated
outputs, rebuilds and checks them under normal and optimized Python, and
compares exact bytes with the sealed references. Environment-bearing
receipts are matched to their own mode. Changed and missing equations,
coefficient corruption, unsafe paths and a corrupted ZIP member are explicit
negative controls. The original release is not modified.

To verify a delivered archive without rerunning algebra, add its path:
\begin{verbatim}
python -B reproduce.py --archive ../release.zip --verify-only
\end{verbatim}
The ZIP builder uses sorted portable member names and fixed metadata,
builds two independent archives, requires byte identity, and checks CRC,
complete inventory and every member byte. The replay summary also binds
executed source files and the exact replay plan, so a later code change
cannot silently reuse an old replay result. Integrity manifests are not
signatures or mathematical proofs.

\subsection{The report and remaining boundary}
The modular editable source is \path{report/report.tex}. Its copied
producer sections have exact source and destination hashes, and every
presentation replacement is recorded. The root result data generate the
summary table; an independent report-data checker recollects the three
headline quartics, counts the compact graphs and authenticates all fixed
payloads. The self-contained TeX attachment expands only local source
inclusions and retains a separate source map.

Run \path{report/build_report.sh} to rebuild the modular report outside the
sealed tree. Shell escape is disabled. On a minimal Debian installation
without generated TeX caches, the script creates a temporary format from
already installed source files; it does not change the system installation.
The delivered PDF's page-by-page inspection is recorded in
\path{report/QA_RECEIPT.json}. PDF bytes may differ across TeX installations;
the deterministic arithmetic and ZIP claims do not imply universal PDF-byte
reproducibility.

The mathematical boundary remains explicit: ordinary reductions compose with
retained compiler, Pell, calculus and refutation-calibration theorems.
Neither these finite programs nor a correctly rendered PDF constitute a new
end-to-end proof-assistant certificate, a consistency decision, or a global
optimality claim. No repository write, commit or third-party publication was
performed.
