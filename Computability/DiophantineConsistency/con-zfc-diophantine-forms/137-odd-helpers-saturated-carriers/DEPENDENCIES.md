# Dependencies and verification boundary

## Current execution closure

REPRODUCE_PLAN.json enumerates the approved finite commands and exact output
comparisons. CODE_REVIEW.json pins the executable closure to inspected bytes.
Each replay starts in a fresh temporary copy of the sealed release, deletes
listed generated outputs, regenerates them and compares them to the immutable
reference. Normal and optimized Python have separate environment-bearing
receipt references where necessary. All original release bytes remain intact.

Historical source programs are retained as evidence and remain inert unless
the replay plan explicitly names them. Any executed coefficient recipe must
be identified separately from the inherited semantic theorem it encodes.
No consistency search, refutation enumeration, remote write or machine
simulation is part of the replay.

## Mathematical source closure

The complete preceding Signed Caps and Free Scales release is retained under
prior/wave16/. Its original manifest entries are verified byte-for-byte.
Current branches additionally retain their immediate source statements,
coefficients, licenses and immutable source pins. A source checksum authenticates
text; it is not a proof of the assertions in that text.

Each compact native equation uses a whole authentic coefficient tuple. The
source34 unrestricted-integer tuple and source133 directly indexed BFS943
compact44 strictly-positive tuple are
distinct. In particular, the already shifted high-mask coefficient must not
be shifted again, nor may ports be exchanged between different controller or
tile-ordering conventions. Direct quartics instead deliver every integer
coefficient explicitly in a sparse expansion.

The semantic boundary is the fixed recursive proof system, compiler and
calibration theorem retained in the preceding source chain. New zero-set
transformations are ordinary unbounded proofs with stated source hypotheses.
Finite symbolic checks authenticate transcription and algebra, not those
unbounded theorems. No new end-to-end proof-assistant certificate, proof of
consistency or optimality theorem is claimed.

## Document and archive

The report has source-mapped presentation copies distinct from immutable
producer TeX sections. Exact data bindings check tables against delivered
JSON. TeX compilation disables shell escape, writes outside the sealed
release and includes a temporary-format fallback for minimal Debian installs.
The final PDF is visually inspected page by page after its final compilation.
Python replay alone does not imply document compilation or visual QA.

The archive builder checks the final inventory, the executed-code hashes,
replay-plan binding and all compared output hashes. It constructs two ZIPs
with sorted portable names and fixed metadata, requires byte identity, and
verifies member contents and CRC. Manifests are integrity receipts, not
cryptographic signatures or mathematical certificates.
