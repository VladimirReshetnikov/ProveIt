# Why the smaller chart suffices

Replace actual q+1 everywhere by3u+2, so q=3u+1. Then neither q nor q+1
can vanish; as consecutive nonzero integers they have the same sign. Units
q=1 and q+1=-1 are allowed at this point.

The unchanged signed anchor/frame/orientation proof identifies every principal
pair as the canonical signed-index Pell pair before any pooled power or
semantic sign recovery. This interface explicitly permits signed requested
indices; it uses the cap's absolute-index recovery, not nonunit-base powers.

The reciprocal theorem consequently applies. It yields mi=ni^ki for both
blocks, with unit powers interpreted for all signed indices. It does not need
to conclude ki>=0 at unit bases. Canonical Pell congruences then give
Ti dividing delta_i=mi-Xi+(A-ni)Yi for every request, because ni is a unit
modulo Ti. Thus Ti divides Ei, also in the two possible unit cases.

Set Li=Ei/Ti and Ki=2Hi+(2A-ni)Li. These are integers and restore all four
old pool rows. All other old weighted-source equations are unchanged. Invoke
the complete old-source soundness theorem only now. Therefore any further
sign or nonunit exclusions needed by the old arithmetic decoding are
inherited from that restored full system, not assumed beforehand.

Conversely the already established cofinal completeness construction yields
q=4 modulo12, hence q=1 modulo3. It supplies the new chart integer u=(q-1)/3.
True powers produce the reciprocal quotient as before. The stricter
completeness witness construction and the weaker soundness chart are fully
compatible; this does not claim a bijection on every old unrestricted zero.
