\section{Unfinished directions}
These are research questions, not results of this release.
\begin{enumerate}
\item Can a smaller signed anchor preserve the acyclic orientation proof? Any deletion needs a proof for the actual emitted rows, not only canonical witnesses.
\item Can cofinal choices lower natural dimension without the large height cost of aggressive monic substitutions? Domain-specific objectives must remain separate.
\item Can incidence-local contraction, affine factorization and hub partition be optimized jointly? The finite search proves no global optimum.
\item Are there better collision-safe equality polynomials that preserve a complete inverse witness map while improving the height-one dimension/support frontier?
\item Can eleven-integer cofactor degree or cost be reduced without changing the authentic numerical tuple or the required interpolation modulus?
\item Can the ordinary arithmetic and inherited logical calibration be joined into a new end-to-end kernel-checked endpoint? This release does not complete that formalization.
\end{enumerate}
