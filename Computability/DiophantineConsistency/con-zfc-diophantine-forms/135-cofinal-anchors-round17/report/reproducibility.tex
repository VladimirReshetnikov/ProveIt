\section{Reproduction and evidence boundaries}
Extract the archive to a fresh directory and run \texttt{python3 verify.py}. Mathematical verification uses the Python standard library only. The driver validates every enumerated byte digest, makes a disposable copy, rebuilds the selected artifacts deterministically, compares the rebuilt mathematical objects to the reference bytes, and runs independent checks in normal and optimized Python modes. Every mathematical condition is enforced by an explicit exception rather than a removable \texttt{assert}. The checks require no repository checkout, network access, parent workspace or private helper. A separate report build requires a normal TeX installation and is invoked with \texttt{sh build\_report.sh}.

The disposable-copy rule is substantive: an inherited natural projection checker writes its own verification receipt. Its output must never modify the immutable release reference between normal and optimized passes. All such calls are directed to fresh copies. The manifest excludes only its own bytes and explicitly named replay receipts; the structure checker rejects undeclared files and unsafe paths. Ancestor PDFs, nested ZIP files, exploratory outputs, private notes and acquisition helpers are not part of this release.

The release supplies four different kinds of evidence, with different purposes:
\begin{enumerate}
\item \emph{Authentication} binds incoming archives and source files to exact public Git objects and full byte hashes. It says nothing by itself about their mathematics.
\item \emph{Finite exact algebra} verifies every coefficient identity, literal emitted row, monic restoration, translation, graph incidence, numerical port, degree certificate and corruption-control rejection that the checker claims.
\item \emph{Unbounded ordinary proofs} establish the Pell classifications, cofinal choices, inequalities, interpolation and both witness directions. A bounded experiment is not used in place of one of these arguments.
\item \emph{Logical calibration} is the identified inherited ordinary numerical-calculus or native-compiler correspondence with finite syntactic refutations. Retained Lean interfaces identify the boundary; merely including them does not certify the new arithmetic in a proof assistant.
\end{enumerate}
The full proof and exact artifact closure are necessary together. A successful replay is not a proof that ZFC is consistent, and does not decide whether the displayed polynomials have a zero.

\subsection{Portable proof closure}

The complete constructor, derived-label, rank, signed-source and new composition proofs are retained under the component source and proof directories. Scalar source34 coefficient construction, signed Pell folding, nonodd rank restoration, fixed-pair supported-modulus interpolation and compiler/refutation sources are retained separately. The height-one theorem is unconditional as a transformation of an explicit integral quadratic system; its consistency interpretation comes only after composing the calibrated source supplied with it.

All local source names and their hashes are collected in the manifests and component closure maps. Historical copies may refer to their original archive layout; the active release maps identify where their required material is now stored. No external helper URL is a runtime dependency.

\subsection{Report fidelity}
The PDF is built in three TeX passes, rendered page by page, and checked against a fresh three-pass build for raster identity. The final approved PDF is copied byte for byte into the ZIP. Its editable TeX sources, the proof-rendering script and the independent character-fidelity checker accompany it. Rendering receipts describe presentation checks only; they are not mathematical proof objects.
