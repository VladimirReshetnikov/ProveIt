# Attribution, provenance and scope

The credited prior affine refactorizer, incidence-local alias contractor, literal printer, normalization and signed-network compiler remain inherited under their preserved licenses. The copied upstream files are byte-identical to the Round20 release; inherited network and polarization proofs are retained.

Round21 additionally adds `split_normalize.py`, sharing coefficients multiplicatively through monic scales; the signed-network entry point accepts this selected normalizer.

Round21 adds `anchored_cycles.py`, which selects complete height-checked unit-homogenized equality cycles. `spread.py` expands that mode; `check_network.py` independently expands its square-difference identity; `check_steps.py` independently checks the exact polynomial difference and unchanged semantic namespaces; pipeline, build and verify compose it with the inherited construction. The new zero-set witness maps are identity maps in the same coordinates.

Source provenance remains the exact Round20 originals pinned in SOURCE_BINDINGS.json. Their enclosing finite-refutation calibration is an inherited proof interface, not supplied by finite arithmetic testing alone. The frozen Round21 release authenticated its matched Round20 final hashes; current replay pins and rebuilds unchanged-normalization Round21 controls.

No consistency proof, global minimum, exhaustive Pareto frontier, literature priority, or new end-to-end formal-kernel certification is claimed. Fixed graph parameters specify concrete equations and are not variables of those equations. Portable verification uses only Python's standard library. Exploratory source transfers and negative searches are excluded by the release whitelist.

Round22 adds `product_constants.py` (monic constant products and optional
chained scales) and the independent `check_product_constants.py`; pipeline,
build, verify and release metadata select and check those operations.
Round21 final coefficients/certificates are retained byte-for-byte as matched
controls, except the explicitly new h26 control from the identical unchanged
normalization algorithm. The inherited source closure remains unchanged.

Round23 adds `fused_normalize.py`, `inline_constants.py`, and
`inline_scales.py`, plus fixed profile selection in pipeline/build/verify.
These fuse exact known products into source rows, prune unreachable monic
constructors, and inline additive constant/scale identities without altering
the inherited graph proof. The independent `check_network.py` is byte-identical
to Round22; no producer code is imported by that arithmetic checker. Frozen
Round22 controls are copied exactly except the explicitly new h28 control.
The inherited source bytes and their enclosing calibration closure are unchanged.
