\section{Reproduction and the evidence boundary}
\label{sec:verification}
The release is supplied as ordinary disjoint ZIP parts, each within the
requested 4 MB limit and sharing one top-level directory. Extract all parts
into the same parent directory. The combined directory is the standalone
source closure; an individual part is not advertised as complete.
No publication, repository commit or external formal-kernel execution is
implied by the archive.

The normative definitions are complete finite arrays and arithmetic graphs.
Each selected quartic includes its ordered variables, residuals and full
collected polynomial. Each selected reciprocal endpoint includes its exact
source/pool certificate, unit-pivot substitution ledger, complete residuals
and any stated complete expansion. Height-one endpoints include collected
JSON and literal-text polynomials with complete semantic graph certificates.
Scalar endpoints include full binary-operation graphs and all four actual
minimal unsigned coefficient payloads. A hash authenticates those bytes;
it is never substituted for an absent coefficient.

\subsection{Executable reconstruction}
The component READMEs and the root release README give exact offline command
lines and closure locations. The core finite workflows use Python's standard
library and do not require the network or a proof assistant. Each checker is
run normally and with assertions disabled by optimized Python where stated;
its explicit failures remain active. The root receipt records terminal
outcomes, not an optimistic command list. Integrity-only verification is
labelled as such and is not confused with mathematical reconstruction.

For the direct quartics, the independent checks reconstruct the actual
source changes, frame atoms, orientation deltas, growth splits and affine
maps. They compare every changed and unchanged row, restore every deleted
coordinate, collect the entire sum of squares, and verify exact degree,
height, support and live coordinate count. The ordinary Pell and cofinal
arguments are separate proofs, not inferred from examples.

For the reciprocal family, independent checks authenticate every raw pair,
request port, norm, wire, private quotient and source-row correction. They
reconstruct both unweighted pool rows, every selected monic elimination and
its integral inverse, then recollect the stated complete expansions. A
matched control uses the same permitted pivot strategy with orientation
unfused, isolating the new joint theorem rather than comparing unrelated
search outputs. Larger exploratory residual systems with unmaterialized
sum-of-squares expansions have no invented support or height.

The network checker does not import the producer. It checks each monic
triangular constructor and original source pullback, all occurrence bindings,
block trees, aliases, equality/unit squares, full coefficient arrays and the
symbolic lift including the hub term. The final text parser is a separate
representation check. Parameter-matched new controls are distinguished from
unchanged historical controls.

The scalar checker independently reconstructs every gate cut and formal
quotient identity, all 594 whole-product defect terms, both complete highest
forms after actual leading substitution, and the complete coherent coefficient
tuple. The 438 single-operator mutations are rejected; a separate algebra
implementation confirms the 84-term center and 594-term defect. The inherited
native proof and decoder are retained in their full authenticated source
closure. These checks do not turn scalar numerical bounds into a new native
soundness theorem.

\subsection{Native report build and visible equations}
From the combined root, rebuild this document with
\begin{quote}\ttfamily
sh report/build\_report.sh
\end{quote}
The script compiles native pdfLaTeX three times in a fresh temporary directory,
with a local format fallback when necessary. It rejects overfull boxes,
unresolved references and undefined citations. No screenshot or imported
PDF is substituted for native mathematical source.

The principal residual appendix is generated from the literal residual array;
its independent parser re-reads every displayed coefficient and exponent and
compares all rows. The comparison and catalog tables are generated from
frozen inventories and bound by their input and TeX digests. The selected
scalar equations are printed in full with their acyclic polynomial
abbreviations, while their operation-counted DAGs remain supplied verbatim.
The reciprocal source and ordered pivot tables specify exact finite
substitution rather than a generic promise to eliminate variables.

After the final three-pass compilation every PDF page is rendered and visually
inspected. The report QA receipt binds the inspected PDF hash, page count,
render inventory and successful compilation logs. Only the complete TeX/PDF,
rebuild/check prerequisites and concise QA records appear in the report
release whitelist; exploratory build products and stale reports do not.

\subsection{What the release does not claim}
The ordinary unbounded proofs use the explicitly named inherited arithmetic
and logical interfaces. They are formalizable in ZFC, but no fresh complete
transitive Lean or Rocq build, encoded object-language derivation, external
human refereeing, consistency proof or global minimality theorem is asserted.
All claimed new endpoints have full witness arguments and finite artifact
bindings; the comparison-only inputs carry the narrower evidence labels in
Section~\ref{sec:comparison}. The distinction survives successful replay.
