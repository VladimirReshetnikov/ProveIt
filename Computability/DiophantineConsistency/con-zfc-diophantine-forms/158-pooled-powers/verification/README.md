# Verification receipts

These receipts authenticate finite data. None is a proof that a zero does
or does not exist, and none replaces the unbounded arithmetic proof.

| Receipt | What was actually checked |
|---|---|
| `REBUILD.json` | Independent reconstruction of all five transformation boundaries; exact residual identities and final expansion; all 20 stage JSON files rebuilt byte for byte. |
| `OPTIMIZED.json` | The same literal and coefficient audit under optimized Python, where `assert` statements are disabled. |
| `PARENT_REPLAY.json` | The immediate parent's independent source, projection, translation, and expansion checks; 88 retained source pins; all 16 parent JSON artifacts rebuilt byte for byte. |
| `PRINTED_EQUATION.json` | Exact read-back of all 162 TeX residuals and their 1,177 terms; public/stage copies; metrics and variable list. |
| `POOL_LEMMA.json` | Independent symbolic identities for 1, 3, and 11 summands; 1,260 signed-index modular checks; 36 exact-power witness families; 30 original Pell-frame instances; 63 square-frame bounds. |
| `POOL_FRAME.json` | Independent exact reconstruction of the 36 affine squares and membership of all fourteen pooled bases, indices, and outputs. |
| `ALL_FRAME_ATOMS.json` | A second independent reconstruction of the frame, covering every actual base, index, and output of all seventeen retained power requests. |
| `VALIDATION_CONTROLS.json` | Rejection of 22 malformed literal/evaluator inputs under optimized Python; evaluator agreement with the expanded polynomial at three explicit tuples. |
| `PDF_QA.json` | The final PDF page count, compilation status, and visual inspection scope. |

The main finite verifier imports no producer module. The frame checkers and
polynomial-identity checks were written independently of that verifier.
The report appendix checker imports neither the exporter nor the builder.

The supplied mathematical review notes were independently assigned within
the AI-assisted research session. They are not external human peer review.
The full imported Lean dependency closure was not rebuilt; the ordinary
shell-recoding proof and identified C222/ZF/ZFC logical interfaces are
explicitly retained and documented.
