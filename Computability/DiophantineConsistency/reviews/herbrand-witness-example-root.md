# One-parameter witnessing example

The example proves the candidate-PRA sentence `∀x ∃y, y=x` and applies the
general witnessing theorem to obtain a primitive-recursive arity-one code
and a candidate-PRA proof of its equality instance. It tests the parameter
order and actual theorem interface; it does not establish conservation.

Two isolated builds against the independently replayed general-witness
provider `/tmp/herbrand-all-instantiation-independent-kqk0f573/lib` matched
source, object and complete-log hashes. The [independent driver and logs](herbrand-witness-example-root-replay/)
and [author packet](herbrand-witness-example-author-replay/) are retained.
Foundation, Mathlib and unchanged local objects are inherited boundaries.
