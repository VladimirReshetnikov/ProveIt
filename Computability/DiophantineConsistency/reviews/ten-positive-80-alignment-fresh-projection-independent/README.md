# Independent audit of 80-graph alignment and fresh projection

The selected-receipt checker passes for five guarded author checks, with 16
direct imports, eight retained terminal histories and 21 sampled resource
observations. It rehashes accepted source, runner, Lean binary, selected
provider and all explicitly listed objects; it verifies direct import
resolution, output/log hashes, axiom reports and shared-producer hashes. It
also compares the directly imported simple-parity, occupied-anchor and
fresh-first-main objects to the preceding independent review's object hashes.
This audit does **not** replay Lean or authenticate full transitive serialized,
package, dynamic-library or historical source-to-object ancestry. Lean axiom
reports describe metatheory dependencies, not the object-theory axioms.

For an actual positive graph zero and all four explicit symbolic port
equalities, `graph_aligned_shift` joins simple-parity and support N values by
internal exponential injectivity; occupied-anchor facts refer to the same
graph's word. It gives a single N carrying the actual graph residual-power
identity, the compact carry input, and `E % 67 = 0`, where
`E = rankNat - 67*(8807*N)`. `graph_cell_shift` reconciles additional lengths
from parity, support and temporal-band results with its selected N, and
derives `s<N` and `(E/67) % (8807*N) = 8807*s`. The conclusion is an offset
modulo the cycle, not the unqualified equality `E/67 = 8807*s`.

The independent canonical-bounds declarations need no zero: the rank bound
uses β≥31 and positivity only of graph variables 0, 2 and 5, while cubic
divisibility of Y follows from its definition with no positivity hypothesis.
`graph_fresh_pell_norms` assumes a positive graph zero and the β/low/high
symbolic ports. It retains one r and the same fresh K,C,η,ζ from the fresh
interval construction, and produces positive roots of both displayed Pell
norms; P>0 supports the natural subtraction in its first base. The separate
`graph_fresh_projection` obtains one r,η,ζ and a positive γ satisfying the
fresh first/main identities and the displayed main-root projection. Its C is
the fresh unscaled Pell ordinate and is not equated to the scaled graph
ordinate. Neither theorem constructs an old graph zero.

## The fixed kernel is different

The candidate JSON fixes K0 through `ten-positive-unshift-t-finite/coefficients/K.bin.gz`.
A second captured check decompresses that file and compares it with the
retained original-K payload used in the previous independent symbolic-kernel
reconstruction. Each has 74,111 little-endian bytes and 592,884 significant
bits. The candidate hashes to
`0a86821a704294199c2e1a50379d242c96840a3366e9d965689ba3d74605203f`;
the original hashes to
`c6d523bd32af8dd0345db843cdadf6932bfcad186912a6d112314b60657c554e`.
The actual byte strings differ at 6,752 bytes and 20,002 bits; their first
differing byte has zero-based offset 28,903. The check verifies the candidate
JSON's K0 hashes and reruns the previous independent recipe reconstruction,
which reconstructs the latter original value from the pinned Lean source
text and matches it to the full retained payload. The candidate's own
[provenance](../../research/ten-positive-unshift-t-finite/provenance/indexed-proof.md)
likewise explains that its direct enumeration changes K.

The symbolic alignment theorems explicitly assume `p 1 = paramKernel rho`,
and the graph uses `p 1` for K0. The existing external reconstruction relates
that symbolic recipe to the **original** payload, while the 80-row candidate
uses the different regenerated payload. Therefore these conditional results
cannot currently be presented as results for that candidate's fixed K0. The
decoder and its supporting proofs need an adapted indexed-kernel connection
or a separately justified alternative. This comparison is external finite
evidence based on a manual transcription of the Lean recipe: it is not a Lean
equality or inequality between serialized files and `paramKernel rho`.

The results also do not establish temporal-window/machine equivalence in
either direction, external bindings for all graph ports, or an iPRA endpoint.
Captured unsuccessful or warning-rejected attempts remain historical records,
not evidence of successful Lean checks.
