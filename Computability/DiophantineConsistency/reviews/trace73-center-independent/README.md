# Independent review: conditional trace73 center probe

The pinned external candidate is exactly the 75-row parent with `LBt=V2*Bt` and `center=n-LBt` removed and every remaining use of `center` replaced by input `n`. `check.py` independently checked topological row order and liveness: all 73 operations (43 multiplications, 17 additions, 13 subtractions), all 10 witness inputs and all four fixed ports reach the output. It decompressed the separately retained coefficient payloads and verified their raw hashes against the graph metadata; it does not assert identical compressed bytes. Structural degree propagation gives an upper bound of 352. An independent sparse polynomial computation, setting all ten witnesses to one indeterminate and using the actual four payloads modulo 1,000,000,007, gives a nonzero `t^352` coefficient of 316589492. Together these certify exact total degree 352 for the external pinned payloads.

The accepted Lean source states for arbitrary commutative ring `R`, `p : Fin 4 → R` and `v : Fin 10 → R` that `value75 p (lift p v) = value73 p v`, where `lift` changes slot 7 to `v 7 + V²*B` computed from the original parent registers. Its separate center-register equality is used in the substitution proof. `check.py` rehashed the source/runner/output/logs and all direct recorded pins, and checked both retained `[propext]` axiom reports and that the first attempt failed. This review did not replay Lean. In particular the Lean theorem uses ring-valued ports and an abstract Lean `value73`; the external JSON rows and payload bytes are not parsed or formally bound by it.

The equality does not prove the transformed witness is positive or that a parent positive zero yields a positive centered zero, nor the converse on arbitrary zeros of the changed graph. It establishes no positive-zero equivalence, machine halt or iPRA theorem. Direct parent object and transitive project/package/dynamic provenance remain inherited, and external file semantics are outside Lean.
