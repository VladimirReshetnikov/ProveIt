Among those 680 examined source-graph-safe inherited objects, the two original stale users are the remaining verified project-environment mismatches; this does not certify the selected prefix/suffix objects or external transitive and dynamic ancestry.

On the historical five-change source graph, rebuilding the two stale users and reverse dependents alongside changed sources yields a **247-module lower bound**, rather than the source-only 189. Later merges can enlarge or otherwise change that graph. After the fixed endpoint parent passes, survey current source/import changes afresh and recover the actual original transitive project environment of each candidate reused prefix and suffix object as well as the inherited objects. Mark source changes, confirmed stale users, unverified original environments and all their reverse dependents for rebuild; iterate until every reused object's complete recorded project environment agrees with the proposed selected objects. Build that closed set in dependency order on one guarded provider and independently replay. If an origin cannot be verified, rebuild the necessary reachable source closure.
