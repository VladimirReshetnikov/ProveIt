Key sources: [all-block endpoint](../../research/ordinary12-ipra-bridge/compact44-fixed-graph-all-blocks-prototype/FixedGraphAllBlocks.lean), [spatial successor](../../research/ordinary12-ipra-bridge/compact44-fixed-graph-all-blocks-prototype/FixedGraphSpatialSuccessor.lean), [marker successor](../../research/ordinary12-ipra-bridge/compact44-marker-successor-prototype/MarkerSuccessor.lean), [marker indexing](../../research/ordinary12-ipra-bridge/compact44-marker-successor-prototype/MarkerBlockIndex.lean) and [model orbit induction](../../research/ordinary12-ipra-bridge/compact44-internal-occupied-orbit-prototype/InternalOrbit.lean).

The endpoint assumes an `ORingStructure` model of `IΣ₁`, positive coordinates and `InternalZero` for the literal fixed symbolic graph ports containing the distinct `paramKernel rho`. It concludes that some model `N>0` satisfies the stated `q = Exp.exp ((67*8807)*N)` and that every model `h<N` has `SelectedBlock N C h`. A selected block means an externally finite `Fin 943` selector exists with the selected pattern and matching local decoded copy word. The theorem is conditional; it does not assert the existence of a graph zero or an internal PRA proof.

For the successor step, write `g = (h+1)%N`. At block `g`, the marker equality at phase 1073 identifies its offset-1011 source digit with the offset-1031 digit of `cyc N g 1`. The cyclic forward/back identity gives `cyc N g 1 = h` for `h<N`; hence the equality is **current marker in g = previous marker in h**, and propagates forward from `h` to `g`. The selected row at `h`, together with the local input bounds, supplies digit 1 at offset 1031. The equality supplies digit 1 at offset 1011 in `g`, and the uniform decoder rules out its all-zero branch, yielding a selected block at `g`. This establishes occupancy only; this marker argument by itself does not establish equality of full neighboring row fields or an edge relation.

The wrap case is covered, including `N=1`, where `h=g=0`. `MarkerBlockIndex.previous` explicitly reduces `1%N` before applying the bounded block-shift lemma; it does not require `1<N`. The stride-one application of `InternalOrbit.all` likewise has no `s<N` premise. `check_wrap.py` independently checks the corresponding standard cyclic index equations for 210 cases with `1≤N≤20`; this is supporting evidence, not a substitute for the arbitrary-model lemmas.

The spatial-successor proof obtains origin occupancy, decoder facts and field-marker facts from separate graph invocations. They use the same tuple, ports and `q`; model exponent injectivity and cancellation identify their `N`s before the facts are joined. Only facts independent of the separately extracted `w` and temporal shift `s` are transferred, so those witnesses need not be equated. The final proof matches the decoder's `N` to the successor theorem's `N` in the same way.

For induction, `InternalOrbit.all` does not induct directly over the externally finite `SelectedBlock` disjunction. It inducts over the model Σ₁-definable predicate `Occupied C N 1 t`, whose bounded witness is a model `j<943`, using `ISigma1.sigma1_succ_induction`; this covers nonstandard model `t` as well. The decoder and `BlockSelectionBridge` convert between that predicate and selected blocks using a bounded-standard lift to `Fin 943`. For each `h<N`, `(h*1)%N=h`, so the induction gives occupancy at that same block before the bridge extracts its selected row.

The conclusion does not construct a represented global word, prove edge matching, exclude the extra row, establish machine correctness, bind the symbolic kernel or ports to retained displayed equation bytes, or prove a PRA-internal consistency equivalence. The reported builds are single-author exploratory runs; this review runs no Lean and is neither an independently coherent provider replay nor a paired artifact audit.
