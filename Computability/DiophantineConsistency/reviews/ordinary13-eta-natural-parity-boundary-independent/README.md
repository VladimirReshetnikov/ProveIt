# Independent review: eta-natural parity boundary

The two proposed clients use a coherent tuple of first norm, main norm,
first index and quotient witnesses, and specialize eta to zero consistently
at the stated source interfaces. No hidden eta-positive assumption or
source-level witness mismatch was found. Both clients and their providers
remain unelaborated; the graph's strong/auxiliary representations are
explicit assumptions, not established here.

The fact client instantiates the large-ordinate theorem with `eta=0` and
`zeta=k`, so its required `zeta>0` is the client's explicit `k>0`.
The same tau and g provide the first and main norms, with `c=Y*k`. It
uses the resulting large-k bound and eta-natural geometry with the same
X,Y,k and `D=(3+4a)+a²`; eta zero is not fed into the earlier positive-eta
geometry theorem. The strong adapter receives the same c,i,D,f, and its
returned positive auxiliary offset u is used with the same T,R,y and signed
z in the absdiff equation. Those model-natural/signed equations are explicit
hypotheses, not consequences of the fact client's theorem.

The main Pell classification is applied to the same natural g and c that
satisfy the main norm, yielding a main index m with `ycoord m a=c`. It is
not assumed that g equals the oriented main carrier root. The final
contradiction call receives the original first-index n and its quotient w,
the classified m, the same c/a/g, and `mu=q⁴`, along with the explicit
rank lower bound, strict modulus window, congruence, strong norm and absdiff
auxiliary equation. The early congruence `(2n)%q⁴=R+1` is not confused with
the later equality `2n=R+1`.

The compact graph client destructures the graph early-index result as
`tau,n,w,hfirst,...,hny,hnmod,...,hks` and passes those same witnesses and
facts into the fact client. Its independent graph-natural norm extraction
provides the main g; the unused first-root witness from that separate call
is not substituted for tau. Under explicit `v9=0`, its main norm, strong
and auxiliary premises use `c=Y*k`. It obtains the strict modulus bound
from the compact rank window and positive q. The strong and auxiliary
signed graph representations are still **explicit premises**; in
particular, matching the signed graph rank to its natural rank must be
proved separately.
