# Finite mixed strict Π₂ normalization

For any finite tree of conjunctions and disjunctions of strict
universal-existential blocks, Lean constructs PA-minus rule proofs in both
directions between the tree and a single block whose universal and witness
tuples accumulate the leaves' arities. It preserves free parameters and
bounded matrices. The checks exercise a mixed three-leaf example. This is a
proof-output adapter, not a height-preserving source-derivation transformation
or a normalization theorem for arbitrary Foundation Π₂ formulas. It uses
classical metatheoretic completeness and is noncomputable.

Two isolated builds against the independently replayed tuple provider
`/tmp/parsons-prenex-tuple-independent-2s2pjxqi/lib` matched sources, objects
and complete logs. The driver verifies frozen local providers. The [independent
driver and logs](parsons-prenex-tree-root-replay/) and [author packet](parsons-prenex-tree-author-replay/)
are retained. Foundation, Mathlib and completeness objects remain inherited
boundaries.
