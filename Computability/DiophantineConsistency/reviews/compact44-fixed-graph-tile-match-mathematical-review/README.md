The word theorem concludes a positive model `N` with the stated `q` exponent, `W` with `Blocks 10 (row C N 1) N W`, and, for every model `h<N`, a selected finite-table row whose zero-based index is the corresponding row value, is below 943, and is not 1. The stride-one orbit is `(h*1)%N=h` on that range. The absent low-mask phase 1 and per-position `NoCarry` give `dig 67 C (8807*h+1) = 0`; if the selected index were 1 its selector requires that same digit to be 1. This includes `h=0` because the addressed digit is positive. `Blocks` encodes indices, not tile payloads or matching proofs.

The tile endpoint returns the same kind of `N,W`, a model `s<N` with the displayed reduced-displacement equality, and, for every model `h<N`, rows `i,j,l : Fin 943` for positions `h`, `cyc N h s`, and `cyc N h 1`. It proves actual natural table-coordinate equalities **south(i) = north(j)** and **east(i) = west(l)**. Since `cyc N h e` is subtraction modulo `N`, these are predecessors `h-s` and `h-1`, not forward-indexed statements. With `N=1`, necessarily `s=0` and both neighbors are the same sole block; the horizontal source proof reduces `1%N` before invoking the bounded shift lemma. The theorem does not identify `s` with a physical time step.

The final `s` is the one returned by the marker theorem, with its own displacement equality. The decoder's independent `w,s` are not transferred, so no unproved identification of them is used. Each of the three selected rows is obtained from the same all-block word at a proved in-range model index, while local decoder inputs are taken at those same indices.
