# Independent review of the 16-module source preflight

The source-declared closure and current point-in-time artifact checks reproduce. Run `nice -n 19 python3 -I -S -B check.py`; it reads project and provider files and invokes no Lean process. The script pins the original preflight, result, current14 base manifest and state, and lakefile, and checks the recorded successful outer exit.

An independent traversal resolves the pinned five target modules through the lakefile, removes nested source comments and strings, rereads source imports, and verifies source bytes and recorded paths. It recovers exactly 1,007 project modules: 991 shared with the pinned base manifest and 16 additional modules. The saved extension order places each source-declared extension dependency earlier. The traversal also recovers the declared external names and confirms five names newly introduced relative to the base.

For each shared module, the review checks the saved producer's source and object association, ten expected output or companion slots, and direct-input names and hashes. It independently rechecks 9,910 such slots and 4,151 direct dependency edges covering 1,093 distinct paths. It also rechecks the recorded presence, absence, realpath, and hash of external candidates, and equality of competing main-object hashes. These are checks at review time against saved records, not a continuous history of those files.

The scope remains **source-declared**: this is not an immutable source snapshot, a Lean dependency traversal, complete package or dynamic provider ancestry, a build, or a proof of compatibility for all 16 modules. The successful separate case A import tests only its particular combined imports; it does not compile this extension. The preflight's scanner is a constrained lexical source reader, not a Lean parser; unsupported or semantically significant syntax outside that model requires separate examination. No source-to-object provenance is inferred merely from a package candidate's path and hash.
