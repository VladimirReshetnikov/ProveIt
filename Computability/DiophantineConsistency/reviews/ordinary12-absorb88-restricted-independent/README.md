# Independent 88 transport-restricted equivalence review

`Absorb88Restricted.positive_zero_iff` states that for every IΣ₁ model and
natural port tuple with `beta > 0`, the 89-row Lean graph has a positive zero
iff the 88-row Lean graph has a positive zero **that also satisfies**

```text
(F+alpha)*(K0+w)+F < q*(K0+w),    q = 1+J*beta.
```

The inequality is inside the existential on the 88 side. It is not a theorem
that every positive 88 zero satisfies it. The forward map from 89 adds
`ell+k` to the relevant witness; the existing 89 transport theorem supplies
the inequality. In the reverse direction the bound supplies positive `Bt`;
the proof uses the positive first-root branch or reflects the negative branch
while preserving the whole graph, then subtracts `ell+k` from the selected
witness. The separate conditional lemmas expose these maps and hypotheses.

The independent check verified 14 accepted source snapshots, object hashes,
logs and allowed axiom reports, all selected predecessor resolutions and the
1,291-file provider union twice. It also checks three earlier failed or
warning-rejected attempts and sampled resource records. The first-norm source
suppresses unused-variable and unused-simp linters, and the reflection model
source suppresses the unused-simp linter; these suppressions are part of the
checked sources. The external DAG check confirms 88 live operations.

The audit found no mismatch in the stated conditional equivalence. It does
not establish unrestricted 88/89 equivalence, an 88 halt theorem, an iPRA
endpoint, or a PDF binding. No independent Lean replay was made; full
package-transitive, dynamic, and historical source-to-object ancestry remain
inherited.
