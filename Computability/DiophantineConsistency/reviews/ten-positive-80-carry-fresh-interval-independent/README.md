# Independent audit of 80-graph carry and fresh Pell witnesses

This read-only review checks nine selected guarded author receipts, their
current and archived Lean source bytes, runner/tool hashes, all individually
listed object hashes, direct import resolution, cross-producer object hashes,
logs, axiom reports, and sampled resource guards. The captured checker passed:
its output inventories 27 direct imports, 15 terminal histories and 34 sampled
resource observations. The review does **not** rerun Lean or reconstruct the
complete transitive serialized, external package, dynamically loaded, or
historical source-to-object ancestry. The axiom reports concern Lean's
metatheory, not axioms of the object theory iPRA.

For `graph_support_carry`, the actual positive 80-graph zero and all four
explicit symbolic port equalities yield a carry input and the support and
Boolean bounds for one radix length N. It obtains N twice and proves the
lengths equal using internal exponential injectivity. `graph_simple_parity`
independently reconciles a further fixed-slot N with that same N, then proves
the two anchor-column parity conclusions and incoming-carry bounds. The
`graph_clean_carry` theorem selects t=4393 or 5495 with zero temporal digit,
bounded predecessor digit, zero incoming carry and exact raw output digit.
The `graph_occupied` client reconciles three obtained lengths by the same
argument and derives digit 1 for the seven named positions with indices
34–40. These are statements in each stated IΣ₁ model; they do not posit a
zero of an older graph. The actual graph variable `v 5` remains the unscaled
residual power throughout the exposed carry conclusions.

`graph_half_binomial` assumes β≥31 and odd β, the stated low/high inequalities,
and an actual positive zero; it derives a shared r for the odd rank, the
power identity and the half-binomial identity. It does not need the four
symbolic port equalities. `graph_fresh_auxiliary` instead assumes the
symbolic β/low/high equalities and uses the proved phase to obtain the source
Pell auxiliary witnesses with the **fresh** ordinate `ycoord R (Y*(X+1))`.
It does not identify this ordinate with the scaled ordinate in the 80 graph.

The generic `split_floor` retains a small remainder from the scaled
sandwich; `transfer_floor` turns a second strict sandwich into a common
integer floor. `graph_fresh_interval` applies these facts to the actual
graph's X, Y, and a single r while constructing a distinct unscaled Pell
pair K,C and proving `K*Y < C < K*(Y+1)`. `graph_fresh_first_main` uses that
same pair and rank to construct positive η,ζ with `C=K*Y+η` and `K=η+ζ`.
The β/low/high symbolic port equalities remain hypotheses in both graph
clients, and these constructions do not yet supply a source graph zero.

The finite symbolic port equalities are not here proved to match the external
decimal equation or PDF. Temporal phase alignment, full window/machine
soundness, the source/80-graph existence equivalence in both directions, and
an internal iPRA endpoint are not established by this audit. Attempts with
errors or diagnostics, including the warning-rejected earlier floor attempt,
remain inventoried as historical attempts rather than successful evidence.
