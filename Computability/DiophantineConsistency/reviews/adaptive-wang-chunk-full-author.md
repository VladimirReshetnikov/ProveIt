# Full Wang-table predicate chunks in a private overlay

The private draft extracts the unchanged standard Wang-table definitions from the pinned source, checks each of the original `GoodA`, `GoodB` and `GoodC` predicates in eight separate row chunks, and recombines them with a generic take/drop membership proof. The first seven chunks cover successive blocks of 128 rows; the final `drop 896` chunk covers the remaining list. The author run `/tmp/adaptive-wang-chunk-full-f_42gnf_` passed the extracted core, all 24 chunk modules and the recombination module, with final original-source, canonical-guard and provider-object reauthentication. The [generator](../research/wang-chunk-full/generate.py) reproduced all 28 generated source/metadata snapshot files byte-for-byte from the pinned original.

This is a private alternative proof of the three full row predicates. It does not rebuild the original `ArithmeticWangTable` module, compare all exported theorem interfaces, replace any canonical object, or establish the current-source CellWindow or Assembly. Independent replay and an exact interface comparison are separate gates before integration. The original live WangTable worker and repository source were not modified. Package and canonical provider boundaries remain inherited.

The [86-file evidence manifest](adaptive-wang-chunk-full-author-evidence/FILES.json) has SHA256 `ec9cfcc10da3da6eaf90a4a6a76774e46bbb09aec24e302e8322ee83b515b940`. It preserves the original source snapshot, generator, all generated source snapshots, full logs and timings, driver, state, and canonical guard/provider inputs. To replay, generate `/tmp/adaptive-wang-chunk-full-src` with the generator and run `success/driver.py`; the driver uses `/tmp/adaptive13-assembly-recomposed-q9s50zdl` and creates a private complete symlink overlay. Its scope is limited to the chunked predicates and recombination.
