# Adaptive rank window: author result

From an actual adaptive zero, the new all-model client proves the explicit
rank bounds `24 ≤ R` and `R+q³+q+1 ≤ q⁴`. It takes no first/main index
relation, input power, or divisibility of X by q as a hypothesis. The generic
port client requires only the port inequalities, coordinate positivity, and
literal zero; the current and single-positive-shift clients discharge these
premises for the current expression. See the [scope note](../research/adaptive-rank-window2011.md)
for the exact definition of R and remaining work.

The upper bound uses the existing finite additive slack argument, with the
gap obtained from the independently reviewed actual first-carrier transport.
It copies the small scalar identity and current-mask bounds from the existing
fourteen-variable support rather than importing its much larger, inapplicable
index chain. The mask is the actual once-shifted fourth port.

Two fresh author builds passed with matching source, object and complete log
hashes and no warnings. The four reported Lean axiom lists are `propext`,
`Classical.choice`, and `Quot.sound`; these are metatheory dependencies, not a
proof within HA. The parent provider is the independently replayed adaptive
index overlay `/tmp/adaptive13-indices-seijhykj/lib`. Package and toolchain
interiors remain inherited boundaries. This pair still requires independent
review; the first successful provider is `/tmp/adaptive13-rank-window-4rv86k2e/lib`.
