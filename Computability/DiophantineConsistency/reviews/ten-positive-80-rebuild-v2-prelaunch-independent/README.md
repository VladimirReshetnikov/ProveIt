## Blocking guard defects

* `run_monitored` requires at least 8 GiB `MemAvailable` at stage launch, but aborts an active stage only below **2 GiB**. A drop from 8 GiB to any value in the 2–8 GiB range is therefore permitted. Change the live cutoff to the agreed 8-GiB threshold and record samples; resource sampling is still not a continuous guarantee or inter-process lock.
* The diagnostic regex `(?i)(?:error:|warning:|sorryAx)` rejects literal `warning:` and `error:` but misses coded Lean diagnostics such as `warning(lean.unusedSimpArgs):` and `error(lean.foo):`. Parse both optional-code and plain forms and retain logs. Lean nonzero exit provides an additional error guard, but does not make the warning policy effective.

## Additional reproducibility and failure-capture gaps

* The script hashes all selected outside `.olean` inputs at preflight and protects each direct outside dependency and its companions during its particular build stage. Its final whole-union companion recheck covers only project objects. Capture a documented pre-run presence/hash baseline for **all selected outside objects and companions**, and recheck outside baselines after the build as well as around relevant stages. This confirms stability during the new run; it does not authenticate the historically different Foundation package object or its transitive/dynamic ancestry.
* Each original and copied source is checked before and after its own stage, but there is no final pass rehashing **all 127** sources and copies. Add that pass to support a final whole-run snapshot claim. The exact fixed-client receipt should be hash-pinned before reading rather than merely dynamically hashed and checked for successful status.
* Record each planned stage number, command and output paths before invoking preflight/Popen, so a preflight rejection or startup failure has a stage-specific record. Write status snapshots atomically to avoid a truncated `result.json` if interrupted. These do not turn a failed run into resumable evidence; any new attempt still needs a fresh root.
