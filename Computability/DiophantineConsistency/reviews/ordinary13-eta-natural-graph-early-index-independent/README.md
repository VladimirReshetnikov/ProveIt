carrier and carries one first norm witness tau into the same n/w conclusion
of the pinned compact early-index client. Its signed-rank premise and
natural magnitude input match the source interfaces. No source-level
witness or arithmetic mismatch was found. The review does not elaborate
Lean, establish all-model graph evaluation, authenticate providers, or prove
an exact index, zero map or iPRA endpoint.

`main_field` requires `F≤q` to invoke the separate signed/natural rank
representation. With that representation and `k=kbase+1`, the prototype's
actual signed main root is

```

P=U*(X+a*c)+H*(U*gamma+R+1), N=H*k.
```

There is no extra `X*Y*q` term. The graph field/cast simplification and the
rank representation itself remain unelaborated. `main_pair_norm` uses the
same literal root and its proposed signed norm, plus the field casts for U,
Delta and c, to call the graph-independent signed-pair magnitude theorem.
This magnitude is a norm premise; it does not identify a natural quotient
with a separately oriented main root.

In `compact_early_index`, the graph's first-root norm theorem returns tau;
the client passes that **same tau** and the actual main pair norm to
`compact_early_index_of_norms` at the same symbolic tuple and valuation.

doubled y-coordinate, congruence and exact k expression. The output
`(2*n) mod q⁴=R+1` is an early congruence, not the later equality
`2*n=R+1`. A separate main-index and strong/auxiliary argument is needed
for that equality.

The source obtains `F≤q` from the prototype's own proposed gap, beta
positivity from the symbolic compact tuple, and graph J positivity from its
separate draft. The graph unit-factor proof, positive X, rank window,
source/object provider closure, chosen physical K/PDF binding, all Lean

unshifted model-natural input; the source does not assume it positive.
