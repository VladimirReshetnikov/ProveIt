It independently reconstructs the star/range binders and `L=5^39`, checks the seed and coefficient-definition metadata, and runs source-pinned regeneration and the author's structural validator.

The intended exponent subtraction is saturating `Nat.sub`, and `indexY` retains integer-to-natural truncation. The prototype records these definitions as names; it does not execute them. The four validator mutations test forward references, invalid input index, unbound star variable and a dead node. The validator checks scope, topology, liveness and syntax; it cannot identify a well-formed but semantically wrong operation, fixed constant or transcription.

These are 45 live named macro nodes, not a binary-operation count. The independent reference is also a manual transcription, not a verified parser. No Lean macro evaluator/equality theorem or JSON-to-Lean serialization binding has been established here; no expansion of coefficients, exact degree, PDF binding or iPRA transfer for these JSON bytes follows. `result.json` captures the check output.
