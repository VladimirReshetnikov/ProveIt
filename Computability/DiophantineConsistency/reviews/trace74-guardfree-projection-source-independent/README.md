# Independent source review: guard-free projection and product

Reviewed source SHA-256 values: `Trace74Projection.lean` `1694ffb14a449b228a73e666fa2a8dc209c76ea5c9560afe404ac4239a10f4b8`; `Trace74GraphProduct.lean` `1a667752791fd01e55abb3c4cbf4bf8b4393d4de3df84bd3a3833d161fe741a6`. The mathematical adaptation is consistent at the stated conditional scope; Lean elaboration and direct/provider compatibility are not checked by this source review. No Lean was run.

For the same actual positive-beta, positive-v 74 zero, the first source uses the checked guard-free carrier square to obtain `Z=±M·(tau·f·y)` in the difference ring. The factorization requires its no-zero-divisors property; the source invokes that property for the model difference ring, not for a generic ring. The exact Z shape then yields `H ∣ Y·(hX)K`. Since `H=Y·4(X+1)−1`, the separate all-commutative-ring Bezout identity cancels Y and yields `H ∣ (hX)K`; it does not cancel hX or assert H positive or a guard.

The product source keeps the same masked p/v, sets `a=A−1`, `T=exp r`, and explicitly assumes the same ordinate `c=ycoord r a`. Its A and c casts, `H=4a+3`, recurrence quotient, Pell norm and K identity feed the existing whole-product lemma with multiplier `hX`. The result is `H ∣ (hX)(X−T)(TX+1)`. The second theorem obtains an existential positive odd r from checked Fold and passes that same r and ordinate to the product. The first product theorem itself requires the ordinate but does not require oddness. Neither theorem identifies r with rank, proves X=exp r, a height bound, individual F/C bounds, or the guard. Possible expensive masked simplification, definitional casts, `simp`/`ring` and witness tuple elaboration remain for a guarded Lean check; full provider/search-path ancestry remains separate.
