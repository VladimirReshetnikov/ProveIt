# Independent audit prerequisites

Verify the actual terminal exit and its process-log and state hashes; the
11-source Git-pinned manifest and 18 exact report names; all copied source,
log and output hashes; the 37 direct imports and guarded companion inventories;
the independently audited historical AQ29 parent, provider and toolchain;
and the native and standard bit sentences and both exact checker/no-zero
endpoint statements for the same existential code. Confirm that all ten
predecessor modules and the bit client were rebuilt in one overlay and no
exploratory extension objects were imported. Record a distinct audit exit and
receipt, and do not substitute a different provider if artifacts vanish.

A successful artifact audit is not a second Lean run, an audit of unobserved
dynamic/package-transitive ancestry or transient changes, formal PDF
semantics, an internal comparison with another verifier, or a proof of ZFC
consistency. The output, parent, provider, original Git blobs and compiler
must remain available.
