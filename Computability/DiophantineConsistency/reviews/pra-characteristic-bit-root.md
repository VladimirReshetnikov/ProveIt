# Provable Boolean range for open-formula characteristics

`PRACharacteristicBit` gives every Foundation open semisentence a fixed
PR code with two closed candidate-PRA proofs: its output is always zero or
one, and output one is equivalent to the formula. A second theorem handles
open formulas with free numerical parameters via the explicit packing
interface. The Boolean range is an object-theory theorem, not only a
standard-model fact. This does not cover bounded quantifiers, universal
presentation, or general Σ₁ witnessing.

The independent replay `/tmp/pra-characteristic-bit-root-htc8xisc` passed
both modules without warnings, matched author object hashes, and reported
only `propext`, `Classical.choice`, and `Quot.sound`. It used the reviewed
parameter-packing provider and checks current arithmetic source/object
hashes. Foundation, Mathlib, PRATheory and earlier code objects remain
inherited cache boundaries. The [evidence packet](pra-characteristic-bit-root-replay/)
preserves the clean author and independent runs.
