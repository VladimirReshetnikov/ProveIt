# Independent review of the direct-main draft graph

`check.py` independently parses the complete Lean graph definition and checks every row, input and port slot, residual and output against the pinned draft JSON. It compares each named row against the pinned 91-row parent, checks topology and reverse reachability from `P12`, and independently counts 90 live operations: 50 multiplications, 23 additions and 17 subtractions. The only parent changes are deletion of `g54 = gamma + w` and substitution of the new witness `direct` for `g54` in `g56 = U * direct`. This is a shared straight-line DAG count; it is not a minimality claim.

The three recorded Lean theorems compare the first, main and ordinary residuals over an arbitrary commutative ring and arbitrary four integer ports. The new valuation updates slot 11 to old slot 11 plus slot 5, leaving the others unchanged. Consequently the old positive values of `gamma` and `w` give a positive new `direct`; the source does **not** state or prove positivity transport, output-zero transport, reverse existence, a machine halt theorem, or an iPRA proof. For reverse transport the proposed old witness `gamma = direct - w` must be positive, which does not follow from positive `direct` and `w` alone. Separate arguments may still establish an appropriate witness from graph-specific hypotheses. Neither these forward identities nor the external graph count establishes an equation-to-PDF binding.

The audit checks the source snapshot, compiled object, Lean binary and runner against the successful receipt, rehashes all 1,291 selected project-union files and their symlink targets before and after rerunning the author's pinned external DAG checker, and checks the selected `XQ91.olean` producer. The captured Lean stdout reports `propext` for each identity, with exit 0 and empty stderr. The recorded resource samples are point observations. The union and producer match recorded selected bytes; full historical source-to-object ancestry, package and dynamic-library closure are inherited and have not been independently rebuilt or scanned here. No Lean replay was run for this review.

Reproduce from this directory with `python3 -I -S -B check.py`; `observations/stdout` captures the successful run. Temporary object and provider paths must still exist. The graph and all source/file comparisons are external checks, not Lean proofs of file contents.
