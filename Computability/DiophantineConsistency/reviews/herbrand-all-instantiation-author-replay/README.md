# From universal–existential proofs to candidate-PRA witnesses

For each Foundation open semisentence `φ` with one existential variable followed by `n` parameters, `PRA_witness_of_exists` turns a candidate-PRA proof of `∀⁰* ∃⁰ φ` into a code `c : Code n` together with primitive recursiveness of its standard evaluation and a candidate-PRA proof of `∀⁰* openMatrixAt φ c`. The output is a single fixed code for all parameter values, not merely a witness in the standard model.

The proof first transports the theorem to the deductively equivalent universal presentation. The sequent calculus lemma `instantiateAll` specializes every universal binder to the corresponding free parameter while preserving the list of axioms. Cut elimination produces the existential-only prepared sequent. The existing finite Herbrand extraction collects its witness terms. Those terms are converted to PR codes by retaining the designated parameters and replacing other free variables by zero; the existing finite witness selector combines the resulting list into one code. The proof uses Foundation's completeness theorem and hence classical reasoning in the Lean metatheory.

This is a theorem about the specifically defined candidate theory `PRA`, not a formal identification with a standard presentation of PRA. It does not show that PA or HA is conservative over this candidate theory, nor does it produce an HA proof of the Diophantine consistency equivalence. Those are separate obligations. `#print axioms` reports only `propext`, `Classical.choice`, and `Quot.sound` for the final result. The archived failed attempts and earlier-snapshot checks are historical evidence, not proof inputs.
