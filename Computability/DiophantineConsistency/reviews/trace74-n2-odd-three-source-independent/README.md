It derives positive X,Y, c<k(Y+1), then uses the unaccepted fifth-growth draft and the checked odd-ordinate witness for the same p/v to get r<5. The bounded finite-index reasoning is valid in a nonstandard model as written; it does not enumerate the whole model or assume F/C bounds or the guard.
