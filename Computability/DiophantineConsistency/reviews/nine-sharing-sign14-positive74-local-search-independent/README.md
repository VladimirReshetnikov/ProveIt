# Independent external review

Both frozen scripts were rerun in isolated Python; their full outputs reproduced the recorded result files byte for byte. The checker independently parses the audited Lean circuit, verifies 74 topologically ordered gates, and verifies that each of the five candidate sign reversals is a subtraction used solely twice by its own square. Swapping operands therefore negates that residual and leaves the entire integer output unchanged, for every one of the 31 nonempty sign masks.

For a target, the search enumerates an earlier-value first gate using unordered addition/multiplication (including squares) and ordered subtraction. It then queries a second gate combining that fresh result with an earlier value, in both subtraction directions, or squaring it. Inputs consist of the earlier registers, 14 variables, four symbolic ports and literals −4 through 8. It compares three deterministic signatures modulo the checked prime 1,000,000,007, then recomputes live gate count for a matching replacement. Nonconstant zero samples and zero target samples are explicitly rejected in every sign variant, avoiding the division-by-zero blind spot. Literal zero multiplication cannot match the nonzero target signatures. The baseline's 746,845 first-gate recipes and 19,906 second-gate queries agree with independent combinatorial counts; no strict reduction survives in baseline or sign variants.

The positive control inserts two live redundant operations and recovers reductions from its 76-gate graph, including an exact return to 74 gates. This tests the search path but is not an exhaustive coverage certificate. A modular match is not an exact polynomial identity; any proposed candidate requires exact proof. The negative result concerns this same-target bounded family with these leaves and 31 sign variants, not arbitrary circuit restructuring, zero-equivalent transformations, a global lower bound, or a Lean binding to external JSON/PDF bytes. The scripts' square-root branch is for this prime, which is 3 modulo 4, and checks every sign choice across the three samples.
