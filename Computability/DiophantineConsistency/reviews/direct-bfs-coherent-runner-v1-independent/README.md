Use `os.path.lexists()` or equivalent and reject every existing path before writing. More broadly `files()` maps any path for which `is_file()` is false to absent: dangling symlinks and other non-regular filesystem entries can be mistaken for absent baseline, outside, or union companions. Enforce that absent really means no directory entry and reject any present entry that is neither a regular file nor a link resolving to a regular file.
2. The outer wrapper computes its expected runner hash dynamically. It detects changes during its own run but does not enforce that the launched runner is the reviewed `8af60...` version. Pin the reviewed runner bytes in the held wrapper and verify before and after the child invocation; independently verify the wrapper's own frozen hash when launching.
