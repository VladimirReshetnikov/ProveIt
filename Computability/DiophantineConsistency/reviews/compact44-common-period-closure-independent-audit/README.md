The unchanged source scan reran and matched its recorded JSON; optimized execution was rejected. The review rehashed 150 corresponding `.olean` objects on each side and checked 160 external input slots, 240 absent target slots and ten Init slots. This is a point-in-time source/provider inventory, not a parent audit rerun, Lean build or paired replay.

The proposed final theorem assumes positive graph variables and internal graph zero with fixed symbolic beta and low/high masks and arbitrary natural K. It obtains one common N,w and bounds selector digits for all model periods, handles the origin separately, proves the row-1 digit zero, and bounds the 41 copy digits across those same periods.
