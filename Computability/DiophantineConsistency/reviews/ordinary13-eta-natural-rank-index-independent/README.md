# Independent review: eta-natural rank and conditional early index

The proposed lower bound for the **natural truncated rank** and the compact
q/early-index source interfaces match their pinned declarations. The early
index conclusion retains the same first root tau, index n and quotient w
from the imported fact-level theorem. No source-level mathematical mismatch
was found. This is not Lean elaboration or a proof of graph norm extraction,
port provenance, an eta-zero contradiction, or an iPRA endpoint.

For natural

```
R=((q−1)*(q−F)+alpha)*(q²−1)+(MC+q*MF)*J,
```

all subtractions are truncated. The graph's shifted `alpha≥1` gives the
first coefficient at least one even if `q<F`; `q≥6` gives `q²−1≥35`, so
`R≥26` follows without a C-gap assumption. This is only the natural rank.
For the scalar control `q=6`, `beta=5`, `J=1`, `F=7`, `alpha=1`,
`MC=MF=0`, the truncated rank is 35 while the signed expression is −140.
Thus the natural-rank theorem alone does not identify the graph's signed
rank when `F>q`. It is not a graph-zero counterexample. The separate gap
and rank-representation source is still required for that identification.
At `q=5` the scalar natural rank can be 24, illustrating that this proof
cannot simply weaken its threshold to 5 without other hypotheses.

The compact q source's exact interface assumes positive model J and returns
`q≥47` for the pinned symbolic port tuple; it does not take the unrelated
residue graph zero as an input. The client obtains J from its prototype-zero
source and rewrites the two q definitions, then applies the natural-rank
bound. It keeps K an arbitrary natural and does not establish its physical
kernel/port association.

The compact early-index client explicitly assumes the first natural norm for
its named tau and the exact natural magnitude main norm with
`P=U*(X+a*c)+H*(U*gamma+R+1)` and `N=H*k`: there is no `X*Y*q` term.
It supplies positive q and X, `Y=q³*(v7+1)`, `Y≥8`, `k>0`, `R≥24`
and the separate compact rank window to the pinned early-index theorem.
The returned `xcoord n=tau`, doubled first ordinate and exact k expression
all use the same n and w. The theorem does not derive its stated first and
main norm inputs, a main Pell index, auxiliary offset, or eta-zero
contradiction. Model casts, graph factor/norm extraction, consistent provider
objects, Lean elaboration, zero maps and iPRA translation remain separate.
