# Independent review: direct-BFS halt-to-packing ingredients

These five frozen source declarations are model-level ingredients, not a completed halt-to-80-graph completeness theorem. They work over arbitrary ordered arithmetic models satisfying `IΣ₁`; halt times and all model elements can be nonstandard. `check.py` verifies each accepted author receipt, current/copy source, runner, output and log hashes, pre/post direct input pins, first selected source-direct imports, printed axiom reports and absence of source `sorry`/`admit` or logged diagnostics/`sorryAx`. Exact paths, hashes and receipt digests appear in `check-output.txt`. All printed reports list `[propext, Classical.choice, Quot.sound]`. No Lean replay was performed; transitive object selection, historical source-object lineage, package and dynamic-library provenance remain inherited.

`DirectBFSModelForwardWord.transfer` takes any original-table `CompactLocalWord.Word b N s` and returns `DirectBFSLocalWord.Word (fun j => forward (b j)) N s`, preserving the same N and s, the <943 row bound, origin row 0, excluded row 1 and both local cyclic edge conditions. Its model `forward` maps bounded original row values **to direct-BFS row values**, using the finite original→direct renaming and edge equality. It is conditional on the input word; it does not construct a packing.

The three halt/packed theorems have distinct quantifier scopes:

* `DirectBFSHaltPackedWord.halt_packed_word` assumes internal `first (ArithmeticMachineRun215.run T)=0` and produces one definable direct row function b, N,W,s,C. It chooses the zero dummy, states `N=power 581197 (T+1)*power 581197 (T+3)` and `s=power 581197 (T+1)`, `Blocks 10 b N W`, a direct local `Word b N s`, positive bounded C, Boolean radix digits, and all selector/copy-digit equalities for that same b,N,C.
* `DirectBFSHaltPackedPulse.halt_packed_word` takes an **arbitrary supplied Σ₁-definable** dummy function before the existential row witness; it additionally proves digit 1063 is `dummy j%2` for all j<N. The same b,N,s,C is used throughout that instance.
* `DirectBFSHaltPackedFamily.halt_packed_family` places `∃ b,N,W,s` **before** `∀ dummy [Σ₁-Function₁ dummy]`. Thus one shared b,N,W,s works for every definable dummy; for each dummy the displayed `C=packedWord b dummy N` can vary, and has the same bounds, selector/copy equations and pulse equation. It does not assert that a suitable calibrated pulse already exists.

`DirectBFSConditionalPacking.pack_from_remaining_fields` assumes a direct local word `row,N,s`, `dummy 0%2=0`, `1<N`, `s<N`, `mask+1<Exp.exp d`, `1≤HP<Exp.exp d`, and the full `TransportFields d K HP N s (cellWord row dummy)`. Those five explicitly assumed fields are: `K*X j<Exp.exp d*Exp.exp d` for j<N; `X j+blk ... j<Exp.exp d` for j<N; positive origin block; `NoCarry (blk ... 0) (HP-1)`; and `NoCarry (blk ... j) HP` for all `0<j<N`. The conclusion is `PackingInput d K mask HP N s (cellWord row dummy)` for exactly those same inputs. The theorem derives the low fields, but does not establish the five remaining transport fields, scalar bounds, calibrated rank, Pell seeds or graph zero from halt.

The three halt-packed packets select byte-identical `DirectBFSHaltWord` and `DirectBFSConstructedWord` objects; the transfer packet selects the previously reviewed direct-to-original transfer object as an import, and the conditional packet selects its explicit low-field/transport providers. This direct-import agreement does not prove all prior source-object and transitive dependencies coherent. No direct-BFS halt→packing→80-zero implication, converse, external coefficient/file identity or syntactic iPRA endpoint is asserted by these ingredients.
