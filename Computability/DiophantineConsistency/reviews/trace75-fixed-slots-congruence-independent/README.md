Both statements quantify an arbitrary IΣ₁ model, natural tuple `p` and model tuple `v`, with `p 0 = betaNat`, `p 2 = lowNat`, `p 3 = betaNat + highNat`, every coordinate of `v` positive, and actual trace75 difference-ring value zero. No equality or size condition is imposed on `p 1` (K0).

`graph_fixed_slots` obtains one positive `N` from fixed saturation and retains it for the repunit, q and high-mask no-carry. It separately obtains positivity of `Cnat` on the same graph and applies its locally proved `increment_digits` lemma to derive origin digit 1 and no-carry at each non-origin `j < 8807*N` against low-mask digit `j % 8807`. This is slotwise, not an assertion that the digits equal machine states. The source's introductory comment calls it an 80 graph; the actual theorem uses `TenPositiveTrace75.value75`.

It identifies them using injectivity of exponential and cancellation of nonzero 67×8807, then proves `(67×8807)*N ≤ rankNat`, the stated expression for `v 5`, `0 < b`, `v 1 < b`, and the precise natural congruence `((p 1 + v 5)*Cnat) % b = v 1`. Origin digit and bounded-window digits refer to that same `N`. Neither statement establishes halt, iPRA equivalence or file binding.
