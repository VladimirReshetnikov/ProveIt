# Independent audit of direct-BFS bands and 80-graph carry

The captured read-only check inspects both selected guarded author receipts,
six resolved and individually pinned direct imports, two terminal histories
and nine sampled resource observations. It checks source/runner/tool and
selected object hashes, direct import resolution, cross-producer objects,
logs and printed axiom targets. The direct-BFS model-mass object and the
earlier graph fixed-congruence object match their prior review hashes. This is
not an independent Lean replay or a complete transitive serialized, package,
dynamic-library or historical source-to-object ancestry audit.

`DirectBFSBandCarry` decomposes the **direct-BFS** symbolic kernel into two
bands and bare terms, proves the corresponding modular rotation and indexed
flattening, and obtains the generic carry input from an explicitly assumed
rotated-band congruence and digit/size bounds. Its carry mass premise comes
from the direct-BFS model-mass theorem. These statements hold in the stated
IΣ₁ models; the generic carry theorem does not by itself supply a graph zero
or its congruence.

`DirectBFS80Carry.graph_indexed_carry` supplies that interface from an actual
positive 80-graph zero with four explicit symbolic port equalities, including
`p 1 = DirectBFSSymbolicKernel.paramKernel rho`. It retains one positive N
for the radix/repunit, actual graph's residual power `v 5`, and indexed carry
input using the direct-BFS selector family. The fixed congruence is first
derived with p₁ arbitrary; the proof then uses the specified p₁ equality to
apply the direct kernel-band cast. No original-kernel or old 12-variable
graph-zero premise appears.

The separately reviewed external reconstruction matches the direct symbolic
recipe to the candidate K payload, but this receipt audit does not prove a
Lean equality with that payload or bind the other external ports. Full
selected-column decoding, tile/color machine conjugacy, converse, iPRA and
external JSON/PDF binding remain outside the theorem. The printed Lean axioms
describe metatheory dependencies, not object-theory iPRA axioms.
