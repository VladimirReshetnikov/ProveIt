# Independent audit of the 51-variable quartic display

`run_audit.py` ran five independent checks on the recorded input hashes. `audit.py` uses its own tokenizer and sparse-polynomial implementation to compare all 54 displayed definitions, including all 35 residuals, with the pinned 187-gate candidate in 55 independent symbols. It checks all 51 displayed variable names and positions, the complete sum wiring, all 187 evaluator rows, and all 187 Lean-literal rows. It also rejects two corrupted raw sums. `evaluate_samples.py` separately checks the same definitions on 25 deterministic assignments, with seeds 80231 through 80255.

`check_generator.py` reproduces the TeX byte-for-byte in a temporary copy. `check_verifier.py` independently confirms that the shipped verifier rejects both the bare-residual-alias spoof and an extra term outside the split environment. `check_pdf.py` independently rebuilds the PDF byte-for-byte; the local TeX run reported eight font-substitution warning lines and no overfull boxes. Both PDF pages were also inspected visually.

The audit initially identified pairwise-distinctness wording, a collision between a residual and the fixed decimal integer, two verifier false-negatives, circuit-label ambiguities, and visual confusion between circuit input `O` and digit `0`. These were corrected before the recorded final run; the input is now spelled `sumY` in the evaluator and mapped to the displayed `O`. This packet checks the displayed equations and local reproduction, not historical Lean object ancestry or the separate identification of the mapped refutation predicate with Con(ZFC).
