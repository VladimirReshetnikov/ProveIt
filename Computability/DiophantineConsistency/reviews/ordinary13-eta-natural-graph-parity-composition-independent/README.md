# Independent review: eta-natural graph parity composition

The proposed composition supplies the compact parity boundary's previously
explicit strong and auxiliary equations from the same prototype graph zero,
port tuple and valuation. Its local premise types match the boundary's types
after introducing the same `p=ports K`, and its eta-zero specialization is
consistent with the pinned field interfaces. No source-level tuple or
witness mismatch was found. This is not a Lean-checked eta-forcing theorem,
zero equivalence or iPRA endpoint.

The compact beta source and the prototype's separate J-positive draft are
used to obtain a positive beta cast; the prototype gap draft then gives
`F+alpha<q`, hence the exact `F≤q` premise required by the graph auxiliary
ordinate's signed-to-natural rank representation. The same p and v are used
throughout. No independent, unrelated graph zero is supplied to that step.

The client takes the **third** equation of the prototype's signed-norm
result, and rewrites the actual I, Delta and f field evaluations. At the
explicit boundary assumption `v9=0`, `c=v9+Y*k` becomes `c=Y*k`. The local
strong equation has exactly the compact boundary's required type. For the
auxiliary equation, it invokes the graph `direct_auxiliary` source with the
same p, v and `F≤q`, then specializes the same c, Delta and shifted `T=v5+1`.
The local auxiliary type also matches the boundary's required type. The
independent checker compares both full premise types after removing only the
boundary's local `let p` binder; this is a text/interface comparison, not
Lean typechecking.

The proposed `eta_zero_impossible` calls the compact boundary with these two
equations and the same `K,v,hz,heta`. The subsequent `eta_positive` reasons
that a natural eta not greater than zero equals zero. Its source is generic
in the intended `IΣ₁` model, but neither source has been elaborated. Applying
it as the separate zero-map draft's all-model `ForcedEta K` still needs an
explicit, checked wrapper and coherent model/provider dependencies. The
compact boundary's large-k geometry, common Pell-index witness, offset,
rank window and classification proofs are inherited unelaborated source
dependencies. The symbolic tuple's concrete K/byte/PDF binding and the exact
parent polynomial bridge also remain separate.

From this directory run

```
python3 -I -S -B check.py > /tmp/eta-graph-parity-independent.json
cmp result.json /tmp/eta-graph-parity-independent.json
```

The checker pins the composition and key source interfaces, compares the
strong/auxiliary premise types, and tests 250 bounded prototype evaluations
at eta zero with `F≤q`. The evaluations need not be zeros and do not prove
model casts, eta forcing or Lean tactic correctness. No reviewed source was
modified.
