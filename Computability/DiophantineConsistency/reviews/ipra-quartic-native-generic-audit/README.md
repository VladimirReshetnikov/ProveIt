topological order, matching author/peer rows, actual objects and complete logs,
every direct dependency hash, and the recorded present and absent parent,
fallback and direct-input guards. It also checks the 19 retained parent source

still has an explicit polynomial-bridge premise; this receipt audit is not a
no-premise concrete endpoint or an actual process-exit observation. Inherited
transitive project, package and dynamic ancestry remain outside its scope.
