# Independent external audit: MF source-port block layout

Checker exit 0. Independently converting the 2,012 proposed radix digits block-by-block gives 252 little-endian blocks whose concatenation equals the 11,815-byte decompressed MF_source snapshot. Independent grouping yields ten distinct patterns and the 12 claimed run counts. Snapshot, author checker and result hashes were checked. The last four-digit block occupies 18 bytes because its upper zero bits are omitted.

This is external Python arithmetic/filesystem evidence, not a Lean theorem about the whole port, a file or gzip, or a JSON/PDF binding.
