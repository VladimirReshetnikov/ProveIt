# Independent review of the trace75 decimal display

PASS for the pinned external transcription and finite degree/liveness checks. This review does not establish Lean's JSON/TeX/PDF binding, a coherent provider ancestry, or an iPRA theorem. The [display README](../../research/trace75-bfs-decimal-display/README.md) makes those limits explicit.

The review's independent `check.py` rehashed the pinned JSON, TeX, PDF, BFS row source, indexed tile data, slot source and prior fixed-formula display. It compared all 75 literal TeX gate lines and all 75 PDF-extracted gates against the JSON, including operand order and operation. It found 10 unknowns, all 75 live gate outputs and all 14 graph inputs reachable from the final output, with 44 multiplications, 17 additions and 14 subtractions. The checked main TeX and PDF match the retained `build01` files byte for byte.

The 943 row tuples parsed from the pinned BFS Lean source matched the independently retained indexed tile JSON. The independently recomputed 943 decimal selectors and 41 slots matched the PDF extraction in order. The four fixed integers were reconstructed and compared byte for byte to their retained compressed payloads after checking the payload hashes. The fixed-constant TeX section and the corresponding PDF-extracted formulas matched the previously reviewed BFS decimal display; this is an external comparison, not a formal semantics of the PDF.

The review independently evaluated the entire univariate polynomial coefficient array modulo 1,000,000,007 after setting all ten unknowns to `t`. Its coefficient at degree 402 is 607287076. A separate gate-by-gate total-degree bound gives at most 402. Together these establish exact degree 402 for the pinned integer coefficients. The display's own checker, degree checker and liveness checker were also rerun successfully; the display checker reported four PDF pages and a minimum text bounding-box margin of 28.028 points.
