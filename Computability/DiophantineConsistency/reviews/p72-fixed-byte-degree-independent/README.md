# Independent review: P72 fixed-byte degrees

The independent checker expands each residual as an exact sparse integer polynomial using explicit exponent tuples, rather than the certificate author's packed representation. Treating all four port values and the six specified derived fixed leaves as constants with respect to witness variables, it gets P13 residual degrees 13, 13, 13 and 14, and P14 degrees 12, 11, 12, 12 and 2. It independently verifies each remaining finalizer equals the sum of residual squares; hence the total-degree upper bounds are 28 and 24.

For the lower bounds it reads the actual restored gzip paths, verifies both compressed/raw hashes and minimal unsigned little-endian byte interpretation, evaluates all graph rows with each witness set to `t`, and computes over the prime 1,000,000,007. The resulting leading coefficients are 148,768,232 at degree 28 and 925,559,841 at degree 24. Each is nonzero, so the corresponding fixed-byte integer polynomial has exactly that degree. The graph liveness and operation counts are 98 (57 multiplications, 25 additions, 16 subtractions) and 101 (58, 26, 17), counting the six derived leaves as precomputed constants.

A separate gatewise exponent-bound calculation gives maximum 28 in both graphs, below the author's six-bit packing radix 64, so adding packed monomial indices cannot carry between coordinates. The original checker was rerun and reproduced its retained result byte-for-byte. The coefficient files and JSON are external inputs; this is not a Lean total-degree or file-semantics theorem. Run `python3 reviews/p72-fixed-byte-degree-independent/check.py` from the DiophantineConsistency directory.
