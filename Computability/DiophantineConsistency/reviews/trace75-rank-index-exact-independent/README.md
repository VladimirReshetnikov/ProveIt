# Independent review of trace75 rank-index and rank-exact

Both graph theorems require the same p,v in an IΣ₁ model, positive ten coordinates, actual trace75 difference-ring zero, and the **model-side** bounds `31≤beta`, `MC<beta`, `MF<2*beta`. K0 is arbitrary.

`Trace75RankIndex.graph_rank_auxiliary` exports one I,j,h with I,j positive, `c² | I`, the strong Pell x/y equations, `SignMod F c (ycoord (2h+1) (A−1))`, and `SignMod c rankNat (2h+1)`. Its proof obtains a single joined-square tuple including V0 and its actual graph V-square; it derives `F mod c = 1 mod c` using `U=i*c²`, applies the generic **single-multiplier** signed-rank theorem to that same V0, and uses the odd quotient residue of that same I,h. V0 and its square are used internally and are not exported by RankIndex. The theorem establishes congruence up to sign, not equality of rank and index.

`Trace75RankExact.graph_rank_exact` uses the auxiliary I,j,h above and separately obtains a main-ordinate witness r,j0,I0 from `graph_main_index` on the same p,v,c. The generic rank-reduction theorem transfers the signed auxiliary residue to `SignMod c rankNat r`, and the strict half-size bounds `2*rankNat<c` and `2*r<c` plus positivity imply `rankNat=r`. Rewriting yields the actual graph rank cast, `3q<rankNat`, oddness `rankNat mod 2=1`, `c=ycoord rankNat (A−1)`, and the q⁴ upper window. The two strong witness pairs I,j and I0,j0 are not identified. This proves c is the indicated Pell ordinate; it does not prove `X=2^rankNat`, halt/iPRA equivalence, trace74 reverse guard, fixed-port bounds, or external data binding.
