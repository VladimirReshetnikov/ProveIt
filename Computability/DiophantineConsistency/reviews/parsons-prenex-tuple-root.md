# Strict Π₂ tuple normalizers

For two finite universal-existential blocks, Lean constructs actual PA-minus
rule proofs in both directions for their disjunction and conjunction and a
single block with concatenated universal and existential tuples. The four
transformers allow arbitrary finite tuple lengths, including zero, preserve
free parameters, and retain a bounded matrix when both input matrices are
bounded. This is a proof-output normalization fragment: it does not yet
provide the height-preserving source-derivation adapter or normalize every
non-prenex Π₂ formula. The construction uses classical metatheoretic
completeness and is noncomputable.

Two isolated builds against the independently replayed strict-disjunction
provider `/tmp/parsons-prenex-pi2-or-independent-_zzb0w81/lib` matched source,
object and complete-log hashes. The driver verifies frozen local providers.
The [independent driver and logs](parsons-prenex-tuple-root-replay/) and
[author packet](parsons-prenex-tuple-author-replay/) are retained. Foundation,
Mathlib and completeness objects remain inherited boundaries.
