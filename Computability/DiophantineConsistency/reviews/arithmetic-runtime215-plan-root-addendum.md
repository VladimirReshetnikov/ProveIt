# Runtime seed parameter terminology

The ROOT plan review's phrase "clock 40" denotes the entry parameter k,
which counts spare blocks. It is not an execution time. The approved seed
is control 1, the physical file [0,0,0,0,0,0,4,0,0], k=40 and gap=1;
the accepted boot execution time remains 95,714. This corrects prose only.
The frozen plan, graph, provider inventory and implementation scope agree
on those exact values and remain unchanged.
