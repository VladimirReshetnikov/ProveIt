# Independent source review: first/main large-k fact

The exact square-gap interface excludes eta+zeta=2 from the main norm; positivity gives eta+zeta≥2. The first norm then matches the existing Pell-descent bound with m=XY²>0, giving k≥8XY²+4. No strong/auxiliary norm, literal graph zero or root sign is assumed.

The checker tests bounded square-gap/Pell cases, pins the previously passed independent component reviews and receipts, and replays the author source receipt. It does not rerun those independent reviews, elaborate Lean, or establish parent/endpoint bindings. Run `python3 -I -S -B check.py` and compare with `result.json`.
