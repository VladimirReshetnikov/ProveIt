# Independent review: twelve new full-client producers

The retained producer comparison covers exactly the twelve new project modules in the full-recipe BFS client's serialized closure. `check.py` independently rehashed the twelve successful producer receipts, the current recorded source and output objects, producer logs and the comparison result. For each producer it matched the non-`Init` serialized import list to its source imports, then matched all 16 direct project-import edges to that producer receipt's object path, hash and resolved-target pins. `result.txt` records the successful check. The current objects were also rehashed; the independent serialized-closure review checked the 71 captured header batches.

The record demonstrates agreement of the retained producer-time pin records with the later captured selection, not a fresh Lean replay. It does not independently establish each historical compiler's lookup sequence or every dependency companion at that earlier time. `Init` is excluded from the 16 project-edge count and appears only in the captured outside boundary. Older project and supplementary provenance, package-transitive and dynamically loaded objects, and PDF/file binding remain outside this comparison.
