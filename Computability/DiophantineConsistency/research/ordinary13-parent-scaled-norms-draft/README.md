# 13-parent own-zero to adaptive scaled norms — source draft

This proposed same-valuation model binding extracts the parent first/main
residual zeros from its four-square own zero. Over arbitrary commutative
rings the adaptive first/main unit factors evaluate as one plus those
residuals; the first comparison distributes the folded Bt term. The existing
model unit/signed-pair square interface and natural-port right-hand-side
identities then give the two `ScaledNorms` on the same Fin13 valuation.

Natural ports are explicit, and no adaptive-expression zero, quotient,
positive valuation, parent-to-88 witness or endpoint is assumed. This source
is unelaborated; exact graph/factor identities and all Lean/provider
compatibility require independent review and subsequent elaboration.
