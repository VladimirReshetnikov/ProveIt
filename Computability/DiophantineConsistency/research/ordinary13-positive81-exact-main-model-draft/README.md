Lean theorem, provider closure, all-model 81/83 transfer, or iPRA endpoint.

additional explicit assumption `eta=v9>0`, and arbitrary natural K.

first-ordinate, exact quotient and q⁴ residue equations. It proposes to:

   that same natural root and signed balance;

   carrier balance. This proposes both `ExactIndexCut` and `OrientedMainCut`.

obtains its n/w from the actual graph early-index draft. The final conditional
source wrapper applies them to an actual positive-81 zero via the one-way

or fixed physical byte/PDF binding is used.
