# Sign25 direct endpoint without an expression alias

This source-only retry uses `Sign25CurrentExpression.expression` and the
already checked `Sign25DirectIPRA.polynomialBridge` directly. It removes the
new typed expression alias that failed in the minimal diagnostic and applies
the existing generic native endpoint theorem, followed by standard and
Gödel–Gentzen translated wrappers. These statements have not been compiled;
the first stage imports both bridge and endpoint framework and may exceed the
same Lean interpreter limit. Guarded preflight, independent review and an
assigned Lean slot are required before any run. The inherited provider and
point-observation qualifications remain.
