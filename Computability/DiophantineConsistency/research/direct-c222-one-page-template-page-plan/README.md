## Proposed layout and honest size comparison

The document proposes US Letter portrait, two columns, 0.43-inch margins,
a 13-point column gap, and 9-point text/math with a 10.2-point baseline.
The title uses 11 points. There is no smaller seed/table font. These are
literal source settings, not observed dimensions or a visual-quality
assessment. The document has no forced page break and has never run.

A hand count of the displayed mathematical rows is approximately 56:
34 for coordinates/front/constructors/local polynomial and 22 for the
private tuple/residuals/request family/final equation. This is a layout
estimate, not a parser count or a measurement of rendered line boxes.
The surrounding prose might take roughly 25--40 column lines. Ordinary
display spacing and the title add further height. At a rough total of
90--110 column-line equivalents, balanced columns would have about
45--55 lines each. That suggests a plausible one-page target at the
chosen settings, with substantial uncertainty from long formulas and
unbreakable display groups. No actual page count follows from this
estimate.

The likely horizontal pressure points are the longer axiom codes, the
bundle's K helper, the eleven-entry upper-argument vector and the
twenty-seven-coordinate tuple. Manual line breaks were included in the
bundle and tuple. Only a later authorized complete compilation, extracted
glyph audit and actual visual inspection can settle clipping, overlap,
column/page breaks, indices and readability. A shorter text is not worth
an unreadable page, and no current page should be changed on this basis.

The generic byte counter observes `equation.tex` at 5555 bytes and 166
source lines. The maintained 55-radix page's previously bound TeX source
is 5195 bytes. Therefore this FIRST readable draft is 360 source bytes
longer, about seven percent; it supplies no source-byte reduction over
that maintained page. Source lines are not rendered lines. No further
normalization, token count, ink-area count, operation count, expanded
coefficient count, or bit-cost measurement was performed.

The possible benefit is a complete small-numeral mathematical recipe
with no seed/table decoding, rather than a demonstrated shorter TeX file
or smaller equation. The measured 5555 bytes also includes explanatory
prose and formatting; removing those would not establish a fair saving
without a consistent comparison convention. Physical fit alone would
not make this 554-variable high-degree route dominate the maintained
fifteen-positive-variable 66-operation degree-157 equation. Both tradeoffs
must be retained honestly.
