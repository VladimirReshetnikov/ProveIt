# Natural 89 existential r replacement: model draft

This is an **unelaborated source-only proposal**, not a checked root switch,
all-model zero map or iPRA theorem. It targets the exact natural-89 unit-product
graph and the `RReplacement K` interface of the mixed 89/80 source. It does
not assert that the original zero has positive r.

The proposed forward map raises J, gamma, w, and eta through the separately
introduced 89→88→87→86→85 evaluation identities. It leaves f, r and y
unchanged. The same source proposes that changing only coordinate 8 commutes
with this forward map, so any same-valuation prototype output equality can be
transported back to the exact 89 literal without taking any predecessor of the
other four coordinates.

If r is already positive, retain the original zero. If r=0, the prototype
first norm has the exact root form and scale required by the separately
drafted `ResidueRootSwitchExtractDraft.positive_replacement`. The compact
model-cast beta is positive, and J is positive from the prototype first-factor
source. Since eta was raised, `k≥2` even though the 85 prototype itself allows
eta=0. The fact-level helper proposes a positive model-natural r′ with the
same first-root square, using signed magnitude, scaled-square divisibility,
and signed-to-natural quotient reflection. The source then proposes that the
prototype's other three product factors do not depend on r, so its total
output is unchanged. Mapping back yields a 89 zero with r′>0 and exactly the
same f and y. No compact K upper bound or `ForcedEta` premise is used.

The helper's sign cases, positive natural quotient, graph field/evaluation
normalization, model casts, factor-unit first norm, all forward maps, compact
beta, compatible providers and actual axiom reports remain unelaborated.
The separate `DirectFY` source and exact positive-80 `PolynomialBridge` are
still needed by the mixed 89/80 bridge. No physical file/PDF interpretation
or end-to-end iPRA/ZFC equivalence is asserted.
