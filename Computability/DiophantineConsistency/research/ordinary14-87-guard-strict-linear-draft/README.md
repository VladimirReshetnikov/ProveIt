# 87 own-zero strict guard bound with X ≥ q — source draft

This source-only draft weakens the independently reviewed sufficient growth
hypothesis from X ≥ q² to **X ≥ q**. The 87 own-zero guard gives F < q,
therefore F < X; the remainder of the strict-guard proof is unchanged.
It assumes positive beta and valuation and explicit beta/K port casts. It
assumes neither an 86 zero nor an old-coordinate witness.

The hypothesis X ≥ q is not proved here. Lean has not been run: elaboration,
graph/provider coherence, reverse existence, iPRA endpoint and file binding
remain open. The finite controls verify the arithmetic implication, not Lean.
