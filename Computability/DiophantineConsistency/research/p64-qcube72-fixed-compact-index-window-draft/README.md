# First-index window at fixed compact ports

`FreeMainFixedCompactIndexWindow.first_index_window` proves that, in any IΣ₁
model, every actual positive zero of the 72 graph at the fixed compact44 beta
and masks and any natural K supplies a model element `n` with
`n<R<2n`, together with its two first Pell-coordinate identities. Here `R`
is the graph's actual rank, already identified with the main Pell index by the
checked fixed compact ranked-main theorem. In discrete arithmetic this implies
`R+1≤2n`. The proof composes the checked fixed-compact `n<R` result and the
generic `m<2n` result; it assumes no early congruence.

The upper bound and congruence needed to conclude `2n=R+1` are not supplied.
This does not establish the old carrier, a reverse witness map, existence
equivalence of the 72 graph, or an iPRA endpoint.
