# Direct-BFS symbolic rows and kernel

Lean proves the exact row count, all four coordinate widths, per-row bounds, and the all-model cast identity for that kernel. This is a new symbolic term; it is **not** the existing `CompactSymbolicKernelOpaque.paramKernel`, which uses the retained-original row order/colors. In particular no existing machine decoder, completeness/controller theorem, positive-zero equivalence, iPRA proof, or coefficient-file binding is inferred from the new definitions.
