# Three-operation fork screening for an 86-gate output

[`screen-three-fork.py`](screen-three-fork.py) extends the earlier heuristic with replacements shaped as two independent one-operation intermediates followed by one `+`, `-` or `*` operation combining them. Both intermediate operands come from inputs, literals or earlier rows of the pinned 87-gate candidate; neither intermediate may depend on the other. The script uses the same three pseudorandom field samples, prime, seed and available literals as [SCREENING.md](SCREENING.md), and refuses a candidate JSON hash other than `da6b88365da3ec9db6040373c25de20b30baf63edc9fdf742de2aa4b2c06e6e8`.

For each target row it first replaces the row temporarily with `0+0` and counts how many old live rows become dead. The script checks the 25 target rows for which this potential is at least three: adding two intermediate gates cannot reduce the live total otherwise. For each such target it stores all represented one-operation intermediates, matches possible final operations by modular signatures, inserts the three gates, and recounts live rows. The saved [run output](screen-three-fork.out) reports all 25 checked targets and no candidate with fewer than 87 live operations. Script SHA256 is `780fa9878d15604b18fe0852e25b63a61eaa90c4890c6b49b63d962fef8a48e5`; output SHA256 is `4868462c44f434c89e86f36854b83d88ea29cc40da83e09ab05864b1bdd941a6`.

This is heuristic screening, **not an exhaustive search or a minimality proof**. It covers only the specified fork shape, a single replaced row and the existing earlier-row order. It excludes identical intermediate operation triples, skips multiplicative matching when an intermediate has a zero sample, and accepts only equality of three modular signatures. It does not search serial three-operation expressions, shared intermediate subexpressions, multi-row rewrites, other constants or alternative equations. Modular collisions can cause false matches; a reported candidate would require exact polynomial and liveness verification and a Lean binding. No 86-gate equation is claimed.
