# First-index residue from the actual adaptive zero

The first classified Pell index `n` from a literal current adaptive natural
zero now satisfies `(2n) mod q⁴ = R+1`, `R+1 ≤ 2n`, `R+1 ≤ k`, and
`13 ≤ n`, in every selected `IΣ₁` model. The theorem retains the actual
scaled first-root magnitude and recurrence coordinates. It combines the
signed rank congruence with the actual rank window, `q³ | Y`, and the
internal Pell residue theorem. Since `Q = XY²`, the derived Y quotient gives
`q⁴ | 2Q`, which is the required recurrence period divisor.

The exact residue is meaningful because the rank window proves `R+1 < q⁴`.
No prior sign of `k−R−1`, index offset, power representation, or equality of
the main index with R is assumed. The lower bound is 13 because the current
formal rank window uses `24 ≤ R`; a stronger numerical bound would require a
stronger rank-window theorem. The main-index comparison and full HA proof
remain separate work.
