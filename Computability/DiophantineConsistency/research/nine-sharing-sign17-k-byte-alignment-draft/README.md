# Source-only staged K block alignment

The external-data generator proposes eight independent source groups covering 252 full radix/byte blocks, with each element justified by one proposed numeric pattern theorem. Tail block 252 remains separate. Neither the generated block lists nor any connection to the actual symbolic stream has been checked in Lean. They require compiled/audited numeric pattern providers, guarded prelaunch and exclusive allocation; no external-file theorem is asserted.
