# Source-only K digit-bound probe

The conditional statement would bound all digits of an arbitrary 986-vector stream if every coefficient plus one is below the actual radix. Three concrete per-block checks sample the first 32 tile coefficients, the final 14 and the 44 controls. They do not yet cover the other tile blocks or prove the actual stream bound. This draft has not been compiled; it requires a fresh guard, independent prelaunch and exclusive Lean allocation. No byte or external JSON/gzip/file/PDF claim is made.
