\subsection{Contents of the delivery}
\begin{description}[style=nextline]
\item[\code{report.tex} and \code{sections/}] Complete editable LaTeX source. Build with XeLaTeX; no network access or generated image asset is needed.
\item[\code{report.pdf}] Compiled and visually inspected report.
\item[\code{lean/}] Checked standalone arithmetic sources, a focused decoder, and complete modified Pell modules. The README states which files are integration candidates rather than checked production modules.
\item[\code{patches/}] Exact unified patches against the source baseline, including both canonical-decoder clients and the shared helper placement.
\item[\code{validation/}] Compiler output, status receipts, source hashes, and dependency provenance. A failed full MRDP import attempt is identified separately from successful focused checks.
\item[\code{evidence/}] Novelty ledgers, independent review, source manifest, and closing-head comparison.
\item[\code{screened_out/}] The withdrawn aggregate-support candidate and its explicit non-recommendation notice.
\item[\code{scripts/}, \code{README.md}, \code{SHA256SUMS}] Reproduction instructions, report build script, validation replay script, and integrity manifest.
\end{description}
