# Structural candidate: prove the zero test from its last two rows

## Recommendation

Retain one concrete new mechanism: the Boolean/idempotence row is unnecessary
for the soundness argument of the existing zero-test certificate. Prove the
selector from annihilation and balance. Apply this to both the external
natural-number certificate and the entire internal omega of an arbitrary model.

The proposed patch changes only the bodies of
`QuadraticBoolean.zero_certificate_sound` and
`ObjectZeroTest.certificate_sound`. All certificate definitions, literal
polynomial rows, public theorem statements, witness counts, generated syntax,
and downstream interfaces remain byte-for-byte unchanged. In particular this
is a proof simplification, not a proposal to change the represented equation.

## Mathematical reason

Let R be a commutative semiring with multiplicative cancellation away from
zero, and let u be nonzero. Suppose

    b*n = 0,        n + b*u = u.

If n is nonzero, the first equation gives b = 0. If n = 0, the second becomes
b*u = u = 1*u, so cancellation gives b = 1. Therefore

    b = if n = 0 then 1 else 0.

The equation b*b = b has not been used. Indeed it follows from the displayed
conclusion. No natural-number induction, discreteness theorem, or enumeration
of an internal model's elements is involved. For the internal certificate,
take R = `ObjectOmegaSemiring.Natural H` and u = slack + 1. The existing theorem
`ObjectNaturalDiscrete.add_one_ne_zero H slack` supplies the exact nonzero
premise for arbitrary internal slack, including nonstandard slack.

For the external certificate its last polynomial row is

    n - (1-b)*(slack+1) = 0

over integers. Ring normalization gives the same balance equation. The natural
slack guarantees that its integer cast plus one is nonzero. In the direct
external replacement, `simp_all [mul_eq_zero]` handles the factor equations
after splitting n = 0; `omega` excludes a natural slack whose integer cast is
-1. The unused Boolean row is explicitly cleared by the `-` pattern in `rcases`,
so `simp_all` cannot use it as an inaccessible hypothesis.

The nonzero multiplier premise is essential. With u = n = 0 the two equations
hold for b = 2, but the zero-test output should be 1. The checked kernel includes
this boundary counterexample. Likewise `NoZeroDivisors` alone in an arbitrary
semiring is not asserted to give cancellation. The generic kernel states
`IsCancelMulZero` explicitly. Nontriviality need not be a separate hypothesis:
the supplied nonzero multiplier already rules out the trivial situation.

`Computability/DiophantineConsistency/Lean/DiophantineConsistency/`.

### External natural certificate

`QuadraticBoolean.lean:16–27` currently splits roots of the first polynomial,
casts the two possible values back to naturals, then inspects the tested
number. Replace only its proof body by:

```lean
  rcases h with ⟨-, hn, hs⟩
  by_cases hz : n = 0 <;> simp_all [mul_eq_zero]
  omega
```

fixture. Both the generic derivation and this literal direct replacement have
been elaborated successfully. The complete production module, including its
full dependency closure, has not been rebuilt by this subtask.

### Internal natural certificate

`ObjectZeroTest.lean:26–36` currently invokes
`ObjectNaturalDiscrete.mul_self_eq_self_iff` on the first field, then handles

```lean

  have hunit := ObjectNaturalDiscrete.add_one_ne_zero H slack
```

The checked abstract fixture uses the exact three-field certificate shape and

## Novelty boundary

The closest earlier material is:

1. Packet `2026-10-26x` derives the Boolean root theorem from cancellation
   and moves strict multiplication ahead of successor discreteness. That
   still assumes the idempotence equation. This proposal establishes that the
   zero-test soundness proof needs no idempotence equation at all.
2. Packet `2026-10-26m` (also listed under the subsequent packet index) consumes
   `exists_zero_certificate_iff` before constructing conditional witnesses.
   It simplifies clients after zero-test correctness has been established;
   it does not weaken the premises needed by zero-test correctness.
3. Packet `2026-10-26zg` normalizes actual zero-test polynomial rows through
   the cancellative-semiring split-zero interpretation. It retains the Boolean
   row in the resulting arithmetic certificate.
4. Generic elementary row operations preserve common zero sets, but those
   proposals do not identify this nonzero-multiplier consequence at these
   concrete zero-test targets.

The novelty claim is narrow: discharge this exact redundant mathematical
premise in the two current soundness proofs. Cancellation, factorization,
Boolean reasoning, and general semantic normalization are prior infrastructure.

## Further research questions

Can the omitted row be removed from a separately versioned zero-test system
while preserving every compiler-level count and the exact downstream
equiconsistency statement? This is additional encoding work and is deliberately
outside this proof-only patch. It would require updating the literal row
family, sum-of-squares expression, cost theorems, and object interpretations.

More broadly, which other small certificates contain an equation that follows
only after cancelling a separately certified nonzero factor? The relevant
criterion is a concrete guarded consequence, not generic row deletion. The
pairing certificate's Boolean row should not be presumed redundant: the other
rows can admit non-Boolean selectors, so every prospective elimination needs
its own argument or counterexample search.
