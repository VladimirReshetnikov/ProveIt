## Preliminary decisions on the new study's candidates

These are novelty decisions only, not compiler-acceptance claims.

1. **Function-valued deterministic witness elimination in composition — eligible, narrowly.** `ComposeRepresentation.Rep.compose` and `DirectComposition.GraphRep.composeDirect` end with an existential function `a` constrained pointwise to the deterministic composed vector. After the previous Fin-block and assignment APIs have done their work, an extensional equality substitution remains. No prior file mentions `funext_iff` or `exists_eq_right`; no prior candidate changes these two correctness tails. Closest prior idea is m's Boolean certificate consumption, but that is a fixed finite Boolean/slack certificate. The new claim should be confined to eliminating the *function-valued deterministic intermediate*, not generic existential simplification.
2. **Helical row-zero by periodicity of the diagonal pullback — eligible.** No prior proposal text/code/patch mentions `row_zero_of_helix`, `HelicalQuotient`, `helix`, or `sub_int_mul_eq`. The nearby u/v interval proof concerns guarded propagation on a bounded interval, and i/l finite inverse invariance concerns finite dynamics. Neither produces the one-period function `s ↦ T(x+w*s,t-s)`. Packet o explicitly declines a generic additive-quotient framework; the proposed local application of `Function.Periodic` requires none.
3. **ThirteenCarrierSoundness auxiliary absolute/square bound — eligible.** `ThirteenCarrierSoundness` appears in f only as an avoidable import in dependency restructuring. Neither its `auxiliary_estimates` nor `transport_nonneg`, nor an `abs_le_self_sq`/`abs_le_sq` simplification, appears in the proposal corpus. Common negative-norm obstructions in q concern other exact targets and a different mechanism.
4. **Joint optimizer semantic-and-size induction — no exact prior proposal located, but lower priority.** Prior a only shortens the primitive recursion congruence branch of `ScalarPROptimizer.eval_optimize`; it does not fuse correctness and size induction in `NaturalSimplifier`. Nevertheless, fusion by itself may merely move code. Require a real duplicated induction or downstream joint use and count the shared helper before recommending it.

5. **Monomial-list interpretation as a library sum — eligible, narrowly.** `SyntaxCoefficients` is mentioned in earlier packets only by source-tree inventories. Its `interpret_append`, `interpret_negate`, `interpret_leftMul`, `interpret_multiply`, and `coefficient_interpret` inductions are not targeted by earlier coefficient proposals. The new proof-only `interpret_eq_sum` bridge identifies the exact retained list semantics with a library sum, permitting map/append/flatMap distribution and coefficient-homomorphism laws. Prior EX035 concerns coefficient row tables and generic arithmetic expressions; EX036 proposes a sparse row checker. Neither already removes these five list interpretation inductions. Preserve order and duplicate terms in the executable `expand` and `multiply` data, and count the bridge/import cost.

6. **Reuse the five Jones expression-evaluation lemmas — eligible.** `JonesSyntax` and `ExecutableJones` occur in prior material only as source-tree inventory paths. The exact `eval_rad`, `eval_wt`, `eval_dvsr`, `eval_dvnd`, and `eval_marg` bridge proofs are not prior targets. Existing scalar/DAG tail extraction does not make these private semantic lemmas accessible. Promoting the earlier five unchanged statements and bodies, deleting the downstream private duplicates, and qualifying their existing clients is an additional concrete reduction.
7. **Coprime two-channel divisibility proof cleanup — reject as a new mechanism.** The exact `RatioReparameterization.combined_dvd_iff` target is unmentioned, but packet l explicitly proposes keeping divisibility witnesses abstract and using principal-ideal closure (`dvd_add`, `dvd_sub`, `dvd_neg`) when quotients are immediately repackaged. The new proof is a further application of that technique, while the coprime two-channel equivalence already exists as the maintained statement. Omit from the new-idea set under the strict non-repetition requirement.
8. **Positive defect for the thirteen-carrier auxiliary norm — eligible.** Under `S² V² − (S²−1)y² = 1`, the identity `(S²−1)(4V²−y²)=(3S²−4)V²+1` makes the square gap positive for `S≥2`. Prior q/m/t fundamental-Pell minimality, l nonsquare integer norm arguments, and s/u sequence ratio estimates address different obligations. The integer-unit shortcut for `y≠0` is supporting reuse and receives no separate novelty credit. This can share a report chapter with the distinct affine-step domination lemma.
