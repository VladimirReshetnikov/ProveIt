\section{C Remove the expanded polynomial detour}

The original proof first establishes the natural-subtraction domains, casts the repunit balance, derives a separate $\beta J=q-1$ fact, instantiates the shared packing lemma, spells out a second long casted polynomial, and finally identifies the rank expression. The proposed proof keeps the domain reasoning but closes the normalized equality directly:

\begin{Lean}
  have hJ := CurrentNativePacking2011.repunit_pos (N:=N)
  have hHJ : 1 ≤ highPort*repunit width N := Nat.mul_pos highPort_pos hJ
  have hCq : C ≤ q N := by omega
  have hFq : F+1 ≤ q N := by omega
  have hb := congrArg (fun n : ℕ => (n : ℤ))
    (CurrentNativePacking2011.repunit_balance (N:=N))
  push_cast at hb
  unfold fourBlocks rank NativeRankVariation.windowRank
  push_cast [Nat.cast_sub (by omega : 1 ≤ C),Nat.cast_sub hHJ,
    Nat.cast_sub hCq,Nat.cast_sub (by omega : 1 ≤ q N-F),
    Nat.cast_sub (by omega : F ≤ q N)]
  linear_combination -(q N : ℤ) * hb
\end{Lean}

\subsection{Why the equality is unchanged}
Write $L,H,J,q,C,F,\beta$ for the corresponding integer quantities. The natural four-block expression becomes
\[
 (C-1)+(LJ+1)+q(F+HJ-1)+q^2(q-C)+q^3(q-F-1).
\]
The rank is
\[
 (q(q-F)-C)(q^2-1)+(L+q(H+\beta))J.
\]
Their difference is exactly $-q(\beta J+1-q)$, zero by the cast repunit balance. This is the \emph{same} identity as the existing shared packing lemma, with the orientation reversed; no new algebraic discovery is claimed.

The cast is valid only after the bounds for $C-1$, $HJ-1$, $q-C$, $q-F$, and $(q-F)-1$ have been proved. All original domain facts remain. In particular, the high-port product is positive and $C>0$, $C+F<q$ remain explicit. Replacing natural subtraction by integer subtraction without these facts would be unsound. The source's once-shifted fourth port $H+\beta$ is not altered or shifted twice.

\risk{} This removes eleven physical lines and no import or helper is added. It bypasses the shared theorem, so future changes to that theorem's normal form will not automatically update this client. Prefer the existing proof when that maintenance benefit outweighs brevity. Exact \texttt{push\_cast} and \texttt{linear\_combination} elaboration remains a future compile gate.
