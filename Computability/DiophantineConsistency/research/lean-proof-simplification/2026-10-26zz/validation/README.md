# Validation scopes

Source replay, baseline evidence replay, exact one-fragment patch replay and independent guard/import review are distinct. None invokes Lean. Historical author/reviewer compilation reports remain attributed historical evidence only.

`replay_archive.py` extracts a sealed ZIP into a temporary directory after CRC and path checks, runs the shipped verifiers with ordinary and optimized Python, checks three deliberately damaged disposable copies are rejected, rebuilds the report in isolation, and requires page-by-page extracted text and rendered pixels to agree. It checks that the original extraction is still byte-identical afterward. An optional `--output-dir` preserves logs and a machine-readable receipt outside the sealed bundle.

The expected new-source saving is ten physical lines in one local proof fragment, not a post-adoption aggregate. All earlier outcomes and new incoming ideas have zero new credit. A signature match or bounded recurrence check cannot establish elaboration, axiom equality, proof-term size or performance.
