The last commit provides two distinct sides: \code{row_step} extracts the actual step of an encoded configuration, while \code{stepTile} constructs a row from it. Their overlap supports the narrow complete-tile proposal; it does not make a generic simulation framework new. See \src{WangTiles942RowStep}{164}{203} and \src{WangTiles942StepConstruction}{22}{44}.

\textbf{The later maintained source goes further.} Commit \commit{512e0f6a3} adds the actual marked-word halting theorem, using existing row evolution and the origin-color contradiction, and \code{CurrentSoundness2011} proves positive polynomial zero $\Rightarrow$ actual blank halt $\Rightarrow$ syntactic ZFC refutation. Hence ConZFC excludes positive zeros of the maintained polynomial and three thirteen-variable forms. See \latesrc{WangTiles942Soundness}{24}{68} and \latesrc{CurrentSoundness2011}{24}{70}.

Commit \commit{be45083ae} also closes the marked-language equivalence: existence of an actual marked word is equivalent to actual blank halting; absence of marked words is equivalent to ConZFC. The cofinal construction admits independently large width and height. These are maintained external Lean statements, not new proposals here; see \latesrc{WangTiles942Completeness}{28}{79}. The actual polynomial converse and internal-ZFC formalization are still separate obligations.
