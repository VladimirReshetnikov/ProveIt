\subsection{Replay in a complete pinned checkout}

Use the repository's \code{leanprover/lean4:v4.32.0} and locked Mathlib revision \href{https://github.com/leanprover-community/mathlib4/commit/81a5d257c8e410db227a6665ed08f64fea08e997}{\texttt{81a5d257c8e4}}. The archive is not a standalone build environment. First obtain a \emph{complete} checkout with its submodules and dependencies; do not infer build readiness from this source snapshot.

\begin{enumerate}
\item Re-run the snapshot and corpus verification scripts. Inspect each patch against the pin and apply it only in a throwaway worktree. Keep R2 independent from the five local replacements so its API cost is visible.
\item Compile the isolated candidate modules. Confirm they prove their own statements rather than calling the original target theorem. Run every supplied regression statement, especially target 215 versus invalid 216, old/new write positions, time zero, and both movement directions.
\item Rebuild changed source modules and paired Checks modules. For E1 and M1, rebuild the action, step, and row-construction consumers; for R1 rebuild reset and strip clients; for R2 rebuild all users of west/east projection theorems and row construction.
\item Compare \code{#print axioms} for old and proposed declarations and relevant public endpoints. A shorter tactic proof may introduce standard axioms even when the old proof did not. Do not treat their absence from source text as an axiom audit.
\item Measure elaboration and memory only after successful checking, using comparable clean/cached conditions. Keep the less fragile proof if the shorter one imposes substantial import or simplifier cost.
\end{enumerate}
