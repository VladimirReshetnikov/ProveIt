\section*{1 The useful new changes}
\textbf{The new code offers three small proof refactors and one narrowly scoped coherence API.} The best immediate pilot is to specialize the existing binary-prefix theorem directly in the two South-word clients. Next, reuse the existing aligned translation as a reachability witness and specialize the existing general propagation theorem. Finally, package the new boundary-color classifiers as two exact fibers, so eight color corollaries no longer repeat family elimination.

The core proposal changes \textbf{three existing modules}, preserves all existing theorem statements, and adds only the two boundary-fiber helpers. Its complete-module physical line count falls from \textbf{534 to 462}, a net reduction of \textbf{72 lines}. Selected proof bodies fall from \textbf{138 to 52 nonblank lines}, including the new helpers' 22 proof lines. These are static source measurements, \textbf{not Lean compilation or performance results}.

\pageheading{4 Use the existing binary prefix theorem directly}
\textbf{Delete the function-equality detour in the two new South-word clients.} The general theorem \code{binaryWord_prefix} is already present at \src{CurrentSouthShift2011}{32}{51}. Each client currently introduces a function \code{f}, a translated-word equality, a separate equality of functions proved by \code{funext}, and then an intermediate identity that is reformatted into the goal. Only the address association is nontrivial.

Let \(W_n(f)=\sum_{j<n}2^j f(j)\). The existing result says
\[
 W_{k+n}(f)=\bigl(2^kW_{k+n}(j\mapsto f(k+j))\bmod 2^{k+n}\bigr)+W_k(f).
\]
Only the retained suffix needs its Boolean bound. In the two clients \((k,n)=(1,8)\) and \((2,7)\). The translated addresses reduce to the same South block because
\(941+(1+j)=942+j\) and \(940+(2+j)=942+j\). A restricted simplification set can make those rewrites inside the lambda.

\textbf{Candidate for \code{offset19_word}.} The statement at \src{CurrentSouthShift2011}{92}{113} is unchanged; replace its 14 nonblank body lines by:
\begin{lstlisting}
  have hp := binaryWord_prefix
    (fun j => c (((theta t b : Cell N) : ZMod (N * 2011)) +
      ((941+j : ℕ) : ZMod (N * 2011)))) 1 8 (fun _ _ => hc _)
  rw [copy_word_translation c t 941 b (by omega) hcopy]
  simpa only [southWord, ← Nat.add_assoc, binaryWord_one, Nat.add_zero] using hp
\end{lstlisting}
\textbf{Candidate for \code{offset20_word}.} The statement at \src{CurrentSouthShift2011}{116}{140} is unchanged; replace its 16 body lines by:
\begin{lstlisting}
  have hp := binaryWord_prefix
    (fun j => c (((theta t b : Cell N) : ZMod (N * 2011)) +
      ((940+j : ℕ) : ZMod (N * 2011)))) 2 7 (fun _ _ => hc _)
  rw [copy_word_translation c t 940 b (by omega) hcopy]
  simpa only [southWord, ← Nat.add_assoc, binaryWord_two, Nat.add_zero] using hp
\end{lstlisting}
The one- and two-bit prefix lemmas are already private declarations earlier in this module, so these are in-place replacements, not an import-only proof that accidentally relies on inaccessible names. No global simp rule is added.

\textbf{Keep the exact correction.} Offset 20 concludes a weighted low prefix, \(c(940)+2c(941)\), not an unweighted error estimate. Its separate bound by 2 uses the one-hot selector count; without it, prefix 11 has weight 3. Both patches retain all nine copy equalities, arbitrary natural shift \code{t}, its residue hypothesis, the global Boolean bound and the physical source \code{theta t b}. They introduce neither occupation nor decoded tile labels.

\textbf{Evidence and limit.} Independent enumeration checks all 1,024 one-bit-prefix/9-bit-word cases and all 2,048 two-bit-prefix cases. This confirms the finite arithmetic identity, not Lean's simplifier or elaborator. The compile gate must confirm the two \code{simpa only} calls without broadening their rewrite set unnecessarily.

\pageheading{5 Reuse the exact cycle witness and propagation theorem}
\textbf{The new reachability proof rebuilds closure already packaged by \code{theta}.} At \src{CurrentCellCycle2011}{97}{109}, the original proof forms \(b-a\) in \(\mathrm{ZMod}(2011N)\), proves its representative is aligned using \code{subtraction_residue}, and then turns it into a \code{Cell N}. But translation by the aligned representative of \(a\) already returns precisely that cell.

For an aligned cell \(a\), its representative satisfies \(a.\mathrm{val}\bmod2011=0\), so \(\mathrm{wholeShift}(a.\mathrm{val})=a.\mathrm{val}\). Therefore the underlying value of \(d=\mathrm{theta}(a.\mathrm{val})(b)\) is \(b-a\). The existing quotient index supplies \(\mathrm{index}(d)<N\); the existing iterate formula gives
\[
 \mathrm{next}^{\mathrm{index}(d)}(a)=a+2011\,\mathrm{index}(d)=a+d=b.
\]
All equalities are in the full physical cyclic word, not merely equalities of residues modulo 2011. Replace the 11-line body by:
\begin{lstlisting}
  let d := theta (a : ZMod (N * 2011)).val b
  refine ⟨index d, index_lt d, ?_⟩
  apply Subtype.ext
  rw [coe_iterate_next, cast_index_mul, coe_theta]
  simp only [wholeShift, a.property, Nat.sub_zero, ZMod.natCast_zmod_val]
  abel
\end{lstlisting}
The new source already supplies \code{index_lt}, \code{cast_index_mul} and \code{coe_iterate_next}; see \src{CurrentCellCycle2011}{50}{78}. The candidate adds no theorem or new coordinate abstraction. Its one elaboration-sensitive point is reducible unfolding of local \code{d} when rewriting \code{coe_theta}.

\textbf{Preserve the degenerate case.} The hypothesis remains \code{[NeZero (N * 2011)]}; the theorem still includes \(N=1\). There is no assumption that 2011 is invertible modulo \(N\), nor a replacement of the physical modulus by a coprime quotient. Independent arithmetic checks cover all 11,440 ordered aligned-cell pairs for \(1\le N\le32\), including singleton and wraparound cases. They are sanity checks, not a proof for arbitrary \(N\).

\textbf{Make the zero-base theorem a specialization.} The adjacent theorem \code{propagate} repeats an iterate induction that already occurs in \code{propagate_from}. Move the former, with its unchanged statement, below the latter and replace its eight-line body with:
\begin{lstlisting}
  exact propagate_from P 0 hzero hnext
\end{lstlisting}
The existing general theorem does not use \code{propagate}, so the reorder creates no cycle; compare \src{CurrentCellCycle2011}{113}{135}. The predicate remains arbitrary and no occupation premise is introduced.

\textbf{Novelty is limited to these clients.} Prior reports already recommended reusing translation and iteration interfaces. The new value here is the exact witness and existing specialization at newly committed declarations, not another modular-arithmetic library or scanner framework. Together, the cycle changes remove 12 body lines without adding helpers.

The eight exact-color corollaries then repeatedly eliminate those same alternatives and discard the impossible colors. The proposal adds an equality-indexed fiber theorem on each side and makes the corollaries specializations.

    t.north = c ↔
      (c = 435 ∧ t = start) ∨
      (c = 434 ∧ t = ⟨2,434,2,0⟩) ∨

\pageheading{8 Characterize the assignment by the original selectors}
\textbf{Expose when an independently extracted index function equals the existing assignment.} The marked-word code chooses an index from the occupation witness at each canonical inverse coordinate. Its \code{assignment_selected} theorem retains the full selection predicate, not merely a tile color; see \src{CurrentMarkedWindow2011}{37}{46}.

The selection predicate says \(f(i)=1\) and \(f(j)=0\) for every \(j\ne i\). Its existing \code{Selected.unique} theorem already identifies any other index with value one: \src{CurrentCellLabels2011}{128}{129} and \src{CurrentCellLabels2011}{169}{174}. The new API should use that theorem, not re-prove uniqueness or assume injectivity of the tile table.

\textbf{Add an exact assignment characterization.} For the same word \code{c}, occupation proof \code{ho} and independently supplied function \code{a}, the proposed statement and body are:
\begin{lstlisting}
theorem assignment_eq_iff_selector (c : ZMod (N * 2011) → ℕ)
    (ho : ∀ b : Cell N, Occupied c b) (a : ZMod N → Fin 942) :
    a = assignment c ho ↔
      ∀ j, selectorValue c
        ((coordinate.symm j : Cell N) : ZMod (N * 2011)) (a j) = 1 := by
  constructor
  · rintro rfl j
    exact (assignment_selected c ho j).1
  · intro ha
    funext j
    exact (assignment_selected c ho j).unique _ (ha j)
\end{lstlisting}
The reverse implication does not ask the alternate decoder to provide all the other-zero clauses again. Those clauses already belong to the known selected assignment. Its single selected-bit equation suffices to identify the same index pointwise.

\textbf{Reuse the existing marked-word proof by equality transport.} The companion theorem \code{facts_marked_word_of_selector} takes the original \code{Facts v N x c carry digits}, an alternate \code{a}, and its selector equations, and concludes \code{MarkedWord N (stride v N : Int) a}. Its proof is:
\begin{lstlisting}
  rw [(assignment_eq_iff_selector c
    (facts_occupied v x c carry digits h) a).mpr ha]
  exact facts_marked_word v x c carry digits h
\end{lstlisting}
The existing orientation proof at \src{CurrentMarkedWindow2011}{97}{117} remains essential. It is not replaced by these two lines: the new theorem makes that proof reusable for another extraction implementation.

\textbf{Cost and adoption threshold.} This is an additive API, not a current line reduction. The two actual declaration blocks add 17 lines, including eight proof-body lines. The standalone candidate module has 47 physical lines with imports, context and comments. Adopt when a second decoder or consumer needs this contract; otherwise retain it as a prototype. Do not subtract its two-line client from the existing 18-line correctness proof.

The result is stronger than independence of two occupation proofs, which is already proof irrelevance, but weaker than an unrestricted uniqueness theorem about tilings. It preserves the same \code{c}, the same inverse coordinate, actual selected indices and the original unreduced stride. It assumes neither color injectivity, coprimality nor a globally unique Start. Generic coherence includes \(N=1\); the separate Facts-specific nonzero-stride conclusion is not erased or used as a hidden premise.

These checks are supplied as specifications and have not been executed here.
\item Inspect axiom output and then build the aggregate \code{DiophantineConsistency} target. Preserve statements, numerical constants, exact source bindings and downstream interfaces. Do not resolve an elaboration problem by adding an assumption, changing an index map or inserting \code{sorry}.
\item Record actual time and memory only after a like-for-like fresh run. Source-line counts alone cannot support a claim about proof-term size, heartbeat use or checking speed.
\end{enumerate}

\textbf{Stop if the current client does not pay for an abstraction.} Existing periodic-plane wrappers and coordinate proofs are already short. No new additive quotient framework, global simplifier or generic finite dispatcher is warranted by these concrete changes. The optional coherence theorem has a clear semantic contract but is explicitly outside the 72-line saving.
