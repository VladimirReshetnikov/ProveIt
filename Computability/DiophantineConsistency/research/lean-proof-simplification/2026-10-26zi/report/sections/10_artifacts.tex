\subsection{Reproduce the non Lean checks}

\begin{Lean}
python provenance/verify_snapshot.py
python validation/source_validate.py
python helical/validation/test_candidates.py
python bridges/validate_static.py
bash report/build.sh
\end{Lean}
The Python commands check evidence or candidates without Lean. The last command needs XeLaTeX and rebuilds only the PDF. Read each component README before rerunning candidate generators; their inputs are the pinned snapshot, not a moving branch.
