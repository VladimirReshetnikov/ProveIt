## Evidence discipline

All recursive packet trees returned `truncated: false`. Sources were read through the connected GitHub API and matched by Git blob SHA-1 (`blob <size>\0` plus bytes), byte count and SHA-256. Old inspection reuse follows hash equality, not filenames. Candidate/prototype Lean files were read as text; no supplied script or Lean proof was run. Historical compilation logs are not fresh evidence.

The full-root recursive request initially returned a transport error; bounded subtree reads then succeeded. No permission denial, pending escalation, or access blocker remains. Raw archives, PDFs, full source snapshots, download responses and receipt bulk are excluded from the delivery whitelist.
