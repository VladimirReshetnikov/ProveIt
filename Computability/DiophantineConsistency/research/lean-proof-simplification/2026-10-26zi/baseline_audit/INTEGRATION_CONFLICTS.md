# Compatible-outcome reconciliation

The assumption is not a claim that conflicting patch files have been applied simultaneously.

- **Pell upper estimates (P01/R02/S02/U01):** retain common bounds and exact ordinary/native adapters. The Nat perturbation implementation and positive-real scale implementation are alternative proofs. No duplicated savings or vanished factor two.
- **Pell minimality (M02/T04):** grant a usable small-ordinate/minimum-y-square criterion and the existing fundamental-unit theorem. If its entire bespoke proof was removed by M02, do not count a shorter abs-value proof of that deleted body again.
- **Signed divisibility (L03/M04/V16):** local closure-law proof and SignedModEq composition grant the same sign-preserving endpoint. No simultaneous four-branch rewrite required.
- **Norm nonvanishing (L05/M01):** integer cancellation and exact rational descent coexist as valid facts; do not pretend both replace the same proof twice.
- **Internal zero cases (L01/Q01):** prefer one coherent low-level NaturalCases placement. Heavy InternalSat imports are an alternative, not extra simplification.
- **Observed closure (Q05/S04):** full carrier inclusion and pair-only inclusion are compatible interfaces with explicit adapters. Insertion needs justified new step and (for arbitrary observations) encoding injectivity; arbitrary upward closure is false.
- **First failure (T05/U04):** both prefix and guarded predecessor outcomes are available, with explicit lower endpoint. Decidable and classical implementations retain their different axiom footprints.
- **Integer intervals (U03/R3-05):** the guarded translated Int.induction_on outcome is available. The shorter Int.inductionOn variant is an optional alternative with its advertised Classical.choice cost.
- **Spatial rows (U05/R3-06):** give one coherent pulse/edge view plus actual equality, allowedness, liveCfg and compatibility adapters. Do not count implementing previously missing adapters as new. No temporal-cycle or helical-band theorem follows for free.
- **List codec (T01/T02):** pointwise identity preserves literal code data; optional library length proof has a different axiom dependency. No claim of definitional equality or erased dependency cost.
- **Lowering and relocation:** all advertised common layers preserve old names and imports without assuming a nonexistent import cycle; relocation is not an independently new proof.

Actual committed adoption remains a separate read-only source question. `provenance/RECENT_COMMITS.md` and its source-file delta are authoritative; the repository adoption record contains historical queued statuses and is not a fabricated current build receipt. This audit runs no Lean and makes no new axiom/performance claim.
