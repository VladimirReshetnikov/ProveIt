# Weighted main-root congruence

`ArithmeticAdaptiveMainCongruence2011` derives an additive congruence from the
actual adaptive zero in every model of `IΣ₁`. Using the rank `R` from
[the rank-window note](adaptive-rank-window2011.md), let `E = XY`,
`k = η+ζ`, `c = η+Yk`, `a = E+Y`, and `H = 3+4a`. The theorem produces
positive internal `s` and `main`, with `Y = q³s`, and proves

```
H(Eq + R + 1) + q⁵·s(X + ac + Hγ) = Hk + q⁵·s·main.
```

This exact additive identity is the signed statement that `q⁵` divides
`H(Eq+R+1−k)`. It is derived by combining the literal signed main-root
representation with the previously proved positive orientation and the
actual first-carrier quotient for Y. The two syntactic forms of the rank
are equated using the proved identity `q−1 = v₀β`.

The equality does not cancel H. In particular arbitrary internal q can have
common factors with the constant term 3 of H. A separate factor-three
argument is needed to lose at most one q factor and conclude the signed
`q⁴` divisibility of `k−R−1`, since `q⁴ | Eq`. No index relation, power
representation, or coprimality is assumed.
