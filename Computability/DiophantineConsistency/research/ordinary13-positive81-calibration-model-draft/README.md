# Conditional positive-81 power calibration

These sources are **unelaborated drafts**. They do not prove a graph endpoint,
`X≥q²`, an all-model carrier transfer or an iPRA/ZFC equivalence without the
explicit assumptions below and checked providers.

The 81 client uses only the proposed one-way 81→80→89→85 graph-zero path;
it does **not** invoke the unresolved 83→81 transport. On that exact prototype
valuation, `EtaNaturalGraphEarlyIndexDraft.compact_early_index` proposes a
single first root tau, index n and quotient w, including the actual first
ordinate, `k=2n+4XY²w`, and `2n mod q⁴=R+1`. That congruence alone is not
an exact paired index.

`ExactIndexCut` explicitly requires the upgrade `2n=R+1` for the same n and w.
The separate fact-level `Positive81ExactIndexCut.exact_pair` records the
precise `P72Exact.indices_ordinary` interface that could establish this
upgrade: positive eta and other coordinates, R≥26 and R+1<mu, the main Pell
index and main norm, the graph's strong norm, and the *exact* absdiff
auxiliary equation. These graph bindings and their common witnesses are not
inferred or implemented by the wrapper.

`OrientedMainCut` separately requires one same main root satisfying its
x/y Pell coordinates at **R** and the actual no-`E*q` oriented carrier
balance. With these cuts, compact beta and prototype positivity, the source
proposes to apply the existing no-extra-term `EtaZeroGrowthDraft.power` to
obtain `X=2^R`. The quotient w is the one returned by early-index extraction;
the graph w input is kept distinct. No residue-adjusted `E*q` carrier lemma
or original free-J zero wrapper is silently used.

The proposed `rank_qsquare` uses only `q≥2`, `F<q`, and the shifted
`alpha≥1`: both `q−1` and `q−F` are at least 1, so the first rank coefficient
is at least 2, and `q²≤2*(q²−1)≤R`. `prototype_rank_qsquare` obtains q≥2
and F<q from the compact beta/J and positive-C graph drafts. Thus
`prototype_power_and_qsquare` and `calibration81` propose `q²≤X` from that
rank bound, `X=2^R`, and the model exponential inequality `R<2^R`. This is
unelaborated, and the bound is not claimed to follow from the rank window
alone. The 81 wrapper still exposes the exact-index and oriented-main cuts. Its
`original81_coordinates` lemma proposes the explicit identification with
the original positive-81 J and w values, so the conclusion is about that
graph’s actual `X=(1+J*beta)*w`, not an unrelated prototype quantity.
