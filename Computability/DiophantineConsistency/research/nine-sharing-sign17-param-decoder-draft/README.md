# Source-only parametric decimal action decoder

This uncompiled client proposes a genuinely parameterized version of the displayed action decoder and proves that specializing its input to the existing in-Lean seed gives the existing `DecimalMachine215.action`. It does not yet bind the 12 decimal lines to this parameter, prove any cached tile/rank or K theorem, or interpret PDF/file bytes. A fresh guard, independent prelaunch and allocation are required.
