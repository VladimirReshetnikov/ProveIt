# Literal 74 own-zero guard unit — source draft

This source-only composition supplies the literal 74 graph's three proposed
mod-four exclusions to its own-zero signed-product extraction. With explicit
positive beta and J/w/s slots and the beta port cast, it obtains the literal
guard factor as the positive signed unit, then converts that pair equality to
value one in the model difference ring. No guard sign condition is assumed.

The imported graph, own-zero, residue and first-factor sources and this client
are unelaborated. This does not yet prove the guard coordinate is greater than
one, the 74↔75 map, provider compatibility, an iPRA endpoint, or byte/PDF
binding. No Lean run is claimed.
