# RAW squared-radius source prototype

This research packet materializes a new arithmetic RAW parent and twelve
complete monic projections. It changes only the original radius row75 to
`raw89=raw87²` and the existing factorial guard from `raw87-2>=0` to
`raw87-raw86>=0`. All other original rows, variables and71 guard records
remain literal copies of the frozen72-predicate RAW parent. The private
row74 `raw88=raw86²` remains present. Factorial1 keeps its radius `g*t²`.

These are literal arithmetic prototypes. **No equivalence with the old
source or a syntactic refutation is asserted by this packet.** Full new
compiler/radix soundness and fresh canonical completeness require the
separate ordinary review in `research/factorial-square-guard-exchange`.
The old source calibration does not apply to changed row75 merely because
the new polynomial is smaller. No compact bridge is assumed or supplied.
No measured result here is promoted to the accepted consistency frontier.

`source/raw_builder.json` retains the entire1259-coordinate/1177-row raw
data, changing only row75's operands. Its historical metadata stays byte
for byte equivalent as JSON data. `RADIUS_POLICY.json` explicitly states
the current radius laws and guard exchange; inherited header labels are
retained as provenance and supply no calibration license. `CUTS.json`
maps every original raw/body/guard row and records both changed rows in
the full1475-coordinate/1249-row quadratic parent.

`raw/parent.json` and `raw/domain.json` contain all72 predicates: the same
69 scalar guards, V>=1, the paired-slack product, and the exchanged f>=K
predicate using the same final three auxiliary coordinates. Every projected
configuration includes its whole equation, signed integer restoration
certificate and complete expanded quartic. `CENSUS.json` records measured
properties of these prototypes, with ordinary-source status false.
`MEASURED_COMPARISON.json` records independently checked literal differences
against the same frozen72 RAW settings; it asserts no semantic improvement.

The producer uses the pinned reviewed monic terminal optimizer. The separate
checker imports only its independent projection verifier and polynomial
dependencies, plus an independently reviewed complete squared-residual
expander. It checks every changed and retained record, all monic inverse
steps over unrestricted integers, every quartic coefficient, all census
fields, arbitrary signed restoration fixtures, and deliberate corruptions.
It imports no optimizer, old source checker or compiler calibration.
