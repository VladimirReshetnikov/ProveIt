# 86→87 residue-guard ring-field identity — source draft

This unelaborated source proposal maps the 86 guard coordinate h to
`omega=h+C*K`, with signed-ring `C=q−F−alpha` and `q=1+J*beta`. It proposes
equality of all five residuals and the full 87/86 outputs over an arbitrary
commutative ring. In particular `C*(X+K*q)−F−(q−1)*(h+C*K)` is exactly the
86 guard. This alone is not a natural positive witness map: natural
subtraction casts require the guard gap; reverse positivity requires additional
calibration.

The checker pins both candidates, checks their exact row delta, replays source
generators and tests 300 signed finite valuations without Lean. Provider
ancestry, arbitrary-model elaboration, iPRA endpoint and physical-file/PDF
semantics are separate.
