fresh cofinal converse and both positive P66 witness maps for a new
four-integer tuple. The front retains fifteen positive variables,

The kernel now copies only selector 0, the calibrated Start selector,
with the single monomial `rho^1048`. The previous 943-term selector-count
block is gone. The zero-weight physical marker at 1048 tracks the Start
indicator in the temporal successor, not occupancy: canonical words use
`a_j=x_(0,j+width)` modulo N. For a one-Start word there is exactly one
marker. Safe dummy subsets preserve that pattern.

Alignment uses three already present parity tests. In the forced Start
cell, south bits 1 and 8 give ones at 974 and 981, and the copied Start
selector gives one at 1048. Fractional shifts cannot satisfy the two
south parity tests. For any remaining nonzero field offset, the marker
test forces an offset at least 39; the first south test bounds it by 974.
The two south preimages would then be distinct selectors in the same
cell, contradicting the clean clauses' already proved selector count
at most one. No unique-support-difference premise is used.

coefficients and the same label/dummy layout as zero-weight6007. The

last product field is 4156. All 875 padding tests occupy 18 full zero
