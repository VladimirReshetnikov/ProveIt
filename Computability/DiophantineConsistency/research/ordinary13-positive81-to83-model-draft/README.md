# Positive 81↔83 carrier: conditional model transport

These are **unelaborated source-only drafts**, not an all-model proof,
positive-zero equivalence or iPRA endpoint. The exact positive 83 graph is
generated from its pinned JSON; the exact positive 81 graph is the separately
generated four-square literal.

The graphs differ only in the first carrier. The proposed source first
establishes that the three non-first residuals are unchanged when only the
first-root coordinate r=8 changes. It then proposes `zero81_to83` and
`zero83_to81`: if a positive replacement r makes the **target graph's exact
first residual** zero, the source sum-of-squares zero gives the other three
residuals, so the target graph is zero. This reduces the two zero directions
to `CrossRootCut K`, an explicit all-IΣ₁-model assumption providing a positive
target r in **each** direction. The corresponding `SameNoZero` and bridge
client also retain an explicit `PolynomialBridge` for the exact positiveShift
83 parent. The proposed native 85 client inherits both hypotheses.

`CarrierWitnessFacts.positive_target_root` is a separate fact-level proposal:
if the *target* carrier P is a positive natural `P=b*t` with `t>0` and
`tau>ell`, then the natural witness
`r=k*(P−1)+t+(tau−ell)>0` has target signed root `+b*tau`. The source norm,
exact graph field binding, positivity/divisibility of the target carrier and
same-model tau are **not** supplied by that lemma. An explicit prerequisite
for the hard 81→83 direction is the sufficient `X≥q²` bound (or a different
proved positive-companion construction), as documented in the independent
`ordinary13-positive81-to83-model-gap-audit`. The scalar control there shows
that first-carrier positivity and rank window alone do not supply that bound.
The converse needs its own target-carrier positivity/divisibility proof; the
source does not infer it from a signed shift without positivity.

`prototype_zero_of81` exposes the useful one-way actual graph path: an 81
positive zero maps to an 80 zero, then lowers ten coordinates to the 89 graph
and uses the forward J/gamma/w/eta shifts into the actual 85 prototype. This
path does not invoke inverse eta forcing or the 89 r replacement. Existing
prototype early-index facts are a congruence, not yet the exact paired-index
and power calibration `X=2^R` needed for `X≥q²`.
