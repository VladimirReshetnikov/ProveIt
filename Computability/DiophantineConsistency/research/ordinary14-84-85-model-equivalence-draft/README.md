# Proposed positive 84↔85 model-zero equivalence

This unelaborated source wrapper composes the proposed 84→85 and 85→84
positive witness maps. It explicitly retains positive beta, `beta≥46`,
`beta=Exp.exp t−1`, `t≥4`, four natural port casts and mask inequalities.
Each direction starts from its own graph's all-positive zero; neither assumes
the other zero or pre-assumes q∣X.

This is **not an elaborated Lean theorem**. Both directions and the many
transitive model, arithmetic and graph sources require guarded Lean checking
and compatible provider ancestry. Symbolic compact-port instantiation, the
connection to the existing iPRA endpoint, and external file/PDF semantics
remain separate. The checker inventories the two map interfaces and replays
their source/finite-control receipts, without invoking Lean.
