# Ordered-ring lower-endpoint certificate

This source formalizes the lower part of the [ordinary-integer obstruction](../trace74-first-index-three-obstruction/README.md). In a linearly ordered commutative ring, with `X≥0`, `Y≥1`, `W≥0` and `2Y+W=X²+4X+4`, the displayed polynomial slack identity gives `k(Y+1)<c`. The [independent source review](../../reviews/trace74-first-three-lower-ordered-source-independent/README.md) and [guarded check with result audit](../trace74-first-three-lower-ordered-rebuild/README.md) passed. It does not bind `k,c` to Pell ordinates or a graph zero.
