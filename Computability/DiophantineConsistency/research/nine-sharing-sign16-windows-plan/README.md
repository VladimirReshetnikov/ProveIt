# Sign16 window assembly: remaining model obligations

The independently audited transport, first norm, main norm and auxiliary norm clients give four premises of `Sign33Windows.windows_from_maintained_norms` from the sign16 seed under represented ports and explicit beta/MC/MF bounds. A strict norm client is proposed and awaits Lean checking and audit. Each client has its own point-in-time provider qualifications; this note does not combine them into a theorem.

The remaining assembly must instantiate `J,F,alpha,z,f,i,T,s,w,N,eta,zeta,y,gamma` with the corresponding sign16 coordinates plus one. It must check the defining expressions: `q = A`, `Y = Sign16SharedValues.Y`, `E = Sign16SharedValues.E`, `c = Sign16SharedValues.C`, `R = Sign16RankValue.Rank`, and `d = Root + 1`. The existing first norm uses natural truncated subtraction and the retained tau witness. The existing main and proposed strict norm use the polynomial `(E+Y+1)*(E+Y+3)`, definitionally the window theorem's `delta (E+Y)`.

A further equality must be derived from the main norm before transporting the auxiliary norm: `Scale = (v6+1) * ((E+Y+1)*(E+Y+3)) * C * C`. This is an equality of natural expressions and follows by ring rearrangement from the main norm, but the separate theorem and its guarded check remain outstanding. Positivity of shifted coordinates is routine but must be proved in Lean. After checking all five premises, the window theorem would provide `2*R<C`; a separate inner-sign theorem and natural representative still must follow. This would not by itself prove a sign16 equivalence or an iPRA endpoint.
