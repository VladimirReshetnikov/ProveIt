# Sign20 symbolic count diagnostic draft

A single source-only diagnostic proposes using `beq_iff_eq` with explicit
`List.count_cons` to turn boolean AST comparisons into propositional equality.
Its provider is the exact five successful children of an audited failed
parent; the parent did not complete and its sixth child contains sorryAx.
The diagnostic cannot itself establish the full coefficient, lower bound,
exact degree or external binding.
