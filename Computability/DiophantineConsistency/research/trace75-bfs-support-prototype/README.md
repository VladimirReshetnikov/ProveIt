direct-BFS carry theorem with the separately rechecked fixed-slots theorem.

trace75 zero, it obtains one common repunit length and both the
indexed carry input and the low-mask support/Boolean properties. It uses
injectivity of the radix power to identify independently obtained lengths.

file-binding theorem.
