# Exact first and main Pell indices

An actual zero of the current adaptive 13-variable natural expression now
constructs, in every selected `IΣ₁` model, its first and main Pell indices
`n` and `m` with

```
13 ≤ n < m,     m = R,     2n = R+1,
k = R+1+4Q·t for some internal t.
```

Here `R` is the literal rank, `Q = XY²`, and `k = η+ζ`. The theorem retains
the actual scaled first-root magnitude, the oriented main signed root, and
both pairs of recurrence coordinates. The generic client uses the actual
zero, positive inputs and fixed port bounds; the current natural client
discharges these premises from the single positive shift.

The argument uses the previously derived index comparison, rank window,
strong norm and signed auxiliary norm. It derives the auxiliary sign modulo
`c` through the internal relaxed Pell classification and divisibility of
ordinates, rather than cancelling the discriminant or assuming coprimality.
The auxiliary ordinate's positive magnitude is derived from its norm and
`c²i ≥ 2`. The generic half-index theorem then identifies `m=R`. The rank
residue, window and `n<m` force `2n=R+1`, and the first recurrence supplies
the displayed quotient.

This is an all-model semantic result, not by itself a formal HA proof-existence
theorem. It does not yet recover the required power representation, interpret
the remaining polynomial, establish the reverse construction, or prove the
full equivalence. The quotient `t` is not claimed positive in this theorem.
