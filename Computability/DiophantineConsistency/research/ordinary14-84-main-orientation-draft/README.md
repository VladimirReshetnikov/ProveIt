# Conditional 84 main-root orientation — source-only draft

`MainOrientation.lean` proposes to select the positive sign of the scaled
main root obtained from the **84 graph's own zero**. In addition to the beta
cast and positive slot 7 it explicitly assumes `Y≥8`, `k>0`, and a natural
representation `rank=ι R` of the signed rank. The proposed proof applies the
previous modified-main-parts inequality to show the signed main value is
positive, then rules out the negative branch of the signed-root draft.

The rank representation and the size bounds are **not derived here** from the
graph zero; extracting them from the guard and the actual compact ports is
remaining work. Pell index classification and the subtraction-free natural
carrier balance also remain separate. This is an unelaborated source proposal
with draft dependencies, not a checked model theorem, compatible provider
chain, iPRA endpoint or file/PDF binding.

The checker inventories source assumptions, replays dependency receipts and
checks 300 finite natural examples of the explicit inequality. It does not
invoke Lean or prove the arbitrary-model theorem.
