# Uncompiled 2011 parent-zero caller drafts

These sources are **uncompiled drafts**, retained to make the next proof
steps concrete. They are outside the Lean project and do not provide a
verified theorem, proof of an actual-zero implication, or iPRA endpoint.
Their attempted use of the current 2011 tuple must not be confused with a
calibration of the distinct phase-split2471 tuple.

[`Model69CurrentOuter.lean`](Model69CurrentOuter.lean) attempts to derive,
from the exact maintained 2011 14-coordinate positive zero, a positive gap,
a positive transport divisible by `beta*J`, and the main Pell ordinate
identity. It is intended to combine `current_equations`, `current_power`,
`current_population_lower`, `population_le`, `maintained_first_indices`,
and the independently reviewed conditional scalar outer theorem. Every
unification, cast, let-binding, positivity and dependency condition still
needs Lean checking. In particular the output equality to the corresponding
`Carrier65.core` transport in the model's difference ring needs a later
explicit proof.

[`Model69CurrentPhase.lean`](Model69CurrentPhase.lean) attempts to derive
`rank%4=3` from that same actual positive zero. It uses the model window origin
as a modulus-47 digit, the repunit form of the first coordinate, the actual
low-mask residue and a four-block identity. Its scope includes no different
port tuple. Its imports need the complete coherent window/rank extension; the
initial 20-module prefix planned for the outer draft is insufficient.

The source snapshots and provider preparations are tracked separately in the
[source closure plan](../thirteen-model-parent-current-closure/README.md) and
[20-module prefix plan](../thirteen-model-parent-prefix/README.md). No draft
has been compiled by placing it in this directory; any later replay must pin
its exact source bytes, rebuild compatible project dependencies, record actual
process exits and retain failed attempts. These drafts must not be interpreted
as a proof that either theorem elaborates.
