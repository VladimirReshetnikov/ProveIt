# Sharing-aware quartic seed candidate for nine unknowns

This is an **external candidate**, not yet a Lean proof or a nine-variable iPRA endpoint. It starts with the separately checked current-port **14-variable, 67-operation, degree-94 graph**, not the original 65-operation maintained syntax. Its purpose is to feed the already checked general Jones theorem with a quartic seed that preserves shared gate values instead of compiling the original expression tree. The current tree-based Jones seed has an independently checked external count of 16,893,385 witnesses; this candidate uses **110 quartic witnesses plus the distinguished Jones input coordinate**.

`seed.json` is a concrete finite residual recipe. Coordinates 1–14 are naturals and represent the 67-graph's positive inputs after adding one. For each of the first 66 graph gates, the recipe allocates one natural witness when it is syntactically known nonnegative and otherwise allocates two naturals representing the positive and negative parts. A gate is marked known nonnegative only if it is addition or multiplication of two already known nonnegative operands; inputs, small numerals and the four actual current fixed ports are nonnegative. There are 37 one-witness gates and 29 two-witness gates. The final graph operation is asserted directly as a zero residual, avoiding two output witnesses. Coordinate 110 is the guard witness, whose residual is `guard - 1`. This gives `14 + 37 + 2·29 + 1 = 110` witnesses, with 97 residuals: one guard, 95 gate constraints and one output constraint. Coordinate 0 is the distinguished Jones input and is unused in the residuals.

For a signed operand pair `(a⁺, a⁻)` representing `a⁺ − a⁻`, addition and subtraction take the obvious pairwise sums, and multiplication uses `(a⁺b⁺ + a⁻b⁻, a⁺b⁻ + a⁻b⁺)`. All right-hand sides used to construct witnesses contain only addition and multiplication of naturals. A one-witness gate instead uses the direct nonnegative addition or multiplication. Each residual has degree at most two in the 111 seed coordinates, treating the fixed ports as integer constants; the sum of their squares has degree at most four. At every distinguished input `x`, when all 110 witnesses are 0, the guard square is 1 and all other squares are nonnegative, so the sum is nonzero. The seed does not use coordinate 0, hence the stronger normalization uniformly in `x` holds as well as the input-1 instance used by the checked `nine_iff` theorem.

The forward/backward argument to formalize is finite. Given a positive zero of the 67 graph in an IΣ₁ model, write its coordinates as `u + 1`, recursively construct the natural signed pairs, and set the guard to one: every gate residual and the final residual vanish. Conversely, if the sum of squared residuals is zero in the model's ordered difference ring, each residual is zero; induction through the 66 gates shows each stored pair's difference equals the corresponding graph value. The last residual makes the graph output zero. The separately checked 67/94 all-model bridge can then transfer this existential equivalence to the maintained current equation. Finally, formalize the quartic degree and nonvanishing claims and instantiate `NineFreshJones.nine_iff`. None of those Lean proof steps has been carried out for this new seed.

`check.py` rehashes the source graph and the actual fixed-port gzip/raw bytes, independently reconstructs every gate's signed-pair polynomial identities over a free commutative ring, checks distinct coordinates, sign propagation, liveness, residual degrees and guard structure, and runs 12 deterministic small-value forward assignments. These finite checks support the candidate and the stated proof route; sampled assignments alone do not prove the model theorem. The external number 110 is a count of this seed's declared witnesses, not a Lean-verified count or an operation/degree claim about the resulting nine-variable Jones polynomial. No file, gzip, PDF or total-degree theorem is asserted in Lean.

Run `python3 -I -S -B check.py` from this directory. `build.py` deterministically emits the frozen `seed.json` and refuses to overwrite it.
