This source-only draft supplies the three fixed-mask inequalities of the conditional rank/saturation client using `CompactFixedBeta.bounds` at the same positive `J`. It retains the individual `F<q`, `C≤q`, radix and both population hypotheses. It does not derive them from a 74 graph zero or establish a guard theorem.
