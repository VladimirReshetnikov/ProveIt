`FoundationHAConsistencyNormalization.rho` is exactly Foundation's `provabilityPred 𝗭𝗙𝗖 ⊥`, and `source_eq_neg_rho` is definitional. In the external Foundation `Foundation/FirstOrder/Bootstrapping/Syntax/Proof/Basic.lean`, `provabilityPred` substitutes the code of `⊥` into `provable`; `provable` is `∃d, proof.sigma d ⌜⊥⌝`; `proof.sigma` contains `∃s, insertDef s ⌜⊥⌝ 0 ∧ derivationOf.sigma d s`; and `derivationOf.sigma` conjoins `fstIdxDef s d` with the Σ-side of the derivation fixpoint graph. These graph predicates are the actual Foundation encodings, not a substituted machine validator.

`rho_sigma_one` proves the literal formula has Foundation's `Hierarchy 𝚺 1`. That hierarchy allows bounded universal quantifiers over unbounded existential formulas, so it is not a declaration that the literal displayed syntax is already one existential prefix with a bounded matrix. `StrictSigmaOneInduction.bnd rho` is an explicit one-parameter formula bounding each formerly unbounded existential by the new last variable; `hierarchy_bnd rho_sigma_one` certifies that formula as `Hierarchy 𝚺 0`. Let `B(b)` denote this exact bounded formula and `C` denote `∃b, B(b)`, with the required binder/embedding conventions retained.

`PRAWitnessZFCRefutationBound.PRA_proves_refutation_bound` proves `rho → C` in the repository's candidate **classical** PRA calculus. Its proof explicitly uses `Theory.Proof.complete_on_eq_models` and a model-theoretic witness-bound chain; it is not an intuitionistic PRA derivation. Conversely, `StrictSigmaOneInduction.eval_bnd_imp` is a semantic bounded-erasure theorem, also not by itself a syntactic iPRA proof. The current `PRA` language and derivations use Foundation's classical `Semiformula`; the external `Foundation/FirstOrder/Intuitionistic/Deduction.lean` provides a separate `Propositionᵢ` / `Hilbertᵢ` / `HilbertProofᵢ` interface, where the intuitionistic axiom set contains EFQ and the classical extension additionally includes excluded middle. A candidate native theory `IPRANativeTheory.nativeTheory` has since been defined; its equivalence to a standard iPRA presentation and the language/axiom proof translation remain to be established.

The existing HA result `FoundationHAConsistencyNormalization.equivalence` establishes the desired normalization in its own HA calculus. It uses Foundation's genuinely intuitionistic `Derivation.neg_doubleNegation` to identify `(∼rho)ᴺ` with `¬(rhoᴺ)`, then `FoundationHASigmaOneGG.sigma_one_doubleNeg` to identify `rhoᴺ` with `¬¬rho` under its ordinary interpretation, followed by triple-negation stability. This does not directly supply an iPRA proof: `FoundationHADeltaZero.hierarchy_zero_decidable` calls `HABoundedQuantifiers.decisions_all`, which invokes HA formula induction, and the general Σ₁ comparison uses `HABoundedDoubleNegation.bounded_shift_all`, an HA induction on a formula containing arbitrary double negations.

A potentially smaller route for this **fixed** predicate is:

1. Define the exact iPRA theory in the intuitionistic Hilbert calculus, translate the language embedding and show that the Gödel–Gentzen image of each classical PRA axiom is iPRA-provable. The quantifier-free induction case requires explicit decidability/stability of quantifier-free formulas in the primitive-recursive language. Prove a Lean proof transformer, rather than using classical model completeness as an intuitionistic proof rule.
2. Apply that transformer to the existing classical PRA proof of `rho → C`, obtaining `rhoᴺ → Cᴺ`. The separate `IPRANativeForward` development now constructs the general `native φ → φᴺ` proof in the Foundation intuitionistic Hilbert calculus, and `IPRANativeForwardTheory` lifts it to arbitrary `Theoryᵢ`; its [guarded independent replay](../reviews/ipra-native-forward-independent.md) has passed. The native reader uses the stated NNF treatment of negated atoms and commutes with Foundation rewrites.
3. Give the fixed bounded matrix `B(b)` a primitive-recursive characteristic code and prove its bit and correctness properties **inside iPRA** using quantifier-free induction. `PRABoundedFormula.PRA_proves_boundedBooleanCharacteristic` and its code constructors provide a concrete starting point, but their present correctness proofs use classical completeness (for example in `PRABoundedCharacteristic` and `PRABoundedBoolean`); their proof objects are not iPRA certificates. Derive the required equivalence between `B(b)ᴺ` and native `B(b)`, or the weaker direction sufficient to turn `Cᴺ` into `¬¬C`.
4. The syntactic intuitionistic bounded erasure `C → rho` is now independently replayed for every closed arithmetic NNF formula in the arithmetic language ([structural proof](../reviews/ipra-bounded-erasure-independent.md), [outer existential](../reviews/ipra-bounded-exists-erasure-independent.md)). Its target-language mapped form has passed an author replay ([receipt](../reviews/ipra-bounded-mapped-erasure-author.md)); the independent replay and exact ZFC client have separate receipts. These arguments preserve the native NNF disjunction used for bounded universals and do not use `eval_bnd_imp` or decidability. With this erasure in the target theory, `rhoᴺ → Cᴺ → ¬¬C → ¬¬rho`, while `rho → rhoᴺ` gives the reverse implication needed after negation. Compose with Foundation's `Derivation.neg_doubleNegation` and `¬¬¬rho ↔ ¬rho`. No witness is extracted from `¬¬rho`, and an intuitionistic proof of the stronger native statement `rho → C` is not required by this route.

The logical outline above is a proposed proof plan. No standard-presentation equivalence for the candidate iPRA theory, bounded-decision certificate, classical-PRA-to-iPRA proof transformer, backward comparison `rhoᴺ → ¬¬native rho`, or final iPRA `GG(¬rho) ↔ ¬rho` theorem is claimed here. The conditional pure logic and arbitrary-theory steps have independently replayed, and the native-to-GG direction has independently replayed; see the linked receipts. The 85-operation semantic shift work separately uses classical IΣ₁-model semantics and does not discharge any of these syntactic obligations.

The exact ZFC mapped client has a guarded author replay: it discharges native erasure for the literal mapped `C` and retains only two explicit theory-proof premises, namely `rhoᴺ → Cᴺ` and `Cᴺ → ¬¬native C`. See [its author receipt](../reviews/ipra-zfc-mapped-erasure-author.md) once frozen; this does not establish either remaining premise or identify the native reader with the separate PAHF interpretation. All these narrow replays retain inherited Foundation, HA, ZF and package provenance boundaries.
