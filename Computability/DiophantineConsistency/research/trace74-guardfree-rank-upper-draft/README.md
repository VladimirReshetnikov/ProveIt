# Guard-free signed upper window for the 74 rank

This source draft proves the all-ring slack identity and proposes a bound in the model's ordered difference ring. All scalar inputs `q,beta,MC,MF,J,F,C` are elements of the nonnegative IΣ₁ model. With `q=beta*J+1`, `J,F,C>0`, `MC<beta` and `MF<2*beta`, every slack factor is nonnegative; the resulting inequality is `rank + ι(q³+q+1) ≤ ι(q⁴)`. A final client identifies the signed expression with the actual masked 74 rank for the same tuple.

The [independent source review](../../reviews/trace74-guardfree-rank-upper-source-independent/README.md) checked the mathematical assumptions, and the [guarded author check with independent result audit](../trace74-guardfree-rank-upper-rebuild/README.md) passed. Neither `F<q`, `C≤q`, their sum guard, nor a graph-zero premise is used. This upper bound by itself gives no lower rank bound, repunit or endpoint.
