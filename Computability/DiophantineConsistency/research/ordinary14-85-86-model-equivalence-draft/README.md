# Proposed positive 85↔86 model comparison — source draft

This unelaborated wrapper composes the direct 85→86 positive witness map and
the fresh-root 86→85 map under explicit positive beta and beta port cast.
The other integer ports are arbitrary. A second proposed statement specializes
to natural port tuples via `P72Root.cast_port`. Each direction starts from
its own graph's all-positive zero; reverse does not assume a sign or bound on
the old first root.

This is not a Lean-checked model equivalence: both directions and their many
transitive draft sources require guarded elaboration and compatible provider
ancestry. The iPRA endpoint and external file/PDF semantics remain separate.
The checker inventories the interfaces and replays both source/finite-control
receipts without invoking Lean.
