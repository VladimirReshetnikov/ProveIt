# Proposed compact symbolic-port 78↔86 model comparison

This unelaborated source wrapper composes the proposed 78↔85 compact-port
comparison with the proposed natural-port 85↔86 q-cubed comparison. Both use
the same symbolic tuple `[beta,K,low,beta+high]`, with arbitrary natural K;
existing symbolic port bounds supply the required positive beta. Each side
quantifies an all-positive fourteen-slot model valuation.

The wrapper and all imported graph/model clients require Lean elaboration and
compatible provider ancestry. It is not a checked model equivalence or iPRA
endpoint, and does not establish a physical-file, TeX or PDF correspondence.
The checker inventories the composition interfaces and replays both source
receipts; no Lean is invoked.
