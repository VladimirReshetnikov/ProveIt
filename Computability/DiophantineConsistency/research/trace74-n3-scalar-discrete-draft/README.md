# Discrete ordered-ring scalar obstruction draft

This source joins the checked generic lower and upper endpoint inequalities, then excludes them when `q≥32`, `X=q*w`, `Y=q³*s` in a discrete linearly ordered commutative ring. Discreteness is an explicit hypothesis. The [independent source review](../../reviews/trace74-n3-scalar-discrete-source-independent/README.md) checked the interval, signed factorization and contradiction. No graph, Pell or model instantiation is claimed until separately checked.
