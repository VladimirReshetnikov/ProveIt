# Sign25 pretyped full-assertion staging draft

The previous diagnostic compiled the generic endpoint, the pretyped no-zero
sentence and the heavy import-only module, then hit an interpreter memory
exception in a module containing a `#check` of the whole standard assertion.
This source-only strategy types the entire biconditional assertion and its
definitional equality before importing the heavy polynomial bridge. A generic
framework theorem accepts an arbitrary assertion equal to the ordinary
biconditional; the heavy specialization states only that the pretyped assertion
is derivable, and a final stage exposes the original equality. No extra axiom
or opaque replacement is introduced. The import and elaboration changes may
still fail under the fixed limit, and these declarations are uncompiled.
