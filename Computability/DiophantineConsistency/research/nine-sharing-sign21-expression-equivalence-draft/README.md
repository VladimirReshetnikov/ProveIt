This proposed client adapts the checked sign22/sign23 expression equivalence
to Fin21/Fin22 direct expressions, composing their evaluation identities with
the sign21 same-input seed equivalence specialized to current ports. A
matching source copy passed a guarded build and [independent terminal audit](../../reviews/nine-sharing-sign21-expression-equivalence-terminal-independent/README.md).
