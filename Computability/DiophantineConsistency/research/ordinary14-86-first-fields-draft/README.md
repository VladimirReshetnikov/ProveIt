of the signed natural pair `(M*P+b*Y, M*r)` minus `M²*D`, proves the other
four field expressions independent of the first-root coordinate, and extracts
all five signed fields from an 86 own-zero using the generic five-square draft.

or positive witness is assumed.

finite literal-field formulas and replays source receipts. It does not run
Lean. The ring/positive bridge, quotient proof, compatible providers, iPRA
endpoint and physical-file/PDF semantics remain separate.
