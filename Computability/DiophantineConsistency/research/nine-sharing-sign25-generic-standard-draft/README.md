# Generic standard endpoint and sign25 specialization draft

This source-only strategy first proves the standard-theory iPRA endpoint for
an arbitrary expression and arbitrary `PolynomialBridge`, with no sign25
expression or sign25 source imported. A separate module specializes that
generic theorem to the previously checked sign25 bridge; a third proposes the
translated consistency wrapper. It uses the sign25 concrete bridge whose full
guarded producer completed, rather than the later partially successful native
endpoint producer. The generic and specialization statements are not yet
compiled, and changing import boundaries can alter resource use. No endpoint
is claimed without a guarded run and independent audit.
