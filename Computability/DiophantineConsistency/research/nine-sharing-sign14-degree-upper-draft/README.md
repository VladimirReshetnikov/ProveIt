# Sign14 degree upper bound: source-only draft

This staged draft proposes total degree ≤ 124 for the symbolic Fin14 Lean
expression for arbitrary integer ports, by bounding the syntactic degree of
its five staged residuals. Node and row proof sources are generated from the
pinned external candidate AST; the source-generation procedure and the proposed
correspondence with the staged Lean syntax require independent review. No Lean
compilation, external-file binding, exact-degree result or endpoint claim is made
by this packet. Failed attempts elsewhere motivate small compositional stages.
