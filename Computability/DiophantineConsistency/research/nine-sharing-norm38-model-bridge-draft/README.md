# Uncompiled all-model bridge draft for the 38-witness seed

All Lean sources in this directory are **uncompiled drafts**. `NormAssignment38.lean` gives one concrete final assignment environment for the first 60 current graph nodes: 14 shifted source inputs, four natural port representatives, constants 1/3/4, and 60 graph values. Each of the 19 cut nodes reads its corresponding final witness coordinate; each of the 36 inline and five norm nodes directly computes its signed pair from earlier nodes. It also records the ordered 60-gate list, a proposed `gatesHold` predicate for one final assignment, and the five norm targets. `check.py` confirms all 81 generated nodes, all 60 dependencies, cut-coordinate uses and terminal indices against the frozen source graph and norm38 AST. This is a source transcription check, not Lean elaboration or a model theorem.

`SharingNormTrace.lean` drafts a generic observation: if all residuals hold at one final pair assignment, the assignment itself forms a constant residual-satisfying chronological trace. This does not by itself identify the final values with the source expression. Its proposed `ringStep_extends` lemma isolates the additional topological induction: when a fresh gate's operands already agree with reference values, its output can be added to the agreement set. The concrete 60-row acyclic alignment is externally checked, but its Lean replay and its connection to the current expression remain open.

`SharingNormSquares.lean` copies the elementary sum-of-squares extraction argument from the separately checked lightweight quartic bridge, and drafts its specialization to the literal 38-seed. It has not been compiled here. The remaining key obligations are to derive all materialized gate equalities and five terminal norm residuals from a seed zero, discharge inline gate equations definitionally, apply the ordered source-DAG induction, relate the five values to `Carrier65.core` and cancel positive `Delta`, and construct the reverse witness assignment using `ForwardWitness38`. Four actual port values need model-natural representatives, and the current norm theorem also needs its explicit positive-coordinate and `Facts` hypotheses. The separately drafted seed degree/normalization, `NineFreshJones.nine_iff` instantiation, and iPRA transfer are not yet proved for this candidate.

The files contain proposed proof scripts but no compiled Lean object, and this packet makes no Lean model bridge, Jones endpoint, file-content or degree theorem claim. Run `python3 -I -S -B check.py` for the source-alignment check only.
