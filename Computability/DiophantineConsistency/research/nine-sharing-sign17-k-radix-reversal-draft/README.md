# Source-only radix reversal and increment

This uncompiled draft proposes generic identities needed to reverse a finite coefficient vector and add one to a selected little-endian digit. It depends on the generic ofDigits sum retry; its terminal audit is pending. No result, K-byte identity, or file/JSON/gzip/PDF binding is asserted here. The eventual K application must account for a 20-digit offset: reversed coefficient position 984 becomes global digit 1004, where the middle sentinel adds one to coefficient c[1].
