# Separate finite projection packet: outline only

This document is a construction and review plan. It contains no executable
producer, imported optimizer, emitted projection, collected polynomial or
predicted measurement. The signed-cap ordinary/design packet is frozen, and
the new source-only packet has passed its five authorized author commands.
Root's independent literal-source acceptance and closed source-only manifest
are still prerequisites for implementing or running a finite compiler packet.

The future finite packet must start from the complete generated
`research/signed-pell-cap-source/guarded.json`, SHA256
`be87e468907558b14197424c0ab117ea1b69b0d163af4e5f35fd3abe7791e781`.
It must also pin that packet's entire eventual closed manifest, all eighteen
source input pins, its ordinary/design seal, the original raw/power metadata,
and the exact selected compiler/checker module closure. No tool, program or
module may be treated as authorized merely because an older packet used it.

The guarded source already contains all Legendre graphs, including the cap's
direct C-W and squared-cap graphs. A future compiler should optimize this exact
integer system. It must preserve every inherited semantic coefficient and free
port, and it must not silently apply the proposed later common-helper reflection
or guard relaxation, change any weighted interval guard, revert any substituted
remainder, add an unsigned-domain assumption, or change the set of cap targets.
Any such operation requires its own source transformation and ordinary proof.

A first producer can use a pinned, completely read monic projection engine on
the exact quadratic residual list. Before its first execution, reviewers must
read the complete new producer, every executable imported dependency, the full
optimizer-free checker and all adapter code. The engine may then emit only
separately named profiles with complete retained coordinate lists, residuals,
inverse/restoration ledgers and collected polynomials. Profile configurations
must be recorded literally; their number and heuristics are review decisions,
not inferred improvements from the source transformation.

The independent checker must import no optimizer or producer. For every emitted
profile it must verify both directions of the complete integer solution map:
each eliminated coordinate has a signed integer polynomial restoration with
unit coefficient, the chosen pivot row is solved exactly, substitution into
every other row is exact, every retained source coordinate is accounted for,
and the inverse composition is the identity on all source and retained ports
under the corresponding residual ideals. A raw-to-compact index change needs
its own complete bijection and both round-trip identities. No comparison with
the old selectively squared private Pell tuple may replace these maps.

Whole-literal binding precedes polynomial measurements. Each final residual
list and each inverse certificate must be bound to the exact guarded source;
each collected quartic must equal the complete sum of squares of its actual
residual list. Every monomial, signed coefficient and complete polynomial must
be retained, rather than only a support digest or a summary census. The checker
must calculate actual live-variable, residual, term, degree and height data from
those complete artifacts and check every reported field. No count is licensed
by the number of deleted source comparisons, added rows or Legendre variables.

Meaningful corruption controls should alter actual source binding, an inverse
sign, a pivot coefficient, a retained-coordinate map, a final residual, a
collected coefficient, and a reported measurement. Controls should cover the
cap joint row, C-squared bound, signed pool quotient and F-retained guard status
as well as the generic projection machinery. They must reject actual modified
artifacts while admitting the unmodified complete profiles.

After full static approval, the finite producer and independent checker require
normal/optimized deterministic rebuilds and normal/optimized checks to fresh
scratch outputs. Every generated member must match its retained record exactly,
all source and executable pins must remain unchanged, and independent reviews
must bind the whole closure. Only then can an actual closed inventory be sealed
for root's acceptance. This plan grants no permission to execute those future
programs and makes no ordinary-equivalence or frontier promotion claim beyond
the separately accepted source interface.
