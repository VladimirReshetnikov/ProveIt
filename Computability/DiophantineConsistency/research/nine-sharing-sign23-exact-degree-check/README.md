# Sign23 exact degree guarded client

A source-only client combines the independently audited upper and lower degree
proofs. The runner rechecks the lower provider's seven stages and overlay; an
upper survey rechecks four upper stages and their 1,412 byte-matching overlay
links, with no extras. It injects those four exact upper objects in a fresh
output and reruns both surveys at postflight. Same `-M3600`, sampled RSS,
host floor, timeout and disk guards apply. This is not a JSON/PDF binding.
