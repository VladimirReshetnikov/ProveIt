# Abstract repunit radix and mask population

This factor assumes model values `d,N,J,beta,MC,HP`, a positive repunit witness, `beta+1=exp d`, and the stated mask bounds, residues and population sum. It derives the radix identity and exact repeated-mask population without expanding fixed symbolic numerals.
