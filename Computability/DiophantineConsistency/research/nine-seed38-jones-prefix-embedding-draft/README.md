# Candidate generic typed prefix embedding

This source-only client defines a typed path from one macro DAG to a sequence of snoc extensions, carrying a `Fin` index embedding. It proposes an induction proving lookup preservation and a two-snoc example using the already checked `snoc_previous` lemma. It has not been compiled. It does not construct paths for the 45-node recipe, prove its semantic equality, or verify a JSON/document parser.
