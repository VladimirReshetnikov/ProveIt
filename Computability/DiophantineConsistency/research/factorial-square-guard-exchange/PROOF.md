## 3. Recover the factorial before using it elsewhere

Because d>=K, the coefficients binom(K+d,j), j<=K, are nondecreasing
through K, and

```
binom(K+d,K)=product((d+j)/j,j=1..K)<=(d+1)^K=N<b.
```

All lower coefficients are valid base-b digits. The unchanged choose0
rows therefore give C=binom(K+d,K). The exact ceiling rows imply
`f=ceil(N/C)`.

For completeness, the needed squared-radius lemma has a particularly
short proof under the strengthened hypotheses K>=4,f>=K. Let m=K! and

```
q=N/C=m*product((f²+1)/(f²+j),j=1..K).
```

Then 0<q<=m, so a fixed point f=ceil(q) has f<=m. The finite product
bound gives

```
0<=m-q<m*K*(K-1)/(2f²)<m/2.
```

Consequently f>=q>m/2. Substituting this improved lower bound back gives

```
m-q<2*K*(K-1)/m<=1,
```

using K!>=2K(K-1) for K>=4. Thus m-1<q<=m and f=m. Conversely at
f=m the same deficit is <K(K-1)/(2m)<=1/2, so the ceiling is m and
f>=K. This proves both directions on every actual input allowed here.

version as well, including all small cases. No fixed-point search is
used as the mathematical proof.
