# Proposed iPRA endpoint for the 94-operation candidate (unchecked draft)

`SumSquaresIPRAEndpoint.lean` proposes clients that instantiate the checked
94-operation positive model equivalence with either the fixed symbolic ports
or their decoded Lean byte recipes, then apply the separately checked generic
standard and equality-only iPRA adapters. The proposed no-zero sentence uses
the adaptive `x+1` substitution; the 94-operation count is for the original
positive-coordinate evaluator before those substitutions.

**This source has not been compiled.** Its existing model and iPRA imports
have incompatible selected provider histories. They must first be rebuilt or
otherwise validated in a coherent provider, after which this client needs its
own guarded check. It is not evidence that the declarations elaborate, that
an iPRA proof exists for the 94-operation expression, or that external
JSON/gzip/filesystem/PDF bytes are formally bound to it.
