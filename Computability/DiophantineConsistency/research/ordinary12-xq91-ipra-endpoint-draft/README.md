# Proposed iPRA endpoint for the 91-operation candidate (unchecked draft)

`XQ91IPRAEndpoint.lean` proposes clients that instantiate the author-checked
91-operation fixed-port positive model-halt equivalence for the symbolic ports
and their closed Lean byte recipes, then apply the separately checked generic
standard and equality-only iPRA adapters. The proposed no-zero sentence uses
`x+1` for each coordinate; the 91-operation count is for the original
positive-coordinate evaluator before those substitutions.

**This source has not been compiled.** The existing compact model and generic
iPRA providers have conflicting selected project objects. The ongoing
425-module expanded-cone rebuild is intended to resolve that particular
selected-project mismatch, but completion will not automatically validate or
compile this newer client. The 91 model endpoint and adapter must be built or
otherwise validated in a coherent provider, and this client then needs its own
guarded check. The draft does not establish that its declarations elaborate,
that an iPRA derivation exists for the 91-operation expression, or that
external JSON, gzip, filesystem, TeX or PDF bytes are bound to it in Lean.
