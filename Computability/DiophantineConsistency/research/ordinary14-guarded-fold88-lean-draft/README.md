# Source-only Lean route for the quotient-guarded 88/26 graph

This adapts the separate source trace in
`../ordinary14-guarded-fold89-lean-draft/` to the independently reviewed
14-positive quotient-guarded 88/26 graph. It is **uncompiled source**, not a
Lean theorem, model bridge, iPRA derivation, PDF/file binding, operation-count
theorem or endpoint replay. The 88/30 parent and 88/46 precursor model clients
remain uncompiled drafts. No provider compatibility or prelaunch readiness is
asserted.

`make_graph.py` pins the reviewed 88-row candidate and generates
`P88QuotientGuardedGraph.lean` with `Expr (Fin 14)` variables, a proposed
five-square `output_shape`, and source fields for Bt and `b=J*beta`. The
slot named r is sigma-prime; slot 13 is the positive quotient t. The
`--check` mode verifies exact generated bytes and does not call Lean. Parsing,
elaboration, the identifier `guard`, casts and proof reduction remain untested.

## Difference from the 89-gate guard

The final guard is `Bt−b*t`, not `Bt−h`. A guarded zero gives `Bt=b*t>0`
directly, so the guarded→parent route does not need to extract this quotient.
However the signed-fold comparison needs the new positivity lemma

```
sigma = sigma_prime−t > 0.
```

The reviewed external proof uses the signed first norm and main norm to show
`k>2`, then the first-Pell descent to obtain `k>=8*X*Y²+4`. From
`tau²=1+m(m+1)k²` one has `2*tau<2*ell+k`; the actual port bound and
`Y>=q³` give `4*t<k`. The two root branches imply
`sigma_prime=ell+k+s±tau`, so sigma_prime>t. In an IΣ₁ model these statements
must be proved with natural arithmetic, inequalities and the signed-magnitude
embedding; rational division notation is not itself a model proof.

`ArithmeticPellFirstNorm.descent` and `positive_parameter_solution` are
existing source theorems suitable for the Pell step; the quantitative
`8m+4` bound is **not** yet a graph theorem. The source trace for the 89
variant explains the available `scaled_quotient`, internal square-divisibility,
main-root k=2 exclusion, and signed-pair adaptations. `q³∣Y`, internal
quotient s, first-root sign split, `Fin` witness projection and exact graph
substitution still need new clients. The independently reviewed
standard-integer positive-Bt repair cannot simply be imported as an IΣ₁
proof.

For parent→quotient-guarded, the old first-carrier route must first extract
`b|Bt` and positive t; the reviewed 89 construction supplies the conceptual
sigma, then sigma-prime=sigma+t. New internal clients must carry those
coordinate maps and all sign/cast conditions. The parent itself is not yet a
compiled 88/30 model theorem.

## Internal fixed-port and endpoint boundary

As in the 89 trace, the external positive existence equivalence assumes
`beta>0` and `0<=K0<(beta+1)²`. `CompactFixedBeta.beta_identity`,
`CompactFixedBeta.bounds` and `CompactCellProductBound.symbolic_kernel_lt`
provide source ingredients for a **new** internal port bound; exact casts and
port-index relations remain to be proved. The association of symbolic ports
to byte payloads stays external. Only a completed model-wise bridge in every
required IΣ₁ model could be composed with the parent positive bridge and the
existing iPRA endpoint adapters; none is supplied here.

The reproducible generator is source evidence only, not a route, companion,
package or dynamic-load audit. Any future compile requires independent
preflight, a compatible guarded provider route, established resource/disk
limits and exclusive Lean allocation.
