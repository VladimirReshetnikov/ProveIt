# Bounded conditional signed-cut search

This read-only external search explores 6,000 deterministic mutations of cut sets and repairs their two-component syntactic degree propagation on the pinned current 65-gate source (first 60 rows, five unit norms). The seed is 20261106. Every chosen cut uses one natural coordinate, so each signed source value must be representable in the selected direction; it selects nonnegative orientations except `V2minusY2`, which is nonpositive. It keeps `qm` and `q` inline and `q2` materialized so the first residual at all-zero witness coordinates remains `−(beta+1)^2`. These are restrictions, not a general lower bound.

The best examined cut set has 19 cuts plus 14 shifted input coordinates, hence 33 witnesses. It swaps `V` for `f2inner` relative to the audited 33 candidate, but no exact residual AST, full source-conditional sign proof, model bridge, Lean theorem or endpoint is produced for that alternate cut set. This search therefore found no reduction below the checked 33-witness seed; it is neither exhaustive nor evidence that such a reduction is impossible. The result's `unproved_sign_obligations` names nontrivial pair-sign obligations for its selected representation, and the zero-component test is syntactic, not a separate mathematical sign proof.
