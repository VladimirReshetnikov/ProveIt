# Sign23/sign24 direct-expression zero equivalence: source-only draft

This proposed client adapts the checked sign24/sign25 expression equivalence
to Fin23/Fin24 direct expressions, composing their evaluation identities with
the sign23 same-input seed equivalence specialized to current ports. A matching
source copy passed a guarded build and [independent terminal audit](../../reviews/nine-sharing-sign23-expression-equivalence-terminal-independent/README.md).
The iPRA endpoint, Lean degree theorem and external byte binding remain separate.
