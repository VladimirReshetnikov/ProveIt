deletion. Start from the exact current78-guard raw source underlying
`candidates/projected-radius-comparison-base`. Remove the guard on
raw694/base0.T and instead guard raw645/shared.Zminus1. Keep the other77
guards, all original1259 source coordinates and all1177 rows unchanged.
The two guarded systems have the same existence of integer zeros. A guard
on a value v means v=a^2+b^2+c(c+1) with three private integer witnesses.
No new quartic or projected metric is materialized here. No Lean work,
internal-ZFC transfer or new native calibration is claimed.

The proof does **not** assume that a square is even. In the actual source
raw86 is `(t+x+y+M0+2)^(2^23)`, not `(M0+2)^2`; raw36 is y+1. Its
constructor has no fixed parity. The earlier finite sign/constructor audits

## 3. Exact negative-A residue alternatives

Suppose for contradiction A=-a. Consider any actual source call with
1<=n<W,1<=k<W,0<=m<W and the above positive seed ordinate. Its exact
modulus and residue rows are

    T=2An-n^2-1=-D,  D=2an+n^2+1>a>W^W,
    X-(A-n)Y-m=T*h.

Put chi=chi_k(a),psi=psi_k(a), and

    p=chi-(a+n)psi, q=chi+(a+n)psi.

The Pell recurrence gives p_(l+1)=-n*p_l-D*psi_l(a),p_0=1, so
p=(-n)^k modulo D. The exact norm identity gives p*q=1-D*psi^2.
Consequently the actual source row has precisely these implications:

* If X=-chi, then m=-(-n)^k modulo D.
* If X=+chi, then m*(-n)^k=1 modulo D.

Both m+n^k and m*n^k+1 are positive and at most W^W<D. Also m and
n^k are individually below D. It follows, with no modular inverse,
that the only viable alternatives are

    k odd, X=-chi, m=n^k>=1;
    k even, X=+chi, n=m=1.

For example, the first negative-root/even-k branch would make the positive
m+n^k<D divisible by D. The positive-root/odd-k branch similarly makes
m*n^k+1<D divisible. In the remaining even-k branch, the integer
m*n^k-1 has absolute value less than D and must be0, forcing n=m=1.
Thus every positive-base call has output m>=1; if its base is at least2,
it necessarily has odd exponent and the exact intended positive power.
This conclusion is specific to the negative-A branch and does not presume
the complete source's power semantics.
