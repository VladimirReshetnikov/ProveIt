# First and main Pell index comparison

An actual current natural adaptive zero yields first and main Pell indices
`n` and `m` satisfying `13 ≤ n < m`, `14 ≤ m`, and `2R < c` in every
selected `IΣ₁` model. The theorem retains the actual first-root magnitude,
positive orientation of the literal main root, both recurrence coordinates,
and `(2n) mod q⁴ = R+1` from the earlier result.

The comparison uses monotonicity of the Pell coordinates in the base, proved
by represented induction over the internal index. The actual quotient for Y
supplies `Y ≥ 2`; this makes the main base at most the first base and makes
`k < c`. If `m ≤ n`, monotonicity would give `c ≤ k`, a contradiction. The
rank half-window follows from `R+1 ≤ k`, `Y ≥ 2`, and positive η.

No equality between `m` and `R`, no equality `2n = R+1`, and no input power
representation is asserted. Establishing the main-index equality still
requires the actual strong and auxiliary carrier equations and their generic
half-index argument; the full internal HA proof remains open.
