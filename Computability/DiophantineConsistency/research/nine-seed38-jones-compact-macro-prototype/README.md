Powers and finite sums are explicit symbolic macros; the seed-derived `z`, `y`, `pCoefficient` and `expo` remain closed Lean-definition references, so neither their huge values nor the geometric sum is expanded. The output is the final node.

The file records the intended exact current seed and symbolic coefficient definitions. It must not treat these fixed closed values as extra input variables.
