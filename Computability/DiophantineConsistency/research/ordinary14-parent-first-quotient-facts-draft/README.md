# Folded parent signed-pair quotient facts — source draft

This graph-independent unelaborated model fact starts from the explicitly
stated scaled square of the folded parent signed pair, with positive b,Y,D.
Scaled quotient and modulo q³ give Y=q³s with s>0; modulo b and the exact
identity `(1+kb)q³=1+bL` give b dividing the magnitude of the Bt signed pair.
It also retains positive tau with tau²=D. Both signs of Bt are allowed: this
is **not** yet a positive t witness and does not assert Bt>0.

A separate 13-parent graph binding must supply this signed pair and norm,
and a model sign argument is needed to obtain Bt=b*t>0. Lean elaboration,
provider closure, converse map and iPRA endpoint remain open.
