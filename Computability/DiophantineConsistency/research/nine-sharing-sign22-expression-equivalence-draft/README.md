# Sign22/sign23 direct-expression zero equivalence: source-only draft

This proposed client adapts the checked sign23/sign24 expression equivalence
to Fin22/Fin23 direct expressions, composing their evaluation identities with
the sign22 same-input seed equivalence specialized to current ports. A
matching source copy passed a guarded build and [independent terminal audit](../../reviews/nine-sharing-sign22-expression-equivalence-terminal-independent/README.md).
The iPRA endpoint, Lean degree theorem and external byte binding remain separate.
