# Source-only K byte-block samples

The generator reads pinned external coefficient and K snapshot data to propose four in-Lean finite numeric identities: full radix/byte blocks 2, 125 (including the digit-1004 collision), 126 and the five-digit/24-byte tail 252. These are sample arithmetic fixtures only. No relation to the actual in-Lean stream, complete byte list, or external files is asserted until separately checked. The generated Lean source is uncompiled and requires a guard, independent prelaunch and exclusive Lean allocation.
