# Sign17 root-form signed-lift draft

This source-only client specializes the generic sign lemmas to the algebraic
root shape `x9*(beta*(x1+1)+1) + beta*(x1+1) + B + C`, with B and C
represented as arbitrary model naturals, and the associated positive scale.
It proposes a natural representative for the signed difference when beta>0
and the retained norm equation holds. It does not yet bind B/C to the exact
external AST, prove residual transfers or establish a model/iPRA bridge.
