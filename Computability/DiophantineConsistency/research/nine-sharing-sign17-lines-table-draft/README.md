# Source-only in-Lean decimal-line tile-table reconstruction

This uncompiled source proposes reconstructing all ordered tile rows from the in-Lean 715-digit seed through its parametric decoder, decoded target-set sorting and rail formulas, while retaining the fixed start/copy/tail formulas. It then proposes equality to the existing ordered table and its 942 indexed tiles. Target-list-order compilation and audit, a guarded prelaunch and exclusive allocation remain required. It does not interpret PDF bytes or external files.
