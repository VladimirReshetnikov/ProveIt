# Carrying the auxiliary sign to the 43-variable quartic

`AdaptiveNamedValues50.exists_positive_extension_with_embedding` strengthens
the existing 42-to-50 extension by retaining all embedded coordinates.
`AdaptiveVSignTransport43.from42` follows that extension through the checked
50-to-49-to-47-to-46-to-44-to-43 maps. For natural ports with first port at
least two, every positive 42-named-graph zero with `v 31 < v 30` yields a
positive 43-variable parent zero with `u 26 < u 25`.

This is a witness transport theorem; it does not assert that every parent
zero is oriented or independently supply the starting witness. The focused
replay inherits the 43-native peer's transitive and dynamic ancestry.

The first exploratory full probe was terminated after a separate diagnostic
identified expensive implicit unification between two 49-literal definitions.
That diagnostic temporarily postulated the coordinate-preserving extension
and is not proof evidence. The repaired full proof uses the actual extension
and an explicit `literal_eq` rewrite; it exited cleanly before the paired
source replay.
