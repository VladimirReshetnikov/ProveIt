# Positive 84 ↔ 87/36: source-only unscaling transport

This packet generates both actual 13-coordinate graph literals from the pinned
84 and 87/36 JSON rows and proposes graph-level Lean model transfer. None of
these files has been elaborated, compiled, built, or axiom-audited. The
conditional theorem does **not** discharge either graph cut or establish an
endpoint, iPRA proof, compact fixed-port equality, PDF semantics, or coherent
provider ancestry. In particular, Lean tactic and cast behavior remains open.

`first_scale` proposes the exact all-ring graph identity: for 87 model-natural valuation
`v`, model-natural s with no positivity assumption, and `ι(v 7)=q³ιs`, update coordinate 7 to s and
coordinate 8 from r to r+s. The 87 first residual is q⁶ times the 84 first
residual. `shared` proposes the exact matching of the other three graph fields
for **any** target r. Four squares imply their residuals vanish, and positive
q allows cancellation. The outputs themselves generally differ by q¹² in
the first squared term. `positive_zero_iff` assembles the two directions from
explicit `ForwardGraphCut` and `ReverseRootCut` assumptions; it makes no claim
that a supplied replacement r equals the original r or its predecessor.

The forward cut is reduced further to `ForwardNormBinding`: for each
positive 87 graph zero, supply a natural beta represented by port 0 and the
exact signed first-root equations `ScaledFirstCut`. The latter supplies both
the source root equality and square norm, using the literal graph `root` and
`bt` fields. `quotient_of_cut` applies the existing unelaborated source-only
`positive_quotient_of_signed_norm` to obtain positive s with Y=q³s; the
proposed `forward_of_norm_binding` handles the same-model cast and q≠0.
This quotient fact needs Y>0 and the displayed norm, and does not itself
need beta>0. It is not yet a proof that an actual graph zero supplies those
premises. The compiler must still validate the source proofs and dependency
providers, including the signed-square divisibility and natural reflection.

The reverse cut requires, for each positive 84 graph zero, positive model
naturals Y and r with Y=q³s and an actual zero of the 87 first residual.
It is deliberately not replaced by the invalid naive formula r_old=r84−s.
The existing positive-target-root helper only applies after obtaining a
positive carrier P=b*t, the first norm and a strict root margin; none of
those bindings is silently assumed here. The separate unscaling audit and
source-only margin drafts detail a candidate route. The other fields are
r-independent, so a successful witness suffices for the proposed `shared`
client.

The pinned audit proves the key scalar ring identity by exact polynomial
arithmetic. This packet's separate checker compares all 84/87 literal input,
port and row strings to JSON and checks 300 concrete positive assignments,
including the q⁶ residual and q¹² squared-term factors. Such finite checks do
not prove all-model graph equivalence or any Lean proof. The source checker
verifies key theorem and assumption text; it does not execute the proposed
proof scripts or validate an import graph.
