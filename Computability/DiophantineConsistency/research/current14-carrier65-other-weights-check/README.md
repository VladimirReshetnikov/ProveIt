# Carrier65 non-Q factor syntax weights

This unrun client proposes standalone unit-weight syntax expressions for
`delta`, `P`, `U`, `W`, and `Z` and exact syntactic weights 12, 22, 62, 2,
and 46 respectively, with several intermediate weights. The independently
audited Q-input syntax module supplies the shared expressions. The no-Lean
preflight passes; independent prelaunch review is pending.

These are proposed syntactic calculations, not yet actual Carrier65 field
bindings or multivariate degree bounds. They also do not use the separate Q
cancellation or establish the whole polynomial's degree.
