# Sign25 pretyped sentence staging draft

The generic arbitrary-expression standard theorem compiled as the successful
child of a failed outer run, but concrete specialization exceeded the fixed
interpreter memory limit. This source-only strategy reruns the generic theorem,
then defines the concrete no-zero sentence and its definitional equality in a
module that imports the existing current-expression definition but not the
larger sign25 polynomial bridge. A later module imports the bridge, states the
endpoint using the pretyped sentence and applies the generic theorem; a final
module exposes the original sentence by equality rewriting.

The staging aims to reduce elaboration work in the heavy environment; it does
not change the equation or theory. None of these source declarations is yet
checked. An independently reviewed provider survey is required to bind the
current-expression module to its checked producer; a guarded same-limit runner,
preflight review and assigned Lean slot are required before testing. The
translated wrapper remains separate even if all stages compile.
