## Why134 is a substantive arithmetic lead

The [complete compact proof](../../con-zfc-diophantine-forms/134-certificate-reductions/compact/PROOF.md)
removes the artificial q^2+1 scale. With Y=q^3s and an integral recovered
carrier it first proves Y^2 divides(q-1)H e. Since q^6 divides Y^2
and is coprime to(q-1)H, it gets q^6|e. The first Pell congruence
then bounds the small index error2n0-R-1 by R<q^4<q^6, giving
2n0=R+1. Only afterward does it recover FULL Y^2|e. This avoids the
false assumption gcd(Y,q-1)=1. The supplied proof includes the scale-one
ratio theorem, chronological transport/rank recovery and fresh positive
strong/auxiliary witnesses. Those dependencies were read for intake;
the transitive native/compiler/calibration chain has not been reapproved.

Both circuits retain the old indexed67-bit-radix tuple: largest port
592884 bits, total295388 raw bytes,52904 more than maintained radix55.
The [printed constant recipe](../../con-zfc-diophantine-forms/134-certificate-reductions/report/compact_constants.tex)
does include the full436-character seed, alphabet, decoder,943 tiles and
all four fixed integers. It is a complete specification, with no new
single-page fit, glyph count or visual acceptance established here.

A possible LATER transfer is to delete its remaining T+alpha addition.
Its bV sign proof would need a fresh scale-one version. A useful hand
sublemma is that a hypothetical main index3 gives

2Y-X in{1,2}, incompatible with q|X,Y. This suggests extending the
existing sign-free bV gap to scale one. It is NOT a complete new
soundness/completeness theorem, emitted77/78-operation circuit, accepted
degree or size gain. It is parked pending the current49 work and a full
review of134.
