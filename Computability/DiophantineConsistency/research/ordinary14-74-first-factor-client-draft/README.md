# Literal 74 direct-first factor client — source draft

This proposed client evaluates the literal 74 graph's first factor as the
signed difference between `r²` and `(m*k)*(m*k+k)`, with `m=X*Y²` and
`k=eta+zeta`. It retains an explicit beta port cast. Positive beta and the
J, w, s slots imply `q≥2`, `X≥2`, `Y≥1`, and therefore `m≥2` inside the
model; no stronger Pell growth or standard-integer argument is used.

The last source theorem composes that cut with the proposed generic
pair-evaluation bridge and reviewed five-unit fact. The signed product equal
to one and the three other negative-unit residue exclusions are still explicit
premises; it does not infer them from the graph's own zero. The 75 graph has
the same first expression, but this file asserts only the 74 claim. All graph,
helper and bridge draft imports remain unelaborated. No model equivalence,
provider compatibility, iPRA endpoint, byte/PDF binding, or Lean run is claimed.
