# Compositional prefix reflection: source-only draft

This proposes a symbolic code AST with separate port placeholders, an encoder,
interpretation, depth bound, and a universal theorem that decoding an encoded
code followed by an arbitrary suffix recovers its interpretation. If checked,
future row proofs can split byte equality and staged interpretation into smaller
chunks instead of normalizing full parser executions in one term. No Lean
compilation, row byte binding, JSON parser theorem, or PDF connection is claimed.
