# Exploratory compact-field lookup bridge

`CompactFieldCastBridge.lookup_row` converts the exact standard-index lookup/cast interface to the finite table's `Compact943Data.row` coordinate. `lookup_matches` then turns the proved table-coordinate equalities at `cyc N h 1` and `cyc N h s` into the two old compact-word east/south conditions for every model index and arbitrary positive N, including wraparound and arbitrary s. It assumes the lookup-cast law for functions vanishing at the default zero tuple; the existing `CompactRowTransport.compactField_cast` states that law for the actual compact lookup. No coprimality or positive-stride assumption is used.

The lookup is intentionally abstract in this module. Actual old-interface `CompactWord`, reverse-marked composition, represented machine halt, retained tuple binding and iPRA remain unproved here. The historical old-interface provider has unavailable links and a `ModelDifferenceRing.olean` differing from the graph overlay; this check imports no objects from that provider and is not evidence that the two providers are coherent.

Single-author Lean 4.32.0 exploratory compilation used the graph author overlay and guarded foundation package recorded in the origin-match packet, a clean loader, `-M3000 -j1 -DElab.async=false`, and a 120-second timeout. Sessions 42715 and 88275 exited 1 on lookup lemma naming/inference and emitted warnings and `sorryAx`; their exact sources and logs are retained. The corrected lookup-row session 65896 and full matching session 61316 each exited 0 without warnings or `sorryAx`, with their axiom reports retained. This is not a paired replay or independent artifact audit.
