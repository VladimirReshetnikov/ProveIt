Every row index is below 943 and different from the erased selector row 1. The cyclic predecessor includes wrap at N=1. The statement uses the literal 943-row table and its proved field bounds; it does not identify s with a physical time step or assert machine simulation, graph existence, retained K/port-byte binding, or iPRA completion.
