The final graph-halt and report clients in that plan remain uncompiled. It records commands, logs, object hashes, guard snapshots and the axiom reports named in source. The report parser requires the exact requested names, rejects duplicates and axioms outside `propext`, `Classical.choice`, and `Quot.sound`, and records observed sets; it does **not** claim pre-pinned exact per-declaration sets.
