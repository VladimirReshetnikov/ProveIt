`replay.py` is a bounded **author-only exploratory** runner for the 22 modules in the independently reviewed [source plan](../compact44-marked-suffix-source-plan/README.md). The final graph-halt and report clients in that plan are explicitly uncompiled. No real suffix compiler has been launched by this runner, and no graph-to-marked, machine-halt, paired-build, retained-byte, converse, or iPRA conclusion is asserted.

The runner pins both earlier graph-marked source-scan JSON files, the reviewed 22-source scan and scanner, the independent closure review's CHECK/terminal/audit bytes and schema, the split-Wang author audit's corresponding artifacts, the 96-child author result, monitor and Lean binary. It checks the first 18 source identities against the two pinned earlier scans and the complete 22-source list against the independently reviewed scan. It reruns the no-Lean closure audit before and after a full build, requiring its JSON to match the reviewed CHECK. That audit itself reruns the parent artifact audit and source scan. This does not make the exploratory seed's inherited package, transitive or dynamic ancestry independently authenticated.

A fresh output overlay is linked only to the recorded split-Wang author seed. Preflight compares both candidate-root direct object and companion slots to the reviewed source scan, records absent and present slots and all target-package slots, freezes every source, detects inconsistent repeated observations, and pins each child's actual dependency resolution to its saved mapping. It rejects redirected output/frozen directories, collisions, warnings, admissions, unexpected output companions and nonzero child exits. It records commands, logs, object hashes, guard snapshots and the axiom reports named in source. The report parser requires the exact requested names, rejects duplicates and axioms outside `propext`, `Classical.choice`, and `Quot.sound`, and records observed sets; it does **not** claim pre-pinned exact per-declaration sets. The final inventory draft requests 16 named reports; the full 22-source list requests 58.

The runner uses a clean compiler environment, Lean `-M3000 -j1 -DElab.async=false`, a 600-second per-child limit, the existing sampled 3.5 GiB leader-RSS and 4 GiB free-disk guard, and fresh output/companion slots. Dependency queries and no-Lean audit subprocesses have timeouts but not the same RSS monitor; sampling and before/after hashes are not quotas or continuous mutation guarantees. A future independent runner review, source freeze and coordinated sole-Lean slot are required before any real build.
