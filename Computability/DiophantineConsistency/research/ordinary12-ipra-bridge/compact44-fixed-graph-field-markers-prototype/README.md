# Exploratory field-marker endpoints

The two field-bit equalities extend to their marker endpoints in arbitrary IΣ₁ models. The vertical endpoint has phase 1022 and equates the offset-30 source digit to the actual temporal whole-cell source digit. The horizontal endpoint has phase 1073 and equates the offset-62 source digit to the offset-8849 source digit. The horizontal source at offset 8849 crosses the block boundary; the theorem retains the exact cyclic index.

`HorizontalMarkerGeometry` and `VerticalMarkerGeometry` check the exact finite support and high-mask phases; `FieldMarkerHigh` transfers high-mask NoCarry to even output digits. `FieldMarkerColumns` finds the surviving raw-column terms. `FieldMarkerParity` proves the endpoint equalities using explicit source bounds, low- and high-mask NoCarry, aligned whole-cell rotation and an indexed b=1 CarryInput; its predecessor reset does not assert predecessor temporal zero. `FixedGraphFieldMarkers.graph_field_markers` supplies these hypotheses from the same N,w,s witnesses for a positive-coordinate zero of the fixed symbolic graph. It extends the existing field theorem to vertical `u<10` and horizontal `u<9`, with arbitrary in-range model positions and the original cyclic indices.

The graph theorem does not assert graph existence, an ordinary successor block-index join, row propagation, field equality, retained K/port binding, machine semantics or iPRA completion. The 1073 marker is promising for a successor occupancy argument only after the block wrap and payload joins have been proved.
