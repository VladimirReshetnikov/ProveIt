# Unchecked full symbolic MC byte-recipe assembly

`CompactLowByteAssembly.lean` is generated by `generate.py` and is a
**draft, not a Lean-checked theorem**. It proposes to partition every
index below 73,759 into the separately checked prefix, dense regions, gaps,
tail and twelve boundary intervals, then apply the checked radix-window
reconstruction theorem and the symbolic MC size bound. The twelve boundary
modules must first be proved in bounded runs and a coherent mixed-provider
root built; no all-index partition or decoded-list equality follows merely
from this source.

An independent source review identified that four branches needed an
explicit `256^j = 2^(8*j)` rewrite. The current draft includes that rewrite;
the earlier source is retained in `observations/generate-attempt01` and the
corrected snapshot is in `generate-attempt02`. The current generated source
SHA-256 is `cceaf2af001850fa8887f52e80109fc7e9255342f0fb2187c5a5df65ef759f8a`.
The source review and its external interval sweep are not Lean compilation.

Even a future successful Lean compilation would identify `lowNat` with a
closed **Lean byte recipe**, not prove that external gzip or filesystem
bytes equal that recipe. The generator/payload provenance, parent-to-
supplement link, PDF and iPRA endpoint remain separate obligations.
