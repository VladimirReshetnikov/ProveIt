# Exploratory fixed-graph successor occupancy

`BlockSelectedMarker` proves exact reflected copy indexing, that any selected row at an in-range block forces the 1095/2195/3296 source markers to 1, and that a single copy bit equal to 1 excludes the local decoder's all-zero alternative. `BlockOrbit.forward_back` proves cyclic addition by s followed by cyclic subtraction by s returns h for h<N, without any coprimality hypothesis.

`FixedGraphOccupiedOrbit.graph_occupied_orbit` combines the fixed symbolic graph's uniform 4393-band decoder, cyclic block copy and origin bit, aligning both N and s across witnesses. It assumes positive graph coordinates and literal graph zero at the fixed symbolic ports with `paramKernel rho`; it obtains the same N,w,s and indexed carry input, proves block 0 has a selected row, and proves for every model h<N that a selected row at h implies one at `(h+s)%N`. This is successor closure and an anchor, not a represented internal orbit, an all-block occupancy theorem, a proof of graph existence, an interpretation of s as a semantic stride, retained port/K byte binding, machine semantics or internal iPRA.
