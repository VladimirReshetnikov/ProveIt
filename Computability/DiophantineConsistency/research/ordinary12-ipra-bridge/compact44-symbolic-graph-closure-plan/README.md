# Preliminary symbolic graph-digit closure

`scan.py` is a point-in-time source/import and object inventory, not a build. It observed 127 matching inherited objects on the independently audited graph-digit author/peer providers. The topological order contains the three audited low-population sources, the single-side exploratory low-even source, the audited high-population and high-residue sources, and an **uncompiled** proposed client. The five already audited population/residue sources are pinned to the hashes reported in their respective audit receipts. The parity source is pinned to its exploratory bytes, not represented as independently audited or paired.

There are two local `CompactLowPopulation` candidates: the scanner records both and explicitly selects the previously audited exact-population source. It checks the four recorded audit receipt hashes, same-side provider object hashes, the direct import graph, selected source hashes and rejection of project-library package fallback. It does not rerun those audits, freeze inputs simultaneously, compile Lean, or validate the proposed theorem. Normal scanning exited 0; Python `-O` was rejected with exit 1.

The proposed client retains two explicit model equalities identifying the low and high ports with symbolic lists and all remaining graph, positivity, beta, radix, repunit, split and product hypotheses. It attempts to derive the population sum, the low-even and high-mod-8 conditions, and the high word bound from symbolic-mask results. It does not establish retained-port calibration, machine semantics, a checker, or a PRA proof. A coherent same-provider source freeze, reviewed replay and independent artifact audit remain required. The high-mask and low-mask providers must not be merged as binary overlays without a matching import-closure audit.
