# Exploratory fixed-graph occupancy of every block

`FixedGraphSpatialSuccessor.graph_spatial_successor` joins the fixed-graph marker endpoint, uniform decoder and origin occupancy. Their model lengths are identified by exponential injectivity. From positive coordinates and zero of the fixed symbolic graph it produces a positive model N with an occupied selected row at block zero and closure under ordinary cyclic successor `(h+1)%N` for every `h<N`. The row, marker and decoder are all taken at that same model length and symbolic source word.

`FixedGraphAllBlocks.graph_all_blocks` joins the same decoder and applies the existing `InternalOrbit.all` IΣ₁ induction with stride one. The induction predicate is the model Σ₁-definable occupancy predicate, and `(h*1)%N=h` for each model `h<N`. It concludes a selected row at every in-range block. This assumes the positive-coordinate fixed symbolic graph zero; it does not assert such a zero exists, construct a represented global word, exclude the extra row, prove edge matching or machine semantics, bind retained K/port bytes, or establish iPRA completion.

Single-author exploratory compilation used the existing coherent author overlay `/tmp/compact44-graph-support-join-01/lib`, including the source chains recorded by the preceding field-marker and marker-successor packets, and the guarded foundation package. Lean 4.32.0 ran with a clean loader, `-M3000 -j1 -DElab.async=false`, and a 120-second timeout per child. Spatial-successor session 79664 and all-blocks session 94758 actually exited 0 without warnings or `sorryAx`; their logs record the axiom reports. This is not a paired replay or independent artifact audit.
