# Exploratory occupied source digits from the selected origin

`OccupiedBits.high_bits_one` is a generic IΣ₁-model statement: for 41 model values bounded by 1, if their weighted sum is at least `127 * 2^34`, every bit at indices 34 through 40 is 1. If one were zero, the full weight sum would fall strictly below that threshold. The proof uses the finite standard index set and model arithmetic; it does not transfer an external computation to nonstandard indices.

`SelectedOriginOccupied.selected_origin_occupied` combines that inequality with the selected-origin decoder, its Boolean copy inputs, the payload's seven fixed high bits and reflected source-index identities. For an in-range selected target T at least 3296, with `C[0] = 1` and the existing decoder alternative, each of the seven source digits `C[position j]`, for 34 ≤ j < 41, is 1. `FixedGraphSelectedOccupied.graph_selected_occupied` derives these facts from the fixed symbolic graph zero under positive graph coordinates while retaining its chosen common N, w and t, indexed `CarryInput`, zero temporal target, half-radix predecessor bound and zero incoming carry. `OccupiedNamedSlots.named_slots` makes the consequences `C[1095] = C[2195] = C[3296] = 1` explicit. Other occupied source positions are 1031, 1022, 1011 and 992.

The fixed-graph theorem assumes graph zero and does not establish existence. Occupied source digits do not by themselves prove neighboring local decoders, cyclic row matching, retained port/K byte binding, machine semantics or an internal iPRA result. A separate per-position decoder and overlap/field proof is needed for propagation.
