# Auxiliary-seed ordinate order

`CompactSeedOrdinateOrder.seed_ordinate_ge` applies the generic auxiliary
norm ordering theorem to the **actual seed form**. In any model of `IΣ₁`,
from `R>0`, `i>0`, `y>0`, with `c=ycoord R a` and
`I=delta a*i*c*c`, it takes the seed norm

```
I*I*w*w+y*y=1+I*I*y*y
```

and proves `w≤y`. It derives `c>0` from `R≤ycoord R a`, proves
`delta a>0`, and obtains `I>0` from those facts and `i>0`. Thus the required
positivity of `I` is not an extra premise. This is the exact natural
subtraction condition for the proposed ordinary graph coordinate
`delta a*i+(y-w)`, provided the graph binding identifies its `V` with
this auxiliary `w`.

The result does not construct the seed, bind the graph expressions, prove a
graph zero, identify retained/displayed coefficient bytes, or establish an
iPRA derivation.
