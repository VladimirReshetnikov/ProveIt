# Proposed fixed-symbolic graph paired replay

`replay.py` freezes the six reviewed closure sources and rebuilds them separately on the audited symbolic-join author and peer providers. It pins the exact closure audit receipt and terminal observation, reruns the symbolic-join parent audit and source scan, checks both 134-object inventories, enforces same-side project imports and a regular Init object, rejects warnings/errors/sorryAx and unexpected declaration names or axiom sets, and compares paired results. This is a proposed launcher, not a completed replay; independent exact-byte fake-loop and negative-control review is required before a root-coordinated stable-HEAD/sole-Lean launch with a trusted clean initial loader.

The first no-Lean verify-only attempt failed before Lean because the parent audit requires a commit and receipt hash; its source and observation are retained under `observations/preflight01`. The corrected parent/closure verify-only run exited 0. Focused controls accepted expected axiom reports, rejected seven mutated axiom/declaration cases and rejected missing, directory and dangling Init entries; an initial scratch run failed before those controls because its temporary directory was too shallow, and the deeper scratch retry passed. Optimized Python was rejected with exit 1. These controls do not replace full independent fake-loop review.

The compiler monitor samples leader memory and disk and is not a hard whole-process-tree quota. Direct dependency and parent-audit subprocesses have timeouts without that monitor. Package/dynamic ancestry and the parent provider's proof-theory qualifications remain inherited. The fixed-symbolic theorem retains its explicit graph-zero, variable-positivity, N>0, radix and repunit assumptions and arbitrary K; retained byte/decimal binding and PRA remain open.
