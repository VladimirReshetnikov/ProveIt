# Coherent population graph-client closure: preliminary scan

The graph-independent population theorem uses the half-binomial library. The
free-J `graph_power` theorem is available in the separately audited matched
provider. A preliminary comparison of that free-J overlay with the 342-module
endpoint successor found two different object hashes among 64 shared `.olean`
paths; the earlier six-object comparison concerned the separate 24-module
window overlay. Objects from these providers must not be mixed without a
coherent rebuild or an audited exact dependency closure.

`scan.py` walks source-declared imports and records current source SHA-256s,
module order and both free-J provider sides' inherited `.olean` hashes and
resolved paths in `scan.json`. At this observation, both free-J overlays had
the same 97 object paths and matching hashes, and both standalone
`FreeJPowerFinish.olean` objects matched the independently audited power
receipt. The preferred closure for importing `ArithmeticHalfBinomialCompat` on
the free-J provider contains nine missing source modules. The alternative
closure for rebuilding `FreeJPowerFinish` on the endpoint successor contains
33 research modules. These are preliminary source scans, not compilations or a
proof that package-transitive and dynamically loaded ancestry is complete.
The scanner's direct-import lists are parsed from current source; the selected
source bytes are not frozen simultaneously. An isolated normal scan exited 0;
an isolated `-O` invocation was rejected with exit 1.

The proposed replay is to freeze the nine listed source files and the adapted
population/client sources, validate their declared imports against that frozen
manifest and the exact two audited free-J overlays, and build each source in
topological order separately on each side. The imported `FreeJPowerFinish`
seed must match its audited object hash. Each Lean compiler's `--deps` output
must match the expected same-side objects, and the replay must check source,
seed and inherited object hashes before and after, compiler exits, warning and
axiom reports, and matching author/peer outputs. Use the reviewed sampled
monitor (`-M3000`, `-j1`, async elaboration disabled, 180-second per-child
limit, sampled 3.5 GiB leader-RSS and 4 GiB free-disk checks) with actual
outer exit recorded. These are sampled leader/process-group controls, not a
hard process-tree memory quota. Audit the finished pair independently.

A narrow population source can import `ArithmeticHalfBinomialCompat` directly,
so the unrelated adaptive-2011 radix and population modules are not needed.
The graph client must explicitly preserve the free-J port hypotheses,
positivity, the beta bound needed for power, and the q/radix hypotheses. The
scan does not establish those facts or any graph client, compact44 port or
checker binding, internal PRA proof, or consistency equivalence.
