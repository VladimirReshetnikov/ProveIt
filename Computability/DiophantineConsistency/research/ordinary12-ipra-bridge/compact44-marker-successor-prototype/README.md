# Exploratory marker successor

`MarkerBlockIndex.previous` proves the exact horizontal marker index identity in arbitrary IΣ₁ models, including the cyclic wrap and N=1. `marker` consequently translates the phase-1073 field equality to `C[8807*g+1011] = C[8807*cyc N g 1+1031]` for each `g<N`.

`MarkerSuccessor.occupied_successor` takes this marker equality, a selected decoded current row with its Boolean copy inputs, and a decoder conclusion at `(h+1)%N`. The current row forces its phase-1031 marker to one; the block-index identity forces phase 1011 of the successor to one; its decoder's zero alternative is thereby excluded. All indices are model values and wrapping is explicit. This theorem is conditional: it has not yet joined the separate fixed-graph same-witness marker and uniform decoder results, proved field-value matching, or asserted machine semantics or iPRA completion.
