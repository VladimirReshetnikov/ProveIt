# Exploratory local selector/copy decoder

For any IΣ₁ model and arbitrary `f : Fin 943 → V`, `b : Fin 41 → V` with explicit pointwise bounds `f i ≤ 1` and `b j ≤ 1`, `local_decode_iff` composes the finite coefficient identity, 41-bit copy bound and existing concrete decoder. It equates `NoCarry` for the finite selector/copy weighted sum and the fixed mask `2^51−2` with either all selector inputs and the copy word zero, or one selected row whose tile payload equals the copy word. NoCarry is the left-hand proposition of the iff; it is not derived here. The functions are arbitrary external finite families, and the result does not identify this sum with any actual graph column or assert any Boolean bound on the two-bit dummy.

The exact copy-bound source was freshly rebuilt over the decoder-based exploratory author overlay in session 30015, which actually exited 0; the local client session 30908 actually exited 0. Both have no warnings or `sorryAx`, and their named reports list `[propext, Classical.choice, Quot.sound]`. Their sources, logs, provider and object hashes and resource limits are retained. This is a single-side exploratory composition, not a paired replay or independent audit. In particular, it avoids copying the older same-witness copy-bound object across overlays with two differing shared objects, but it does not by itself establish full paired provider coherence.

Graph-derived selector/copy slot bounds, reflected coefficient/column transport and collisions, actual NoCarry, retained K and graph-port binding, machine semantics and an internal iPRA theorem remain open. A source-pinned same-provider paired replay and independent audit are needed before using this as a paired result.
