The hypotheses use arbitrary model lengths and cyclic source indices. `ParityAdjacentPhase` proves symbolically, then lifts to arbitrary models, that at least one of the two anchor predecessor sources has phase outside `{1063,1064}`. `ParityPreviousPhase` shows the cyclic predecessor of a source outside phase 1064 is outside phase 1063. Thus one anchor supplies both Boolean digits from the established graph support facts.

`FractionalAnchorConflict.conflict` combines an explicit positive remainder, source-word bound, b=1 `CarryInput`, coefficient-room bound, anchor parity and two Boolean source digits. At that anchor the temporal target is even, so parity forces incoming carry 1; its temporal predecessor is at most half-radix, so the existing reset lemma forces that carry 0. `FixedGraphAlignedShift.graph_aligned_shift` obtains these premises from the fixed symbolic graph's same N,w witnesses and concludes `(R - 67·8807N) % 67 = 0`, retaining the indexed carry input. It assumes positive graph coordinates and literal graph zero at the fixed symbolic ports with `paramKernel rho`; it does not assert such a zero exists or prove a graph contradiction. It does not identify the aligned quotient with a valid spatial/time offset, bind retained K/port bytes, construct a global row decoder or prove an internal iPRA theorem.
