# Sign14 diagonal degree: generic ingredient draft

This source-only generic lemma proposes degree 8 for the substituted inner
polynomial under explicit correction-degree ≤2, rank-degree ≤4 and nonzero
port assumptions. It reuses the sign17 univariate root/scale infrastructure.
It is not a statement about actual sign14 staged nodes; axis binding, seed
composition, expression diagonal and exact degree remain separate. No Lean
result is claimed before guarded compilation and independent terminal review.
