# Assemble decoded fragment DAG into Fin14 expression: source-only draft

This proposes an equality between the sum-of-squares expression assembled from
five decoded short-fragment DAG rows and the audited symbolic Fin14 expression.
It depends on five currently uncompiled row-decode stages and a separately
pinned expression provider. The correspondence between the fragment DAG and
original prefix/JSON files remains externally checked, not a Lean theorem.
No Lean expression assembly or PDF binding is claimed by this draft.
