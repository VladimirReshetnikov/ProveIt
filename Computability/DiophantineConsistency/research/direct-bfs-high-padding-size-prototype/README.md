# Direct-BFS high-padding size bound

`DirectBFSHighPaddingSize` combines the direct kernel's checked lower-mass bound and low/high product split with the sharper direct-cell bound. `block_lt_padding` proves that a transport block from a positive-length small-cell family lies below the high padding phases. This is a size prerequisite for high-mask safety; it does not yet prove the per-phase no-carry statement or a complete packing.
