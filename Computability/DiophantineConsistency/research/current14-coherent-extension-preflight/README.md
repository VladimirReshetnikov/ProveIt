# Current14 coherent-extension survey

`inspect.py` is a **read-only planning observation**, not a Lean launch or a build-readiness certificate. It pins the source manifest, recorded successful 1,000-module base state, its independent audit and actual outer exit, and the independently audited quoted-translated endpoint state and outer exit. It rechecks current source bytes, base outputs, 4,179 recorded direct-input hashes and 11,050 input-companion guards. It follows the quoted endpoint's *recorded direct edges* until reaching matching fresh-base objects or external inputs; it also rechecks the quoted stages' dependency/compile exits and 33,420 captured direct-companion guards. It separately follows line-parsed workspace imports from `CurrentWitnessEquivalence2011` and `ObjectCurrentEquation2011` using lakefile namespace roots. It records source copies, point-in-time Git tracking/cleanliness, conflicts, a topological order of observed union names, package observations and resources. It does not write files or run Lean.

The captured [`observation.json`](observation.json) is one run at Git HEAD `dc6e552d7432895dff025d2640fda0a98f78ab28`; the script hash is embedded in that observation. Its salient results were:

- All 1,000 base source hashes matched, with no recorded base output, direct-input or companion-guard issues at observation time. This base was compiled once; its package-transitive, dynamic-loading and between-observation ancestry remain inherited.
- The host bridge's declared source closure contains 452 workspace modules: 196 overlap the base and 256 are additional. All are present and tracked, and none differed from that HEAD at the `git diff` observation. Its 91 direct external import names include 25 not listed as *direct* imports in the base manifest; all 91 had locally resolvable objects at the observed paths, which does not authenticate package ancestry.
- The quoted client direct-edge walk saw 259 distinct project objects: 21 route to matching fresh-base objects, 231 have individually successful stages under PASS parent states, and seven have individually successful stages under **FAILED** parent states. The latter do not become successful parent runs; a coherent replay must rebuild or independently justify those stages. All 238 traced non-base modules had at least one clean, Git-tracked workspace source copy with the recorded snapshot hash. The script saw no unresolved recorded edges, declared-direct-import mismatch, duplicate module/object hash conflict, or source disagreement with the host closure. This is not a proof that those sources will rebuild together.
- The 256 host extras and 238 traced quote modules overlap in four names, producing a **490-name observed extension union** and an acyclic proposed order in the receipt. The existing 238 quote objects total 107,604,360 bytes; that is a footprint observation, not an upper bound or disk reservation for rebuilding the union.
- `/tmp` shared the root filesystem, which had 5,429,764,096 bytes free, only 429,764,096 bytes above the inherited 5,000,000,000-byte preflight threshold. Available memory was 19,569,557,504 bytes. These are samples and may change; neither value establishes sufficient resources for 490 Lean compilations or their intermediate files.
