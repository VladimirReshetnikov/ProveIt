# A bounded route from literal halt to source halt

This note sharpens the physical-extraction obligation in [PA-BRIDGE.md](../PA-BRIDGE.md).
It is a proof plan in the language of arbitrary PA models, not an exported PA
theorem. Its purpose is to avoid needing an inverse map from the literal
196-control tape machine to the auxiliary 215-control machine.

Let `c_i` be the exact coded source run from `entryState`, generated by
`stepValue`, and let source control `0` mean halted. Let `N` be a literal
blank-tape halt time in the same PA model. A sufficient target is

```
exists i <= N+1, control(c_i) = 0.
```

The proposed argument uses these specific ingredients already present in the
imported project:

1. [`trace_exists`](../../jamesyc-upstream/pa196/PA196/Arithmetic/Machine/InternalCodedSourceTrace.lean)
   constructs a coded source trace for any model element `N+1`. Its validity
   is maintained by `step_valid` from
   [`InternalCodedSourceStep.lean`](../../jamesyc-upstream/pa196/PA196/Arithmetic/Machine/InternalCodedSourceStep.lean).
2. [`physical_step`](../../jamesyc-upstream/pa196/PA196/Arithmetic/Machine/EndpointInternalCodedSourcePhysicalStep.lean)
   is proved by a case split on the current resolved source instruction. In
   the `.halt` case the source successor has control 0. **In every other
   instruction case**, the proof constructs a positive auxiliary segment
   ending in a frame refining `stepValue c`; it does not use the halt branch.
3. [`startup_all_models` and `startup_refines_all_models`](../../jamesyc-upstream/pa196/PA196/Arithmetic/Machine/EndpointInternalStartupFrame.lean)
   provide the fixed blank-to-entry auxiliary segment and its exact entry
   frame. The existing physical-trace lift already composes model-length
   segments using PA induction.
4. [`step_maps` and `segment_avoids_padding`](../../jamesyc-upstream/pa196/PA196/Arithmetic/Machine/StateMapTrace.lean)
   project auxiliary rows to literal rows along nonpadding runs.
   `segment_avoids_padding` is currently stated for a segment ending at
   auxiliary halt; its displayed induction uses only the initial state and
   step preservation, so a generalized-endpoint version is needed here.

Assume for contradiction that `control(c_i) != 0` for every `i <= N+1`.
For each `i < N+1`, the instruction at `c_i` is not `.halt`: otherwise the
source step has control zero at `i+1`. Thus the nonhalt case in item 2 gives a
positive physical segment to the frame of `c_(i+1)`. The intended strengthening
of the existing source-trace lift composes these segments by internal PA
induction and retains their cumulative length `K`, with `K >= N+1`. The
initial entry frame is the frame from item 3. The induction formula must carry
the coded source trace, the exact full frame and file, the composed physical
segment, and the inequality; an external induction over standard indices is
insufficient.

Prepend the fixed startup segment and project its entire control vector by the
forward map in item 4. This gives a literal blank-start step sequence of
length `58154 + K > N`; no inverse mapping of a literal trace is required.
The given literal halt trace and this longer trace have identical first `N`
configurations by determinism of the exact arithmetic row relation. The former
is in literal state 196 at time `N`, while the latter has a next step there.
That is impossible: the literal step formula has rows only for states
`0,...,195`. This proves the displayed source-halt bound once the following
facts have been established **inside PA**:

* the strengthened nonhalt-step and cumulative-length lift, including source
  validity and coded sequence composition at all model-length indices;
* the generalized nonpadding lemma and projection for arbitrary segment
  endpoints, including the fixed startup; and
* determinism of the literal arithmetic transition formula and absence of an
  outgoing row from 196, plus a PA induction comparing coded traces. The row
  formula makes these plausible by unique binary quotient/remainder and a
  finite row split, but the existing standard-`Nat` tape determinism must not
  be substituted for that all-model argument.

[`Exact/PAHaltingFormula.lean`](../../jamesyc-upstream/pa196/PA196/Arithmetic/Machine/Exact/PAHaltingFormula.lean)
does not require its witness vectors to have exactly `N+1` entries; the trace
comparison must use their defined `nth` values as stated, rather than silently
assuming normalized lengths. This argument would establish only the
literal-to-source part of the missing reverse direction. It does not extract
a calculus proof from a source halt or translate one into a PA refutation.
