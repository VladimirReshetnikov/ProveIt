# PA194 equality axiom sequents

`finiteEqAxiomCode` is a chosen finite, model-valued source-code predicate listing the quotes of the five equality axioms in the function-free relational source language (reflexivity, symmetry, transitivity, and relation extensionality for equality and membership). `finiteEqAxiomCode_definable` proves it is Σ₁; `finiteEqAxiomCode_standard` proves that, on the quote of every standard typed source sentence, it agrees exactly with Foundation's `Theory.eqAxiom`.

`finiteEqAxiom_sseq` handles every model-valued source code p satisfying this finite predicate, and every possibly nonstandard internal finite source set containing p: its numerical target sequent of negated translations proves contradiction code 1 when `base+p ≤ reserve`. This connects all five previously checked target suppliers to the concrete nonstandard-sequent layer. `standardEqAxiom_sseq` gives the corresponding statement for an actual standard typed Foundation equality axiom. The finite code predicate is a newly selected presentation: no equality with a pre-existing internal coded source-theory or proof-axiom predicate is claimed. Nor are other axiom schemes, source proof-rule simulations, a uniform proof-code supplier, derivation induction, or a consistency implication proved. The retained-overlay checker recompiles local sources, including upstream sequent modules, and audits eight reports; it is not an empty-overlay build.
