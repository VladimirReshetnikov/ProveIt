# Contextual ordinal-base proof shift

In every PRA model with IΣ₁ arithmetic reduct and any internal theory, a contextual derivation of the ordinal-base formula for an arbitrary internal property shifts to a derivation of the shifted property's base in the shifted context. The exact proof value is the existing `contextShiftCode`, whose fixed Σ₁ graph has already been checked. The original base derivation is an explicit premise.

This does not itself derive the base, complete ordinal induction, or prove the iPRA machine equivalence. The checker recompiles the source with selected byte-checked repository-built dependencies; other imports are prebuilt. Run from the repository root:

```
Computability/BusyBeaver/Research/PA/pa194-work/pa194-model-axioms/check-contextual-base-shift.sh "$PWD" /dev/shm/pa194-contextual-base-shift-repo
```

Choose a fresh output for another run.
