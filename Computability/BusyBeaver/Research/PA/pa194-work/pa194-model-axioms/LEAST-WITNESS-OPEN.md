# Least witness opening and elimination

Opening the witness produces the leastness formula at free index 0, with the trace-set index shifted by one; a second theorem aligns it with the ternary least template at any dummy index. Given a least-existence derivation and a branch derivation under that opened witness, the contextual existential eliminator constructs the result, and its exact proof code has a fixed Σ₁ graph for arbitrary model-valued indices.
