# Open a domain-successor witness

For every PRA model with IΣ₁ arithmetic reduct, the fixed domain-successor existence formula opens as an existential whose fresh witness is free index 0 and whose predecessor index is shifted by one. Its domain and successor conjuncts have explicit contextual projection proofs, exact proof-value theorems, and fixed Σ₁ graphs. Given an existential derivation and an appropriate shifted branch derivation, the existential eliminator has a fixed Σ₁ proof-code graph. All indices may be model-valued, including nonstandard ones.

Existence and branch derivations remain hypotheses. This does not yet assemble the outer induction contradiction or prove a native iPRA machine theorem. The checker recompiles the source with selected byte-checked repository-built dependencies; other imports are prebuilt. Run from the repository root:

