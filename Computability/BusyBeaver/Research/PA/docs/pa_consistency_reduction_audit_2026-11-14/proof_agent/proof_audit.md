# Proof audit and admissible AX transformations

Snapshot: `VladimirReshetnikov/ProveIt@906367250a7f96c923147b10df392294bced7be5`.
This note establishes a formula-family preservation theorem and audits proof
status. It does **not** establish a new literal-machine consistency biconditional.

## 1. What the imported PA196 result actually proves

The exact table is `Computability/BusyBeaver/Research/PA/jamesyc-upstream/pa196/data/pa196.tm`, SHA-256
`e8bbccd4cfa325251ca95066db116b5aa766e404b0971c33c02772be1c3617a8`.
Its working-state count is 196, with a separate halt label 196. If `H` is the
exact arithmetic halting sentence and `N=¬H`, the theorem
`PA196.Arithmetic.pa_proves_nonhalting_consistency` in `PA196/Independence.lean`
has type `M6.PA.theory ⊢ nonhaltingSentence 🡒 M6.PA.consistencySentence`.
It supplies **N → Con(PA)** internally. The same file proves two-sided
independence using that direction and standard-model facts. `PA196/Nonhalting.lean`
proves literal nonhalting externally in Lean. Neither fact supplies the reverse
PA implication `Con(PA) → N`.

The gap is already recognized, rather than new to this audit:
`PA/pa196-vs-u208/PA-BRIDGE.md`, `COMPARISON.md`, and the reverse-cert-stack notes
carefully separate the relevant obligations. In particular, a paper proof
using an external model of PA is not by itself a uniform PA proof that every
model-length native refutation yields an ordinary PA refutation.

Two precise sufficient bridges are:

1. PA proves that a coded literal blank-tape halting trace yields an accepted
   native certificate of formula code 1.
2. PA proves that every accepted native certificate of code 1 is transformed
   into a syntactic PA refutation.

The first requires reverse extraction through startup, total source and
command scheduling, positive nonhalting primitive segments, determinism, and
possibly nonstandard trace lengths. The second requires a uniform proof
compiler, not a uniform truth predicate. The direct bit-membership interpretation
already proposed in the incoming literature is appropriate: every native axiom
has a PA proof generated by a fixed template; the separation instance uses
full PA induction with the input formula substituted into a bounded bit-set
comprehension argument. But its exact coding, freshness, proof-stack handling,
and attachment to the literal machine remain explicit proof obligations.

A finite startup trace, all standard-Nat command lemmas, or testing many
source frames cannot be silently upgraded to either bridge.

## 2. A preservation theorem for independently reparameterized heads

Use the existing constructor codes I, M, U and E, including the transposed
quantifier U(d,h)=4 pair(h,d)+2. Write N(B)=I(B,1) and
Ex(d,B)=N(U(d,N(B))). In emission order, the six ordinary heads are:

1. Ex(D,U(D,H)) → H.
2. U(D,U(A,H)) → U(A,U(D,H)).
3. M(H,D) → (E(H,A) → M(A,D)).
4. E(H,D) → (M(A,H) → M(A,D)).
5. Ex(D,E(H,D)).
6. U(D,A) → (U(D,A→H) → U(D,H)).

The command's prefix saves the old top, emits a generalization, and emits the
restricted propositional head rho8. These are left unchanged.

**Theorem (independent head reparameterization).** For each i in {1,...,6},
choose an arbitrary permutation pi_i of the three register names {D,H,A}.
Replace head h_i(D,H,A) by h_i(pi_i(D,H,A)), and emit the six resulting heads
in any chosen order. The set of all available ordinary head instances is
unchanged. Consequently, with the same generalization rule, propositional
head, gate family and modus ponens, the native derivability relation is
unchanged.

**Proof.** For each fixed head i, pi_i is a bijection N^3→N^3. Thus the set
{h_i(pi_i(v)):v∈N^3} equals {h_i(v):v∈N^3}, using pi_i inverse for one inclusion.
This remains true when a head ignores one coordinate. The union over heads
therefore coincides exactly, as numerical formula codes. A derivation translates
by recursion on its tree: replace each head leaf by the inverse-parameter
instance, and leave MP, generalization, rho8 and gate leaves unchanged. The
inverse transformation uses pi_i. No semantic soundness or consistency
assumption enters this proof. Both translations are primitive recursive.

To justify that command parameters realize these families, invoke the existing
DISCARD interface, which leaves d=h=0. Then AX(c,x,y) has D=x, H=y, A=c, so
its parameter triple ranges over all N^3. To extract h_i(v) in the changed
machine, choose (x,y,c)=pi_i inverse(v), then use the existing head-selection
word with the new stack position of i. All six heads still have code 0 or at
least 2: the implication heads have residue 0 modulo 4 and the existential
head is an implication code. Thus the Shift-based selectors retain their
required nonhalting tests. The number of pushed values stays nine including
the saved top, so the same fixed-length stack interfaces remain available.
Only head positions and supplied triples change.

The literal numerical sequence of the emitter changes, so this theorem alone
is not a tape simulation proof. A new source trie and state allocation still
need exact source binding, startup and arbitrary-register primitive contracts.
It also does not fill the independent missing PA196 reverse bridge above.

## 3. Other admissible variants supplied by the emitter

`axiom_variants.py` reproduces the exact 201-token baseline emitter from
`PA196/Source/AXProgram.lean` and supplies a 64-element family. Its bits independently
perform the following changes:

- Swap the two curried antecedents in head 3, head 4, or head 6.
- Swap equality vacuity Delta and membership vacuity V in the outer gate.
- Swap the two conjuncts in the separation formula S.
- Replace M(H,D)→(A→M(A,D)) in S by A→(M(H,D)→M(A,D)).

Currying exchange is a theorem of implicational logic and is explicitly
available as `Dominated.exchange` in the imported development. These three
head changes therefore admit fixed derivation templates in both directions.
The gate is F=N(Delta→(V→Q)), propositionally Delta ∧ V ∧ ¬Q. The Delta/V
swap preserves it. The S changes are pointwise propositional equivalences;
generalization and the retained quantifier-distribution head lift them under
U. The remaining implication and negation contexts preserve equivalence.
The existing original h1 family is retained, so the existing derivations of
explosion and double-negation elimination remain available. Reparameterizing
h1 does not affect that availability, because its full instance set remains
identical.

The API also permits reversing D and H **throughout the gate only**. This is
an exact reparameterization of its two object-label arguments, while the
property code A is unchanged. Its guard A≠D and A≠H is symmetric. It is not
safe to permute A with an object-label register while leaving the guard and
freshness proof unchanged: A doubles as the property's formula code and its
fresh binder. No such transformation is enabled.

The source-trie search may independently permute the six heads and the
parameters of each. This is a substantially larger finite design family than
binary reassociation of one fixed token word. Its extensional preservation
proof does not assert that a particular optimizer will save a physical state.

### Excluded h1 contrapositive

An initially considered option would replace Ex(D,U(D,H))→H by
N(H)→U(D,N(U(D,H))). Do **not** use it as an established transformation.
The existing calculus derives explosion from h1 itself (`Context.explosion`
in `PA196/Logic/Deduction.lean`). Recovering h1 from this negation-based
contrapositive would appeal to that same explosion/double-negation machinery,
which would be circular. Before establishing explosion, code 1 is an arbitrary
formula code in the implicational calculus, not a built-in logical constant.
For example, treating U as identity and code 1 as an arbitrary proposition b,
the proposed new schema collapses to (H→b)→(H→b), whereas the old one becomes
((H→b)→b)→H; they differ when b is true and H is false. This is an obstruction
to the proposed propositional justification, not a full countermodel to every
other axiom. The emitter rejects this option explicitly.

## 4. Transfer from ZFC and ConciseIPRA

The accepted ZFC K215 material contributes useful compiler methods: closed
source reassociation preserving both successor graphs; context-sensitive
state allocation; arbitrary-value symbolic primitive proofs; and positive
simulation durations. Its calibrated theorem concerns Con(ZFC), not Con(PA).
Its proof strength cannot be changed by relabeling states or importing its
formal endpoint. The `k215-residual-parameter` experiment is a concrete warning:
removing an MP numeric parameter produced smaller source descriptions but
larger conservative physical allocations (234 or more), with no state saving.

ConciseIPRA contributes primitive-recursive representations and disciplined
classical-to-intuitionistic transfer. The specific bridge files under
`PA/pa196-vs-u208/ipra` are explicit about their limitations:
`PA196Bounded.lean` binds bounded simulation in standard-Nat semantics;
`PA196Endpoint.lean` assumes the two machine-specific reductions;
`PA196ForwardGG.lean` and `PA196ReverseGG.lean` assume appropriate classical
PRA derivations and, in the latter case, a bounded-witness certificate.
They do not prove the requested PA consistency biconditional or give a smaller
binary machine. A compact iPRA checker is not automatically a checker for full
PA, and Python byte count is not a binary-TM state count.

## 5. Scanner195: interpretation of the failed certificate

The shortened-scanner table has 195 states, but is not established as a
consistency machine. The archived arbitrary-frame checker reports 96 failed
contracts out of 4,780. The first strengthened affine check at site 0 still
fails because a required positive run may be empty. Such a failure invalidates
that submitted symbolic certificate; it is not itself a proof that the
blank-run consistency statement is false.

A further caution emerged in this audit: the **first** return to dispatcher
84 is not necessarily the completion of a source primitive. The parent itself
can return several times before its contract endpoint. Independently simulating
its source from site 25 and registers [2,0,...,0] reaches site 0 after 43 steps,
with registers [3,0,0,0,0,0,1,0,1]. For the corresponding admissible gap-57
frame, the 196-state parent returns to the root after 134 and 290 steps with
intermediate tapes, and reaches the required site-4 frame after 574 steps.
Therefore a first-return mismatch cannot alone refute the intended multi-pass
contract. `scanner_source_witness.py` records this check and the shortened
candidate's differing finite prefix. It makes no later-rejoining or blank-run
claim.

An independent exact-configuration cycle probe of the shortened candidate's
blank run reached 10,000,000 transitions without detecting a halt or sampled
exact cycle; at the cap it was in native state 0, head 18,796, with 4,688 one
cells and 64,774 dispatcher visits. This is only bounded evidence. It neither
certifies nonhalting nor restores the consistency equivalence.
