\section{Result and exact conventions}

The requested primary objective was a binary blank-tape PA consistency
machine with fewer than 194 working states. The present investigation did
not achieve it. It gives the expressly permitted alternative: two complete,
materially different 194-state constructions with a new combined command
architecture, together with all literal data and the proof dependencies.

Each machine has one head, a two-way infinite tape with alphabet
$\{0,1\}$, blank symbol zero, initial head coordinate zero, working
controls $0,\ldots,193$, initial control zero, and separate terminal label
194. Every transition writes one bit and moves exactly one cell left or
right. The halt label has no outgoing transitions and is excluded from the
194-state count. There is no prewritten tape or external initialization.
All 194 working controls are reachable in the transition graph.

\input{results_table.tex}

The exact dense tables are in \file{machines/PA194AX11GH/machine.tm} and
\file{machines/PA194AX11GHS/machine.tm}. A row is
\begin{center}\ttfamily state\quad read\quad write\quad L\_or\_R\quad next\end{center}
The native versions retain the inherited compiler labels, with initial
control 74, source-boundary control 84, and halt label 254. The two
\file{labels.json} files give complete dense/native conjugacies.
Appendix~\ref{app:tables} prints both complete dense tables.

\paragraph{What is materially different.}
The common source uses all of the following together: an AX command with
four explicit operands and eleven saved entries; an explicit first AX
operand as the binder of the saved generalization; the exchanged sixth
distribution head; no-push modus ponens; and a Shift that halts exactly
when its cache is code one. The first AX operand changes the formula
actually generated, the fourth is consumed by the interpreter, and the
Shift change changes both halting behavior and proof compilation.
These affect recurring execution, not only initialization or state names.

AX11G already has the first four ingredients but retains the sum-one
Shift test. GH and GHS have the explicit generalization and cache-only
guard but retain the older AX protocol. AX11H/QAX11H have the eleven-entry
protocol and cache-only guard but use the offset as the saved binder.
The new pair combines these interfaces. GHS additionally realizes the
same abstract guard through a different primitive comparison and an
extra context fold. Its 154-step startup saving is an initialization
measurement, not a uniform speed theorem.

\subsection{Exact structural novelty}

For each complete table, the checker considers every control from which
the full working graph is reachable. From each such root it forms the
complete breadth-first transition tuple, visiting read zero before read
one. Minimizing those tuples removes arbitrary state names and arbitrary
choice of a spanning root. Equality is checked on full tuples, not only
hash digests. The broader screen additionally permits left/right
reflection, global bit exchange, and ignored final write/move decorations
on transitions entering halt. Bit exchange is deliberately a structural
test; it is not assumed to preserve an all-zero blank tape.

Both new graphs differ from all 110 previous classes under that stronger
comparison, and from one another. All 110 historical 194-state graphs and
both new graphs also retain 194 classes under ordinary immediate-action
control bisimulation. That excludes only simple control quotients, not
context-dependent reductions. No worldwide priority or optimality claim
is made.

\section{The literal-tape proof and its arithmetic scope}
\label{sec:physical}

The independent literal checker imports neither the constructor nor the
constructor's arithmetic-box oracle. It derives four generic unary-list
sweeps directly from each literal transition table, using an arbitrary
natural block value and arbitrary surrounding contexts. Its full frame
has a complete zero exterior, a left marker, an instruction address, an
affine nonnegative header gap, all nine arbitrary natural register values,
an arbitrary first spare value, and an arbitrary finite remaining spare
list. Both branches of every decrement are checked.

The source-boundary frame has the shape
\[
  0^\omega\,1\,p\,0^{48+n-|p|}\,1\,B(v_0)\cdots B(v_8)
       B(a_0)\cdots B(a_k)\,0^\omega,
  \qquad B(v)=0\,1^{v+1},\quad k\ge0.
\]
The physical register permutation is
$(6,2,0,4,3,7,8,5,1)$ for logical registers
$(N,T,W,A,D,H,X,Y,L)$. The literal interpreter returns at native control
84. Startup reaches logical seed $(2,0,\ldots,0)$ at source site 25, head
$-2$, gap parameter zero, and 26 one-valued spare blocks. The checker
compares the entire finite support of the blank run against this frame,
not just a window around the head.

Every symbolic certificate has an affine duration with thirteen slots:
constant, gap, nine primary values, first-spare value, and the width of
the \emph{same} remaining spare list used in the tape description.
The minimum constant is three and every coefficient is nonnegative.
The endpoint audit independently checks that every nonhalting successor
address, padded by zeros to the common header length, equals the address
of the resolved source successor. All nonhalting head displacement and
address-overflow terms are zero. The instruction tree has depth at most
48, so the frame is closed under every source step.

\begin{theorem}[Positive segment transport]
For either displayed machine $M$ and its displayed primitive source $R$,
the exact blank startup and the complete positive frame contracts prove
in iPRA that $\Halt(M)$ is equivalent to halting of $R$ from the stated
source seed.
\end{theorem}
\begin{proof}
Interpret a symbolic run length by primitive recursion. A one-block
traversal is proved by quantifier-free induction on its block value;
the corresponding list traversal uses quantifier-free induction on a
finite list code, keeping its concrete width tied to that list. Finite
literal transitions and run/list composition then prove each complete
contract as an equality of configuration codes. All intermediate controls
are nonterminal except for the explicitly halting source instruction.

Let $c_k$ be the iterated source configuration and let $d(c_k)\ge1$ be
the exact duration of its next nonhalting segment. Define
$T_0=B$ and $T_{k+1}=T_k+d(c_k)$, where $B$ is 57,922 or 57,768.
After a halt, use an absorbing halted configuration and a positive idle
clock in the arithmetical coding. Quantifier-free induction proves the
endpoint equality at every $T_k$ and the bounded no-halt assertion on
each open segment. A source halting witness $k$ produces a physical
witness by this primitive recursive cumulative clock. Conversely, for
a physical witness $t$, either a source halt occurs within the first
$t+1$ segments or all those positive segments are nonhalting and cover
the proposed physical time, which contradicts the witness. The bounded
case distinction and all finite conjunctions are primitive recursive
Boolean equations. This is constructive; no extraction of an unbounded
least halting time is used.
\end{proof}

The symbolic executor is executable evidence for this written induction,
not a proof-assistant kernel. Its rules and the arithmetic transport
argument are preserved in the supplied proof sources, including the
inherited detailed \file{physical_ipra_audit.tex} and
\file{ipra_simulation_theorem.tex}. Its exact finite instance is rechecked
for the two new tables. Counts of symbolic operations are checker costs,
not uniform physical running-time bounds.

\section{Exactly which consistency theorem is inherited}
\label{sec:calibration}

Let $P_Q$ be existence of a finite refutation in the exact
$\mathcal C_4^Q$ numerical calculus displayed above. The new command
compiler, source-template clocks, and literal-frame arguments establish
\[
 \ipra\vdash\Halt(\GH)\leftrightarrow P_Q,
 \qquad
 \ipra\vdash\Halt(\GHS)\leftrightarrow P_Q.
\]
The updated incoming QAX11H manuscript has the same $P_Q$ endpoint,
with its offset-binder compiler. Consequently the new result includes
\[
 \ipra\vdash \Halt(\GH)\leftrightarrow\Halt(\QH)
 \quad\text{and}\quad
 \ipra\vdash \Halt(\GHS)\leftrightarrow\Halt(\QH).
\]
The exact calibrated QAX11H dense table has SHA-256
\begin{quote}\small\ttfamily
\nolinkurl{19e215df20429fa6a35f0a99ba0dcfcb40893a6e4b9a4ae6e450b0225f110e50}.
\end{quote}

\begin{theorem}[Corollary using the inherited written calibration]
Composing the relative equivalences above with the updated incoming
QAX11H manuscript's written calibration gives, for each displayed $M$,
\[
                   \ipra\vdash\Con(\PA)\leftrightarrow\neg\Halt(M).
\]
Here $\Con(\PA)$ is the repository's pinned
\texttt{nativePAConsistency} sentence, the negation of
\texttt{nativePARefutation}, as identified by that manuscript.
\end{theorem}

The logical composition is immediate intuitionistically: provable
$A\leftrightarrow B$ gives provable $\neg A\leftrightarrow\neg B$.
The inherited calibration is a mathematical theorem dependency,
not an assumption that PA is actually consistent.

The dependence is substantial and should remain visible. The incoming
AX11H proof supplies a current-Foundation PA-to-PAeq adapter, term and
formula proof compilers, finite-demand trees replacing stronger
all-environment inductions, model-uniform $\mathrm I\Sigma_1$ reductions,
and the cited transfer to iPRA. Our targeted audit examined the critical
rank/dependency and bounded-invariant patterns and the physical/source
clock arguments. It did not independently rederive every local proof
constructor or compile a new end-to-end Lean theorem. All ten original
proof fragments, the calibrated table, source identity, original notices,
and an explicit audit note are included under \file{references/AX11H/}.
The report does not replace this dependency by successful finite tests.

A fresh full replay of that inherited packet checked all 1,186 manifest
entries and reproduced both parent tables and their literal contracts,
source bindings, physical frame audit, and finite proof-constructor
checks. Its retained receipts explicitly state that they are not a kernel
check or a computational verification of the uniform arithmetic proof.
The new pair separately passed the aggregate full replay described below.

The formal status in the repository's PA README and the newer incoming
written claim are therefore presented separately. The conclusion should
be read as a new checked relative construction with its \emph{explicitly
inherited written absolute calibration}. A reader who has not accepted
that manuscript can use the relative theorem without accepting the
absolute corollary.

The unsuccessful searches were directed at several different costs,

\subsection{Why the known 193-state runtime is insufficient}

The useful runtime identification merges native control 301 into 88 and
uses $88/0=0L51$, $51/0=0R122$. It can satisfy allocated-register runtime
contracts because the next bit is a one there. The blank initializer
encounters a zero at that location. The allocated-block premise is thus
unavailable at exactly the moment startup needs the old action.
Changing a start control or testing a few register values cannot bridge
this mismatch.

Fresh radius-ten, 80-step local synthesis considered 5,649,890 two-row
repairs of this identification and found eighteen local survivors.
Seven fail the source check. Eleven pass only the unchanged-box oracle
while changing an arithmetic-box row; such a pass is not accepted as
a proof of their changed block semantics. None reaches the required
blank-seeded frame. Nine runs have exact outward-ray certificates and
nine exit the stated finite search bound; the latter are not classified
as divergence proofs. A different 16/122 identification tested
4,791,766 specifications without a local survivor.

\subsection{Whole-source and new-graph searches}

A sound zero/positive abstract interpretation from the primary source
seed reaches 263,888 abstract configurations. Every pair of the nine
registers conflicts, excluding direct register aliasing in this particular
abstraction. It is not a proof against more sophisticated encodings.

For the new AX11GH graph, a complete source/startup context collection
contains 30,818 conservative radius-six windows, including 6,242
observations inside accelerated scans. Arithmetic-box states retain
broad all-tape contexts. Two distinct 180-step synthesis screens attempt
control merging with future joins and elimination of one control by
rewriting its incoming actions. Neither produces a candidate.

The new grammar searches permit both shared-subtree reassociation and
independent parameter permutations in the six unrestricted heads.
They correct macro word lengths for the two- and four-increment
terminals before using the head intervals. One search uses the GH fixed
part; the other uses the fixed part after the verified symmetric fold.
Both price 134 effective fixed controls and seek an effective reader
score at most 59. They remain at best score 60, corresponding to 194.
Structural penalties are search guidance, and any hit would still require
full source, simultaneous-fold, startup, and logical checking.

\section{Ideas from the other requested programs}

The ZFC K216 partial-provider selector construction is useful because a
history fold may constrain only the branches actually used by a particular
two-cell context. Its other branches can remain available to the decoder.
That is a genuine search direction for a larger PA reparse, but it does
not supply a ready-made state saving without new incoming-context and
endpoint proofs \cite{zfc216}. Some K215 mechanisms, including the
69/400 predecessor marker and the $81/0=0L111$ repair, already occur in
the PA table \cite{zfc215}. They cannot be counted twice.

A literal transplantation of the documented ZFC marker-relay recipe
into the new GH table fails source ordinal two and reaches native state
35 at head coordinate 19 after 117 blank transitions. Its entire one-set
is then $\{-3,1,11,12\}$. Since $35/0=1R35$, every subsequent step
writes one and moves farther into untouched zeros. This is a finite
certificate of an infinite outward ray. Protected tails or zero-spare
logical seed theorems do not repair a physical machine that never reaches
such a seed. \file{research/physical/ZFC_TRANSFER.md} gives the inspected
paths and the exact transferred rows.

\section{Further research questions}

\begin{enumerate}
\item Can a 193-control runtime initialize a different but fully justified
source frame? The most concrete obstacle is the unallocated-block case
at native state 51. A successful repair must prove its literal blank
trajectory and the changed block theorem together.
\item Can a larger decoder reparse expose a partial provider in the K216
sense, producing reader score 59 while retaining all structured jump
targets? The present grammar searches do not exhaust such reparses.
\item Can a weaker reachable-register invariant justify sharing that the
all-register frame contracts intentionally forbid? Any proposed saving
must also establish that invariant in iPRA from blank startup, including
nonstandard iteration lengths.
\item Can the guarded finite-set head be shortened without losing the
atomic-vacuity and equality arguments needed for PA calibration? Deleting
a long subformula on syntactic grounds is inadequate; the necessary
derived schema or a countermodel should be supplied first.
\item Can the incoming finite-demand PA compiler and the new clock
transport be packaged as small reusable Lean theorems? This would let
future source architectures reuse the difficult calibration while
checking only their exact finite interfaces.
\end{enumerate}
