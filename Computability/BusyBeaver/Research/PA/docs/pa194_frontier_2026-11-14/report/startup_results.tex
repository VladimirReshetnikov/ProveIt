The fixed-start extension of the original input screened 106,694 quadruples,
with 119,534 runs including preparatory cases and 10,827,753,922 literal
transitions. It found no nominated frame; 54,362 runs reached a finite
limit. The append-zero variant screened 103,375 quadruples, with 115,953
runs and 9,589,305,357 transitions, again with no frame. These first two
extensions retain the inherited detector's permissive minimum gap 36 and
its original minimum-one-count filter. Their quadruple phases fix start 74;
the baseline and single-edit preparations also inspect all 193 starts.

A further correction and reduction make the all-start screen more useful.
Before the first written one, a blank run either stays zero forever or
reaches a control that writes one on zero. Starting directly at that control
has the same subsequent computation, up to translation. The original core
has eight such controls; the entire edit pool adds just control 302. Thus
nine starts cover every possible blank start in this fixed edit family.
The detector's preliminary filter was also lowered from thirteen ones to
twelve: a minimal source-site-zero frame has exactly twelve ones and was
incorrectly excluded by the old filter. A dedicated twelve-one positive
control confirms the repair.

The corrected nine-start experiment at 200,000 steps screened 226,546
quadruple/start cases and 248,457 runs including its preparatory cases,
executing 25,275,985,412 literal transitions. It found no complete nominated
frame. There were 121,405 certified rays, five finite halts, and 127,047
finite-limit exits. The last group remains unresolved. The nomination
detector inspects configurations strictly before the 200,000-transition
limit. The nomination
detector uses the permissive gap bound 36; a hypothetical hit there would
still need a physical theorem for that gap and an adequate semantic store.
With the proved gap bound 48, a separate baseline control recovers the
entire accepted primary seed at exactly 58,154 steps. The production search
and its positive controls therefore have deliberately different purposes.
