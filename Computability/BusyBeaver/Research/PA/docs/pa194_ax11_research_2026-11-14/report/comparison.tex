\section{Comparison of the existing designs}
\label{sec:comparison}

\subsection{All deliveries and a fresh table census}

The audit covers all 61 filed PA research packets and all five current
incoming archives: 66 deliveries. All 62 top-level filed README files
were read (one packet has two), and the current incoming result statements
and relevant construction/rejection sections were inspected. Appendix
\ref{app:packets} gives the complete ledger. The fresh scanner verifies
10,165 tracked candidate files against their pinned Git blob identities,
inspects 12,415 file/member payloads, and traverses 19 distinct ZIP payloads
through 31 references. It recognizes 1,607 literal or explicit-JSON table
occurrences, 667 normalized table identities, and 563 complete one-halt
action-graph classes having a spanning root. Six normalized identities
without such a root are recorded separately. There are no scan errors.

The recognizer accepts complete five-column binary $L/R$ tables in
\file{.tm}, \file{.txt}, \file{.tsv}, and \file{.csv} files, and explicit
transition arrays, dictionaries and text encodings in JSON. It does not
execute arbitrary generators or extract tables printed only in prose or
TeX; source-only proposals are represented by the delivery ledger.
Thirty-five incidental one-state JSON fragments are excluded, while
explicit \file{.tm} diagnostic tables remain. These totals therefore
describe a reproducible table census, not every possible program implicit
in arbitrary source code, and not a count of PA-consistency theorems.

There are 76 prior 194-state graph classes. This exceeds the filed
catalogue's 49 because the current incoming material adds QH, 23 source-tree
rotations, two A/D-layout companions, and an exploratory N6 append-zero
patch. The 76 classes split as follows:

\subsection{Why the two existing 193-state objects fail the target}

The rejected coefficient-three design has a smaller verified physical
implementation, but its calculus is inconsistent. With unchanged heads,
\[
 I(a,b)=3p(a,b),\qquad E(a,b)=3p(a,b)+3,
 \qquad E(1,0)=6=I(0,1).
\]
The collision combines with the fifth logical head, restricted implication,
generalization and MP to derive code one. The supplied expanded certificate
contains 73,393 primitive proof steps. Later work extends the obstruction
to every constant nonnegative equality offset for its specified unchanged
head/rule family. It does not rule out all possible three-tag encodings.

The other object is the runtime193 marker fold \cite{runtime193}.
It identifies native 301 with 88 and replaces
$(88,0)$ by $(0,L,51)$ and $(51,0)$ by $(0,R,122)$.
All 4,780 source contracts pass. The changed marker action has a sound
two-step identity on unary-register frames, where the next cell is one.
During startup that next cell can instead be zero. The original blank
start reaches an outward ray. The packet rejects 1,158 elementary starts
and records a broader 65,041-simulation neutral-edit screen with no complete
source frame. This is a valuable runtime reduction, but not a calibrated
blank-start machine. Our additional multi-edit work is recorded below.

The incoming direct-selector study also gives an exact rational-dual
obstruction for disjoint reader folds on one fixed raw 201-state parent:
at most seven net controls can be saved in that specified family.
Changed grammars, helper-to-helper jumps, overlapping folds and longer
detours are outside the result. Neither it nor any bounded search supplies
a 194-state lower bound.

\subsection{Material novelty of the two delivered machines}

PA194AX11 retains the ordinary coefficient-four logical heads and places
the final guarded head on the proof stack. Its AX command acquires an
additional numerical field when it falls through the existing MP tail;
the exact four-field protocol and new selectors are proved below.
An earlier eleven-head experiment instead changed the logical basis to
Brouwer plus explosion, scored 199 states at source level, and supplied no
complete physical or all-store proof compiler. The earlier split-gate
proposals also differ from the new unchanged-head protocol.

PA194QH5 combines Q, visible no-push MP, cached-only Shift and coefficient
five. It is a new composition of existing ideas. Its global arithmetic
change is distinct from merely changing a start or state numbering.

Both new complete tables were compared against all 76 prior 194-state
classes, allowing arbitrary control renaming, any spanning root, global
tape reflection, global bit exchange, and arbitrary final write/move into
halt. Exact canonical tuples match none; the new tables also differ from
each other. Hashes serve only as identifiers. A positive control checks
that a deliberately renamed, reflected and complemented baseline is
recognized as the same graph. This is a strong finite structural novelty
check, separate from the consistency proofs.

\subsection{What transfers from ZFC and ConciseIPRA}

The ZFC work contributes contextual state folds, protected tails,
all-store scheduler reasoning and positive source-simulation contracts
\cite{zfc}. Its consistency predicate cannot replace $\operatorname{Con}(\mathrm{PA})$.
ConciseIPRA contributes a useful design principle: derive a smaller
operational interface by explicit proof translations \cite{ipra}.
Replacing PA proof search by an iPRA checker would lose the required
strength. Here the simplified interface is the axiom command; the
full PA-calibrated calculus is retained.
