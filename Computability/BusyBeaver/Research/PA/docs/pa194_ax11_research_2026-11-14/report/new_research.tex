\section{Fresh attempts below 194}
\label{sec:research}

The searches in this section did not produce an accepted 193-state machine.
Their executable inputs and logs are retained so that their actual scope
can be distinguished from a lower-bound claim.

\subsection{A new command word and reader search}

The AX11 discovery changes an operational interface instead of asking
another optimizer to revisit the identical source word. A subsequent
source-word-preserving reader-association search used the primary and
Q-head seeds, the existing scanner constraints and simultaneous fold
screen. It made 2,669,812 proposals and accepted 138,489 grammar moves
in a recorded 240.026-second run. The best effective reader count was
60, giving $134+60=194$. No 193-state nomination was produced.
The frozen successful AX11 construction does not depend on repeating
this time-limited search.

A separate scanner-shortening investigation preserved all 3,673 old
resolved instructions after an outer reassociation, and reduced the
minimum all-zero source address from six bits to five. The direct 193-state
patch nevertheless failed 52 arbitrary-register physical outcomes.
Local dispatch repairs could fix the fixed-pop cases only at the cost of
breaking AX outcomes. The research therefore records a failed physical
alignment, not an accepted source-to-tape theorem.

\subsection{Two- and three-edit startup screens for runtime193}

The incoming runtime193 table has a valid source-step interface but bad
blank initialization. Its corrected finite-context envelope supplies
327 outside-arithmetic-box candidate row rewrites \cite{runtime193}.
We screened coordinated pairs and triples from this fixed pool. The
pool is a source-context screening result: final universal neutrality of
an arbitrary combination was not assumed. A successful startup would
still have required complete source checking and calibration.

Every search starts on a wholly blank tape with one of the 193 existing
initial controls. Acceptance requires an exact canonical source frame
at a site from 25 through 44, allowing arbitrary values of all nine work
registers, arbitrary finite nonempty spare tail, arbitrary tape translation
and header padding at least 48. Thus the acceptance test is deliberately
broader than a proven calibrated seed. It compares the entire tape support.

Each literal execution is bounded by 200,000 transitions, support size
20,000 and head displacement 24,900. If an edit is never reached in the
corresponding unmodified or partially modified bounded run, it cannot
change that bounded prefix. This observation prunes redundant executions.
For triples, the first changed row must occur in the unmodified prefix,
the second in a one-edit prefix and the third in a two-edit prefix. Exact
set keys remove duplicate triple/start combinations.

The last run includes 3,187 preliminary unmodified/one-edit executions
and 562,445 literal executions in total. It performed 50,593,490,055
literal transitions. Five executions halted and 306,688 reached a
certified outward self-loop; 255,752 reached a search limit. A limit is
not a nontermination certificate. The experiment does not exclude later
successes, four or more edits, a different candidate pool, or coordinated
changes that are not individually neutral in the inherited envelope.

As an additional exact check, combining the AX11 two-row source change
with the 301-to-88 runtime fold still fails startup for all 193 possible
initial controls: two halt and 191 reach outward self-loops, with 1,587
literal transitions total and no timeouts. That table is retained only as
an explicitly rejected research input.

\subsection{Interpretation}

The best supported state count remains 194 in this work. The new AX11
protocol is a concrete different design at that count. Its extra field
and changed selectors are mathematical obligations of the construction;
the report proves them instead of treating two changed rows as sufficient
evidence. The unsuccessful searches identify specific remaining routes,
especially a different decoder allocation or a genuinely coordinated
startup repair. They do not establish optimality of 194.
