2. PA195 reconstruction and reproduction
----------------------------------------
PA195 has 3,700 source sites: 1,468 increment, 1,115 conditional decrement,
1,116 jump, and one halt. Its primitive branch count is 4,815. The longest
source address is 37 and longest consecutive zero run is six. The physical
allocation is 134 inherited controls + 68 new AX readers - 7 compatible
contextual folds = 195. This was an improvement in association and simultaneous
physical allocation, not a newly invented 191-token diagonal emitter.

I replayed the supplied independent checker against the exact extracted
archive. Its separate source resolver, dense/native conjugacy, graph closure,
and complete blank startup passed. The startup consists of exactly 58,154
literal transitions, ending at dense state 75, head -2, with 66 one cells,
the standard clean source seed, and the entire rest of the tape zero. Both
set-of-cells and zipper representations agreed. The 19,260 supplementary
finite concrete primitive tests also passed, consuming 8,234,830 literal
transitions (largest individual run 708). Their scope is finite regression;
the symbolic contracts and the inherited loop lemmas carry the universal
claim. See pa195_independent_replay.json.

This replay reuses the earlier independently structured checker. It is not a
claim that a new proof-assistant endpoint has been elaborated in this audit.

4. Logical audit of the PA195 baseline
--------------------------------------
The PA195 paper claims an ordinary mathematical proof of an internal PA
biconditional. Its new endpoint is not an already checked Lean/Rocq theorem.
The imported PA196 Lean declaration provides the internal direction
Nonhalt -> Con(PA); this is not itself the converse. The PA195 paper explicitly
supplies the converse by syntactic proof translation and proof annotations.

No mathematical gap was identified in the portions checked directly against
the inherited source definitions. The important distinctions and checks are:

* Diagonal vacuity uses B -> U(B,B), exploiting the strict inequality between
  every variable label in B and the code B. The two reverse membership
  interfaces can be recovered without assuming general equality vacuity.
  In the source file PA196/Logic/Reverse.lean, negativeSpecialization uses
  only direct membership rewriting, a mirrored equality witness, and
  membership-only vacuity. Its premises are available in the new calculus.
  Thus the revised proof does not secretly invoke the equality-vacuity
  premise it is replacing. Neighborhood binder transport uses the recovered
  membership interfaces and membership-only vacuity.

* The reverse interpretation into PA uses finite bit comprehension for an
  arbitrary formula. The formula code is substituted into a fixed induction
  proof template, and PA checks the generated proof syntactically. There is
  no use of uniform truth or soundness reflection for arbitrary PA formulas.
  In the gate, the coincident-label case a=b changes a bound atom into
  Bit(z,z); the written proof separately handles that case using a singleton
  set matrix. Treating x_a as fixed inside that binder would have been wrong.

* The semantic aliases I(0,0)=0 and pair(0,0)=0 are treated explicitly. The
  first is handled by a fixed truth equivalence; the second by the canonical
  finite Cantor-stack convention. Source false code 1 translates to
  Bit(x_0,x_0), whose negation PA proves even inside further quantifiers.

* The command invariant annotates both t and h and all live stack entries,
  because the original Shift halt test is t+h=1. MP, AX, zero-stack pop and
  failed matches preserve these annotations exactly. The scheduler carries
  its live store between words; the proof does not assume a reset.

* Finite physical halting is reflected using positive source-to-tape
  segments. Under consistency, iterate T+1 command boundaries to construct
  a physical run longer than any alleged T-step halt. This bounded coded
  iteration and deterministic trace comparison are provable in PA. Exact
  endpoint reachability cannot pass through an earlier partial halt.

The useful source anchors are the PA195 report's pa_calibration.tex, its
runtime_review.txt and check_engine.py, and upstream PA196/Logic/Reverse.lean,
PA196/Commands/Store.lean, PA196/Source/CommandTransfer.lean,
PA196/Source/Nonhalting.lean, and M6/Runtime.lean. Those sources still require
the ordinary mathematical composition and arithmetic induction described
in the paper; the executable tests should not be called a full kernel proof.

5. Simplest proof route for a new purely physical reduction
----------------------------------------------------------
If the new machine changes only the physical implementation and has an exact
PA-provable positive simulation of PA195, the new consistency theorem should
be obtained by composition. It need not repeat or alter the proof calculus.

Let q -> f(q) map old working states to new working states, map halt to halt,
and preserve the designated start and tape. Suppose a PA-provable invariant
contains the old start and is preserved by all old transitions. For every
old step from that invariant, a fixed finite rule supplies one or more new
steps to the exact mapped next configuration, including the complete tape
and head. Assume the local traces are genuinely nonempty and their end
controls are ordinary whenever the parent end control is ordinary.

A parent halting trace translates by concatenation. Conversely, if the parent
has no halt, its first T+1 steps translate to more than T new steps for any T;
determinism therefore precludes a new halt by time T. These are primitive
recursive finite trace constructions and induction statements in PA. Thus
PA proves Halt(new) <-> Halt(PA195). Composing with the existing PA195 theorem
gives the required internal consistency biconditional.

For contextual reader folds, the invariant can often be certified by the
finite incoming-row census: each entry arrives from the left and writes the
specified predecessor bit, and the folded states are not initial. The local
proof enumerates the remaining read bits and checks full restoration of every
touched cell. Simultaneous folds must be checked in the fully patched table;
a matching of individually eligible pairs is not sufficient when a helper
is itself changed. This exact issue distinguishes PA195's compatible seven
folds from an earlier unsuccessful seven-edge matching.

6. Transferable ideas and limitations
--------------------------------------
The useful ZFC techniques are history-sensitive reader identification,
source association, register-engine reuse, arbitrary-counter block contracts,
and positive finite simulation. Their logical consistency calibration is
about a different theory and does not transfer merely by renaming the machine.

ConciseIPRA suggests deriving only the interfaces used by proof transport and
exploiting syntax to obtain freshness. Its checker-size objective is not a
binary-TM state bound. The finite-comprehension proof here uses induction for
an arbitrary formula; equiconsistency of iPRA cannot simply be substituted
for Con(PA). A genuine theory-level replacement would need fresh proofs of
both refutation translations and an actual smaller complete machine.

None of the current census or archived finite searches is a lower bound on
the number of states needed for the task.
