FRESH U208 COMPARISON

The nine designated final tables in five construction archives form exactly
two rooted, action-preserving graph-isomorphism classes. Class A has five
presentations and class B four. Every table has 208 working states, 416 rows,
and all 208 controls reachable in the transition graph. This does not assert
that every control occurs on the blank computation. The complete canonical
encodings and old-to-canonical state maps are retained, not merely hashes.

The main tables in ConPA, Conditional Context, Entry Context and History
belong to A. Their Compatibility alternatives and the research package's
main table belong to B. The research package's variant_plain belongs to A.
All use the same final identification of historical native roles 172 and 211;
the apparent separate one-state savings cannot be added.

An independent source resolver based on ordinal subtree intervals verifies
that A and B have identical ordered operation/argument sequences and identical
complete source control graphs: 3,909 leaves, 5,083 nonhalting edges, counts
CI 1,558, CD 1,175, CB 80, CC 1,095, CH 1. Their paths differ at 720 occurrences;
maximum lengths are 42 and 41, with maximum zero run 6 for both.

and 159 distinct internal nodes. The table combines 36 engine controls,

assert an ordinary-mathematical biconditional but disclaim a new end-to-end
exported proof-assistant or PA certificate. A changed table does not discharge
either machine refinement or the missing internal arithmetic direction.

names. Introduce the shared closed factor G=(node55,node65). Replace

  node75=((node32,(node53,node55)),node65)

and replace

  x37=(node55,(((node65,x27),x19),x35))
    by (G,((x27,x19),x35)).

including the occurrences of node75 inside x27. The flattened source still
has 3,812 leaves. The exact ordered instructions and every ordinal successor

identity. The number of distinct internal syntax nodes drops 159 to 158.
The first 50 source paths agree, including seed site 25 at 100000. There are
1050 changed paths overall; maximum path length is 37.

This simplified witness has maximum zero run 8, at source site 224, path

origin-scanner contract. The earlier randomized witness from which it was
simplified has a different shape and must not be assigned this same statistic.

There is a separate, concrete physical-sharing obstruction. Native state 69
represents both node20 and node72. Its read-zero action uses the old node75
as a free helper:

  69/0  = 0 L213
  213/0 = 0 R92       213/1 = 1 R90
  92/0  = 0 R104       90/0 = 0 R105.

The immediately preceding bit selects native 104 (node32) or native 105
(node17). After three transitions the tape is unchanged and the head is one
cell to the right of its position on entry to 69. Restructuring node75 removes
this free helper: its right child is now G, whose zero child is node55,
not node17. The whole changed source has no node H of the shape

  H=((node32,A),(node17,B)).

The apparent state estimate 195 silently retains the old alias saving at 69,
even though this particular supporting helper has disappeared. A valid
physical construction must repair that routing, retain its cost explicitly,
and handle the scanner before the source count can imply a TM state saving.
This is a precise obstruction to the attempted transfer, not an impossibility
proof for all 195-state machines or all other helper implementations.
