## Presentation and evidence differences

The Plain packet gives a 30-rotation construction from U212 and proves a useful
negative theorem: dropping the dominated propositional row makes the remaining
native calculus PA-provably consistent under a nonclassical Boolean-equality
valuation. The name "dominated" describes an enumeration parameter bound; it
does not assert logical redundancy. This is a serious obstruction to a naive
source-level reduction.

Compatible Folds gives a compact 720-primitive region retree after continuation
movement. Joint describes the entire 3,096-primitive closed region using 18
selectors and includes the complete nested calibration lineage. These deliver
the same machine, so their arguments complement each other without supplying
independent machines or independent logical foundations.

Composed derives the same source through 30 rotations and a five-state
permutation. It includes the recovered complete U222 calibration archive
explicitly; its primitive-runtime inference count equals the other class-A
packages because its table is a relabeling.

Compatibility makes the shared-helper argument most explicit. Its runtime
backward call through 129 reaches 158 and 204 on zero, so 204/1 can be repurposed
without breaking that call. This is a useful template for additional reductions
across source/runtime-shared states. Its 1,248,748 symbolic inference count is
slightly below class A's 1,250,049. These are checking-work counts, not running
times of the blank proof search, and depth 41 vs 42 does not prove a speedup.

All five quick replay commands passed independently in isolated copies. The
quick commands explicitly omit fresh universal primitive derivation. Fresh full
replays for Joint and Compatibility are run separately as one representative
per graph class; see `full_results.json` and their `_full.log` files for results.

## Audit of the unary theory

I inspected `unary_core.tex`, `unary_arithmetic.tex`, and `upper_transport.tex`
in the exact `pa_unary_power_cover` archive. I found no concrete mathematical
defect in the main interpretation chain. This is ordinary mathematical review,
not proof-assistant verification.

The theory uses equality-free classical first-order logic on a nonempty domain,
one binary relation, and the schema

    forall a exists b [forall x (x in b -> phi(x)) and
                       forall x (Sub(x,a) -> (phi(x) -> x in b))],

where `FV(phi)` is contained in `{x}`. This is a weak cover. Neither unrestricted
free matrix parameters nor exact filtering at arbitrary sources follow just by
definition.

The lower interpretation avoids circularity in the following order:

1. Define numerical representatives by saturation, transitivity, strict class
   order, and endpoints for existing intersections.
2. Derive local predecessor facts and induction before successor totality.
   If a failure cover intersects a number, its least class gives the usual
   contradiction; if it does not, the number itself is the least failure.
3. Internalize arbitrary induction parameters into a unary formula by universally
   quantifying the base-and-step hypothesis. The argument works even when the
   induction predicate distinguishes coextensional representatives.
4. Derive numerical comparison and least failed tuples, then bind the tuple
   inside a unary matrix to obtain bounded numerical comprehension under its
   explicit invariance and support hypotheses.
5. Obtain total successors and exact powers of numerical sources, saturated
   pair codes, graph comprehension, and deterministic histories. Graph objects
   are bound inside the canonical extension/restriction formulas; none leaks as
   a forbidden free unary-schema parameter.
6. Histories give total addition and multiplication; representative induction
   gives every translated PA induction axiom.

The upper interpretation uses binary bit membership in PA. Inclusion of one-bit
sets bounds the subset code by the source; PA induction builds a characteristic
code for each fixed translated formula. This works formula by formula in
nonstandard PA models and does not invoke a uniform truth predicate. The same
interpretation satisfies unrestricted weak cover and global irreflexivity.

The stated finite-proof translations use primitive recursive syntax operations
and fixed proof templates. This supports the conventional internal theorem
`PA proves Con(U) iff Con(PA)`. There is no delivered general proof-translator
implementation or new Lean/Rocq/MM0 certificate for that unbounded theorem.

## The actual machine/theory boundary

The machines execute the older numerical calculus D_U, calibrated to unrestricted
weak covering W plus global irreflexivity IR. They do not compile the separate
positive dyadic stream in the unary-theory archive. The calibration uses
PA-verifiable refutation maps along `Con(PA) -> Con(W+IR) -> Con(U) -> Con(PA)`.

The inherited obligations include small-code truth/falsity aliases, the gated
role-a cover/vacuity bundle and its source/output collision, the proof-description
compiler, fair search/cofinality, and the nine-head/two-debt protection above the
opaque startup tail 4. Literal primitive checks alone cannot discharge these
source/theory obligations. All new candidate claims must name this inheritance.

## Inspection of the symbolic-induction engine

I read Joint's complete `symbolic_runtime.py`, `check_runtime.py`, and
`independent_runtime.py`. No concrete unsound rule was found. The two-sided word
representation is oriented by the direction flag; changing direction puts the
written cell back on the old source side, and makes the previous destination side
the new current-cell side. This is consistent with literal left/right movement.

The engine has the following mathematical justification:

* A literal step requires a run length with constant term at least one, so it
  never guesses the first bit of a possibly empty unknown run.
* A self-loop that moves in the current direction consumes an arbitrary affine
  unary run in exactly its length, preserving the loop state. Its correctness
  is induction on that natural length, including zero.
* The four list-traversal lemmas are rederived from the exact transition table
  on a symbolic arbitrary block between opaque unread exteriors. Their duration
  and displacement are both checked as `v+2`. Finite-list induction composes them.
* The normalization identity `C(A) 1 = 1 B(A)` is valid for an empty list and
  follows for arbitrary finite lists from the one-block word identity.
  Reversal is handled explicitly. C and B blocks have the same length, so the
  single tail-width variable is preserved by every transformation used.
* Adjacent zero runs can be absorbed into an infinite blank exterior without
  changing the represented whole tape. Normalization preserves words.
* Each nonhalting primitive returns to the exact full-tape target key, not only
  register values. Expected address transformations and head displacement are
  checked separately. Halting primitives must reach the literal halt label.
* The returned duration has nonnegative affine coefficients and positive constant,
  so indefinitely composing source primitives cannot hide a zero-time loop.

The arbitrary tail-width variable ranges over a superset of actual finite-list
widths. This overapproximation is harmless here because all duration claims are
valid for every nonnegative width; it does not permit fictitious paths.

The legacy/native relabeling in `check_runtime.py` is checked injective and applied
to all transitions. Every source primitive and both decrement cases are freshly
derived; all 418 rows are covered. Coverage concerns canonical primitive frames,
not visits in the actual blank computation. Assertions are required and optimized
Python is rejected. The finite local checkers separately test `-O` behavior.

The engine is compact trusted Python plus mathematical induction. It is stronger
than a bounded simulation but is not a small-kernel exported formal proof. The
fixed-data hashes and expected inference count are integrity controls, not the
reason the inductive rules are valid.

## Consequences for the sub-209 search

Searching five tables duplicates work; search both graph classes once each.
Preserve all incoming edges, including backward arithmetic/helper calls, when
changing a shared decoder. Internal-prefix checks alone may accept source
associations with seven-zero runs, while the origin detector makes them invalid
as runtimes; use final complete primitive contracts and startup.

The existing fixed-table searches are bounded negative evidence only. Joint
reports 43,264 ordered alias candidates through 15 steps and 7,038 contextual
fold candidates without a new saving. This does not exclude source reassociation,
different contextual guards, coupled helper redesign, or other state reductions.

For a new table, state the new literal halting-preservation theorem first. Then
compose it with the retained calibration. Do not assert actual nonhalting without
Con(PA), a new kernel theorem, global minimality, or independent record priority.
