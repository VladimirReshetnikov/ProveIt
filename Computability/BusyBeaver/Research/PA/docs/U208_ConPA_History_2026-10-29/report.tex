\begin{abstract}
The five complete 209-state submissions in the requested ProveIt snapshot
represent two rooted transition-graph isomorphism classes, rather than five
different machine designs. All execute the same 3,909 primitive instructions
and the same 5,083 ordinal control edges. We compare their exact tables,
source arrangements, reconstruction methods, and proof boundaries.

The new construction deletes native state 211 by sharing native state 172.
Two entry invariants, established from complete predecessor histories of
length at most three, distinguish the required behaviors. The resulting
machine has \textbf{208 working states and 416 transitions}, including blank
initialization. Exactly three retained transition rows change, two rows are
deleted, and no source instruction or source address changes.

Four complete local cases prove halting equivalence with the supplied U209
parent on every common initial tape from state 0. Old steps expand to one,
three, or seven new steps. A separate fresh symbolic derivation verifies all
5,084 arbitrary-value primitive contracts and all 416 literal rows. The exact
48,140-step blank initialization is preserved. The same reduction applies
to all five proposals; a second, structurally distinct 208-state variant is
also supplied.

The new local preservation theorem is independent of the logical calibration.
The intended $\Con(\UU)$ and $\Con(\PA)$ endpoint composes it with the
retained conventional proof-search and interpretation arguments. This packet
does not provide a new end-to-end Lean, Rocq, MM0, or exported PA proof
certificate. It also preserves a concrete counterexample to a tempting
source-reassociation shortcut, so that the unsuccessful attempt is not
mistaken for a second valid reduction.
\end{abstract}

A row $q\ b\ w\ D\ r$ means: in state $q$, read $b$, write $w$,
move in direction $D$, and enter $r$. Entering the halt label terminates
after the write and move. The header \code{\#! start 0} is not a transition.

Native labels retain the historical names, with native halt 254. In particular,
\emph{delete native state 211} is a label-level instruction, not a state-count
claim. The exact bijection in \path{machine/state_map.json} converts native
labels to the dense table. Native 172 becomes dense 165.
All 208 working states are reachable in the transition graph from state 0.
This graph property does not assert that every state is visited on the blank run.

Let $M$ be the exact Plain U209 parent retained in
\path{inputs/u209.native.tm}, and let $N$ be the new U208.
The principal new theorem is
\[
 \Halt(M,T,0)\ \longleftrightarrow\ \Halt(N,T,0)
\]
for every common binary tape $T$, with a common initial head position.
The last argument indicates the initial state. Section~\ref{sec:proof}
proves this statement directly, using only the literal tables.

The arithmetic instance needed for the research goal is
\begin{equation}\label{eq:localPA}
 \PA\vdash
 \Halt(N,\mathrm{blank})\longleftrightarrow
 \Halt(M,\mathrm{blank}).
\end{equation}
The finite-history and bounded-block argument supplies an ordinary
PA-formalizable proof of this equivalence. Combining it with the retained
U209 calibration yields the intended endpoint
\begin{equation}\label{eq:consistency}
 \PA\vdash
 \neg\Halt(N,\mathrm{blank})\longleftrightarrow
 \Con(\UU)\longleftrightarrow\Con(\PA).
\end{equation}
The inherited dependencies and the evidence for each layer are identified
in Section~\ref{sec:calibration}. Equation~\eqref{eq:consistency} is not
presented as a newly checked proof-assistant declaration.

\subsection{How the constructions differ}
All five submissions combine earlier savings associated with native states
180, 181, and 218. Those earlier U211 savings could not simply be overlaid:
the shared helper states required different incoming tape conditions.
The U209 packets solve this compatibility problem with different
descriptions of source reassociation and helper allocation.

Plain and Composed expose a sequence of 30 closed source rotations.
Composed additionally presents a label permutation and is particularly
explicit about the complete logical ancestry retained from U222.
Joint organizes the main change as one reassociation of a 3,096-primitive
region using 18 internal selectors, followed by three smaller rotations.
Compatible Folds gives the same final source and literal machine as Joint.
These are useful differences in proof organization, but they are not
additional state-count improvements.

Compatibility yields the distinct class B. Its construction starts from
Research U211, passes through U210, and permits a shared backward helper
to retain its read-zero behavior while changing its read-one source-decoder
behavior. Its final $180$ fold uses native 216 as the representative,
where class A uses native 163. This creates a different decoder association
with maximum depth 41.

For subsequent work, class A is the larger consensus among the supplied
packets; Plain is a convenient exact parent for the three-row patch below.
Joint has a compact grouped builder, and Composed preserves a particularly
clear account of the recovered logical calibration. Compatibility deserves
separate analysis because it is a different machine, even though its
primitive program is identical. Neither the smaller depth nor the number
of symbolic inference steps establishes a faster complete proof search.

\section{The new construction: three changed rows}
\subsection{Literal recipe}
Define a state map on native labels by
\[
 \rho(211)=172,\qquad \rho(q)=q\quad(q\ne211).
\]
Starting from the exact Plain U209 table, redirect every target through
$\rho$, remove both rows of state 211, and set
\begin{equation}\label{eq:newrow}
                  N(172,0)=\act0L{214}.
\end{equation}
No other action is altered. Table~\ref{tab:patch} is the complete difference.

The retained row $172/1$ is $\act1R{184}$, equal to the deleted row
$211/1$. The difficulty is the two read-zero behaviors: one must move left
to 67, the other right to 157. Reading a short portion of the already
written tape distinguishes them without another state.

After deletion, sort the 208 remaining native working labels increasingly
and rename them $0,\ldots,207$; rename native halt 254 to 208.
The builder checks both directions of the resulting table correspondence.
The exact reconstruction uses no search, source optimizer, solver, or
external dependency.

\subsection{Why this differs from the previous reductions}
The new optimization does not reassociate the source, reassign a source
subtree, or modify the numerical proof calculus. Its required information
comes from the histories of entrances to existing states. In particular,
state 211 is entered both from the left and from the right; examining only
the direction and bit written by the immediate predecessor loses a useful
conditional invariant.

The discovery search enumerated finite predecessor histories, converted them
to disjunctions of known tape cells, and screened possible shared-state
dispatches. The delivered proof does not depend on the discovery search.
It reduces the successful result to the five explicit incoming inventories
and four explicit local cases below. Novelty is claimed relative to the
audited incoming packets, not as an independent historical priority claim.

\section{Complete preservation proof}\label{sec:proof}
\subsection{Two entry invariants of the old machine}
For a configuration with head at $h$, let $t(j)$ denote the tape bit at
offset $j$, that is, at coordinate $h+j$.
All inventories in this subsection refer to the \emph{old} machine $M$.
The full incoming-edge lists are:
\begin{center}\small
\begin{tabular}{@{}rl@{}}
\toprule
Target & All incoming transitions\\
\midrule
172 & $116/0\mapsto\act0R{172}$\\
116 & $216/1\mapsto\act1R{116}$\\
211 & $163/0\mapsto\act0L{211}$,\quad
       $163/1\mapsto\act1R{211}$\\
163 & $132/1\mapsto\act1R{163}$,\quad
       $199/1\mapsto\act1R{163}$,\quad
       $214/0\mapsto\act0R{163}$\\
214 & $204/1\mapsto\act1R{214}$\\
\bottomrule
\end{tabular}
\end{center}
None of these states is the initial state 0. Consequently, every visit on
a run starting at 0 has the necessary predecessor history, regardless
of the initial tape.

\begin{lemma}[Guard at old 172]\label{lem:172}
Every reachable old configuration in state 172 has
\[
                         t(-2)=1,\qquad t(-1)=0.
\]
\end{lemma}
\begin{proof}
The only entrance to 172 is $116/0$, which writes zero immediately left of
the new head. The only entrance to 116 is $216/1$, which writes one one cell
farther left. Both moves are rightward and neither step changes the other
cell. This establishes the two asserted bits.
\end{proof}

\begin{lemma}[Conditional guard at old 211]\label{lem:211}
Every reachable old configuration in state 211 scanning zero has
$t(-1)=1$.
\end{lemma}
\begin{proof}
If the last step was $163/1$, it wrote one and moved right, so the conclusion
is immediate.

Otherwise the last step was $163/0$, which wrote zero and moved left.
The scanned cell at old 211 is then the cell immediately left of the
previous head at 163. An entrance to 163 through $132/1$ or $199/1$ would
have written one in this cell, contradicting the present read-zero condition.
The entrance to 163 must therefore have been $214/0$, a right move after
writing zero. The only entrance to 214 is $204/1$, which wrote one in the
cell now immediately left of the head at 211. The intermediate two steps
do not change that cell. Hence $t(-1)=1$.
\end{proof}

The argument for Lemma~\ref{lem:211} uses at most three predecessor
transitions. The independent checker enumerates all such suffix histories
and all assignments to their touched cells; it does not sample a finite
prefix of the blank run. Unread exterior cells remain arbitrary.

\paragraph{Old 211, scanning zero.}
The known window is $t(-1)=1,t(0)=0$. Starting the new machine in the

The three steps read $0,1,0$, respectively. Each writes the bit it reads.
The old single step $211/0\mapsto\act0R{157}$ has exactly this final

\subsection{Global simulation and its converse}
\begin{theorem}[All-common-tapes preservation]\label{thm:global}
For every binary tape and common initial head position, the runs of $M$ and
$N$ from state 0 halt together. At aligned macro boundaries, their tapes
and heads are equal and their states are related by $\rho$.
\end{theorem}
\begin{proof}
The initial configurations satisfy the relation because $\rho(0)=0$.
Suppose the relation holds at an old-step boundary. If the old state is
neither 172 nor 211, the corresponding new transition is exactly its
quotient under $\rho$. All 414 such old rows are checked literally.
If the old state is 172 or 211, the relevant guard follows from
Lemmas~\ref{lem:172}--\ref{lem:211}, and one of the four proved macros
restores the relation. Every macro takes a positive number of steps, at most
seven, and none halts internally.

Induction therefore constructs an aligned new execution for every finite
old execution. If the old execution halts, its aligned new execution halts.
If the old execution is infinite, positive macro lengths produce infinitely
many new steps, none with an internal halt. Determinism makes this constructed
execution the unique new execution. The new machine therefore cannot halt
when the old machine does not. This proves both implications.
\end{proof}

The guards concern old boundary configurations. They need not hold at every
intermediate new configuration, and the argument does not assume that they do.
This distinction is essential because the seven-step case passes through
the representative state at an intermediate head position.

\begin{corollary}[Exact time accounting]\label{cor:time}
For any aligned finite prefix, let $n_{172,0}$ and $n_{211,0}$ count old
steps using the two zero rows. Then
\[
 T_N=T_M+6n_{172,0}+2n_{211,0},
 \qquad T_M\le T_N\le7T_M.
\]
The same identity holds for a halting run.
\end{corollary}
This comparison is directly with the supplied Plain U209 table. Unlike the
earlier source-reassociation constructions, the new reduction changes no
addresses, so no separate source-layout stage lies outside the time bound.
It is a reduction of finite-control size, not a claimed speedup.

\subsection{Arithmetization}
For the blank-input theorem, configurations and finite runs have ordinary
number codes. The two entry guards are finite predecessor facts; the four
macros are literal constant-size computations. PA can prove the simulation
by induction on the coded old run length, defining the aligned new length
$\tau(n)$ with
\[
                     n\le\tau(n)\le7n.
\]
The converse can also be expressed entirely with finite prefixes: if the
new machine halted after $s$ steps but the old machine had not halted in its
first $s$ steps, the constructed old-prefix simulation would extend the new
run for at least $s$ steps without a halt, a contradiction. No appeal to
actual consistency or to a soundness principle is required.

The external theorem allows arbitrary binary tapes as functions on the
integers. The internal PA statement quantifies coded finite input data and
finite computation histories, including the blank instance. It does not
introduce second-order quantification over arbitrary tape functions into PA.
The packet supplies the finite certificates and the mathematical induction,
not an exported derivation in a PA proof language.

\section{The inherited logical endpoint}\label{sec:calibration}
\subsection{The specified unary theory}
The supplied unary-power-cover report~\cite{unary} defines $\UU$ in
equality-free classical first-order logic over a nonempty domain, with one
binary relation written $\in$. Define
\[
 x\subseteq a\quad:\Longleftrightarrow\quad
 \forall t\,(t\in x\longrightarrow t\in a).
\]
For every formula $\varphi(x)$ with no free variable other than $x$, the
single axiom schema is
\[
 \forall a\,\exists b\,
 \left[
   \forall x\,(x\in b\longrightarrow\varphi(x))
   \ \land\
   \forall x\,(x\subseteq a\longrightarrow
                         (\varphi(x)\longrightarrow x\in b))
 \right].
\]
The source variable $a$ is not a free matrix parameter. Arbitrarily many
bound variables are allowed; this is not one-variable first-order logic.
The assertion is weak covering, rather than an exact power filter for
arbitrary sources.

The supplied paper gives conventional mutual interpretations and
formula-specific finite-proof translations establishing the PA-provable
equiconsistency of $\UU$ and PA. Its lower interpretation first derives
representative induction, before successor totality. It then develops
comparison, least failed numerical tuples, bounded numerical comprehension,
successor constructions, numerical powers, saturated graph codes, and
canonical finite histories. This order addresses the possible circularity
in using finite constructions to obtain induction.

Its upper interpretation uses binary bit membership on natural numbers.
PA proves the required finite comprehension one matrix at a time. This
does not require a uniform truth predicate for all arithmetic formulas.
Our independent reading found no concrete circularity or illicit free
matrix parameter in the examined arguments. The present work does not
implement or verify a general arbitrary-PA-proof translator.

\subsection{What the literal machine actually searches}
The native numerical calculus is calibrated to unrestricted weak covering
$\WW$, which allows additional matrix parameters, together with
irreflexivity $\IR$. It is not the separate positive dyadic theorem stream
described in the unary archive. Unary $\UU$ embeds into $\WW+\IR$, while
the bit-membership interpretation in PA handles unrestricted matrices and
proves irreflexivity. Combined with the lower interpretation into $\UU$,
the retained finite-refutation translations connect all three consistency
statements.

The inherited numerical presentation uses dual Cantor pairing, low-code
truth/falsity aliases, seven logical rows, a dominated propositional row,
modus ponens, generalization, and a gated covering/vacuity bundle.
The code-zero correction, freshness conditions, exceptional variable-role
cases, and proof enumeration are substantive parts of the original
calibration. They have not been simplified away by the new state fold.
The full Plain parent packet, including its nested dependencies and
attribution, is retained unchanged in \path{reference/}.

Thus the logical chain for the new table is:
\begin{enumerate}
\item the exact new fold preserves blank halting of the supplied U209;
\item the supplied U209 program searches the retained numerical
refutation calculus with its protected initialization and fair enumeration;
\item that calculus is calibrated to unrestricted covering plus
irreflexivity;
\item the retained finite-proof translations identify its consistency
with $\Con(\UU)$ and $\Con(\PA)$ inside PA.
\end{enumerate}
Only the first link is newly proved by the finite-history argument.
The fresh primitive runtime and startup checks strengthen the executable
connection, but do not replace the other logical links.

\section{A rejected source compression, with a counterexample}
An additional source search found two appealing closed reassociations:
\[
 ((98,12),150)\longmapsto(98,(12,150)),\qquad
 ((166,12),150)\longmapsto(166,(12,150)).
\]
In native decoder labels, these act at roots 155 and 52. After updating all
five occurrences of the first source subtree and all three occurrences of
the second, states 85 and 154 acquire identical rows with children
$(12,150)$. Removing 154 then yields another syntactically complete
208-state table.

The entire 3,909-instruction word and all 5,083 source control edges remain
unchanged. The final equal-row merge is sound for the already modified
table. Nevertheless, the preceding reassociation is invalid as a
source-to-runtime transformation, because these physical decoder states
also serve the arithmetic engine. The original zero-decrement path includes
\[
 152/0\longrightarrow159/1\longrightarrow118/0
 \longrightarrow155/0\longrightarrow85/0\longrightarrow98/0.
\]
The altered association changes which tape cells this runtime path reads.
Pure read-preserving right-moving rows and a closed source factor do not
by themselves establish that a decoder fragment is used only for decoding.

The failure has an independent finite witness. Start at native state 84,
head 0, source ordinal 25 (\code{CD 1}), with all nine registers zero,
gap zero, and spare list $[0]$. The one-cells are exactly
\[
           \{-1,2,3,6,56,58,60,62,64,66,68,70,72,74,76\}.
\]
All other cells are zero. The correct successor is ordinal 28.

\subsection{What remains open}
The bounded discovery searches are incomplete. Additional alias and
contextual-fold searches on the new U208 did not produce another accepted
reduction, and the investigated source shortcut failed. Neither result
is a lower bound or a proof that 208 is optimal.

the exact new local theorem, followed by the complete U-machine calibration.

are five finite incoming inventories, four constant-size macros, and a
bounded simulation induction. The more substantial remaining formal work

uniform finite-refutation translations for the U/PA interpretation.

uses before it is accepted. The delivered finite-history fold establishes the
requested strict improvement, with its proof and reproduction separated
from those future possibilities.
