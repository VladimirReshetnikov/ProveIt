# Additional finite grammar searches

These are finite heuristic searches for smaller machines, not state lower bounds. Every accepted hypothetical hit would still require complete construction, arithmetic-source binding, blank startup and literal physical validation. No such hit occurred in the recorded runs. The `best` score is AX reader controls minus the compatible reader folds found by the screen; add the stated fixed-control count to obtain its candidate size. This local folding screen is incomplete.

Three seed associations are supplied for each command word. Moves reassociate binary source trees and permute the three freely instantiated parameters within the six ordinary logical axiom heads. The guarded rho head, diagonal head, interface tail and fixed arithmetic engine are preserved. Fold compatibility is tested on all local history/bit cases in the screened family. The first QGD run seeks 194 or fewer; the two AX11GD runs seek 193 or fewer. Failed thresholds and later full physical verification are distinct claims.

The HS search first performs the independently checked fixed-core fold 41→331. Its four exact local cases are in `fixed_fold.json`; the input has 134 fixed controls after this fold. The published HS builder retains the more transparent 135 + 69 − 10 state budget.

Replay requires Python 3 and a C++17 compiler:

```sh
python3 -B check_templates.py
python3 -B run_search.py ax11gdh_600s --output replay_h
```

Select `qgd_240s` or `ax11gdhs_240s` for the other runs. A `--seconds` override permits a shorter investigation. The seed and trajectory are deterministic until the time cutoff; iteration totals depend on hardware and concurrent load. `receipt.json` records the actual completed runs. Saved best grammars, where present, are heuristic outputs, not newly certified consistency machines.

`search.cpp`, `screen.cpp` and `leaf_attrs.txt` derive from the pinned incoming GD packet. The QGD threshold is changed from 59 to 60; the template files carry the new source word and exact fixed core. See the main construction NOTICE and licenses for upstream attribution. The full fixed rows and tree DAGs are embedded in `templates.txt`, so rerunning the search needs no repository checkout or network access.
