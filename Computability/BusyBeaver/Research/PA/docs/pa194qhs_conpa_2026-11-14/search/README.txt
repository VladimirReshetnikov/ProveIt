-----------

Successful replay confirms these restricted computational results. It is
not a proof of consistency calibration or of a general state lower bound.

QHS PAIR SEARCH
---------------
The first screen uses a radius8 (17-cell) abstraction of blank-tape execution.
At each projected tape shift, the new boundary bit may be either0 or1. This
loses information and overapproximates the literal blank computation.
The second uses corrected radius6 symbolic source envelopes and the complete
57,768-step startup outside the arithmetic-box interface. Box controls keep
the original overapproximation. The complete source collector covers4750
instruction outcomes and interior positions of accelerated constant-symbol
self-loops. It yields30,294 source windows and30,358 windows after startup.

For every control/read pair, the solver enumerates first transition actions
with working-control destinations. It accepts an action only if the subsequent
bounded continuation, in the unchanged table, reproduces the old one-step
control, head position and whole window. Continuations may not leave the window
or pass through controls whose rows would change. A pair of controls can then
be merged only when each read bit has a common admissible action. All other
rows are fixed except redirection of the removed control's incoming targets.
The duration bound is300. No candidate pair is returned in either screen.

This excludes only candidates recognized by this sufficient local rule.
It omits direct first actions into halt and does not cover arbitrary two-row
synthesis, coupled pairs, representation changes, longer excursions, or other
source programs. Negative results are not minimality theorems.

RUNTIME193 TWO-EDIT SCREEN
-------------------------
The supplied incoming archive pa_sub194_research_2026-11-13.zip introduces
runtime193.native.tm: identify301 with88, then set88/0=0L51 and51/0=0R122.
It verifies source contracts but rejects its own blank startup. This file
is a rejected runtime core, not the positive construction in this package.

We take its corrected327 outside-box candidate row rewrites and combine
all52,128 pairs affecting distinct rows. For each resulting table, all193
possible initial working controls on blank tape are considered. Before the
first written1, the tape is blank. A repeated control therefore yields a
blank translational cycle, while a first written1 produces a one-bit tape
with the head one cell to its left or right. Normalizing translations and
coalescing identical resulting configurations avoids repeating equivalent
simulations. This reduction is exact before the first written1.

Every normalized run searches for a COMPLETE physical source frame at any
of source sites25..44, allowing arbitrary9 register values, padding>=48,
and any finite nonempty spare tail. This acceptance set is deliberately
broader than the semantically calibrated seeds. Both spare-appending choices
at198/0 were tested. No accepted physical frame occurred.

Append1:417,349 normalized runs;114,987,509 simulated transitions after
first1;104,255 halts;312,581 certified outward rays;513 bounded runs.
Append0:365,221 normalized runs;21,260,321 simulated transitions after
first1;156,383 halts;208,778 certified outward rays;60 bounded runs.

Each normalized run is limited to200,000 transitions, head displacement20,000,
and support size20,000. The573 bounded runs were not proved divergent.
Interactions between pairs of source-neutral rewrites were not assumed safe:
a discovered seed would still have required complete source verification.
No seed was discovered, so no paired table is promoted as a candidate.

The same runtime193 collapse transferred mechanically to38 current native
194 tables whose labels and affected rows match. All reach the same outward
ray at native control35 after92 transitions from start74. The exact prefix
failure alone rejects each transferred table; source equivalence is not asserted.
