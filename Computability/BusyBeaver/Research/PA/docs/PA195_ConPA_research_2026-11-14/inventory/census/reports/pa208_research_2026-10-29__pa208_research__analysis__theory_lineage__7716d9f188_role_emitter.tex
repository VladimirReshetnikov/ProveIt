\subsection{Soundness of every enabled instance}

Use the inherited normalized native decoder in the machine-facing
theory $W+\mathsf{IR}$, where $W$ permits arbitrary matrix parameters
in the weak power-cover schema and $\mathsf{IR}$ is global
irreflexivity. Write $\phi$ for the decoded formula of code $a$.
For $a>0$, every variable label occurring effectively in $\phi$ is
strictly below $a$. For $a=0$, $\phi$ is the fixed closed truth alias.
Thus the output variable $v_a$ is fresh in $\phi$ in every case.
The gate ensures $c\ne a,b$, so the tested variable is distinct from
both source and output.

If $a\ne b$, the guard $G$ decodes to
$\operatorname{Sub}(v_c,v_b)$, and $\neg H$ decodes to the ordinary
weak cover of $\phi$ at source $v_b$, with tested object $v_c$ and
fresh output $v_a$. Any occurrence of the source in $\phi$ is an
allowed matrix parameter of $W$. This argument also permits the tested
variable to be absent from $\phi$.

If $a=b$, the guard's local binder $a$ captures both occurrences of
the source/output label within the guard. It therefore decodes to
\[
 \forall v_a\,[E(v_a,v_c)\to E(v_a,v_a)],
\]
which is equivalent, under $\mathsf{IR}$, to
$\operatorname{Emp}(v_c)$. The desired shell is consequently
\[
 \exists v_a\,\forall v_c\,
 \bigl[(E(v_c,v_a)\to\phi)\land
       (\operatorname{Emp}(v_c)\to(\phi\to E(v_c,v_a)))\bigr].
\]
Theory $W$ first supplies an empty source using a false-matrix
instance. At this source $s$, $\operatorname{Sub}(x,s)$ is equivalent
to $\operatorname{Emp}(x)$. The $\phi$-cover at $s$ is exactly the
required shell. Fresh-bound-variable renaming keeps the auxiliary
source separate from the displayed variables. No extensionality,
unique empty object, or representation of tuples is used.

The two small matrix codes introduce no further exception. Code zero
is closed truth, giving an output containing every empty representative
when $a=b=0$. Code one is uniformly false under $\mathsf{IR}$, giving
an empty output. These are instances of the two arguments just given,
not assumptions that a small selector is fresh by size.

The unchanged gate makes $V$ a valid atomic membership-vacuity
instance. Classical currying makes $B^*$ equivalent to
$V\land\neg H$, so every enabled bundle is sound in $W+\mathsf{IR}$.
