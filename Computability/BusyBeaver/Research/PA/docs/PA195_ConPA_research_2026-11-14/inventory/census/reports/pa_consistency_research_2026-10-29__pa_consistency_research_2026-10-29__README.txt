PA CONSISTENCY: AUDIT AND NEW SOURCE REDUCTIONS
29 October 2026

RESULT

No validated Turing machine below 208 working states was obtained.
The positive new theorem specializes the inherited register program from
3,909 to 3,904 primitive occurrences, preserving halting from its established
canonical source seed. This is a source theorem, not a smaller physical table.

The five supplied U208 archives contain nine designated final tables but only
two rooted action-preserving graph-isomorphism classes. Their final state
saving is the same 172/211 contextual fold and cannot be added together.

Start with report.pdf; report.tex and verification_status.tex are its complete
LaTeX sources. The report contains the comparison, reviewed logical bridge,
source proof, exact search scopes, counterexamples, limitations, and references.

QUICK OFFLINE REPLAY

Python 3.10+ and its standard library are sufficient:

    python3 -B reproduce.py --output /tmp/pa-consistency-check

This verifies the archive's file manifest, independently canonicalizes all
nine tables, compares both source control graphs, rebuilds the 3,904-primitive
source normally and with Python optimization, compares all generated bytes,
checks the finite tape-window invariant, and replays the rejected experiments.
It writes a fresh receipt and per-command logs to the chosen output directory.
The default output, if omitted, is ./reproduction-results.

The new source certificate needs two small single-register abstractions:
6,430 location/category pairs for register 1 and 9,651 for register 6. The
278,384-pair joint zero/positive invariant is also regenerated and retained.
The optimized source SHA-256 is:

FULL SYMBOLIC BASELINE REPLAY

    python3 -B reproduce.py --full-baseline --output /tmp/pa-full-check

This additionally extracts the unchanged compact reference package into the
output directory and runs its verify.py --full. No network is required. The
fresh preparation run passed both graph classes: 5,084 contracts and 416 rows
per class, with 1,251,865 symbolic applications for A and 1,250,564 for B.
It took approximately 187 seconds in the preparation environment.

The symbolic engine deliberately requires assertions enabled. Do not run the
full-baseline option under python -O. The source specialization and curated
window-certificate checker retain their checks under -O.

CLAIM BOUNDARIES

The new source proof is an ordinary mathematical, PA-formalizable equivalence
with executable finite premises. No new end-to-end Lean, Rocq, MM0, or exported
PA certificate is claimed. The native U208 tables use the Cantor-coded calculus
for unrestricted covering plus irreflexivity; the unary ZIP's separate dyadic
emitter has not been compiled into them. Source leaf count, distinct subtree
count, physical working-state count, and sampled running time are not interchangeable.

No search failure here proves a lower bound of 208 states. No file named
rejected207 should be treated as a valid Con(PA) construction.
