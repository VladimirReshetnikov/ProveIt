PA CONSISTENCY MACHINES: TWO NEW 194-STATE COMPOSITIONS
Research release dated 15 November 2026 (UTC)

RESULT

No justified machine with fewer than 194 working states was obtained.
The requested fallback consists of two new 194-state, binary, single-tape,
blank-start machines:

  machines/PA194H5X_MF/machine.tm
  machines/PA194JH5X_MF/machine.tm

Both have working states 0--193, start 0, separate halt 194, initial head 0,
and an all-zero two-way infinite tape. Each has 388 rows. A row is
  current_state  read_bit  write_bit  L_or_R  next_state
The write and move happen before entering the target, including halt.
Native tables instead use start 74 and halt 254; native 194 is a working
state. Native/dense bijections are supplied beside the tables.

The complete report is report/report.pdf. Its editable LaTeX master is
report/report.tex, with the complete relative proof in proof/relative_proof.tex
and generated appendices in report/. Both full dense tables are printed.

PROOF AND ITS DEPENDENCIES

Let P be the corresponding supplied H5X/JH5X parent and M its new MF child.
This release gives a direct written proof in iPRA of

  H_P(t) -> H_M(5t),       H_M(t) -> H_P(3t),

where H means halting by the specified time. Hence iPRA proves
NH(P) <-> NH(M). The proof uses explicit predecessor-bit invariants,
primitive-recursive clocks, complete local tape identities, and
quantifier-free induction. Absorbing totalization handles arbitrary
intermediate alleged halting times without inverting a clock.

Composition with the supplied revised AX11H written calibration and the
H5X/JH5X proof transports yields the written conclusion

  iPRA |- NH(M) <-> Con(PA).

The absolute arithmetic calibration is an inherited mathematical dependency.
We reviewed its architecture and critical proof obligations but did not
independently reconstruct every transitive proof-generating recipe.
The unchanged exact parent archive, including that calibration, is retained
under references/. This is not a newly completed end-to-end Lean or Rocq
theorem; the repository's machine-specific Lean assembly is still unfinished.
Finite executable checks are not being equated with that formal endpoint.

The precise consistency sentence is
DiophantineConsistency.IPRAPA196Consistency.nativePAConsistency,
the native negation of the mapped Foundation PA refutation predicate.
PROVENANCE.json and the report identify the exact theorem and source files.

WHAT CHANGES

The two constructions combine known ingredients on the newest witness-calculus
parents: two guarded three-to-one physical shortcuts and a separated marker/
history selector. The old marker 51 is renamed 400; old reader 301 is removed;
reader 88 and the now-separate selector 51 distinguish the two incoming cases.
One control is removed and one is introduced, so the total remains 194.
No extra initialization or marker control is hidden from the count.

These are new compatible compositions, not claims of inventing their
ingredients. They are not state renamings, reflected copies or changes only
to unreachable rows. Exact graph matching distinguishes both from all 530
recognized 194-state graphs and from each other, even after reflection,
symbol exchange, root change and erased halt-entry decorations. Both
mechanisms execute again after the canonical startup is complete.

REPRODUCE THE POSITIVE RESULTS

Python 3.10 or later and its standard library suffice. From this directory:

  python3 -B verify_all.py

Run without -O or PYTHONOPTIMIZE, because inherited matcher assertions are
part of its checks. No network, compiler, or proof assistant is required.
The driver verifies the release manifest, rebuilds the machines in a temporary
directory and compares every generated byte, runs the independent verifier,
and repeats exact structural comparison against the entire 530-graph corpus.
It also tests a renamed positive control and matches both known parents.
An optional --output argument writes a fresh JSON receipt outside this tree.

The independent verifier imports no builder. It checks all 384 ordinary rows,
12 acceleration windows, four marker cases, and all 24,832 radius-three
state/window pairs in each parent/accelerated table. It reconstructs the
whole canonical seed tape, confirms startup in 57,970 child transitions,
and follows another 10,000 accelerated-parent steps in complete synchrony.
All one-cells and zero exterior are checked; this is not a head-window test.

Individual commands, if desired:

  python3 -B build.py --output /tmp/pa194-mf-rebuild
  python3 -B verify_independent.py --output /tmp/pa194-mf-independent.json
  python3 -B comparison/novelty.py machines/PA194H5X_MF/machine.tm machines/PA194JH5X_MF/machine.tm

Build the PDF with an ordinary LaTeX installation:

  cd report
  python3 build_fragments.py
  pdflatex -interaction=nonstopmode -halt-on-error report.tex
  pdflatex -interaction=nonstopmode -halt-on-error report.tex

Packages: standard AMS/math and table packages, geometry, lmodern, microtype,
xcolor, xurl/hyperref, enumitem, fancyhdr. No shell escape is required.
The frozen TeX appendices already exist, so build_fragments.py is optional.

modulo state renaming and arbitrary root. Novelty is checked under the
