The current top-level PA README reports unfinished Lean/iPRA machine-specific directions. This does not invalidate the later incoming package's distinct claim of an ordinary written iPRA proof. The latter has ten TeX proof files, 4608 lines, and expressly does not claim a kernel build.

Reviewed closely: consistency_equivalence.tex, physical_ipra_audit.tex, consistency_implies_nonhalting.tex, the primitive command contracts in ax11h_preservation.tex and source_command_completion.tex, and substantial parts of forward_calibration_completion.tex and foundation_paeq_completion.tex. This is a focused mathematical audit, not a reconstruction of every imported finite theorem and not a full end-to-end independent verification.

The physical simulation argument is correctly formulated for weak arithmetic: complete tapes are pairs of binary naturals; symbolic unary loops and four generic block/list traversals have quantifier-free prefix invariants; one spare-list width variable is bound to the actual same list rather than independent; normalization handles empty unary runs and zero exterior; exact source frames include evolving gap and spare list. The local relation Run(D(z),E(z))=E(F(z)) composes by primitive-recursive clock tau. Positivity D>=3 before halt supplies the explicit reverse witness k=t+1 without minimization or Markov's principle.

The forward PA-proof compiler does not merely weaken a PA theorem by assertion. Its strategy computes all queries in a finite demand tree before using child proof outputs, with strictly decreasing formula/proof-code rank inside a stratum and completed lower strata. A full binary tree of depth rank+1 is primitively recursively bounded even if parameter/output magnitudes grow. A reverse evaluator with bounded Boolean proof-checking invariants avoids the forbidden induction over all environments. The manuscript explicitly provides the critical formula realization, arbitrary induction-matrix, closure, and outer sequent request maps. This is a plausible and appropriately scoped method, but its many exact finite recipes remain an inherited proof dependency.

The final argument is model-uniform I-sigma-1 calibration, composed with the repository's existing negative-statement transfer to iPRA. It does not infer positive existential witnesses by double-negation elimination. The written manuscript states the current Foundation PA predicate explicitly and supplies a separate Foundation-to-ordinary-PAeq adapter. Thus describing this inherited dependency merely as a PA equivalence would omit the later manuscript's actual content.

Safe description for a new relative machine transformation: its iPRA equivalence to the exact inherited machine can be established independently of PA calibration. Composing with the cited written calibration gives the requested written iPRA consistency equivalence. Keep separate (a) new relative proof and finite certificates, (b) imported written PA calibration, (c) unfinished kernel formalization. Do not say that executable finite checks alone prove the entire consistency equivalence.

Bootstrap freedom: any fixed seed threshold N0 preserves scheduler completeness if execution thereafter enumerates all higher candidates, because the all-store compiler is cofinally encodable by neutral AX prefixes. Soundness accepts any theorem-annotated store, in particular all-zero t,w,h with arbitrary offset. Consequently an initialization search need not insist on exactly original N=2; it may accept a canonical source frame meeting those conditions and a valid residual/candidate relation.
