# Competing proposals: independent review

The companion `competitor_census.json` is generated by `census.py`. It parses
every row of each supplied main table, checks unique binary rows, verifies
exactly two rows per working state, verifies the unique separate halt, and
counts graph-reachable states from the declared start. This is an independent
structural check. It does not rerun all competitors' proof or runtime receipts.

## Checked rejection: swapped unshifted fixed roles

U222 uses source variable 0, tested variable 1 and output label `n`, where
the natural number `n` also decodes the matrix. Swapping source/test roles
while retaining an unshifted `n` is not sound. At `n=0` the matrix is truth,
the output and tested labels collide, and the local subset guard is

    G_0 = forall v_0 (E(v_0,v_0) -> E(v_0,v_1)).

Under irreflexivity this is true. The lower covering clause then becomes
`forall v_0 E(v_0,v_0)`, which is false in every nonempty irreflexive
structure. The emitted existential conjunction is therefore false. The old
gate `c != a,b` does not eliminate this case: choose `c=0,a=b=1`.

A possible sound future variation is to swap source/test roles while using
`n=c+1` as both matrix and binder. The remaining small case `n=1` expresses
existence of an empty object; every `n>=2` has the ordinary self-freshness
proof. This is only a source-level idea until compiled and verified.

## Checked rejection: transfer of the PA237 equality helper

U222's destructive equality subtree is at source path
`110100100111010110` and operates on registers 5 and 6. The subtree has ten
primitive occurrences. Replacing all its occurrences by the seven-node
cancellation/transfer scheme in `u237_construction` increases the entire
source DAG from 204 to 205 nodes and primitive occurrences from 3891 to
3895. The maximum source depth and zero run remain 45 and 6. This direct
transfer gives no source-size advantage. These numbers are source metrics,
not an independently compiled state count.

## Valid source variations explored separately

The lower clause

    forall x (G(x,a) -> (phi(x) -> E(x,b)))

may be replaced by

    forall x (phi(x) -> (G(x,a) -> E(x,b))).

This is a classical tautological reordering of antecedents. The upper and
lower cover clauses may also be exchanged. `source_dp.py` searches four
such fixed-role variants with a bounded parenthesization beam, reusing
K215 source subtrees and rejecting replacement trees with zero runs above
six. Its output consists of source candidates and source metrics only.
No candidate is to be described as a new TM unless separately compiled,
all contextual arithmetic routes are protected, and universal runtime and
blank initialization are checked.

The completed beam-12 results are:

| Clause order | Lower antecedent order | Distinct source DAG nodes |
|---|---|---:|
| Lower first | Guard then matrix | 204 |
| Lower first | Matrix then guard | 204 |
| Upper first | Guard then matrix | 203 |
| Upper first | Matrix then guard | 202 |

All four best results have 3891 primitive occurrences, maximum source depth
45, and maximum zero run 6. The strongest source candidate is
`order1-commute1-beam12-rank0.sites.json`; two alternative parenthesizations
are retained at ranks 1 and 2. The exact recipes were separately reconstructed
with the original `build_source.build` routine and compared byte for byte.
The JSON table `dp-results-beam12.json` records the exact constructor tokens.
This is a bounded heuristic result; it establishes neither global optimality
of the parenthesization nor a 220-state Turing machine.

For the 202-node candidate, let `e=R(1,c)` and
`G=Q(c,I(R(c,1),R(c,0)))`. Define

    U = Q(1,I(e,c)),
    L' = Q(1,I(c,I(G,e))),
    H' = Q(c,I(U,N(L'))).

The old lower clause is `L=Q(1,I(G,I(c,e)))`. The implication exchange
tautology gives `L <-> L'` even before interpreting the designated false
formula. The same exchange law gives
`I(L,I(U,F)) <-> I(U,I(L',F))`. Universal quantification at `c` then proves
the equivalence of `H` and `H'`, so the old vacuity/cover bundle and both
exceptional-code arguments carry over. This argument uses formula positions
and scopes exactly as written and does not exchange the fixed source/test
variable labels.

## Verification lessons

1. U222's own history records an earlier 222-state table rejected for
   incorrect arithmetic context. Matching opcode/register does not suffice.
2. The PA236 report records a locally valid fold whose first source rotation
   raised an address zero run from six to seven and failed full runtime.
3. The runtime U237 packages have different nonblank startup checkpoints.
   Equality of the active register vector alone does not identify a tape;
   actual gaps, all spare registers and all nonblank cells are needed.
4. A conditional merge can be valid even if deterministic all-tape state
   bisimulation leaves every state singleton. A sufficient invariant for
   the discarded transition should be proved from incoming actions.
