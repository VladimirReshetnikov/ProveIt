A state count excludes the separate halt control. Source sites count primitive instruction occurrences. ## Evidence key

- **K:** Published Lean development proves the physical refinement and the internal direction PA ⊢ Nonhalt → Con(PA). A full internal biconditional is not asserted to be an already existing kernel theorem.
- **E:** Executable symbolic contracts for arbitrary natural register values, protected register-engine premise checks, exact finite startup, and ordinary proof transfer. This is not a newly elaborated Lean theorem.
- **I:** The runtime obligations use a proved source invariant at the changed site.
- **L:** The numerical calculus changes, so the supplied ordinary syntactic PA calibration must also be used. The new PA195 report includes an independently audited ordinary proof of both PA directions.
- **Audit completed:** An archived physical table whose missing complete runtime or startup binding was checked afresh in this audit; the report does not pretend the supplied primary receipt already contained that check.

For each diagonal closing variant, all 4,815 baseline branch contracts are covered differentially: 45 affected branches are replayed as 69 affine cases under the checked trit invariant; every other branch provably avoids the changed row. The complete blank startup is also checked. These four auxiliary variants occur in engine-search directories.

The maximum symbolic-step statistic is an abstract certificate length, not a literal runtime bound. Finite startup alone is no nonhalting evidence. Shorter sources can have more physical states if they lose useful sharing.
