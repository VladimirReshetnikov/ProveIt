ADDITIONAL PHYSICAL REDUCTION SEARCHES

No blank-tape PA consistency machine below 194 states was established here.
This small package records two new negative investigations of the supplied
193-control initialized runtime, with reproducible code and exact finite
counterexamples. It is not a lower-bound argument.

REPRODUCTION
  python3 -B reproduce.py --output /absolute/fresh/output-directory
  python3 -B reproduce.py --quick

The full run needs Python 3 and g++ with C++17 support. The quick run checks
only file identities, the exact relay transformation, its literal bad source
endpoint, and its blank-start outward ray. No network or repository checkout
is needed. Do not use Python -O: assertions check the certificates.

THE INPUT CORE
The supplied incoming pa_sub194_research_2026-11-13 packet constructs an
initialized runtime with 193 controls by identifying native 301 with 88 and
changing rows 88/0 and 51/0. Its exact table is data/runtime193.native.tm.
That packet validates all 4780 primary PA194 source outcomes and explains
the modified marking identity, but explicitly rejects blank initialization.
Those inherited generic source contracts are not newly reproved here.

THE TWO-EDIT SCREEN
The input pool is the supplied corrected radius-four pool after excluding
all arithmetic-box controls: 327 candidate row rewrites at 84 distinct rows.
The source of this pool is
  research/reduction/recorded/runtime193_corrected_neutral_k4.jsonl
in the supplied sub194 packet. The previously rejected q35 rewrites are
absent. Simultaneous pairs are not assumed to preserve the runtime; any
positive candidate would need its own generic validation.

Every pair of edits to distinct rows was tested. There are 52,128 pairs.
Every existing control is allowed as the blank starting state, giving
10,060,704 represented initial conditions. Exact first-change configurations
are identified up to tape translation: their entire finite support, current
control, and head-relative position agree. This reduces the explicit work to
84,266 representative literal simulations; unchanged original executions
account for 9,127,208 starts and end at a halt or certified outward ray.
The remaining starts share a representative's exact translated computation.

The detector accepts ANY complete physical source frame at source ordinal
25 through 44. All nine register values are unrestricted. Header padding is
48+n for arbitrary n>=0; there must be at least one spare block. The entire
finite nonzero support is checked, including the left marker, encoded path,
header marker, every unary block, and the zero exterior. An independent
positive control finds the original primary194 startup at step 58,154, head -2,
source 25, with the original 35 physical fields. Thus no soundness assumption
about a small initial proof store restricts the negative screen.

Observed totals:

A representative is bounded by 200,000 transitions AFTER its first changed
row, head displacement 20,000 from that point, and support size 20,000. The 775
bounded outcomes are unresolved beyond those limits. Finite windows and
neutral-action synthesis are incomplete search restrictions. No impossibility
claim is made about other rewrites, other startups, or other runtime designs.
The log is retained under recorded/; the full replay checks all totals.

TRANSFER OF THE ZFC MARKER RELAY
The ZFC k218-continuation-search/marker-relay proposal was transferred to this
PA core. It adds the temporary marker 36/0=1R16, changes 16/1=1L56, and routes
six existing decoder returns through 122. It has 193 controls, but fails the
primary PA source already at ordinal 2, path 00000101, continueTo2 with target 0.
For a legal frame with all nine registers zero, one zero spare, and gap zero:
  primary194 reaches the correct complete endpoint after 32 transitions;
  transferred relay reaches a wrong source header after 54 transitions,
  with differing tape cells 3, 6, 8, 9.
The source ordinal is zero-based, and initial head coordinate is 0.
This is a literal finite counterexample, not merely a symbolic fuel failure.

Starting the same relay table from blank tape in native 74 gives an outward
ray after 116 transitions: native 35, head 18, finite support {-3, 1, 11, 12}, and
row 35/0=1R35. The machine therefore continues writing ones rightward forever.
The proposed source equivalence is already refuted; the blank behavior is
also explicitly classified. data/relay193.native.tm is a rejected experiment,
not a new PA consistency machine.
