\begin{abstract}
No machine with fewer than 194 working states was established. The successful
fallback consists of two explicit, two-symbol, one-tape, blank-input machines
with 194 working states: PA194SUMS and PA194NS. They preserve the original
sum-based Shift guard while reversing the operands of its destructive
comparison. This eliminates a register-transfer loop. PA194NS additionally
uses the no-push successful modus-ponens protocol. A new one-bit history fold
absorbs the extra control state needed by the replacement trailer.

The construction includes exact tables, dense state maps, a finite local-fold
certificate, universal symbolic source checks, an exact blank-startup check,
and a PA-verifiable finite-trace equivalence to the appropriate calibrated
parent source. The logical calibration is inherited from the repository's
separate-diagonal-head PA calculus. No newly compiled Lean or Rocq endpoint
is claimed. Neither transition graph occurs in the audited current corpus,
which has 51 different byte presentations in 28 graph classes, including
rejected diagnostic candidates.

The finite certificates were replayed in independent JavaScript/V8
implementations and then in the supplied Python and Node.js programs.
The source bundle includes the complete tables, proof references, graph
audit, verification receipts, and reproducible build scripts.
\end{abstract}

\section{Result, machine convention, and scope}
A state count in this report excludes the distinguished halt state. Each
machine has a two-way infinite tape, alphabet $\{0,1\}$, blank symbol $0$,
one head, and only left or right moves. Dense working states are
$0,\ldots,193$; the initial state is $0$ and the halt label is $194$.
There are exactly $388$ transition rows. In inherited native labels the
initial state is $74$ and halt is $254$.

Write $H_M$ for the arithmetical assertion that the literal table $M$ has a
finite halting computation from its all-zero tape. The intended theorem is
\[
 \PA\vdash \neg H_M\longleftrightarrow\Con(\PA).
\]
This is an internal proof-translation statement, not an inference from an
external belief that the machine runs forever. The report supplies the new
finite-trace transport and identifies the inherited source-calibration and
arithmetic-engine dependencies explicitly.

\midrule

PA194SUMS &194&3670&4776&58004\\

\bottomrule

The shorter source and startup do not imply a global runtime improvement:
the changed comparator has different intermediate counter trajectories.

The novelty is a changed register protocol and a changed literal transition
graph. It is not a new arithmetic engine, a new logical basis, or a claim
of an entirely unrelated proof enumerator. In particular, the existing
cached-head symmetric design PA194CS uses a different guard/protocol.
The new SUMS/NS controllers retain the original sum guard and its
arbitrary-store meaning.

\section{Why reversing the comparison is correct}
\begin{lemma}[Destructive equality]
The common first eleven source instructions halt exactly when $H=X$.
If $H\ne X$, they terminate at instruction 11 with $H=X=0$ and every
other register unchanged.
\end{lemma}
\begin{proof}
The comparator decrements the two natural counters in lockstep.
If both reach zero together it takes the halt branch. If exactly one
reaches zero first, the remaining loop clears the other counter and
exits. Each loop has a decreasing natural counter, so no nonhalting
behavior is introduced inside the block. This is a PA-provable
induction on the initial counter sum.
\end{proof}

\begin{lemma}[Original sum-guard symmetry]
The old and new Shift blocks have the same halting decision and the
same complete nonhalting register store for arbitrary incoming
$(T,H,X)=(t,h,x)$.
\end{lemma}
\begin{proof}
The common prefix first transfers $T$ into $X$, and then transfers
$H$ into both $T$ and $X$. Put $k=x+t+h$. At this point
\[
 (T,H,X)=(h,0,k).
\]
The old tail transfers $X$ into $H$ and increments $X$. The new tail
increments $H$. Their respective comparator inputs are therefore
\[
 (h,k,1)\qquad\hbox{and}\qquad(h,1,k).
\]
By the preceding lemma both halt exactly when $k=1$. Otherwise both
leave $(T,H,X)=(h,0,0)$, with every other register identical. All local
loops terminate on natural stores. In particular, the statement does
not depend on assuming the scratch register $X$ was initially zero.
At command boundaries, where $X=0$, the guard is exactly $t+h=1$.
\end{proof}

\begin{theorem}[Finite-trace transport]
PA proves that SUMS halts if and only if the primary PA194 source halts.
It proves that NS halts if and only if the no-push PA194N source halts.
\end{theorem}
\begin{proof}
Decompose a source computation into unchanged instructions and complete
visits to the changed finite block. Replace each old block by its new
counterpart, or conversely. The preceding lemma gives identical
nonhalting exits and matching halting decisions. The finite blocks
terminate with positive duration. Induction on the number of boundary
visits yields a primitive-recursive transformation of finite halting
traces in each direction. Determinism and positive progress also exclude
a spurious halt hidden between simulated boundaries. All these are
finite arithmetic statements and inductions available in PA.
\end{proof}
This is an equivalence of halting statements, not a claim that the two
machines have identical intermediate configurations or equal running times.

\section{Calibration to PA and the no-push protocol}
\subsection{Inherited numerical calculus}
The retained source uses Cantor pairing
\[
 p(a,b)=\frac{(a+b)(a+b+1)}2+b
\]
and constructors
\[
 I(a,b)=4p(a,b),\quad M(a,b)=4p(a,b)+1,\quad
 U(i,a)=4p(a,i)+2,\quad E(a,b)=4p(a,b)+3.
\]
Code zero is truth and code one is $M(0,0)$, the designated contradiction.
The stack constructor is $[a;w]=p(a,w)$; in particular,
$p(0,0)=0$. The exceptional equality $I(0,0)=0$ also has to be handled
by a fixed truth-proof template. Neither encoding is freely injective
into a disjoint truth constructor at zero.

The separate diagonal head is
\[
 \Gamma(B)=I(B,U(B,B)).
\]
Every variable label occurring in the formula coded by $B$ is below $B$,
so the binder in this head is fresh. The primary calibration supplies
primitive-recursive proof translations between the separate-head and
bundled-gate calculi, and between this calculus's refutations and PA
refutations. Its finite binary-membership interpretation handles
two-way membership rewriting, the equality witness, and the
coincident-variable cases explicitly. The full retained calibration
fragment is in \file{reference/pa194_calibration.tex}.

For soundness, $M(a,b)$ is interpreted as binary membership
$\operatorname{Bit}(x_a,x_b)$, and $E(a,b)$ as equality. PA proves
finite binary comprehension by induction. Substituting a formula
into that induction pattern is a syntactic proof-producing operation;
no arithmetical truth predicate or reflection principle is used.
For completeness, the supplied proof compiler recovers the original
PA196 interfaces using diagonal vacuity and pointed separation.
These are inherited logical dependencies, not discoveries of this
controller change.

\subsection{The corrected direct no-push interface}
On a logical command store $(T,W,D,H)=(t,w,d,h)$ put $y=d+x$.
The no-push MP command satisfies
\[
 \MP_x(t,w,d,h)=
 \begin{cases}
   (y,w,y,0),& I(t,y)=h,\\
   (0,w,y,0),& I(t,y)\ne h.
 \end{cases}
\]
In particular, $D=y$ after a successful MP. Treating the successful
branch as if $D$ were zero gives an incorrect compiler argument.
The original-guard Shift halts if $t+h=1$; otherwise its interface is
\[
  \Shift(t,w,d,h)=(h,\operatorname{tl}(w),d,\operatorname{hd}(w)).
\]
NS has exactly this command interface by the preceding symmetry lemma.

Let $A_0=\AX(0,0,0)$. The unchanged ten-entry AX interface has output
\[
   (g,[q_1,\ldots,q_9,t;w],0,0),
\]
where the selected quantifier head is $q_9=U(d,h)\ge2$.
The gate and the first eight generated heads have residue zero modulo four; the ninth is $U(d,h)$ and has residue two. Thus generated heads and the gate are not code one. The saved old top $t$ is not included in that assertion.
Useful normalized words are
\begin{align*}
 \mathsf{Push}&=A_0\,\Shift^9\,\MP_0,\\
 \mathsf{Pop}&=A_0\,\Shift^{11},\\
 \mathsf{Discard}&=\MP_0\quad\text{when }D=0.
\end{align*}
Their effects are respectively
\[
 (t,w,d,h)\mapsto(0,[t;w],0,0),\qquad
 (t,[a;w],d,h)\mapsto(t,w,0,a),
\]
and, with $D=0$,
\[
 (t,w,0,h)\mapsto(0,w,0,0).
\]
The last effect holds on either branch since the MP candidate is zero.
The Pop word is total even for top $t=1$: its last sum guard has the
form $U(d,h)+t\ge2$, rather than comparing $t$ against a zero cache.

Generalization at index $i$, from $(a,w,0,0)$, can use
\[
 \mathsf{Push}\,\MP_i\,\Shift\,\AX(i,0,0)\,\Shift^{10},
\]
producing $(U(i,a),w,0,0)$, or an earlier acceptable halt if a contradiction
has already been exposed.

For a modus-ponens proof node with minor conclusion $a$, major conclusion
$I(a,b)$, and target $b$, an explicit reserved-zero compiler word is
\[
 \mathsf{Discard};\mathsf{Push};C_{\rm major};\mathsf{Push};
 C_{\rm minor};\mathsf{Push};\Shift;\Shift;\MP_b;\mathsf{Pop}.
\]
Before the two Shifts its store is
\[
 (0,[a,I(a,b),0;w],0,0).
\]
The Shifts give $(a,[0;w],0,I(a,b))$, unless a contradiction triggers an
acceptable earlier halt. MP then gives $(b,[0;w],b,0)$, and Pop gives
$(b,w,0,0)$. The reserved zero is supplied by the compiler, not by the
modified successful MP command. This is also valid under the canonical
zero-stack convention $[0;0]=0$.


For completeness, the axiom leaves also have explicit clean-store selectors.
The inductive compiler contract allows every initial top $t$ and stack $w$,
but assumes $D=H=0$:
\[
 C_p(t,w,0,0)\ \text{either halts or returns}\ (f,w,0,0)
\]
when $p$ derives $f$. Thus $\mathsf{Discard}=\MP_0$ is used only with
$D=0$. The all-store wrapper $A_0$ establishes that precondition.

Number the nine generated heads in their actual stack order. For
$j=1,\ldots,7$ the head selector is
\[
 \mathsf{Discard};\AX_{A,D,H};\Shift^{j+1};
 \mathsf{Pop}^{9-j}.
\]
The saved old top is zero after Discard, so the final Pop leaves a clean
cache. The restricted implicational head is
\[
 \rho(a,b,c,u)=
 I\bigl(I(I(c,u),a),\,I(I(a,c),I(b,c))\bigr),\quad u\le a.
\]
It is selected by
\[
 \mathsf{Discard};\MP_u;\AX_{b,a-u,c};\Shift^9;\mathsf{Pop}.
\]
For a guarded gate $g(a,b,c)$, the selector is
\[
 \mathsf{Discard};\AX_{c,b,a};\mathsf{Pop}^{10}.
\]
Only legitimate guarded axiom instances enter this proof-leaf case.
Together with the displayed generalization and MP words, these selectors
give the structural proof induction without assuming that successful MP
still pushes a zero.

These axiom selectors and inductive proof constructors
yield a clean proof compiler $C_p$. Prefixing by $A_0$ normalizes an
arbitrary carried store, and a final Shift exposes contradiction code
one. Thus a PA refutation yields a finite halting command word from
every carried store, not just from a hypothetical reset. The inherited
fair command-word scheduler eventually executes a witnessing word.

Conversely, annotate top, cache, and every live canonical stack entry
with PA proofs of their translated formula. AX, MP, and Shift preserve
these annotations. The no-push MP omits the extra truth push;
it creates no theorem lacking a proof. A sum-guard halt has
$(t,h)=(1,0)$ or $(0,1)$, exposing a proof of the designated contradiction.
The annotations and the canonical zero cases give a primitive-recursive
translation from a finite source halt to a PA refutation.

\subsection{The resulting theorem and its formal boundary}
\begin{theorem}
With the repository's retained arithmetic-box lemmas and its explicit
separate-head PA calibration, the constructions give
\[
 \PA\vdash
  \neg H_{\rm SUMS}\longleftrightarrow\Con(\PA),
 \qquad
 \PA\vdash
  \neg H_{\rm NS}\longleftrightarrow\Con(\PA).
\]
\end{theorem}
\begin{proof}
For SUMS, compose its finite-trace equivalence with the primary calibrated
source. For NS, compose with the no-push source calibration, equivalently
use the corrected direct command compiler above. The universal physical
contracts, local quotient witnesses, and literal blank entry transport
each source halting statement to its exact binary TM. Finally negate
the existential PA-refutation predicate.
\end{proof}

The qualifier identifies mathematical lemmas being reused; it is not a
claim of an additional consistency assumption. The deliverable is an
ordinary proof with executable finite certificates. It does not claim
that all referenced calibration text, source compilation, box contracts,
and literal tables have now been assembled into a new single Lean or
Rocq theorem. The repository's stronger iPRA-endpoint questions also
remain separate.

\section{Attempts below 194 and lessons from rejected reductions}
No lower bound is proved. Several finite search spaces and proposed
logical shortcuts were examined without producing a certified smaller
table.

A direct scanner merge $34\to75$ fails 113 primary symbolic outcomes,
at 57 source sites. The source has relevant leading-zero paths and
transient zero stretches outside a naive AX-only bound. Existing
six-state synthetic scanner examples do not validate that merge for
the real source.

The surveyed 229 retained valid grammar objects did not give a usable
maximum zero stretch of five. Expanded history-context searches,
recursive equal-branch pair-fold searches, and scanner merges into
non-engine controls likewise produced no accepted 193-state table.
These are failures of the specified searches, not a proof that 193
states are impossible. Some historical packets already contain very
large grammar searches; rediscovering their negative candidates is
not new progress.

A proposed swap of the classical head
$\neg B\to H$ into $\neg H\to B$ was rejected: a derivation using
double-negation elimination or explosion is circular if those principles
themselves rely on the old head. Curried-premise exchange in safe
implicational/quantifier heads can be derived using independent
propositional templates, but it was already present in the comparison
corpus and did not yield a new sub-194 allocation here.

A tempting deletion of the second membership-rewrite head is also
invalid. Interpret $M(s,z)$ as the $z$-th binary bit of $s$, and
$E(s,t)$ as inclusion of the corresponding finite sets. Container
transport and the equality-witness head remain valid. But the proposed
deleted head
\[
 E(c,a)\to(M(b,c)\to M(b,a))
\]
fails for distinct variable labels $a,b,c$ under the valuation
$x_c=0$, $x_a=x_b=1$: $E(c,a)$ and $M(b,c)$ are true, while
$M(b,a)$ is false. The designated contradiction $M(0,0)$ is still false.
Thus this does not merely exploit a changed meaning of falsehood.
It refutes the proposed derivability shortcut; it does not preclude
every possible different PA interpretation of a reduced calculus.

The actionable outcome is the sum-comparator transfer elimination and
its compensating history fold. Further state reduction must pay for
an actual source protocol and pass complete physical contracts; a small
source expression or a plausible local scan bound does not suffice.
