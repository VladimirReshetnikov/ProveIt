PA194QNS - a concrete same-size fallback
======================================

This packet supplies a 194-working-state, two-symbol, one-tape, blank-start
Turing machine. The new composition combines the supplied Q axiom emitter,
no-push MP and symmetric implementation of the original sum-based Shift.
Each component is attributed to the existing packets. No sub-194 machine is
claimed here, and this is not a new end-to-end Lean/Rocq/iPRA kernel theorem.

The ordinary mathematical proof in proof.tex gives an explicit finite-trace
equivalence to the frozen PA194QN source for every initial logical store at
source entry 25. Combining it with the supplied QN syntactic PA calibration
and the complete source/tape simulations establishes the same PA-provable
consistency biconditional. The inherited logical fragments are retained.

The first symbolic checker uses the unchanged inherited register-box lemmas.
The separate literal checker imports neither that compiler nor its box oracle:
it reconstructs the source graph in two ways, rederives four list lemmas from
the actual rows, verifies every primitive outcome for arbitrary natural
registers and the stated spare-list/gap interface, and separately executes
and compares the complete blank startup tape. Successful execution is
mathematical implementation evidence, not a proof-assistant kernel result.
