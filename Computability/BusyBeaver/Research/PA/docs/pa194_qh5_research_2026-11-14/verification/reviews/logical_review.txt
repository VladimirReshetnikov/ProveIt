Independent logical review of PA194QH5
====================================
Scope: proof/qh5_preservation.tex, proof/check_commands.py, proof/exchange_certificate.py, references/logical/radix_calibration.tex, the relevant main-report statements, and the inherited source scheduler's seed/parse equations. Read the upstream RestrictedImplication.lean definitions through rho8All. This review did not rerun expensive physical verification, kernel-check the complete machine theorem, or independently reconstruct the original PA-to-coefficient-four-calculus calibration.

Result: no mathematical blocker found in the new QH5 preservation argument within its stated inherited-calibration boundary. The one packaging correction found during review has been resolved: the release now includes the exact pinned RestrictedImplication.lean at references/logical/RestrictedImplication.lean, SHA-256 00af59bb2f970f780b834b721cccd06c4ed5b5ee13fbfddb0deb0139b4c62581, with input pin, provenance and inherited license. No new Lean elaboration is implied.

1. Command algebra and carried stores
The no-push MP and cache-only Shift identities are consistent with each other. In particular, MP(0) at offset zero gives (0,w,0,0) for every old cache because both comparison outcomes coincide. Push leaves (0,[t;w],0,0), using the implication/universal residue mismatch. Pop tests the saved top at its last Shift and gives the stated behavior even when p(0,0)=0. A plain final Shift would lose a contradiction in the top; the report correctly uses Pop.

The MP compilation reserves zero before compiling either premise. Its actual store before the suffix is (0,[a,I(a,b),0;w],0,0). The two Shifts place a in the top and I(a,b) in the cache. Successful MP leaves b over [0;w], so the final Pop removes the reserved zero and either returns (b,w,0,0) or detects b=1. A false antecedent causes an earlier safe halt. Head selectors, the guarded gate selector, target-offset rho selection, and generalization have the required stack and cache effects. These arguments require numerical Cantor identities but no injectivity of a free constructor algebra; zero aliases are addressed explicitly.

The derivation induction gives an either-halt-or-return statement for every arbitrary underlying stack and arbitrary initial top with cleared caches. Prefix AX(0,0,0) clears arbitrary carried caches and creates another arbitrary underlying stack, to which that induction applies. If the proof concludes 1, the final Pop tests that 1 before consuming the old tail. Therefore the halting suffix really works from every incoming numerical store. It does not assume all trials restart from zero, and it does not assume the incoming store is already a sound proof store. Sound proof annotations are a separate argument for the converse direction.

2. Scheduler coverage
The displayed encoding correctly distinguishes a fresh candidate from a continuation. The inherited source uses seed(n,l)=n when l=0 and l-1 otherwise. Thus e(c::w)=1+b_c(e(w)) is a continuation code, whereas a fresh prefix AX(k,0,0) followed by a suffix of continuation code z has candidate b_AX(k,0,0)(z)=p(k+2,p(0,p(0,z))), without an outer +1. Parsing that candidate leaves continuation z; parsing z-1 recovers the suffix's first command. The report's formula has the correct convention.

For fixed z these candidate numbers strictly increase and are unbounded as k increases. Prefix execution can change the carried store because the suffix is all-store halting. Positive continuation l becomes a projection of l-1, hence strictly decreases. Fresh trials advance n by one. Each arithmetic command has a terminating primitive-recursive execution, and bounded iteration over the candidate interval therefore supplies PA-verifiable finite execution up to a chosen cofinal candidate unless an earlier halt occurs. No fairness assumption about an infinite externally given execution is needed.

3. Coefficient-five recoding
F recodes both numerical formula codes and numerical variable labels, which is necessary for the self-indexed diagonal binder. Its component recursion is strictly descending on positive codes. The left inverse J proves F injective and preserves the disequality guards. F fixes 0 and 1 and commutes with all four constructors, including the exceptional I(0,0)=0 case. J is not improperly asserted to translate every target proof backwards.

F is not order preserving. The report correctly avoids transferring a restricted rho leaf by an unsupported F(u)<=F(D) claim. The inherited rho8All finite template supplies unrestricted rho from restricted leaves whose target order requirements follow from reflexivity and implication-argument bounds. The bounds a,b<=5p(a,b) hold also at zero. Target command offsets are then chosen for those actual valid target leaves. There is no claim that F conjugates addition, subtraction, stack coding, or machine trajectories.

Unused residue 4 modulo 5 is interpreted as truth, so arbitrary numerical command parameters remain covered. Residues 0,1,2,3 do not collide. Every source variable label in the interpretation of B is below B, giving diagonal freshness; zero and unused-tag cases are closed truth. The truth/implication-zero alias needs the fixed proof equivalence noted in the report. Soundness uses syntactic PA proof suppliers for finite bit comprehension, with a full PA induction instance, and does not invoke a satisfaction predicate or PA reflection.

4. Premise exchange
The K,S,MP exchange template is hypothesis-free and works under numerical substitution even if two free-algebra expressions collapse to code zero. Swapping its two parameters supplies the converse. Replacing sixth-axiom leaves by this fixed derivation gives primitive-recursive translations preserving exact conclusions. The K,S dependency on the restricted rho basis is explicitly separated from the 61-line exchange checker.

5. PA versus iPRA and proof boundary
The main theorem is presented as an ordinary mathematical PA-provability result, with the original coefficient-four calibration and its diagonal/separate-head transformations retained as named dependencies. It is not represented as a newly kernel-checked Lean/Rocq theorem or as a completed iPRA endpoint. The use of arbitrary-formula finite comprehension in the soundness supplier is appropriately identified; replacing the searched theory by iPRA would not establish the same Con(PA) calibration. The positive-duration simulation argument for the literal converse does not require decoding arbitrary intermediate tapes: under Con(PA), source execution continues, and T+1 positive source segments contradict a proposed earlier literal halting time by determinism.
