The initialization runs split into 181,281 proved outward blank rays,
63,943 exact repeated complete configurations, and 1,870 runs unresolved
beyond the cutoff. These categories sum to 247,094. The ray check requires
a read-zero control cycle moving only outward, with the head already beyond
all one-cells in that direction. Cycle detection verifies the entire
configuration after a possible hash match; a hash collision alone cannot
certify repetition. Individually source-neutral edits are only candidate
ingredients: their joint runtime correctness is not assumed.

The local-quotient context collector covers all 4,839 source outcomes,
interior positions of accelerated scans, the complete initialization, and
all 8,192 binary windows at each of 23 arithmetic-engine controls. Its
219,298 control/window pairs were independently regenerated and compared
as exact sets. The unconstrained arithmetic windows deliberately avoid
assuming a narrowed reachable invariant inside those engines. Thus a
negative result in this context domain can exclude a particular local
transformation, but cannot exclude a more specialized global invariant.

The rejected parity-scheduler combination is especially concrete. Delete
native control 301 and redirect it to 88, set
$(88,0)\mapsto(0,L,51)$ and $(51,0)\mapsto(0,R,122)$.
After 93 blank-start transitions its state is 35, its head is at 15, and
the complete set of one-cells is $\{-3,1\}$. Its row
$(35,0)\mapsto(1,R,35)$ runs outward forever. The new scheduler control
3000 is never reached. A separate script reconstructs this exact prefix
and the sufficient ray premise.
