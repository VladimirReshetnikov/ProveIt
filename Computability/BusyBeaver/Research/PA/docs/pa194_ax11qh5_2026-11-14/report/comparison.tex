These counts include raw compilers, experimental transformations, tests and
rejected tables. They are not counts of consistency theorems. The 651
component buckets include disconnected objects; only the full spanning
single-halt graphs support the headline graph-class counts. A disconnected
194-state diagnostic is additional to the 82 full 194-state graphs.
Arbitrary transition-dictionary encodings, unexecuted generators, diagrams
and prose are outside the literal-table recognizer. Each principal delivered
machine table discussed here is covered.

Native labels are not state counts. State zero is a start only when declared
or fixed by a delivery's dense-table convention; one older packet uses dense
labels for a native table whose start is elsewhere. Graph comparison may
forget the start, but a blank-start theorem must retain it. The audit stores
the declared or inferred start separately and does not infer an execution
theorem from graph reachability.

\subsection{Why the smaller tables are not accepted solutions}

The coefficient-three 193-state machine retains incompatible constructor
tags:
\[
 E_3(1,0)=3p(1,0)+3=6=3p(0,1)=I_3(0,1).
\]
Its supplied 73,393-step primitive numerical refutation derives code one.
Another incoming report proves that merely replacing the equality tag by
any fixed nonnegative offset still fails with the remaining heads retained.
These are obstructions to specified syntaxes, not lower bounds on Turing
machines.

Runtime193 instead has passing source-frame contracts under its stated
arithmetic interface, but fails blank initialization. The current 53
193-state graphs include this core, its unaccepted startup/runtime
transplants, marker-relay and append-zero experiments, and the inconsistent
coefficient-three machine. The presence of 386 transition rows is therefore
insufficient evidence for a smaller consistency machine. Bounded repair
searches, source-only scanner reassociations and optimistic grammar scores
are retained as research, not promoted to constructions.
