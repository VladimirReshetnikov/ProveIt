\section{What transfers from the three related projects}
All source references in this section use the pinned ProveIt revision
\texttt{32d0d8b7d93a63ad4106c18cdb29b37927acdad2}.

\paragraph{The ZFC machines.}
The exact K215 proof combines command-local field readers with a partial
selector, then reuses marker contexts to fold physical controls. Its source
identity check covers $4751$ primitives and $6175$ guarded edges; its
universal physical replay covers $6176$ cases and its blank prefix has
$95714$ transitions. The proof separately establishes source calibration,
arbitrary-register runtime, and the entire blank tape. It also explicitly
handles the initial enumeration cutoff four by a cofinal compiler.
These are useful architectural ideas: read an operand only where it is
needed, permit a carried store, and prove local tape blocks over arbitrary
outside contexts. AX11G uses the latter two principles in its all-store
compiler and literal replay. Its fourth AX operand illustrates the main
cost: falling through an existing reader changes the certificate language,
which requires a new inverse encoding even when it costs no control state.
K215 itself targets ZFC and has $215$ states; its proof explicitly leaves
the internal-PA endpoint open. It supplies neither a PA replacement nor
a state-count shortcut.

\paragraph{Diophantine consistency.}
The maintained compact equation has ten positive unknowns, $85$ live
arithmetic operations and degree $328$. Its four complete fixed integers,
$943$ tiles, decoder, alphabet and $436$-character numeral remain part of
the displayed object. This makes a direct polynomial-zero search a precise
alternative architecture, but its arithmetic-operation count does not
count binary TM controls. A blank-start implementation must construct the
fixed data and implement enumeration and the evaluator. Moreover, these
coefficients encode ZFC refutations, so a PA target first needs a changed
refutation encoding and its constructive calibration. The directory
reports iPRA proof-existence endpoints for several earlier equations and
a trace75 candidate, with explicitly separate file/provider ancestry
conditions; the final $85/328$ page has its own finite and ordinary proof
record. We did not obtain a smaller certified binary machine by this route
and infer no impossibility from those costs.

\paragraph{Concise iPRA.}
The scalar core uses iterator terms, equality, closure $Q$, and witnessed
closure $D$. Its direct-closure rule removes an existential witness from
equational progress; one-term transport reduces the primitive equality
interface; other variants move computation into normalization. These
suggest eliminating redundant operands and deriving auxiliary rules
instead of making them primitive. They also expose a cost transfer:
normalization, substitution and freshness still require an implementation.
The project's measured objects are complete Python proof checkers, with
significant tokens, AST nodes and normalized bytes as size coordinates.
Those measurements do not imply a count for the present binary machine.
More fundamentally, searching for a contradiction in an iPRA-equivalent
calculus changes the target consistency statement; it does not by itself
enumerate PA refutations. Our concrete simplification therefore stays in
the existing PA numerical calculus: AX's explicit binder shortens its
generalization word, and the delivered $18897$-line exchange certificate
derives the needed rule using only native restricted $\rho$ and MP.
