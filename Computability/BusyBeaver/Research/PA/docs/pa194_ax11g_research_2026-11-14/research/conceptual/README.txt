Two rejected conceptual reductions
==================================

From the bundle root:
    python3 research/conceptual/replay.py --output /tmp/conceptual-replay

The script uses the bundled construction/vendor modules and PA194G parent
inputs. It needs Python 3 with assertions enabled, no checkout or network.

Deleted-copyH: removing the first copyH macro shortens AX from 190 to 189
tokens. Both original and changed grammar still have 67 reader controls
and a maximum matching of 7 in the tested finite fold census, giving the
same optimistic 194 count. Semantically the saved generalized value becomes
U(c,t); the original top is no longer preserved. The established all-store
proof compiler does not survive this change, and no replacement compiler
was obtained. This is a rejected grammar-cost experiment, not an accepted
alternative machine.

Parity/radix6: move the equality residue from 3 to 4 and accept an odd theorem
code. The proposal relies on a model in which membership with all labels
zero is false and unused odd residues also denote false. Its explicit
implementation increases the raw control count to 205 = 137 fixed + 68 readers.
Even the optimistic seven-fold matching gives 198, so this instantiation
does not improve 194. The complete raw runtime check passes 4,890 source
outcomes, but no blank calibration or full logical calibration was supplied.
The recorded raw table and grammar are included. The matching is a finite
cost screen, not a certified simultaneously folded 198-state table.

Neither rejected experiment proves any lower bound for other Turing
machines, other grammars, or a more effective physical allocator. The
positive 194-state AX11G construction is in the main machine/ directory.

Input provenance is recorded in PROVENANCE.json. Upstream software license
notices are retained in construction/licenses/ at the bundle root.
