\begin{abstract}
No blank-start machine with fewer than 194 working states was established.
The deliverable instead contains two explicit new 194-state designs.
PA194AX11QGH combines an eleven-entry axiom block and a fourth operand with
an explicit generalization binder, the exchanged quantifier head, and a
cached-theorem-only halt test. PA194AX11HR keeps the AX11H source program
but changes ten active routing rows and the physical register allocation;
its exact blank initialization takes 48,320 rather than 57,922 transitions.
Both tables have 388 binary transitions, start on an entirely blank two-way
tape, and exclude their terminal state from the count.

The new execution arguments are expressed with primitive recursive clocks
and quantifier-free induction. Composing them with the latest incoming
written AX11H/QAX11H calibration gives written iPRA proofs of
nonhalting being equivalent to $\Con(\PA)$. The inherited calibration is
included unchanged and its review is documented. No completed end-to-end
Lean or Rocq verification is claimed.

The comparison covers the 82 filed packets and four current incoming
archives at the pinned snapshot. Their literal-table census has 110
194-state catalog classes, including auxiliary and rejected experiments.
Fresh searches examine direct contractions, arbitrary rewrites of both
rows of a merged state, and 422 neutral single-row preconditions. None
produces a certified sub-194 machine. These negative results concern
explicit finite search families, not a lower bound on all constructions.
\end{abstract}

\section{Result, conventions, and proof status}

Throughout, a machine has one two-way infinite binary tape, blank symbol
zero, and one head initially at coordinate zero. Every working transition
writes a bit and moves exactly one cell left or right. Dense state zero is
the start; states $0,\ldots,193$ are working states; label 194 has no rows
and is terminal. An arithmetic absorbing halt code used in proofs does not
add a physical working state.

\begin{center}
\begin{tabularx}{\linewidth}{@{}lrrX@{}}
\toprule
Design & States & Blank startup & Distinguishing change\\
\midrule
PA194AX11QGH &194&57,922&Different recurring AX/generalization/Shift interface.\\
PA194AX11HR &194&48,320&Ten active routing changes and a different complete register layout.\\
\bottomrule
\end{tabularx}
\end{center}
The startup counts refer to the complete first canonical source frame,
including every nonzero tape cell, the head, the instruction address,
all nine registers, and the spare tail. They are not halting-time claims
and do not predict the running time of proof enumeration.

\begin{theorem}[Written mathematical result]
For either explicitly supplied table $M$,
\[
 \ipra\vdash\Con(\PA)\longleftrightarrow\neg\Halt_{\rm blank}(M).
\]
The proof uses the new execution arguments below and the written numerical
calculus calibration in the pinned incoming AX11H archive identified in
Section~\ref{sec:calibration}. It does not assume $\Con(\PA)$.
\end{theorem}

This is a theorem at the level of the supplied written proofs. The
machine-specific finite identities are accompanied by executable
certificates. The complete mathematical proof compiler is specified in the
inherited paper but has not been implemented and run as a full compiler;
the whole consistency theorem has not been checked by a Lean kernel.
These distinctions are part of the result, not a substitution of bounded
simulation for a universal assertion.

\section{Comparison of the current designs}
\label{sec:comparison}

\subsection{Scope and identity}

The maintained catalog records 13,006 historical table occurrences in 82
filed packets and 682 catalog classes. Repeated byte strings and control
renamings account for much of that count. Of those classes, 94 have 194
reachable working controls. The four current incoming ZIP files contribute
22 further literal-table classes, including 16 at 194: five principal
proposals and eleven auxiliary/search variants. The combined catalog has
704 classes and 110 at 194. The 53 classes at 193 are runtime/search or
rejected objects; their presence does not establish a blank-start
consistency machine.

The archive's comparison ledger includes every 194-state class in this
scope and its source location and status. It distinguishes a report's
claim from a mathematical proof inspected here and from a verification
actually rerun here. The filed census is inherited from its pinned
manifests; the incoming literal files and novelty comparisons were freshly
parsed. Table expressions present only in executable code or JSON are not
silently counted as an exhaustive literal-table census. The report-family
review supplements the table comparison.

For a spanning table, identity means an isomorphism of the transition
graph preserving both read symbols, writes, moves, and terminal behavior.
An initial-state convention is retained separately. This matters for
native-numbered copies and older packets in which state zero is not the
intended start. The supplied novelty checks also examine reflected tape
directions and terminal-action conventions. Nonspanning diagnostic tables
are handled separately: the catalog's maximal-reachable invariant is not
advertised as a canonicalization of every disconnected graph.

\subsection{Architectural comparison}

Nearly all proposed 194-state designs share a nine-register numerical
calculus engine, a structured binary source decoder, and an AX emitter
represented by a shared reader graph. Their substantive differences lie
in the following axes; the detailed ledger identifies the exact tables.

\begin{longtable}{@{}p{0.22\linewidth}p{0.70\linewidth}@{}}
\toprule

\midrule\endhead
Primary PA194 / alternate associations &

Changing numerical constructor coefficients changes emitter sharing and

Reordering generated heads or changing diagonal placement can improve

Changing non-arithmetic entry routes changes the physical register

Two putative savings may use the same provider control or the same
history bit. Therefore their state counts cannot be added without
checking the final simultaneous table. Likewise a correct register
instruction implementation says nothing about blank initialization until
that separate execution reaches its full frame.

\section{Which calibration is being used}
\label{sec:calibration}

The maintained PA README says that the repository's literal-machine iPRA
equivalence remains open. It also records extensive standard finite-run
Lean results and some model-uniform components. Standard finite-run
theorems alone cannot supply a nonstandard-time arithmetic reduction.

The latest current incoming AX11H archive adds a separate written
completion. Its literal tables coincide with the filed AX11H and QAX11H
tables; the new content is the proof. We inspected its physical/source,
source/command, command/calculus, Foundation-adapter, term-supplier,
forward-calibration, reverse-soundness, and final-transfer arguments.
Representative critical constructor recipes were checked against the
retained Lean source. No blocking defect was found in that inspected
chain. The precise review and fresh replay records are included; this is
not an assertion that approximately 700 inherited Lean reference files or
the whole new arithmetic proof have been independently kernel verified.

The written chain supplies the following indispensable ingredients.
First, it arithmetizes the actual symbolic tape interpreter and proves
each normalization, unary sweep, and list sweep by quantifier-free
induction. Its complete frame includes the growing header gap and spare
tail, and its exact instruction durations are primitive recursive.
Second, it matches the entire primitive source graph to explicit
arithmetic templates, including their scratch invariants and clocks.
Third, it proves an all-store command compiler and a cofinal enumeration
argument without assuming that failed candidates reset the store.

The forward PA proof translation uses finite request trees. Each recursive
family computes its child queries before their proof results and decreases
an explicit source rank; parameter growth is permitted inside a bounded
primitive recursion. Reverse evaluation of the finite tree maintains
Boolean checking invariants. Term uniqueness is completed before calls
on substituted terms, avoiding the false assumption that such a term is
smaller than the original variable. The Foundation adapter distinguishes
its square-pairing falsity code 13 from the numerical calculus code 1.
Finally the two model-uniform $I\Sigma_1$ reductions are transferred to
the required negative iPRA statements without Markov's principle.

\subsection{Representation and the proof in iPRA}

The source address, header gap, and block code $B(v)=0\,1^{v+1}$ are as in
the incoming physical proof. Encode the register vector by placing logical
value $r_i$ at physical position $\pi(\mathrm{old}(i))$. The spare tail is
an arbitrary nonempty finite list, outside all nine working registers.
The whole configuration coding, including the complete blank exteriors,
is primitive recursive.

The independent literal verifier rederives the four generic list sweeps
from the candidate rows, using the new logical-to-physical map. It checks
every increment, both decrement outcomes, every jump and the halt case
for arbitrary register values, header gap, and spare list. The source
array is byte-identical to the base AX11H array. Its 3,671 sites give 4,778
outcomes; nonhalting endpoints are matched to the full independently
resolved source graph, not only to the intended register update.

\begin{lemma}[Exact source simulation]
Let $P$ be the unchanged AX11H primitive source program and $E_\pi$
the new frame encoding. There are primitive recursive frame-update and
duration functions such that every live source step is represented by
an exact positive-duration literal segment of AX11HR. The statement and
its finite table instances are provable in iPRA using the symbolic-rule
proofs of the included physical audit.
\end{lemma}
\begin{proof}
The four list lemmas and ordinary row rules retain their arithmetic
proofs. The candidate-specific symbolic replay instantiates those rules
with the permuted frame. Their conclusions are complete configuration
equalities, with the stated source endpoint and register change; all
ordinary durations are affine expressions with nonnegative coefficients
and constant at least three. The finite certificates therefore compose
by equality substitution. No inference from a sample of numeric register
values is used. Finite source-address padding and the scratch-free frame
closure are checked separately for every nonhalting outcome.
\end{proof}

The direct blank replay reaches source site 25, native state 84, head $-2$,
and the complete encoded initial store $(2,0,\ldots,0)$ after exactly
48,320 transitions. Its extra gap is zero and its 26 spare values are all
one. Equality of the entire finite support, including its zero exterior,
is checked. This finite trace gives a closed arithmetic equality.

For precision, let $z_k$ be the iterated encoded source frame and define
the cumulative duration $\tau(0)=0$,
$\tau(k+1)=\tau(k)+d(z_k)$, putting $d=0$ after source halt.
Quantifier-free induction gives
\[
 \Run_M(48320+\tau(k),\mathrm{blank})=E_\pi(z_k).
\]
While $z_k$ is live, positivity of all preceding segments gives
$\tau(k)\ge3k$. A source halt therefore supplies a literal halting
witness. Conversely, if the literal table has halted by time $t$, choose
$k=t+1$. If that source frame were live, the equality and the bound would
place a nonhalting literal state after an already absorbing halt, a
contradiction. Decidability of the encoded source halt flag proves the
reverse implication intuitionistically. This is an arithmetic argument
for arbitrary, including nonstandard, times.

The old AX11H physical theorem gives the same source halting predicate.
Consequently
\[
 \ipra\vdash\Halt(\mathrm{AX11HR})\leftrightarrow
                   \Halt(\mathrm{AX11H}).
\]
Negating both sides intuitionistically and composing with the stated
written base calibration proves the result for AX11HR. No new logical
axiom, PA proof translator, or scheduler correctness assumption is needed
for this layout transport.

\subsection{What the layout search does and does not prove}

The search enumerated all $8!=40,320$ physical permutations fixing the
initially nonzero register's position. It used a 100,000-transition cap
and a tape window of coordinates $[-512,1535]$, seeking the exact fixed
source frame with extra gap zero and 26 one-valued spares. On AX11H, 137
layouts reached that exact frame; 48,320 was the shortest observed time.
The remaining 40,183 were unsuccessful under these search limits, which
does not prove that they cannot initialize in some other way. The final
candidate's positive startup certificate has no such uncertainty.

The reduction in this particular initialization is
$57,922-48,320=9,602$ transitions, about $16.58\%$.
This is not a claim of a globally optimal layout or a uniform speedup of
the infinite proof-enumeration run. A separate primary-PA194 layout search
found a 40,856-step initialization and passing source contracts; it is
retained as exploratory search evidence rather than used as the principal
calibration base of this second construction.

For the new AX11QGH table, the second search screened 24,426,152 single-row
assignments, 122,567 complete row pairs, and 90,501,864 local simulations.
For AX11HR the corresponding counts are 24,241,464 single-row assignments,
120,856 full pairs, and 86,710,550 local simulations, also without a survivor.
The neutral-precondition stage added 15,800,524 ordered pair checks.
The programs also recover a known nonvacuous duplicate-state merger in a
separate synthetic positive control. Exact-coordinate comparisons and
input validation are part of the shipped final replays.

The invariant used by these searches starts with the blank initial
radius-five window. On each projected step it permits either newly
entering boundary bit. It therefore overapproximates every actual blank
run window. A proposed contraction must reconnect the complete tape
window, head coordinate, and projected state after positive numbers of
old and new steps. Neither trace reads outside the checked window.
Unchanged states have a one-step correspondence. An accepted certificate
would compose by primitive-recursive induction into halting equivalence.
For a two-row rewrite, both original incoming states are checked.

This explains both the strength and the limitation of a negative result.
An actual smaller machine may need a stronger reachability invariant,
more space or time before reconvergence, several jointly changed rows, a
different tape representation, or a different source program. No global
state-count lower bound follows.

\subsection{Alternative logical heads and emitter searches}

We also tested two genuinely different orientations of the first logical
head. With $\Box A=U(D,A)$ and $\Diamond A=N(\Box N(A))$, the old
schema is $(\Diamond\Box A)\to A$. Two interchangeable replacements are
\[
 B_D(A)=A\to\Box\Diamond A,\qquad
 C_D(A)=N(A)\to\Box N(\Box A).
\]
The appendix gives fixed proof templates and primitive-recursive proof
translations in both directions. Each schema has seventeen emitter
tokens. They were crossed with equality orientation, three premise
exchanges, diagonal parameters, and source-tree shapes, then searched
using local/shared associativity changes and parameter permutations.

The B, C, and B-plus-direct-binder runs made respectively
2,996,090, 2,952,436, and 717,499 proposals: 6,666,025 in total.
Their best optimistic effective-reader counts were 65, 68, and 65;
adding the 134 fixed controls gives 199, 202, and 199. These are search
scores, not simultaneous-fold certificates or proposed consistency
machines. No design at or below 194 states resulted. Exact seeds,
iteration limits, random seeds, source, best grammars and completed logs
are retained under \file{search/modal_heads/}.

\subsection{The initialization obstruction in the known 193-state core}

The prominent earlier runtime reduction identifies native control 301
with 88 and installs
\[
 (88,0)\mapsto(0,L,51),\qquad(51,0)\mapsto(0,R,122).
\]
On a marked runtime block the cell after its delimiter is one, and
states 16 and 122 have the same read-one transition. This explains the
runtime identity. During bootstrap that following cell can be zero.
The splice then takes the wrong branch and reaches the outward row
$(35,0)\mapsto(1,R,35)$ on a blank half-line. The known fixed-start
trace reaches this obstruction after 92 steps. Existing all-start,
one-bit-entry, and register-allocation audits rule out several obvious
repairs. The contrast between a good runtime and a failed initialization
is an actual configuration mismatch, not merely an unproved termination
claim.

\section{Lessons from the other requested source areas}

The ZFC reductions supply useful history-sensitive folds and runtime
identities, including the splice just discussed. The relevant transfer
unit is a concrete local tape contract with its incoming history, not a
nominal state-count saving. Bootstrap and provider compatibility must be
checked on the target PA table.

DiophantineConsistency supplies ways to move between proof search and
arithmetical or polynomial predicates. Such a reformulation preserves
the intended logical content only with explicit witness translations;
it does not by itself compress the binary tape implementation. We did
not obtain a cheaper counter machine for a Diophantine checker, so no
state saving is attributed to that route.

ConciseIPRA is useful here for its discipline about the actual proof
checker and weak induction. The finite-demand proof compiler and the
explicit positive-duration simulation are concrete ways to avoid an
unbounded all-environments induction. A shorter axiomatization or a
smaller implementation in a high-level language does not alone imply a
smaller two-symbol transition table. No such unsupported inference is
used in the constructions.

\section{Further research questions}

\begin{enumerate}
\item Can a bootstrap-sensitive repair of the 301/88 runtime splice be
found with two or more jointly neutral changes, or with a different
finite-support frame? The exact exceptional zero/read-zero case is a
better synthesis target than another unconditional marker merge.
\item Can the new AX11QGH command interface change the useful source
invariants enough to certify a merge rejected by the coarse blank-window
overapproximation? Any proposed invariant should be proved before it is
used to discard a branch.
\item Does a logically equivalent replacement of an entire head improve
reader sharing? We examined the modal dual of $h_1$,
$H\to\forall_D\exists_D H$, using classical contraposition and
quantifier distribution. No accepted 193-state construction resulted;
the idea remains distinct from merely exchanging two premises.
\item Can the arithmetic engine and the spare-tail representation be
redesigned together, so that initialization no longer uses a transition
whose runtime contract has a different incoming-bit hypothesis?
\item Can the complete written finite-demand PA proof compiler be
implemented and its requested-label invariants kernel checked? This is
the highest-value verification step for the current mathematical
calibration, independent of further state reductions.
\item Can physical allocation and decoder folding be optimized jointly
with a certificate that tracks both startup and all source instructions?
The new layout demonstrates that active routing choices substantially
change initialization even at a fixed state count.
\end{enumerate}
