This bundle records two finite searches on the literal PA194CS and new PA194N (NoPush, also called PA194NP in the raw search records) tables. It does not prove a state lower bound. No state reduction was found within either search rule.

The state starts are native 74; halt is 254. Context windows have eleven cells. The collection includes every source outcome, symbolic unary-sweep interiors, four list-block proofs with arbitrary list context, and the complete finite blank initialization. Unknown exterior bits and unresolved run lengths are conservatively overapproximated. Native table identities, source counts and startup lengths appear in `results/summary.json`.

## Common-action merger

`source/action_merge_all.cpp` is retained from the supplied PA194 cached-research packet. For each two distinct working controls except the start, it seeks common replacement first actions that reproduce each former action by at most 300 transitions inside the window, with every cell restored except the cell changed by the former action. The continuation restrictions forbid circular reliance on changed endpoint rows. The search returns no candidates for either supplied context set.

## Incoming-edge bypass (new search operator)

`source/edge_bypass.cpp` is a different sufficient contraction rule. It selects a control without a self-loop and considers each incoming row separately. Each such row may receive its own write bit, direction and existing target. Its replacement must simulate the original incoming transition followed by one transition of the eliminated control. Every continuation avoids the eliminated control and all rows being rewritten, and must reach exactly the same target control, head position and eleven-cell tape within 300 steps. Thus this operator can eliminate a control without identifying all of its incoming edges with one common surviving control.

No control passes all its incoming-edge checks on either input. The rule is finite and incomplete: it excludes self-looping removed states, bounded continuations that leave the window, simulations requiring several modified helper rows, and other globally valid program transformations. Empty JSONL outputs are intentional; companion logs show all processed controls.

## Replay the frozen searches

Run from this directory with Python 3.10+ and a C++17 compiler:

```sh
mkdir -p replay
c++ -O3 -std=c++17 source/action_merge_all.cpp -o replay/action_merge_all
c++ -O3 -std=c++17 source/edge_bypass.cpp -o replay/edge_bypass
replay/action_merge_all inputs/NOPUSH.native.tm 5 300 inputs/NOPUSH.patterns_k5.txt > replay/NOPUSH.merge.jsonl 2> replay/NOPUSH.merge.log
replay/edge_bypass inputs/NOPUSH.native.tm 5 300 inputs/NOPUSH.patterns_k5.txt > replay/NOPUSH.bypass.jsonl 2> replay/NOPUSH.bypass.log
replay/action_merge_all inputs/CS.native.tm 5 300 inputs/CS.patterns_k5.txt > replay/CS.merge.jsonl 2> replay/CS.merge.log
replay/edge_bypass inputs/CS.native.tm 5 300 inputs/CS.patterns_k5.txt > replay/CS.bypass.jsonl 2> replay/CS.bypass.log
```

To regenerate contexts from literal rows, source paths, and the inherited independent symbolic induction engine:

```sh
python3 source/collect_contexts.py inputs/NOPUSH.native.tm inputs/NOPUSH.sites.json 58154 replay/NOPUSH-contexts
python3 source/collect_contexts.py inputs/CS.native.tm inputs/CS.sites.json 57768 replay/CS-contexts
```

Do not use Python `-O`: assertion checks are part of the executable evidence. `source/reference/README.md` records the provenance of the imported symbolic executor. This context collection is discovery evidence, not a new proof-assistant theorem. The final successful machine has a separate universal physical certificate.
