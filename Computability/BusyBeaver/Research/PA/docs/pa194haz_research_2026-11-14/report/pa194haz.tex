\begin{abstract}
We give a complete binary single-tape machine, PA194HAZ, with 194 working
states and an ordinary mathematical proof, formalizable in PA using the
supplied development's unchanged calibration and arithmetic-block lemmas,
that its blank nonhalting is equivalent to $\Con(\PA)$. The machine changes
five transitions of the primary PA194 table. It combines the supplied
MPH cached-result protocol, the A/D physical register exchange, and a
known-zero AX closure. The four-transition companion PA194HA is also supplied.
Each constituent idea has a prior instance in the supplied corpus; the
contribution is the particular composition, its explicit command-level
proof, its source invariant, and its verified physical realization.

The audit covers all 41 placed PA research packets and all five incoming
archives at a pinned revision. Their 3,597 recognized table occurrences
contain 666 byte forms. The 664 forms with a spanning control root give
476 action-graph classes, including 28 classes at 194 states. Both new
machines differ from every recorded 194-state class even under control
renaming, arbitrary spanning-root choice, tape reflection, and global
symbol complementation. Auxiliary and rejected tables are included.

Executed Python and JavaScript checks agree on all 4,751 outcomes of
HAZ's 3,650-site source and its exact 58,122-step blank initialization.
A separate finite control-graph checker validates the four-site invariant.
No sub-194 machine was obtained, and no lower bound or new proof-assistant
endpoint is claimed. Complete tables, source, proofs, corpus data, negative
search receipts, and offline reproduction programs accompany this report.
\end{abstract}

\section{The result and its precise scope}

The machine uses alphabet $\{0,1\}$ on a two-way infinite tape, initially
zero everywhere, with the head at cell zero. Every transition writes one
bit and moves one cell left or right. There are 194 working states; the
halt label is separate. In the dense table the start is zero, working
states are $0,\ldots,193$, and halt is 194. The native start is 74 and the
native halt is 254. All 194 working controls are graph-reachable from the
start; this is a graph property, not a claim that the blank run visits them all.

The claimed arithmetic result is
\[
 \PA\vdash\bigl(\neg\Halt(\mathrm{PA194HAZ},\text{blank})
                 \leftrightarrow\Con(\PA)\bigr),
\]
where $\Halt$ is the usual existential finite-run predicate and $\Con(\PA)$
is the absence of a PA proof of $0=1$. The proof is given below by composing
finite syntactic proof transformations and source-to-machine simulation.
The corresponding statement also holds for PA194HA.

global read/write symbol complementation and left/right reflection, we

lexicographically least complete encoding. Equality of these encodings
exactly decides the stated graph equivalence for this class of tables.
The replay program compares complete strings; hash values are identifiers,
not the basis of an assumed collision-free proof.

\section{Numerical calculus and the hybrid command interface}

Let
\[
p(a,b)=\frac{(a+b)(a+b+1)}2+b,\qquad [a;w]=p(a,w).
\]
The total inverse projections satisfy $\hd(0)=\tl(0)=0$ and $[0;0]=0$.
A store is $\st{t}{w}{d}{h}$: visible theorem, encoded stack, numerical offset, cached theorem. A canonical store means $\st{t}{w}{0}{0}$; its top and stack are otherwise arbitrary.

Retain the numerical formula constructors
\[
 I(a,b)=4p(a,b),\quad M(a,b)=4p(a,b)+1,\quad
 U(a,B)=4p(B,a)+2,\quad E(a,b)=4p(a,b)+3.
\]
Code zero is truth; code one is contradiction $M(0,0)$. Write
\[
N(B)=I(B,1),\quad B\wedge C=N(I(B,N(C))),\quad
\exists x_a B=N(U(a,N(B))).
\]
The diagonal head is $\Gamma(B)=I(B,U(B,B))$.

The six ordinary heads are
\begin{align*}
L_1(D,H)&=I(\exists x_D U(D,H),H),\\
L_2(D,A,H)&=I(U(D,U(A,H)),U(A,U(D,H))),\\
L_3(D,A,H)&=I(M(H,D),I(E(H,A),M(A,D))),\\
L_4(D,A,H)&=I(E(H,D),I(M(A,H),M(A,D))),\\
L_5(D,H)&=\exists x_D E(H,D),\\
L_6(D,A,H)&=I(U(D,A),I(U(D,I(A,H)),U(D,H))).
\end{align*}
The dominated propositional head is
\[
 \rho(a,b,c,u)=I(I(I(c,u),a),I(I(a,c),I(b,c))),\qquad u\le a.
\]
For the separation gate put
\begin{align*}
 V(a,b,c)&=I(M(a,b),U(c,M(a,b))),\\
 P(a,b,c)&=I(c,M(c,b)),\\
 B(a,b,c)&=U\bigl(b,I(M(a,b),P(a,b,c))\wedge I(M(c,b),c)\bigr),\\
 Q(a,b,c)&=U(c,I(B(a,b,c),N(P(a,b,c)))).
\end{align*}
The guarded head $G(a,b,c)$ is zero if $c=a$ or $c=b$, and otherwise is
$N(I(V(a,b,c),Q(a,b,c)))$. This is the unchanged numerical calculus of \cite{calibration}.

\subsection{Commands}

The hybrid Shift is
\[
 \Shift\st{t}{w}{d}{h}=
 \begin{cases}
 \mathsf{halt},&t+h=1,\\
 \st{h}{\tl(w)}{d}{\hd(w)},&t+h\ne1.
 \end{cases}
\]
For $y=d+x$, the changed MP command is
\[
 \MP_x\st{t}{w}{d}{h}=
 \begin{cases}
 \st{0}{w}{0}{y},&I(t,y)=h,\\
 \st{0}{w}{y}{0},&I(t,y)\ne h.
 \end{cases}
\]
Neither branch pushes on the stack. PA194C has this MP behavior but a different Shift test, $h=1$.

For $\AX_{c,x,y}$ set $D=d+x$, $H=h+y$, $A=c$. AX returns top $G(H,D,A)$, clears offset and cache, and pushes the following ten entries, top first:
\[
 \Gamma(A),L_6,L_5,L_4,L_3,L_2,L_1,\rho(D,A,H,d),U(d,h),t.
\]
The arguments of $L_i$ are those displayed above. There are nine newly generated formulas and the saved incoming top.

Every generated formula except $U(d,h)$ is divisible by four. The universal formula is congruent to two modulo four and at least two. The gate is divisible by four. In particular, no generated formula is code one.

\section{A total Pop operation and complete proof compilation}

Throughout this section set $n=10$, the exact push count of AX. Semicolon denotes execution in the written order. The total Pop identity also holds in the supplied uncached protocol; it is used here with the cached-result MP interface.

\begin{lemma}[Total stack operations]
Define
\begin{align*}
 \Push_n&=\AX_{0,0,0};\Shift^{n-1};\MP_0,\\
 \Pop_n&=\AX_{0,0,0};\Shift^{n+1},\\
 \Discard_n&=\MP_1;\AX_{1,0,0};\Shift^n;\MP_0.
\end{align*}
Then
\begin{align*}
 \Push_n\st{t}{w}{d}{h}&=\st{0}{[t;w]}{0}{0},\\
 \Pop_n\st{t}{w}{d}{h}&=\st{t}{\tl(w)}{0}{\hd(w)},\\
 \Discard_n\st{t}{w}{0}{0}&=\st{0}{w}{0}{0}.
\end{align*}
All three identities are total.
\end{lemma}
\begin{proof}
The intermediate generated formula codes cannot trigger the sum-one test. After $n-1$ Shifts in Push, the cache is $U(d,h)$, whereas every implication code is divisible by four; MP therefore fails at parameter zero and clears both visible registers, preserving $[t;w]$.

After $n$ Shifts in Pop, the top is $U(d,h)$, the cache is the saved $t$, and the stack is the original $w$. The last Shift is safe because $U(d,h)+t\ge2$. This handles $t=1$ explicitly.

In Discard, the first MP fails because $I(t,1)>0$ and the cache is zero. It establishes offset one and zero visible theorems. After AX and $n$ Shifts, top is $U(1,0)$, cache zero and stack $w$. The final comparison also fails since $I(U(1,0),0)>0$.
The proof uses pairing identities, not a false assumption that a zero push increases canonical stack length.
\end{proof}

Define $\operatorname{Offset}_0$ to be the empty word and
$\operatorname{Offset}_i=\MP_i$ for $i>0$.
\begin{lemma}[Generalization]
The word
\[
 \Gen_{i,n}=\Push_n;\operatorname{Offset}_i;\Shift;\AX_{i,0,0};\Shift^n
\]
maps $\st{a}{w}{0}{0}$ to $\st{U(i,a)}{w}{0}{0}$ for every $a,w$.
\end{lemma}
\begin{proof}
Push stores $a$ and clears the visible registers. Offset establishes $d=i$. Shift then loads $a$ into the cache. The last generated AX head is $U(i,a)$, which the final $n$ Shifts select while recovering the saved zero cache. No sum-one check fails, including when $a=1$.
\end{proof}

For a head at top-down position $1\le j\le n-3$, use
\[
 \operatorname{Select}_{j,D,H,A}=
 \Discard_n;\AX_{A,D,H};\Shift^{j+1};\Pop_n^{\,n-1-j}.
\]
From any canonical incoming store $\st{t}{w}{0}{0}$ this selects that head, retaining $w$ and zero offset and cache. At $n=10$, positions $1,\ldots,7$ are $\Gamma(A),L_6,L_5,L_4,L_3,L_2,L_1$. The dominated head with $u\le a$ is selected by
\[
 \Discard_n;\operatorname{Offset}_u;\AX_{b,a-u,c};\Shift^{n-1};\Pop_n.
\]
The separation gate is selected by
\[
 \Discard_n;\AX_{c,b,a};\Pop_n^n.
\]
These are the correctly adjusted ten-entry selectors. Old nine-entry indices would be wrong.

\begin{lemma}[MP suffix]
On $\st{0}{[a,I(a,b),0;w]}{0}{0}$, the word
$\Shift;\Shift;\MP_b;\Shift$ halts if $a=1$ or $b=1$; otherwise it returns $\st{b}{w}{0}{0}$.
\end{lemma}
\begin{proof}
The successive nonhalting stores are
\begin{align*}
 &\st{0}{[I(a,b),0;w]}{0}{a},\\
 &\st{a}{[0;w]}{0}{I(a,b)},\\
 &\st{0}{[0;w]}{0}{b},\\
 &\st{b}{w}{0}{0}.
\end{align*}
The second Shift halts exactly when $a=1$, and the last exactly when $b=1$. The inserted zero restores the underlying stack.
\end{proof}

Proofs in the numerical calculus are built from the displayed axioms by MP and generalization. Define $W_p$ by recursion on such a proof. An axiom uses its selector. Generalization at $i$ uses $W_{p_0};\Gen_{i,n}$. For MP with minor proof $p_0$ of $a$ and major proof $p_1$ of $I(a,b)$, use
\begin{align*}
W_p={}&\Discard_n;\Push_n;W_{p_1};\Push_n;\\
     &W_{p_0};\Push_n;\Shift;\Shift;\MP_b;\Shift.
\end{align*}

\begin{theorem}[All-store completeness]
For every $t,w$, $W_p$ from $\st{t}{w}{0}{0}$ either halts or returns
$\st{\operatorname{concl}(p)}{w}{0}{0}$.
If $p$ proves code one, then
\[
 \AX_{0,0,0};W_p;\Shift
\]
halts from every incoming store.
\end{theorem}
\begin{proof}
Induct on $p$, using the selector, generalization and MP identities. In the MP case the first Discard and Push insert the needed dummy zero. An early halt is already a successful completeness outcome. For the last assertion, the initial AX clears offset and cache. If $W_p$ returns, it leaves top one and cache zero, so the final Shift halts.
\end{proof}
This universal incoming-store property is the correct scheduler interface. The inherited scheduler carries its store between command words; a completeness proof assuming a fresh reset after every trial would be insufficient.

\section{Soundness and PA formalizability}

Annotate top, cache and every canonical live stack entry with a numerical-calculus derivation. The offset requires no proof. Code zero has a fixed derivation, obtained from the all-zero dominated propositional head.

AX supplies its axiom instances, generalizes the cached theorem to $U(d,h)$, preserves the incoming top and clears visible cache. Successful MP obtains a proof of $y$ from proofs of $t$ and $I(t,y)$ and puts $y$ into the cache. Failed MP uses the fixed zero proof. A nonhalting Shift moves existing annotations.

If Shift halts, $t+h=1$ implies $(t,h)=(1,0)$ or $(0,1)$. One of the visible annotations is therefore a refutation. Canonical stack expansion handles $[0;0]=0$: a pop of numerical zero supplies the fixed truth proof.

\begin{theorem}[Command equivalence]
The HA command enumerator halts exactly when its unchanged numerical calculus has a refutation.
\end{theorem}
\begin{proof}
The annotation invariant gives soundness. The all-store contradiction word and the inherited exhaustive scheduler give completeness.
\end{proof}

The proof transformations used here are primitive recursive: pairing and projections, finite command words, recursive proof-tree compilation and annotation updates. Their correctness follows by induction on finite proofs, words and runs, all available in PA. No truth or reflection principle for PA is used.

The inherited numerical calibration \cite{calibration} supplies proof translations between numerical refutations and PA refutations. Its ingredients include diagonal freshness, syntactic recovery of membership rewriting and equality interfaces, a finite-binary-membership interpretation, and uniformly proof-producing PA finite-comprehension induction templates. The exceptional code identity $I(0,0)=0$ is treated explicitly. This report retains that ordinary calibration; it does not replace it with a new kernel-checked endpoint.

\path{original_pa195_calibration.tex}, \path{diagonal_calculus.tex}, and

Each nonhalting primitive source step has a positive-duration physical
realization with its complete frame and correct successor. Concatenation
gives physical completeness. For the converse, suppose the physical run
first halts at time $T$. If the source did not halt, $T+1$ nonhalting source
steps would give a nonhalting physical run beyond time $T$, contradicting
determinism. This finite argument is formalizable in PA and avoids any
assumption that a long observed run proves nonhalting.

\begin{theorem}[PA calibration of the literal tables]
Using the unchanged inherited arithmetic-block and numerical-calibration
lemmas specified above, for $M\in\{\mathrm{PA194HA},\mathrm{PA194HAZ}\}$,
\[
 \boxed{\PA\vdash
       \bigl(\neg\Halt(M,\text{blank})\leftrightarrow\Con(\PA)\bigr).}
\]
\end{theorem}
\begin{proof}
The HA command compiler, soundness invariant and exhaustive scheduler
translate between finite source halts and numerical refutations. Compose
with the inherited PA-refutation translations. The four-site invariant
transfers this source theorem to HAZ. Compose each source theorem with
its universal positive-duration refinement and exact initialization.
Negate the resulting equivalence of existential halting and PA-refutation
predicates. All new finite transformations and inductions are available
in PA; no PA reflection principle is used.
\end{proof}
The receipts explicitly record \texttt{kernel\_checked: false}. This
qualification concerns the form of verification, not an assumption of
$\Con(\PA)$ in the equivalence theorem.

\section{Attempts to get below 194 states}

\subsection{Bounded physical quotients}

Three sufficient contraction rules were implemented. The first merges a
control into another through a bounded local detour that restores the
complete local tape, head and endpoint modulo the proposed alias. The
search includes arithmetic controls. The second represents the removed
control with a head displacement of $\pm2$, compensating incoming movement.
The third represents it by toggling a neighboring marker bit, compensates
the incoming write, and requires restoration before continuation.

A radius-$r$ abstract context retains the $2r+1$ cells around the head.
Boundary transitions admit both possible new bits, giving a conservative
reachable-window invariant. The limits below restrict the sufficient
certificate rules and detour lengths, not the represented natural
register values. Failure to find such a certificate is not a lower bound.

can be inspected rather than inferred from the number of trials.

\subsection{Transfer from ZFC and concise iPRA}

The ZFC omit-zero alternative \cite{zfc} shows that removing the
successful-MP dummy push can preserve the consistency target after changing
the proof compiler. It changes native target 98 to 114, removing 19 source
primitive occurrences while retaining 218 physical states in that ZFC
construction. PA194N is the corresponding supplied PA no-push direction.
HAZ instead uses target 130 and the cached-result interface. Source trace
equality is not available for these MP changes, which is why the explicit
command proof is needed.

Concise iPRA \cite{ipra} suggests restricted term forms, checking a rule in
its consumer context, and syntactic proof translations. Its scalar core
uses zero, successor and iteration; its equality, Q and D formula forms
are useful checker-compression ingredients. A PA-calibrated refutation
checker built from such a core remains a possible direction. The existing
iPRA checker alone has a different consistency target. Its short high-level
source also does not price the binary-tape register engine, scheduler and
blank initialization needed for a state bound.

The most direct remaining physical target is an effective AX-reader score
59 with the 134-state fixed core, or a certified net saving in that core.
A useful next search would jointly vary the emitter grammar and a proved
tape marker invariant, rather than count nominal folds independently of
the states that implement their contexts. These are research proposals,
not unverified machines offered as solutions.

The Python and JavaScript construction checks, independent invariant
checker, and corpus checks were executed successfully during this work.

and both candidates.

\begin{verbatim}
node search/search.cjs machine/pa194haz.native.tm 74 8 384
\end{verbatim}
For the report, run \texttt{latexmk -pdf pa194haz.tex} in \path{report/}, or
run \texttt{pdflatex -halt-on-error pa194haz.tex} twice. This PDF was compiled
from the supplied LaTeX and visually inspected. Python 3.10 or newer,
a recent Node.js with standard modules, and a conventional TeX Live
installation suffice. No Lean installation is required for these finite
checks; compiling a new kernel proof is not one of the reproduced steps.

The main deliverables are the native/dense machines, label maps, complete
resolved sources, manuscript and PDF. The package also contains execution
receipts, the independent invariant certificate, the 41-packet ledger,
all 667 prior raw byte forms, graph representatives and manifests, search
code/results, inherited proof texts, provenance and licenses. A top-level
\path{SHA256SUMS} authenticates the packaged files.

The calculus, register engine, compilation interfaces and original 194-state
allocation are credited to the supplied ProveIt work and James Chang's

relative to the fully inspected literal corpus. Their mathematical and
