\begin{abstract}
We deliver two complete binary, single-tape, blank-start machines with
\textbf{194 working states}, called PA194C and PA194CS. The requested
strict reduction below 194 was not obtained. Both fallbacks are materially
different from the three positive 194-state constructions in the supplied
corpus. PA194C returns successful modus-ponens conclusions in a cache and
tests that cache in Shift. PA194CS further removes a restoration loop by
using symmetry of a destructive equality routine, and recovers its state
cost with a new contextual fold. Their sources have 3,649 and 3,646 primitive
instructions, compared with 3,673 in the supplied constructions. Both
control graphs are new even after state renaming, change of designated
start, tape reflection and symbol complementation, and are distinct from
one another under those transformations.

Both machines retain the 67-reader/seven-fold axiom decoder. PA194CS adds
one controller reader and folds it with an existing decrement interface.
Both verification implementations pass all 4,749 and 4,745 respective
arbitrary-register instruction outcomes. The independent literal-tape
checker rederives its list lemmas from the actual rows and checks complete
blank initializations of 57,922 and 57,768 transitions. Ordinary finite-trace
preservation connects both machines to the supplied 195C source. Composing
this with the separate-head calculus's ordinary syntactic PA calibration
gives $\PA\vdash(\neg H_M\leftrightarrow\Con(\PA))$ for each delivered machine.
The logical calibration is an explicitly inherited mathematical dependency;
no new end-to-end proof-assistant theorem is claimed.

The comparison is pinned to ProveIt commit
\texttt{768c2be1a8e4d2fcf8aa3443c7b0f084d145734c}.
All 36 incoming archives were traversed, including nested packages, and
direct PA tables were included. We distinguish supported manuscript
constructions, conditional formal endpoints and rejected experiments.
The archive includes both complete transition tables, deterministic builders,
two verification implementations, source maps, evidence, search records,
the corpus census and this report's LaTeX source.
\end{abstract}

\subsection{What is new, and what is inherited}

The first contribution is a new verified composition at the current state
frontier. Neither the cached-head command convention nor the seven-fold
decoder is claimed as a newly invented ingredient. Both were supplied,
but they had not been combined into a 194-state machine in the pinned
corpus. The existing 194-state machines use the original Shift/MP
controller. PA194C changes six native transition rows, two source-tree
definitions, the full source graph, and command-level traces. It retains
the exact source of the supplied 195C machine while reducing that
machine's physical allocation by one control.

The second contribution is a further source-level simplification:
PA194CS exploits the fact that the existing equality test clears both
arguments on failure. It can exchange those arguments and omit an entire
restoration loop. A new three-step contextual simulation identifies a
controller reader with a decrement interface, retaining 194 controls.
Its source has 3,646 sites and its blank startup takes 57,768 transitions.
This is a new source change in addition to the first composition.

For PA194C the count is
\[
 \underbrace{134}_{\text{fixed controller and arithmetic}}
 +\underbrace{67}_{\text{raw axiom readers}}
 -\underbrace{7}_{\text{compatible contextual folds}}=194.
\]
PA194C removes 24 primitive source sites relative to primary PA194,
and has 31 fewer primitive branch outcomes. Its complete blank startup
takes 57,922 transitions, versus 58,154 for primary PA194 and 58,122 for
the existing A/D companion. The 232- and 200-transition differences are
startup comparisons; no uniform speed improvement for all computations
is asserted.

Let $H_M$ denote the usual arithmetic sentence asserting a finite halting
trace from the literal blank start of $M$. The proof is organized into
two levels:
\begin{enumerate}
\item The new, machine-specific preservation result is
      $\PA\vdash H_{194C}\leftrightarrow H_{195C}$.
\item The supplied logical calibration of the unchanged numerical
      calculus, together with its command compiler and scheduler, yields
      $\PA\vdash(\neg H_{194C}\leftrightarrow\Con(\PA))$.
\end{enumerate}
The second statement uses inherited ordinary mathematical theorems.
It does not acquire a kernel-checked status from the successful Python
certificates. The current repository itself leaves its machine-specific
iPRA consistency bridges open~\cite{pa-readme,pa194-endpoint}.

\section{Why the symbolic physical checks are universal}
\label{sec:universal}

The independent checker represents complete tapes by finite sequences
of fixed bits, constant-bit runs with affine lengths, arbitrary register
blocks and an arbitrary finite spare list, with blank exterior on both
sides. Its affine coordinates include the gap, nine independent register
values, the first spare value and the remaining list width. A positive
decrement represents the tested value as $v+1$; its zero branch sets that
value to zero. Other values remain independent.

Each elementary certificate rule has an ordinary arithmetic proof:
\begin{enumerate}
\item A literal transition is applied only when the scanned run has
      a positive constant part, so the scanned bit is determined for
      every assignment of its natural parameters.
\item A same-control sweep through a constant-bit run is exactly
      repeated application of one transition, proved by induction on
      its length. Its time and displacement are recorded symbolically.
\item A list sweep is justified by a generic one-block trace with an
      arbitrary value and arbitrary exterior contexts, followed by
      induction on the finite list. The four used one-block traces are
      rederived from the delivered table; each has duration $v+2$.
\item Normalization uses exact concatenation identities. For example,
      if $B(v)=0\,1^{v+1}$ and $C(v)=1\,0\,1^v$, then
      $C(v)1=1B(v)$. Its extension over a list and its reversal follow
      by finite-list induction. Adjacent blank zero runs may be absorbed
      into the infinite blank exterior.
\end{enumerate}
Induction on the checked certificate establishes equality with the
intended complete target frame. Nonnegative affine coefficients certify
all-natural length bounds. The positive constant part of the duration
is checked separately; the minimum over the delivered source contracts
is three. A nonhalting source outcome closes only at its exact target
frame, and cannot pass through the terminal control on the way.

These rules explain the universal quantification behind the 4,749 and
4,745 checks. The recorded 1,096,302 and 1,100,204 symbolic steps are verifier work, not a
bound on the physical runtime for arbitrary register values. The finite
57,922- and 57,768-step blank runs serve a different purpose: they establish
the exact initial frames, including every nonzero tape cell. They are not
evidence obtained by extrapolating a long nonhalting prefix.

\section{Logical calibration and its exact dependency}

The unchanged numerical calculus codes implication, membership,
universal quantification and equality by
\[
 I(A,B)=4p(A,B),\quad M(a,b)=4p(a,b)+1,\quad
 U(a,B)=4p(B,a)+2,\quad E(a,b)=4p(a,b)+3,
\]
where $p(a,b)=(a+b)(a+b+1)/2+b$. Code zero is truth, code one is
$M(0,0)$, and $N(B)=I(B,1)$. The transposed quantifier arguments are
part of the exact definition. The separate diagonal head is
$\Gamma(B)=I(B,U(B,B))$.

The supplied calibration uses the strict descent of formula components
to show that variable label $B$ is absent from the formula coded by
$B$. The exceptional truth case and $I(0,0)=0$ are treated separately.
Thus diagonal vacuity has a primitive-recursive proof-producing
translation into ordinary first-order arithmetic. The bundled and
separate diagonal presentations are intertranslatable by fixed classical
implicational derivations and suitable fresh parameters.

For the direction from numerical refutations to PA refutations,
membership is interpreted as finite binary membership. One convenient
formula is
\[
 \operatorname{Bit}(s,z)\equiv
 \exists u,v\,[s=(2u+1)2^z+v\ \wedge\ v<2^z].
\]
For each arithmetic formula $\theta$, PA proves finite binary
comprehension by induction on the bound: retain the old bitset when the
new instance of $\theta$ fails, and add $2^n$ when it holds. Substitution
of a formula's syntax into that induction-proof template is a primitive
recursive operation on proof codes. This is a syntactic construction,
not an appeal to an arithmetic truth predicate. Pointed separation
uses this comprehension with the proper variable-collision cases.
PA proves $\neg\operatorname{Bit}(x,x)$ uniformly, since
$\operatorname{Bit}(s,z)$ implies $z<s$. Thus a translated proof of code
one, the atom $M(0,0)$ with variable label zero, yields a PA refutation.

For the converse, the supplied proof recovers reverse membership
rewriting and neighborhood equality using pointed separation and
diagonal-code freshness, then substitutes these interfaces into the
PA-refutation compiler. The relevant proofs and exact axiom heads are
retained in \file{construction/logical_reference/}, including the
original PA195 calibration, the supplied 195S/195C preservation and
the primary PA194 calibration. They are cited inherited results rather
than a fresh claim that the physical verifier proves a logical theorem.

The command proof in Section~\ref{sec:pa194c} establishes both directions
between the unchanged calculus and the new source controller. It handles
the ten-entry AX interface, the zero-stack alias, early halts, and a
refutation word that works from every incoming store. The latter is
essential because the scheduler carries its store between trials.
The physical proof then transports that source result to the exact
literal binary machine. All proof-store annotations, finite trace
concatenations and bounded source iterations are available in PA.

\section{Ideas transferred from ZFC and ConciseIPRA}

The most concrete ZFC connection is the cached-result return convention.
The K217 cache-return composition explicitly moves a successful
modus-ponens conclusion into the cache instead of pushing a dummy zero
and copying to the current-formula register~\cite{zfc-cache}. Its source
and decoder checks did not themselves save a physical control, and its
modified full runtime had a separately stated proof boundary. The PA
corpus later combines the corresponding convention with H-only Shift.
PA194C carries that established PA controller into the smallest existing
decoder allocation and supplies the complete changed physical checks.

The wider ZFC search also illustrates why source simplification and
machine minimization must be combined: register roles, marker history,
scanner range and available helper states determine whether two
apparently useful savings can coexist~\cite{zfc-readme}. We used this
principle in the reader/fold searches and in verifying the controller
composition in its final table.

ConciseIPRA's small kernels derive substantial logical infrastructure
from a small native interface, and its artifacts insist on complete
checker costs and explicit interpretation boundaries~\cite{concise}.
That suggests looking for derived axiom heads and alternative proof
objects. It does not license replacing the PA proof search by an iPRA
proof search: their consistency assertions are different objectives.
Nor does a smaller Python checker automatically give a smaller binary
one-tape machine. This construction retains the existing PA-calibrated
calculus and uses those methodological lessons without attributing a
new logical compression to ConciseIPRA.

\section{Reproduction and package contents}

All primary construction and verification commands use Python 3.10 or
later and its standard library. Assertions must be enabled. From the
archive root run:
\begin{verbatim}
python3 -B construction/build_cached.py
python3 -B construction/verification/check_cached.py
python3 -B comparison/verify_novelty.py \
  construction/candidate/pa194C.tm \
  --census comparison/census.json
\end{verbatim}
The first command regenerates the exact table and the construction
receipt. The second writes new independent results under
\file{construction/verification/results/}. It can take several minutes.
The third checks the finite corpus novelty claim. Neither the stochastic
discovery search nor a new repository download is necessary to rebuild
and verify the machine.

For the symmetric-guard companion, run:
\begin{verbatim}
python3 -B secondary/pa194CS/build.py
python3 -B secondary/pa194CS/verification/check.py
python3 -B comparison/verify_novelty.py \
  secondary/pa194CS/machine/pa194CS.tm \
  --census comparison/census.json
\end{verbatim}
The first two commands reconstruct the shorter source and exact fold,
and independently verify every physical outcome and the complete seed.
The additional novelty receipt also compares PA194CS with PA194C.

To rerun the entire corpus census, supply a local checkout at the pinned
commit with the PA and incoming paths available:
\begin{verbatim}
python3 comparison/census.py --repo /path/to/ProveIt \
  --output /path/to/new-census
\end{verbatim}
The script refuses another commit. The recorded census already includes
all paths and hashes. A separate selected-machine CSV preserves the
earlier report's positive and experimental evidence classifications.

The full LaTeX source is in \file{report/}. Rebuild with two runs of
\file{pdflatex -interaction=nonstopmode -halt-on-error pa194_cached_research.tex}
from that directory. The archive's \file{SHA256SUMS} binds the delivered
files. Regenerated timing receipts may differ from recorded receipts;
the transition table is deterministic and must have the published hash.
