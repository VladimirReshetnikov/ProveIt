## What the names conceal

The 139 spanning frontier graphs split, by attributed report status, into
**67 principal constructions, seven supplementary constructions, 47 research
auxiliaries, four research seeds, and 14 rejected constructions**. These labels
summarize what the reports claim; they do not mean that 67 separate iPRA
calibrations have been independently audited. Their source-calculus and physical
proof obligations differ materially.

Most reported constructions share the same proof-enumeration architecture.
Their differences occupy several axes, which should not be confused:

| Axis | Representative families | Actual change and proof obligation |
|---|---|---|
| Formula arithmetic | Primary, M4R, M5/M6, Q5/Q6, N5/N6, H5/H6 | Constructor coefficient four, five, or six; hereditary recoding, literal variable labels, unused residues, zero alias, and dominated-propositional side conditions must be addressed. |
| Universal-distribution orientation | Q and its descendants | Exchange the two curried premises. Fixed implicational proof templates translate both ways while preserving the actual conclusion. |
| Diagonal emitter | Primary, D, DHS | Emit the diagonal head at A or D. The schema family is preserved, but selectors and correlated neighboring heads change. Gamma(H) exists as an older source experiment, not as an accepted 194-state principal design. |
| Successful MP store | Original, N, C/CS | Original MP inserts a dummy zero; N omits it and leaves a visible result; C caches the result and clears visible state. All-store command compilers need the matching zero-stack discipline. |
| Halting guard | Original/sum-guard NS versus H/HS | Original Shift tests visible top plus cache; H tests only the cache. A visible contradiction with empty cache needs an additional cache-loading command. |
| AX interface | Ten-entry parents versus AX11 descendants | AX11 pushes the guarded gate and falls through the full MP parameter reader, consuming a fourth operand and returning an eleven-entry prefix. Its selectors and Pop word have different lengths. |
| Generalization binder | G, GH/GHS, AX11G, AX11GH/GHS | Generalize the incoming cached theorem using the explicit first AX operand rather than the incoming offset. Completeness no longer needs the preceding offset-setting command. |
| Destructive comparison | CS, HS, QHS, GHS, AX11GHS, SUMS/NS | Reverse comparison inputs and remove restoration work. This is an implementation change; it is not itself the change from sum guard to cache guard. |
| Known-zero returns | J, A, F, ZR, CZ/CSZ, HA/HAZ | Replace selected jumps by decrements of registers proved zero. The entry invariant must hold during the entire blank initialization too. |
| Decoder association | 4L, AX11QH4L/R, LC families | Reassociate source syntax or loop continuations while retaining the resolved source graph; addresses, history folds, physical timing, and startup must be rechecked. |
| History selectors | B, SEL and research companions | Factor recurring reader contexts using a bit written by the predecessor. A full-tape local simulation and an inductive entry-context invariant give relative iPRA equivalence. |
| Physical layout | AD, P5, TDY, HX, AX11HR | Reallocate physical registers and entry routers while preserving logical register semantics. These change the tape representation and initialization time, not just control labels. |
| Physical acceleration | AX11GHF, AX11GHSF | Shortcut two three-step detours under incoming-row bit invariants, with exact same-tape clock bounds. |

The primary source has 190 AX macro tokens and 3,673 primitive sites. Its literal
budget is **134 fixed controls + 67 raw readers - seven simultaneously compatible
folds = 194**. The alternate 68-reader/eight-fold primary also gives 194. Several
other families have 135 fixed controls and an effective reader cost of 59.
Consequently a shorter word, a smaller source array, or one more advertised fold
does not automatically save a literal state. New helper controls and incompatible
history requirements can consume the nominal gain. Every retained graph also
has 194 singleton classes under ordinary action-preserving control bisimulation,
as independently checked in `current/control_bisimulation.json`. That rules out
an unconditional same-tape quotient of that exact form, not a contextual
transformation, tape recoding, or redesigned source program.

## Written mathematics and formalization status

The current authoritative `PA/README.md` still says that neither primary
machine-specific direction of the iPRA consistency equivalence is established
in its Lean development. It describes completed standard-run simulation,
model-uniform scheduler/gate work, finite-code components, and generic
I-Sigma-1-to-iPRA transfer endpoints, while leaving model-length physical/source
correspondence and the complete internal PA-proof compiler open. These formal
components should not be mistaken for a discharged literal-machine theorem.

There is a distinct current written-mathematics development. The second filed
`pa194_ax11h_research_2026-11-14_2` packet contains explicit completion papers
for the physical/source bridge, source/command bridge, current Foundation
adapter, finite-demand term/formula proof suppliers, and direct PA proof
translation. Its `proof/consistency_equivalence.tex` states the full written
iPRA theorem for AX11H and QAX11H. The physical paper gives quantifier-free
induction proofs for literal transitions, unary and list sweeps, normalization,
source-frame closure, variable source clocks, and a reverse witness `t+1`.
The forward compiler uses explicit finite demand trees rather than induction
on an unbounded assertion over all environments. The Foundation adapter
handles the actual differing finite axiom and canonical induction-closure
counts. These are substantive mathematical arguments, not only PASS receipts.
No new end-to-end Lean/Rocq kernel build is supplied by that packet.

The latest GH/GHS, F, LC_AX11H, and HR reports expressly import that revised
written calibration to obtain their absolute consistency corollaries. SEL
and the four original-primary LC tables directly prove relative iPRA

calibration premise. One earlier AX11GH delivery leaves physical
internalization open; other current deliveries provide fuller arguments for

the evolving written proof, and completed formal endpoints.

## Why the existing sub-194 material is not a solution

The coefficient-three shortcut breaks the supplied numerical calculus: prior
work supplies a concrete primitive refutation and an all-offset obstruction
for that particular unchanged-head family. It does not rule out every syntax
with coefficient three, much less all 193-state machines.

The Runtime193 splice is correct on its intended clean source frames but
fails to initialize those frames from a blank tape. Existing exact finite
certificates classify the tested starts as literal halts or outward rays,
and an allocation-specific obstruction covers all nine-factorial register
permutations for that splice. These are restricted results. Altered contexts,
more coordinated edits, a different source representation, or a different
initializer remain outside their scope.

The newest loop-continuation package adds a **54th 193-state graph**, explicitly
rejected. It has 3,734 source sites rather than the primary's 3,673. On a
positive constructor-loop entry, the source cycles through four increments
of T, one increment of register 6, and a jump back, without revisiting its
decrement test. Its finite startup and local folds therefore do not establish
the desired source program. The same packet records seven 194-state
shortened-scanner/loop compositions: their source graphs agree with the
primary, but each fails exactly 47 of the 4,780 symbolic source outcomes.

The other new research-only inputs comprise ten individual/composite
history-selector tables and a one-row append-zero experiment. Their presence
in a graph census is not a claim of a new calibrated consistency design.
The even-only scheduler, top-only cache protocols, eager MP halting, marker
relays, and several modal-head replacements similarly remain source studies,
larger verified implementations, or explicitly rejected experiments in the
current collection.

Large finite search totals should be read with their certificate models.
Existing searches cover strict one-step folds, multistep stuttering folds,
two-row synthesis, independent incoming-edge detours, neutral rewrites,
paired/triple startup repairs, grammar reassociations, head permutations,
and physical layouts. Unsuccessful bounded runs are not divergence proofs;
absence of a certificate in one finite window model is not a state lower
bound. The new search should target a changed logical/source interface or a
genuinely stronger tape invariant rather than recount these old screens as
new progress.

## Transferable lessons from the suggested related projects

ZFC work contributes finite-history sharing, caller-selected return paths,
marker relays, protected tails, exact source-frame contracts, and all-store
proof-word compilation. Each imported optimization must be rechecked against
the PA source contexts and the full blank initialization. Its theory strength
cannot simply be substituted for Con(PA).

The Diophantine constructions emphasize uniform primitive-recursive witness
maps and the difference between an existential consistency statement and a
small literal evaluator. A compact equation does not itself yield a smaller
binary machine: decoding, unbounded search scheduling, and arithmetic
evaluation still consume controls.

ConciseIPRA demonstrates that proof translations can make an apparently
primitive logical rule dispensable. Its proof-checker-size objective is not
the literal-state objective here, and replacing a PA refutation search by an
iPRA checker would change the target consistency predicate. The useful lesson
is to simplify the actual logical interface with explicit proof translations,
then price the resulting source emitter and physical machine jointly.

## Reproducibility

Run `rebuild_current_census.py` with the pinned materialized source tree and
its exact Git manifest to regenerate the inventory. The precise invocation
is recorded in `census.log`. Run `annotate_census.py` to attach the reviewed
mechanism/status labels. `check_novelty.py` compares full canonical tuples
against all 139 frozen frontier representatives; a positive novelty result
is only a structural statement. `check_control_bisimulation.py` repeats the
unconditional control-quotient check. No census script supplies an arithmetic
correctness oracle.
