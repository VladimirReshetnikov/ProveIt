\subsection{Exact arithmetic command semantics}

For completeness the unchanged guarded gate is
\begin{align*}
 V(a,b,c)&=M(a,b)\to U(c,M(a,b)),\\
 P(a,b,c)&=c\to M(c,b),\\
 S(a,b,c)&=U\bigl(b,(M(a,b)\to P(a,b,c))\wedge(M(c,b)\to c)\bigr),\\
 Q(a,b,c)&=U(c,S(a,b,c)\to\neg P(a,b,c)),\\
 G(a,b,c)&=\neg(V(a,b,c)\to Q(a,b,c)),\qquad c\ne a,b,
\end{align*}
where $B\wedge C=\neg(B\to\neg C)$ and $\neg B=B\to1$.
These are equations between numerical constructors.  The false guard
branch emits the theorem code zero, not an unguarded $G$ instance.

Let $[a;w]=p(a,w)$, with nested brackets for several entries.  These are
Cantor pairs, not freely generated lists: $[0;0]=0$ and both projections
of zero are zero.  The command store is $(t,w,d,h)$, comprising visible
top, stack, offset, and cache.  Put $A=c$, $D=d+x$, $H=h+y$ and define
\[
 \mathsf{AX}_{c,x,y,z}(t,w,d,h)
       =(0,[q_0,q_1,\ldots,q_9,t;w],z,0),                 \tag{AX}
\]
with the exact order
\begin{center}
\begin{tabular}{@{}clcl@{}}
\toprule
$j$&$q_j$&$j$&$q_j$\\\midrule
0&$G(H,D,A)$ if $A\ne H,D$, else $0$&1&$\Gamma(A)$\\
2&$h_6(D,A,H)$&3&$h_5^X(D,A,H)$\\
4&$h_4(D,A,H)$&5&$h_3(D,A,H)$\\
6&$h_2(D,A,H)$&7&$F(D,H)$\\
8&$\rho_8(D,A,H,d)$&9&$U(c,h)$\\
\bottomrule
\end{tabular}
\end{center}
The restriction on $\rho_8$ is respected because $d\le d+x$.
The final saved generalizer uses the \emph{incoming} cache $h$ and the
explicit operand $c$.  The fourth field $z$ is consumed by the full MP
fallthrough; it is not a dummy field in the literal program.

The other two commands are
\[
 \mathsf S(t,w,d,h)=
 \begin{cases}
 \mathsf{halt},&h=1,\\
 (h,\operatorname{tl}w,d,\operatorname{hd}w),&h\ne1,
 \end{cases}                                             \tag{S}
\]
and, for $b=d+x$,
\[
 \mathsf{MP}_x(t,w,d,h)=
 \begin{cases}
 (b,w,b,0),&I(t,b)=h,\\
 (0,w,b,0),&I(t,b)\ne h.
 \end{cases}                                             \tag{MP}
\]
Only Shift halts.  Every $q_0,\ldots,q_8$ has residue zero modulo four;
$q_9$ has residue two and is at least two.  None equals one.  This remains
true after replacing $O$ by $J$; the outer constructor is still $I$.

\subsection{All-store proof-word compilation}

Execute command words from left to right and set $A_0=\mathsf{AX}_{0,0,0,0}$.
The total pair-projection equations give
\begin{align*}
 \mathsf{AX}_{c,x,y,0};\mathsf S^{10}(t,w,d,h)&=(q_8,[t;w],0,q_9),\\
 \mathsf{AX}_{c,x,y,0};\mathsf S^{11}(t,w,d,h)&=(q_9,w,0,t).
\end{align*}
Neither word tests the saved $t$.  Define
\[
 \mathsf{Push}=A_0;\mathsf S^{10};\mathsf{MP}_0,\qquad
 \mathsf{Pop}=A_0;\mathsf S^{12},\qquad
 \mathsf{Discard}=\mathsf{MP}_0.
\]
Their exact contracts are
\begin{align*}
 \mathsf{Push}(t,w,d,h)&=(0,[t;w],0,0),\\
 \mathsf{Pop}(t,[a;w],d,h)&=
   \begin{cases}\mathsf{halt},&t=1,\\(t,w,0,a),&t\ne1,\end{cases}\\
 \mathsf{Discard}(t,w,0,h)&=(0,w,0,0),\\
 \mathsf{MP}_i(0,w,0,0)&=(0,w,i,0).
\end{align*}
Push's comparison fails by residues.  Pop's twelfth Shift tests the saved
visible top.  All equations include the zero-stack alias.

For $0\le j\le8$, the head selector
\[
 \mathsf{Discard};\mathsf{AX}_{A,D,H,0};
              \mathsf S^{j+2};\mathsf{Pop}^{9-j}           \tag{Sel}
\]
sends $(t,w,0,0)$ to $(q_j,w,0,0)$.  In particular, the parameters of
$h_5^X$ and $J$ are available independently.  For an arbitrary dominated
instance $u\le D$, use
\[
 \mathsf{Discard};\mathsf{MP}_u;
 \mathsf{AX}_{A,D\mathbin{\dot-}u,H,0};
              \mathsf S^{10};\mathsf{Pop}.                \tag{Rho}
\]
The generalization word is
\[
 \mathsf{Gen}_i=\mathsf{Push};\mathsf S;
                   \mathsf{AX}_{i,0,0,0};\mathsf S^{11}.  \tag{Gen}
\]
Starting at $(a,w,0,0)$, Push and Shift give $(0,w,0,a)$; the following
AX consumes the cache before another Shift tests it.  The final state is
$(U(i,a),w,0,0)$, including when $a=1$.

At a modus-ponens proof node with major premise $I(a,b)$ and minor premise
$a$, compile
\[
 \mathsf{Discard};\mathsf{Push};W_{\rm major};
 \mathsf{Push};W_{\rm minor};\mathsf{Push};
 \mathsf S;\mathsf S;\mathsf{MP}_b;\mathsf{Pop}.          \tag{CmpMP}
\]
The initial pair reserves a zero below both premises.  Unless a premise
word already halts, the last suffix starts at
$(0,[a,I(a,b),0;w],0,0)$.  It either detects an earlier contradiction or
returns $(b,w,0,0)$.  The final Pop clears the offset and removes the
reserved zero.  Thus, for a proof $\pi$, the exact compiler invariant is
\[
 W_\pi(t,w,0,0)=\mathsf{halt}\quad\text{or}\quad
 W_\pi(t,w,0,0)=(\operatorname{concl}\pi,w,0,0).          \tag{Cmp}
\]
For a refutation, the word
\[
             V_\pi=A_0;W_\pi;\mathsf{Pop}               \tag{Ref}
\]
halts from \emph{every} store.  The initial AX normalizes offset and
cache.  The final Pop detects a visible contradiction; a plain Shift
would instead test the zero cache and would be incorrect.

Push, Pop and Gen have lengths 12, 13 and 25.  Selector $j$ has length
$121-12j$, and the dominated selector has length 26.  An MP node has
53 commands of overhead.  If $n$ is the number of nodes of the expanded
proof tree, then $|W_\pi|\le121n$ and $|V_\pi|\le121n+14$.
This is not a linear bound in the number of lines of an unexpanded DAG.

\paragraph{Why the compiler proof belongs to iPRA.}
An induction whose assertion is correctness for every unbounded store
would be insufficient justification.  Instead use the retained bounded
input argument from \cite{ax11h,gh}.  Given a valid $N$-line proof, compile
all earlier words and compute the largest length $L$ and command code $K$.
For the absorbing PR command transition $\operatorname{next}$ put
\[
 \Phi_K(s)=1+\max\left(s,\max_{c\le K,\ u\le s}
                                  \operatorname{next}(c,u)\right),
 \qquad B(j)=\Phi_K^{L(N-1-j)}(s_0).
\]
For $i<j<N$, $\Phi_K^L(B(j))\le B(i)$.  Induct on the Boolean statement
checking every earlier line on every normalized input within its assigned
bound.  Every premise invocation inside word $j$ is reached within $L$
steps; its input lies in the earlier line's bound, and the local word
contracts make it normalized.  Halt is absorbing.  The invariant is a
bounded conjunction and therefore a PR Boolean test, so quantifier-free
induction applies.  At the final line $B(N-1)=s_0$.  Since $s_0$ was an
arbitrary free parameter, (Cmp) and (Ref) hold uniformly.  Malformed
proofs are assigned a fixed default word, keeping the compiler total.

\subsection{Scheduling and extraction in both directions}

The scheduler starts at $(n,\ell,t,w,d,h)=(2,0,0,0,0,0)$.
When $\ell=0$ it chooses raw seed $n$ and increments $n$; otherwise it
chooses $\ell-1$ without incrementing $n$.  After unpairing a seed, tag
0 means Shift, tag 1 means MP with one parameter, and tag $c+2$ means
AX with fields $y,x,z$, in that order.  For a command word let
$e(\epsilon)=0$ and $e(C::v)=1+b_C(e(v))$, with
\[
\begin{split}
 b_{\mathsf S}(r)&=p(0,r),\\
 b_{\mathsf{MP}_x}(r)&=p(1,p(x,r)),\\
 b_{\mathsf{AX}_{c,x,y,z}}(r)&=p(c+2,p(y,p(x,p(z,r)))).
\end{split}
\]
All fields, including zero fields, are recovered by total projections.
Every positive continuation decreases strictly.  A fresh raw seed $m$
therefore drains in at most $m+1$ command calls unless it halts sooner.

For a refutation $\pi$, the raw seed
\[
 N_\pi=p\bigl(2,p(0,p(0,p(0,e(V_\pi))))\bigr)\ge3
\]
executes an extra AX followed by the all-store halting word.  It is
reached, or an earlier halt occurs, within the PR command bound
$K(\pi)=(N_\pi+2)^2$, because
\[
 \sum_{m=2}^{N_\pi}(m+1)
       =\frac{N_\pi^2+3N_\pi-4}{2}<(N_\pi+2)^2.
\]
This uses a bounded counter induction.  Failed candidates need not reset
the store; all-store completeness is precisely what removes that premise.

In the converse direction, maintain a finite checked derivation list
whose indices justify $t,h$ and every canonical stack head.  The fixed
instance $\rho_8(0,0,0,0)=0$ supplies the zero theorem, including virtual
zero heads of a zero stack.  For a positive stack code, its tail is
smaller, so its decoding is bounded.  AX appends axiom instances and the
generalization of the cache; its guard and dominated side condition are
verified by primitive recursive comparisons.  MP and Shift preserve the
annotations.  A halting Shift exposes a proof of one.  Induction on a
bounded Boolean proof-prefix checker gives, for each new calculus
$\mathcal C$ and corresponding scheduler $R$,
\[
 \ipra\vdash\quad
 \Halt(R)\ \longleftrightarrow\
                \exists\pi\,\operatorname{Prf}_{\mathcal C}(\pi,1).
 \tag{Log}
\]
The logical translations of the preceding section convert these
refutations to and from $\Cold$ with the same final numerical conclusion.

\subsection{Literal tape contracts and the weak-base transport}

Both machines use the logical-to-physical register-slot map
$[6,2,0,4,3,7,8,5,1]$.  The complete 57,922-transition blank run reaches
native control 84, head $-2$, the initial logical register file, and
26 spare blocks of value one.  The certificate checks the complete
nonzero support and both blank exteriors, not only a local tape window.

The independent literal checker imports no construction compiler and
uses no unproved arithmetic-box oracle.  Its symbolic tape atoms are
unary runs, arbitrary finite lists of blocks, and blank or opaque
exteriors.  Every ordinary step reads the actual transition table.
Unary sweeps are justified by induction on their run length.  Four
generic list traversals are reconstructed directly from literal rows,
then proved by induction on the prefix length of an arbitrary coded list.
The implementation of these arithmetic rules and their full proofs are
retained in \path{references/baseline_proof/physical_ipra_audit.tex}.

Each source outcome has nine arbitrary primary-register parameters, an
arbitrary nonempty finite spare-register list, and an arbitrary
nonnegative gap.  Duration and displacement are affine expressions.
The coefficient slot for spare-list width means the width of the
\emph{same} list occurring on the tape; it is not an unrelated variable.
Normalization merges equal runs and removes exterior zero padding only
when that is equality of the complete zero-extended tape.  The separate
closure audit verifies every target source address, complete tape shape,
zero net boundary movement, and positive duration.  The one halting
outcome is distinguished explicitly.  These checks support the
model-uniform interpretation of the finite certificates.

For clarity, the general arithmetic transport argument is recorded here.
The physical source state is the \emph{extended} source state: program
counter, nine primary registers, the evolving gap, and the entire spare
list.  The boundary origin can also be carried, or fixed because every
live certified segment has zero net motion.  This bookkeeping projects
to the primitive register run in (Src) and preserves its halt flag.
It is included in $s_k$, $F$, $\delta$ and $\tau$ below; a bare register
file would not determine the whole tape or its segment duration.

Use the absorbing PR run $s_k$ of these extended states, its exact frame
map $F$, and the specified positive PR target duration $\delta(s)$ on
live states.  In the arithmetic target representation, all physically
halted configurations are mapped to one absorbing code $H$ after the
literal halt has occurred.  This changes neither the physical table nor
its halting predicate, and $F$ maps an extended source halt to $H$.
It is harmless to set duration zero after halt.  Define
\[
 \tau(0)=0,\qquad \tau(k+1)=\tau(k)+\delta(s_k).
\]
Quantifier-free induction gives
\[
 \operatorname{Run}_{M}(T_0+\tau(k))=F(s_k),
 \qquad h_M(F(s_k))=h_{\rm Src}(s_k).
 \tag{Tape}
\]
If $s_k$ is live, all its predecessors are live by absorption, hence
$\tau(k)\ge k$.  Given a physical halt by time $t$, decide the halt
flag of $s_{t+1}$.  If live, (Tape) would give a live target frame after
time $t$, contradicting target absorption.  If halted, $t+1$ is already
an explicit source witness.  This is a decidable finite case split, not
double-negation elimination for an unbounded existential.

Apply the same argument to (Src) and then to (Tape).  If
$\Theta(k)=\sum_{i<k}\theta(R^i(c_0))$, a refutation $\pi$ supplies
the explicit PR physical halting witness
\[
             57922+\tau\bigl(\Theta(K(\pi))\bigr).
\]
Conversely, two positive-clock transports and the annotation extractor
turn any literal halting witness into a numerical refutation.  No
assumption of PA consistency enters either construction.  Consequently,
for each delivered machine $M$,
\[
 \ipra\vdash\quad
 \Halt_{\rm blank}(M)
 \longleftrightarrow\Halt(R_M)
 \longleftrightarrow\exists\pi\,\operatorname{Prf}_{\mathcal C_M}(\pi,1)
 \longleftrightarrow\exists\pi\,\operatorname{Prf}_{\Cold}(\pi,1).
 \tag{New}
\]
