# Boundary-derived local windows (research lane)

For radius 3, each saved integer describes the seven cells at offsets -3,...,3 from the head, in that order (least significant bit is offset -3).

The input is the literal 208-state Entry Context table. The inherited symbolic checker rederives all 5,084 primitive contracts over nine arbitrary natural primary register values, arbitrary nonnegative gap, arbitrary first spare and arbitrary finite remaining spare list. Before every symbolic literal inference, `project.py` projects the full-frame symbolic tape to the seven cells.

Projection deliberately forgets correlations. A run with nonconstant nonnegative affine length c+sum(a_i*x_i) admits every length at least c, whether or not actually realizable. A constant run has its exact length. Only lengths up to the requested prefix width matter. Any opaque or finite-list atom is replaced by all bit prefixes of the needed width. Infinite blank exterior contributes only zeros. Left and right possibilities are combined independently. Each relaxation enlarges the represented set.

Compressed unary traversals may pass through many configurations not exposed as literal inference boundaries. Every state appearing in such a traversal is therefore assigned *all* seven-bit windows. List traversals are handled similarly; moreover every literal state occurring in each proved single-block traversal receives all windows. This coarse treatment avoids inferring internal guards from endpoints. The exact first 48,140 blank-input steps and their final boundary are also included.

Consequently, conditional on the inherited source semantics and its symbolic full-frame contracts, every configuration on the intended blank computation has a window in the corresponding set. This is a mathematical overapproximation, not a finite sample of register magnitudes or a claim that all recorded windows are reachable. A successful use in a reduced machine would need a local macro identity for *every* recorded window, positive progress, and unchanged halt reflection, followed by induction at old-machine transition boundaries.

The `search.py` lane restricts to unordered pairs of noninitial states with at least one transition agreeing after quotient. It changes one representative transition to any write/direction/retained-target action and checks all source windows symbolically, branching on each previously unknown bit encountered outside the window. Thirty primitive reduced-machine steps is a proof-search cutoff, not a semantic bound. Failure means only no witness was accepted by this particular bounded family.

Orientation is handled explicitly: with direction +1, the left atom stream starts at offset -1 and the right at offset 0; with direction -1, the left starts at offset 0 and the right at +1. Hence the left prefix has length 3 or 4, is reversed, and concatenated with the right prefix of length 4 or 3. Constant zero-length runs disappear; variable runs of minimum zero include the length-zero choice and continue into the suffix, so no positivity assumption is smuggled into projection.

At a contract endpoint the complete frame is the next source boundary, whose guard is supplied by the corresponding next primitive contract, or the halt state, which needs no working-state guard. Source closure is inherited from the source semantics; the category-specialized lane additionally independently checks the product-category invariant and its transport to this exact ordered source CFG. The initial finite startup includes both time zero and the full canonical endpoint at time 48,140. No guard is inferred only from the endpoint of a skipped traversal.

Results: 7,697 universal windows, 7,694 category-specialized windows. The latter remove exactly three windows. Both common-row searches test 224 unordered eligible pairs and 186,368 actions with no survivor. The universal generalized unchanged-branch macro search admits 489 directed pair/branch choices and tests 406,848 actions, also with no survivor. These finite searches prove no minimality statement.
