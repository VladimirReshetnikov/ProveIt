REPLAY (Python3.10+, standard library)
From the extracted root:
    python3 -B reproduce.py --receipt /tmp/below-u208-replay.json
The default is FULL: both inherited208 graph classes are rederived through
all5,084 symbolic contracts; both new boundary projections are rebuilt; the
bounded selector/offset synthesis family is rerun; applicable independent
finite checks also run under Python-O. Four independent jobs may run in
parallel. Temporary files are outside the sealed package. Assertions must
remain enabled for symbolic induction. A finite search is not a kernel proof.

For an explicitly incomplete, faster check:
    python3 -B reproduce.py --quick
This skips full runtime/projection derivations and the offset-neutral search.
It does NOT establish that those skipped stages passed. The much larger
local merge and source-layout discovery runs are retained as hashed terminal
receipts and optional scripts; neither default mode reruns every such search.
Each subdirectory README specifies its exact replay scope.
