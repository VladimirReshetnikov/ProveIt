The universal projection records 7,697 state-window pairs over 5,084 primitive
contracts. The source-category specialization records 7,694 pairs over 5,079
contracts, removing exactly three windows. Both retain all 128 seven-bit
windows for each of the 25 conservatively opaque engine states. Specialization
uses the separately checked product-category invariant at source ordinals,
transported to the exact ordered control-flow graph. It does not assume that
an arbitrary register store is reachable.

one row to agree after quotient; the generalized family permits the unchanged
branch to agree by a macro. The 30-step cap is a proof-search restriction, not
a semantic runtime bound. A ten-stage full replay of the boundary bundle
passes. In each Python mode, finite projection sanity checks cover 2,880
instances and reject eight tampered controls; these tests supplement, rather
than replace, the all-length projection argument.
