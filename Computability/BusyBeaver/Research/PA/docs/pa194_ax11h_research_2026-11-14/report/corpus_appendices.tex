\section{All supplied 194-state frontier objects}
\label{cmp:frontier-appendix}

The following table contains all 83 objects in the frozen frontier
catalogue.  F01 is a disconnected diagnostic; each of F02--F83 has a root
that reaches all 194 nonhalting controls in its action graph.  These are
83 distinct census fingerprints even after global reflection.  They are
not 83 independently proved blank-start consistency machines.
The new AX11H candidate is outside this supplied-corpus list.

The status abbreviations describe the \emph{historical evidence level}:
Pr = reported principal construction (40); Sup = supplementary
construction (7); Aux = research auxiliary (25); Seed = research seed
(4); Rej = explicitly rejected (6); Diag = diagnostic control (1).
``Pr'' does not assert that the iPRA equivalence has been proved.
The categories were checked against newly parsed tables; the old
calibrations were not all re-proved.  The source-rotation group retains
individual rows because different associations can produce distinct
literal tables despite preserving the resolved source program.

The local reference F\emph{nn} is the one-based data-row number in
\path|comparison/frontier194.csv|, ignoring the header.  Its JSON
counterpart records the full canonical fingerprint, representative,
original evidence source, occurrence count and proof-status statement.
A representative transition file is stored as
\path|comparison/representatives/| followed by its full table-class
fingerprint and \path|.tm|.  The detailed byte identities and paths are
kept there rather than abbreviated into an unreadable printed table.
\cite{repo,incoming,ax11packet}
