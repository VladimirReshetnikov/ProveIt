Research toward fewer than 194 states
====================================

These directories are optional research evidence. The accepted machine is
../machine/machine.tm (PA194QN6, 194 working states). No table in this
research directory is claimed as a new sub-194 consistency machine.

grammar_search/
  Fourteen completed bounded decoder/source searches, with 22,761,138
  attempted grammar moves. The count includes inapplicable proposals and
  does not count distinct grammars or verified candidates. Searches cover
  per-occurrence rotations, broader fixed/AX folds, dictionary reparsing,
  QNS/QNS6 compositions, equality-head premise exchanges, diagonal-head
  changes, exact fixed-pair reuse and coefficient-five/six associations.
  C++/Python source, inputs, completed logs and final grammars are included.
  README.txt and SUMMARY.json give exact seeds, requested bounds, observed
  counts, and the scope of each result. No qualifying reduction was found.

physical_search/
  Startup repair of the existing runtime193, register-layout permutation,
  a second local control merge, transplants into 49 native variants, and a
  ZFC marker-relay transplant. Exact inputs, source code and recorded logs
  are retained. README.txt distinguishes proved blank rays, finite bounded
  outcomes, conditional runtime screens and unverified candidate edits.
  Applying the runtime quotient to the new QN6 table gives a certified ray
  after 92 transitions. The marker relay has a short 116-transition ray.

toponly196/
  A distinct top-only Shift design, 136 fixed + 67 readers - 7 folds = 196.
  A portable builder checks 4,754 source outcomes and complete blank startup
  at 58,154 steps. This optional branch uses the inherited arithmetic-block
  interface, and has not received the independent literal block replay or
  complete secondary calibration performed for the accepted QN6 machine.
  Its README documents this boundary and the mathematical compiler idea.

The stochastic discovery searches and optional branch builders are not
required to reproduce the accepted result. From the release root, use
python3 -B verify.py for the accepted-machine acceptance checks. Search
results are finite negative evidence for the stated domains, never a state
lower bound or proof that a 193-state construction is impossible.
