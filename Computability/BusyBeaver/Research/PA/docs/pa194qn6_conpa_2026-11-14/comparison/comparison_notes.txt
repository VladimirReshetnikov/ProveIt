1. Scope and population

The source has 61 filed research deliveries under PA/docs and five current
incoming ZIP archives. The 66-row packet ledger records every delivery's
reported contribution. The earlier U209--U222 ancestors are also present in
nested reference archives. Both imported James Chang snapshots and the other
tracked PA files are included in the literal-table scan.

The scanner inventories 21,022 tracked blobs, traverses nested archives, and
recognizes complete numeric five-column binary transition tables in .tm,
.txt, .tsv and .csv files. It also recognizes complete textual tables and
five-column row arrays recursively inside JSON. All first-pass exclusions
for large JSON were subsequently inspected; they yielded no extra table.
Arbitrary transition dictionaries, code generators and prose are not parsed
as literal machines. Packet-level review complements that recognition scope.

The result is 1,832 recognized occurrences, 670 byte forms, and 666 distinct
labeled transition lists. There are 563 full spanning one-halt action-graph
classes. The broader 576 maximal-component buckets also include disconnected
fixtures, multiple-exit components and nonhalting controls; they must not be
described as 576 established consistency machines. At 194 states there are
76 distinct spanning graphs. One additional nominal-194 bucket consists of
padded diagnostic controls with only three states reachable from any root.

The repository's 7,130 original .tm-file count refers to pre-dedup deliveries.
Many original copies were removed during filing. It does not conflict with
the current-blob/ZIP/JSON occurrence count above. MACHINE_FILES.tsv and
OMITTED.tsv retain their historical identities; current table bytes were
rescanned rather than inferred from file names.

seven supplementary constructions, 30 search seeds or auxiliary graphs, and

the supplied manuscripts and receipts; all 76 PA consistency arguments were
not independently reconstructed. Some auxiliary graphs have source identity

At 196 states, the current census has 103 full graph classes. The original
PA195 packet's detailed evidence ledger classifies 90 of these: 25 supported

3. The main design families

The older unary-power-cover line reached 208 states through source reduction,
decoder reassociation and tape-context folds. Its theory and source program
are not merely differently numbered versions of the later PA196 line.

The PA196/195/194 line uses a fixed unary-register interpreter with a compact
binary axiom-reader graph. Its numerical formula constructors use Cantor
pairing. The coefficient-four presentation has implication, membership,
universal quantification and equality in residues 0, 1, 2 and 3, with truth
code 0 and contradiction code 1. Physical size is governed by distinct reader
subtrees and compatible contextual folds, not by source-token count alone.

The principal PA195 reduction uses a bundled diagonal-vacuity emitter and
134 fixed controls + 68 raw readers - 7 folds. Separating its diagonal theorem
from the guard gives the 190-token source used by the primary PA194 program.
Two accepted 194-state realizations have budgets 134 + 67 - 7 and
134 + 68 - 8. Thus the two packets named PA194 already describe different
decoder graphs. The A/D companion permutes physical register roles while
preserving the numerical source semantics.

Subsequent constructions change three largely independent parts:

* Logic and numerical coding: coefficient 5 or 6; the Q exchange of the two
  curried quantifier-distribution premises; or the diagonal instance Gamma(D)
  in place of Gamma(A). TAG196N exchanges quantifier/equality residues, but
  remains at 196 states. The Q exchange is justified by an explicit finite
  K/S/MP proof, not by an assumed extra inference rule.

* Command stores: the original successful MP pushes a dummy zero; C keeps the
  result in the cache; N removes the push but leaves the result visible.
  H combines visible no-push MP with a cache-only Shift halt test. A compiler
  must establish the new successful-command behavior from arbitrary incoming
  stores, because the scheduler carries its proof store between trials.

* Physical/source layout: symmetric destructive comparison, known-zero
  decrements replacing jumps, A/D register exchange, or reader reassociation.
  The J, F, R, A and ZR families use different particular source invariants.
  An unchanged finite resolved source graph is valuable evidence, but it
  does not alone prove that an altered scanner or blank startup is correct.

The QN, QNS, QH, QH6, N5/N6, Q5/Q6 and DHS machines are compositions of these
ideas. Their individual component ideas are prior work. A new composition
needs exact source binding, a compatible final fold set, whole-tape source
simulation and a complete blank-start certificate.

4. Names that would otherwise mislead the comparison

PA194C is delivered as the primary result in five packets but is one graph.
PA194QN and PA194NQ are the same table. The two QNS packets are the same
table. PA194N6 is repeated in two deliveries. The earlier cache-only PA194NS
is the same table as PA194HS. The later uppercase PA194NS_research packet
uses the same short name for a different machine preserving the original
sum guard; its PA194SUMS companion retains the original MP push. The ledger
therefore uses the packet, exact transition identity and guard semantics.

Native and dense numbering are also distinct concepts. Dense zero is only
a packet convention when the table has no explicit start declaration. Some
comparison exports are densely numbered without preserving the real start
at zero. Graph comparison ignores the start conservatively; the actual
blank-tape theorem must keep its designated initial control.

5. Why the two existing 193-state tables do not solve the task

The coefficient-three machine has physically valid source simulation, but
its unchanged logical interface is inconsistent. The collision
E3(1,0) = I3(0,1) = 6 yields a derivation of code 1, expanded in the packet
to 73,393 primitive steps. Later work extends this obstruction to every
constant equality offset within the stated coefficient-three interface.
That is a restricted encoding obstruction, not a general 194-state bound.

The other table, Runtime193, merges native control 301 into 88 and changes
rows (88,0) and (51,0). It passes all 4,780 source-outcome contracts, but its
original blank start enters an outward ray. The packet rejects 1,158 tested
elementary starts and explicitly supplies no calibrated blank initialization.
Its broader source-seed theorem allows sites 25--44 with logical T=W=H=0
and arbitrary other six registers. A complete physical frame still has to
be reached. A runtime core with a prepared input is not the requested blank
one-tape machine.

6. Proof status and transferable methods

The requested result is a PA-provable equivalence. The ordinary calibration
manuscripts use finite bit-set comprehension proved by full PA induction,
syntactic proof suppliers, diagonal-vacuity recovery of the old logical
interfaces, and an invariant carrying PA proofs for every live formula.
The supplied current PA README separately states that the end-to-end iPRA
formalization is not complete. An ordinary PA proof can use this inherited
mathematics without being a newly compiled Lean/Rocq theorem. The distinction
must be explicit in the result, rather than treating a Python PASS as the
missing kernel theorem or treating the iPRA gap as automatically refuting
the ordinary PA argument.

The ZFC work contributes useful methods: context-dependent folds, exact
initialization, source graphs, complete tape frames and positive-duration
simulation. A ZFC-consistency machine is not itself a PA-consistency machine.
ConciseIPRA contributes the strategy of shrinking interfaces and supplying
explicit proof translations. Replacing the PA checker by an iPRA checker
would change the required consistency statement without a new calibration.

7. Reproducible novelty boundary

check_novelty.py compares exact canonical graph tuples with all 76 current
full 194-state graphs (and both 193-state graphs). It allows arbitrary state
renaming, every spanning root, global reflection, symbol complementation,
and arbitrary final halt-edge write/move effects. The 76 reference graphs
remain pairwise distinct even under these enlarged identifications. The
primary PA194 positive control matches exactly one entry. Novelty means
absence from this pinned recognized corpus, not absence from every possible
unmaterialized generator and not semantic inequivalence: accepted machines
are intended to share the same halting condition.
