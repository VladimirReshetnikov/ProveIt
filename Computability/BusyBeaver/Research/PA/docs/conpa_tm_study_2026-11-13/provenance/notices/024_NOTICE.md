# Attribution and proof boundaries

This contribution was prepared for Vladimir Reshetnikov's ProveIt project on 21 October 2026 with AI-assisted construction and independent agent review.

The new contribution consists of the successful contextual reassociation, its exact ST215 source and table, zero-refill startup calibration, deterministic reconstruction and replay packaging, candidate-specific proof integration, new formalism obstructions and abstract parser lemmas, and recorded bounded searches.

The underlying numerical calculus, arithmetic macros, source language, physical engine, two marker folds, dominated-rho8 recovery certificate, three-command strong compiler, ordinary protected-credit theorem, and much of the symbolic verification code are inherited work. They must not be attributed as new here.

The immediate parent is reference/transfer-parent/, copied without modifying its files from the frozen subdirectory of the repository's incoming T215_Transfer_2026-10-20.zip. Its licenses and provenance are retained, together with copies of the relevant licenses at the packet root. Its historical claims and artifact names describe that parent, not ST215. In particular, any historical statement about not executing received code is not this packet's policy: the included inherited checker code is intentionally executed as a verifier.

The current symbolic_runtime.py retains the original proof functions and removes the unused historical command-line/input-validation tail. independent_runtime.py retains only the exact table parser, physical register permutation, frame constructor, address increment, and address-strip functions needed by that engine. The new check_runtime.py binds those inherited rules to this packet's exact source/table and zero-refill policy. The original versions and their attribution are available through the parent and the pinned short-transfer packet; provenance/UPSTREAM.json records exact inputs.

The finite logical certificate checker is inherited unchanged. It verifies the 3,728-node dominated-to-unrestricted propositional recovery and handles the numerical truth alias explicitly. It does not by itself prove the full native-calculus-to-ZFC comparison.

The new ordinary machine theorem uses the existing numerical-calculus calibration and all-natural command arithmetic theorems. The report states the dependency chain explicitly. No newly compiled Lean/Rocq endpoint, unconditional nonhalting theorem for ST215, 214-state construction, or state-count lower bound is claimed.

Every comparison table is inert input data. Corpus provenance records all original names and archive hashes. Distinct byte files are not presumed to be nonisomorphic machines. Rooted graph distinction is stronger than changed file bytes but does not assert semantic inequivalence of arbitrary machines.

Research scripts and receipts specify their own scope. In particular, the hypothetical biased-parser equations do not describe the rejected archived scratch-biased source. Its wrong continuation is preserved and exposed by the supplied negative-control audit.
