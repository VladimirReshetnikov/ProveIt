Family comparison for the main report

Historical 209--222 controls and U208.
The older material includes two different 209-state lineages. The imported
James Chang PA209 has 3,948 source sites; the Joint-U209 parent underlying the
principal U208 packets has 3,909. A shared native state number therefore is
not an interchangeable semantic role. The principal U208 submissions reduce
to two rooted action graphs, although their broader helper families contain
additional implementations. Their one-state savings all identify the same
conditional-history roles172/211 and cannot be stacked. Both roles disappear
in the PA196 lineage. Larger retained tables establish provenance and search
history; the current corpus's many207/208 literal graphs include mutants and
diagnostic inputs, so their counts are not counts of accepted consistency
machines. [Sources: pa_tm_research_2026-11-13/README.md;
pa_consistency_research_2026-11-13_2/README.md; U208 packet READMEs.]

PA196, the classical source, and diagonal vacuity.
The imported PA196 provides the principal register/tape compiler and formal
execution framework. Its original source has3,812 sites. Later work replaces
parts of the logical emitter using diagonal vacuity; initially the shorter
source compiles to199/198 controls, and later layouts reach196. This shows
why fewer logical tokens or primitive operations need not imply fewer tape
states: sharing and binary association determine reader allocation. Within
the196 family, changing head order, reassociating a decoder, switching to
known-zero decrements, and changing Shift/MP semantics are distinct types of
optimization. A196-state source/tape certificate is not automatically the
full PA-internal consistency biconditional. The imported formal result
explicitly establishes PA-provable Nonhalt=>Con(PA); the manuscript reverse
translations and later finite-run formal bridges must be identified
separately. [Sources: jamesyc-upstream/README.md;
pa_consistency_research_2026-11-13_2/README.md; PA/README.md.]

Original PA195 versus195S,195C and195DC.
Original PA195 keeps the bundled-diagonal191-token AX word, all3,700 source
sites,134 fixed controls and68 AX readers, and gains a seventh compatible
fold:134+68-7=195. The later195S uses the separate-diagonal190-token word and
3,673 sites; its allocation is134+67-6=195. The separate head changes the
logical/stack interface, while the table reduction is an allocation fact.
195C keeps the195S decoder but changes the controller: successful MP caches
its result and Shift tests that cache; it has3,649 sites. 195DC instead applies
the same Combined controller to the bundled-diagonal original195 emitter;
it has3,676 sites and remains134+68-7=195. Thus195C and195DC are not aliases:
they use different emitter interfaces. M195S8 is another195-state physical
implementation with eight local folds and a longer scanner; its tempting
194-state counterpart is rejected because a legal seven-zero address is
misread as a separator. [Sources: pa195_conpa_2026-11-13/README.txt;
PA195_ConPA_research_2026-11-14/README.txt;
pa195_diagonal_combined_2026-11-13/README.txt;
pa195_followup_research/README.md. File extensions are those in source
metadata; packet_ledger contains authoritative directory names.]

The194 frontier.
Primary PA194 combines the separate source's67-reader allocation with seven
compatible folds,134+67-7=194. Another source-equivalent allocation uses68
readers and eight folds. A/D placement, M4R and R add physical layouts;
C,CS,N,H,HS and SUMS change command/cache/stack behavior; radix5/6 changes the
formula encoding; D changes the separately emitted diagonal head; Q exchanges
curried premises in a quantifier-distribution head; J,ZR and their siblings
use source invariants to specialize zero-valued returns. New incoming
DHS,H6,HA,HAZ,QN,SUMS and NS(sum) compose these mechanisms. There are42
literal194-state graph classes in the current pinned corpus, comprising28
reported constructions,nine auxiliary tables and five rejected tables.
Every one was compared structurally, while historical proof claims were
attributed rather than silently promoted to fresh verification.

PA194QH in this landscape.
The supplied Q already has the cached-result C controller; the attempted QC
reconstructed it byte-for-byte and is rejected as a novelty claim. QH instead
combines the Q head with H's no-push visible-top MP and cached-only Shift.
Relative to Q, MP success changes(0,w,0,b) to(b,w,b,0). Relative to QN, the
Shift halt guard changes t+h=1 to h=1. Relative to H, the quantifier head has
its curried premises exchanged. These are recurring semantic differences
requiring a changed proof compiler; QH is a new concrete composition of prior
ideas, not a new calculus or a reduction below194.
