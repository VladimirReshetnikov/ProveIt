Audit conclusions:

1. The finite-demand method in forward_calibration_completion.tex is a valid
   way to avoid an induction formula saying that every environment has some
   certificate. Provided all recursive child queries are computed from the
   parent request before child outputs, and same-stratum ranks decrease,
   expand the full bounded binary demand tree to depth r+1, then evaluate it
   in reverse order. Both loops are primitive recursive. The finite Boolean
   assertion that every completed valid request contains a checked proof is
   a quantifier-free invariant. Increased input ranks in already completed
   lower strata are harmless. These are genuine reasons for the weak-base
   construction, not an inference from the word primitive-recursive alone.

2. physical_ipra_audit.tex explicitly arithmetizes complete finite-support
   tapes and gives the correct binary updates for both head directions. It
   proves the four list sweeps via one-block calculations and prefix-length
   induction. Its spare-list width is bound to the same list appearing on
   the tape. The padded address equality and zero displacement conditions
   account for the whole next source frame. The source register permutation,
   changing gap, and spare-list extension are explicit.

3. The positive-clock converse is sound. If z_k is a nonhalting source state,
   cumulative physical duration is at least 3k. The exact endpoint equality
   at k=t+1 contradicts a physical halt at t unless z_(t+1) has halted,
   using only decidability of equality with a fixed halt code and absorption.
   There is no Markov principle, least-witness search, or inference from
   successful standard sample runs.

4. source_command_completion.tex specifies a complete scheduler embedding
   and positive primitive-source clocks. The data-retaining halted source
   configuration is identified explicitly, so its endpoint need not be
   incorrectly identified with a single pre-halt tape or register file.

5. The final negative consistency statement is obtained through the pinned
   all-model I-Sigma-1/conservation and negative-translation endpoints. This
   should not be restated as an unqualified positive existential equivalence
   proved by a generic double-negation elimination argument.

No mathematical counterexample or immediate circularity was found in the
central finite-demand and physical/source clock schemes inspected here.
This is a targeted audit, not independent rederivation of every local
constructor in the much larger upstream compiler. The absolute calibration
should remain a named inherited written theorem dependency. Any new literal
table still requires its own source bindings, whole startup, frame closure,
and simultaneous-fold certificates. Successful finite replays do not become
an end-to-end Lean proof.

For the new parameter-permutation investigation, each unrestricted head has
its own bijection of the three numerical parameters. Every emitted head
therefore remains an instance of that same schema. Conversely, reset the
offset registers as in the inherited command compiler, choose the inverse
permutation of the desired parameter tuple, invoke AX, and select the same
head index. Guarded and dominated heads are left untouched. Thus schema
membership and complete access to all six schema families are preserved;
the AX stack height and individual selection depths remain unchanged.
The change affects the actual per-command formula stream and compiled
reader graph, not merely state labels. Formal verification of the exact
candidate must still compare the full free-algebra AX expression.
