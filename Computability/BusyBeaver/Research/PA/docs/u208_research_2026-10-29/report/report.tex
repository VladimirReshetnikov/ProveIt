\begin{abstract}
We construct a binary, single-tape Turing machine with \textbf{208 working
states and 416 transitions}, including its all-zero-tape initializer.
The new reduction folds native state 172 into 211 in the exact supplied
Compatibility 209-state machine. It changes two surviving transition rows
and deletes two outgoing rows. No source reassociation, new tape symbol,
additional tape, prewritten input, or omitted initialization is used.

The proof uses the different predecessor contexts of the two states.
Four complete-tape identities replace one old transition by one, three,
or seven new transitions; all 414 other old rows commute with the state
projection. This gives a PA-formalizable halting equivalence independently
of the numerical program. A fresh universal symbolic replay of the final
literal table also proves all 5,084 guarded interpreter contracts, covers
all 416 rows, and preserves the exact 48,140-step startup and its 141-step
source bridge.

Composing the new local theorem with the retained parent calibration yields
\[
 \PA\vdash\neg\Halt(U_{208},\mathrm{blank})
 \ \longleftrightarrow\ \Con(\UU)
 \ \longleftrightarrow\ \Con(\PA).
\]
This is an ordinary mathematical, PA-formalizable proof, not a newly
exported proof-assistant certificate. It does not assert unconditional
nonhalting or global state minimality. The six named incoming archives
contain only two distinct rooted labelled machine classes, not six
independent savings.
\end{abstract}

A row \texttt{q b w D r} reads $b$ in state $q$, writes $w$, moves one
cell in direction $D$, and enters $r$. Entry into the halt label ends
the computation after that write and move. Every working state and the
halt vertex are reachable in the labelled transition graph; this says
nothing about whether halt is reached on the blank computation.

\begin{theorem}[New local reduction]\label{thm:local}
PA proves that $P$ and $C$, started in state 0 on the same represented
initial tape, halt equivalently. If they halt, their times satisfy
\[
 T_P\le T_C\le7T_P.
\]
For the blank tape, the complete finite startup is unchanged, not merely
bounded by this estimate.
\end{theorem}
The proof is given next without assuming consistency of any theory.
The inherited endpoint enters only after this local machine theorem.

\section{A contextual fold of native states 172 and 211}
\subsection{The entire literal edit}
Define $\rho(172)=211$ and let $\rho$ fix every other state, including
0 and 254. Starting with the exact parent table, make only these edits:
\begin{center}
\begin{tabular}{cll}\toprule
Old row & Parent action & New action\\\midrule
$116/0$ & $0R172$ & $0R211$\\
$211/0$ & $0R157$ & $0L214$\\
$172/0$ & $0L67$ & deleted\\
$172/1$ & $1R184$ & deleted\\\bottomrule
\end{tabular}
\end{center}
The $211/1$ row remains $1R184$. State 172 has just one incoming row,
$116/0$, so the first edit accounts for every redirected target. All other
surviving rows are unchanged byte-for-byte after normalized serialization.
In particular, the source map is literally unchanged.

\subsection{The predecessor contexts are exhaustive}
Put the head at coordinate 0 at the configuration being considered.
The following facts hold at every occurrence in any old run started
from state 0, irrespective of the exterior tape.

\begin{lemma}[Context at 172]\label{lem:172}
At old state 172, cells $-2$ and $-1$ contain 1 and 0 respectively.
\end{lemma}
\begin{proof}
The only transition entering 172 is $116/0$, which writes 0 and moves
right. The only transition entering 116 is $163/1$, which writes 1
and moves right. Neither 172 nor 116 is initial. These two immediate
predecessors place the two claimed bits and do not overwrite them
before arrival at 172.
\end{proof}

\begin{lemma}[Context at 211]\label{lem:211}
At old state 211, if the current bit is 0 then cell $-1$ contains 1.
\end{lemma}
\begin{proof}
The complete incoming list is $216/0:0L211$ and $216/1:1R211$.
The latter writes the required preceding 1 directly. In the former
case, all incoming rows to 216 move right:
\[
 132/1:1R216,\qquad199/1:1R216,\qquad214/0:0R216.
\]
If either of the first two was used, the next left move to 211 reads
the just-written 1, contrary to the current-bit hypothesis. Hence
the entry was $214/0$. The only entry to 214 is $217/1:1R214$.
Its written 1 is immediately left of the zero subsequently read by 211.
All these states differ from the initial state, so no first-visit
exception is possible.
\end{proof}

These are finite predecessor arguments about the old run. It is neither
necessary nor correct to assume that every intermediate visit of the
new run has the old meaning of its state label. Only block boundaries
are projected old configurations.

\subsection{Four complete tape identities}
Write $q_h$ for state $q$ with head coordinate $h$. For an old 172/0
configuration the known bits are $(-2,-1,0)=(1,0,0)$, and the new run is
\begin{align*}
211_0&\to214_{-1}\to216_0\to211_{-1}\\
 &\to214_{-2}\to163_{-1}\to157_0\to67_{-1}.
\end{align*}
This is seven transitions. The endpoint is exactly the old $0L67$
endpoint. For old 211/0, the known bits are $(-1,0)=(1,0)$ and
\[
211_0\to214_{-1}\to163_0\to157_1,
\]
three transitions, with exactly the old $0R157$ endpoint. If either
old state reads 1, the shared $1R184$ row gives the matching endpoint
in one transition.

\begin{center}\small
\begin{tabular}{ccclc}\toprule
Old state & Read & Known cells & Endpoint & New steps\\\midrule
172 & 0 & $(-2,-1,0)=(1,0,0)$ & $67_{-1}$ & 7\\
172 & 1 & $(-2,-1,0)=(1,0,1)$ & $184_1$ & 1\\
211 & 0 & $(-1,0)=(1,0)$ & $157_1$ & 3\\
211 & 1 & $(0)=(1)$ & $184_1$ & 1\\\bottomrule
\end{tabular}
\end{center}

Every transition on these paths writes back the bit it reads. No cell
outside the displayed known cells is read. Thus the equality is of
complete tapes, not only a finite projection or a sampled exterior.
No intermediate configuration is halting. All 414 parent rows outside
the two exceptional states satisfy the one-step equation
\[
 C(\rho(q),b)=(w,D,\rho(r))\quad\text{when }P(q,b)=(w,D,r).
\]
The verifier enumerates those rows and checks each local path using a
partial tape that raises an error on any unknown read.

\subsection{Halting preservation and reflection in PA}
Induct on old transition count. At each boundary, configurations have
the same head and entire tape and their states differ by $\rho$.
The predecessor lemmas license the appropriate exceptional block;
all other rows take one new step. Concatenating the nonempty blocks
constructs exactly the deterministic new run.

A finite old halting run therefore gives a finite new halting run.
For reflection, suppose the new machine halts by time $S$. If the old
machine had not halted during its first $S$ transitions, the block
induction would construct a nonhalting new prefix of length at least
$S$, a contradiction. This bounded argument is formalizable directly
in PA and does not require an appeal to actual infinite objects.
The local identities also show that no new halt occurs inside a block.

More precisely, if $n_{172,0}$ and $n_{211,0}$ count the indicated old
rows in a halting computation, then
\[
 T_C=T_P+6n_{172,0}+2n_{211,0}.
\]
The stated bounds follow. The complete old-state count is 209, the new
count 208; the halt label is not included in either. This proves
Theorem~\ref{thm:local}.

\section{Independent final table verification}
\subsection{Universal interpreter contracts}
The new local theorem already transports the exact parent's endpoint.
A separate replay on the final 208-state table checks the interpreter
without relying solely on that transport. There are 3,909 primitive
occurrences: 1,558 increments, 1,175 guarded decrements, 80 forward
branches, 1,095 backward branches and one halt. Splitting each decrement
into zero and positive branches gives 5,084 cases and 5,083 nonhalt
source edges.

These are a finite number of \emph{symbolic derivations}, not tests of
bounded register values. Their variables range over arbitrary natural
registers and header gap, and arbitrary nonempty finite spare lists.
The executable mathematics uses literal transitions, induction over
unary scan lengths, and structural induction over finite lists after
checking the one-block schema. Endpoints include the entire tape,
head, source address and register frame. A positive decrement is
represented with an arbitrary natural remainder plus one; zero and
positive branches are disjoint and exhaustive.

The accepted primary-table replay produced
\begin{center}
\begin{tabular}{lr}\toprule
Guarded contracts & 5,084\\
Literal rows covered & 416 of 416\\
Symbolic transition steps & 1,250,564\\
Working states checked & 208\\\bottomrule
\end{tabular}

The runtime engine is self-authored verification infrastructure reused
at exact file hashes, with assertions explicitly required. The supplied
external Python programs are preserved only as evidence where selected;

This is not a proof-assistant kernel: soundness rests on the stated
symbolic rules, their mathematical justification, and review of the
ordinary Python implementation. Passing all literal rows is useful
coverage evidence, but is not by itself a substitute for the quantified
contracts or for the consistency calibration.

\section{The inherited consistency endpoint}
\subsection{The exact unary theory}
Theory $\UU$ uses classical equality-free first-order logic over nonempty
domains, with membership as its only nonlogical symbol. Put
$\operatorname{Sub}(x,a)\equiv\forall z\,(z\in x\to z\in a)$.
For every formula $\varphi(x)$ with no other free variable, its schema is
\[
 \forall a\,\exists b\,
 \bigl[\forall x\,(x\in b\to\varphi(x))\ \land\
 \forall x\,(\operatorname{Sub}(x,a)\to(\varphi(x)\to x\in b))\bigr].
\]
Bound variables are freshened. The source $a$ is not a permitted free
matrix parameter. This is weak covering, not ambient extensionality
and not an exact power filter.

The retained unary-theory proof gives interpretations in both directions
with primitive-recursive finite-refutation translations. Its upper
interpretation uses binary-bit membership and formula-specific finite
comprehension in PA. The lower interpretation uses numerical
representatives modulo coextensionality and saturated codes; induction
is established before total successor existence. Parameters are bound
inside legal unary matrices. The resulting ordinary mathematical
statement is the PA-provable biconditional
$\Con(\UU)\leftrightarrow\Con(\PA)$, not merely external semantic
equiconsistency.

\subsection{The program and protected initial tail}
The machine searches the inherited numerical calculus $\mathcal D_U$.
Its truth and falsity codes are 0 and 1; its proof steps include the
logical and dominated propositional axioms, modus ponens,
generalization and the gated covering bundle. This machine-facing
cover presentation is parameter-rich and calibrated through unrestricted
covering with global irreflexivity. Retained U214, U218 and U222 arguments
handle translations, equality interpretation and small-code aliases.
Its axiom strings are not literally the unary schema. The separate
positive dyadic emitter in the unary package is not this program.

The startup calibration constructs nine theorem heads above opaque tail
4: seven logical instances, one dominated propositional instance and
truth 0. Protection matters because the inherited pairing satisfies
$4=P(1,1)$ and $1=P(1,0)$. The scheduler's prefix debt is at most two
from candidate index one, leaving margin seven. A ghost list length
handles $P(0,0)=0$ without a numerical stack-length decoder. The protected
tail does not become top or cache. The strong compiler above arbitrary
underlying stacks, together with cofinally successful candidate indices,
gives completeness despite the finite initial cutoff.

These are inherited mathematical dependencies. The new local proof and
runtime replay do not rederive every logical translation or export an
arbitrary-proof translator. Their exact source files, original notices,
licenses and nested archive identities are retained in the compact
dependency selection. A theorem for the different K215 ZFC machine
cannot certify this PA machine by substituting theory names.

\subsection{Composition of the new and inherited theorems}
The audited Compatibility parent has the retained ordinary calibration
\[
 \PA\vdash\neg\Halt(P,\mathrm{blank})\leftrightarrow\Con(\UU).
\]
Theorem~\ref{thm:local} gives, without consistency assumptions,
\[
 \PA\vdash\Halt(C,\mathrm{blank})\leftrightarrow\Halt(P,\mathrm{blank}).
\]
Classical propositional reasoning inside PA, followed by the retained
unary calibration, proves the endpoint in the abstract. Exact dense
renaming transfers it to \file{machine/u208.tm}. Inheritance records
proof provenance; it is not an extra axiom asserting that PA is
consistent. Neither this argument nor the checks establish actual
unconditional nonhalting.

\section{Reproduction and evidence boundaries}
The package is self-contained for the new transition and symbolic
checks. From its extracted root run
\begin{verbatim}
python3 verify.py --output finite.json
python3 -O verify.py --output finite_optimized.json
python3 verify.py --full --output full.json
\end{verbatim}
The first two commands need only Python's standard library. The full
command needs ordinary Python with assertions enabled and replays the
pinned self-authored unary/list-inductive engine; it does not run the
supplied programs. Outputs may be placed outside the package to keep
the sealed tree unchanged. The report can be rebuilt from
\file{report/report.tex} using two runs of \texttt{pdflatex}, with the
included transition-table TeX; PDF rebuilding is not needed for machine
verification.

The release manifest binds all selected file bytes. The source-selection
ledger separately records original archive members and original hashes:
it does not pretend that omitted PDF copies or large regenerable case
dumps remain present. The six input ZIP identities and the unary
archive identity are retained even where duplicate archive bytes are
not shipped. Original manifests are evidence of the originals, not a
manifest of this compact derivative.

The report's complete dense table is generated from the machine-readable
artifact. Final release checks extract the sealed ZIP to a fresh path,
replay finite and full verification there, rebuild the PDF, compare
extracted text and rendered page pixels, and record a standalone
verification receipt. Every final PDF page is visually inspected.

\textbf{Scope of the result.} The construction demonstrates a specific
208-state machine below the requested threshold. It does not prove
208 minimal, classify all possible reductions, or treat failed bounded
searches as impossibility results. Its genuinely new mathematical
content is the contextual 172-to-211 fold; source and theory remain
unchanged.
