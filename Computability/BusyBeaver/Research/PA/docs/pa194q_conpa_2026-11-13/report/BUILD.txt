Build the report
================

From this directory, with a normal TeX Live or equivalent installation:

    pdflatex -interaction=nonstopmode -halt-on-error pa194q_report.tex
    pdflatex -interaction=nonstopmode -halt-on-error pa194q_report.tex

Required packages are listed at the start of pa194q_report.tex. The report
uses Latin Modern, amsmath/amssymb, booktabs, longtable/tabularx, microtype,
xurl/hyperref, enumitem and fancyhdr. Every included .tex file is supplied.
No bibliography program, external figure, network or shell escape is used.

The supplied PDF was compiled twice and its rendered pages were visually
reviewed. The complete transition-table appendices are also bound to the
delivered numeric tables by the package assembly check.
