Proof obligations for safe_gate_and_encoding_variants.json

This file describes source-calculus equivalences. It does not certify any
new compiled binary Turing machine or establish a state count.

1. Conjunct reversal in the separation matrix
Let L=M(H,D)->(A->M(A,D)) and R=M(A,D)->A. The old separation
matrix is L and R, with and defined by N(I(L,N(R))). Replacing it
by R and L is a fixed classical equivalence. Head1 remains unchanged,
so code1 still has its established explosion property and all ordinary
classical propositional equivalences are available. Generalization and
the retained distribution head lift each implication to U(D,...).
Pure implicational congruence then replaces the S occurrence in Q,
and the final gate. This gives fixed, primitive-recursive proof templates
in both directions for every parameter tuple. All guards are retained.

2. Curried-premise reversal inside the separation matrix
Replace L=M(H,D)->(A->M(A,D)) by A->(M(H,D)->M(A,D)). This
is an equivalence of pure implicational logic, requiring no special
assumption about code1. Lift it to the entire gate exactly as above.
The point condition P=A->M(A,D) remains unchanged at its outer use.

3. Curried-premise reversal in heads 3,4,6
Replace X->(Y->Z) by Y->(X->Z) in any subset of those heads.
They are interderivable by fixed implicational templates. All parameters,
guards, numerical formula positions, and the ten-entry stack protocol
are unchanged. These are known safe variants in earlier packets, not
new mathematical discoveries.

4. Global reversal of M and/or E arguments
Let epsilon_M,epsilon_E be independent Booleans. Replace every M(a,b)
generated by AX with M(b,a) when epsilon_M is set, and every E(a,b)
with E(b,a) when epsilon_E is set. Other constructor meanings and MP
are unchanged. The source formula code used as a binder must be transported
at the same time as all other labels in the correctness argument.

Define tau(0)=0. For n>0, decode n=4p(u,v)+r. Recursively apply tau
to u,v, reverse their order for r=1 if epsilon_M and r=3 if epsilon_E,
then re-encode with tag r. This is a primitive-recursive involution,
fixing 0 and 1. The proof is structural induction on the strictly
decreasing Cantor components, with the I(0,0)=0 case handled separately.
In particular it is injective and preserves the two inequality guards.

Uniformly rename each variable label a to tau(a) and each formula code B
to tau(B). All constructor identities now commute with tau when the
new M/E orientation is used. This includes Gamma(B)=I(B,U(B,B)), and
the separation gate: its formula code c and separator label c become
the same number tau(c). The six ordinary heads, theorem generalization,
and MP therefore transport. The restricted propositional head needs one
additional established interface: replace a transported restricted instance
by the already derived unrestricted implicational head, since tau need
not preserve <=. The derivation of that unrestricted head uses only the
implicational basis, reflexive <=, and constructor-component bounds;
those are unchanged by this recoding. The inverse involution gives the
reverse proof translation. Both are verified in PA by induction on
finite proof codes. Soundness can equivalently interpret the new M or E
constructor by the reversed old relation.

5. Quantifier/equality tag exchange
Keep I=4p and M=4p+1. Use U(a,B)=4p(B,a)+3 and E(a,b)=4p(a,b)+2.
Modify every U/E construction, including the initial generalization.
The generated word has 202 tokens, not 190. Define tau recursively as
above, exchanging residues 2 and 3 after the recursive component map.
The recoding is bijective, fixes 0 and 1, and preserves all required
constructor identities and inequality guards. The same proof translation
works; combine raw argument flips with tag exchange if selected.
The source-stack compiler still has ten pushed entries. Its generated
universal formula has tag3 rather than tag2; both differ from tag0
and code1, so the forced MP failure and harmless Shift tests still hold.

6. Explicitly rejected near-variant
Replacing head1 by H->U(D,Ex(D,H)) alone is NOT established and must
not be included as a safe variant. Although classically dual to the old
schema once falsity/explosion is known, the original proof of 1->H uses
the old head1. Treating code1 as true and every U as identity witnesses
the circularity. Similarly, replacing old head1 (modal B) by universal
elimination (modal T) plus explosion requires a new argument; ordinary
normal modal logic does not derive B from T.
