\begin{abstract}\noindent
The requested blank-start machine with fewer than 194 working states and
an iPRA-provable equivalence of nonhalting with $\Con(\PA)$ is
\textbf{not established in this packet}. An unconditional iPRA consistency
equivalence is not claimed for the fallback either. The current repository
explicitly leaves that calibration open even for its primary PA194 table.
This is a proof boundary, not a nonexistence result.

The positive construction is \textbf{PA194AX11S}, a complete 194-state,
binary, one-tape machine combining the supplied eleven-entry AX interface
with the symmetric implementation of the original sum-based Shift test.
It is distinct from all \FrontierCount{} recovered prior 194-state classes
in the documented scope. It changes recurring execution, preserves AX11's
exact command interface, and removes three primitive source instructions.
Its relative source equivalence has a written proof in iPRA by
quantifier-free counter induction. The packet supplies its literal table,
deterministic builder, independent physical checks, exact blank startup,
source arrays, complete delivery and frontier ledgers, unsuccessful
sub-194 searches, and a proof that finitely many label exceptions cannot
repair the coefficient-three collision.
\end{abstract}

\section{Result and exact claim boundary}
The comparison is pinned to ProveIt commit
\href{\repo/commit/\pin}{\texttt{1c9524d8bf2e0a27b9a16ff622359927f536e663}}.
It covers 61 filed PA research packets and all eleven current incoming
archives: 72 deliveries. The delivery ledger records contributions;
the frontier separately records transition classes. Deliveries, table
classes, and accepted consistency constructions are different quantities.

The current PA README explicitly says that neither machine-specific
direction of the desired iPRA equivalence is established for PA194, the
original PA195, or PA196. It distinguishes ordinary PA calibration
manuscripts, standard finite-run Lean theorems, executable certificates,
and conditional iPRA endpoints \cite{pa-status}. Those distinctions are
retained here. Lack of a compiled Lean theorem alone would not refute a
complete ordinary mathematical iPRA proof. Here, however, explicit
mathematical obligations remain open too. Merely noting that the programs
are primitive recursive does not supply their weak-arithmetic correctness.

\section{Comparison of the designs}
\subsection{Scope, identity and evidence}
The filed repository index describes 7,130 historically delivered
\texttt{*.tm} occurrences in 61 packets and 535 classes. Its 49 classes
at 194 reachable states are not the full current frontier: explicit JSON
encodings, other literal formats and incoming archives add objects
\cite{machine-index}. The historical index and fresh census therefore
remain separate artifacts.
\input{census_summary.tex}

Novelty is checked on complete transition actions. The extended comparison
allows arbitrary state renaming, any graph-spanning initial root, global
left/right reflection, global binary-symbol exchange, and suppression of
write/move decoration on a terminal halt edge. Exact canonical tuples
are compared, not hashes alone. These allowances make novelty harder to
establish. In particular, symbol exchange need not preserve the designated
blank-zero computation; it is used as a conservative extra identification.

Start controls are recorded separately. Diagnostic assumptions of a
zero start for otherwise undeclared dense tables are explicitly flagged;
they do not establish a designated blank startup. Native tables,
renumbered tables with another initial state, runtime-only objects, and
rejected tables are not promoted to consistency constructions by a
dense-numbering convention. The census
recognizes the listed literal/JSON formats; it does not extract arbitrary
machine encodings from prose or executable programs. Historical evidence
labels attribute the supplied claims. All 72 contribution summaries were
reviewed; historical verification pipelines were not all rerun.

\subsection{Ideas transferred from the adjacent programs}
The ZFC work directly informs sharing conditioned on execution history,
reuse of return paths, and changes to continuations and spare registers. Its
phase-entry examples display the same risk as Runtime193: a proposed
runtime change may fire before initialization has completed. A long
observed computation does not establish calibration
\cite{zfc-phase,zfc-allocation}.

DiophantineConsistency usefully separates finite artifact identities,
refutation predicates, and internal iPRA proof-existence endpoints.
Polynomial-variable or arithmetic-circuit savings do not automatically
save TM controls; an evaluator, tuple enumeration, constants and startup
must all be counted \cite{diophantine}. ConciseIPRA measures a complete
standalone proof checker, not binary-state count. Its explicit logical
infrastructure can help internalization, but replacing PA refutation
search by iPRA refutation search changes the consistency target
\cite{concise}.

\section{The new literal machine}
\subsection{Conventions and identity}
PA194AX11S has one two-way infinite tape, alphabet $\{0,1\}$, blank zero,
initial head position zero and initial state zero. Working controls are
$0,\ldots,193$. The separate halt label 194 has no outgoing rows. Every
one of the 388 rows writes a bit and moves exactly one cell left or right.
There is no external initialization or preloaded program.

The authoritative dense table is \path{machine/machine.tm}, with SHA-256
\begin{quote}\small\ttfamily
ae52144ee2bb48e2e90cd473b09054d2024cbdd05deb7261a9bb5bfbf67b4db1
\end{quote}
The native table has start 74, halt 254 and hash
\begin{quote}\small\ttfamily
e20ddac13f587826e318e1d1e1f0d823033da438edd00a811b12a2ae28966909
\end{quote}
The label bijection includes the halt label. All 194 working controls are
reachable in the directed transition graph; this is not a claim that the
blank computation visits every control.

The source replaces \texttt{node168=(node37,node57)} by
\texttt{(node37,node56)} and \texttt{node171=(node170,node23)} by
\texttt{(node170,(inc 5,continueTo 3))}. AX's grammar, its four-field
decoder, every formula head, and no-push MP are unchanged. The first
3,667 resolved instructions agree; the final five become two. The new
source has 3,669 sites and 4,775 outcome contracts.

The physical allocation is
\[
135\text{ fixed}+67\text{ AX readers}-8\text{ history folds}=194.
\]
Seven folds are inherited reader folds. The eighth shares old 41 with
new 330, distinguished by the preceding written bit. All 32
history/current-bit cases and the incoming-row hypotheses are checked
in the final simultaneous table. The exact traces are supplied.

Neither the AX11 protocol nor the symmetric comparator principle is
claimed as newly invented here. The contribution is their previously
unmatched, completely bound physical composition and the new source-level
weak-arithmetic proof presentation. This changes a recurring command
implementation; it is not a control renaming or a change to unused rows.

\subsection{Preserved commands}
For Cantor pairing $p(a,b)=(a+b)(a+b+1)/2+b$, use total stacks
$[a;w]=p(a,w)$ and formula constructors
\[
I(a,b)=4p(a,b),\ M(a,b)=4p(a,b)+1,\
U(a,B)=4p(B,a)+2,\ E(a,b)=4p(a,b)+3.
\]
The store is $(t,w,d,h)$: visible top, encoded stack, offset and cached
head. For $b=d+x$, no-push modus ponens is
\[
\mathsf{MP}_x(t,w,d,h)=
\begin{cases}(b,w,b,0),&I(t,b)=h,\\(0,w,b,0),&I(t,b)\ne h.\end{cases}
\]
The four-operand AX command remains
\[
\mathsf A_{c,x,y,z}(t,w,d,h)
=(0,[q_0,q_1,\ldots,q_9,t;w],z,0).
\]
The ten generated entries are the same guarded, diagonal, six ordinary,
restricted implication and universal heads as in AX11. The extra $z$
is read by the full MP reader after the push. Soundness must cover every
$z$; the inherited completeness compiler chooses $z=0$. The present
change does not remove that fourth field \cite{ax11}.

The exact Shift remains
\[
\mathsf S(t,w,d,h)=
\begin{cases}\mathsf{halt},&t+h=1,\\
(h,\operatorname{tl}(w),d,\operatorname{hd}(w)),&t+h\ne1.
\end{cases}
\]
It is distinct from the cache-only H protocol, and does not halt when
$t=h=1$.

\section{Physical and executable verification}
The construction and independent checkers implement the source-to-tape
check separately. They share the declared interface and inherited
mathematics; they are not two independent proof-assistant kernels. The
independent checker imports no arithmetic-box oracle and rederives four
generic list identities from literal rows before checking every outcome.
\input{verification_table.tex}

The contract domain consists of nine arbitrary natural register values,
an arbitrary finite nonempty list of natural spare values, and an affine
header gap $48+n$, with source-address length subtracted. Both decrement
outcomes are checked. Symbolic-operation counts measure verification
work, not an upper bound on the eventual physical computation.

At move 58,004 the complete blank startup reaches native state 84, head
$-2$, and source entry 25. Logical register zero contains two; the other
eight registers contain zero; 26 spare blocks contain one. The equality
checks every marker, source bit, register/spare block and the zero
exterior. AX11's corresponding startup is 58,154 moves. This 150-move
saving is an initialization comparison, not a uniform literal speedup.

Positive-duration source contracts connect clean frames to the next
frame or to halt. Along with exact startup, they establish the physical
construction's ordinary mathematical source interpretation. Formalizing
the full connection in the repository's object arithmetic requires the
additional obligations in the following appendix to the main argument.

\section{Attempts to pass below 194}
\subsection{Runtime193 and startup repair}
The inherited Runtime193 core identifies $301$ with $88$, redirects its
targets, removes control 301 and changes
\[
\delta(88,0)=(0,L,51),\qquad\delta(51,0)=(0,R,122).
\]
It has 193 controls and 386 rows. Its source contracts pass on prepared
frames, but the original blank start enters a certified outward ray.
Changing only the initial control does not provide a suitable startup.
The core is not a 193-state blank-start solution.

The complete census contains 53 whole spanning 193-state classes: 49
runtime-collapse transplants, this AX11 runtime core, a QN6 runtime core,
a relay, and the coefficient-three design. A separate literal startup
replay checks all controls for the 49 transplants and AX11 core, and the
documented native start 74 for the relay and QN6 core. Its 9,652 blank
runs finish within 2,000 steps with 102 halts and 9,550 certified outward
rays; none remains unresolved. The coefficient-three failure is logical,
so its inherited rejection is attributed separately. Representatives,
classifications, run witnesses and replay code are under
\path{comparison/}; the new finite-exception obstruction is proved below.

The new experiments try coordinated row changes proposed by context screens
and alternative helper realizations. They require a complete canonical frame,
not a tape window that merely resembles one. Pools, explicit horizons,
runtime rejections, and speculative arithmetic-box edits are recorded.
\input{startup_search.tex}

These finite negative results do not cover new representations, all
initialization seeds, arbitrary coordinated changes, or different source
programs. They establish no state-count lower bound.

\subsection{Decoder allocation}
Two bounded searches use the AX11S fixed table after its controller fold.
The first reassociates the two supplied AX11 macro-word seeds; the second
also changes parameter permutations of the six ordinary heads. With 134
fixed controls, an effective-reader score of 59 would nominate 193 states.
Such a score would still require source, tape and startup verification.
\input{grammar_search.tex}
The fitness includes scanner constraints and compatible history folds;
it is not a universal complexity measure. Replaying optional stochastic
searches is unnecessary for verifying the frozen construction.

\section{Further research questions}
\begin{enumerate}
\item Can Runtime193 reach a different valid enumeration seed after a
representation-aware startup repair? A relaxed seed still needs a
complete proved frame and exhaustive scheduling.
\item Can longer remembered tape contexts share a physical control
without changing initialization or a register-arithmetic lemma?
One-helper and bounded-window searches leave this open.
\item Can AX11's fallthrough support a decoder or command composition
that removes a fixed control? The fourth operand is a real cost.
\item Can a typed grammar or changed equality-witness constructor make
coefficient three viable? Finite exceptions are insufficient; new proof
translations and a measured physical implementation are required.
\item Can the complete controller/frame invariant be expressed as a
primitive-recursive relation with a quantifier-free induction proof?
This could connect the existing contracts to the all-model endpoint.
\item Can the arbitrary-PA-proof compiler be made explicit enough to
invoke the existing $\mathrm I\Sigma_1$ transfer? The next target is an
actual calibration premise for a pinned table.
\end{enumerate}

Keep assertions enabled and run from the packet root:
\begin{verbatim}
python3 -B verify_all.py --receipt fresh_verification.json
\end{verbatim}

replays both physical checkers, checks the source and obstruction
certificates, and tests novelty against the frozen frontier. No original
checkout, network, solver or proof assistant is needed. Optional searches
may require a C++17 compiler.
