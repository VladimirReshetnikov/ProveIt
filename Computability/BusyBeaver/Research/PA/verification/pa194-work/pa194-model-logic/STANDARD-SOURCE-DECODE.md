# Decode valid standard source-formula codes

`standard_sourceFormula_quote_surjective` proves that every standard natural p satisfying `IsSemiformula SourceL n p` is exactly the quote of some typed standard `Semiproposition SourceL n`, for every natural n. It covers arbitrary nesting. The proof first decodes every scoped relational-source term; it uses the actual relation-language encoding to decode positive and negative atoms, and strong induction on the coded formula for Boolean and quantifier constructors. All natural-model coding is explicit; no nonstandard-code surjectivity is claimed.

Together with the separately checked standard shift-fixed/no-free correspondence, this provides the arbitrary-natural decoding prerequisite for the uniform separation classifier's standard membership theorem.
