This package constructs fixed ordinaryPAeq proofs of the arithmetic sentences `∀x, x + 0 = x`, `∀x, x * 0 = 0`, and `∀x, x * 1 = x` using PAeq induction, and verifies their exact Foundation source translations and quotation as valid internal ordinaryPAeq proofs in every arithmetic IΣ₁ model. The last certificate uses the checked typed add-congruence specialization `addCongrAt`; the repository draft `addExtCertificate`, which contains sorry, is not imported.

Combining those three with the six earlier audited cases, `finite_cases` exhaustively classifies every Foundation PeanoMinus axiom as one of these nine proved cases or an element of the explicit 17-entry `remainingFinite` list. The list contains function congruence for addition and multiplication, relation congruence for equality and order, and 13 remaining arithmetic/order cases. `pa_refutation_of_remaining` proves in any arithmetic IΣ₁ model that a PA refutation yields an ordinaryPAeq refutation assuming ordinaryPAeq provability of the 17 listed translated sentences. The remaining finite cases are not proved here; PAeq-to-source proof compilation, physical machine synchronization, and native iPRA equivalence remain separate. These are modeled proof-existence statements, not a uniform proof-code transformer.
