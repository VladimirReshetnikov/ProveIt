# Standard-property ordinal proof reduced to six fixed premises

`standardOrdinalProofOfExactContext` constructs an actual Foundation internal proof of `⌜inductionStatement p⌝` in `adjunctiveFullSepTheory`, for each **standard typed** source property p, in each covered candidate-PRA + induced-IΣ₁ model, assuming internal proofs of each of the six fixed formulas in `exactContext`: empty, exact adjunction, reflexivity, symmetry, transitivity, and congruence.

The construction quotes the existing standard Foundation `inductionFoundationDerivation p` into the model and eliminates its finite context by internal cut. The separate intersection and parameterized separation-of-¬p premises are supplied from the classifier-defined union theory, using the independently replayed `PA194OrdinalSuppliers`. The six fixed context proofs remain explicit hypotheses. The standard typed property restriction is essential: this result does not construct a proof for arbitrary nonstandard internal property codes and does not yield a uniform proof-code transformer or an iPRA theorem.
