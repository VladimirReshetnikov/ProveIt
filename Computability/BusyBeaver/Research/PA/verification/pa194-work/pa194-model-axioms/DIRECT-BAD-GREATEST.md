# Greatest predecessor existence for a direct bad trace

In every PRA model with IΣ₁ arithmetic reduct and any internal theory, a trace of the negated property and membership of an arbitrary point in that trace, together with source domain, ordinal base and two fixed universal theorem derivations, yield an internal derivation that the point has a greatest predecessor. This works for arbitrary internal property codes and model-valued source, witness and point indices. The exact resulting proof code is defined by a fixed Σ₁ graph.

All input derivations remain hypotheses; this does not itself construct the least witness, complete ordinal induction, or prove an iPRA machine theorem. The checker recompiles the source with selected byte-checked repository-built dependencies; other imports are prebuilt. Run from the repository root:

