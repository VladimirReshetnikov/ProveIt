# PA194 site-28 increment instruction

`PA194Site28Complete.complete` proves an all-model physical execution of the pinned PA194 stepper from a state-24 source frame at the actual site-28 path to a state-24 frame at the actual site-29 path. The input must have the startup's numeric suffix `seedTail`, which encodes 25 one-valued spare blocks. The theorem accepts arbitrary model-valued logical registers, the preceding spare, and padding `k`; it preserves the other logical registers and that preceding spare, increases logical register 8 by one, and updates suffix slot 10 to `block 1 seedTail` to account for the new spare block. The input zero run has length `k+2` and the output run has length `k+1`; the site-29 path itself is one bit longer. The physical execution is given by explicit nested stepper applications and clocks.

`PA194Site28OutputFile.outputFile` identifies the reconstructed file with the stated logical-register and suffix updates. `PA194Site28SeedOutput.seedReturnFile` proves the actual 25-block tail reconstruction and the appended spare. Its fixed natural-number identity is derived in `PA194Site28SeedOutputProbe.probe` from structural file/word results and kernel-checked list identities; no native computation oracle is used.

`check-site28-complete.sh` rebuilds these four modules against the retained site-27 baseline and the documented site-28 carry, code, round-trip, seed, and finish-return stages. It pins directly imported objects and sources, audits axiom reports for `sorryAx`, rejects machine-specific fallback roots and overlapping machine objects, and verifies all input objects unchanged during compilation. Invoke it with `REPO SITE27_BASELINE SITE28_STAGE CODE_STAGE ROUND_STAGE SEED_STAGE FINISH_STAGE PROJECT_FOUNDATION PACKAGE_FOUNDATION SOURCE_DIR NEW_OUTPUT`. Earlier stages and general foundation objects require independent reproduction or trust.

This proves one complete source instruction semantically in every candidate model of PRA, for this specific finite tail. It does not yet derive a native iPRA sentence for the instruction, cover every source instruction or arbitrary runs, or prove either direction of the consistency/nonhalting equivalence.
