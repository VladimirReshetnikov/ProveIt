# Model-uniform coded carry through a finite physical file

`PA194Site28CarryCodes.carryFileCoded` proves the state-3 carry for each externally chosen finite number `n` of blocks, with arbitrary model-valued block lengths and arbitrary complete final numeric suffix. It gives the physical state-3 output and its exact clock and left-tape half as explicit primitive-recursive codes. The code families `timeCode n` and `leftCode n` are built by Lean recursion on the external natural number `n`; the theorem does not quantify internally over arbitrary, possibly nonstandard, block counts.

The proof factors through `PA194Site28CarryCell.carryCell`, the reusable one-block increment-marker transport, and `PA194Site28CarryFile.carryFile`, the corresponding model-uniform finite-block theorem with semantic recursive expressions. It preserves the next block and entire suffix without assuming a blank tail. It does not itself include the initial site-28 root-to-write path or prove the final site-29 source frame.

`check-site28-carry-codes.sh` rebuilds the three sources against a pinned site-27 coherent baseline and the retained output of `check-site28-after-carry-seven.sh`. It checks their object hashes before and after compilation, rejects overlapping machine objects and machine-specific fallback roots, pins the directly imported increment-write object and the three source hashes, and checks target axiom reports for `sorryAx`. The direct object pin and unchanged-object receipts do not independently prove the prior stage or foundation provenance; reproduce or otherwise trust their documented builds.
