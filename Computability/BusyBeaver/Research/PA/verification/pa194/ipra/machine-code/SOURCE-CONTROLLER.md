# Finite PR controller code and source selector binding

`PA194SourceControllerCode.lean` constructs a finite primitive-recursive code for a source controller step and its iteration. A state is a square pair `(pc,file)`; `file` contains nine nested square pairs for registers and an arbitrary residual suffix. Program counters 0 through 3672 denote source ordinals; 3673 is the malformed sentinel and 3674 the absorbing halted sentinel. A normal root exit restarts at source ordinal 0. The finite instruction list is built directly from the pinned `PA194SourceTree.trie` using `nthSite` and `M6.FastResolve.resolveTree`; its sites are not hand transcribed. Instructions update the program counter and relevant register, and the run is the existing generic PR iterator.

`PA194SourceControllerBinding.selectActual` kernel-checks that, in every candidate PRA model, the constructed selector chooses the resolver's actual instruction for every **standard Lean natural** i < 3673 whenever the model PC equals the model numeral i. This is a standard finite-index family quantified by Lean; it is not yet an object-theory universally quantified source execution theorem, nor a theorem about an arbitrary nonstandard model PC. `PA194SourceControllerSites` checks the source table length, the halt instruction at site 10, and the site-25 decrement of register 8 with zero/positive targets 27/26, then specializes selector correctness to both. `PA194SourceRegisters` checks model semantics for the actual nested-pair read and write codes and proves same-register and other-register read-after-write laws for all model values and standard register indices. All audited theorem reports contain no `sorryAx`.

The finite PR code's instruction execution has not yet been fully proved equivalent to source `cycleStep`; selector binding and register laws are components of that obligation. The source table's completeness/well-formedness, reachable-state invariant, initialization, representation by physical frames and exact clock, scheduler correspondence, and native iPRA consistency direction remain separate obligations. The built-in absorbing halt is entered *after* executing site 10; the earlier gated theorem treats PC=10 as ready-to-halt and stops the active prefix there.
