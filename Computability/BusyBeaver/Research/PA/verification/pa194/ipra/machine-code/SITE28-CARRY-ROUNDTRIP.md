# Site-28 finite-file blank-tail carry round trip

`PA194Site28CarryRoundTrip.roundTrip` composes a coded state-3 carry across an externally chosen finite list of model-valued blocks, the final block, the three-step blank-tail exit, and a coded state-7 rewind across the same blocks. Its input requires the far-end numeric suffix to be zero and the initial marked left half to have odd parity. It states an exact nesting of stepper applications and clocks, returning to state 7 with the restored left half and an explicit primitive-recursive `returnCode` expression for the reconstructed right tape. Block values remain arbitrary. The finite block count is external, not an internal quantifier over possibly nonstandard numbers.

The proof factors out `PA194Site28ReturnCarry.returnCarry`, which independently reverses the new carry-left representation through an arbitrary fixed finite number of blocks, given an odd marked left base and an arbitrary odd right-tape base. It uses the existing primitive-recursive return and clock codes. `PA194Site28BlankExit.blankExit` is explicitly limited to a blank right half; `PA194Site28ReturnKick.kickReturn` connects that exit to the existing return-cell theorem. The generic table lemma `PA194LeftZeroWriteOne.leftZeroWriteOne` covers any checked left-moving row with a zero read and one write.

`check-site28-carry-roundtrip.sh` recompiles these five sources against the retained site-27 coherent baseline, the source-rebuilt site-28 carry stage, and the coded-carry stage. It pins the manifest and direct imported objects, verifies source hashes and all input objects unchanged, rejects machine-specific fallback roots and overlapping machine objects, and checks the target axiom reports for `sorryAx`. Invoke with `REPO SITE27_BASELINE SITE28_STAGE CODE_STAGE PROJECT_FOUNDATION PACKAGE_FOUNDATION SOURCE_DIR NEW_OUTPUT`. The earlier stages and general foundation objects must independently be reproduced or trusted; this checker does not authenticate their original provenance.

This theorem does not yet reconstruct the state-24 site-29 source frame, prove the combined result in native iPRA, handle an arbitrary unstructured far-end suffix, or establish either direction of the consistency equivalence.
