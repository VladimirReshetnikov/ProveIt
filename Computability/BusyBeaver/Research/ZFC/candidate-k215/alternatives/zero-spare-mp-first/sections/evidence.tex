\section{Verification, reproducibility, and novelty}
The proof obligations are deliberately separated.
\begin{enumerate}
\item \textbf{Literal construction.} Rebuild the table from the pinned parent, its one changed row, and its designated start; check all working states, outgoing rows, targets, and dense renaming.
\item \textbf{Blank connection.} Replay every transition of the finite initialization in independent sparse-tape and dense/native forms; reconstruct the entire endpoint frame and compare the source AX prefix.
\item \textbf{Unbounded physical simulation.} For each of the 6,209 guarded source primitive cases, use symbolic induction over arbitrary unary runs and block lists, with arbitrary natural primary values, gap, and nonempty finite spare lists. This is not a bounded test of small register values.
\item \textbf{Source soundness and completeness.} Use the exact command contracts, protected-tail theorem, strong compiler, and cofinal encoding. None follows merely from a primitive census or a successful blank prefix.
\item \textbf{Theory calibration.} Use the explicitly inherited numerical-calculus equivalence with ZFC consistency.
\end{enumerate}
The fresh runtime proof passes all 6,209 guarded cases, with 1,610,781 symbolic rule applications, minimum affine duration constant 10, and coverage of all 430 physical rows. The frozen receipt binds these counts to the exact source and table hashes. The portable verifier rederives the runtime proof when its full-runtime option is selected. The default verifies the exact artifact and stored evidence, and must not be described as a fresh rederivation of all runtime cases.

The independent comparison uses 77 distinct 215-state tables representing 44 rooted transition-graph classes. It covers all 28 table paths in the current \file{candidate-k215} subtree at the pinned repository snapshot, the relevant new incoming archives, and the retained historical comparison tables. The new machine has no rooted state-renaming match, including after a global tape reflection. A frozen corpus and offline checker make this bounded statement reproducible. It is not a claim to have compared every Turing machine or every unpublished construction.
