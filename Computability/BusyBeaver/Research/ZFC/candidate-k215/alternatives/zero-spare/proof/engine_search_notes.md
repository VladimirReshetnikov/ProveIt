These are failed or inconclusive searches, not lower-bound proofs.

1. A local all-tape search considered28 state pairs with disjoint four-bit
   predecessor contexts and one identical row, seeking existing provider
   blocks of at most28steps. A second search allowed both rows to change,
   considering3,567 pairs and blocks up to20steps. Neither found a verified
   provider. Failure to close is not semantic inequivalence.

   primitive contracts and blank startup. State198/1 is essential to this

3. A bounded filter tried856 single-row replacements of66/0 after deleting198.
   The first sample was CI8 on nine zero registers with spares `[0,1,0]`; the
   second was a zero CD8. Six replacements survived the increment sample, but
   each produced an incorrect canonical frame for the zero decrement. Some
   other rejections were time bounds, so the result is only a failed filter.

   two-truth-prefix source theorem is essential to validate that frame.
