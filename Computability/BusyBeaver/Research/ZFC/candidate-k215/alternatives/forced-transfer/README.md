## Reproduction

Python 3 with its standard library suffices. Assertions must be enabled. No network, downloaded executable, installed solver or proof search is needed.

    python3 -I -B verify.py --work /fresh/empty/output
    python3 -I -B verify.py --runtime --work /fresh/full/output

The output directory must be empty and outside the packet. The first command rechecks all exact source bindings, complete tape startups in three implementations, source bridges, finite credit certificates, rooted graph/reflection comparison against the included finite prior corpus and the inherited dominated-row certificate. The second additionally rebuilds every universal guarded primitive proof for all three selected tables, totaling 18,484 cases, and compares the exact censuses. It takes several minutes.

The checker's passing status means the listed executable checks passed. Written infinite mathematical proofs and inherited logical calibration are separate, identified dependencies. The source runtime is arbitrary-natural and whole-tape; the finite credit bases are justified by the accompanying all-natural counting bounds, not empirical extrapolation.
