This first explicit family contains3,888 source layouts: independent permutations of three numerical parameters in each of K, S and QS, six formula orders, and right/left/balanced macro sequencing. These figures count source subtrees, not working states.

Every constituent macro is closed, and exact symbolic postfix decoding checks each formula. The eight retained zero-run-compatible trees pass two independent complete source control-graph resolvers. Their attempted incremental allocations all fail decoder-prefix validation; no raw table is accepted or published as a machine. The identity allocation control reproduces the exact218 table before modification.

Parameter permutations count recipes, including repetitions caused by unused parameters. No optimizer beyond these three prescribed parses was run. The result gives no general grammar or machine lower bound, and it does not establish enumerator coverage, blank startup, primitive runtime, or a consistency theorem for a changed binary table.
