# Independent review of the single-rotation fold experiment

The new census and discovery drivers have no identified mathematical or
candidate-acceptance blocker. The completed run covers 25 independently
constructed one-rotation layouts and exactly 282,416 specifications, with no
filter survivor. No primitive runtime, blank initialization, proof-assistant
endpoint, 217-state construction, or lower bound follows from these negatives.

I read both complete root-authored drivers and the relevant source-language,
decoder binding, filter and independent-checker interfaces. My own static
auditor imports none of these programs. It independently reconstructs all
retained source substitutions and four-row physical rewrites, checks the
complete internal-prefix relation and ordinal CFG, and regenerates the finite
candidate specification sets without running their filter. It reads every
compressed rejection record, checks its membership and unique identifier, and
exhausts each expected specification set. The result is 1,707,341 assertions,
25 layouts and 282,416 records, all passing.

The source rotation replaces every equal parent subtree simultaneously. Its
two represented states are each single-role, pure right-moving states; the
child has only the parent-edge incoming row. Each of A, B and C is closed and
halt-free. The exact source word and ordinal transitions are unchanged, but
the physical table still requires new primitive execution and startup proofs.
The inherited decoder checker deliberately skips leaf-entry edges. The new
driver correctly compares its entire internal state/subtree relation to the
intended replacement, rather than merely accepting arbitrary reached states.

Every ordered pair touching either rotated state receives its inherited
action family. Synthesis of the other branch occurs only when exactly one
mapped branch is common. Other pairs are considered only with exactly one
common branch and a synthesized target in the two rotated states. Initial
state deletion is represented by the mapped new start. The old-path cache is
per layout, contains unmapped paths, and applies the current deletion map at
candidate comparison. Every possible positive result would receive the
independent checker, with a freshly recomputed all-initial-tape domain and
negative control. No such call occurred in this all-negative run.

The 180-second bound is checked between operations; it is an internal soft
deadline, supplemented by the reported external limit. The completed measured
run is below both. Assertions must remain enabled. Neither arbitrary row
pairs nor two or more successive source rotations are covered.

I read both portability diffs and the publication README. The portable
repository lookup is correct; the census helper bodies are AST-identical,
and the search is byte-identical after reversing its exact path/argument
substitutions. All 54 published layout/census/result/stream files checked
equal the audited originals. No portable driver or candidate was rerun.

The only requested prose correction concerns attribution: the fast filter was
authored by this reviewer in earlier K219 research; the independent checker
is the Source139 submission, while source/decoder utilities are inherited
K221 code. This review is independent of the new root-authored drivers but
does not present the reviewer's own older filter as independently authored.
