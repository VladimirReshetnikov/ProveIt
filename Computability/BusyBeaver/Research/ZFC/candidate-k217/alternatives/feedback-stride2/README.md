## Reproduce

Use Python 3 with its standard library. Assertions must be enabled. No network access, package installation or proof search is required.

    python3 -I -B verify.py --work /fresh/empty/output
    python3 -I -B verify.py --runtime --work /fresh/full/output

The output directory must be empty and outside the extracted packet. The second command rebuilds all 6,152 arbitrary-natural primitive cases of the rejected experiment and all 6,153 cases of the corrected 217-state companion, all finite-list certificates and the exact ordered case census. It takes a few minutes. Results are written only to the chosen output directory.

A successful command means that the listed checks passed, including confirmation of the source error. It confirms that the 215-state experiment is rejected. The corrected 217-state calibration additionally relies on the included written source and mathematical proofs, not an exact-table Lean/Rocq endpoint. Mathematical proof arguments, full source-macro binding and physical runtime are separate obligations.

For the PDF, run build_report.sh with a normal TeX Live installation. The source uses standard LaTeX packages and Latin Modern fonts.
