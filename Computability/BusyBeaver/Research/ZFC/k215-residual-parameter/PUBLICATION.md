# Additive residual compiler: publication and independent root review

The new source language has an ordinary proof that its proof enumeration
halts exactly when the inherited numerical ZFC calculus derives falsity.
It removes MP's numeric field while retaining AX's additive first argument.
This is progress on the encoding interface. Its current physical prices
do not reach 214 working states, and no new binary machine is accepted.

Root read the complete [ordinary proof](proof.md), new finite interface
checker, source constructor, conservative allocator, compressed-source
recovery helper, README and attribution. The two essential details are
the preserving zero setter and the three-AX RESET. Two RESET halves leave
an old bundle cached. In GEN, the new AX argument is A=i; row9 and tag
safety justify selection without assuming its gate is zero. Dominated
row compilation uses A−U only under U≤A. The original certificate then
recovers unrestricted rows. Raw zero stack aliases and unsafe initial
cache values are covered explicitly in the completeness proof; soundness
uses only theorem-safe seeds.

The exact-source checks establish all retained instruction effects and
guarded targets under the splice map. Ordinary all-natural loop reasoning
establishes the changed residual contract; its finite probes are supporting
evidence. The 16 saved closed reassociations preserve the entire primitive
word, both full guarded graphs and the frozen partial-selector subtree.
Closedness permits divergence and does not imply termination.

The own finite interface checker covers 5,915 cases with three abstract
safe-row implementations and explicit compiler-premise oracles. It does
not execute the complete native AX generator. Root replayed the portable
source construction, interface checker and exact decompression after
publication, recording separate stdout/stderr, timings and unchanged code
input captures in [verification](verification/portable.json).

Two allocator policies retain distinct limitations. The conservative
allocator reproduces the exact 215 identity but prices the best 206-DAG
source at 240 states. The role-pool identity also reproduces all 430 rows;
its single candidate solve is infeasible under that policy. Its domain
census has 27 new roles and 22 eligible states with injective assignment,
so this particular necessary condition already fails. Neither result is
a lower bound on TMs, other source forms or less restrictive allocators.
No new full runtime or blank-start proof follows from these prefix checks.
