leaf measurements and the three passed actual-tree subtree pilots. It uses the
exact current raw PASS records, complete source/audit snapshots, original logs,
current dependency/source/object hashes and original pre-audit object bindings.
It requires17 named reports,31 typed callers and zero selected warnings.

under `Research/ZFC/routing245-coverage-pilots`, and ten raw result records.

lossless history, including preparations, batch records, reviewer scripts and
receipts. Cache products and symlinks are explicitly listed as exclusions; no
object file is published. The original guards remain historical, with no new
portable guard or clean-checkout compilation claim. No installation is performed.

90leaves/117guards. These families overlap and their counts must not be added.

objects; these pilot artifacts do not prove complete8391-case coverage, blank
startup, or a binary/PA consistency endpoint.

The author has only prepared and statically parsed this builder. Root should
read it and choose a fresh external `--output` before any execution. It invokes
no compiler, simulation, proof checker, supplied generator or Git command.
