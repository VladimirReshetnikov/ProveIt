# Context-aware decoder sharing

The [bounded investigation](notes.md) develops Source 167’s trace-sharing proposal and records a concrete failure of sharing by state/read-bit alone. Its 281 local frame classes cover 4,749 internal decoder edges; the existing 4,751 leaf and 6,176 branch obligations remain. These local counts establish no full-checker speedup.

The own finite census and original source/table pins are retained in `census.py`, `result.json` and `review.json`. No Lean implementation or kernel result is claimed. The script retains its historical workspace path and overwrites a result beside itself if run; use a scratch copy for replay.
