\begin{abstract}
The main result is a stronger and smaller replacement for the dominated-$\rho_8$ completeness proof used by K215. The new theorem applies to an arbitrary implication operation and a reflexive relation closed under placing a related term inside either operand. Restricted $\rho_8$ instances and modus ponens suffice: no distinguished true numeral, least element, numerical encoding, injectivity, decoding, or identity $0\impop0=0$ is needed. A compressed finite derivation retains 84 of the original 117 numbered helper schemas; the main unrestricted-$\rho_8$ theorem depends on 82. A direct composition/exchange argument replaces the local deduction calculus. The generic result is checked in Lean and Rocq, and a numerical Lean adapter preserves the current public interface. A further checked specialization shows that four explicit implication-context schemes suffice, with no order relation at all. A numerical client proves equality with the existing $C222$ calculus for every code.

A second checked contribution composes the incoming 1,426-entry normalized source certificate with balanced lookup, using an exact refinement theorem rather than a new semantic simulation proof. An optional Lean patch makes the register-to-tape halting bridge an instance of an existing positive-simulation theorem. We compare alternative 215-state machines by proof obligation, prove a logical obstruction to one restricted-vacuity recovery strategy, and search a different family of state eliminations. No verified 214-state machine is produced.
\end{abstract}

\section{A stronger dominated-implication theorem}
\label{sec:abstract}
The old proof is phrased over natural-number codes. Its architecture obscures which numerical facts are actually needed. The new derivation separates the implication calculus from its encoding.

\begin{definition}
A \emph{dominance language} consists of a type $A$, a binary operation $x\impop y$ on $A$, and a relation $\preceq$ satisfying
\begin{align}
 a&\preceq a,\\
 u\preceq x&\ \Longrightarrow\ u\preceq(x\impop y),\\
 u\preceq y&\ \Longrightarrow\ u\preceq(x\impop y).
\end{align}
There is no separate transitivity or antisymmetry requirement. Define
\[
\Rho{a}{b}{c}{u}
 =((c\impop u)\impop a)\impop((a\impop c)\impop(b\impop c)).
\]
A predicate $\T\subseteq A$ is closed under modus ponens if
\[
 \T(x\impop y)\ \text{and}\ \T(x)\quad\Longrightarrow\quad\T(y).
\]
\end{definition}

\begin{theorem}[Restricted rows suffice]
\label{thm:rho}
Let $(A,\impop,\preceq)$ be a dominance language. Suppose $\T$ is closed under modus ponens and
\[
 u\preceq a\quad\Longrightarrow\quad\T(\Rho{a}{b}{c}{u})
 \qquad(a,b,c,u\in A).
\]
Then every unrestricted row belongs to $\T$:
\[
 \T(\Rho{a}{b}{c}{u})\qquad(a,b,c,u\in A).
\]
The same assumptions derive composition and distribution:
\begin{align*}
\T\bigl((a\impop b)\impop((b\impop c)\impop(a\impop c))\bigr),\\
\T\bigl((a\impop(b\impop c))\impop((a\impop b)\impop(a\impop c))\bigr).
\end{align*}
\end{theorem}

The conclusion assumes no distinguished element $0$, known theorem at that element, least-element property, pairing function, or decoder. The operation need not be injective; different expressions may denote the same element. This directly accommodates codes that need not decode to ordinary formulas.

\subsection{Eliminating the initial theorem assumption}
An intermediate bootstrap is conveniently proved assuming one theorem $\T(\tau)$. This can be discharged internally. For any argument $a$ of the desired conclusion, choose
\[
 \tau=\Rho{a}{a}{a}{a}.
\]
Reflexivity gives $a\preceq a$, so the restricted-row premise proves $\T(\tau)$. Instantiate the bootstrap with this $\tau$.

No global nonemptiness assumption is required: the first supplied argument supplies the seed. For an empty carrier the universal statement is vacuous. The private seeded presentation is a proof organization device, not an axiom of the public theorem.

\subsection{Compressing the finite bootstrap}
The baseline module has 117 numbered helper schemas: 58 bootstrap lemmas and 59 condensed-detachment lemmas. A search for alternative instances of existing schemas produced thirteen new two-premise modus-ponens steps. Replacing those steps and taking the acyclic dependency closure removes 33 numbered schemas. The result retains 84; 82 lie in the dependency closure of the main unrestricted-row result. The two additional schemas preserve the exported distribution theorem.

Each replacement is an explicit proof term. The generator selects substitutions, but Lean or Rocq checks the resulting formulas and modus-ponens applications. The archive contains the pinned input, replacement plan, generated proofs, and compiler receipts. No optimality claim is made for the remaining 84 schemas.

For example, two of the new dependency edges are
\[
 \code{cd75}\ \longleftarrow\ (\code{b52},\code{cd92}),\qquad
 \code{cd103}\ \longleftarrow\ (\code{cd104},\code{cd69}).
\]
The complete substitutions appear in the delivered source. The graph is topologically sorted before emission; numbered labels retain provenance rather than prescribing file order.

\subsection{A direct final argument replaces deduction}
\label{sec:direct}
The earlier final step introduced a local proof syntax, proved its soundness, proved a deduction theorem by induction, and discharged several hypotheses. That machinery proves more than this target requires.

The finite bootstrap supplies
\begin{align*}
 B'(x,y,z)&=(x\impop y)\impop((y\impop z)\impop(x\impop z)),\\
 C(x,y,z)&=(x\impop(y\impop z))\impop(y\impop(x\impop z)),\\
 K(x,y)&=x\impop(y\impop x),\\
 P(x,y)&=((x\impop y)\impop x)\impop x.
\end{align*}
From $B'$ and modus ponens, derived implications compose. From $B'$ and $C$, an established implication can be transported under a fixed antecedent:
\[
 \T(x\impop y)\quad\Longrightarrow\quad
 \T\bigl((z\impop x)\impop(z\impop y)\bigr).
\]
To obtain this, exchange the two antecedents of $B'(z,x,y)$ with $C$, then apply modus ponens with $x\impop y$.

Set
\[
 d=c\impop u,\quad f=d\impop a,\quad g=a\impop c,\quad q=d\impop c.
\]
Composition gives $\T(f\impop(g\impop q))$. Peirce gives $\T(q\impop c)$. Transporting Peirce under $g$ and composing gives
\[
 \T(f\impop(g\impop c)).
\]
Finally, $K(c,b)$ gives $\T(c\impop(b\impop c))$. Transport that implication under $g$ and compose again:
\[
 \T(f\impop(g\impop(b\impop c)))
   =\T(\Rho{a}{b}{c}{u}).
\]
This uses no general deduction theorem and no distribution schema in the final step. The two substantive hypotheses $f$ and $g$ are each used once. Distribution remains exported for compatibility.

\subsection{A syntactic corollary}
\begin{corollary}[Subterm restriction]
On the free language of implication trees, let $u\preceq a$ mean that $u$ is a subterm of $a$. Modus ponens and only those $\rho_8$ instances for which $u$ is a subterm of $a$ derive every unrestricted $\rho_8$ instance.
\end{corollary}
\begin{proof}
Subterm satisfies reflexivity and both operand-insertion rules. Apply Theorem~\ref{thm:rho}.
\end{proof}
The delivered Lean example also proves equality of the restricted and full derivability predicates. This is an alternative formulation of the propositional component, not yet a smaller TM implementation: recognizing subterms may cost more than the present numerical restriction.

\section{Normalized certificates with balanced lookup}
\label{sec:source}
Incoming work separately establishes two refinements. Trailing-zero normalization identifies paths with the same implicit infinite zero extension, reducing the source certificate from 2,240 entries to 1,426. Balanced storage replaces linear list indexing by lookup in a certified binary tree. The present contribution checks their composition.

\subsection{Exact refinement replaces a new semantic proof}
For a valid certificate tree $T$, the inherited theorem gives
\[
 \operatorname{getTree}(T,j)
 =\operatorname{getc}(\operatorname{flatten}(T),j).
\]
The new \code{BalancedNormalized.v} lifts this equality through branch and entry checks and traversal of the entries:
\[
 \operatorname{ncheckTree}(p,q,T)
 =\operatorname{ncheck}(p,q,\operatorname{flatten}(T)).
\]
The normalized checker's existing soundness theorem then supplies the equivalence. No additional induction on machine execution and no new restriction on register values is introduced.

The concrete theorem is
\[
 \forall R,\quad
 \operatorname{rm\_halts}(p215,([],R))
 \longleftrightarrow
 \operatorname{rm\_halts}(dagPerm,([],R)).
\]
The register file $R$ is arbitrary. Bounded segment extraction constructs a finite certificate; it does not bound the execution in this semantic theorem.

The tree constructor is untrusted. Separate kernel-checked statements establish exact flattening, validity, 1,426 entries and height 12. The complete concrete theorem was freshly compiled with Coq 8.18.0 and recursively checked by \code{coqchk}. The compatibility shim for inherited Rocq 9.1 source is documented and retained.

\subsection{Operation counts are not a speedup claim}
There is one entry branch and two outgoing branches for each of 1,425 non-halt entries, hence 2,851 lookups. Row 19 is the sole halt entry. Exact counts are

This is about 61.7 times less counted lookup work. It is not a corresponding runtime claim. The complete new concrete module took 15.741 seconds in this run, versus 9.238 seconds for the normalized list module. Keep this as a verified optional storage refinement, and measure the production build before preferring it. The normalized list certificate may be the simpler immediate integration choice. Saving one class of evaluator operations does not establish a faster full proof.

\section{A reusable halting bridge: benefit and cost}
An earlier FM215 proof-compression proposal supplies a generic positive-simulation theorem. We instantiate it at the current \code{KSim} definitions, replacing the specialized halting proof by one application and preserving the public theorem types.

The reusable principle relates source and target configurations at checkpoints. Each source step corresponds to a positive finite number of target steps, restoring the relation at the next checkpoint. A terminal source configuration leads to target halting after finitely many target steps. The reverse halting implication follows from deterministic execution and strictly positive simulated progress. Positivity prevents an infinite source run from being represented by finitely many target steps and cannot be dropped when replacing bespoke fuel arguments.

The focused integration changes \code{KSim.lean} from 355 lines and 16,074 bytes to 324 lines and 14,758 bytes. Public type and axiom reports compare identically. However, first use adds 99 inherited generic-theorem lines and 63 adapter lines. Total source grows by 131 lines in this isolated adoption.

This is useful when shared across machines or compiler stages. It is not the leading compression result for a one-machine endpoint. The packet labels it optional, attributes the generic theorem, and records its check separately.

\section{Searching for 214 states}
The new bounded search considers \emph{edge-specific elimination}. To remove a state $q$, different incoming transitions may choose different replacement write symbols, directions and target states. This is more flexible than identifying $q$ with one globally chosen survivor.

The checker constructs an inductive finite overapproximation of local tape contexts, starting from every inspected tape window at the initial control state and searches for positive bounded joins between old and replacement executions. New entering bits are unconstrained, so the invariant covers every initial tape, including the blank tape. Leaving the inspected window before an exact join is rejected. A replacement cannot reach the removed state or an unresolved patched row before joining. This defines a conservative local search family; lack of a certificate does not prove a replacement globally incorrect.

Seven 215-state tables were examined, with 214 removable labels apiece, giving 1,498 table/label pairs in each run:

\subsection{Why removing truth does not automatically remove a boot state}
The new calculus theorem does not by itself eliminate a physical instruction. In K215, zero also serves as a stack terminator and initial register value. Startup constructs an interpreter frame and enumeration counter; there is no separate physical instruction whose only purpose is to assert $\T(0)$.

In the current coding, the all-zero restricted-$\rho_8$ row already derives zero. The abstract result broadens permissible encodings, but a different encoding still needs source and tape invariants. Reinterpreting a startup zero without those invariants would not establish a smaller correct machine.

A useful next compiler target is to combine local engine shortcuts with decoder reallocation. A reachable state can have an unneeded symbol row available for a decoder role. The required saving may therefore involve both the engine schedule and decoder assignment. No theorem here guarantees that this will reach 214.

\section{A logical obstruction to one recovery strategy}
A separate source-reduction proposal restricts atomic vacuity to a cofinal set of indices. One tempting proof strategy is to recover all ordinary atomic-vacuity instances from the remaining logical rules. The following model blocks that logical-only strategy.

Let $e:\mathbb N\to\{0,1\}$ be a valuation. Interpret equality ordinarily, quantifiers by coordinate updates, and implication classically. Set
\[
 R(a,b)[e]\quad\Longleftrightarrow\quad e(0)=0\ \text{and}\ e(a)\ne e(b).
\]
The displayed arguments are $a,b$, but the relation also depends on coordinate zero.

The checked fragment includes ordinary equality/quantifier rows $r_1$--$r_7$, unrestricted propositional $r_8$, generalization, all equality-vacuity instances with the usual distinct-index conditions, the merged equality row, and relation-vacuity only when
\[
 a+b<c:\qquad R(a,b)\to\forall c\,R(a,b).
\]
All these instances are valid. The cofinal restriction makes $c$ different from $0,a,b$, preserving the hidden coordinate.

But
\[
 R(1,2)\to\forall0\,R(1,2)
\]
is false when $e(0)=e(1)=0$ and $e(2)=1$: changing coordinate zero to one destroys the relation. Soundness yields a formal nonderivability theorem. \code{HiddenCoordinate.lean} contains the complete definitions, row-by-row semantics, soundness induction and witness.

This is not a model of the set-theoretic seed bundles. It does not refute equiconsistency of the full restricted calculus or establish that a TM candidate is wrong. It blocks deriving all missing vacuity instances from this logical fragment alone. A successful proof may use the bundles, interpret the weakened calculus differently, or prove equiconsistency without recovering every ordinary first-order axiom.

\section{Integration and reproduction}
Recommended order:
\begin{enumerate}
\item Add the generic implication core and replace \code{DomRho8.lean} with its compatibility adapter. Update the generator too, so regeneration preserves the new proof.
\item Recheck \code{KCodeDom.cdom_iff_c222} and the two production K215 endpoint clients. The delivered focused client check is not a substitute for the production dependency-closure gate.
\item Instantiate the checked Rocq abstract core in the maintained numerical lane, then run its full endpoint build and assumption audit.
\item Adopt the incoming normalized source certificate. Treat balanced storage as optional and measure production cost.
\item Use the positive-simulation adapter where shared reuse justifies its additional source. Do not count the smaller \code{KSim} file alone as net compression.
\item For another endpoint, finish CM215's adapter closure or the M124/FM215 native-to-dense bridge, binding exact table hashes.
\end{enumerate}
The archive includes proof sources, deterministic generation data, patches, pinned minimal dependencies, receipts and logs, and search artifacts. It excludes compiled objects, toolchains, full repository copies and superseded whole incoming archives. The lightweight audit checks hashes, counts and bindings. Proof-assistant replays are separate explicit commands.

\subsection{Remaining limits}
No new complete 214-state machine is claimed. The generic theorem simplifies a calibration layer. The separate $C\mathrm{Four}$ adapter does prove equality of derivability with $C222$, but no source enumerator or tape machine for that presentation has been compiled here. The full production Lean and Rocq endpoint closures were not rebuilt after these edits. The preserved interfaces and focused checks make the replacement concrete, but the integration gate remains necessary.

The next mathematical question is which restricted implication presentations admit a cheaper enumerator. The next compiler question is whether the local engine shortcuts release enough symbol rows to remove a decoder state. This packet provides checked proof cores and concrete local constraints for those questions.
