# Phase21 Lean evidence

The [terminal result](result.json) and [independent actual readback](result-review.json)
pass for **226 providers**: 211 project modules and fifteen existing typed clients.
Eighteen providers compile fresh, 208 reuse exact phase20 source and dependency
bindings, and both endpoint audits compile fresh. This phase has one accepted run;
it introduces no additional old-source baseline or typed client.

One structural AX-expression proof now serves the native routine and the existing
AX words. Private word-to-expression bridges preserve the word checker and
evaluator interfaces. The native routine uses a literal expression of 180 semantic
macro operations, whose complete program shape is checked by the Lean kernel.
Its enumerator effect follows by direct symbolic simplification in the native AX
module. The root imports the same `ax_eval` theorem and no longer uses the
single-use `e1` bridge or generated per-node evaluation module. The native
`f1`/`l1`/`c1` contracts and the maintained word interfaces remain intact.

All 93 client reports, five `WFTheory` reports and ten endpoint audit reports retain
exact assumption profiles. All fresh providers and audits have zero warnings;
fifteen warning occurrences belong to reused providers. The two existing native
compatibility clients rebuild through source transitivity. Source-forward
providers and all nine 215 site batches retain their accepted bindings and are
reused here. This check does not cover other variants' full certificate stacks.

Eleven failed prefixes, through the eleventh candidate, remain explicit,
unaccepted history. They preserve the syntax failures and unsuccessful attempts
to normalize a computed native expression, including heartbeat failures. The sixth
candidate reaches the actual 120-second module timeout: its raw record reports
exit `-9` and `timed_out: true`. The accepted source replaces that decoder with
literal data and direct simplification. Each failed prefix preserves its source,
log, raw record, workspace prefix, plan, runner, launcher, freeze and terminal outer
receipt. None is counted as an accepted run or rewritten to resemble the final run.

The actual readback checks 195 adjacent provider raw records. Thirty-one inherited
providers retain the pinned accepted aggregate, workspace, object, dependency and
log boundary because their adjacent original raw record is absent. All eighteen
fresh providers and both endpoint audits have explicit exit-zero, non-timeout raw
receipts. Object hashes and dependency receipts are preserved; executable objects
are not shipped.

uses deterministic, content-addressed blobs. The eleven exact phase20 leaf files
remain an external byte boundary; their archive is not copied. Old canonical

bytes. Failed-prefix records retain their original statuses.
