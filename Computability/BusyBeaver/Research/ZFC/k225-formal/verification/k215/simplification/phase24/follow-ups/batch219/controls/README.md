## Why adoption does not currently shorten the proof

The current `KSim`, `KFastSites215`, `SiteCoverage`, `KHome` and `KHomeReady` total 878 lines / 38,613 B. The site facade and nine generated batches total 965 lines / 70,750 B. Much of that handwritten layer remains imported by the frame library; mixed coverage still needs literal fallback checks. These are separate scopes, so neither subtotal can be deducted from the new frame sources as a demonstrated saving. Existing generated proof bodies are short kernel decisions, even when their evaluation is expensive.

The projected expensive-body counts are 4,789 for the 35-template variant and 4,773 for the 20-template variant, against 6,176 current outcomes. All 4,751 leaves and 6,176 source-outcome bindings remain required. No packet supplies a measured whole-endpoint source, object or build-time reduction. Adding the endpoint port API alone costs 21 lines and does not prove the missing simulation.

## Best retained lead and exact next obligations

The useful integration seam is already isolated in the [phase23 dispatch-port sketch](https://github.com/VladimirReshetnikov/ProveIt/blob/3b5376377b0a282d225675550437f4aae8c5e7f8/Computability/BusyBeaver/Research/ZFC/k225-formal/verification/k215/simplification/phase23/leads/README.md): complete a caller's full semantic edge contract. It is future uncompiled work, not a new batch219 discovery or an adoption recommendation.

1. Elaborate `dispatch_to_framed_port` using current `KDecoderPrefix215.leaf_prefix` and `conc_leafPort`, then identify its state using `portState_of_path`. Retain the complete consumed word, final primitive bit, marker and `n + (64 - word.length)` gap.
2. Compose the prefix's possibly zero-step `Reach` with `all_caller_standard`'s positive residual. For break, derive the no-overflow bit from `sourceGuard` and `stripPath_append`; otherwise the target marker/gap may differ. Rewrite the exact current `conc_target`.
3. Rebase the narrow archived `RunContract`/`EdgeContract`/`SemanticCovered` consumer while preserving old wrappers, both decrement guards, halt handling and decoder totality. Current `KSim.Covered` requires a successful fuel-4000 Boolean replay; semantic reachability does not establish that result.
4. Kernel-check the phase22 ordered classifier and fresh mixed fallback batches. Caller validity alone does not prove exhaustiveness. Retain `consume P d`, including implicit zeros, and the exact literal exceptions `001/brk 1` and `11011/brk 1`. Reusing old `all_sites` is a compatibility pilot that retains the certificates.
5. Preserve the current 105 subtree boundaries and balanced table lookup if later adapting the owned site producer. `fast_eq` only transfers table equality. Charge every new library, classifier, caller and producer before claiming a net maintenance or timing benefit.

The frame theorem's empty-left guard is essential before each local step. Left normalization is not preserved when a nonblank frame is appended. Source stripping and carry must stop within the certified suffix. Positive Home return, complete tapes and natural-subtraction length premises are substantive parts of the contracts. The inspected statements preserve these boundaries.

The optional scheduler refinement is distinct: `T(N) - T(index) + pending` bounds successful abstract enumerator commands to a target boundary or a pre-halt state. The final halt transition is excluded. Shared cofinal scheduling and arbitrary-position completeness were already Source194 proposals; a future sharing patch must retain current `build_c222` and charge all adapters. The bound alone adds a result rather than removing the current proofs.
