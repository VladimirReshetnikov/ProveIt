# Attribution and scope

The inherited numeric calculus, commands, block compiler, and invariants are
retained from the pinned ProveIt sources listed in provenance.json. Their
upstream arithmetic-code ancestry is recorded in the original file headers
and THIRD_PARTY.upstream.md, retained verbatim. LICENSE.ProveIt is the pinned
repository license; it does not override the upstream scope qualification.

This packet contributes the candidate ranking theorem, arbitrary-initial-state
completeness refactor, the new general invariant-conditioned equivalence,
the local-opacity application to L1_SoundPerm, patches, portable build driver
and evidence. It does not claim novelty for Cantor coding, compilation from
Hilbert derivations, generic ranking functions, or the pre-existing K215 machine.

Only the Stdlib-to-Coq namespace spelling is changed in Coq 8.18 build copies.
No axiom, unsafe flag, admission, or native trusted computation is introduced.
