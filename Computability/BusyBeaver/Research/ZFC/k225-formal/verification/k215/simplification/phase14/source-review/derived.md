The shared Rows structure has exactly nine fields: generalization, rho2, rho4, rho6, rho1, rho7, rho5, rho3 and membership vacuity. It has no equality-vacuity field. Its two instances are direct existing constructor assignments. The propositional proofs use only the explicit classical implication structure. Quantifier monotonicity additionally uses Rows; ex_elim_of_vac keeps its vacuity hypothesis. vac_imp combines the two input vacuity proofs using negated vacuity, quantifier monotonicity and the existing propositional case split. vac_all first generalizes the supplied implication and then commutes the quantifiers. Neither helper manufactures a new atomic vacuity premise.

Atomic transport is also correctly generalized. Forward transport changes each argument of an arbitrary binary atom using the supplied left/right congruence proofs. Reverse transport takes equality symmetry explicitly. In the unequal-coordinate cases the argument is unchanged and identity is discharged propositionally; in equal-coordinate cases the supplied congruence premise applies. No inference of general equality symmetry or equality vacuity from Rows is hidden here.
