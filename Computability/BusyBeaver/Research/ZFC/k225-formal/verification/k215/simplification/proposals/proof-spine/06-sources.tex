\textbf{Artifact map.} The report sources and PDF are at the archive root. \code{review/} contains the pinned-source and integration review, current-source snapshots, historical ledger and read-only verifier. \code{lean/} contains the generic-spine patch, candidate files, source-movement audit and reproducible builder. \code{rocq/} contains the new finite diagnostic, pinned runtime inputs and uncompiled fork candidates for both proof assistants. \code{audit/} contains separately written static and finite replays and their source reviews. The root \code{verify.py} and \code{MANIFEST.sha256} bind and check the complete package.

Original repository source notices are retained. The package does not contain old proposal archives, large build logs, external delivery records, compiled theorem objects, private notes or page-render images.
