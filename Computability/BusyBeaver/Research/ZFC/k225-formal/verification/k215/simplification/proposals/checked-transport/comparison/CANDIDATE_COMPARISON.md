## Recommendation

Keep primary K215 as the main target for reducing the total correctness proof. Its literal table already has compiled Lean and Rocq endpoints. Several alternative candidates have a smaller **incremental** proof because they can inherit that endpoint by a local machine-to-machine theorem; this is different from having a shorter proof of the whole ZFC calibration from first principles.

For a second endpoint, there are two practical choices. The M124/FM215/M125 marker family has the smallest inspected local invariant, and its incoming Rocq package already supplies a generic finite checker and three compiled all-tape instances. CM215 has less remaining Lean integration work because its actual Core/dense bridge is recorded as compiled. The final CM215 ZFC adapter and complete dependency closure were not freshly compiled in that delivery. The six-block context215 variant is a useful independent transport target: all of its machine-specific facts fit into 28 literal block transitions and nine incoming histories, and its full machine proof can reuse K215's startup and numerical calibration.

## A family theorem and an exact clock corollary

For each subset S of the five changed rows, let B_S apply precisely those patches to A. The previously supplied block pairs remain valid in every B_S that includes their entry row: every strict block interior avoids **all five** changed rows. Entries whose patches are omitted take the common single A/B_S transition.

**Theorem.** For every subset S, integer head position h and arbitrary two-sided Boolean tape t,

```
Halts(A, (0,h,t)) <-> Halts(B_S, (0,h,t)).
```

At every synchronized boundary, let T and T_S be the elapsed times. If N is the number of completed delayed blocks at row13/1 with predecessor symbol0 and the state13 patch is selected, then

```
T_S = T + 2*N,                 T <= T_S <= 2*T.
```

If the state13 patch is omitted, synchronized times are identical. If either execution halts, the halt is a synchronized boundary, so the same exact clock equation and bounds hold for the two halting times.

**Proof.** Begin at the common initial full configuration. At a synchronized configuration with unchanged active row, take its common one-step transition. At a patched row, the old execution has the requisite predecessor history. Select the corresponding block from the finite table above. The two positive blocks reach the same full configuration, and neither strict interior contains halt. This recursively defines common boundaries. Every old increment is at least1 and every new increment is at least1, so both boundary times grow without bound unless a halt is reached. A halt in either execution cannot occur strictly inside one of the chosen blocks; it occurs at their common endpoint and therefore occurs in the other execution. Summing the block durations gives the clock equation. Each delayed block consumes two old transitions, so `2*N <= T`; this proves the upper bound. No blank-start, register-value, finite-support, or consistency assumption is used.

The independent script `audit_context_family.py` recomputes the literal five-row delta, finite whole-window blocks, old predecessor histories, early-entry exclusion, and compatibility of all 32 subsets. It also verifies that every subset retains 215 graph-reachable working states, that the 32 rooted read-labelled write/move graphs are pairwise nonisomorphic, and that no pair is identified by global tape reflection. The audit passed: nine histories, eight compatible histories, 28 literal block transitions, and 32 distinct rooted graphs.

This family theorem is a compositional corollary of already known local rewrites. It is not a new 214-state machine or a new logical architecture, and the independent Python audit is not itself a proof-assistant theorem. Its practical value is to let a formal attachment handle a Boolean patch mask once and to isolate the sole time-changing block. The 16 masks omitting state13 need only the four immediate guards and equal-duration blocks, which offers a smaller initial formalization target.
