# Two shared-node commutations, checked without new axioms

This packet closes the local semantic part of the earlier two-template CFG
proposal. It does **not** assert that the K215 source certificate can already be
deleted.

The current `DagPerm.v` is copied byte-for-byte from ProveIt commit
`cbf94cb552a3b49509e0eee80e7455d4eb5974c6`. The new program `dagPermComm`
changes exactly node 188 from `(Inc 6, Inc 7)` to `(Inc 7, Inc 6)` and node 190
from `(Inc 6, Inc 1)` to `(Inc 1, Inc 6)`. Its root, node bound, and every other
node body are unchanged.

## Checked results

`dagPerm_comm_iter_iff` proves, for **every** initial natural-valued register
function `R`,

```text
iter_halts dagPerm R <-> iter_halts dagPermComm R.
```

`dagPerm_comm_runs` and `comm_dagPerm_runs` preserve any structured execution
starting at any edge. They preserve normal, break, continue, and halt exits,
and relate output register files pointwise.

The generic `run_transfer_ext` and `iter_iff_ext` support replacement of any
collection of shared nodes by such local contracts. Induction is over finite
execution derivations, including the loop-restart constructor. No assumption
about DAG acyclicity or program termination is used by this transport theorem.

The fresh component build compiled four sources with Coq 8.18.0 / OCaml 4.14.1.
Six selected `Print Assumptions` commands report `Closed under the global
context`. Recursive `coqchk` of `Refactor.TwoNodeCommutation` passed.
`evidence/result.json` and the raw logs identify exact source and object hashes.
The maintained production lane uses Rocq 9.1.0; that lane and the full ZFC
endpoint were not rebuilt here.

## Why the register relation matters

Registers in the actual RM semantics have type `nat -> nat`. A direct proof
that two reordered functional updates have equal output functions would
normally appeal to functional extensionality after proving equality at each
register. The existing `LocalProgram.Closed` interface expects exactly equal
result functions. This packet instead changes the *transport interface* to
pointwise related inputs and outputs. The primitive rules preserve that
relation, and both node substitutions satisfy it constructively. It does not
introduce functional extensionality or claim an impossibility theorem about
every potential intensional proof of the old equality.

## Remaining bridge

The earlier finite CFG investigation found 256 expanded commutation occurrences
generated by these two shared nodes, and found equality of the ordered primitive
CFGs after the changes. That investigation remains structural/Python evidence.
This packet supplies the two-node semantic theorem, not a source-to-CFG compiler
soundness theorem or a kernel check of the full flattened CFG equality.

To replace `Source215.p215_dagPerm` without its 1,426-row normalized certificate,
prove and instantiate the separate equivalence between `p215` path semantics
and `dagPermComm` structured iteration. This requires sound elimination of
control-only chains, exact entry and successor correspondence, preservation of
halt versus stuck configurations, and exclusion or explicit treatment of
control-only cycles. Do not identify equality of diagnostic CFG JSON files
with that missing semantic theorem.

## Reproduction

With `coqc` and `coqchk` on `PATH`:

```sh
python3 build.py --out /tmp/k215-two-node-fresh
```

For an unpacked Ubuntu Coq installation with an `ocamlfind.conf` pointing at
its own `usr/lib/ocaml`, add `--toolchain /absolute/path/to/toolchain`.
The output directory must be fresh. Sources, logs, object identities, compiler
identities, assumptions reports and recursive-check result are preserved.
