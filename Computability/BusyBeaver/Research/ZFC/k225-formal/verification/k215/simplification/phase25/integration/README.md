# Phase25 source and verification records

[Source spec](source-spec.json), [metrics](metrics.json) and [proof diff record](source.diff.json)
bind the five proof-only changes. The [initial](source-plan-peer.json) and
[final source-plan peers](source-plan-final-peer.json) are source metadata reviews;
subsequent kernel results establish elaboration. Preparation-time pending labels
remain chronological records.

The [runtime source peer](runtime-source-peer.json), [capture source peer](capture-source-peer.json)
and [publication source peer](publication-tools-peer.json) preceded their respective
executions. [Actual readback](actual-review.json) checks the complete accepted run.
[Capture review](capture-review.json) reconstructs every archive member, logical
entry and source alias. The publication readback checks copied bytes and local links.

The [profile reduction](calculus-profiles/reduction.json) preserves the original
strict comparison failure while checking its one justified axiom reduction.
Failed and passed focused histories, unexecuted calculus drafts and separate
benchmark histories are retained as inert files in the content-addressed archive.
They are never substituted for the accepted phase24 reuse basis.

[Upstream coordination](upstream-coordination.json) confirms no new origin/main
commits or source overlap. No submitted checker, proof or generator was executed.

Diff records preserve the original UTF-8 text and its hash inside JSON strings.
The exact raw patches remain in the archive; this representation avoids physical
whitespace-only context lines in published files.
