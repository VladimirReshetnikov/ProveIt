## Mathematical boundary

`TarskiDerived.Rows T` packages the nine existing generalization/quantifier/equality-congruence/membership-vacuity constructors. It deliberately has no equality-vacuity field. Both concrete instances are supplied directly by their existing calculus constructors. Propositional rules are generalized to an arbitrary predicate `T` with the existing `Kalmar.Classical` structure; quantifier rules additionally require `Rows T`. This is an explicit assumption interface with concrete instances, not an axiom declaration or an added inference rule.

The shared `vac_imp` and `vac_all` are the former implication and quantifier cases of the two vacuity inductions. The first uses classical case splitting, negated vacuity and quantifier monotonicity; the second uses generalization and the existing quantifier-commutation row. General equality vacuity remains confined to the ordinary `Thm` induction. `ThmK.vac_of_not_occurs` still requires `EqFree`; its equality case still eliminates an impossible premise. Its reflexivity proof still uses the exact helper binder `Code254.wel x x`, and its Leibniz, specialization and alpha-renaming theorems retain the old `QF`, `EqFree` and freshness premises. No hidden general-vacuity or free-binder strengthening was found.

The forward atomic substitution proof is parameterized by the theorem predicate. The reverse direction explicitly receives equality symmetry (`hs`), allowing each calculus to supply its own established symmetry theorem. This is the correct distinction: generic `Rows` does not silently recover unrestricted equality vacuity. The object-level existential monotonicity proof is similarly shared. `KEind222` only changes name resolution and passes its existing `classical` proof to the shared rules. Every declaration header in that file is unchanged, including the interpretation and `c222_complete` endpoints. All retained `KThmK` headers are unchanged; its calculus and syntactic-class definitions are unchanged.
