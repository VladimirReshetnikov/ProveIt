\section{Prove one return to dispatch scan instead of replaying it}
The new owned replay finds a common phase consuming most symbolic site-check steps. It starts in state 2, scans left to the outer blank region, then returns to state 84 immediately to the right of the leftmost marker. This is a reusable whole-tape theorem, not a new machine.

\begin{proposition}[Scanner contract]
Let the current head be at $h$ in state 2. Read leftwards a nonempty finite word $W$ occupying $h,h-1,\ldots,h-|W|+1$. Suppose its last bit is 1, no eight consecutive bits of $W$ are 0, and every cell strictly to its left is 0. The tape to its right is arbitrary. Then the literal K215 table reaches state 84 at head position
\[
 h-|W|+2
\]
in exactly $|W|+18$ concrete steps, with the entire tape unchanged.
\end{proposition}

The proof reads only 18 table rows. In the chain
\[
 2,3,5,9,15,23,34,50,
\]
a 1 resets the leftward scan to state 2; a 0 advances the chain, and the eighth consecutive 0 enters state 75. The guard prevents this before the blank exterior. State 75 scans right across nine blank cells, then crosses the marker to state 84. Every traversed bit is rewritten unchanged. This yields $|W|+8+10$ steps and the displayed head location. It also supplies strictly positive progress for composition.

\textbf{Symbolic interface.} In a zipper whose left list is read from the head outwards, write that list as $W$ followed by blank padding, and its arbitrary right continuation as $R$. The macro result has marker 1 as its singleton left list and
\[
 \operatorname{reverse}(\operatorname{init}(W))\mathbin{+\!+}R
\]
as its right list, with the head on the right side. Absolute-coordinate translation is part of the contract. Opaque protected tails are carried as a frame, not inspected or erased.

The executable guard handles affine repeated runs conservatively. Unbounded zero runs inside $W$ are rejected. A true run which can vanish at parameter zero must not be treated as a guaranteed separator: it may join two zero streaks. Two genuine site cases fail this sufficient guard and correctly fall back to ordinary steps. A sufficient guard need not be complete.

\section{Factor decoder roles without erasing their guards}
An incoming proposal covers 4,750 expanded internal source occurrences by 234 decoder roles. Those roles distinguish the source node, physical state and a short preceding-bit guard. Some duplicate the same node/state with different allowed guards. Grouping by \emph{node and physical state}, while retaining the union of guards, gives 180 roles. This is a proof-certificate quotient, not a merger of TM states.

The independent checker binds the exact expanded source tree and literal machine rows. It checks 287 internal bindings, 73 primitive bindings and 371 guarded local cases. There are 281 distinct local trace contracts, a count already present in the incoming packet: 252 need no preceding-bit read, 25 read one bit, and four read two. The root is fixed to the source root, state 84 and guard 1. Every internal transition preserves its local tape and carries an allowed guard to its child; primitive exits retain their literal action and state.

The natural formal structure is a local contract library indexed by state, current bit and the actually required suffix, followed by a small structural composition theorem. Keep the source-node binding separate from that shared physical contract. A suffix is an invariant hypothesis, not decorative certificate data: merging states or dropping suffix checks would admit different control behavior. Negative controls reject a changed root state, changed root guard, malformed index and missing role. The verbose factored JSON is larger, so no storage saving is claimed.

A primitive binding proves only its first transition, not the full primitive/return contract. That missing theorem must quantify the whole path and require membership in the role graph's accepted prefix language, in addition to the original gap, branch and register conditions. The same two-bit suffix alone is not enough: a primitive can revisit dispatch with modified path data. Thus 180 guarded interfaces do not replace the 6,176 complete runtime obligations.

This is complementary to the scanner macro. The scanner compresses repeated long physical returns; the guarded decoder library shares the small local dispatch proofs. Begin with the scanner, whose ordinary proof is particularly small. Only then measure whether the 180-role quotient improves the remaining checker enough to justify its additional data structure. The guarded-composition theorem and its connection to every site endpoint are still kernel obligations.

\section{Derive well formedness witnesses from the DAG}
The checked source lanes still provide three lists $H,B,C$ of length 487 and verify inequalities against them. These 1,461 supplied numbers describe structure already present in the graph. A memoized all-node fold can compute the escape bounds and obtain the height witness from completion order.

For an edge $e$, let $B_e,C_e$ be its escaping break/continue levels. A decrement has $(B_e,C_e)=(1,0)$; break $k$ has $(k,0)$; continue $k$ has $(0,k)$; increment and halt have $(0,0)$. A node edge reads its previously completed child's values. If node $n$ has car edge $a$ and cdr edge $b$, define
\begin{align*}
 B_n&=\max(B_a\mathbin{\dot-}1,B_b),\\
 C_n&=\max(C_a,C_b\mathbin{\dot-}1),
\end{align*}
where $x\mathbin{\dot-}1=\max(x-1,0)$ on naturals. These are the least values satisfying the existing four escape inequalities. The current generator already computes these recurrences in Python; the new proposal moves that construction under one proved evaluator. The asymmetry matters: car consumes one break level; cdr consumes one continue level. Replacing both by an undirected maximum is wrong.

Use unseen/active/complete marks to reject cycles and memoize shared nodes. Let $\rho(n)$ be the positive completion index of node $n$. Each node child completes first, hence
\[
 \rho(\mathrm{child})<\rho(n),\qquad 1\leq\rho(n)\leq N.
\]
With primitive height zero, $H(n):=\rho(n)$ is already a witness for the existing \file{RMEquiv.WF.height}; the root bound $H(r)\leq N+1$ follows. There is no need to calculate or transmit a minimal-height array merely to prove acyclicity and sufficient decoder fuel.

\textbf{Acceptance conditions must stay exact.} Require $r<N$, every node reference below $N$, positive break/continue levels, completion of \emph{every} bounded node, and $B_r=C_r=0$. The current \file{WF} quantifies over every bounded node, not only reachable nodes. The target graph has 261 reachable nodes among 487; a cycle in one of the other 226 must still be rejected. Register-index bounds are not part of this particular \file{WF} and must not be silently added.

For the literal 487-node graph, the computed canonical arrays exactly match all supplied $H,B,C$ entries; the root is $(H,B,C)=(178,0,0)$. Completion rank also satisfies the original inequalities, with root rank 261. The iterative implementation uses 1,859 jobs against its $4N=1,948$ structural work bound. An independent repeated-readiness implementation agrees on all 14,741 enumerated one- and two-node graphs, and every accepted graph satisfies the original inequalities. Eleven adversarial controls include unreachable cycles and escaping break/continue levels.

The intended simplification removes \emph{supplied} summaries and their redundant consistency checks, not all witness computation. The normalized packet has 16 well-formedness checks within one program module; only the \file{k215-simplification-2/plain_source} lane puts them in 16 separate files. Do not report sixteen file deletions for both lanes.

\textbf{Kernel gate.} Use a total, fuel-bounded evaluator which rejects on exhaustion. Prove completed-table invariants and soundness for arbitrary fuel, retaining a final scalar check $H(r)\leq N+1$; a formal completeness proof or $4N$ counting theorem is not needed for this first version. Derive \file{WF} from acceptance and evaluate the literal instance. One generic soundness theorem can replace the hand-supplied arrays while preserving the existing structured/path-semantics theorem. If kernel reduction of the fold is expensive, keep transparent chunked execution or checked intermediate states; an elegant algorithm is not automatically the cheapest kernel computation.

\section{Narrow the lower calibration to the named seeds it uses}
The earlier semantic round-trip proposal is still useful, but it unnecessarily enters the numerical decoder to recover a seed already expressed in named syntax. Two smaller changes expose a cleaner lower-bound interface.

\subsection{Fresh universal padding reuses an existing theorem}
The repository already proves \file{Code254GIC.occurs_lt_enc}, including binder occurrences, and \file{not_free_enc}. No new freshness induction is required. For any named formula $\psi$, set
\[
 \operatorname{pad}(\psi):=\forall_{\enc(\psi)}\psi.
\]
Its binder is not free in $\psi$. Therefore, for every membership relation and displayed valuation $e$,
\[
 \Sat(\mathrm{mem},e,\operatorname{pad}(\psi))
 \iff \Sat(\mathrm{mem},e,\psi).
\]
Forward elimination uses the explicit witness $e(\enc\psi)$; reverse introduction uses freshness and valuation extensionality. The proof needs neither irreflexivity nor equality-freeness and does not infer an inhabitant of an empty domain. Padding is constructive, preserves equality-freeness definitionally, and its encoding exceeds 1. It adds one formula constructor rather than the four added by literal double negation; this is a local syntax saving, not a measured build improvement.

Define a sparse named axiom family
\[
 \operatorname{SeedAx}(f)\iff\exists\psi,\
 \operatorname{EqFree}(\psi)\land
 f=\operatorname{bundleNF}(0,1,\enc(\operatorname{pad}\psi),
                              \operatorname{pad}\psi).
\]
Every such formula is derivable by the existing bundle rule, so it can feed the unchanged \file{KEind222.c222_complete}. The lower endpoint need not use the theory of \emph{all} derivable formulas to obtain the seeds it actually consumes. This narrows a model interface, not the machine's axiom enumerator: the inherited logical-completeness infrastructure and AX heads are not thereby removable. The supplied first-stage draft implements this adapter, but still uses two semantic encode/decode equivalences. It is uncompiled.

\subsection{The next named bundle theorem removes those two decoder uses}
Let
\[
 R(x,y):=\Sat(\mathrm{mem},e[a\mapsto x][b\mapsto y],m).
\]
The precise remaining theorem is
\begin{align*}
 &a\neq b,\quad k\neq a,\quad k\neq b,\quad k\notin\mathrm{Free}(m)\\[-2pt]
 &\qquad\Longrightarrow\quad
 \Sat(\mathrm{mem},e,\operatorname{bundleNF}(a,b,k,m))
 \iff \operatorname{SeedProp}(\mathrm{mem},R,e(a)).
\end{align*}
Prove it by named request semantics, named closure semantics and freshness-based environment transport. It needs no irreflexivity or equality-free premise for \emph{semantic normalization}; equality-freeness remains necessary separately for the code-calculus derivability bridge. Its existential normalization is classical, unlike padding itself.

At roles $a=0,b=1$, use $m=\operatorname{pad}\psi$ and $k=\enc m$. Existing freshness and $1<k$ discharge the side conditions. Then \file{seedProp_congr} and padding give the required seed directly. This would remove the raw decoder from this lower semantic path, not automatically from module imports or from the entire proof.

\textbf{Do not overgeneralize the interface.} The upper soundness direction still covers \emph{every natural code}, including junk codes and coincident ordinary roles. In particular, code 1 decodes to the self-membership atom rather than genuine bottom, so its semantic falsity still uses irreflexivity. Preserve raw \file{bundle_of_seed}, the equality interpretation, the indiscernibility quotient and all exceptional-role cases. This changes neither the consistency strength nor the literal machine, and no proof-size or runtime improvement is yet measured.

\section{Allow finite terminal cleanup in the transport API}
The new positive-stuttering source also reveals a small genuine weakening of its hypotheses. Let $A,B$ be deterministic \emph{partial} transition systems, with successor functions into an option type. A terminal configuration has no successor. Let $R$ relate configurations and assume:
\begin{enumerate}
\item If $R(a,b)$ and $a\to a'$, there are $k>0,b'$ with a successful target run $b\to^k b'$ and $R(a',b')$.
\item If $R(a,b)$ and $a$ is terminal, then $b$ eventually halts.
\end{enumerate}
Then $R(a,b)$ implies $\Halts(a)\leftrightarrow\Halts(b)$. Immediate terminal agreement is stronger than necessary.

Preservation follows by induction on a terminating source run, using the second premise only in its base case. Reflection uses the first premise alone: strongly induct on a terminating target run length. If the source is nonterminal, its successful positive target block is a prefix of that deterministic terminating run. It cannot pass a terminal configuration. Removing it strictly decreases the remaining length.

The existing strict interface implies the weaker terminal-drain premise, so it can remain as a compatibility constructor. The inspected reflection proof does not use its terminal field at all. The derivative draft changes that field and the preservation base case; it does not overwrite production code.

This permits a terminal source to correspond to a target that performs finite cleanup before halting. The finite audit exhausts 36,864 small systems/relations; 7,273 satisfy both new hypotheses, including 1,506 that do not satisfy strict terminal agreement. Zero-length progress and missing terminal drain have explicit counterexamples. \emph{Do not transfer this proof unchanged to a total step function with an absorbing halt}: positive absorbing steps would destroy the reflection argument. This is an API simplification, not a new CM215 invariant or state reduction.

\section{Ranked integration plan and acceptance gates}
\begin{enumerate}
\item \textbf{Build on phase five rather than repeat it.} Ordinary 2,240-row Lean checking is now production. Adapt the separately checked 1,426-row quotient to the current decoder-parametric checker and 512-step decoder; preserve the public theorem and rebuild endpoint clients and axiom reports. In parallel integrate the compact single-certificate Rocq route. Do not confuse either route with packet intake.
\item \textbf{Prove the scanner macro and refine the site checker.} Its 18-row ordinary argument and 6,176-case replay give the clearest new cost target. Preserve full tape, symbolic guards, positive progress and fallback. Measure clean and incremental checking time and peak memory.
\item \textbf{Replace supplied DAG summaries with a sound fold.} Reuse \file{RMEquiv.WF}; cover all bounded nodes and both asymmetric escape rules. Compare one fold with transparent batched checking before removing old witnesses.
\item \textbf{Build the named lower-calibration interface.} Compile padding and sparse seeds, then prove the named bundle theorem and remove only the now-unused lower decoder path. Keep raw upper soundness and the exact endpoint statement.
\item \textbf{Add the guarded decoder library and terminal-drain API when useful.} Both have precise contracts and finite regression tests, but their integration benefit should be demonstrated rather than assumed.
\end{enumerate}
For every accepted change, retain exact table hashes, bind source receipts to the rebuilt source, reject placeholder/native-evaluator assumptions, and test the final public machine-to-consistency theorem. No 214-state construction is established by this report.
