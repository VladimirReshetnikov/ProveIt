# Phase20 Lean evidence

The [terminal result](result.json) and [independent actual readback](result-review.json)
pass for **227 providers**: 212 project modules and fifteen unchanged typed clients.
Fourteen providers compile fresh, 213 reuse exact phase19 source and dependency
bindings, and both endpoint audits compile fresh. This phase has one accepted run;
it introduces no additional old-source baseline or typed client.

The selected closure checks the shared AX-word proof, the shortened 222/219/Dom/Perm
AX interfaces, the shared 219 program contracts and their maintained root callers.
All 93 client reports, five `WFTheory` reports and ten endpoint audit reports retain
exact assumption profiles. All fresh providers and audits have zero warnings;
sixteen warning occurrences belong to reused providers. Source-forward providers
and all nine 215 site batches keep their accepted bindings and are reused here.
This check does not cover other variants' full certificate stacks.

Three rejected prefixes remain explicit, unaccepted history. The first failed on
the multiline literal-read record syntax; the second failed while elaborating
implicit register-file arguments in transfer callbacks. The third compiler returned
PASS/0 for a proof with an unused `wa` simp argument, and the outer warning policy
returned FAIL/1 without an accepted result. The final source repairs remove those
issues without relaxing the proof or warning policy. Each rejected prefix preserves
its source, log, raw record, workspace prefix, plan, runner, launcher, freeze
and terminal outer receipt. No rejected prefix is counted as an accepted run.

The actual readback checks 196 adjacent provider raw records. Thirty-one inherited
providers retain the pinned accepted aggregate, workspace, object, dependency and
log boundary because their adjacent original raw record is absent. All fourteen
fresh providers and both endpoint audits have explicit exit-zero, non-timeout raw
receipts. Object hashes and dependency receipts are preserved; executable objects
are not shipped.

The [archive](evidence.tar.gz), [index](index.json) and [capture receipt](capture.json)
bind the current checked workspace, raw receipts, source reviews, exact before/after
snapshots and the three retired producer source files. The archive uses deterministic,
content-addressed blobs. Its receipt records the actual member counts and SHA-256.
The eleven exact phase19 core files remain external; their archive is not copied.
Old canonical source paths are historical labels, and the indexed snapshot paths
supply their bytes. Failed-prefix records retain their original statuses.

The [plan](check-plan.json), [runner](check.py), [auditor](review_actual.py) and
[capture map](capture-config.json) retain the exact absolute-path evidence bindings.
The [capture helper](capture.py) treats every script and proof as inert data.
Portable reproduction uses
the [maintained Lean driver](../../../lean/README.md) with a new output directory.

The proof cleanup removes 3,059 Lean lines and retires 704 producer lines. The primary
endpoint closure grows from 178 modules / 1,765,109 source bytes to 179 modules /
