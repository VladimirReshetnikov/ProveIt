# BusyBeaver

- [Lean](Lean/) contains the machine model, score and time certificates, and
  shared verification code.
- [Rocq/Coq](Coq/) contains independent formal developments and certificate checks.
- [PA consistency machines](Research/PA/README.md) tracks literal tables, the
  object-theory equivalences, and their replay commands.
- [ZFC consistency machines](Research/ZFC/README.md) tracks machine designs,
  exact verification, and the strength of internal consistency results.

The [iPRA unification plan](../../Logic/PrimitiveRecursiveArithmetic/UNIFICATION-PLAN.md)
describes arithmetic reuse and the verification steps for migrating machine
proofs at their published interfaces.
