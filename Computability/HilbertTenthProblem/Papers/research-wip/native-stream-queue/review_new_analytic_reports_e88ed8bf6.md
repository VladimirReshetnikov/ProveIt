## A concrete computable-real boundary

The spectral manuscript's literal Fourier rule is

```
T_a e_m = sum_(|j|<=d, b divides m+j) a_j e_((m+j)/b),
coefficient_k(T_a f) = sum_j a_j coefficient_(bk-j)(f).
```

This is linear weighted frequency routing; there is no digit product or
Boolean branch in that rule. Its finite core has radius
`K=floor(d/(b-1))` and matrix `A[k,m]=a_(bk-m)`. Infinite function inputs
still have infinitely many Fourier coordinates. These observations do not
constitute a general nonuniversality theorem about all uses of the operator.

The Fabius/spectral reviewer gives the following new representation-sensitive
obstruction. For `b=2` and

```
a_theta(x)=1-theta*cos(2*pi*x),      1/2 <= theta <= 3/4,
```

all masks satisfy the nonnegative Markov hypotheses. The core is
three-dimensional with eigenvalues `1,-theta/2,-theta/2`. At regularity
`s=2`, the critical circle has radius `1/4`. For a machine index e, set
`theta_e=1/2+2^(-t-2)` if e first halts at time t, and `theta_e=1/2`
otherwise. Bounded simulation gives uniform fast Cauchy names for every
coefficient. The double eigenvalue lies on that circle exactly when e never
halts; otherwise its modulus is greater than `1/4`.

Consequently exact boundary classification on all these coefficient-program
indices is not decidable and has no uniform finite ordinary existential
Diophantine representation for the boundary-equality predicate: such
solvability would enumerate nonhalting. Root independently checked the
matrix eigenvalues, the coefficient approximation and that direction of the
reduction. This is a review-side consequence, not a defect in the source's
spectral theorem. It does not apply to explicit rational/algebraic input
representations, does not ban finite truncation calculations, and gives no
numerical gate lower bound for a restricted compiler.
