## Arithmetic relevance and retained boundaries

The useful lesson for compiler work is an interface obligation: replacing a family of individually named maps by one uniform evaluator requires a proof about the evaluator and its input language. It is not automatically a harmless abbreviation. Here the evaluator is an externally named class operation, and the finitely generated case uses an unrestricted pure function selecting representative words.
