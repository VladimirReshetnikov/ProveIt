## 3. The input language recovers the missing initial bound

A positive integer has bounded zero runs if its ordinary binary expansion
has no consecutive block of more than beta zeros, including at the end.
The actual valid input has the form

    V0=[E(w)], e(b)=1 0^beta 1, e(c)=1,
    E(w)=e(w without its final b) 1 0^beta.

Here brackets add the leading sentinel1. The valid nonempty word w ends
in b. Every zero run of V0 has length exactly beta. Write its binary word
as P0 1 0^beta, where P0 is nonempty and ends in1, including w=b.
Subtracting2 changes this suffix to

    V0-2 = binary(P0 0 1^(beta-1) 0).

For beta>=2 it is positive and every zero run still has length at most
beta: the new internal and trailing runs have length1, and earlier runs
are unchanged. Thus both possible initial integers

    I=V0 or V0-2 = W+epsilon_L

have the required bounded-zero-run property. This uses the actual word
recipe supplied by the restored low recoder, independently of the high
history's chronology.

Use the following elementary lemma. Let D=2^d, b=2^(d+k), k>beta, and
let I>0 have no zero run longer than beta. If

    I modulo b < D,

then I<b. Indeed, if I>=b, its nonzero high block and its residue below
2^d leave every binary position d,...,d+k-1 zero. That is a run of at
least k zeros inside the canonical expansion, or part of a trailing run
if the residue is zero. Both cases contradict the hypothesis.

The paid lower unit is

    epsilon_L=H_V+P*V_f-b*N_V-W in{-1,+1}.

Reducing it modulo b gives v_0=I modulo b. The typed range already gives
0<=v_0<D, while(1) supplies k>=beta+3. The lemma therefore proves

    I=v_0<D<b.                                       (4)

No chronological transition or initial-height inequality was assumed to
obtain(4). The word-language hypothesis is essential: I=b+1 has residue1
below any D>1 but contains a long zero run and lies outside this input
language.

With the upper initial digit1 and(4), both transports meet the elementary
terminal-bound lemma of255. The update words and histories lie below P,
so the terminal values lie below b and every chronological digit equality
holds. If epsilon_L=-1, the initial word V0-2 has the forbidden internal
101, which the lower appends cannot erase; upper tile words with their
terminal suffix have zero runs exactly beta. The existing four-tile
sentinel argument therefore forces epsilon_L=+1. The resulting exact
history starts from the genuine V0 and proves acceptance by the unchanged
U9, loader, physical counter and valid program recipe.
