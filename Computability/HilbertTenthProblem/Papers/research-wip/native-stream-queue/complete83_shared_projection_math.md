# Shared positive projection: exact offset and a diagnostic extra-zero construction

This bounded note proves an exact necessary form for every positive zero of the proposed shared-projection83 source on a valid inherited compiler slice. It also constructs a full positive zero with a nonzero offset for explicit **diagnostic scalar numerals**, not a certified compiler program. The candidate's ordinary-input soundness on valid program slices remains unresolved. There is no new universal-operation bound or rejected-input counterexample here.

The source replaces `rho` by positive `shared_projection=U` and computes

```
D = a*c + X + U + sigma*H,
mu = a*kappa + W + U,
H = 4*a+3.
```

All other definitions remain those of complete84, notably `X=w*q`, `Y=s*q^3`, `a=Y(X+1)`, `c=kY+eta`, `k=eta+zeta`, and the normalized auxiliary block. Root's fresh emitted array saves one multiplication, with 83=46M+37A and 18 positive witnesses. This note reads that array/helper inertly and checks the mathematical interface; it is not a separate complete source/degree audit.

## 1. What every positive candidate zero still forces

Write `A=a+2`, `Delta=A^2−1`, `E=XY`, `P=2XY^2+1`, and `u=2dx+b`. To avoid confusing the new U with the auxiliary root, call the latter

```
S=Delta*i*c^2,
V=c(T*f−1)−R*f^2,     T=auxiliary_quotient.
```

The actual output is still

```
Delta*(Nfirst*Nmain*Ninput*Naux*Nindex*Ntransport
       *(f^2−Delta*i^2*c^4)−1).
```

Thus at a positive zero the normalized seven factors are integer units. `Delta>0` precedes the equation. The norm sign arguments in normalized85 mathematical review §2 are unchanged: main/input/strong norms exclude −1 modulo4, the square coefficient S² excludes −1 for the auxiliary norm, and the first norm's integral descent excludes −1. The remaining index/transport units initially share a sign epsilon.

The unchanged transport and positive slack argument gives `C>=0`, `F+Z<q`, `|W|<q`, and the valid shifted-mask scalar bounds give

```
q>=B>=16,   R>3q+1,   R+2<q^4<=E<a,   Delta>R.
```

These are pretyping inequalities. In particular q has not been assumed dyadic. The changed main root is positive, since `D=ac+X+U+sigma*H`. The first and main norms therefore classify

```
k=2*psi_P(n), tau_root=chi_P(n),
c=psi_A(p), D=chi_A(p),
2n=R+epsilon modulo E,  p>n>=(R−1)/2.
```

All steps of normalized85 mathematical review §§3–6 now apply directly to these individual equations. They do not require `H|U` or an integral main quotient `(D−ac−X)/H`. In detail, the strong equation gives `f>c^2>2c` and `S^2=Delta*(f^2−1)>R*f^2+c`. For an integer solution of `S^2*V^2−(S^2−1)*y^2=1`, either `|V|=1` or `|V|>=2*S^2−1`. The congruence `V=−c mod f` excludes both unit values because `0<c−1<c+1<f`; T>0 gives `V>−R*f^2−c`, excluding the large negative branch. Thus V>0 before any H-divisibility conclusion.

Normalized Pell rank gives `f=chi_A(m)`, `psi_A(m)=i*c^2` and `p*c|m`: strong divisibility first gives p|m, and expanding the multiple-index coefficient modulo c gives `c|(m/p)`, since gcd(D,c)=1. The two literal auxiliary congruences `V=−c mod f`, `V=−R mod c` then force `p=R` by the cited signed chi step-down and the already available `c>2p,2R`. The first/main ratio excludes epsilon=−1 and yields `2n=R+1`. The generic fixed-minus parity argument applies to positive V and gives `R=3 mod4`. Neither A-even nor q-dyadic is assumed in this chain.

The lower-ratio estimate remains available before exponent recovery. Put `r=(R−1)/2`, `xi=(X+1)^(2r)/X^r`. Half-binomial42 §5 gives `xi<2Y+2`, hence

```
Y>X^r/2−1>X^r/3,
a>X^(r+1)/3>2^R.
```

Here `X=w*q>=16`, `r>=24`, and `6XY^2>a` are enough; the strict last inequality follows already from `16^(r+1)/3>2*4^r`. No main-root modulus congruence, dyadic typing, or old full positive-parent theorem has been used.

## 2. The input index remains canonical, but both exponents may shift

Since `kappa=u+delta*Delta>0` and `a>q`, the input root satisfies `mu=W+a*kappa+U>a−q>0`. Its norm gives `mu=chi_A(v)`, `kappa=psi_A(v)` for a positive integer v. Define

```
E_j=chi_A(j)−a*psi_A(j).
```

This sequence is strictly increasing: `E_0=1`, `E_1=2`, and for j>=1, `E_j=2psi_A(j)−psi_A(j−1)` with positive successive differences. The shared U cancels:

```
E_v=W+U < X+U+sigma*H=E_R.
```

Indeed `W<q<=X` and sigma>0. Hence v<R. The outer slack gives `0<u<2q<R<a+1`. For indices v<R, the discriminant residues are

```
psi_A(v)=v mod Delta           if v is odd,
psi_A(v)=A*v mod Delta         if v is even.
```

Both displayed representatives are strictly between zero and Delta. An even v would give `A*v>=2A>2q>u`; an odd v forces v=u. Consequently **v=u**, without using the parity of A or a power representation for q.

The recurrence with `E_0=1,E_1=2` gives `E_j=2^j mod H`: multiplying `E_j=2^j` by the recurrence has error `(4A−5)2^(j−1)=H*2^(j−1)`. Subtracting the two root definitions therefore yields

```
X−W = 2^R−2^u mod H.
```

Both representatives actually lie between zero and a. For the first, `0<X−W<X+q<=2X<a`; for the second, `0<2^R−2^u<2^R<a`. Thus

```
X−W=2^R−2^u,
e := X−2^R = W−2^u.                         (1)
```

Define integers `rho0=(E_u−2^u)/H` and `gamma0=(E_R−2^R)/H`. They are positive: u>=3, and `E_j/2^j` strictly increases after j=1. The exact remaining formulas are

```
U=H*rho0−e,      sigma=gamma0−rho0.            (2)
```

Because `X,2^R<a`, one has `|e|<a<H`. Therefore on every candidate zero

```
H divides U  <=>  e=0  <=>  X=2^R  <=>  W=2^u. (3)
```

At e=0, `rho=U/H` is a positive integer and restores a complete84 positive zero with every other supplied coordinate fixed. Conversely every positive parent zero has this image. The nonzero-offset sector is the sole missing same-coordinate inverse. Equations (1)–(3) do not show that this sector is empty, or that its ordinary inputs are new. In particular, v=u by itself does not finish decoding.

## 3. A full positive diagnostic zero with e nonzero

The following explicit scalar slice satisfies the elementary radix/mask conditions, but is **not claimed to be generated by the fixed universal compiler**:

```
Bm1=15, Kconstant=28, twice_cell_bits=8, inner_bits=1,
MC=14, MF=19.
```

Here B=16 and unshifted MF0=4. Set

```
J=1, x=1, F=4, Z=1, alpha=2.
```

Then the literal outer definitions give

```
q=16, C=q−F−Z−alpha−8x=1, W=C−Z=0, u=9,
R=(q^2−Z−qF)(q^2−1)+(MC+qMF)J=49023,
r=(R−1)/2=24511.
```

Thus `R=3 mod4`, `3q+1<R<q^4−q^3`, and popcount(R)=14=3log2(q)+2. Even the decoded mask conditions hold: `(Z−1) AND (MC*J+1)=0` and `F AND (MF0*J−1)=0`. These observations do not make the scalar slice a valid program.

Put

```
X=2^R−2^9, w=X/16,
M=binom(2r,r)+sum_(j=1..r) binom(2r,r+j)*X^j,
Y=M/2, s=Y/16^3.
```

These are mathematical definitions, not uncharged circuit producers. X and w are positive integers. The central coefficient has 2-adic valuation13, while `v2(r+1)=6` and r is odd; therefore `v2(binom(2r,r+1))=7`. Since `v2(X)=9`, the j=1 term has valuation16, and every j>=2 term has valuation at least18. Hence `v2(M)=13` and `v2(Y)=12`, proving positive integral s with the original cubed scale retained.

Also w=6 mod15. Set

```
transport_quotient=(28+w+11)/15>0.
```

This is integral and the literal transport factor is `(28+w)C+q−F−15*transport_quotient=1`.

We now give all remaining witnesses parametrically. At the fresh X,Y define

```
a=Y(X+1), A=a+2, Delta=A^2−1, H=4a+3, E=XY,
P=2XY^2+1, n=(R+1)/2,
c=psi_A(R), D=chi_A(R),
k=2psi_P(n), tau_root=chi_P(n),
eta=c−kY, zeta=k(Y+1)−c, h=(k−R−1)/E.
```

These have the required signs. To check the ratio rather than importing `X=2^R`, write `xi=M+theta`, where `0<theta<1/2`: the lower binomial tail is less than `2^(2r−1)/X<1/2` because `X>2^(R−1)`. The elementary Pell estimates give

```
xi/2 < c/k < (xi/2)*(1+8r/a).
```

Here `4r/a<1/2`, `xi<3Y`, and `12r/(X+1)<1/2`, so

```
Y < c/k < Y+1/4+1/2 < Y+1.
```

Thus eta,zeta>0. The first recurrence modulo E gives `k=2n=R+1 mod E`; Pell growth gives h>0.

For the input/shared roots put

```
kappa=psi_A(9), mu=chi_A(9),
delta=(kappa−9)/Delta,
U=E_9,
sigma=(E_R−E_9−X)/H.
```

The odd discriminant residue makes delta a positive integer. Because `X=2^R−2^9`, sigma is integral. It is positive since `E_j/2^j` is strictly increasing, giving `E_R−E_9>2^R−2^9=X`. The two changed root definitions hold exactly. Moreover

```
U=E_9=512 mod H,  0<512<H,
```

so H does not divide U. In this construction e=−512 and W=0.

For completeness, the auxiliary witnesses also admit an explicit positive completion. Set

```
m=2cR, f=chi_A(m), i=psi_A(m)/c^2,
S=Delta*psi_A(m), y_aux=psi_S(R), V=chi_S(R)/S,
T=(V+c+R*f^2)/(c*f).
```

The Pell multiple-index expansion shows `c^2|psi_A(2cR)`, so i is a positive integer and `S=Delta*i*c^2`. The odd auxiliary index makes V integral. The standard polynomial identity `chi_S(2r+1)/S=C_r(S^2)`, with `C_r(0)=(-1)^r(2r+1)` and `C_r(-Delta)=(-1)^r psi_A(2r+1)`, gives `V=−R mod c` and `V=−c mod f`, since r is odd and `S^2=Delta*(f^2−1)`. Finally `f^2=1 mod c` and gcd(c,f)=1 prove that the numerator defining T is divisible by cf. Every term is positive, so T>0. These formulas establish both strong and auxiliary norms and the literal quotient definition of V.

All seven normalized factors are therefore +1, so the complete scaled83 output vanishes with all 18 witnesses positive. This is a **parametric existence proof**, not a materialized native tuple. It demonstrates that H-divisibility cannot follow merely from the surviving Pell equations, cubed scale, scalar radix/mask restrictions and those outer equations. It does not refute soundness for an actual fixed-program recipe.
