## 1. Every macro has the advertised primitive meaning

Composition is right to left. `sigma^-1=rho sigma rho` moves indices one site left. Therefore `zeta_i=sigma^i zeta sigma^-i` frees exactly i, `T_i=sigma^i tau sigma^-i` swaps i and i+1, `Left=rho pi rho` frees sites below zero, and `Right_j=sigma^j pi sigma^-j` frees sites above j. These formulas are direct substitutions into the definitions on finitely supported integer functions; no incorrect printed general-swap or left-liberation formula is imported.

`Block_d(A)=Right_(d-1) Left A intersect Box_d` extracts the first d coordinates of a single witness in A. The liberated sets do not mix the retained coordinates from different witnesses. Conversely, a given witness may first be patched on negative sites and then above d-1, both with finite support, to produce any chosen extension of its retained block. Intersection with `Box_d` sets the other coordinates to zero. This remains valid for A with no uniform support bound. For a set already supported inside finite F, `Keep_(F,I)(A)=zeta_(F minus I) A intersect Box_I` forgets the other values existentially; it does not require that they were originally zero.

The unary cylinder shifts its single value to i and frees precisely the other sites of the fixed window. In `Pair_d(B;i,j)`, `T_(i+1)` acts first after the shift and the consecutive swaps move only the second value from i+1 to j, leaving the first at i; the complement liberation then gives the exact ordered-pair constraint. The adjacent case uses no swaps. Reversed arguments use `tau B`, so the same finite expression applies to the decrement relation with its arguments reversed. All branch arguments are distinct sites.

The equality intersection is exactly `(a,a+1,a)`, with support in {0,1,2}; theta therefore produces exactly `(a,a)`. This use of theta is not a general coordinate-extraction assertion: the displayed support restriction is what makes its other output coordinates zero. No primitive arithmetic equality or copy operation was assumed.

For `V=omega_2(zeta_1 Z union tau S)`, the intersection with `sigma^-1 V` forces every adjacent pair to be either `(0,b)` or `(a,a-1)`. A negative entry would force an infinite decreasing tail and contradict finite support. Every n>=0 has a witness consisting of the descending finite string n,...,1 with zeros on both sides. `Block_1` hence gives exactly the nonnegative integers. For a unary A, `Next(A)=theta(tau S intersect zeta sigma A)` gives its pointwise successor because the intersection is `(a+1,a)` with a in A. The constant recursion is only the fixed list C0 through C31, and Pos is exactly the positive integers.

## 2. Literal table, loader, and ordinary-input meaning

Every U21 row in the draft was matched by hand to `korec_packed_counter_units.md` Section 1, including pure test 8, halt 21 and the inherited corrected routing. This is a table/interface comparison with the committed source, not a new proof of the primary contraction or universality theorem. All nine added rows were checked using the stated I/D/T semantics.

At each entry to state 22, the registers have shape `(N,e,0,0,...)`, with N>0. States 23--25 remove two units of R0 for each unit added to R2. When N is even, state 23 reaches its zero branch with `(0,e,N/2,0,...)`; state 26 increments e, and states 27--28 transfer the quotient back to R0. The transfer terminates, R2 is again zero, and the new positive dividend N/2 is strictly smaller. When N is odd, state 24 discovers zero only after state 23 removed the last unpaired unit. State 29 therefore sees `(0,e,(N-1)/2,0,...)`. It enters U21 exactly when the quotient is positive. The other branch reaches the endless increment loop at 30. These are deductions for all integers N, not finite test results.

The entry to U21 is consequently exactly `(0,e,x,0,...)` for the unique factorization `n=2^e(2x+1)` with x>=1. Powers of two reach N=1 and are rejected. No U21 target enters the loader or reject states, and no reject edge reaches halt. Only the fixed machine index e depends on the represented c.e. set; the body input x is unchanged. The unary set U is thus the one defined by the actual U21 enumeration, not by an unrelated implicit program numbering.

The U21 table has eight I, twelve D and one T instruction, giving 34 branches. The loader/reject table has four I, three D and two T instructions, giving 14 branches. Hence the actual Run union has 48 branch expressions, with Clear and Restart providing two further alternatives. There are thirty nonhalting instruction rows, nine configuration fields, and state tags through 31. These are exact finite H-grammar counts, not Diophantine gate counts.

## 3. Full transition and history equivalence

Each Run alternative fixes the two positive state tags and all sixteen counters to their nonnegative domain. The increment S constraint advances exactly one counter. Reversing S for a positive D makes current=next+1, so next>=0 already enforces current>0. Zero D fixes current=0 and preserves it; the T branches preserve all counters and distinguish Pos from C0. The other seven counters are held equal. Thus each alternative is exactly its machine branch on a valid configuration. No Run branch leaves halt 21, and every Run target is nonzero because its tag is positive.

Clear has precisely tag 22 (halt state 21), nonnegative counters and an all-zero next block. Restart requires the entire current block to be zero and leaves the next arbitrary. The all-zero 18-tuple is therefore included, as required for the omega construction to have finitely supported witnesses.

`omega_18 R` checks adjacent configuration pairs at even block indices, while membership in its shift by -9 checks the odd indices. Together they impose every adjacent transition. Starting from a live block, finite support supplies a first future zero block. Before it, Restart is unavailable. The edge entering it cannot be Run, whose target tag is positive, so it is Clear from a genuine halt. This proves soundness even if other, unrelated episodes occur at negative indices. Conversely, any finite actual run to halt, followed by Clear and zero blocks and preceded by zero blocks, satisfies both alignments; Restart permits its first edge. The proof also covers an initial halted configuration for the intermediate Reach relation.

The order of the final operations is essential and correct: first take `Reach=Block_9(Hist)`, then impose Init with tag 23, a positive R0, and the other seven registers zero; only after that use Keep to remove the tag and other sites. The shift by -1 then puts the selected R0 at coordinate zero. Thus the expression returns exactly `{(n):n in U}`. It neither forces the original future history to be zero nor forces the nonzero initial tag to vanish before projection. ## 4. Retained boundaries and remaining construction

**Review remark 1 (tag/delimiter boundary).** Removing the state tag would identify an all-zero-counter nonhalting configuration with the zero delimiter. An endless zero-test machine would then admit the all-zero history. The present positive tag avoids that false shortcut; no claim about an executed U21 false positive is made.

**Review remark 2 (alignment boundary).** A single omega condition checks only disjoint pairs. A legal nonhalting pair surrounded by zero pairs can satisfy it while omitting the required following transition. Both alignments in the actual expression are needed; this is not a counting or support approximation.

**Review remark 3 (positive ordinary input).** Allowing state 29 to enter U21 with quotient zero would send powers of two to an x=0 body run, outside the chosen interface. The draft retains the positivity test and claims no evaluated halting outcome for such body runs.
