## 1. The matrix package: an actual directed universal alphabet

The matrix ZIP's `core/PROOF.md` constructs a directed semi-Thue simulation of the literal15-state binary U15 machine. A valid finite input is

    [ reverse(left_nearest_first) A 0 right_nearest_first ],

with blank0 outside both finite halves. Each of29 defined machine instructions gives three local/boundary rewrites. The additional rules are `J1→X`, the four tape erasures adjacent to X, and `[X]→X`, totaling93. The terminal X is fresh. Before its introduction every configuration has one state; after it there is one X and only cleanup can apply.

The original tile alphabet has20 copy tiles,93 reversed rule tiles `(h,g)=(rhs,lhs)` and a separator tile `(#,#)`, totaling114. Its exact word equation is

    w# h(s)=g(s) X#.

Let `E_j=[[1+4j,2],[-8j²,1−4j]]`, let Phi encode the21 top letters by E1..E21, and let t=E0 and xi=Ei in the separate lower block. The229 matrices are

    A_i=diag(Phi(h_i),xi),
    B_i=diag(Phi(g_i)^−1,t^−1 xi^−1 t),
    C=diag(Phi(X#)^−1,t).

The finite-input target is `T(w)=diag(Phi(w#)^−1,t)`. Freeness of the conjugates E_j makes the lower block force every positive generator word with value t to have exactly the form

    A_i1 ... A_ir C B_ir ... B_i1.

The upper block is then exactly the displayed correspondence equation. No inverse generators, externally imposed word order or computation-length bound are used. The publication's finite TM→clockwise→bi-tag→U15 initialization is the many-one universality premise; this archive implements the finite-U15-tape target map, not that entire arbitrary-program loader. This is the same finite-input U15 dependency already identified by the WIP U15 report, including Table16's sole undefined J1 instruction.

The intake independently reconstructs all93 rules,114 tiles and229 matrices, matches the table to the WIP receipt's compact transcription, checks determinants/distinctness and reproduces the coefficient census: maximum entry63,038,000,1,831 nonzero entries,21,372 magnitude bits. It directly simulates the accepting left011/right-empty tape: seven machine steps reach J1. It also checks all14 rewrite steps, the94-tile word equation and the entire189-matrix product against the exact target. These checks substantiate the actual numerical data; the general marker/simulation arguments remain mathematical proofs.

### A derived197-generator subset

There is a simple new reduction on this exact archive, materialized in `matrix.derived_subset197.retained_generators` in the intake receipt. Delete the copy tiles for A..O and X: original tile IDs3..17 and20. Delete both A_i and B_i for those16 IDs. Keep copy tiles1,2,18,19 for0,1,[,], all93 rewrite tiles and separator114. Thus the retained98 tiles give **197 distinct literal matrices**. Their old lower-block indices and all remaining entries are unchanged; no uncounted recoding is required.

The helper checks from every actual rule that its left and right sides each contain exactly one letter from A..O,X. Starting from a valid finite U15 input, every live configuration contains exactly one state, and each chosen transition or halt rule consumes that state. During cleanup the chosen rule consumes the unique X. Every untouched context therefore contains only0,1,[,], whose copy tiles are retained. Every accepting derivation has the same forward tile certificate in the restricted alphabet.

Conversely the restricted positive semigroup is a subset of the original one. Membership of the unchanged target therefore still implies U15 halting by the original theorem. These two directions prove exactly the same finite-input halting equivalence, and hence many-one r.e.-completeness, for the fixed197-generator semigroup. Its full target encoder, including all21 top letter codes, is unchanged. The saved189-generator accepting word uses only retained matrices and is included with the subset.

This forward argument is deliberately restricted to well-formed U15 inputs. It does not preserve the original package's stronger rewriting equivalence for every malformed word, because an untouched extra state might require a deleted copy tile. It is not an inverse-closure theorem, a new Diophantine operation count, a minimal generator claim or an improvement to the different97-tile WIP GPCP construction.

    U*(1+sum R_j²)−1.
