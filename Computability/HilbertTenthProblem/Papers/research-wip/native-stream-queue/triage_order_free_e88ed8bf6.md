## 3. Spectral report: literal linear frequency interface

The exact source interface is at 368–423, with its paid-data assumptions: integer dilation b≥2 and a real nonnegative finite trigonometric mask a satisfying a_0=1 and a_{bj}=0 for nonzero j. On Fourier characters,

    T_a e_m = Σ_{|j|≤d, b|(m+j)} a_j e_{(m+j)/b},
    coefficient_k(T_a f) = Σ_j a_j coefficient_{bk−j}(f).

The second formula follows directly by Fourier integration/change of variables, or first for polynomials and then by uniform approximation; it does not assume pointwise convergence of the Fourier series of f. For the Rvachev mask b=2, a=1−cos(2πx), this is

    e_(2m) ↦ e_m,

## 4. Review-side computable-real obstruction

This independent consequence is **not a source defect** and does not restrict explicitly represented rational/algebraic matrices. It isolates the representation assumption in the finite procedure.

Take b=2 and a_θ(x)=1−θ cos(2πx), with 1/2≤θ≤3/4. These are strictly positive, normalized masks of fixed degree one. In the basis (e_{−1},1,e_1), the literal source rule gives

    A_θ = [ −θ/2   0     0   ]
          [ −θ/2   1    −θ/2 ]
          [   0    0    −θ/2 ].

Thus its characteristic polynomial is (z−1)(z+θ/2)^2. Its double eigenvalue has modulus θ/2, equal to the general operator's critical radius 2^(−2)=1/4 at s=2 exactly when θ=1/2. This is T_a, not the repository's differently normalized L=T_a/2. The equality in question concerns the finite-core eigenvalue; it is not the presence of an essential spectral circle, which is present regardless of θ in the source theorem.

Wrap machines so that any first halting time t is at least one. Define θ_e=1/2+2^(−t−2) when machine e first halts at t, and θ_e=1/2 otherwise. These parameters have uniform fast Cauchy names: to precision 2^(−N), simulate N steps and return the appropriate rational if halting is observed, otherwise 1/2. Any unobserved later increment is smaller than 2^(−N). Their values lie within the allowed interval, and all mask coefficient programs are total.

The double eigenvalue is on the critical circle iff e never halts; otherwise it is exterior. Consequently no uniform algorithm decides that exact equality on all these coefficient-program indices. Nor can a uniform effective translation produce a finite ordinary existential Diophantine problem solvable exactly for that equality: integer solvability is computably enumerable, so dovetailing the resulting searches would enumerate nonhalting.
