# Inverse-graph folding preserves the matrix subgroup

A fixed inverse-closed matrix alphabet can be compiled through an inverse graph and folded while preserving its evaluated matrix subgroup. This permits a stronger transformation than the earlier [exact-language sharing](group_projective_shared_macro_automaton.md). The physical word language generally changes. The preserved object is the set of evaluated matrix products, which is sufficient for the paired endpoint predicate.

For the explicit table below, the resulting graph has **28 directed physical edges, 13 states and lane capacity32**. The [standalone source](group_inverse_stallings_controller.py) and [receipt](group_inverse_stallings_controller.json) contain the complete labeled graph and conservative fold traces. They contain no complete arithmetic compiler, operation improvement, witness-tuple bijection or numerical universal bound. A separate full compiler must charge its flow, packing, native interfaces and finalizer; fewer graph states or edges alone do not determine that cost.

The standard free-group formulation appears in Kapovich and Myasnikov, [*Stallings foldings and the subgroup structure of free groups*](https://arxiv.org/abs/math/0202285), particularly Lemma3.4 and Lemma6.1 of the [author-hosted paper](https://web.stevens.edu/algebraic/alexeim/Teaching/GroupTheory626/graph5.pdf). An elementary proof tailored to the present matrix interface follows. The executable does not fetch or depend on the paper.

## 1. The general invariant and chronological convention

The physical alphabet has inverse pairs `(1,2),(3,4),(5,6),(7,8)`. Assign to each letter a fixed invertible matrix, with inverse letters assigned inverse matrices. An inverse graph has a directed edge `v --a--> w` precisely when it has the reverse edge `w --a^-1--> v`. Fix one vertex as both initial and accepting state.

The evaluations of based closed walks form a subgroup: concatenate walks for multiplication, reverse a walk for inversion, and use the empty walk for identity. In the compiler's chronological convention, each next shear acts on the left, so

```
M(uv)=M(v)M(u).
```

This reverses the order of concatenation but still gives a subgroup and preserves every free cancellation. In particular inverse-pair insertions always evaluate to identity.

Build a bouquet of generator cycles and add reverse edges. A walk in this inverse bouquet can backtrack or traverse a complete generator cycle in either direction. Equivalently, collapsing a spanning tree gives precisely the group generated by the designated cycles. If the original macro alphabet contains inverses, its macro-star matrix image is already this subgroup. Adding inverse edges therefore preserves the matrix image even though it can introduce new physical spellings.

Consider a fold of two edges

```
v --a--> u1,     v --a--> u2.
```

Identify u1 and u2 and the equally labeled edges, together with their inverse edges. Every old closed walk maps to a new closed walk with the same label, proving one inclusion of matrix images.

For the reverse inclusion, the old graph contains a connector

```
u1 --a^-1--> v --a--> u2
```

and its reverse, both with identity evaluation. Lift a new walk one edge at a time to the old graph. Whenever consecutive chosen preimages fail to meet, their endpoints are u1 and u2, so insert the appropriate connector. If the base vertex was identified, use the same connector at the beginning or end to retain the original base vertex. Thus every new based closed walk lifts to an old based closed walk with the same freely reduced label and the same matrix product. Parallel edges with the same endpoints and label may simply be deduplicated.

Each nontrivial fold reduces the finite edge count, so iteration terminates. The invariant holds at every step, including folds involving the base vertex or loop edges. This proof applies to any matrix group, not only to a faithful free-group representation. Removing a nonbase hanging tree, if desired, also preserves the image: every closed excursion into that tree returns by inverse edges. No such pruning is needed for the concrete graph here.

## 2. The explicit Nielsen change and folded graph

Set

```
Rtilde=(2,3,6,7), U=(1,5), B=U^5, A=Rtilde B.
```

The original inverse-closed table is `(A,B,A^-1,B^-1)`, with lengths14,10,14,10. In the free group on physical letters,

```
Rtilde=A B^-1,      A=Rtilde B.
```

Consequently the two generator pairs have the same free subgroup and the same evaluated matrix subgroup. Chronological evaluation is important: the matrix equations are

```
M_A=M_B M_Rtilde,   M_Rtilde=M_B^-1 M_A.
```

They are not obtained by copying the formal word order into an ordinary left-to-right matrix product. In each 2-by-2 block, the actual matrices are

```
M_Rtilde=[[1,−1],[1,0]],
M_B=[[1,5],[0,1]],
M_A=[[6,−1],[1,0]].
```

Both blocks carry the same matrix. The helper verifies these products and both freely reduced Nielsen identities exactly.

The four-code private graph initially has48 directed edges and45 states. Replacing its generators by `(Rtilde,B,Rtilde^-1,B^-1)` gives28 private directed edges but25 states. The inverse bouquet instead shares the forward and reverse paths, leaving14 undirected edges,28 directed edges and13 states. It is already folded: the root's outgoing labels are `{1,2,6,8}`, and at each internal vertex the forward and backward labels are distinct.

The saved canonical state codes are0 through12, with root0. Two cycles and all their inverse edges specify every edge:

| Cycle | Successive states | Successive physical labels |
|---|---|---|
| Rtilde |0,2,6,4,0|2,3,6,7|
| B |0,1,5,8,10,12,11,9,7,3,0|1,5,1,5,1,5,1,5,1,5|

All state codes are below32. The next power of two at least28 is32, so the literal controller fits32 lanes. Compared with the proposed30-edge exact-language shared controller, this saves two directed edge coordinates but does not halve the lane capacity. It does not by itself establish a full operation saving.

Four independent initial bouquets yield exactly this same canonical labeled graph:

| Generator cycles before adding inverse edges | Initial directed edges | Initial states | Directed edges after inverse augmentation | Recorded vertex folds |
|---|---:|---:|---:|---:|
|A,B,A^-1,B^-1|48|45|96|32|
|A,B|24|23|48|10|
|Rtilde,B,Rtilde^-1,B^-1|28|25|56|12|
|Rtilde,B|14|13|28|0|

Inverse augmentation and fold bookkeeping are construction steps, not paid arithmetic instructions. The receipt records all54 folds with their before/after graphs and identity connectors.

A separate spanning-tree calculation verifies the final based subgroup generators are exactly Rtilde and B, up to inversion. Every chord produces its root-to-source tree path, edge, and reverse root-to-target path. Along any closed walk the inserted tree paths telescope, proving that these chord loops generate all its labels. There are14 undirected edges and13 vertices, hence two chords. Because the graph is folded, a freely reduced nonempty graph path cannot have an empty freely reduced label; this also identifies the abstract free rank as2.

The matrix image has additional relations: `M_Rtilde^6=I`. Therefore the free-group core is not claimed minimal for the evaluated matrix subgroup, for state count under matrix relations, or for arithmetic operations.

## 3. Why this changes words but preserves the endpoint query

The word Rtilde itself is accepted by the folded graph. It is not in the original macro-star language: it has length4, whereas every original nonempty macro has length at least10. This explicit witness refutes formal word-language equivalence. The helper checks it against the actual original directed macro graph and the final graph.

Nevertheless both graphs evaluate to the same subgroup, by Sections1–2. The existential paired-action condition therefore agrees for each fixed ordinary input and loader parameter:

```
M*(1,u,1,u)^T=(0,1,0,1)^T.
```

The identity matrix cannot satisfy this endpoint because the initial first coordinate is1 and the target first coordinate is0. Thus the newly available empty walk creates no accepted input. The same observation handles any nonempty physical spelling whose matrix product is identity. Every matrix product satisfying the endpoint necessarily has a nonempty spelling on either side.

This argument applies to the actual abstract fixed inverse-closed universal alphabets used by the [projective subgroup construction](group_projective_zero_mortality6.md). It does not require faithfulness of their physical free-group representation. It also does not instantiate a numerical universal alphabet or transfer a particular ordinary-input theorem to arbitrary program numerals.

## 4. Compiler transfer requires new histories and paid graph arithmetic

For an arbitrary directed inverse graph, the existing [general graph adapter](group_projective_shared_macro_automaton.md) requires positive edge hats, their paid checksum, injective lane positions, physical selector sums and chronological state flow. Source and target state codes must lie below m and the radix. The physical history, selected-output, range AND, native signs, ordinary loader and positive height constructor must all remain present. Private-path shortcuts may not be reused on a branching folded graph without new identities.

Once these obligations are compiled, any accepted path has finitely many signed intermediate states. Choose a fresh dyadic D larger than u, the graph margin and every needed absolute history bound. Set the positive height slack to D−u, use radix16D, and rebuild the duration, histories and selector words for that path. The [product-scale](group_projective_product_radix_scale.md) and [tail-quotient](group_projective_tail_quotient_shift.md) converses then supply fresh positive native coordinates. This applies in either direction because the matrix endpoint is preserved.

A freely reduced or folded spelling can have a different duration and different intermediate coordinates; it cannot generally reuse the original height, packed history or native witnesses. This is equality of existential input predicates, not an all-value polynomial identity or a bijection of complete positive zero tuples.

Fixed numeral margins must be checked on the newly emitted graph. First freely reduce the fixed codes and discard empty reduced words; this preserves the matrix subgroup. When the resulting alphabet includes literal inverse words, choose one representative of each formal inverse pair; adding inverse arcs then uses no more directed edges than the original table, and folding only decreases that number. An already valid margin remains sufficient in that case. For other presentations there is no automatic cost or margin claim: those are obligations of the concrete compiler, or of its once-fixed program padding. The present concrete reduction64 lanes to32 satisfies the corresponding downward margin condition.

## 5. Evidence and replay

The helper authenticates seven frozen source, receipt and proof dependencies and verifies the saved general graph predecessor's self-source hash. It does not import any predecessor code. Its scope is the explicit graph and theorem above, not a maintained general compiler API.

It reconstructs the graph by all four routes, saves the54 elementary folds, and lifts28 prescribed closed loops through378 individual fold steps. Every lifted path is checked against the actual old edges; its freely reduced label and paired matrix product are checked exactly. Four separate spanning-tree audits recover the two stated subgroup generators. These finite checks supplement the unrestricted connector and spanning-tree proofs; they do not stand in for an unbounded subgroup theorem.

All arithmetic is standard-library integer arithmetic. Saved receipts are compared with exact JSON types, and dependency bytes are authenticated by SHA256. Run from any working directory:

```sh
python3 /path/group_inverse_stallings_controller.py \
  --root /path/native-stream-queue \
  --expect /path/group_inverse_stallings_controller.json
```

`--output FILE` writes a fresh receipt. Optimized Python is rejected. Writer and fresh exact saved-receipt replay from `/` pass. No frozen predecessor or repository file is changed.
