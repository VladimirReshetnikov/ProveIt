# Sequential PD0L evaluation and a 12-operation transport/phase component

A productive non-erasing PD0L word can be generated by a FIFO queue that
consumes one letter at each step. Its phase advances on every consumption,
independently of the queue's length. A finite target occurrence can therefore
be witnessed in a whole number of phase cycles. Coding the initial and final
phase as zero leaves just **one multiplication** for the packed phase
transport. Together with content and length, the three outer transports cost
**12=6M+6A**.

This is a component count. The joint phase/letter rule test, weighted output
selection, bounds, common row geometry, mask/kernel, positive-variable
adapters and raw numerical input conversion remain unpaid. The exact checker
is `../verification/explore_fifo_pd0l.py`, with an adjacent JSON receipt.
The frozen locally uniform PD0L note is unchanged; the queue result here does
not assume locally uniform lengths.

## 1. Exact evaluator and finite occurrence

Use the periodically applied morphisms of
[Endrullis--Hendriks, Definition 1.1](https://arxiv.org/pdf/1207.2336).
There are p>=1 non-erasing morphisms h_0,...,h_(p-1); the letter at position j
uses h_(j mod p). Fix a finite seed s such that s is a prefix of H(s), and
suppose its limit x=H^omega(s) is infinite. Then

    H(s)=s t,  t nonempty.                          (1)

The equality H(s)=s would instead give a finite fixed point. Conversely, for
non-erasing H a strict extension in (1) makes successive iterates strictly
longer, so the hypotheses are effectively checkable on this input.

Initialize the queue to t. At step i, read its first letter a, remove that
letter, and append h_((|s|+i) mod p)(a). The next phase is obtained by adding
one modulo p. There is no reset at an original parallel-generation boundary.
All image words are nonempty, so the queue stays nonempty and its length
never decreases.

If v is the word consumed so far and q is the current queue, the invariant is

    H(s v)=s v q.                                  (2)

It holds initially by (1). If q=a q', then
H(s v a)=H(s v)h_((|s|+|v|) mod p)(a), proving (2) after the next step.
Alternatively, induction using H(x)=x shows that s v q is a prefix of x:
the queue front is the next letter of x, and the appended image extends the
already generated H(s v). The generated prefix length tends to infinity
because |v| grows by one on every step. Thus the consumed letters enumerate
exactly x(|s|),x(|s|+1),... .

A target letter already in s is an immediate positive instance. Otherwise it
occurs in x if and only if some consumed source letter is that target. This
is a finite existential event; it does not require productivity or infinite
occurrence to serve as an acceptance predicate. Productivity is an input
hypothesis ensuring the evaluator continues.

After a target has been consumed, evaluation may continue. Consequently,
when the target is not in s, occurrence is equivalent to a positive finite
run whose number h of consumed letters is divisible by p and which has at
least one target source letter. Rotate the fixed morphism tuple by |s| mod p
so that the initial phase has code0. Then the endpoint phases of this run
are both0. No additional input word is inserted.

The fixed input interface is the queue t and its length, obtained from the
specified finite seed. This computable preprocessing is not a priced loader
for an arbitrary raw numerical query. On the general seed domain the
immediate-positive seed case is separate; the 12-operation component below
uses target-not-in-s. The occurrence reduction in Definition4.3/Theorem4.15
has a distinguished seed and a distinct target, so this restriction is
compatible with that application, without making it a fixed raw-input result.

## 2. Scalar queue, rule and phase relations

Choose an injective digit map into {1,...,b-1}. Encode each queue front at
the least significant end. Let n_i be its code and L_i=b^(queue length).
For the row's joint rule, let a_i be the read digit, u_i the code of its
nonempty appended word, ell_i its length, and

    lambda_i=b^(ell_i-1).

These rule entries are fixed numerals. Let sigma_i in {0,...,p-1} be its
source phase and phi_i=(sigma_i+1) mod p its successor phase. The scalar
relations are

    b n_(i+1)=n_i-a_i+u_i L_i,
    L_(i+1)=lambda_i L_i,
    sigma_(i+1)=phi_i.                             (3)

Conversely, start with the valid initial queue and choose entries from the
joint phase/letter table. If (3) holds over the integers, reduction of the
first equation modulo b forces a_i to be the actual front digit: L_i is a
positive power of b, and both candidate digits lie between1 and b-1. The
remaining quotient is exactly deletion followed by appending the selected
word. The second equation gives the correct new length marker; the third
gives the correct phase. Induction recovers the exact FIFO computation.
Thus validity of later queues is a consequence, not an additional premise.

For p>=2, a positive whole-cycle run visits all phases, so both packed phase
words below are strictly positive even though individual phase codes may
be zero. For p=1 they are zero and the phase comparison can be omitted,
leaving an 11-operation transport component; this is a single-morphism
case and is not presented as a universal occurrence machine.

## 3. All three packed transports and the complete subtotal

Conditionally supply common row geometry Q=R^h, h>=1, and the seven words

    N=sum n_i R^i,        A=sum a_i R^i,
    U=sum u_i L_i R^i,    Z=sum L_i R^i,
    W=sum lambda_i L_i R^i,
    S=sum sigma_i R^i,    F=sum phi_i R^i,           0<=i<h.

Let n0,L0 encode the fixed initial queue and nh,Lh the final queue.
Summing (3) yields

    R(N-A+U)=b(N-n0+nh Q),
    RW=Z-L0+Lh Q,
    RF=S.                                         (4)

The last equation includes both phase endpoints as zero. It is not a
comparison with an omitted nonzero input phase. Its scalar coefficients
force sigma_0=0, sigma_i=phi_(i-1), and phi_(h-1)=0. Joint rule validity
therefore implies h=0 modulo p.

| Transport | Multiplications | Additions/subtractions | Total |
|---|---:|---:|---:|
| Content | 3 | 4 | 7 |
| Length | 2 | 2 | 4 |
| Phase | 1 | 0 | 1 |
| Total | 6 | 6 | 12 |

The two endpoint products nh Q,Lh Q and the multiplication by fixed b are
charged. Equality comparisons and fixed numerals are free; intermediate
differences may be signed. The checker records every primitive and verifies
all three independently written source polynomials.

For a sound packed converse, a surrounding source must establish the common
row supports and bounds on the scalar residuals before decoding (4).
For example, |rho_i|<R for every coefficient in each expanded transport
ensures that a vanishing sum rho_i R^i has each coefficient zero, by reduction
modulo R and induction. For the phase relation, R>p suffices. No such bounds
are derived merely by writing (4). Given their actual derivation and the
joint rule/weight tests below, (3) and its scalar converse prove exactness.

Every genuine finite target occurrence admits the chosen cycle extension.
Its row values and residuals have finite size, so one may choose R sufficiently
large in the completeness construction. All seven outer words are positive
for p>=2 and h a positive multiple of p. This construction is not a substitute
for proving the required pre-decoding bounds in a complete source.

## 4. Periodicity and the remaining joint selection obligation

For each rule indexed by phase r and letter a, a direct specification uses
Boolean row selectors D_(r,a) and weighted selectors T_(r,a), where

    D_(r,a)=sum selected R^i,
    T_(r,a)=sum selected L_i R^i.

They must partition the common rows and refer to the same selections. Then

    sum D_(r,a)=J,
    A=sum c(a)D_(r,a),
    S=sum r D_(r,a),       F=sum ((r+1) mod p)D_(r,a),
    Z=sum T_(r,a),
    U=sum code(h_r(a))T_(r,a),
    W=sum b^(|h_r(a)|-1)T_(r,a).                    (5)

Here h_r denotes the rotated fixed table and J=sum_(i<h) R^i. These seven
identities are a sufficient specification, not free computations in (4).
Every phase, input letter, image and image length must come from the same
table entry. Multiplying D_(r,a) by Z does not produce T_(r,a); it convolves
different rows.

Once scalar phase transport has been proved, the aggregated phase masks
have the exact periodic shape, for h=pT,

    D_r=sum_a D_(r,a)=R^r(1+R^p+...+R^(p(T-1))).    (6)

Equation (6) is a consequence of the coupled table and phase relation, not
an unpriced source constraint. Thus the 12-operation schedule does not
compute R^p or construct p independent periodic masks. Conversely, simply
asserting known phase masks would still leave each phase's actual read-letter
selection and the weighted T_(r,a) relation to certify. No complete savings
from a particular implementation of those tests is claimed.

## 5. A second exact route: one finite self-extending prefix

There is also a history-free semantic certificate. For the same productive
non-erasing (H,s), the target occurs in x if and only if there is a finite w
such that

    s prefix w,  target occurs in w,  w prefix H(w). (7)

For the forward implication, take a sufficiently long prefix w of x.
The output H(w) is another prefix of x and, because H is non-erasing, has
length at least |w|. Hence it extends w. Conversely, the prolongable w has
a prefix limit y. Since s prefix w, every H^n(s) is a prefix of H^n(w).
The former lengths tend to infinity, so y is infinite and extends infinite
x; therefore y=x. Thus w itself is a prefix of x. This also proves that
H(w) strictly extends w whenever w extends the productive seed: equality
would bound all iterates of s by the finite word w.

If the target is absent from s, let Ns,Ls=b^|s| encode that fixed seed.
Assuming N,L are the exact code and length power of w and O is the exact
code of H(w), the two prefix gluings are

    N=Ns+Ls V,  O=N+L T.                           (8)

Both V,T are positive on the intended witnesses. These equalities cost
4=2M+2A, with Ls a free fixed numeral. Digit typing, L=b^|w|, the marker
witness and especially the exact positional morphic-image relation remain
unpaid. For locally uniform lengths that last relation is precisely the
shared-polynomial resampling problem in the separate locally uniform note;
for general lengths the output offsets also depend on earlier letters.
Thus (8) is not a four-operation universal certificate or a direct numerical
competitor to the 12-operation queue subtotal.

## 6. Evidence boundary

The checker independently verifies the 12-operation source and the four
prefix-gluing operations. It compares FIFO consumption and invariant (2)
with direct parallel iterates, checks both scalar recurrences, all packed
transports, all seven selector forms, the periodic phase masks and positive
whole-cycle phase words. It distinguishes an already-present seed target,
a witnessed later occurrence and mere bounded nonobservation. It separately
enumerates candidate words for (7), including false candidates, and checks
accepted candidates against a sufficiently long directly generated prefix.

These tests support the general proofs. They do not supply the missing joint
table arithmetic, masks, geometry, bounds or a full positive Pell extension.
