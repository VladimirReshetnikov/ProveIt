\begin{abstract}
For a set $X\subseteq\N$, let $\Core(X)$ be the sets computable from every
coarse description of $X$. We prove that the possible cores are exactly the
countable Turing ideals. More precisely, a positive-density column code for a
sequence $(A_i)$ has core equal to the ideal generated by that sequence, and its
entire representative spectrum is characterized by a single computable array
whose rows eventually stabilize as whole reals. The quantifier order in this
characterization is essential; merely computing each $A_i$ separately is not
enough.

We then separate common information from the difficulty of producing a
representative. If $Y$ can be approximated arbitrarily closely in upper-density
distance by computable sets, adjoining $Y$ preserves the core of every $X$.
For the classical dyadic code $\Rcode(H)$ this gives the exact operation
\[
 \Core(X\oplus\Rcode(H))=\Core(X),\qquad
 \Spec(X\oplus\Rcode(H))=\Spec(X)\cap\{\mathbf b:H\leT B'\}.
\]
Here $B$ is any representative of $\mathbf b$. Relative jump inversion turns
this identity into a join-preserving order embedding of the Turing cone above
$\degT(X')$ into both the uniform and the nonuniform coarse degrees with core
$\Core(X)$, above the coarse degree of $X$. Every fixed-core collection therefore
contains continuum many distinct representative spectra and has no countable
cofinal subset. The proofs are explicit, including the analytic locality lemma,
the coding estimates, and the jump-inversion argument.

\emph{Merged report.} Part~I is the manuscript above (source~12, the base).
Part~II (source~08) realizes every countable ideal by a two-level code whose
descriptions are Medvedev equivalent to arrays of finite variants of the
generators, builds a perfect family of pairwise exact descriptions with jumps
below $\bigoplus_m(\bigoplus_{n<m}A_n)'$ and one common effective null envelope,
and constructs, inside every core fiber, exact pairs with any prescribed common
jump above the jump of the presentation. Part~III (source~10) realizes every
countable ideal by a layered factorial-block carrier, proves an
ideal-protected fusion theorem giving a second proof without cone-avoiding
compactness, and locates each level of the ideal in a robustness filtration
within a factor four in radius. Results proved by more than one source are
printed once and credited; genuinely different proofs are kept as marked
second routes. The core-realization theorem was already proposed, with a proof
sketch, as target~C4 of the programme's research plan, and its column mechanism
has a published antecedent in Hirschfeldt--Jockusch--Schupp \cite{HJS}.
\end{abstract}

\part{Source 12: ideal realization, whole-row spectra, and fixed-core embeddings}\label{cr12:part1}
\section{The target and the contribution}\label{cr12:sec:intro}
\subsection{The repository question}
The ProveIt synthesis \cite{Repo} studies the failure of least Turing-degree
representatives in coarse equivalence classes. Its final subsection, ``What is
not settled'', specifically asks which countable ideals can occur as cores and
which upward-closed sets of degrees can occur as representative spectra. We
answer the first question completely and give a family of exact constructions
for the second. The repository was inspected at commit
\shortrepo; the full commit identifier and source path appear in
Appendix~\ref{cr12:app:sources}.

The distinction between these two questions is fundamental. The core records
what \emph{every} description can compute. The spectrum records which oracles
can produce \emph{some} description. A lower bound common to all descriptions
need not itself produce a description. A principal core is therefore not a
certificate of a least representative. The repository already demonstrates
this for every principal ideal \cite{Repo}; we do not count that observation as
a new result.

\mergenote{The synthesis is not the only place the question appears. At the same
pinned commit the programme's research plan \cite{Plan} lists it as target~C4,
``Is every countable Turing ideal a core?'', rated ``V: proof sketch supplied;
novelty unchecked''. Its Proposition (proposed) uses the column code
$X(2^k(2t+1)-1)=\Jcode(A_k)(t)$, which is the shorter code of
Remark~\ref{cr12:rem:shortcode} below, and its sketch is the two-inclusion argument
of Theorem~\ref{cr12:thm:realize} with the robust radius taken from the synthesis.
None of the three sources cites the plan. The plan's C4 tasks are addressed here
as follows: the sketch is checked (Theorem~\ref{cr12:thm:realize}, and
independently in Parts~II and~III); the literature search finds the antecedent
\cite[Lemma~3.10 and Theorem~3.11]{HJS} (Section~\ref{cr12:sec:earlier}); for which
sequences the class has a least degree is decided for the code $X_{\vec A}$ by
Theorem~\ref{cr12:thm:rows} with Corollary~\ref{cr12:cor:infimum}; and the uniform core
defined with a single functional is trivial
(Proposition~\ref{cr12:ep:prop:uniform-core}).}

Gerdes's Question~7 \cite{Gerdes} places least representatives and spectral
classification in a broader comparison of robust reducibilities. The present
paper concerns binary coarse descriptions, where erroneous values are allowed
on a density-zero set. It does not silently transfer its constructions to
error-free partial descriptions.

\subsection{Four statements proved here}
The central results are the following, with all notation defined in the next
section.

\paragraph{Realization.}
For every countable Turing ideal $\I$ there is a binary set $X$ with
$\Core(X)=\I$. The construction works from any sequence of generators and gives
$X\eqT\joinvec A_i$ for that presentation
(Theorem~\ref{cr12:thm:realize}). Since every core is a countable ideal, this is an
exact classification of the possible cores.

\paragraph{Presentation-sensitive spectra.}
For our code $X_{\vec A}$, an oracle $B$ computes a coarse description exactly
when it computes a total binary array $f(i,s,n)$ satisfying
\[
 (\forall i)(\exists s_i)(\forall s\ge s_i)(\forall n)\quad
 f(i,s,n)=A_i(n).
\]
The stabilization is uniform over the entire real in each fixed row, but the
threshold need not be uniform over the rows (Theorem~\ref{cr12:thm:rows}). A concrete
example explains why the ideal alone cannot determine this spectrum.

\paragraph{Preserving the core while changing the spectrum.}
For arbitrary $X,H$, the operation $T_X(H)=X\oplus\Rcode(H)$ preserves
$\Core(X)$ and intersects its spectrum with the jump cone determined by $H$
(Theorem~\ref{cr12:thm:filter}). This is a special case of a general invariance theorem
for joins with sets of coarse computability bound $1$
(Theorem~\ref{cr12:thm:neutral}).

\paragraph{Universality within a fixed core.}
For $H,K\geT X'$,
\[
 H\leT K
 \quad\Longleftrightarrow\quad
 T_X(H)\leuc T_X(K)
 \quad\Longleftrightarrow\quad
 T_X(H)\lenc T_X(K).
\]
The induced maps preserve binary joins. Thus an entire Turing upper cone lives
above every coarse degree without changing its core
(Theorem~\ref{cr12:thm:embedding}). This is stronger than producing a pair of
inequivalent examples with the same common information.

\subsection{What comes from earlier work}\label{cr12:sec:earlier}
The cone-avoiding compactness theorem of Hirschfeldt, Jockusch, Kuyper, and
Schupp \cite[Theorem~3.7]{HJKS} is the source of the robust-radius principle
used here. The prefix-density proof in Section~\ref{cr12:sec:radius} follows the
locality approach in the repository synthesis \cite{Repo}. The classical dyadic
coarse-computability criterion is due to Jockusch and Schupp
\cite[Theorem~2.19]{JS}; we use its relativization and give the proof.

The positive-density column construction is not new. Hirschfeldt, Jockusch,
and Schupp \cite[Lemma~3.10 and Theorem~3.11]{HJS} use columns of robust codes of
the members of a countable ideal, together with finite-column truncations, in
studying closed subspaces of the density metric. Our exact core identity follows
by combining that mechanism with the radius principle. The repeated robust code
used for the sharper spectrum statement is a variant of the uniform coarsenings
in \cite[Section~2]{HJKS}; compare also the robust coding framework in
\cite{DI}.

Accordingly, the ideal-realization theorem should be understood as a precise
resolution of the repository's stated target from established ingredients,
not as evidence that a difficult published open problem had escaped all previous
methods. The whole-row characterization and fixed-core structural theorems are
proved as research extensions here. Their global novelty would require a more
exhaustive literature review than the targeted source check performed for this
manuscript.

\subsection{How this report is assembled}\label{cr12:sec:assembly}
\mergenote{This subsection and the next were written for the merge.}
This report merges three manuscripts delivered together in batch~37 of
ProveIt's intake (manuscripts 12, 08 and 10 of that batch), all written against
ProveIt commit \path{1a1396d4d3a2ac6812692df520517d86ba3a4785} and all dated
28 September 2026. They share one spine:
\begin{enumerate}[label=(\roman*)]
\item every countable Turing ideal is the core of a binary set;
\item joining the dyadic code $\Rcode(H)$ keeps the core and cuts the spectrum
 by the jump cone of $H$;
\item relativized Friedberg inversion turns (ii) into an order embedding of a
 Turing upper cone into a single core fiber, for both $\leuc$ and $\lenc$.
\end{enumerate}
\textbf{Part~I} (Sections~\ref{cr12:sec:intro}--\ref{cr12:sec:questions} and
Appendices~\ref{cr12:app:audit}--\ref{cr12:app:sources}) is source~12, the base.
It is the most general of the three: its core-neutrality theorem
(Theorem~\ref{cr12:thm:neutral}) and embedding theorem
(Theorem~\ref{cr12:thm:embedding}) hold for an \emph{arbitrary} base set $X$, where
sources 08 and 10 prove the analogues only for their own carriers; it accepts an
arbitrary generator sequence, where source 10 needs an increasing cofinal chain;
it alone has the exact whole-row spectrum (Theorem~\ref{cr12:thm:rows}) and the
fiber cofinality result (Corollary~\ref{cr12:cor:cofinal}); and it proves the robust
radius (Theorem~\ref{cr12:thm:radius}) instead of importing it.
\textbf{Part~II} (Sections~\ref{cr12:ep:sec:scope}--\ref{cr12:ep:sec:questions}) is
source~08, and \textbf{Part~III}
(Sections~\ref{cr12:lr:sec:intro}--\ref{cr12:lr:sec:questions}) is source~10. Each
part keeps its own code and its own hypotheses. Appendix~\ref{cr12:app:provenance}
records what each source contributed and where the merge had to choose.

The three sources realize an ideal by three \emph{different} codes, so the
classification (i) is proved here four times:
\begin{enumerate}[label=(\alph*)]
\item by the robust radius, proved from Baire category
 (Theorem~\ref{cr12:thm:realize}, source 12);
\item by cone-avoiding compactness \cite[Theorem~3.7]{HJKS} used as a published
 black box (Section~\ref{cr12:ep:subsec:compactness}, source 08;
 Section~\ref{cr12:lr:sec:realization}, source 10);
\item by row-finite finite-extension forcing, which yields a perfect family of
 pairwise exact descriptions with jump control (Section~\ref{cr12:ep:sec:realization},
 source 08);
\item by ideal-protected fusion, which yields a perfect family of pairwise exact
 descriptions close in the prefix metric (Section~\ref{cr12:lr:sec:fusion}, source 10).
\end{enumerate}
Routes (c) and (d) use neither the Baire category theorem on $\CD(X)$ nor
\cite[Theorem~3.7]{HJKS}. Statements proved in more than one source (the
elementary properties of cores and spectra, the column estimates, the limit
lemma, the dyadic criterion, uniform dyadic transport, and relative jump
inversion) are printed once, in Part~I, with a merge note naming the other
sources; where their proofs coincide in substance they are not repeated.
Source~10's embedding theorem is a special case of
Theorem~\ref{cr12:thm:embedding} and is stated as such in
Section~\ref{cr12:lr:sec:embedding}. Source 08's embedding
(Theorem~\ref{cr12:ep:thm:embedding}) is a different construction, with the parameter
in rows inside the code, and is printed in full with its own proofs; a merge
observation (Remark~\ref{cr12:ep:rem:filtercompare}) shows that its classes coincide,
up to uniform coarse equivalence, with those of Theorem~\ref{cr12:thm:embedding} for
$X=\QQ(\vec A)$.

\paragraph{Formal status.} Nothing in this report is formalized. The ProveIt Lean

\section{Descriptions, spectra, and common lower bounds}\label{cr12:sec:basic}
\subsection{Conventions}
We work in classical mathematics (ZFC) with standard oracle Turing machines.
We identify a set of natural numbers with its characteristic function. Write
$A\leT B$ for Turing reducibility, $A'$ for the Turing jump, and
$\degT(A)$ for the Turing degree of $A$. Binary join means
\[
 (A\oplus B)(2n)=A(n),\qquad (A\oplus B)(2n+1)=B(n).
\]
An infinite join uses a fixed computable pairing function. Different standard
pairings give uniformly Turing-equivalent encodings.

For $n\ge1$ and $E\subseteq\N$, put
\[
 \rho_n(E)=\frac{|E\cap[0,n)|}{n},\qquad
 \Dens(E)=\limsup_{n\to\infty}\rho_n(E),\qquad
 \delta(X,Y)=\Dens(X\sd Y).
\]
The pseudometric $\delta$ measures upper-density disagreement. We write
$X\approx Y$ when $\delta(X,Y)=0$, and
\[
 \CD(X)=\{D\in\Cantor:D\approx X\}.
\]
Every description in this paper is total and binary.

\begin{definition}
Write $X\lenc Y$ if every $D\in\CD(Y)$ computes some member of $\CD(X)$.
Write $X\leuc Y$ if a single Turing functional maps every member of $\CD(Y)$
to a member of $\CD(X)$. The corresponding equivalence relations are denoted
$\eqnc$ and $\equc$.

Set
\[
 \Spec(X)=\{\degT(B):(\exists D\leT B)\ D\in\CD(X)\},
 \qquad
 \Core(X)=\bigcap_{D\in\CD(X)}\Low(D),
\]
where $\Low(D)=\{A:A\leT D\}$.
\end{definition}

We use ideals of \emph{sets}: a Turing ideal is a nonempty collection closed
under Turing reducibility and binary join. It is automatically saturated under
Turing equivalence. Equivalently, one can work with its collection of degrees.
Countability has the same meaning in either formulation, because a Turing degree
contains only countably many sets.

\begin{lemma}[Elementary properties]\label{cr12:lem:corebasic}
For every $X$, $\Core(X)$ is a countable Turing ideal. It is the common lower
cone of $\Spec(X)$:
\[
 A\in\Core(X)\quad\Longleftrightarrow\quad
 (\forall\mathbf b\in\Spec(X))\ \degT(A)\le\mathbf b.
\]
Both $\Core$ and $\Spec$ are invariants of nonuniform coarse equivalence,
and hence of uniform coarse equivalence.
\end{lemma}
\begin{proof}
Downward closure is immediate. If two sets are computable from every
$D\in\CD(X)$, their binary join is too. Every computable set belongs to the
intersection. Since $X\in\CD(X)$, the core is contained in the countable
collection $\Low(X)$.

If $B$ computes a description of $X$, every core member is below $B$. Conversely,
each description itself supplies a degree in the spectrum. This proves the
common-lower-cone identity. Equivalence preserves which oracles can compute a
description, by composition of Turing computations, and then preserves the core.
\end{proof}
\mergenote{Source 08 (its Lemma 2.2) and source 10 (its Proposition 2.3) prove the
first assertion by the same argument. Both add monotonicity: if $X\lenc Y$, then
$\Core(X)\subseteq\Core(Y)$. For $Z\in\Core(X)$ and $D\in\CD(Y)$ a reduction gives
some $E\leT D$ in $\CD(X)$, whence $Z\leT E\leT D$; no uniform choice of the
reduction index is required (source 08).}

\begin{proposition}[The three representative spectra]\label{cr12:prop:spectra}
$\Spec(X)$ is upward closed and equals each of
\[
 \{\degT(D):D\approx X\},\quad
 \{\degT(Y):Y\equc X\},\quad
 \{\degT(Y):Y\eqnc X\}.
\]
Furthermore,
\begin{equation}\label{cr12:eq:order-spectrum}
 X\lenc Y\quad\Longleftrightarrow\quad\Spec(Y)\subseteq\Spec(X).
\end{equation}
\end{proposition}
\begin{proof}
Suppose $D\approx X$ and $D\leT B$. On the computable density-zero set
$P=\{2^n:n\in\N\}$ replace $D(2^n)$ by $B(n)$, and leave all other positions
unchanged. The resulting $E$ satisfies $E\approx X$ and $E\eqT B$: $B$ computes
$E$ using its computation of $D$, while the values on $P$ recover $B$.
This proves the first equality and upward closure. If $E\approx X$, the identity
functional gives reductions in both coarse directions, since
$\CD(E)=\CD(X)$.

If $Y\eqnc X$, applying $X\lenc Y$ to $Y$ itself shows that $Y$ computes a
description of $X$. This proves the remaining equalities. Finally, the forward
implication of \eqref{cr12:eq:order-spectrum} follows by composition. For the reverse,
a description $D$ of $Y$ has degree in $\Spec(Y)$, so the assumed inclusion
says exactly that $D$ computes a description of $X$.
\end{proof}
\mergenote{Source 08 (Lemma 2.3) and source 10 (Lemma 2.1) prove the same identities by
the same sparse coding on $\{2^n\}$. Source 08 adds that the common lower bounds of
the spectrum are exactly $\Core(X)$ (Lemma~\ref{cr12:lem:corebasic}); source 10
states \eqref{cr12:eq:order-spectrum} and
$\Core(X)=\bigcap_{\mathbf d\in\Spec(X)}\{A:\degT(A)\le\mathbf d\}$ in the same
lemma. The sparse-coding step is formalized, with markers $\{2^k-1\}$
(\texttt{exists\_description\_of\_degree}; Section~\ref{cr12:sec:assembly}).}

This proposition, including sparse degree coding, is background already present
in \cite{Repo}. The reversal of inclusion in \eqref{cr12:eq:order-spectrum} is worth
noting: a more difficult coarse problem has fewer solving degrees.

\begin{proposition}[Binary joins]\label{cr12:prop:joins}
For all $X,Y$,
\begin{equation}\label{cr12:eq:join-spectrum}
 \Spec(X\oplus Y)=\Spec(X)\cap\Spec(Y).
\end{equation}
Binary join is the least upper bound for both coarse reducibilities.
Moreover,
\begin{equation}\label{cr12:eq:join-distance}
 \delta(X\oplus Y,U\oplus V)
 \le\tfrac12\delta(X,U)+\tfrac12\delta(Y,V).
\end{equation}
The upper-density error of either half is at most twice the error of the join.
\end{proposition}
\begin{proof}
At a prefix of even length $2n$, the error count is the sum of the two length-$n$
error counts. Odd endpoints change the fractions by a quantity tending to zero.
This proves the density statements. Splitting a description gives descriptions
of both halves; conversely, joining two descriptions gives a description of the
join. These operations are uniform. The spectrum equality follows, allowing the
two reductions from a fixed solving oracle to have different indices.
\end{proof}
\mergenote{Source 10 (Lemma 2.2) proves the spectrum identity and the least-upper-bound
property in the same way. It notes that only two computations are combined, so no
question of uniformity over an infinite sequence arises, and it also records that
$X\lenc Y$ implies $\Core(X)\subseteq\Core(Y)$.}

\begin{corollary}[Infimum versus least element]\label{cr12:cor:infimum}
$\Spec(X)$ has an infimum in the full partial order of Turing degrees if and
only if $\Core(X)$ is principal. If $\Core(X)=\Low(A)$, that infimum is
$\degT(A)$. It is a least element precisely when
$\degT(A)\in\Spec(X)$.
\end{corollary}
\begin{proof}
By Lemma~\ref{cr12:lem:corebasic}, the degrees of the core are exactly all the lower
bounds of the spectrum. They have a greatest member exactly when the ideal is
principal. A greatest lower bound is a least member precisely when it belongs
to the spectrum itself.
\end{proof}
\mergenote{Source 08 (Corollary 2.4) states the same: a least member of $\Spec(X)$ exists
if and only if the core is principal and its generator belongs to the spectrum.
Source 10 proves the direction used in its no-least arguments as
Lemma~\ref{cr12:lr:lem:least}.}

\section{A locality theorem for common information}\label{cr12:sec:radius}
The following theorem is an equivalent form of the cone-avoiding compactness
principle in \cite[Theorem~3.7]{HJKS}. We include a proof to expose exactly where
nonuniform finite information enters. The prefix-metric approach is developed
in the repository's category section \cite{Repo}.

\begin{theorem}[Robust radius]\label{cr12:thm:radius}
For all $A,X\subseteq\N$,
\begin{equation}\label{cr12:eq:radius}
 A\in\Core(X)
 \quad\Longleftrightarrow\quad
 (\exists\eta>0)(\forall Y\in\Cantor)
 \bigl[\delta(X,Y)<\eta\ \Longrightarrow\ A\leT Y\bigr].
\end{equation}
\end{theorem}

\subsection{The complete metric used in the proof}
The pseudometric $\delta$ vanishes throughout $\CD(X)$, so it cannot be used for
Baire category on that space. Instead put
\[
 d(U,V)=\sup_{n\ge1}\rho_n(U\sd V).
\]
This is a genuine metric. It controls short prefixes as well as asymptotic
behavior, and $\delta(U,V)\le d(U,V)$.

\begin{lemma}\label{cr12:lem:metric}
The metric space $(\CD(X),d)$ is nonempty and complete. Every finite-prefix
cylinder is open in it. If $\delta(Y,Z)<a$, there is a finite modification
$\widetilde Y$ of $Y$ with $d(\widetilde Y,Z)<a$.
\end{lemma}
\begin{proof}
A disagreement at position $k$ forces $d(U,V)\ge1/(k+1)$, which proves both
separation and openness of cylinders. The triangle inequality follows from the
corresponding inequality for error counts at each prefix.

Let $(D_j)$ be $d$-Cauchy in $\CD(X)$. Each coordinate eventually stabilizes;
call the coordinatewise limit $D$. For a given $\varepsilon>0$, choose $j_0$ so
that $d(D_j,D_k)<\varepsilon/2$ whenever $j,k\ge j_0$. Fix $j\ge j_0$ and a
prefix length $n$. Taking $k$ sufficiently large that $D_k\rest n=D\rest n$
gives $\rho_n(D_j\sd D)<\varepsilon/2$. Consequently
$d(D_j,D)\le\varepsilon/2$, and $D_j\to D$ in $d$.
Since
\[
 \delta(D,X)\le d(D,D_j)+\delta(D_j,X)=d(D,D_j),
\]
we have $D\in\CD(X)$. Nonemptiness follows from $X\in\CD(X)$.

Finally choose $a'$ strictly between $\delta(Y,Z)$ and $a$. For all sufficiently
large $n$, $\rho_n(Y\sd Z)<a'$. Replace the corresponding finite initial
segment of $Y$ by that of $Z$. The new error count is zero at short prefixes
and no larger than the old error count at long prefixes. The resulting distance
is at most $a'<a$.
\end{proof}

The finite modification in the last paragraph is Turing equivalent to $Y$.
Its finite values and its length can be incorporated as constants into a
program. No effective procedure for finding those constants is asserted.

For a string $\tau$ and a set $Z$, let $\tau\patch Z$ agree with $\tau$ below
$|\tau|$ and with $Z$ afterwards. Then
\begin{equation}\label{cr12:eq:patch}
 d(\tau\patch Z,Z)=
 \max_{1\le m\le|\tau|}
 \frac{|\{j<m:\tau(j)\ne Z(j)\}|}{m},
\end{equation}
with the empty maximum interpreted as $0$. Beyond the end of the string the
numerator is fixed and the denominator only increases.

\subsection{Decoding from a neighborhood}
Fix a standard enumeration $(\Phi_e)$ of oracle programs, and define
\[
 S_{e,A}=\{D\in\CD(X):\Phi_e^D\text{ is total and equals }A\}.
\]
For a finite oracle string, a halting computation is accepted only when every
oracle query lies within that string.

\begin{lemma}[Local decoder]\label{cr12:lem:decoder}
Suppose $S_{e,A}$ is dense in a nonempty $d$-ball $B_d(Z,r)$ inside $\CD(X)$,
where $r>0$ is rational. Every $Y\in\Cantor$ satisfying $d(Y,Z)<r/4$ computes
$A$. A decoding program can be chosen using only $e$ and $r$, not the center $Z$.
\end{lemma}
\begin{proof}
On input $n$, search for a finite string $\tau$ such that $\Phi_e^\tau(n)$
halts and
\begin{equation}\label{cr12:eq:search}
 \max_{1\le m\le|\tau|}
 \frac{|\{j<m:\tau(j)\ne Y(j)\}|}{m}<r/2.
\end{equation}
Dovetail the halting tests. The displayed condition is a finite rational test
computable from $Y$. Output the value of the first successful computation.

The search terminates. Density supplies
$D_*\in S_{e,A}\cap B_d(Z,r/4)$, so $d(D_*,Y)<r/2$. A sufficiently long prefix
of $D_*$ witnesses the search condition and the halting computation at $n$.

Every accepted value is correct. For an accepted $\tau$, put
$H=\tau\patch Z$. It belongs to $\CD(X)$ because it is a finite modification
of $Z$. At prefixes of length at most $|\tau|$, the error against $Z$ is less
than $r/2+r/4$. By \eqref{cr12:eq:patch}, $H\in B_d(Z,r)$. The cylinder determined
by $\tau$, intersected with this ball, is therefore a nonempty open set.
It contains a member of $S_{e,A}$. On that member the same finite computation
must output $A(n)$, so the accepted output is $A(n)$.
\end{proof}

\begin{proof}[Proof of Theorem~\ref{cr12:thm:radius}]
The right-to-left direction holds because every coarse description has distance
zero from $X$. Conversely, let $A\in\Core(X)$. Then
$\CD(X)=\bigcup_e S_{e,A}$. The Baire category theorem and
Lemma~\ref{cr12:lem:metric} imply that some $S_{e,A}$ is not nowhere dense.
Thus its closure contains a nonempty ball $B_d(Z,r)$ with rational $r>0$,
and it is dense in that ball.

Let $\eta=r/4$, and suppose $\delta(X,Y)<\eta$. As $Z\approx X$,
$\delta(Y,Z)<\eta$. By the finite-patch part of Lemma~\ref{cr12:lem:metric}, a finite
modification $\widetilde Y\eqT Y$ satisfies $d(\widetilde Y,Z)<r/4$.
Lemma~\ref{cr12:lem:decoder} yields $A\leT\widetilde Y\eqT Y$.
\end{proof}

\begin{corollary}[Finite-stage capture]\label{cr12:cor:capture}
If $\delta(X,X_k)\to0$ and $X_k\leT B_k$ for every $k$, then
\[
 \Core(X)\subseteq\bigcup_k\Low(B_k).
\]
Indeed every member of the core is below $B_k$ for all sufficiently large $k$.
\end{corollary}
\begin{proof}
Choose the radius in Theorem~\ref{cr12:thm:radius} for a fixed core member and use
convergence. No effective rate and no uniform list of the reductions
$X_k\leT B_k$ are needed.
\end{proof}
\mergenote{Sources 08 and 10 do not prove Theorem~\ref{cr12:thm:radius}. Both use
\cite[Theorem~3.7]{HJKS} as a published black box
(Theorems~\ref{cr12:ep:thm:HJKS} and~\ref{cr12:lr:thm:compactness}); source 10 obtains
\eqref{cr12:eq:radius} as its contrapositive, noting that strict and non-strict error
tolerances are interchangeable after shrinking a positive radius. Source 10's
ideal approximation lemma (Lemma~\ref{cr12:lr:lem:idealapprox}) is the ideal-valued
form of Corollary~\ref{cr12:cor:capture}: if a Turing ideal contains sets
arbitrarily close to $X$ in $\delta$, it contains $\Core(X)$.}

This is the locality principle behind ideal realization: information common to
all exact coarse descriptions is already unavoidable at some positive error
scale. It can therefore be captured by a sufficiently accurate finite-stage
approximation.

\section{Coding geometry and a uniform robust code}\label{cr12:sec:codes}
\subsection{A partition with computably small tails}
Define
\begin{equation}\label{cr12:eq:pairing}
 p(i,m)=2^i(2m+1)-1,
 \qquad C_i=\{p(i,m):m\in\N\}.
\end{equation}
Every $n\in\N$ lies in exactly one column, whose index is $\nu_2(n+1)$.
Here $\nu_2(t)$ is the exponent of $2$ dividing the positive integer $t$.
The density of $C_i$ is $2^{-i-1}$.

\begin{lemma}[Column estimates]\label{cr12:lem:columns}
Let $T_k=\bigcup_{i\ge k}C_i$. Then
\begin{equation}\label{cr12:eq:tail}
 T_k=\{n:2^k\mid n+1\},\qquad
 |T_k\cap[0,N)|=\left\lfloor\frac{N}{2^k}\right\rfloor.
\end{equation}
If $E$ has density zero, then
$E_i=\{m:p(i,m)\in E\}$ has density zero for every $i$.
Conversely, if every $E_i$ has density zero, then $E$ has density zero.
In particular, a set meeting each column in only finitely many positions has
density zero.
\end{lemma}
\begin{proof}
The first assertions follow by factoring $n+1$. For the forward density
implication, the first $M$ positions of $C_i$ lie below $2^{i+1}M$, so
\[
 \frac{|E_i\cap[0,M)|}{M}
 \le 2^{i+1}\rho_{2^{i+1}M}(E)\longrightarrow0.
\]
For the reverse implication, fix $k$. On each of the finitely many columns
$i<k$, the count of errors below $N$ is $o(N)$, because the number of positions
of that column below $N$ is asymptotic to $2^{-i-1}N$. The remaining errors lie
in $T_k$. Hence
\[
 \limsup_N\rho_N(E)\le2^{-k}.
\]
Now let $k\to\infty$.
\end{proof}
\mergenote{Source 08 adds the exact column count
$|C_n\cap[0,N)|=\lfloor(N+2^n)/2^{n+1}\rfloor$ (equation~\eqref{cr12:ep:eq:counts}),
and source 10 the quantitative restriction bound
$\delta(X_n,D_n)\le2^{n+1}\delta(X,D)$ (Lemma~\ref{cr12:lr:lem:columns}). The tail
count, the bounded-column criterion and the restriction of density-zero errors to a
column are formalized as \texttt{card\_tail}, \texttt{densityZero\_of\_bounded\_columns}
and \texttt{errCnt\_div\_tendsto} (Section~\ref{cr12:sec:assembly}).}

The last argument is a finite-head/small-tail argument, not an appeal to closure
of density-zero sets under arbitrary countable unions. Such closure is false.
It is the uniform tail bound \eqref{cr12:eq:tail} that makes this particular
countable assembly safe.

\subsection{Three different codes}
We need to distinguish three operations. The dyadic repetition code is
\begin{equation}\label{cr12:eq:R}
 \Rcode(A)(p(i,m))=A(i).
\end{equation}
Its decoding from a coarse description generally costs a jump. In contrast,
write
\begin{equation}\label{cr12:eq:J}
 \Jcode(B)(0)=0,\qquad
 \Jcode(B)(t)=B(\lfloor\log_2 t\rfloor)\quad(t\ge1).
\end{equation}
Thus $B(k)$ is repeated on the entire interval $[2^k,2^{k+1})$.
Finally define
\begin{equation}\label{cr12:eq:E}
 \Ecode(A)=\Jcode(\Rcode(A)).
\end{equation}
All three exact codes are uniformly Turing equivalent to their inputs. The
composition in \eqref{cr12:eq:E} provides the stronger decoding property required
for our spectrum theorem.

\begin{lemma}[Block majority]\label{cr12:lem:majority}
For a binary oracle $D$, let $M_D(k)$ be the majority bit of $D$ on
$[2^k,2^{k+1})$, with ties assigned $0$. If $D\approx\Jcode(B)$, then
$M_D(k)=B(k)$ for all sufficiently large $k$.
\end{lemma}
\begin{proof}
A wrong majority on a block of length $2^k$ requires at least $2^{k-1}$ errors
on that block. Therefore
\[
 M_D(k)\ne B(k)\quad\Longrightarrow\quad
 \rho_{2^{k+1}}(D\sd\Jcode(B))\ge\tfrac14.
\]
The implication remains valid for $k=0$, where any wrong bit gives an even
larger error fraction. Infinitely many wrong block majorities would contradict
density-zero disagreement.
\end{proof}
\mergenote{The consequence that every coarse description of $\Jcode(B)$ computes $B$ is
\texttt{blockCode\_decode} in the Lean library, whose \texttt{blockCode} is exactly
$\Jcode$. Sources 08 and 10 prove majority lemmas for their own block codes:
Lemma~\ref{cr12:ep:lem:majority} for $\Jsh$ (error fraction above $1/4$ at the block
endpoint $2^{k+1}-1$) and Lemma~\ref{cr12:lr:lem:robust} for $\Jfac$ (recovery from
every $D$ with $\delta(D,\Jfac(A))<1/2$).}

\begin{proposition}[Whole-real recovery in the limit]\label{cr12:prop:robust}
There is a single oracle-computable procedure which, from any
$D\in\CD(\Ecode(A))$, produces a total binary function $F_D(s,n)$ with
\begin{equation}\label{cr12:eq:uniform-coarsening}
 (\exists s_0)(\forall s\ge s_0)(\forall n)\quad F_D(s,n)=A(n).
\end{equation}
In particular, every coarse description of $\Ecode(A)$ computes $A$.
\end{proposition}
\begin{proof}
Set
\[
 F_D(s,n)=M_D(p(n,s)).
\]
By Lemma~\ref{cr12:lem:majority}, there is a $K$ such that
$M_D(k)=\Rcode(A)(k)$ whenever $k\ge K$. Since $p(n,s)\ge s$ for every
$n,s$, all $s\ge K$ satisfy
\[
 F_D(s,n)=\Rcode(A)(p(n,s))=A(n)
 \quad\text{for every }n.
\]
This proves \eqref{cr12:eq:uniform-coarsening}. To obtain an individual Turing
reduction of $A$ to $D$, use one such stable $s$ as a fixed program constant.
\end{proof}

\begin{remark}[What is uniform, and what is not]\label{cr12:rem:uniform}
The procedure computing the entire two-variable array $F_D$ is uniform in $D$.
Selecting a stable row is not asserted to be uniform. Confusing these two claims
would invalidate later arguments. A single output real computed uniformly from
all descriptions is a stronger demand than the uniform array in
\eqref{cr12:eq:uniform-coarsening}.
\end{remark}

The repeated-code method is a concrete instance of uniform coarsening as used
in \cite[Definition~2.1 and Proposition~2.3]{HJKS}. The choice of exponentially
sized blocks rather than another standard rapidly growing partition affects
neither the conclusions nor the underlying computability notion.

\section{Realizing exactly the countable Turing ideals}\label{cr12:sec:ideals}
For a sequence $\vec A=(A_i)_{i\in\N}$, define
\begin{equation}\label{cr12:eq:idealcode}
 X_{\vec A}(p(i,m))=\Ecode(A_i)(m),
 \qquad
 \I_{\vec A}=\bigcup_{k\in\N}
 \Low\!\left(\bigoplus_{i<k}A_i\right).
\end{equation}
The empty finite join is computable. No computability assumption is placed on
the sequence of inputs; $\joinvec A_i$ is the oracle presenting that sequence.

\begin{theorem}[Ideal realization]\label{cr12:thm:realize}
For every sequence $\vec A$,
\begin{equation}\label{cr12:eq:realize}
 \Core(X_{\vec A})=\I_{\vec A},
 \qquad X_{\vec A}\eqT\joinvec A_i.
\end{equation}
Consequently the cores of binary sets are exactly the countable Turing ideals.
\end{theorem}
\begin{proof}
Let $D\approx X_{\vec A}$ and define the $i$th column oracle by
$D_i(m)=D(p(i,m))$. By Lemma~\ref{cr12:lem:columns},
$D_i\approx\Ecode(A_i)$. Proposition~\ref{cr12:prop:robust} gives $A_i\leT D_i\leT D$.
Thus every finite join of the $A_i$ is computable from $D$, and so is every
member of $\I_{\vec A}$. This proves
$\I_{\vec A}\subseteq\Core(X_{\vec A})$.

For the opposite inclusion let $X_{<k}$ agree with $X_{\vec A}$ on columns
$i<k$ and be zero on all later columns. Then
\[
 X_{<k}\leT\bigoplus_{i<k}A_i,
 \qquad
 \delta(X_{<k},X_{\vec A})\le2^{-k}
\]
by \eqref{cr12:eq:tail}. Corollary~\ref{cr12:cor:capture} now gives the desired reverse
inclusion. This is the step excluding information accidentally encoded across
infinitely many columns from becoming common to \emph{all} coarse descriptions.

The infinite join uniformly computes $X_{\vec A}$ by evaluating the codes.
In the other direction, $X_{\vec A}$ uniformly supplies each exact oracle
$\Ecode(A_i)$, and each $A_i(n)$ can be read at a computably specified position
of that exact code. For example,
\[
 A_i(n)=X_{\vec A}\bigl(p(i,2^{p(n,0)})\bigr).
\]
Hence the exact code computes the entire presentation, proving the Turing
 equivalence in \eqref{cr12:eq:realize}.

Finally let $\I$ be a countable Turing ideal and enumerate its members as
$(B_i)$. Take $A_i=\bigoplus_{j\le i}B_j$. These sets generate exactly $\I$,
so the construction realizes it. Conversely every core is a countable Turing
ideal by Lemma~\ref{cr12:lem:corebasic}.
\end{proof}
\mergenote{The classification in Theorem~\ref{cr12:thm:realize} is target~C4 of the
research plan \cite{Plan}, proposed there with essentially this proof sketch for the
shorter code of Remark~\ref{cr12:rem:shortcode}, and its column mechanism is
\cite[Lemma~3.10 and Theorem~3.11]{HJS}. The same classification is proved in
Part~II for source 08's code $\QQ(\vec A)$, by row-finite forcing
(Theorem~\ref{cr12:ep:thm:headline-core}) and from \cite[Theorem~3.7]{HJKS}
(Section~\ref{cr12:ep:subsec:compactness}), and in Part~III for source 10's layered
carrier $\Lam$, from \cite[Theorem~3.7]{HJKS} (Theorem~\ref{cr12:lr:thm:mainreal}) and
by ideal-protected fusion (Theorem~\ref{cr12:lr:thm:fusion}). Neither source 08 nor
source 10 cites \cite{HJS}; that antecedent bears on their column constructions as
well.}

\begin{remark}[A shorter code suffices for the core alone]\label{cr12:rem:shortcode}
Replacing $\Ecode(A_i)$ by $\Jcode(A_i)$ in \eqref{cr12:eq:idealcode} gives the same
core identity: block majority recovers $A_i$ modulo finitely many bits, and
those bits can be supplied as finite constants. This is closely aligned with
the coding construction in \cite[Theorem~3.11]{HJS}. We use $\Ecode$ because
its uniform approximation by whole reals also yields the exact spectrum in the
next section. The extra repetition is not needed to solve the bare
core-realization problem.
\end{remark}

\subsection{Two examples and an effectivity boundary}
\begin{example}[A principal ideal]
For the constant sequence $A_i=A$, the exact presentation is Turing equivalent
to $A$. Theorem~\ref{cr12:thm:realize} gives core $\Low(A)$; since the code itself
has degree $\degT(A)$, that degree is the least member of its spectrum.
\end{example}

\begin{example}[Exactly the arithmetical sets]\label{cr12:ex:arith}
Let $A_i=\emptyset^{(i)}$, the $i$th finite jump. Then
\[
 \Core(X_{\vec A})=
 \bigcup_i\Low(\emptyset^{(i)}),\qquad
 X_{\vec A}\eqT\emptyset^{(\omega)}
 :=\joinvec\emptyset^{(i)}.
\]
The displayed ideal is not principal. If it had a greatest degree, that degree
would be below some finite jump, whereas the next jump is a strictly larger
member of the ideal. Thus the representative spectrum of $X_{\vec A}$ has
\emph{no infimum at all}, by Corollary~\ref{cr12:cor:infimum}.
Every description still computes every individual finite jump. It need not
compute their infinite join: such a claim would make $\emptyset^{(\omega)}$
a core member, contradicting the formula above.
\end{example}
\mergenote{Source 08 (Section~\ref{cr12:ep:subsec:arithmetic}) and source 10
(Example~\ref{cr12:lr:ex:arith}) treat the same ideal with their own codes and add
exact pairs: two descriptions of $\QQ(\vec A)$ whose common lower cone is the
arithmetical ideal and whose jumps are below $\emptyset^{(\omega)}$, and two
descriptions of $\Lam$ computable in $\Aplus'$ with the same common lower cone, at
least one of which does not compute $\Aplus$.}

The construction is uniform from a \emph{given presentation}; it does not
provide a computable enumeration of an arbitrary countable ideal. Nor does
countability make the choices of indices for the separate reductions
$A_i\leT D$ uniformly computable. These distinctions are precisely what the
spectrum calculation measures.

\section{An exact spectrum theorem for the ideal code}\label{cr12:sec:rows}
\subsection{Eventually correct whole rows}
\begin{definition}\label{cr12:def:row}
For a fixed sequence $\vec A$, let $\Row(\vec A)$ be the set of Turing degrees
$\mathbf b$ for which an oracle $B\in\mathbf b$ computes a total binary
function $f(i,s,n)$ satisfying
\begin{equation}\label{cr12:eq:row}
 (\forall i)(\exists s_i)(\forall s\ge s_i)(\forall n)\quad
 f(i,s,n)=A_i(n).
\end{equation}
\end{definition}
The degree property does not depend on the chosen representative $B$.
The parameter $s_i$ may depend arbitrarily on $i$. However, once $s\ge s_i$,
the \emph{entire} function $n\mapsto f(i,s,n)$ is correct; this is not merely
pointwise convergence as $s$ grows.

\begin{theorem}[Whole-row spectrum]\label{cr12:thm:rows}
For the code in \eqref{cr12:eq:idealcode},
\begin{equation}\label{cr12:eq:rowspec}
 \Spec(X_{\vec A})=\Row(\vec A).
\end{equation}
This is simultaneously the spectrum of the density-zero class, the uniform
coarse class, and the nonuniform coarse class of $X_{\vec A}$.
\end{theorem}
\begin{proof}
Suppose $B$ computes $D\approx X_{\vec A}$. The column oracles
$D_i(m)=D(p(i,m))$ are uniformly computable from $B$ and satisfy
$D_i\approx\Ecode(A_i)$. Apply the single array-producing procedure of
Proposition~\ref{cr12:prop:robust} on each column:
\[
 f(i,s,n)=M_{D_i}(p(n,s)).
\]
For each fixed $i$, only finitely many block majorities are wrong. The proof
of that proposition supplies a threshold $s_i$ valid for every $n$, so
\eqref{cr12:eq:row} holds.

Conversely assume $B$ computes such an $f$. Construct a total binary set $D$
columnwise. Put $D(p(i,0))=0$. At $m\ge1$, put
\begin{equation}\label{cr12:eq:rowdecode}
 D(p(i,m))=f\!\left(i,m,
       \nu_2\bigl(\lfloor\log_2m\rfloor+1\bigr)\right).
\end{equation}
Indeed the target bit is
\[
 \Ecode(A_i)(m)
 =\Rcode(A_i)(\lfloor\log_2m\rfloor)
 =A_i\!\left(\nu_2\bigl(\lfloor\log_2m\rfloor+1\bigr)\right).
\]
For fixed $i$, \eqref{cr12:eq:rowdecode} is therefore correct at every
$m\ge\max(1,s_i)$, and is also correct at $m=0$ by definition of $\Ecode$.
The error set is finite on each column. Lemma~\ref{cr12:lem:columns} gives
$D\approx X_{\vec A}$, and $D\leT B$ by construction.
The last sentence follows from Proposition~\ref{cr12:prop:spectra}.
\end{proof}

The theorem is an exact effective condition rather than a characterization
solely in terms of the generated ideal. It removes the density quantifiers
from membership in this particular spectrum and replaces them by a uniform
array with the specified stabilization property.

\begin{corollary}[Necessary information bounds]\label{cr12:cor:rowbounds}
Let $\Aplus=\joinvec A_i$. Then
\begin{equation}\label{cr12:eq:sandwich}
 \{\mathbf b:\Aplus\leT B\}
 \ \subseteq\ \Spec(X_{\vec A})
 \ \subseteq\
 \{\mathbf b:(\forall i)\ A_i\leT B\ \text{and}\ \Aplus\leT B'\}.
\end{equation}
\end{corollary}
\mergenote{Source 12 writes $S$ for $\Aplus$ here (Section~\ref{cr12:sec:notation}).}
\begin{proof}
The left inclusion follows either from $X_{\vec A}\eqT \Aplus$ or by taking
$f(i,s,n)=A_i(n)$. For the right inclusion, a stable row computes $A_i$ from
$B$ using its threshold as a constant. Also $f(i,s,n)$ is a $B$-computable
pointwise convergent approximation to the characteristic function of $\Aplus$,
so the relativized limit lemma gives $\Aplus\leT B'$. A proof of that limit lemma
is included in Section~\ref{cr12:sec:jump}.
\end{proof}

\subsection{Computable rows can have a nontrivial collective spectrum}
\begin{example}[The presentation itself carries information]\label{cr12:ex:constantrows}
Given any $H\subseteq\N$, let $A_i$ be the constant real with value $H(i)$.
Every $A_i$ is computable, so $\I_{\vec A}=\Comp$. Nevertheless
\begin{equation}\label{cr12:eq:constantrows}
 X_{\vec A}\approx\Rcode(H),\qquad
 \Spec(X_{\vec A})=\{\mathbf b:H\leT B'\}.
\end{equation}
To see the first assertion, $\Ecode(A_i)$ agrees with the constant real $A_i$
at all positions except possibly $0$. Hence discrepancies from $\Rcode(H)$
can occur only at $p(i,0)=2^i-1$, a density-zero set. The spectral assertion
is Theorem~\ref{cr12:thm:jump-spectrum} below.

Taking $H=\emptyset''$ makes the spectrum omit the computable degree, even
though every individual input row is computable. Replacing this presentation
by the constant zero presentation gives the same ideal $\Comp$ but a spectrum
containing every Turing degree. Thus the condition
$(\forall i)\ A_i\leT B$ is not a substitute for \eqref{cr12:eq:row}.
\end{example}
\mergenote{The same phenomenon for the other two codes: source 08
(Section~\ref{cr12:ep:subsec:presentation}) and source 10
(Proposition~\ref{cr12:lr:prop:noncanonical}) take $A_n$ constant with value $H(n)$.
Source 10's carrier then differs from $\Rcode(H)$ only on $\{2^n-1\}$, as here;
source 08's code is then exactly $\Rcode(H)$ (a merge observation: every row is
constant).}

This example is also a warning about the phrase ``uniformly computable
sequence''. A sequence all of whose entries are computable can encode an
arbitrarily complicated choice of those entries. Here that choice is exactly
$H$.

\section{The dyadic jump spectrum and uniform transport}\label{cr12:sec:jump}
This section gives the classical ingredients needed for the fixed-core
construction. They are not claimed as new: the basic dyadic criterion is the
relativization of \cite[Theorem~2.19]{JS}, and is also used in \cite{Repo,HJS}.

\begin{lemma}[Relativized limit lemma]\label{cr12:lem:limit}
$H\leT B'$ if and only if there is a total $B$-computable binary function
$h(i,s)$ such that $h(i,s)\to H(i)$ for every $i$.
\end{lemma}
\begin{proof}
For one direction, $B'$ can decide whether there exists a $t>s$ with
$h(i,t)\ne h(i,s)$, since this is a computably enumerable condition relative
to $B$. Search for a stage with no subsequent change and return its value.
The search terminates because the binary sequence converges.

For the other direction, approximate $B'$ by finite stages of its standard
$B$-computable enumeration. On input $(i,s)$, run the fixed reduction of $H(i)$
to $B'$ for $s$ steps, using that stage's finite approximation as the oracle.
Return its binary answer if it halts, and $0$ otherwise. The genuine halting
computation uses only finitely many oracle answers. Eventually all those
answers are correct and the time bound is long enough, so the simulation
returns $H(i)$ at all later stages.
\end{proof}
\mergenote{Source 08 (its Appendix~A) and source 10 (its Lemma 3.4) prove the same
lemma by the same argument. Source 08 notes that the proof is included to expose
both uniformity directions used in its spectrum factorization
(Theorem~\ref{cr12:ep:thm:factorization}).}

\begin{theorem}[Dyadic jump-cone criterion]\label{cr12:thm:jump-spectrum}
For every $H$,
\begin{equation}\label{cr12:eq:jumpspec}
 \Spec(\Rcode(H))=\{\mathbf b:H\leT B'\}.
\end{equation}
Moreover, for every $\varepsilon>0$ there is a computable $C$ such that
$\delta(\Rcode(H),C)<\varepsilon$.
\end{theorem}
\begin{proof}
Suppose $D\approx\Rcode(H)$ and $D\leT B$. On each column the errors have
density zero. Thus the majority of the first $s+1$ column values,
\[
 h(i,s)=\operatorname{Maj}\{D(p(i,0)),\ldots,D(p(i,s))\},
\]
is eventually $H(i)$. This is a total $B$-computable pointwise approximation,
so Lemma~\ref{cr12:lem:limit} gives $H\leT B'$.

Conversely, take the approximation $h$ supplied by that lemma and define
$D(p(i,m))=h(i,m)$. On each column $D$ differs from $\Rcode(H)$ at only
finitely many positions. The column lemma gives $D\approx\Rcode(H)$.

For the final claim, copy the finitely many bits $H(i)$ on columns $i<k$ and
put zero on columns $i\ge k$. The result $C_k$ is computable, because those
finitely many bits can be included as program constants, and
$\delta(C_k,\Rcode(H))\le2^{-k}$. Choose $k$ with $2^{-k}<\varepsilon$.
\end{proof}
\mergenote{Source 10 (its Theorem 3.5) proves the same criterion with the same proof
(majority of the first $s$ column entries, stage-zero majority $0$), citing
\cite[Theorem~2.19]{JS} for the unrelativized case and the synthesis for the
relativized spectrum formulation. Source 08 uses the constant-row case inside its
own code (Section~\ref{cr12:ep:sec:fibres}). In limit form the criterion and the
spectrum are formalized (\texttt{description\_iff\_limit}, \texttt{spectrum\_Rc});
Lemma~\ref{cr12:lem:limit} is not, since the Lean library has no jump operator.}

The last assertion does not say that the sequence of indices for $C_k$ is
computable independently of $H$. It also does not imply the existence of a
single computable coarse description. For example, when $H=\emptyset''$,
\eqref{cr12:eq:jumpspec} rules out such a description.

\begin{proposition}[Uniform transport along Turing reductions]\label{cr12:prop:transport}
If $H\leT K$, then $\Rcode(H)\leuc\Rcode(K)$. In addition,
\begin{equation}\label{cr12:eq:Rjoin}
 \Rcode(H\oplus K)\equc\Rcode(H)\oplus\Rcode(K).
\end{equation}
\end{proposition}
\begin{proof}
Let $D\approx\Rcode(K)$. Column majorities give, uniformly in $D$, a total
array $k(i,s)$ with pointwise limit $K(i)$. Fix an index for the reduction
$H\leT K$. At stage $s$ simulate that program on input $i$ for $s$ steps with
oracle $j\mapsto k(j,s)$; return $0$ if no binary answer is obtained. The
resulting $h(i,s)$ is total and converges to $H(i)$, because the true computation
has a finite halting trace. Now output $h(i,m)$ at $p(i,m)$. The converse
construction in Theorem~\ref{cr12:thm:jump-spectrum} shows this is a coarse description
of $\Rcode(H)$. Every step is one fixed oracle procedure once the reduction
index is fixed.

For \eqref{cr12:eq:Rjoin}, a description of the right side splits into descriptions
of $\Rcode(H)$ and $\Rcode(K)$. Their column-majority approximations can be
interleaved into one approximation to $H\oplus K$, and then converted into a
description of $\Rcode(H\oplus K)$. Conversely, the even and odd entries of a
pointwise approximation to $H\oplus K$ approximate $H$ and $K$. Applying the
same conversion to both arrays and joining the outputs proves the other uniform
reduction.
\end{proof}
\mergenote{Source 10 (its Lemma 3.6) proves the same monotonicity and join equivalence
by the same bounded simulation against pointwise approximations.}

\section{Changing a spectrum without changing its core}\label{cr12:sec:neutral}
\subsection{A general invariance principle}
\begin{definition}
A set $Y$ is \emph{approximable by computable sets in density distance} if
\begin{equation}\label{cr12:eq:approximable}
 (\forall\varepsilon>0)(\exists C\text{ computable})\quad
 \delta(Y,C)<\varepsilon.
\end{equation}
Equivalently, its coarse computability bound
$\gamma(Y)=1-\inf_{C\text{ computable}}\delta(Y,C)$ equals $1$.
\end{definition}

The fact that \eqref{cr12:eq:approximable} implies $\Core(Y)=\Comp$ is the theorem
credited to Igusa in \cite[Theorem~4.3]{HJKS}. The following statement establishes
invariance under adjoining $Y$ to an \emph{arbitrary} base problem.

\begin{theorem}[Core neutrality under joins]\label{cr12:thm:neutral}
If $Y$ satisfies \eqref{cr12:eq:approximable}, then for every $X$,
\begin{equation}\label{cr12:eq:neutral}
 \Core(X\oplus Y)=\Core(X).
\end{equation}
\end{theorem}
\begin{proof}
A description of $X\oplus Y$ computes a description of $X$ by taking its even
half, so $\Core(X)\subseteq\Core(X\oplus Y)$.

For the reverse inclusion let $A\in\Core(X\oplus Y)$ and take its radius
$\eta>0$ from Theorem~\ref{cr12:thm:radius}. Choose a computable $C$ with
$\delta(Y,C)<\eta/2$. If $\delta(X,U)<\eta/2$, then
\[
 \delta(X\oplus Y,U\oplus C)
 \le\tfrac12\delta(X,U)+\tfrac12\delta(Y,C)<\eta.
\]
The radius property yields $A\leT U\oplus C\eqT U$.
Thus $\eta/2$ is a robust radius witnessing $A\in\Core(X)$.
\end{proof}

This proof uses more than $\Core(Y)=\Comp$. It uses arbitrarily accurate
\emph{computable approximations} to $Y$. The theorem does not assert that every
trivial-core set is neutral under joins.

\subsection{An exact jump filter}
\begin{definition}
For a base set $X$ and a parameter $H$, put
\[
 T_X(H)=X\oplus\Rcode(H),\qquad
 \mathcal Q_H=\{\degT(B):H\leT B'\}.
\]
\end{definition}

\begin{theorem}[Core-preserving spectral filter]\label{cr12:thm:filter}
For all sets $X,H$,
\begin{align}
 \Core(T_X(H))&=\Core(X),\label{cr12:eq:filtercore}\\
 \Spec(T_X(H))&=\Spec(X)\cap\mathcal Q_H.\label{cr12:eq:filterspec}
\end{align}
Also $X\leuc T_X(H)$ and $T_X(H)\eqT X\oplus H$.
For every sequence $\vec A$ this specializes to
\begin{equation}\label{cr12:eq:combined}
 \Core(T_{X_{\vec A}}(H))=\I_{\vec A},\qquad
 \Spec(T_{X_{\vec A}}(H))=\Row(\vec A)\cap\mathcal Q_H.
\end{equation}
\end{theorem}
\begin{proof}
Theorem~\ref{cr12:thm:jump-spectrum} shows that $\Rcode(H)$ satisfies
\eqref{cr12:eq:approximable}; hence \eqref{cr12:eq:filtercore} follows from
Theorem~\ref{cr12:thm:neutral}. Equations \eqref{cr12:eq:join-spectrum} and
\eqref{cr12:eq:jumpspec} give \eqref{cr12:eq:filterspec}. Projection to the even half
is the asserted uniform reduction. The exact Turing equivalence follows from
$\Rcode(H)\eqT H$. Finally use Theorems~\ref{cr12:thm:realize} and~\ref{cr12:thm:rows}.
\end{proof}
\mergenote{For source 10's carrier, $T_{\Lam}(H)$ is source 10's $F_{\vec A,B}$, and
Theorem~\ref{cr12:lr:thm:insertion} states \eqref{cr12:eq:filtercore} and
\eqref{cr12:eq:filterspec} for it. Its proof is a second route: it approximates
$T_{\Lam}(H)$ by sets \emph{in the ideal} and applies the ideal approximation lemma
instead of core neutrality; a third proof comes from ideal-protected fusion
(Theorem~\ref{cr12:lr:thm:mainperfect}). Source 08 attaches the jump cone
differently, by constant rows inside its code
(Theorem~\ref{cr12:ep:thm:factorization}).}

The parameter $H$ can be arbitrarily complicated. Its effect is visible in
which jumps occur above solving degrees, while the intersection of their lower
cones stays fixed. Thus the entire common-information ideal can remain
unchanged under substantial increases in the difficulty of producing a coarse
description.

\begin{corollary}[Strict extensions and unattained infima]\label{cr12:cor:strict}
If $H\nleT X'$, then
\[
 X\leuc T_X(H),\qquad T_X(H)\not\lenc X,
\]
and $\Spec(T_X(H))$ has no least element. If
$\Core(X)=\Low(A)$, its infimum is $\degT(A)$ and is not attained.
If $\Core(X)$ is nonprincipal, its spectrum has no infimum.
\end{corollary}
\begin{proof}
The degree of $X$ belongs to $\Spec(X)$ but, by
\eqref{cr12:eq:filterspec}, not to $\Spec(T_X(H))$. Formula
\eqref{cr12:eq:order-spectrum} rules out $T_X(H)\lenc X$.

Suppose $\mathbf b$ were the least member of $\Spec(T_X(H))$.
Every representative of $\mathbf b$ would lie in the core of $T_X(H)$,
which equals $\Core(X)\subseteq\Low(X)$. Thus $\mathbf b\le\degT(X)$.
Membership in the filtered spectrum would give
$H\leT B'\leT X'$, a contradiction. The two infimum assertions now follow
from Corollary~\ref{cr12:cor:infimum} and \eqref{cr12:eq:filtercore}.
\end{proof}

For example, $H=X''$ always satisfies the hypothesis. This gives a strict
extension inside the same core above every base set $X$, not merely above the
special ideal codes.

\begin{example}[A transparent principal-core spectrum]\label{cr12:ex:principal-filter}
Take $X=\Ecode(A)$. Proposition~\ref{cr12:prop:robust} and the exact equivalence
$X\eqT A$ give $\Spec(X)=\{\mathbf b:A\leT B\}$. Consequently
\[
 \Core(\Ecode(A)\oplus\Rcode(H))=\Low(A),\qquad
 \Spec(\Ecode(A)\oplus\Rcode(H))
 =\{\mathbf b:A\leT B\ \text{and}\ H\leT B'\}.
\]
When $H\nleT A'$, the infimum is $\degT(A)$ and is unattained. The existence
of prescribed unattained infima is already in \cite{Repo}; the displayed
spectral formula is the useful additional information supplied by this form of
the construction.
\end{example}

\section{Turing-cone universality inside a fixed core}\label{cr12:sec:embedding}
\subsection{The classical inversion ingredient}
We include the relative jump-inversion argument to make the separation part
of the embedding theorem independent of any unproved construction in the
repository. This is the classical Friedberg jump-inversion method, not a new
inversion theorem. Its use in density-metric arguments is also discussed in
\cite[Section~3]{HJS}.

\begin{lemma}[Relative jump inversion]\label{cr12:lem:inversion}
If $K\geT X'$, there is a set $B\geT X$ such that $B'\eqT K$.
\end{lemma}
\begin{proof}
We construct a binary real $Y$ and put $B=X\oplus Y$. Start with the empty
string $\sigma_0$. Given $\sigma_e$, ask whether there is a finite extension
$\tau\supseteq\sigma_e$ such that
\[
 \Phi_e^{X\oplus\tau}(e)\downarrow,
\]
where every query to the $Y$-part must be answered within $\tau$.
This is a computably enumerable question relative to $X$, hence decidable
using $X'$. If the answer is yes, choose the first witness found by a fixed
$X$-effective dovetailed search. If the answer is no, put $\tau=\sigma_e$.
In either case set
\[
 \sigma_{e+1}=\tau\cat K(e).
\]
Let $Y=\bigcup_e\sigma_e$. Each stage adds at least one bit, so $Y$ is total.
The construction is computable from $K$, because $K$ computes $X'$ and $X$.

The answer to the stage-$e$ question is exactly the characteristic value
$B'(e)$. A yes answer fixes a finite halting computation forever. A no answer
excludes halting on every infinite continuation of $\sigma_e$. Thus $K$
computes $B'$ by reconstructing the stages, and $B'\leT K$.

To decode $K$ from $Y\oplus X'$, reconstruct the same sequence of stages.
At stage $e$, $X'$ determines the yes/no answer and the deterministic choice
of $\tau$. Then the next coding bit is $Y(|\tau|)=K(e)$. Hence
$K\leT Y\oplus X'$. Since $Y\leT B\leT B'$ and $X'\leT B'$,
we obtain $K\leT B'$. The opposite reduction was already proved.
\end{proof}
\mergenote{Source 08 (its Appendix~B) and source 10 (its Appendix~A) prove exactly this
lemma, with base oracle $\Aplus$, by the same finite-extension argument. Source 10
cites Friedberg's original article \cite{Friedberg}. Source 08 adds that modern work
continues to develop variants of Friedberg inversion in weak systems, for example
\cite{Belanger}; that citation is context, not a dependency.}

The requirement $B\geT X$ matters. An arbitrary jump inverse of $K$ need not
solve the base coarse problem $X$; the relative construction guarantees that it
does.

\subsection{The embedding theorem}
For $r\in\{\mathrm{uc},\mathrm{nc}\}$ and a countable ideal $\I$, define the
\emph{fixed-core collection}
\[
 \fiber_r(\I)=\{[Y]_r:\Core(Y)=\I\},
\]
ordered by the corresponding coarse reducibility. It is well defined by
Lemma~\ref{cr12:lem:corebasic}. This is the fiber of the core invariant; no closure
under arbitrary joins of its members is assumed.

\begin{theorem}[Fixed-core upper-cone embedding]\label{cr12:thm:embedding}
Fix $X$ and let $\mathbf x=\degT(X)$. For $H,K\geT X'$,
\begin{equation}\label{cr12:eq:embed-equiv}
 H\leT K
 \quad\Longleftrightarrow\quad
 T_X(H)\leuc T_X(K)
 \quad\Longleftrightarrow\quad
 T_X(H)\lenc T_X(K).
\end{equation}
For either $r\in\{\mathrm{uc},\mathrm{nc}\}$, the map
\[
 \mathbf h\longmapsto[T_X(H)]_r
 \quad(\mathbf h\ge\mathbf x')
\]
is therefore a well-defined order embedding into $\fiber_r(\Core(X))$,
with every image element above $[X]_r$. It preserves binary joins:
\begin{equation}\label{cr12:eq:embedjoin}
 T_X(H\oplus K)\equc T_X(H)\oplus T_X(K).
\end{equation}
Distinct input degrees also have distinct representative spectra.
\end{theorem}
\begin{proof}
If $H\leT K$, split a description of $T_X(K)$ into its two halves. Keep its
$X$-description, and apply Proposition~\ref{cr12:prop:transport} to its description
of $\Rcode(K)$. Joining the outputs gives a description of $T_X(H)$ by one
fixed functional. This proves the first forward implication. Uniform
reducibility always implies nonuniform reducibility.

For the converse, suppose $T_X(H)\lenc T_X(K)$. By
Lemma~\ref{cr12:lem:inversion}, choose $B\geT X$ with $B'\eqT K$. The oracle $B$
computes the exact set $X$ and a coarse description of $\Rcode(K)$, the latter
by Theorem~\ref{cr12:thm:jump-spectrum}. Thus
\[
 \degT(B)\in\Spec(T_X(K)).
\]
The assumed nonuniform reduction and \eqref{cr12:eq:order-spectrum} put the same
degree in $\Spec(T_X(H))$. Formula \eqref{cr12:eq:filterspec} now gives
$H\leT B'\eqT K$, as required.

The map is well defined on Turing degrees by the already proved forward
implication in both directions, and is injective by the converse. Its core and
its position above $[X]_r$ are given by Theorem~\ref{cr12:thm:filter}.

For binary joins, rearrange
\[
 (X\oplus\Rcode(H))\oplus(X\oplus\Rcode(K))
\]
to two copies of an $X$-description and one description of each dyadic code.
Either copy of the $X$-description suffices; in the reverse direction one can
duplicate it. These finite splitting, rearranging, and duplicating operations
preserve density-zero error. Proposition~\ref{cr12:prop:transport} replaces the two
dyadic descriptions by one of $\Rcode(H\oplus K)$, or conversely.
This proves \eqref{cr12:eq:embedjoin} with uniform reductions.

Finally, equality of two image spectra implies nonuniform equivalence by
\eqref{cr12:eq:order-spectrum}, and \eqref{cr12:eq:embed-equiv} then forces equality of
the input Turing degrees.
\end{proof}
\mergenote{Taking $X=\Lam$ and restricting to $H,K\geT\Aplus'$, a subcone because
$\Lam\leT\Aplus$ gives $\Lam'\leT\Aplus'$, gives source 10's embedding theorem,
restated as Theorem~\ref{cr12:lr:thm:embedding}; source 10's proof is this proof.
Source 08's Theorem~\ref{cr12:ep:thm:embedding} embeds the cone above $\Aplus'$ by a
different map, $H\mapsto\Fint_H$, with the parameter in constant rows inside the code,
and proves its uniform half through the normal form; by
Remark~\ref{cr12:ep:rem:filtercompare} (a merge observation) that map agrees, up to
uniform coarse equivalence, with this theorem for $X=\QQ(\vec A)$.}

The lower endpoint $\mathbf x'$ of the domain is not claimed to map to
$[X]_r$. The theorem is an embedding into the region above $[X]_r$, not a
bottom-preserving isomorphism with that entire region. Likewise it identifies a
join-closed \emph{subcollection} of the fiber; it does not show that the full
fiber is closed under arbitrary binary coarse joins.

\subsection{Consequences for all countable ideals}
\begin{corollary}[Continuum many spectra with one prescribed core]\label{cr12:cor:continuum}
For every countable Turing ideal $\I$ and either coarse reducibility,
$\fiber_r(\I)$ contains a join-preserving copy of a Turing upper cone. Above
each of its members there are continuum many members with pairwise distinct
representative spectra.
\end{corollary}
\begin{proof}
Theorem~\ref{cr12:thm:realize} makes the fiber nonempty. Apply
Theorem~\ref{cr12:thm:embedding} to any representative $X$ of a chosen member.
Every Turing upper cone has continuum many degrees: there are continuum many
oracles of the form $X'\oplus Z$, and each Turing degree contains only
countably many oracles. Distinctness of the image spectra is part of that theorem.
\end{proof}
\mergenote{Source 08 (Corollary~\ref{cr12:ep:cor:continuum}) and source 10
(Theorem~\ref{cr12:lr:thm:continuum}) state the companion fact explicitly: every
countable ideal is the core of continuum many coarse degrees, distinct for both
reducibilities, having \emph{no least Turing-degree representative}. For the
construction of this part the absence of a least member follows from
Corollary~\ref{cr12:cor:strict} whenever $H\nleT X'$.}

\begin{corollary}[No maximal member and no countable cofinal family]\label{cr12:cor:cofinal}
For every countable Turing ideal $\I$ and
$r\in\{\mathrm{uc},\mathrm{nc}\}$, the ordered collection
$\fiber_r(\I)$ has no maximal member and no countable cofinal subset.
\end{corollary}
\begin{proof}
For any $X$ with core $\I$, the set $T_X(X'')$ has the same core and is
strictly above $X$ even for nonuniform coarse reducibility, by
Corollary~\ref{cr12:cor:strict}. This proves the first assertion.

For the second, let $(X_n)$ be any nonempty countable sequence of representatives
with core $\I$, repeating entries if the proposed family is finite. Put
\[
 L=\bigoplus_n X_n',\qquad H=L',\qquad Z=T_{X_0}(H).
\]
Then $\Core(Z)=\I$. If $Z\lenc X_n$, the exact oracle $X_n$ would compute a
coarse description of $Z$. Formula \eqref{cr12:eq:filterspec} would imply
$H\leT X_n'\leT L$, contradicting $L'\nleT L$.
Thus $Z$ is not below any listed member even nonuniformly, so the family is
not cofinal for either reducibility. The empty family is not cofinal because
the fiber is nonempty.
\end{proof}

Cofinality here is inside the \emph{coarse-degree collection with a fixed
core}. It must not be confused with the coinitiality of Turing degrees inside
one representative spectrum, which is a different question studied in
\cite{Repo}.

\section{Interpretation, limitations, and formalization}\label{cr12:sec:interpret}
\subsection{What has been determined}
There is no additional realizability restriction on a countable Turing ideal
arising from being the information common to all coarse descriptions. Every
such ideal occurs, with a code whose exact degree is the degree of its chosen
presentation. In particular, cores need not be principal, and the lack of a
least representative can reflect either an unattained infimum or the complete
absence of an infimum.

At the same time, this classification is far from a classification of coarse
degrees. Theorem~\ref{cr12:thm:embedding} locates a full Turing upper cone inside
every one of the classes grouped together by the core invariant. Those embedded
problems can be ordered, joined, and separated by their spectra while preserving
every member of their common lower cone. The failure of completeness of the
core invariant is therefore structural, not just an isolated counterexample.

The construction also separates two kinds of uniformity. A coarse description
of $X_{\vec A}$ uniformly produces an array approximating all its rows. It
need not uniformly identify the stabilized row for each $i$. That missing
selection information is a genuine source of spectral complexity, already
visible when every individual $A_i$ is computable.

\subsection{Claims not made}
The paper does not show that every upward-closed collection of Turing degrees
with a prescribed common lower cone is a coarse spectrum. Formulas
\eqref{cr12:eq:rowspec} and \eqref{cr12:eq:combined} describe the particular constructions
used here. They do not imply that every possible spectrum has one of these forms.

A spectrum without a least member can still have minimal members. None of the
arguments proves the absence of all minimal elements in a representative
spectrum. Similarly, the upper-cone embedding uses no claim that Turing jumps
preserve arbitrary meets or that the Turing degrees form a lattice.

No computable rate of convergence is supplied for arbitrary sequences of
generators, and no arithmetical complexity bound follows from countability
alone. The explicit bound $X_{\vec A}\eqT\joinvec A_i$ is relative to a selected
presentation, not an intrinsic canonical degree assigned to the ideal.

Finally, density-zero modifications preserve coarse descriptions because errors
are permitted. Effective-dense descriptions permit omissions but not erroneous
answers. Sparse replacement and the coding constructions cannot be reused for
that setting without a separate proof. Gerdes's effective-dense question
\cite[Question~7]{Gerdes}, also marked C2 in \cite{Repo}, is not answered here.

\subsection{A formalization route}
The results have been proved as conventional mathematics in this manuscript;
no accompanying Lean theorem file has been compiled. A useful formalization
order would isolate three modules.

First, formalize finite density estimates and the partition $p(i,m)$:
the exact tail count, restriction of null errors to a positive-density column,
the finite-head/small-tail assembly lemma, and block-majority recovery. These
are the parts directly supported by the finite checks in this package, although
finite checks do not establish their universal statements.

Second, formalize the common-information invariant and its robust-radius theorem.
This requires the prefix-density metric, its completeness on $\CD(X)$,
continuity of finite oracle computations, and the local decoder. The dependence
on Baire category should be exposed rather than hidden in an admitted
``compactness'' statement. With that module available, the ideal-realization
and neutrality theorems are short deductions.

Third, add use-bounded oracle computations, the limit lemma, and relative jump
inversion. The proof of Theorem~\ref{cr12:thm:embedding} then separates into a uniform
positive reduction and a single inverse-jump witness for the converse. A clean
API should distinguish a Turing reduction of an individual real from an oracle
procedure returning a convergent array. That distinction is essential in
Theorem~\ref{cr12:thm:rows}.

\mergenote{The manuscript did not consult the Lean library. At the pinned commit (and
now) \path{Computability/TuringDegrees/Lean/CoarseDegrees} already proves much of
the first module: the exact tail count, restriction of density-zero errors to a
column, the bounded-column assembly lemma and block-majority decoding
(Section~\ref{cr12:sec:assembly}). The second and third modules are absent: the
library has no prefix-density metric and no Baire-category argument, states the
dyadic criterion only in limit form because it has no jump operator, and has no
use-bounded model of Turing functionals. Sources 08 (Section~\ref{cr12:ep:subsec:formal})
and 10 (Section~\ref{cr12:lr:subsec:mapping}) propose similar layered decompositions.}

\section{Further research questions}\label{cr12:sec:questions}
The questions below are proposed continuations of the proved results. They are
not all asserted to be independently verified open problems in the published
literature. Each identifies a boundary not settled by this manuscript.

\begin{question}[Spectra over a fixed ideal]\label{cr12:q:spectra}
Fix a countable ideal $\I$. Which upward-closed sets $S$ of Turing degrees occur
as $\Spec(X)$ with $\Core(X)=\I$? Beyond the common-lower-cone condition, what
effective or descriptive-set-theoretic restrictions are necessary and sufficient?
\end{question}
Theorem~\ref{cr12:thm:filter} gives exact closure operations on already realized
spectra. A first concrete target is to find a necessary condition not implied
merely by upward closure and the prescribed common lower cone.

\mergenote{Source 08 (Question~\ref{cr12:ep:q:spectra}) and source 10
(Question~\ref{cr12:lr:q:spectra}) ask the same question. It is the spectra half of
the synthesis's ``Classification'' item and of plan target C5(b), and it stays open.
Theorem~\ref{cr12:thm:filter}, Theorem~\ref{cr12:ep:thm:factorization} and
Theorem~\ref{cr12:lr:thm:insertion} give three families of realized spectra.}

\begin{question}[Simplifying the whole-row condition]\label{cr12:q:rows}
For which presentations $\vec A$ is the right inclusion in
\eqref{cr12:eq:sandwich} an equality? Can whole-row stabilization be characterized
by a useful index-selection or domination condition on a presentation?
\end{question}
The constant-row example rules out dropping the jump condition altogether.
It does not settle the converse with both necessary conditions present.
Canonical increasing sequences of finite jumps provide concrete test cases.

\mergenote{For source 08's code the corresponding spectrum has the row-finite normal
form of Corollary~\ref{cr12:ep:cor:normal-spectrum};
Remark~\ref{cr12:ep:rem:rowcompare} compares the two exact spectra.}

\begin{question}[Exact characterization of neutral joins]\label{cr12:q:neutral}
Is a set $Y$ neutral for all cores, in the sense that
$\Core(X\oplus Y)=\Core(X)$ for every $X$, exactly when $\gamma(Y)=1$?
If not, what is the correct characterization?
\end{question}
Only the sufficient direction is proved here. Taking $X$ computable shows
that universal neutrality implies a trivial core, but this necessary condition
is weaker than the hypothesis used in Theorem~\ref{cr12:thm:neutral}.

\begin{question}[When common information increases under joins]\label{cr12:q:synergy}
Given $\Core(X)=\Core(Y)=\I$, under what additional assumptions does
$\Core(X\oplus Y)=\I$ follow? Which larger ideals can arise from their join?
\end{question}
The embedded families in Theorem~\ref{cr12:thm:embedding} stay in one core under
binary joins. This does not settle the behavior of arbitrary pairs from the
same fixed-core collection.

\mergenote{Re-scoped. For $\I=\Comp$ the second half is answered in report~11 of this
programme (batch-37 manuscript 07; its two-share realization theorem and the
corollary after it, Theorem~6.1 and Corollary~6.2 in its delivered numbering):
there are $X,Y$ with $\Core(X)=\Core(Y)=\Comp$ and $\Core(X\oplus Y)$ equal to any
prescribed countable ideal, so no operation on cores computes the core of a join.
The first half, and the second for nontrivial $\I$, remain open here.}

\begin{question}[Uniform degree structure beyond spectra]\label{cr12:q:uniform}
Within a fixed core, how much can uniform coarse degrees vary while the
nonuniform coarse degree, and therefore the representative spectrum, is fixed?
Can one give an exact presentation-theoretic criterion for that variation?
\end{question}
Equation~\eqref{cr12:eq:order-spectrum} completely captures the nonuniform order,
but not the requirement for a single functional. The explicit uniform
reductions in Theorem~\ref{cr12:thm:embedding} do not collapse the two global degree
structures.

\mergenote{Source 08 (Proposition~\ref{cr12:ep:prop:uniform-core}) shows that the
\emph{uniform exact} core, the sets produced by one functional from every
description, is $\Comp$; report~11 relativizes this (its Proposition~5.3 in the
delivered numbering). That concerns uniform extraction of a fixed set, not uniform
coarse reductions, so this question stays open, as does plan target~C8.}

\begin{question}[Minimal solving degrees]\label{cr12:q:minimal}
For the spectra $\Row(\vec A)\cap\mathcal Q_H$, when do minimal elements
exist, and can one give a natural presentation whose spectrum has none?
\end{question}
The existence of an infimum is already decided by the core. Minimality is a
separate local property of the upward-closed spectrum and calls for a different
argument, likely involving controlled jump inversions or refinements of
presentations.

\mergenote{Sources 08 and 10 ask the same for their constructions
(Questions~\ref{cr12:ep:q:minimal} and~\ref{cr12:lr:q:minimal}). The research plan
(target~C5) records that for the dyadic codes minimal elements do exist, by Cooper's
jump inversion for minimal degrees; for the spectra of this report the question is
open.}

\begin{question}[Effective realizations and formal assurance]\label{cr12:q:effective}
For ideals presented at specified arithmetical or hyperarithmetical complexity,
what are the sharp degrees of realizing codes and of cone-avoiding descriptions?
Which parts of the radius and whole-row theorems admit economical Lean
formalizations over the repository's existing oracle-computability framework?
\end{question}
An effective index for a sequence is substantially more information than a
nonuniform collection of individually simple generators. Sharp results should
state explicitly which presentation data are supplied to the construction.

\mergenote{Parts~II and~III give presentation-relative bounds: source 08's pairs have
jumps below $\Theta_{\vec A}\leT\Aplus'$, and its fiber pairs have any prescribed
common jump above $\Aplus'$ (Theorems~\ref{cr12:ep:thm:headline-pairs}
and~\ref{cr12:ep:thm:prescribed-jump}); source 10's splitting systems are computable
in $(\Aplus\oplus H)'$ (Theorem~\ref{cr12:lr:thm:mainperfect}). Sharpness is open
(Questions~\ref{cr12:ep:q:thresholds} and~\ref{cr12:lr:q:witness}).}

\begin{question}[The error-free boundary]\label{cr12:q:ed}
What replaces the core and the whole-row spectrum theorem for effective-dense
descriptions, and can an error-free coding operation preserve their common
information while imposing an independent jump condition?
\end{question}
A successful answer would have to address the prohibition on erroneous values,
not merely shrink their density. It could provide a genuinely new route to the
remaining effective-dense least-representative problem.

\mergenote{All three sources leave the effective-dense questions open (source 08's
Question~\ref{cr12:ep:q:other}, source 10's Question~\ref{cr12:lr:q:restrictions}).
Report~14 of this programme (batch-37 manuscript 11) answers the least-representative
question C2 negatively for $1$-generics with computable agreement; it does not treat
cores, spectra of codes, or this question.}

The inspected source is the ProveIt repository at commit

\subsection{Three main conclusions}
All ideals in this part are nonempty. We regard an ideal either as a collection of
sets closed under Turing equivalence, or as its corresponding collection of degrees.
Let $\vec A=(A_n)_{n\in\N}$ generate the countable ideal
\begin{equation}\label{cr12:ep:eq:ideal}
 \I_{\vec A}=\{Z:(\exists m)\ Z\leT \Alt m\},
 \qquad \Alt m=\bigoplus_{n<m}A_n,
 \qquad \Alt 0=\emptyset.
\end{equation}
Use fixed effective codings for all finite and countable joins, and set
\begin{equation}\label{cr12:ep:eq:oracles}
 \Aplus=\bigoplus_n A_n,\qquad \Theta_{\vec A}=\bigoplus_m \Alt m'.
\end{equation}
The principal results are as follows; all constructions and reductions are given
later.

\begin{theorem}[Core realization; proved in Section~\ref{cr12:ep:sec:realization}]\label{cr12:ep:thm:headline-core}
A collection of sets is $\Core(X)$ for some $X\in\Cantor$ if and only if it is a
countable Turing ideal. For every presentation $\vec A$ there is an explicit
$X=\QQ(\vec A)\eqT \Aplus$ realizing $\I_{\vec A}$.
\end{theorem}

\begin{theorem}[Effective perfect exact pairs; proved in Section~\ref{cr12:ep:sec:fusion}]\label{cr12:ep:thm:headline-pairs}
For every $\vec A$ and every $m_0$, there is a $\Theta_{\vec A}$-computable continuous
injection $P\mapsto D_P$ from $\Cantor$ into $\CD(\QQ(\vec A))$ such that, for
distinct $P,Q$,
\begin{equation}\label{cr12:ep:eq:headline-exact}
 \Low(D_P)\cap\Low(D_Q)=\I_{\vec A},
 \qquad D_P'\leT \Theta_{\vec A}\oplus P.
\end{equation}
There is one $\Theta_{\vec A}$-computable set $V$ of density zero, with a
$\Theta_{\vec A}$-computable density modulus, covering all $D_P\sd\QQ(\vec A)$.
Moreover
\[
 |V\cap[0,N)|\le 2^{-m_0}N\qquad(N\ge1).
\]
In particular, two computable branch parameters give an exact pair with both jumps
below $\Theta_{\vec A}$.
\end{theorem}

\begin{theorem}[Rich fibers and prescribed common jumps; proved in Section~\ref{cr12:ep:sec:fibres}]\label{cr12:ep:thm:headline-fibre}
For each $\vec A$, there are binary sets $\Fint_H$, all with core $\I_{\vec A}$, such
that for $H,K\geT \Aplus'$,
\begin{equation}\label{cr12:ep:eq:headline-embedding}
 \Fint_H\lenc \Fint_K\quad\Longleftrightarrow\quad
 \Fint_H\leuc \Fint_K\quad\Longleftrightarrow\quad H\leT K.
\end{equation}
For every such $H$, the class $\CD(\Fint_H)$ contains an exact pair for $\I_{\vec A}$
with both jumps Turing equivalent to $H$. Restricting the parameters to
$H\geT \Aplus''$ gives continuum many distinct uniform coarse degrees, and also
continuum many distinct nonuniform coarse degrees, with this core and with no least
Turing-degree representative.
\end{theorem}

\subsection{What is classical, what is established here}
The information set called $\Core(X)$ here is the $X^{\mathfrak c}$ of Hirschfeldt,
Jockusch, Kuyper and Schupp \cite[Definition~3.1]{HJKS}. Their Theorem~3.7 supplies
the short alternative proof of realization in
Section~\ref{cr12:ep:subsec:compactness}. The finite-extension mechanism used below is
an adaptation of classical exact-pair reasoning; the row-finite form is visible, for
example, in Franklin and Solomon's presentation of an exact-pair construction
\cite[Section~2]{FS}. Neither ordinary exact-pair existence nor the underlying
no-splitting argument is claimed as new.

The contribution of this draft is the explicit package: every countable ideal inside
a single coarse-description class; a computable retraction normal form; a
presentation-sensitive jump bound and common null envelope; and an upper-cone
embedding with prescribed-jump exact pairs inside each fixed core. The literature
check establishes the relevant precedents, but does not establish priority for this
package. Even the bare classification should not be advertised as a previously
unknown general theorem: its deduction from published compactness is short once the
coding is chosen.

\begin{assessment}{Scope of the claimed resolution}
The countable-core realization question in the inspected repository is resolved.
The classification of \emph{all representative spectra} is not. We do not settle
whether the spectra in question have minimal elements, the general effective-dense
least-representative problem, or a general equivalence of uniform and nonuniform
coarse reducibility. The equivalence in \eqref{cr12:ep:eq:headline-embedding} holds
only for the displayed family.
\end{assessment}

\subsection{Cores, spectra, and the uniformity boundary}

$\overline\rho=\Dens$, $\CD(X)$, $\lenc$, $\leuc$, $\Low$, $\Core$ and $\Spec$, the
standard coarse reducibilities \cite{HJKS,Gerdes}, with a Turing ideal a nonempty

\section{A two-level code and a computable normal form}\label{cr12:ep:sec:normal}

\subsection{Columns and blocks}
Use the computable bijection
\begin{equation}\label{cr12:ep:eq:pairing}
 p(n,t)=2^n(2t+1)-1\qquad(n,t\in\N).
\end{equation}
Its $n$th column is $C_n=\{p(n,t):t\in\N\}$. The tail of the column partition is
\[
 T_m=\bigcup_{n\ge m}C_n=\{x:2^m\mid x+1\}.
\]
Direct counting gives
\begin{equation}\label{cr12:ep:eq:counts}
 |C_n\cap[0,N)|=\left\lfloor\frac{N+2^n}{2^{n+1}}\right\rfloor,
 \qquad |T_m\cap[0,N)|=\left\lfloor\frac{N}{2^m}\right\rfloor.
\end{equation}
In particular, $C_n$ has density $2^{-n-1}$, whereas the tail has density $2^{-m}$.
These are exact finite counts, not merely asymptotic estimates.

Inside each column, partition the row coordinate $t$ into blocks
\begin{equation}\label{cr12:ep:eq:blocks}
 I_k=[2^k-1,2^{k+1}-1),\qquad |I_k|=2^k,
 \qquad \ell(t)=\lfloor\log_2(t+1)\rfloor.
\end{equation}
For $U\in\Cantor$ define the repetition code $\Jsh(U)(t)=U(\ell(t))$. For an array
$Y=(Y_n)_{n\in\N}$ define
\begin{equation}\label{cr12:ep:eq:Q}
 \QQ(Y)(p(n,t))=Y_n(\ell(t)).
\end{equation}
Thus every bit of every row is repeated on a finite block, while every row occupies
a positive-density column. The array itself is regarded as a set via a fixed
computable pairing of its two coordinates.

\mergenote{$\Jsh$ is Part~I's $\Jcode$ shifted by one position,
$\Jsh(U)(t)=\Jcode(U)(t+1)$, so its blocks are $[2^k-1,2^{k+1}-1)$ rather than
$[2^k,2^{k+1})$; the Lean library's \texttt{blockCode} is $\Jcode$, not $\Jsh$. The
code $\QQ(\vec A)$ is the plan's C4 code with $\Jsh$ in place of $\Jcode$, and it is
not Part~I's $X_{\vec A}$, which uses $\Ecode=\Jcode\circ\Rcode$.}

\begin{lemma}[Restriction and majority]\label{cr12:ep:lem:majority}
If $E\subseteq\N$ has density zero, then for each fixed $n$ the row set
$\{t:p(n,t)\in E\}$ has density zero. If $D$ is a coarse description of $\Jsh(U)$,
majority decoding on the blocks $I_k$, with ties decoded as $0$, agrees with $U$
except at finitely many $k$.
\end{lemma}
\begin{proof}
For $s\ge1$, all $p(n,t)$ with $t<s$ are below $2^{n+1}s$. Therefore the row error
fraction is at most
\[
 \frac{|E\cap[0,2^{n+1}s)|}{s}
   =2^{n+1}\rho_{2^{n+1}s}(E),
\]
which tends to zero for fixed $n$.

If a block majority is wrong, at least $2^{k-1}$ of the $2^k$ positions in that
block are wrong; this lower bound is harmless also at $k=0$. At the endpoint
$N_k=2^{k+1}-1$, the total error fraction is at least $2^{k-1}/N_k>1/4$. Infinitely
many wrong block majorities would therefore contradict density zero.
\end{proof}

\subsection{The row-finite mass problem}
For a prescribed sequence $\vec A=(A_n)$, put
\begin{equation}\label{cr12:ep:eq:F}
 \FF_{\vec A}=\{Y:(\forall n)\ Y_n=^*A_n\},
\end{equation}
where $=^*$ means finite symmetric difference. The finite exceptional set can depend
on $n$, with no uniform bound or effective selector.

\begin{theorem}[Computable retraction normal form]\label{cr12:ep:thm:normal}
There are total computable functionals $\Gamma$ and $\Delta$, independent of
$\vec A$, with the following properties:
\begin{enumerate}[label=\textup{(\roman*)}]
\item $\Gamma(Y)=\QQ(Y)$ and $\Delta\Gamma(Y)=Y$ for every array $Y$.
\item If $D\in\CD(\QQ(\vec A))$, then $\Delta(D)\in\FF_{\vec A}$.
\item If $Y\in\FF_{\vec A}$, then $\Gamma(Y)\in\CD(\QQ(\vec A))$ and $\Gamma(Y)\eqT Y$,
uniformly.
\end{enumerate}
Consequently $\CD(\QQ(\vec A))$ and $\FF_{\vec A}$ are Medvedev equivalent: a single
computable functional translates solutions in either direction. The map
$\Gamma\Delta$ is idempotent and normalizes coarse descriptions to row-block codes.
\end{theorem}
\begin{proof}
Let $\Gamma$ be \eqref{cr12:ep:eq:Q}, and define
\[
 \Delta(D)(n,k)=
 \begin{cases}
 1,&\displaystyle\sum_{t\in I_k}D(p(n,t))>2^{k-1},\\
 0,&\text{otherwise}.
 \end{cases}
\]
Every output bit uses finitely many oracle bits. For a code $\Gamma(Y)$ the relevant
block is constant, so $\Delta\Gamma(Y)=Y$. Alternatively $Y_n(k)$ can be recovered
by sampling $\Gamma(Y)(p(n,2^k-1))$; thus coding and decoding preserve the degree
uniformly.

For (ii), restrict the error set $D\sd\QQ(\vec A)$ to each column.
Lemma~\ref{cr12:ep:lem:majority} gives density-zero row errors and then finitely many
majority errors in each row. This is precisely membership in $\FF_{\vec A}$.

For (iii), let $S_n=Y_n\sd A_n$, a finite set. The error set of the coded sequences
has exactly
\begin{equation}\label{cr12:ep:eq:Km}
 K_m=\sum_{n<m}\ \sum_{k\in S_n}2^k
\end{equation}
points in the first $m$ columns. Every other error belongs to $T_m$. Hence for all
$N\ge1$,
\begin{equation}\label{cr12:ep:eq:tailbound}
 \rho_N(\QQ(Y)\sd\QQ(\vec A))
 \le \frac{K_m}{N}+2^{-m}.
\end{equation}
For fixed $m$, take the limit superior in $N$, and then let $m$ increase. The result
is density zero. Finally, $\Delta\Gamma$ is the identity on all arrays, so
$(\Gamma\Delta)^2=\Gamma\Delta$.
\end{proof}

\begin{corollary}[Spectrum normal form]\label{cr12:ep:cor:normal-spectrum}
\begin{equation}\label{cr12:ep:eq:normal-spectrum}
 \Spec(\QQ(\vec A))
 =\{\degT Y:Y\in\FF_{\vec A}\}
 =\{\degT D:(\exists Y\leT D)\ Y\in\FF_{\vec A}\}.
\end{equation}
Every member of this spectrum bounds every member of $\I_{\vec A}$, and
$\QQ(\vec A)\eqT \Aplus$.
\end{corollary}
\begin{proof}
Theorem~\ref{cr12:ep:thm:normal} identifies which oracles compute a solution. To
check equality of the \emph{exact} degree spectra, note that $\FF_{\vec A}$ has an
upward-closed spectrum: given $Y\in\FF_{\vec A}$ and $Z\geT Y$, replace $Y_n(0)$ by
$Z(n)$ for each $n$. The resulting array is still a finite variant in each row and
has degree exactly that of $Z$.

For $Y\in\FF_{\vec A}$, each $A_n$ is Turing reducible to $Y_n$, by hard-coding its
finite exceptional set. For any fixed finite collection of rows these reductions can
be combined. This proves the lower-bound claim but does not uniformly recover the
infinite join. Exact coding of the original array does recover its infinite join,
proving $\QQ(\vec A)\eqT \Aplus$.
\end{proof}

\begin{remark}[Why both coding levels are needed]
The outer positive-density partition lets each individual row survive coarse
errors. The growing inner blocks let the row itself survive with only finitely many
decoded errors. Merely putting $A_n(t)$ at $p(n,t)$ would yield a coarse description
of $A_n$, not a finite variant of $A_n$. Conversely, assigning rows to density-zero
sets would allow an entire generator to be erased. The two levels solve different
problems.
\end{remark}

\section{The finite-extension mechanism}\label{cr12:ep:sec:forcing}
We now work inside $\FF_{\vec A}$. A useful topology on this mass problem is not its
inherited Cantor-space topology. Instead, give the countable collection of finite
variants of each row $A_n$ the discrete topology, and take the product.
Equivalently, identify a row with its finite error set. The resulting space is
homeomorphic to Baire space.

A condition is a finite sequence $p=(S_0,\ldots,S_{m-1})$ of finite subsets of $\N$.
Its length is $|p|=m$, and its cylinder is
\begin{equation}\label{cr12:ep:eq:cylinder}
 [p]=\{Y\in\FF_{\vec A}:(\forall n<m)\ Y_n=A_n\sd S_n\}.
\end{equation}
Thus a condition fixes finitely many \emph{complete rows}, not a finite initial
segment of the coded set. An extension fixes more rows and never alters a
previously fixed row. Every cylinder is nonempty.

\mergenote{Here and in \eqref{cr12:ep:eq:Km} the letters $S_n$ are finite error masks
and $p$ is a condition, as in source 08; $p(n,t)$ remains the pairing.}

\subsection{Finite computations are searchable in a finite join}
\begin{lemma}[Possible convergence]\label{cr12:ep:lem:possible}
For a condition $p$ of length $m$, the relation
\begin{equation}\label{cr12:ep:eq:possible}
 (\exists Y\in[p])\ \Phi_e^Y(k)\mathord\downarrow=b
\end{equation}
is computably enumerable in $\Alt m$, uniformly in the finite parameters. For two
conditions $p,q$, the existence of a cross-disagreement
\begin{equation}\label{cr12:ep:eq:split}
 (\exists k)(\exists Y\in[p])(\exists Z\in[q])\quad
 \Phi_e^Y(k)\mathord\downarrow\ne\Phi_f^Z(k)\mathord\downarrow
\end{equation}
is computably enumerable in $\Alt{\max(|p|,|q|)}$.

The oracle $\Theta_{\vec A}$ decides these existential questions and, in a positive
case, computes extending conditions that preserve the displayed finite
computations.
\end{lemma}
\begin{proof}
On the fixed rows, oracle answers are computable from $\Alt m$ and the finite masks
in $p$. On all other rows, any finite consistent assignment of queried bits is
possible. Indeed, finitely many prescribed bits can always be realized by a finite
variant of $A_n$, regardless of how complicated the unqueried part of that row is.

Enumerate finite computation traces together with their finitely many guesses for
unfixed-row answers. Reject inconsistent traces and traces conflicting with a fixed
row. This is an $\Alt m$-effective enumeration and enumerates exactly the possible
convergences. Two independent copies of the same procedure enumerate
\eqref{cr12:ep:eq:split}, using the larger finite join for their fixed rows.

The relevant finite-join jump is a component of $\Theta_{\vec A}$, so this oracle
decides whether such a trace exists. When it exists, search for one. The oracle
$\Theta_{\vec A}$ also uniformly computes every $A_n$: it computes $\Alt{n+1}$ from
$\Alt{n+1}'$. For each as-yet-unfixed row touched by the trace, choose the finite
error mask making its queried answers correct. Fill any skipped rows with the empty
mask and fix all rows through the largest touched index. These extensions preserve
the convergences. For a cross-disagreement do this separately on the two sides.
\end{proof}

The extension oracle is used in two distinct ways. A finite-join jump decides
whether a trace exists; the original rows allow the chosen finite trace to be
completed to whole rows. No decision about totality of an arbitrary functional is
made.

\subsection{No cross-disagreement means common information is already finite}
\begin{lemma}[No-cross-disagreement lemma]\label{cr12:ep:lem:no-cross}
Let $p,q$ be conditions and $e,f$ indices. If \eqref{cr12:ep:eq:split} fails, then
whenever $Y\in[p]$ and $Z\in[q]$ make $\Phi_e^Y$ and $\Phi_f^Z$ total, those outputs
are equal and their common value is computable in $\Alt{|p|}$. In particular any
common total output belongs to $\I_{\vec A}$.
\end{lemma}
\begin{proof}
Fix a total pair. On input $k$, search, using $\Alt{|p|}$, for any finite trace
witnessing a possible convergence of $\Phi_e$ on input $k$ inside $[p]$. The search
terminates because the actual computation from $Y$ is one such trace. Let the found
output be $b$.

The actual computation of $\Phi_f^Z(k)$ is a possible convergence on the other side.
Since there is no cross-disagreement anywhere in the rectangle, its output must be
$b$. The same argument applies to the actual left computation, and hence both total
outputs equal the function computed by this search. The finite condition and
program index are fixed constants in the reduction, not an additional oracle.
\end{proof}

\begin{proposition}[Dense exact-pair requirements]\label{cr12:ep:prop:dense}
For every $p,q,e,f$, there are extensions $p^*\supseteq p$ and $q^*\supseteq q$ such
that either the two functionals are forced to disagree at some input, or every
common total output on $[p^*]\times[q^*]$ belongs to $\I_{\vec A}$. Such extensions
and the relevant case can be chosen with oracle $\Theta_{\vec A}$.
\end{proposition}
\begin{proof}
Decide \eqref{cr12:ep:eq:split}. In the positive case, force a witnessing disagreement
using Lemma~\ref{cr12:ep:lem:possible}. In the negative case, leave both conditions
unchanged and apply Lemma~\ref{cr12:ep:lem:no-cross}. Both conclusions persist under
further extensions.
\end{proof}

This is the classical exact-pair dichotomy in the form needed here. Crucially, a
negative answer does not require deciding that a functional is partial. If total
common output eventually occurs, the no-cross-disagreement search supplies its
finite-join computation. This avoids an unnecessary extra jump in the construction
oracle.

\section{Perfect exact pairs with jump control and one null envelope}\label{cr12:ep:sec:fusion}
We prove Theorem~\ref{cr12:ep:thm:headline-pairs}. A family indexed by all of Cantor
space cannot consist entirely of sets below one oracle. The branch parameter in the
bound $D_P'\leT \Theta_{\vec A}\oplus P$ is therefore essential; only selected
computable branches have the unparameterized bound.

\subsection{Construction of the finite tree}
Fix $m_0$. At level zero use the single condition of length $m_0$ with every mask
empty. It requires the first $m_0$ rows to agree exactly with $\vec A$. We build
conditions $p_\sigma$ for binary strings $\sigma$, extending their predecessor
conditions. At the end of each level all conditions at that level have a common
finite length, and that length tends to infinity with the level. Store finite
records for the jump decisions made below.

Suppose the conditions at level $s$ have common length $L$. To construct level
$s+1$, perform the following finite operations, all with oracle $\Theta_{\vec A}$.

\begin{enumerate}[label=\textbf{\arabic*.},leftmargin=2em]
\item \textbf{Split.} For each level-$s$ node, create two extending conditions fixing
the fresh row $L$. Make its bit $0$ equal to $0$ in one child and $1$ in the other,
and keep the rest of that row equal to $A_L$. The required masks are either empty or
$\{0\}$, selected using $A_L(0)$. Descendants of distinct children will remain
different.
\item \textbf{Meet cross requirements.} For every ordered pair of distinct nodes now
at level $s+1$, and every pair of indices $e,f\le s$, apply
Proposition~\ref{cr12:ep:prop:dense}, replacing the two conditions by the extensions
obtained. The list is finite. A later replacement cannot destroy an earlier forced
disagreement or an earlier absence of cross-disagreements.
\item \textbf{Decide the next jump bit.} For each node, decide whether some array in
its current cylinder makes $\Phi_s^Y(s)$ converge. In a positive case extend the
condition to preserve a finite convergent computation and record $1$; in a negative
case leave it and record $0$. Lemma~\ref{cr12:ep:lem:possible} makes this decision
possible using $\Theta_{\vec A}$. Again these decisions persist under all further
extensions.
\item \textbf{Pad and synchronize lengths.} Extend all conditions with empty masks to a
common length at least $s+1$ and at least as large as every length produced so far.
Retain every finite record.
\end{enumerate}

There is no injury: rows, disagreement witnesses, and negative existence decisions
are preserved. The complete finite tree and its records are computable in
$\Theta_{\vec A}$.

\subsection{Verification of exactness and effectivity}
For $P\in\Cantor$, every row is eventually fixed along the branch. Let $Y_P$ be the
unique array in every cylinder along that branch, and put $D_P=\Gamma(Y_P)$. Each
row of $Y_P$ is a finite variant of the corresponding $A_n$, so
Theorem~\ref{cr12:ep:thm:normal} gives $D_P\in\CD(\QQ(\vec A))$.

Every member of $\I_{\vec A}$ is computable from every $D_P$. For the reverse
inclusion, take distinct $P,Q$ and a set $Z$ with
\[
 Z=\Phi_e^{Y_P}=\Phi_f^{Y_Q}.
\]
Choose a level after the two branches have separated and with $s\ge e,f$. The
construction processes the corresponding pair of nodes. A forced disagreement would
contradict the displayed equality, so the no-cross-disagreement alternative must
apply. Lemma~\ref{cr12:ep:lem:no-cross} then puts $Z$ in $\I_{\vec A}$. Since $D_P$
and $Y_P$ have uniformly equivalent degrees, this proves
\[
 \Low(D_P)\cap\Low(D_Q)=\I_{\vec A}.
\]

To compute $Y_P'$ from $\Theta_{\vec A}\oplus P$, locate the node on $P$ at the level
where the construction decided its $e$th jump bit, and read the stored answer. A
positive answer preserved a halting trace. A negative answer excluded every possible
extension in that cylinder. Thus the answer is correct for the final branch, and the
procedure is uniform in $e$. The equivalence $D_P\eqT Y_P$ is uniform, hence so is
$D_P'\eqT Y_P'$. We obtain
\begin{equation}\label{cr12:ep:eq:jump-bound}
 D_P'\leT \Theta_{\vec A}\oplus P.
\end{equation}

To compute a bit of $D_P$, compute enough of the finite tree for its row to have
been fixed, and use the corresponding finite prefix of $P$. This proves that
$P\mapsto D_P$ is a $\Theta_{\vec A}$-computable continuous map. The preserved marker
bits make it injective. A continuous injection from compact Cantor space into Cantor
space is a homeomorphism onto its image: images of closed sets are compact and
therefore closed. The image is consequently a nonempty perfect set.

In particular, $P=000\ldots$ and $Q=100\ldots$ give two descriptions whose jumps are
below $\Theta_{\vec A}$. The same is true for every computable branch parameter, and
any two distinct such parameters give an exact pair.

\subsection{A common error set with an effective modulus}
For each $n$, compute a level at which every node has fixed row $n$. Let $R_n$ be the
union of the finitely many error masks appearing in that row among those nodes.
Later extension cannot alter them. Thus $R_n$ is a finite set computable uniformly in
$n$ from $\Theta_{\vec A}$, and
\[
 Y_{P,n}\sd A_n\subseteq R_n\qquad\text{for every }P.
\]
Define
\begin{equation}\label{cr12:ep:eq:V}
 V=\{p(n,t):\ell(t)\in R_n\}.
\end{equation}
Membership in $V$ is $\Theta_{\vec A}$-computable. All errors $D_P\sd\QQ(\vec A)$ are
covered by $V$. With
\[
 K_m^V=\sum_{n<m}\ \sum_{k\in R_n}2^k,
\]
the exact counting argument from \eqref{cr12:ep:eq:tailbound} gives
\begin{equation}\label{cr12:ep:eq:V-bound}
 \rho_N(V)\le \frac{K_m^V}{N}+2^{-m}.
\end{equation}
This proves density zero. More explicitly,
\begin{equation}\label{cr12:ep:eq:modulus}
 M(r)=2^{r+1}\bigl(K_{r+1}^V+1\bigr)
\end{equation}
is $\Theta_{\vec A}$-computable, and $N\ge M(r)$ implies $\rho_N(V)<2^{-r}$. This is
a density modulus, not merely a proof that a limit exists.

The initial condition imposed $R_n=\emptyset$ for $n<m_0$. Therefore
$V\subseteq T_{m_0}$, and the exact tail count gives the asserted global bound
$|V\cap[0,N)|\le2^{-m_0}N$. This completes the proof of
Theorem~\ref{cr12:ep:thm:headline-pairs}.

\begin{remark}[What the bound does not say]
The oracle $\Theta_{\vec A}$ is the countable join of the jumps of \emph{finite
joins}. One must not replace it by $\bigoplus_n A_n'$ without additional hypotheses.
The jump need not distribute over finite joins. On the other hand,
$\Theta_{\vec A}\leT \Aplus'$ because each finite projection $\Alt m\leT \Aplus$ is
uniform in $m$. The smaller bound $\Theta_{\vec A}$ can matter substantially;
Section~\ref{cr12:ep:subsec:arithmetic} gives an example.
\end{remark}

\begin{corollary}[Computable masks would force a principal core]\label{cr12:ep:cor:mask}
Suppose $D,E\in\CD(X)$ satisfy $\Low(D)\cap\Low(E)=\Core(X)=\I$, and a computable
density-zero set $V$ covers both $D\sd X$ and $E\sd X$. Then $\I$ is principal and
its generator lies in $\Spec(X)$. In particular, for a nonprincipal ideal the common
envelope in the preceding construction cannot be computable.
\end{corollary}
\begin{proof}
Let $W$ agree with $X$ outside $V$ and be $0$ on $V$. Since $D$ and $E$ agree with
$X$ outside $V$, the computable mask lets either oracle compute $W$. Thus $W\in\I$.
Also $W\in\CD(X)$, so every member of $\Core(X)=\I$ is below $W$. Downward closure
gives $\I=\Low(W)$, and its generator is attained. For the construction above,
equality of its core with $\I_{\vec A}$ is proved in the next section.
\end{proof}

\section{The complete core-realization theorem}\label{cr12:ep:sec:realization}
\begin{proof}[Proof of Theorem~\ref{cr12:ep:thm:headline-core}]
The necessity is Lemma~\ref{cr12:lem:corebasic}. Conversely, let $\I$ be a countable
Turing ideal. Choose a countable sequence of sets generating it under downward
closure and finite joins. If the ideal is presented as a countable collection of
degrees, first choose representatives. In classical ZFC these are ordinary countable
choices; no effective enumeration of the ideal is assumed.

Let $\vec A$ be the chosen sequence and $X=\QQ(\vec A)$.
Corollary~\ref{cr12:ep:cor:normal-spectrum} gives $\I\subseteq\Core(X)$. The
construction of Section~\ref{cr12:ep:sec:fusion} supplies $D,E\in\CD(X)$ with
$\Low(D)\cap\Low(E)=\I$. Since the core is contained in the common lower cone of any
two descriptions, $\Core(X)\subseteq\I$. Thus equality holds. The degree identity
$X\eqT\bigoplus_n A_n$ was proved in Corollary~\ref{cr12:ep:cor:normal-spectrum}.
\end{proof}

\subsection{A shorter independent route through published compactness}\label{cr12:ep:subsec:compactness}
For perspective, the classification itself does not require our perfect-family
construction. We state the particular published result needed for the shorter
route.

\begin{theorem}[Cone-avoiding compactness, HJKS]\label{cr12:ep:thm:HJKS}
If, for every $\varepsilon>0$, there is an $E_\varepsilon$ with
$\overline\rho(X\sd E_\varepsilon)\le\varepsilon$ and $Z\nleT E_\varepsilon$, then some
$D\in\CD(X)$ satisfies $Z\nleT D$.
\end{theorem}

This is \cite[Theorem~3.7]{HJKS}; it is not proved anew here. To apply it, fix
$Z\notin\I_{\vec A}$ and truncate $X=\QQ(\vec A)$ to its first $m$ columns, putting
$0$ on all remaining columns. Call the result $E_m$. Then
\[
 E_m\leT \Alt m,\qquad Z\nleT E_m,\qquad
 \overline\rho(X\sd E_m)\le2^{-m}.
\]
The published compactness theorem yields a description avoiding $Z$, so
$Z\notin\Core(X)$. Together with the already-proved reverse inclusion this yields
the same classification.

This argument explains the literature status precisely: a question explicitly
unclassified in the repository has a positive answer obtainable from an existing
general theorem. The longer construction is retained because it supplies joint
witnesses, perfect families, jump bounds, and an effective null envelope, none of
which follows just by separately avoiding one set at a time in this short argument.

\subsection{Nonprincipal ideals and missing infima}
\begin{corollary}\label{cr12:ep:cor:nonprincipal}
Every countable nonprincipal Turing ideal is the common lower cone of each pair of
distinct members of a perfect set contained in one density-zero equality class. Such
pairs have no greatest lower bound. Their common coarse class has neither a greatest
lower bound for its representative spectrum nor a least representative.
\end{corollary}
\begin{proof}
Use Theorem~\ref{cr12:ep:thm:headline-pairs} and core realization. The lower cone of a
greatest lower bound would be principal, contradicting the chosen ideal. The
representative-spectrum assertions follow from Corollary~\ref{cr12:cor:infimum}.
\end{proof}

This does not imply that the spectrum has no \emph{minimal} members. A partially
ordered set can lack a least member and still have many minimal members. No
construction in this part silently replaces the least-member question by the
minimal-member question.

\subsection{The ideal of all arithmetical sets}\label{cr12:ep:subsec:arithmetic}
Take $A_n=\emptyset^{(n)}$, using the usual finite iterates of the Turing jump, with
$A_0=\emptyset$. Then $\I_{\vec A}$ is exactly the ideal of arithmetical sets, and the
uniform join is $\emptyset^{(\omega)}$. With standard uniform choices of the
finite-jump reductions,
\[
 \Alt m\eqT\emptyset^{(m-1)}\quad(m\ge1),\qquad
 \Theta_{\vec A}\eqT\emptyset^{(\omega)}.
\]
Thus there is a binary set $X\eqT\emptyset^{(\omega)}$ with
\[
 \Core(X)=\{Z:(\exists n)\ Z\leT\emptyset^{(n)}\},
\]
and two coarse descriptions $D,E$ such that
\begin{equation}\label{cr12:ep:eq:arithmetic-pair}
 \Low(D)\cap\Low(E)=\Core(X),\qquad
 D',E'\leT\emptyset^{(\omega)}.
\end{equation}
Neither $D$ nor $E$ is arithmetical. If, for example, $D\leT\emptyset^{(n)}$, then
the fact that $D$ computes every generator would give
$\emptyset^{(n+1)}\leT\emptyset^{(n)}$, contradicting strictness of the jump.
Nevertheless both descriptions, and even their jumps, lie below the displayed limit
join.

Equation~\eqref{cr12:ep:eq:arithmetic-pair} illustrates the nonuniform nature of
recovering the generators: each description computes every finite jump, but the
construction does not give a uniform computation of the entire infinite join from
either description. Nor does it assert that their jumps are \emph{equal} to the
limit join. The conclusion is the stated upper bound.

infimum) and Example~\ref{cr12:lr:ex:arith} (source 10's carrier). Here
$\Theta_{\vec A}\eqT\Aplus=\emptyset^{(\omega)}$, strictly below
$\Aplus'$, which is the example promised in the remark after
\eqref{cr12:ep:eq:modulus}.}

\subsection{Principal ideals and dependence on presentation}\label{cr12:ep:subsec:presentation}
For a principal ideal $\Low(A)$ one may take every row equal to $A$. Then
$\QQ(\vec A)\eqT A$ and its spectrum has least degree $\degT A$. The ideal is not
enough, however, to determine the mass problem in \eqref{cr12:ep:eq:F}. A sequence of
individually computable rows can still carry noncomputable information in the way
those rows are assembled.

For example, for a set $H$, let the $n$th row be the constant sequence
$\bitconst{H(n)}$. Every row is computable, so the generated ideal is $\Comp$. But
solving the row-finite mass problem produces a simultaneous family of sequences
converging to the bits of $H$. The uniform difficulty of that task can be
arbitrarily large. The next section makes this observation quantitative for every
core, not just $\Comp$.

Example~\ref{cr12:ex:constantrows} and Proposition~\ref{cr12:lr:prop:noncanonical},
which record the same phenomenon for the other two codes.}

\section{Changing the coarse degree while keeping the core fixed}\label{cr12:ep:sec:fibres}
Fix the sequence $\vec A$ for the rest of this section. For each set $H$, define an
interleaved sequence of rows by
\begin{equation}\label{cr12:ep:eq:W}
 W^H_{2n}=A_n,\qquad W^H_{2n+1}=\bitconst{H(n)},
 \qquad \Fint_H=\QQ(\WW^H).
\end{equation}
The odd rows are constant binary sequences. As individual sets they have degree
zero, regardless of whether $H$ is computable. Consequently
\begin{equation}\label{cr12:ep:eq:samecore}
 \I_{\WW^H}=\I_{\vec A},\qquad \Core(\Fint_H)=\I_{\vec A}
 \quad\text{for every }H.
\end{equation}
There is no appeal here to a density-preserving arbitrary permutation of $\N$:
$\Fint_H$ is literally the code of the displayed interleaved array.

\mergenote{Do not read $\Fint_H$ as Part~I's $T_{\QQ(\vec A)}(H)=\QQ(\vec A)\oplus\Rcode(H)$:
here the parameter occupies the odd rows \emph{inside} one code, not a second half.
The two sets differ, but their coarse classes coincide up to uniform equivalence;
see Remark~\ref{cr12:ep:rem:filtercompare}.}

\subsection{An exact spectrum formula}
For a degree $\mathbf h$, write
\[
 \mathcal Q_{\mathbf h}=\{\mathbf d:\mathbf h\le\mathbf d'\},
\]
so $\mathcal Q_H=\mathcal Q_{\degT(H)}$ is the jump cone of Part~I. The elementary
relativized limit lemma used below is Lemma~\ref{cr12:lem:limit}. It says that
$H\leT D'$ exactly when there is a $D$-computable binary approximation $h(n,s)$
converging to $H(n)$ for every $n$.

\begin{theorem}[Spectrum factorization]\label{cr12:ep:thm:factorization}
For every set $H$,
\begin{equation}\label{cr12:ep:eq:factorization}
 \Spec(\Fint_H)=\Spec(\QQ(\vec A))\cap\mathcal Q_H.
\end{equation}
Equivalently, $D$ computes a coarse description of $\Fint_H$ if and only if it
computes a coarse description of $\QQ(\vec A)$ and $H\leT D'$.
\end{theorem}
\begin{proof}
Suppose $D$ computes a description of $\Fint_H$. Apply $\Delta$ from
Theorem~\ref{cr12:ep:thm:normal} to obtain a $D$-computable array $Y$ with
$Y_j=^*W^H_j$ for each $j$. The even rows form a member of $\FF_{\vec A}$. Hence $D$
computes a coarse description of $\QQ(\vec A)$. The odd rows give the $D$-computable
approximation
\[
 h(n,s)=Y_{2n+1}(s)\longrightarrow H(n),
\]
so $H\leT D'$ by the limit lemma.

Conversely, suppose $D$ computes $Y\in\FF_{\vec A}$ and a convergent approximation
$h(n,s)\to H(n)$. Form the $D$-computable array $Z$ with $Z_{2n}=Y_n$ and
$Z_{2n+1}(s)=h(n,s)$. Each odd row is a finite variant of the relevant constant
sequence, and each even row is a finite variant of $A_n$. Thus $Z\in\FF_{\WW^H}$, and
$\Gamma(Z)$ is a coarse description of $\Fint_H$. Proposition~\ref{cr12:prop:spectra}
translates this statement about oracles computing descriptions into the exact
degree-spectrum equality.
\end{proof}

The constant-row special case is the familiar dyadic jump-cone phenomenon. The code
$\Rcode(H)(p(n,t))=H(n)$ has a $D$-computable coarse description exactly when
$H\leT D'$; compare Jockusch--Schupp \cite{JS} and the repository's dyadic
development \cite{Repo}. Theorem~\ref{cr12:ep:thm:factorization} attaches that
phenomenon to an arbitrary prescribed core without changing the core.

\subsection{Uniform reductions from ordinary Turing reductions}
\begin{lemma}[Uniform monotonicity]\label{cr12:ep:lem:uniform-mono}
If $H\leT K$, then $\Fint_H\leuc \Fint_K$.
\end{lemma}
\begin{proof}
Fix an oracle program $\Psi$ with $\Psi^K=H$. From an arbitrary $D\in\CD(\Fint_K)$
compute $Y=\Delta(D)$. Its even rows are finite variants of $A_n$; its odd rows
supply the convergent approximation
\[
 k_s(n)=Y_{2n+1}(s)\longrightarrow K(n).
\]
Define a total approximation $h_s(n)$ by running $\Psi^{k_s}(n)$ for at most $s$
steps, using its binary output if it halts with output $0$ or $1$, and using $0$
otherwise. For each fixed $n$, the true computation $\Psi^K(n)$ has finite time and
finite oracle use. Eventually $s$ exceeds that time and $k_s$ is correct on every
queried input. Consequently $h_s(n)\to H(n)$.

Keep the even rows of $Y$, and replace its odd rows by the sequences
$s\mapsto h_s(n)$. The resulting array lies in $\FF_{\WW^H}$. Apply $\Gamma$. All
steps use one total computable functional determined by the index of $\Psi$, and no
convergence modulus or extra jump is used. This proves the uniform reduction.
\end{proof}

\subsection{Reflection of order on an upper cone}
\begin{theorem}[Order-embedded upper cone in every fiber]\label{cr12:ep:thm:embedding}
Let $\Aplus=\bigoplus_n A_n$. For $H,K\geT \Aplus'$,
\[
 \Fint_H\lenc \Fint_K\quad\Longleftrightarrow\quad
 \Fint_H\leuc \Fint_K\quad\Longleftrightarrow\quad H\leT K.
\]
Hence both coarse-degree structures contain an order-embedded copy of the Turing
upper cone above $\degT \Aplus'$ all of whose members have core $\I_{\vec A}$.
\end{theorem}
\begin{proof}
The right-to-left implication, including uniformity, is
Lemma~\ref{cr12:ep:lem:uniform-mono}; every uniform coarse reduction is also
nonuniform.

For the remaining implication assume $\Fint_H\lenc \Fint_K$. Relativized Friedberg
jump inversion gives a set $D\geT \Aplus$ with $D'\eqT K$, since $K\geT \Aplus'$. A
proof of exactly this form is Lemma~\ref{cr12:lem:inversion} (with $X=\Aplus$).
Because $D$ computes the complete generator array, $D$ computes $\QQ(\vec A)$. The
spectrum factorization therefore says that $D$ computes a coarse description of
$\Fint_K$. Nonuniform reducibility transfers this to a $D$-computable coarse
description of $\Fint_H$. Applying the same factorization again yields
\[
 H\leT D'\eqT K.
\]
This proves order reflection. If $H\eqT K$, the uniform monotonicity lemma in both
directions gives $\Fint_H\equc \Fint_K$, so the map factors through Turing degrees.
Reflection shows that it is injective and has the asserted order.
\end{proof}

The upper-cone hypothesis is a sufficient condition allowing the reflecting oracle
$D$ to compute the original array. No claim is made that this threshold is optimal
for every presentation. The spectrum identity alone would not prove the positive
\emph{uniform} reduction; the separate construction in
Lemma~\ref{cr12:ep:lem:uniform-mono} is needed.

\subsection{Exact pairs with a prescribed common jump}
Let $\Theta_{\WW^H}$ denote the finite-join-jump oracle for the interleaved sequence
in \eqref{cr12:ep:eq:W}. The following computation is important: adding individually
computable rows need not preserve this \emph{uniform} oracle, because their constant
values can encode $H$.

\begin{lemma}[Oracle accounting]\label{cr12:ep:lem:oracle-account}
Uniformly in the presentations,
\begin{equation}\label{cr12:ep:eq:H-account}
 \Theta_{\WW^H}\eqT \Theta_{\vec A}\oplus H,
 \qquad \Theta_{\vec A}\leT \Aplus'.
\end{equation}
In particular $H\geT \Aplus'$ implies $\Theta_{\WW^H}\eqT H$.
\end{lemma}
\begin{proof}
Every finite initial join of the $A_n$ is a computable projection of a finite initial
join of the $W^H_j$, uniformly in its length. Jump monotonicity gives
$\Theta_{\vec A}\leT \Theta_{\WW^H}$. Also $H(n)$ is the first bit of the $(2n+1)$st
row, so a sufficiently large finite-join jump computes it uniformly; hence
$H\leT \Theta_{\WW^H}$.

Conversely, a finite initial join of the interleaved rows consists of finitely many
$A_n$ together with finitely many constant rows. Given those finitely many bits of
$H$, an oracle program using this join can be translated into one using the
appropriate $\Alt m$: replace queries to an odd row by its known constant answer and
queries to an even row by the corresponding finite-join query. Therefore its halting
problem is decidable in $\Alt m'$ using these finite parameters. The translation is
uniform from the prefix length and the requisite bits of $H$, proving
$\Theta_{\WW^H}\leT \Theta_{\vec A}\oplus H$.

Finally the projection $\Alt m\leT \Aplus$ is uniform in $m$, so the induced
reduction of $\Alt m'$ to $\Aplus'$ is uniform in $m$. Taking their countable join
proves $\Theta_{\vec A}\leT \Aplus'$. This uses monotonicity of the jump, not
distribution over finite joins.
\end{proof}

\begin{theorem}[Prescribed-jump exact pairs in a single coarse class]\label{cr12:ep:thm:prescribed-jump}
Fix $H\geT \Aplus'$ and $m_0$. There is an $H$-computable continuous injection
$P\mapsto D_P$ into $\CD(\Fint_H)$ such that, for $P\ne Q$,
\begin{equation}\label{cr12:ep:eq:prescribed-pair}
 \Low(D_P)\cap\Low(D_Q)=\I_{\vec A},\qquad
 H\leT D_P'\leT H\oplus P.
\end{equation}
There is one $H$-computable null envelope, with an $H$-computable density modulus and
prefix-density bound $2^{-m_0}$, covering all errors against $\Fint_H$. Every
computable branch parameter yields $D_P'\eqT H$. Thus any two distinct computable
parameters give an exact pair with prescribed common jump $H$.
\end{theorem}
\begin{proof}
Apply Theorem~\ref{cr12:ep:thm:headline-pairs} to the sequence $\WW^H$. Its generated
ideal is $\I_{\vec A}$, and Lemma~\ref{cr12:ep:lem:oracle-account} identifies its
construction oracle with $H$. This proves all assertions except the lower bound on
each jump. But $D_P\in\CD(\Fint_H)$, so the spectrum factorization gives
$H\leT D_P'$. For computable $P$ the upper bound reduces to $H$, proving equality.
\end{proof}

Notice that $\Fint_H\eqT \Aplus\oplus H\eqT H$ under this hypothesis, whereas a
computable-parameter description with $D_P'\eqT H$ is strictly below $H$. This is
compatible with belonging to the same coarse class: coarse descriptions need not
preserve the original Turing degree. Pairwise common information has been held fixed
at $\I_{\vec A}$ while the exact jump of selected descriptions is prescribed
independently above the stated threshold.

\subsection{Continuum many classes without least representatives}
\begin{corollary}\label{cr12:ep:cor:continuum}
Every countable Turing ideal is the core of continuum many different nonuniform
coarse degrees, and of continuum many different uniform coarse degrees, each with no
least Turing-degree representative.
\end{corollary}
\begin{proof}
Fix $\vec A$ and restrict the embedding of Theorem~\ref{cr12:ep:thm:embedding} to
$H\geT \Aplus''$. If the ideal is nonprincipal, Corollary~\ref{cr12:cor:infimum}
already excludes a least representative. If it is principal, say
$\I_{\vec A}=\Low(Z)$, any least representative would have degree $\degT Z$. Since
$Z$ is below some finite join, $Z\leT \Aplus$ and $Z'\leT \Aplus'$. But if $\degT Z$
belonged to $\Spec(\Fint_H)$, Theorem~\ref{cr12:ep:thm:factorization} would give
\[
 \Aplus''\leT H\leT Z'\leT \Aplus',
\]
contradicting strictness of the jump. Thus the principal case also has no attained
least degree. Its infimum is $\degT Z$; in the nonprincipal case there is no
infimum.

There are continuum many Turing degrees above $\Aplus''$: the sets $\Aplus''\oplus R$
for $R\in\Cantor$ form a continuum-sized collection, and each degree contains only
countably many sets. In ZFC a countable-to-one partition of a continuum-sized set has
continuum many classes. The order embedding preserves distinctness in both
coarse-degree structures. There cannot be more than continuum many binary coarse
degrees, so the cardinality is exactly continuum.
\end{proof}

This completes Theorem~\ref{cr12:ep:thm:headline-fibre}. The result is a failure of
classification by common information, not a failure of core realization: every
allowable core occurs, but fixing it leaves enough room for an entire upper cone of
degree-theoretic complexity.

\section{Uniformity, comparison, and proof boundaries}\label{cr12:ep:sec:audit}
\subsection{A uniform core would collapse}
There are three different notions of uniformity in the preceding arguments: one
functional converting descriptions to arrays; a uniform join of the original
generators; and one functional extracting a fixed set from all descriptions. Only
the first is supplied by the normal-form theorem. The second is deliberately not
recovered from an arbitrary solution, and the third is impossible for a
noncomputable set.

\begin{proposition}[No uniform extraction of noncomputable common information]\label{cr12:ep:prop:uniform-core}
For any $X,C\in\Cantor$, the following are equivalent:
\[
 C\text{ is computable};\qquad
 (\exists e)(\forall D\in\CD(X))\ \Phi_e^D=C.
\]
\end{proposition}
\begin{proof}
A computable $C$ can be produced without using its oracle. Conversely, suppose one
functional produces $C$ from every description. Every finite binary string extends
to a member of $\CD(X)$, simply by modifying a finite prefix of $X$. Consequently any
finite convergent trace of that functional on input $n$ must output $C(n)$: extend
its finite oracle answers to a description and use the assumed correctness. Search
computably for any such trace. One exists because the functional is total on $X$
itself. The search computes $C(n)$ without an oracle.
\end{proof}

Thus $\Core(X)$ is genuinely a \emph{nonuniform} intersection of lower cones. This
proposition also explains why the finite exceptional sets in majority decoding
cannot be uniformly corrected to recover an arbitrary generator from every coarse
description. The uniform coarse reductions of Section~\ref{cr12:ep:sec:fibres} avoid
that impossible step: they only transform one family of converging approximations
into another.

\mergenote{This answers the last task of plan target~C4 (``decide whether the uniform
core, defined with a single functional, behaves differently''): it is always
$\Comp$. Report~11 of this programme proves the relativized form (its
Proposition~5.3 in the delivered numbering).}

\subsection{Dependency and correctness checks}
The proof has a small number of sensitive points, each made explicit in the text.
\begin{enumerate}[label=\textup{(\arabic*)}]
\item \textbf{Finite row errors are not a uniform finite error set.} The passage to
density zero uses a fixed finite set of columns followed by a small-density tail; it
never takes the union of all row errors to be finite.
\item \textbf{Positive column density is used before decoding.} A global density-zero
error set induces density-zero errors in every fixed row because the column
enumeration has bounded linear growth. No arbitrary sparse subsequence is used.
\item \textbf{The search oracle is a finite join.} Conditions fix complete rows;
possible convergence is enumerable in the finite join of those rows. A negative
existence answer is decided by that finite join's jump. No unproved effective
totality test occurs.
\item \textbf{Jump accounting retains the presentation.} $\Theta_{\vec A}$ uses jumps of
finite joins. Adding individually computable but nonuniformly assembled rows can
increase it. Lemma~\ref{cr12:ep:lem:oracle-account} tracks that increase exactly for
the fiber construction.
\item \textbf{A perfect family requires a branch parameter.} Only its finite tree is
computed by the construction oracle. A general branch is allowed its own $P$,
yielding the bound in \eqref{cr12:ep:eq:jump-bound}; computable branch parameters
give the two low-complexity witnesses.
\item \textbf{Density transport is explicit.} The fiber construction is an actual
interleaving of rows inside the same code, not an appeal to preservation of
asymptotic density under arbitrary computable permutations.
\item \textbf{Uniform and nonuniform reductions are proved separately.} Spectrum
inclusion supplies the necessary condition for order reflection. A total functional
on descriptions supplies the sufficient uniform reduction.
\item \textbf{The mask obstruction needs exactness with the core.}
Corollary~\ref{cr12:ep:cor:mask} assumes $\Low(D)\cap\Low(E)=\Core(X)$. Without this
equality, two descriptions could share additional information written only on the
null mask.
\end{enumerate}

\subsection{A practical formalization decomposition}\label{cr12:ep:subsec:formal}
The repository's existing set-based Turing-reducibility and coarse-density
infrastructure is a natural starting point \cite{RepoReadme}. A formal development
should separate the purely combinatorial code from the oracle semantics and from the
infinitary construction.

\paragraph{Coding layer.}
Formalize the pairing $p$, its inverse via the power of two dividing $x+1$, the exact
column and tail counts, the block partition, and the finite-majority error
implication. These are arithmetic and finite-set statements. Next prove the density
transfer, estimate \eqref{cr12:ep:eq:tailbound}, and the two directions of the
normal-form theorem. The executable finite checks in the archive exercise these
definitions, but are not substitutes for these proofs.

\paragraph{Oracle layer.}
Use a model of partial oracle computations with finite use. Prove a trace-extension
theorem and an effective enumeration of traces compatible with finitely many fixed
rows. Package Lemma~\ref{cr12:ep:lem:possible} with its exact finite-join oracle,
rather than assuming a generic forcing decision procedure. Jump monotonicity and
uniform index translations must be supplied explicitly.

\paragraph{Construction layer.}
Represent a condition by a finite list of finite error masks. State the invariants of
the level construction: predecessor extension, common end-of-level row length,
permanent distinct markers, persistent cross requirements, and recorded correct jump
decisions. Define branches from the row-stabilization property. Derive the
continuous injection and the common null envelope from the same finite tree, so that
their effectivity is not hidden behind an application of an abstract perfect-set
theorem.

\paragraph{Degree-theoretic layer.}
After quotienting by Turing equivalence, prove core realization, spectrum
factorization, and the two implications in the fiber embedding. The only extra
classical constructions needed for order reflection are the limit lemma and relative
jump inversion, both given in Part~I (Lemmas~\ref{cr12:lem:limit}
and~\ref{cr12:lem:inversion}; source 08 gives them in its appendices). The
common-jump theorem should then be a short corollary of the explicit
oracle-accounting lemma.

This is a proposed implementation plan, not a report of completed formalization. It
deliberately keeps machine-level uniformity statements separate from existence
statements in the degree order.

\mergenote{Of the coding layer, the Lean library already proves the tail count, the

\section{Source 08: further research questions}\label{cr12:ep:sec:questions}
The following are proposed next problems for this programme. They are not blanket
assertions that every formulation below is absent from the published literature;
each should receive a dedicated literature check before a priority claim.

\begin{question}[Which upward-closed spectra occur?]\label{cr12:ep:q:spectra}
Characterize the sets of Turing degrees that occur as $\Spec(X)$. Core realization
determines their common lower bounds, but this is far from a spectrum
classification. Even with a fixed core $\I$, Theorem~\ref{cr12:ep:thm:embedding}
leaves an upper cone's worth of different possibilities. Can the row-finite normal
form be extended to capture all coarse spectra, or can one prove that some coarse
spectra are not of this form?
\end{question}

\begin{question}[Minimal representatives, not least representatives]\label{cr12:ep:q:minimal}
For a nonprincipal $\I$ and the explicit classes $\Fint_H$, when does $\Spec(\Fint_H)$
contain a minimal degree? Can one identify a presentation and parameter for which it
has no minimal element? The present proof excludes a least element but neither
establishes nor excludes minimality. The mass problem $\FF_{\vec A}$ offers a concrete
place to test minimal-upper-bound methods.
\end{question}

\begin{question}[Optimal jump thresholds]\label{cr12:ep:q:thresholds}
The common-jump theorem works for $H\geT \Aplus'$, whereas the unparameterized
construction already gives pair jumps bounded by $\Theta_{\vec A}\leT \Aplus'$.
Determine the least hypotheses on $H$ permitting an exact pair for $\I_{\vec A}$ in a
prescribed coarse-description class with both jumps exactly $H$. Is there a
presentation-invariant characterization, rather than one stated using a particular
uniform join?
\end{question}

\begin{question}[Sharper effective error control]\label{cr12:ep:q:budget}
The family has a common $\Theta_{\vec A}$-computable null envelope and can be confined
to a tail of arbitrarily small global prefix density. Can one simultaneously impose
an arbitrary prescribed unbounded sublinear counting budget while retaining an
arbitrary nonprincipal core and the same jump bound? The present tail argument does
not do this: the sizes of individual finite block corrections are unrestricted.
\end{question}

\begin{question}[When do two presentations give the same coarse degree?]\label{cr12:ep:q:presentations}
Find useful necessary and sufficient conditions on generator sequences $\vec A$ and
$\vec E$ for $\QQ(\vec A)\leuc\QQ(\vec E)$ or $\QQ(\vec A)\lenc\QQ(\vec E)$. Inclusion of
generated ideals is necessary but, by the fiber theorem, not sufficient. A natural
target is an effective transformation of finite-variant arrays that does not require
finding their unknown finite corrections.
\end{question}

\begin{question}[Structure internal to one core fiber]\label{cr12:ep:q:fibre}
The fiber contains an order-embedded upper cone, but this alone does not identify
which joins, meets, antichains, or intervals in the coarse-degree order remain inside
the fiber. Determine whether the embeddings can preserve additional operations, or
whether common information is necessarily created by some coarse joins.
\end{question}

\begin{question}[Other reducibilities and ideals]\label{cr12:ep:q:other}
Which parts of the construction survive for effective-dense or generic descriptions,
for bounded-error variants, or with hyperarithmetic reducibility replacing Turing
reducibility? The majority normalization is specific to permitted errors. A
description notion that allows omissions but forbids errors requires a different
normal form, and no answer to its least-representative question follows
automatically from this paper.
\end{question}

\begin{question}[Formal and foundational economy]\label{cr12:ep:q:formal}
Implement the finite-trace and row-mask argument in the repository and determine the
weakest classical choice and comprehension principles needed for the realization and
effective-family statements. The parameterized theorem for a given sequence avoids
selecting an enumeration of an arbitrary ideal; separating these formulations may
clarify the foundational strength.
\end{question}

\mergenote{Status of these questions in the merged report. Question~\ref{cr12:ep:q:spectra}
is Part~I's Question~\ref{cr12:q:spectra} and Part~III's
Question~\ref{cr12:lr:q:spectra}. Question~\ref{cr12:ep:q:presentations} is Part~III's
Question~\ref{cr12:lr:q:presentations} for another code. For
Question~\ref{cr12:ep:q:fibre}, Part~I's Theorem~\ref{cr12:thm:embedding} gives a
\emph{join-preserving} upper-cone embedding into every fiber, which by
Remark~\ref{cr12:ep:rem:filtercompare} covers source 08's map as well, and
Corollary~\ref{cr12:cor:cofinal} shows that no fiber has a maximal member or a

report~10 of this programme shows that cone-avoiding compactness fails, so no

\subsection{Source 08's conclusion}\label{cr12:ep:sec:conclusion}
The core-realization problem has a clean answer: there is no additional restriction
beyond being a countable Turing ideal. Positive-density columns protect individual
generators, and robust finite blocks reduce coarse errors to independent finite
errors in the rows. Classical exact-pair reasoning can then be performed inside this
row-finite mass problem, with every search charged to a finite join and every
decision to its jump.

The second conclusion is equally important for classification. The core records
unavoidable individual information, but not the cost of assembling solutions
uniformly. By interleaving constant rows carrying a separate parameter, one preserves
the core while changing that assembly problem. This produces an upper-cone embedding
in every fiber, exact spectrum constraints, and exact pairs with controlled common
jumps. These are proved extensions of the repository programme; claims of historical
priority or proof-assistant certification are separate questions and are not made
here.

\subsection{Statements at a glance}
We identify a Turing ideal with its collection of set representatives. Thus a nonempty
family $\I\subseteq\Cantor$ is a Turing ideal when it is downward closed under Turing
reducibility and closed under finite joins. Write $\Low(A)=\{C:C\leT A\}$.

\begin{theorem}[Core realization]\label{cr12:lr:thm:mainreal}
A family of sets is the coarse core of some binary set if and only if it is a
countable Turing ideal. More explicitly, if
\[
 A_0\leT A_1\leT\cdots,\qquad
 \I=\bigcup_{n\in\N}\Low(A_n),
\]
then the layered carrier $\Lam$ defined in Section~\ref{cr12:lr:sec:realization}
satisfies
\[
 \Core(\Lam)=\I,\qquad \Lam\leT \Aplus:=\bigoplus_n A_n.
\]
No computable enumeration of the ideal is assumed.
\end{theorem}

\begin{theorem}[Fixed-core embeddings]\label{cr12:lr:thm:mainembed}
For the carrier and $\Aplus$ above, let $T_{\Lam}(H)=\Lam\oplus\Rcode(H)$, where $\Rcode$
is the dyadic code. For all $H$,
\[
 \Core(T_{\Lam}(H))=\I,\qquad
 \Spec(T_{\Lam}(H))=\Spec(\Lam)\cap\{\mathbf d:H\leT D',\ D\in\mathbf d\}.
\]
For $H,K\geT \Aplus'$,
\begin{equation}\label{cr12:lr:eq:introembed}
 H\leT K\quad\Longleftrightarrow\quad
 T_{\Lam}(H)\lenc T_{\Lam}(K)
 \quad\Longleftrightarrow\quad
 T_{\Lam}(H)\leuc T_{\Lam}(K).
\end{equation}
The induced maps on degrees preserve finite joins. The canonical representative
$T_{\Lam}(H)$ has Turing degree $\degT(H)$ on this parameter cone.
\end{theorem}

\begin{theorem}[Perfect exact-pair realization]\label{cr12:lr:thm:mainperfect}
For every $\vec A,H$, every $\varepsilon>0$, and every $L\in\N$, there is a perfect set
$\mathcal P\subseteq\CD(T_{\Lam}(H))$ such that every $D\in\mathcal P$ extends
$T_{\Lam}(H)\rest L$, satisfies $d(D,T_{\Lam}(H))<\varepsilon$, and, for distinct
$D,E\in\mathcal P$,
\[
 \Low(D)\cap\Low(E)=\I.
\]
A binary splitting system parametrizing $\mathcal P$ is computable in
$(\Aplus\oplus H)'$. In particular, there are two such distinct descriptions below
$(\Aplus\oplus H)'$. The whole perfect set is not asserted to consist of sets below
that oracle.
\end{theorem}

\section{Two codes and two kinds of recovery}\label{cr12:lr:sec:codes}
\subsection{Positive-density columns}
For $n,k\in\N$, let
\begin{equation}\label{cr12:lr:eq:columns}
 p(n,k)=2^n(2k+1)-1,\qquad C_n=\{p(n,k):k\in\N\}.
\end{equation}
These are a computable partition of $\N$, with
\begin{equation}\label{cr12:lr:eq:tailcount}
 \rho(C_n)=2^{-n-1},\qquad
 \left|\bigcup_{n\geq s}C_n\cap[0,m)\right|=\left\lfloor\frac m{2^s}\right\rfloor.
\end{equation}
The tail identity follows because $k$ lies in the union exactly when $2^s$ divides
$k+1$.

For a set $D$, denote its pullback along the $n$th column by $D_n(k)=D(p(n,k))$.
\begin{lemma}[Restriction and finite heads]\label{cr12:lr:lem:columns}
For all $X,D,n$,
\begin{equation}\label{cr12:lr:eq:pullback}
 \delta(X_n,D_n)\leq2^{n+1}\delta(X,D).
\end{equation}
In particular, a coarse description restricts to a coarse description on each column.
Conversely, if each $(X\sd D)\cap C_n$ is finite, then $D\approx X$.
\end{lemma}
\begin{proof}
The first $t$ elements of $C_n$ lie below $p(n,t-1)+1$, and the ratio of that endpoint
to $t$ tends to $2^{n+1}$. Bounding their errors by all errors below that endpoint and
taking a limsup proves \eqref{cr12:lr:eq:pullback}. For the converse, fix $s$. Errors
on the first $s$ columns form a finite set, and all remaining errors lie in a tail of
upper density $2^{-s}$. Thus $\delta(X,D)\leq2^{-s}$ for every $s$.
\end{proof}

\subsection{A robust repeated-block code}
Let $I^!_m=[(m+1)!,(m+2)!)$ and let $\lambda(m)=\nu_2(m+1)$. The intervals partition the
positive integers. Define
\begin{equation}\label{cr12:lr:eq:blockcode}
 \Jfac(A)(0)=0,\qquad \Jfac(A)(k)=A(\lambda(m))\quad(k\in I^!_m).
\end{equation}
This is a factorial-block coarsening with a computable repetition schedule, a variant
of the constructions in \cite[Section~2]{HJKS}. The repetition will distinguish
recovery of an entire set from pointwise convergence of an approximation.

\mergenote{$\Jfac$ is neither Part~I's $\Jcode$ (blocks $[2^k,2^{k+1})$, each label once)
nor source 08's $\Jsh$: its blocks are factorial and every label $k$ recurs on the
infinitely many blocks $I^!_m$ with $\nu_2(m+1)=k$, which is what makes the recovery
radius $1/2$ below.}

\begin{lemma}[Robust recovery]\label{cr12:lr:lem:robust}
The code $\Jfac$ is computable from its argument. If
\[
 \delta(D,\Jfac(A))<\tfrac12,
\]
then $A\leT D$. In particular, every coarse description of $\Jfac(A)$ computes $A$.
There is also a single procedure which, from such a $D$, produces total sets
$\tilde A_s$ with $\tilde A_s=A$ for every sufficiently large $s$.
\end{lemma}
\begin{proof}
Let $v_D(m)$ be the majority bit of $D$ on $I^!_m$, breaking ties by choosing $0$. If
this bit is wrong, at least half the block consists of errors, and therefore
\[
 \rho_{(m+2)!}(D\sd\Jfac(A))\geq
 \frac{(m+2)!-(m+1)!}{2\,(m+2)!}
 =\frac{m+1}{2(m+2)}.
\]
The right side tends to $1/2$. Under the strict error hypothesis, only finitely many
blocks can have a wrong majority. Fix $M$ beyond them. Given $k$, find an $m\geq M$
with $\lambda(m)=k$ and output $v_D(m)$. Every label occurs infinitely often, so this
computes $A$. The integer $M$ is a finite parameter in the reduction; it is not claimed
to be recoverable uniformly from $D$.

For the last assertion, let $m(k,s)$ be the least $m\geq s$ with label $k$ and put
$\tilde A_s(k)=v_D(m(k,s))$. This is total and uniform in $D,k,s$. For all $s\geq M$,
it equals $A$ on \emph{every} input simultaneously.
\end{proof}

\begin{remark}[What uniformity does not say]
The lemma does not give one functional that outputs $A$ exactly from every
description of $\Jfac(A)$. The uniformly available object is an eventually correct
sequence of whole sets. The exact computation of $A$ may use a different finite
stabilization parameter for each description. This is sufficient for membership in a
Turing core.
\end{remark}

\subsection{The dyadic code and the jump}
The dyadic code $\Rcode(H)(p(n,k))=H(n)$ has a different recovery property. It repeats
one bit on each positive-density column. Unlike $\Jfac$, it gives pointwise eventual
information, with no single stage at which all decoded bits must be correct.

Source 10 then proves the relativized limit lemma (its Lemma~3.4), the dyadic
description criterion ``$D$ computes a coarse description of $\Rcode(H)$ iff
$H\leT D'$'' with $\Spec(\Rcode(H))=\mathcal Q_H$ (its Theorem~3.5), and uniform dyadic
monotonicity and joins, $H\leT K\Rightarrow\Rcode(H)\leuc\Rcode(K)$ and
$\Rcode(H\oplus K)\equc\Rcode(H)\oplus\Rcode(K)$ (its Lemma~3.6). These are
Lemma~\ref{cr12:lem:limit}, Theorem~\ref{cr12:thm:jump-spectrum} and
Proposition~\ref{cr12:prop:transport} of Part~I, with the same proofs. Source 10 notes
that the unrelativized criterion is due to Jockusch and Schupp
\cite[Theorem~2.19]{JS}, that the relativized spectrum formulation is already in the
ProveIt synthesis, and that the proofs are included to expose the exact uniformity
needed next: in the monotonicity proof each oracle query requires only a finite
majority computation, and every procedure is total and fixed independently of the
supplied description.

\section{Realizing every countable ideal}\label{cr12:lr:sec:realization}
\subsection{The approximation principle}
We first record the published compactness theorem in the exact form used.
\begin{theorem}[Cone-avoiding compactness, HJKS]\label{cr12:lr:thm:compactness}
Let $A,X$ be sets. If for every $\varepsilon>0$ there is a set $Y$ such that
$\delta(X,Y)\leq\varepsilon$ and $A\nleT Y$, then some $D\in\CD(X)$ satisfies
$A\nleT D$.
\end{theorem}
This is \cite[Theorem~3.7]{HJKS}. We use it as published background, not as a new
result. Its contrapositive gives
\begin{equation}\label{cr12:lr:eq:radius}
 A\in\Core(X)\quad\Longleftrightarrow\quad
 (\exists\eta>0)(\forall Y)\,[\delta(X,Y)<\eta\Longrightarrow A\leT Y].
\end{equation}
The switch between strict and non-strict error tolerances is harmless after shrinking
a positive radius. The reverse implication follows simply because every description
has error zero.

\mergenote{Second route (source 10) to Theorem~\ref{cr12:thm:radius}:
\eqref{cr12:lr:eq:radius} is \eqref{cr12:eq:radius}, which Part~I proves from Baire
category.}

\begin{lemma}[Ideal approximation]\label{cr12:lr:lem:idealapprox}
Suppose $\I$ is a Turing ideal and, for every $\varepsilon>0$, there is a set $T\in\I$
with $\delta(X,T)<\varepsilon$. Then $\Core(X)\subseteq\I$. If in addition
$\I\subseteq\Core(X)$, equality holds.
\end{lemma}
\begin{proof}
If $A\notin\I$, downward closure implies $A\nleT T$ for every $T\in\I$. The
approximants therefore satisfy the hypothesis of
Theorem~\ref{cr12:lr:thm:compactness}. Thus $A\notin\Core(X)$. Equivalently, one can
apply \eqref{cr12:lr:eq:radius} to a core member and choose a sufficiently accurate
approximant in the ideal.
\end{proof}
This generalizes the familiar argument that arbitrary accuracy by computable
approximants forces a trivial core. Countability is not required in the lemma, though
it is necessary for an ideal to equal a core.

\subsection{The layered carrier}
Let $\I$ be a countable Turing ideal. Enumerating its members set-theoretically and
taking finite joins produces a cofinal sequence $\vec A=(A_n)$ with
\begin{equation}\label{cr12:lr:eq:cofinal}
 A_n\leT A_{n+1},\qquad \I=\bigcup_n\Low(A_n).
\end{equation}
No effectiveness is built into this enumeration. Define
\begin{equation}\label{cr12:lr:eq:carrier}
 \Lam(p(n,k))=\Jfac(A_n)(k).
\end{equation}
A standard computable pairing is used for the presentation oracle
$\Aplus=\bigoplus_n A_n$, so the carrier is uniformly computable from $\Aplus$.

\mergenote{The increasing-chain hypothesis \eqref{cr12:lr:eq:cofinal} is used below only
to place each truncation in $\Low(A_{s-1})$ and each protected pattern in
$\Low(A_s)$. For an arbitrary sequence one may pass to $\hat A_n=\Alt{n+1}$, which
is increasing and generates the same ideal; Part~I works with arbitrary sequences directly.}

\begin{proof}[Proof of Theorem~\ref{cr12:lr:thm:mainreal}]
Necessity is Lemma~\ref{cr12:lem:corebasic}. For sufficiency, let $D\in\CD(\Lam)$. Its
$n$th column describes $\Jfac(A_n)$, so $A_n\leT D$ by
Lemmas~\ref{cr12:lr:lem:columns} and~\ref{cr12:lr:lem:robust}. It follows that
$\I\subseteq\Core(\Lam)$.

For $s\geq1$, define the truncation
\begin{equation}\label{cr12:lr:eq:truncation}
 \Lambda_{\vec A,<s}(p(n,k))=
 \begin{cases}
  \Jfac(A_n)(k),&n<s,\\
  0,&n\geq s.
 \end{cases}
\end{equation}
It is computable from the finite join of $A_0,\ldots,A_{s-1}$, hence from $A_{s-1}$,
and belongs to $\I$. By \eqref{cr12:lr:eq:tailcount},
\begin{equation}\label{cr12:lr:eq:truncationbound}
 d(\Lam,\Lambda_{\vec A,<s})\leq2^{-s}.
\end{equation}
Lemma~\ref{cr12:lr:lem:idealapprox} now gives $\Core(\Lam)\subseteq\I$. The
computation from $\Aplus$ was explicit in \eqref{cr12:lr:eq:carrier}.
\end{proof}

\begin{remark}[Finite versus infinite uniformity]\label{cr12:lr:rem:nonuniform}
For each fixed $s$, finitely many reduction indices suffice to compute $\Lambda_{\vec A,<s}$ from
$A_{s-1}$. No algorithm is asserted to obtain those indices from $s$. Likewise, a
description computes each $A_n$, but this does not imply that it computes the infinite
join $\Aplus$: the reductions may depend on $n$ noncomputably. Confusing these two
assertions would destroy the distinction between a nonprincipal ideal and a principal
lower cone.
\end{remark}

Section~\ref{cr12:lr:sec:fusion} gives a second proof of the same core equality, by
constructing two descriptions whose common lower cone is exactly $\I$. That proof does
not appeal to cone-avoiding compactness.

\section{An independent perfect exact-pair construction}\label{cr12:lr:sec:fusion}
\subsection{Protected regions and reservoirs}
The following lemma permits the finite-information oracle to rise through an ideal.
Its assumptions are chosen to make all finite compatibility checks explicit.

\begin{definition}[An ideal-protected presentation]\label{cr12:lr:def:protected}
Let $\vec A$ satisfy \eqref{cr12:lr:eq:cofinal}. A set $X$ has an ideal-protected
presentation if there are uniformly computable increasing sets $P_s$ and positive
numbers $\epsilon_s\to0$ such that:
\begin{enumerate}[label=\textup{(\roman*)}]
\item every $\N\setminus P_s$ is infinite, and $\rho_m(\N\setminus P_s)\leq\epsilon_s$
for all $m\geq1$;
\item the total function which is $X$ on $P_s$ and zero elsewhere is computable in
$A_s$, for each fixed $s$;
\item $\I\subseteq\Core(X)$.
\end{enumerate}
An oracle $W$ with $X\leT W$ will bound the construction, but is not used as the bound
on common information.
\end{definition}

For a finite string $\sigma$, set
\[
 \Res(\sigma,s)=
 \{Y\succeq\sigma:(\forall k\geq|\sigma|)\,[k\in P_s\Longrightarrow Y(k)=X(k)]\}.
\]
A finite extension $\tau\succeq\sigma$ is admissible if it obeys the same restriction
below $|\tau|$. Admissibility is decidable in $A_s$: only finitely many protected
values are queried. It is also decidable in $W$.

\begin{lemma}[Cross-disagreement dichotomy]\label{cr12:lr:lem:cross}
Fix $s,\sigma,\tau,e,j$. Either there are admissible extensions $\alpha\succeq\sigma$,
$\beta\succeq\tau$, and an input $n$ for which
\begin{equation}\label{cr12:lr:eq:cross}
 \Phi_e^\alpha(n)\downarrow\ne\Phi_j^\beta(n)\downarrow,
\end{equation}
or every common total function of the form
\[
 G=\Phi_e^D=\Phi_j^E,
 \qquad D\in\Res(\sigma,s),\quad
 E\in\Res(\tau,s),
\]
is computable in $A_s$. The existence of witnesses to \eqref{cr12:lr:eq:cross} is a
$\Sigma^0_1(W)$ question.
\end{lemma}
\begin{proof}
Suppose there are no witnesses and a common total $G$ exists. With oracle $A_s$,
enumerate all admissible $\alpha$ and dovetail $\Phi_e^\alpha(n)$. Return the first
value obtained. Some prefix of $D$ supplies a convergent computation, so this search
terminates. A sufficiently long prefix of $E$ supplies the value $G(n)$ on the other
side. An incorrect returned value would therefore give \eqref{cr12:lr:eq:cross}, a
contradiction. The finite strings, $s$, and the finitely many indices needed to compute
protected values are constants in this reduction. This proves $G\leT A_s$, not
necessarily uniformly in those constants.

Using $W$ instead, admissibility is decidable and convergence on finite strings is
effectively enumerable. Thus existence of the displayed finite witnesses is c.e.\ in
$W$ and decidable in $W'$.
\end{proof}

\mergenote{Source 10 writes $H$ for the common function; it is $G$ here because $H$ is
the dyadic parameter.}

\begin{remark}[Why the product is legitimate]
The two extensions in \eqref{cr12:lr:eq:cross} are chosen independently. There is no
extra requirement that their disagreement set already have density zero, or satisfy a
joint budget. Each eventual path will approximate $X$ because the protected regions
increase. This separation of the compatibility condition from the limiting density
condition is what makes the no-disagreement search valid.
\end{remark}

\subsection{Fusion with a rising ideal bound}
\begin{theorem}[Ideal-protected fusion]\label{cr12:lr:thm:fusion}
Suppose $X$ has an ideal-protected presentation and $X\leT W$. Fix a starting level
$t$ and a length $L$. There is a binary splitting system $(\sigma_u)_{u\in2^{<\N}}$,
computable in $W'$, whose path map
\[
 D_Q=\bigcup_k\sigma_{Q\rest k}\qquad(Q\in\Cantor)
\]
is an injection into $\CD(X)$. Its image is perfect, every path extends $X\rest L$,
and distinct paths satisfy
\begin{equation}\label{cr12:lr:eq:exactpair}
 \Low(D_Q)\cap\Low(D_R)=\I.
\end{equation}
The system can be arranged so that $D_Q\in\Res(\sigma_{Q\rest k},t+k)$ and
\begin{equation}\label{cr12:lr:eq:fusionmetric}
 d(D_Q,X)\leq\epsilon_t,\qquad
 Q\rest k=R\rest k\Longrightarrow d(D_Q,D_R)\leq\epsilon_{t+k}.
\end{equation}
In particular, $\Core(X)=\I$.
\end{theorem}
\begin{proof}
Start with the root string $X\rest L$ at protection level $t$. At level $k$, the
current leaves are indexed by $u\in2^k$, each with reservoir parameter $s=t+k$.
Process every ordered pair of distinct leaves and every pair of functional indices
$e,j\leq k$. There are only finitely many tasks at that level.

For a task, ask $W'$ whether \eqref{cr12:lr:eq:cross} has witnesses in the two current
reservoirs. If it does, find such witnesses using $W$ and replace the two leaves by
those extensions. If it does not, leave them unchanged and retain the no-disagreement
conclusion of Lemma~\ref{cr12:lr:lem:cross}. All subsequent reservoirs for these
leaves are subsets of the current ones, so a forced disagreement persists, and so does
the relevance of a no-disagreement conclusion. Tasks already processed cannot be
injured.

After the finite task list, pad every leaf to a common larger length using the values
of $X$ at newly appended positions. For each leaf choose a fresh position outside
$P_s$, beyond this length, and form two extensions which agree with $X$ at intervening
positions and assign different bits at that position. Such a position exists because
the complement of $P_s$ is infinite. These siblings are incompatible. Pad further if
needed so that the next level has a common length strictly larger than the preceding
one. Regard the children as conditions with protection level $s+1$. Their reservoirs
are subsets of their parents' reservoirs: on previously protected positions the finite
extensions were admissible, and beyond the new prefixes $P_s\subseteq P_{s+1}$. New
errors on positions newly protected at level $s+1$ are confined to the finite prefix
and are permitted.

This describes a $W'$-computable construction. More formally, intermediate leaves can
be extended while tasks are processed, and the strings for a level are finalized
before its children are built. Descendants always extend the finalized strings. The
strictly increasing common lengths ensure total paths; sibling incompatibility ensures
that the map $Q\mapsto D_Q$ is injective.

\emph{Density.} For any fixed level $k$, let $M_k$ bound the lengths of its finalized
strings. Every path agrees with $X$ on $P_{t+k}$ beyond $M_k$. Thus, for every $m$,
\[
 \rho_m(D_Q\sd X)\leq\frac{M_k}{m}+\epsilon_{t+k}.
\]
Taking a limsup and then letting $k\to\infty$ gives $D_Q\approx X$. Since all paths
remain in the root reservoir and its prefix agrees with $X$, their errors are contained
in $\N\setminus P_t$, proving the first part of \eqref{cr12:lr:eq:fusionmetric}. If two
paths share a level-$k$ node, they agree below its prefix length and both agree with
$X$ on $P_{t+k}$ thereafter. Their disagreement is contained in
$\N\setminus P_{t+k}$, proving the second part.

\emph{Exactness.} Let $Q\ne R$, and let a set $G$ be computed from both paths by
functionals $e,j$. Choose $k$ sufficiently large that $e,j\leq k$ and the paths have
distinct level-$k$ nodes. Their task was processed at that level. A forced
cross-disagreement would contradict equality of the two total outputs. Hence the
no-disagreement alternative held, and Lemma~\ref{cr12:lr:lem:cross} gives
$G\leT A_{t+k}$, so $G\in\I$. Conversely, every path is a description of $X$, and
assumption (iii) implies that every member of $\I$ is below every path. This proves
\eqref{cr12:lr:eq:exactpair}.

\emph{Perfectness and core.} Equation~\eqref{cr12:lr:eq:fusionmetric} gives continuity
into the prefix-density metric. A continuous injection from compact Cantor space into
a metric space is a homeomorphism onto its image, so the image is compact and has no
isolated points. It is also perfect in the usual Cantor topology, by the same
injection and the growing prefix lengths. Finally, a core member is computed from any
two distinct paths; \eqref{cr12:lr:eq:exactpair} puts it in $\I$. The other inclusion
was an assumption.
\end{proof}

\subsection{Applying fusion to the carrier}
For $X=\Lam$, take
\[
 P_s=\bigcup_{n<s}C_n,\qquad \epsilon_s=2^{-s},\qquad W=\Aplus.
\]
All hypotheses hold. The protected values are computable from $A_s$, the complement is
an infinite arithmetic progression, and the lower core inclusion was proved using
robust recovery only. Therefore Theorem~\ref{cr12:lr:thm:fusion} independently proves
$\Core(\Lam)=\I$ and gives an $\Aplus'$-computable splitting system of pairwise exact
descriptions.

This establishes that the ideal-realization theorem does not depend on any admitted
theorem in the repository or on our using Theorem~\ref{cr12:lr:thm:compactness} as a
black box. The compactness proof is shorter and yields the useful general
approximation principle; the fusion proof supplies additional witnesses and a
presentation-relative complexity bound.

\section{Varying coarse strength without changing the core}\label{cr12:lr:sec:insertion}
\subsection{Core-preserving insertion}
For an arbitrary parameter set $H$, define
\begin{equation}\label{cr12:lr:eq:decorated}
 T_{\Lam}(H)=\Lam\oplus\Rcode(H).
\end{equation}
The intended roles of its two halves are different. The carrier protects the
information in $\I$. The dyadic half constrains the jump of an oracle computing a
description, while being approximable arbitrarily well by individually computable
sets.

\begin{theorem}[Core-preserving spectral cuts]\label{cr12:lr:thm:insertion}
For every $H$,
\begin{align}
 \Core(T_{\Lam}(H))&=\I,\label{cr12:lr:eq:fixedcore}\\
 \Spec(T_{\Lam}(H))&=\Spec(\Lam)\cap\{\mathbf d:H\leT D',\ D\in\mathbf d\}.
 \label{cr12:lr:eq:spectralcut}
\end{align}
\end{theorem}
\begin{proof}
Every description of $T_{\Lam}(H)$ projects to a description of $\Lam$, so
$\I\subseteq\Core(T_{\Lam}(H))$.

Let $U_s(H)$ agree with $\Rcode(H)$ on columns $C_n$, $n<s$, and be zero on the others.
For each fixed $s$, this is a computable set: only the finitely many bits
$H(0),\ldots,H(s-1)$ are needed, and they can be built into its program. A uniform
computable map from $s$ to such programs is not being asserted. Its error satisfies
$d(U_s(H),\Rcode(H))\leq2^{-s}$. The set
\[
 \Lambda^H_{\vec A,<s}=\Lambda_{\vec A,<s}\oplus U_s(H)
\]
belongs to $\I$ and satisfies $d(\Lambda^H_{\vec A,<s},T_{\Lam}(H))\leq2^{-s}$. To see the last
inequality also for odd initial-segment lengths, apply the bound separately to the
first $\lceil m/2\rceil$ and $\lfloor m/2\rfloor$ positions in the two halves; their
lengths sum to $m$. Lemma~\ref{cr12:lr:lem:idealapprox} proves
\eqref{cr12:lr:eq:fixedcore}.

Equation~\eqref{cr12:lr:eq:spectralcut} is Proposition~\ref{cr12:prop:joins} together
with Theorem~\ref{cr12:thm:jump-spectrum}.
\end{proof}

\mergenote{Second route (source 10) to the case $X=\Lam$ of
Theorem~\ref{cr12:thm:filter}. Part~I derives \eqref{cr12:lr:eq:fixedcore} from core
neutrality (Theorem~\ref{cr12:thm:neutral}) for an arbitrary base set; this proof uses
approximants lying in the ideal itself.}

\begin{remark}[No general additivity of cores is assumed]
The proof did not infer the core of a join from the cores of its halves. Such an
inference would discard possible joint information. Here the exclusion of extra
common information comes from explicit approximants lying in the same ideal. The
exact-pair proof below gives a second exclusion argument.
\end{remark}

\subsection{Exact pairs for every parameter}
Define the protected regions in the joined space by
\[
 P_s^*=\{2k:k\in P_s\}\cup\{2k+1:k\in P_s\},
 \qquad P_s=\bigcup_{n<s}C_n.
\]
They are uniformly computable and increasing, with infinite complements. For every
$m\geq1$,
\begin{align*}
 |(\N\setminus P_s^*)\cap[0,m)|
 &=\left\lfloor\frac{\lceil m/2\rceil}{2^s}\right\rfloor
   +\left\lfloor\frac{\lfloor m/2\rfloor}{2^s}\right\rfloor\\
 &\leq 2^{-s}m.
\end{align*}
The values of $T_{\Lam}(H)$ on $P_s^*$ are computable from $A_s$ and the finitely many
bits $H(0),\ldots,H(s-1)$. Hence they are computable in $A_s$ for each fixed $s$. Those
finitely many bits do not enlarge its Turing degree. The whole target is computable in
$W=\Aplus\oplus H$.

\begin{proof}[Proof of Theorem~\ref{cr12:lr:thm:mainperfect}]
Apply Theorem~\ref{cr12:lr:thm:fusion} to these protected regions and choose $t$ with
$2^{-t}<\varepsilon$. The lower inclusion $\I\subseteq\Core(T_{\Lam}(H))$ uses only
projection and robust recovery, so this is also an independent proof of
\eqref{cr12:lr:eq:fixedcore}. The construction gives all the asserted properties,
including the $(\Aplus\oplus H)'$ bound on its splitting system. Taking two distinct
computable paths through the binary index tree yields two descriptions below that
oracle.
\end{proof}

A useful distinction follows. The location of a perfect family can be controlled by
one jump of a presentation oracle, but its uncountably many members cannot all be
computable in that oracle: each oracle computes only countably many sets. The correct
uniform bound is
\begin{equation}\label{cr12:lr:eq:pathbound}
 D_Q\leT (\Aplus\oplus H)'\oplus Q.
\end{equation}
This is exactly what the splitting-system construction supplies.

\section{Upper-semilattice embeddings in a fixed core fiber}\label{cr12:lr:sec:embedding}
\subsection{The order-reflection argument}
The relevant form of Friedberg jump inversion is
\begin{equation}\label{cr12:lr:eq:jumpinversion}
 K\geT \Aplus'\quad\Longrightarrow\quad
 (\exists D\geT \Aplus)\ D'\eqT K.
\end{equation}
This is a classical relativized theorem, not a new construction claimed here. It is
Lemma~\ref{cr12:lem:inversion} with $X=\Aplus$; source 10 proves it in its
Appendix~A by the same argument.

\begin{theorem}[Order and join preservation]\label{cr12:lr:thm:embedding}
Fix $\vec A$ and $\Aplus=\bigoplus_n A_n$. For each $r\in\{\mathrm{nc},\mathrm{uc}\}$,
the assignment
\[
 \degT(H)\longmapsto [T_{\Lam}(H)]_r,
 \qquad \degT(H)\geq\degT(\Aplus'),
\]
is a well-defined upper-semilattice embedding. Its image lies above $[\Lam]_r$ and
entirely inside the fiber with core $\I$.
\end{theorem}
\begin{proof}[Proof (as merged)]
This is Theorem~\ref{cr12:thm:embedding} for $X=\Lam$, restricted to parameters above
$\Aplus'$; since $\Lam\leT\Aplus$, these parameters lie above $\Lam'$. Source 10's
proof is the same argument: order preservation and well-definedness by the uniform
dyadic transformations of Proposition~\ref{cr12:prop:transport} (keep the carrier half,
convert the other half, interleave); order reflection by \eqref{cr12:lr:eq:jumpinversion}
(a $D\geT\Aplus$ with $D'\eqT K$ computes $\Lam$ exactly and a description of
$\Rcode(K)$, hence a description of $T_{\Lam}(H)$, whence $H\leT D'\eqT K$); and joins
by
\begin{equation}\label{cr12:lr:eq:fjoin}
 T_{\Lam}(H)\oplus T_{\Lam}(K)
 \equc \Lam\oplus\Rcode(H)\oplus\Rcode(K)
 \equc T_{\Lam}(H\oplus K).
\end{equation}
The reassociations here are implemented by projections and interleavings of finitely
many components, each of positive density. Thus they preserve density-zero errors; no
invariance under arbitrary computable permutations is invoked. Projection places each
image above the carrier, and Theorem~\ref{cr12:lr:thm:insertion} fixes its core.
\end{proof}

\begin{proof}[Completion of Theorem~\ref{cr12:lr:thm:mainembed}]
The core and spectrum formulas are Theorem~\ref{cr12:lr:thm:insertion}, and the order
equivalences and join preservation are Theorem~\ref{cr12:lr:thm:embedding}. If
$H\geT \Aplus'$, then $T_{\Lam}(H)\leT \Aplus\oplus H\eqT H$. Conversely, reading the
exact dyadic half computes $H$, so $H\leT T_{\Lam}(H)$. Thus $T_{\Lam}(H)\eqT H$ on the
stated cone.
\end{proof}

\subsection{Why an upper cone, rather than all degrees?}
The threshold $\Aplus'$ is used in a specific place: order reflection needs a jump
inverse of $K$ which also computes the carrier. Unrelativized inversion only supplies a
jump inverse somewhere, and it need not compute $\Lam$. The base-oracle clause in
\eqref{cr12:lr:eq:jumpinversion} closes this gap.

Accordingly, the theorem does not assert an embedding of the entire Turing-degree
structure into every fiber. Nor does it assert that the parameter-to-class map is
injective below $\Aplus'$. For example, when the carrier is computable, all parameters
$H\leT\emptyset'$ have coarsely computable dyadic codes by
Theorem~\ref{cr12:thm:jump-spectrum} and collapse to the least coarse degree.

It is also unnecessary, and generally invalid, to distribute the Turing jump over
joins. The join argument uses only the elementary equivalence
\[
 H\oplus K\leT D'\quad\Longleftrightarrow\quad
 H\leT D'\ \text{and}\ K\leT D',
\]
and the explicit uniform code transformations of
Proposition~\ref{cr12:prop:transport}.

\mergenote{Part~I's Theorem~\ref{cr12:thm:embedding} lowers the threshold for this carrier
from $\Aplus'$ to $\Lam'$ (still an upper cone): the jump inverse only needs to compute
$\Lam$, not the presentation. Whether it can be lowered further is
Question~\ref{cr12:lr:q:threshold}.}

\section{Consequences for representative spectra}\label{cr12:lr:sec:consequences}
\subsection{Least representatives and principal cores}
\begin{lemma}\label{cr12:lr:lem:least}
If a coarse-equivalence class has a representative of least Turing degree $\mathbf a$,
its core is the principal ideal $\down\mathbf a$. Conversely, a principal core does not
alone imply that its generator occurs in the representative spectrum.
\end{lemma}
\begin{proof}
By Proposition~\ref{cr12:prop:spectra}, the representative spectrum is $\Spec(X)$. If
$\mathbf a$ is its least element, its common lower cone is exactly $\down\mathbf a$,
which equals $\Core(X)$ by Lemma~\ref{cr12:lem:corebasic}. The final assertion will
follow from the examples in the next theorem, and also appears in the repository
synthesis.
\end{proof}

\begin{theorem}[Continuum many classes with the same core and no least degree]\label{cr12:lr:thm:continuum}
Every countable Turing ideal $\I$ is the core of continuum many distinct nonuniform
coarse degrees, also distinct as uniform coarse degrees, whose representative spectra
have no least element.
\end{theorem}
\begin{proof}
Use the family $T_{\Lam}(H)$ with $\degT(H)>\degT(\Aplus')$. If $\I$ is nonprincipal,
Lemma~\ref{cr12:lr:lem:least} rules out a least representative.

If $\I=\Low(A)$ is principal, its generator satisfies $A\leT \Aplus$: membership in the
union \eqref{cr12:lr:eq:cofinal} places it below some $A_n$. A least representative
would have degree $\degT(A)$. But \eqref{cr12:lr:eq:spectralcut} would then imply
$H\leT A'\leT \Aplus'$, contradicting the parameter choice. Thus no member of the
family has a least representative in either case.

There are continuum many degrees strictly above any fixed degree. For completeness,
the reals $\Aplus'\oplus Q$ range over continuum many distinct sets as $Q$ varies; each
Turing degree contains only countably many sets, so their degrees have cardinality
continuum in ZFC. Removing the single degree of $\Aplus'$ leaves continuum many.
Theorem~\ref{cr12:lr:thm:embedding} makes their images distinct already in the
nonuniform coarse degrees.
\end{proof}

\begin{corollary}[Perfect antichains of descriptions]\label{cr12:lr:cor:antichain}
For the parameters in Theorem~\ref{cr12:lr:thm:continuum}, the perfect families
supplied by Theorem~\ref{cr12:lr:thm:mainperfect} have pairwise incomparable Turing
degrees. In particular, every countable ideal is the exact common lower cone of a
perfect family of pairwise incomparable, density-equal sets.
\end{corollary}
\begin{proof}
No degree of a description lies in $\I$. Indeed, such a degree would, because every
core member is below that description, be a greatest member of $\I$ and a least
element of the spectrum. If $D,E$ from the perfect family were comparable, say
$D\leT E$, exactness would put $D$ in $\Low(D)\cap\Low(E)=\I$, a contradiction.
\end{proof}

\subsection{What these statements do not imply}
A \emph{least} element is below every element of the spectrum. A \emph{minimal}
element merely has no strictly smaller element within the spectrum.
Theorem~\ref{cr12:lr:thm:continuum} proves absence of the former, not the latter. Even
a perfect antichain of descriptions does not by itself rule out other minimal elements
of the same spectrum.

Likewise, \eqref{cr12:lr:eq:spectralcut} is an exact formula for the constructed
family relative to $\Spec(\Lam)$. It is not a characterization of every upward-closed
subset of degrees that can be a coarse spectrum. The carrier spectrum is not silently
replaced by the set of all upper bounds of $\I$. Every description degree is such an
upper bound, but an arbitrary oracle computing each $A_n$ separately need not
uniformly assemble a description of \eqref{cr12:lr:eq:carrier}.

\section{Quantitative recovery and presentation sensitivity}\label{cr12:lr:sec:radii}
\subsection{A filtration by error tolerance}
For $r>0$, define
\begin{equation}\label{cr12:lr:eq:Ir}
 \mathcal K_r(X)=\bigcap_{\delta(X,Y)<r}\Low(Y).
\end{equation}
This is the information which survives every error pattern of upper density less than
$r$, with no uniformity demanded of the recovery programs. It is a countable Turing
ideal, since $X$ itself occurs among the oracles being intersected. The ideals grow as
$r$ decreases. Equation~\eqref{cr12:lr:eq:radius} says
\[
 \Core(X)=\bigcup_{r>0}\mathcal K_r(X).
\]
For our carriers, their relation to the presentation levels is quantitative.

\begin{theorem}[Fourfold localization of the ideal filtration]\label{cr12:lr:thm:filtration}
For every $n\in\N$,
\begin{equation}\label{cr12:lr:eq:sandwich}
 \mathcal K_{2^{-n}}(\Lam)
 \subseteq\Low(A_n)
 \subseteq\mathcal K_{2^{-n-2}}(\Lam).
\end{equation}
\end{theorem}
\begin{proof}
If $\delta(Y,\Lam)<2^{-n-2}$, the $n$th column has error less than
\[
 2^{n+1}\,2^{-n-2}=\tfrac12
\]
relative to $\Jfac(A_n)$, by \eqref{cr12:lr:eq:pullback}. Robust recovery yields
$A_n\leT Y$. This proves the right inclusion.

For the left inclusion, the truncation $\Lambda_{\vec A,<n+1}$ is computable in $A_n$ and
satisfies
\[
 \delta(\Lambda_{\vec A,<n+1},\Lam)\leq2^{-n-1}<2^{-n}.
\]
A set in $\mathcal K_{2^{-n}}(\Lam)$ is therefore computable in $\Lambda_{\vec A,<n+1}$ and hence
in $A_n$.
\end{proof}

Thus the decreasing spatial weights of the layers have an exact conceptual purpose:
each finite level of the ideal becomes robust at a definite positive tolerance, while
the tolerance needed for all levels simultaneously tends to zero. The factor four is
the bound proved by this particular choice of column weights and majority decoder; no
optimality claim is made.

\mergenote{The filtration uses the quantitative radius $1/2$ of $\Jfac$
(Lemma~\ref{cr12:lr:lem:robust}); neither Part~I's code nor source 08's has a stated
analogue.}

\subsection{Arithmetical information as a nonprincipal core}
\begin{example}\label{cr12:lr:ex:arith}
Take $A_n=\emptyset^{(n)}$, with $\emptyset^{(0)}=\emptyset$. Then
\[
 \Core(\Lam)=\{C:(\exists n)\ C\leT\emptyset^{(n)}\}.
\]
This is the ideal of arithmetical sets. Every description computes every finite jump,
separately. The presentation oracle $\Aplus=\bigoplus_n\emptyset^{(n)}$ is not in this
ideal: if $\Aplus\leT\emptyset^{(m)}$, then its $(m+1)$st column would contradict
strictness of the jump. By the exact-pair construction, there are descriptions
$D,E\leT \Aplus'$ such that their common lower cone is precisely the arithmetical
ideal. At least one fails to compute $\Aplus$, since otherwise $\Aplus$ would lie in
their common lower cone. Hence the distinction between separate computations and one
computation of the infinite join is witnessed inside a single density-zero class.
\end{example}
The construction uses only the usual finite-jump characterization of arithmetical
sets; it does not supply uniform reduction indices from a description to all finite
jumps.

$\emptyset^{(\omega)}$ (equation~\eqref{cr12:ep:eq:arithmetic-pair}), a stronger

\subsection{Even the zero ideal has presentation-dependent carriers}
\begin{proposition}[Noncanonical carriers]\label{cr12:lr:prop:noncanonical}
A fixed cofinal sequence of \emph{degrees} need not determine the coarse degree of its
layered carrier. This fails already for the constant sequence of computable degrees.
\end{proposition}
\begin{proof}
Given an arbitrary set $H$, let $A_n$ be the constant binary function with value
$H(n)$. Each $A_n$ is computable, so the generated ideal is $\Comp$ and the sequence
is increasing in Turing degree. For positive arguments, $\Jfac(A_n)$ has constant value
$H(n)$; only its argument $0$ is set to zero by definition. Therefore $\Lam$ agrees
with $\Rcode(H)$ except possibly at the positions
\[
 \{p(n,0):n\in\N\}=\{2^n-1:n\in\N\},
\]
a density-zero set. Thus $\Lam\approx\Rcode(H)$, even though every level of its
cofinal degree sequence is $\zero$.

For $H=\emptyset$ the carrier is computable. For $H=\emptyset''$,
Theorem~\ref{cr12:thm:jump-spectrum} says that it has no computable coarse description.
These carriers have the same core and the same level-by-level Turing degrees, but
different coarse degrees.
\end{proof}

This phenomenon is not an accident of the proof. The ideal records which sets are
necessarily recoverable one at a time. It does not record the nonuniform information
used to choose or present infinitely many such sets. The spectral insertion theorem
exploits precisely that separation.

\subsection{Principal ideals recover the known special cases}
For $\I=\Low(A)$, choose $A_n=A$ for all $n$. Then $\Lam\leT A$, while robust recovery
gives $A\leT D$ for every description $D$. Consequently $\Spec(\Lam)$ is exactly the
cone above $\degT(A)$. The insertion formula becomes
\[
 \Spec(T_{\Lam}(H))=\{\mathbf d:\degT(A)\leq\mathbf d\ \text{and}\ H\leT D',\ D\in\mathbf d\}.
\]
These principal-core constructions specialize the unattained-infimum and jump-cone
mechanisms already present in the repository. The unrestricted nonprincipal
realization and the resulting general fixed-core embeddings are the additional content
of this manuscript.

$\Ecode(A)$.}

\subsection{Critical quantifier checks}
There are four places where exchanging quantifiers would produce a false or
unsupported statement.

First, the conclusion that a description computes $A_n$ is for each fixed $n$, with
its own finite stabilization parameter. It is not a uniform reduction to
$\bigoplus_n A_n$. Second, the finite truncations of $\Rcode(H)$ are individually
computable even when no computable sequence of their program indices exists. Third, a
no-disagreement argument produces a program for a common function only under the
hypothesis that both designated functionals are total and equal; it does not decide
totality. Fourth, the perfect family's splitting system is below one oracle, but its
paths have the bound \eqref{cr12:lr:eq:pathbound}, not a uniform bound by that oracle
alone.

The join proofs combine only finitely many outputs. The density arguments first fix a
finite number of protected columns, take a limsup, and only then let the number of
columns grow. They never interchange an infinite sum and a limsup without a tail
bound.

\subsection{Mapping the development to ProveIt}\label{cr12:lr:subsec:mapping}
The current repository separates its foundational Turing-degree library from its
coarse-degree library; its README and audit document admitted published inputs on the
coarse side \cite{RepoReadme}. This manuscript does not claim to have rebuilt either
library or certified new Lean files.

A practical formalization can be divided into three layers. The first consists of
finite combinatorics: the exact column counts, density pullbacks, factorial-block
majority bounds, and interleaving bounds. The existing files for columns, majority,
blocks, and dyadic coding provide natural integration points, although the
repeated-label block convention here should be reconciled explicitly with the
repository's convention rather than identified by name.

The second layer is the semantic one: an ideal of set degrees, a cofinal family, the
carrier, finite truncations, and the implication from ideal-valued approximation to a
core bound. A development accepting HJKS compactness as an explicit hypothesis can
obtain the first proof quickly. Its theorem statement should expose that hypothesis
and not hide it behind a global axiom.

The third layer formalizes the independent construction. It needs finite oracle
strings, a use-bounded convergence predicate, persistence under extension, and a proof
that admissibility is computable relative to a finite ideal level. The key interface
is Lemma~\ref{cr12:lr:lem:cross}, not a generic appeal to forcing. A recursive family of
finite task lists then gives the splitting system, followed by separate proofs of
density, exactness, and continuity. This route removes dependence on HJKS compactness
for the explicit realizations. The upper-cone embedding further requires a genuine
jump and the relativized inversion argument.

\section{Source 10: further research questions}\label{cr12:lr:sec:questions}
The following questions concern extensions not proved in this manuscript. They should
not be read as assertions that every formulation has been established as open
throughout the literature.

\begin{question}[Classify spectra over a prescribed core]\label{cr12:lr:q:spectra}
For a fixed countable ideal $\I$, characterize the upward-closed collections
$\mathcal S$ of Turing degrees for which
\[
 \mathcal S=\Spec(X),\qquad \Core(X)=\I
\]
for some $X$. Necessarily $\I$ is the common lower cone of $\mathcal S$. Is there a
useful additional descriptive or effective condition sufficient for realization? The
family \eqref{cr12:lr:eq:spectralcut} supplies many examples but is not a full answer.
\end{question}

\begin{question}[Minimal elements of a spectrum]\label{cr12:lr:q:minimal}
Which of the spectra $\Spec(T_{\Lam}(H))$ have minimal elements? Can one choose an ideal
presentation and a parameter for which the spectrum has no minimal element at all? A
proof must lower a degree while retaining a description, not merely exhibit an
incomparable exact partner.
\end{question}

\begin{question}[Remove or lower the embedding threshold]\label{cr12:lr:q:threshold}
Can the upper-cone embedding for a fixed ideal be extended to an embedding of the
entire Turing-degree structure? More modestly, can the threshold $\Aplus'$ be lowered
for useful classes of presentations, or replaced by an invariant of the ideal rather
than of the chosen presentation? The present proof needs a jump inverse that computes
the carrier.
\end{question}

\begin{question}[Effective comparison of presentations]\label{cr12:lr:q:presentations}
Give sufficient uniformity hypotheses on two cofinal presentations of the same ideal
that force their carriers to be uniformly or nonuniformly coarsely equivalent.
Proposition~\ref{cr12:lr:prop:noncanonical} shows that merely having the same sequence
of Turing degrees is insufficient. Uniformly supplied cofinal maps and reduction
indices are a natural starting point, but the totality requirements in a coarse
transformation must still be proved.
\end{question}

\begin{question}[Sharper witness complexity]\label{cr12:lr:q:witness}
For a carrier computable in $\Aplus$, when can the exact descriptions in
Theorem~\ref{cr12:lr:thm:fusion} be placed strictly below $\Aplus'$? Can one
simultaneously control their jumps, degrees, or definability while retaining the
prescribed nonprincipal common lower cone? The present algorithm makes
$\Sigma^0_1(\Aplus)$ extension decisions and therefore gives an $\Aplus'$ bound, not an
optimality result.
\end{question}

\begin{question}[Quantitative error profiles]\label{cr12:lr:q:profiles}
Can one prescribe the entire family $r\mapsto\mathcal K_r(X)$, rather than only its
union? Theorem~\ref{cr12:lr:thm:filtration} realizes a cofinal filtration within a
factor four in radius. Determine sharp constants, realizable discontinuities, and the
effect of changing column weights or block codes. A stronger version would
characterize which decreasing families of ideals arise in this way.
\end{question}

\begin{question}[Small disagreement budgets with nonprincipal cores]\label{cr12:lr:q:budget}
Can the perfect exact-pair family be made to agree off one set obeying a prescribed
unbounded sublinear counting budget, while retaining an arbitrary nonprincipal ideal as
its common lower cone? The present protected-column construction gives density zero
and arbitrarily small prefix-density distance, but not an arbitrarily slow prescribed
bound on the number of disagreements. The repository's one-bit-reserve budget
constructions suggest a different method, whose compatibility with rising ideal bounds
remains to be established.
\end{question}

\begin{question}[Restrictions on representatives and reducibilities]\label{cr12:lr:q:restrictions}
Which ideals can be realized when $X$ is required to lie in a fixed definability class,
or to satisfy an effective randomness condition? Which parts of the realization and
fixed-fiber results survive for effective-dense descriptions, where wrong answers are
forbidden? A separate question concerns hyperarithmetic common information: report~10
identifies a failure of the Turing compactness mechanism there, so a transfer would
require a genuinely different proof.
\end{question}

\begin{question}[A checked construction rather than an admitted compactness theorem]\label{cr12:lr:q:lean}
Implement the finite-use oracle interface and ideal-protected fusion in Lean, then
derive the core-realization theorem and perfect exact-pair theorem without importing
an admitted cone-avoidance result. This is a specific mechanization project with a
small mathematical interface; it would strengthen assurance without changing the
statements proved here.
\end{question}

\subsection{Source 10's conclusion}\label{cr12:lr:sec:conclusion}
The countable-ideal part of the repository's coarse-core classification problem has a
complete answer: every countable Turing ideal occurs, and no other kind of family can
occur. The construction has two complementary explanations. Each ideal level is
encoded robustly on a positive-density region, so it survives every coarse
description. At the same time, finite initial collections of levels approximate the
carrier arbitrarily well, preventing extra information from becoming common to all
descriptions. Independent reservoir fusion realizes this exclusion as a perfect
exact-pair family and gives a presentation-relative effective bound.

The core is nevertheless a coarse invariant of limited discriminatory power. Dyadic
insertion leaves it unchanged while imposing an arbitrary jump-cone cut on the
description spectrum. Relativized jump inversion makes those cuts order-reflecting
above a presentation-dependent threshold. Thus every countable core fiber contains a
join-preserving copy of a Turing upper cone, with continuum many examples having no
least representative. The distinction between common information and the full
computational strength of an approximation problem is therefore structural, not merely
a feature of the computable-core examples.

\section{Proof audit and quantitative checks}\label{cr12:app:audit}
\subsection{Critical logical checkpoints}
The following checkpoints summarize the issues most likely to create a false
stronger statement.

\paragraph{Finite constants are not a uniform algorithm.}
The finite patch in Theorem~\ref{cr12:thm:radius}, the stable row in
Proposition~\ref{cr12:prop:robust}, and the finite truncations in
Theorem~\ref{cr12:thm:jump-spectrum} are used as witnesses to individual Turing
reductions. The paper never claims that their indices or stabilization stages
are computable uniformly from the displayed oracles.

\paragraph{Whole-row stabilization is stronger than pointwise convergence.}
The decoding formula \eqref{cr12:eq:rowdecode} uses the value at a coordinate that
itself changes with the stage $m$. It is justified by
$\exists s_i\,\forall s\ge s_i\,\forall n$, not by
$\forall n\,\exists s_{i,n}\,\forall s\ge s_{i,n}$.
The block-of-repetitions code was chosen specifically to supply the stronger
order of quantifiers.

\paragraph{Countably many error sets require the tail estimate.}
Nullity of every column's error set does not by itself follow from a countable
union theorem. The proof first handles finitely many columns, then bounds
\emph{all} remaining errors by $2^{-k}$, and only then lets $k$ grow.
The exact floor formula in \eqref{cr12:eq:tail} is the quantitative certificate.

\paragraph{Core realization needs both inclusions.}
Robust recovery of each generator proves only
$\I_{\vec A}\subseteq\Core(X_{\vec A})$. The upper inclusion is a separate
application of robust radius to the finite-column truncations. Omitting it
would leave open the possibility of unintended common information across the
columns.

\paragraph{The reverse embedding uses a relative jump inverse.}
The witness $B$ must satisfy both $B\geT X$ and $B'\eqT K$.
These properties ensure that $B$ actually solves the target base-plus-code
problem before its jump separates $H$ from $K$. Lemma~\ref{cr12:lem:inversion}
proves exactly this pair of requirements.

\paragraph{Different partial orders are kept separate.}
The notions of least member, minimal member, infimum, cofinal family, and
coinitial family are not interchanged. In particular,
Corollary~\ref{cr12:cor:cofinal} concerns coarse degrees in a fixed-core collection;
Corollary~\ref{cr12:cor:infimum} concerns Turing degrees within one spectrum.

\subsection{Finite verification artifacts}
The companion program, shipped as
\path{code/12-ideal-realization-finite_checks.py}, uses only Python's
standard library. It checks the column partition and exact tail counts,
majority-error thresholds, the index bound used for whole-real stabilization,
and finite simulations of the assembly and presentation examples. It also
