# Report289 exact companion

This dependency-free Python 3 companion computes exact ordered-quadruple energies,
checks the index-two sum-of-squares identity, and supplies finite diagnostics and
small polynomial certificates for Report289. It does not certify the imported
Mahler-measure theorem, prove a universal statement by enumeration, or provide a
proof-assistant kernel certificate. It makes no floating-point calculations.

## Reproduce

From the `Report289` directory:

```sh
python3 -B companion/exact_checks.py > /tmp/report289-companion-summary.json
python3 -B -O companion/exact_checks.py > /tmp/report289-companion-summary-optimized.json
cmp /tmp/report289-companion-summary.json /tmp/report289-companion-summary-optimized.json
python3 -B -m unittest discover -s tests -p test_companion.py -v
python3 -B -O -m unittest discover -s tests -p test_companion.py -v
```

The first command prints a deterministic JSON summary to standard output. It
performs no network access and writes no files itself. The shell redirections
above create temporary output files outside the frozen source inventory. `--help` prints usage without running the diagnostics.
Unexpected options are rejected before work. The two test commands each run
52 unittest test methods, with many parameterized cases within those methods.
These are not 52 universal theorem proofs. Normal and optimized executions have
identical mathematical output and retain the same input validation.

## Representation and limits

- `Group((0, 6))` means `Z × C6`; modulus zero means an infinite cyclic factor
- A group has one through four factors, each modulus is an integer in `0..128`,
  and the product of its finite factor sizes is at most 128
- Group points are tuples. Finite coordinates must be canonical residues;
  input integer coordinates have absolute value at most 4096. Internal pair
  sums and differences are exact and may exceed that input coordinate bound
- Weights are dictionaries keyed by points, with at most 128 entries. Zero
  entries are removed. Energies require a nonzero nonnegative weight
- Rational weights must be actual `int` or `fractions.Fraction` values. Bools,
  floats, negative weights, inconsistent image dictionaries, and malformed
  points are rejected
- `Quadratic(a,b,d)` represents exactly `a+b*sqrt(d)` for `d=2` or `d=6`.
  A weight may mix rationals and one quadratic field, but not two fields.
  Comparisons use rational squares and signs, never decimal approximations
- Input weight coefficients have numerator bit length at most 256 and
  denominator bit length at most 128. The same limits apply to public
  three-point weights and invariants. Intermediate exact arithmetic is not
  rounded or truncated
- `binomial_weights`, `binomial_defect`, and `binomial_upper_bound` accept
  integers `m=1..32`. Lower-bound functions accept projection sizes `1..128`
- `support_window(epsilon)` takes an exact rational strictly between 0 and
  1/4, with numerator and denominator bit lengths at most 128

These are deliberate computational bounds, not mathematical restrictions on
Report289's theorems. Public validation uses exceptions, not assertions, and
remains active under `python -O`.

## Principal API

```python
from fractions import Fraction
from companion.exact_checks import Group, parity_sos, local_gap_check

G = Group((2, 0))
w = {(0, 0): 1, (1, 1): 2, (0, 2): 1}
result = parity_sos(G, w, (1, 0))
assert result['energy'].ratio == Fraction(27, 35)
gap = local_gap_check(G, w, (1, 0))
assert gap['local']['free_projection_size'] == 3
```

The assertions in this usage example are optional caller checks, not runtime
validation used by the companion.

`energy(domain, target, weights, images)` groups ordered pairs by their domain
sum and their image sum and squares the bucket masses. The result is an
`Energy` with exact `ordinary`, `respected`, `ratio`, and `defect` properties.
The parity routines use labels 0 and 1 with image sums in **Z**. Replacing this
target by C2 would make parity a homomorphism and give ratio one instead.

`parity_sos(group, weights, coefficients=None)` validates an arbitrary
homomorphism to C2. The default is first-coordinate parity. A coefficient 1 is
allowed only on an infinite or even cyclic factor; a coefficient 0 is allowed
on any factor. The character may be trivial on the supplied group. The return
value includes all four pair norms, both convolution squares, the mixed
convolution, the cross-correlation, the difference norm, and the correlation
asymmetry. It checks

```
4*E_a - 3*E = ||e*e-o*o||^2 + 2*sum_h (R(h)-R(-h))^2
```

and checks that equality is equivalent to `e*e=o*o` in each computed case.

`local_structure` uses the group generated by **support differences**, not the
ambient group and not the group generated by the untranslated support. The
kernel of the free-coordinate matrix is computed over Z by unimodular column
operations. Its images in the finite factors generate the actual local torsion.
The returned parity-one witnesses determine whether the local-torsion hypothesis
holds. This uses a full saturated integer kernel, not a rational nullspace with
separately cleared denominators. Tests independently check kernel saturation
against small integer relations.

`local_gap_check` rejects a false local-torsion hypothesis. Otherwise it computes
`m`, the number of distinct free projections, and verifies the observed defect
against `1/(4^m*binom(2m-2,m-1))` and `1/(4*16^(m-1))`. Fibers do not add a
multiplicity penalty. The theorem establishing these bounds is in the report;
this function is a diagnostic of the supplied weight, not a substitute proof.

`support_window` returns an integer-rounded necessary support bound from the
central-binomial lower bound and a sufficient support size from the binomial
construction. It uses exact integer/rational comparisons rather than logarithms.
These two bounds need not coincide, and do not purport to give the true optimum.

## Polynomial and endpoint certificates

`three_point_polynomial_certificate` compares every coefficient in
`Q(sqrt(6))[p,q,t]` in the identity

```
E - (12+2*sqrt(6))*p*q
  = (t-2*p)*(t+2*p+4*q) + (q-sqrt(6)*p)^2
E = t^2+2*p^2+q^2+4*q*(t+p)
```

For positive endpoint weights a,c and middle weight b, substitute p=ac,
q=b², t=a²+c². `three_point_slack` verifies the nonnegative certificate and
its equality case p=1, q=sqrt(6), t=2. The actual optimal middle weight is
6^(1/4), not sqrt(6); no approximation to that fourth root is used.

Additional exact diagnostics include:

- C6 weights `(6,5,3,2,3,5)`, energies 55728 and 41796, and no nonzero period
- The C8 seven-point weight `1+cos(2*pi*j/8)` represented in Q(sqrt(2)),
  energies 576 and 432, with every parity-one element of order eight
- Two separately attaining C6 fibers whose union on Z × C6 has defect 1/770,
  establishing that fiberwise attainment alone is insufficient
- The cyclotomic n=2 weight `(1,sqrt(2),1)`, signed product `1+z^4`,
  integer energy 34 and defect 1/68; finite even orders 4 through 16 include
  the N=4 wrapping case with energy 36 and defect 1/36
- The cyclotomic n=4 polynomial `1+a*z+b*z^2+a*z^3+z^4`, where
  b=2+sqrt(2), a>0 and a²=2b. Every calculation is reduced to Q(sqrt(2))
  by writing the weight as e+a*u on its even and odd supports. The code
  checks `F(z)F(-z)=1+z^8`, integer energy `1154+768*sqrt(2)`, defect
  `1/(2*E)`, and finite wrapping at N=6,8,10. This is a polynomial reduction,
  not a general quartic-field implementation. Tests separately enumerate
  all ordered quadruples using the same defining algebraic relation

## Fixed diagnostic counts

The JSON records separate, deliberately bounded families:

- 96 rational SOS samples: eight group/character pairs and twelve seeds each
- 255 nonempty support subsets of `{-3,-2,-1,0,1,2,3,4}`, with one specified
  rational weight per support, for lower-bound diagnostics
- 12 binomial examples, m=1 through 12, including the strict
  `defect < 1/(2*16^m)` inequality and its exact product bound
- 64 positive integer three-point weight triples, plus one polynomial identity
  and the exact algebraic minimizing invariants
- 16 full finite-torsion indicators, on even cycles of orders 2 through 32
- Five local/translation/counterexample records, plus the named C6, C8,
  cross-fiber, and cyclotomic certificates

The tests also include independent ordered-quadruple counts, saturated-kernel
checks, exact support-rounding boundaries, malformed and oversized inputs,
field-mixing rejection, and normal/optimized CLI comparisons. Subcases are not
summed into a misleading grand total.

## JSON schema

The top-level object contains `report: 289`, `schema_version: 1`, `status`,
`arithmetic`, `scope`, and one object per diagnostic family. Object keys are
sorted in the printed representation. Rational scalars are strings such as
`"3/4"`; quadratic scalars are objects `{"a":"3/5","b":"1/15","radicand":6}`.
Tuple-keyed convolution dictionaries become sorted lists of `point`/`value`
objects. Scalar rationals may retain the quadratic representation with zero
irrational coefficient when they were calculated inside that field. Counts and
input indices remain JSON integers.
