# Integration contract

## Intake and preservation

Use the repository's existing `docs/incoming/README.md` procedure. Preserve the delivered archive and bytes before making integration edits. This package does not reserve a report number. It does not delete, overwrite, commit or push any repository file.

A suggested standalone code location is:

```
Topology/UnknotRecognition/fast/fastunknot/private_cocore/
```

`install_overlay.py` previews an additive copy to that location; `--apply` performs it only if that entire destination does not already exist. It does not connect any entry point or update the synthesized article. The deliverable remains useful as a standalone report until native integration is validated.

## Native source boundary

Keep the established verifier's reconstruction of the raw cut, product/boundary structures, forest, augmented handles, real attaching curves, and nondisk annular midpoint curves. In particular retain disjointness, actual unsigned occurrence counts, supported multiplicities, attachment/base ownership and source component checks. An arbitrary supplied word or matrix is not a geometric witness.

At the matrix boundary, the adapter's `source_matrices` consumes `augmented`, `core_proof`, and the already reconstructed `curves`. It extracts dimension-one source occurrences and excludes forest columns while retaining original one-handle labels. The private-family result then preserves the maintained canonical least-column choice, not just existence of some witness. Component ownership must still be checked using native source data.

A caller that uses the standalone `verify_certificate` must reconstruct these matrices independently of the producer. Do not authenticate the geometry by trusting fields that were only asserted in the new certificate.

## Schedules and fallback

The default kernel accepts complete zero-real-fill schedules, including mixed row-private and column-private pivots. It rejects real fill rather than pretending its source entries remain unchanged.

For a supplied complete **source-unit** matching, `normalize_matching` recognizes acyclicity and constructs a column-private order. The article proves that the full passive terminal matrix is unchanged by this normalization of a fixed matching, even if the originally supplied order creates fill. An integrator may opt into this path after preserving the enclosing geometric checks.

Pivots whose source entry was zero but became one through earlier fill are outside that theorem. Preserve the legacy replay or use a separately justified alternative. A kernel rejection, missing private column, exception-search exhaustion or resource cap is not a knottedness or nonhandlebody verdict.

## Certificate versioning

The existing native `core-primitive-annuli-v1` record authenticates `curves`, `final_rows`, and `witnesses`. **Do not accept that schema while ceasing to verify `final_rows`.** The new `private-cocore-owner-v1` format is an explicitly separate matrix-query ledger, not an enclosing topology proof format.

A future native schema can omit full final rows only after the complete source verifier and every enclosing dispatcher have been changed deliberately. Keep all legacy schemas replayable with their original field semantics. Independently replay native saved proofs with producer entry points disabled. Test schema downgrade, omitted curves, owner mismatch, unsupported pivots and mutated witness labels.

`private-cocore-native-query-v1`, returned by the narrow adapter, is merely its proposed local result tag. It is not registered as a valid whole-cut or unknot certificate.

## Exceptions are residual work, not missing topology

`query_atlas` tests the subfamily outside D. `find_exceptions` discovers such a D within budget. A result can support an actual cancellation of the retained handles only under the article's geometric hypotheses. All omitted attaching curves must remain in a residual handle description and be transported through the actual cancellations. The atlas does not encode those curves.

A found D can be checked independently by reindexing the retained source passive rows and running the ordinary owner producer/checker, keeping the map to original attachment IDs. This validates the subfamily query only. No incomplete family should enter the existing full-family genus deduction.

## Validation before enabling a native path

The delivered source-shaped adapter tests do not replace native geometry tests. Run the complete maintained suite and the appropriate source-cut corpus, replay all old certificates, compare full reconstructed incidences where feasible, and verify all source component/witness labels. Measure source extraction, proof serialization, verification, and complete query cost on paired identical inputs. Retain tiny-input regressions and failure/refusal cases.

The controlled matrix data motivate testing this optimization; they do not establish a default threshold. A small-input dense path may be preferable, but choose any threshold from actual native measurements rather than from the synthetic ratios in this delivery.

## Complexity integration

Charge real/passive source extraction and integer parsing before the new local bound. Add orbit queries, forests, kernel construction, curve reconstruction, source transport and enclosing verification separately. The local theorem does not turn all normal-cut processing into a linear operator and supplies no bound on the number or encoded sizes of useful hierarchy stages.
