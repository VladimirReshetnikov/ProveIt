\begin{abstract}
We develop a certificate-producing unknot recognizer whose input is a binary straight-line program for a braid word, rather than an expanded crossing list. For every three-strand input it decides whether the closure is a knot and, when it is, whether it is trivial, in deterministic time polynomial in the grammar's bit size. The algorithm combines the existing three-braid criterion in ProveIt with explicit compressed reduction in $C_2*C_3$. Its central operation is one longest-common-prefix query followed by at most one syllable merge. For $s$ input rules and $B$ bits of represented-length metadata, a direct implementation allocates $O(s^2(B+1))$ string rules. An independently structured verifier checks polynomial-size certificates without repeating longest-prefix searches.

We lift singleton-generator connected-sum decomposition to native compressed inputs of arbitrary strand count. Every three-strand factor is removed from the difficult part of the problem without expansion. If $\kappa_i$ is the minority-sign count of an unresolved wider factor, a complete exponential fallback gives
\[
 \poly(g)+\sum_{i\in\exc}2^{O(\kappa_i)},
\]
where $g$ is input bit size. Thus only the largest \emph{exceptional} minority count controls the exponential term. This is a restricted-input quasi-polynomial result, not a general quasi-polynomial algorithm for arbitrary knot diagrams.

The package supplies source, an independent replay layer, 42 passing unit tests, an exhaustive 87,381-word comparison, compressed-capacity checks, and paired timings. It also proves an exponential bit-size obstruction to materializing Burau matrices on compact conjugate inputs. Polynomial compressed conjugacy in virtually free groups is established prior theory; our contribution is the explicit certificate-oriented specialization, native compressed decomposition, and reproducible implementation, not a claim of priority for that general complexity fact.
\end{abstract}

\section{Research objective and the precise increment}
\subsection{Why change the input representation?}
The repository already has a linear-time recognizer for explicit three-braid knot closures. It also has substantially more general exact recognition machinery and increasingly capable compressed free-group operations \cite{repo}. Reimplementing the explicit three-braid criterion would not advance that work. The missing interface addressed here is different: a braid may be presented by a small acyclic grammar while its literal Artin word is exponentially longer. Expanding that grammar before using an otherwise efficient recognizer destroys the available compression.

We therefore ask for a decision algorithm measured in the number of bits actually supplied. Its output must not include the full expanded cyclic normal form, an enormous integer matrix, or a sequence of individually expanded conjugations. An affirmative answer must still be tied to the precise input braid. A matching numerical fingerprint, a small-looking intermediate presentation, or an exhausted computation is not a certificate.

This work targets three related bottlenecks. First, make three-braid closure recognition native to grammar inputs. Second, make every algebraic transformation independently replayable in that representation. Third, preserve compressed easy factors when an arbitrary-strand braid is split into connected-sum factors. The third point is important: expanding a huge easy factor simply because another factor needs a general backend would forfeit the main gain.

\subsection{Relation to the inspected project}
The maintained file \texttt{fast/fastunknot/braid.py} already uses the quotient $B_3/Z(B_3)$ and exponent sum to decide explicit three-braid closures. Its alternate matrix backend uses Burau at $t=-1$. The string kernel in \texttt{compressed\_words.py} implements exact SLP equality and compressed free-group operations. Report 19 studies explicit rank-two substring replacements. Report 34 studies explicit singleton splitting, minority-sign bounds, and endpoint descent \cite{repo,ranktwo,minority}. We use those results as starting points, not as newly proved project achievements.

The supplied \texttt{strings.py} is an attributed, source-derived adaptation of the maintained exact string kernel. It is neither a byte-identical checkout nor the entire original module. New producer and replay modules implement free-product, not free-group, reduction. In particular, a $y y$ boundary becomes $y^2$; it is not treated as a free-group cancellation. The existing general group-search SLPs are not automatically braid-word SLPs, so they cannot be passed to this backend merely because their storage formats look similar.

\subsection{Prior mathematical complexity results}
Exact equality of SLP strings is deterministic polynomial time; we use the standard primitive in the form developed through Plandowski's method and explained by Schleimer \cite{schleimer}. Holt, Lohrey, and Schleimer prove polynomial-time compressed word and simultaneous conjugacy algorithms for fixed hyperbolic groups \cite{hls}. Since $C_2*C_3$ is virtually free, those results already imply a polynomial algorithm for the relevant quotient conjugacy tests. Keeping exponent sum separately handles the central lift. We make no novelty claim for this existence consequence.

The purpose of our direct construction is a transparent implementation contract: explicit syllable reduction, concrete size accounting, short replay witnesses, and compatibility with the repository's exact string interface. Its cost analysis exposes the dependence on the equality kernel rather than hiding it behind a claimed small exponent.

\subsection{What remains outside the result}
The general target is still an end-to-end bound for arbitrary knot diagrams. Lackenby's July 2026 preprint gives a new hierarchy algorithm; its Section 9 explicitly distinguishes iteration counting from costs of operations, and Section 10 bounds refined hierarchy length in terms of initial complexity \cite{lackenby}. Neither those statements nor the present algebraic module supplies a complete implementation of the missing accelerated geometric operations.

Input compression also differs from compressed \emph{homology output}. Kelom\"aki and Sch\"utz analyze exponential behavior of explicit Khovanov constructions and develop compressed descriptions in restricted settings \cite{ks}. Our backend never builds a Khovanov complex for a solved three-braid. It does not claim that a polynomial-size description of homology can always be discovered from an arbitrary compact input.

\section{Input model, finite summaries, and bit-size conventions}
\begin{definition}[Binary braid grammar]
For a specified strand count $m$, a grammar consists of a distinguished empty rule $X_0=\varepsilon$, followed by $s$ rules
\[
 X_i=\sigma_j^{\epsilon}\quad(1\le j<m,\ \epsilon\in\{-1,1\}),
 \qquad\text{or}\qquad X_i=X_aX_b\quad(a,b<i),
\]
and a root index $r$. Its value is an Artin word, and its topological meaning is the ordinary closure of that word on $m$ strands. The grammar has no power, inverse, recursive, or probabilistic rule type.
\end{definition}
Powers and inverses are conveniences of the builder, not extra input semantics. Binary powering creates $O(\log(q+1))$ concatenation rules for a positive power $q$. Inversion reverses concatenations and negates generator signs with memoization. Arbitrary shared DAGs are allowed; a small number of signed runs is not required.

Write $g$ for the total input encoding size in bits, including indices and the strand count. Let $N_i$ be the expanded length of rule $i$, and set
\[
 N=N_r,\qquad N_* = \max_{0\le i\le s}N_i,
 \qquad B=\left\lceil\log_2(N_*+2)\right\rceil.
\]
We use $N_*$ rather than $N$ because the public validator processes all supplied rules, including unreachable ones. A root of length two can coexist with a large unused rule. For binary acyclic grammars $N_*\le 2^s$, so $B=O(s+1)$ and $s\le g$ up to a fixed encoding convention. There is no hidden assumption that arithmetic on an $N$-bit matrix entry costs one operation.

\begin{lemma}[Finite metadata]\label{lem:metadata}
For fixed $m$, lengths, exponent sums, and strand permutations are computable in polynomial bit time in $g$. For $m=3$, these computations require $O(s)$ additions or constant-size permutation compositions on integers of $O(B)$ bits.
\end{lemma}
\begin{proof}
A terminal has length one, exponent $\epsilon$, and the adjacent transposition $j\leftrightarrow j+1$. Concatenation adds the two lengths and exponents and composes the two permutations. Strictly earlier references permit one topological pass. Absolute exponent is bounded by expanded length. The cycles of the root permutation are the components of the closed braid, so a three-cycle is exactly the one-component condition when $m=3$.
\end{proof}

The implementation rejects malformed rules, out-of-range generators, forward references, noninteger indices, and Boolean values masquerading as integers. It distinguishes a multi-component closure, reported as \texttt{LINK}, from a nontrivial knot, reported as \texttt{KNOTTED}. The knot-detection theorems apply only after the component check. For $m=1$ the empty braid closes to an unknot, whereas the empty three-braid closes to a three-component link.

The native JSON schema is deliberately small:
\begin{lstlisting}
{"strands": 3,
 "rules": [["e"], ["g", 1], ["g", 2], ["c", 1, 2]],
 "root": 3}
\end{lstlisting}
This is the braid $\sigma_1\sigma_2$, not a planar-diagram record. Binding it to a separately supplied diagram requires an additional certified conversion; no such binding is silently assumed.

\section{The three-braid criterion, with an algebraic audit}
This section records the criterion already used in the project and explains why the compressed backend may use it. It also separates a necessary invariant from a complete classification in this special domain.

Put $a=\sigma_1$, $b=\sigma_2$, $x=aba$, and $y=ab$. The standard presentation is
\[
 B_3=\langle x,y\mid x^2=y^3\rangle,
 \qquad c=x^2=y^3,
 \qquad G=B_3/\langle c\rangle=C_2*C_3.
\]
Exponent sum $e$ sends $a,b$ to $1$, so $e(c)=6$. Consequently the map
\[
 B_3\longrightarrow G\times\Z,\qquad \beta\longmapsto(\bar\beta,e(\beta))
\]
is injective: an element in its kernel is $c^q$ with $6q=0$. The same observation handles conjugacy lifts once a quotient conjugator is known.

Write $z=y^2$. The quotient syllables are $x,y,z$, with
\[
 x^{-1}=x,\quad y^{-1}=z,\quad z^{-1}=y,
 \qquad
 a\mapsto zx,\ a^{-1}\mapsto xy,\ b\mapsto xz,\ b^{-1}\mapsto yx.
\]
A reduced word alternates between the $x$ factor and the $\{y,z\}$ factor. A cyclically reduced word of length greater than one has its first and last syllables in different factors.

\begin{theorem}[Existing three-braid closure criterion]\label{thm:criterion}
Let $\beta\in B_3$ have a one-component closure, exponent $e$, and cyclically reduced quotient word $C$. Its closure is the unknot exactly in the following cases:
\[
\begin{array}{c|l}
 e& C\text{ up to cyclic rotation}\\\hline
 2&y\\
 -2&z\\
 0&\text{a length-four word with two }x\text{'s, one }y\text{ and one }z.
\end{array}
\]
In particular, the decision needs the exact exponent and at most four syllables of the cyclic core, not the full core when it is longer.
\end{theorem}
\begin{proof}
Bennequin's inequality and the inequality for the mirror imply $|e|\le2$ for a three-braid unknot \cite{bennequin}. At $t=-1$, the reduced Burau matrices are
\[
 A=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad
 B_0=\begin{pmatrix}1&0\\-1&1\end{pmatrix}.
\]
The braid Alexander formula specializes, for three strands, to
\[
 \det K=\left|\det(I-M)\right|=|2-\tr M|,
 \qquad M=\rho_{-1}(\beta),
\]
where the usual Laurent-unit ambiguity disappears after absolute value \cite{conway}. An unknot therefore has $\tr M\in\{1,3\}$.

We audit the corresponding small-trace quotient classes. A nontrivial cyclically reduced word of length greater than one can be rotated to
$x y^{\epsilon_1}\cdots x y^{\epsilon_q}$ with $\epsilon_i\in\{1,2\}$. Up to overall sign and conjugation by $\operatorname{diag}(1,-1)$, its matrix is a product of
\[
 L=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad
 R=\begin{pmatrix}1&0\\1&1\end{pmatrix}.
\]
Indeed $\rho(xy)=-L^{-1}$ and $\rho(xy^2)=-R^{-1}$. If the positive product contains $p$ letters $L$ and $q'$ letters $R$, both positive, expand each factor as $I+E$ or $I+F$. All entries in all terms are nonnegative. Each of the $p q'$ terms choosing precisely one $E$ and one $F$ has trace one, while the identity term has trace two. Hence
\[
 \tr(\text{positive product})\ge2+p q'.
\]
Absolute trace three is possible only for one $L$ and one $R$, and is attained there. A product with only one letter type has trace two. The remaining cyclic quotient cores are the empty word, $x$, $y$, and $z$; their absolute traces are respectively $2,0,1,1$. Thus absolute trace one or three forces $C=y,z$, or the stated mixed length-four core.

The quotient also determines exponent modulo six. The two one-syllable cases have residues $2$ and $-2$; the mixed length-four case has residue $0$. With $|e|\le2$, the exponents are exactly those in the statement.

Conversely, the three cases are quotient-conjugate to the images of
\[
 ab,\qquad b^{-1}a^{-1},\qquad ab^{-1},
\]
respectively, with the same exponent. Lift a quotient conjugator to $B_3$. The two resulting braids can differ only by $c^q$, and exponent equality forces $q=0$. These three canonical closures are unknots by two elementary destabilizations. Conjugacy preserves braid closure, completing both implications.
\end{proof}

For general strand count, determinant one is not an unknot certificate. Even here determinant one without the exponent restriction is insufficient. The implementation relies on the complete theorem in its stated domain, not on an unqualified polynomial-identity test.

\section{Compressed free-product multiplication and cyclic reduction}
\subsection{The exact string interface}
A string arena stores terminal syllables and binary concatenations as an interned DAG. For a node $U$, the arena supplies length, first and last syllables, concatenation, half-open slicing $U[i:j]$, and exact equality. Inversion in this section is the anti-morphism reversing the word and exchanging $y,z$ while fixing $x$. It is \emph{not} integer sign negation as in a free-group alphabet.

Let $E(S,B)$ be a deterministic polynomial bit bound for exact equality on two strings in an arena with $S$ rules and $B$-bit length metadata. The standard SLP equality theorem gives such an $E$ \cite{schleimer}. We leave its exponent symbolic. Binary search using exact substring equality computes a longest common prefix in at most $B+O(1)$ queries. A bounded direct DAG walk is a permissible fast path only because it falls back to this complete procedure.

\begin{lemma}[One query, at most one merge]\label{lem:product}
Let $U,V$ be reduced words in $G$. Set
\[
 k=\LCP(U^{-1},V),\qquad
 U'=U[0:|U|-k],\quad V'=V[k:|V|].
\]
Their reduced product is $U'V'$ unless both surviving boundary syllables belong to the $C_3$ factor and are equal. In that case replace the two boundary syllables $yy$ by $z$, or $zz$ by $y$. No further reduction is necessary.
\end{lemma}
\begin{proof}
The inverse-prefix equality cancels exactly a suffix of $U$ against a prefix of $V$. If a remainder is empty, the other is already reduced. Otherwise maximality of $k$ says that the two surviving boundary syllables are not inverses. Distinct factors therefore require no action. Two $x$ syllables would be inverses, as would $y,z$ in either order; these cases contradict maximality. The only remaining same-factor pairs are $yy$ and $zz$, with the products stated. On either side of the new $C_3$ syllable, any existing neighbor is an $x$, because the original words were reduced. Thus no new same-factor adjacency is created.
\end{proof}

The algorithm processes input rules in order. A terminal is replaced by its two-syllable image. A concatenation invokes Lemma~\ref{lem:product} on the already reduced child roots. Both children may share large subgraphs; no rule requires enumeration of occurrences in the expanded value.

\begin{lemma}[A compressed cyclic core and conjugator]\label{lem:cyclic}
Let $W$ be reduced. Define
\[
 t=\LCP(W,W^{-1},\lfloor |W|/2\rfloor),\quad
 P=W[0:t],\quad R=W[t:|W|-t].
\]
If $|R|\le1$ or the endpoints of $R$ have different factors, put $C=R$, $Q=P$. Otherwise $R=fMf$ for $f\in\{y,z\}$, and put
\[
 C=Mf^2,\qquad Q=Pf.
\]
Then $C$ is cyclically reduced and $W=QCQ^{-1}$ in $G$.
\end{lemma}
\begin{proof}
The prefix equality gives $W=PRP^{-1}$. A longer inverse pair at the endpoints of $R$ would contradict maximality of $t$. If the endpoints have the same factor and there is more than one syllable, they must therefore be equal $C_3$ syllables. The interior $M$ starts and ends with $x$ whenever nonempty; since $R$ was reduced, this same-factor endpoint case has length at least three. The word $Mf^2$ is consequently cyclically reduced. Finally,
\[
 (Pf)(Mf^2)(Pf)^{-1}=P f M f^2 f^{-1}P^{-1}=P f M f P^{-1}=W.
\]
All equalities use $f^3=1$. The other cases are immediate.
\end{proof}

\subsection{Discovery pseudocode}
\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
validate the binary grammar and compute length, exponent, permutation
if the permutation is not a three-cycle: return LINK
if abs(exponent) > 2: return KNOTTED with the finite witness
normal[0] = empty
for rule i in topological order:
    if terminal: normal[i] = the two-syllable generator image
    else:
        k = LCP(inverse(normal[left]), normal[right])
        normal[i] = trim k from the adjoining ends; merge once if needed
        record k
(core, conjugator, trim, merge_flag) = cyclic_reduce(normal[root])
read core only if its exact length is at most four
apply the exponent/core criterion and emit the reduction certificate
independently replay the certificate before publishing a decision
\end{lstlisting}
\end{minipage}
The procedure finds the core; it is not a certificate-existence argument. Its number of rule reductions is exactly bounded by the input DAG, unlike unrestricted searches through Whitehead or Markov moves.

\section{Polynomial grammar growth and bit complexity}
A polynomial-time primitive is not enough if the calling program creates exponentially many intermediate rules. This section accounts for that growth explicitly.

\begin{lemma}[Slice and height bounds]\label{lem:height}
An interval of a binary string grammar of height $h$ can be represented using $O(h)$ new concatenation nodes without increasing height. The reduced representative of an input rule at dependency depth $d$ can be maintained with height at most $2d+2$.
\end{lemma}
\begin{proof}
Only the two boundary paths of an interval can be partially retained. Every completely included subtree is reused. Reassembling the retained pieces in the original tree shape needs at most a constant number of nodes per boundary-path level; deleting empty pieces does not increase height. Reversal with syllable inversion preserves height. A terminal image has height two. In a product reduction, slicing does not raise child height, and reassembly uses at most two additional concatenations. Induction on input dependency depth proves the second bound.
\end{proof}

\begin{theorem}[Native compressed three-braid recognition]\label{thm:main}
For a binary SLP describing a three-braid, a complete component-and-unknot decision and a replay certificate can be produced in deterministic polynomial bit time in $g$. More explicitly, there is an implementation with
\[
 S=O\bigl(s^2(B+1)\bigr)=O(s^3+s^2)
\]
allocated string rules and at most $O(s(B+1))$ exact string-equality queries. Its discovery time is bounded by
\begin{equation}\label{eq:discovery}
 O\!\left(s(B+1)\,E\bigl(C s^2(B+1),B+O(1)\bigr)\right)
 +\poly(s,B)
\end{equation}
for an absolute constant $C$. Here $E$ is any fixed deterministic polynomial SLP-equality bound.
\end{theorem}
\begin{proof}
There are at most $s$ product reductions and one cyclic reduction. Each has one prefix query, with at most $B+O(1)$ bisection steps: all syllable lengths are at most twice the corresponding input lengths, and all scratch substrings have length at most $2N_*$. Each bisection step needs a constant number of slices; Lemma~\ref{lem:height} bounds their new nodes by $O(s)$. The final trimming and reassembly for each product also adds $O(s)$ nodes. Memoized inversion adds at most a constant multiple of the number of reachable nodes it has not yet inverted. Thus total allocation is $O(s^2(B+1))$.

The equality method operates on this bounded arena. Metadata arithmetic has $B+O(1)$ bits. Topological validation, finite summaries, dictionary operations under conservative polynomial worst-case accounting, and the other DAG traversals contribute a polynomial term. Equation~\eqref{eq:discovery} follows. Since $B=O(s+1)$, it is polynomial in the input bit size. Correctness follows from Lemmas~\ref{lem:product} and~\ref{lem:cyclic}, induction over rules, and Theorem~\ref{thm:criterion}.
\end{proof}

The theorem does not advertise a cubic-time implementation. The cubic expression bounds \emph{allocated string rules}, not the running time of equality. Nor does an abstract work counter establish a CPU-instruction bound. Completeness concerns the uncapped procedure; the research CLI uses finite allowances and can return inconclusive. Increasing allowances by a doubling schedule until discovery and replay finish recovers the complete procedure with polynomial overhead. It is nevertheless a genuine polynomial algorithm in compressed input size: both call count and representation growth have been bounded before invoking the polynomial primitive.

\begin{corollary}[Compressed conjugate sleeves]\label{cor:sleeves}
Let $U$ be any braid SLP of size $h$, and let $\gamma$ be one of the three canonical unknots in Theorem~\ref{thm:criterion}. A grammar for $U\gamma U^{-1}$ has size $O(h)$, and its closure is decided without expanding $U$. The same conclusion holds with any fixed three-braid $\gamma$, including knotted examples.
\end{corollary}
\begin{proof}
Memoized inversion and concatenation add $O(h)$ rules. Apply Theorem~\ref{thm:main}; no conjugating decomposition has to be supplied separately to the recognizer.
\end{proof}

This class includes grammars with nested reuse and many signed runs. It is strictly more general as a representation class than a word with logarithmically many explicit twist blocks. Conversely, an arbitrary explicit word need not have a sublinear grammar. Constructing an identity-sized grammar from it preserves polynomial correctness but is generally slower than the maintained linear explicit gateway.

\section{Proof-carrying recognition and independent replay}
\subsection{Certificate contents}
A versioned three-braid certificate contains the original grammar, the recomputed finite summaries, a string-rule table, the reduced root for every input rule, and one cancellation length for every concatenation. It also gives the final cyclic trim, the possible endpoint-merge flag, a core root, and a conjugator root. Exact long integers such as lengths and exponents use canonical signed hexadecimal strings, avoiding a decimal-conversion limit when lengths have thousands of bits. Node indices remain ordinary bounded integers.

The certificate binds to the supplied input by exact canonical JSON comparison, not by trusting a digest. A SHA-256 digest is retained as an integrity aid but is not a mathematical equality oracle. In particular, the verifier rejects a Boolean substituted for an integer generator even though a programming language might otherwise compare those values as equal.

The arena can contain scratch strings. The verifier therefore does not infer that every arena node is a reduced group word. It computes a reducedness flag compositionally and requires the claimed normal roots, cyclic core, and conjugator to have that property. References must point to earlier well-formed nodes. The verifier imports all strings into a fresh arena and recomputes lengths and endpoints; producer metadata is not authoritative.

\subsection{Checking a product without searching for its cancellation}
For an input concatenation, let $U,V,W$ be the independently reconstructed child and claimed result roots, and let $k$ be the claimed cancellation length. The verifier checks
\[
 0\le k\le\min(|U|,|V|),\qquad
 \bigl(U[|U|-k:|U|]\bigr)^{-1}=V[0:k]
\]
by exact string equality. It then examines the surviving endpoints. A residual inverse pair is forbidden. Equal $C_3$ endpoints must be merged, while different factors must be concatenated without a merge. Finally, the resulting string is compared with $W$. The endpoint condition establishes maximality of $k$ without recomputing an LCP.

For the cyclic witness the checker similarly verifies that the claimed prefix and suffix are inverse, checks that no further inverse trimming is possible, reconstructs the one permitted endpoint merge, and checks both $C$ and $Q$. The classification is then recomputed from the source exponent and the certified core. The producer's final status is accepted only if it agrees.

\begin{theorem}[Certificate soundness and size]\label{thm:certificate}
Every certificate accepted by the independent verifier gives the correct component or knot verdict for its supplied three-braid grammar. An honestly generated certificate has bit size
\begin{equation}\label{eq:certsize}
 O\bigl(g+S\log(S+2)+sB\bigr),\qquad S=O(s^2(B+1)).
\end{equation}
Its replay uses $O(s)$ exact string-equality queries and polynomial other work. Verification of an arbitrary supplied certificate is polynomial in the combined input and certificate sizes, subject to explicit resource caps.
\end{theorem}
\begin{proof}
The finite branch recomputes the root permutation and exponent, so its conclusions follow from component counting and Bennequin's obstruction. In the quotient branch, terminal roots are compared with the fixed generator images. Assume inductively that the child normal roots are correct. The checked inverse substring equality proves that the claimed cancellation is valid. The residual endpoint checks and reducedness prove maximality and validate the only possible merge, by Lemma~\ref{lem:product}. Exact equality with the claimed result completes the induction. The cyclic checks establish Lemma~\ref{lem:cyclic}, after which the source exponent and Theorem~\ref{thm:criterion} force the verdict.

Each arena rule has a constant number of references of $O(\log(S+2))$ bits. Each input rule contributes a root index and a cancellation integer of $O(B)$ bits. The rest consists of the original input, finite summaries, and a constant number of roots and offsets. This proves~\eqref{eq:certsize}. Each input product requires only a constant number of equality queries; so do each terminal and the final cyclic check. For valid producer output, the arena height is $O(s)$, and the checker's extra slices and inverse strings keep its allocation within the same polynomial envelope. For arbitrary supplied rule tables, their own heights and bit lengths replace those honest-output bounds, still giving polynomial verification in the combined encoding size.
\end{proof}

The replay implementation is independently structured: it imports neither the producer's reduction object nor its prefix-search routine. Tests disable both the producer entry point and the arena's LCP method during replay. However, the two sides intentionally share the exact string kernel and the imported topology. This is a smaller and clearer trust boundary, not the elimination of every common dependency. No formal proof assistant has checked this implementation.

A valid affirmative witness can also be interpreted as a compact braid conjugator. Lift each quotient syllable by the fixed words $x=aba$, $y=ab$, $z=(ab)^2$. In the length-four case adjust by a constant-length cyclic rotation. The quotient conjugacy and exact exponent then lift to equality in $B_3$. Thus the certificate does not conceal an exponentially long search for a conjugator; a polynomial-size grammar for one is available from its recorded data.

\subsection{Resource semantics}
A node, work, or external cooperative budget exception supplies no mathematical verdict. The CLI reports \texttt{INCONCLUSIVE} for its supported resource exception. Discovery and replay use fresh arenas, and a decision is published only after successful replay. The work counter charges abstract kernel operations, not every bit operation or elapsed second. Metadata validation and JSON parsing must also be covered by a host application's global size and time policy.

In the forest interface, arena caps apply separately to each child computation; they are not a global forest work allowance. A production integration should supply a shared deadline or work callback across all leaves and replay phases. An exception from an actual injected upstream kernel must be handled as that kernel's resource type, not mistaken for our local \texttt{Limit} class. The optional checkout check makes this boundary explicit.

\section{Why full Burau matrices can defeat compression}
The maintained matrix control is elegant and effective for explicit words. It is not automatically a polynomial-bit algorithm for SLP input merely because matrix powering uses logarithmically many multiplications.

\begin{theorem}[Materialization obstruction]\label{thm:matrix}
There is a family of three-braid unknot grammars of size $O(\log(m+1))$ for which a full ordinary binary representation of the Burau matrix at $t=-1$ requires $\Omega(m)$ bits, although its trace is identically one. With $m=2^k$, this is exponential in the grammar size.
\end{theorem}
\begin{proof}
Let $u=ab^{-1}$ and $\beta_m=u^m(ab)u^{-m}$. Its closure is an unknot. Binary powering and shared inversion give the claimed grammar size. Write
\[
 Q=\rho(u)=\begin{pmatrix}2&1\\1&1\end{pmatrix},\qquad
 T=\rho(ab)=\begin{pmatrix}0&1\\-1&1\end{pmatrix}.
\]
The Fibonacci identity gives, for $m\ge1$,
\[
 Q^m=\begin{pmatrix}a&b\\b&d\end{pmatrix}
 =\begin{pmatrix}F_{2m+1}&F_{2m}\\F_{2m}&F_{2m-1}\end{pmatrix},
 \qquad a=b+d.
\]
The upper-right entry of $Q^mTQ^{-m}$ is
\[
 b^2+a(a+b)=3b^2+3bd+d^2.
\]
Since $F_{2m}\ge2^{m-1}$, that entry has at least $2m-1$ bits. Conjugation nevertheless keeps the trace equal to $\tr T=1$. Hence any algorithm that materializes this full matrix in ordinary binary integer form has the stated output-size lower bound.
\end{proof}

The obstruction is deliberately narrow. It does not rule out compressed arithmetic circuits, modular obstructions, symbolic cancellation of a recognized conjugator, or other matrix-informed algorithms. It rules out treating ordinary huge matrix entries as unit-cost scalars. Our quotient string representation avoids exactly that materialization obligation.

This example also distinguishes three measures that can otherwise be confused: the represented braid length, the size of a symbolic proof of its conjugacy, and the size of an integer matrix representation of the same braid. The first and third may be exponential while the second remains small. A complexity analysis must name the representation at every interface.

\section{Singleton forests directly on compressed braids}
\subsection{The topological split and its provenance}
For a braid word $w$ on $m$ strands, let $c_j(w)$ count occurrences of $\sigma_j$ or $\sigma_j^{-1}$, without regard to sign. The singleton observation has classical antecedents in work of Van Cott \cite{vancott}; the project already develops an explicit all-factor version \cite{minority}. We give the topological argument to specify exactly what is preserved by our compressed projections.

\begin{lemma}[Singleton connected-sum split]\label{lem:split}
Suppose the closure of $w\in B_m$ is a knot and $c_j(w)=1$. Delete that unique crossing and project the remaining letters onto indices less than $j$ and greater than $j$, shifting the latter down by $j$. These give braids $w_L\in B_j$ and $w_R\in B_{m-j}$. Their closures are knots and
\[
 \cl(w)=\cl(w_L)\mathbin{\#}\cl(w_R).
\]
The conclusion is independent of the sign of the singleton crossing.
\end{lemma}
\begin{proof}
Cyclically rotate $w$ to place the singleton crossing at the closure seam. Every remaining letter belongs to one of the two strand intervals, and letters from the two intervals commute: their generator indices differ by at least two. Thus the two subbraids can be drawn in disjoint side-by-side regions, with the sole crossing joining the distinguished closure arcs. A separating sphere through those two joining arcs exhibits their connected sum. The sign changes the local band convention but not the two summand knot types. If the two separate closures have $r_L,r_R$ components, that joining merges one component from each, leaving $r_L+r_R-1$. A one-component original therefore forces $r_L=r_R=1$.

Projecting the original word instead of its cyclic rotation only cyclically rotates each projected subword. Their closures are unchanged. Thus the statement applies to the deterministic source-order projections used by the implementation.
\end{proof}

Split at all indices with $c_j=1$. Induction in Lemma~\ref{lem:split} gives interval leaves and a connected-sum forest. A projection removes letters of other indices but neither changes nor duplicates occurrences of a retained index. Therefore every retained internal generator in a leaf is either absent or still has its original multiplicity. For a knot leaf none is absent, and, after all singleton cuts, each multiplicity is at least two.

\subsection{Counting without enumerating occurrences}
The same terminal rule may occur exponentially many times in the root value. Counting one occurrence per stored terminal would be wrong. Instead put multiplicity one on the root and propagate weights down the DAG in reverse topological order. At $X_i=X_aX_b$, add the weight of $i$ to both $a$ and $b$, including twice when $a=b$. At a terminal, add its accumulated weight to the unsigned generator count. This computes every $c_j$ exactly with a linear number of propagation steps and polynomial-size integers.

There is a subtle input-validation issue when the strand count itself is binary encoded. An empty grammar with an enormous $m$ must not cause allocation of an enormous permutation array. If any index $1\le j<m$ is missing, the braid permutation preserves both strand intervals separated by $j$; its closure cannot be a knot. A missing index can be found by sorting the stored support and locating a gap. If no index is missing, then every one of the $m-1$ labels appears in some terminal rule, and hence
\begin{equation}\label{eq:strandbound}
 m\le s+1.
\end{equation}
Only then do we allocate and compose $m$-point permutations. This makes variable-strand component validation polynomial in actual input size, not in a potentially enormous unsupported strand count.

\begin{lemma}[Native interval projections]\label{lem:projection}
Given a strand interval $[\ell,h]$, its projected braid grammar can be computed using at most $s$ nonempty rules, by deleting terminals outside the interval, shifting retained generator indices, and pruning empty concatenations. All singleton leaves together have polynomial total encoding size in $g$.
\end{lemma}
\begin{proof}
Process each input rule once. A terminal maps either to a shifted terminal or to the distinguished empty node. A concatenation maps to the concatenation of its mapped children, with an empty child suppressed. Interning can only decrease the number of nonempty output rules. There are at most $m$ leaves, and~\eqref{eq:strandbound} applies to an input that passes the knot-component test. Thus at most $O(sm)$ rules are needed, with polynomial-size indices and generator labels.
\end{proof}

\begin{theorem}[Native compressed singleton-forest recognition]\label{thm:forest}
There is a deterministic polynomial-bit procedure on arbitrary-strand binary braid grammars that computes and verifies their singleton decomposition and completely decides every input for which all leaves have at most three strands. This conclusion is independent of the leaves' expanded crossing counts. On other inputs it gives sound one-sided decisions and otherwise reports \texttt{INCONCLUSIVE}.
\end{theorem}
\begin{proof}
Perform compressed counts and component validation, then construct all interval projections. One-strand leaves are unknots. A two-strand knot closure has odd exponent and is unknotted exactly when the exponent has absolute value one. Apply Theorem~\ref{thm:main} to every three-strand leaf. The original knot is trivial exactly when all its connected-sum factors are trivial. For the nontrivial implication, intersect a spanning disk with a summing sphere, remove closed intersection curves by innermost-disk surgeries, and cut along the sole remaining arc; this gives spanning disks for the capped summands. Conversely, boundary-connecting summand disks gives a spanning disk for their connected sum. There are polynomially many leaves of polynomial grammar size, proving the time and certificate bounds. A wider leaf may be rejected by Bennequin's obstruction. Without such an obstruction or a separate complete backend it remains unresolved. No unresolved leaf is ever counted as an unknot.
\end{proof}

The forest verifier recomputes source counts, the complete cut set, and every interval projection. It then invokes child verifiers and recomputes the connected-sum verdict. Projection code is shared between discovery and replay; the independently implemented component of replay is the three-braid algebra, not a second independent topology library. A tampered cut list or altered projected grammar is rejected.

\subsection{Why closure equivalence is not a substring rewrite}
Theorem~\ref{thm:criterion} is a theorem about \emph{closed} braids. It does not license replacing an arbitrary three-strand subword of a larger braid by any other word with the same closed knot. Such a substitution can alter how the tangle meets its environment. The singleton theorem supplies a genuine connected-sum separation, making the closed factor the correct object to decide. In other settings one must retain boundary and peripheral data, or prove equality in the braid group rather than equality of closed knot types. The implementation performs only the certified singleton separation, not unrestricted local closure replacements.

\section{The three-braid-exempt minority bound}
The compressed forest makes an existing minority-sign estimate more useful. One need not pay an exponential cost for the minority count of a factor that has already been decided in compressed form.

For each leaf $i$, let $n_i$ be its expanded crossing count, $m_i$ its strand count, $e_i$ its exponent, and
\[
 \kappa_i=\min(n_i^+,n_i^-)=\frac{n_i-|e_i|}{2}.
\]
These integers are computed directly on the leaf DAG. Let $\mathcal E$ be the set of leaves with more than three strands that pass the Bennequin test and are not otherwise decided by a certified easy backend. Define
\[
 \kappa_{\exc}=\max_{i\in\mathcal E}\kappa_i,
 \qquad \max\varnothing=0.
\]
For the delivered implementation, the easy complete backends are the at-most-three-strand ones; no additional wider-leaf backend is assumed in its actual verdicts.

\begin{lemma}[Exceptional crossing bound]\label{lem:minority}
Every unresolved leaf after all singleton cuts and its local Bennequin test satisfies
\[
 n_i\le4\kappa_i,\qquad m_i\le2\kappa_i+1.
\]
\end{lemma}
\begin{proof}
Each of the $m_i-1$ internal generator indices occurs at least twice, so $m_i-1\le n_i/2$. Passing the local test means $|e_i|=n_i-2\kappa_i\le m_i-1$. Combining gives $n_i-2\kappa_i\le n_i/2$, hence $n_i\le4\kappa_i$, and then $m_i\le n_i/2+1\le2\kappa_i+1$.
\end{proof}
This elementary estimate is inherited from the explicit singleton/minority analysis \cite{minority}. What changes is the exceptional set: arbitrarily large compressed three-braid leaves have already been solved and are excluded.

\begin{theorem}[Hybrid complete bound]\label{thm:hybrid}
Attach any complete exact fallback that decides a $k$-crossing knot diagram in $2^{O(k)}$ bit time. On a binary braid grammar of bit size $g$, the singleton forest followed by compressed three-braid decisions and separate exceptional fallbacks is a complete recognizer with time
\begin{equation}\label{eq:hybrid}
 \poly(g)+\sum_{i\in\mathcal E}2^{O(\kappa_i)}
 \ \le\ \poly(g)+|\mathcal E|\,2^{O(\kappa_{\exc})}.
\end{equation}
It is polynomial in $g$ when $\mathcal E$ is empty and quasi-polynomial in $g$ whenever $\kappa_{\exc}=O(\log^2(g+2))$.
\end{theorem}
\begin{proof}
All native compressed operations have polynomial cost by the previous theorems. Any knotted easy factor or local Bennequin obstruction terminates with a sound negative decision. Otherwise the original is an unknot precisely when all unresolved factors are unknots. By Lemma~\ref{lem:minority}, an exceptional leaf expands to at most $4\kappa_i$ crossings on at most $2\kappa_i+1$ strands. Expanding that leaf and constructing its ordinary diagram takes polynomial time in this size, absorbed by $2^{O(\kappa_i)}$. Apply the fallback independently to each leaf and sum the costs. The number of leaves is polynomial in $g$. Finally $2^{O(\log^2(g+2))}=(g+2)^{O(\log(g+2))}$.
\end{proof}

A suitable theoretical fallback exists by building a reduced Khovanov complex over $\F_2$ and doing exact linear algebra. A $k$-crossing knot has $2^k$ resolutions and only $O(k)$ state circles, so the expanded chain dimension and all elementary construction and elimination costs are $2^{O(k)}$. Kronheimer--Mrowka's rank-one detection theorem supplies the decision criterion \cite{km}; the integral universal-coefficient comparison transfers rank-one detection to $\F_2$. The package does \emph{not} include a new full Khovanov implementation or claim to have wired this fallback into production. Equation~\eqref{eq:hybrid} is the proved bound for that complete composition; the delivered forest module deliberately returns \texttt{INCONCLUSIVE} on unsupported leaves.

\begin{corollary}[Conventional diagram-size formulation]\label{cor:qp}
Suppose an $n$-crossing input is transformed, with verified closure-preserving provenance and polynomial cost and encoding size, into the grammar of Theorem~\ref{thm:hybrid}. If its exceptional minority parameter is $O(\log^2(n+2))$, the complete composed recognition algorithm takes $n^{O(\log n)}$ time.
\end{corollary}
\begin{proof}
Substitute the polynomial grammar bound and the stated parameter bound into~\eqref{eq:hybrid}, and include transformation and verification costs.
\end{proof}

\subsection{Strict scope gain over counting all factors}
Consider a singleton join of many conjugate three-braid sleeves. Each sleeve may have exponentially large minority count in its SLP size, yet all leaves are solved by Theorem~\ref{thm:main}. Thus $\kappa_{\exc}=0$ even while the largest minority count over \emph{all} factors is exponential. Append one fixed wider factor through a singleton join. The exceptional parameter is now bounded by that fixed factor alone. The remaining decision cost does not depend exponentially on the sleeves' expanded lengths.

This is a genuine improvement in the sufficient parameter condition, not a claim that every knot has a cheaply discoverable singleton decomposition of this kind. Braids with no singleton generator can leave a single large exceptional factor. The supplied four-strand inconclusive control demonstrates the boundary of the native recognizer rather than pretending that a failed split is a certificate.

\subsection{The precise missing general theorem}
For a general quasi-polynomial result along this route one would need a constructive transformation, with controlled proof size and cost, that always exposes a polynomial-size compressed easy-factor forest and leaves $\kappa_{\exc}=O(\log^2 n)$. We prove neither the existence nor the discoverability of such a transformation for arbitrary diagrams. Merely knowing that an unknot can be simplified, or that a certificate can be encoded compactly, would not bound a search for that certificate. Those are separate requirements, and the present backend removes only the cost of solving the easy leaves once they are available.

\section{Integration contract and proposed project corrections}
\subsection{Additive integration rather than an assumed patch}
The supplied implementation is additive. A suitable review location is a named directory such as
\texttt{Topology/UnknotRecognition/research/compressed-braid-certificates/}.
No numbered report slot is assumed. The first production promotion should be the input schema, producer, and verifier behind an opt-in native-SLP route. Existing explicit-word dispatch and legacy certificate readers should remain unchanged.

The three-braid producer and verifier accept an arena factory. The intended factory is the maintained \texttt{WordArena}; only its exact string interface is used, and the free-product anti-morphism is implemented separately. The package supplies \texttt{integration/upstream\_check.py} to check that interface against an actual checkout and to compare actual imported explicit decisions. This check was \emph{not run} in the delivery environment. Repository reading through the connected GitHub tool succeeded, but obtaining a full checkout in the execution container did not. The source-derived local kernel tests must not be relabeled as actual upstream integration.

\subsection{Corrections to avoid in complexity claims}
The following are precise qualifications, not allegations of newly discovered errors in the maintained source.
\begin{enumerate}
\item The existing explicit three-braid algorithm is already linear in its word length. The present polynomial bound is in \emph{compressed input size}; these two statements concern different input models.
\item The local $O(s^2(B+1))$ estimate bounds grammar allocation, not total running time. Exact equality still contributes the polynomial $E(S,B)$.
\item A polynomial compressed word primitive does not bound the number of general search moves. Our three-braid producer has a bounded DAG pass; the maintained general group search needs a separate move-count and grammar-growth argument.
\item The inequality $n_i\le4\kappa_i$ is used only after all singleton cuts and a passed \emph{local} Bennequin test. Applying it before those conditions is unjustified.
\item An unresolved factor is not discarded. The hybrid theorem requires a complete fallback; the delivered partial forest interface does not silently provide one.
\item Certificate replay shares the exact string kernel and imported knot theory. It is independent of producer search, not independently formalized mathematics.
\end{enumerate}

\subsection{Operational review before promotion}
Production review should run the real factory-injection script, then the current full regression suite, preserving proof-format versioning and resource semantics. It should also check that a grammar-producing front end binds every compressed braid to the original diagram or accepted raw-braid input. A generated group presentation is not such a binding. For wider-leaf fallbacks, retain separate source projections and check each backend's certificate in the appropriate domain before combining statuses.

A service-facing verifier must limit input bytes, certificate bytes, declared rules, and integer sizes before substantial allocation. Internal abstract work caps should not be mistaken for hard wall-clock or memory limits. Cooperative external callbacks are useful, but a hosting process must enforce its own global policy. The supplied research CLI is not claimed to be a hardened adversarial-input service.

\section{Further research questions and topics}
The following questions are organized by the proof obligation they would remove. A successful answer should include both a mathematical size bound and a checked implementation, rather than only favorable examples.

\begin{question}[A sharper free-product string kernel]
Can direct compressed reduction in $C_2*C_3$ reduce the $O(s^2(B+1))$ allocation envelope while improving worst-case equality cost? One concrete target is an $O(s^2)$-size normal-form representation with deterministic prefix queries that avoid a separate binary search over $B$ bits. The analysis must include all substrings and inverse nodes accumulated across the whole DAG.
\end{question}

\begin{question}[Representation-insensitive performance]
How do equivalent balanced, skewed, reassociated, and deliberately nonshared input grammars change the cost of recognition? The positive sleeve benchmark favors exact sharing. A useful next corpus should preserve the represented braid while varying its parse independently, record equality splits and peak assertions, and identify a normalizing or balancing transformation whose own cost does not erase its benefit.
\end{question}

\begin{question}[Smaller proof objects]
Can discovery discard equality scratch nodes and emit only the subgrammar needed for replay, with a proved near-quadratic or better certificate-size bound? Any compaction must preserve exact references and must not reintroduce exponential duplication. Compare producer-arena size, reachable proof size, serialized bytes, and fresh verifier allocation separately.
\end{question}

\begin{question}[An independently verified equality foundation]
Can the finite-factor reduction and cyclic-conjugator lemmas be formalized, followed by the indexed split-and-compaction equality kernel? An intermediate milestone is a second structurally different equality backend used only for audit. Sharing the same kernel on producer and verifier is practical, but it remains the largest common algorithmic dependency.
\end{question}

\begin{question}[Compressed moves that reveal new singleton cuts]
Can certified context-safe braid equalities, cyclic cancellation, and endpoint descent update occurrence multiplicities and interval projections without expansion? The goal is to expose singleton cuts hidden by a compact sequence of elementary moves. A result must bound the number of moves and aggregate grammar growth; repeated local improvement alone does not give such a bound.
\end{question}

\begin{question}[A broader exact family of easy leaves]
Which wider braid families admit polynomial-in-SLP-size closure recognition with independently replayable certificates? Reducible or explicitly decomposed braid families are natural candidates, provided their boundary identifications are retained. Every additional exact easy-leaf family can be removed from $\mathcal E$ in Theorem~\ref{thm:hybrid}, improving the exceptional parameter without changing its proof pattern.
\end{question}

\begin{question}[Four-strand input as a controlled next case]
What additional information beyond exponent and a virtually free quotient is needed for a useful four-strand compressed backend? The concrete target is a certified subclass with an exact membership and decision procedure, not a claim that the three-braid constant-core criterion simply generalizes. The supplied unresolved four-strand example is a minimal interface test for this extension.
\end{question}

\begin{question}[Presentation-dependent minority parameters]
How much can $\kappa_{\exc}$ decrease under a bounded, certified set of Markov and braid moves? This parameter is attached to a presentation and its certified decomposition, not claimed to be a knot invariant. Prove either useful approximation guarantees under a restricted move system or obstruction families showing why a proposed local system cannot achieve them.
\end{question}

\begin{question}[A certified diagram-to-grammar producer]
Can the general diagram pipeline produce compact braid words and a proof of their closure equivalence, while preserving compression during simplification? The relevant measure is the sum of discovery time, proof size, and replay time. A small final grammar is not enough if an exponentially expanded intermediate object was needed to find it.
\end{question}

\begin{question}[Marked collars and geometric hierarchies]
Can braid-encoded collars or parallelity regions inside a geometric hierarchy be replaced by compressed certified objects while retaining meridian, longitude, and attachment data? A successful interface would connect the present exact algebra to the geometric program. An unmarked closed-braid classification is insufficient for substitution into an arbitrary three-manifold boundary pattern.
\end{question}

\begin{question}[An end-to-end exceptional-parameter theorem]
Find a natural nontrivial diagram class for which a certified polynomial-size transformation always yields $\kappa_{\exc}=O(\log^2 n)$. A stronger universal statement would meet the general goal, but even a precise structural class beyond planted connected sums would be meaningful. The theorem must describe how the transformation is discovered, not merely assert the existence of a favorable representation.
\end{question}

\begin{question}[Fallback and budget integration]
Wire the verified exceptional leaves into the maintained complete backend with a shared global resource ledger and preserved child certificates. Measure crossover thresholds for explicit versus compressed leaves and verify that a fallback timeout never changes an unresolved overall status into an affirmative one. This is an implementation milestone, not a new mathematical assumption in the hybrid bound.
\end{question}

\begin{question}[Independent nonplanted evaluation]
Build a reproducible corpus from actual grammar-producing project workflows, rather than only powers and known conjugates. Keep explicit-input and compressed-input populations separate. Report unsuccessful decompositions, no-progress overhead, certificate size, replay cost, and whole-pipeline cost. An exact algebraic stress test and an operational knot benchmark answer different questions and should remain separately labeled.
\end{question}

\section{Conclusion}
The concrete achievement is a complete native compressed recognizer for three-braid knot closures, with controlled grammar growth and a replayable proof for every reported decision. Its connected-sum extension preserves this advantage at arbitrary strand count whenever all factors fall into the supported family. A matrix materialization lower bound explains why this gain is not obtained automatically from a compact product notation.

For the broader quasi-polynomial program, the useful new accounting rule is to charge the exponential backend only for \emph{exceptional} factors. The three-braid-exempt minority bound permits huge compressed easy factors without placing their crossing or minority counts in that exponent. The missing general step is still a provably efficient producer of favorable decompositions. The article and artifacts make that remaining obligation explicit, while supplying a tested, exact component that such a producer can use.
