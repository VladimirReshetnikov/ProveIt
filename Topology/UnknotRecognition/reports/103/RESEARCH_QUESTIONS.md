# Further research: a programme toward quasipolynomial recognition

These are proposed problems, not consequences already established by the present results. Section 9 of the article explains their mathematical motivation and the precise gaps they address. The first three are the most direct continuation of the measured implementation; the others concern the geometric and global obligations needed for a complete complexity theorem.

## 1. Reuse authenticated source work

**Question.** Can one internally constructed immutable source context serve several stages without repeating triangulation validation, normal-coordinate reconstruction, and incidence compilation?

The local queue is now cheap enough that common source work dominates the large measured case. A useful design must retain exact input identity and prevent a caller from forging a “validated” context. Separate producer and verifier reconstructions should remain where they provide certificate independence. Measure construction cost, whole-query latency, memory, mutation rejection, and interruption behavior. A cache-hit microbenchmark alone would not resolve this problem.

## 2. Lift stopping cores through the full finite terminal matrix

**Question.** Can the exceptional-row quotient operate on the combined core and saturated-bundle matrix while preserving the existing geometric projection and private-cocore accounting?

The current kernel experiment covers core attaching rows. The remaining whole-cut failures involve the assembled terminal problem. The next result should track row ownership, interface-circle charts, and the reasons omitted private columns cannot become pivots. Its output should identify actual source curves and annuli behind the residual obstruction. That would make later geometric repairs precise even before it increases coverage.

## 3. Compare valid source-tree policies on genuine long-row inputs

**Question.** When do the default queue and the universal source tree have the same terminal success set? Can a different valid top tree help when exceptional rows survive?

The source template proves universal validity, not downstream optimality. The homological theorem shows that eligible trees in the stated short-row class cannot differ in complete-peeling outcome. Look for policy differences in authenticated long-row examples, preserve the exact attaching geometry, and test the full terminal consumer. Reject examples that fail the chain identity before treating them as geometric evidence. A smallest genuine example where forest choice changes raw completion would be valuable.

## 4. Transport an inherited boundary pattern in compressed form

**Question.** Can the relative collar maps be extended to compactly transport admissible pattern curves or trivalent graphs that cross the cancellation support?

One possible representation is a composition grammar of local PL boundary maps with source flags and affine rank intervals. The required theorem must bound the representation and the actual queries made by a hierarchy: intersections, embeddedness, disjointness, and pattern admissibility. The local move list is short; its fully expanded action on a complicated pattern need not be. Avoidance of the native ports is only the first special case.

## 5. Parameterize the forest search by exceptional interaction

**Question.** For `k` exceptional rows, is there a complete search over useful geometric forest changes or local repairs in `(t+b_x)^{O(k+1)}` time, or another bound that is quasipolynomial for logarithmic `k`?

The fixed-forest matrix has at most `3^k-1` nonzero column types, but the number of types is not a bound on all reachable geometric states. The forest components, pin locations, and reconstruction maps can change. A first milestone is either a bounded family of representative states with a lifting theorem or a counterexample showing why a proposed locality/exchange rule fails. General peelable row sets are not a matroid, so ordinary matroid exchange cannot be assumed.

## 6. Optimize the primal cocore system

**Question.** Can a primal zero/one forest be chosen so that exceptional rows have bounded number or bounded interaction complexity?

The rigidity theorem fixes this primal forest. Changing it changes the surviving columns and may change which rows are short. This is a plausible source of real algorithmic freedom. Any objective should include the positions and multiplicities of exceptional pins, not just the count of long rows. A certificate must identify the new geometric cocores and preserve all relevant marks; algebraic exponent reduction does not substitute for unsigned geometric intersection reduction.

## 7. Find a complete geometric repair family for a lifted stopping core

**Question.** Which handle slides, disk exchanges, and boundary bigon removals suffice to make progress near an exact lifted obstruction?

The maximal stopping lift gives exceptional rows and the short-tree paths supporting them. A desired theorem would show that a useful repair lies in a controlled neighbourhood, give a compact certificate for the repair, and prove a decrease of a bounded potential. A counterexample in which every useful repair leaves that region would be equally informative. The exact obstruction localizes the question; it does not prove such locality or completeness.

## 8. Batch large geometric primitive reductions

**Question.** Can a long sequence of related curve slides be represented and checked as one operation on binary source coordinates?

Compressed free-group primitivity supplies instructive algorithmic comparisons, including exponentially long elementary descent sequences. Its algebraic operations must be lifted to actual embedded curves, disjointness relations, and protected patterns before they help this pipeline. Seek families with a provably repetitive geometric move pattern, then bound both the batch description and its independent replay. Avoid expanding the represented sequence even when its endpoint word is short.

## 9. Establish a hierarchy potential that survives rebuilding

**Question.** Is there a monotone or amortized potential controlling source size, coordinate bit length, pattern complexity, and the cost of resetting the representation?

Deleting equal numbers of two- and three-handles preserves Euler characteristic and is not by itself a global topological progress measure. A sound recurrence must charge operations within a phase and the cost of its successor state. Separate estimates with circular dependencies do not bound a complete algorithm. State the recurrence in encoded sizes and account for memory as well as time.

## 10. Connect compressed operators to complete useful-surface discovery

**Question.** Can separator, first-return, and surface-batch operators be connected to the admissibility and essentiality conditions of a complete hierarchy with explicit bit bounds?

The incoming work provides several exact graph and normal-coordinate operators. They still need authenticated source exporters, correct geometric interpretations, and a proof that their candidate families are complete for the intended next step. Polynomial checking of a candidate is not polynomial discovery. For any restricted search, specify precisely what exhaustive failure certifies and whether a larger fallback remains necessary.

## 11. Generalize the native source interface for later hierarchy states

**Question.** Can the source constructor and all relevant consumers handle several boundary components and inherited patterns?

The local source top theorem already allows nonempty boundary in this generality, while the native validator accepts a single torus boundary. Removing that test alone would not prove the downstream contracts. Review boundary component ownership, compressing-disk claims, pattern essentiality, and provenance from the original knot diagram. Reentrant source construction is a natural point to connect successive hierarchy states explicitly.

## 12. Formalize the finite certificate kernel

**Question.** Which cap, rooted-tree, graphic-peeling, and stopping-lift lemmas can first be mechanized?

The finite certificate logic is small enough for a focused formalization. A useful milestone states exactly what every accepted trace proves about graphs and occurrence rows. The PL source interpretation should remain a separately named theorem until it too is formalized. Independent Python implementations, exhaustive finite checks, and oracle comparisons have different evidential roles from a proof assistant and should continue to be reported separately.

## A useful global acceptance criterion

A claimed quasipolynomial continuation should provide bounds on both the number `N(n)` of visited states and their encoded size `L(n)`, along with a fixed polynomial bound per authenticated state. Then the accumulated local cost is `O(N(n)L(n)^c)`. The present source top theorem avoids adding a coordinate-support or tree enumeration merely to obtain a valid top reduction. It does not prove the missing bounds on `N` and `L`.

The next decisive advance would combine a complete geometric progress operation with this kind of global accounting. Another optimizer for arbitrary abstract cap/occurrence graphs would leave the main geometric obstruction unresolved.
