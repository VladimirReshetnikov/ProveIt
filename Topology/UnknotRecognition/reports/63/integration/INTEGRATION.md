# Proposed native integration contract

This is an integration specification, **not an installed or tested native patch**.
The independently runnable braid wrapper is delivered; a complete native WordArena
donor collector and native PD/trace integration remain future work.

## Placement and initial policy

Keep the standalone package under a nonconflicting research directory. Do not
replace the maintained primitive projection/forest code or certificate versions.
Introduce a new optional deletion stage only after a native source-bound prototype
has passed the existing suite. Preserve the old path byte-for-byte when disabled.
Do not reserve a certificate version number without checking the then-current repo.

## Trusted facts and source binding

The absolute-cycle rule requires **classical knot-group provenance**, not merely
torsion-freeness. The complete source PD and every prior presentation change must
already be independently replayed. A Boolean flag from a caller is not proof.

Authenticate each donor against its current relator slot. A root raised to a positive
power may be reduced to its root only using the proven torsion-free premise. Record
all word cuts or equality proofs needed for `x_s^a U x_t^-b U^-1`. A plain flag may
be issued only for a conjugator proved equal to the identity. Never infer a plain
flag from zero abelianized exponent sums.

## Kernel and proof boundary

`power_graph.Edge(s,t,a,b,plain)` uses positive generator identifiers and nonzero
signed exponent integers. `power_graph.infer(vertices,edges,modular=True)` returns
`killed`, `witnesses`, and diagnostic `stats`. Pass only `killed` and `witnesses` to
`graph_checker.verify(vertices,edges,proof)`; the strict checker rejects extra fields.
The checker recomputes exact cycle products, validates traversal, and reconstructs
component closure independently. The modulus 65,537 is a search shortcut, not a
probabilistic or final equality test. Exhausting a budget is inconclusive.

A successful batch adjoins only identities proved by the selected cycles. Apply the
resulting simultaneous deletion to **every** retained relator, and keep every slot.
Delete no additional relation because its abelianization vanishes. Live-generator
changes and source-slot identities must be replayed independently of the planner.

## WordArena extension

Map the original immutable source grammar under the cumulative deletion mask. Keep
active source size separate from all historical arena allocations. This gives a
nonexpanding raw representation, but it does not solve compressed normalization or
exhaustive exposed-donor discovery. Record the latter as a separate budgeted module.
Neither a grammar-node cap nor the paper's mathematical bit bound is a hard process
memory limit for Python.

## Endpoint and fallback

Use an existing source-bound cyclic-group endpoint only after all relators have been
checked. No unsuccessful graph query is evidence of knottedness. The standalone
missed input `(strands=3, braid=[-1,2])` is a regression fixture for this boundary.
Retain complete recognition fallback and the prior remaining resource allowance.
The unconditional two-power minor checker may be used on authenticated plain donor
rows without a knot premise, but it still does not authenticate arbitrary source
rows or an entire knot presentation.

## Required native experiments before promotion

1. Replay old/current complete source certificates on actual PD inputs and all
   existing versions; mutation-test slot, sign, conjugator and source substitutions.
2. Search actual stalled intermediate presentations for cycle donors; compare with
   pure-power deletion, primitive forests, and singleton eliminations separately.
3. Measure full calls with shuffled old/new A/A controls, preserving all timeouts,
   regressions, proof-construction time, and mandatory replay time.
4. Keep the option disabled unless those measurements establish a useful policy.

The present audit provides no extra small-braid coverage from cycle inference. The
most informative next result would therefore be a genuine native stalled source
with a replayed nonseed cycle—not another large abstract determinant family.
