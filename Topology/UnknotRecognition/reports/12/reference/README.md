# Reference sources and verification boundary

The current ProveIt sources were read through the GitHub connector on 7 October 2026, under `Topology/UnknotRecognition/fast/fastunknot/`. The production paths are identified by Git blob IDs in `provenance.json`. A blob ID identifies file contents; it is not a repository commit ID.

## Current-source execution fixtures

`upstream/algebra.py` was transcribed from the complete connector response and its Git blob hash equals the inspected upstream hash. It is byte-identical to that source file.

`upstream/planar.py` and `upstream/scan_fast.py` retain the executable algorithms read from the current source, with shortened comments and formatting. They are **source-derived execution fixtures**, not byte-identical checkout files. Their local hashes intentionally differ from the upstream hashes. Their use is disclosed in the article, benchmark metadata, and integration guide. They were checked against the independent legacy engine on matching compositions and complete raw scans, including homological-degree ranks and square-zero differentials. These comparisons are finite checks, not a formal proof of transcription equivalence.

`upstream/geometry.py` is a small compatibility shim importing the retained legacy geometric definitions. The current `Planar` fixture only needs the smoothing table; the current `FastScan` fixture only needs the `ScanLimit` exception. Tests of `BitAlgebra` also exercise its geometric helpers through the shim. This file is not represented as the current upstream `geometry.py`.

The primary timing baseline is the **current-source-derived Planar/FastScan fixture**, not the older archive. The complete current repository was not downloaded and its full test suite was not run. Use `integration/check_checkout.py` and the real checkout's own test suite before integrating a production default.

## Independent older oracle

`legacy/fastunknot/diagram.py` and `legacy/fastunknot/scan.py` are byte-identical extractions of `fast/fastunknot/diagram.py` and `fast/fastunknot/scan.py` from the user's earlier `Knots.zip` archive (uploaded 18 September 2026). Only these two modules and minimal package initializers are retained. This older set-based scanning engine is an independent correctness oracle. It is not used as the timing baseline for the claimed current-engine improvement.

The JSON diagram examples were retained from that archive's `fast/examples/` directory. The large structured-block certificate is newly generated by `benchmarks/succinct_example.py`; it is algebraic and does not assert a knot verdict.

The archive's MIT No Attribution license is retained at `legacy/LICENSE`. New files and source-derived adaptations use the bundle's MIT-0 license. No third-party research paper PDFs, downloaded lecture slides, or font files are redistributed.

## Reproducible identities

`provenance.json` records actual local SHA-256 and Git blob hashes, inspected upstream blob hashes, and byte-identity checks where applicable. `checksums.sha256` at the bundle root covers the final deliverable files. The independent archive itself is not bundled.
