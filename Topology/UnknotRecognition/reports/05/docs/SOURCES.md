# Sources and roles

Checked during this task on 17 September 2026. The uploaded slide deck is not
redistributed in the archive. There are no copied third-party source-code files.

1. Marc Lackenby, **Unknot recognition in quasi-polynomial time**, February 2021,
   uploaded 109-page slide deck `quasipolynomial-talk.pdf`. Main source for the
   hierarchy program and its named subroutines. Especially pp. 24–30, 53, 59–74,
   82–91, and 101–109.

2. Marc Lackenby, **Incompressible surfaces, hierarchies and unknot recognition**,
   arXiv:2607.23350v1, 25 July 2026. Additional primary source. Definition 3.4
   supplies pattern complexity; Section 9 / Proposition 9.1 separates iteration
   counts from unbounded step costs. Section 10 is a refinement, not the complete
   quasipolynomial implementation delivered here (none is claimed).
   ```text
   https://arxiv.org/abs/2607.23350
   https://arxiv.org/html/2607.23350v1
   https://people.maths.ox.ac.uk/lackenby/algorithm-incompressible-250726.pdf
   ```

3. P. B. Kronheimer and T. S. Mrowka, **Khovanov homology is an unknot-detector**,
   Publications Mathématiques de l'IHÉS 113 (2011), 97–208,
   arXiv:1005.4346. The deep external detection theorem used by the exact
   baseline, not a running-time theorem for this implementation.
   ```text
   https://arxiv.org/abs/1005.4346
   ```

4. Mikhail Khovanov, **A categorification of the Jones polynomial**, Duke
   Mathematical Journal 101 (2000), 359–426, arXiv:math/9908171. Original
   homology construction and invariance background.
   ```text
   https://arxiv.org/abs/math/9908171
   ```

5. Dror Bar-Natan, **On Khovanov's categorification of the Jones polynomial**,
   Algebraic & Geometric Topology 2 (2002), 337–370, arXiv:math/0201043.
   Computational exposition of the cube/Frobenius-algebra construction.
   The supplied Python code is independently written; it is not Bar-Natan's code.
   ```text
   https://arxiv.org/abs/math/0201043
   ```

6. Sudipta Kolay, **Knot Colorings: Coloring and Goeritz matrices**,
   arXiv:1910.08044 (2019). Coloring-matrix determinant background for the
   polynomial rejection filter.
   ```text
   https://arxiv.org/abs/1910.08044
   ```

Computational observations, code complexity estimates, the explicit hard-unknot
braid reduction, and the finite graph/cocycle algorithms are derived in the
accompanying report. Benchmark results are generated by the included scripts,
not taken from a knot package or literature table.
