# Integration status

The observer consumes the audited state layout but is not installed into the maintained pipeline. `upstream_probe.py` is a diagnostic runner for a complete local checkout. It was not run in the delivered session.

Suggested destination inside ProveIt: a new research-report directory or optional extension under `Topology/UnknotRecognition`, preserving the article, raw results, and claims boundary together. No report number is assumed or reserved.

First validate the source hashes in `provenance.json` against the intended checkout. Add the package root to `PYTHONPATH` along with `fast/`. The observer reads `mid`, `deg`, `out`, `algebra.pairs`, and optional `owner`, `weights`, `rank_cap`; it does not modify the scan.

Use only proper prefixes with a fixed marked segment near an unprocessed root crossing. For exact weights the full lower bound is monotone under refinement. For saturated weights of cap at least two, only its cap-at-two projection has the guaranteed monotonicity property. Do not use final unmarked closed generators as individually reduced objects.

The independent signed-graph kernel can be integrated separately from the observer. Its block verifier certifies exact linear algebra. The geometry verifier checks a proposed quotient against an actual completed PD, including the raw Tait phase, but needs a supplied vertex correspondence and has quadratic matrix-comparison cost. It does not construct a useful common terminal graph automatically.

Hard time limits require a separate design: the reference observer does not interrupt an integer determinant midway. Default production behavior, recognition filters, fallbacks, and `UNKNOWN` semantics should remain unchanged until genuine upstream regressions and paired end-to-end measurements have completed.
