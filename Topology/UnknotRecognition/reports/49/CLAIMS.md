# Claim boundary

## Proved in the article

1. Selected original source exponent rows have rank equal to the number of
   verified primitive contractions.
2. The cumulative monomial columns are primitive, disjointly supported, and
   generate the full saturated integer kernel of those rows.
3. Cofactors bound their entries by `Delta_t(L)` and their bit lengths by
   `O(r (B + log(r+1)))`, throughout arbitrary valid raw phase schedules.
4. A unit-coordinate forest batch can be linearized leaf-first, preserving the
   original donor words until used, so the same theorem applies to forests.
5. Distinguishing reachable from allocated gates yields polynomial total
   allocation and raw-epoch work for the inspected existing updater mechanism.
6. Source-anchored candidate discovery, updates, and independent replay are
   polynomial in initial encoded epoch parameters.
7. A known nonzero source character sharpens cumulative exponent bounds blockwise;
   a meridional all-one character forces unit images within that raw epoch.
8. Explicit source chains require linear `r B` exponent-bit growth in general.

These are strengthening/synthesis claims relative to the inspected repository.
They are not claims of exhaustive literature priority for classical lattice,
Hadamard, primitive-word, or compressed-word results. The proofs are supplied
for review and are not proof-assistant checked.

## Implemented and executed

A standalone pair-batch kernel, independent replay, scalar length preflight,
all-relator rank-one checks, an exact linear audit, protocol adapters, 38 passing
unit tests, the completed audit, and supplied-schedule maintenance benchmarks.
The reference updater is a verbatim source-derived excerpt executed with a
standalone compatible arena. Comparisons are exact raw words, not fingerprints.

## Not supplied by this work

- A general quasi-polynomial unknot recognizer or a proof of global short search.
- Native full-pipeline integration, native whole-suite execution, Rust changes,
  whole-recognizer timing improvements, or difficult-knot experiments.
- Authorization of proper-power elimination for arbitrary source presentations.
- A new direct forest certificate API in the source-anchored implementation.
- A bound on the cost or count of arbitrary normalization, nonmonomial exposure,
  source resets, or presentation recombination outside a raw epoch.
- A completed large chained-update comparison in the 64-generator/1024-bit case.

## Essential counterexample

`<a,b | a^2 b^3>` has source row `(2,3)` and primitive kernel vector `(3,-2)`;
all linear audits can hold, but the group surjects onto nonabelian S3. The width
test rejects that relator. The lattice theorem never replaces primitive-word
verification.

## Meaning of the returned endpoint

`rank_one_zero=True` means the checked sequence of free-factor quotients reaches
one generator with every retained relator exponent zero. For exponent-one donors
these are group-preserving Tietze operations. With proper-power donors, they are
group-preserving only under independently established torsion-freeness.
Even then, this arbitrary-presentation API has not established knot provenance.
The existing source-reconstructing topological host remains necessary.
