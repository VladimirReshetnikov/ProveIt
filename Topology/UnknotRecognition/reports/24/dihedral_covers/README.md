# Binary dihedral surface covers

This exact kernel classifies a finite covering of a compact connected
surface with nonempty boundary when the sheet monodromy is generated by
maps `x -> sign*x + shift (mod W)`, with `sign` equal to `+1` or `-1`.
It uses integer arithmetic and does not enumerate the `W` sheets.

The result contains **at most three component-family records**. Each has:

- the number of components in that family;
- the degree of each component over the base surface;
- orientability, genus or crosscap number, and Euler characteristic;
- the number of boundary components;
- for every base boundary circle, the complete multiplicity/degree profile
  of its lifts;
- the product/twisted type of the canonical interval bundle with orientable
  total space over that component.

All generic components within one family are isomorphic **as covers of the
same base**, not only as abstract surfaces. The bound of three is sharp,
including for orientable base surfaces. The report section gives a full
proof and a sharp family on a genus-one surface with two boundary circles.

The result also gives the **exact** number of cover-isomorphism types in
`cover_isomorphism_type_count`. Each family has a `type_id`. When there are
two exceptional residue components, their covers are isomorphic exactly
when `m=W/d` is odd; then their distinct component records share a type ID.
Distinct residue records and query labels are retained for attachments.
Different type IDs can have the same abstract genus and boundary count:
these identifiers classify coverings over the specified base surface.

## Scope

This is a restricted covering-space algorithm. It does not extract the
covering presentation from a normal surface, certify an embedding in a
3-manifold, recognize a 3-ball or a knot, or provide a general replacement
for Agol–Hass–Thurston interval-pairing orbit counting. Arbitrary attachments
to the lifted boundary cannot be reconstructed from topology counts alone.
Finite marked queries are supported without expansion.

Every accepted input specifies a genuine surface cover: the input surface
has a canonical free fundamental-group basis, so there are no unverified
group relations. Closed surfaces are intentionally outside this schema.

## Input

An example giving all three topological types is:

```json
{
  "surface": {
    "orientable": true,
    "genus": 1,
    "boundary_components": 2
  },
  "sheets": 16,
  "monodromy": [
    {"sign": 1, "shift": 4},
    {"sign": -1, "shift": 0},
    {"sign": -1, "shift": 0}
  ]
}
```

Here the three components have:

| Covering degree | Orientable genus | Boundary circles |
|---:|---:|---:|
| 8 | 5 | 8 |
| 4 | 2 | 6 |
| 4 | 3 | 4 |

For an **orientable** genus-`g` surface with `b` boundary circles, the maps
are given in the order

`a1, b1, ..., ag, bg, c1, ..., c(b-1)`.

The first `b-1` boundary words are `cj`; the last is the inverse of
`[a1,b1] ... [ag,bg] c1 ... c(b-1)`. All generators have orientation
character zero.

For a **nonorientable** surface, `genus` means its positive number of
crosscaps. The map order is

`x1, ..., xg, c1, ..., c(b-1)`.

The last boundary word is the inverse of `x1^2 ... xg^2 c1 ... c(b-1)`.
The `xi` have orientation character one; the `cj` have character zero.
There must be at least one boundary component. The disk has zero maps.

Shifts may be negative and are reduced modulo `sheets`. Unknown fields,
wrong numbers of maps, invalid surface parameters, noninteger values,
booleans used as integers, and invalid affine signs are rejected.

## Usage

Python 3.9 or newer; standard library only.

```sh
python dihedral_cover.py examples/three_types.json
python test_dihedral_cover.py
```

```python
from dihedral_cover import classify_cover, component_key, boundary_lift_key

raw = {
    "surface": {"orientable": False, "genus": 1, "boundary_components": 1},
    "sheets": 1 << 10000,
    "monodromy": [{"sign": -1, "shift": 0}],
}
result = classify_cover(raw)
assert len(result["families"]) == 3
assert result["cover_isomorphism_type_count"] == 2
assert result["component_count"] == (1 << 9999) + 1

# No component list is expanded, even for these 2^10000 sheets.
component = component_key(result, 7)
boundary = boundary_lift_key(result, 0, 7)
```

`component_key(result, x)` labels the connected covering component
containing fibre point `x`. Its tuple has one or two residues modulo the
computed translation divisor.

`boundary_lift_key(result, j, x)` labels the lifted circle over base
boundary `j` (zero-based), specifies its covering degree, and identifies
the covering component containing it. The point `x` is expressed at the
common basepoint using the paths specified by the canonical boundary
words. Keys for distinct base boundary circles are distinguished by `j`.

The field `orientation_interval_bundle` concerns the canonical interval
bundle with orientable total space. It does not silently specify a
separate arbitrary interval-bundle twisting character.

## Algorithm

Positive affine generators and products of pairs of reflections generate
a translation subgroup `d Z/W`. Extended gcd computes `d` and retains
the orientation bit of a Bezout generator. If no reflection is present,
there is one family with `d` components. Otherwise the remaining
involution on `Z/d` is `r -> a0-r`; it has at most two fixed residues.
All other residue pairs give one family of isomorphic covers.

Orientation is decided from signed stabilizers, including relations whose
permutation action is trivial but whose orientation character is nonzero.
Boundary counts come from ordinary gcds for translations and a two-point
involution calculation for reflections. Multiplicativity of Euler
characteristic then gives genus or crosscap number.

There is no loop over the sheet count, the component count, the boundary
lift count, or the divisors of the sheet count. A conservative elementary
bound is polynomial in the number of free generators, the total boundary
word length, and the bit length of `W` and the supplied shifts.

## Independent verification

`test_results.txt` records a passing run of ten test groups. There are
**13,846 independent expanded-sheet topology comparisons**:

- every affine assignment on rank-one schemas through 40 sheets;
- every assignment on four rank-two schemas through 9 sheets;
- every assignment on five rank-three schemas through 4 sheets;
- 2,000 seeded larger schemas through 100 sheets;
- six targeted orientation and small-modulus examples.

The reference oracle constructs the lifted graph explicitly, finds its
connected components by graph search, propagates orientation parity along
lifted edges, and enumerates the boundary permutations directly. It does
not use the classifier's gcd computation, word evaluation, or canonical
schema generator. All component and boundary queries are also checked.

Further checks include 300 conjugations of the fibre labels, malformed
inputs, and exact classification of `2^10000` sheets, including exponentially
many connected components. Tests verify mathematics and representation;
they are not empirical evidence for a global unknot-recognition complexity
bound.

The generic cover-isomorphism formula is also checked directly on 156
dihedral presentations: the constructed fibre bijections commute with
every generator of monodromy.
For exceptional cover isomorphisms, 60 small presentations are checked by
enumerating every possible fibre bijection and testing equivariance with
the original generating permutations, without assuming the bijection is
a translation. Four additional cases check type counts for `W=1,2`.

## Provenance and relation to established work

The covering-space viewpoint and monodromy classification are standard.
Gross and Tucker introduced permutation voltage assignments in 1977, and
their 1979 paper already gives component-counting and orientability
algorithms. This work specializes those principles to a binary-encoded
dihedral action and provides the explicit three-family classification,
boundary profiles, marked queries, and tested code. No claim of literature
priority for the elementary group-theoretic bound is made.
