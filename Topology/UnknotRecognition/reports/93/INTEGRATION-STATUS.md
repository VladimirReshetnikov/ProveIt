# Native moment integration status (2026-10-12)

The original delivered files remain unchanged. The native moment boundary
compiler, independent checker, literal oracle and tests have been ported to
`../../fast/fastunknot/parallelity_boundary_moments.py`, its `_verify.py`
companion, and `../../fast/marked_parallelity_research/`.

`normal_cut_handlebodies(..., boundary_method='moments')` reuses its already
constructed source geometry and runs one boundary census. Whole-cut replay
independently authenticates the original source and all five orbit traces.
Earlier mask proofs remain supported; masks remain the default because the
paired complete-query measurements show instance-dependent gains and losses.
The standalone packet adapter still authenticates an external packet before
using it, and its verification budget counts upstream traces as well.

Both pair and four-field codecs, complete label inventory, exact integer
roots, local fibre data and exact original-edge gap lengths are retained.
The theory, measurements and validation are maintained in
`../../synthesis/moment_boundary.tex` and `../../synthesis/data/moment-boundary-*`.
This integration does not include the report's unused-handle or attachment
kernel proposals, which require separate review. It does not establish a
uniform trace bound, useful-surface discovery or general quasi-polynomial
unknot recognition.

Before porting, all nine delivered moment tests passed against the current
runtime from an isolated copy in 159.509 seconds. The native nine tests pass
in 164.451 seconds; five whole-cut integration tests pass in 6.662 seconds.
The delivered report's source tests and binary metrics were written only to
the isolated copy, and are retained separately with the native evidence.

The full maintained suite subsequently passes all 1,710 tests in 735.091
seconds, without skips. The 120-source differential audit preserves all
102 complete censuses, replays both backends, preserves all 92 historical
mask-certificate hashes, and agrees with 95 retained literal references.
The delivered files have not been changed by these integration checks.
