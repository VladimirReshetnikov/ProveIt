## Claims deliberately not made

There is no unconditional general quasi-polynomial recognizer, new universal width theorem, complete disk-language producer, normal-surface exporter, native runtime improvement, complete rooted-component transfer algebra, counting algorithm, or proof-assistant certificate. No worldwide priority is asserted for an equivalent diagram-algebra identification.

## Main dependency chain

Separated intervals → defect monotonicity → whole-disk cap predicate → exterior rank → cap-radical congruence → splitting/matrix theorem and weighted contextual replacement → exact binary grammar → bit bound and compressed optimum → geometric conditional bridge.

Free-star pumping is a separate branch. It is not a justification for modifying the physical length of a source region.
