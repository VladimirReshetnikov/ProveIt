# Integration contract

## Additive intake, not a production patch

The package is designed for the next report under `Topology/UnknotRecognition/reports/<NN>/`, with `NN` assigned by the owner under the current `docs/incoming/README.md`. Preserve the complete delivered article, software and evidence. No branch, pull request, dispatcher change or automatic test execution is requested by the package itself. No standalone checksum manifest is included.

## Supported search interface

A source grammar is topologically ordered, uniformly `b -> b`, and built from explicit atom lists, identity, ordered concatenation, equal-span union and literal nonnegative powers. Costs are scalar signed integers at fixed length. Charges form an explicitly sized XOR group. Every component of an atomic surface must be a disk meeting an external port.

A geometric type must make **every external legal substitution identical** for candidates reduced together. The checker does not infer such a type from a bare partition. Cyclic ordering, collars, source location, quadrilateral compatibility and boundary ownership may all need to be included. The number of types and the cost of testing them must enter any claimed runtime.

`power(X,W)` allows independent choices from X in each of W occurrences. It does not allow deleting occurrences, relabelling their ambient region, or inventing a new repeatability chart.

## Native adapter obligations

Before producing a native positive result, implement and independently validate all of:

1. Source binding to the maintained validated diagram/exterior construction.
2. A repeated-region chart or finite-grammar source certificate with complete legal local options.
3. Actual separated proper interval attachments, including their multiplicities and all boundary destinations.
4. Embeddedness, matching collars and global compatibility of every permitted substitution.
5. Chain-level generation of boundary charges from authenticated torus cocycles, with seam cancellation and position-dependent corrections where applicable.
6. A source-bound exporter or a compressed embedding verifier for the selected witness DAG.

For a negative native answer, additionally prove language completeness for the relevant disk class. A small explicitly listed language that misses some disks cannot certify knottedness.

## Output interpretation

- `FOUND_ABSTRACT_DISK`: the selected grammar word and cap are one abstract disk, with the requested formal module charge. Native soundness still requires the adapter contracts.
- `NO_DISK_IN_GRAMMAR`: no successful word in this particular complete finite grammar. It says nothing about omitted geometric alternatives.
- `UNKNOWN_RESOURCE_LIMIT`: a guard prevented completion. Never reinterpret as a negative answer.
- `VALID_ABSTRACT_RUN`: the independent mathematical kernels checked source-reconstructing weighted pruning. This is not a source-embedding theorem.

The query routine accepts module charge sectors. A cap with charge h requires shifting a total target eta to module sector eta XOR h. Its constant cost is added externally.

## Good first integration experiment

Use one authenticated repeated region whose templates, boundary collars and local option completeness can be proved independently. Export its grammar, run both an explicit-layer baseline and the powered backend to completion, reconstruct the selected source witness, and independently verify its embedding and boundary. Retain the full source instance, both optima, all timings and negative controls. Do not begin by routing every normal-surface query through this restricted backend.

## Dispatch and limits

Powering stores a two-sided 2b-port interface, whereas a fixed-prefix scan may use only b ports. The delivered corpus shows large short-span regressions. A native dispatcher should retain a narrow explicit scan for short or highly constrained regions and use powering for sufficiently long repeated blocks, with work estimates and fallback outcomes recorded.

Free-star pumping is a different operation. It may optimize a language where length is unconstrained; it cannot justify shortening a fixed source region. Rooted disk-component search also requires a different state and sealing policy.
