\section{Artifact map and reproduction}
\label{sec:artifacts}

The package is additive. It can be placed under a new research directory
without overwriting maintained modules. The suggested location is
\path{Topology/UnknotRecognition/research/compiled_port_quotients/}.
The root README gives the exact commands and integration caveats.

\begin{longtable}{@{}p{0.37\linewidth}p{0.58\linewidth}@{}}

From the package root:
\begin{lstlisting}
python -m unittest discover -s tests -v
python experiments/audit.py
python experiments/benchmark.py
python experiments/make_tables.py
python examples/demo.py
sh paper/build.sh
\end{lstlisting}
The first five commands use only Python's standard library. The build
requires a standard LaTeX installation with the packages listed in
\path{paper/main.tex}. Benchmark medians will naturally vary with the host;
the exact results and trial counts must not.

For the native gate, supply the maintained \texttt{fast} directory:
\begin{lstlisting}
python integration/native_gate.py \
  --fast-root /path/to/ProveIt/Topology/UnknotRecognition/fast
\end{lstlisting}
A missing native module is a gate error, not a fallback to the literal
oracle. The full maintained suite should then be run from that checkout.
The gate writes a separate result file, leaving the delivered historical
\texttt{NOT\_RUN} status as a record of this article's execution scope.

\section{Minimal usage example}

The following example is deliberately an abstract census. Its mass equations
are valid, but no source-bound knot or normal-surface claim is implied.
\begin{lstlisting}[language=Python]
from compiled_ports import Profiles, ConeProgram
from compiled_ports.verify import verify_threshold

q = 1 << 256
profiles = Profiles.from_histogram((q,) * 8, {(1,) * 8: q})
nodes = [
    {"op": "cone", "atoms": []},
    {"op": "power", "child": 0, "exponent": 1 << 4096},
    {"op": "cone", "atoms": [3]},
    {"op": "concat", "left": 1, "right": 2},
    {"op": "power", "child": 3, "exponent": 1 << 4096},
]
program = ConeProgram(8, nodes)
answer = program.first_at_most(profiles, 1)
assert answer["index"] == (1 << 4096) + 1
assert answer["trials"] == 2
assert verify_threshold(profiles, nodes, program.root, 1,
                        answer["index"])
\end{lstlisting}

To obtain a trusted table from an actual native relation, use
\texttt{compile\_profiles(..., record\_certificate=True)} and then
\texttt{verify\_native\_certificate} against the original pairings and cuts.
Only the returned authenticated table should enter a source-bound downstream
claim. That path is supplied but awaits the native gate described above.
