# Optional upstream integration (not executed here)

`probe.py` is an additive adapter for the inspected `fastunknot` Diagram API.
It is not wired into the maintained recognizer. `upstream_smoke.py` has not
been run against a local checkout in this environment.

Keep existing cheap certificates, free/cyclic reduction, singleton Markov
descent, and specialized rank-two preprocessing ahead of an expensive global
probe. A successful proposal comes from the original checked `braid_source`,
is independently replayed, and must improve on the *current simplified*
diagram's crossing count. It is not enough to beat only the original word.

Restart recognition under the remaining global budget, with this probe
disabled to prevent recursion. Keep earlier PD simplifications and the new
source-braid route in distinct evidence branches. Do not concatenate a cyclic
braid certificate with a PD Reidemeister trace as though they were one trace.

Local operation/dictionary/allocation exhaustion skips the probe. An invalid
certificate is a programming error, not evidence for either verdict. The
adapter's operation allowance is cooperative, not a hard time/memory limit.
The host remains responsible for deadlines and process-level resource limits.

To run the limited Diagram/provenance smoke test after obtaining a checkout:

```sh
python integration/upstream_smoke.py --upstream /path/to/UnknotRecognition/fast
```

This checks only conversion and proposal provenance. It does not run the
complete recognizer or its full regression suite. Required next validation:
full normalized-homology comparisons on small knots, all maintained tests,
resource and restart regressions, and paired whole-recognizer measurements
with unchanged early certificates and A/A controls. No production default
change is justified by the isolated kernel timings alone.
