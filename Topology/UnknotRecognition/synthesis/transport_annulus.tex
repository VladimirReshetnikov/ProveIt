\section{Primitive annulus caps on transported sources}
\label{sec:transport-annulus}

The preceding epoch adapter recognizes a positive essential normal-disc
component. It can nevertheless continue costly descent from a source already
carrying a certifiable primitive annulus. The existing native capping theorem
provides a different witness. This continuation authenticates that theorem
on a replayed moved source and exposes an explicit terminal annulus option.
It preserves all source, connectivity, primitivity and arithmetic requirements;
Euler characteristic zero alone never supplies a knot verdict.

\subsection{Negative pilots identify the useful scope}

Radius-one type-window queries at selected smaller endpoints find no extra
disc on the sampled controls and consume allowance otherwise used for
descent. Radius-two queries likewise find no witness while costing more.
Repeated boundary shelling removes additional tetrahedra but supplies no new
hard-control success and does not improve the target's checkpoint total.
The edge-first/span-second gauge pilot also gives no new witness and raises
work on the demonstrated target. These experiments are retained as finite
negative observations, not promoted into new runtime defaults.

The useful distinction is instead topological witness type. The initial
optimized-positive source has Euler zero and a independently checked
minimum-span primitive connected fibre. Its annulus already admits the
existing capping argument, while disc-only epoch search consumes its budget
seeking a normal disc. The source query therefore needs an authenticated
annulus terminal rather than a larger unproved disc-search family.

\subsection{The capping theorem and its source hypotheses}

\begin{proposition}[Primitive annulus cap after source replay]
Let $M$ be a compact knot exterior authenticated from the input diagram and
source-replayed relative-boundary replacements. A connected orientable
properly embedded primitive relative-class surface with Euler zero is an
annulus. Exactly one of its boundary circles is inessential on $\partial M$.
Capping that circle on the boundary torus and rounding inward gives an
embedded compressing disc. Thus this authenticated surface proves that the
input knot is the unknot.
\end{proposition}
\begin{proof}
A connected orientable Euler-zero surface is either an annulus or a closed
torus. A knot exterior has $H_2(M)=0$, so a closed torus cannot represent
the nonzero primitive relative class. The boundary of that relative
class generates the primitive kernel of
$H_1(\partial M)\to H_1(M)$; in particular it is neither zero nor twice
an integral class. Two disjoint essential simple circles on a torus are
parallel and their signed sum is zero or twice a primitive slope. Two
inessential circles have zero sum. Hence the annulus has one essential
and one inessential boundary circle. The latter bounds a disk in the
torus disjoint from the essential circle. A boundary collar permits the
cap to be rounded into $M$ without intersecting the annulus. The remaining
boundary is essential, giving a compressing disk. Boundary compressibility
of an authenticated knot exterior yields unknotness. This is the existing
primitive capping theorem applied after the verified source replacements,
not a new literature-priority claim.
\end{proof}

The implementation obtains connectedness and orientability through the
retained coherent-surface minimum-span theorem, with an independently
verified arithmetic dual witness. Integral primitivity is checked on actual
signed source edges after a separate tree gauge. It is not the gcd of
ungauged heights and not an assertion from the optimizer. A valid doubled
minimum-span certificate still fails this primitive period check; the new
regression test exhibits that distinction explicitly.

\subsection{Bind a terminal surface to the original moved source}

The new \code{diagram-transport-annulus-v1} proof contains the original PD,
original exterior, optional initial shellings, initial cochain, the complete
actual move/gauge chain and a terminal surface certificate. Source replay
is shared privately with the existing disc checker: every geometry and
cochain transport is authenticated, and the computed final triangulation is
owned by that verification call. No public caller-supplied source cache is
accepted.

The terminal \code{diagram-cocycle-annulus-v1} data contain that final
triangulation, reference integral heights, actual normal coordinates and a
minimum-span certificate. A closed source predicate binds it to the exact
triangulation computed by replay. The existing independent cocycle inspector
checks the original input identity, matching geometry, global edge values,
primitive period class and the minimum-span primal/dual equality. Only
then are its connected surface summary and Euler value used. The required
value is exactly zero.

The final annulus is authenticated on the moved source, not asserted to be
the unchanged fibre of every earlier cochain. Its reference heights and
minimum-span proof are independently checked on that source. Source rank
one and the capping theorem come from the replayed knot exterior. A different
source, a missing geometric move, changed gauge data, forged coordinates,
invalid dual equality or nonprimitive class cannot substitute for these
hypotheses. No normal-coordinate vector for the capped disk is invented.

Move-only and mixed move/gauge disc proofs retain their v1/v2 schemas and
full final-component authority. The new annulus format is explicitly
different, and the disc checker rejects it. The annulus checker imports no
source constructor, optimizer, move producer, epoch planner or normal
component search.

\subsection{A cheap terminal check inside the bounded epoch policy}

The optional epoch mode exposes \code{annulus\_caps}. Zero/default false
preserves the preceding behavior. At the initial span optimum and every
current-source gauge optimum, the adapter retains the minimum-span witness
and its reference heights. A geometric move invalidates that witness until
another optimum is available. If a retained witness has Euler zero, the
full original-source annulus verifier runs before more geometric branching.
Only its completed positive replay returns \code{UNKNOT} with method
\code{native-pachner-annulus}. Other Euler values continue ordinary disc
queries and strict descent.

The source preparation, Euler observation, primitive/connectivity replay
and all arithmetic checks use the existing shared work allowance. The
initial geometric-node allowance is still required; a work or node cap
never becomes a capping certificate. A miss or capped query continues the
complete recognizer, while the global deadline remains global.
The recognizer and CLI require explicit epoch mode for
\code{pachner\_seed\_annulus=True} or \code{--pachner-seed-annulus}.
No optional geometric policy becomes a default.

This adds a verified terminal witness type to the actual source search.
It gives no theorem that every unknot reaches a primitive annulus or disc
within small upward/epoch/support bounds. It does not classify a stationary
source as knotted or eliminate the hierarchy's missing global obligations.
