\section{Linear static contraction of weighted interval runs}
\label{sec:weighted-sweep}

The binary normal-surface operators depend on weighted interval-orbit
transport. Its static contraction step removes intervals of points that
have become singleton orbits, accumulates their weights in the histogram,
and closes the deleted gaps. The preceding implementation formed a set
of every run and gap endpoint and sorted that set at every contraction.
Both input families are already ordered. The maintained implementation
now merges them directly without collecting or sorting their boundaries.

\begin{proposition}[Exact linear boundary sweep]
For a canonical covering of $[0,N)$ by $R$ constant-weight runs and $G$
ordered disjoint inclusive static gaps, contraction requires $O(R+G)$
boundary steps and $O(R)$ output records. It emits exactly the old histogram
increments, canonical surviving runs and emission counter, sharing surviving
weight tuples. No represented point is enumerated.
\end{proposition}
\begin{proof}
Maintain the current run position, the first gap whose right endpoint has
not been passed, and the number $d$ of already deleted points. The next
piece ends at the run boundary, at the next gap's left boundary if outside
it, or just after that gap's right boundary if inside it. A deleted piece
of length $\ell$ adds $\ell$ singleton orbits of its unchanged weight and
increases $d$ by $\ell$. A surviving piece $[a,b)$ is sent to
$[a-d,b-d)$ with the same weight. Each step passes a run boundary or one
gap boundary; each gap pointer advances once. These are precisely the
pieces induced by the former sorted boundary set. The same adjacent-equal
coalescing restores the same canonical result and the same emission count.
Removing gaps from one run cannot increase its number of surviving weight
changes, so at most $R$ output runs remain.
\end{proof}

The bound is on boundary processing, not unit-cost manipulation of arbitrary
integers or weight vectors. Endpoint arithmetic charges their binary lengths;
histogram hashing, integer addition and adjacent-vector comparisons charge
the vector dimension and coefficient sizes. Thus the former
$O((R+G)\log(R+G+1))$ endpoint-sort work becomes linear while the existing
weighted arithmetic and independent replay accounting remain in force.
The independent checker retains its separate implementation. Certificate
schemas and histogram semantics are unchanged, and cooperative cancellation
is polled at every processed piece.

Literal signed-vector deletion tests include 2,000 seeded finite systems,
complete deletion, no deletion, coincident boundaries and separated runs
coalescing after contraction. A 16,385-bit endpoint case checks binary
processing without expansion; complete weighted-orbit tests use the existing
pointwise oracle and independent checker. This is an improvement to a
compressed hierarchy prerequisite. It does not supply core topology,
ordered attachments or a bound on hierarchy depth, and it does not establish
a general quasi-polynomial unknot recognition algorithm.
