\subsection{Native validation and measured scope}

The native \code{power\_components.py} research driver pins predecessor
\code{8be43faf3e73} and 453 current source/fixture hashes, checked before and
after each run. It loads the predecessor separately and records every proof,
source diagram, status and work count. The existing pair-only focused tests
continue to pass after factoring their row extraction. All 1,142 maintained
tests pass in 214.775 seconds.

Four hundred random connected signed graphs compare native discovery with
an independent rational Gaussian-rank calculation. Valid witnesses also pass
literal and compressed checking and retain unrelated raw words and empty
slots exactly. Tests reject balanced cycles, disconnected witnesses, arbitrary
words having misleading exponent sums, unknown fields, Boolean or duplicate
indices, foreign labels and attempts to erase every live generator. Other
cases check binary input, producer-disabled replay, version downgrades,
source rebinding, cancellation, work exhaustion and node exhaustion without
publishing partial roots or labels.

The first node-limit fixture used the word $t x t$ as an unrelated retained
word. Its cyclic spelling is itself a two-run power row, so it joined the
free label to the annihilating component and correctly made that proposed
whole-component deletion ineligible. Replacing it by a three-label retained
word tests the intended interrupted export. The initial failed fixture log
is retained; the final focused and full runs pass.

The ordinary source audit covers 85 diagrams in default, projection and forest
modes, with no work-limit failures. Complete certificates and positive coverage
are identical to the predecessor. No component detector activates on these
ordinary search states. This is consistent with the meridional obstruction:
original meridians have nonzero abelianization charge, while a generator proved
trivial must have charge zero. Changes of generators are needed to expose
eligible targets.

Three additional source fixtures use the closures of the five-, nine- and
seventeen-strand stabilized circles. Supplied Whitehead automorphisms send each
nonbase generator to a conjugated difference from the base meridian. After
checked cyclic normalization, the relators are a pure seed, a chain of
adjacent differences and a redundant final pure relator. A direct call to the
native component planner yields one component witness. Both full source
replayers accept, for a total of 654 source replays across the audit. The
predecessor rejects the unsupported version-ten format. These fixtures prove
source-bound integration; ordinary search can use its higher-priority primitive
or pair rules on the same states, and no newly discovered exposure is claimed.
A separate algebraic audit deletes two disjoint product-difference-one cycles
in one batch and checks both replayers. The final audit takes 6.436 seconds;
it overlaps the suite and is not a timing comparison.

The four binary cycle fixtures have $(n,b)=(3,64),(8,64),(16,128),(32,128)$.
The predecessor's configured algebraic search returns unsuccessful on each;
the new search succeeds with exactly one component move. Each complete new
trace independently replays against a fresh source grammar. At $(32,128)$,
production uses 146,211 work units and 8,622 ordinary nodes, with no allocation
increase during deletion. The baseline's unsuccessful work count is recorded
but is not interpreted as a speedup denominator.
