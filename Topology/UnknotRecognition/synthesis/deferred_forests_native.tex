\subsection{Native deferred discovery for cores and complete interfaces}
\label{marked-cut:deferred-native}

The preceding review now has a maintained producer integration. The core
and whole-boundary kernel accept \path{defer_forest=True}. The whole-cut API
accepts \path{lower_forest='deferred'} and adds this method after its two
existing fixed-forest attempts in the adaptive policy. All independent
checkers and certificate formats remain unchanged. The improvement is
exact elimination of lower-forest enumeration within the fixed raw model,
together with an additional independently certified whole cut. It does
not provide a general recognition complexity bound.

\paragraph{Discovery and execution are different orders.}
The core producer first forms occurrence rows on \emph{all} original
one-handles and applies the static column-leaf queue. If a row remains,
the result is \path{all_lower_forests_raw_obstruction}: the greatest
stopping set is an obstruction for every lower forest on these rows.
The result remains \path{INCONCLUSIVE}; it is not a negative manifold
certificate. Otherwise let $P$ be the pivot columns. Scan source edges in
identifier order, accepting an edge outside $P$ precisely when it joins
distinct current components. Union by size with path compression controls
the work, and a separate least-identifier field gives the historical
component labels. Finally check that every original source edge has
endpoints in the same resulting component. A malformed source incidence
model that lets pivots disconnect the graph raises an error instead of
emitting a false forest certificate.

The bridge argument of the preceding section proves that this spanning
check succeeds on authenticated cycle rows. The resulting ordinary core
v2 proof records the forest, column schedule and remaining genera. The
independent core checker reconstructs the actual alternating zero/one
attaching cycles, validates the forest, and checks the cancellation trace
on the matrix \emph{after} forest contraction. It needs neither the new
discovery algorithm nor a certificate of its optimality.

\paragraph{Why the complete interface must precede the choice.}
The bundle kernel computes the original source component labels but
initially retains every source one-handle column. It reconstructs the
actual attaching circles and adds their raw rows and dedicated base
columns. Only after this complete finite matrix exists does it peel and
choose the source forest avoiding its pivots. Auxiliary base columns may
be pivots but are not source forest edges. Component labels agree with
the original component partition. Forest columns are then removed from
the finite genus count. Connecting-handle forest selection, implicit
inert genus columns and the source Euler identity retain their existing
meaning and checks.

The emitted kernel proof uses the already implemented v3 supplied-forest
schema. The checker reconstructs all rows from source charts, verifies
that forest, and applies the existing independent column timestamp
checker. No new trusted count, parity assertion or optimality flag is
introduced. The completeness theorem applies when the fixed kernel's
geometric admission conditions and omitted-column lifting hypotheses
hold. It does not turn every conservative return elsewhere in the
whole-cut wrapper into a universal obstruction.

Disk-bundle absorption has the same dependency. Adding its two-handle
rows can destroy a previous core-only column leaf. Deferred mode therefore
recomputes discovery on the augmented core whenever absorption adds rows.
Core-side annular transport consumes that resulting certificate and its
actual selected forest. If the complete boundary kernel is needed, it
makes its own choice from the full kernel matrix. These are separately
verified sufficient constructions of the same cut; a core-only forest is
not substituted for the full-interface choice.

\paragraph{Interaction with top reduction and early refusal.}
Deferred discovery follows the selected relative two/three reduction.
For its attempt, the maximum-weight top selector is priced against the
historical source lower forest; it is fixed before deferred selection.
The maximum-weight theorem still concerns that stated additive objective,
not the lower forest eventually discovered. The new completeness theorem
ranges over lower forests for these \emph{retained} rows only. It does not
optimize upper and lower forests jointly.

The optional source precheck may use full-matrix deferred peeling. A
source stopping set then persists after adding annular rows and dedicated
bundle columns: the new columns vanish on the original source rows and
cannot supply a unit on the stopping set. It is therefore safe to skip
boundary discovery on this universal raw obstruction for the selected top
reduction. A successful source precheck is only necessary for this path;
the augmented and full-interface problems still need their own checks.

The adaptive policy first returns any earlier source or maximum-passage
success unchanged. If their forests coincide, it skips only the duplicate
fixed attempt and still tries deferred discovery. Source parallelity and
lazy boundary discovery remain invocation-local cached packets. The third
attempt does not rerun orbit queries or reset their cycle allowance.
A boundary-budget refusal returns immediately, and callback exceptions
propagate through discovery, union operations and certificate construction.
Thus the default performs at most three finite attempts, with one set of
four source queries and its selected one- or two-query boundary backend.

\paragraph{Local complexity and the remaining gap.}
For a supplied matrix with $R$ rows and $P$ nonzero incidences, the static
peeling stage costs $O(R+P)$ indexed operations and stores $O(R+P)$ records.
For $V$ source zero-handles and $E$ source one-handles, forest discovery
costs $O((V+E)\alpha(V+E))$ disjoint-set operations and $O(V+E)$ storage.
Auxiliary pivot identifiers cannot delete source edges. These bounds
concern discovery after the finite matrix has been constructed; they do
not hide source reconstruction, annular tracing, component census or
independent replay. For example, existing component assembly may rescan
finite handles by component, and the source geometry has its own cost.
All integer and index bit lengths remain part of a full bit-complexity
account. No normal sheet multiplicity is expanded by the new selector.

Unlike testing a bounded collection of heuristically selected forests,
this pass decides whether \emph{any} lower forest permits full raw
cancellation for the admitted fixed matrix. It replaces the potentially
exponential forest space by a polynomial local construction. The raw
model is itself incomplete for arbitrary handlebodies; the top-tree
choice, geometric successor transport, useful-surface discovery, native
orbit-trace bounds, hierarchy size and restart accounting remain separate
requirements for quasi-polynomial unknot recognition.
