The principal integration here is report 57's exact candidate discovery in
a supplied compatible quadrilateral sector. Earlier observers test a normal
vector already in hand. This module instead enumerates every non-link

Q-ray phase when its positive-Euler criterion suffices. The implementation

\path{fastunknot/normal_sector_verify.py}. It uses the existing independently
checked essential-disc counts on the resulting candidates. Its public API
asserts properties of the supplied triangulation and sector; diagram-bound
recognition needs the established exterior provenance in addition.

\subsection{What each delivery adds, and what its native gate establishes}

Report 54 compiles the complete component profile on fixed source atoms.
It packs atom counts into a carry-free scalar weight, preserving capacity
bounds, and computes full-port cones from the resulting multiplicity-aware
incidence graph. A touched type with multiplicity $h$ contributes $h$ times
its profile to the merged component, rather than a single copy. If $a$ atoms
are active and they occupy $b$ active blocks, the potential $2a-b$ increases
on each effective cone and has maximum $2m-1$ for $m$ fixed atoms. This bounds
the number of partition-changing instructions independently of their binary
repetition counts. The sharp example first cones $m$ two-point atoms
separately, then joins them in $m-1$ further steps. Compressed threshold
descent can use at most $g+1$ state trials for a grammar with $g$ nodes.
These results require full-port coning and fixed atoms; they do not represent
specified pointwise attachment bijections or refinement of the source atoms.
The fresh native gate passes 402 packed/vector comparisons and source-bound
replays, rejecting 400 source mutations. All 25 standalone tests pass.

Report 55 compiles a complete orbit trace into a nonnegative integer linear
transfer circuit. Scalar observations select an emission, and one transposed
evaluation recovers its source profile. Interval prefix sums then recover
normal coordinates without transporting every component's dense coordinate
vector. All 24 standalone tests pass. A fresh current-tree adapter audit
checks 64 supplied normal vectors: 12 positive disc extractions and 52
complete supplied-vector negatives, agreeing with the existing coordinate
census. Its positive checker establishes an admissible connected essential
disc $y\le x$. It does not independently establish that $y$ is a component
of $x$; a hierarchy consumer requiring that stronger statement must retain
the transfer theorem or a stronger certificate. Source provenance and
arbitrary cut/glue attachment data remain separate.

Report 56 proves that a frozen raw singleton elimination epoch can be
discovered by original-source Horn closure. Rules use exact-once raw
occurrence, not exponent sum. The theorem includes all raw elimination
orders but excludes intervening free reduction, root extraction and other
normalization. Its separate orbit index compiles canonical minima and
rank/select queries from a completed trace. A current-tree additive scratch
overlay runs these modules and report 58's observers together: 60 test

option overlay remains separate from the current dispatcher; these tests
do not validate its whole-recognizer hook or normalization search.

Report 58 reconstructs the joint component spectrum of Euler characteristic,
actual boundary-circle count and orientability from a boundary transversal

two parts. At $v=0$, use $A(0)=2H(0)-K(0)$ and $O(0)=K(0)-H(0)$; treating

The fresh scratch-overlay Regina audit passes 1,395 API comparisons and

\subsection{A reflection compatibility defect found at intake}

The new interval reflection event postdates these deliveries. Their minima
and transversal compilers must not inherit acceptance of a larger proof
language without implementing its transformations. On the three-point
relation $0\sim1$, the actual least representatives are $\{0,2\}$. The
current interval checker correctly accepts a reverse-sweep proof. Report
58's delivered transversal checker then ignores its reflection when lifting
selected sets and accepts the false set $\{0,1\}$, which contains two points
from one orbit and none from the other. The cardinality is still two, so a
count-only check cannot detect this error.

The retained counterexample includes the complete valid orbit proof and
the incorrect accepted transversal certificate. Report 56's index compiler
rejects the same valid proof with an unknown-event error. These are different
failure modes caused by the same vocabulary extension. Report 58 was written
against versions one and two, where its monotone survivor-label argument
applies. The fresh forward tests do not justify its checker on reflected
traces. Before promotion, the observer needs an explicit supported-version
guard or a correctly proved reflection-aware selector. Simply preserving
survivor points under reflection would select maxima in the original order,
so obtaining canonical minima requires more than reversing endpoint formulas.
The sector modules use the established weighted-disc path and are not affected
by this delivered transversal checker.

\subsection{An exact cone kernel for a supplied sector}

Let $t$ be the tetrahedron count and allow one quadrilateral type in each
of $k$ selected tetrahedra. At each glued face corner, matching has form
\[
 T_d-T_c=b_e(q),
\]
where $b_e$ involves at most two allowed quadrilateral coordinates. Construct
the triangle difference graph and contract every edge with identically zero
restricted label. This imposes precisely triangle equality, so it preserves
real solutions and the integral lattice. Each allowed quadrilateral meets
four faces, so at most $4k$ nonzero-label equations remain. Retain their
loops: a loop may constrain $q$ even though its triangle difference vanishes.

At a global vertex with only one contracted class, its triangle value is
an independent nonnegative vertex-link factor. At a vertex with $p_v\ge2$
classes and $m_v$ retained edges, connectivity gives $p_v-1\le m_v$ and
$p_v\le2m_v$. Hence at most $8k$ triangle-class variables and $k$
quadrilateral variables remain, with at most $4k$ equations. Copying each
class value to its original corners and restoring the independent link
factors gives mutually inverse nonnegative integer-linear maps. Primitive
and extreme rays are preserved. This is an algebraic search kernel; the
original triangulation and expansion map are still required for geometry.

Write the reduced matrix as $[B\mid D]$, where $B$ is a graph incidence
block. Every square minor of $B$ is zero or a unit: expand on a row with
at most one nonzero entry, or observe that when every row contains both
opposite entries, the all-ones vector is in the kernel. Each quadrilateral
column of $D$ has absolute column sum at most four. Successive determinant
expansion on the chosen $D$ columns therefore bounds a mixed minor by the
product of their column sums. An extreme ray on its positive coordinate
support has a one-dimensional kernel and is given by maximal cofactors,
followed by gcd division. If its actual quadrilateral support has size $a$,
every triangle coordinate is at most $4^a$, and each positive quadrilateral
coordinate is at most $4^{a-1}$. Omitted zero columns give independent
coordinate axes and satisfy the same bound. Expansion merely repeats
triangle values, so the bounds hold in the original coordinates.

\subsection{Canonical lifting and adaptive complete enumeration}

Integrating the difference labels along spanning trees gives integer
potentials $\ell_c(q)$. Non-tree edges give the remaining cycle constraints
$R_Sq=0$. The quadrilateral cone is $q\ge0$ in $E=\ker R_S$, with nullity
$d$. Its canonical lift subtracts $\min_{c\text{ at }v}\ell_c(q)$ at each
global vertex. It has no vertex-link summand; every other nonnegative lift
adds such summands. A lifted Q-extreme ray is standard extreme, because any
standard decomposition projects to multiples of its Q-ray and the zero
triangle at each vertex forces the link summands to vanish. These canonical
conversion facts are part of classical Q-theory~\cite{burton-convert}.

Canonical Euler characteristic is positively homogeneous and subadditive:
its linear part is corrected by subtracting each positive vertex-link Euler
value times a minimum of linear forms. A positive value somewhere in the
quadrilateral cone therefore implies a positive value on some Q-extreme ray.
This justifies the preliminary Q-ray screen for positive canonical Euler.
An inessential disc, sphere or projective plane may also have positive
Euler characteristic. Each positive candidate still undergoes the existing
compressed essential-disc count and independent replay.

Complete standard enumeration has two routes. The support route tests every
positive variable support of size at most $\operatorname{rank}(M_S)+1$,
retaining precisely one-dimensional strictly positive kernels. It uses
at most $2^{9k}$ exact linear systems. The arrangement route adds coordinate
hyperplanes and all within-vertex ties $\ell_c(q)=\ell_{c'}(q)$ in $E$.
There are at most $32k^2$ distinct nonzero hyperplanes. On each closed
chamber the canonical lift is linear. A standard extreme ray must project
to an extreme chamber ray, otherwise a nonproportional chamber decomposition
would lift to a standard decomposition. Thus it is found among intersections
of $d-1$ independent hyperplanes. Some ties concern nonminimal potentials,
so candidates must still pass the exact standard-extremality rank test.

The dispatcher compares the actual support-subset count against
$\binom H{d-1}$ and chooses the smaller. Complete sector search has bound
\[
 \operatorname{poly}(t,k)\min\{2^{9k},\binom H{d-1}\}.
\]
It uses exact rational arithmetic and binary coordinates. This is an
adaptive selection between complete enumerators with explicit search-count
bounds, rather than a prediction from elapsed progress. Dense support can
be easy when nullity is one.

The independent exhaustion checker constructs the original dense matching
matrix, eliminates triangle variables with separate arithmetic code,
reconstructs the full ray set and compares the transcript, Euler values
and negative disc proofs. It imports no sector producer helpers. Negative
replay repeats an enumeration and is not claimed polynomial in a short
negative transcript's length. The implemented basis allowance counts failed
linear systems too. The orbit allowance is per positive candidate; Q and
standard phases each receive their named per-sector allowance. Cancellation
can impose a shared external limit. Incomplete discovery returns no absence
claim. Successful exhaustion excludes only the advertised sector or support
range, rather than all normal surfaces in the manifold.

\subsection{Why support alone cannot give the general target}

Searching all supports up to $K$ costs
\[
 \operatorname{poly}(t,K)\left(1+\sum_{j=1}^{\min(K,t)}
                 \binom tj3^j2^{9j}\right).
\]
This is $t^{O(\log t)}$ for $K=O(\log t)$ under the promise that an essential
standard vertex disc exists with that support. It gives no universal
small-support promise. In the Fibonacci layered solid tori, an essential
meridian meets a selected boundary edge at least $F_{t+3}$ times. A primitive
standard vertex disc with support $a$ has edge weight at most $3\cdot4^a$
by the height bound. Thus $a\ge(\log_2 F_{t+3}-\log_2 3)/2=\Omega(t)$.
The delivery extends the same conclusion to fundamental meridians using
the corresponding $a4^a$ bound. This is a representation obstruction on
these triangulations, not a lower bound for unknot recognition.

Their supplied dense meridian sector has nullity one. Its Fibonacci
recurrence determines the canonical triangles and quadrilaterals from a
single parameter, so the arrangement route tries one system. The real
outer task is therefore to discover useful low-complexity sectors or change
the geometry under an encoded-volume bound. Neither dense-support examples
nor polynomial supplied-vector observers settle that task.

both phases, comparing 2,361 Q-rays and 3,249 standard rays with no caps
or mismatches. A separate 481-sector audit verifies 962 certificates with
producer functions disabled: 134 positives, 694 negative positive-Euler
results, 67 positive-Euler-only results and 67 standard-sector negatives.
It rejects 60 mutations and checks resource and callback behavior. Eight
maintained integration tests cover methods, positivity traps, source binding,
restricted exhaustion, cancellation and immutable inputs.
