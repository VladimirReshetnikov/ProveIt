\section{Memoized frontiers for exact word inversion and reduction}
\label{sec:word-cache-frontier}

The compressed word engine already caches exact inverses and freely reduced
words. Its earlier traversal nevertheless collected every reachable source
node before consulting these caches during evaluation. Repeated queries on
slightly extended words could therefore revisit a large cached subgrammar.
The new traversal stops at known results. It changes neither the equations
for inversion and free reduction nor the independently implemented group
certificate moves, and applies to both search and compressed replay.

\subsection{A cached node is a complete boundary condition}

Let an immutable binary word grammar have terminals and concatenation rules
$X=YZ$, with children allocated before their parent. For one operation let
$K(X)$ store its exact completed result: either $X^{-1}$ or the freely reduced
word represented by $X$. Starting from a queried root, visit only nodes absent
from $K$. Stop at each cached child, and deduplicate uncached nodes encountered
along different paths. Sort the collected nodes by allocation identifier and
then evaluate them in that order.

For inversion the rule is
\[
 K(X)=K(Z)K(Y),\qquad K(a)=a^{-1}.
\]
The concatenation is raw; inversion itself performs no cancellation. For free
reduction, terminals are already reduced, and the rule is
\[
 K(X)=\operatorname{red}(K(Y)K(Z)).
\]
The existing exact boundary-cancellation operation evaluates this product
using compressed longest common prefixes, inversion and slicing.
The new traversal does not replace any of those algebraic operations.

When a collected node is evaluated, each child either lay on the cached
frontier or was collected earlier in the allocation order. Both therefore
have exact results. Induction proves the computed result exact. A node that
becomes cached as a side effect of processing another node can also be skipped:
the same invariant applies to every published cache entry.

Crucially, a cached node need not have cached descendants. A substring of a
known reduced word is reduced, so slicing can certify its new root without
individually reducing the intermediate concatenations created by the slice.
The bounded-run evaluator can similarly certify a rebuilt reduced root.
Only that root's result is needed when reducing an ancestor. Descending below
it would compute answers that are unnecessary for the current query.

The discovery pass does not publish cache entries. Evaluation publishes a
result only after its exact operation completes. Cancellation, work exhaustion
or node exhaustion therefore leaves only completed entries, which remain
valid on a later query. The existing resource exceptions and caller
cancellation still propagate; no partial traversal is treated as a proof.
The old full reachable-node traversal remains available for operations that
actually need every source node, such as occurrence counts and cold
substitution. Section~\ref{sec:sparse-substitution} adds an exact support
frontier when substitution metadata is already warm.

\subsection{Amortized traversal cost and its limits}

For completed query $i$, let $u_i$ be the number of previously uncached nodes
collected above its frontier. At most $1+2u_i$ stack entries are examined,
since each collected binary node adds two children. Sorting costs
$O(u_i\log(u_i+1))$ identifier operations. Each collected node has a cache
entry by the end of the successful query, and cache keys are never removed.
Thus, for $q$ completed calls and $U$ source nodes first collected over their
entire sequence,
\[
 \sum_i u_i\le U,\qquad
 T_{\mathrm{traversal}}=O(q+U\log(U+1)).
\]
This is a separate bound for each of the inverse and reduction caches. It
allows the arena to grow between calls; $U$ can be bounded by its eventual
historical node count. Identifier encoding and dictionary-access costs retain
the qualifications of the earlier word-engine analysis. With at most $M$ historical nodes, each identifier needs
$O(\log(M+1))$ bits. Temporary traversal storage is
$O(\max_i u_i)$ such identifiers. The two persistent result caches were
already present; this change adds no per-node semantic cache.

An interrupted discovery can be repeated, so the amortized statement excludes
repeated aborted attempts. It also excludes the algebraic cost of computing
new inverses or reductions, exact big-integer arithmetic, and all other word
operations. In particular it does not bound the total grammar generated by
an arbitrary knot search. A growing chain with each previous prefix already
cached needs one new source concatenation per query, rather than rescanning
all earlier prefixes. This removes quadratic traversal on that family without
asserting linear bit time for the complete compressed-word computation.

The exact word represented by every result is preserved, but unused cache
entries and intermediate allocations need not match the old implementation.
Some producer heuristics inspect arena size, and resource budgets count work.
Consequently universal equality of finite-budget search outcomes or traces
is not claimed. The source-bound audit below checks the maintained modes
against the entire pinned prior package.

\subsection{Validation and measurements}

Six focused tests cover two hundred random streams of mixed word operations;
cached substrings with uncached descendants; 2,400-deep growing grammars;
2,050-bit represented lengths; interrupted discovery and evaluation; and
work/node exhaustion. All focused tests pass in 0.238 seconds. The maintained suite passes
1,018 tests with Regina in 205.119 seconds. The exhaustive
word audit checks every signed rank-two word through length seven: 21,845
words and 65,535 inverse, free-reduction and cyclic-reduction comparisons
against literal stacks and the pinned prior engine.

Against baseline \texttt{4cef49dffbc3}, eighty actual diagrams preserve all
400 outcomes across the default, projection, forest, direct batch and adaptive
batch modes, including positive certificate hashes. Each positive is replayed
with both the old and current packages, using both literal and compressed
reconstruction. Five additional supplied source proofs cover Whitehead and
projection prefixes, including an exponent $2^{1024}$; modified source bindings
are rejected. All production modules other than the shared word engine are
checked for identical source. The audit takes 20.225 seconds.

On Gordian the default producer's work falls from 1,215,145 to 1,154,597 with
the same certificate and 9,025 nodes. The adaptive host still falls back and
its total work falls from 1,305,050 to 1,244,502. Direct batching still exhausts
the two-million-work allowance. These counters isolate saved work; wall-time
measurements and their controls are reported separately below.
