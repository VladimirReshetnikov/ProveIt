PROOF AND ARTIFACT REVIEW

The article uses conventional mathematical proofs. Separate AI-assisted
reviews checked the main derivations and the final consistency of the
opening claims, assumption ledger, and research agenda.

MATHEMATICAL POINTS CHECKED

Residual codes:
- The stage-controlled embedding of a linearly ordered alphabet Y into
  No_{<|Y|} has birthday at stage xi at most xi, including singular cardinals.
- The sign code (- -> 00, termination -> 01, + -> 11) is prefix-free.
- All lengths are ordinal lengths. Regular variable-length concatenation,
  singular fixed-length padding, and above-cutoff absorption are distinguished.
- The main prefix code works before the enumeration is exhaustive.
- Codes chosen for residual alphabets depend consistently on equal prefixes.
- The singular scheduler survives deletion of fewer than kappa labels.
- The smaller singular strong-limit reserve lies below the original cutoff.
- Disjoint sign cones support finite mixed descent.
- A strictly descending sequence of residual cardinalities terminates finitely.
- The strict singular inflation example uses multiplier delta = 1; no
  unjustified strict comparison is asserted when ordinal absorption occurs.
- The above-cutoff argument removes CH at the first uncountable cutoff.

Topology and measurability:
- Cofinite-prefix topology agrees with the order topology of the prefix space.
- The factorial-fiber decomposition accounts for all endpoint and isolated points.
- The split-order Borel description permits only countably many split fibers.
- Ranking and relation coding are treated as different maps with different
  thresholds, rather than inferred from their being inverse bijections.
- Individual rays can have F_sigma preimages even when arbitrary open-set
  preimages do not remain Borel.
- The single orientation predicate repairs the P_2 measurable presentation;
  it does not make the full-product topology a refinement of the lex topology.

Class theory:
- Set-supported partial tables are extended to every supplied global type
  using set-valued recursion with set-sized histories.
- Internal supports are distinguished from arbitrary external supports.
- The arbitrary-scan no-jumps theorem is restricted to set-like orders;
  the canonical scan has the stronger theorem on all class well-orders.
- The eventual-equality core uses an additively indecomposable alignment
  ordinal after reordering an initial set.
- Pair coding and decoding recover class availability without forming a
  class of all proper classes.
- Core preservation setwise differs from fixing every core point.
- Tarski's theorem is used as a definability obstruction, without denying
  the existence of class truth predicates in stronger theories.
- Definability with a specified set parameter is separated from existence
  in the class sort.

FINITE COMPUTATION

The included Python script independently compares acyclicity (Kahn elimination)
with exhaustive existence of a permutation extension. For sizes 0 through 5,
the number of acyclic/extendible tables is:
    1, 1, 3, 25, 543, 29281.
The total number of partial orientation tables checked is 59,810.

It also checks 110 diagonal/opposite-direction cases, 63 finite sign words
(3,969 ordered comparisons and 1,953 distinct prefix comparisons), all binary
pair-swap words for 0 through 5 pairs, and all six three-label well-orders.
All checks passed. The JSON contains the full finite scope and results.

LIMITS

The finite tests do not establish any transfinite theorem. No new theorem
was implemented in Lean, and the repository was not rebuilt. The source
declarations identified in the article were inspected. The work is not an
assertion of historical originality or a substitute for external peer review.
