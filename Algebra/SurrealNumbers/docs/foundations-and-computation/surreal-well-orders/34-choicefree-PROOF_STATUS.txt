PROOF STATUS AND ASSUMPTION LEDGER

1. FOUNDATIONS

GB means the two-sorted class theory with the ZF set axioms, elementary
comprehension, and Class Replacement; neither set Choice nor Global Choice
is assumed. GBC adds Global Choice. Class well-orders in the choice-free
results use the full admitted-subclass minimum definition.

Lemma 2.2 proves in GB that a class LINEAR order is a class well-order
exactly when every nonempty SET subset has a minimum. Its proof chooses a
predecessor by minimizing rank and then taking the order-minimum in that
set slice. It does not identify 'no infinite descending sequence' with
well-foundedness in arbitrary choiceless settings.

2. FINITE-SUPPORT POWERS

Theorem 4.2 is proved in GB in two independent ways. The greedy-prefix
proof maintains a nonempty retained subclass, with every rejected code
larger than every retained code. Unique minima choose the next exponent
and digit. Nontermination would give a descending exponent sequence.
The second proof collapses the set of coordinates and digits in any set
of finite graphs to ordinary ordinals and uses Lemma 2.2.

All polynomial objects are finite sets. The arbitrary ordinal coefficients
are not claimed to have finite strings over a fixed finite alphabet.

3. THE REPOSITORY-LOCAL REFINEMENT

Theorem 5.8 establishes over GB the equivalence of:
- strong class-well-order initial-segment comparability (CWO);
- canonical histories on the input-order schedule W+1 (CTH);
- a canonical terminating history on some class-well-order schedule;
- an initial embedding of every nonempty W into P(W).

The inspected repository already supplies the core argument over GBC.
The choice-free polynomial lemma removes its only Global Choice use for
arbitrary carriers. The proof checks cover floors, finite changes, digit
reconstruction, the fixed-cap argument establishing initiality, and
anchored convex restriction. Source labels and exact attribution are in
the article's appendix.

The separate reduction to orders on the entire surreal carrier is not
included in the choice-free strengthening. The theorem is an equivalence
of principles, not a proof that GB establishes either one unconditionally.
The published question whether CWO implies ETR remains unresolved here.

4. HEREDITARY FIXED POINT

Section 6 constructs finite trees directly, before proving their order
well-founded. A common ordinal specialization of any SET of terms gives
its minimum, and Lemma 2.2 yields full class well-foundedness in GB.
No sequence of proper classes is constructed by unexplained omega-length
class recursion. The height cuts are initial; coefficient-bounded
subsystems generally are not initial.

The root constructor gives Ord^[E] isomorphic to E. Its universal property
is stated for a supplied INITIAL embedding Ord^[X] into X and proved using
finite-term evaluation. The construction also works for other nontrivial
class well-order bases. In the full interpretation over inaccessible kappa,
its external order type is epsilon_(kappa+1), not epsilon_kappa.

5. DIAGONAL AND TRUTH

The uniform-family diagonal is a GB theorem when the index class is
already supplied with a class well-order. GBC provides a global order
for arbitrary index classes. The diagonal admits no order embedding into
any fiber because such an embedding would restrict to C+1 into C.

The truth jump ASSUMES a full elementary satisfaction class for the stated
expanded language and GBC. The validity filter is first-order and does
not evaluate a second-order formula through a first-order truth predicate.
Invalid presentations become empty fibers. General initial-segment
comparison is used only where explicitly assumed.

The bounded-complexity jumps are separate constructions for each fixed
standard complexity. They are not one uniformly definable sequence.

6. EXTERNAL SPECTRA

The full spectrum calculation assumes an inaccessible cardinal in an
external ZFC universe and the full class model over V_kappa.
The parameter-free cofinality theorem assumes a transitive SET beta-model
of GBC, finitely many fixed predicates, and a named global well-order.
The beta condition ensures that the internal well-order filter excludes
external pseudo-well-orders. Countable cofinality of the external cutoff
does not imply that the cutoff is countable or internally represented.
