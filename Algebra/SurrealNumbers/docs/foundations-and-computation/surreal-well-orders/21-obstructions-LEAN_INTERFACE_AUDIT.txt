arithmetic. Numerical order is explicitly distinguished from birthday comparison.

The proof uses a complete lexicographic order of full Boolean words with fixed
ordinal length b, bounds option birthdays, and constructs a separator of exactly
birthday b. The common bound b need not be a successor ordinal. The code calls
birthdays_bounded on the sum of the two small index types.

Limit: only SmallCutData with lower-universe option indices is covered. This is
not unrestricted filling of all Set SignSequence predicates. Auxiliary full-word
and aboveWord/belowWord declarations are private and should not be cited as a
stable public API.

noUnrestrictedCuts is the completely general irreflexive-relation statement:
  not (forall L R : Set X,
    (forall l in L, forall r in R, lt l r) ->
    exists x, (forall l in L, lt l x) /\ (forall r in R, lt x r)).
Its proof takes L=Set.univ and R=empty. It is not a theorem prohibiting all
lower-universe small cuts.

Other usable consequences:
- HasSmallCutFillers.hasSmallStrictUpperBounds
- HasSmallCutFillers.exists_strict_lower_bound
- HasSmallCutFillers.exists_strict_lower_bound_above
- HasSmallStrictUpperBounds.exists_bound_of_small_set
  (requires a Small.{u} instance for the set's element subtype)

FIRST FORMALIZATION MILESTONES SUPPORTED BY THESE INTERFACES

A. Numerical first-divergence proofs can reuse SignSequence.lt_iff and ext.
B. Prefix and simplicity arguments can reuse IsPrefix, truncate, and their laws.
C. Bounded birthday fragments can be transported to a lower-universe carrier
   using small_bounded; an arbitrary higher-universe type cannot be silently
   treated as lower-universe small.
D. Small-family interpolation can be expressed through SmallCutData or through
   exists_separator_of_small_sets with both explicit Small assumptions.
E. The noUnrestrictedCuts theorem provides a direct formal guard against an
   illicit unrestricted self-cut.
