1. INTRINSIC COMPLETION

Input: a Hausdorff space M with jointly continuous commutative,
cancellative addition and a linear natural algebraic order
x <= y iff y=x+z for some z in M.

Criterion: continuity of delta(y,x)=y-x on E_M={(y,x):x<=y},
with the subspace topology from M^2.

Conclusion: a unique Hausdorff group topology on G=M-M induces
the given topology on M, with zero base U-U.

Reviewed: algebraic embedding; G=M union (-M); filter, symmetry,
internal openness and addition for U-U; Hausdorff separation;
both topology comparisons; uniqueness.
Continuity is used only at (x,x) and (x,0), giving the local tests.
No metrizability or local compactness enters the general equivalence.

2. POLISH AND LOCALLY COMPACT UPGRADES

A countable monoid zero base gives a countable group zero base.
The abelian group admits an invariant metric. Its metric completion
is Polish because the group is separable.
M and -M are completely metrizable in their subspace topologies,
hence G_delta in the completion. Their finite union is a dense
G_delta subgroup. Baire category forces it to equal the completion.

Complete metrizability of a subspace is distinguished from
completeness for a particular inherited metric.

A compact monoid zero neighborhood K gives the compact group
neighborhood K-K, proving preservation of local compactness.

3. EXTENSION AND REGULARITY COROLLARIES

Continuous monoid homomorphisms extend by formal differences.
Continuous biadditive maps extend by the four-term formula.
Continuity at (0,0), separate continuity, and the bilinear expansion
give joint continuity everywhere. Semiring multiplication therefore
extends to topological-ring multiplication.

Borelness of order and partial subtraction follows by Lusin-Souslin.
It is already covered by the repository's automatic Borel
definability theorem and is credited accordingly.

Finite-index analytic subgroups are open by Baire category.
The residue corollary explicitly assumes both continuous addition
and continuous partial subtraction.

4. CLASS-THEORETIC BASE

The set axioms are ZFC with Foundation OMITTED, not negated.
Class axioms are elementary comprehension with set/class parameters
and class Replacement for specified class functions. Separation
with class parameters is used.
Set Choice is available.
Global Choice, unrestricted Collection, and proper-class recursion
are not assumptions.

Topologies are represented by classes of SET basic opens.
No class of all proper-class open subsets is formed.
Only the absence of nonempty proper clopen sets is needed for
the main connectedness inference.

5. CLOSURE CODING AND NEIGHBORHOOD SELECTION

For a set A and x in its closure, define
Phi_A(x)={B subset A : x in closure(B)}.
This belongs to P(P(A)). Hausdorffness makes the map injective.
Separation forms its image; inverse Replacement proves that
closure(A) is a set. This classical coding argument is credited.
It uses no Choice or rank hierarchy.

An exhaustion bounds every set of points by least-stage indices
and Replacement. At x, take the least stage containing any
open set neighborhood. Union ALL eligible neighborhoods inside
the power set of that stage. This gives a specified open set N(x)
without choosing from a proper class.
H(A)=union_{x in A}N(x) is a specified set-valued enlargement.

6. CLOPEN HULL

For set-tightness <=kappa, iterate closure and H for kappa^+ stages.
Limit stages and the final union are sets by Replacement and Union.
The recursion has SET length and a functional rule.
H need not be monotone, since
O_alpha subset closure(O_alpha) subset O_{alpha+1}
already makes the sequence increasing.

A tightness witness of size <=kappa lies in one stage by regularity
of kappa^+. The next stage contains its closure points. Thus the
final union is clopen. Connectedness makes any nonempty such hull
the whole carrier.

7. MANIFOLDS, COMPONENTS, METRICS, AND CODES

Chart domains are sets by inverse class Replacement.
First countability gives countable tightness by ordinary Set Choice.
The classical continuum bound is proved only after carrier sethood,
when candidate chart domains form sets inside P(X).

Canonical connected neighborhoods keep the hull construction
connected. Components are proved to be sets BEFORE their class
is formed.

A specified compatible real metric gives N(x) by the least natural
index with a set-sized shrinking ball.
A class topological group gives N(g)=gU from a set identity
neighborhood.

Surreal sign sequences have set birthday stages. Injections into
an exhausted class transport stages by unique inverse Replacement;
surjections transport stages by direct-image Replacement.
Continuity of a coding map is not required.
