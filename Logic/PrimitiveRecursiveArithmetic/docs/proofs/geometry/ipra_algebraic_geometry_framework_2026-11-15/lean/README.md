# Lean artifacts

- `CertifiedSetoid.lean`: host data structures for proof-relevant equality and congruence.
- `PresentedAlgebra.lean`: target interfaces for quotient presentations, localizations, principal covers, and gluing.
- `ProjectiveCech.lean`: target interfaces for the standard projective atlas and the `O(d)` Čech computation.
- `ObjectTheoryPlan.lean`: exact intended `Prf PRAAx` endpoint and repository bridge.
- `FORMALIZATION_PLAN.md`: dependency-ordered route to complete Lean formalization.

These files are outlines, not compiler-checked theorems. They deliberately avoid placeholders that would make unfinished claims look proved.
