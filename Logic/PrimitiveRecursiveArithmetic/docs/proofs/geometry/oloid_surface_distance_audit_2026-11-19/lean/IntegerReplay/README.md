# Kernel replay of the finite distance certificates

Run `sh build.sh` here with Lean 4.32.0 on PATH, or set `LEAN` to its absolute filename. No external package is required. All 219 displayed equalities use `by decide +kernel`. The 45 pair files follow lexicographic order in the point indices, starting with (1,2), (1,3), and ending with (9,10).

The 154 word trees each prove a lower bound for an admissible word. The 45 upper checks certify the listed dyadic paths. Twenty additional trees prove that every parameter tuple of the winning curved word is in its specified root box or has a cost at least one unit of 10^-14 above the feasible upper bound. Each binary split bisects the longest parameter interval with ties resolved in gate order. Both children inherit the common midpoint ball. The lower checker verifies squared bounds on every integer support vector and on each difference between adjacent vectors. It subtracts the rounded-up chord error times this difference bound and uses the smaller endpoint dot product. The upper checker verifies every leg against an integer square bound and includes both ball radii.

`ReplayBalls.lean` contains the rational enclosure data. In `analytic_inputs.csv`, a row Pj refers to the folded and developed point Pj. A letter A, B, L or R refers to the value of that gate at the specified rational normalized parameter. The coordinates and radii in each Lean ball are integers in units of 10^-14. The import from geometric analysis consists of the validity of those sample enclosures, the chord-tube curvature estimate, and the global route theorem. The Python analytic evaluator supplies the enclosures. The current Lean modules check the resulting integer certificate arithmetic. The generation script `code/emit_replay.py` reads the supplied CSV and tree descriptions; the support directions it proposes are independently tested in Lean.

The more precise forty-place bounds use a separate gradient calculation. Their localized Hessian and analytic-series operations are in the Python replays.
