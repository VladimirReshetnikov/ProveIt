# Executable reference algorithms

Run `python3 test_pell.py` to reproduce the deterministic validation suite.
Run `python3 pell_reference.py` to print the seven worked examples.
Run `python3 export_certificates.py` to regenerate their complete traces in
`cf-certificates.json`.
The code requires only the Python standard library.

All arithmetic is exact. `sqrt_floor` uses a finite binary digit scan;
continued-fraction states are checked using squared integer comparisons;
no floating-point value or real-number package is used. Every algorithm
has explicit finite fuel. Early returns and breaks are equivalent to
freezing the state for the remainder of that fuel.

`cf_certificate` records the complete reduced period and two periods of
convergents. It checks the simultaneous linear identities, determinant,
norm, coordinate bound, endpoint formula, and negative-unit square.
Its `fundamental` field uses the finite Legendre and minimality theorem
proved in the article. `fundamental_by_scan` is the separate slower bounded
selector, useful for independent crosschecks on modest coordinates.

The main additional functions implement norm-one classification, negative
Pell classification and bounded seed scanning, generalized norm seeds and
descent, finite congruence periods, rational square-root enclosures, small
finite Dirichlet certificates, and integral equal-signature quotients.

The tests check all nonsquare discriminants from 2 through 500 for the CF
invariants, independently check minimality on a bounded manageable subset,
and exercise the other theorems on the ranges recorded in `test-results.json`.
Known cases include D=61, whose fundamental positive solution has a large
second coordinate. The CF computation and descent use the proved finite
iteration bounds; they do not scan all denominators up to that coordinate.

`test-results.json` is generated by an actual run. These tests validate the
implementation on the recorded finite inputs. They are not Lean proofs,
not certificates for the embedded iPRA checker, and not substitutes for the
general arguments in the article.
