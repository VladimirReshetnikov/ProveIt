# Companion programs

- `exact_coefficient_checks.py`: exact `fractions.Fraction` checks for duplication, hypergeometric, Bessel, incomplete-gamma, and Lerch coefficient identities.
- `numerical_special_cases.py`: 80-digit `mpmath` comparisons for 63 Meijer-G special cases, including elementary functions, incomplete gamma, Bessel, Lerch, the generalized-r cosine, the six-term identity, and the Whittaker kernels.
- `generate_coverage_table.py`: regenerates the typeset ledger from `claims/coverage.csv`.
- `coverage_summary.py`: writes the status summary to both `claims/` and `evidence/`.

These programs are regression evidence, not the trusted proofs.
