Directly read files and useful content:
- PR.lean: PR k syntax (zero/successor/projection/composition/primitive
  recursion), PTm syntax, PRAAx, PRA.qfInd. All induction axioms require
  an explicit witness that the induction formula is QF.
- Syntax.lean: Fm T n with equality, bottom, conjunction, disjunction,
  implication and first-order quantifiers; Fm.QF returns False for either
  quantifier. De Bruijn variable 0 is innermost.
- Deduction.lean: Prf Ax Gamma phi is intuitionistic natural deduction
  with equality. Actual target is a Prf PRAAx derivation, not merely a Lean
  proposition about Nat or Rat.
- Scalar.lean: TeqAx is scalar iterator theory with equation induction,
  coverage and separation.
- TeqReflect.lean: characteristic term chi of a QF formula and chi_iff;
  Teq.qfInd derives QF induction from equation induction.
- TeqRec.lean: Tm.prc encodes recursion by pairing counter and state in
  an iterator; Q.prc_zero and Q.prc_succ prove defining equations.
- PRAToScalar.lean: FromPRA.code compiles every PR syntax tree to a
  scalar term; FromPRA.sigma translates PTm; FromPRA.interp proves
  interpretation of PRAAx into TeqAx.
- Native.lean: NFm/NPrf native calculus and NPrf.sound to TeqAx.
- NativeBiInterpretation.lean: pra_iff_native transfers an actual
  iPRA derivation to the native calculus; native_iff_pra gives reverse
  faithfulness; both round trips are proved.
- ConciseIPRA/README.md: project overview and current status.
- Analysis/README.md: existing analysis projects. No dedicated iPRA
  Stirling development was identified in these inspected sources.

Searches for Stirling and Wallis:
The returned Stirling hits included combinatorial Stirling-number code,

exhaustive absence claim about all repository contents.

Important distinctions:
1. A Lean theorem over Rat does not establish an iPRA derivation.
2. Primitive-recursiveness of a checker does not establish that iPRA
   proves that checker universally succeeds.
3. A uniform universal evaluator for arbitrary PR codes cannot be assumed
   primitive recursive; only the fixed codes occurring here are needed.
4. A fixed-precision finite inequality must be proved by QF induction.
   Induction over predicates quantifying over every precision is forbidden.
5. The imported repository bridge solves translation between calculi,
   not the new arithmetic estimates.
