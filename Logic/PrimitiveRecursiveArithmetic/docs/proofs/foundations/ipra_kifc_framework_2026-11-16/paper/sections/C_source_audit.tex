\subsection{Audit limitations}

The repository contains many proof packets and changes rapidly.  This task inspected the central indexes, current logical APIs, checked derivation core, the negative-translation source layer, representative theorem files, and prior general-framework artifacts.  It did not independently rebuild every packet or verify every theorem claimed in packet prose.  The theorem ledger therefore distinguishes inherited checked components, human-complete arguments, finite-tested algorithms, uncompiled Lean outlines, placeholder-bearing formalization targets, conditional producer interfaces, and genuine open problems.
