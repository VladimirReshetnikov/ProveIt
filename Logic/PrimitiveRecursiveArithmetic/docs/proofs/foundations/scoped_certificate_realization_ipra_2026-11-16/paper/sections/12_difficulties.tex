\subsection{What has genuinely been resolved}

Four improvements go beyond renaming prior contract graphs.

\begin{enumerate}[label=(\arabic*)]
\item \textbf{Choice is classified by escape, not by finiteness.}  Earlier
normal forms tend to select a least accepted global code whenever finite
witnesses appear.  SCR proves that a proof-local witness needs no selector or
bound at all.  This materially reduces the obligations for noncanonical and
conditionally produced objects.
\item \textbf{The boundary theorem is already a final object theorem.}  A
missing producer does not block the verifier and extractor: they compile to
\((\exists c\,V)\to G\) or a context theorem now.
\item \textbf{Dependent local witnesses compose without global packing.}
Nested existential elimination handles finite dependent DAGs directly.  Whole
trace coding is introduced only at object-variable horizons.
\item \textbf{The open bridge is tied to the same contract interface.}  Local
hypotheses and arbitrary query terms are first-class, so a packet need not
close every theorem merely to cross between repository formalizations.
\end{enumerate}

\subsection{What no framework resolves}

A generic framework cannot prove a uniform height bound, discover a missing
analytic rate, decide a singular branch continuously, or turn a non-effective
compactness theorem into a finite cover.  Its contribution is to reduce each
application to a small, exact producer statement and to prove everything
downstream of that statement in a reusable way.  This is a stronger result
than an informal claim of ``formalizability'': it identifies the theorem whose
absence is mathematically decisive.
