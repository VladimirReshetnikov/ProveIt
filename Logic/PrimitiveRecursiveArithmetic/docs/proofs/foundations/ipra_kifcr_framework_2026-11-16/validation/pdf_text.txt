                                              Abstract
      The current ProveIt repository has crossed an important threshold. It no longer contains
  only a small checked presentation of intuitionistic primitive recursive arithmetic and a collection
  of prose proof packets: it also contains a substantial kernel-checked derivation library, including
  arithmetic, bounded search, simultaneous recursion, Euclidean algorithms, finite sums and
  products, descent, finite-dimensional linear algebra, and many theorem modules. The remaining
  general problem is therefore more precise. Given a finite mathematical construction and some
  genuinely theorem-specific quantitative inputs, how can one systematically produce a value of
  the embedded judgement
                                            Γ ⊢ [PRAAx]φ
  without confusing an ambient Lean theorem, a tested program, or an unavailable quantitative
  producer with an object-theory proof?
      This report develops KIFC-R, an updated residualized version of the Kernel-Integrated
  Finitary Contract framework. A theorem is compiled query-by-query into fixed primitive-
  recursive terms, a finite proof graph, and an explicit list of residual boundary formulas. Checked
  infrastructure is reused rather than reimplemented: in particular, the present repository already
  supplies least bounded search and simultaneous recursion inside Prf PRAAx. New generic
  components are isolated where the checked library is still thin: fixed-formula Booleanization,
  proof schedules, residual normalization, capped cyclic demand closure, trace reflection, finite
  relational viability, stable-observer elimination, and quantitative interfaces for guards, nets,
  names, and height-bounded enumeration.
      The central output is not an unconditional overstatement but a canonical conditional derivation

                                     B1 , . . . , Br , Γ ⊢ [PRAAx]Φ.

  Each Bi is an exact missing producer obligation: for example a separation gap, a height cutoff,
  a finite-cover margin, or an effective analytic constant. Supplying derivations of the Bi closes
  the theorem by simultaneous cut; leaving them open records the precise research boundary.
  Complete human-readable arguments are given for residualized graph compilation, least fixed
  points of capped monotone demand systems, one-loop trace normalization, finite path extraction
  by backward viability, exact and approximate choice erasure, regular-name extraction from
  shrinking clouds, guarded operations, finite-net transfer, and the equivalence between effective
  height bounds and complete bounded lists.
      The archive includes a current-API Lean formalization plan, source-oriented Lean modules,
  exact Python reference algorithms and tests, a theorem/status ledger, and a compiled PDF. The
  new Lean modules are explicitly outlines rather than claimed kernel-checked additions; inherited
  checked results are identified separately. General effective Faltings, Siegel, Roth, Mordell–Weil

1     Executive result and design summary
1.1    The current problem
A claim that a classical theorem has been embedded into iPRA should separate four logically different
achievements.
 (1) The familiar mathematical statement has been replaced by a finite numerical presentation
     with explicit moduli, bounds, margins, charts, or relations.
 (2) The finite construction has been compiled to fixed primitive-recursive symbols and quantifier-
     free loop invariants.
 (3) Lean has constructed an actual derivation of an explicit object formula from PRAAx.
 (4) An external interpretation theorem explains how that object formula recovers the familiar
     statement.
The current repository provides many successful instances of (2)–(3), but most delivered packets
remain at (1) or at a semantic version of (2). It also contains hard targets for which a quantitative item
in (1) is genuinely missing. A useful general framework must therefore do two things simultaneously:
automate the reusable proof engineering, and expose rather than conceal the missing mathematics.

1.2    The KIFC-R endpoint
Fix a finite theorem-specific interface graph G, a numerical input x, and a finite query q. Compilation
produces:
    • fixed PR symbols for every executable node;
    • a demand vector fixing all precision, fuel, finite-use, and table bounds before the main
      induction;
    • a packed forward trace and one quantifier-free invariant;
    • a proof schedule containing local derivations and their dependency order;

1.4   Main metatheorems
Theorem 1.1 (Residualized kernel compilation). Let G be a fixed finite interface graph. Suppose
every executable node has a fixed primitive-recursive implementation and an object-level local
soundness derivation; every recursion has a quantifier-free invariant; every finite relation has
bounded validity and compatibility formulas; and every unresolved input is declared as a residual
boundary formula. Then a metalevel compiler can construct a finite list Res(G, q) and a derivation

                                   Res(G, q), ΓG ⊢ [PRAAx]ΦG (q).

If each residual formula has a derivation from ∆, simultaneous cut produces

                                       ∆, ΓG ⊢ [PRAAx]ΦG (q).

The construction does not add an object-level graph interpreter, reflection axiom, choice principle,
or induction scheme.

Proof. Specialize the finite graph at the metalevel. Traverse it backward to compute which assump-
tions and numerical demands are actually needed. For acyclic resource dependencies, take finite
maxima in reverse topological order. For monotone cyclic dependencies with supplied caps, iterate
the capped update map until its rank can no longer rise; theorem 9.3 proves that this yields the
least closed vector above the seed. Generate a packed forward transition and prove its QF invariant
by the checked induction interface. Each node’s local rule is instantiated with the generated terms.
Compose the instantiated rules in topological proof order using Prf.trans; where a premise is not
produced by an executable node, retain it in the context. Backward reachability removes unused
residuals and duplicate formulas. The resulting nested cuts are exactly the required derivation. A
final application of simultaneous cut supplies any residual proofs that later become available.
Theorem 1.2 (Finite relational elimination). For a bounded layered relation of finite horizon,
backward viability holds at a candidate exactly when that candidate begins an accepted compatible
suffix. Hence a viable start yields a primitive-recursively selected finite path. If a terminal observer
is constant on all accepted candidates, the observed output is canonical without a canonical witness.
If its diameter is at most δ(q), any selected output is canonical up to δ(q). A coherent infinite name
follows only from an additional primitive-recursive adjacent-motion budget with a summable tail
modulus.

KIFC-R for iPRA                                                                              2026-11-16


Proof. The viability equivalence is backward induction on the finite horizon. The path is obtained by
checked least bounded search at the first level and at each successor level. Exact observer elimination

independently nonempty shrinking clouds need not yield a computable coherent choice.

The main update is not another renaming of the same semantic ideas. It changes the formalization
baseline and the output discipline.
 (1) The current checked IPRADerivations.Core.Search is treated as inherited infrastructure.

1.6   Scope
The framework resolves many proof-engineering difficulties and gives correct conditional forms for
several deep targets. It does not manufacture a height theorem, a spectral gap, an effective zero-free

either be proved in iPRA, supplied as finite evidence with a verifier, or remain in the residual context.
This is a feature: the final sequent says exactly what has and has not been established.

3      Logical substrate and admissible proof engineering
3.1     The object theory
Fix a number n of free numerical variables. The type PTm(n) contains terms built from variables
and primitive-recursive function symbols. A formula φ ∈ Fm(PTm, n) is interpreted only through
the derivability relation
                                         Γ ⊢ [PRAAx]φ.




                                                 12
KIFC-R for iPRA                                                                            2026-11-16


The metatheory is Lean. The object theory is iPRA. This separation allows the metatheory to use
finite types, inductive syntax, quotient constructions, and normalization tactics while still exporting
a derivation whose leaves are exactly the axioms of iPRA.
The following derived operations are the backbone of the compiler.
Lemma 3.1 (Substitution). If Γ ⊢ φ and σ substitutes terms for all free variables, then

                                             Γ[σ] ⊢ φ[σ].

Proof. Induct on the given natural-deduction derivation. The only nontrivial cases are binders.
Under a binder, lift σ by mapping the newly bound variable to itself and shifting every old image.
The syntax library proves the required substitution identities. The axiom case follows because
an open axiom is universally instantiated by the axiom rule. This is the content of the current
Prf.substWeaken and Prf.subst theorems.
Lemma 3.2 (Simultaneous cut). If h : Γ ⊢ φ and, for every ψ ∈ Γ, one has kψ : ∆ ⊢ ψ, then
∆ ⊢ φ.

Proof. Induct on the list Γ. The empty case is weakening. For Γ = ψ :: Γ′ , first discharge ψ from h
by implication introduction, recursively cut all members of Γ′ , and finally apply modus ponens to
kψ . This is exactly the current theorem Prf.trans. Notice that no cut rule is added to the kernel;
simultaneous cut is derived in intuitionistic natural deduction.
Lemma 3.3 (Quantifier-free induction interface). Let I(z, ⃗x) be quantifier-free. If

                              ⊢ I(0, ⃗x)    and        I(z, ⃗x) ⊢ I(Sz, ⃗x),

then ⊢ I(z, ⃗x) as an open theorem, and hence every term instance I(t, ⃗u) is derivable.

Proof. Apply the PRAAx induction axiom to I, use implication introduction for the step, and
universally eliminate the resulting formula onto the open induction variable. The repository packages
this as PRA.qfInd and, in the derivation library, as LeanProofs.IPRA.ind. Term instances then
follow from substitution.

The compiler is designed so that every recursive correctness argument terminates at theorem 3.3.
This is why Boolean reflection and state packing are not optional optimizations: they are the
mechanism that makes the invariant quantifier-free.

3.2   Finite data inside one numerical sort
Every finite data type used by a fixed theorem is encoded by natural numbers together with primitive-
recursive projections and a bounded well-formedness predicate. There are several interchangeable
choices:
   • iterated pairing, with a fixed arity known at compilation time;
   • mixed-radix tuples when component bounds are available;
   • tables encoded by bounded products of radices;
   • finite lists represented by a length and a bounded tuple code.



                                                  13
KIFC-R for iPRA                                                                          2026-11-16


No coding theorem requires exponentiation as a primitive operation: exponentiation, bounded
products, pairing, and table lookup are primitive recursive and therefore have symbols in the
ordinary language.
A coding package for a type X consists of a predicate WFX (c), projections, constructors, and
object-level equations showing that projecting a constructed code returns its components. Equality
of codes is not automatically mathematical equality. When multiple codes represent the same
object, an explicit primitive-recursive equivalence relation c ∼X d and congruence theorems for all
observations are part of the interface.

3.3     Metalevel normalization is legitimate when it produces proof terms
The current algebraic derivation library illustrates a general pattern. The metatheory forms a
quotient of terms by provable equality, proves that the quotient is a cancellative commutative
semiring, embeds it in a ring of differences, and invokes a ring normalizer. The final theorem is
recovered through injectivity as an object-level equality derivation. The normalizer is not an extra
axiom of iPRA; it is a proof-producing metaprogram.
The same standard applies to every KIFC-Rcompiler phase:
 (1) the metaprogram may inspect a fixed graph, calculate a topological order, allocate registers,
     and synthesize terms;
 (2) it must also synthesize or invoke derivations of all local equations and implications;
 (3) the exported theorem must have the embedded derivability type;
 (4) an axiom audit must show no theorem-specific opaque axiom or sorryAx.

4      Kernel-Integrated Finitary Contracts with residual boundaries
4.1     Observation presentations
A large mathematical object is useful to a finitary proof only through a finite set of questions. This
motivates the basic representation.
Definition 4.1 (Finitary observation presentation). A presentation X with parameters x consists
of primitive-recursive data:
    (i) a query code q ∈ N;
 (ii) an answer bound BX (x, q);
(iii) a validity Boolean VX (x, q, a) ∈ B, used only for a < BX (x, q);
 (iv) an object-level totality contract

                                      PX (x) −→ ∃a < BX (x, q) VX (x, q, a) = 1.

The bounded existential is compiled by the Boolean/search machinery of section 6; it is not retained
inside an induction invariant.
The presentation is deterministic when valid answers are provably equal. It is observationally
deterministic for an observer O when O(x, q, a) = O(x, q, b) for all valid a, b. It is diameter bounded
when a rational-code metric satisfies

                                        d(O(x, q, a), O(x, q, b)) ≤ δX (x, q)

for all valid answers. These distinctions let a theorem consume exactly the amount of uniqueness it
needs.
Example 4.2 (Real numbers). A real number need not be introduced as a completed quotient of all
Cauchy codes. For a theorem asking for precision q, a presentation may return a dyadic rational
a/2m(q) together with a certified interval of radius 2−q . Two codes represent the same observed value
at precision q when their intervals overlap within the prescribed tolerance. An operation is proved by
transforming finite intervals and error budgets.
Example 4.3 (Polynomial roots). At a fixed precision, the answer may be an unordered finite
multiset of rational boxes, each carrying a multiplicity and a Rouché, Sturm, or interval certificate.
Ordered root labels are not part of the general presentation. Under a supplied separation gap,
matching becomes unique and labels can be recovered as a guarded observer.

Theorem 4.4 (Deterministic contract composition). Let C : X → Y and D : Y → Z be determinis-

requested Y -observation by the finite X-demand required by C. The composite transducer is ordinary

Proof. Fix a terminal query r. The contract D requests finitely many observations qj of Y . For each

combined demand, instantiate the soundness proof of C separately for every qj . These derivations

4.3   Relational contracts
Some constructions are total only as finite relations. A relational contract replaces RunC by a
bounded candidate relation
                               RC (x, r, ⃗a, b),  b < BC (x, r, ⃗a),
and proves bounded nonemptiness and validity of every accepted candidate. A downstream consumer
may depend on a candidate, but only through finitely many later compatibility checks. It is unsound
to choose candidates independently at each node; a locally valid candidate may lead to a dead end.
The remedy is not an axiom of choice. It is the finite dynamic program of section 10: propagate
viability backward from the terminal acceptance condition, then use least bounded search to select
a path through the viable subrelation.

4.4   Stable observation contracts
A consumer often does not need the witness itself. It needs an observation that all valid witnesses
share. A stable observation contract contains:
  (i) a bounded total relation R(x, q, a);
 (ii) an observer term O(x, q, a);
 (iii) either an exact stability proof R(a) ∧ R(b) → O(a) = O(b), a diameter estimate, or a guarded
       uniqueness proof.
The observer can then be evaluated at the least valid candidate. Exact stability removes the
arbitrary internal choice from the theorem statement. Diameter stability produces an approximate
observation. Guarded uniqueness produces an exact label only when the guard supplies a positive
gap.

4.5   Demand transformers
An operation on approximations is accompanied by a backward precision transformer. For example,
addition of dyadic approximations may require input precision q + 2, while inversion under |x| ≥ 2−g
may require q + 2g + c. A demand transformer is not merely an implementation hint: its local
adequacy is a theorem converting input error bounds into the requested output error bound.

cycle is never justified by circular reasoning.

5     Residual boundaries and conditional proof normal form
5.1    Why residuals are formulas
Suppose a finite verifier can use a height bound H(C), but the present mathematics does not
construct that bound. A host-language structure
       structure HeightData where H : Nat; complete :              Point p -> height p <= H
may be convenient, but it is not yet an iPRA theorem. If the field complete is populated by an
unproved proposition or an opaque assumption, the apparent construction has merely moved the
missing theorem into data.
The object-theory endpoint should instead retain the exact formula

                BH (C, H) ≡ “every represented point on C has height at most H”

as a hypothesis. The generic enumerator then proves

                   BH (C, H), Γ ⊢ [PRAAx]“the filtered list below H is complete.”

This conditional derivation is useful even before BH is solved: it verifies all coding, search, dedupli-
cation, and transport steps, and it names the remaining mathematical problem exactly.
Definition 5.1 (Residual boundary). A residual boundary node is a named formula B ∈ Fm(PTm, n)
together with metadata recording which graph nodes consume it and what mathematical producer
is expected. It has no local soundness proof. During compilation, every use of B is justified by the
corresponding retained hypothesis in the context.
Residual nodes are not axioms of the theory. They are antecedents of one particular conditional
theorem. If later work derives B from ∆, simultaneous cut removes it. If no derivation is known,
the theorem remains correctly conditional.

5.2    Proof dependencies and data dependencies
A graph has two distinct edge relations.
    • A data edge says that the primitive-recursive output term of one node is an argument of
      another.
    • A proof edge says that one formula is a premise of another node’s local derivation.
These often coincide, but not always. A denominator term may be computed unconditionally
while its positivity formula is residual. Two branches may share data but consume different gap

assumptions. A semantic parameter may appear in the external interpretation while not occurring
in the executable trace.
The compiler therefore performs reachability in the proof graph from the requested terminal formula.
A boundary formula belongs to the final residual list exactly when a reachable node consumes it
and no reachable executable node produces it.

Conversely, removing an unused hypothesis from the generated context changes no use of Prf.hyp,
so the same schedule compiles after the corresponding list reindexing. No semantic argument is
required.
Lemma 5.3 (Residual monotonicity). If the requested sink set is enlarged, the normalized residual
set can only enlarge. If a residual boundary is replaced by an executable producer with the same
conclusion, that boundary disappears from every request whose only uses are supplied by the new
producer.

Proof. Backward reachability and finite union are monotone in the sink set. Replacing a boundary
by a producer changes the recursive clause at that node from a singleton to the union of the
producer’s own dependencies. If those dependencies are already produced or absent, the original
formula is no longer inserted. Duplicate elimination cannot introduce a new formula.

5.5    Alternatives, implications, and partial progress
A deep input often has several possible producers. For example, a nonvanishing condition might
be established by a direct rational lower bound, by a discriminant estimate, or by membership in
one chart of a finite cover. The graph should represent these as alternative producer nodes whose
conclusions imply a common boundary formula. Each implication is itself an object-level local rule.
The residual normal form then retains the common formula only when no alternative producer is
selected; selecting one producer replaces it by that producer’s own residuals.
This organization supports meaningful partial results. A packet may close all arithmetic and
representation obligations while leaving one analytic estimate residual. Another packet may later
prove precisely that formula and close the theorem without redoing the finite compilation.

5.6    Cyclic proof dependencies
A raw cycle of the form “A is proved from B, and B from A” is not a proof. Cycles are admissible
only after they are converted into one of three finite well-founded forms:
 (1) a primitive-recursive time loop with a QF invariant;
 (2) a backward induction on a finite horizon, as in viability;
 (3) a capped monotone fixed-point iteration with a finite rank bound, as in section 9.
After such a component has a single exported theorem, the quotient proof graph is acyclic and
theorem 5.4 applies.

6     Boolean reflection and bounded search
6.1   Boolean conventions
Use numerical Booleans 0, 1. Define primitive-recursive operations
                                     ¬b,       b ∧ c,       b ∨ c,        b ⇒ c,
by fixed case distinctions, and normalize every Boolean-producing term so that an object-level range
theorem proves b = 0 ∨ b = 1. Equality and order on natural numbers are primitive recursive; let
                                           eq(s, t),    lt(s, t),    le(s, t)
denote their Boolean codes. The basic reflection library proves, for example,
                           eq(s, t) = 1 ↔ s = t,               lt(s, t) = 1 ↔ s < t.
The right-hand relations are themselves expressed in the fixed arithmetic language, for instance
using truncated subtraction or bounded witnesses. Once proved, application modules use only the
reflected form.

6.2   Finite folds
For a Boolean predicate term p(i, ⃗x), define primitive-recursive folds
                   All(0, ⃗x) = 1,                         All(Sn, ⃗x) = All(n, ⃗x) ∧ p(n, ⃗x),
                  Any(0, ⃗x) = 0,                         Any(Sn, ⃗x) = Any(n, ⃗x) ∨ p(n, ⃗x).
These functions carry all bounded quantifier content in a numerical state.
Theorem 6.1 (Finite-fold reflection). Assume p(i, ⃗x) is Boolean-valued and reflects a fixed formula
P (i, ⃗x). Then iPRA derives
                                      All(N, ⃗x) = 1 ↔ ∀i < N P (i, ⃗x),
                                     Any(N, ⃗x) = 1 ↔ ∃i < N P (i, ⃗x).
Moreover the induction used to establish the fold equations has a quantifier-free matrix.

Proof. The executable state is only the accumulator Boolean. Its defining equations are instances of
primitive recursion. First prove by quantifier-free induction that the accumulator remains Boolean.
For the universal fold, prove the two implications externally to the loop invariant.
For left-to-right reflection, use ordinary induction on N at the proof-construction level. At zero the
bounded universal statement is vacuous. At SN , the successor equation and Boolean reflection of
conjunction yield both All(N ) = 1 and p(N ) = 1. Apply the induction hypothesis to the first and
predicate reflection to the second.
For right-to-left reflection, again use induction on N . The successor bounded universal supplies
the prefix and the endpoint. Reflect these to All(N ) = 1 and p(N ) = 1, then use the conjunction
equation. The existential fold is dual: at the successor stage, split a bounded witness into the cases
i < N and i = N , and use reflected disjunction. All finite case splits are intuitionistically valid
because the relevant numerical comparisons have decidable Boolean codes.
A direct Lean implementation may package the prefix assertions as formulas containing bounded
quantifiers, but it need not apply the PRAAx induction rule to those formulas. The only object
recurrence requiring induction is the quantifier-free equality that defines the fold. Reflection is then
assembled from the fold equations, comparison reflection, and natural-deduction reasoning.

6.3    Structural Booleanization
A fixed bounded formula is generated from atomic equalities and inequalities by propositional
connectives and quantifiers of the forms

                               ∀i < t(⃗x) A(i, ⃗x),        ∃i < t(⃗x) A(i, ⃗x),

where all terms are primitive recursive and the formula syntax is fixed at compilation time.
Theorem 6.2 (Bounded Booleanization). For every fixed bounded formula A(⃗x), one can effectively
construct a primitive-recursive Boolean term χA (⃗x) and an object-level derivation

                                    ⊢ [PRAAx]A(⃗x) ↔ χA (⃗x) = 1.

The construction is syntax directed and uses no universal evaluator.

Proof. Proceed by structural recursion in the metatheory on the fixed formula A.
   • For an atomic equation or comparison, use the corresponding reflected Boolean.
   • For B ∧ C, B ∨ C, and B → C, combine the recursively constructed Booleans with fixed
     Boolean operations and compose their reflection theorems in intuitionistic logic. Implication
     is valid because the antecedent Boolean is decidable; its truth table is checked by the four
     Boolean cases.
   • For a bounded universal or existential, recursively Booleanize the matrix and apply theorem 6.1
     at the bound term.
The compiler constructs a dedicated term for this one syntax tree. It does not code formulas
and evaluate their codes inside the object theory. Thus the construction is compatible with the
impossibility of a total universal primitive-recursive evaluator.

6.4    Checked least bounded search

6.5   Derived finite algorithms
The same search theorem yields a library of reusable combinators.
  • Bounded argmin. Search the least index attaining the least value in a finite table; comparison
    reflection supplies the predicate.
  • Duplicate-free enumeration. Scan a bounded box, append an item only if its verifier
    succeeds and no earlier appended item is equivalent.
  • Finite cover selection. Search a finite net for the first cell whose certified test covers the
    current query.
  • Pivot selection. Under a margin certificate asserting that some pivot exceeds a threshold,

  • Finite path successor. Given a viability table, search the least compatible viable successor.
Each derived algorithm inherits a QF invariant because every finite universal or existential subcon-

7     One-loop normalization and trace reflection
7.1     Certified iteration
A loop node is specified by:
    • a packed state code s;
    • an initializer s0 (⃗x);
    • a transition T (i, s, ⃗x);
    • a fuel term F (⃗x);
    • a quantifier-free invariant I(i, s, ⃗x);
    • an output projection O(s).
All numerical maps are primitive recursive. The state trace is the primitive recursion

                             S(0, ⃗x) = s0 (⃗x),       S(i + 1, ⃗x) = T (i, S(i, ⃗x), ⃗x).

Theorem 7.1 (Object trace reflection). Assume object-level derivations of

                                      I(0, s0 (⃗x), ⃗x),
                                      I(i, s, ⃗x) −→ I(i + 1, T (i, s, ⃗x), ⃗x).

Then iPRA derives I(i, S(i, ⃗x), ⃗x) for all open i, and in particular at the fuel term F (⃗x). If a terminal
derivation proves
                                     I(F, S(F ), ⃗x) −→ Q(O(S(F )), ⃗x),
then Q is derivable.

Proof. Substitute the trace term into the invariant to obtain the QF formula

                                            J(i, ⃗x) ≡ I(i, S(i, ⃗x), ⃗x).

The base derivation is the supplied base proof followed by the zero computation equation for S. For
the step, assume J(i, ⃗x), use the supplied transition-preservation proof, and rewrite S(i + 1) by the
successor computation equation. Apply quantifier-free induction to J. Substitution instantiates the
resulting open theorem at F (⃗x), and modus ponens with the terminal derivation yields Q.

This theorem is already very close to the current LeanProofs.IPRA.ind API. The accompanying
KernelCore.lean packages exactly the base, step, and QF fields needed to invoke it.

7.2     Why all precision must be fixed before induction
A common invalid pattern is to put into the invariant the assertion

                                   ∀q “the state is correct to precision q”.

This is not quantifier-free. Even when every individual precision computation is finite, the displayed
invariant is stronger than the induction rule permits.
The correct transformation is:

                                                           24
KIFC-R for iPRA                                                                             2026-11-16


 (1) fix the terminal precision q∗ as an open parameter;
 (2) run the reverse demand pass to calculate every intermediate request from q∗ ;
 (3) allocate in the state only the finite observations required at those requests;
 (4) prove one QF invariant about this finite table;
 (5) after obtaining the open theorem for arbitrary q∗ , universally quantify over q∗ if the final
     theorem needs all precisions.
The universal quantifier is introduced after induction, not inside its matrix.

7.3   Collapsing nested bounded constructions
A fixed theorem may contain many loops, searches, and finite table passes. They can be combined

7.4     Clocked traces as an alternative
Sometimes it is easier to let an external producer supply a trace and have iPRA verify it. A trace
certificate contains s0 , . . . , sF . A primitive-recursive checker verifies the initial state, every adjacent

conjunction of local facts. This route is useful when the producer is complex but the transition is
simple. However, the checker still needs an object-level reflection theorem, and the trace length
must have an explicit bound. “Python produced a valid trace” is not itself the desired derivation;
the checked acceptance equation and its reflection proof are.

8      Proof schedules and residualized graph compilation
8.1     Local rules versus global proofs
A normalized graph node does not merely compute a value. It exports a local rule

                                             ∆v ⊢ [PRAAx]ϕv ,

where ∆v is the finite list of predecessor certificates actually used by the node. A topological schedule
turns these local rules into a global proof. The schedule is a metalevel object, so its dependency
lists may be ordinary Lean finite lists and its acyclicity may be checked by the elaborator.
Definition 8.1 (Kernel proof schedule). Fix a context Γ. A proof schedule for φ is generated by:
    (i) a terminal derivation Γ ⊢ φ; or
 (ii) a derivation h : Γ ⊢ ψ, followed by a schedule for φ under the enlarged context ψ :: Γ.
The new formula ψ may be an equation defining a register, a reflected Boolean fact, a loop invariant
instance, or a validity certificate.
Theorem 8.2 (Schedule compilation). Every kernel proof schedule compiles to a derivation Γ ⊢ φ.

Proof. Induct on the schedule. A terminal schedule already contains the desired derivation. In the
extension case, the induction hypothesis gives ψ :: Γ ⊢ φ. Apply simultaneous cut: discharge the
first hypothesis with h, and discharge each inherited member of Γ by the corresponding hypothesis
rule. The result is Γ ⊢ φ.

KIFC-R for iPRA                                                                            2026-11-16


This tiny theorem is the object-proof core of the graph compiler. Everything else constructs the
node formulas and their local derivations.

8.2   Static graph elaboration
A KIFC-Rgraph carries the following finite metadata:
   • node identifiers in topological order;
   • a node class and theorem-specific parameters;
   • predecessor identifiers;
   • a demand transformer for each incoming observation;
   • register widths and state projections;
   • the local formula exported by the node;
   • a Lean expression constructing the local derivation;
   • separate data and proof dependencies;
   • optional residual boundary formulas with stable names and provenance.
The elaborator performs only metalevel tasks: arity checking, topological sorting, variable allocation,
common-subexpression sharing, generation of primitive-recursive symbols, and construction of a
proof schedule. It is acceptable for the elaborator to fail. Its output, when accepted by Lean, is
checked independently by the kernel.

8.3   The four compiler passes
For a terminal query q∗ , compilation has four logically distinct passes.

Residual pass. Traverse proof dependencies backward from the requested sinks. Compute the
canonical duplicate-free residual list of section 5, discard proof-irrelevant nodes, and collapse every
certified recursive component to one exported theorem.

Demand pass. Start with the terminal demand. Traverse acyclic resource dependencies backward
using theorem 4.5. For monotone cycles with supplied caps, compute the least capped closure of
theorem 9.3 and retain cap adequacy as a proof or residual formula. The result is a finite demand
table DG (x, q∗ ) fixed before forward induction.

Forward pass. Traverse the graph in topological order. Exact nodes compute terms. Boolean
nodes compute reflected finite certificates, and search nodes instantiate the checked Search theorems.
Loop nodes run their specialized state recurrences. Relation nodes compute viability tables for the
finite horizons demanded by consumers. Observer nodes extract only stable terminal information.
By theorem 7.2, the entire pass may be represented by one packed state recurrence.

Proof pass. The base and step proofs establish the combined trace invariant. At the final state,
each executable node’s exported formula is available. The metalevel elaborator instantiates local
rules and arranges them in a kernel proof schedule. Boundary premises are discharged by hypotheses



                                                  27
KIFC-R for iPRA                                                                              2026-11-16


from the normalized residual context. Theorem 8.2 therefore produces the conditional terminal
derivation.

8.4    Soundness theorem
We can now refine the proof of theorem 1.1 at the trace level.

Trace-level proof of theorem 1.1. Fix the graph, its parameters, and a terminal query.
Primitive-recursive specialization. Since the graph has finitely many nodes and every numerical
constituent is primitive recursive, residual reachability and acyclic reverse demand are finite metalevel
computations; capped cyclic closure is a bounded primitive recursion. Each forward node is primitive
recursive: exact composition is closed under composition; Boolean folds and viability are bounded
recursions; checked least search is a fixed primitive recursion already available in the library; each
loop node is supplied as primitive recursion. The one-loop construction of theorem 7.2 therefore
yields a specialized primitive-recursive state symbol SG .
Quantifier-free invariant. Replace every bounded formula appearing in a local certificate by its
Boolean code using theorem 6.2. Add range equations for every flag, index, and code. Insert the
supplied loop invariants and local transition equations, guarded by the finite program-counter cases.
The resulting formula IG (t, SG (t), x, q∗ ) is quantifier-free.
Trace proof. The initializer equations and local base certificates prove the base case. For the step,
use Boolean reflection to split on the program counter. In each branch, invoke the corresponding
local preservation derivation, rewrite by the transition equations, and rebuild the finite conjunction.
Theorem 7.1 gives the invariant at the terminal fuel.
Node certificates. Terminal projection equations extract the equations, Boolean facts, search facts,
relational validity facts, and observer facts exported by each node. Each such fact is appended to a
kernel proof schedule. Whenever a local rule needs predecessor facts, they are already earlier in the
schedule by topological ordering. Instantiate its variables by the generated state projections, then
apply substitution.
Composition. Compile the schedule by theorem 8.2. This yields Res(G, q∗ ), ΓG ⊢ ΦG . Every
derivation leaf is one of: a PRAAx instance, a supplied local certificate, a residual hypothesis, or a
permanent hypothesis from ΓG . The only global principles used are intuitionistic natural deduction,
equality substitution, simultaneous cut, and QF induction. No arbitrary program code is interpreted
and no unbounded witness is selected. Supplying proofs of the residual formulas closes the theorem
by theorem 5.5.

8.6    Why the compiler is not a universal evaluator
It is tempting to define one object-level function U (e, x) that evaluates any encoded primitive-
recursive program. That cannot be total and primitive recursive while covering all unary primitive-
recursive functions.
Barrier 8.4 (No total universal primitive-recursive evaluator). There is no primitive-recursive
U (e, x) and coding of all unary primitive-recursive functions such that every unary primitive-recursive
f has a code e with U (e, x) = f (x) for all x.

Proof. If such U existed, the diagonal function g(e) = U (e, e) + 1 would be primitive recursive. Let
d be its code. Then
                                   g(d) = U (d, d) + 1 = g(d) + 1,
a contradiction.

KIFC-Ravoids the premise. Graph syntax is consumed by a metalevel elaborator, and the emitted
object term is a fixed composition/recursion tree. A clocked evaluator for one finite instruction set
and one explicit step bound is also harmless, because it verifies only a bounded trace and does not
enumerate all total primitive-recursive functions extensionally.

9     Capped cyclic demand closure
9.1    Why acyclic propagation is sometimes insufficient
Most precision graphs are acyclic: the output tolerance determines tolerances of its inputs. Some
useful interfaces, however, produce mutually dependent finite resource requests. A chart-refinement

routine may ask for coefficient precision determined by a separation estimate, while the verified

enlarge both the candidate horizon and the precision used to test compatibility. These are not
legitimate unbounded recursive definitions, but they can be sound when all coordinates have justified
finite caps and all updates are monotone.
The correct object is a least fixed point in a finite product of natural intervals. The finite lattice is
not invoked abstractly. We compute the fixed point by a bounded primitive recursion and prove
termination by an explicit integer rank.

9.3   Overflow as a residual or a diagnostic
The compiler must not silently interpret saturation as success. It has two admissible policies.
 (1) Static cap proof. Prove in the object theory that every edge transformer maps the relevant
     source cap below the target cap. By monotonicity, overflow is impossible throughout the
     iteration.
 (2) Dynamic boundary. Compute r∗ , retain the formula ov(r∗ ) = 0 as a residual boundary, and
     compile the downstream theorem conditionally on it.
A failed finite test may suggest a larger cap, but only an object-level cap proof or retained boundary
justifies the final theorem.

9.4   Object-theory realization
For a fixed N and edge set, encode the vector in a fixed nested pair or a bounded table. Generate
primitive-recursive symbols for lookup, update, the finite maxima, T , overflow, rank, and the L-step
iteration. The main invariant contains only equations and order predicates already represented by
QF formulas:
                      Inv(t) : s ≤ r(t) ≤ C ∧ r(t) ≤ r(t+1) ∧ ρ(r(t) ) ≤ L − 1.
The base and successor cases use the defining equations of the generated folds and the checked

   • Prove the rank-increase implication and use QF induction to show that L strict updates

9.5    Changing-parameter recursion
Some cycles are only apparent because a later phase changes a parameter. For example, a horizon h
may grow while precision q(h) is recomputed. The framework first chooses a single finite terminal cap
H, then treats (h, q) as coordinates of the same capped closure. This avoids induction hypotheses
that quantify over all future horizons. If no finite H is known, the theorem is not a finite-use result
and the missing horizon producer must be made residual.

9.6    Commutation with proof compilation
Demand closure is computed before term generation and forward proof scheduling. The closed
vector is substituted into every node’s local contract. Thus resource closure and proof compilation
commute in the following precise sense: compiling with the least closed vector yields the same
terminal formula as compiling with any larger adequate vector, except that the latter contains
unused precision. Monotonicity lemmas transport observations from the larger requests down to the
requested tolerance. The least vector is preferred for proof size and executable cost, not for logical
strength.


10     Finite relational witnesses and backward viability
10.1    Why local choice is insufficient
Suppose a computation has finite candidate sets A0 , . . . , AH , validity predicates Vi (a), compatibility
relations Ei (a, b) ⊆ Ai × Ai+1 , and a terminal acceptance predicate T (a) on AH . Pointwise
nonemptiness of every Ai does not imply the existence of a compatible path. Choosing the least
valid candidate at each level can enter a dead end.
The correct finite analogue of dependent choice is to remove dead ends before selecting anything.

10.4    Finite-use composition theorem
Consider a producer whose output at each query is a finite relation rather than a function. A

10.6    Products and amalgamation
If a theorem needs several independent relational certificates at the same finite horizon, form the
product candidate set and conjunction of validity/compatibility predicates. The product bound
is the product of component bounds and remains primitive recursive. Backward viability then
performs finite witness amalgamation. This is the appropriate replacement for statements such as
“choose all local branches coherently.”
The construction can be expensive, but proof-theoretic feasibility and computational efficiency are
separate. Sharing, incremental viability, and problem-specific pruning can reduce the state space
without changing the theorem.

11.5    Metastability as a final interface

may propagate these requests backward and search the required windows. Thus metastability is not
a failure: it is a different, weaker interface that composes with finite consumers.

an arbitrary computable metastability bound for a sequence to a computable Cauchy modulus for
that sequence.

control function, a finite stable window may still be found effectively. A uniform transformation
would turn these window procedures into a modulus and contradict the known computability
separation. In the present framework the conclusion is operational: retain the metastable contract
unless an explicit tail argument such as theorem 11.3 is supplied.

12     Guarded operations, extensionality, and finite gluing
12.1    Nonzero is not positive apartness
In constructive arithmetic, the proposition x ̸= 0 does not generally provide an integer g such that
|x| ≥ 2−g . Algorithms for division, matrix inversion, Newton iteration, branch selection, and chart
changes need such quantitative data to choose a finite input precision.
A guarded operation therefore has two layers:
 (1) a total primitive-recursive program, defined on every code and permitted to return a default
     outside the intended domain;
 (2) a correctness theorem under a positive rational margin certificate.
For inversion, a typical contract is

                    |x| ≥ 2−g ,   |x̃ − x| ≤ 2−m    =⇒       invm,g (x̃) − x−1 ≤ 2−q

when m ≥ q + 2g + c. The exact constant depends on the rational coding. The backward demand
edge for inversion is therefore q 7→ q + 2g + c.

12.2    Totalization theorem
Theorem 12.1 (Guarded totalization). Let a partial mathematical operation f have a finite
approximation algorithm whose correctness proof uses only a decidable guard G(x, g) and a primitive-
recursive demand d(q, g). Define the program on all codes by returning a fixed default when the
finite guard checker fails. Then the program is primitive recursive and iPRA proves

                  G(x, g) ∧ ValidX (x, d(q, g), a) −→ ValidY (f x, q, Runf (x, q, g, a)).

No correctness claim is made when G fails.

Proof. The guard checker and branch selector are primitive recursive, so totalization preserves
primitive recursiveness. Under the guard hypothesis, reflection shows that the successful branch
is taken. The theorem-specific quantitative estimate proves output validity. The failed branch is
irrelevant under the hypothesis. This pattern permits total terms in the language without weakening
the mathematical domain condition.

12.6    Projective and quotient data
Many singular choices disappear when the output is represented invariantly:
   • a line is a primitive integer or rational vector modulo nonzero scaling, with equality witnessed

   • a divisor or sheaf section is represented by finite local data and explicit overlap witnesses.

12.7    Exact branch data
Exact Puiseux coefficients or analytic branches require more than arbitrary Cauchy coefficients.

guarded.


13     The checked algebraic backend
13.1    Why this backend matters
Many packets reduce a theorem to a finite polynomial identity but then stop at a semantic ring
proof. The current Derivations library closes this gap for a substantial class of identities. It
derives arithmetic laws in the embedded theory, quotients terms by provable equality, embeds the
quotient semiring into a ring of differences, performs metalevel ring normalization, and reflects the
normalized equality back to Prf PRAAx.
This architecture is exactly compatible with KIFC-R. An algebra node stores an output equation
and a proof-producing tactic invocation. The equation can then be consumed by later search, loop,
or observer nodes through ordinary equality substitution.

KIFC-R for iPRA                                                                          2026-11-16


13.2    Provable-equality quotient
Fix a context Γ. Define s ∼Γ t when Γ ⊢ s = t. Reflexivity, symmetry, and transitivity are derived
in the deduction system; congruence follows from equality substitution. Thus ∼Γ is a congruence
for the derived addition and multiplication symbols. The quotient QΓ is a cancellative commutative
semiring because the corresponding laws and cancellation are proved in iPRA.
Natural-number terms embed into the Grothendieck ring G(QΓ ). Injectivity of the canonical map
follows from additive cancellation. An integer term is represented by a pair (p, n) denoting p − n,
and equality of integer terms is translated to the natural equality

                                          p + n′ = p′ + n.

Consequently, if a polynomial identity holds in G(QΓ ), injectivity yields an equality in QΓ , which
by definition is an object-level derivation.

13.3    Sound use of metalevel tactics
The tactic ipra_ring does not assert that ring normalization is an axiom of iPRA. Its proof term
has the following shape:
 (1) map each object term to its class in QΓ and then to G(QΓ );
 (2) use Lean’s ring tactic to prove equality in this metalevel ring;
 (3) apply injectivity to recover equality of quotient classes;
 (4) unfold quotient equality to obtain Γ ⊢ s = t.
The current axiom-audit module reports no sorryAx. It lists only Lean’s standard metatheoretic
axioms for quotients, choice, and propositional extensionality; the object theorem still depends only
on PRAAx.

A generic algebra node can be represented by:

are:

  • determinant and adjugate identities at fixed dimension;
  • integer-coordinate geometry identities;
  • finite combinatorial sum identities after recurrence expansion.
Not every algebraic theorem is a ring identity. Inequalities require order lemmas and often sums of
squares or explicit witnesses. Divisibility requires a witness term. Matrix statements of variable
dimension require loop invariants. The node interface is nevertheless useful: these stronger nodes
may call the ring backend for their local algebraic subgoals.

calculations reduce to polynomial identities and divisibility witnesses.

Height-bounded enumeration. A rational point is encoded by primitive integer tuples with

  (i) a bound H proved to dominate the height of every valid point;
 (ii) a finite complete duplicate-free list of all valid points.
The conversion from a list to a bound takes the maximum height (or zero for the empty list); the
conversion from a bound to a list is bounded enumeration and verification.

Proof. Given H, enumerate every canonical code of height at most H, retain exactly those satisfying
the verifier, and remove duplicates. Every retained item is valid by reflection. Every valid point has
height at most H, hence has a canonical code in the enumerated box and appears in the filtered list.
Conversely, given a complete list, take the maximum of the finitely many heights. Completeness
implies every valid point occurs and is bounded by that maximum. All operations are bounded
folds and searches, so their correctness is handled by section 6.

This theorem clarifies the Faltings/Siegel difficulty. The finite part of the proof is not the obstacle.
The obstacle is the uniform, effective, object-justified height producer.

Mordell–Weil descent. A Selmer class is not automatically a rational point on its covering. The
interface must return a finite relation of covering representatives with explicit local/global compati-
bility certificates. Backward viability can amalgamate a finite descent tree once such representatives
are supplied. A general uniform representative producer remains a separate mathematical problem.

Runge and explicit special cases. When geometry yields an explicit height inequality, the
complete proof fits the framework: derive the inequality using algebra nodes and guarded estimates,
compute H, enumerate, and verify. This is why Runge-type cases can be fully constructive even
when general Siegel remains open.

14.3    Real and complex analysis
Real names.      Use dyadic rational approximants with a regularity contract

                                       |ak − aℓ | ≤ 2−k   (ℓ ≥ k),

or a relational cloud plus theorem 11.3. Addition and multiplication have explicit demand trans-
formers. Inversion, logarithm, square root, and inverse trigonometric functions require guards.

Integration. A Riemann or quadrature approximation is a finite rational sum. The input
includes a modulus of continuity or derivative bounds and a tail/error theorem. The terminal query
determines a mesh size. The object proof consists of the finite sum identity, local cell estimates, and
a finite error sum. An “integrable” proposition without a modulus is insufficient for a uniform PR
integrator.

Power series. A series is consumed through a partial sum and a tail bound. Composition,
differentiation, or inversion requires explicit coefficient bounds and a radius/apartness guard.
Formal power-series identities are exact algebra nodes; analytic equality adds a finite tail estimate.

Contour arguments. Replace a contour by a rational polygonal path or a certified finite
parametrization, and replace integrals by quadrature with explicit error. Winding numbers are finite
integer computations under a positive distance-from-pole guard. Residue theorems then separate
into exact algebraic residue identities and quantitative approximation estimates.

Gamma, zeta, and special functions. Choose one finite representation—Euler products, alter-
nating series, Euler–Maclaurin sums, or contour quadrature—and attach explicit domain, truncation,
and error contracts. Functional equations become comparisons of two finite approximations with
common error budgets plus exact algebraic identities. Any hidden ineffective constant remains a
producer obligation.

14.4    Probability and limit theorems
A directly admissible probability object is a finite rational law. Expectations and moments are
finite sums. For triangular arrays or approximated laws, input data include tail, moment, and
quantization moduli. A central limit theorem suitable for iPRA states an explicit finite bound, such
as a Berry–Esseen inequality for rational variables with a displayed constant. CDF comparisons at
discontinuity points require anti-concentration or smoothing data. Weak convergence without a
modulus is retained as a finite-test or metastable contract.

14.5    Geometry
Coordinate algebra. Whenever possible, express the theorem as a polynomial identity in integer
or rational coordinates. The current ipra_ring backend already handles a meaningful class of
triangle identities.

Avoiding division. Use homogeneous coordinates, oriented determinants, squared distances, and
cross-multiplied ratio statements. Introduce a denominator only under a nondegeneracy/apartness
certificate.

Incidence and conics. A projective incidence theorem is a determinant identity plus rank/nonde-
generacy guards. Pappus, Pascal, Desargues, Ceva, and Menelaus are natural algebra-node targets
after suitable coordinate normalization.

Spherical and rotational geometry. Trigonometric quantities are finite names with error
contracts. Exact axes and inverse angles are guarded. At singular configurations, use rotation
matrices, quaternions modulo sign, or relations of admissible axes rather than a discontinuous
selected vector.

14.6    Linear algebra and spectral theory
Fixed-dimension determinant, adjugate, Cayley–Hamilton, and characteristic-polynomial identities
are algebra nodes. Variable dimension uses loops over indices with QF matrix-entry invariants.
Gaussian elimination is totalized: pivot search consumes a certified rank/pivot margin, or the output
is a relation of row-reduction branches.
For symmetric spectral theory, an unordered multiset of eigenvalue intervals is stable through
collisions. Ordered labels require a separation certificate. Eigenspaces are represented by approximate
projectors or finite relations of bases; a normalized eigenvector requires a simple-eigenvalue gap and
a sign/coordinate normalization guard.

14.7    Combinatorics and finite topology
Finite combinatorial identities are particularly well suited to KIFC-R. Objects are bounded codes,
predicates are decidable, and counting is primitive recursion. Bijections can be supplied as mutually
inverse PR maps with object-level inverse equations. Recurrences use QF induction.
Topological theorems should first be stated for finite simplicial or cubical complexes. Chains,
boundaries, parity, homology over finite coefficients, and carrier maps are finite matrix calculations.
Passage from a represented continuous space to a finite complex requires an approximation/nerve
producer with explicit mesh and separation data. The finite theorem and the approximation theorem
remain distinct contracts.

14.8    Algebraic geometry and sheaf-like constructions
Use finite affine presentations, ideal-membership witnesses, localization equalities with explicit
killing exponents, finite principal-open covers, and Cech tuples. A section is local finite data plus
overlap certificates. Gluing follows theorem 12.4; quotient equality is witnessed algebraically rather
than decided for arbitrary represented reals. General geometric finiteness theorems still require
effective degree/height bounds before enumeration.

14.9    Classical finite arguments
A finite decidable argument may be classically discovered and then checked constructively. The best
route is certificate extraction: a classical search tool produces a finite witness, and iPRA verifies it.
For theorem schemas whose conclusions are negative or stable, a negative-translation route may
also apply, but it should be formalized as a separate proof translation and not assumed globally.
Disjunction and existential conclusions require explicit recoverability, normally supplied here by
bounded decidability and least search.


15     Resolution of the reported difficulties
This section states what the framework actually resolves. A “resolution” may be a full generic
theorem, a correct reformulation under additional data, or a proof that the stronger requested

interface is unavailable.

15.1    Proof objects versus semantic theorems
Difficulty. A Lean file defines a proposition expressing the intended theorem and proves a semantic
fact about natural numbers, but no value of type Γ ⊢ [PRAAx]φ is constructed.
Resolution. Every node contains a local embedded derivation; theorem 8.2 composes them.
Loops terminate at IPRA.ind; algebraic identities terminate at the checked quotient/ring backend.
The verification gates in section 18 reject a theorem whose public conclusion is only a semantic
proposition.

15.2    Quantifiers in induction predicates
Difficulty. Correctness is phrased as “all entries processed so far satisfy P ”, leaving a bounded
universal quantifier in the induction matrix.
Resolution. Compile the prefix property to All and store the equation All(i) = 1. The recurrence for
the Boolean accumulator and its state invariant are quantifier-free. Fold reflection is applied outside
the induction matrix. The same pattern handles bounded existential search, table verification, path
checking, and finite covers.

15.3    All-precision invariants
Difficulty. An analytic loop tries to maintain correctness at every precision simultaneously.
Resolution. Treat the terminal precision as a parameter, propagate it backward through demand
transformers, and run one finite computation at the resulting requests. Universal quantification over
the terminal precision is introduced after the open QF-induction theorem has been constructed.

15.4    Coherent choices from approximate witnesses
Difficulty. For every precision there exists a valid approximant, but independently selected
approximants may oscillate or be incompatible.
Resolution. For a finite consumer, build the finite interaction tower and use backward viability.
For a genuine infinite name, require within-level diameter, adjacent motion, and a summable
tail modulus; then apply theorem 11.3. Without the tail data, retain a relational or metastable
conclusion.

15.5    Root ordering and algebraic branches
Difficulty. Ordered roots and branch labels are discontinuous at collisions. Exact Puiseux branches
are requested from arbitrary Cauchy coefficients.
Resolution. The unguarded presentation returns multisets, clusters, or finite relations of approx-
imate branches. Symmetric functions and cluster projectors are stable observers. Exact labels
require a certified separation/discriminant gap. Exact Puiseux coefficients require an exact algebraic
coefficient presentation and splitting data. The unrestricted selector is rejected as a representation
error rather than left as an unexplained formalization hole.




                                                  45
KIFC-R for iPRA                                                                            2026-11-16


Barrier 15.1 (No total exact branch selector near collision). A total operation that assigns one of
two colliding branches a persistent discrete label cannot be continuous at the collision. Therefore it
is not uniformly computable from ordinary Cauchy names, and no finite precision transformer can
validate it there.

Explanation. Consider the roots {−ε, ε}. At ε = 0 they coincide. Any label that distinguishes “left”
and “right” must swap when the sign of ε swaps, yet arbitrarily accurate finite observations near
zero cannot determine that sign without a positive lower bound. A computable operation to a
discrete label is locally constant on names determined by a finite prefix, contradicting this behavior.
A gap |ε| ≥ 2−g supplies the missing finite decision point.

15.6    Spectral vectors and rotation axes
Difficulty. A unique normalized eigenvector is requested at a repeated eigenvalue, or a unique
rotation axis is requested at the identity.
Resolution. Return invariant-subspace/projector data or a relation of admissible bases/axes. A
simple-eigenvalue gap plus a normalization margin recovers an exact eigenvector label. A distance-
from-identity guard recovers an axis; at the identity, the projective/quaternionic relation is the
correct object.

15.7    Mere nonzeroness in partial operations
Difficulty. Division or pivoting assumes x ̸= 0 but needs a finite stage at which nonzeroness is
visible.
Resolution. Consume an apartness witness g with |x| ≥ 2−g , totalize the program, and prove
correctness only under the guard. Mere negative nonzeroness remains a proposition and is not
treated as an algorithmic modulus.
Barrier 15.2 (No uniform extraction of apartness from negative nonzeroness). For general repre-
sented reals, a uniform procedure transforming x ̸= 0 into a numerical lower bound |x| ≥ 2−g would
validate a form of Markov-style search not available intuitionistically and would decide discontinuous
sign information.

15.8    Compactness and minimization
Difficulty. A proof invokes an arbitrary finite subcover, minimum, or convergent subsequence.
Resolution. Require a finite net producer, a coverage certificate, and a continuity/stability
modulus. Then finite search finds the least acceptable cell or approximate minimizer. If only
sequential compactness is available without a modulus, the result remains relational or metastable.

15.9    Faltings and Siegel
Difficulty. Finiteness of rational or integral points is treated as though it supplied a search cutoff.
Resolution. Theorem 14.1 proves that an effective height bound is exactly the missing finite-
search datum for a decidable presentation. The bounded enumerator, duplicate elimination, and
completeness proof are generic. The general height producer is isolated as an open mathematical
interface rather than hidden inside the framework.



                                                  46
KIFC-R for iPRA                                                                                  2026-11-16


Barrier 15.3 (Finiteness alone does not compute a cutoff). There is no computable procedure that,
from an index for a uniformly computably enumerable set known to contain at most one natural
number, always returns an upper bound for its possible member.

Proof. Given a program e, enumerate no number unless e halts; if it halts after exactly t steps,
enumerate t. The resulting set contains at most one number, uniformly in e. If a computable
bound H(e) were available, simulate e for H(e) steps. If it has not halted, it can never halt later,
because its halting time would be a member exceeding the bound. This decides the halting problem.
Therefore a bare cardinality/finiteness theorem is not a uniform height producer.

15.10     Mordell–Weil descent
Difficulty. A finite Selmer computation is followed by the assumption that every relevant class has
a rational covering point.
Resolution. The covering-point step is a bounded or finitely presented relation with explicit local
and global certificates. If a finite candidate set is supplied, viability and stable observation complete
the descent. A uniform producer of rational representatives for arbitrary coverings is not implied by
the Selmer cardinality computation and remains open.

15.11     Ineffective analytic constants
Difficulty. An asymptotic theorem or compactness argument asserts the existence of constants but
the algorithm needs them numerically.
Resolution. Put constants, thresholds, and error orders in the certificate. The generic verifier
checks the finite inequality. If the literature proof is ineffective, the packet can still state a conditional
theorem and identify the producer problem, but it cannot claim an unconditional PR algorithm.

15.12     Metastability
Difficulty. A finite stable-window theorem is silently upgraded to a Cauchy rate.
Resolution. Keep metastability as a first-class finite-use contract. A regular name is exported
only after an explicit tail modulus or shrinking-cloud theorem. This both preserves constructive
validity and lets finite consumers use the available theorem.

15.13     Classical arguments
Difficulty. A finite proof uses excluded middle, choice, or a contradiction argument without
explaining recovery of witnesses.
Resolution. Decidable bounded predicates admit constructive case splits and least witnesses.
Classical external tools may produce finite certificates that are checked intuitionistically. A general
negative-translation compiler is a separate formalization target; it recovers negative/stable conclu-
sions directly, while disjunctions and existentials require bounded decidability or an explicit witness
extractor.

17.1    Example A: a checked algebra node for Heron’s identity
The coordinate Heron theorem in the current derivation library defines integer-coordinate terms
for three points, twice the signed area D, and squared side lengths A, B, C. It proves the closed
universal form of
                            4D2 = 2AB + 2BC + 2CA − A2 − B 2 − C 2
by calling ipra_ring on the open identity and then applying universal closure.
As a KIFC-Rgraph this is a single algebra node. The input registers are the positive and negative
parts of the six integer coordinates. The output formula is the displayed integer equality translated
to a natural equality. The local derivation is inherited from Geometry/TriangleFormulas.lean. A
downstream geometry theorem may use the equality through Prf.eqSubst or wrap it in a guarded
square-root/area contract.
This example demonstrates the intended proof boundary: Lean’s ring tactic is used in the metatheory,
but the graph receives a checked Prf PRAAx derivation, not a semantic equality of Lean integers.

17.2    Example B: exact rational bisection for y 3 + y = x
Fix a rational input x. Set M = |x| + 1. For

                                         fx (y) = y 3 + y − x

one has fx (−M ) < 0 < fx (M ). Moreover, for a < b,

                           fx (b) − fx (a) = (b − a)(a2 + ab + b2 + 1) > 0.

The positivity of the second factor follows from

                           4(a2 + ab + b2 + 1) = (2a + b)2 + 3b2 + 4 > 0.

Thus there is at most one root and every sign bracket contains the same root in the observational
sense needed below.

State. Use integer-over-common-denominator codes for endpoints (ℓ, u). At step i, let m =
(ℓ + u)/2. Evaluate the exact rational sign of fx (m):
  • if fx (m) < 0, set ℓ := m;
  • if fx (m) > 0, set u := m;
  • if fx (m) = 0, set ℓ = u = m and keep the state fixed thereafter.
All operations are primitive recursive on signed integer/rational codes.

Invariant.   The QF invariant is the conjunction

                        ℓ ≤ u,   fx (ℓ) ≤ 0,   0 ≤ fx (u),   2i (u − ℓ) ≤ 2M,

together with well-formedness of the rational codes and a Boolean halted flag. Comparisons are
reflected Boolean equations. The base follows from the choice of M . Each step preserves the sign
bracket and halves the width unless the exact root is found, in which case the width becomes zero.

                                                   56
KIFC-R for iPRA                                                                              2026-11-16


Output contract.       After N = q + ⌈log2 (2M )⌉ + 1 steps, the midpoint rq satisfies

                                            |rq − y∗ | ≤ 2−q

for the unique root y∗ , expressed finitely as: every rational z satisfying fx (z) = 0 lies within 2−q of
rq . Existence of a completed real root need not be postulated in the loop. The nested intervals
themselves form a regular name, and completeness can be handled by the chosen representation
theorem.

Node decomposition. The graph uses algebra nodes for the monotonicity factorization and sign
arithmetic, Boolean nodes for comparisons, one loop node for bisection, and an observer node for
the midpoint. No relational choice is needed for exact rational x.

Cauchy input variant. If x is supplied only by approximations, the sign of fx (m) may be
undecidable near zero. A sound generalization keeps a finite relation of possible child intervals
whenever the interval evaluation contains zero. Backward viability removes branches incompatible
with later precision requests; the output midpoint is diameter-stable because all viable intervals
have certified small width. An exact branch is recovered only under a separation margin.

17.3    Example C: finite relational paths with dead ends
Let
                 A0 = {0, 1, 2},   A1 = {10, 11, 12},    A2 = {20, 21},    A3 = {30}.
Allow edges
                       0 → 10, 1 → 11, 2 → 12, 10 → 20, 11 → 21, 20 → 30.
Candidate 12 is an immediate dead end and 21 a later dead end. Local least choice would select 0
in this ordering and happen to succeed, but a harmless permutation could make it fail. Backward
viability gives
                       W3 = {30}, W2 = {20}, W1 = {10}, W0 = {0}.
The least viable path is forced: (0, 10, 20, 30). The reference test suite checks this example and
randomized finite towers against brute-force path enumeration.
In an object proof, each set is a bounded Boolean row. The recurrence is a reverse table loop. The
path is a bounded tuple code. The public theorem is the reflected path-checker equation, from
which the downstream terminal rule is cut.

17.4    Example D: a stable symmetric root observer
Suppose a quadratic certificate returns either ordered pair (a, −a) or (−a, a). The witness order is
non-canonical. The observer
                                     O(r1 , r2 ) = (r1 + r2 , r1 r2 )
is exactly stable: both orders produce (0, −a2 ). Least search may choose either certificate according
to its code order; theorem 11.1 proves that the public coefficient output is independent of this choice.
The pattern scales to unordered polynomial roots: elementary symmetric functions, discriminants,
power sums, and factor coefficients are stable observations even at collisions. Individual roots are
not.

17.5    Example E: complete Diophantine enumeration from a height bound
Let F (X, Y ) ∈ Z[X, Y ] be fixed and suppose a producer proves that every integer solution has
|x|, |y| ≤ H. Enumerate the square [−H, H]2 , evaluate F , and retain exactly the zeroes. The loop
invariant records:
 (a) every stored pair lies in the processed prefix and satisfies F = 0;
 (b) every processed solution appears in the stored list;
 (c) the list is duplicate-free.
Each clause is stored as a Boolean fold/table equality, so the combined invariant is QF. At the end,
the height hypothesis turns prefix completeness into global completeness.
For rational points, enumerate primitive triples or normalized numerator/denominator tuples and
use cross-multiplied polynomial equations. Duplicate elimination uses a decidable normalized-code
equality.

17.6    Example F: a finite-net maximum bound
Suppose f : [0, 1] → R has a supplied modulus m, and for target q take the dyadic grid of mesh
2−m(q+3) . Assume certified evaluations vj with error at most 2−q−3 . Let j∗ be the least index
maximizing vj , found by bounded argmax. For any x, choose the least covering grid cell j. The
modulus and evaluation errors give

                                    f (x) ≤ vj + 2−q−2 ≤ vj∗ + 2−q−2 .

Thus vj∗ + 2−q−2 is a certified approximate supremum. A unique maximizer is not claimed. Under
a strict isolation gap, guarded argmax recovers a stable cell label.

predicate
                           P (n) = Alli,j∈[n,F (n)] d(xi , xj ) ≤ 2−k .

Given a metastability bound B(k, F ), least search below B + 1 finds the first valid n. The consumer
proceeds with that finite window. Nothing in the theorem asserts a global rate N (k), so the

A.1     Variable order
The proposed Lean library should fix conventions globally:
    • loop formulas: variable 0 is time/state focus, followed by state components and external
      parameters;
    • relation formulas: variable 0 is the current candidate, variable 1 the next or comparison
      candidate, followed by query and parameters;
    • observer formulas: two candidate blocks first, then query and parameters;
    • rational metric formulas: numerator/denominator components are grouped and accessed
      through named substitutions.
Named substitution helpers should be proved once. Ad hoc Fin.cases expressions are a major
source of binder errors.

A.2     Rational codes
A convenient exact rational code is a signed integer numerator and a positive natural denominator.
Normalization is optional for arithmetic, but equality is cross multiplication. Every theorem that
divides by a denominator carries its positivity proof. Dyadic codes may use a signed numerator and
exponent; comparisons are reduced to a common exponent.

A.3     Bounds
All bounds are exclusive unless explicitly stated. “Search below B” means candidates 0, . . . , B − 1. A
finite relation may totalize invalid out-of-range cells as false. This convention simplifies rectangular
table encoding.
