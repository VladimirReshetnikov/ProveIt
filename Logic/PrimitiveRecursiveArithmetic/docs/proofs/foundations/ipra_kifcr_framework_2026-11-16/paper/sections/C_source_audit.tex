\subsection{Audit limitations}

A full repository clone and Lean build were unavailable in the artifact container.  The audit used repository API reads of current files and therefore did not independently compile every current module or packet.  The generated Lean files are consequently marked as outlines.  Inherited checked claims are based on the current source types and axiom-audit declarations; packet-specific deep claims remain targets or residual producers unless an actual checked derivation was inspected.
