\subsection{Validation layers}

The archive distinguishes five kinds of evidence.
\begin{enumerate}[label=(\arabic*)]
  \item \textbf{Inherited checked derivations.}  These are existing current-repository theorems whose endpoint is \(\Prf\,\PRAAx\), including search and pairing.  They were inspected through the pinned source interface; this artifact did not rebuild the whole repository.
  \item \textbf{Human mathematical proofs.}  The PDF gives the finitary arguments and their induction/representation audits.
  \item \textbf{Source-oriented Lean outlines.}  The archive gives structures, definitions, target signatures, and a dependency order.  Lean is not installed in the artifact environment, so no new-module compilation is claimed.
  \item \textbf{Exact executable evidence.}  Python uses integers and \texttt{Fraction}, tests success and failure cases, and compares viability/closure algorithms with brute force on finite instances.
  \item \textbf{Artifact validation.}  The PDF is compiled, preflighted, text-inspected, rendered, and visually audited; JSON and checksums are validated.
\end{enumerate}

\subsection{What the framework resolves}

At the generic level, the framework resolves:
\begin{itemize}
  \item how to keep all bounded content out of QF induction matrices;
  \item how to reuse checked bounded search and simultaneous recursion;
  \item how to compose local object proofs into a theorem-specific global derivation;
  \item how to represent unavailable producers without overstating the result;
  \item how to compute least acyclic or capped cyclic finite demands;
  \item how to use a finite relation without global choice;
  \item how to erase witness choices through exact or metric stability;
  \item how to isolate guards, finite nets, and height cutoffs as explicit quantitative inputs.
\end{itemize}

\subsection{What remains theorem-specific or open}

This report does not claim:
\begin{itemize}
  \item a general effective Faltings, Siegel, Roth, or Mordell--Weil generator;
  \item effective Chebotarev, Siegel--Walfisz, or Bombieri--Vinogradov constants beyond whatever explicit estimates are separately supplied;
  \item exact Puiseux labels from arbitrary Cauchy-presented coefficients across singular fibers;
  \item a spectral gap or eigenvector label at repeated eigenvalues;
  \item a Cauchy modulus from metastability alone;
  \item a universal PR evaluator or internal theorem compiler;
  \item a completed checked generic \KIFCR\ library in the current repository.
\end{itemize}
For these targets, the report identifies the finite verifier/composition theorem and the exact residual producer formula.  This is genuine progress: all avoidable coding and logical ambiguity is removed, while the remaining mathematical content is stated with the right quantifier order.

\subsection{Required ledger for migrated packets}

A packet migrated to the framework should record:
\begin{enumerate}[label=(\arabic*)]
  \item the exact object formula and external interpretation;
  \item every numerical representation and totalization convention;
  \item the fixed PR symbols or generated terms;
  \item the local rule list, distinguishing inherited checked proofs, new checked proofs, outlines, and residual boundaries;
  \item every induction call and its QF witness;
  \item acyclic and cyclic demand tables, caps, and overflow obligations;
  \item witness mode: deterministic, relational, exact-stable, diameter-stable, projective/quotient, or gap-guarded;
  \item all moduli, margins, heights, cover data, and effective constants with their producer/verifier status;
  \item clean build, absence of \texttt{sorry}, and axiom audit;
  \item exact tests, labeled as tests rather than proof.
\end{enumerate}
