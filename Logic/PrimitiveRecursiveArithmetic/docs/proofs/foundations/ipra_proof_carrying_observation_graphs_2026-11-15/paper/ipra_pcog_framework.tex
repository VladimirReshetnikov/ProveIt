\textbf{Status.}
The mathematical arguments in this report are human proofs.  The accompanying
Python code is exact finite regression evidence and is not an arithmetic proof
checker.  The Lean files give a repository-specific implementation path and a
small proof-composition core, but were not elaborated in this artifact
environment because no Lean executable was available.  Existing declarations
reported as kernel-checked are cited as inherited repository facts; no new
headline theorem is represented as kernel-checked here.
\end{minipage}}
\end{center}
