\section{Boundaries, resolved obstacles, and research program}
\label{sec:boundaries}

A useful framework must state not only what it proves but what it refuses to
hide.  The following boundaries are structural, not temporary omissions in
exposition.

\subsection{Resolved at the framework level}

The report gives complete human arguments for the following generic problems.

\begin{enumerate}
\item \textbf{Bounded formula compilation.}  Fixed strictly bounded formulas
have PR Boolean checkers with iPRA reflection proofs.
\item \textbf{Uniform finite traces.}  Base and step object derivations compile
to an invariant at arbitrary PR fuel.
\item \textbf{Acyclic proof composition.}  A fixed graph of proof-producing
rules compiles by a topological fold.
\item \textbf{Precision composition.}  Monotone local demands have a least
safe backward assignment and support a valid forward run.
\item \textbf{Finite relational choice.}  Backward viability and least bounded
search produce finite paths without infinitary choice.
\item \textbf{Coherent approximate names.}  Shrinking viable clouds and a
summable motion budget yield a PR Cauchy modulus.
\item \textbf{Exact branch recovery.}  A positive finite gap turns an
approximate relation into a unique stable label.
\item \textbf{Fixed-dimensional termination.}  Mixed-radix rank gives PR fuel
for bounded lexicographic descent.
\item \textbf{Simultaneous finite stability.}  Finite exceptional-set budgets
yield a common good index.
\item \textbf{Effective finite sets.}  For decidable coded objects, an explicit
height bound and a complete finite list are interconvertible.
\end{enumerate}

Together these results are broad enough to cover the common computational
skeleton of the proof collection.

\subsection{Not resolved by a general compiler}

The following remain theorem-specific or impossible in the proposed uniform
form.

\paragraph{General effective Faltings and Siegel.}
The framework does not produce the missing global height or cover bounds.  It
turns such a bound into a complete list and verifies all downstream steps.

\paragraph{Uniform Mordell--Weil generators.}
The framework can verify a supplied descent cover and generator list, and can
run bounded reduction.  It does not construct the general covering package
from arbitrary input curves.

\paragraph{Deep prime-distribution estimates.}
Finite sums and rational inequalities are formalizable, but zero-free regions,
density estimates, exceptional zeros, and effective constants remain the
substantive analytic nodes.

\paragraph{Exact singular branch selection.}
A finite cloud of branch jets is available; a uniform exact selector from
arbitrary Cauchy coefficient names is not claimed.  Isolation data permits a
guarded selector.

\paragraph{Metastability-to-modulus conversion.}
Finite stable windows do not generally yield a computable Cauchy rate.  A
separate quantitative theorem is required.

\paragraph{Cardinality-to-cutoff conversion.}
A finite cardinality bound does not generally yield a search height.  The
compiler demands an actual bound, list, or finite cover.

\paragraph{Universal PR evaluation.}
No total PR evaluator for arbitrary encoded PR programs is used or sought.
The compiler specializes graph syntax at the host level.

\subsection{Strength of the base theory}

The framework is designed to stay within iPRA because all induction invariants
are quantifier-free and all algorithms are primitive recursive.  A particular
application may nevertheless require a theorem not provable at this strength.
The right response is not to obscure the dependency, but to label the producer
node with the stronger assumption or theory and keep the finite compiler layer
separate.

This modularity also supports conservation results.  If a producer theorem can
be shown conservative over iPRA for the relevant first-order statement, the
rest of the graph need not change.

\subsection{Proof size and generated code}

A staged compiler can generate large \texttt{PR} syntax and proof terms.
Several optimizations preserve the mathematics.

\begin{itemize}
\item Share common subterms and predecessor nodes at the graph level.
\item Use table checkers rather than nested formula conjunctions.
\item Compile fixed dispatch through balanced decision trees.
\item Normalize terms only at module boundaries.
\item Prove generic table and Boolean lemmas once, then instantiate them.
\item Keep subject-specific algebra in certificate checkers when direct
symbolic proofs would explode.
\end{itemize}

A small trusted checker for graph certificates can help generate Lean source,
but the generated \texttt{Prf} term must remain the final authority.

\subsection{Recommended repository integration}

The proposed integration order is:

\begin{enumerate}
\item move the checked local-global trace rule into the core Lake library;
\item move the checked stable-observation combinators likewise;
\item add the minimal \texttt{Rule}/\texttt{Compiled} graph module;
\item complete Boolean folds and least search;
\item integrate the existing term and backward-demand compilers;
\item prove finite table and viability theorems;
\item complete the cubic benchmark as an actual closed
\texttt{Prf PRAAx} theorem;
\item migrate one medium theorem packet to PCOG normal form;
\item only then automate graph generation broadly.
\end{enumerate}

The cubic benchmark is intentionally chosen to exercise guarded inversion and
backward demand, not merely a trivial counter loop.  A successful closed proof
would validate the architecture before applying it to large theorem packets.

\subsection{Criteria for a completed application}

A theorem packet using this framework should be considered complete only when:

\begin{enumerate}
\item the public first-order formula is written explicitly;
\item all fixed algorithms are emitted as \texttt{PR} syntax;
\item every recursive component has a quantifier-free invariant;
\item every local contract is an object derivation;
\item all producer assumptions are named and none is disguised as a verifier;
\item every unstable choice remains relational or has a gap proof;
\item the final declaration has type \texttt{Prf PRAAx [] phi};
\item the root build and axiom audit succeed.
\end{enumerate}

Human-complete mathematics plus a precise Lean path remains valuable before
this endpoint, but its status must be stated accurately.

\subsection{Conclusion}

The proof collection already contains many of the mathematical ideas needed to
embed serious finite and quantitative mathematics into iPRA.  The main missing
piece is organizational and formal: a reusable construction that consumes
local object proofs rather than semantic assurances.  Proof-carrying
observation graphs provide that construction.

The framework's central discipline is simple:

\begin{quote}
compile fixed syntax, prove local contracts, retain non-unique data
relationally, propagate demands backward, execute traces forward, and compose
only actual embedded derivations.
\end{quote}

Following this discipline does not make every classical theorem effective or
provable in iPRA.  It does something more precise: it exposes the exact finite
content of a proof, resolves the recurring coding and composition obstacles,
and leaves the genuinely deep producer theorem as a small, honest interface.
