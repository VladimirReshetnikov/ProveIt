\subsection*{Logical conventions}

All existential searches described as algorithms are bounded.  When an
unbounded first-order existential occurs in a public theorem, its witness is
usually a value of a named PR producer, so existential introduction is direct.
No use is made of countable choice.  Classical reasoning about arbitrary
propositions is not used in the compiler theorems; Boolean case splits concern
predicates already equipped with reflection.

\subsection*{Metric conventions}

Metric observations are rationally coded.  Statements involving a completed
real object are shorthand for first-order inequalities between its finite
names.  Infinite sums in human estimates are used only when accompanied by a
primitive-recursive finite-tail modulus that becomes the actual arithmetic
statement.
