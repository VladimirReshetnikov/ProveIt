RESULT
------
The corrected Python implementation passed an independent run of
  python3 -B test_certificates.py
with exit code 0: all 14 exact implementation checks passed.
The packaged code/test_results.txt reports the same current count.

One actual defect was found and corrected before this receipt:
the evaluator cached intervals by Python object id without retaining the
expression. Reusing one evaluator on temporary rat(n) roots could read a
stale cached interval after object-id recycling (reproduced at n=2).
The code author changed the cache to retain (Expr, Interval) pairs, checks
object identity on retrieval, and added a regression covering 100 temporary
roots. The independent 14-check run includes that regression.

MANUAL MATHEMATICAL CHECKS
-------------------------
- Polynomial coefficient/degree bounds and the emitted expression agree
  with the report's displayed compiler.
- Interval multiplication checks all four endpoint products.
- Absolute value and the dependent |v|-v interval use correct images.
- Directed dyadic rounding is outward for both signs.
- Machin's formula uses correctly oriented alternating arctangent bounds.
- Sine truncation has a finite primitive recursive upper bound.
  At j >= max(r^2, bits+5, 1),
    (2j+1)! >= 2^(j-1) (j+1)^(j+1),
    r^(2j+1) <= (j+1)^(j+1).
  Hence the first omitted absolute term is <=2^(1-j), twice that term
  is <=2^(-bits-3), and its tail ratio is <=1/2.
  The implemented limit r^2+r+bits+8 includes such an index.
- The B,W recurrences correctly propagate endpoint magnitudes and interval
  widths, provided W_root * 2^(-work_bits) <= 1.
- All parent W bounds dominate their child bounds.
- The predetermined working precision meets the final width target.
- Decimal strings are display-only; exact rational endpoints determine
  certificate validity.
- There is no unbounded search in the Python approximation routines.
