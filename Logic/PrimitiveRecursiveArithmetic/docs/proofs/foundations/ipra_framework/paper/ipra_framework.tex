\begin{abstract}
We develop a reusable arithmetic interface for finite mathematical objects,
fixed primitive recursive approximation families, and certified numerical
constructions.  Its core is a direct proof of bounded-formula
Booleanization, a guarded bounded-loop rule, and composition of finite
observation contracts.  Every induction is reduced to a quantifier-free
invariant, while global hypotheses remain explicit first-order assumptions.

Applications include an explicit stable-window selector for represented
monotone sequences; a convergent implicit power-series branch for arbitrary
primitive recursive Cauchy coefficients on a certified regular chart,
including a primitive recursive certificate producer from simple-root
data; and an all-exponent power-gap theorem giving integral-point height
bounds, a certificate constructor, bounded-denominator transport, and a
complete uniform family classification.

The report distinguishes these results from the genuine remaining
obstructions in the source collection.  Compiled Lean lemmas, an actual
embedded iPRA induction proof, executable exact-arithmetic reference code,
and precise unproved Lean targets accompany the full written arguments.
The general compiler and the object-theory derivations of the major
applications remain explicit formalization tasks.
\end{abstract}
