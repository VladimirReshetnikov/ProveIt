\section{Further research questions}\label{sec:research}

\begin{enumerate}
  \item Can \RepoPath{OpenContract.lean} be admitted as a tiny common core and used to replace the several context-fixed conditional records already present in proof packets?
  \item What is the smallest checked reflected-formula library that covers equality, order, bounded folds, and fixed strategy certificates without introducing a universal syntax evaluator?
  \item Can proof-producing graph compilation be implemented as a Lean elaborator with deterministic source and a machine-checked residual-minimality theorem?
  \item Which existing packet is the best benchmark for the first full end-to-end generated \(\Prf\,\PRAAx\) theorem: rational bisection, a finite-net inequality, or a bounded combinatorial game?
  \item Can strategy certificates be DAG-compressed while retaining a simple primitive-recursive checker and reflection theorem?
  \item Which relational applications require a genuine coherent path, and which can be reformulated entirely through stable observers or quotient data?
  \item Can the diameter/motion/tail theorem be factored into a checked rational-metric core reusable by analysis, probability, root approximation, and dynamical systems?
  \item Can capped demand closure infer safe caps from syntactic majorants often enough to eliminate cap-adequacy residuals in routine applications?
  \item Can the Foundation bridge expose a public open-contract transport theorem that preserves arbitrary finite contexts and parameters while keeping its import closure independent of Busy Beaver and Diophantine applications?
  \item How much of the existing checked probability, Fubini, linear-algebra, and number-theory library can be registered automatically as contract nodes with generated provenance?
  \item Is there a useful proof-cost semantics on contracts that predicts generated term size and guides sharing, without entering the object theory?
  \item Can a library of producer interfaces clarify the exact effective content of difficult theorems such as Faltings, Siegel, Mordell--Weil, compactness principles, or prime-distribution estimates?
\end{enumerate}
