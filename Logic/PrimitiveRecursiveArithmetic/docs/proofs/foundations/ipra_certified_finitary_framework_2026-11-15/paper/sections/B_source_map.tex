\subsection*{Relationship to earlier framework packets}

This report does not replace the existing packets.  It consolidates them and
changes the recommended implementation order in three ways:
\begin{enumerate}[label=(\arabic*)]
\item it reduces the proposed trace compiler to the already checked
      primitive-recursion invariant transformer;
\item it promotes direct stable-observable choice erasure ahead of path-based
      coherence; and
\item it gives metastability a positive finite-consumer interface while
      retaining the impossibility of a general Cauchy-rate conversion.
\end{enumerate}

The included theorem ledger distinguishes inherited checked components,
human-complete generic arguments, executable finite tests, Lean blueprints, and
open producer obligations.
