\section{Further research questions}
\label{sec:research}

\begin{enumerate}[label=\textbf{Q\arabic*.}]
\item \textbf{Complete the trace endpoint.}  Can the formula-identification
      proof that reduces \code{traceReflection} to
      \code{primitiveRecursionAt} be completed with a small stable set of
      substitution lemmas and no new axioms?

\item \textbf{Generate object proofs from a bounded DSL.}  What is the smallest
      typed program syntax whose compiler covers the majority of existing
      packets while keeping generated \(\Prf\) terms manageable?

\item \textbf{Proof-term sharing.}  Can repeated fold and arithmetic lemmas be
      referenced compositionally, or must generated derivations duplicate
      large subterms?  What proof-size compression is compatible with the
      native scalar calculus?

\item \textbf{Canonical representation library.}  Which pair, list, integer,
      rational, polynomial, matrix, and finite-map encodings minimize both
      proof complexity and checker implementation size?

\item \textbf{Automated Booleanization.}  Can a verified syntax compiler turn a
      bounded \(\Fm\) formula into a \(\PR\) checker and simultaneously produce
      the equivalence derivation?

\item \textbf{Demand inference.}  Can precision demands and error ledgers be
      inferred compositionally from certified arithmetic operators, including
      adaptive branches and finite query lists?

\item \textbf{Stable-observable detection.}  Can application developers be
      guided automatically to prove certificate independence before building a
      more expensive viability construction?

\item \textbf{Finite Hausdorff kernel.}  What is the most economical object
      theory for finite sets, matchings, clusters, and Hausdorff bounds that
      supports roots, spectra, compact sets, and probability laws uniformly?

\item \textbf{Metastable consumer compiler.}  Can a consumer trace automatically
      synthesize its control function \(G\), either by worst-case finite search
      or from a verified query-log certificate?

\item \textbf{Domain migration.}  Which existing packets can be completed most
      quickly after the common kernel: exact polynomial algebra, finite sums,
      square-root intervals, matrix invariants, finite nets, or path viability?

\item \textbf{Producer complexity.}  For certificate-relative theorems, what
      natural complexity classes of producers can themselves be represented in
      iPRA, and when is an external producer with internal verification the
      correct final architecture?

\item \textbf{Arithmetic geometry.}  Can restricted families of curves admit
      primitive-recursive height producers or rational-covering certificates
      even though no general producer is currently available?

\item \textbf{Analytic constants.}  Which classically ineffective theorems can
      be reformulated as uniform finite certificate verifiers with useful
      conditional computational content?

\item \textbf{Native-code target.}  After completing an ordinary iPRA proof,
      how much can \code{pra\_iff\_native} and the native round-trip theorems
      reduce the final proof checker and proof object sizes?

\item \textbf{Independent verification.}  Can a second small checker, perhaps
      extracted from the native calculus, validate the generated proof
      artifacts independently of the main Lean development?
\end{enumerate}
