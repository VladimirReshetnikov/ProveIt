\appendix
\section{Exact generic theorem interfaces}
\label{app:interfaces}

This appendix collects the framework's central interfaces in a form suitable
for translation into \(\Fm\,\PTm\) formulas.

\subsection{Boolean fold interface}

For each fixed \(b:\PR(r+1)\), provide symbols
\(\All_b,\Any_b,\Search_b\) and derivations of:
\begin{align*}
&\All_b(0,\bar x)=1,\\
&\All_b(n+1,\bar x)=\mathsf{and}(\All_b(n,\bar x),b(n,\bar x)),\\
&\Any_b(0,\bar x)=0,\\
&\Any_b(n+1,\bar x)=\mathsf{or}(\Any_b(n,\bar x),b(n,\bar x)),
\end{align*}
plus the bounded logical equivalences and least-search specification of
\cref{thm:fold-correct}.

\subsection{Trace interface}

A \code{PRTraceSystem} has symbols of arities \(1,1,1,3,3,2\).  Its proof
record contains:
\begin{align*}
[]&\vdash[\PRAAx]G(u)\to I(0,\mathsf{init}(u),u),\\
[]&\vdash[\PRAAx]G(u)\to I(i,s,u)\to
 I(i+1,\mathsf{step}(i,s,u),u),\\
[]&\vdash[\PRAAx]G(u)\to I(\mathsf{bound}(u),s,u)\to A(s,u).
\end{align*}
The compiler returns
\[
 []\vdash[\PRAAx]\forall u\,[G(u)\to
 A(\Run(\mathsf{bound}(u),u),u)].
\]

\subsection{Demand interface}

For a fixed \(D:\PR 2\), define a schedule symbol \(h:\PR 3\) and derive:
\begin{align*}
 h(N,k,N)&=k,\\
 t<N&\to h(N,k,t)=D(t,h(N,k,t+1)).
\end{align*}
For a quantifier-free \(P(t,r)\), the proof package supplies the specialized
base and local transfer derivations and returns \(P(N,k)\).

\subsection{Relational interface}

For fixed \(B,\Good,\Compat\), define \(\Viable\), \(\mathsf{Reach}\),
\(\FullV\), a path checker, and a least-path constructor.  Public object
formulas state:
\begin{align*}
\Viable(p,k,d,a)=1&\leftrightarrow
  \exists c<C(p,k,d)\;\mathsf{PathOK}(p,k,d,a,c)=1,\\
\FullV(p,h,k,a)=1&\leftrightarrow
  \mathsf{Reach}(p,k,a)=1\wedge\Viable(p,k,h-k,a)=1,\\
\Viable(p,k,d,a)=1&\to
  \mathsf{PathOK}(p,k,d,a,\mathsf{leastPath}(p,k,d,a))=1.
\end{align*}
The logical existential is derived from the bounded search checker; the
induction itself is on Boolean equations.

\subsection{Stable-observable interface}

For finite certificates, the assumptions are:
\begin{align*}
&\forall p,n\;\Any_{a<C(p,n)}\mathsf{Cert}(p,n,a)=1,\\
&\forall p,n,m,a,b\;[a<C(p,n)\wedge b<C(p,m)\wedge
 \mathsf{Cert}(p,n,a)=1\wedge\mathsf{Cert}(p,m,b)=1]\\
&\hspace{35mm}\to
 d(\Obs(p,n,a),\Obs(p,m,b))\le E(p,n,m).
\end{align*}
The derived selector theorem substitutes the least valid candidates.  A modulus
formula then yields the regular-name contract.

\subsection{Shrinking interface}

The assumptions are object derivations of cloud nonemptiness, horizon
monotonicity, cloud diameter, edge motion, and rational pseudometric laws.  The
conclusion is the finite inequality
\[
 d(x(p,k),x(p,\ell))\le
 \varepsilon(p,k)+\Tail(p,k,\ell)
\]
under \(k\le\ell\).  A separate tail-modulus derivation produces a regular-name
formula.

\subsection{Finite-consumer metastability interface}

A consumer package contains a trace, a query-bound proof
\(q_i\in[N,N+G(N)]\), and a local soundness derivation from pairwise stability
of all recorded queries.  The metastability package supplies either:
\begin{enumerate}[label=(\alph*)]
\item a bounded witness checker and nonemptiness derivation, permitting least
      search and a computed output; or
\item an existential witness derivation, permitting an existential output
      theorem by \code{Prf.exE}.
\end{enumerate}
The interface deliberately distinguishes these conclusions.

\subsection{Height/list interface}

A height presentation supplies a code bound \(C(p,H)\) covering every object of
height at most \(H\), a decidable object predicate, list operations, duplicate
removal, and finite maximum.  The two certificate transformations are:
\begin{align*}
 \mathsf{HeightBound}(p,H)&\to
 \mathsf{CompleteList}(p,\mathsf{enumerate}(p,H)),\\
 \mathsf{CompleteList}(p,L)&\to
 \mathsf{HeightBound}(p,\mathsf{maxHeight}(L)).
\end{align*}
No transformation from a cardinality bound is included.
