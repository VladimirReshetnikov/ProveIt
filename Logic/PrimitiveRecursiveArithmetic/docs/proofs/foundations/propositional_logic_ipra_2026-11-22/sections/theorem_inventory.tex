\section{Numbered result inventory}\label{sec:inventory}
The report contains 64 numbered results: theorems, lemmas, propositions,
and corollaries. Several statements package multiple laws or uniform
schemes. This count does not treat every substitution instance, every row
of a truth table, or each executed test as a separate theorem. The small
countermodels and additional derived rules in the prose are not separately
numbered. All entries below have developed human proofs. The final compactness
entry is a finite coding reduction and an external scope comparison; it
does not assert infinite-path existence in iPRA. The accompanying
Lean implementation is an uncompiled outline, with the large numerical
object-derivation endpoints still to be implemented.
