A Kernel-Facing Finite-Use Framework
for Mathematics in Intuitionistic Primitive Recursive
Arithmetic
Proof-carrying DAGs, bounded relational choice, stable observables,
and explicit boundaries for difficult mathematics
Prepared for Vladimir Reshetnikov
15 November 2026

Abstract
The current Logic/PrimitiveRecursiveArithmetic tree of the ProveIt repository contains
a kernel-checked foundation and a large collection of research packets spanning algebra, analysis,
geometry, topology, number theory, probability, category theory, and mathematical physics. The
packets share a productive finitary methodology—codes, bounded traces, finite certificates, rational
approximations, and explicit resource budgets—but many stop one level before the formal target:
they establish a host-language fact or design a semantic algorithm without constructing a derivation
of the repository’s deep-embedded judgment
Γ ⊢PRAAx φ.
A recent contract-DAG packet identifies the right architecture but leaves its generic object compiler
schematic.
This report develops a kernel-facing finite-use framework that closes that generic logical layer. A
proof-carrying reverse-topological schedule records, for each node of a fixed finite contract graph, an
actual local Prf PRAAx derivation from earlier nodes. Simultaneous cut compiles a new node, and
finite iteration compiles the whole graph. A separate quantifier-free loop theorem packages the sole
induction needed for bounded traces while permitting a quantified terminal result. Bounded search
and backward viability eliminate hidden finite choice; stable-observable comparison eliminates the
need for coherent representatives; exact branch selection is permitted only under an explicit gap;
and genuinely global or ineffective mathematics is isolated as a boundary theorem rather than
misrepresented as an algorithm.
The main arguments are given in full at the human level. The archive includes Lean modules
whose generic conclusions have the actual embedded Prf PRAAx type, a dependency-ordered
formalization plan, a conservative Lean schedule generator, exact Python reference algorithms, and
independently checked certificates. Lean was unavailable in the build runtime, so source without
placeholders is supplied but not claimed to have been typechecked. The framework does not
manufacture missing height bounds, convergence moduli, separation estimates, or effective forms of
deep global theorems; it makes those obligations precise and composable.
