\subsection{Claims deliberately not made}

The following are not counted as results of this archive:
\begin{itemize}
  \item compilation of the supplied Lean files;
  \item a generic verified implementation of every \texttt{BForm} constructor;
  \item automatic migration or verification of the 78 repository packets;
  \item a new effective theorem supplying general Diophantine height bounds;
  \item exact branch choice without a separation theorem;
  \item a proof that the Python implementation and future Lean implementation are extensionally identical;
  \item historical priority for the broad ideas of finite certificates, demand propagation, dynamic
        programming, or proof-producing compilation.
\end{itemize}

\subsection{Source relationship}

The report consolidates ideas already present in the repository---finite observations, producer/verifier
separation, contract graphs, reverse demand, bounded traces, relational viability, stable observables,
resource ranks, and finite algebra---but changes the center of gravity.  The principal new synthesis is to
make \emph{arity normalization by checked proof substitution} the front door to the graph compiler.  This
addresses the concrete mismatch between local application lemmas and one global theorem frame, and it
reduces the generic trusted code to operations already proved in \texttt{Deduction.lean}.

\subsection{Artifact validation}

The package's Python validation performs eight test groups:
\begin{enumerate}
  \item bounded least search and complete filtering;
  \item mixed-radix rank and lexicographic descent;
  \item finite-box demand closure and error cases;
  \item static proof-schedule validation and dependency rejection;
  \item backward viability and least successful paths;
  \item exact and diameter-stable observables;
  \item height/list conversions;
  \item exact rational cubic bisection.
\end{enumerate}
The tests use only the Python standard library.  The build script also checks that the Lean sources contain
no admitted theorem keywords, compiles this PDF when \texttt{pdflatex} is available, verifies the manifest,
and writes validation logs.  These checks increase reproducibility but do not replace Lean kernel checking.
