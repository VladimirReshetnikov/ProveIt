The current \texttt{PrimitiveRecursiveArithmetic} subtree contains a checked Lean implementation of ordinary intuitionistic primitive recursive arithmetic and its native scalar presentation, together with a large collection of unverified research packets proposing finite observations, contracts, demand propagation, relational witnesses, and quantitative versions of classical mathematics.  The packets have converged on the correct mathematical philosophy, but most stop one level too early: they prove a host-language statement, or specify an arithmetic invariant, without constructing the final object-theory judgment
\[
   \Gamma\;\vdash_{\PRAAx}\;A.
\]
This report consolidates their reusable ideas into a small framework whose central operation is \emph{arity-normalized staged specialization}.  Every local theorem is first instantiated into one fixed global parameter frame by the already checked substitution theorem for \(\Prf\), then aligned by weakening, and finally composed by simultaneous cut.  Recursive nodes alone invoke quantifier-free induction.  The graph is traversed at Lean elaboration time, so the object theory receives only concrete primitive-recursive symbols and proof terms; no universal evaluator is postulated.

The framework also identifies boundaries that notation cannot remove: exact branch selection needs a gap or branch-invariant output; a cardinality bound is not a height bound; and ineffective global constants must remain explicit producer data.
