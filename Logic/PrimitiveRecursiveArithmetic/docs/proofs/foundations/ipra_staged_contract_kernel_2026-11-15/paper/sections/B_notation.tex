\paragraph{Logical convention.}
All searches described as algorithms are bounded.  An unbounded existential in a public theorem is normally
introduced with the value of a named primitive-recursive producer.  Relational theorems retain the
existential only when no canonical selector is mathematically justified.  No countable choice is used.

\paragraph{Metric convention.}
Distances and error bounds are rational codes.  Statements about limits, real numbers, or completed metric
objects abbreviate families of finite rational inequalities with explicit moduli.  Infinite sums in human
estimates are replaced in the object theorem by finite partial sums and a primitive-recursive tail bound.

\paragraph{Uniformity convention.}
A host compiler may generate one concrete module for each fixed finite syntax or dimension.  This is not an
object-language universal evaluator.  When a dimension or syntax code is itself an arithmetic input, the
corresponding list-coded algorithm and resource theorem must be supplied explicitly.
