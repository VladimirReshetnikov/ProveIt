# Difficulty matrix

| Recurring difficulty | Framework repair | Boundary that remains |
|---|---|---|
| Host Lean truth confused with iPRA derivability | Require local and final `Prf PRAAx` fields | Domain proofs still must be built |
| Local lemmas have different arities/contexts | `instantiateInto` = `Prf.subst` + `Prf.weaken`; schedule uses `Prf.trans` | Lean API must be compiled and checked |
| Universal evaluator assumed | Host-time specialization emits concrete `PR` syntax | No object-level universal PR evaluator |
| Bounded quantifiers inside QF induction | Boolean folds and reflection | Unbounded quantifiers need a different theorem shape |
| Adaptive/circular precision | Reverse demand; finite capped monotone closure | A cap or continuity/gap theorem is required |
| Root/eigenvalue/branch collisions | Finite clouds, viability, stable observables | Exact labels need separation |
| Nonempty levels assumed coherent | Backward viability and least successful finite paths | Finite horizons alone do not give an infinite path |
| Cardinality mistaken for enumerability | Height/list equivalence with explicit completeness | Deep height producer may be unknown |
| Ineffective constants | Boundary-conditional theorem with verifier | Verifier does not produce the constant |
| Resetting counters | Fixed-dimensional mixed-radix rank | Variable dimension needs explicit list-coded fuel |
| Local data assumed to glue | Finite overlap relation/equalizer/viability | Finite cover and compatibility data must be supplied |
| Convergence without modulus | Explicit name, metastability, or boundary modulus | No automatic full Cauchy modulus |
| Compactness used to obtain finite net | Net producer plus coverage proof | Bare compactness is not an algorithm |
