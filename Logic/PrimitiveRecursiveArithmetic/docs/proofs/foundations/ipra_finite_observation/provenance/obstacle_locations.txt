## Main positive result developed during this audit

`work/fta_extension.tex` closes the explicit **variable-degree factorization
gap for one fixed input coefficient evaluator**. It uses the repository's
finite rational descent lemma, then supplies every additional construction:

- Monic root constants `B=M+2`, `D=2^n*4^(2n²)`, `K=8nD`, `R=BK+1`,
  `L=2+bl(16D(n+1)R^n)`, `H=bl(BK)`, `J(t)=K(t+H+2)`.
- Raw root query horizon `U(n,M,t)=L+J(t)`.
- Rounded roots, coefficient normalization, explicit coefficient-cap growth,
  a deflation precision shift, and a local polynomial defect bound.
- A separate verification horizon `V(n,M,h)` covering all shifted input
  name comparisons and residual checks.
- Backward horizon planning followed by forward finite-table evaluation;
  no evaluation of growing PR program codes.
- A finite coefficient telescoping identity and error `d W G^d 2^(-t)`;
  this proves the final represented polynomial equality with only
  quantifier-free numerical induction.

The exact baseline request is
`algebra/FTA_iPRA/FTA_iPRA.tex`, lines 992–1028, and
`algebra/FTA_iPRA/LEAN_PLAN.md`, line 195. The baseline already proves a
uniform one-root result; this extension is not a new proof of that entire
descent argument. It fills the missing uniform iteration argument and
tracks the first-order schema boundary accurately.

## Directly resolved open question

- `analysis/bohr_mollerup_ipra_2026-11-15/paper/bohr_mollerup_ipra.tex`, lines 183–202, describes the rational presentation with a separately supplied local modulus `M_F`.
- Same file, lines 216–239, defines RLC only at positive rational arguments and says `M_F` is extra data for the real-domain corollary.
- Same file, lines 712–789, derives a modulus for the constructed gamma presentation and uses candidate `M_F` for completion uniqueness.
- Same file, lines 989–993, explicitly asks whether candidate `M_F` follows from recurrence and RLC.

The new theorem answers yes for exactly this rational-presentation setting. Positive RLC implies ordinary rational convexity by finite weighted AM–GM. Let `a=alpha/2`, `b=beta+1`, `delta=min(alpha/2,1)`, and let `M` be a coarse integer upper bound on `F(a)` and `F(b)`. The two rational secant inequalities show

`|F(x)-F(y)| <= (M/delta)|x-y|` on `[alpha,beta]`.

Thus `mu_F(alpha,beta,k) = k + ceil(M/delta)` is an explicit PR modulus. Recurrence and normalization are not used for this implication. Candidate `M_F` can be deleted as independent input and replaced by this definition. Strong positivity and RLC remain assumptions.

Scope: this gives the canonical continuous extension of the rational presentation. Conditions imposed only at rational arguments do not establish compatibility of independently supplied values at irrational arguments. Do not claim such a stronger theorem.

## Additional simplification of the finite AM–GM subroutine

Same Bohr–Mollerup source, approximately lines 245–284, gives a doubling/descent construction; lines 998–1001 ask about a shorter AM–GM certificate generator.

For `s` positive entries, set `m` to the least power of two >= `s` and `a` to the mean of the original entries. Pad once with `m-s` copies of `a`. A binary AM–GM tree on at most `2s` entries gives `(prod u_i)*a^(m-s) <= a^m`; one cancellation yields `prod u_i <= a^s`. This eliminates the separate descent through intervening lengths. We prove the arithmetic construction and its PR bounds. We do not claim a measured reduction in checker byte count or native proof size because no baseline implementation was compared.

## Mathematical QA notes

- Infimum interval endpoints are `L_k=m_k-2^(-k-1)`, `U_k=m_k+2^(-k-2)`, width `3*2^(-k)/4`. Cross-compatibility follows from `L_i <= f(a_j) <= U_j`.
- `v(k)=k+max_{j<=k}u(j)` is monotone and exceeds both `u(k)` and `k`. The latter fact is needed for optimum-gap convergence in the canonical evaluation proof.
- The direct strong-convex schedule `2k+c` also has both properties and is enough by itself.
- The construction of infimum values does not need uniqueness. The construction of a coherent optimizer does.
- The AM–GM padding proof uses positivity only for its final cancellation. Named inputs have finite positive lower witnesses and upper bounds; the manuscript supplies a concrete dyadic precision demand.
- Metastability counterexample: a halting bit has at most one jump; two disjoint windows guarantee one constant window. A uniform Cauchy rate at tolerance `1/2` would decide halting. This establishes a failure of *uniform* rate extraction, not that each one-jump sequence lacks some individual modulus.

## New main result

For any rational polynomial `f` of exact degree `m`, integers `r >= 1`, `s >= 0` with `m > r*s`, put `Phi(x,y) = (1,x,...,x^s,y)` on `y^r=f(x)`. Every proper rational linear subspace contains feature images of at most `m` distinct rational points. This is a sharp bound for the stated family.

The proof is elementary and supports a uniform iPRA derivation with only bounded, decidable invariants. A nonzero annihilator has form `P_s(x) + a*y`. If `a != 0`, substitution gives nonzero degree-`m` polynomial `(-P_s)^r - a^r*f`, and each x determines y. If `a = 0`, at most s x-values, and at most r y-values per x. No smoothness, irreducibility, genus, divisor, real, or algebraic-closure premise.

Thus, for the monic quintic family `y^2=f_5(x)`, choose `(1,x,x^2,y)`; the fibre bound is **five**, independently of coefficient heights. Given a tuple-local cover by M proper subspaces, one gets cardinality <= 5M. The cover can depend on the input tuple; no global exception list is claimed. All candidate tuple-local covers are reduced to bounded masks of the input list; the success of this bounded search is still the missing approximation theorem.
