# Metadata

- `theorem_ledger.csv`: result-by-result status and dependencies.
- `difficulty_matrix.csv`: recurring obstacle, FINER treatment, and remaining
  producer data.
- `proof_status.json`: machine-readable verification disclaimer.
- `framework_schema.json`: descriptive schema for specialized proof graphs.
- `source_audit.md`: pinned repository paths and relationship to prior packets.

The JSON graph schema is an interchange/documentation format. It does not
assert a universal primitive-recursive evaluator inside iPRA.
