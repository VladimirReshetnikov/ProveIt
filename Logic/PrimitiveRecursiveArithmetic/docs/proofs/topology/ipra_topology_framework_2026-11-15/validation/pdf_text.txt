Certified Observation Towers
A general framework for embedding mathematics into intuitionistic
primitive recursive arithmetic, with topology as a case study
Prepared for Vladimir Reshetnikov
15 November 2026

Abstract
This report develops a reusable method for placing mathematical concepts and proofs
inside intuitionistic primitive recursive arithmetic (iPRA). The method begins with the
current ProveIt infrastructure—fixed primitive-recursive symbols, bounded Boolean tests,
quantifier-free induction, finite contracts, and the existing bridge from ordinary iPRA
derivations to the concise native calculus—and adds a missing topological and choice-stable
layer.
The central new organizing object is a certified observation tower: an inverse tower of
finite nerves whose refinement maps are represented not by arbitrary exact choices but by
finite simplicial carriers. A carrier assigns a nonempty cloud of possible target cells to every
source cell. Its strong simplex condition implies that every deterministic selection is simplicial,
any two selections are contiguous, and their chain maps are related by an explicit finite
prism homotopy. Consequently homology maps are independent of boundary choices. Carrier
composition is finite relational composition, so continuous maps and their compositions can
be represented without a discontinuous global selector.
The report gives complete human-readable proofs of the bounded Booleanization principle,
finite-space/preorder equivalence, carrier composition, selection independence, the mod-2
prism identity, functorial homology for observation towers, and several closure constructions.
It explains how compactness, connectedness, separation, products, subspaces, quotients,
homotopies, manifolds, fixed-point arguments, Jordan separation, and dimension obstruction
should be stated as arithmetic schemas with explicit finite data and moduli. It also identifies
genuine boundaries: unrestricted quantification over open sets or functions is not first-order
arithmetic, exact choice at collisions is not constructively free, and finite verification never
manufactures a missing modulus, height bound, or exhaustion theorem.
The package includes an exact Python kernel and 15 passing tests for finite preorders,
simplicial carriers, tower composition, mod-2 homology, and the prism identity. It also
includes two Lean blueprints: a semantic finite-topology layer and an object-language
completion plan using the actual ProveIt declarations PR, PTm, PRAAx, PRA.qfInd, Prf,
NFm.ofPRA, and pra_iff_native. The Lean files are deliberately marked as uncompiled
outlines; no unfinished semantic theorem is presented as an iPRA derivation.

Repository audit and exact proof status

1.1

The arithmetic backend

5

The relevant ProveIt development has a precise formal core. In its ordinary presentation, iPRA
has one function symbol for every primitive-recursive definition, the defining equations for those
symbols, the successor axioms, intuitionistic first-order natural deduction with equality, and
induction restricted to quantifier-free formulas. The Lean types are PR k for a k-ary primitiverecursive symbol, PTm n for terms with n free variables, PRAAx for the axiom family, and Prf for
derivations. The theorem PRA.qfInd is the actual induction endpoint. The current library also
proves
(Γ ⊢PRAAx φ) ⇐⇒ NPrf(ofPRA(Γ), ofPRA(φ)),
under the name pra_iff_native. Thus the correct workflow is to construct an ordinary
object-language derivation first and transport it only afterwards. The bridge does not turn a
true statement about natural numbers, or an ambient Lean theorem, into an iPRA derivation
automatically [1].
This distinction is the main quality gate for the present report. Every mathematical algorithm
described below has three possible statuses:
(i) a human proof that a finite algorithm is correct;
(ii) a semantic Lean theorem about that algorithm;
(iii) an actual object-language term of type Γ ⊢PRAAx φ.
Only (iii) is an internal iPRA proof. The supplied Lean files specify a path from (i) to (iii), but
do not claim to have completed it.

1.2

What the existing proof packets already achieve

The repository contains a large collection of delivered packets. They establish a strong common
style:
• replace arbitrary real objects by fixed primitive-recursive evaluators, rational approximants,
and explicit moduli;
• replace compactness by finite grids or finite nets;
• replace exact sign or branch tests by strict margins, overlap, or positive separation data;
• package algorithms as bounded traces with Boolean invariants;
• state explicitly that exact reference programs and semantic Lean lemmas do not by
themselves constitute an object-language proof.
The strongest current foundational packet, “finite contracts”, already gives compiled semantic
lemmas, a copied and audited object kernel, actual object-iPRA examples, and a contract record
that contains both a fixed PR program and a Prf PRAAx certificate. Other packets contribute
variable-length recursion, coherent finite presentations, relational outputs, backward demand
analysis, and finite observation compilers. These ingredients are not repeated here; they are
reorganized into one topological calculus.

The topology packets and their remaining gap

Two existing topology packets are particularly important.
The dimension packet proves a finite rational theorem. A table F : {0, . . . , N }d → Qm whose
opposite source faces stay h apart, and whose image on every Kuhn simplex has diameter below
h/d, must satisfy d ≤ m. The positive alternative extracts either a close opposite-face pair or a
large same-simplex oscillation. A cubical Sperner parity argument and staggered target grids
drive the proof. The passage to presented homeomorphisms uses fixed evaluators and explicit
local uniform moduli.
The Jordan packet works with a circle embedding given by rational approximation routines,
a forward continuity modulus, and a positive inverse-separation modulus. It constructs a stable
inside/outside bit only for points with positive clearance, uses finite crossing parity, and produces
polygonal routes with certified clearance. Crossing paths yield arbitrarily accurate approximate
contacts; the packet does not silently assert an exact intersection parameter.
Both reports give substantial complete human arguments, but their Lean files are explicitly
scaffolds. Moreover, they solve theorem-specific finite combinatorics. They do not yet supply a
reusable answer to the following common question:
When a point, cell, root, chart, or branch lies on a finite boundary and several exact
choices are compatible with all available observations, how can a map be composed
and a topological invariant be proved independent of the choice, without invoking a
discontinuous selector?
The new ingredient of this report is a finite relational answer: retain the whole compatible
cloud as a simplicial carrier; prove that all selections are contiguous; and use an explicit prism
homotopy to show choice independence on homology. This is a classical topological mechanism
in finite, proof-producing form. It is closely related to the carrier methods of algebraic topology
[3], but the point here is its exact role as an iPRA interface.

1.4

Audit conclusion

The repository’s recurring difficulties can be divided into three classes.
A1. Representation difficulties. Arbitrary functions, open sets, measures, or infinite
structures are higher-type. They must be replaced by fixed evaluators, finite observations,
or explicit finite tables.
A2. Constructive stability difficulties. Exact boundary choice, exact sign at zero, eigenvector selection at multiplicity, and branch selection at collision may be discontinuous. They
require overlap, a relational output, or an apartness gap.
A3. Proof-internalization difficulties. A finite algorithm may be mathematically correct
yet still lack Booleanization lemmas, defining-equation derivations, loop invariants, or the
final Prf PRAAx term.
Certified observation towers address A1 and A2 uniformly for topology and many adjacent
subjects. The bounded proof compiler described in Sections 3 and 10 addresses A3 at the level
of a precise implementation plan. The framework does not pretend that missing analytic moduli,
Diophantine height bounds, or theorem-specific parity arguments can be obtained by encoding
alone.

Statement discipline: what an iPRA theorem may say

2.1

First-order schemas rather than hidden higher types

A first-order arithmetic theory quantifies over natural numbers. It does not quantify directly
over arbitrary functions N → N, arbitrary subsets of a space, or arbitrary topological spaces.
There are three legitimate ways to express such data.
Definition 2.1 (Fixed-symbol schema). Choose a particular primitive-recursive evaluator e and
add its fixed PR syntax tree to the statement. Prove the theorem uniformly in the numerical
inputs to e, but not by quantifying over the set of all evaluator codes.
Definition 2.2 (Finite-table input). For a requested precision k, pass a number coding exactly
the finite table read by the proof. A bounded verifier checks the table and the local compatibility
laws.
Definition 2.3 (Clocked trace). Pass a code for a bounded computation trace together with its
time bound. Verify each transition and the exit condition by bounded Boolean tests.
A total primitive-recursive universal evaluator for all primitive-recursive program codes
cannot exist: if U (e, x) uniformly evaluated every such program, then n 7→ U (n, n) + 1 would be
primitive recursive and disagree with its own index. Thus “a code for an arbitrary PR program”
is not a harmless substitute for a fixed evaluator. The framework uses fixed symbols, finite
tables, or clocked simulations, exactly as the existing ProveIt reports recommend.

2.2

All-precision statements

A represented-real assertion often has the form
∀k ∃w R(k, w),
where R is a bounded numerical predicate. The constructive and iPRA-friendly order is:
1. keep k as a free numerical input;
2. compute a finite demand bound D(k);
3. read or produce only the finite observations below D(k);
4. run a bounded algorithm and prove a quantifier-free invariant;
5. output w(k) and prove R(k, w(k));
6. universally quantify k only after the finite proof is complete.
One must not perform induction on a formula that itself quantifies over all future precisions.
That formula is not quantifier-free. The finite-demand pass converts it into a finite Boolean
table at the current precision.

The same pattern is used for malformed lists, invalid simplices, singular matrices, and absent

2.4

Positive data versus negated equality

Constructive topology and analysis require careful use of apartness. The proposition “x ̸= y” is
negative. It need not provide a numerical scale at which x and y can be separated. Algorithms
instead require positive data such as
d(x, y) > 2−s
with an explicit s, or a pair of disjoint basic neighborhoods with certified membership. Likewise,
“a point is outside a closed set” should be replaced by a positive clearance witness when a routing
algorithm needs room to move.
The framework therefore distinguishes:
• equality of names, which is generally a universal all-precision relation;
• apartness, which is witnessed at a finite scale;
• ambiguity, represented by a finite cloud rather than resolved by arbitrary choice.

2.5

Finite verification does not produce global bounds

A verifier for a candidate subcover does not produce a subcover. A verifier for a list of all rational
points does not produce a height bound. A verifier for a contraction certificate does not discover
a contraction region. These distinctions are logical, not merely engineering details.
Every interface in this report separates:
producer

+

finite verifier

+

correctness proof.

If the producer requires a modulus, a separation bound, a finite exhaustion, or a height certificate,
that datum is an explicit premise. The framework can compose such certificates and eliminate
finite bookkeeping; it cannot conjure missing mathematical information.

Bounded formulas are Boolean

Let a bounded formula be built from equality and order between fixed primitive-recursive terms,
intuitionistic connectives, and quantifiers of the forms
∀u < B(⃗x) φ(u, ⃗x),

∃u < B(⃗x) φ(u, ⃗x).

Theorem 3.1 (Bounded Booleanization). For every fixed bounded formula φ(⃗x) there is a fixed
primitive-recursive Boolean term bφ (⃗x) and an iPRA derivation
iPRA ⊢ φ(⃗x) ↔ bφ (⃗x) = 1.
The construction is uniform by metalevel recursion on the finite syntax tree of φ.
Proof. Atomic equality and order have primitive-recursive decision procedures. Their correctness
is proved from the defining equations and quantifier-free induction. Boolean conjunction, disjunction, and implication are represented by fixed truth-table functions. Since their arguments have
already been proved equivalent to Boolean equalities, the corresponding connective equivalences
follow intuitionistically.
For a bounded existential, define the finite disjunction fold
E(0, ⃗x) = 0,

E(t + 1, ⃗x) = max(E(t, ⃗x), bψ (t, ⃗x)).

Quantifier-free induction on t proves
E(t, ⃗x) = 1 ↔ ∃u < t bψ (u, ⃗x) = 1.
The existential direction uses the least successful index from bounded search; the reverse direction
is immediate from the fold. Evaluate at t = B(⃗x).
For a bounded universal, use the finite conjunction fold
A(0, ⃗x) = 1,

A(t + 1, ⃗x) = min(A(t, ⃗x), bψ (t, ⃗x)).

Quantifier-free induction proves the corresponding universal equivalence. Every induction formula
is an equality between Boolean primitive-recursive terms, hence quantifier-free. This completes
the syntax recursion.
Remark 3.2. The theorem concerns each fixed bounded formula. It does not assert a primitiverecursive truth predicate uniform over arbitrary formula codes. The metalevel compiler emits a
particular PR syntax tree and a particular derivation.

Definition 3.3 (Finite contract). A finite contract from input code x to output code y consists

1. a fixed primitive-recursive producer p(x);

4.7

Pointfree interpretation

The tower may be used without a pre-existing set of points. Its vertices are basic observations,
its simplices are positive finite intersections, and its refinement carriers are cover relations. This
is close in spirit to formal topology, where basic opens, covers, and positivity are primary and
arbitrary point sets are not assumed [5]. It is also compatible with represented-space practice,
where topological properties are expressed through the computability of operations on names
and open information [4].
The present construction is deliberately more finitary: at each requested scale, only a finite
complex and finite carrier are manipulated. This is what makes quantifier-free induction and
bounded verification available.

Acyclic carriers as an extension

Strong carriers may be generalized. Assign to each source simplex σ a target subcomplex A(σ)

Finite topology inside iPRA

Finite topological spaces are a useful exact test: no limiting representation is required, yet

Continuous maps are monotone maps

Theorem 6.2 (Finite continuity). For finite spaces presented by their specialization preorders,
a function f : X → Y is continuous if and only if it is monotone:
x ⪯X x′ =⇒ f (x) ⪯Y f (x′ ).

and makes continuity a bounded pairwise condition. It is therefore the preferred exact finite

6.3

Basic constructions

All of the following are primitive-recursive on finite codes.
Products. The product preorder on X × Y is coordinatewise: (x, y) ⪯ (x′ , y ′ ) iff x ⪯ x′ and
y ⪯ y ′ . The standard product topology on finite spaces is recovered.
Subspaces. For a bitset A ⊆ X, restrict the preorder to selected vertices. A coded reindexing
produces a finite preorder on {0, . . . , |A| − 1}.
Quotients. Given a finite equivalence relation E compatible with the preorder, choose the
least representative of each class and define the quotient relation by bounded existential search.
A verifier checks well-definedness and the universal property for supplied maps.
Connected components. The undirected comparability graph has an edge between x and
y when x ⪯ y or y ⪯ x. Its graph components are the topological connected components of a
finite space. Breadth-first search with a visited-bitset invariant computes them.
Order complex. For a finite T0 space, the order complex has a simplex for every finite chain
x0 < · · · < xq . Its construction is bounded. It supplies the bridge from finite spaces to simplicial
homology used in McCord’s theory [2].

What finite topology does and does not solve

Finite spaces provide exact models, regression tests, and finite approximants. They do not imply
that every infinite topological theorem reduces to one finite space. The missing information is
carried by the observation tower: how finite covers refine, how maps act at every requested scale,
and what quantitative condition connects the tower to the intended space.

A topology library built from finite certificates

This section lists the principal topological notions and gives an iPRA-compatible formulation.
The goal is not to force all topology into one definition, but to expose exactly which finite
observations and positive certificates each theorem uses.

7.1

Open information and continuity

At scale k, a basic open is a vertex of Kk . A finite union is a bitset. Membership of a presented
point is positive when its observation simplex meets the bitset in a certified way. Arbitrary
subsets of points are not internal objects.
A continuous map is represented by a modulus and carriers as in Section 4. This formulation
has three advantages:
1. it is pointfree at the finite level;
2. it permits multiple valid target cells at boundaries;
3. composition is finite relational composition.
For metric presentations, the familiar evaluator/modulus formulation induces the carrier
formulation. Conversely, if the tower is spatially complete and has a shrinking mesh, a coherent
carrier map determines the usual continuous action on regular point names. That converse is a
semantic theorem about the chosen presentation, not a generic fact of first-order arithmetic.

7.2

Compactness

Abstract compactness says every open cover has a finite subcover. Quantifying over arbitrary
open covers is higher-type and often nonconstructive. The usable data are instead:
Definition 7.1 (Finite compactness contract). A compactness contract supplies a primitiverecursive net N (k), a finite cover Uk , and a verifier proving that every represented point is
observed in at least one member, with mesh or Lebesgue data sufficient for the intended theorem.
If an application receives a finite candidate cover by basic opens, coverage reduces to
a bounded statement about the net plus a supplied uniform-continuity or inclusion margin.
Bounded search extracts a subcover when the list is redundant. The contract does not turn
an arbitrary infinite enumeration of opens into a finite subcover without a bar, modulus, or
stopping bound.

7.3

Separation and apartness

A Hausdorff-style effective presentation supplies a separation procedure:
Apart(x, y, s) = 1 =⇒ disjoint basic neighborhoods of scale s.
For regular fast metric names, a witnessed lower distance bound provides this procedure. Negated
name equality alone does not.
At the tower level, two observation clouds are apart at scale k when no simplex contains
a vertex from each cloud, or when an explicit disjointness certificate is supplied. Separation
propagates under refinement by a bounded proof.

Connectedness and paths

There are several constructive strengths.
Definition 7.2 (Finite chain connection). Two vertices of Kk are chain connected when they lie
in the same component of the 1-skeleton. A certificate is a finite vertex path whose consecutive
pairs are edges.
A presented space is uniformly chain connected when a fixed primitive-recursive procedure
produces such paths between observation clouds at every requested scale. This positive statement
is stronger and more computational than merely denying a separation into two opens.
A represented path is a tower map from an interval tower. Polygonal paths with rational
vertices are especially convenient: evaluation, subdivision, and clearance tests are primitive
recursive. Homotopies are tower maps from a product with an interval tower.

7.5

Products

Given covers Uk and Vk , use the product cover Ui × Vj . A finite family of product cells has
nonempty intersection exactly when both coordinate families do, provided the factor intersection
certificates are available. Thus the product nerve is a finite combinatorial construction on pairs.
Refinement and map carriers are componentwise.
The construction proves that products of certified towers are certified towers. For metric
spaces, the max metric gives a simple mesh bound. All dimension bounds, bitset encodings, and
demand transformations are explicit.

7.6

Subspaces and closed conditions

A subspace cannot in general be formed merely from a negative predicate. The tower needs a
positive answer to “which cells meet the subspace?” Suitable inputs include:
• a finite decidable subset of a finite space;
• an zero set with isolating boxes and sign/degree certificates;
• a compact set with a distance-name and positive intersection witnesses;
• a supplied finite subcomplex.
Cells with certified intersection become vertices; inherited intersection certificates define the
subcomplex. Ambiguous cells remain as clouds rather than being discarded.

7.7

Quotients

For finite spaces and finite complexes, quotients by a decidable equivalence relation are bounded
constructions. For represented spaces, a quotient presentation requires more:
1. a fixed evaluator for the equivalence relation or orbit action;
2. finite saturation of observation clouds;
3. compatibility of refinement;
4. separation data if a Hausdorff quotient is claimed.
Without these fields, a quotient may destroy effective separation or make equality undecidable.
The framework therefore treats quotient quality as a certificate, not as an automatic theorem.

Homology and cohomology

At each scale, mod-2 homology is computed from finite boundary matrices. Gaussian elimination
is a bounded loop. Its invariant records:
• the processed pivot columns;
• preservation of row space under elementary operations;
• pivot distinctness;
• rank accounting.
The Betti formula is

βq (K) = nq − rank ∂q − rank ∂q+1 .

Cohomology uses transposed boundary matrices. Cup products are finite formulas on simplex
tables; associativity and the Leibniz rule can be proved by bounded index manipulations. Integral
torsion is added by checked Smith certificates as described after Theorem 5.4.
The tower does not force Betti numbers to stabilize. Stabilization, pro-isomorphism, or
identification with singular/Cech homology is a semantic theorem requiring hypotheses on the
cover system. McCord’s finite-space results and classical nerve theorems indicate the relevant
bridges [2], but each effective use must supply finite good-cover or acyclicity certificates.

7.9

Fundamental groups

For a finite complex, an edge loop is a finite list of vertices. Elementary edge homotopies
insert or delete backtracks and triangle moves. A bounded sequence of such moves is a positive
null-homotopy certificate. Van Kampen presentations can be produced from a finite spanning
tree and 2-simplex relations.
What is not available uniformly is a decision procedure for the word problem in arbitrary
finitely presented groups. The iPRA interface is therefore asymmetric:
• a supplied bounded homotopy is verifiable;
• bounded search can find one below a stated bound;
• absence of a bounded certificate is not a proof of non-null-homotopy;
• special classes with a proven normal-form algorithm may add a decision contract.

7.10

Manifolds and atlases

A compact effective d-manifold can be presented by a finite atlas at each scale:
(Ui , ϕi , ψi , ri ),
where ϕi and ψi are fixed rational evaluators for a chart and its inverse on guarded domains, ri is
a positive interior margin, and overlap transitions have explicit moduli. Finite cover certificates
prove that the shrunken chart domains cover the space. Carriers handle points lying in several
charts.
Local topological proofs reduce to rational boxes. Differential topology adds rational derivative
names, determinant gaps for inverse-function steps, and transversality margins. Smooth partitions
of unity require explicit bump-function approximants and denominator lower bounds. None of
these should be hidden inside the word “smooth.”
For noncompact manifolds, add a primitive-recursive exhaustion by compact charted pieces.
A theorem at precision k advertises the exhaustion stage it needs. This is the same finite-demand
discipline used throughout.

Fixed-point theorems

A Sperner labeling on a finite triangulation is a bounded object. The parity proof yields an
approximate fixed-point simplex. Given a uniformly continuous map on a compact presented
simplex, a mesh choice turns this into
∥f (x) − x∥ < 2−k
for an explicitly produced rational point x.
An exact fixed point is a different claim. To construct a coherent name, one needs nested
compatible approximate witnesses. This can be obtained from an isolation/uniqueness modulus,
from a relational viability dynamic program, or from an explicit compact choice principle
available for the particular presentation. Unrelated approximate fixed points at each scale do
not automatically form one point.

7.12

Dimension and local degree

Dimension obstructions are particularly suitable for finite topology. The repository’s staggeredgrid theorem is already a quantitative finite alternative. Invariance of domain can be approached
similarly: triangulate a rational box, represent a map by a sufficiently fine carrier, compute a
local mod-2 degree on a boundary complex, and use an injectivity-separation modulus to prevent
cancellation. The finite degree calculation is within iPRA; producing the required uniform
separation data is the substantive application hypothesis.
One must not silently infer unrestricted classical invariance theorems from the finite core.
Reverse-mathematical work shows that some unrestricted Brouwer invariance statements have
weak-Koenig-lemma strength over standard base theories [6]. The present goal is the maximal
explicit, effectively presented version: fixed evaluators, positive moduli, and finite certificates.

8.1

The Sierpinski space

Let X = {0, 1} with preorder 0 ⪯ 1 and no converse relation. The upward opens are
{1},

∅,

{0, 1}.

The exact Python kernel reconstructs these opens from the relation. Exhaustive enumeration of
all maps between three representative two-point preorders confirms the theorem “monotone iff
continuous” in every case; the human proof is Theorem 6.2.
This example is small but instructive. Open information is directional: observing 0 forces
compatibility with 1. A preorder code expresses this directly, while an open-set list obscures it.
It also illustrates why non-Hausdorff finite spaces remain topologically meaningful.

8.2

A carrier tower for the circle

Let Cn be the one-dimensional cycle complex with vertices 0, . . . , n−1 and edges {j, j +1 mod n}.
Define a binary refinement carrier
R : C2n ⊸ Cn
by

R(2i) = {i},

R(2i + 1) = {i, i + 1 mod n}.

For every fine edge, the union of its endpoint clouds is one coarse edge, so R is a strong carrier.
There are two obvious selections: choose the smaller or the larger endpoint of each ambiguous
cloud. They differ exactly at subdivision vertices. By Theorem 5.3, both are simplicial and

22

contiguous. The prism theorem proves they induce the same map on H1 . The exact kernel
verifies
β(C4 ) = β(C8 ) = β(C16 ) = (1, 1)
and checks the prism matrix identity for the two selections.
This is the model for a boundary point in a cover: the point belongs to two adjacent cells,
and no exact convention should affect the topological invariant.

8.3

Jordan separation

The constructive Jordan theorem is naturally expressed with positive clearance. Let γ be a
circle embedding with:
• a fixed rational approximation evaluator;
• a forward continuity modulus;
• an inverse separation modulus ensuring that separated parameters have separated images.
For a rational query point p with a positive lower distance bound from the curve, a sufficiently fine
polygonal approximation has stable crossing parity. Triangle replacement proves independence
from further refinement. A finite grid or honeycomb flood computes a route within the equalparity region; failure would extract a separating cycle whose parity change contradicts equality
of the endpoint bits. This is the constructive strategy of Berg–Julian–Mines–Richman in finite
arithmetic form [7], consistent with the discrete bounded-arithmetic analyses of Nguyen and
Cook [8] and later constructive treatments [9].
The carrier framework improves the interface in four ways.
1. A curve sample lying on a grid boundary belongs to all adjacent safe cells. Keep that
cloud rather than imposing a global tie-break.
2. Polygon refinements are carriers between finite cycle complexes. Crossing parity invariance
is a finite chain statement.
3. Safe-region routes are finite edge chains in a complement complex; alternative routing
choices are related by finite 2-cell fillings when available.
4. The inside/outside bit is defined on the apartness complement. No decision at zero
clearance is asserted.
A complete object proof still needs the theorem-specific crossing and flood-fill invariants.
The tower/carrier library removes repeated map-choice, refinement, and homology bookkeeping;
it does not replace the Jordan parity argument itself.

8.4

Invariance of dimension

For a presented map f : [0, 1]d → Rm , choose a rational grid fine enough that the oscillation on
each Kuhn simplex is below a requested threshold. Encode its vertex values as rational integer
tuples after clearing denominators. The repository’s finite theorem gives the positive alternative:
if d > m, then either opposite source faces have images closer than the claimed
separation, or one Kuhn simplex has image oscillation at least the local bound.

Certified Observation Towers in iPRA

23

Both conclusions are finite witnesses. Applied to a presented homeomorphism and its inverse
with explicit moduli, they force equality of dimensions.
In the tower language, Kuhn triangulations are levels, subdivision is a refinement carrier,
and the map evaluator induces a target-grid carrier. Staggered grid labels are Boolean functions
on vertices. The cubical Sperner parity theorem becomes a reusable finite contract. Boundary
ambiguity is harmless because adjacent target cells form a carrier simplex.
The restriction to explicitly presented maps is essential. The statement is a schema for fixed
evaluators and moduli, not a first-order universal quantification over all real functions. This
matches the logical boundary highlighted by the existing packet and by reverse-mathematical
results on unrestricted invariance principles [6].

8.5

Nerve computations from good covers

Suppose a compact presented space has a finite cover U such that every nonempty finite
intersection comes with a contraction certificate. The nerve N (U) is finite. An effective nerve
theorem can be organized by two acyclic carriers:
1. a carrier from a sufficiently fine spatial triangulation to the nerve, assigning all cover
elements containing a cell;
2. a carrier back, using supplied contraction/filling operators for cover intersections.
The carrier composites are chain homotopic to identities. Therefore the finite nerve and the
spatial complex have isomorphic homology. If the intersections are literally represented by one
simplex at the finite level, strong carriers suffice; otherwise use the certified acyclic extension.
The phrase “good cover” must therefore expand to finite data: an intersection table, positivity
witnesses, and bounded contractions or filling matrices. With those fields, the proof is finite and
iPRA-compatible.

8.6

Surfaces and Euler characteristic

A triangulated compact surface is a finite complex with local-link certificates. The Euler
characteristic
χ=V −E+F
is exact integer arithmetic. Edge-incidence checks verify that each edge has two incident faces
in the closed case, and vertex links verify the local manifold condition. Mod-2 Betti numbers
provide
χ = β0 − β1 + β2 .
The equality follows from rank cancellation in the finite chain complex and is formalizable by
bounded matrix arithmetic.
Classification of surfaces requires more: a finite sequence of certified elementary moves
reducing a triangulation to a normal form, or an algorithm with a well-founded finite measure
and invariant. The framework can verify such traces and prove their invariants. It does not
treat the classification theorem as a one-line consequence of coding.

9

Resolution of recurring difficulties beyond topology

The carrier idea is topological in origin but addresses a general problem: finite evidence may
determine a compatible family rather than a unique output. This section records how the
framework applies across the repository.

Certified Observation Towers in iPRA

9.1

24

Root and eigenvalue collisions

At precision k, let vertices be rational boxes or spectral intervals. A simplex is a jointly
compatible cluster. Refinement relates fine isolating boxes to every coarse box containing them.
Polynomial evaluation or a matrix algorithm returns a carrier of possible clusters.
Symmetric observables—root multisets, elementary symmetric functions, spectral projectors
separated by a gap—are invariant under selections. An individual ordered root or eigenvector is
produced only when an isolation or apartness certificate collapses the cloud. This avoids exact
choice at collisions and matches the existing root-cluster and stable-observable recommendations.

9.2

Local analytic branches

A local implicit-function proof typically has several overlapping rational charts. Let vertices be
certified chart domains; a simplex means a common subdomain is nonempty. Transition maps
form carriers because a point on a chart boundary may admit several valid target charts. Carrier
composition proves that finite analytic continuation does not depend on tie-breaking, while a
monodromy invariant can be computed on the resulting nerve.
The producer still needs a simple-root or invertible-Jacobian gap. At a singular point, a
chart cloud may fail to contract to one branch. The framework represents this honestly rather
than asserting a hidden selector.

9.3

Integration and measure

Use finite partitions with rational interval enclosures for function values and cell masses. Refinement carriers relate subcells to containing cells. Lower and upper sums are finite rational
folds. A modulus or variation bound controls the gap. Measures are not quantified as arbitrary
higher-type functionals; a fixed mass evaluator and additivity certificates are supplied.
Discontinuous tests, such as a cumulative distribution function exactly at an atom, require
an anti-concentration margin or one-sided interval output. A relational interval is the measuretheoretic analogue of a carrier cloud.

9.4

Diophantine finiteness

For a bounded region, candidate points form a finite complex with discrete vertices. A verifier can
check equations and distinctness. A height certificate turns qualitative finiteness into complete
bounded enumeration. Carrier methods help with local charts or descent representatives, but
they do not produce the height bound.
Thus the correct contract remains:
height/cover producer

+

finite enumeration verifier.

The framework clarifies exactly which part is missing in general Siegel- or Faltings-type applications.

9.5

Prime-distribution and analytic constants

A finite verifier can check zero-free rectangles, explicit coefficient inequalities, or an exceptionalzero certificate. It cannot derive ineffective constants from a qualitative classical theorem. The
theorem should be parameterized by an analytic-input certificate whose fields are consumed
by bounded computations. Precision demands are propagated backward through the contract
graph.

Certified Observation Towers in iPRA

9.6

25

Metastability and convergence

A metastable window theorem returns, for every control function and precision, a finite stable
interval. It does not automatically return a Cauchy modulus. Observation towers record windows
and their refinement compatibility. A coherent limit name requires additional uniqueness or
compactness data. This prevents an invalid conversion from “there are arbitrarily stable windows”
to “there is a computable final stage.”

12

Limits, residual obligations, and research directions

12.1

What has been resolved

At the level of statement design and finite mathematics, the framework resolves the following
recurring obstacles.
1. Boundary ambiguity. Replace exact choice by a finite carrier cloud. Composition
remains total, and homology is choice independent.
2. Map composition. Relational union composes finite approximations without coordinating
arbitrary tie-breaks.
3. Topological invariants. The prism identity gives an explicit finite witness that contiguous
choices induce the same homology map.
4. Finite topology. Preorders give a compact exact coding, and continuity becomes bounded
monotonicity.
5. Compactness usage. Finite covers, nets, and mesh/Lebesgue certificates replace an
unbounded open-cover quantifier.
6. All-precision reasoning. Finite demand analysis and Booleanization keep induction
quantifier-free.
7. Formal endpoint. Every main theorem has a stated Prf PRAAx target and a dependency
order.

12.2

What remains theorem-specific

The framework deliberately does not claim completed object proofs for:
• cubical Sperner parity and staggered-grid dimension obstruction;
• the complete Jordan crossing, flood-fill, and boundary-density argument;
• a general effective nerve theorem with produced contraction data;
• invariance of domain or general manifold classification;
• stabilization of homology for arbitrary observation towers;
• production of finite atlases, triangulations, or good covers from weak input presentations.
These are mathematical modules to be built on the common kernel.

Certified Observation Towers in iPRA

12.3

31

Logical boundaries

The following stronger principles are not obtained by better coding alone.
1. There is no uniform total primitive-recursive evaluator for arbitrary PR program codes.
2. Negated equality does not uniformly yield a positive apartness scale.
3. A finite verifier does not produce a missing global bound or modulus.
4. Independent approximate witnesses at every precision do not necessarily form one coherent
point.
5. Unrestricted classical topological statements may have proof-theoretic strength exceeding
the intended finitistic base; effective hypotheses must be stated explicitly [6].

12.4

Recommended next formal milestones

The most valuable immediate work is foundational rather than another large theorem outline.
1. Complete and compile the bounded Booleanization library in the actual ConciseIPRA
environment.
2. Formalize strong carriers and the circle refinement example end to end, including the
object prism identity.
3. Add bounded Gaussian elimination and a verified Betti-number contract.
4. Refactor the Jordan and dimension packets so that their finite complexes and refinement
maps use the shared carrier API.
5. Develop certified acyclic carriers with explicit finite filling operators; this unlocks effective
nerve theorems and chain-level local-to-global arguments.
6. Build a compact metric-space tower interface with rational covers, mesh bounds, positive
intersections, and map moduli.

12.5

Conclusion

The most robust way to place topology in iPRA is not to encode an arbitrary powerset topology
as one enormous natural number. It is to identify the finite observations actually used by a
proof, arrange them in certified refinement towers, preserve ambiguity as relational carriers, and
compile every finite invariant into bounded Boolean arithmetic.
This yields a coherent division of labor. Topology supplies covers, nerves, carriers, chain
homotopies, and local-to-global structure. iPRA supplies primitive recursion, bounded search,
exact arithmetic, and quantifier-free induction. The representation theorem connecting a tower
to a classical or constructive space remains explicit. The object-language derivation remains
explicit. Under these rules, sophisticated topological arguments can be developed without
importing hidden choice, compactness, or higher-type quantification.

Bounded breadth-first search

A graph on n vertices is an n × n Boolean matrix. A BFS state is (seen, frontier, parent). At
most n rounds are needed because every successful round adds a new vertex. The invariant says:
1. every seen vertex is reachable by the recorded parent chain;
2. every edge from a processed vertex leads to a seen vertex;
3. the frontier is contained in seen;
4. parent indices are bounded.
All clauses are bounded Boolean formulas. This supplies path certificates for finite connectedness
and flood-fill algorithms.
