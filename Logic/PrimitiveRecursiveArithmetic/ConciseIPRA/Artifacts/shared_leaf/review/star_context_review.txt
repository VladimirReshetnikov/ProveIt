1. What changes
----------------
The core uses the global-scope recursive membership-leaf protocol. It also
retains the administrative true resource 0 in every context and calls the
major-proof routine even at an introduction's literal-zero source. A fixed
dummy packet [0,0,0] discharges that neutral proof. No eigenparameter is
allocated by this extra successful call.

The initial context is the single-byte literal b'\x00'. Python iterates
this literal as the one-element sequence of integers [0]. The AST's actual
constant value was independently checked; it is not the four textual
characters backslash, x, zero, zero. The program only uses g by unpacking
its elements into (*g,H) or [*g,h]. Thus it has precisely the same behavior
as initial g=[0]. After the first continuation its context is an ordinary
new list. No certificate byte string is interpreted as code and no hidden
table or compressed proof kernel is present. This literal is simply a
smaller AST spelling of the same fixed, singleton neutral context.

2. State invariant and continuation
-----------------------------------
At every recursive entry g contains 0 plus the inherited retained resources;
k is the global decreasing supply of already allocated rigid parameters.
The byte-literal/list representation of g does not change the sequence of
its elements. Contexts are never mutated: [*g,new_hypothesis] allocates a
new list for the continuation and leaves every premise context unchanged.

For a nonleaf the code first computes

  h = c(g,s) or s*3 or (a := i(*a,t,2)).

Every successful c call returns None. If s is truthy, its proof is checked
before h=s*3 is used. If s is literal 0, its proof succeeds from the neutral
context entry and h is the instantiated introduction matrix. This is the
same h as in the conditional form, with one harmless true premise added.

Only AFTER this major proof and introduction-witness opening succeed does
the image argument execute k := k-1. Its mode is 1 if s is truthy and
len(a)==2 otherwise. This is Boolean-equivalent to the inherited
(s or len(a)==2) and k image selector. In particular an introduction with a
Q matrix of arity three still receives zero/case mode. The rejected
len(h)>1 rule is not used.

The new hypothesis is opened using the newly allocated floor; the successor
goal is then opened with [k], and the recursive continuation receives the
same new context and goal as the inherited loop. No input is read by these
opening operations. A global floor changed by a major proof is carried on
in exactly the same way as before. The old/new scope distinction is retained.

3. Soundness
-------------
Induct on a finite successful recursive execution. The extra context resource
0 has the sorted formula reading true, represented by 0=0. A hypothesis leaf
therefore uses either an ordinary retained premise or this fixed theorem.

For a computation leaf, the successful lazy no-image scan preserves the
sorted reading and is idempotent. If its output equals H(s,u,t), then H is
scope-valid; the inherited direct computation-leaf lemma proves its reading
from the iterator equations. Hence the original goal has that same true
reading. The treatment of raw aliases here uses the sorted-decoder proof,
not the false assertion that every successful lazy scan is literally the
identity.

All other branches are the inherited introduction, opened-major, or
goal-directed elimination transition. Their premises have just been checked;
the allocation order establishes their freshness conditions. Adding or
proving the neutral true resource cannot strengthen the ordinary theory.
Consequently every accepted canonical public goal is a theorem of the same
guarded scalar theory, and therefore has its original iPRA interpretation.

4. Canonical completeness
-------------------------
Start with a canonical derivation/certificate of the direct-leaf global token
control. Retain its public goal and its numerical labels literally. At each
hypothesis leaf insert [0,0,0] for the membership preview. At each zero-source
introduction insert a further [0,0,0] for the newly explicit neutral-major
call. All other packets are retained in recursive execution order.

The extra neutral proof has no continuation and does not change k. It proves
the literal formula 0, already retained in every new context. The old
context embeds as the nonneutral resources of the new one. Canonical goals
and computation instances are fixed by no-image scanning; canonical preview
totality is the inherited lemma. Induction over the canonical proof tree
therefore yields a successful candidate execution with exactly the same
public goal and eigenparameter names.

This establishes equality of represented public theorem sets. The common
whole-domain bi-interpretation with full first-order iPRA, actual equality,
and both identity numerical comparison graphs is unchanged. It is not a
claim of identical arbitrary raw certificate languages. In particular,
some noncanonical falsy-source aliases may require an additional neutral
proof, and lazy scanning may normalize ignored annotations.

5. Focused executable evidence
-------------------------------
compile_star_context.py instruments the exact direct-leaf token243 control
and inserts packets at its actual hypothesis exits and zero-source
introductions. It is untrusted and not imported by the checker.

verify_star_context.py independently ran 40 standalone executions, in both
ordinary and -O modes, with zero unexpected outcomes. The cases include
computation, inferred-major elimination, implication elimination, shared
computation, induction using its hypothesis, false-goal mutations, inherited
context/scope attacks, and direct successor computation with zero initializer.

A targeted false guarded theorem uses the future variable -1 as its witness.
Its neutral-major dummy packet is supplied explicitly, so rejection occurs
at the witness's old-scope opening (TypeError), not just missing input.

The translated used-induction proof has 281 packets: 268 inherited packets,
6 added hypothesis packets, and 7 added neutral-major packets. The literal
public formula is unchanged. These tests are finite implementation evidence;
the universal correctness and equivalence arguments are Sections 2-4 above.
