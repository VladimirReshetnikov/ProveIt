PDF REPRODUCTION

For a standard TeX Live installation, run sh build.sh in the package root.
It validates the checkers and runs pdflatex three times.

The production environment had TeX binaries and package sources but no
prebuilt pdflatex format or font-map database. The PDF was compiled using
a local format built from pdflatex.ini with pdftex -ini -etex, a TEXMF
search path without database-only markers, and explicit lm.map, cm.map,
and symbols.map loading. No document content or mathematics was changed
by this environment repair.

All 16 pages were rendered with pdftoppm and reviewed. The final LaTeX
log has no bad boxes or unresolved reference warnings.
