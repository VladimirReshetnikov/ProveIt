INDEPENDENT REVIEW OF ESTABLISHED-COMPOSITION FAMILY

Scope: The programs preserve the inherited initialized-iterator Choice-DI
presentation. This work does not establish a new arithmetic basis or a
significant foundational breakthrough. The source census is pinned to
b9c4d74a0018bdafc5bc06e755a0145f4ed2b8d6.

Transformations reviewed
1. Neutral major: begin with the theorem encoded by [], and check every major
   unconditionally. This is the existing monus report's protocol. The retained
   mode must compare len(a)%2 with u, not with the unrestricted s field.
2. Local scopes: recursively proving a major uses a local copy of its floor.
   The checked major and context cannot contain that proof's fresh parameters;
   hence local allocations need not affect the parent. The named producer uses
   floor=-len(context) with a zero-length logical initial context. The checker's
   additional neutral-truth assumption is administrative and has no name.
3. Hypothesis supply: m*3 or (u and computation) or introduction is identical
   to the old branch sequence on successful traces. A surviving nonempty major
   exports a nonempty list; a selected computation constructs a two-element
   list. Only the introduction can be the final alternative. The root invariant
   excluding successfully proved numeric majors is inherited unchanged.
4. Loop: replace the tail-recursive continuation by a while loop. The context
   is an immutable tuple, and += therefore creates a fresh tuple. The recursively
   checked major retains the previous tuple. The local fresh floor decreases
   once per loop command, in the same order as the recursive checker. The
   opener closes over this mutable local floor, so it observes the updated
   floor when the fresh parameter is inserted into both goal and hypothesis.
5. Explicit conditional transport: if the transport matcher succeeds, replace
   the goal by its source instance. The shorter Boolean expression retains the
   old goal when this source is false-valued. Every successful reached goal and
   source instance is a list; a false-valued list is [], denoting fixed truth.
   The inherited raw analysis therefore makes both styles sound. Their canonical
   traces coincide, since canonical formulas are nonempty lists. The explicit
   conditional is easier to read and has fewer AST nodes but more bytes.
6. Missing substitution image: 0j is not supplied by JSON. Just like None, it
   fails the ordered numeric comparison whenever an unresolved odd-depth
   substitution tries to validate it. Both retain the same successful traces.

Generic versus exact-list opening
The generic try/except opener retains the existing qualification: nonempty
strings can recurse forever in an ideal stack-unbounded execution. Actual
CPython rejects through its recursion limit and subsequent type errors. Empty
strings/dictionaries can open to [] and represent the fixed truth; their
finite accepted traces remain covered by the sorted decoder. The explicit
isinstance and zero-product list recognizers avoid this qualification. Neither
introduces an omitted parser or theorem-specific external dependency.

Why no single complete record is claimed
The byte optimum in this established-composition family is 529 bytes but has
266 tokens and 310 AST nodes. The token profile attains 261 tokens, matching
rather than beating the old minimum. The immutable-loop generic profile reaches
290 AST nodes but has 610 bytes. The coordinate family envelope is 529/261/290,
attained by different programs. The currently archived coordinate envelope is
542/261/291. There is no single tested composition below all three old minima.

Finite verification
verify_family.py imports the unchanged untrusted named producer and its case
builder, translates packet modes to the established neutral-major protocol,
and independently renumbers lexical scopes for local profiles. It exercises
both ordinary and optimized Python. It covers positive computations, literal
zero repairs, equality transport, paired introduction/elimination, parameter
scope, contextual induction, compound-progress rejection, malformed JSON
values, generic aliases, and the prior integer/float capture attack.

A deliberate shared-mutable-context mutation of the loop accepts the inherited
false equation 0=S0. The proper tuple-loop rejects the same packet, in both
Python modes. This directly confirms that the immutable context condition is
not optional. These finite checks supplement the above simulation arguments;
they are not proof-assistant verification or universal bi-interpretability.

Failed experiment retained only as scratch
FAILED_neutral_depth.py tried deriving the floor once from context length.
It fails because the opener must see a decremented floor while inserting the
new parameter; leaving a stale floor rejects genuine canonical proofs. It is
not a selected checker or a legitimate size comparison entry.
