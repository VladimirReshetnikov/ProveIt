3. Trusted-boundary qualifications

Compact checkers promise integer/list certificates, a canonical guarded
public grammar, and appropriate initial scope. The strongest compact source
figures omit a complete public syntax validator. Those omissions do not
remove validation rules from a strict checker for free; comparisons must
state the difference.

The 458-byte program reads [Gamma,A,0] as the SEQUENT Gamma |- A, not as the
bare assertion A. A certificate for [0=1] |- 0=1 is not a proof of 0=1.
Initial assumptions and goal are closed canonical public formulas, so
negative eigenparameters are fresh. The 455-byte and 238-token variants
require the administrative neutral truth 0 to occur explicitly in the
initial context. This moves a representation convention into the input;
it is already present in the corpus and is not a new simplification.

Sorted public validators retain administrative constructor slots. Their
soundness is given by an ordinary reading, while completeness is only for
canonical encodings that do not mention dummy slots. The old false-complete
extension is obstructed by [[5],[1]], shifted to [[7],[1]] in the two-offset
syntax. The actual-binding 582-byte exact program avoids those phantom
slots and has a different comparison boundary.

Newest local validators deliberately allow arbitrary UNUSED JSON annotations.
The important obligation is that used goals, hypotheses, majors, retained
numerical leaves, and inserted substitution images are validated. A whole-
document integer/list lexical filter is stricter than needed for soundness.
This local-validation idea is already in the repository incoming packages.

All recorded programs include parsing/imports and explicit ACCEPT output.
Completeness uses idealized unbounded finite resources; CPython recursion,
integer-conversion and parser bounds can reject some large valid inputs.
Finite regressions are not a proof of the universal Python semantic theorem.

4. Already-proposed mathematical and representational ideas

The README and unified article already cover extensive permutations of
one-term transport, restricted transport sources, fused evaluation/discharge,
canonical and zero-normal iteration, root/diagonal introduction selectors,
case introduction at a fixed/newest witness, progressive Q closures,
clause contexts, one-body contexts, and nonstandard sequent/program inputs.

The latest four archives add:
  * structural_parameters: opaque finite-tree eigenparameter names, with
    freshness from proper-subtree size. It is equivalent on the inherited
    contract but does NOT beat the compact envelope. Its strict coordinate
    refinements use shifted sorted syntax with canonical completeness only.
  * exact_threshold: threshold/progress-selector refinements for genuine
    binders, 314/357/590. No global target crossing.
  * local_validation: validation of used values only, an exact actual-binding
    checker 312/353/588 and sorted companion 297/336/556. A separate
    tail_induction.tex replaces backward iteration computation by forward
    iteration plus equation induction with one changing parameter, with
    interpretation proofs but no smaller checker.
  * retained_validation: parity itself validates retained numerical leaves;
    a separate integer coercion is redundant; source-instance opening may
    be deferred until elimination matches. Exact profiles above. No global
    target crossing.

Do not present one of these as a fresh discovery. A source-level variation
may be absent from the finite corpus without constituting a new
mathematical axiom deletion.

5. Practical candidate-audit risks

Evaluation order matters: a witness-dependent expression must be formed
before checking the major allocates the eigenparameter used for discharge.
Checking scope only after the major returns can admit future-witness
capture. A proposal eliminating a floor check or changing packet ordering
needs a new proof, not only regression data.

Equality/Q source inference and root-determined DI modes depend on the
ordinary reading of auxiliary formulas. The compact guarded calculus is
not complete for arbitrary raw Eq/Q/D syntax. The public image translation
cannot simply be omitted: the README explicitly records failures of
raw transitivity and raw case-introduction under the restricted calculi.

Normalization, an external compiler, a generated theorem table, a required
certificate header, and an embedded source evaluator all affect what is
being counted. A tiny wrapper around a larger trusted engine is not a
smaller standalone proof checker by the stated repository criterion.
