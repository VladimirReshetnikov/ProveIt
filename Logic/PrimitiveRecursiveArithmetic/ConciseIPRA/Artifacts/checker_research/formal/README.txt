NativeZeroSource.lean is an unchanged upstream source file, included for
auditability of the inherited nonzero-source transport theorem. It belongs
to the complete Lean project in VladimirReshetnikov/ProveIt, commit
65c32fbe4730bfe5a064502b0b95ebc798c732fa, under
Logic/PrimitiveRecursiveArithmetic/ConciseIPRA/Lean/ConciseIPRA/.

It imports other modules of that project. This archive does not reproduce
that dependency tree and does not claim a new Lean build. The Python
implementation and its proposed refinements have not been verified in
Lean or Rocq. Tests and written arguments have their stated, limited roles.
