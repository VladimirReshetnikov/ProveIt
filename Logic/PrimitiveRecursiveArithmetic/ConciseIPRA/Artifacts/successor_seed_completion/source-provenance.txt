OFFLINE REPRODUCTION
--------------------

From the package root, run:

  python3 code/audit_novelty.py

This uses only Python's standard library and the bundled sources/. It needs
no network, git executable, or checkout. Git blob identifiers are recomputed
as SHA-1 of b"blob " + decimal byte length + NUL + archive bytes; the commit
above is fixed provenance, not a newly inferred repository state.

The scan recursively includes embedded ZIPs and deduplicates archives and
TEX/MD/TXT documents by SHA-256. It reproduces:

  9 direct archives; 14 distinct archives including embedded ZIPs;
  105 distinct TEX/MD documents; 187 distinct TEX/MD/TXT documents;
  61 documents with a recorded search match; 0 reading/decoding errors.

It writes evidence/reproduced_novelty_scan.json and
evidence/reproduced_novelty_matches.txt. It also compares the complete direct
archive records, archive inventory, document inventory, excerpts, and counts
against evidence/J_novelty_scan.json. Any discrepancy yields nonzero exit.
That original frozen JSON is left unchanged.

evidence/audit_successor_seed_novelty.py is explicitly marked as the
historical repository-backed script. The portable entry point above is the
one intended for the delivered archive. The original narrative audit is
evidence/J_novelty_audit.txt, including the limited primary-literature check.
