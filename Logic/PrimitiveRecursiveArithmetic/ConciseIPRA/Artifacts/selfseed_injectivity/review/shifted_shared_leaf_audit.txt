2. SORTED READING AND THE ZERO/TRUTH ISSUE

At p protected slots, meaningful depths are formula 2+2p and term 5+2p.
At a term position, nonnegative scalars below 5 denote numerical zero;
scalars 5+2j and 6+2j for j<p denote slot j; a scalar r with k<=r<0
denotes the old rigid parameter r; other scalars denote the opening hole.
At a formula position every scalar denotes the true equation 0=0.

The array reading is inherited unchanged:
  term arity1: successor, with two zero dummy slots;
  term arity3: iterator, with one dummy slot in counter/seed and
               one real state slot in its body;
  other term arities: zero, with semantically irrelevant annotations;
  formula arity1: D, adding its two slots;
  formula arity2: equality;
  formula arity3: Q of its last child, adding one slot;
  other formula arities: truth.
The single traversal law child-depth=d+5-arity realizes these changes.

Using scalar 0 for both numerical zero and administrative truth is safe
because the decoder is sorted. They occur in distinct syntactic positions.
The initial context member 0 is read at formula sort as 0=0. It cannot
identify the false formula 0=S0 with truth: the canonical false formula
is a binary array, and the opener preserves every array's outer arity.
The public interface promises a canonical array formula, so accepting a
bare scalar 0 as an auxiliary goal grants no extra public theorem.

Canonical codes are zero 0, negative parameters unchanged, and protected

3. OPENING, CAPTURE, AND FRESHNESS

The actual opener is partial. At a scalar outside [k,d), it evaluates the
replacement at numerical root depth 5, THEN multiplies its result by
d mod 2. Eager validation must be retained in the argument: a semantically
unused replacement can cause rejection. No claim equates the actual
partial function with a lazy semantic erasure.

If an actual opening succeeds, its meaningful reading is capture-avoiding
substitution for its hole, exactly as in the offset proof. At even depth
the replacement is either 0 or []; both denote formula truth. At odd
depth it is the validated numerical term. A root-validated numerical
image can use only its own protected slots and old negative names, so
insertion below more outer slots captures neither. Lowering a meaningful
depth by 2 exposes exactly the old outermost protected slot.

In particular a D matrix at formula depth 6 opened at depth 4 loses the
existential witness slot and retains the index slot. Opening that result
at depth 2 substitutes the index. Tripling the unary D array and opening
at depth 2 gives its Q resource under the fresh witness.

In this particular multiplication-based module, successful no-image
validation actually fixes the entire raw tree: any scalar fallback would
try to validate the missing function-valued image and fail. This stronger
observation is not required for soundness, but is valid for the exact
candidate. It must not be generalized to earlier short-circuit openers.

A meaningful closed reading at floor k contains only negative names in
[k,0). The new name b=k-1 is therefore fresh for the old goal, context,
major, and any witness opened before allocation. Positive reserve aliases
3 and 4 denote zero; they cannot name b. All future-name checks remain on
the unchanged negative floor.

4. THE SHARED LEAF

Unlike the older offset472 module, the candidate reads one packet BEFORE
checking context membership. It builds the equation

  J(s,u,t) = [[s and [s],u,t], O(t;[s,u,t],5) if s else u].

It accepts this leaf if the validated goal belongs to g+[J(s,u,t)].
If it belongs to g, the hypothesis rule is sound; the additional preview
has merely imposed a possible extra rejection. If it equals J, the same
sorted direct-computation lemma as in OFFSET_PROOF section 4 applies.
The equality to a validated goal ensures that J has a closed meaningful
reading, although J was assembled from raw annotations.

For false-valued s (0 or []), J reads I(0,alpha;v.h)=alpha.
For true-valued s, it reads I(S sigma,alpha;v.h)=h(I(sigma,alpha;v.h)).
When h uses its state, actual image validation makes the two predecessor
and seed readings agree; when h does not use its state, the right-hand
reading is h independently. Raw truthiness of s is not numeric nonzeroness:
a true raw zero alias still gives a legitimate native computation.
Hence no unchecked equation is introduced by merging the two leaf tests.

5. NONLEAF SOUNDNESS

Every nonleaf first checks c(g,m,k), using the OLD floor k. A successful
compact call returns a nonempty one-element list, so its truth value is
always true. The readable expansion returns True instead; these values
are interchangeable at every caller, since only their truth value is used.
There is no bypass of recursive major verification.

For a true-valued unary major m=[B], m*3 opened at b supplies Q_y B(b,y).
Its old reading is D_{x,y}B. The replacement test cannot match this unary
major, so the branch proves the old b-free goal; native DE discharges it.
For other true majors the tripled array/scalar reads truth. If the paired
replacement test matches a binary major, it is ordinary equality
transport; if it matches a ternary major, it is QE. Otherwise the goal
reading is unchanged. Equality transport and QE occur inside the NEW
scope, because the actual tuple tests are evaluated after allocation.
This is sound: the branch obtains the OLD goal, whose reading is b-free,
then the irrelevant fresh parameter and truth assumption can be discarded.

For a false-valued major, witness opening occurs before allocation at
depth 4. Thus its numerical witness has only old parameters. The
continuation at depth 2 with image [b] reads the successor instance.
The added hypothesis reads the predecessor instance for a binary matrix
and the zero instance for a meaningful compound matrix. These are
equation progress and case introduction, respectively. Other successful
arities have true readings. The replacement test cannot activate in
this false-major case, because its proposed major is a nonempty binary
or ternary array.

The eager expression any((m,3%len(a))) may reject additional malformed
goals, but whenever it is defined it chooses exactly the inherited mode.
Canonical nonleaf formula goals are nonempty arrays, so completeness
does not lose any such introduction or elimination.

Induction on the finite call tree now proves native soundness of every
accepted raw trace. Initially g=[0] contains only the theorem 0=0.

6. CANONICAL COMPLETENESS AND PACKET CONSUMPTION

Use the established compiler for the guarded source-selected calculus,
with shifted codes and scalar 0 for the administrative major. Opening
commutes with canonical encoding and the offset preserves every arity,
logical rule, and negative eigenparameter. Genuine source hypotheses
remain canonically present in the context. Semantically true garbage
triples are not used to discharge genuine source hypotheses.

The shared-leaf protocol requires a packet even for a retained hypothesis,
including the auxiliary major 0. The universally safe dummy packet is
[0,0,0,0]: its computation preview is [[0,0,0],0] and needs no recursive
image validation. A retained canonical hypothesis therefore consumes this
single packet and returns. In particular c(g,0,k) with 0 in g is realized
by one such packet, not by an empty stack. This is the necessary change
from the older offset472 compiler.

For a non-hypothesis, choose the usual source instruction. If its
computation preview already proves the current goal, emit that one packet
and omit descendants. Otherwise recursively compile the major and the
continuation, after allocating their stated scopes. Serialize so the
parent packet is popped first, then its major stack, then its continuation
stack. This branch-aware construction consumes EXACTLY the intended
packet suffix at every call. One cannot excuse unused descendant packets
inside a major proof by citing the allowed unused outer prefix: they
would obstruct its caller's continuation. The construction prevents them.

Canonical zero-predecessor successor computation uses the same certified
nonliteral-zero repair as the unshifted source-selected presentation.
No new special case is needed or omitted by the offset.

Every public theorem consequently has a finite accepted shifted certificate.
Soundness and completeness concern exactly the canonical public theorem
set, not literal recodings of every arbitrary raw accepted certificate.
