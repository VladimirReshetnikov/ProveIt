SHIFTED SHARED-LEAF CHECKER
==========================

checker468.py independently reconstructs an existing compact representation
composition. Its normalized size vector is 271 tokens / 305 AST nodes /
468 bytes, with gzip-9 size 309 bytes. The exact historical shared-leaf
control is 272 / 306 / 469 / 309. This is a one-byte historical comparison,
not a new current record and not an arithmetic axiom deletion.

The final freshness audit at repository commit
96c398c189048d713bc692720e6d72416fde40a7 found the newly added incoming
ipra_468_presentation.zip, whose compact468.py is byte-identical to this
file. Its Git blob is 00ec3419184ad8bc31a4e26d60faca5deecc4e20. The current
combined compact envelope is 240 tokens / 261 AST nodes / 468 bytes,
attained by different programs and input framings. This reconstruction
therefore makes no new compact-frontier claim. The new mathematical
result in the main report is the separate self-seeded axiom deletion.

The reconstructed checker accepts the same guarded public theorem set as its
469-byte control. It preserves the inherited full intuitionistic iPRA
bi-interpretation and equiconsistency. See PROOF.txt for the precise
input contract, shifted syntax, universal written proof, and limitations.
The public goal and integer/list alphabet are promised by the interface;
this is not an arbitrary-JSON validating checker.

Run with Python 3.12:
  python3 checker468.py < fixtures/shifted/guarded_induction_with_used_hypothesis.json
  python3 verify.py

verify.py uses only the standard library and the files in this directory.
It reruns 126 isolated normal/-O checks and writes evidence/verification.json.
The translator is untrusted and supports canonical source certificates
only. checker_readable.py exposes the same scope schedule and packet rules.
controls/ contains exact inherited sources. reference/ contains attributed
proof ingredients. SOURCE_PROVENANCE.json records exact repository paths,
archive identities and source hashes. No remote repository was modified.

This companion does not beat the independent current 240-token and
261-AST-node records, ties the existing 468-byte source size, and does not
establish a simplest mathematical axiomatization.
