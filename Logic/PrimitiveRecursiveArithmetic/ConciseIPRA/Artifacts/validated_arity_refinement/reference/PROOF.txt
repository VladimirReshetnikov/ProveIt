EXACT ARITY-MODE REFINEMENT OF THE FULLY VALIDATED iPRA CHECKER

The candidate differs from the pinned 599-byte control by precisely one
predicate replacement:

    v <= (len(a) in (1, 2 + d % 2))

becomes

    len(a) ** v in (1, 2 + d % 2).

Invariant: at every evaluation of this predicate, v is either 0 or 1.
The initial public-goal call explicitly supplies v=1. Every recursive call
uses the default v=0. In the initial call, v is assigned 0 after the first
opening has completed and before subsequent proof operations. The recursive
opening closure uses that same local flag. There is no user assignment to v.

The preceding short-circuit condition a*0 != 0 ensures that, on inputs that
pass the whole-JSON alphabet validation, this predicate is evaluated only
for a list. Hence n=len(a) is an ordinary nonnegative integer. The candidate
does not change the preceding condition, the JSON parser, or the alphabet
validation; values of forbidden JSON types are rejected before checking.

For v=1, n**v=n, and 1 <= Boolean(P) holds exactly when P holds. Thus the
two predicates agree. For v=0, 0 <= Boolean(P) always holds; n**0=1,
including 0**0=1; and 1 belongs to (1,2+d%2). They again agree. This proof
does not require d to be nonnegative, nor any fixed arity bound.

The predicates have no side effects and raise no exceptions for finite
integer/list inputs under ideal finite-resource semantics. Replacing one
with the other therefore preserves every branch, returned value, input
packet read, context mutation, and scope-allocation event. Both the public
grammar check and the subsequent proof execution are identical. Consequently
the two complete modules have the same successful finite input/output
relation, with no certificate translator and no change in the input contract.
The test harness rotates legacy fixture packets only because those inherited
fixtures predate BOTH the control and candidate; both receive identical input.

The existing control's ordinary Eq/D calculus, full iPRA bi-interpretation,
whole domains, actual equality, both formula round trips, and identity
comparison graphs transfer without alteration. This change deletes no
mathematical axiom or inference rule. It is a strict source-size improvement
for the fully validated presentation, not a new mathematical foundation.
