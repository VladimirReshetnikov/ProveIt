the same list, and recursive continuation calls use g + [hypothesis], again
a list. Neither program can obtain a context value from certificate data.
Python iteration of the bytes object b'\x00' yields exactly one integer, 0.
Therefore in-place list extension by that object has exactly the same effect
as in-place list extension by [0]. The identity of the mutated list is also
the same. This matters because major calls may retain an alias to it.

same context object with the same sequence of entries. They next read the
same packet, evaluate the same expressions, reserve the same eigenparameters,

used. An induction on finite execution traces establishes exactly the same
successful input/output relation. The proof assumes ideal finite resources,
