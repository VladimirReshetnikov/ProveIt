1. What “lower bound” currently means

No general proof-checker-size lower-bound theorem is established by these packages. They report observed minima in a specified source/runtime/interface class. It is incorrect to call a smaller program a violation of a mathematical lower bound, or to infer absolute simplicity from beating those observed minima. The minimum is coordinatewise: different programs attain the token, AST, and byte records.

The repository says CPython 3.12.14; remove leading module/class/function docstrings recursively (repair empty nonmodule bodies with Pass), then normalize the entire source using ast.unparse + LF, significant lexical tokens excluding comments/layout/encoding/endmarkers; AST includes operator/context nodes. Standard Python plus standard-library JSON parser is ambient. Packed execution wrappers are a separate accounting class, and some small modules are partial utilities or explicitly rejected unsound experiments.

Agent kernel_candidate is investigating it.

A 465-byte source is present in ipra_whole_json_refinement_2026-11-12/negative/REJECTED_UNSOUND_no_parity.py. Its filename, report, and tests explicitly exclude it. Do not report an unclassified raw source minimum as a sound checker frontier.

The compact programs have a promised canonical closed GUARDED Eq/D public goal and finite exact-integer/list proof alphabet. They do not validate all these conditions. Comparing a 606-byte whole-input checker directly with a 469-byte compact checker hides trusted interface work. Full validation and compact promised validation are separate classes.

Some accepted proof fixtures use auxiliary Q formulas or unguarded equations. Auxiliary success does not extend the public theorem contract. In particular the guarded source-restricted calculus is strictly weaker on arbitrary open sequents; it is equivalent after the prescribed public translation. README cites native Lean countermodels for the loss of transitivity and atomic case introduction.

4. Scope of bi-interpretability

The repository adopts an unusually strong record convention: whole numerical domains, actual equality, both numerical comparison graphs x=y. The user explicitly allows a different language and domain, requiring only equiconsistency and bi-interpretability. Thus an alternative domain with definable nonidentity round-trip isomorphisms is allowed by the USER, even though it would be outside the existing stricter record convention. Do not accidentally impose the repository convention as an extra user constraint.

Full first-order intuitionistic PRA is the target. Showing only the primitive recursive functions agree, only quantifier-free conservativity, only mutual interpretability, or only equiconsistency is insufficient. A complete proposal must supply formula translations, soundness in both directions, and definable round-trip isomorphisms (or identity when appropriate).

5. Existing mathematical reductions already covered

The corpus has already explored: one D binder; no Q via clause contexts; ordinary formula assumptions encoded as one-body gates; one-term, one-occurrence, all-occurrence, variable-only and newest-variable equality; equality fused with evaluation or discharge; raw, zero-normal and full-normal syntax; computational root conversion; deterministic witnesses and specialization; successor-seeded, counter-aware, self-seeded, no-constant recursors; uniform terminal certificates; scalar uniqueness, successor rigidity, progressive closures; and many negative results for restricted recursors or omitted induction.

The established fewest rule-family calculus is three families (Use, Intro, Name/Open/Discharge) with fixed reflexivity clause and normalization infrastructure. Rule-family count alone is therefore not an honest new complexity record. It is easy to combine arbitrary rules using tags into one family without reducing the checker.
