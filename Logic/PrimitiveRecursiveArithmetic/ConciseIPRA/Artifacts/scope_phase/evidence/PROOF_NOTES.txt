NATIVE STRICT CHECKING WITH THREE FIELDS AND ENTRY RESERVATION
============================================================

Status
------
This is a new checking presentation of the inherited native scalar calculus.
It does not delete a logical or arithmetic axiom. Its whole-domain ordinary
realization and identity bi-interpretation with first-order iPRA are inherited
from the pinned ConciseIPRA development. The new contribution is a scope and
phase invariant, together with a direct-terminal three-field composition.

The delivered profiles have different certificate protocols and must not be
identified as one checker. Under CPython 3.12.14 whole-module normalization:

  checker_tokens302.py       302 tokens / 352 AST / 646 bytes
  checker_ast340.py          314 tokens / 340 AST / 681 bytes
  checker_bytes584.py        311 tokens / 362 AST / 584 bytes
  checker_entry_tokens304.py 304 tokens / 349 AST / 646 bytes

The first retains an explicit initial-validation bit and reserves a new name
at return. The remaining profiles reserve a name immediately after their
entry scan and use the floor itself to identify the validation phase. The
first, second and fourth read three fields; the byte profile reads four.
All read one complete JSON value, validate the entire integer/list alphabet,
and validate the same native Eq/D public goal grammar with zero encoded by 1.

No statement of exact acceptance equality on arbitrary raw certificates is
made. The new floor schedules change the names available in annotations.
No single delivered program is below 306/348/589 in all three coordinates;
the new coordinatewise envelope 302/340/584 is attained by three programs.
The compact promised-grammar frontier is not beaten. No absolute minimum
or new Lean/Rocq verification is asserted.

1. Input and public grammar
--------------------------
The lexical gate str(p).strip('0123456789-[], ') admits exactly the finite
exact-integer/list trees among values returned by the standard JSON reader.
A forbidden value anywhere, including an unused prefix, prevents q from being
a callable packet reader. This is the inherited strict whole-input gate.

At initial depth d=0, public arrays have length 1 or 2+d mod 2; recursive
children have depth d+5-r for an array of length r. Public scalars satisfy
0 <= a < d, with d odd and a odd. Thus public numerical zero is represented by
1. An invalid array falls to a scalar comparison and fails. An invalid scalar
consults the missing image and fails. In the byte profile the eager product
consults that missing image even at an even depth, so invalid scalar formulas
are not silently turned into truth. Every accepted public goal is therefore
in exactly the inherited native Eq/D1 grammar.

The token profile has v=1 during its first complete scan, then v=0 forever.
The entry profiles start at k=0, use strict tests exactly while k=0, and change
k only after the complete root scan. From that moment k is strictly negative
and only decreases, so no separate validation bit is needed.

2. Three-field direct terminals and the atomic-mode correction
-------------------------------------------------------------
A three-field packet is (s,u,t). Before nonterminal reasoning, the checker
accepts a hypothesis or a computation frame. On a nonterminal endpoint match
O(t;u)=A, it replaces the goal by O(t;s), replaces s by the reconstructed major
[s,u] when s is truthy, or [t,t,t] otherwise, and then PROVES that major.
Thus equality transport and closure specialization still check their major.
A nonmatching truthy s is proved and supplies its repeated closure, as in the
inherited three-field protocol. A nonmatching false s introduces the paired
binder at witness t.

Crucial: after computation is moved to terminals, the old selector
len(A)%2 == u is NOT sound. A nonterminal packet with u=1 would select progress
at an odd-arity compound matrix. The delivered code instead uses exactly

                  len(A) == 2 == u.

So progress is possible only at a literal equation, with marker u=2. Case
introduction uses u=[] (u=0 also selects cases). This exact atomic restriction
is part of the specification, not an implementation option. The prior
three-field supply checker could use u=0 for progress because every truthy u
was intercepted by its computation branch; that argument is unavailable once
that branch is removed.

3. Entry reservation: the new invariant
--------------------------------------
Consider a call whose input goal and context have the inherited sorted reading
closed over names already in scope at floor K. The entry scan O_K(A) occurs
BEFORE the floor changes. Immediately afterward set alpha=K-1. The name alpha
may occur in subsequent packet fields. It is an additional arbitrary free
parameter; it is not the discharge eigenparameter of this call.

If the call is nonterminal, its preimage H is formed at alpha:
  H = m*3, or the matrix of A opened at its proposed witness,
with m replaced by s in the three-field program. This formation, in particular
witness opening, happens BEFORE the recursive major call.

Every recursive major call first scans its own goal and then decrements the
floor. Therefore when that major call returns its final floor beta is strictly
below alpha. Every active numerical parameter of the already formed H, the
parent context, and the pre-major goal lies at or above alpha. The name beta
is consequently fresh for all of them. Further decrements inside the major
can only make this freshness stronger. Its returned theorem remains about its
input formula, which was scanned before its own entry reservation.

The parent then opens H at beta (progress/discharge) or zero (cases), opens its
continuation goal at the corresponding successor, and checks the continuation.
This is the same numerical eigenparameter condition used by the ordinary
native rules. The unused name alpha requires only ordinary weakening of the
ambient parameter context. It does not supply an assumption or an induction
hypothesis, and the parent conclusion was checked before alpha was admitted.

For the lazy opener, use semantic closedness in the inherited sorted reading,
not the false claim that every raw scalar annotation is literally in scope.
An ignored formula-slot scalar reads as truth. Active numerical slots are
validated by the old-floor scan and by the semantic exposure lemma. The eager
byte opener additionally validates images at even fallback positions.

The decrement is placed as the first member of the membership tuple. This
member cannot discharge the old-scanned goal: a successful scalar O_K(A) is
an old in-range scalar (or the neutral scalar), never K-1; a list is not that
integer. Thus the tuple element performs allocation only.

4. The delayed endpoint in the four-field byte profile
------------------------------------------------------
The four-field packet is [s,u,t,m]. Its major is proved at the old scope for
that major; the witness/matrix preimage was already formed. The endpoint test
is evaluated after the major returns, at beta. This does not combine a late
substitution with a witness-dependent discharge:

* Only an equality major or a closure major can literally equal [s,u] or
  [t,t,t]. In these cases m*3 has the neutral auxiliary reading, and any extra
  parameter admitted in an annotation is ordinary parameter weakening. The
  literal major identity and semantic opening lemma justify transport/QE.
* A paired-binder major has unary arity, so it cannot satisfy either endpoint
  identity. Its old goal is retained and is fresh for beta; this is DE.
* A false major likewise cannot satisfy the endpoint identity. Introduction's
  witness was opened before the major call and is fresh for beta.

These are the inherited separate semantic cases; no blanket literal
closedness statement for all malformed annotation trees is used.

5. Soundness and canonical completeness
---------------------------------------
For soundness, induct on the finite successful call tree. The entry scan and
whole-input gate establish the alphabet and public contract. Hypothesis and
computation terminals use the inherited reading of those terminals. At each
nonterminal, the proved major, semantic opening, exact atomic progress test,
and freshness invariant of section 3 give the corresponding native inference.
The auxiliary neutral is 0 for the lazy profiles and [] for the eager profile;
both have the truth reading. The final public theorem is therefore a theorem
of the inherited native calculus.

For completeness, start with canonical native proof trees. Introductions,
transport, closure specialization and paired elimination compile with exactly
their existing templates and witnesses. Progress uses the marker 2, cases [].
A three-field computation needs only its predecessor, seed and body. Genuine
canonical term annotations cannot accidentally match a formula endpoint,
because terms have no binary equation node. If a direct terminal closes a node
early, emit only its packet and omit its now-unused subtrees.

Assign fresh negative names as the compiler traverses the new schedule. For
entry reservation, ignore alpha as an unused ambient parameter and map the
source derivation's next eigenparameter to beta after the major. Canonical
annotations mention only already assigned names, so all extra scans succeed.
The major's complete finite subtree is emitted before the continuation's.
For return reservation use the established return-reservation naming schedule.
This recursive construction preserves the closed public goal literally.

The executable compilers supplied here implement that construction for the
packaged canonical fixtures. They are deliberately untrusted and are not
claimed to translate every arbitrary aliased bytecode accepted by a control.
The general mathematical completeness argument is about canonical derivations.

6. A concrete failure if the order is reversed
----------------------------------------------
Let C(y,a,b)=I(y,a;u.b). The public formula

                   D_{x,y}(C(y,0,x)=C(y,0,y))

is false in the natural numbers: its base is 0=0, and its y=1 and y=2 instances
would force x=1 and x=2. The new five-packet capture fixtures attempt witness
S(beta), where beta=-2 is the name reserved by the root's neutral major call.
If the witness is opened only AFTER that call, the progressive step is the
reflexive equation C(S(beta),0,S(beta))=C(S(beta),0,S(beta)). It has a short
proof from two zero-computation leaves and transport. The assumption is unused.

The delivered checkers reject before beta is available to the witness. The
explicitly UNSOUND diagnostic variants reverse just that evaluation order and
accept the false public goal, in normal and optimized Python. The receipt
records both outcomes. This demonstrates why the preimage-before-major order
is indispensable even though entry reservation otherwise admits one extra
free parameter.

7. Interpretation and limits
----------------------------
The ordinary realization, vocabulary macros, numerical domain and equality
are unchanged. Composing checker soundness/completeness with the inherited
native-calculus correspondence and whole-domain identity bi-interpretation
with iPRA transfers both bi-interpretability and equiconsistency. This is an
inherited foundational theorem plus a new checking-presentation theorem; it
is not an independently mechanized re-proof of the arithmetic bridge.

Finite tests are supporting evidence. Resource exhaustion can reject a large
valid proof; the usual mathematical completeness claim concerns finite runs
with no fixed global memory or recursion cap. Measured profiles import only
the Python standard JSON reader, never a producer, theorem database, normalizer,
this compiler, or these proof notes.
