Independent source certificates for deterministic-specialization translation
===========================================================================

These eight JSON certificates are in the unrestricted source checker's
oldest-first, four-field Use format. Their validity is checked before
translation. The main portable suite should forward-translate each, check
the deterministic result, reverse-expand that result, and check the expanded
unrestricted proof. Both directions must preserve the goal literally.

compound_rank_1 / 2 / 3
  The clause body has one, two, or three D binders over a reflexive equation
  containing the specialized numerical parameter. The chosen target is a
  nonliteral iterator term, so target deletion requires the naming and full
  formula-transport constructions. In the compound transport branches, the
  naming clause ceases to be newest; its equality must be regenerated by U_0.

persistent_compound_rank_1 / 2 / 3
  In addition, the antecedent proof is itself a Use of a compound ordinary
  assumption. Its source tree must be compiled again when the surrounding
  specialization opens another naming scope. The numerical target contains
  an older free parameter, so simply treating every free parameter as the
  newest parameter would fail. These cases exercise the source-proof-height
  persistence argument as well as the formula-rank argument.

dependent_binders
  The innermost arithmetic expression contains both coordinates bound by D,
  and the transported external parameter also occurs under nested iterator
  bodies. This checks that opening the witness coordinate at depth 1 and
  the closure coordinate at depth 0 preserves the remaining template binder.

persistent_dependent_binders
  Combines the dependent-binder expression with the persistent-antecedent
  and older-free-parameter conditions described above.

These are finite implementation checks. They do not replace the written
universal proof or constitute a proof-assistant verification.
