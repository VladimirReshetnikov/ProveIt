2. Trust boundary and comparison convention

Each measured complete module contains its input loading, syntactic opening/validation, inference dispatch, arithmetic computation supply, fresh-name bookkeeping, and ACCEPT output. It imports only standard json; no theorem producer or arithmetic evaluator is imported. Standard Python, the JSON decoder, and runtime implementations are excluded uniformly. This is the same convention used by the drafts. Size counts remove comments and genuine docstrings, run ast.unparse, and append one newline. Token counts omit whitespace/comment/layout tokens. AST counts include the whole module and driver. Gzip is gzip.compress(raw,compresslevel=9,mtime=0), including wrapper bytes.

Successful checking requires zero process exit and exactly ACCEPT output. Ordinary exceptions reject via nonzero process exit. The older explicit REJECT print wrapper is unnecessary under this common convention; matched-driver controls already appear in current drafts. Changing the success protocol cannot fairly be represented as a foundational simplification.

The byte leader uses a*0==[] as an exact-JSON-list test. The recommended source uses isinstance(a,list), adding 8 normalized bytes. The joint token/AST leader uses exception-based generic traversal; its handling of malformed nonempty strings relies on Python's finite recursion limit, so it is not structurally terminating on all finite JSON for an ideal unlimited stack. This is disclosed in the draft. Canonical array/number proof syntax is structurally recursive in every profile.

3. Current architecture; ideas that are already present

Native formulas are equality plus Q_y B and D_xy B, with intended readings B(0)->forall y B(y), and exists x(B(x,0)->forall y B(x,y)). Primitive rules: hypotheses, equality transport, Q elimination, D elimination, D case introduction, equation-only D progress introduction, and known-zero-instance computation supply. The initialized scalar iterator I(n,a;v.h) has the two ordinary computation equations. The logical/arithmetic interpretation bridge is inherited through most current drafts.

Arity-calculus representation already gives Eq=[s,t], D=[B], Q=[B,B,B], uniform opening increment 5-len(node), numerical roots at depth 3, and high-arity ignored nodes interpreted as zero/truth. The scalar iterator update binds one state, not the recursion counter. Primitive recursion is derived through pairing after predecessor and equality reflection. This representation removes arity tables but has intentional annotation aliases; it is not a conventional explicit AST type checker.

Affine-arity representation already replaces lookup by d+len(a)+1 and adds harmless dummy coordinates, using false interpretation for sufficiently large formula arrays with an exact introduction shape guard.

Uniform-predecessor packets already construct successors from supplied predecessors. Flat computation already uses boxed predecessors to postpone validation without losing equations. Constructed-computation already constructs computation source terms rather than accepting and separately checking them. Local scopes already explore branch-local allocation. Affine supply already combines affine scoping, arity encoding, predecessor packets, and immutable contexts in a loop; mutable shared contexts are unsound.

Certified zero already removes the separate arithmetic opcode by using truthy/nonempty initializer syntax as the dispatch. C=I(2,1;v.0)=0 is established directly with nonzero raw predecessor/initializer, and a single equality transport replaces forbidden zero seeds and zero successor predecessors simultaneously. Each excluded computation leaf becomes exactly three native nodes. Shared continuation-hypothesis construction supplies much of its source saving. Do not rediscover this as new.

4. Important existing negative results and failed simplifications

Adaptive-seed draft: restricting elimination majors to retained hypotheses loses even closed Q_y(0=0). The explicit proof and a structural root invariant rule out recovery in that exact changed Eq/Q/D calculus. This does not rule out removing Q from public goals, adding a charged Q introduction, or a genuinely different calculus; it rules out merely deleting recursive major checking.

Local-scopes/adaptive/uniform drafts: tied-seed or same-body feedback numerical languages have strong almost-unary bounding obstructions, including versions with bounded observations, unary PR functions, finite registers, and quotient domains. Some stronger variants rule out full first-order bi-interpretations using arbitrary formula-defined operations under specified axioms. These results have carefully stated scope; they are not blanket impossibility theorems for all smaller theories.

Bounded-initializer draft: adding a Boolean numerical actual-equality test to a tied-seed language restores a full-domain interpretation using bounded compilation and coherent caps. This new arithmetic theory is distinct from that draft's measured checker, which remains the inherited initialized-I/Choice-DI calculus.

Certified-zero eager obstruction: F(0,a;h)=h(a), F(Sn,a;h)=h(F(n,a;h)) admits a two-element model, even with separation, coverage, and all-formula induction. Thus that tempting seed fusion cannot interpret iPRA in ordinary finite-dimensional definable domains/quotients.

Compact-kernel symmetry result: eventual-constant powers retain involutions even under broad positive induction fragments, obstructing bi-interpretability. Again distinct from its positive inherited checker.

5. Focused correctness review and executable reproduction

The certified-zero normalization argument is valid at the canonical native-rule level: the single closed C=0 certificate repairs initializer and predecessor simultaneously by literal equality transport. In raw syntax the new computation hypothesis H(k) need NOT hold at every fresh k; only H(0) is guaranteed. Soundness uses capture-avoiding zero-substitution into the continuation and a cut against that computation theorem. Old-floor validation of retained goals/contexts is essential. Fractional negative names admitted in the new unit interval must all be replaced, not silently conflated with the designated integer. The draft explicitly handles this.

I found no concrete new correctness defect in this focused kernel/normalization audit. That is not full proof-assistant verification of the inherited arithmetic/logical metatheory. No draft supplies Lean/Rocq verification of the whole equivalence. The principal current improvements are representation/program reductions, and the drafts themselves correctly avoid claiming a major new axiomatic foundation or absolute minimality.
