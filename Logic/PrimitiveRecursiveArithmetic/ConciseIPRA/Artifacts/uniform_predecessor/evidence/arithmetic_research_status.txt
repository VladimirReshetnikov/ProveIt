Arithmetic research status, 2026-11-10
====================================

No positive numerical-basis reduction beyond the current 16-draft corpus has
been established. The scalar successor-seeded R basis and its initializer
compiler are already solved in scalar_successor, successor_seed_completion,
and transient_seed; claiming them again would repeat the current frontier.

New written theorem: single_body_barrier.tex
------------------------------------------
Extends the tied-seed one-bounding-coordinate obstruction to arbitrary fixed
finite registers, arbitrary fixed finite probes of ONE body, target-counter-
dependent initialization probes, arbitrary PR index maps, arbitrary PR maps
combining probe outputs, and nested finite descriptions. It still holds if
all unary PR maps and every bounded PR predicate are freely adjoined.

The theorem and proof are self-contained standard-model metamathematics. It
is a term-representation obstruction only. It does not rule out relational,
quotient, or changed-domain bi-interpretations. No empirical tests or source
metrics are asserted for this theorem.

Novelty scope: the exact general theorem does not occur in the inspected
current archives. The base one-bounding-coordinate idea is explicitly
inherited from current transient_seed and counter_congruence proposals.

Why easy alternative routes did not close
----------------------------------------
1. A graph-defined selector can exist in ordinary intuitionistic logic even
   when no selector term exists. But adding that function by definitional
   extension does not automatically extend the old B_h recursion schema to
   bodies involving the new function. The missing recursion closure remains.
2. Binary-tree domains offer PR encodings and potential whole-domain
   equivalence, but folds require constructor/pattern bookkeeping or input
   projections; no reduction of the complete checking mechanism was found.
3. Body-syntax-dependent arithmetic (e.g. one behavior when a variable is
   absent) risks violating capture-free substitution or merely disguising
   additional constructors. No valid smaller presentation was obtained.
