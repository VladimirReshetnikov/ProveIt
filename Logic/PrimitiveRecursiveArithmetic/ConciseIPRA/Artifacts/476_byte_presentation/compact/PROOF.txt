    274 significant Python tokens, 306 AST nodes, 476 UTF-8 bytes.

is the compact477.py member of the current incoming head-conversion ZIP.
The new module changes exactly one expression:

    bool(m or 3 % len(a))

to

    any((m, 3 % len(a))).

This is a one-byte improvement, a two-token increase, and no AST-node
change. It improves the byte coordinate of the current compact envelope

This is an implementation refinement of an inherited iPRA presentation,
not a deletion of a mathematical rule or a proof of absolute shortestness.

The eager-selector idea is already in the boolean-constancy archive,

2. UNCHANGED PUBLIC THEORY AND CERTIFICATE CONTRACT

The input is a finite JSON array consisting of exact-integer/list trees,
consumed from right to left. Its final item is [A,0], where A is a closed
canonical guarded Eq/D public formula and 0 is the initial scope floor.
Every preceding consumed instruction has four fields [m,s,u,t]. The
initial retained administrative resource is []; a canonical unused major
is also []. Unread array prefixes are permitted, just as in the control.

The program checks certificates for this fixed public syntax; it does
not validate the entire promised alphabet or public grammar. This is
exactly the control's contract, with no new promise or external oracle.
Successful acceptance is normal termination, zero exit status, and
exactly ACCEPT followed by LF. Exceptions reject. The reader and output
are included in the complete module and all three measurements.

Define G476 and G477 to be the respective sets of canonical public
formulas having an accepted finite certificate. The result below is
G476 = G477. The unchanged interpretation of the public guarded theory
therefore supplies its equiconsistency and bi-interpretability with
first-order intuitionistic primitive recursive arithmetic. No new
numerical domain, equality relation, or interpretation map is introduced.

3. UNIVERSAL SOUNDNESS BY SUCCESSFUL-TRACE SIMULATION

Let e denote 3 % len(a), evaluated at the mode selector. For every JSON
tree m and every defined e,

    bool(m or e) == any((m,e)).

Both return the disjunction of the truth values of m and e. All these
values are ordinary integers or lists; no overloaded truthiness or
user-defined side effects are present. The only evaluation difference
is that tuple construction computes e even if m is true. The operations
len and integer remainder have no state-changing effect.

Consider a successful finite execution of compact476.py. At every
reached selector, e was defined. Replace just that selector evaluation
by the old expression. It returns the same Boolean and changes no
state. In particular, the major-premise check and construction of the
old-floor raw hypothesis occur before both expressions, and the scope
floor decrement occurs after both expressions. There is no reordering
of a recursive proof check, any assignment to a, any context extension,
any certificate read, or either scope-sensitive opening.

Induction on the complete finite evaluation trace, including all
recursive major checks, gives an accepted execution of control477.py
on exactly the same parsed certificate. Hence every newly accepted
certificate was accepted by the sound control. This argument covers all
auxiliary integer/list payloads allowed by the unchanged contract, not
only canonical compiled proofs. Thus G476 is a subset of G477.

4. CANONICAL COMPLETENESS

The established completeness compiler for G477 uses genuine numerical
terms and genuine Eq/D formulas, together with the canonical internal
Q resource and the neutral administrative resource []. Genuine Eq, D,
and Q formulas are nonempty arrays, of arities two, one, and three.

At a formula goal the array is therefore nonempty. A genuine
introduction changes a to an instantiated formula matrix, again a
nonempty formula. A retained neutral major [] is checked immediately
against the initial resource; it returns before a mode selector is
reached. Other canonical administrative truth resources are nonempty
arrays. These facts also hold in recursively checked canonical majors.
Consequently every mode selector reached in a canonical compiled trace
has a nonempty array a. The additional evaluation 3 % len(a) is defined.

The same trace induction as in Section 3, now in the other direction,
shows that each canonical G477 certificate is accepted unchanged by
G476. The canonical compiler supplies such a certificate for every
theorem of the public guarded theory. Thus G477 is a subset of G476.

Together with soundness, G476 = G477. Compose this identity on public
formulas with the existing numerical and logical bi-interpretation.
The interpretation, its inverse, the domains, and both comparison maps
are unchanged. This is stronger than merely observing equal outcomes
on a finite regression suite, but it inherits the control's established
soundness/completeness and theory-to-iPRA bridge.

5. PRECISE LIMITS

The soundness argument establishes subset inclusion of accepted raw
certificate languages. We do not claim that this inclusion is strict,
or that the raw languages are identical. No raw-acceptance separating
certificate is included. The older Boolean-constancy boundary for
479 versus 478 bytes does not separate the present 477/476 pair after
its certificate is recoded to the current protocol.

No Lean or Rocq formalization of this Python transformation is claimed.
The current minimum is an observed record in a specified source
collection, not a mathematical lower bound over all presentations.
Physical resource exhaustion can reject finite proofs too large for
the available interpreter; this operational limitation is unchanged.
