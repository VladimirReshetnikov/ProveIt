COMPACT CORRECTNESS
The sole edit is bool(m or 3 % len(a)) -> any((m, 3 % len(a))).
Every successful new run is an old successful run on the same certificate:
the new eager remainder is pure, and the selector returns the same Boolean.
Every theorem retains a canonical accepted proof, because each reached
selector has a nonempty formula goal. Neutral [] majors return from the
retained-resource check before reaching the selector. Thus the public
canonical theorem sets agree, and the inherited whole-domain,
actual-equality bi-interpretation with iPRA is unchanged.

The compact contract promises a closed canonical guarded Eq/D public
goal and finite exact-integer/list proof trees. This module does not
validate that entire promise. The input is a JSON stack ending in
[goal,0], with earlier four-field packets [m,s,u,t]. Administrative majors
are []. The reader and ACCEPT output are included in all measurements.
No extra promise or external proof oracle is introduced by this change.
No equality or strict difference of arbitrary raw acceptance languages
is claimed. There is no new Lean/Rocq verification.

clause, and three inference families: Use, diagonal Intro, and partial
evaluation with witness discharge. It has a direct same-tree
substitution theorem, and is equivalent to the existing diagonal clause
calculus, hence bi-interpretable and equiconsistent with iPRA.

Its complete strict normalized checker has vector 678 / 727 / 2087,
versus 688 / 735 / 2128 for the matched four-family diagonal reference.

643 / 695 / 1892. PD itself does not establish a compact size record.

A separate implementation appendix lowers native-goal-validation
coordinate minima to 319 / 367 / 594 and native-goal plus whole-alphabet

Those five modules implement the inherited calculus, not PD.
