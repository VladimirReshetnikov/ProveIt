COMPOSITION PROOF OBLIGATIONS AND DISCHARGE

1. Underlying theory. Keep the initialized scalar iterator equations I0/IS and
all native Choice-DI rules unchanged. The inherited full-domain bi-interpretation
with iPRA is therefore the target correspondence, not a new claim about a
weaker arithmetic or a new primitive connective.

2. Codec. Use the arity-calculus semantic decoder: Eq binary, D unary, Q ternary
with third field meaningful and canonical triple repetition; formula arities0
and >=4 are truth. Numerical arities0,2 and>=4 are zero, unary is successor,
ternary is initialized scalar iteration. At meaningful numerical roots the
protected-slot base is3. Unary numeric children receive two dummy zero slots;
I counter/seed receive one dummy zero slot, and its update one state slot.
The arity-calculus proof of semantic opening for d+5-len(a) is retained.

3. Logical instructions. They are exactly the arity-calculus instructions:
checked major, endpoint transport/Q specialization, major*3 exports a Q from
unary D and only truth from other meaningful arities, and i(*a,t,2) can introduce
only unary substantive goals (the empty raw goal already means truth).
The only interface change is selecting arithmetic with m is None, so zero
is now an available literal D witness without boxing. The uniform-predecessor
symbolic producer supplies this syntax. Scope validation occurs before the
new eigenparameter is allocated, as in both parents.

4. Arithmetic. For null major construct L=[s and [s],u,t]. If s is false,
its successfully traversed numerical meaning is zero, so [L,u] is I0. If s
is true, its constructed unary wrapper denotes S(p), whatever p's value.
The recursive image R=[s,u,t] is opened at root3 when used by t. If used,
its old-floor validation plus the retained semantic substitution lemma identify
the RHS as the update at I(p,a;h), giving IS. If unused, the update is independent
of that state slot and IS applies without inspecting a recursive value.
Additional dummy-zero slots in the source successor leave the zero-completed
meaning of p unchanged; any captured positive slots then denote zero, and
rigid parameters preserve their values. At high-arity subtrees the decoder
is constant, so opening artifacts below those fields carry no arithmetic
content. The final generated equation is opened with image0; new rigid
parameters are arbitrary and the computation is valid uniformly in them.

5. Completeness. Every native logical rule uses the canonical arity-calculus
encoding. I0 and IS at nonzero raw predecessors are direct null packets. For
IS at literal0, choose B(0)=I(0,0;v.0), whose nonempty encoding denotes0;
prove B(0)=0 by I0, use direct IS at B(0), and transport along that equation.
Thus every primitive rule still has a finite canonical certificate. General
finite native derivations compile by structural induction and fresh renaming.
The supplied producer only demonstrates selected instances of that translation.

6. Termination. On finite JSON, explicit list dispatch traverses a finite tree.
Any exposed numerical leaf validates the supplied image with the default
missing-image sentinel, so there is no self-feeding substitution loop. At a
non-hypothesis proof node one packet is popped; major and continuation recursion
consume finite remaining packets or fail. Thus ideal mathematical checking
terminates. Ordinary Python resource limits can still reject large valid proofs.

7. Scope of novelty. The new code combines two old representation protocols;
the unary-D grammar, affine depth, scalar iterator, full logical bridge, and
uniform predecessor supply are all inherited. Do not claim a new foundational
breakthrough or absolute smallest possible axiomatization. The measured savings
and the matched-control losses should be stated together.

8. Short profile. Its Boolean transport expression falls back to the old goal
when the replacement formula is raw-falsy. A replacement can be raw-falsy only
at an empty-array or scalar formula root, whose semantic meaning is truth;
opening never changes a nonempty formula array's root length. The matched
original goal is therefore truth as well. On all canonical nontrivial formulas
the expression performs exactly the original transport. The alternative
assumption-image expression returns BooleanFalse instead of integer0 in its
false case; these are identical zero aliases under this decoder and Python
container equality. These are inherited implementation idioms, not new rules.

9. Arithmetic freshness qualification. The old arity packet used major0;
its common continuation could open an arithmetic source at the newly allocated
parameter. That proof required a zero-instance argument. Here arithmetic is
selected by majorNone, so the final image expression is unconditionally zero.
Newly admitted rigid negative labels can survive, but I0/IS hold uniformly in
their arbitrary values. The state-demanded recursive image validates against
the OLD floor. If a new rigid parameter is visible only after allocation,
then either the base rule applies or the update was independent of its state
image; both cases are uniformly valid computations. The independent diagnostic
explicitly varies the newly allocated parameter through0,2,5; no uniformity
claim is inferred from evaluating that parameter only atzero.
