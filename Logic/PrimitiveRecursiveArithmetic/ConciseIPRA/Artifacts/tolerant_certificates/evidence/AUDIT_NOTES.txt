1. What the incumbent actually is

The README's historical aggregate (249 tokens / 271 AST nodes / 479 bytes)
is no longer the current envelope. The current article advances it, and the
seven incoming ZIPs advance it again. All seven archives in docs_tree.json
were retrieved and their exact Git object hashes verified. The resulting
receipt is incoming_blob_audit.json.

The smallest direct implementations still implement the inherited native
scalar core, with raw terms x,0,S,I and Eq/Q/D formulas, a root-selected
introduction, source-selected elimination, guarded public embedding, and an
arity-based raw codec. Their improvements do not delete a primitive iPRA
logical or arithmetic principle. The ordinary realization inherits the
whole-domain, actual-equality identity bi-interpretation from the existing
native-core arithmetic bridge.

4. Verification and cautions

targeted_replay_audit.json records30 fresh isolated CLI executions, all with
the expected verdict:10 AST265 fixtures and20 byte477 fixtures, including
actual induction with its hypothesis used, compound implication elimination,
both computation equations, capture/future-scope/context-leak/false-goal
attacks. These are finite implementation checks, not a metatheorem or formal
verification of the arithmetic bridge.

The compact contract promises a canonical closed guarded Eq/D public goal
and finite exact integer/list proof data. It does not independently validate
arbitrary hostile JSON. Native validation removes the public-goal promise;
strict validation also checks the entire parsed alphabet. A new comparison
must not charge those checks to one competitor and omit them from another.

Ordinary normalization, macro expansion, dispatch tables, primitive function
descriptions, decompressed source and other trusted code must be counted if
the candidate checker depends on them. The corpus already discusses and
excludes source-compression wrappers as misleading direct-checker records.

Potential straightforward implementation composition: boolean_constancy's
'from json import *' import saves4 bytes in the AST265 source, keeping the
same token and AST counts, but gives249/265/601 only. This does not improve
any coordinate of the full compact envelope and is not new mathematics.
