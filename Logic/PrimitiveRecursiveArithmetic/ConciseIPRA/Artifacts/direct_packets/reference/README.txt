Pinned mathematical dependencies
===============================

The chapter files are exact source copies from ProveIt commit
c2e762c43a39ae3757a1208b333e97df056085f8. They are reference material from
the existing combined article; they are not inputs to report.tex and are
not individually standalone LaTeX documents.

The Lean files are exact source excerpts identifying established theorem
statements and their imports. This directory is not a standalone Lean
project. No new Lean compilation or formal verification of the Python
checker is asserted. The full dependency tree is at the pinned repository
URL in report.pdf. Their SHA256 hashes and repository paths are recorded
in source_manifest.json.

The inherited shared-leaf provenance file was preserved as attribution
for the old control/fixtures. The root PROVENANCE.json describes this
delivery. Do not attribute the inherited package's earlier mathematical
or code contributions to the current report.
