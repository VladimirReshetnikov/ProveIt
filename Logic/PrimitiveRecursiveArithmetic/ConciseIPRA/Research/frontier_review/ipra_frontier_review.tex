\begin{abstract}
The requested result is a presentation bi-interpretable with full first-order
intuitionistic primitive recursive arithmetic whose complete checker improves
the current repository frontier. This investigation does \emph{not} establish
such an improvement in all complexity coordinates and does not establish a
new mathematical axiomatization. It establishes a smaller byte implementation
of the existing guarded scalar presentation: 513 normalized UTF-8 bytes in
place of 516, with 268 significant tokens and 306 AST nodes. The token and AST
records, 256 and 278 respectively, are not improved. The transformation has a
written successful-trace inclusion proof and preserves completeness for the
canonical certificate compiler. A separately measured 1183-byte program
validates the integer/list alphabet and guarded public goal. The inherited
axioms, logical encodings, and whole-domain bi-interpretation are stated
explicitly. All computational checks and comparison sources are supplied.
The distinction between a byte improvement, an empirical coordinate envelope,
and an actual mathematical simplification is maintained throughout.
\end{abstract}

\begin{remark}[An empirical envelope is not an impossibility theorem]
The achieved vector $(256,278,516)$ is a coordinatewise envelope of existing
implementations. It supplies upper bounds on the unknown optima of the three
minimization problems. It is not a proved lower bound on every possible
presentation of $\ipra$, and it is not the size vector of one existing
program. No claim of an absolute simplest axiomatization follows from a
finite collection of checkers.
\end{remark}

\subsection{What the small size includes}
The 513-byte and 516-byte modules use the same multiline JSON input and
\file{ACCEPT\string\n} output convention. They include the opener, rule
checking, context handling, JSON input, and output. Their mathematical
comparison contract is an integer/list certificate with a canonical closed
guarded public goal. The compact module does not itself validate that public
grammar or the entire data alphabet. The pinned compact documentation
explicitly makes this distinction \cite{compact}.

The strict module adds both checks. It rejects booleans, floats, strings,
objects, and null anywhere in the certificate, including unused prefixes.
It also checks the canonical guarded Eq/$\D$ public grammar. Scope checking
remains in the kernel. It permits an unused, well-typed prefix of instructions,
as does the comparison protocol. Its 1183 bytes are reported separately;
there is no claim that it improves every existing validated checker.

\section{The actual refinement}
The only change to the byte-control kernel is its goal-selection expression.
Write
\[
 C\equiv
 (m,a)=\bigl(s\mathbin{\texttt{and}}[s,u]
                   \mathbin{\texttt{or}}[t,t,t],\ i(t,u)\bigr),
 \qquad R=i(t,s).
\]
Here $C$ is a Python Boolean obtained by structural comparison, and $i$ is
the scope-sensitive opener. The previous expression was
\begin{lstlisting}
a = C and R or a
\end{lstlisting}
and the replacement is
\begin{lstlisting}
a = (a, R)[C]
\end{lstlisting}
The actual module inlines $C$ and $R$. Its size falls because the normalized
indexed expression is shorter in bytes. This is not an arbitrary rewrite of
Python's Boolean-selection idiom: false values and the additional eager
evaluation have to be addressed.

\subsection{Root shape and false results}
For fixed current floor $k$, the opener is
\begin{lstlisting}
i = lambda a, t=c, d=0: [i(b, t, d + 5 - len(a)) for b in a] if a * 0 != 0 else a if k <= a < d else d % 2 and i(t, d=3)
\end{lstlisting}
The proof in this section is over finite trees whose leaves are integers
and whose internal nodes are lists. The strict module enforces that alphabet.

\begin{lemma}[Root-shape lemma]\label{lem:root}
Suppose $i(t,s,0)$ and $i(t,u,0)$ both terminate successfully. If $t$ is a
list, their results are lists with the same outer arity as $t$. If $t$ is
an integer, the two results are equal and independent of the image.
Consequently, if either result is false in Python, the results are equal:
they are both the empty list or both the same zero.
\end{lemma}
\begin{proof}
On a list, the first branch constructs one output child per input child,
without changing the outer list. A nonempty list is true irrespective of
its children. On an integer at depth zero, the interval branch returns
that integer when $k\le t<0$; otherwise the factor $0\bmod2$ returns zero.
Neither scalar case reads the image. The only false outer list is the
empty one. This proves each assertion.
\end{proof}

\begin{lemma}[Equality of the selected goal]\label{lem:selection}
Whenever the new indexed expression completes, it selects the same goal
as the old Boolean expression evaluated from the same state.
\end{lemma}
\begin{proof}
If $C$ is false, both select $a$. If $C$ is true, the old match establishes
$a=i(t,u,0)$. For a true replacement $R$, both expressions select $R$.
For a false replacement, Lemma~\ref{lem:root} gives $R=i(t,u,0)=a$, so the
old fallback and the new selected value are still equal. No assumption
that all intermediate goals are nonempty formulas is needed.
\end{proof}

\subsection{A successful trace is not enlarged}
\begin{theorem}[Successful-trace inclusion]\label{thm:trace}
On every finite integer/list certificate accepted by the new compact
program, the pinned byte-control program also accepts. Along the
corresponding executions they consume the same instructions and have the
same current goal, context, and scope state at each common checker entry.
\end{theorem}
\begin{proof}
The new expression evaluates $R$ eagerly before evaluating $C$. The opener
is pure: it creates lists, performs arithmetic comparisons and recursive
calls, and neither mutates its input nor consumes an instruction. On a
successful new evaluation all operations needed by the old expression are
therefore available with the same values. Lemma~\ref{lem:selection} proves
equality of the selected goal.

The remainder of the instruction is unchanged. Both executions check the
same major premise recursively, compute the same supplied hypothesis,
decrement the same local floor, and form the same continuation goal and
context. The expression \file{g + [new_hypothesis]} allocates a new list;
it does not mutate a parent's context or the default list. In particular,
local hypotheses from a recursively checked major do not escape into its
caller. Induction over the finite successful execution tree gives the
claimed correspondence and the same final output.
\end{proof}

The converse assertion for all raw certificates is deliberately absent.
The extra eager operation can reject an old trace whose otherwise unused
field is malformed. This is a restriction of raw certificates, and it does
not introduce an extra accepted theorem.

The supplied \file{fixtures/eager_control_only.json} makes the distinction
concrete. Before an ordinary positive computation proof it inserts the
unused packet \file{[0, 3, [0], [5, 0]]}. Both control programs accept the
certificate, while both refined programs reject it: the new eager opening
tries the out-of-scope image $3$ at numerical root depth $3$. The public
goal itself is valid and retains its original canonical proof. Thus raw
certificate equality would be a false claim even with a validated public
goal; equality of the recognized theorem sets is the relevant assertion.

\subsection{Canonical completeness survives the extra evaluation}
\begin{lemma}[Total opening with a valid image]\label{lem:total}
Fix $k$. If the numerical-root check $i(s,d=3)$ terminates successfully,
then $i(t,s,d)$ terminates for every finite integer/list tree $t$ and every
integer initial depth $d$.
\end{lemma}
\begin{proof}
Induct on $t$. A list makes finitely many calls on proper subtrees. At an
integer leaf the result is that integer, zero, or the fixed successful
numerical-root check of $s$. No recursive call continues into a newly
inserted image with the same substitution argument. Thus the structural
induction terminates even when an ignored annotation has negative depth.
\end{proof}

\begin{theorem}[Canonical completeness preservation]\label{thm:complete}
Every theorem of the pinned guarded public presentation that has its
intended canonical certificate has a certificate accepted by the new
compact program. Consequently the new and old programs recognize the same
theorems on that public language, with the inherited certificate compiler.
\end{theorem}
\begin{proof}
Keep a canonical source certificate and standardize unused fields. A
genuine transport or closure-elimination packet already evaluates its
selected replacement in the old successful execution. Alternatively, its
source is a valid outer numerical term, so Lemma~\ref{lem:total} applies.
A canonical computation packet also has a valid source (zero or its
well-scoped predecessor term). For an introduction packet, set its unused
source field to zero. Its zero major cannot accidentally match the
nonempty reconstructed elimination major, and its introduction branch is
unchanged. For a $\D$-elimination packet set all three inert fields to zero.
Its unary major cannot match the ternary reconstructed major; the exported
closure is unchanged, and the eager opener on zero terminates.

There is also a direct check for canonical numerical bodies and witnesses:
their node arities are one and three. An opening that starts at formula
depth zero stays at even depth, so it never inspects the substitution image.
Thus the additional operation is total on every intended packet. Apply
the same finite-execution induction as in Theorem~\ref{thm:trace}.
\end{proof}

This is a refinement of an existing calculus. Its whole-domain
bi-interpretation is inherited. A new proof of that arithmetic equivalence
is not being inferred merely from passing a finite test suite.

\section{The inherited mathematical presentation, explicitly}
To specify exactly which arithmetic strength is intended, this section
states the ordinary native presentation behind the compact public codec.
It is the existing Choice-DI presentation of the repository
\cite{choice,current}. It is not a new axiom inventory.

\subsection{Terms, formulas, and semantics}
There is one numerical sort. The finite terms are
\[
 t::=x\mid0\mid St\mid I(n,a;u.h).
\]
Only $u$ in the body $h$ is bound. Each fixed body is a staged first-order
function description built from earlier descriptions. Numerical variables
do not range over functions, and there is no uniform object-language
evaluator of all primitive-recursive codes.

Use formulas
\[
 A::=(s=t)\mid\Q_y A\mid\D_{x,y}A,
\]
with readings
\[
 \Q_yB:=B(0)\to\forall y\,B(y),\qquad
 \D_{x,y}B:=\exists x\bigl(B(x,0)\to\forall y\,B(x,y)\bigr).
\]
The designated native contradiction is $0=\one$. Contexts are finite
reusable lists of formulas; all substitutions avoid capture.

\subsection{The complete rule inventory}
Besides the two displayed computation schemes, there are six inference
patterns. They are listed separately to make every primitive explicit.
\begin{align*}
 &\Gamma\vdash I(0,a;u.h)=a, &&\text{I0},\\
 &\Gamma\vdash I(Sn,a;u.h)=h[I(n,a;u.h)/u], &&\text{IS}.
\end{align*}
\[
 \frac{A\in\Gamma}{\Gamma\vdash A}\;\mathrm{Hyp}
 \qquad
 \frac{\Gamma\vdash s=t\quad\Gamma\vdash F(s)}
      {\Gamma\vdash F(t)}\;\mathrm{Tr}
\]
\[
 \frac{\Gamma\vdash\Q_yB(y)\quad\Gamma\vdash B(0)}
      {\Gamma\vdash B(t)}\;\mathrm{QE}
\]
\[
 \frac{\Gamma\vdash\D_{x,y}B\quad
       \Gamma,\Q_yB(b,y)\vdash A}
      {\Gamma\vdash A}\;\mathrm{DE}
\]
\[
 \frac{\Gamma,B(t,0)\vdash B(t,Sz)}
      {\Gamma\vdash\D_{x,y}B(x,y)}\;\mathrm{DI}_{\mathrm{case}}
\]
\[
 \frac{\Gamma,E(t,z)\vdash E(t,Sz)}
      {\Gamma\vdash\D_{x,y}E(x,y)}\;\mathrm{DI}_{\mathrm{progress}}
 \qquad(E\text{ a literal equation}).
\]
In DE, $b$ is fresh for $\Gamma$, the conclusion, and the passive
parameters of $B$. In each introduction, $z$ is fresh for $\Gamma$, $t$,
and the passive matrix parameters. The two bound variables of $\D$ are
distinct. The transport template $F$ is any fixed native formula template.
The displayed local assumptions are discharged.

No separate successor-injectivity, successor-separation, reflexivity,
ordinary logical, or additional induction axiom is primitive here. The
equivalent current kernel uses direct progress introduction of $\Q_yE$;
the unused-witness construction converts between the two formulations.
The compact checker applies further established public-language and
certificate transformations, discussed in Section~\ref{sec:codec}.

\subsection{Equality, cases, and equation induction}
Put $r=I(0,t;u.0)$. The computation $r=t$, used as both transport premises
with template $F(v)\equiv(v=t)$, gives $t=t$. Ordinary equality templates
then give symmetry, transitivity, and numerical congruence.

Progress introduction with an unused witness coordinate gives
$\D_{v,y}E(y)$. Its elimination supplies the conditional closure of $E$.
Using the base $E(0)$ and QE therefore derives contextual equation induction:
\[
 \frac{\Gamma\vdash E(0)\qquad\Gamma,E(z)\vdash E(Sz)}
      {\Gamma\vdash E(t)}.
\]
The corresponding case introduction, ignoring its local assumption,
derives numerical cases for every native formula:
\[
 \frac{\Gamma\vdash F(0)\qquad\Gamma\vdash F(Sz)}
      {\Gamma\vdash F(t)}.
\]
Both statements have the usual fresh-$z$ condition. Induction remains
restricted to literal equations. Allowing progress at arbitrary compound
matrices would yield arbitrary-formula induction and would change the
intended arithmetic strength.

\section{Recovering all intuitionistic logical operations}
The following constructions are inherited from the Choice-DI development
\cite{choice}. They explain why the economical native formula grammar
still presents full first-order intuitionistic logic.

First remove an auxiliary $\Q_yB$ by the interderivable
$\D_{u,y}B(y)$ with unused $u$. Define the numerical selector
\[
 C(v,a,b):=I(v,a;u.b),\qquad
 C(0,a,b)=a,\quad C(Sz,a,b)=b.
\]
For Eq/$\D$ formulas define a gate
\[
 G_v(s=t):=C(v,0,s)=C(v,0,t),\qquad
 G_v(\D_{x,y}B):=\D_{x,y}G_vB,
\]
renaming bound variables away from $v$. Equality and binder congruence
give $\vdash G_0A$ and $G_{Sz}A\dashv\vdash A$. Padding
\[
 L(A):=\D_{u,y}G_yA
\]
with unused fresh $u$ is interderivable with $A$: introduce by cases in
one direction, and open, supply the true zero gate, and specialize at one
in the other.

Every Eq/$\D$ formula is a chain of paired binders ending in an equation.
To construct a selector $M_v(A,B)$, pad the shallower operand until both
have the same number of binders, align fresh bound names, and replace their
terminal equations $s=t$ and $p=q$ by
\[
 C(v,s,p)=C(v,t,q).
\]
The control is lifted under the aligned binders. The gate and padding
proofs establish the endpoint equivalences
$M_0(A,B)\dashv\vdash A$ and $M_{Sz}(A,B)\dashv\vdash B$.

Put $\delta(v)=C(v,1,0)$ and $p(z)=I(z,0;u.\delta(u))$.
The computations $p(1)=1$ and $p(2)=0$ suffice for the macros
\begin{align*}
 A\Rightarrow_* B&:=\D_{u,z}M_z(A,B),\\
 A\wedge_* B&:=\D_{u,z}G_zM_{p(z)}(A,B),\\
 \exists_*x\,A(x)&:=\D_{x,y}G_yA(x),\\
 A\vee_* B&:=\exists_*x\,M_x(A,B),\\
 \forall_*x\,A(x)&:=A(0)\wedge_*\D_{u,z}G_zA(z),\\
 \bot_*&:=(0=1).
\end{align*}
Every new binder is fresh and the displayed $u$ is unused.

Implication introduction uses its zero row as the assumption and its
successor row as the consequent. Elimination opens its closure and
specializes at one. Existential introduction supplies its witness;
elimination opens at a fresh witness and removes the gate at one.
Disjunction injections use witnesses zero and one, while elimination
uses numerical cases on the selector control. The conjunction has a
provable zero row, and its rows at one and two recover $B$ and $A$.
Numerical cases prove its introduction rule.

The universal macro's first conjunct is essential: it supplies the zero
instance erased by the other conjunct's gate. The paired conjunct supplies
all successor instances. Numerical coverage then supplies the instance at
an arbitrary term. Coverage itself is derived by numerical cases:
\[
 (x=0)\vee_*\exists_*v\,(x=Sv).
\]
At zero use the first injection; at a successor use the second injection
with its evident witness and reflexivity.

Under $0=1$, selector computation and transport give
$s=C(0,s,t)=C(1,s,t)=t$ for all terms. Thus every equation follows.
External induction on finite formula syntax, using case introduction,
gives every native formula. This proves falsity elimination without
introducing excluded middle for quantified formulas.

\section{The inherited whole-domain bi-interpretation}
\subsection{Ordinary realization and the falsity bridge}
Let $\TI$ be intuitionistic first-order logic with actual equality and
genuine falsity over the staged iterator signature. Its nonlogical
axioms are I0 and IS, numerical coverage,
\[
 \forall x\,(x=0\vee\exists y\,x=Sy),
\]
separation $(0=S0)\to\bot$, and contextual induction for literal equations.
Separation is explicit: positive numerical equations alone admit a
singleton structure. The native contradiction convention must not be
mistaken for an ordinary first-order falsity axiom.

Interpret the native binders by their displayed ordinary meanings, using
the whole domain $x=x$ and actual equality. Case introduction is sound by
coverage, and progress introduction is sound by equation induction under
its conditional base. The reverse interpretation uses the preceding
logical macros. A crucial internal round trip is
\[
 \D_{x,y}B\dashv\vdash
 \exists_*x\bigl(B(x,0)\Rightarrow_*\forall_*y\,B(x,y)\bigr).
\]
Forwards, open the paired formula, reconstruct its conditional universal,
and introduce the existential macro. Backwards, open the existential and
use case introduction at that witness. The selector endpoints give the
ordinary logical round trips; structural induction extends them to every
finite formula. These are full formula comparisons, not merely agreement
on closed equations.

\subsection{The arithmetic dependency order}
The scalar body does not see its recursion counter. Recovering all
primitive-recursive functions therefore requires an internal arithmetic
argument. The supplied reference sources give it in the following order
\cite{bridge,predecessor,reflection,recursion}.

First, using computations, equations, cases, and equation induction,
construct a scalar predecessor $P$ and prove internally
\[
 P0=0,\qquad P(Sn)=n.
\]
The construction uses a parity iterator, a three-state cycle, a ramp, a
factor map, and a saturated counter. It does not assume pairing. Its final
form is
\[
 P(m)=I\bigl(m,0;u.C(L(SSu,m),u,Su)\bigr),
\]
where $L$ is the comparison term constructed earlier in that proof.
The complete inherited definitions and derivation are provided in
\file{reference/foundations/scalar_predecessor.tex}. These identities hold
at arbitrary internal arguments, not just at standard numerals.

Next define truncated subtraction
\[
 d(x,y)=I(y,x;u.Pu),\quad
 \operatorname{sg}(v)=C(v,0,1),\quad K(v)=C(v,1,Pv).
\]
The internally proved residual identity
$d(Sa,b)=1\leftrightarrow a=b$ yields the actual-equality characteristic
\[
 e(a,b)=\operatorname{sg}\bigl(K(d(Sa,b))\bigr),\qquad
 e(a,b)=0\leftrightarrow a=b,
\]
with $e(a,b)$ always zero or one. In particular the equality being reflected
is the original equality relation, not an assumed congruence or quotient.

Compile each fixed quantifier-free formula $A$ to a Boolean-valued term
$b_A$, using
\begin{align*}
 b_{s=t}&=e(s,t),&b_\bot&=1,\\
 b_{A\wedge B}&=C(b_A,b_B,1),&
 b_{A\vee B}&=C(b_A,0,b_B),\\
 b_{A\to B}&=C(b_A,b_B,0).
\end{align*}
Induction on finite formula construction proves $b_A=0\leftrightarrow A$
and that $b_A$ is zero or one. The implication clause uses decidability of
its quantifier-free antecedent. Equation induction on $b_A(n)=0$ then
gives every quantifier-free induction instance, with retained side
assumptions. This does not make quantified formulas decidable.

After quantifier-free induction is available, construct the pairing
$\pi(a,b)=(a+b)^2+a$. A bounded square-root search produces $q(n)$ with
$q(n)^2\le n<(q(n)+1)^2$. Put
\[
 L_p(n)=d(n,q(n)^2),\qquad H_p(n)=d(q(n),L_p(n)).
\]
Then $L_p(\pi(a,b))=a$ and $H_p(\pi(a,b))=b$. Surjectivity is unnecessary:
pairing stores an internal state and does not replace the numerical domain.

For a fixed primitive-recursive description
\[
 f(0,\vec p)=g(\vec p),\qquad
 f(Sn,\vec p)=h(n,f(n,\vec p),\vec p),
\]
define its scalar compilation by
\begin{align*}
 W(u,\vec p)&=\pi\bigl(SL_p(u),h^*(L_p(u),H_p(u),\vec p)\bigr),\\
 V(n,\vec p)&=I\bigl(n,\pi(0,g^*(\vec p));u.W(u,\vec p)\bigr),\\
 f^*(n,\vec p)&=H_p(V(n,\vec p)).
\end{align*}
Equation induction proves $L_p(V(n,\vec p))=n$, and the projection
identities give both defining equations of $f^*$. Initial functions and
composition translate directly. The compilation is external recursion on
a fixed finite description, not an object-language universal evaluator.

\subsection{Both composites are proved internally}
Conversely, $\ipra$ interprets each fixed scalar iterator by ordinary
primitive recursion whose update ignores the counter. It proves the
iterator equations, coverage, separation, and equation induction.

For two fixed iterators with the same seed and provably equal updates,
equation induction on the equality of their values proves uniqueness at
every internal counter. The same argument applies to ordinary primitive
recursion. Inducting externally over a finite function description shows
that its double translation satisfies the original defining equations;
internal uniqueness identifies the original and double-translated
operations. This also supplies coherence when substituting parameters
changes the staged spelling of an update.

\begin{theorem}[Inherited arithmetic equivalence]
The ordinary realization $\TI$ is bi-interpretable with full first-order
$\ipra$. Both interpretations have whole numerical domains and actual
equality. The internally definable isomorphism for each numerical composite
has graph $x=y$. Together with the logical round trips and preservation of
falsity, the finite proof translations give equiconsistency.
\end{theorem}
\begin{proof}
The two interpretations of fixed function symbols and axioms were described
above. Internal uniqueness proves the numerical round trips; structural
induction and the logical endpoint arguments prove the formula round trips.
The explicit falsity bridge preserves contradiction in both directions.
The graph $x=y$ is internally a total bijection preserving every interpreted
operation. These facts are the inherited proof of the theorem, supplied
in full source form with the archive \cite{bridge,recursion}.
\end{proof}
No claim is made that either consistent theory proves its own consistency.
The new 513-byte implementation inherits this equivalence through the
unchanged guarded public presentation and Theorems~\ref{thm:trace}--\ref{thm:complete}.

\section{The compact codec is a separate layer}\label{sec:codec}
The mathematical rule inventory above is not a literal description of
every raw JSON value accepted as an intermediate resource. The current
compact program uses the following arity representation:
\[
 \D B\longleftrightarrow[B],\qquad
 s=t\longleftrightarrow[s,t],\qquad
 \Q B\longleftrightarrow[B,B,B].
\]
Terms use $0$, scalar coordinates, unary successor arrays, and ternary
iterator arrays. The opener changes its depth by $5-r$ at a list of arity
$r$. For relevant arities $1,2,3$ these increments are $4,3,2$.
Two-wide numerical slots and dummy slots make the one traversal implement
the distinct logical and numerical binders.

The sorted reading of additional arrays is essential. High-arity formula
padding denotes truth; inappropriate numerical shapes denote zero.
Tripling a unary $\D$ major produces a ternary closure resource. Tripling
other nonempty major arrays produces administrative truth. These extra
arrays are representation aliases, not new unrestricted logical symbols.

The current compact kernel restricts transport sources away from literal
zero and chooses the introduction mode from the matrix root: progress at
an equation and cases at a compound matrix. The pinned Lean development
proves that the relevant restricted calculus agrees with the native
kernel on its guarded public translation, and also proves that removing
this public-language qualification would be wrong \cite{current}.
Public atomic matrices under $\D$ use the guard
\[
 I(y,0;u.h)=I(y,0;u.k).
\]
The formula gate used in the logical constructions supplies the required
translation to guarded formulas. An arbitrary native formula is not to be
identified with an arbitrary raw administrative array.

The supplied older \file{inherited_arity_checker.tex} explains the sorted
decoder and arithmetic-supply mechanism. Its historical packet interface
has a choice of introduction modes and differs from the current program.
Its old full-native completeness statement is therefore background, not
a theorem transplanted verbatim onto the 513-byte module. The actual
refinement theorem compares the pinned executable byte control with the
new executable, under the current contract \cite{compact}.

\subsection{Why context and phase changes need proofs}
Two attractive source shortenings were rejected. Replacing an immutable
context extension by in-place list extension would leak local hypotheses
from a recursively checked major into its parent. Removing the scope
counter by the entry identity $k=1-|g|$ also requires changing the phase
order: the original program decreases $k$ before the new context entry
has been inserted. A direct textual replacement uses the old context
length while checking the new eigenparameter and rejects valid proofs.
Neither change is present in the delivered implementation.

The harmless extra opener in the byte refinement has a much smaller proof
obligation: it changes no state. That is why its correctness can be
established locally by the root-shape and totality lemmas.

\section{A barrier to removing every supplied term}
Several recent proposals remove the explicit witness from introduction;
another restricts clause specialization to the newest parameter or a fixed
numeral. Their naive combination does not preserve the intended native
consequence relation. This is a review of the fixed-range obstruction
already anticipated in the repository, not a new arithmetic breakthrough
\cite{constructed,specialization}.

Consider a clause calculus with introduction choosing the newest outer
parameter, or zero in an empty scope. Suppose every allowed specialization
term is a parameter, zero, or one. Its intended $\D$ reading is the one
above. There is a different Boolean reading that validates those restricted
rules and refutes a standard naming theorem.

Evaluate numerical terms in $\mathbb N$, assigning every ambient free
parameter zero. Evaluate formulas recursively, with
\[
 [\![\D_{x,y}B]\!]_\rho
 =\bigl([\![B]\!]_{\rho[x:=0,y:=0]}
                  \Rightarrow[\![B]\!]_{\rho[x:=0,y:=1]}\bigr).
\]
Read a retained clause $[A;y.B(y)]$ as
\[
 [\![A]\!]\Rightarrow
 \bigl([\![B(0)]\!]\land[\![B(1)]\!]\bigr).
\]
An antecedent-free clause means the conjunction of those two instances.

Computation and equality remain valid because numerical terms have their
ordinary values. Every permitted specialization term has value zero or
one, so clause use is sound. In introduction, the selected witness and
fresh eigenparameter both have value zero; either local assumption
$B(0,0)$ or $B(0,z)$ has value $B(0,0)$, and the successor conclusion has
value $B(0,1)$. Thus case and equation-progress introduction are sound.
Ordinary elimination opens at the fresh value zero and adds the clause
$B(0,0)\Rightarrow(B(0,0)\land B(0,1))$, which follows from the major.

An inferred equality discharge is also sound. If its zero row is literally
true and its first row is $b=t$, the major forces $t$ to have value zero,
the same as the opened $b$. Substitution preserves the value of the
exported formula. In the default case it is identity substitution.

But the closed native formula
\[
 N_1:=\D_{x,y}\bigl(C(y,0,x)=C(y,0,1)\bigr)
\]
has false counterreading $(0=0)\Rightarrow(0=1)$. In the intended calculus
it is a theorem: choose witness one, making the two terms identical.
Therefore the combined restrictions lose an intended closed theorem.

This establishes failure of the intended native consequence equivalence.
It is not an impossibility proof for every conceivable different
bi-interpretation of the restricted formal system.

\section{Executed evidence and its limits}
The supplied \file{reproduce.py} runs with the Python standard library and
was executed under CPython 3.12.14. Its complete results are in
\file{evidence/results.json}. The checks are:
\begin{itemize}
\item Twenty-one pinned regression certificates, including computation,
transport, compound introduction, implication elimination, used induction
hypotheses, zero-source transport, and scope/context attacks. Each is run
through the compact control, compact candidate, strict control, and strict
candidate, under both ordinary and optimized compilation: 168 outcomes.
\item Twelve actual command-line subprocess checks of accepting and rejecting
inputs, including Python's \file{-O} mode. These check the input/output
contract independently of the in-process harness.
\item 1200 deterministic random integer/list certificates and 600 mutations
of known positive certificates. No new acceptance absent from the control
was observed. There were 75 candidate acceptances in the random set and
14 in the mutation set; these counts include administrative test goals and
are not counts of new arithmetic theorems.
\item Twelve additional malformed-input or invalid-goal checks for the
strict candidate. Noninteger/list unused prefixes are rejected.
\item An explicit control-only certificate verifies the strict raw-trace
inclusion boundary: both controls accept and both refinements reject it,
while its public goal still has the original accepted canonical proof.
\item Reproduction of all six full-module measurement rows in Section 1.
\end{itemize}
All assertions passed. One pinned accepted fixture deliberately has an
unguarded auxiliary goal; the compact comparison accepts it and the strict
public checker rejects it, as specified. The other regression expectations
are preserved.

These are finite implementation checks. They neither prove universal
soundness nor establish bi-interpretability. The universal claims rely on
the written refinement proof and the identified inherited mathematical
theorems. No new Lean or Rocq development was compiled for this report.

\section{Further research questions}
\begin{enumerate}
\item \textbf{Can a mathematical change beat every coordinate?}
Find a complete module with fewer than 256 tokens, fewer than 278 AST nodes,
and fewer than 516 normalized bytes, using a fixed, stated input contract.
A single module would be stronger evidence than three separate profiles.
The present 513-byte program does not do this.
\item \textbf{Can validation become cheaper together with the kernel?}
The public grammar and the integer/list alphabet have visible costs.
An improvement that shares a proved invariant between parsing, binding,
and proof checking could be more useful than another isolated byte saving.
Its soundness statement must cover the full accepted input language.
\item \textbf{Can scope state be eliminated with a smaller phase-aware design?}
Context length determines the local scope at checker entry, but the
continuation temporarily uses the next scope. A semantics-preserving design
must account for that transition and for immutable branch contexts.
\item \textbf{Can introduction and specialization both be automatic without
a costly enumerator?} The finite-target counterreading rules out a natural
combination. Enumerating terms through dummy scopes can avoid a finite
range, but the decoder, scope validation, and proof-padding construction
must all be counted. That is presently an interface tradeoff, not a
smaller trusted arithmetic basis.
\item \textbf{Can the refined checker itself be formally connected to the
Lean kernel?} The repository formalizes substantial native-calculus
equivalences. An end-to-end theorem about the exact JSON parser, opener,
administrative aliases, and standalone program would remove a remaining
implementation-to-mathematics boundary. The local root-shape lemma is a
small suitable starting point.
\item \textbf{Can an alternative arithmetic signature simplify the internal
bridge and the checker simultaneously?} A recursor with direct access to
its counter simplifies predecessor, but existing normalized presentations
pay for their normalizer and syntax. Both source size and internal
round-trip proofs need to be measured together.
\end{enumerate}
