\section{One scope check instead of two}
\label{scope:section}

This implementation theorem changes neither the arithmetic calculus nor
its certificate protocol. It factors a standalone goal validator into a
shape check and the scope check that the proof kernel already performs.
The improvement applies to both ordinary and crossed elimination, with
exactly the same accepted finite JSON certificates as the respective
supplied comparator. It is a separate contribution from any change of
axiomatization.

\subsection{The two checks in the old interface}

Let $V(a,D)$ denote the supplied strict validator. Its depth $D$ is even
at formula positions and odd at numerical positions. The root has
$D=0$. On a child of an array of arity $r$, depth becomes $D+5-r$.
The admitted array arities are $1,2$ at Eq/$D$ formula positions, $1,2,3$
at Eq/$Q$/$D$ formula positions, and $1,3$ at numerical positions.
In the full formula grammar, an arity-three formula must have three
identical children. A scalar is admitted precisely when it is an exact
Python integer, it occupies a numerical position, and
\[
 a=0\quad\hbox{or}\quad 3\leq a<D\ \hbox{and}\ a\equiv1\pmod2.
 \tag{Old scalar check}\label{scope:oldscalar}
\]
Exact list tests reject other JSON node types.

After this validation, the checker immediately executes its existing
no-image opening $i(a)$ at floor $k=0$, before consuming a proof
instruction. The opener visits children at the same depth $D+5-r$ and
preserves an integer exactly when $0\leq a<D$. At a numerical position,
an integer outside that interval attempts to insert the unavailable
default image. In these modules that image is the function object
\texttt{c}; the first arithmetic operation on that object raises
\texttt{TypeError}. Thus a missing image is rejection, not a default
numerical value. No-image opening at a formula scalar can return padding,
but the public shape validator excludes every formula scalar.

The interval test $a<D$ was therefore being performed twice on every
admitted public numerical variable.

\subsection{The new shape-only validator}

Replace $V$ by $W(a,b)$, where $b$ is a Boolean recording only the sort:
false for formula, true for numerical term. At an integer, require
\[
 b\quad\hbox{and}\quad
 \bigl(a=0\ \hbox{or}\ (a\geq3\ \hbox{and}\ a\equiv1\pmod2)\bigr).
 \tag{Static scalar check}\label{scope:newscalar}
\]
Require the same exact node types and the same allowed constructor
arities. For Eq/$D$, both sorts allow arity one, and the other arity is
$2+b$; thus the arity test is simply $r\in\{1,2+b\}$.
The child sort is
\[
                         b\lor(r=2).
 \tag{Child sort}\label{scope:sort}
\]
A numerical child remains numerical. A child of a formula is numerical
exactly when its parent is equality. A $D$ or $Q$ child remains a formula.
The Eq/$Q$/$D$ variant retains the diagonal-triple check verbatim.
No proof instruction, opening operation, fresh-name convention, or
administrative formula interpretation is changed.

\begin{lemma}[Shape, scope, and opening]
\label{scope:factor}
For every finite JSON value $a$, the following are equivalent:
\begin{enumerate}
\item $V(a,0)$ accepts;
\item $W(a,\mathrm{false})$ accepts and the unchanged initial no-image
opening $i(a)$ succeeds.
\end{enumerate}
When these conditions hold, $i(a)=a$ as raw finite trees.
\end{lemma}
\begin{proof}
Compare the two traversals by induction on their finite trees.
Their exact type and arity tests agree. If $W$ admits a node, its Boolean
sort is the parity of the depth used by $V$ and by the opener. Indeed,
the increments for arities $1,2,3$ are respectively $4,3,2$:
formula unary and ternary constructors preserve formula parity,
equality switches to numerical parity, and the admitted numerical
constructors preserve numerical parity. This proves
\eqref{scope:sort} at every child. All reached numerical depths are
positive odd integers at least three.

Consequently, the only difference between the scalar tests is the upper
bound $a<D$. Every scalar admitted by $W$ is nonnegative. At a zero
scalar the bound automatically holds. At an admitted positive scalar,
the unchanged opener preserves it if the bound holds; otherwise the
position is numerical and the missing-image attempt raises an exception.
There is no formula-scalar branch available to conceal that failure.
Thus success of opening restores exactly the missing upper bounds,
at every numerical leaf. If all bounds hold, every leaf is preserved,
and hence the entire tree is preserved. All other JSON values are
rejected by both shape checks before this comparison is needed.
\end{proof}

\begin{theorem}[Exact certificate-language preservation]
\label{scope:checker}
For each of the six paired modules supplied with this section, replace
only the definition of \texttt{v} by the new Boolean-sort validator.
Then the old module accepts a finite JSON certificate if and only if
the new module accepts that same certificate. Acceptance means normal
exit with exactly \texttt{ACCEPT} followed by one newline. As usual,
the universal statement abstracts from finite machine resources.
\end{theorem}
\begin{proof}
Input parsing, goal extraction, the optional whole-certificate exact
integer/list check, the proof kernel, and the output driver are identical.
If the new shape check rejects, the old validator rejects as well.
If the new shape check accepts but the old validator rejects,
Lemma~\ref{scope:factor} says that initial opening fails. That call is
the first action of the proof kernel and occurs before its instruction
reader is invoked, so the new module cannot accept.

If the old validator accepts, the new shape check accepts and initial
opening succeeds with exactly the same unchanged goal tree. From that
point the two executions have identical code, environments, retained
context, name floor, and unconsumed instructions. They therefore have
the same acceptance outcome. This proves both directions. The argument
also covers malformed auxiliary proof data and inert prefix data:
their treatment after the first opening is unchanged.
\end{proof}

\begin{corollary}[Transfer of soundness and completeness]
Every soundness or completeness theorem of a paired comparator transfers
to its new module under the identical public-goal and raw-certificate
contract. In particular no new assumption that intermediate formulas
use only canonical odd slots is needed. The opener and every internal
raw alias have exactly their previous behavior.
\end{corollary}

This is a relative implementation theorem, not a newly mechanized proof
of the inherited Python kernel. Its exact-language part is independent
of any assertion that the comparator's declared public grammar is the
unique preferred spelling of native syntax. The new module preserves
that grammar's acceptance relation exactly.

\subsection{Measured consequence}

The strongest small comparison uses the existing ordinary-elimination
Eq/$D$ module, not the larger crossed module. Whole standalone sources
are normalized with \texttt{ast.unparse(ast.parse(source))} plus one
newline under CPython 3.12.14. The supplied measurements give
\[
\begin{array}{lrrrr}
 &\text{tokens}&\text{AST nodes}&\text{bytes}&\text{gzip-9 bytes}\\
\text{ordinary Eq/$D$, old}&373&426&824&460\\
\text{ordinary Eq/$D$, new}&359&414&803&463\\
\text{ordinary Eq/$Q$/$D$, old}&399&456&873&477\\
\text{ordinary Eq/$Q$/$D$, new}&391&444&863&484\\
\text{ordinary fully typed, old}&450&514&1049&540\\
\text{ordinary fully typed, new}&442&502&1039&547
\end{array}
\]
The crossed variants change respectively $830\to809$, $879\to869$,
and $1055\to1045$ normalized bytes. Compression increases in these
profiles and is reported without being used as an optimization objective.
These figures are strict-interface comparisons, not improvements to the
separate 522-byte compact public-input-contract frontier.

The reproduction script checks exact syntax-tree identity of every module
outside the validator. It records 984 process executions, 492 paired
comparisons including normal and optimized Python modes, and zero
mismatches. The paired runs contain 198 old acceptances and 294 old
rejections. It additionally compares the validator factorization on
15,781 finite trees for each of the two public grammars, with zero
mismatches. The structural proof above establishes the universal
statement; those finite checks are implementation evidence.
