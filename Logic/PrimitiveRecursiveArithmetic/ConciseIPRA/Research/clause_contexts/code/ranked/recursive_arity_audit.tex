\section{Audit of the recursive-formula tree control}
Numerical terms use only integers and lists of lengths one and three.
A formula is either an endpoint pair \([s,t]\), or
\([\mathtt d,A]\), where the string \(\mathtt d\) is excluded from
numerical syntax. The generic opening function therefore has disjoint
cases on well-formed input: a \(\mathtt d\)-headed pair contributes two
binders; an iterator triple contributes one binder only in its body;
an ordinary endpoint pair contributes none; a successor singleton
contributes none. This one traversal correctly replaces the separate
ranked-formula instance operation.

The first Step proof is matched against \([s,t]\) without an explicit
equation tag test. This is safe under the successful-derivation invariant.
A \(D\) formula could match that pattern only with \(s=\mathtt d\).
The second proof must have shape \([[[n],a,h],r]\), which excludes a
\(D\) formula and gives well-formed numerical \(n,a,h,r\).
The following source check requires
\[
 s=\begin{cases}a,&n=0,\\[n,a,h],&n\ne0.\end{cases}
\]
Its right-hand side is a numerical term and hence never the string
\(\mathtt d\). Consequently a \(D\) first premise fails this check.
Every accepted Step therefore has two genuine equation premises,
with exactly the intended common iterator source.

The successful-derivation invariant is proved by induction on its
finite proof tree. The initial reflexivity body is well scoped.
Use returns a normalized instance of a well-scoped context body.
Step has the just-proved equation shapes and preserves scoping.
Open/Close validate their outer goal before adding the fresh level,
construct a well-scoped clause and branch target, and demand the exact
target back from the branch. Thus the implicit shape test does not
assume its own conclusion circularly.

The implementation sets scope equal to context length minus one.
This is valid for its reachable states: the root contains the single
fixed reflexivity clause and no free levels; Open and Close each add
one clause and one level. The abstract calculus may retain separate
scope and context parameters, while this root-to-leaf certificate
protocol can recover one from the other.

This control has the same ordinary interpretation and derivable
closed formulas as the explicit-tag and ranked controls. Its smaller
opening routine is an implementation consequence of disjoint data
shapes; it introduces no new axiom or arithmetic inference.
