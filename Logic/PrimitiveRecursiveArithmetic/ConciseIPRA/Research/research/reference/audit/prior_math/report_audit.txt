the target definition of B returns the original B. However the reverse
interpretation compiles each target PR description, so target C and P

earlier source abbreviations C and P. Their equality is easy to prove,
but should not be silently identified.

its reverse image Bhat satisfies those same two endpoint equations in
the source. Source B has precisely the same endpoints. Coverage on n
therefore proves Bhat(n,b)=B(n,b). This proves the B composite directly,
without invoking any helper-function composites or induction on an
unproved equivalence.

Alternatively, explicitly identify compiled target P and C with source
P and C by their endpoint equations and coverage before applying the
displayed characterization of B. Either repair closes the small gap.
