CERTIFICATE CONTRACTS

1. PRIMARY FULLY VALIDATED NATIVE CHECKER

The input is one nonempty JSON list. Its last item is a canonical closed
goal. Earlier items are four-field instruction packets, consumed from
right to left as needed. An unused prefix is logically inert but must
still contain only exact integers and lists. All booleans, floats
(including nonstandard NaN/Infinity), strings, null, and dictionaries
are rejected. Entire malformed JSON is rejected by the standard parser.

Acceptance is normal exit with output exactly "ACCEPT\n".
Every exception is rejection. There is no reliance on Python assertions.

Full public formulas have Eq, Q, and D; the Eq/D version excludes public
Q nodes but uses the same internal proof kernel. Q is definitionally
equivalent to D with an unused witness coordinate.

2. INHERITED CANONICAL ARITY ENCODING

Canonical zero is raw 0; [0] denotes S0.
Formula list arities 1, 2, 3 denote D, equation, and Q.
A canonical Q has three identical copies of its matrix.
Numerical list arities 1 and 3 denote successor and iterator.
Formula root depth in the opener is 0; numerical root depth is 3.
Each list edge increases depth by 5 minus its arity.
Protected variable slots have width 2; dummy slots under numerical
constructors are part of the inherited encoding.
The precise decoder and scope proof are in
reference/inherited_arity_checker.tex.
The preserved old packet documentation is
reference/SOURCE_DISPATCH_FORMAT.txt; the changes below supersede its
old neutral-marker and guarded-profile descriptions.

The new public validator shifts these depths by 2:
d=0 is raw integer/list type checking; the goal is checked at d=2.
This shift affects the public validator only, not the opening kernel.

3. NATIVE LOCAL PACKETS [m,s,u,t]

m is proved recursively. Neutral m=0 closes from the initial administrative
truth. A nonzero source selects equality major [s,u]; source zero selects
Q major [t,t,t]. The target instance of t must match the current goal;
the remaining minor obligation is its source instance.

A proved singleton major D exports the corresponding Q resource at a
fresh witness. Nonneutral majors are verified before any exported
resource can be used.

With m=0 and u truthy, the packet introduces a computation equation:
s is the zero marker or successor predecessor, u the initializer,
and t the update template.
Zero initializer/predecessor instances use the inherited certified-zero
derived expansion (see the report).

With m=0 and u falsy, the packet introduces D with witness t:
u=[] selects cases; u=0 selects progress when the matrix is an equation.
Progress on a compound formula is not supplied.
The exact syntax and rules are in Section 2 of the report.

4. COMPACT GUARDED PROFILES

Public goals are Eq/D formulas, with atomic D matrices restricted to
I(y,0;u.h)=I(y,0;u.k). Internal auxiliary formulas remain unrestricted.
The introduction choice is root-directed: equation progress, compound cases.

The byte and AST profiles use local freshness and neutral major m=0.
The token profile uses a global monotonically decreasing freshness floor
and an initially empty tuple context. It uses the inherited global packet
convention. Local and global certificate files are not interchangeable.

guarded_goal_checked.py validates the public guarded goal, but does not
claim the whole-certificate exact integer/list contract of the native
typed checkers. The other guarded profiles assume the advertised public
goal is canonical; they are not public-grammar validators.
All these distinctions are retained in the measurement tables.

5. EXAMPLE

tests/native_computation.json is
[[0,0,[0],0],[[0,[0],0],[0]]]
Its goal is I(0,1;u.0)=1, a genuine computation theorem.
Run:
python3 code/native_typed_full.py < tests/native_computation.json

6. TRUST BOUNDARY

Only the selected standalone checker source plus Python and the standard
JSON library are trusted executable dependencies for checking.
Producers, proof transformations, report sources, tests, measurement scripts,
and frozen controls are not imported by a selected checker.
No Lean/Python correspondence theorem is claimed.
