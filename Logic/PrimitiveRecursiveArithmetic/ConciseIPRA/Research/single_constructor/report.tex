\begin{abstract}
We give a concrete simplification of the current
\emph{ConciseIPRA} presentations. Numerical terms have only variables,
zero, and one ternary binding constructor
$\R(n,a;i,u.h)$. The same two-variable binding convention serves this
constructor and the sole compound formula constructor $\D_{x,y}$.
The entire proof calculus has one fixed reflexivity clause and the
three inference families Use, Introduce, and Open. Both computation
equations are incorporated in canonical syntax.

The construction combines two existing ingredients: the counter
recursor of \texttt{uniform\_binding} and the three-family logic of
\texttt{inferred\_witness}. The new compatibility argument supplies full
normalization, an exact translation of the former scalar computation
syntax, and a complete checker for their combination. The direct
primitive-recursion compiler also shortens the arithmetic bridge:
neither pairing nor the scalar predecessor construction is needed.
Both interpretations have the whole numerical domain and actual
equality; both numerical composites are internally the identity.

The complete matched Python checker decreases from 1,990 to 1,965
normalized bytes and from 771 to 764 AST nodes, with 683 significant
tokens in both. This is a measured improvement of a particular complete
presentation, not a claim of absolute minimality or a new global
byte record. All mathematical claims here have written proofs;
no new Lean or Rocq verification is claimed.
\end{abstract}

\section{Result, comparison, and scope}
\label{sec:result}

The comparison is pinned to ProveIt commit
\[
 \texttt{9f9545f5ffd9e0392d4a36639503aca12383450a}.
\]
The repository contains many presentations, including three-family
calculi and several substantially smaller compressed implementations.
Consequently, reducing an earlier six- or eight-rule inventory would
not by itself improve the current mathematical frontier.

The present construction, denoted $\K$, keeps the three-family logical
interface and removes the independent successor constructor from its
numerical syntax. It also gives every binding constructor exactly two
bound positions in its final child. These are changes to the formal
language and its computation, not a renaming of Python variables.
The actual implementation comparison counts the new normalizer and
all validation code.

\begin{theorem}[Main result]
\label{thm:main}
The calculus $\K$ specified in Sections~\ref{sec:syntax}
and~\ref{sec:rules} is equiconsistent and bi-interpretable with full
first-order intuitionistic primitive recursive arithmetic. The
interpretation domains are the entire numerical domains, interpreted
equality is actual equality, and both numerical composite
isomorphisms have graph $x=y$.

There is a direct compiler for every fixed primitive-recursive
description into its numerical language. Each compiled recursion
has its defining equations by computation. There is also an
effective, rule-for-rule translation of the inherited fully normalized
scalar inferred-opening calculus into $\K$.
\end{theorem}

For clarity, \emph{full first-order iPRA} here means intuitionistic
first-order logic with equality and genuine falsity, the usual
successor axioms, the defining equations for every fixed finite
primitive-recursive description, and induction for all
quantifier-free formulas. Quantified formulas are allowed in
contexts and conclusions. Induction for arbitrary quantified
formulas is not supplied.

\paragraph{What is inherited.}
The successor-seeded counter recursor, its successor decoder, the
direct recursion macro, and the short logical macros below are
already in \texttt{uniform\_binding}. Inferred witness opening and
the essential logical completeness argument are already in
\texttt{inferred\_witness} and the associated Lean modules
of the repository~\cite{inferred,lean}. This report claims their
fully normalized combination, its compatibility proofs, the
resulting simpler term grammar, and the matched complete
implementation. It does not claim to have invented those ingredients.

\paragraph{What the size result does not say.}
The repository also supplies a compact 516-byte protocol, a 788-byte
checker for a different public grammar, and an 820-byte validator
profile for the inherited native calculus~\cite{canonical,checked,specialization}.
Our 1,965-byte checker is not smaller than those programs.
The comparison above isolates the mathematical change while keeping
the implementation architecture and complete input contract matched.
An observed minimum among programs is an upper bound on the unknown
optimum, not a proved lower bound.

\section{Numerical syntax and full normalization}
\label{sec:syntax}

\subsection{One constructor}

Raw terms are finite expressions
\[
 t ::= x\mid 0\mid \R(n,a;i,u.h).
\]
The two variables $i,u$ are bound in $h$ only. They do not bind in
$n$ or $a$. Passive numerical parameters may occur anywhere they
are in scope. Every body is a fixed finite expression; no
object-language variable ranges over functions, terms, or programs.

Define successor as an abbreviation:
\[
 Sa:=\R(0,a;i,u.0),\qquad 1:=S0,\qquad 2:=S(S0).
\]
The intended computations are
\begin{align}
 \R(0,a;i,u.h)&=Sa, \label{eq:r0}\\
 \R(Sn,a;i,u.h)&=
 h[n/i,\R(n,a;i,u.h)/u]. \label{eq:rs}
\end{align}
Thus a zero iteration returns the successor of the initializer.
The update sees both the old counter and the old state.
The use of a successor initializer is precisely what allows $S$
to be expressed with the same constructor.

These two equations specify computation, rather than additional
proof rules. Every term appearing in a sequent is in the canonical
form described next, and every substitution is followed by
normalization. This convention is part of the trusted specification.

\subsection{Canonical forms}

A canonical successor is exactly $\R(0,a;i,u.0)$, with $a$
canonical. A canonical term other than zero or a canonical successor
is called \emph{neutral}. Neutrals are variables and recursor nodes
with a neutral counter. In a retained recursor node its initializer
and body are also canonical.

Operationally, canonicalization erases the body of every zero-counter
node, and unfolds every successor-counter node using
\eqref{eq:rs}. A node already of the form $\R(0,a;i,u.0)$ is
retained; the first computation is not applied as a self-loop.
The normalizer acts under binders as well as at the root.

The zero-body erasure does not license malformed input. The supplied
checker validates the raw body and its scope before erasing it.
For example, a positive index outside the two new bound positions
cannot be hidden in a discarded body.

\subsection{A total definition by evaluation}

Here is a definition of the normalizer independent of any proposed
termination measure on rewrite sequences. An environment $\rho$
maps free variables to normal terms. Evaluate zero and variables
directly. To evaluate $\R(n,a;i,u.h)$, evaluate $n,a$ to $c,v$ and
use the already defined evaluator of its proper subterm $h$:
\[
 H(d,w)=\operatorname{ev}(h,\rho[i\mapsto d,u\mapsto w]).
\]
For that fixed evaluator define
\[
 \operatorname{run}(c,v,H)=
 \begin{cases}
 Sv,&c=0,\\
 H(d,\operatorname{run}(d,v,H)),&c=Sd,\\
 \R(c,v;i,u.H(i,u)),&c\text{ neutral}.
 \end{cases}                                                \tag{N}
\]
In the neutral case, $i,u$ are fresh and the environment is lifted
past them. The notation $H(i,u)$ means evaluation in this extended
environment; it introduces no function object into the numerical
language. Put $\NF(t)=\operatorname{ev}(t,\mathrm{id})$.

\begin{lemma}[Normalization and substitution]
\label{lem:nf}
Evaluation is total on finite terms and finite normal environments.
Its result is canonical. It fixes every canonical term, respects
\eqref{eq:r0}--\eqref{eq:rs}, and satisfies
\[
 \NF(t\sigma)=\NF\bigl(\NF(t)\,\NF(\sigma)\bigr).               \tag{SC}
\]
The same identity holds for formulas when their terms are normalized.
In particular, normalization is idempotent and commutes with fresh
renaming.
\end{lemma}
\begin{proof}
Define evaluation by structural recursion on the source expression.
At a recursor node, the evaluators of its counter, initializer, and
body have already been defined for all normal environments.
For a fixed total body evaluator, (N) strips the finite leading
successor prefix of the normal counter. Its only recursive call
to the same run has the strictly shorter prefix. Applying $H$
after that call is total by the structural induction hypothesis.
The neutral case evaluates the proper subterm $h$ under two fresh
variables. This establishes totality and normality.

The algebraic verification is made with arbitrary environments.
Renaming the target commutes with evaluation; renaming the source
is precomposition of the environment. Evaluation after substitution
equals evaluation in the environment obtained by evaluating the
substitution's values. These statements are proved by structural
induction, with the three clauses of (N) as the additional cases.
At zero both sides are the successor of the transformed
initializer. At a successor, use the statement for the smaller
counter and for the body with the two transformed arguments.
At a neutral counter, the residual body is the same body evaluator
under two fresh variables. If substitution turns that counter into
zero or a successor, evaluating the residual node uses exactly the
corresponding clause of (N). Thus the statement also covers newly
exposed redexes.

In the identity environment a normal term is fixed by the cases
of its grammar. Environment composition gives (SC) and
idempotence. The first two clauses of (N) establish the
computation identities in every environment. Each recursive
evaluation also gives a finite conversion using those identities,
including erasure of an unused zero body. Thus equal terms in the
computational congruence have the same canonical representative.
When this congruence is read in ordinary first-order arithmetic,
its use under a recursor body is justified by
Lemma~\ref{lem:bodyext} below.
\end{proof}

No uniform primitive-recursive bound on normalization time is
claimed. The construction is a metatheoretic operation on fixed
finite syntax. Ordinary implementation resource limits still
apply to the executable checker.

\section{Primitive recursion is a computational macro}
\label{sec:compiler}

\subsection{The decoder}

Define
\[
 P(t):=\R(t,0;i,u.i).
\]
Its two relevant computations are
\[
 P(0)\longrightarrow 1,\qquad P(Sa)\longrightarrow a.        \tag{P}
\]
The value at zero is intentionally $1$, not the usual predecessor
value. The second identity holds for every open term $a$ by
computation: the body returns the old counter and ignores the
old state. No injectivity or induction argument is involved.

\subsection{The compiler}

For an arbitrary fixed update body $h(i,v)$, define
\begin{equation}
 \Rec(n,a;i,v.h)
 :=
 P\bigl(\R(n,a;i,u.S(h(i,P(u))))\bigr).
 \label{eq:rec}
\end{equation}
All bound names are chosen fresh and the indicated substitution
is capture avoiding. The initializer $a$ may contain passive
parameters, as may $h$.

\begin{lemma}[Ordinary recursion equations]
\label{lem:rec}
The following are computational identities:
\begin{align}
 \Rec(0,a;i,v.h)&\longrightarrow^* a, \label{eq:rec0}\\
 \Rec(Sn,a;i,v.h)&\longrightarrow^*
 h(n,\Rec(n,a;i,v.h)). \label{eq:recs}
\end{align}
\end{lemma}
\begin{proof}
At zero the inner recursor becomes $Sa$, and $P(Sa)$ reduces to
$a$. At a successor the inner recursor becomes
\[
 S\bigl(h(n,P(\R(n,a;i,u.S(h(i,P(u))))))\bigr).
\]
The outer $P$ removes this displayed successor. What remains is
the right side of \eqref{eq:recs}.
\end{proof}

Zero, successor and projections are now terms; composition is
substitution; and an ordinary primitive-recursion clause is
translated by \eqref{eq:rec}. External induction on a finite
primitive-recursive description therefore compiles every
primitive-recursive function. In particular, no pairing function
is needed to store the old counter beside the old state.

The ordinary predecessor and the selector can be chosen as
\[
 p(t):=\Rec(t,0;i,v.i),\qquad
 C(t,a,b):=\Rec(t,a;i,v.b).
\]
They have the computational equations
\[
 p(0)=0,\quad p(Sa)=a,\qquad
 C(0,a,b)=a,\quad C(Sn,a,b)=b.                               \tag{C}
\]
The symbol $p$ is distinct from the decoder $P$.
For example, addition is $\Rec(n,a;i,v.Sv)$ and multiplication
is $\Rec(n,0;i,v.(v+a))$, after expanding the already compiled
addition. These are term abbreviations, not new primitives.

\subsection{Exact compatibility with the scalar syntax}

The inherited scalar term language has $0,S$ and
$I(n,a;v.h)$, where the update does not see the counter.
Translate its variables and zero identically, its successor
by the abbreviation $S$, and its iterator by the
counter-independent instance of \eqref{eq:rec}.
Write $T_{\mathrm{raw}}$ for this hygienic translation before
normalization, and $T$ for the translation on normal source terms.

\begin{lemma}[Exact normal-form embedding]
\label{lem:embedding}
For every scalar term $t$,
\[
 \NF_R(T_{\mathrm{raw}}t)=T(\NF_I t).
\]
Raw translation commutes with capture-avoiding substitution;
normalized translation commutes with normalized substitution.
On normal source terms it preserves and reflects literal zero,
each specified free variable, and the successor category.
It also preserves their free-variable sets.
\end{lemma}
\begin{proof}
The two scalar computation equations translate to the finite
computations in Lemma~\ref{lem:rec}. A normal scalar iterator
has a neutral counter. Its image is
\[
 P\bigl(\R(Tn,Ta;i,u.S((Th)[P(u)/v]))\bigr).
\]
Here $Tn$ is neutral. Thus the inner recursor is retained and
neutral, and the outer $P$ is retained as well. Substitution
of the neutral term $P(u)$ for the old body variable cannot
turn a neutral counter into zero or a successor. Structural
induction therefore proves normality of the whole image.
Zero, variables and successors give the remaining cases.

The raw substitution lemma follows by induction on terms,
freshening the two new variables at every translated iterator.
Lemma~\ref{lem:nf} then gives the normalized version and the
displayed equality. The four source categories have distinct
target root descriptions: zero, the same variable, a canonical
successor, or a neutral recursor. No free variable in a normal
source term is erased by this construction.
\end{proof}

This is more than a comparison of standard numerical values.
It preserves the literal row tests used by the proof rules
below. In particular, a row becomes $0=0$, or has a specified
fresh variable as its entire left side, exactly when its
normal source row did.

\section{The entire axiomatization}
\label{sec:rules}

\subsection{Formulas, clauses, and falsity}

The formula grammar is
\[
 A::=(s=t)\mid \D_{x,y}B.
\]
Both $x,y$ are bound in $B$. There are no primitive
propositional connectives or ordinary quantifiers.
Terms and formulas are canonical, and displayed substitutions
include normalization. The designated contradiction is
\[
 \bot_*:=(0=S0).
 \]

A context is a finite list of reusable clauses
\[
 \cl{\Delta}{y.B(y)},\qquad |\Delta|\in\{0,1\},\qquad
 y\notin\FV(\Delta).
\]
An empty antecedent has no proof obligation. An ordinary
assumption $A$ is the constant unconditional clause
$\cl{}{v.A}$ with $v$ unused. Every proof starts with the
fixed clause
\[
 \mathcal A:=\cl{}{y.y=y}.
 \tag{Ax}
\]
It is part of the axiomatization. Reflexivity has not been
deleted without replacement.

The ordinary readings, used to state soundness and
bi-interpretability, are
\begin{align}
 (s=t)^\circ&=(s=t),\\
 (\D_{x,y}B)^\circ
   &=\exists x\bigl(B^\circ(x,0)\to\forall y\,B^\circ(x,y)\bigr),
   \label{eq:dreading}\\
 \cl{}{y.B}^\circ&=\forall y\,B^\circ,\\
 \cl{A}{y.B}^\circ&=A^\circ\to\forall y\,B^\circ.
\end{align}

\subsection{Use}

For a retained clause $\cl{\Delta}{y.B(y)}\in\Gamma$ and
any well-scoped canonical term $t$,
\[
 \frac{\{\Gamma\der A:\ A\text{ is the antecedent in }\Delta\}}
      {\Gamma\der \NF(B(t))}.
 \tag{Use}
\]
Thus an unconditional clause has zero premises, and a
conditional clause has one. Applying the fixed clause
$\mathcal A$ gives $t=t$.

\subsection{Introduce}

For a well-scoped canonical witness $t$ and a fresh numerical
parameter $z$,
\[
 \frac{\Gamma,B(t,\eta)\der B(t,Sz)}
      {\Gamma\der\D_{x,y}B(x,y)},\qquad
 \eta=
 \begin{cases}
 z,&B\text{ is a literal equation and }t\equiv0,\\
 0,&\text{otherwise}.
 \end{cases}
 \tag{Intro}
\]
The parameter $z$ is absent from the retained context, the
witness, and the passive parameters of $B$.
The assumption displayed above the line is discharged.
The test concerns literal canonical syntax, not provable
equality. The first branch is progress, and the second is
case introduction.

\subsection{Open with an inferred witness}

Suppose the major premise is $\D_{x,y}B(x,y)$.
Choose $b$ fresh for its passive parameters and the retained
context. Put $B_b(y)=\NF(B(b,y))$ and
\[
 \tau_B(b)=
 \begin{cases}
 r,& B_b(0)\equiv(0=0)
       \text{ and } B_b(1)\equiv(b=r),\\
 b,&\text{otherwise}.
 \end{cases}                                                \tag{Probe}
\]
The fresh variable must be the \emph{entire} left side of
the first row. No search for a provable equality takes place.
The rule is
\[
 \frac{\Gamma\der\D_{x,y}B
       \qquad
       \Gamma,\cl{B(\tau_B(b),0)}{y.B(\tau_B(b),y)}
                \der A}
      {\Gamma\der A},
 \qquad b\notin\FV(A).
 \tag{Open}
\]
All substituted instances are normalized. The branch is
checked in the scope that contains $b$, even if the probe
has chosen a term containing $b$. Replacement is simultaneous
and occurs once; inserted copies are not revisited.

These three families, Ax, and the specified canonical
syntax are the complete presentation. There are no additional
primitive equality, computation, induction, hypothesis,
cut, or ordinary logical rules. Structural operations used
in the mathematical proofs below are admissibility theorems.

\section{Why the three rules suffice}
\label{sec:logicproof}

This section makes the logical dependency order explicit.
The argument is inherited in structure from
\texttt{inferred\_witness}~\cite{inferred}; it applies to
arbitrary $\R$ terms because the selector equations (C)
are computational identities in the new language.

\subsection{Soundness of the nonstandard opening}

In ordinary intuitionistic equality logic, open the
existential major at $b$ and obtain
$B(b,0)\to\forall y B(b,y)$.
If the probe succeeds, reflexivity supplies $B(b,0)$ and
specialization at $1$ gives $b=\tau_B(b)$.
If it fails, this equality is $b=b$.
Equality substitution converts the opened clause to the
clause displayed in Open. The branch then supplies $A$,
which does not contain $b$, so existential elimination closes.
This also proves soundness when the inferred term contains $b$.

Case Intro is sound using numerical coverage. Progress Intro
is sound using equation induction under its conditional
zero base. Use and Ax have their ordinary meanings.
Thus every rule is sound in the ordinary realization introduced
in Section~\ref{sec:ordinary}.

\subsection{Structural rules and safe openings}

Weakening by clause occurrences, injective fresh renaming,
and cut of an ordinary assumption are admissible by induction
on derivations. At an assumption cut, replace uses of its
unconditional constant clause by the given proof. Freshen
local parameters before insertion. Injective renaming preserves
the literal tests. Arbitrary term substitution is not yet
being asserted.

Open is already ordinary existential-style elimination
in two cases: when the witness coordinate is unused in
$B$, and when $B$ has compound root. In the first case the
first row contains no fresh $b$, so its left side cannot
be literally $b$. In the second case the zero row is still
compound and cannot be $0=0$. Hence the probe returns $b$.

For an unused witness coordinate write
$q_yA(y):=\D_{w,y}A(y)$. Introducing its witness at $1$
always selects case mode. The two safe openings therefore give
\[
 \frac{\Gamma,A(0)\der A(Sz)}{\Gamma\der q_yA(y)},\qquad
 \frac{\Gamma\der q_yA(y)\quad\Gamma\der A(0)}
      {\Gamma\der A(t)}.
 \tag{Closure}
\]
In particular, from proofs of $A(0)$ and $A(Sz)$ with fresh
$z$, numerical cases yield $A(t)$. This fact is available
\emph{before} equality transport.

\subsection{Repairing case introduction at witness zero}

An arbitrary substitution can send a nonzero witness to
literal zero and switch Intro's mode. The following repair
is required before any substitution theorem.

For an equation $E=(s=t)$ put
\[
 G_vE:=(C(v,0,s)=C(v,0,t)),\qquad
 L(E):=q_vG_vE.
\]
The endpoints are literally $G_0E=(0=0)$ and $G_{Sw}E=E$.
Closure introduction and specialization give
$E\inter L(E)$, using only safe openings.

Suppose $\Gamma,E(0,0)\der E(0,Sz)$, the missing case
premise for an equation at witness zero. Replace its
matrix by the compound formula $L(E(x,y))$.
Unwrap the base, apply the supplied proof, and wrap the
successor result. Compound Intro at zero is in case mode,
so it gives $\D_{x,y}L(E(x,y))$. Open that compound major
safely at a fresh $c$. Introduce $\D_{x,y}E(x,y)$ at
witness $c$: wrap its zero assumption, use the opened
clause at $Sz$, and unwrap. The fresh variable $c$ is not
literal zero, so this last introduction is also in case
mode. Its conclusion is independent of $c$ and is exported.

Thus unrestricted case introduction is admissible for
every matrix and every witness. No general substitution
or equality theorem has been used in its proof.

\subsection{Substitution and ordinary opening}

\begin{lemma}[Admissible simultaneous substitution]
\label{lem:substproof}
If $\Gamma\der A$, then
$\NF(\Gamma\sigma)\der\NF(A\sigma)$ for every well-scoped
simultaneous numerical substitution $\sigma$.
\end{lemma}
\begin{proof}
Use strong induction on the original derivation, with the
induction assertion quantified over all substitutions.
Freshen its eigenparameters away from every substitution image.
Use follows from Lemma~\ref{lem:nf}. A progress Intro remains
progress. A case Intro remains a case unless its equation
witness becomes zero; use the preceding case repair then.

At an Open node, let $B'=\NF(B\sigma)$ and
$\tau'=\tau_{B'}(b)$. If the old probe succeeded at $r$,
its literal zero row and its row $b=r$ remain such rows
after substitution with $b$ fixed. Hence the new probe
succeeds at $\NF(r\sigma)$; translate the old branch with
$b$ fixed.
If the old probe failed, its branch had the ordinary clause
at $b$. The new probe might now succeed. Apply the induction
hypothesis to the original branch with the combined
substitution extending $\sigma$ by $b\mapsto\tau'$.
It produces exactly the new opened clause.
The retained context and conclusion originally omitted
$b$, so they are unchanged by this extra component.
Inserted images are not recursively substituted into themselves.
The induction is always on an original proper subderivation,
which avoids circular use of a transformed, larger proof.
\end{proof}

Ordinary paired elimination is now admissible: given a
branch under the ordinary clause at $b$, apply
Lemma~\ref{lem:substproof} to that branch with
$b\mapsto\tau_B(b)$, then use Open. Its outer conclusion
and context omit $b$. This derivation is why the
substitution theorem must precede unrestricted opening.

\subsection{Equality from a short naming packet}

\begin{lemma}[Transport in a term]
\label{lem:transport}
For every fixed numerical template $h(w)$,
\[
 \Gamma\der s=t,\quad \Gamma\der h(s)=r
 \quad\Longrightarrow\quad
 \Gamma\der h(t)=r.
\]
\end{lemma}
\begin{proof}
Use the canonical matrix
\begin{equation}
 B(x,y):=
 C(y,0,C(P(y),x,h(x)))
 =
 C(y,0,C(P(y),t,r)).
 \label{eq:packet}
\end{equation}
Its normal rows are
\[
 B(x,0)\equiv(0=0),\quad
 B(x,1)\equiv(x=t),\quad
 B(x,2)\equiv(h(x)=r).
\]
Moreover its arbitrary successor row is literally
\[
 B(x,Sz)\equiv C(z,x,h(x))=C(z,t,r),
\]
because $P(Sz)$ computes to $z$.
At witness $s$, numerical cases on $z$ prove this equation:
the zero case is the supplied $s=t$, and the successor
case is the supplied $h(s)=r$. The proof ignores Intro's
local assumption, so it works in either mode and introduces
$\D_{x,y}B$.

Open infers the witness $t$. Its clause has base $0=0$.
Reflexivity supplies that base, and Use at $2$ gives
$h(t)=r$, which is in the outer scope.
\end{proof}

The decoder makes this packet simpler than the parity
packet in the scalar inferred-opening presentation:
one successor computation exposes the very variable
on which numerical cases are taken.

Symmetry follows by taking $h(w)=w$ and the reflexive
minor $s=s$. Transitivity and congruence follow by the
usual finite applications. Equality replacement in both
sides of an equation takes two one-term replacements.
For a compound formula template, use induction on its
formula depth: open the source at a fresh witness,
introduce the target in case mode at that witness,
transport its base backward in the smaller matrix, use
the old clause at a successor, and transport forward.
Thus full formula transport is derived, not primitive.

\subsection{Equation induction}

Given $\Gamma\der E(0)$ and
$\Gamma,E(z)\der E(Sz)$ for a literal equation $E$,
Intro at witness zero with unused witness coordinate
gives $q_yE(y)$. Its opening is safe. Use with the given
base yields $E(t)$ for every term $t$.
This derives contextual equation induction.
No corresponding progress rule is allowed at compound
matrices.

\subsection{Translation of the inherited normal calculus}

The term translation of Lemma~\ref{lem:embedding}, extended
without changing equation or $\D$ roots, translates each
primitive instruction of the inherited fully normalized
inferred-opening calculus. At Use, this follows from
commutation with normalized substitution. At Intro,
literal-zero reflection preserves the mode, and the
translated successor row is the required successor row.
At Open the two row tests are preserved and reflected,
so
\[
 \tau_{T(B)}(b)=T(\tau_B(b)).
\]
Normalized substitution then gives exactly the translated
branch clause. Free-variable preservation supplies the
scope conditions in all three cases.

This proves the rule-for-rule assertion of
Theorem~\ref{thm:main} for the \emph{already normalized}
source calculus. If one starts with raw scalar proofs,
their prior normalization can turn a witness into zero;
the admissible case repair above handles that separate
normalization step.

\section{Recovering ordinary intuitionistic logic}
\label{sec:macros}

The following definitions are external operations on
finite formula syntax. They introduce no new primitive
connectives or inference rules.

Extend the gate from equations to all formulas by
\[
 G_v(\D_{x,y}B):=\D_{x,y}G_vB,
\]
freshening bound variables away from the control $v$.
Reflexivity, compound introduction, and induction on
formula depth give
\[
 \der G_0A,\qquad G_{Sz}A\inter A,\qquad
 A\inter q_yG_yA
 \quad(y\notin\FV(A)).
 \tag{Gate}
\]

Define a selector between arbitrary formulas, first at
equations:
\[
 M_v(s=t,r=w):=(C(v,s,r)=C(v,t,w)).
\]
Align fresh binders at compound roots and use
\begin{align*}
 M_v(\D_{x,y}A,\D_{x,y}B)&=\D_{x,y}M_v(A,B),\\
 M_v(E,\D_{x,y}B)&=\D_{x,y}M_v(G_yE,B),\\
 M_v(\D_{x,y}A,E)&=\D_{x,y}M_v(A,G_yE).
\end{align*}
Here $E$ is an equation. Each recursion reduces the
maximum binder depth, so the definition terminates.
Gate padding and binder congruence establish
\[
 M_0(A,B)\inter A,\qquad M_{Sz}(A,B)\inter B.
\]

The complete ordinary logical interface is
\begin{align}
 \bot_*&:=(0=S0), \notag\\
 A\Rightarrow_*B&:=q_yM_y(A,B), \notag\\
 A\wedge_*B&:=q_yG_yM_{P(y)}(A,B), \notag\\
 \exists_*x\,A(x)&:=\D_{x,y}G_yA(x), \label{eq:macros}\\
 A\vee_*B&:=\exists_*x\,M_x(A,B), \notag\\
 \forall_*x\,A(x)&:=q_yG_yA(P(y)). \notag
\end{align}
All new bound names are fresh. The witness coordinate
of $q$ is unused.

\paragraph{Implication.}
From a derivation of $B$ under $A$, case introduction
uses the zero endpoint $A$ and the successor endpoint
$B$. Elimination opens the clause and uses it at $1$.

\paragraph{Conjunction.}
From $A,B$, numerical cases give $M_z(A,B)$.
Since $P(Sz)$ computes to $z$, this is exactly the
successor gate required for introduction.
For projections, open its zero-gated clause and use
it at $1$ and $2$; the results are respectively
$A$ and $B$.

\paragraph{Existential quantification.}
Introduce with the given numerical witness and the
successor gate. Eliminate at a fresh witness, supply
the zero-gate theorem, and use the clause at $1$.
These are precisely the ordinary eigenvariable
conditions.

\paragraph{Disjunction.}
The two injections use witnesses $0$ and $1$ in the
existential macro. For elimination, discharge the
two branches as implications into the desired
conclusion. Numerical cases show that either
selector endpoint implies that conclusion.
Existential elimination then completes the proof.

\paragraph{Universal quantification.}
From a proof of $A(z)$ with fresh $z$, case introduction
of the unused witness at $1$ supplies
$q_yG_yA(P(y))$: its successor row is $A(z)$
by computation. For elimination at an arbitrary
term $t$, open the unused witness, supply the zero
gate, and use the clause at $St$. The result is
$A(P(St))=A(t)$ by computation.
There is no extra zero-instance conjunct in this
macro. The decoder makes the elimination work
uniformly also at $t=0$.

\paragraph{Falsity.}
Under $0=1$, equality transport gives
$s=C(0,s,t)=C(1,s,t)=t$ for arbitrary terms.
Every equation follows. External induction on
formula depth, using case introduction at
compound roots, gives every formula. This is
falsity elimination. No excluded middle for
quantified formulas has been introduced.

\paragraph{Coverage.}
Numerical cases prove
\[
 (x=0)\vee_*\exists_*v\,(x=Sv).
\]
At zero use the left injection of reflexivity;
at a successor use the right injection with its
predecessor as witness.
Applying the ordinary predecessor equation to a
successor witness strengthens this to
$x=0\vee_*x=S(p(x))$.

\section{The ordinary arithmetic realization}
\label{sec:ordinary}

Let $T_{\R}$ be intuitionistic first-order equality
logic in the staged $\R$ language, with genuine
falsity, computations \eqref{eq:r0}--\eqref{eq:rs},
coverage, the separation axiom
$(0=S0)\to\bot$, and contextual induction for
literal equations. A staged symbol is used for
each fixed finite body; it never quantifies over
descriptions.

Sections~\ref{sec:logicproof}--\ref{sec:macros}
prove that $\K$ and $T_{\R}$ have the full logical
interface in both directions. Soundness was
checked rule by rule. Conversely, the macros
derive each ordinary logical rule, coverage,
equation induction, and the translation of
separation. Computational equality is already
canonical equality. The separation axiom is
explicit in the ordinary realization; equations
alone would admit a one-element structure.

\begin{lemma}[Body extensionality]
\label{lem:bodyext}
In $T_{\R}$, if $a=b$ and the two fixed bodies satisfy
$h(i,u)=k(i,u)$ for arbitrary $i,u$, then
\[
 \R(n,a;i,u.h)=\R(n,b;i,u.k)
\]
for every $n$. The premise may be a retained universally
quantified assumption; no function quantification is used.
\end{lemma}
\begin{proof}
Induct on the displayed literal equation with a fresh
counter variable, keeping all passive parameters fixed,
then instantiate that variable at $n$. At zero its
two sides are $Sa,Sb$, equal by congruence. At a
successor, the induction hypothesis identifies the
two previous states. Instantiate the pointwise
body equality at the old counter and one state,
and use ordinary equality congruence for the
other state. This is the required step.
\end{proof}

Consequently, replacing a fixed body by its
normalized form is sound in the ordinary
first-order realization. The same lemma justifies
using a provably equal returned body, rather
than a literally identical one, in the
interpretation round trips.

\subsection{From equation induction to quantifier-free induction}

For completeness we give the arithmetic argument,
adapted from the inherited equality-reflection
proof~\cite{reflection}. All functions in it are
direct $\Rec$ macros by Section~\ref{sec:compiler}.
Thus their availability is not contingent on
quantifier-free induction.

From $Sa=Sb$, applying $P$ gives $a=b$.
Put $\operatorname{sg}(v)=C(v,0,1)$.
Applying this term to $0=Sa$ yields $0=1$,
so successor is separated from zero.
Coverage gives
\[
 \operatorname{sg}(v)\in\{0,1\},\quad
 \operatorname{sg}(v)=0\ \leftrightarrow\ v=0.
\]
Here $t\in\{0,1\}$ abbreviates
$t=0\lor t=1$.
Let $K(v)=C(v,1,p(v))$. Then
$K(0)=1$, $K(Sv)=v$, and coverage yields
\[
 K(v)=0\ \leftrightarrow\ v=1.
\]
These are constructive case arguments.

Define addition and truncated subtraction by
\begin{align*}
 x+0&=x,&x+Sy&=S(x+y),\\
 d(x,0)&=x,&d(x,Sy)&=p(d(x,y)).
\end{align*}
Four inductions on literal equations give
\[
 0+y=y,\quad (Sx)+y=S(x+y),\quad
 d(Sx,Sy)=d(x,y),\quad d(Sa,a)=1.                            \tag{A}
\]
For the first two, induct on $y$ and compute.
For the third the base is $p(Sx)=x$ and the step
applies $p$ to the induction equality.
For the fourth the base is $d(1,0)=1$ and its
step is the third identity followed by the
induction hypothesis.

The crucial further induction is on the
\emph{single equation}
\begin{equation}
 C(\operatorname{sg}(d(x,y)),x,y+d(x,y))=x.
 \label{eq:residual}
\end{equation}
At $y=0$, its two selector alternatives are
both $x$, using $0+x=x$. For the step set
$r=d(x,y)$ and $r'=p(r)=d(x,Sy)$.
If $r'=0$, the new selector returns $x$.
Otherwise coverage gives $r'=S(p(r'))$.
The zero case for $r$ is contradictory, and
its successor case gives $r=Sr'$.
The induction equation therefore says
$y+r=x$. The identity
$(Sy)+r'=y+Sr'=y+r$ from (A) proves the
new selected equality. All case splits use
coverage, not induction on an implication.

Substitute $x=Sa,y=b$ in \eqref{eq:residual}.
If $d(Sa,b)=1$, then $b+1=Sa$, so
$Sb=Sa$ and $b=a$. Conversely $a=b$
and (A) give that residual value. Hence
\[
 d(Sa,b)=1\quad\leftrightarrow\quad a=b.
\]
The fixed term
\[
 e(a,b)=\operatorname{sg}\bigl(K(d(Sa,b))\bigr)
\]
therefore satisfies, throughout the numerical
domain,
\[
 e(a,b)\in\{0,1\},\qquad e(a,b)=0\leftrightarrow a=b.
 \tag{Equality reflection}
\]
In particular, equality is decidable; this
was proved rather than assumed.

For a fixed quantifier-free formula $A$, define
its characteristic term by finite external
recursion:
\begin{align*}
 b_{s=t}&=e(s,t),&b_\bot&=1,\\
 b_{A\land B}&=C(b_A,b_B,1),&
 b_{A\lor B}&=C(b_A,0,b_B),\\
 b_{A\to B}&=C(b_A,b_B,0).
\end{align*}
Constructive cases on the two-value
characteristics prove
$b_A\in\{0,1\}$ and $b_A=0\leftrightarrow A$.
For implication, the $b_A=0$ branch has $A$
and reduces to $b_B$; the $b_A=1$ branch
has $\neg A$ and reduces to zero.
This uses decidability of a fixed
quantifier-free formula, never excluded
middle for arbitrary quantified formulas.

Translate a quantifier-free induction
premise through this equivalence, apply
equation induction to $b_A(n)=0$, and
translate back. The retained context can
contain arbitrary formulas as long as the
usual induction-variable freshness holds.
Thus $T_{\R}$ recovers the full
quantifier-free induction schema of iPRA.

\section{Both interpretations and both round trips}
\label{sec:biinterp}

\subsection{Interpreting the new calculus in iPRA}

In iPRA, interpret every fixed recursor body by
ordinary primitive recursion with initializer
$Sa$:
\[
 r_h(0,a,\vec p)=Sa,\qquad
 r_h(Sn,a,\vec p)=h(n,r_h(n,a,\vec p),\vec p).
\]
Interpret $\D$ and clauses by
\eqref{eq:dreading}. Every new rule is sound
by the argument of Section~\ref{sec:logicproof}.
Canonicalization preserves these interpretations
because its computations are the displayed
defining equations.

The interpretation domain is $x=x$.
No standardness predicate, coding range,
retract or quotient is introduced.
Equality is unchanged.

\subsection{Interpreting iPRA in the new calculus}

Translate each fixed primitive-recursive
description by \eqref{eq:rec}, and each
ordinary logical operation by
\eqref{eq:macros}. The primitive-recursive
defining equations compute. The successor
axioms, ordinary logical rules, and
quantifier-free induction were derived
above. This therefore interprets the
entire first-order theory, not merely
its equational fragment.

\subsection{Numerical composites}

For a fixed recurrence, two functions with
the same initial value and update are
provably equal by contextual equation
induction: the base is their common
initializer and the step uses congruence
in the common update.

External induction on a finite
primitive-recursive description therefore
shows that its translation into $\R$
and back equals the original operation
at every internal argument.

The other direction must check the
primitive $\R$ itself, not only translated
scalar iterators. Interpreting $\R$ in
iPRA and compiling back, then identifying
the returned initializer and body by
induction on their finite syntax, gives
a term provably equal to
\[
 \Rec(n,Sa;i,v.h(i,v)).
\]
It has the same initial value $Sa$ and
the same successor update as
$\R(n,a;i,u.h(i,u))$.
Equation induction proves
\begin{equation}
 \Rec(n,Sa;i,v.h(i,v))
 =
 \R(n,a;i,u.h(i,u)).
 \label{eq:rround}
\end{equation}
An induction on term construction now
gives the other numerical round trip.
Consequently $x=y$ is a definable total
bijective identity graph preserving
every operation in both composites.

\subsection{Formula composites}

The essential native identity is
\begin{equation}
 \D_{x,y}B(x,y)
 \inter
 \exists_*x\bigl(B(x,0)\Rightarrow_*
                     \forall_*y\,B(x,y)\bigr).
 \label{eq:dround}
\end{equation}
Forward, ordinarily open the left side
at $b$. Under $B(b,0)$ its clause
supplies $B(b,z)$ for a fresh $z$.
Introduce universal, implication and
existential macros, and close the opening.
Backward, eliminate the existential
macro at a fresh witness and introduce
$\D B$ in case mode at that witness.
Its zero assumption, the implication,
and universal elimination supply the
successor instance. Close the outer
existential elimination.

The interpretations of all ordinary
macros have their ordinary round trips:
selector endpoints give implication
and disjunction; rows $1,2$ give
conjunction; the zero gate and row $1$
give existential quantification; and
row $St$ with $P(St)=t$ gives all
universal instances. Falsity uses the
explicit separation bridge.
External induction on formula syntax,
using \eqref{eq:rround} and
\eqref{eq:dround}, proves both
formula composites.

In particular,
\[
 \K\der 0=S0
 \quad\Longleftrightarrow\quad
 \ipra\der\bot.
\]
This is equiconsistency and completes
the proof of Theorem~\ref{thm:main}.
It is a metatheorem, not an assertion
that either arithmetic proves its
own consistency.

\section{The complete checker and its verification}
\label{sec:implementation}

\subsection{Encoding and acceptance contract}

The source is \texttt{code/checker.py}.
It needs only Python's standard library.
Its raw integer/list encoding is:
\begin{center}
\begin{tabular}{@{}ll@{}}
\toprule
Object & JSON representation\\
\midrule
Zero & \texttt{0}\\
Free numerical parameter & negative integer level\\
Bound variable & positive de Bruijn index\\
$\R(n,a;i,u.h)$ & \texttt{[n,a,h]}\\
$s=t$ & \texttt{[s,t]}\\
$\D_{x,y}B$ & \texttt{[B]}\\
\bottomrule
\end{tabular}
\end{center}
Inside a recursor body, index 1 is $u$
and index 2 is $i$. Inside a $\D$
matrix, index 1 is $y$ and index 2
is $x$. Both constructors add two
bound positions in their last child.
A successor is \texttt{[0,a,0]}.

An input is a JSON object with exactly
the keys \texttt{goal} and \texttt{proof}.
Its goal is closed and canonical.
The proof instructions are
\begin{align*}
 &\texttt{['u', clause\_index, term, premise]},\\
 &\texttt{['i', matrix, witness, branch]},\\
 &\texttt{['e', major, branch]}.
\end{align*}
For an unconditional clause, the premise
payload is ignored; use JSON \texttt{null}.
There are no separate proof instructions
for equality or computation.
Acceptance means normal process exit
with \texttt{ACCEPT}; malformed syntax,
an incorrect proof, or an exception does
not constitute acceptance.

\subsection{The trusted changes}

Relative to the pinned inherited checker,
the changes are confined to the arithmetic
syntax, the shared binder increment,
the recursor computation, and the
successor abbreviations in the rules.
The three proof instructions and their
logical tests are unchanged.

Because $\R$ is the only compound
numerical constructor, a compound
canonical counter is a successor
exactly when its first child is zero.
The old test distinguishing a two-child
$S$ node from a three-child $I$ node
is unnecessary. This is the reason
the new syntax reduces validator and
normalizer code despite the update's
extra counter argument.

When unfolding $\R(Sn,a;i,u.h)$,
the implementation first substitutes
the old counter at depth 1, preserving
the state slot, and then substitutes
the recursive state at depth 0.
This order preserves outer indices
under nested binders. Both substitutions
use the same capture-avoiding operation.

\subsection{Scope of executable evidence}

\begin{proposition}[Checker correspondence]
Ignoring finite physical resource limits, the acceptance
module accepts exactly the closed canonical conclusions
having a finite $\K$ derivation, through the stated
certificate encoding.
\end{proposition}
\begin{proof}
On well-scoped finite syntax, induction on the tree
shows that the shared traversal implements the
constructor and binder conventions. Its recursor
case implements (N); the additional induction is
on the finite successor prefix of its counter.
The variable callback in \texttt{syntax} checks
precisely the free-level range and local bound
depth, and comparison with the result enforces
canonicality. Every child is checked before a
zero-body erasure.

The callback in \texttt{sub} replaces the
specified bound slot, shifts the inserted
expression past inner binders, and lowers
the outer indices after removing the slot.
Tree induction, together with (SC) when a
substitution exposes a recursor redex,
proves capture-avoiding opening followed
by normalization.

Induct now on an accepting proof-call tree.
Use checks the selected index and its
antecedent when present. Introduce checks
exactly its successor row under the chosen
assumption and validates the original matrix
in the returned formula. Open checks its
major before extending the context, computes
the specified probe, and validates the branch
conclusion again in the outer scope. If its
probe succeeds, the unmodified stored base
is $0=0$, so it also equals the substituted
base required by the mathematical rule.
These are exactly the three inferences.

Conversely, decorate a finite derivation
with the retained clause indices, its
matrices and witnesses, and fresh negative
levels in order of scope creation.
Use \texttt{null} for an unused premise.
Induction on the derivation shows that
the module validates this certificate.
The global comparison checks its closed
goal. No test-generator correctness
assumption enters either direction.
\end{proof}

\section{Further research questions}
\label{sec:further}

\begin{enumerate}
 \item \textbf{Formal verification of
 the new normalization layer.}
 Extend the repository's normalization
 by evaluation development from
 scalar $I$ to counter-aware $\R$,
 prove the environment laws, and
 lift the existing inferred-opening
 comparison through the exact
 embedding in Lemma~\ref{lem:embedding}.
 This is the most direct next
 verification step.

 \item \textbf{A smaller shared
 binder-opening operation.}
 Both object-language constructors
 now bind two variables, but retained
 clauses have one universal variable.
 Can a uniform representation remove
 partial binder opening while reducing
 the \emph{whole} checker, including
 validation and scope checks?

 \item \textbf{Remove the witness test
 without adding a larger grammar test.}
 Guarded atomic matrices can make
 introduction depend only on the
 formula root and can guarantee a
 reflexive zero row for opening.
 The open issue is whether the
 resulting complete grammar and
 checker are simpler than the
 unrestricted $\K$ presented here.

 \item \textbf{A comparison below the
 compressed frontier.}
 Port this arithmetic/logic combination
 into the repository's compact
 certificate architecture and count
 every validator and normalizer.
 The present 1,965-byte result does
 not settle whether that can beat
 the substantially smaller existing
 profiles.

 \item \textbf{Resource-controlled
 checking.}
 A fuel-bounded implementation with
 explicit rejection can make runtime
 limits part of the certificate
 contract. Compare such implementations
 with equally bounded controls rather
 than charging this overhead to only
 one side.

 \item \textbf{Meaningful minimality
 statements.}
 A global claim needs a fixed
 description language, permitted
 runtime primitives, and input
 contract. Can a lower bound be
 proved in a useful restricted
 class of proof checkers, rather
 than inferred from the smallest
 program currently found?
\end{enumerate}

\section{Complete acceptance module}

The following is the complete
\texttt{code/checker.py}. No external
theorem library, normalizer, or
validator is called.

\begin{lstlisting}
import json

def need(condition):
    if not condition:
        raise ValueError('invalid certificate')

def walk(a, f, d=0, form=None):
    if type(a) is int:
        need(not form)
        return f(a, d)
    need(type(a) is list)
    size = len(a)
    need(form is None or (size in (1, 2) if form else size == 3))
    a = [walk(b, f, d + 2 * (size == 1 or i == 2), size == 1) for i, b in enumerate(a)]
    if size == 3:
        c, b, h = a
        if c == 0:
            return [0, b, 0]
        if type(c) is list and c[0] == 0:
            return sub(sub(h, c[1], 1), walk([c[1], b, h], lambda i, d: i))
    return a

def syntax(a, n, form=False):
    need(walk(a, lambda i, d: need(1 - n <= i <= d) or i, form=form) == a)

def sub(a, t, depth=0):
    return walk(a, lambda i, d: walk(t, lambda j, e: j + d if j > e else j) if i == d + 1 else i - (i > d + 1), depth)

def prove(p, g):
    n = len(g)
    b = -n
    match p:
        case ['u', j, t, q]:
            need(type(j) is int and 0 <= j < n)
            syntax(t, n)
            u, B = g[j]
            if u:
                need(prove(q, g) == u)
            A = sub(B, t)
        case ['e', q, r]:
            D, = prove(q, g)
            B = sub(D, b, 1)
            u, E = (sub(B, 0), sub(B, [0, 0, 0]))
            t0 = E[1] if u == [0, 0] and E[0] == b else b
            B = walk(B, lambda i, d: t0 if i == b else i)
            A = prove(r, g + [(u, B)])
        case ['i', B0, t, r]:
            syntax(t, n)
            B = sub(B0, t, 1)
            u = sub(B, b if len(B0) == 2 and (not t) else 0)
            need(prove(r, g + [([], u)]) == sub(B, [0, b, 0]))
            A = [B0]
        case _:
            need(False)
    syntax(A, n, True)
    return A

def check(data):
    need(set(data) == {'goal', 'proof'})
    syntax(data['goal'], 1, True)
    need(prove(data['proof'], [([], [1, 1])]) == data['goal'])
if __name__ == '__main__':
    check(json.load(open(0)))
    print('ACCEPT')
\end{lstlisting}
