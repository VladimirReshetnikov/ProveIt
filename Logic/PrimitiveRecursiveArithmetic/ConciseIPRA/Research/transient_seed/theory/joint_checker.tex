\subsection{An optional predecessor-specified computation interface}

There is also an initialized-iterator profile below all three attained
incumbent coordinates. Its complete source measures 280 normalized Python
tokens, 314 AST nodes, and 684 normalized bytes, compared with the attained
coordinate envelope 281/315/685. This is a narrow implementation improvement,
not a new arithmetic basis. It changes the computation packet protocol.

An arithmetic packet supplies the triple $s=[n,a,r]$. If $n$ is false,
its generated equation is $I(0,a;r)=a$. If $n$ is true, the checker
\emph{constructs} the successor counter and generates
\[
       I(Sn,a;r)=r[I(n,a;r)/u].
\]
Thus there is no submitted alleged successor constructor whose arity must
be tested. The relevant source is
\begin{verbatim}
n, t, u = s
h = [[n and [n], t, u], i(u, s, 1) if n else t]
\end{verbatim}
The update's used recursive image is still checked at numerical root.
When the update ignores that image, its value is independent of the
recursive state and no such check is required. The generated source is
checked by the common opening in every successful continuation.

\paragraph{Zero-instance soundness.}
For false $n$, every surviving scalar/empty alias denotes zero. The seed
in the source and its exposed copy agree after the newly allocated name
is replaced by zero, by the same zero-extension induction as before.
For true $n$, the source counter is literally the singleton $[n]$;
therefore its numerical interpretation is a successor, regardless of
whether $n$ itself is atomic, unary, or an iterator. If the update uses
its state, the opener validates the entire recursive source $s$ before
inserting it. Extra zero slots under the displayed successor do not
change the decoded predecessor. If the state is not used, the right side
is the same update independent of that state. The old parameters remain
fixed, and every permitted newly exposed name disappears at the zero
instance. Consequently the generated assumption $H(w)$ has a proved
instance $H(0)$ in both branches. The known-instance cut discharges it.
This argument must be read with the explicit sorted codec, not as an
assertion that every raw packet is a standard first-order term.

\paragraph{Canonical completeness at predecessor zero.}
Canonical terms other than literal zero have truthy encodings. To obtain
an ordinary successor computation whose predecessor is literally zero,
put
\[
 z=I(0,0;u.0),\qquad \vdash z=0.
\]
The encoding of $z$ is nonempty. Hence the new packet generates the
successor computation at $z$. Transport that whole equation along $z=0$
with the motive
\[
 F(v)\equiv
 I(Sv,a;u.r)=r[I(v,a;u.r)/u].
\]
This gives $F(0)$. The proof of $z=0$ uses the base packet, so the expansion
is finite and noncircular. All other native inference rules are unchanged.
Replacing each computation leaf in a native derivation by these finite
expansions proves canonical completeness. The new serializer performs
this expansion in named syntax and then assigns fresh labels afresh.

\paragraph{Small source conventions.}
The printable lookup table uses the identities
$\operatorname{ASCII}(B)\bmod8=2$,
$\operatorname{ASCII}(A)\bmod8=1$, and
$\operatorname{ASCII}(D)\bmod8=4$. Constructor arities and their scope
increments remain exactly the same. The default image \texttt{0j} is an
invalid-image marker: like \texttt{None}, it cannot pass comparison with
an integer, and a used missing image therefore rejects. JSON cannot
supply a complex literal. Only the standard \texttt{json} module is
imported; the wildcard import changes no trusted mathematical dependency.

The Boolean expression replacing conditional transport also preserves
successful behavior. Opening a nonempty formula tree preserves its
outer arity. Therefore if a successful formula opening $i(t,s)$ is false,
both openings $i(t,s)$ and $i(t,u)$ are the same empty tree or scalar
truth. In the matched case the latter equals the requested goal $a$.
The fallback to $a$ is thus exactly the same result as the conditional
minor, including that exceptional false-value case.

The readable checker uses the direct table $(0,2,1,4)$, the ordinary
\texttt{None} marker, and an explicit conditional. It implements the
same successful semantics and is supplied for review. These source
conventions account for the final one-unit margins; they should not be
presented as mathematical breakthroughs.
