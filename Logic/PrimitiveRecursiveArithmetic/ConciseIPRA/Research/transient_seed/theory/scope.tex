\section{What improves, and what the comparison establishes}
\label{sec:scope}

The request has two distinct demanding parts: a simpler arithmetic/logical
presentation genuinely equivalent to intuitionistic PRA, and a complete
proof checker below the best supplied implementations. We give a new arithmetic basis, a noncircular bootstrap of the native
logical interface, and a direct complete SR checker below the incumbent
normalized-byte minimum. We do not identify an attained source record
with a proof of absolute optimality.

The comparison is pinned to the repository commit in~\cite{snapshot}.
All nine direct ZIP members of \mbox{\file{docs/drafts}} were read. The directory
contains atomic transport, elimination assumptions, endpoint certificates,
generated assumptions, guarded elimination, named specialization, scalar
countdown, shared continuation, and successor recursion. Their historical
comparison tables refer to older snapshots, so they are not themselves the
current benchmark. The current best complete-source coordinates are
\[
                 281\text{ tokens},\qquad315\text{ AST nodes},\qquad685\text{ bytes}.
\]
The generated-assumptions main program attains 281/318/685, and its AST
variant attains 283/315/710. These are attained upper bounds on the cost of
a checker, not mathematical lower bounds on every possible axiomatization.

\subsection{The new arithmetic result}

The successor-recursion draft~\cite{successor} uses
$R(n,a;u,v.h)$, with separate old-counter and old-state inputs. The
shared-continuation draft~\cite{shared} asks whether the one-state
$R(n,a;v.h)$ can also dispense with a primitive successor. It isolates
the missing theorem $P(Sa)=a$ and correctly warns that the old scalar
predecessor proof already assumes arbitrary initialization.

We supply that missing theorem. The new construction first creates
selected zero-start trajectories using transient seeds, then creates a
Boolean comparator, and finally builds a parameterized reset cycle.
Three explicit equation invariants yield predecessor. The initializer
compiler
\[
 \widehat I(n,a;u.h)=P\bigl(R(n,a;v.S(h[Pv/u]))\bigr)
\]
then satisfies both ordinary scalar recursion equations by computation.
This is a whole-domain argument: the intermediate facts are internal
equations, and every induction holds all passive parameters fixed.

The numerical grammar therefore has two primitive constructors, $0,R$;
its update binds one variable; and it uses two computation schemas. The
ordinary logical rules, coverage, separation, and equation induction are
all stated explicitly below. This is not a finite ordinary first-order
signature with a universal evaluator: each body is fixed earlier finite
syntax, or equivalently names a function in a staged signature.

\subsection{Closing the logical bootstrap, and the remaining boundary}

The native Choice-DI logic in the supplied small programs reconstructs
ordinary logic using an unshifted selector. Applying that reconstruction
before proving predecessor would be circular. Section~\ref{sec:native-sr-bootstrap}
closes this additional gap: successor is already cancellable on Boolean
values by a finite decoder. This yields a restricted native implication
and contextual Boolean case elimination with equation conclusions.
Those are exactly the case analyses used in the comparator and reset-cycle
proofs. Thus predecessor is derived in native SR itself; the unshifted
selector and full ordinary logical interface are reconstructed afterward.

The direct program \file{code/checker_sr_bytes.py} checks the new SR
computation schemas, with a zero-counter result $Sa$ rather than $a$.
Its two-byte change to the arithmetic supply is charged in full. The
other profiles remain initialized-I checkers and are labelled as such.
Both native presentations are bi-interpretable with iPRA, including
native-formula return translations and numerical identity composites.

A globally simplest axiomatization and a lower bound applicable to arbitrary
languages and domains are not claimed. The optional I predecessor-packet
profile does beat all three attained incumbent minima in one complete
program; the native SR program separately beats their byte minimum. The closed result is a genuine
arithmetic and logical reduction, accompanied by a direct implementation
below the supplied byte frontier.
