Canonical numerical syntax
--------------------------
The terms are 0, S(t), and R(n,a;u,v.h), with ordinary rigid parameters
where permitted by scope. The defining computations are

  R(0,a;u,v.h)    = S(a),
  R(S(n),a;u,v.h) = h[n/u, R(n,a;u,v.h)/v].

The old update h is retained inside the recursive state. Substituting the
current counter into the recursive state's own update would be incorrect.

Object formulas and clauses
---------------------------
Object formulas contain only literal numerical equations and paired
closures D_xy B. Unary Q_y B is an internal closure clause, usable by
membership as an elimination major. It is not an object formula that can
be directly concluded. Its ordinary reading is B(0) -> forall y B(y);
D_xy B means exists x (B(x,0) -> forall y B(x,y)).
