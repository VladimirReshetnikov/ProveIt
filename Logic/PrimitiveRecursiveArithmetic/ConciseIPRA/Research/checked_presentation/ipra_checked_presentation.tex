\begin{abstract}
We inspect the current ConciseIPRA collection at commit
\texttt{6ffc49f55d35} (full identity below), including its three incoming
archives. The main deliverable is a standalone proof checker for the existing
native Eq/\(\D\) presentation that validates the entire integer/list certificate
alphabet, its closed public goal, and its binding scope. Its normalized size is
\textbf{\NativeBytes\ bytes, \NativeTokens\ significant Python tokens, and
\NativeAST\ AST nodes}, compared with \textbf{849 / 370 / 426} for the
closest explicitly matched fully typed native control. A separate compact
profile reduces the actual byte incumbent from 506 to \textbf{502} bytes.

The improvement is in the checked representation and validation architecture;
the mathematical axioms and inference rules are inherited. We give their
complete specification, explain the whole-domain bi-interpretation with full
first-order \(\ipra\), prove the implementation transformations, and include
the foundational arithmetic proofs as attributed appendices. The current
compact coordinate envelope is 253 tokens, 275 AST nodes, and 506 bytes,
attained by different programs. The new results do not beat that envelope in
every coordinate and do not establish an absolutely simplest axiomatization.
No new Lean or Rocq verification is claimed.
\end{abstract}

\section{Result, comparison set, and the unresolved part of the request}
\label{main:result}

The requested criterion is the size of a complete proof checker, while the
theory must remain bi-interpretable and equiconsistent with full first-order
intuitionistic primitive recursive arithmetic. This report gives a verified
improvement for a precisely specified complete-checker contract. It does not
claim a new arithmetic basis or a new deletion of a mathematical axiom.

The repository distinguishes several interfaces that must be kept separate:
\begin{enumerate}
\item A \emph{compact} program assumes a canonical guarded public goal and an
integer/list certificate alphabet. It need not enforce both assumptions itself.
\item A \emph{goal-validated} program checks its public formula and scope,
while allowing the inherited treatment of auxiliary data and unused prefixes.
\item An \emph{entire-certificate-validated} program checks every supplied
leaf and container, including unused prefixes, as well as the public formula
and its scope. The selected native program has this contract.
\end{enumerate}
All reported module sizes include the JSON reader, the checker itself, and
the final acceptance output. None of the selected checkers imports a local
helper, an external theorem prover, a compressed hidden checker, or a table
of theorems. Python and its standard JSON library are shared infrastructure,
as in the repository's measurement convention.

\section{The complete mathematical presentation}
\label{main:calculus}

\subsection{Terms, formulas, and freshness}

There is one numerical sort. Terms are fixed finite expressions
\[
 t ::= x\mid 0\mid S(t)\mid I(n,a;u.h).
\]
Only \(u\) in \(h\) is bound by an iterator. Its update may contain any fixed
numerical parameters, but has no extra recursion-counter argument. Every
body is finite earlier syntax. Equivalently, elaborate each fixed body into
its own first-order function symbol with parameters. This convention does
not assert a total numerical universal evaluator for arbitrary primitive
recursive programs.

The native formulas are
\[
 A ::= (s=t)\mid \Q_y B\mid\D_{x,y}B.
\]
The public language of the selected checker omits \(\Q\); closures are
available internally. The designated contradiction is \(0=S0\).
Contexts \(\Gamma\) are finite lists of reusable native assumptions.
The variables \(x,y\) bound by a paired binder are distinct.
All displayed substitution is capture avoiding. Bound variables are renamed
before substitution when necessary.

\subsection{All axioms and all primitive rules}

The two nonlogical axiom schemas, available in any context, are
\begin{align}
 I(0,a;u.h)&=a,\tag{C0}\label{main:c0}\\
 I(Sn,a;u.h)&=h[I(n,a;u.h)/u].\tag{CS}\label{main:cs}
\end{align}
Together with these schemas, the following six rule families specify the
presentation. The two introduction rows are distinct allowed patterns.
\begin{align*}
 &\frac{A\in\Gamma}{\Gamma\vdash A}\quad\mathrm{Hyp},\\[5pt]
 &\frac{\Gamma\vdash s=t\qquad\Gamma\vdash F(s)}
        {\Gamma\vdash F(t)}\quad\mathrm{Tr},\\[5pt]
 &\frac{\Gamma\vdash\Q_y B(y)\qquad\Gamma\vdash B(0)}
        {\Gamma\vdash B(t)}\quad\mathrm{QE},\\[5pt]
 &\frac{\Gamma\vdash\D_{x,y}B(x,y)\qquad
        \Gamma,\Q_y B(b,y)\vdash A}{\Gamma\vdash A}\quad\mathrm{DE},\\[5pt]
 &\frac{\Gamma,B(t,0)\vdash B(t,Sz)}
        {\Gamma\vdash\D_{x,y}B(x,y)}\quad\mathrm{DI}_{\rm case},\\[5pt]
 &\frac{\Gamma,E(t,z)\vdash E(t,Sz)}
        {\Gamma\vdash\D_{x,y}E(x,y)}\quad\mathrm{DI}_{\rm progress}.
\end{align*}
Here \(F\) is any native formula template, and \(E\) is a \emph{literal
equation}. An equation beneath a binder is not a literal equation.
In DE, \(b\) is fresh for the conclusion, context, and passive parameters
of the matrix. In either introduction, \(z\) is fresh for the context,
witness \(t\), and passive parameters. The displayed local assumptions
are discharged.

This is the inherited Choice-DI calculus. Counting each computation schema
as a rule gives eight patterns. There are no additional primitive ordinary
logical axioms, successor axioms, equality-reflexivity axiom, or induction
schemas. The proof checker uses an equivalent packet protocol: some of the
displayed rules are recovered as derived rules rather than assigned distinct
instruction tags.

\subsection{Why ordinary intuitionistic logic is present}

Put \(C(v,a,b)=I(v,a;u.b)\), with \(u\) unused in \(b\). Computation gives
\(C(0,a,b)=a\) and \(C(Sv,a,b)=b\). Define a gate recursively on native
Eq/\(\D\) formulas by
\[
 G_v(s=t)\equiv C(v,0,s)=C(v,0,t),\qquad
 G_v(\D_{x,y}B)\equiv\D_{x,y}G_vB.
\]
The calculus proves \(G_0A\), and \(G_{Sv}A\) is interderivable with \(A\).
It also proves the padding equivalence
\(A\dashv\vdash\D_{u,y}G_yA\), with \(u\) unused.

For formulas of equal binder shape, select between their final equations
using \(C\), and commute this operation through aligned \(\D\) binders.
For unequal shapes, pad the shallower equation with the preceding gate.
This defines \(M_v(A,B)\) with endpoint equivalences
\(M_0(A,B)\dashv\vdash A\) and \(M_{Sv}(A,B)\dashv\vdash B\).
The full recursive definition and derivations are in
Appendix~\ref{sec:choice-introduction}; no propositional connective is
silently assumed by that construction.

Let \(\delta(v)=C(v,S0,0)\) and \(p(z)=I(z,0;u.\delta(u))\).
The ordinary logical operations are the following macros, with fresh
displayed binders and unused \(u\):
\begin{align*}
 A\Rightarrow_*B&=\D_{u,z}M_z(A,B),\\
 A\wedge_*B&=\D_{u,z}G_zM_{p(z)}(A,B),\\
 \exists_*x\,A(x)&=\D_{x,y}G_yA(x),\\
 A\vee_*B&=\exists_*x\,M_x(A,B),\\
 \forall_*x\,A(x)&=A(0)\wedge_*\D_{u,z}G_zA(z),\\
 \bot_*&=(0=S0).
\end{align*}
They admit the ordinary intuitionistic introduction and elimination rules.
Numerical cases are derived by case DI with an unused witness coordinate,
followed by DE and QE. Equation induction is obtained similarly from
progress DI. Explosion follows because \(0=S0\), computation, and transport
make \(s=C(0,s,t)=C(S0,s,t)=t\) for arbitrary terms; induction on formula
syntax then yields every native formula. No excluded middle for arbitrary
formulas is introduced.

\section{The bi-interpretation, including both composites}
\label{main:bridge}

The ordinary first-order realization \(T_I\) uses intuitionistic equality
logic on the same numerical domain, the computation equations C0 and CS,
contextual induction for literal equations, and the two explicit axioms
\[
 \forall n\,(n=0\vee\exists m\ n=Sm),\qquad (0=S0)\to\bot.
\]
The second is an actual falsity bridge. It cannot be omitted on the ground
that the native presentation derives explosion from its designated equation:
positive computation equations alone admit a singleton structure.

The interpretations of the two native binders are
\[
 (\Q_yB)^\circ=B^\circ(0)\to\forall y B^\circ(y),\qquad
 (\D_{x,y}B)^\circ=\exists x\bigl(B^\circ(x,0)\to\forall yB^\circ(x,y)\bigr).
\]
Equation, variable, and numerical term interpretation is the identity.
Case DI is sound by numerical coverage. Progress DI is sound by equation
induction under the temporarily assumed zero instance. The other displayed
rules have their ordinary equality and logical meanings. Conversely, the
macros and derived rules above interpret \(T_I\) in the native calculus.

\begin{theorem}[Inherited whole-domain arithmetic bridge]
\label{main:biinterpretation}
The ordinary realization \(T_I\), and consequently the native presentation,
is bi-interpretable and equiconsistent with full first-order \(\ipra\).
Both numerical interpretation domains are the whole domain, interpreted
equality is actual equality, and both numerical composite isomorphisms have
graph \(x=y\).
\end{theorem}
\begin{proof}
The iPRA interpretation of a fixed iterator uses primitive recursion with
an update that ignores its counter. It proves C0, CS, coverage, separation,
and every contextual equation-induction instance.

The reverse direction uses the following internal constructions in order.
First the scalar predecessor proof gives a fixed term \(P\) satisfying
\(P0=0\) and \(P(Sn)=n\). This yields successor injectivity, and coverage
strengthens to \(n=0\vee n=S(Pn)\). Next, truncated subtraction and the
equality-reflection construction give a term that detects actual equality
on the entire domain. Each fixed quantifier-free formula consequently has
a primitive recursive Boolean characteristic, so literal-equation
induction yields quantifier-free induction. Only after those steps are
pairing and its projections constructed and verified. The proofs are
reproduced in Appendices~\ref{sec:hybrid-bootstrap} and
\ref{sec:iterator-coding}; the equality-reflection appendix lies between
them. This order avoids assuming equality detection or pairing in order
to obtain the predecessor.

If \(\pi,L,H\) are pairing and projections, a fixed primitive recursion
\(f(0,\vec p)=g(\vec p)\), \(f(Sn,\vec p)=h(n,f(n,\vec p),\vec p)\)
is compiled as
\begin{align*}
 V(n,\vec p)&=I\bigl(n,\pi(0,g^*(\vec p));
 u.\pi(SL(u),h^*(L(u),H(u),\vec p))\bigr),\\
 f^*(n,\vec p)&=H(V(n,\vec p)).
\end{align*}
Equation induction proves \(L(V(n,\vec p))=n\); the projection identities
then prove the defining equations of \(f^*\). This is external recursion
on each fixed finite function description, not object-level universal
evaluation of function codes.

For the numerical composites, a double-translated iterator has the same
initializer and the same update after its lower-level descriptions have
been identified. Equation induction on equality of two recurrence values
proves their uniqueness. External induction on finite descriptions thus
identifies every operation with its double translation. The same argument
works for counter-aware primitive recursion. Whole domain and actual
equality make the graph \(x=y\) total, bijective, and operation preserving.

For the formula composites, the ordinary readings of the six logical
macros are intuitionistically equivalent to their intended operations.
The essential native composite is
\[
 \D_{x,y}B\dashv\vdash
 \exists_*x\bigl(B(x,0)\Rightarrow_*\forall_*y B(x,y)\bigr).
\]
Forwards, open \(\D\), assume its base, and use its closure at an arbitrary
fresh parameter before introducing the macros. Backwards, eliminate the
existential at a fresh witness and use case DI, obtaining the successor
instance from the implication and universal. Structural induction gives
both formula round trips. The falsity bridge is preserved, and effective
translations of finite contradiction proofs give equiconsistency.
\end{proof}

This theorem is inherited mathematics, with complete attributed supporting
proofs included below. The new contribution is the checked implementation
comparison. The repository contains Lean proofs of many native-calculus
equivalences; this report neither rebuilds them nor claims that the new
Python modules have been verified by Lean.

\section{What the compact 502-byte profile presents}
\label{main:compact}

The compact profile uses the same scalar terms and a guarded Eq/\(\D\)
public grammar. An equation immediately beneath \(\D_{x,y}\) must have
the literal shape
\[
              I(y,0;u.h)=I(y,0;u.k).
\]
Its zero instance is provable by computation. Compound matrices use case
introduction; literal equations use progress introduction. Arbitrary native
formulas are translated by guarding and padding their atomic parts. The
padding \(\D_{u,y}G_yE\) is equivalent to an equation \(E\), so this
restriction does not lose the represented first-order theory.
Appendix~\ref{sec:guarded-core} proves the guarded/native equivalence.

The source-selected transport protocol reserves literal source zero for
closure elimination. Its missing zero-source transport instances are
derived; the corresponding proof is included in the zero-source appendix.
Thus a short packet format should not be mistaken for a rule that simply
forbids an unrecoverable use of equality.

The 502-byte file assumes the canonical guarded public contract. The
optional exact guarded wrapper includes the validator and therefore has
its own measured size, 1,172 bytes. It is not the preferred standalone
interface: the selected native checker validates all its input in
\NativeBytes\ bytes and exposes the more convenient native Eq/\(\D\)
language directly. The compact profile is included because it improves
the actual compact byte record, not because its missing validation is
free.

\section{The implementation transformations and their proofs}
\label{main:implementation}

\subsection{A single alphabet check discharges repeated type obligations}

After JSON parsing, the selected native checker uses the gate
\begin{lstlisting}
q = not str(p).strip('0123456789-[], ') and p.pop
\end{lstlisting}
and then calls the resulting stack operation. The gate and the driver
together require a top-level list whose descendants are only integers
and lists. In the Python representation of such a tree, every character
belongs to the displayed alphabet. Conversely, a Boolean or null uses
letters, a float uses a decimal point or a nonnumeric spelling, a nested
string has quote characters, and an object has braces and a colon. At
least one forbidden character remains after stripping allowed characters
from the ends. Top-level strings such as a string of digits are a
necessary exception to the alphabet argument by itself: even if that
predicate passes, they have no \file{pop} method and are rejected by the
driver before proof checking. Top-level integers likewise cannot enter
the checker.

For every finite string \(s\) and character alphabet \(A\),
\(s.\mathrm{strip}(A)\) is empty exactly when all characters of \(s\)
are in \(A\). Thus this is an exact alphabet test, not a heuristic test
of the first and last characters.

During the initial public-goal traversal, the old additional
\file{type(a) is int} check is consequently redundant. If the list branch
does not apply, an actual list reaches an invalid scalar comparison and
rejects; every successful scalar case is already an integer. Later
traversals had the initial-validation phase disabled, so removing that
test changes no later rule. For all reachable integer/list data, and any
internally generated Boolean zero, the tests
\file{a * 0 == []} and \file{a * 0 != 0} select the same list branch.
The latter saves a further token, AST node, and byte. The missing-image
function sentinel still rejects.

The remaining initial traversal checks the closed Eq/\(\D\) grammar,
successor/iterator term grammar, and binding scope. An internal phase bit
enables these public checks only at the first call; the JSON certificate
cannot set it. This safely shares grammar traversal with the scope
traversal already required by the checker.

\subsection{Eager tuple selection of the next proof goal}

The incumbent next-goal expression has the shape
\[
                     C\ \mathrm{and}\ R\ \mathrm{or}\ a,
\]
where, after computing the newly retained hypothesis,
\begin{align*}
 C&\equiv (m,a)=
 \bigl(s\ \mathrm{and}\ [s,u]\ \mathrm{or}\ [t,t,t],\ i(t,u)\bigr),\\
 R&\equiv i(t,s).
\end{align*}
The new expression is \file{(a, i(t, s))[C]}. The opener \(i\) is pure
on finite integer/list trees; the caller's scope floor is local and is
not changed by the recursive proof of \(m\). Both openings occur before
the same floor decrement.

\begin{lemma}[False-result lemma]
At formula-root depth zero, if both \(i(t,s)\) and \(i(t,u)\) terminate
and the former is false in Python, they are equal.
\end{lemma}
\begin{proof}
For a list \(t\), the opener preserves the outer list length. A false
result therefore means \(t\) was empty, and both results are empty.
For an integer \(t\), the root-depth-zero branch is independent of the
replacement image: it either retains a scoped negative parameter or
returns zero. A false result is zero in both calls.
\end{proof}

If \(C\) is false, both selectors return \(a\) whenever the eager opening
terminates. If \(C\) is true and \(R\) is true, both return \(R\).
If \(C\) is true and \(R\) is false, the lemma and
\(a=i(t,u)\) give \(a=R\), so the choices again agree.
Every successful eager execution therefore has the old selected goal.
The new computation can reject a noncanonical certificate that the old
short-circuit expression never inspected. It does not follow that the
raw accepted certificate sets are equal.

Canonical completeness is preserved: numerical fields use only odd
list arities, so a formula-root traversal of such a field stays at even
depth and does not inspect its image. Genuine elimination packets already
needed the selected opening. Inert fields can be chosen to be zero.
Hence canonical proofs have the required extra terminating opening.

\subsection{The compact remainder selector}

Only the compact profile changes \lstinline|~len(a) % 2| to
\lstinline|3 % len(a)|. The meaningful formula arities are one for \(\D\),
two for equality, and three for \(\Q\). The two expressions agree there:
\[
\begin{array}{c|ccc}
 r&1&2&3\\\hline
 (\mathord{\sim}r)\bmod2&0&1&0\\
 3\bmod r&0&1&0
\end{array}
\]
At zero arity the new expression rejects. At arities at least four the
inherited sorted decoder interprets the entire formula as administrative
truth. Changing the opening image there cannot add a nontrivial assumption.
For a generated computation, the relevant inherited justification is the
known-zero-instance supply lemma: substitute newly admitted names to zero
and cut in the resulting computation theorem. It is not necessary, and
in general not correct, to claim the fresh-parameter supply is uniformly
a theorem.

This is a semantic soundness argument. The composed compact program is
not claimed to have raw accepted-trace inclusion in the 506-byte control
at all surplus arities. Its claim is the same canonical public theorem
set. The selected fully typed native program retains its original
introduction-mode test unchanged.

\subsection{A mode distinction that must be preserved}

In the native packet protocol, both the integer \(0\) and the empty list
\([]\) are false as control flags, but they are unequal. For an equation
matrix, the condition \lstinline|len(a) % 2 == u| selects progress at
\(u=0\), and cases at \(u=[]\). Both native introduction patterns are
therefore available. Replacing these two falsy values by one bit would
silently remove a required case. The exact alphabet gate admits both
values and the new native code preserves the test.

\begin{theorem}[Implementation claim]
Under the specified JSON protocol, the selected native module validates
the entire integer/list alphabet and its closed native Eq/\(\D\) public
goal. On the decoded public language it is sound and canonically complete
for the inherited native presentation, and hence presents a theory
bi-interpretable and equiconsistent with \(\ipra\).
\end{theorem}
\begin{proof}
The gate and initial traversal give the input invariants above. The
type-check removal and the integer/list discriminator replacement are
exact under those invariants. The tuple-selector lemma gives soundness
relative to the inherited native checker, and the canonical-packet
argument preserves theorem completeness. The remaining source rewrites
are the exact Boolean selection of a nonempty pair and the integer
identity \(\mathord{\sim}(-k)=k-1\). The native checking theorem and
Theorem~\ref{main:biinterpretation} then compose. The raw sorted decoder,
scope invariant, and known-zero-instance lemma are reproduced in
Appendix~\ref{sec:arity-checker}.
\end{proof}

\section{A rejected simplification: the danger of a ternary matrix}
\label{main:rejected}

One tempting attempted refinement was to choose the opening image solely
from the newly retained hypothesis \(h\), using
\file{(len(h) > 1) and k}. It handles an equation and an exported closure
uniformly and appears to remove the explicit major-premise flag. It fails
at a meaningful ternary matrix: an introduction whose matrix is a
\(\Q\) formula would receive the progress mode. Public Eq/\(\D\) validation
does not forbid \(\Q\) inside auxiliary proofs of major premises.

\begin{proposition}[Closure progress is not an innocent mode extension]
Adding progress introduction for arbitrary \(\Q\)-rooted matrices to the
native calculus supplies contextual induction for arbitrary native
formulas, rather than just literal equations.
\end{proposition}
\begin{proof}
For any native formula \(A(n)\), extend the gate by
\(G_v(\Q_yB)=\Q_yG_vB\), renaming \(y\) fresh for \(v\), and put
\(F(n)=\Q_v G_vA(n)\). Gate-zero is provable, and gate removal at \(1\)
gives \(F(n)\dashv\vdash A(n)\). Conversely, under \(A(n)\), numerical
cases give every gate instance and hence the closure. These conversions
use the ordinary native rules, not induction on arbitrary formulas.

Given a base proof of \(A(0)\) and a step from \(A(z)\) to \(A(Sz)\),
convert them to the corresponding base and step for \(F\). The proposed
extra progress introduction, with an unused witness coordinate, gives
\(\D_{x,n}F(n)\). DE opens its closure; the base and QE give \(F(t)\),
then \(A(t)\). Thus the intended induction boundary has disappeared.
\end{proof}

This rejected branch is included to make the crucial mathematical
constraint reviewable. The delivered programs do not use it. The

\section{Reproduction and further research questions}
\label{main:reproduction}

From the extracted archive, run
\begin{lstlisting}[language=bash]
python3 reproduce.py
python3 build_pdf.py
\end{lstlisting}
The first command recomputes the source metrics and reruns the substantive
native and compact certificate suites. The second compiles this report
with pdfLaTeX and no shell escape. All mathematical TeX inputs are
included. The source-level comparison ledger records the exact repository
paths and Git blob identities; the final manifest records delivered file
hashes. No repository was modified by this research task.

The remaining questions are mathematical, not requests to accept another
unproved size claim:
\begin{enumerate}
\item Can an arithmetic or logical rule be genuinely removed while giving
a smaller complete checker under one fixed, fully validated public
contract? The present reductions change validation and certificate
selection, not the axiom inventory.
\item Does successor-only iteration uniqueness imply an actual-equality
discriminator in the scalar language? The current orbit-closure report
derives zero-equation induction, but full equality reflection and hence
the full iPRA bridge remain unproved for that restriction. Its stronger
arbitrary-update uniqueness result must not be reused without proof.
\item Can the remaining induction-independence question be resolved with
a model of the binding iterator that respects substitution and passive
parameter coherence? Models with independently chosen recursion symbols
do not automatically supply such a model.
\item Can the Python acceptance relation, including its totalized arity
decoder and scope transitions, be linked to the existing Lean calculus
by a verified compiler? This would replace the current written
implementation metatheorems with a checkable formal bridge.
\item Which lower bounds can be proved after fixing the programming
language, input protocol, allowed libraries, and formula interface? A
finite repository census alone cannot prove global optimality.
\end{enumerate}
