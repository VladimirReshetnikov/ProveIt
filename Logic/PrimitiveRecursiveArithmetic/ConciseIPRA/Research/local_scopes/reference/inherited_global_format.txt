GENERATED-ASSUMPTION CHECKER: EXACT PUBLIC PROTOCOL
=================================================

Applies to checker.py and checker_ast.py. The strict control has the same
canonical mathematical certificates, with one additional early scope check.
This file describes this package's four-field packets. The inherited
reference/baseline_format.txt is historical and uses a different protocol.

1. INPUT, ORDER, AND VERDICT
---------------------------
Read one JSON array from standard input. Its last item is the requested
closed formula. Preceding items are four-field instructions [m,s,u,t],
consumed from right to left by list.pop(). The proof of a major premise is
consumed before the continuation. A goal already present in the reusable
context closes without consuming any instruction. An unread prefix is
inert, as in the frozen comparison programs.

Successful checking prints ACCEPT and returns exit status 0. Rejection
prints REJECT and returns nonzero; stderr may contain an exception trace.
All three files are complete standalone programs using the standard JSON
module. Submitted strings are never evaluated as Python code. Resource
limits may reject sufficiently large valid proofs; mathematical canonical
completeness is stated with unbounded resources.

To run a supplied example from the package root:

  python3 code/checker.py < tests/fixtures/I0_arbitrary_seed.json

2. SORTED RAW TREES
------------------
The same raw array is interpreted at its indicated sort:

  Arity   Formula                         Numerical term
  0       Truth, 0=0                      Zero
  1       Conditional closure Q           Successor
  2       Equality                        Zero with checked annotations
  3       Paired closure D                Initialized scalar iterator

All traversed arrays have at most three children. Unused annotations are
still traversed and checked. They contribute no mathematical assertion.

Q_y B means B(0) -> forall y B(y).
D_xy B means exists x (B(x,0) -> forall y B(x,y)).

For a protected numerical environment rho, nearest slot first, the decoder
has the following clauses. T is numerical decoding and F is formula
decoding; commas before rho prepend slots.

  T_rho([])        = 0
  F_rho([])        = (0=0)
  T_rho([p])       = S T_(0,rho)(p)
  F_rho([B])       = Q_y F_(y,rho)(B)
  T_rho([p,q])     = 0
  F_rho([s,t])     = (T_rho(s) = T_rho(t))
  T_rho([n,a,h])   = I(T_(0,0,rho)(n), T_(0,0,rho)(a);
                        v. T_(v,v,rho)(h))
  F_rho([P,U,B])   = D_xy F_(y,x,rho)(B)

Only the iterator update binds its scalar state. The two slots in that
update alias the same state; they are not separate state/counter inputs.
The successor's additional numerical slot and the iterator counter/seed
slots are dummy zeros. The two slots in a paired formula are distinct:
the nearest is y, and the next is x.

3. OPENING AND FRESH NAMES
-------------------------
At formula depth 2q and numerical depth 2q+1, q numerical slots are
protected. Canonical positive coordinates 2j-1 and 2j name the same j-th
slot, nearest first. Zero denotes numerical zero. Negative coordinates
name allocated rigid parameters. The floor k begins at 0 and decreases
by 1 at EVERY non-hypothesis continuation, including computation and
neutral endpoint steps. A major proof may itself allocate names first.

Opening i(a,t,d) traverses a list, increasing d by 2,1,4 respectively for
unary, binary, ternary nodes. A scalar a is retained when k <= a < d.
An exposed numerical scalar is replaced by the supplied image t; this
image is itself checked at numerical root (depth 1). Exposed formula
leaves become truth. A missing or malformed USED numerical image rejects.
The initial goal is checked with no supplied image, so it cannot contain
meaningful numerical references to unavailable parameters.

Canonical proofs use arrays and integers. Finite fractional coordinates
that survive a scope comparison alias their integer floors; booleans have
their zero/one values. Other raw inputs can be rejected or replaced by a
checked image. The soundness statement covers every successful run, but
completeness promises canonical certificates, not acceptance of every
noncanonical encoding of a theorem. The report supplies the raw-opening
invariants and addresses these aliases explicitly.

4. FOUR-FIELD PACKETS [m,s,u,t]
------------------------------
A. Truthy major m:

   First prove m in the retained context. A failed major always rejects.
   If either m=[s,u], or s is falsy and m=[t], and i(t,u) equals the current
   requested goal, replace that goal by i(t,s). These are, respectively:

   - equality transport with endpoints s,u and formula motive t;
   - Q elimination with base coordinate zero and target term u, with t
     the Q matrix.

   The new assumption is the opened slice m[2:]. For a binary or unary
   major this is [] (truth). If either match fails, retain the old goal
   and add this same truth: the endpoint request is a neutral step.
   Its alleged endpoint equality is never assumed.

   For a ternary major m=[P,U,B], the endpoint comparisons cannot match.
   The slice is [B], and opening at a fresh parameter supplies the closure
   used in D elimination. The requested goal remains unchanged.

B. Falsy m and truthy original t:

   This is D introduction. Its witness is t. Open the goal's third field
   with t at depth 2; that leaves one induction slot in the matrix.
   Canonical m=[] selects the base assumption B(t,0).
   Canonical m=0 selects E(t,z) when the opened matrix is a literal equation
   and selects B(t,0) for a compound matrix. The new goal is the successor
   instance B(t,Sz). No progress induction on Q or D matrices is allowed.

   To supply a zero-valued but truthy witness, use a proved zero term such
   as [0,0,0] (an initialized zero iterator). A raw scalar 0 or [] is falsy
   and would select computation instead. Equality transport can expand a
   proof when a syntactically different zero witness is used.

C. Falsy m and falsy original t:

   The source s must unpack as [n,a,r]. The packet's original u is unused.
   The program builds a local equation without changing the requested goal:

     false n:  [s,a]
     true n:   [s,i(r,i([*n,a,r],d=1),1)]

   The eager inner opening i([*n,a,r],d=1) is essential. It forces a true
   counter to be a singleton [p] and validates the predecessor iterator
   before substitution, even when the update ignores its state. In
   particular, a binary counter followed by a constant update cannot
   hide a malformed recursive image.

5. THE SHARED CONTINUATION
-------------------------
After any branch, decrease k, replace the requested induction slot by the
fresh successor [k], append the opened local assumption, and recurse.
The assumption's image is k when m is truthy, or when len(a)%2 == m;
otherwise it is zero. This single expression selects DE/progress versus
case assumptions. For a computation equation it may leave a fresh name
in the generated equation.

The requested old goal and retained context exclude that fresh name w.
Every generated arithmetic assumption H(w) has a provable zero instance
H(0). Its use is valid by substitution of zero followed by ordinary cut:

  Gamma,H(w) |- A     Gamma |- H(0)     w absent from Gamma,A
  --------------------------------------------------------
                         Gamma |- A

H(w) need not hold for every w. For example, source [0,1,0] can produce
the context equation [[0,1,0],-1], meaning I(0,0;v.0)=w. Its instance at
zero is a computation theorem. The report proves the general statement
by structural zero extension and the eager predecessor check.

checker_strict.py validates the entire generated equation before fresh
allocation. It rejects the two safe alias fixtures that the witness
profiles accept; this changes accepted raw certificates, not the decoded
closed theorem set. checker_ast.py replaces only the guarded opener by
an exception-based one with the same successful values and failures.

6. TRUSTED BOUNDARY AND REPRODUCTION
----------------------------------
Each entire checker module is measured. No helper producer, proof search,
arithmetic evaluator, source measurer, or external theorem library is
imported. All logical rules and the ordinary iPRA interpretations are
given in ipra_generated_assumptions.pdf and its standalone .tex source.

verify.py measures the three complete checkers and frozen controls,
executes certificates under ordinary and optimized Python, and checks
three targeted unsound guard-removal mutations. tests/producer.py is an
untrusted example producer, not part of the kernel and not a claimed
universal derivation compiler. See tests/README.txt and evidence/ for
actual receipts, proof traces, limitations, and provenance.
