## Prefer a single formal syntax

Use Foundation's `LO.FirstOrder.Arithmetic` throughout: `ArithmeticTheory`, `ArithmeticSentence`, `ArithmeticSemisentence k`, `𝗣𝗔`, `T ⊢ σ`, and `LO.FirstOrder.Satisfiable T`.

A compact, genuine first-order semantic endpoint is:

```lean
∃ e : Nat.Partrec.Code,
  ¬ (Nat.Partrec.Code.eval e 0).Dom ∧
  ∀ n : ℕ, LO.FirstOrder.Satisfiable (insert (HaltSentence e 0 n) 𝗣𝗔)
```

Here HaltSentence must be a fixed, explicitly specified arithmetization of deterministic computation. It is a new definition to implement; it is not a repository theorem name.

In the pinned Foundation version, `Satisfiable T` abbreviates
`Semantics.Satisfiable (SmallStruc L) T`. It is honest model existence, not an abstract placeholder.

## Computability and recursion

Import `Mathlib.Computability.PartrecCode`. Namespace `Nat.Partrec.Code` provides:

```lean
eval : Code → ℕ →. ℕ
evaln : ℕ → Code → ℕ → Option ℕ
evaln_sound : x ∈ evaln k c n → x ∈ eval c n
evaln_complete : x ∈ eval c n ↔ ∃ k, x ∈ evaln k c n
primrec_evaln : Primrec fun a : (ℕ × Code) × ℕ =>
  evaln a.1.1 a.1.2 a.2
eval_part : Partrec₂ eval
fixed_point₂ {f : Code → ℕ →. ℕ} (hf : Partrec₂ f) :
  ∃ c : Code, eval c = f c
```

A proof-search program g(e,x) that returns the output n of the first enumerated PA proof of ¬HaltSentence(e,0,n) can be closed by fixed_point₂.

Crucial simplification: only external equality `eval e = g e` is needed. If any such refutation exists, the search really halts at some m; Sigma-1 completeness gives a PA proof of its actual output, contradictory to the selected refutation. No internalized PA proof of the recursion-theorem equality is needed.

## Model-interface pitfall in a different ProveIt subsystem

`SetTheory.PA.Model` has induction for every Lean predicate and is categorical. It is unsuitable for nonstandard model constructions. The genuine first-order bundle is:
`LeanProofs.PAFiniteBasisReduction.TwoNonisomorphicModels.FirstOrderPAModel`,
imported via `PAFiniteBasisReduction.TwoNonisomorphicModels`, with:
```lean
structure FirstOrderPAModel where
  Carrier : Type
  preModel : PA.PreModel Carrier
  satisfiesPA : RawPASatisfies preModel
```

That file also proves `standardPAModel`, `nonstandardPAModel_exists`, and `peano_arithmetic_has_two_nonisomorphic_models`. Mixing its PA syntax with Foundation is unnecessary for this task.
