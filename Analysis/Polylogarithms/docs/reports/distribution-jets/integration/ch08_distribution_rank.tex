\begin{theorem}[Uniform distribution-row rank]\label{tower:thm:rank}
Let $q\ge2$ and $k\ge1$. Use homogeneous unknowns $X_1,\ldots,X_{q-1}$
and set $X_0=0$, representing a fixed endpoint value. For each prime
$p\mid q$ and $0\le b<q/p$, include the row
\[
 \sum_{j=0}^{p-1}X_{b+jq/p}-p^{k+1}X_{pb\bmod q}=0.
\]
The resulting rational matrix has rank $q-\varphi(q)$, and hence
residual dimension $\varphi(q)-1$. Including every composite-divisor
distribution row does not change the span.
\end{theorem}
\begin{proof}
Temporarily restore $X_0$ and replace $p^{k+1}$ by independent prime
weights $A_p$. Split the grid by reduced denominator $m\mid q$ and
Fourier-transform each stratum by its Dirichlet characters.
For a character of primitive conductor $f$, its block has one vector
$v_{m,\chi}$ at each $f\mid m\mid q$. The complete transformed row
module consists of
\[
 v_{pm,\chi}-\lambda_{p,m,\chi}v_{m,\chi},\qquad
 \lambda_{p,m,\chi}=
 \begin{cases}A_p,&p\mid m,\\ A_p-\chi(p),&p\nmid m.\end{cases}
\]
These edges reduce every vector to a polynomial multiple $E_{m,\chi}$
of $v_{f,\chi}$. Conversely the map $v_{m,\chi}\mapsto E_{m,\chi}$
annihilates all edges and sends $v_{f,\chi}$ to one, so each character
block has exactly one free coordinate. This gives dimension
$\varphi(q)$ before fixing the endpoint. The endpoint is precisely the
principal conductor-one coordinate; fixing it removes one dimension.
Specialize $A_p=p^{k+1}$. Composite rows are generated by the identity
$r_{ab,x}=\sum_{ay=x}r_{b,y}+A_b r_{a,x}$.
\end{proof}

The matrix is now defined independently of the historical source scripts.
This is a formal distribution quotient, not a numerical-independence
claim. The companion contribution \emph{Finite Distribution Modules,
Spectral Jets, and Cyclotomic Trace Identities} proves the polynomial
normal form and its arbitrary-weight specializations, including resonant
weights. For $q>2$, reflection acts by $\chi(-1)$, so fixing the odd
reflection differences leaves $\varphi(q)/2-1$ coordinates. At finite jet
order $N$, the full quotient dimensions are multiplied by $N+1$.
