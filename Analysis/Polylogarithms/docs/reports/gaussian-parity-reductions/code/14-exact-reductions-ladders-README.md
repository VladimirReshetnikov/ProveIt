# Algebraic ladder proof contribution

`../../article/sections/04_ladders.tex` is a self-contained section proving the two cubic and quartic
trilogarithm identities displayed in current manuscript Chapter 3, and giving
the general complementary-power ladder for `rho^a + rho^b = 1`.

The cubic proof includes an exact row certificate using two Kummer substitutions
and one Landen relation; a separate Rogers-pentagon certificate reduces its
dilogarithmic tails. The quartic proof uses only the one-variable Landen law.

These are new local proofs supplied to the repository, not a claim that the
underlying classical functional equations or all their special values are new.

Primary sources to cite:

- Don Zagier, *Special values and functional equations of polylogarithms*,
  appendix to L. Lewin (ed.), *Structural Properties of Polylogarithms*, AMS,
  1991, Section 7, Example 3, equation (7).
  https://people.mpim-bonn.mpg.de/zagier/files/tex/LewinPolylogarithms/fulltext.pdf
- Hiroaki Nakamura and Densuke Shiraishi, *Landen's trilogarithm functional
  equation and l-adic Galois multiple polylogarithms*, arXiv:2210.17182.
  https://arxiv.org/abs/2210.17182

The narrow literature claim is deliberate. The report does not settle any
question of numerical independence, maximal ladder weight, or existence of
all higher golden ladders.
