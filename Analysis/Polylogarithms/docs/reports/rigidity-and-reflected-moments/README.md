# Complementary-Power Rigidity, a Gaussian Euler-Sum Identity, and Reflected Gamma Moments

Research continuation prepared for Vladimir Reshetnikov and the ProveIt project, October 2026.

## Principal proved results

1. **Complete pure-complement classification.** A real base `0 < r < 1` has at most two unordered positive integer pairs with `r^a + r^b = 1`. Two occur exactly for a root of the reciprocal plastic number, with pairs `(d,5d)` and `(2d,3d)`. Equal exponents are included separately.
2. **Signed cyclic equation and degree enumeration.** There are exactly `0`, `3`, `6`, or `12` solutions of `x + y = 1` in the signed cyclic group generated by `r`. An exhaustive search through algebraic degree `D` requires only largest exponent `floor(5D/3)`. An exact counting formula and `N(D) = D^2/2 + O(D log D)` are proved.
3. **Plastic identities.** The existing dilogarithm and trilogarithm formulas receive analytic proofs from the Rogers and Kummer functional equations. Two additional identities without logarithmic terms are proved, including a six-term trilogarithm formula for `4 zeta(3)`.
4. **Gaussian S4.** The manuscript's previously numerical mixed Gaussian reduction is proved by one convergent Möbius duality and an exact rational combination of 911 standard rows. Single-divergence regularization is explicitly justified.
5. **Proportional harmonic depth.** The article supplies a positive, decreasing, convex exponential rate, the prefactor, a first correction, all further fixed orders, and a Gaussian concentration statement.
6. **Reflected gamma moments.** For fixed reflected exponent, it proves meromorphic continuation, exact residues, finite asymptotic expansions, shifted factorial growth, late-coefficient signs and first corrections, and an explicit growing-order remainder bound.
7. **Finite reflection and Appell identities.** An exact finite identity couples reflected residues. A canonical formal version of Conjecture 5.5 in the inspected 2010 Amdeberhan et al. author preprint is proved, with the necessary distinction between formal coefficients and numerical uniqueness.

These are proofs in the stated settings. No period independence, universal maximal ladder weight, formal proof-assistant certification, or historical priority over all equivalent identities is asserted. The classical inputs and the earlier ProveIt results are credited in the article.

## Verify the Gaussian proof

Python 3.10 or newer is sufficient; no third-party packages are required for this command:

```bash
python code/verify_s4.py results/S4_certificate.json
```

Expected result:

```json
{
  "arithmetic": "exact rational",
  "duality_relations": 1,
  "relation_counts": {
    "ds": 713,
    "lift": 17,
    "regularized_ds": 181
  },
  "residual_terms": 0,
  "standard_relations": 911,
  "verified": true
}
```

Run Python normally, without `-O`: several verifiers deliberately use assertions as failed-check guards. The verifier regenerates the word relations, target, and duality seed independently of their stored expansions. It does not evaluate polylogarithms, run PSLQ, use modular rank computations, or load binary caches.

An optional full reconstruction is available:

```bash
python code/discover_s4.py results/S4_certificate_rebuilt.json
python code/verify_s4.py results/S4_certificate_rebuilt.json
```

This exact fraction-free discovery calculation is slower than verification and is unnecessary for checking the supplied proof. Its rank is a rank of the specified formal relation matrix, not a dimension theorem for numerical periods.

## Run all supplied checks

The tested environment used Python 3.12.14, SymPy 1.14.0, and mpmath 1.3.0. Install the small numerical/symbolic dependency set, then run the orchestrator:

```bash
python -m pip install -r requirements.txt
python code/run_checks.py
```

Individual commands are:

```bash
python code/certify_ladders.py --bound 30 --degree-limit 12 --out results
python code/verify_reflected_moments.py
python code/check_s4_numeric.py
python code/verify_saddle.py
```

The result files record 2,008 exact ladder/counting checks plus four numerical ladder audits; 119 exact reflected-moment checks; 24 harmonic saddle quadratures; 16 late reflected coefficients; nine moment/bound cases; and three independent reflected quadrature comparisons. Numerical diagnostics are ordinary high-precision computations, not interval certificates. The infinite families and analytic bounds are proved in the article.

To regenerate the figure, install the optional plotting requirements and run:

```bash
python -m pip install -r requirements-figures.txt
python code/verify_saddle.py --figure
```

## Build the article

A TeX Live installation containing the standard packages in the preamble, `pdflatex`, and `latexmk` is sufficient. The supplied PDF was built with pdfTeX from TeX Live 2023.

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error polylogarithms_rigidity.tex
```

Alternatively, `make pdf` builds into `build/` and copies the resulting PDF to the package root. `make checks` runs the verifiers. `make clean` removes only build intermediates; it preserves the delivered PDF and proof artifacts.

## Proposed repository integration

The confirmed normalization error is in the paragraph after `bloch:eq:goldenP3` and `bloch:eq:sgP3`. Under the manuscript's definition, `P_(2j)(x)=0` for real `0<x<1`, so its even-weight ordinary golden formulas cannot become nonzero zeta multiples under that same modification.

`integration/even_weight_normalization.patch` changes only that paragraph. It was checked with `git apply --check` against the recorded baseline. Review and apply it from the repository root after copying or locating the patch. Mathematical status upgrades for the S4 and plastic identities are documented separately; their proofs should be integrated or referenced together with the upgraded statements.

The article does not prove the adjacent plastic tetralogarithm, general higher-weight Gaussian mixed reductions, or period independence. These remain explicit research questions. Earlier results already present in incoming ProveIt packages are treated as antecedents, not claimed again as new results.
