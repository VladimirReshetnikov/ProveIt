# Harmonic Euler Sums and Lerch Zero Geometry

**Research continuation for ProveIt — 10 October 2026**

The main deliverables are `article.pdf` and the fully expanded `article.tex`.
The modular sources are also supplied for integration. The paper contains
complete proofs, new exact identities, an explicit quantitative conjecture,
proposed manuscript corrections, and fourteen further research directions.

## Main results

1. The harmonic-order interpolation
   \(S(s)=\sum_{n\ge0}(-1)^nH_n/(2n+1)^s\) is entire.
   Its complete real zero set consists of one simple zero in every
   \((-2m-1,-2m)\), \(m\ge1\), with no other real zeros.
   The displacements from the left endpoints strictly decrease to zero,
   and the consecutive gaps exceed two. The paper gives full asymptotics,
   exact negative-integer values, and the zero-free half-plane \(\Re s\ge3\).
2. The smallest Lerch zero on \(k=n-1\), initially at \(a=1\), has velocity
   coefficients generated by
   \(\sum v_n(A)t^n=\log A-u_A(t)\), \(e^{u_A}=A+tu_A\).
   For every lattice endpoint \(A=1+h>1\), infinitely many initial
   velocities are positive and infinitely many are negative.
3. The best constant exterior differential barrier is determined by the
   unique positive root of \(r^3+nr^2-nr-n=0\).
   The optimal coefficient and least uniform summed cutoff are proved,
   including the exact equality set and the nonattainment of the strict
   pointwise infimum. Convergent and asymptotic coefficient formulas follow.
4. A precisely stated accessible-singularity conjecture for \(A=2\)
   predicts an oscillatory two-term asymptotic for the diagonal velocities.
   The local expansion and the conditional transfer theorem are proved.
   Sheet accessibility and dominance remain conjectural.

The inspected baseline already proves the mixed \(S_4\) relation.
The positive-weight \(S_6\) reduction remains open. The complete real-zero
classification of the order interpolation does not imply that arithmetic
reduction.

## Build the article

The expanded source needs the `figures/` directory beside it. A normal
TeX Live installation with pdfLaTeX, latexmk, AMS packages, Latin Modern,
mathrsfs, microtype, graphicx, enumitem, and hyperref suffices.

From the package root:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error article.tex
```

After changing modular sources, regenerate the expanded file first:

```bash
python3 code/assemble_article.py
latexmk -pdf -interaction=nonstopmode -halt-on-error article.tex
```

The assembly script does not change the mathematical content; it expands
the section inputs and preserves their order. Edit either the modular
sources and regenerate, or edit the expanded TeX directly and do not
regenerate over those edits.

## Reproduce the checks

The delivered environment used Python 3.12.14. Install the optional
symbolic, numerical, and plotting dependencies with:

```bash
python3 -m pip install -r requirements.txt
```

The two standard-library checks can be run independently:

```bash
python3 code/verify_diagonal.py
python3 code/verify_gaussian_order.py --output data/gaussian_exact.json
```

The default replay runs all finite certificate engines and the diagonal
quantitative experiment:

```bash
python3 code/run_checks.py
```

To repeat the independent harmonic quadratures and all sample zeros as
well, use the following command. It may take several minutes:

```bash
python3 code/run_checks.py --numeric
```

The equivalent direct harmonic command is:

```bash
python3 code/verify_gaussian_order.py --numeric --full --dps 45 \
  --output data/gaussian_order_verification.json
```

Adding `--resume` to the direct command reuses completed numerical records
at the same precision and computes missing roots. Exact-only mode uses a
different output file and cannot erase the full diagnostic record.

To regenerate the publication figures from the supplied data:

```bash
python3 code/plot_gaussian_order.py
python3 code/plot_barrier.py
python3 code/plot_diagonal.py
```

Or run `python3 code/run_checks.py --figures` to replay finite checks and
regenerate all figures together. Plot scripts place figure files in
`figures/`; newly computed plot data go in `data/`.

## Proof and computation status

- The entire continuation, complete real-zero classification, infinitely
  many signs, optimality, and asymptotic theorems have analytic proofs.
- Negative-integer coefficient identities are checked exactly through
  order thirty by independent rational recurrences.
- Diagonal polynomial identities are checked over \(\mathbb Q[L]\)
  through degree forty. Actual velocity signs are enclosed exactly for
  indices 2–40 and 50–200.
- Barrier samples at \(n=2,3,4,5,10,25,100\) use exact rational interval
  arithmetic and a proved exponential remainder.
- Harmonic zero decimals, Fourier/Mellin residuals, plot curves, critical
  singularity parameters, and asymptotic-model errors are **numerical
  diagnostics**, not certified enclosures or proofs of continuation.
- A finite coefficient match does not prove the dominance conjecture.
  An asymptotic correction need not improve every small-index value.

The package is prepared for later repository integration and does not
perform any remote repository modification.
