\paragraph{Periodic finite-part extension.}
The pointwise Stieltjes derivative tower does not by itself justify
differentiation inside a periodic finite-part product.
With the canonical right-endpoint normalization of
Definition~\ref{shj:defJ}, the periodic Hurwitz residue at spectral
order one is \(1-\delta_0\).
The resulting differentiation rule is
\(D^rG_m=\operatorname{FP}_{\mathrm{per}}\gamma_m^{(r)}
-h_{r,m}\delta_0^{(r)}\), with \(h_{r,m}\) as in
Theorem~\ref{shj:contactthm}.
In particular, the shifted digamma--trigamma integral contains the
additional term \(+\psi'(1-a)\) in equation~\eqref{shj:01}.
This is a distributional extension warning, not a change to the
pointwise derivative theorem.
