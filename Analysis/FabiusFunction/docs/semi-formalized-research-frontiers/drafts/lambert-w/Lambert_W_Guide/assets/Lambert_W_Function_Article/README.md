# The Lambert W Function — article package

This package contains the complete source and rendered version of the article
**“The Lambert W Function: A Real-Variable Guide to Its Branches, Identities,
Series, Asymptotics, Bounds, Approximations, and Computation.”**

## Files

- `Lambert_W_Function_Article.tex` — complete LaTeX source.
- `Lambert_W_Function_Article.pdf` — rendered 55-page article.
- `numerical_experiments.py` — fully commented, reproducible numerical experiments.
- `numerical_values.txt` — high-precision reference values generated by the script.
- `figures/*.pdf` — eight vector figures used by the LaTeX source.

The article includes the two real branches `W_0` and `W_{-1}`, exact branch-pair
identities, differential and integral calculus, Taylor and Puiseux series,
complete logarithmic asymptotic expansions, rigorous bounds, Padé and continued-
fraction approximations, integral representations, numerical algorithms,
applications, exercises with full solutions, coefficient tables, and a compact
formula sheet. Section 19 explains how the sources in the supplied user archive
were incorporated.

## Rebuild the PDF

A reasonably complete TeX Live installation with `latexmk` is sufficient:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error Lambert_W_Function_Article.tex
```

The figures and `numerical_values.txt` are already included, so rebuilding the
article does not require Python.

## Reproduce the numerical material

The Python script requires Python 3 and these packages:

- `mpmath`
- `numpy`
- `matplotlib`

Run:

```bash
python3 numerical_experiments.py --output-dir figures
```

It regenerates all eight vector-PDF figures and overwrites
`numerical_values.txt` with 80-decimal-digit reference calculations. The script
uses no network access. It calls `mpmath.lambertw` only to obtain reference
values; every approximation plotted in the article is implemented separately.
