BUILDING
========

The distributed PDF and all generated inputs are already present.  To compile
without rerunning the numerical experiments, use:

    latexmk -pdf -interaction=nonstopmode -halt-on-error lambert_w_monograph.tex

To regenerate the numerical material first, install the Python dependencies and
run:

    python3 -m pip install -r requirements.txt
    python3 lambert_w_experiments.py
    latexmk -pdf -interaction=nonstopmode -halt-on-error lambert_w_monograph.tex

A reasonably complete TeX Live installation is recommended.  The document uses
standard packages including amsmath, amsthm, mathtools, booktabs, longtable,
graphicx, geometry, hyperref, and cleveref.

NOTES
=====

* The manuscript treats both real branches W_0 and W_{-1} throughout whenever
  the mathematics permits, with complete proofs of the principal results.
* The numerical program uses no random numbers and evaluates reference values
  with mpmath at 50 decimal digits.
* The supplied Lambert-W.zip source archive was consulted and is documented in
  Appendix B of the monograph.  Those third-party source files are not
  redistributed in this deliverable.
