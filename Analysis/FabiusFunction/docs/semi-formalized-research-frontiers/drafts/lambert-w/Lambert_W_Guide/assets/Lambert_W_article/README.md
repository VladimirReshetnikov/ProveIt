# The Lambert W Function

This package contains the complete source and rendered version of the article
**The Lambert W Function: Real Branches, Series, Asymptotics, Bounds,
Continued Fractions, Numerical Evaluation, and Applications**.

## Contents

- `lambert_w_article.pdf` — the 50-page rendered article.
- `lambert_w_article.tex` — complete LaTeX source.
- `lambert_w_experiments.py` — documented, reproducible numerical experiments.
- `numerical_results.tex` — table generated by the Python script and included by the article.
- `data/numerical_results.csv` — machine-readable sampled error results.
- `figures/*.pdf` — seven generated vector figures.
- `requirements.txt` — Python dependencies for regenerating the computational supplement.
- The former package checksum ledger is retired; its historical bytes remain
  recoverable from Git.

The article contains 53 numbered theorem-like statements, including proofs of
the real-branch geometry, differential and integral formulas, Lagrange
inversion applications, the common Puiseux expansion at `-1/e`, unified
asymptotics for `W_0` and `W_{-1}`, rigorous real bounds, continued fractions,
root-finding methods, complex-branch asymptotics, and application formulas.

## Reproducing the figures and numerical table

With Python 3.10 or newer:

```bash
python -m pip install -r requirements.txt
python lambert_w_experiments.py --output-dir .
```

The script uses 80-decimal-digit `mpmath` reference values. Its numerical
maxima are sampled experimental values on the stated grids, not claimed
uniform error certificates.

## Rebuilding the PDF

A current TeX Live or MiKTeX installation with `latexmk` is recommended:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error lambert_w_article.tex
```

The LaTeX source expects the generated files in `figures/`, `data/`, and the
package root exactly as arranged here.
