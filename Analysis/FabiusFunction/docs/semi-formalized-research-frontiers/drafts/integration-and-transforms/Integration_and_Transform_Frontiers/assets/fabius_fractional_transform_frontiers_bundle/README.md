## Principal new operator systems developed in the report

1. **Quantile-Volterra transmutation.** Arbitrary-order Riemann-Liouville integrals of \(\phi(F^{-1})\) are converted to ordinary integrals with kernel \((u-F(x))^\beta\).  The power family is continued entirely in its exponent, covering positive, negative, and complex powers and parameter derivatives such as logarithmic powers.

2. **All-order Caputo calculus for the inverse Fabius function.**  Orders in \((0,1)\) admit a particularly simple kernel.  Higher noninteger orders are expressed through the intrinsic differential operator
   \[
   \mathcal L_F=\frac{1}{F'(x)}\frac{d}{dx},
   \]
   which packages the inverse-function Bell-polynomial structure.  Endpoint asymptotics and an exact \(L^r\)-integrability threshold are derived.

3. **Complex-order generalized Stieltjes resolvents.**  The family
   \[
   \mathcal S_\lambda(z)=\int_0^1(z-x)^{-\lambda}\,dF(x)
   \]
   satisfies coupled dyadic, differential, moment-series, order-shift, Laplace, and boundary-jump identities.

4. **Weyl and Riesz fractional calculus of `up`.**  Fractional derivatives obey an exact order-lowering dilation law.  Their loss of compact support is quantified by convergent algebraic-tail expansions whose coefficients are exact rational moments of `up`.

5. **Entire-order difference hierarchy.**  For \(D=X_2-X_1\),
   \[
   \mathcal K_\beta(a)=\frac{\mathbb E(D-a)_+^\beta}{\Gamma(\beta+1)}
   \]
   is continued in order, linking stop-loss integrals, tail probabilities, autocorrelation, and all derivatives of the difference density.  It satisfies a triangular dyadic refinement equation, inverse-Fabius double-integral formulas, and a fractional Fourier-energy identity.

The report separates proved identities, conditional endpoint expansions, conjectures, and open problems.  “New” is used only relative to the pinned repository snapshot described below; no claim of exhaustive global priority is made.

## Reproducing the numerical experiment

Requirements:

- Python 3.10 or later;
- NumPy;
- SciPy;
- mpmath;
- Matplotlib.

From this directory, run the full experiment:

```bash
python numerical_experiments.py
```

The default grid has \(2^{17}\) points.  It takes only a few seconds on a current desktop and regenerates all tables and figures.  A faster smoke test is available:

```bash
python numerical_experiments.py --quick --output quick-results
```

The script reconstructs `up` independently from the infinite sinc product by inverse FFT, derives \(F\) and \(F^{-1}\), and then evaluates both sides of the new identities by independent numerical routes.  Typical residuals in the bundled full run are about \(10^{-10}\)-\(10^{-13}\) for the transmutation identities, \(10^{-15}\) for the resolvent recurrences, \(10^{-8}\)-\(10^{-11}\) for singular nonlocal tails, and about \(4\times10^{-9}\) for the Fourier-energy quadrature.
