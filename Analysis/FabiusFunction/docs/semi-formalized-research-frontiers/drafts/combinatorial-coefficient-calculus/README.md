# combinatorial-coefficient-calculus

Quick-gate archival group for six combinatorial coefficient-calculus and
inversion manuscripts received on 2026-09-01.  Each arrival supplied one flat
LaTeX/PDF pair.  The ZIP CRCs, member paths, and member types were checked
before extraction; at intake, the filed source and PDF bytes were identical to
their ZIP members.  The sources already used LF line endings, so intake made no
payload normalization.  A later repository notation migration revised the six
sources only; the retained arrival PDFs were not rebuilt.  Every package has a
two-row `SHA256SUMS` covering exactly its current source and historical PDF as
distinct payloads.

The similar titles and abstracts indicate likely overlap, but this checkpoint
does **not** compare claims, select a canonical manuscript, deduplicate prose or
proofs, rewrite LaTeX, rebuild PDFs, or infer Lean verification.  Those tasks
remain explicitly deferred until this archival intake is published on
`origin/main`.
