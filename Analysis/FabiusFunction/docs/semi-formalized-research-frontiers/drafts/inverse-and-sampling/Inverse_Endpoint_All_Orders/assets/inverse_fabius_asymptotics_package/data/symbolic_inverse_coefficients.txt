Symbolic W-resummed inverse coefficients
========================================

Notation: P0=Psi(theta), P1=Psi'(theta), ...; A1_0=A_1(theta), A1_1=A_1'(theta), etc.

d_1 = P0/L

d_2 = (2*A1_0*L - L*beta + 2*P0*P1)/(2*L**2)

d_3 = -(4*A1_0*L**2*beta - 4*A1_0*L*P1 - 4*A1_1*L*P0 - 4*A2_0*L**2 - L**2*beta**2 + 2*L*P0**2 + 2*L*P0 + 2*L*P1*beta - 2*P0**2*P2 - 4*P0*P1**2)/(4*L**3)

h_1 = -P0

h_2 = -(2*A1_0*L - L*beta + 2*P0*P1 - 2*P0)/(2*L)

h_3 = (4*A1_0*L**2*beta - 4*A1_0*L*P1 + 4*A1_0*L - 4*A1_1*L*P0 - 4*A2_0*L**2 - L**2*beta**2 + 2*L*P0**2 - 4*L*P0*beta + 2*L*P0 + 2*L*P1*beta - 2*L*beta - 2*P0**2*P2 - 4*P0*P1**2 + 4*P0*P1)/(4*L**2)

g_1 = -P0

g_2 = -(2*A1_0*L - L*P0**2 - L*beta + 2*P0*P1 - 2*P0)/(2*L)

g_3 = (12*A1_0*L**2*P0 + 12*A1_0*L**2*beta - 12*A1_0*L*P1 + 12*A1_0*L - 12*A1_1*L*P0 - 12*A2_0*L**2 - 2*L**2*P0**3 - 6*L**2*P0*beta - 3*L**2*beta**2 + 12*L*P0**2*P1 - 6*L*P0**2 - 12*L*P0*beta + 6*L*P0 + 6*L*P1*beta - 6*L*beta - 6*P0**2*P2 - 12*P0*P1**2 + 12*P0*P1)/(12*L**2)
