# Complete Superconvergence Phases and Optimal Phase Filters for Rvachev Quadrature

This package contains a 20-page research article, its LaTeX source, and an
independent checking program.

## Main results

* For every positive integer mesh M, the only phases exact through degree
  v_2(M)+1 are 0 and 1/2 when v_2(M) is even, and 1/4 and 3/4 when it is odd.
  A uniform relative first-harmonic bound also gives simple zeros and phase
  conditioning estimates.
* At a reduced rational mesh a/b, a mass-one finite complex phase measure
  gives translation-uniform exactness through degree r exactly when it is
  invariant under translation by 1/[b*2^max(0,r-v_2(a))]. At an irrational
  mesh, uniform constant exactness forces normalized Haar measure.
* This gives sharp bounds and equality cases for finite phase counts,
  a finite Fourier-moment recognition theorem, and polynomial synthesis
  consequences.

The introduction and Section 10 explain the relationship to the inspected
ProveIt modules. These are conventional analytic proofs, not new Lean/Rocq
formalizations. Novelty relative to the entire literature is not certified.
The separate fixed-phase next-degree maximality question is not claimed solved.

## Contents

- `article.tex`: complete source, with an inline bibliography.
- `article.pdf`: compiled article.
- `figures/normalized_defect.pdf` and `.png`: the illustrative plot.
- `reproducibility/verify.py`: standalone exact and numerical checks.
- `reproducibility/requirements.txt`: versions used for the optional checks.
- `validation/results.json`: machine-readable recorded results.
- `validation/run.log`: saved program output.
- `validation/proof_audit.md`: proof and verification boundaries.
- `validation/source_manifest.json`: pinned source references.
- `validation/pdf_quality.json`: PDF structure and layout check summary.

## Build the PDF

Run these commands from the package root with a TeX Live installation containing
New TX fonts and the packages listed in the preamble:

```sh
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
pdflatex -interaction=nonstopmode -halt-on-error article.tex
```

No bibliography processor is needed. The figure PDF is included, so the article
can be rebuilt without running Python. No font files are distributed.

## Reproduce the checks

Python 3.10 or later is recommended. A virtual environment keeps these optional
dependencies separate from other projects:

```sh
python -m venv .venv
# Activate .venv with the command appropriate to your operating system.
python -m pip install -r reproducibility/requirements.txt
python reproducibility/verify.py --plot
```

Without `--plot`, the program does not require NumPy or Matplotlib. It always
requires mpmath. Its exact arithmetic uses Python's standard Fraction type.
It writes `validation/results.json` and prints the same JSON to standard output.
The saved log can be regenerated by redirecting standard output.

The recorded run passed 2,144 exact checks and 1,024 numerical product/sign
checks. The numerical results use finite product and Fourier-series truncations;
they are not directed-rounding certificates and are not proofs of the infinite
statements. The article supplies the analytic proofs separately.
