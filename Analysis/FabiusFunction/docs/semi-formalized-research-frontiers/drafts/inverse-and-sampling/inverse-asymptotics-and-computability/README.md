# Inverse asymptotics and computability

This subgroup collects complementary studies of the inverse Fabius function,
from dyadic germs and endpoint expansions to effective continuity and
certified computation:

- [`Inverse_and_Sampling_Frontiers/`](Inverse_and_Sampling_Frontiers/)
- [`Inverse_Endpoint_All_Orders/`](Inverse_Endpoint_All_Orders/)
- [`Inverse_Fabius_Computability_Report/`](Inverse_Fabius_Computability_Report/)

The first two volumes share the inverse-germ and endpoint problem; the
computability report uses the same inverse structure to obtain quantitative
moduli and effective algorithms.
