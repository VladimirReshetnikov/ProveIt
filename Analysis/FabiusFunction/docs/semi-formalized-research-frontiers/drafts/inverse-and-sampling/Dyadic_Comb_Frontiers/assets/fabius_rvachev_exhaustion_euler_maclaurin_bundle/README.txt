Reproduce the calculations
--------------------------
python verify_fabius_rvachev_quadrature.py --max-degree 7 --output-dir .

All checks use fractions.Fraction. A PASS means exact rational equality, not
agreement within a floating-point tolerance.

Compile the report
------------------
pdflatex fabius_rvachev_exhaustion_euler_maclaurin.tex
pdflatex fabius_rvachev_exhaustion_euler_maclaurin.tex
