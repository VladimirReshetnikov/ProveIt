# Dyadic-comb Fabius/Rvachev sums

This archive contains the source and rendered form of the report
**“Dyadic-Comb Moments of the Fabius and Rvachev Functions.”**

## Principal files

- `fabius-dyadic-comb-sums.tex` — LaTeX source.
- `fabius-dyadic-comb-sums.pdf` — compiled report.
- `experiments.py` — exact rational and high-precision experiments, with comments.
- `generated_results.tex` — exact tables generated by the script.
- `fractional_convergence.png` — optional high-precision convergence figure.
- `corpus_meta.tex`, `corpus_inventory.tex`, `corpus_audit.txt` — reproducible recursive audit of the requested repository corpus.
- `VALIDATION.txt`, `qpdf-check.txt`, `layout-warnings.txt` — build and PDF checks.

## Regeneration

With a checkout of `ProveIt` available:

```bash
python experiments.py \
  --repo-docs /path/to/ProveIt/Analysis/FabiusFunction/docs \
  --out .
pdflatex -interaction=nonstopmode -halt-on-error fabius-dyadic-comb-sums.tex
pdflatex -interaction=nonstopmode -halt-on-error fabius-dyadic-comb-sums.tex
```

The integer-power calculations use Python's exact `Fraction` arithmetic. The
fractional-power table uses `mpmath`; the plot uses `matplotlib` when present.

> **Editorial note (2026-08-28):** the report source (.tex) and compiled PDF listed above were removed from this directory after their content was merged into the volume `Dyadic_Comb_Frontiers.tex`; their SHA-256 hashes remain in the volume provenance section, and git history archives the files. This directory keeps only figures, data, and scripts.
