# Interpolation on a Geometric Comb

This archive contains the report

**Interpolation on a Geometric Comb: Lagrange and Newton Formulas, Jackson Calculus, Modal Filters, Geometric B-Splines, and Fabius--Rvachev Connections**

prepared on 30 August 2026.

## Contents

- `geometric_comb_interpolation_report.tex` - complete LaTeX source.
- `geometric_comb_interpolation_report.pdf` - compiled 34-page report.
- `geometric_comb_experiments.py` - commented, reproducible numerical experiments using exact rational and multiprecision arithmetic.
- `moment_checks.csv` - Gaussian-comb moment and recursion checks.
- `stability_growth.csv` - finite- and infinite-order stability factors.
- `regular_variation.csv` - convergence data for the regular-variation boundary theorem.
- `fabius_boundary.csv` - exact rational dyadic Fabius boundary filters.
- `stability_growth.png`, `regular_variation_convergence.png`, and `fabius_boundary_ratio.png` - figures generated by the Python program and included in the report.

## Reproducing the experiments

The program requires Python 3 with `mpmath` and `matplotlib`:

```bash
python geometric_comb_experiments.py
```

It writes all CSV tables and PNG figures into the directory containing the script. The calculations use exact `fractions.Fraction` arithmetic where possible and 140-decimal-digit `mpmath` arithmetic elsewhere.

## Compiling the report

A conventional LaTeX installation with `pdflatex` and the packages named in the preamble is sufficient. For example:

```bash
latexmk -pdf geometric_comb_interpolation_report.tex
```
