# Fabius--Rvachev frontier report package

Main files:

- `Fabius_Rvachev_Frontier_Report.tex` — complete LaTeX source.
- `Fabius_Rvachev_Frontier_Report.pdf` — rendered report.
- `numerical_experiments.py` — commented arbitrary-precision verification and
  figure-generation code.
- `numerical_results.tex` — tables generated by the numerical program.
- `repository_audit.md` — recursive inventory, hashes, extracted headings, and
  phrase-cluster overlap checks for the repository's TeX corpus.
- `numerical_summary.txt` — principal numerical constants, when generation
  succeeded.
- `pdf_validation.txt` — PDF metadata/extraction/rasterization checks.
- `compile_transcript.txt` — LaTeX build transcript.

Rebuild from this directory:

```bash
python numerical_experiments.py --output-dir .
pdflatex -interaction=nonstopmode -halt-on-error Fabius_Rvachev_Frontier_Report.tex
pdflatex -interaction=nonstopmode -halt-on-error Fabius_Rvachev_Frontier_Report.tex
```

The numerical experiments are consistency checks only.  Every result labeled
as a theorem in the report has a symbolic proof.
