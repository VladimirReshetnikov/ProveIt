# Jacobi-Digit Fabius--Rvachev Frontier Report

This archive accompanies the report

**Jacobi-Digit Deformations of the Fabius--Rvachev Law: Geometric Bessel products, spherical random flights, Rayleigh cumulants, higher-order refinement, and inverse endpoint asymptotics**.

## Main files

- `jacobi_digit_frontier_report.tex` -- complete LaTeX source.
- `jacobi_digit_frontier_report.pdf` -- rendered report.
- `experiments.py` -- fully reproducible numerical and symbolic experiments.
- `requirements.txt` -- Python dependencies.
- `figures/` -- PDF and PNG figures generated by the script.
- `data/` -- CSV and text outputs used for validation and conjecture discovery.
- `numerical_summary.txt` -- parameters and diagnostic summary from the final run.
- `corpus_audit.txt` -- pinned repository-comparison method and novelty boundary.
- The former package checksum ledger is retired and recoverable from Git
  history.

## Reproduce the numerical layer

```bash
python -m pip install -r requirements.txt
python experiments.py --output-root .
```

The default random seed is `20260830`. Monte Carlo is used only for density visualization and an independent moment check; theorem-level formulas use exact recurrences or high-precision determinants.

## Compile the report

From the archive root:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error jacobi_digit_frontier_report.tex
```

The report's repository comparison is pinned to ProveIt commit
`fdfb6369519e00a2213241ddadf03f7556172134` (30 August 2026). Novelty statements are relative to that repository snapshot, not claims of global historical priority.
