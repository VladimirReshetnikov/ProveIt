# Zero-Bias Towers and Spectral Peeling in the Fabius--Rvachev System

This package accompanies the frontier research report prepared from the
`Analysis/FabiusFunction/docs` corpus in Vladimir Reshetnikov's `ProveIt`
repository.  The repository-relative novelty audit is pinned to commit

`40fdea4cc0a728189f357389e3f114a2cb00e561` (30 August 2026).

The report develops an exact zero-bias hierarchy for the centered Rvachev law
and its geometric-uniform generalizations.  Its main results include:

- a random-index, q^2-geometric digit-replacement coupling for one zero-bias step;
- a closed moment formula and a power-biased-radius times spherical-coordinate
  factorization for every iterated zero-bias level;
- a probability interpretation of every normalized derivative of the
  Laguerre--Polya entire transform H;
- exact spectral peeling at the arithmetic Fourier lattice, including the
  first released value and its Thue--Morse sign;
- a complete occupancy law for repeated coordinate hits and a collision-free
  q-Pochhammer probability;
- universal Gaussianization for symmetric compactly supported laws;
- phase-modulated mod-Gamma endpoint asymptotics, high-moment corrections, and
  the sharp leading Wasserstein scale for the Rvachev tower;
- conjectures and a staged Lean formalization plan.

“New” in the report means absent from the inspected repository snapshot and
derived in the report.  It is not intended as a claim of worldwide priority.
General zero-bias transformations are classical.

- `data/` — exact and floating-point CSV tables generated by the script.
- `SHA256SUMS` — checksums for every packaged file except the checksum file

## Reproducing the numerical results

Python 3.11 or later is recommended.

```bash
python -m pip install -r requirements.txt
python zero_bias_tower_experiments.py --max-level 2000 --samples 30000
```

The default random seed is `20260830`.  The script computes the even moments
through `mu_4000`, rewrites all CSV files, and regenerates all figures.  It does
not download external data.

A quicker smoke test is:

```bash
python zero_bias_tower_experiments.py --max-level 200 --samples 3000
```

## Rebuilding the PDF

A reasonably complete TeX Live installation is sufficient.  From the package
root:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error \
  Zero_Bias_Towers_and_Spectral_Peeling.tex
```

The source uses the Libertinus package when available and otherwise falls back
to Latin Modern.
