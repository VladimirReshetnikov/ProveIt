This archive contains the LaTeX source, compiled PDF, exact/numerical experiments, generated tables and figures, and the recursive corpus-audit manifest for the accompanying research report.

## Main contents

The report develops, among other results:

- exact-rational Faber--Schauder expansions of the bounded Fabius function;
- exact-rational piecewise-affine inverse-Fabius approximants;
- rational Haar expansions of the density and a Haar--sinc-squared expansion of the Fourier image;
- a positive rational series and an all-orders dyadic tail expansion for
  `A_2 = integral_0^1 F(x)^2 dx`;
- independent triangular binomial layers and a triangular cosine-product factorization;
- odd-lattice Paley--Wiener reconstruction and zero-jet sample identities;
- Chebyshev/Gegenbauer coefficients as Bessel transforms of the sinc product;
- exact-rational Bernstein limits and finite Kummer-transform sums;
- weighted-cube sublevel-volume and hyperplane-section limits;
- conjectures, open problems, and a Lean formalization roadmap.

The high-precision decimal quoted for `A_2` is stable under changes of dyadic level and acceleration order, but it is not presented as a rigorously certified 60-digit interval: the bundled program does not compute explicit constants for the finite-order asymptotic remainder.

## Reproducing the numerical experiment

The bundled run was performed with Python 3.13.5 and the package versions recorded in `requirements.txt`.  A fresh virtual environment can be prepared with:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run the experiment from the archive root:

```bash
python fabius_multiresolution_experiments.py \
    --max-exact-level 16 --precision 90
```

The program uses no network access.  It regenerates:

```text
numerical_results.txt
numerical_results.json
generated_tables.tex
figures/faber_approximants.png
figures/energy_convergence.png
figures/odd_sampling_convergence.png
figures/triangular_distribution.png
```

The exact layer uses Python's `fractions.Fraction`; the floating-point layer uses `mpmath`, NumPy, SciPy, and Matplotlib.  At level 16, the program evaluates 65,537 exact dyadic Fabius values and performs the triangular-polynomial log-concavity checks through degree 65,519.

## Rebuilding the PDF

A reasonably complete TeX Live installation with `latexmk`, Libertinus, `amsmath`, `mathtools`, `booktabs`, `longtable`, `hyperref`, and `cleveref` is sufficient.  Run:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error \
    Fabius_Rvachev_Multiresolution_Representations.tex
```

The source falls back to Latin Modern if the Libertinus package is unavailable, but the bundled PDF was built with Libertinus.
