# One-scale Legendre--Rvachev closure

This archive accompanies the report **A One-Scale Legendre--Rvachev Closure on [-1,1]**.

## Contents

- `legendre_rvachev_closed_loop.tex` -- LaTeX source.
- `legendre_rvachev_closed_loop.pdf` -- rendered report.
- `legendre_rvachev_experiments.py` -- exact symbolic and numerical experiments.
- `data/` -- exact rational coefficient tables and verification logs.
- `generated/` -- exact LaTeX fragments generated by the script.
- `figures/` -- diagnostic figures generated by the script.
- `requirements.txt` -- Python dependencies.
- `SHA256SUMS` -- integrity hashes for the archive contents.

## Reproduce the computations

```bash
python -m pip install -r requirements.txt
python legendre_rvachev_experiments.py
```

The script uses exact SymPy rational arithmetic for all identities. Floating point is used only for condition estimates and diagnostic plots. The finite-convolution approximation of the up-function is not part of any proof.

## Compile the report

From this directory, run:

```bash
pdflatex -interaction=nonstopmode -halt-on-error legendre_rvachev_closed_loop.tex
pdflatex -interaction=nonstopmode -halt-on-error legendre_rvachev_closed_loop.tex
```

A TeX distribution with `amsmath`, `amsthm`, `booktabs`, `cleveref`, `graphicx`, `hyperref`, `listings`, and the standard font packages is sufficient.
