Method used for this report:

1. The current public GitHub tree and the current raw thematic consolidation
   Exponents_and_q_Series_Frontiers.tex were inspected on 2026-08-30.
2. The current semi-formalized README and draft layout were used to account for
   the 2026-08-28 consolidation of previously separate reports.
3. A preserved complete recursive ledger of 57 TeX paths at commit
   24da985eba70e46d862acdaddd476793a428213e (inspection date 2026-08-27) was
   used to retain coverage of historical and archived paths.  That ledger is
   included as corpus_inventory_2026-08-27.txt.
4. Prior generated reports in the user's file library were phrase-searched for
   Stein-Koopman, spectral determinant, fractional transform, inverse Lambert,
   geometric-comb, Appell, Bell, Bernoulli, and root-of-unity themes.
5. The novelty boundary was set by the current consolidated source, not by the
   older path count.  In particular, the current source explicitly leaves a
   generic natural-boundary conjecture and root-of-unity renormalization
   problem open.  This report proves an explicit fixed-frequency natural-
   boundary theorem for the scalar sinc transform and constructs its radial
   cyclotomic blow-ups; it does not claim to solve the repository's full
   two-nome finite-law problem.

The label "new" in the report means apparently new relative to this audited
repository corpus.  It is not a claim of worldwide priority.
