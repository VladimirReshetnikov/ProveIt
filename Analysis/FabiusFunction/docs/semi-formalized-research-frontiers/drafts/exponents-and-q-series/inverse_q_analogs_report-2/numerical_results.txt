  n=2: q(x)=x
  n=3: q(x)=3*a**2*x**5 + 21*a*x**5 - 5*a*x**4 + a*x**3 + 14*x**5 - 5*x**4 + 2*x**3 - x**2 + x
  n=4: q(x)=3*a**2*x**5 + 10*a*x**5 - 4*a*x**4 + a*x**3 - 4*x**5 + x**3 - x**2 + x
  n=5: q(x)=3*a**2*x**5 + 11*a*x**5 - 4*a*x**4 + a*x**3 + 2*x**5 - x**4 + x**3 - x**2 + x
  n=6: q(x)=3*a**2*x**5 + 11*a*x**5 - 4*a*x**4 + a*x**3 + x**5 - x**4 + x**3 - x**2 + x
  n=8: q(x)=3*a**2*x**5 + 11*a*x**5 - 4*a*x**4 + a*x**3 + x**5 - x**4 + x**3 - x**2 + x
  Stable formula verified exactly for n>=6 through x^5.
