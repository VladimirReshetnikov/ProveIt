This retained asset directory records the expanded English report requested from the
attached Russian `rvachev` chapter and the two attached English report drafts.  The report
itself has been absorbed into `Exponents_and_q_Series_Frontiers.tex`; only its unique
figures, data, scripts, audit, and provenance records remain here.  The absorbed report
follows the notation, proof-status labels, and cross-referencing conventions of the
`ProveIt` Fabius-function documentation corpus.

## Mathematical scope

The source reconstruction covers general compactly supported solutions of
constant-coefficient differential-functional equations, the geometric sinc-product density
`h_a`, the critical identity `h_2 = up`, moment and exact-value formulae, polynomial
reproduction by translates, and Rvachev's auxiliary `Fup_1` construction.  The expansion
connects these topics with probability, Thue-Morse/Prouhet cancellation, q-Pochhammer
symbols, Bernoulli cumulants, Bell polynomials, Strang-Fix theory, Fourier decay, and
Lambert-W endpoint inversion.

The attached English drafts had already been merged into the live repository by the time
this package was finalized.  Their Cantor-gap geometry, derivative equimeasurability,
`Fup_n` hierarchy, q-Gaussian derivative Gram kernel, theta-function Riesz bounds,
log-Weibull leading-jet law, and all-orders differentiated Edgeworth theorem are therefore
retained as current-corpus results rather than presented again as new.

The report's new current-snapshot results are:

1. **Exact Rogers-Szego/Gaussian-binomial orthogonalization.**  Gram-Schmidt on either
   normalized derivative parity tower has explicit q-binomial residual filters, an exact
   inverse triangular transform, scaled Rogers-Szego orthogonal polynomials, and a closed
   finite inverse Gram matrix.
2. **Schur-minor total positivity.**  Every mixed minor of the q-Gaussian kernel is an
   explicit Schur-Vandermonde product; consequently the infinite kernel is strictly totally
   positive, including arbitrary sparse derivative selections.
3. **Refined jet-tail asymptotics.**  The leading log-Weibull law is sharpened by the first
   unbounded `log log` correction, and the exact square-root-log exponential integrability
   threshold is proved, including divergence at the boundary.

All novelty statements are deliberately **corpus-relative**.  They are not claims of
worldwide historical priority.

## Regenerating figures and diagnostics

Python 3.10 or newer, NumPy, and Matplotlib are required.  From this directory:

```sh
python -m pip install -r requirements.txt
python experiments.py
```

The script writes figures to `figures/` and CSV diagnostics to `data/`.  It uses a fixed
random seed; Fourier inversions and symbolic coefficient checks are deterministic.  No
numerical computation is used as a substitute for a proof: every theorem is proved in the
LaTeX report, while the program checks normalization, signs, indices, determinant identities,
and predicted asymptotic error orders.

The package was tested with Python 3.13.5, NumPy 2.3.5, and Matplotlib 3.10.8.

## Source-reconstruction policy

The supplied `.tex` source is OCR-derived and contains damaged signs, superscripts,
factorials, and binary indices.  The report uses mathematical rather than literal fidelity:
printed pages are preferred where legible, invariant formulae are re-derived from adjacent
equations where forced, and unrecoverable strings are paraphrased rather than guessed.  The
appendices contain a repair ledger and an equation-by-equation crosswalk.

## Integrity

`ARRIVAL_CHECKSUMS.sha256` is preserved byte-for-byte as historical delivery evidence. It
is deliberately **not** a current-tree verification target: six of its rows name the
absorbed standalone TeX/PDF, scan/OCR, and two earlier lineage sources that were
intentionally removed; ten CSV rows hash the delivered CRLF bytes, while the repository
stores their LF-normalized equivalents; and its README row predates this editorial note.
Those arrival hashes remain meaningful against the archived delivery and repository
history, but running `sha256sum -c ARRIVAL_CHECKSUMS.sha256` in this reduced directory is
expected to fail.

`CHECKSUMS.sha256` is the operational current-state ledger. It covers all 22 retained files
other than itself, including the historical arrival ledger, and verifies completely against
the repository-normalized bytes. No deleted source, PDF, or scan has been recreated, and no
arrival hash has been rewritten.
