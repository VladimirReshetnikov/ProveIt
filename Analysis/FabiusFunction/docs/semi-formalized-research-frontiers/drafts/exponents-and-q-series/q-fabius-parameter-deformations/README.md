# q-Fabius parameter deformations

These reports study the normalized geometric q-Fabius family as its parameter
moves: the Gaussian/Edgeworth and large-deviation limit near q = 1, the
Lambert boundary regime, and local susceptibility and smooth response near
the Fabius parameter q = 1/2. Their limit and response calculations share
Bernoulli--Bell cumulant machinery while retaining complementary emphases.

| Package | Primary emphasis |
| --- | --- |
| [`fabius_q_frontiers_report/`](fabius_q_frontiers_report/) | Parameter-flow transport, convex order, Gaussian/Edgeworth limits, large deviations, and the Lambert boundary. |
| [`Continuous_Parameter_Edgeworth_and_q_Gevrey_Frontier/`](Continuous_Parameter_Edgeworth_and_q_Gevrey_Frontier/) | Continuous-parameter Edgeworth and Cornish--Fisher theory, large deviations, and quadratic q-Gevrey regularity. |
| [`Fabius_Flat_Parameter_Response_Dynamics/`](Fabius_Flat_Parameter_Response_Dynamics/) | q-susceptibility, tangent measures, flat parameter fronts, transform and moment response, and conditional smooth dynamics. |
