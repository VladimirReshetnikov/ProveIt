AN INVERSE-JET ATLAS FOR q-ANALOGS
===================================

This archive contains a 72-page research report developing parameter-wise
inverse theory for finite and infinite q-Pochhammer products, Gaussian and
q-multinomial coefficients, q-numbers, q-factorials, q-gamma, q-digamma,
q-beta, Euler q-exponentials, basic hypergeometric series, theta products, and
the geometric infinite-sinc product occurring in Fabius-Rvachev theory.

Contents
--------
inverse_q_analog_jet_atlas.tex
    Complete LaTeX source.

inverse_q_analog_jet_atlas.pdf
    Compiled 72-page report.

inverse_q_analog_experiments.py
    Fully commented SymPy/mpmath experiments. The script performs exact
    symbolic assertions and high-precision numerical checks.

numerical_checks.txt
    Audit trail generated by the Python script at 80 decimal digits.

SHA256SUMS.txt
    SHA-256 checksums for all other archive members.

Build the report
----------------
    latexmk -pdf -interaction=nonstopmode -halt-on-error \
      inverse_q_analog_jet_atlas.tex

Regenerate the computations
----------------------------
    python inverse_q_analog_experiments.py --digits 80 \
      --output numerical_checks.txt

Python dependencies
-------------------
Python 3.10 or later, SymPy, and mpmath. No network access is required.

------------------
