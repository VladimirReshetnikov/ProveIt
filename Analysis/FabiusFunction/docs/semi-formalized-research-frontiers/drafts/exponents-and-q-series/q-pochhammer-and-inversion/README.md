# q-Pochhammer theory and inversion

This subgroup pairs the comprehensive forward reference for q-Pochhammer
products and Gaussian coefficients with the canonical synthesis of their
branch-aware inverse and reversion theory. The inverse synthesis explicitly
uses the monograph as its broad forward-theory companion.
