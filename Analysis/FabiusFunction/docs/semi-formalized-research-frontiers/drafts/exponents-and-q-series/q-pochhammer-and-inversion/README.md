# Historical q-Pochhammer and inversion sources

This directory is now a provenance index; it contains no live publication
package. The canonical synthesis moved one level up to
[`q_pochhammer_q_binomial_monograph/`](../q_pochhammer_q_binomial_monograph/),
where the stable published path names both its TeX master and its 334-page PDF.
That document combines forward q-Pochhammer, Gaussian, hypergeometric, theta,
partition, Bailey, cyclotomic, interpolation, Thue--Morse, and
Fabius--Rvachev theory with the branch-aware inverse calculus, asymptotics,
certification, and research frontiers.

The former forward monograph and inverse-q synthesis are implementation and
provenance sources of the canonical successor, not sibling publications. The
three general guides were likewise retired after their independent material
was integrated. The completed
[`source_concordance.csv`](../q_pochhammer_q_binomial_monograph/source_concordance.csv)
records a reviewed disposition for all 547 source result environments in the
five-publication merge. Repository history and the two pinned audit revisions
preserve every historical source layout. All superseded manuscript PDFs were
removed; research-figure PDFs retained under the canonical `assets/` tree are
reproducibility evidence rather than alternate documents.

See the parent [topic index](../README.md) and the
[draft manifest](../../MANIFEST.md) for source disposition and arrival
history.
