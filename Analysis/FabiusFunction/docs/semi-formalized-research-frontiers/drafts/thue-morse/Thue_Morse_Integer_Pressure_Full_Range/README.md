# The full pressure positivity range at every integer order

For every integer m at least 2, every even coefficient of p_m(t/pi) at a degree strictly between 2m and 6m is positive. The analytic proof covers m at least 112. Exact directed-integer enclosures cover all 110 remaining orders and all 12,320 required coefficients. At m=2 the coefficient at degree 12 is negative, so the first excluded even degree cannot be included in a universal statement.

This is unrefereed ordinary mathematics with rigorous finite arithmetic certificates, not a Lean formalization. The stronger raw frozen-tail inequality remains open.

## Files

- `article.pdf`, `article.tex`: unified proof
- `certificates/`: exact scalar interval, Green, coefficient and cutoff checks; Python standard library only
- `finite/producer_v1.cpp`: the exact producer used for the complete calculation
- `finite/produce_guarded.cpp`: the same producer with explicit m>=2 and nonnegative precision checks
- `finite/audit_residual_enclosures.cpp` and `.py`: independent a posteriori Fourier residual verifiers, with independent tangent-ODE pressure conversion
- `finite/production_manifest.json`: every original pressure/trace hash and coverage count
- `finite/independent_manifest.json`: independent verification provenance and coverage
- `finite/state_indices/`: SHA256 of each canonical full integer state, including the exact scale and operator norms
- `finite/producer_versions.json`: both producer source hashes and the bitwise m=2 regression
- `inputs/`: the unchanged positive-triangle proof and versioned repository normalization source (not filed; see the editorial amendments below)
- `PROVENANCE.md`: source and mathematical scope
- `chunks_manifest.json`: interval ZIP ranges and SHA256 hashes

The five accompanying interval ZIPs contain `data/interval_mNNN.json`. Extract them into this package directory. All 110 original files are preserved without altering their runtime metadata. Their 37,070 nonconstant response orders correspond to 37,180 state records including the initial vector in each case. (These five archives were not delivered; see the editorial amendments below, and "Reconstructing the interval archives" for regenerating them.)

## Check the scalar proofs and delivered intervals

    python3 certificates/run_all.py
    python3 finite/check_coverage.py
    python3 finite/check_reference_provenance.py
    python3 finite/check_exact_reference.py

The scalar check includes 524,288 rational cells. Every trigonometric enclosure, comparison and sign decision is exact. The coverage checker validates file hashes, contiguous degree lists, positive rational lower endpoints and state-index coverage. Hashes identify the data; they are not a substitute for the arithmetic proof.

## Regenerate and independently verify the finite proof

Requirements: a C++17 compiler, GMP development headers/libraries, zlib development headers/libraries, and Python 3.11 or newer. No network access is needed once these ordinary build dependencies are available.

    g++ -O3 -std=c++17 finite/producer_v1.cpp -lgmpxx -lgmp -lz -o finite/produce
    g++ -O3 -std=c++17 finite/audit_residual_enclosures.cpp -lgmpxx -lgmp -lz -o finite/audit
    python3 finite/replay_one.py 24
    python3 finite/replay_all.py --jobs 4

`replay_one.py` computes every response order, matches every stored state hash, checks all pressure signs, and then propagates fresh error radii from exact Fourier residuals. The independent verifier does not trust the producer's solution evaluation or its error radii. Use m=2,...,111 to reproduce the whole finite complement. Completed local traces can be reused with `--reuse`; all hashes and independent residuals are still checked. A nonpositive lower endpoint is inconclusive and never accepted as a positive certificate.

The original producer is intentionally retained byte-for-byte. Compile `produce_guarded.cpp` instead for a domain-checked equivalent executable; the main batch used `producer_v1.cpp`. Only m>=2 is in scope. The Python independent verifier accepts a produced pressure JSON and an output JSON:

    python3 finite/audit_residual_enclosures.py finite/generated/interval_m024.json finite/generated/python_audit_m024.json

The Python version is intended for transparent low-order replay; the independent C++ implementation is substantially faster. Both were compared exactly at m=24 and m=111. The additional fraction-free exact solver and its complete m=24 rational reference are supplied as `finite/exact_fraction_free.cpp` and `finite/exact_reference_m024.json`; compile with GMP and run with arguments `24 output.json` to regenerate that cross-check. Reference timings are hardware dependent: the complete production batch took about eleven minutes on four processes, and the largest individual case took about two minutes. The compressed full traces total about 2.1 GiB. They are regenerated by the supplied producer rather than duplicated in the attachment; complete per-order hashes remain supplied.

## Reconstructing the interval archives (ProveIt, 2026-10-01)

The five interval archives were not delivered (see the editorial amendments
below). Their 110 files `data/interval_mNNN.json` (`m = 2..111`) are output
of the filed producer `finite/producer_v1.cpp`, which uses only exact GMP
integer arithmetic; the one run-dependent value it writes is
`runtime_seconds`, and the original value of that field, the byte count and
the SHA-256 of every delivered file are recorded in
`finite/production_manifest.json`. The files can therefore be regenerated
byte for byte.

Requirements: as in "Regenerate and independently verify the finite proof"
above (a C++17 compiler, GMP with `gmpxx`, zlib, Python 3.11 or newer). Work
on a copy of this directory: the commands write `finite/generated/` and
`data/`.

1. Build the producer and the independent verifier, and replay every order:

       cp -r Thue_Morse_Integer_Pressure_Full_Range /tmp/fr && cd /tmp/fr
       g++ -O3 -std=c++17 finite/producer_v1.cpp -lgmpxx -lgmp -lz -o finite/produce
       g++ -O3 -std=c++17 finite/audit_residual_enclosures.cpp -lgmpxx -lgmp -lz -o finite/audit
       python3 finite/replay_all.py --jobs 4

   (`python3 finite/replay_one.py M` does one order.) For each order this
   writes `finite/generated/interval_mNNN.json` with its full trace
   `interval_mNNN.json.trace.gz`, checks every state of the trace against
   `finite/state_indices/compact_mNNN.json`, runs the independent residual
   verifier (`independent_mNNN.json` and `.radii.gz`), checks its pressure
   bounds and fresh radii against `finite/independent_numeric_index.json`,
   and prints `m=M: all ... states match; both exact pressure enclosures
   pass.` With MinGW-w64 and static GMP and zlib libraries add
   `-DGMP_STATIC_COMPILATION -static` to both compilations.

2. Restore the delivered interval files and check them:

       python3 - <<'EOF'
       import hashlib, json, re
       from pathlib import Path
       Path('data').mkdir(exist_ok=True)
       for c in json.loads(Path('finite/production_manifest.json').read_text())['cases']:
           raw = Path('finite/generated', c['pressure_file']).read_bytes().replace(b'\r\n', b'\n')
           raw = re.sub(rb'"runtime_seconds":[^\n]*', b'"runtime_seconds":' + repr(c['runtime_seconds']).encode(), raw)
           assert hashlib.sha256(raw).hexdigest() == c['pressure_sha256'], c['m']
           Path('data', c['pressure_file']).write_bytes(raw)
       print('all 110 interval files restored byte for byte')
       EOF
       python3 finite/check_coverage.py
       python3 finite/check_exact_reference.py

   The script puts the recorded `runtime_seconds` in place of the new one
   (and turns the CRLF line endings of a MinGW build into LF), checks every
   file against its recorded SHA-256, and writes `data/interval_mNNN.json`
   beside `finite/`, where the archives were to be extracted. The two
   checkers then run unchanged. The traces in `finite/generated/` (about
   2.2 GB) are not part of the archives and may be deleted afterwards; they
   too equal the delivered traces recorded in
   `finite/production_manifest.json`, except that zlib on Windows writes 10
   instead of 3 as the operating-system byte of the gzip header.

Time and size: the delivery records 2,679 s of producer time and 1,707 s of
independent verification for the 110 orders (122 s and 78 s for `m = 111`).
Here `m = 80` took 55 s for both (47 s recorded), with peak memory 79 MB
(producer) and 83 MB (verifier), so the whole set takes one to two hours on
one core, or about a quarter of that with `--jobs 4`. The interval files
take 86,335,619 bytes (the five archives were 36,019,151 bytes), the
transient traces 2,241,279,140 bytes, and the verifier's outputs about as
much again as the interval files.

Tested on filing (2026-10-01), on copies: g++ 16.1.0 (MinGW-w64 UCRT) with
static GMP 6.3.0 and zlib 1.2.13, Python 3.14.4. `finite/replay_one.py`
passed for `m = 2, 3, 5, 24, 40, 60, 80`; the restored interval files of all
seven orders reproduce the recorded SHA-256 and byte counts, and so do their
traces once the operating-system byte is set to 3; `finite/check_exact_reference.py`
passed on the restored `m = 24`, and the per-order checks of
`finite/check_coverage.py`, restricted to these seven orders (the program
requires all 110), passed. Steps 1 and 2 were run verbatim, restricted to
`m = 2, 5, 24, 40`. The full set was not regenerated.

Tested on filing (2026-10-05, on a copy, Python 3.14.4): the five archives
match `chunks_manifest.json`, all 110 files match `pressure_sha256` in
`finite/production_manifest.json`, and the three checks pass
(`finite/check_coverage.py`: "110 orders, 12320 positive intervals, 37070

of `certificates/`, rely on bare `assert`s (37 in `finite/`, 45 in

without `-O`; the feedback-boundary package's `quick_checker_repair/` shows
the fail-closed alternative. Porting it here is left to the editorial pass.
