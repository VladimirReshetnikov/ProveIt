## Build ownership

This worktree has its own `.lake` whose `packages` is a directory junction to
the shared `C:\ProveIt\.lake\packages`, so the built Mathlib is reused while
the Fabius build outputs stay isolated.  Builds are strictly serialized, one
`lake build +<module>` per invocation, `LAKE_JOBS=1`.

Two operational findings, both reproduced here:

1. **The module target needs a `+` prefix.**  `lake build FabiusFunction.Basic`
   fails with `unknown target`; `lake build +FabiusFunction.Basic` works.
   `AGENTS.md` said "one module per `lake` invocation" without the syntax.
2. **Windows CRLF.**  A build-order file generated by Python in text mode
   yields `unknown target` (or, with the `+` prefix, `unknown module
   [anonymous]`) for every entry.  Pipe the list through `tr -d '\r'`.

## Mathematical summary

The all-orders expansion previously defined its coefficients only by a chain of
recursions.  This branch closes the chain:

- the differential jet recursion is solved in closed form with signed Stirling
  numbers of the first kind and harmonic numbers;
- the exponent coefficients are reduced to one power of `i` times a jet term
  plus a universal jet-free tail;
- every coefficient becomes an explicit finite sum over compositions, subsets
  and Gaussian moments;
- the second and third coefficients are computed explicitly for the first time;
- the highest-derivative term of the `j`-th coefficient is
  `(-1)^j Psi^{(2j)}/(2^j j! L^{2j})`, which explains the observed growth of the
  oscillation with the order.

Details, tables and an independent numerical verification against exact
rational values of `F(2^-n)` are in
[`../Small_Argument_Asymptotics/Small_Argument_Asymptotics.tex`](../Small_Argument_Asymptotics/Small_Argument_Asymptotics.tex).
