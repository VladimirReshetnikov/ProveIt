# Primary exposition gap register

This directory preserves small claims and derivations removed from the primary
Fabius exposition because they do not yet have exact, public Lean theorem
counterparts.

- [LaTeX source](Primary_Exposition_Gap_Register.tex)
- [Rendered PDF](Primary_Exposition_Gap_Register.pdf)

The register is a research-frontier document: its candidate statements are not
claimed as formal results. Promote an item only after its literal statement has
been proved in Lean, built, and cited from the primary exposition.
