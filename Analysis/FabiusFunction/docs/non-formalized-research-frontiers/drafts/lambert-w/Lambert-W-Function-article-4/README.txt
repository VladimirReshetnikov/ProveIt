THE LAMBERT W FUNCTION
======================

Contents
--------

Lambert-W-Function.tex
    Complete LaTeX source for the article.

Lambert-W-Function.pdf
    Rendered 66-page article.

lambert_w_experiments.py
    Fully commented numerical program.  It evaluates high-precision reference
    values, tests the Puiseux and logarithmic asymptotic expansions on both
    real branches, demonstrates the branch-safe logarithmic Newton iteration,
    and regenerates the four figure files and numerical_values.tex.

fig_real_branches.pdf
fig_branch_point_error.pdf
fig_asymptotic_error.pdf
fig_iteration_error.pdf
    Vector figures generated by lambert_w_experiments.py.

numerical_values.tex
    Small generated table included by the article source.

Rebuilding the article
----------------------

From this directory, run:

    latexmk -pdf Lambert-W-Function.tex

The source was tested with pdfLaTeX.  Standard TeX Live packages used include
amsmath, amssymb, amsthm, mathtools, booktabs, longtable, graphicx, tikz,
hyperref, cleveref, microtype, geometry, fancyhdr, enumitem, xcolor, and lmodern.

Regenerating the numerical material
-----------------------------------

Install Python 3 with mpmath, NumPy, and Matplotlib, then run:

    python3 lambert_w_experiments.py

The script is deterministic, uses no network access, and writes its outputs to
this directory.  It sets mpmath precision to 100 decimal digits for reference
computations.
