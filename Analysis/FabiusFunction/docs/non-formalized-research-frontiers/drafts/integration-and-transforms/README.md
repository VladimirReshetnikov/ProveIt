# Integration and transforms

Repeated integration, antiderivatives, and integral-transform calculus
for the Fabius and Rvachev functions: monomially weighted
antiderivatives, dyadic primitive ladders, Mellin-Newton antiderivatives,
inverse-quantile integrals, and transform dualities including fractional
calculus.
