FABIUS--RVACHEV INTEGRAL TRANSFORMS AND FRACTIONAL CALCULUS
===========================================================

Contents
--------
Fabius_Rvachev_Integral_Transforms_and_Fractional_Calculus.tex
    Main LaTeX research report.

Fabius_Rvachev_Integral_Transforms_and_Fractional_Calculus.pdf
    Compiled and visually inspected PDF.

numerical_experiments.py
    Fully commented reproducible numerical experiments.  It generates the
    numerical results, exact moment table, and two figures.

numerical_results.txt
    Machine-readable output from the numerical experiments.

moment_table.tex
    Exact rational moment table included by the main LaTeX source.

fractional_dilation_defect.png
gamma_zeta_fractional_defect.png
    Figures generated by numerical_experiments.py and included in the report.

Build
-----
Run numerical experiments (optional):
    python numerical_experiments.py

Compile the report from this directory:
    latexmk -pdf -interaction=nonstopmode \
      Fabius_Rvachev_Integral_Transforms_and_Fractional_Calculus.tex

Python dependencies
-------------------
numpy, scipy, sympy, mpmath, matplotlib

Proof and novelty status
------------------------
The report labels results as proved here, derived from audited repository
inputs, numerical, or conjectural/open.  "New" means new relative to the
recursive ProveIt/Analysis/FabiusFunction/docs LaTeX corpus audited on
27 August 2026, not an exhaustive claim of worldwide publication priority.
