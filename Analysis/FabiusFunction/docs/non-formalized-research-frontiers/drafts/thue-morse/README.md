# Thue-Morse

The Thue-Morse side of the corpus: the unified formula atlas for the
sequence itself, and the finite-block calculus connecting Thue-Morse
blocks to the Fabius/Rvachev transforms (block bridges, the zeta-Lambert
tail calculus, q-Richardson weights). Both documents carry extensive
inline Lean crosswalks; the finite-block calculus is, as of 2026-08-28,
formalized end to end in its analytic-logarithm, remainder, and
measure-refinement layers (see its *Formal version* paragraphs).
