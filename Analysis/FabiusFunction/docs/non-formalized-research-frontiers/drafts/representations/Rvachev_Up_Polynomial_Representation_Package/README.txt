Exact Polynomial Synthesis by Finite Rvachev Up-Function Dictionaries
=====================================================================

This package accompanies the research report prepared on 28 August 2026.
It studies exact representation of arbitrary polynomials on a compact interval
by finite signed sums of shifted and scaled copies of Rvachev's up-function.

Package contents
----------------

1. rvachev_polynomial_representation_report.tex
   Complete LaTeX source of the 25-page report.

2. rvachev_polynomial_representation_report.pdf
   Rendered A4 PDF.

3. rvachev_polynomial_representation.py
   Commented exact symbolic implementation of:
   - global moment deconvolution;
   - dense, pair-compressed, full-recurrence, and output-sensitive synthesis;
   - the q-integer/cyclotomic annihilator;
   - the one-scalar and finite Thue-Morse polynomiality certificates;
   - central-basis determinant experiments;
   - independent inverse-Fourier numerical verification.

4. generate_report_data.py
   Recreates all exact and numerical data files shipped with the report.

5. monomial_sparse_coefficients.csv
   Exact endpoint-basis coefficients for t^d through d=8.

6. central_basis_determinants.csv
   Exact determinant evidence through d=12.

7. numerical_residuals.csv
   Independent Fourier-quadrature residuals through d=6.

8. operator_and_annihilator_table.txt
   Low-order coefficients of A_d and H_d.

9. exact_checks.txt
   Summary of exact cross-checks.

10. requirements.txt
    Python package requirements.

Principal proved results
------------------------

For degree at most d and M=2^d, the one-cell local space generated by the
2M active integer shifts of (1/M) up((t-k)/M) has exact dimension d+2, and its
polynomial part is exactly Pi_d.  A proved endpoint basis therefore represents
every P in Pi_d by d+2 common-scale atoms.  No fixed dictionary of fewer than
d+2 nontrivial affine up-atoms can span all of Pi_d on an interval.

The complete alias annihilator is

    A_d(z) = product_{m=1}^d (1+z+...+z^(2^m-1)),

and an output-sensitive O(d^2)-arithmetic algorithm obtains the d+2
coefficients without constructing an exponentially long dense vector.  On J
normalized cells, the construction uses J+d+1 atoms.

Reproducibility
---------------

Python 3.11 or later is recommended.

    python -m venv .venv
    . .venv/bin/activate                 # Windows: .venv\Scripts\activate
    pip install -r requirements.txt

Run exact tests:

    python rvachev_polynomial_representation.py --self-test 10

Print exact monomial examples:

    python rvachev_polynomial_representation.py --examples

Construct a custom polynomial representation on two normalized cells:

    python rvachev_polynomial_representation.py \
        --poly "3*t**4-2*t+7" --degree 4 --cells 2

Recreate all tables:

    python generate_report_data.py

Compile the report, with a TeX Live installation containing latexmk:

    latexmk -pdf -interaction=nonstopmode \
        rvachev_polynomial_representation_report.tex

Exact versus numerical computations
-----------------------------------

All synthesis coefficients, recurrences, certificates, and determinant data
are computed over exact SymPy rationals or integers.  The inverse-Fourier
up-function evaluator is deliberately independent of the synthesis formulas;
it is used only as a numerical diagnostic.  Sparse endpoint bases can exhibit
large cancellation at higher degree, so the numerical residuals should not be
interpreted as limits on the exact identities.
