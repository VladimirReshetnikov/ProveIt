Asset contents
--------------

numerical_experiments.py
  Fully commented exact-symbolic and high-precision numerical checks.  It
  verifies the Walsh moment and q-binomial identities, compares four finite
  transform representations, computes Haar energies and derivative norms, and
  regenerates both figures and numerical_results.txt.

numerical_results.txt
  Deterministic output ledger from numerical_experiments.py.

multiresolution_convergence.pdf/.png
haar_energy_asymptotics.pdf/.png
  Figures generated by the Python script.  The consolidated volume embeds the
  PNG copies to avoid Type-3 fonts from the generated PDFs.

SHA256SUMS.txt
  Checksums for the deliverable files.

Reproducing the calculations
----------------------------

Python requirements:
  Python 3.10 or newer
  mpmath
  numpy
  sympy
  matplotlib

From this directory, run:

  python numerical_experiments.py

The script uses no network access and writes its output next to itself.
The supplied run used 55 decimal digits, 160 sinc-product factors, and 200
half-integer Fourier modes.  It completed 1016 exact Walsh-moment checks and 35
q-binomial aggregate checks with no failures.

Building the report
-------------------

A TeX Live installation containing the packages named in the consolidated
preamble is sufficient.  From this asset directory, build the canonical source
with exactly three passes:

  cd ../..
  pdflatex -interaction=nonstopmode -halt-on-error Representation_Frontiers.tex
  pdflatex -interaction=nonstopmode -halt-on-error Representation_Frontiers.tex
  pdflatex -interaction=nonstopmode -halt-on-error Representation_Frontiers.tex

Status convention
-----------------

The report distinguishes repository input, statements proved in the report,
numerical checks, and explicitly conjectural frontier directions.  "New" means
not located in the audited ProveIt LaTeX corpus; it is not a claim of worldwide
priority.
