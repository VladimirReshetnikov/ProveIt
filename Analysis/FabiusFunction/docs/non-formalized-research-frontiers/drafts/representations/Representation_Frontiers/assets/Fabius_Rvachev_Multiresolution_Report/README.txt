Dyadic Multiresolution and Product-Series Representations
in the Fabius-Rvachev System
=========================================================

Research report prepared for Vladimir Reshetnikov's ProveIt project.

The report audits the recursively collected LaTeX corpus under
Analysis/FabiusFunction/docs, treats the current primary exposition and recent
frontier manuscripts as the nonduplication baseline, and develops a separate
multiresolution family of representations.

Archive contents
----------------

Reproducing the calculations
----------------------------

Python requirements:
  Python 3.10 or newer
  mpmath
  numpy
  sympy
  matplotlib

From this directory, run:

  python numerical_experiments.py

The script uses no network access and writes its output next to itself.
The supplied run used 55 decimal digits, 160 sinc-product factors, and 200
half-integer Fourier modes.  It completed 1016 exact Walsh-moment checks and 35
q-binomial aggregate checks with no failures.

Building the report
-------------------

A TeX Live installation containing the packages named in the preamble is
sufficient.  From this directory, run:

  latexmk -pdf -interaction=nonstopmode -halt-on-error \
    fabius_rvachev_multiresolution_report.tex

The figure PDF files must remain beside the LaTeX source.

Status convention
-----------------

The report distinguishes repository input, statements proved in the report,
numerical checks, and explicitly conjectural frontier directions.  "New" means
not located in the audited ProveIt LaTeX corpus; it is not a claim of worldwide
priority.
