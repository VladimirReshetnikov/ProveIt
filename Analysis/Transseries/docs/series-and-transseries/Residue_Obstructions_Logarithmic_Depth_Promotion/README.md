## Main results

The model is the real, reverse-well-ordered Hahn field generated by x and a
fixed finite number n of iterated logarithms. The derivative acts strongly
by the usual monomial derivative rule.

1. Exactly m residue moments characterize the image of the mth derivative.
2. For L = P(xD) + sum(a_j (xD)^j), assuming every nonzero a_j has largest
   outer x-exponent at most -epsilon for one common epsilon > 0, a finite
   residue matrix determines solvability at the original logarithmic depth.
3. The matrix requires at most floor((largest real root - smallest real root)
   / epsilon) perturbation factors. Kernel and cokernel have dimension
   r - rank(M), with r the sum of the real-root multiplicities.
4. One additional logarithm suffices. With s distinct real roots, a particular
   solution has degree at most s in it, while all homogeneous solutions have
   degree at most s-1. Repeated roots do not add to s.
5. An explicit family has a Jordan-shift obstruction matrix and attains both
   degree bounds. Its second-order member has actual real solutions with an
   explicit error certificate and a signed factorial-series remainder.

These are conventional mathematical proofs. This package is not a Lean
formalization and has not undergone independent peer review. The manuscript
acknowledges the established theory of Hahn fields, strong derivations,
operator inversion, and perturbative elimination. It does not claim an
exhaustive novelty search or a solution of all transseries differential
equations. Formal support estimates and analytic error bounds are distinct.

## Verification

```sh
python -m pip install -r verification/requirements.txt
python verification/verify.py
```

Recorded environment: Python 3.13.5; SymPy 1.14.0; mpmath 1.3.0.

The recorded run reports 212 exact rational block checks and 24 exact
finite-dimensional matrix cases, with seed 20260929, all passing. The
sharpness coefficients are checked for s = 1,...,6. The block test uses
lower guard terms through exponent -28 and checks residuals only at
exponents at least -10. Numerical output is illustrative high-precision
floating-point arithmetic, not interval arithmetic.

The checks do not verify arbitrary infinite Hahn supports, the general
theorems, or their proof-assistant formalization. Those claims rely on the
proofs in the article.

## Editorial amendments (ProveIt, 2026-09-29)

The package was filed unedited in batch 46 (see `docs/incoming/README.md`).
The following changes were made afterwards; each change to the article is
marked in the source by a `% ed. (2026-09-29)` comment, and every visible
addition is an unnumbered "Editorial note (ProveIt, 2026-09-29)", so no
theorem, section or equation number changed. Its repository paths were
already current (the snapshot postdates the move to `Analysis/Transseries`),
so none needed updating.

- `residue_fredholm.tex`:
  - Preamble: the unnumbered `ednote` environment.
  - After Theorem 3.1 (`thm:residue`): the identity `Res_n ∘ D = 0` and the
    non-membership of `log_{n+1} x` are the canonical volume's
    `plt:thm:ext-tower-strict` (with `𝔫_n^{-1} = ρ_n`), which the article
    re-derives without citing; the article strengthens it to exactness of
    the residue sequence, with the explicit primitive `I_n`, and to `D^m`
    (Theorem 4.1). Neither bears on `plt:rmk:ext-open-depth`.
  - Section 11, "The exact minimal power of the promoted logarithm" and
    "Matrix systems and nonreal indicial roots": the later package
    `../Hahn_Fuchsian_Resonance_Analytic_Normalization/` answers the
    homogeneous half of the first and the Jordan-chain part of the second
    for first-order real-spectrum systems at depth 0 (`dim ker B^{d+1}`;
    the nilpotency index of `B = N + ΣR_ρ`); forced equations, depth
    `n ≥ 1`, higher-order matrix polynomials and nonreal roots stay open.
  - Section 11, "Other ordered exponent groups": the non-Archimedean
    reversion package `../Reversion_Beyond_Archimedean_Valuations/` draws
    the analogous separation for reversion; the operator question stays
    open.
- `residue_fredholm.pdf`: rebuilt from the amended source (`latexmk -pdf`):
  27 pages (26 as delivered), no errors, undefined references, multiply
  defined labels, duplicate destinations or overfull boxes.
- `verification/verify.py`: `verification/results.json` is written as UTF-8
  with `newline="\n"`, so a rerun on Windows no longer produces CRLF. A
  rerun of the amended program (Python 3.13.5, SymPy 1.14.0, mpmath 1.3.0)
