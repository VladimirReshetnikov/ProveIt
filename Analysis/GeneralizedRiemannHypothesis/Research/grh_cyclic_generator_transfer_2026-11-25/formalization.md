# Lean implementation plan (not compiled)

Upstream: lsernau/grh-lean, commit 72fead102f663d5c7a407964a13dc0cf9d977207. The exact inspected blob hashes are in source_map.tsv. This is an interface plan, not a claim that the current repository already has a complete Artin L-function API.

## Stage 1: finite-dimensional linear algebra and characters

1. Define a fixed-space dimension defect `defect(V, g) = dim V - dim Fix(g)` and prove it is constant under conjugation and depends only on the cyclic subgroup generated by `g`.
2. Prove `codim (intersection of fixed spaces) ≤ sum codim` for a finite list, by induction using the dimension identity for `inf` and `sup` of submodules.
3. Show `W_C = Reg_G - Ind_C 1 = Ind_C (Reg_C - 1)` and that its inner product with a restriction character equals the fixed-space defect. Use finite induction/restriction reciprocity and decomposition of cyclic regular representation. The inspected `Lib/General/Groups/VirtualCharacters.lean` contains virtual-character infrastructure and restrictions to cyclic subgroups, but the exact needed signatures must be checked.
4. Prove the primary-component decomposition in finite cyclic groups and the character trace inequality `d - re χ(g) ≤ 2 * defect(V,g)` using diagonalization of a finite-order operator. A finite group class function with actual restrictions to all cyclic groups and all selected Sylow groups then admits the quantitative detection theorem by the proof in §2.
5. Prove the explicit Sylow construction recursively on blocks of sizes p^a; use Legendre's formula, and build the even subgroup via pairwise products of the bottom swaps. The Python checks are finite tests only.

## Stage 2: analytic order interface

Formalize or import Artin meromorphic continuation by Brauer induction; Artin induction/restriction; the factorization of Dedekind zeta; nonprincipal finite-order Hecke L-functions' holomorphy and boundary nonvanishing; monomiality of p-groups. These are classical external inputs, not consequences of the exported Dirichlet endpoint. The inspected HeckeContinuation file is explicitly much narrower (real argument and local continuation near 1). Do not silently reuse it as full complex continuation.

Define the Heilbronn virtual character as the irreducible expansion with coefficients `ord_ρ(L_χ)`. Prove restriction to cyclic and p-subgroups is an actual character using monomiality and nonnegative orders. The abelianization pairing is zero off the critical line by `Main.LFunction_ne_zero_of_half_lt_re`, after connecting finite abelian Artin L-functions over Q with Dirichlet L-functions. Apply Stage 1.

## Stage 3: analytic criterion and common window

Define the prime-only statistic and prove the Mellin identity via integral/sum exchange on Re s > 1. Prove normal convergence of the omitted higher-prime-power series on Re s > 1/2. Establish the residue sign and either generalize `IsPolar.landau` to a half-plane-specific meromorphic domain, or formalize the positive-transform proof in §3. The necessity direction uses an effective Chebotarev theorem under Dedekind RH, not the source's existence-only Chebotarev lemma.

For the linear-window theorem use Cauchy derivative bounds, `laplace_pow`, the normalized Gamma integral, and exponential tail tests. The source's `IsPolar.eventually_moment_le` is a starting point; prove the common uniform radius and the bounds for a finite family. The exact endpoint target is a linear-window analogue of `IsPolar.exists_window_sub_mul_le`, adding a removability hypothesis at s=1 if required. Check source's primeError instance supplies it. Once formalized, the window [t,Lt] lies inside the original [t,t²] eventually, so no change to the original arithmetic estimates is needed.

## Stage 4: genuinely new arithmetic (open)

The comparison inequality in §6 is a separate goal, not an axiom to discharge using tactics. It needs an explicit integral-form construction, spanning estimate, and twist/covolume lower estimate sensitive to nonabelian Frobenius. No Lean source for this step is supplied; no `sorry`-based theorem is presented as a proof.
