PUBLISHED VERIFICATION EVIDENCE

Source: https://math.mit.edu/~drew/shortgrh/
Publisher: Andrew V. Sutherland, MIT.

These are selected machine-generated verification logs and SHA-256 manifests.
They are retained byte-for-byte; download_manifest.json records source URLs,
retrieval times, sizes, and hashes. No upstream proof sources or external
shell scripts are bundled here. The checksum lists reference more files than
this selected subset.

The original local audit checked 23 downloaded files against the publisher
manifest. The packaged subset allows a smaller reproducible comparison;
the output records the exact number of files present. Hash matching is
content verification, not a local run of the proof checkers.

readable-memory-guard.log records an earlier run stopped for memory; it
is not a failed proof verdict. The later readable Comparator and standalone
checker outputs report successful completion. See the report for context.
