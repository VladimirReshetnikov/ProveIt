A sharp residue cutoff for spanning trees in abelian Cayley towers
Research supplement, 26 November 2026

report.tex and report.pdf: written proofs and sources.
Build on a standard TeX installation with pdflatex report.tex (twice).
verify.py: exact-arithmetic checks. Requires Python 3 and no dependencies.
verification.txt: replay output. The independent cofactor computations do
not use the cyclotomic arithmetic. The proofs are not kernel-checked in Lean.
SHA256SUMS: run sha256sum -c SHA256SUMS after extracting the archive.
