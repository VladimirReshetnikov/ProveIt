5. WHAT WAS AND WAS NOT REPRODUCED

No new local Lean/lake build, kernel replay, independent-checker replay, or
#print axioms run was performed in this analysis workspace. The upstream
README reports these checks and a three-axiom result; that is upstream
reported evidence, preserved in its original README, not a new local result.
The new mathematical extensions in this report are human mathematical
arguments; their supplied finite computations are not Lean formalizations.

code/a5_detector.py checks finite A5 permutation-character calculations and
the explicit polynomial certificate. It does not prove the missing analytic
prime-sum bound required for nonabelian RH.

code/genus_certificate.py checks exact rational inequalities, table ranges,
and the illustrative discriminant. It does not reprove class field theory,
the Bach--Sorenson prime bound, the published class-group census, or GRH.

code/torsion_checks.py checks finite illustrations of positive-excess
inequalities, cyclotomic examples and exact maximal-order counterexamples.
It does not establish the infinite-family analytic extension by computation.
Its large order illustration is explicitly an approximate scale; the small
harmonic certificate and the algebraic examples use exact arithmetic.

6. REPRODUCTION

From the archive root, run:
    bash code/reproduce.sh

To also repeat the full-repository static inventory, supply a complete,
clean checkout of the pinned GRH repository:
    bash code/reproduce.sh /absolute/path/to/grh-lean

The script verifies the included excerpt hashes, reruns the three finite
certificates, regenerates the genus CSV from its JSON, and rebuilds report.pdf
with latexmk if it is installed. The optional source inventory requires Git
and checks the clone's commit. It neither fetches repositories nor installs
dependencies, and it does not run Lean. The supplied source_audit.py checks
HEAD but does not itself reject local modifications; use a clean checkout.

Requirements: Bash, Python 3, and SymPy for torsion_checks.py. The A5 and
genus scripts use only the Python standard library. Optional static source
reproduction additionally requires Git and the complete pinned upstream
clone. Optional PDF reproduction requires latexmk, pdflatex, and the TeX
packages named in report.tex. To select a Python interpreter, set
GRH_REPORT_PYTHON before invoking reproduce.sh.

The upstream build instructions are preserved in evidence/upstream/README.md
and evidence/upstream/grh/README.md. Running them is a separate verification
task with Lean 4.35.0, pinned Mathlib and the full upstream development.
