# Certified zero counts from real prime data

Research note, 26 November 2026. A derivative-free (beyond the sampled logarithmic derivatives) rational-binomial filter theorem for Dirichlet L-functions, using the proved Dirichlet GRH and classical entire-function theory.

## Deliverables

- `paper.tex`, `paper.pdf`: complete theorem, proof, explicit rate, source analysis, certified numerical method, references and limitations.
- `zero_count.py`: exact rational filter coefficients, interval propagation, and three exact synthetic tests. Optional `--zeta` uses mpmath only as a noncertified cross-check.
- `certified_zeta.py`: standard-library, outward-rounded interval computation for the zeta count at height 8. Analytic series tails are proved in the paper. Relies on the documented correct rounding of Python Decimal elementary operations.
- `zeta_certificate.json`: exact input interval endpoints in units of 10^-100, and rational filter parameters, generated by the certified evaluator.
- `verify_certificate.py`: independent rational certificate checker, given the input enclosures. Run `certified_zeta.py` to regenerate and substantiate those enclosures.
- `experiments.txt`, `certified_experiment.txt`, `verification.txt`: outputs of the executed checks.
- `SOURCE_AUDIT.md`, `FORMALIZATION.md`: provenance, dependencies, and proposed Lean decomposition.

## Reproduction

```sh
python3 zero_count.py
python3 certified_zeta.py
python3 verify_certificate.py
latexmk -pdf paper.tex
```

Optional noncertified cross-check: `python3 zero_count.py --zeta --n 16 --T 8` (requires mpmath).

## Status and limitations

The theorem has a complete classical mathematical proof. The GRH input is the machine-checked result in lsernau/grh-lean; the new theorem was not checked in Lean. The numerical certificate was executed, and its interval evaluation is justified mathematically, but is not a proof-assistant certificate. The sample zero-free interval was already known. A limited literature search did not identify the exact rational-binomial certificate; priority and publication novelty are not guaranteed. The method may be ill-conditioned, particularly for tightly spaced nodes; no complexity or performance superiority claim is made. If the threshold is exactly a zero height, the limiting strict and inclusive counts differ and the integer-equality termination test need not succeed.
