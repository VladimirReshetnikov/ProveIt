# Exclusion audit of the existing GRH simplification proposals

Snapshot: `VladimirReshetnikov/ProveIt`, commit `9050b04000647d588d0c78d945180abcd3b0bcf7`.
Scope: every one of the 18 proposal directories; all main README summaries; all TeX section structures; mathematical statements, integration targets, and future-work passages relevant to novelty. The associated manifest records 59 TeX, README, and integration-plan files. This is a mechanism-focused novelty audit, not an independent verification of every existing proof or every auxiliary script.

The corpus is considerably broader than its five original proposal bundles. Several later bundles duplicate or strengthen earlier mechanisms. A new proposal should compare with the strongest existing variant at each interface, not merely with the original readable proof.

## Distinctions needed in a new proposal

1. A new short-form lattice argument must differ both from flag-adapted rows and from signed gain accounting.
2. A new local Hecke argument must differ both from integer Pieri counting and from orbit-trace invariant averaging / truncated Smith factors.
3. A new local sharpness argument must differ from two/three-factor CM norm cancellation and four-copy padding.
4. A new determinant/exchange argument must differ from normalized orbital coinvariants and from Gram-dual integral adjoints.
5. A new torsion selection argument must beat or simplify the common-shell Newton construction, not just recover dimension independence.
6. A new finite-field label condition is unlikely to be worthwhile: four existing bundles already cover both norm-divisibility preserving and weakened scalar-order routes.
7. Changing translate selection by another generic concentration lemma duplicates the centered/random-product family unless it exploits new actual automorphic structure.
8. Better numerical constants alone are a weaker contribution than removing a distinct construction and its proof dependencies.
