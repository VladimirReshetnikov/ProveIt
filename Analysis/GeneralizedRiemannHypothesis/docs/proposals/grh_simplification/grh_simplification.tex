\vspace{12mm}
{\huge\bfseries Shortening the determinant\\[3pt]
and branching arguments\par}
\vspace{5mm}
{\Large in the Lean RH / Dirichlet-GRH proof\par}
\vspace{9mm}
{\large Direct height certificates, exact power descent,\\
and a norm bound from one highest-weight vector\par}
\vspace{10mm}
\color{black}
\textbf{Recommendation.}
Replace exact absolute-value metadata for exchange scalars by additive bounds
on their normalized squared moduli. Add the exact power-descent lemma for
\code{HeightLe}, so that this change preserves the current unsquared determinant
estimate and all constants in Theorem C. Independently, replace the branching
operator's full evaluation-vector argument by Schur's lemma and one calibrated
highest-weight coefficient.

\textbf{What is established here.}
The height lemma and an abstract determinant/cost recurrence have been checked
with the repository's pinned Lean and Mathlib versions. The report supplies the
mathematical derivation of both refactors, identifies the source interfaces,
audits all 18 existing proposal bundles, and separates checked components from
integration work.

\textbf{Attribution.}
Square-cost bookkeeping, determinant-first induction, and the
Gram-adjoint/Schur branching argument have precedents in the compact edition.
This report credits those sources. Its additions include an exact height
root lemma, guarded additive budgets, a direct unit-tensor calibration,
and a migration plan for the readable proof.
