## Patch A: the finite evaluation-module certificate

1. **Introduce a finite evaluation module.** Given the existing `Φ`, `z`, `p` and `N`, define `V_Q` as the O-span in the quotient of the images of `Φ (z g)`, for any enlarged relation module `Q ≥ N`. Treat the quotient as an O-module by restriction of scalars. Prove it is finitely generated (it is a submodule of the image of a finite free module over a DVR), killed by `p`, and finite length. Do not assume the full R-module quotient is finite length. Use the source's `QuotSpan p` as the dualizing module, and keep the `Unit`-indexed coordinate of `formsMod` in the interface.
2. **Duality.** Prove restriction to a submodule of a finite p-torsion module is surjective for maps into `QuotSpan p`. One direct proof extends one generator at a time, using the equality of the annihilator of `π^(m-k)` with the image of `π^k` in O/(p). Alternatively use a library theorem for the self-injectivity of the quotient DVR ring if present. No theorem about injectivity as an O-module of all of O/(p) is valid; the ambient modules must be killed by p. Prove point separation and length equality from elementary divisors. Then prove the equivalence `formsMod Φ z Q p ≃ₗ[O] (V_Q →ₗ[O] QuotSpan p)` by extending a functional to the image of Φ. This avoids assuming `z` spans all coordinates.
3. **Detection relations.** Given `A : Set G`, let W be the O-span of evaluation vectors on A. Use the dual restriction theorem to identify `relLength Z (.pi A ⊥)` with `length O W`. Choose cyclic elementary-divisor generators `w_i`, lift to E, and add their R-spans. For each generator, the appropriate power of a uniformizer annihilates it modulo N. Reuse `fittingIdeal.mul_mem_of_smul_mem` (line 516, see source audit). Induct over the generators, not over a strictly decreasing chain of function modules. Derive `π^length(W) * Fitt(K) ⊆ Fitt(N)`.
4. **Triangle.** Retain the precise hypotheses of `HasTriangleCost`. For each j in I, add the difference of the two φ-evaluation vectors. The previously added relations and the source hI hypothesis give the required τ equalities for all members of `formsMod` of the current quotient. Dual separation supplies `C*X_j*v_j ∈ Q_j`. Reuse one-vector Fitting transport; the existing `exists_ge_mul_prod_mem` can be retained if it is convenient. Do not substitute values for the X variables at this stage.
5. **Specialize.** Set `T₀=T + ker(constantCoeff) • ⊤`. Identify `E/T₀` with `O^s / eval₀(T)`. Because `Φ(z g)` equals the g-th basis vector modulo N, `V_T₀` is the entire quotient and `p O^s ⊆ eval₀(T)`. Find a row basis of the full-rank DVR submodule `eval₀(T)`; the existing Hermite/Smith infrastructure is imported by `FittingIdealsAndLengths`. Use elementary divisors to show determinant valuation equals quotient length. If a basis theorem supplies an inequality in the needed direction instead, it suffices for the old interface. Lift each row to T and form its determinant D(X). Prove `constantCoeff D` equals the determinant of the row basis.
6. **Finish.** With `S_* = formsMod Φ z T₀ p`, prove S_* satisfies the final cost hypothesis; use the same equalities as the old proof. Add lengths and bound `length(S_*[C])` by `#s * addVal O C`, using at most #s cyclic factors. Handle C=0 and empty indices explicitly as in the paper. Return `F=π^length(W)*C^#I*D`. Keep the exact public statement at `FittingBlock.lean:137`; optionally expose a stronger theorem with actual torsion length and use it to derive the old theorem. Do not modify the Selmer estimate or the coefficient target.

## Patch B: direct Cayley–Hamilton

1. Keep the existing `amitsur_charpoly_mem_of_span` and coefficientwise map `ρX` from `RibetMethod.lean`. Simplify the block-span proof with single elementary blocks. For an off-diagonal block, prove the flattened characteristic polynomial via a permutation or block-triangular identity, not mere nilpotence over an arbitrary commutative ring.
2. In `exists_ribet_polynomial`, use the existing quotient `Q = 𝔞.ringCon.Quotient`. Define the action of `Λ[X]` on Q by left multiplication for constants and right multiplication for X. The coefficient actions commute with X, so use the universal property of the central polynomial ring. The current `mul_aeval_eq_zero_of_adjugate` already works with this convention; reuse relevant ring-action pieces rather than add another incompatible evaluation definition. Extend to the matrix action on Q^K. The action factors through the coefficientwise representation in the following sense: if a polynomial matrix maps to zero under the flattened `ρX`, each coefficient belongs to `ker ρ ⊆ 𝔞`, hence acts by zero.
3. From `hB`, choose `B₁` exactly as in the old proof. Set `D_X = B.map C - X • B₁.map C`; establish that it annihilates y in Q^K. Use Amitsur to choose lifted coefficients of the characteristic polynomial of the flattened `ρX D_X` in R[X]. Define the leading coefficient as 1 (no injectivity of R→L is needed). Cayley–Hamilton implies the lifted characteristic polynomial evaluated at D_X has zero image; hence it acts by zero. All positive powers kill y. The constant coefficient, with the determinant sign, gives the required `P`.
4. Prove the constant term of `P` under specialization is the original flattened determinant; reuse the `charpoly`/`det` identities already present. Prove the two trace conclusions exactly as in the old proof. Keep the public theorem at line 216, including its weaker spanning hypothesis and trace clauses.
5. After building, search callers and delete `exists_adjugate_polynomial` and `mul_aeval_eq_zero_of_adjugate` only if no longer used. Do not delete the global Amitsur or general adjugate library if used elsewhere.
